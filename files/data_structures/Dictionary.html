Data Structures Dictionary

Terms used in the course, each with a short definition and the chapter where it is explained. The chapter column links to that chapter's slides.

TermDefinitionChapter
abstract data type (ADT)A specification of a data type by its values and operations only, saying what the operations do but not how they are implemented.1 · Introduction
accumulatorA parameter that carries the partial result down the recursive calls, so that a tail-recursive method has nothing left to do after its call returns.4 · Recursion
adaptable priority queueA priority queue that can also remove an arbitrary entry or change its key, usually by keeping location-aware entries.11 · Priority Queues and Heaps
adjacency listA graph representation that stores, for each vertex, a list of its neighbors; it uses O(n + m) space and suits sparse graphs.14 · Graphs
adjacency matrixA graph representation as an n × n table whose cell [u][v] records whether, or with what weight, an edge joins u and v.14 · Graphs
adjacentSaid of two vertices joined by an edge; each is then a neighbor of the other.14 · Graphs
agingRaising the priority of a waiting item step by step over time, so that low-priority items are not starved by newer high-priority ones.11 · Priority Queues and Heaps
algorithmA finite, unambiguous sequence of steps that solves a problem, taking an input and producing the correct output in a finite time.1 · Introduction
algorithm analysisThe study of how much time and memory an algorithm needs as a function of its input size, used to compare and predict performance.2 · Algorithm Analysis
aliasingReaching one object through two or more references, so that a change made through one reference is seen through the others.1 · Introduction
amortized analysisAnalysis of the average cost per operation over a worst-case sequence of operations, so that rare expensive steps are spread across many cheap ones.6 · The List ADT and Java Collections
ancestorA node on the path from a given node up to the root: its parent, its parent's parent, and so on.9 · Trees
arrayA fixed-size sequence of elements of one type stored side by side in memory, each reached by an integer index in constant time.3 · Arrays
array covarianceJava's rule that an array of a subtype counts as an array of its supertype, so a wrong store is caught only at run time with ArrayStoreException.3 · Arrays
ASCII (American Standard Code for Information Interchange)A 7-bit character code assigning the numbers 0 to 127 to English letters, digits, punctuation and control characters.1 · Introduction
asymptoticDescribing how a function behaves as its input grows without bound, ignoring constant factors and lower-order terms.2 · Algorithm Analysis
autoboxingJava's automatic conversion of a primitive value into an object of its wrapper class, for example int to Integer.6 · The List ADT and Java Collections
average caseThe expected running time of an algorithm over all inputs of a given size, under an assumed probability distribution of inputs.2 · Algorithm Analysis
AVL treeA self-balancing binary search tree in which the two subtrees of every node differ in height by at most 1, restored by rotations.10 · Search Trees
B+ treeA B-tree variant that keeps all records in the leaves, linked in key order, while internal nodes hold only keys for routing.10 · Search Trees
B-treeA balanced multiway search tree whose nodes hold many keys and children, keeping all leaves at one depth; used for disks and databases.10 · Search Trees
back edgeIn a depth-first search, an edge that leads from a vertex to one of its ancestors still in progress; its presence reveals a cycle.14 · Graphs
backtrackingA recursive search that builds a solution one choice at a time and undoes the last choice as soon as it cannot lead to a solution.4 · Recursion
balance factorFor a binary tree node, the height of its left subtree minus the height of its right subtree, an empty subtree counting as -1.10 · Search Trees
balanced parenthesesThe stack problem of checking that every opening bracket in an expression is closed by a matching bracket in the right order.7 · Stacks
base caseThe input on which a recursive method answers directly without calling itself, which stops the recursion.4 · Recursion
best caseThe input of a given size on which an algorithm does the least work, and the running time it takes there.2 · Algorithm Analysis
Big ONotation for an upper bound: f(n) = O(g(n)) if f(n) ≤ c · g(n) for some constant c > 0 and all n ≥ n0.2 · Algorithm Analysis
Big OmegaNotation for a lower bound: f(n) = Ω(g(n)) if f(n) ≥ c · g(n) for some constant c > 0 and all n ≥ n0.2 · Algorithm Analysis
Big ThetaNotation for a tight bound: f(n) = Θ(g(n)) if f is both O(g(n)) and Ω(g(n)), so f and g grow at the same rate.2 · Algorithm Analysis
big-O notationThe O(·) notation used to state how an operation's cost grows with input size, such as O(1) access or O(n) insertion in an array.3 · Arrays
binary heapA complete binary tree with the heap-order property, usually stored in an array, giving O(log n) insertion and removal of the top element.11 · Priority Queues and Heaps
binary recursionRecursion in which each call makes two recursive calls, as in the naive Fibonacci method or merge sort.4 · Recursion
binary searchA search in a sorted array that compares the target with the middle element and discards half of the range at each step, in O(log n).2 · Algorithm Analysis
binary search tree (BST)A binary tree in which every key in a node's left subtree is smaller than the node's key and every key in its right subtree larger.10 · Search Trees
binary treeA tree in which every node has at most two children, distinguished as the left child and the right child.9 · Trees
binomial heapA priority queue stored as a forest of binomial trees, which supports merging two heaps in O(log n).11 · Priority Queues and Heaps
bipartite graphA graph whose vertices can be split into two groups so that every edge joins a vertex of one group to a vertex of the other.14 · Graphs
bit (binary digit)The smallest unit of digital data, holding one of two values, 0 or 1.1 · Introduction
bit maskAn integer whose set bits select particular positions, used with bitwise AND, OR and NOT to test, set or clear those bits.13 · Sets and Disjoint Sets
bit vectorA set representation for a small universe 0 to U - 1 that stores U bits, bit i being 1 exactly when i is in the set.13 · Sets and Disjoint Sets
black heightIn a red-black tree, the number of black nodes on every path from a node down to a NIL leaf, which is the same for all such paths.10 · Search Trees
bottom-up heap constructionBuilding a heap from n items by placing them in an array and running down-heap on each internal node from the last to the root, in O(n).11 · Priority Queues and Heaps
bounded stackAn array-based stack whose capacity is fixed when it is created, so a push onto a full stack causes overflow.7 · Stacks
breadth-first search (BFS)A graph traversal that visits vertices in order of their distance in edges from the start, using a queue.14 · Graphs
brute forceSolving a problem by directly trying every possibility, simple to write but often slow, such as rescanning the array for each element.7 · Stacks
BST propertyThe ordering rule of a binary search tree: keys in the left subtree are smaller and keys in the right subtree larger than the node's key.10 · Search Trees
bubble sortA sorting algorithm that repeatedly sweeps the array swapping adjacent elements that are out of order, so the largest moves to the end each pass.3 · Arrays
bucketOne cell of a hash table's array; with separate chaining, a bucket holds the list of all entries whose keys hash to that index.12 · Maps and Hash Tables
bufferA memory area, usually a queue, where data waits between a producer and a consumer that run at different speeds.8 · Queues and Deques
byteA group of eight bits, the smallest addressable unit of memory, able to hold 256 different values.1 · Introduction
cacheA small, fast memory near the processor that holds recently used blocks of main memory, which makes access to nearby addresses cheap.3 · Arrays
cache missAn access to data not present in the cache, forcing a slow fetch from main memory; scattered linked nodes cause many of them.6 · The List ADT and Java Collections
call stackThe stack of frames the runtime keeps for active method calls; a call pushes a frame and a return pops it.7 · Stacks
call treeA tree diagram of a recursive computation in which each node is one call and its children are the calls it makes.4 · Recursion
capacityThe number of elements an array or array-based structure can hold before it must grow, as opposed to the number it currently holds.3 · Arrays
chainIn separate chaining, the linked list of entries stored in one bucket of a hash table.12 · Maps and Hash Tables
character encodingA rule that maps characters to numbers and those numbers to bytes, such as ASCII or UTF-8.1 · Introduction
childA node directly below another node in a tree, joined to it by an edge.9 · Trees
circular queueAn array-based queue whose front and rear indices wrap around to 0 after the last slot, using arithmetic modulo the capacity.8 · Queues and Deques
circularly linked listA linked list whose last node points back to the first instead of to null, so traversal can continue around the cycle.5 · Linked Lists
client codeCode that uses a data structure only through its public interface, without depending on how it is implemented.1 · Introduction
code pointThe number that Unicode assigns to a character, independent of how it is stored in bytes.1 · Introduction
collectionAn object that groups a number of elements into a single unit; in Java, the root interface of most container types.6 · The List ADT and Java Collections
collisionThe situation in which two different keys are mapped by the hash function to the same index of a hash table.12 · Maps and Hash Tables
comparatorAn object that defines an ordering on elements by comparing two of them, letting a sort or ordered structure use an order other than the natural one.6 · The List ADT and Java Collections
compile timeThe phase when source code is translated by the compiler, during which errors such as type mismatches are detected before the program runs.1 · Introduction
complete binary treeA binary tree in which every level except possibly the last is full and the last level is filled from the left with no gaps.9 · Trees
complete graphA simple graph in which every pair of distinct vertices is joined by an edge; with n vertices it has n(n - 1)/2 edges.14 · Graphs
complexityThe amount of a resource, usually time or memory, that an algorithm uses, expressed as a function of the input size.2 · Algorithm Analysis
compression functionThe second step of a hash function, which maps an arbitrary integer hash code to an index in the range 0 to N - 1.12 · Maps and Hash Tables
connectedSaid of an undirected graph in which there is a path between every pair of vertices.14 · Graphs
connected componentA maximal set of vertices of an undirected graph in which every pair is joined by a path.14 · Graphs
contiguousStored in adjacent memory locations with no gaps, as the elements of an array are.3 · Arrays
contract (equals/hashCode)Java's rule that objects equal under equals must return the same hashCode, which hash-based collections rely on to find keys.12 · Maps and Hash Tables
correctnessThe property of an algorithm that it produces the right output for every valid input and terminates.2 · Algorithm Analysis
covarianceA typing relation in which a container of a subtype is treated as a container of its supertype, as Java does for arrays.3 · Arrays
covariantHaving covariance; Java arrays are covariant because String[] is a subtype of Object[], while generic lists are not.3 · Arrays
cursorThe conceptual position of an iterator, which sits between elements; each call to next() moves it past one element.6 · The List ADT and Java Collections

cycle detectionDetermining whether following next references in a linked list ever returns to an earlier node instead of reaching null.5 · Linked Lists
d-ary heapA heap stored as a complete tree whose nodes have up to d children, giving height log_d n and faster insertion than a binary heap.11 · Priority Queues and Heaps

data typeA set of values together with the operations allowed on them, such as int with its arithmetic operations.1 · Introduction

depthThe number of edges on the path from the root down to a node; the root has depth 0.9 · Trees
