Introduction to Data Structures

Data structures organize information so that programs can store, access, update, and traverse data efficiently. The right structure depends on the operations a problem performs most often.

Memory foundations Connect variables and references to how structures occupy memory.
Structural patterns Distinguish sequential, hierarchical, and network-shaped organization.
Operational thinking Relate access, insertion, deletion, and traversal to structure choice.

Array

Contiguous storage with fast indexed access. Insertions in the middle may require shifting elements.

Access O(1)Search O(n)

Linked List

Nodes connected by references. Flexible insertion and deletion, but no constant-time random access.

Access O(n)Insert O(1)*

Stack

LIFO structure. The most recently inserted item is the first item removed.

Push O(1)Pop O(1)

Queue

FIFO structure. Items leave in the same order in which they arrive.

Enqueue O(1)Dequeue O(1)

Tree

Hierarchical structure with parent-child relationships, useful for ordered and nested data.

Graph

Vertices connected by edges. Models networks, routes, dependencies, and many-to-many relationships.
