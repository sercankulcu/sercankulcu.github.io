Infix to Prefix Simulator

Prefix (Polish) notation writes the operator before its operands: A + B * C becomes + A * B C. No parentheses or precedence rules are needed to evaluate it.

How to use

  • Type an expression with single-letter or numeric operands, + - * / % ^ and parentheses (up to 22 tokens), then press Convert; Example loads a sample.
  • Next / Previous step through the conversion; Auto Run plays it; Reset returns to the start; Cancel stops playback.

Algorithm

  1. Reverse the expression and swap ( with ).
  2. Scan it with the postfix algorithm: operands go to the output, operators wait on the stack. For equal precedence, pop only for ^; the other operators are pushed (their associativity flips after reversal).
  3. Reverse the temporary output to get the prefix result.

Precedence: ^ > * / % > + -. Time O(n).
