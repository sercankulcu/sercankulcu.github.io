Infix to Postfix Simulator

Postfix (reverse Polish) notation writes the operator after its operands: A + B * C becomes A B C * +. A stack evaluates it left to right without parentheses.

How to use

  • Type an expression with single-letter or numeric operands, + - * / % ^ and parentheses (up to 22 tokens), then press Convert; Example loads a sample.
  • Next / Previous step through the conversion; Auto Run plays it; Reset returns to the start; Cancel stops playback.

Algorithm (shunting-yard)

  • Operand → append to the output.
  • ( → push; ) → pop to the output until (.
  • Operator → pop while the top has higher precedence, or equal precedence and the operator is left-associative; then push it. ^ is right-associative.
  • At the end, pop everything left on the stack.

Precedence: ^ > * / % > + -. Time O(n).
