Directed graph concepts

Indegree and outdegree

Indegree counts incoming edges; outdegree counts outgoing edges. A source has indegree 0, while a sink has outdegree 0.

Direction matters

A → B and B → A are different edges. Reachability therefore depends on edge orientation.

Topological sort

Kahn's algorithm repeatedly removes vertices with indegree 0. A complete ordering exists only for a directed acyclic graph.

Cycle detection

If Kahn's algorithm cannot process every vertex, at least one directed cycle prevents a topological ordering.
