Öncelikli Kuyruk ADT

Öncelikli Kuyruk (Priority Queue)

  • Her öğenin bir önceliği (anahtarı) vardır; öğeler öncelik sırasına göre çıkar.
  • Geliş sırası değil, öncelik belirleyicidir: ambulans trafikte öne geçer.
  • Öncelikli işlerin yönetiminde kullanılır: görev çizelgeleme, acil servis, olay simülasyonu.
  • Maliyetler uygulamaya bağlıdır: heap ile en öncelikli öğeye bakmak O(1), onu çıkarmak O(log n); sırasız listede bakmak bile O(n).

ADT tanımında Goodrich'teki gibi min-öncelikli kuyruk (removeMin) kullanılır; heap uygulama örnekleri ise pptx'teki gibi max-heap (ekle / silMax) üzerindedir. Hangisinin seçildiği yalnızca karşılaştırma yönünü değiştirir.

Kod İzleme: sırasız dizide removeMin()

Sırasız dizi a = [5, 9, 3, 7, 4]: ekleme sona yapıldığı için en küçüğün yeri bilinmez. İlk aday: enk = 0.

k = 1: a[1] = 9 ≥ a[0] = 5 → enk değişmez.

k = 2: a[2] = 3 < a[0] = 5 → yeni en küçük, enk = 2.

k = 3: a[3] = 7 ≥ a[2] = 3 → enk değişmez.

k = 4: a[4] = 4 ≥ a[2] = 3 → enk değişmez.

k = 5 = n → tarama bitti: 4 karşılaştırma. Her removeMin tüm diziyi tarar → O(n).

min = a[2] = 3 saklanır.

Boşluğu kaydırmadan kapatmak için son öğe (4) indis 2'ye taşınır, n = 4. Sıra önemli olmadığından bu O(1).

return 3. Kalan dizi [5, 9, 4, 7] yine sırasız.

// sırasız dizi: insert(x) { a[n] = x; n++; }  O(1)
public int removeMin() {        // n > 0 olmalı
  int enk = 0;                  // en küçüğün indisi
  for (int k = 1; k < n; k++)
    if (a[k] < a[enk]) enk = k;
  int min = a[enk];
  a[enk] = a[n - 1];  n--;      // son öğe boşluğa
  return min;
}

Kod İzleme: sıralı dizide insert(4)

Dizi büyükten küçüğe sıralı; en öncelikli (en küçük) öğe hep sonda. k = n − 1 = 4: sondan başa doğru yer aranır.

a[4] = 2 < 4 → 2, x'ten sonra gelmeli; kaydırılacak.

a[5] = a[4] = 2: bir sağa kaydırıldı (a[4] şimdilik kopya; üzerine yazılacak).

k = 3: bir sola geç.

a[3] = 3 < 4 → 3, x'ten sonra gelmeli; kaydırılacak.

a[4] = a[3] = 3: bir sağa kaydırıldı (a[3] şimdilik kopya; üzerine yazılacak).

k = 2: bir sola geç.

a[2] = 5 ≥ 4 → döngü biter. 4'ün yeri k + 1 = 3.

a[3] = 4, n = 6. Dizi yine sıralı. En kötü durumda (x en büyükse) tüm öğeler kayar → O(n).

Karşılığında removeMin() çok ucuz: en küçük (2) zaten sonda → n = 5, return 2. Kaydırma yok → O(1).

// sıralı dizi: büyükten küçüğe, min hep a[n-1]
public void insert(int x) {
  int k = n - 1;
  while (k >= 0 && a[k] < x) {    // x'ten küçükler
    a[k + 1] = a[k];              // bir sağa kaydır
    k--;
  }
  a[k + 1] = x;  n++;
}
public int removeMin() { n--; return a[n]; }

Dizi ve Bağlı Liste Temsili

Dizi temsili
  • Öğeler dizide tutulur; sıralı tutmak için ekleme sırasında öğeler kaydırılır (O(n)).
  • Öncelikli öğe dizinin başında tutulursa her çıkarmada tüm dizi sola kaydırılır: O(n).
  • Doğrusu: en öncelikli öğeyi dizinin sonunda tutmak → çıkarma O(1).
Bağlı liste temsili
  • Öğeler önceliklerine göre listedeki uygun konuma eklenir: yer arama O(n), bağlama O(1).
  • Öncelikli öğe listenin başındadır; çıkarma = baştan silme, O(1).
  • Kaydırma yok, ama her düğüm ek bir referans taşır.

Liste büyükten küçüğe değil, küçükten büyüğe (min-öncelikli): en öncelikli 3 baştadır. Yeni düğüm 6 oluşturuldu.

Yer arama: onceki.sonraki.deger = 7 > 6 olana dek ilerle → onceki = 5. Bu tarama O(n) sürer.

Önce yeni.sonraki = onceki.sonraki (6 → 7). Sıra önemli: önce bu bağ kurulmazsa 7'ye giden yol kaybolur.

Sonra onceki.sonraki = yeni (5 → 6). Bağlama O(1), kaydırma yok; çıkarma her zaman baştan: O(1).

İkili Heap

İkili Heap (Binary Heap)

Öncelikli kuyruğu uygulamak için en yaygın veri yapısıdır. İki koşulu birlikte sağlayan bir ikili ağaçtır:

1. Heap-sıra özelliğiHer düğüm çocuklarından önce gelir: max-heap'te ebeveyn ≥ çocuk. En yüksek öncelikli öğe köktedir.
2. Tam ikili ağaç özelliğiSon düzey hariç tüm düzeyler dolu, son düzey soldan sağa dolar → yükseklik ⌊log₂ n⌋, dizide boşluk yok.
Ekleme ve çıkarma yalnızca kökten yaprağa uzanan tek bir yol üzerinde çalışır → O(log n). Heap, ikili arama ağacı değildir.

İkili Heap

Min-Heap ve Max-Heap

  • Sıra yalnızca ebeveyn–çocuk arasında geçerlidir: min-heap'te 7 ile 3 kardeştir, 7 > 3 olması sorun değildir.
  • Kökten herhangi bir yaprağa giden her yol sıralıdır (min-heap'te artan, max-heap'te azalan).

İkili Heap

Heap mi, Değil mi?

Her ağaç için karar verin: max-heap mi, min-heap mi, yoksa heap değil mi? Hangi özellik bozuluyor?

Cevapları göster
  1. Max-heap ✓ (tam ağaç, her ebeveyn ≥ çocukları).
  2. Heap değil: 12 > ebeveyni 8 → heap-sıra özelliği bozuk.
  3. Min-heap ✓ (tam ağaç, her ebeveyn ≤ çocukları).
  4. Heap değil: 8'in çocukları yokken 9'un çocukları var → tam ağaç değil.

İkili Heap · Kodu adım adım çalıştır

Kod İzleme: heapMi([10, 8, 9, 3, 5, 7, 4, 6])

heapMi(a) çağrıldı: 8 öğeli dizi. Kök (indis 0) hariç her düğüm, ebeveyniyle bir kez karşılaştırılacak.

i = 1: ebeveyn e = (1 − 1) / 2 = 0. a[0] = 10 ≥ a[1] = 8 ✓ → devam.

i = 2: ebeveyn e = (2 − 1) / 2 = 0. a[0] = 10 ≥ a[2] = 9 ✓ → devam.

i = 3: ebeveyn e = (3 − 1) / 2 = 1. a[1] = 8 ≥ a[3] = 3 ✓ → devam.

i = 4: ebeveyn e = (4 − 1) / 2 = 1. a[1] = 8 ≥ a[4] = 5 ✓ → devam.

i = 5: ebeveyn e = (5 − 1) / 2 = 2. a[2] = 9 ≥ a[5] = 7 ✓ → devam.

i = 6: ebeveyn e = (6 − 1) / 2 = 2. a[2] = 9 ≥ a[6] = 4 ✓ → devam.

i = 7: e = 3. a[3] = 3 < a[7] = 6 ✗ → çocuk ebeveynden büyük: return false.

Sonuç false: ilk yedi öğe geçerli bir heap olsa da 6, ebeveyni 3'ten büyük. En kötü durumda n − 1 karşılaştırma → O(n).

static boolean heapMi(int[] a) {  // max-heap mi?
  for (int i = 1; i < a.length; i++) {
    int e = (i - 1) / 2;           // ebeveyn
    if (a[e] < a[i]) return false; // sıra bozuk
  }
  return true;
}

İkili Heap

Dizi Gösterimi

  • Düğümler kökten başlayarak düzey düzey, soldan sağa (level order) diziye yazılır.
  • Tam ağaç olduğu için dizide boşluk kalmaz; işaretçi (referans) gerekmez.

Düğümlerin yanındaki küçük sayılar dizideki indeksleridir. Bu sunumda indeksler 0'dan başlar; kök heap[0]'dadır.

İkili Heap

Ebeveyn ve Çocuk Hesaplamaları

Çocuklarsol(i) = 2i + 1 · sağ(i) = 2i + 2i = 1 → 3 ve 4 · i = 2 → 5 ve 6
Ebeveynebeveyn(i) = ⌊(i − 1) / 2⌋i = 6 → 2 · i = 5 → 2 · i = 4 → 1
  • Java'da tam sayı bölmesi zaten aşağı yuvarlar: (i - 1) / 2. Çocuk yoksa 2i + 1 ≥ n olur.
  • 1 tabanlı alternatif (orijinal sunum): heap[0] boş bırakılır; çocuklar 2k, 2k + 1; ebeveyn ⌊k/2⌋. İkisi eşdeğerdir, biri seçilip tutarlı kullanılmalıdır.

Ekleme ve Silme

Öğe Ekleme: Up-Heap (yüzdür, swim)

  1. Yeni öğe ağacın ilk boş konumuna (heap[n]) eklenir. Ağaç tam kalır.
  2. Heap-sıra özelliği bozulmuş olabilir: yeni öğe ebeveyninden büyükse (max-heap) yer değiştirilir.
  3. Öğe köke ulaşana ya da ebeveyni kendisinden büyük/eşit olana kadar yukarı taşınır.
MaliyetEn çok h = ⌊log₂ n⌋ yer değiştirme → O(log n).
Neden doğru?Yer değiştirmede aşağı inen ebeveyn, zaten diğer çocuğundan büyüktü.
Adlarıup-heap, bubble-up, sift-up, swim; orijinal kodda yuzdur.

Max-Heap'e Ekleme: Java Kodu

public class MaxHeap {
  private int[] heap = new int[4];
  private int n = 0;                // eleman sayısı

public void ekle(int x) {
  if (n == heap.length) buyut(2 * heap.length);
  heap[n] = x;  n++;              // ilk boş konum
  yuzdur(n - 1);
}
private void yuzdur(int i) {      // up-heap
  while (i > 0) {
    int ebeveyn = (i - 1) / 2;
    if (heap[ebeveyn] >= heap[i]) return;
    yerDegistir(i, ebeveyn);  i = ebeveyn;
  }
}

5 ≥ 1: ebeveyn zaten büyük/eşit → heap-sıra sağlandı, return. 1 yerine oturdu.

ekle(3): 3, ilk boş konuma heap[5]'ye yazılır; n = 6. Ağaç tam kalır ama sıra bozulmuş olabilir.

i = 5 > 0 → ebeveyn = (5 − 1) / 2 = 2. Karşılaştır: heap[2] = 2 < heap[5] = 3.

3 > 2 → yer değiştir (indis 5 ↔ 2); öğe bir düzey yukarı çıktı, i = 2.

i = 2 > 0 → ebeveyn = (2 − 1) / 2 = 0. Karşılaştır: heap[0] = 6 ≥ heap[2] = 3.

6 ≥ 3: ebeveyn zaten büyük/eşit → heap-sıra sağlandı, return. 3 yerine oturdu.

public void ekle(int x) {
  if (n == heap.length) buyut(2 * heap.length);
  heap[n] = x;  n++;              // ilk boş konum
  yuzdur(n - 1);
}
private void yuzdur(int i) {      // up-heap
  while (i > 0) {
    int ebeveyn = (i - 1) / 2;
    if (heap[ebeveyn] >= heap[i]) return;
    yerDegistir(i, ebeveyn);  i = ebeveyn;
  }
}

8 hücrelik yeni dizi ayrılır; Java int dizisini 0 ile doldurur.

public static void heapSort(int[] a) {
  int n = a.length;
  // 1) oluştur: son iç düğümden köke
  for (int k = n / 2 - 1; k >= 0; k--)
    batir(a, k, n);
  // 2) sırala: en büyüğü sona al
  for (int son = n - 1; son > 0; son--) {
    yerDegistir(a, 0, son);
    batir(a, 0, son);           // heap boyutu = son
  }
}
static void batir(int[] a, int i, int n) {
  while (2 * i + 1 < n) {
    int j = 2 * i + 1;
    if (j + 1 < n && a[j + 1] > a[j]) j++;
    if (a[i] >= a[j]) return;
    yerDegistir(a, i, j);  i = j;
  }
}

son = 2: kök (en büyük, 3) ile a[2] = 1 yer değiştirir → 3 kesin yerine oturdu, heap boyutu 2.

batir(a, 0, 2): i = 0 için büyük çocuk a[1] = 2 > 1 → yer değiştir (0 ↔ 1). İndis 1 yaprak → batir biter.

son = 1: kök (en büyük, 2) ile a[1] = 1 yer değiştirir → 2 kesin yerine oturdu, heap boyutu 1.

batir(a, 0, 1): heap boyutu 1, kökün çocuğu yok → hiçbir şey yapılmaz.

son = 0 → döngü biter. Dizi artan sırada: [1, 2, 3, 4, 5, 6]. Ek dizi kullanılmadı (yerinde), toplam O(n log n).

public static void heapSort(int[] a) {
  int n = a.length;
  // 1) oluştur: son iç düğümden köke
  for (int k = n / 2 - 1; k >= 0; k--)
    batir(a, k, n);
  // 2) sırala: en büyüğü sona al
  for (int son = n - 1; son > 0; son--) {
    yerDegistir(a, 0, son);
    batir(a, 0, son);           // heap boyutu = son
  }
}

peek(): kökteki 1 döner ama çıkarılmaz → O(1).

poll(): kök 1 alınır; son öğe 8 köke taşınır, size = 2.

x = 9: offer(9) → sona eklenir, up-heap. size = 3.

size = 3 ≤ k = 3 → henüz atılacak öğe yok.

x = 3: offer(3) → sona eklenir, up-heap (yukarı yüzdü: 1 kaydırma). size = 4.

x = 7: offer(7) → sona eklenir, up-heap. size = 4.

size = 4 > k → poll(): en küçük 3 atılır (k büyüğe giremez). Son öğe köke, down-heap.

x = 6: offer(6) → sona eklenir, up-heap (yukarı yüzdü: 1 kaydırma). size = 4.

size = 4 > k → poll(): en küçük 5 atılır (k büyüğe giremez). Son öğe köke, down-heap.

Döngü bitti: pq = en büyük üç öğe {6, 7, 9}. peek() = 6 → 3'üncü en büyük. Toplam O(n log k), bellek O(k).

static int kinciEnBuyuk(int[] a, int k) {
  PriorityQueue<Integer> pq = new PriorityQueue<>();
  for (int x : a) {
    pq.offer(x);                    // O(log k)
    if (pq.size() > k) pq.poll();  // en küçüğü at
  }
  return pq.peek();       // k büyüğün en küçüğü
}
