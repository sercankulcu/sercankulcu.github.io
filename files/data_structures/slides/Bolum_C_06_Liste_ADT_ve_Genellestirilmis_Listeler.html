C ile Gerçekleştirim

Atom veya alt liste düğümü

typedef enum { ATOM, ALT_LISTE } Tur;
typedef struct Oge {
    Tur tur;
    union {
        char atom;
        struct Oge *alt;
    } icerik;
    struct Oge *sonraki;
} Oge;
Tür tanımı veri yapısının bellekteki biçimini; yordamlar ise bu yapı üzerindeki davranışı kurar.

Sahip kim?

Sınırlar

Boş durum

Temel İşlemler

Atomları özyineli yazdırmak

void atomlari_yaz(const Oge *p) {
    for (; p != NULL; p = p->sonraki) {
        if (p->tur == ATOM)
            printf("%c ", p->icerik.atom);
        else
            atomlari_yaz(p->icerik.alt);
    }
}
Kod örnekleri C99/C11 uyumlu olacak biçimde küçük ve tek sorumluluklu tutulmuştur.

Adım Adım

(a, (b, c), d) listesini dolaş

a

İlk öğe atomdur; a yazılır.

(b,c)

İkinci öğe alt listedir; özyineli çağrı başlar.

b ve c

Alt listedeki atomlar sırayla yazılır; çağrı geri döner.

d

Dış listenin son atomu yazılır. Çıktı: a b c d.
