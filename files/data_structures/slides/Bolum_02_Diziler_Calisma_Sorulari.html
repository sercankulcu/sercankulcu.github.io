Soru 2: Adres Hesabı

int[] d = new int[100]; dizisinin öğeleri bellekte 1000 adresinden başlıyor (int = 4 bayt). d[25] hangi adrestedir?

adres = başlangıç + i × öğe boyutu = 1000 + 25 × 4 = 1100. Tek çarpma ve toplama yeter; süre dizinin boyutundan bağımsızdır → O(1). A öğe boyutunu unutur; C indisleri 1'den sayar (o adres d[26]'nın).

String[] isimler = {"Ali", "Ayşe"};

Cevabı göster

Soru 4: Varsayılan Değerler

Kodun çıktısı nedir?

double[] d = new double[2];
boolean[] b = new boolean[2];
String[] s = new String[2];
System.out.println(d[0] + " " + b[1]
                   + " " + s[0]);

new ile oluşturulan dizinin her öğesi türünün varsayılan değerini alır: double → 0.0, boolean → false, nesne (String) → null (char ise '\u0000'). Yerel değişkenlerin aksine dizi öğeleri ilk değersiz kalmaz, bu yüzden C yanlış; String'in varsayılanı "" değil null'dır.

Soru 5: Tanımlama Hataları

Numaralı satırlardan hangileri derleme hatası verir? Her birini düzeltin.

int[] a = {1, 2, 3};          // 1
int[] b;  b = {4, 5};         // 2
int[] c = new int[] {6, 7};   // 3

Cevabı göster

  • 5: length dizide metot değil alandır: a.length (String'de ise s.length()).

1 ve 3 doğrudur (3, sonradan atamada da kullanılabilen yazım).

Soru 6: Referans mı, Kopya mı?

Kodun çıktısı nedir?

int[] dizi = {1, 2, 3};
int[] r = dizi;
int[] k = Arrays.copyOf(dizi, dizi.length);
r[0] = 99;
k[1] = 50;
System.out.println(dizi[0] + " " + dizi[1]);

r = dizi yalnızca adresi kopyalar: r ve dizi heap'teki aynı nesneyi gösterir, r[0] = 99 diziyi değiştirir. Arrays.copyOf yeni bir nesne oluşturup öğeleri tek tek kopyalar (O(n)); k'deki değişiklik diziye yansımaz, bu yüzden C yanlış.

Soru 7: java.util.Arrays

Programın çıktısı nedir? Her satırı kısaca gerekçelendirin.

int[] a = {5, 3, 8};
int[] b = {5, 3, 8};
System.out.println(a == b);
System.out.println(Arrays.equals(a, b));
int[] c = Arrays.copyOf(a, 5);

        + " " + Arrays.toString(c));
Cevabı göster 
false
true

Soru 8: Varargs

Üç çağrı ne döndürür ve son satırdaki f tanımı neden derlenmez?

static int say(String ad, int... d) {
    return d.length;

say("a")

say("c", new int[] {4, 5})

Cevabı göster

Soru 9: Stack, Heap ve GC

Metot çağrıldığında çıktı nedir ve System.gc() satırında dizi neden toplanamaz?

static void ornek() {
    int[] d = new int[1000];
    int[] yedek = d;
    d = null;
    System.gc();
    System.out.println(yedek.length);
}
Cevabı göster

Çıktı: 1000.

  • d ve yedek yerel değişkenlerdir: metodun stack çerçevesinde yalnızca referans tutarlar. Dizi nesnesi heap'tedir.
  • d = null yalnızca bir referansı koparır; yedek diziyi hâlâ gösterdiği için dizi erişilebilirdir → GC toplayamaz. Ayrıca System.gc() yalnızca bir istektir, garanti vermez.
  • Metot bitince çerçeve silinir, referans kalmaz; dizi ancak o zaman toplanabilir. C'deki free/delete[] gibi bir işlem Java'da yoktur.

Soru 12: Ortanca

ortanca({7, 1, 9, 4}) ve ortanca({1000, 3, 5, 1, 4}) ne döndürür? İkinci dizide ortanca neden ortalamadan daha anlamlıdır?

static double ortanca(double[] dizi) {
    double[] s = dizi.clone();
    Arrays.sort(s);
    int n = s.length;
    if (n % 2 == 0)
        return (s[n/2 - 1] + s[n/2]) / 2;
    return s[n / 2];
}
Cevabı göster
  • {1, 4, 7, 9}: n = 4 çift → (s[1] + s[2]) / 2 = (4 + 7) / 2 = 5.5.
  • {1, 3, 4, 5, 1000}: n = 5 tek → s[2] = 4.0.

İkinci dizinin ortalaması 1013 / 5 = 202.6'dır: tek bir uç değer (1000) ortalamayı çeker, ortancayı etkilemez.

clone() çağıranın dizisinin sırası bozulmasın diye alınır. Maliyet sıralamada baskındır: O(n log n), ek bellek O(n).

Soru 13: Mod Hesabını İzleme

mod({5, 2, 5, 2, 9}) ne döndürür? İki değer eşit sayıda tekrar ederse hangisi seçilir?

Önce kendiniz tahmin edin, sonra › ile ilerleyin.

Kopya sıralanır: eşit değerler yan yana gelir. Çağıranın dizisi bozulmaz.

İlk değer (2) şimdilik rekor: 1 kez.

s[1] = 2 == s[0] → aynı değer sürüyor, mevcut = 2.

2 > 1 → yeni rekor: enCok = 2, 2 kez.

s[2] = 5 ≠ 2 → yeni değer, sayaç 1'e döner. 1 > 2 yanlış.

s[3] = 5 == s[2] → mevcut = 2.

2 > 2 yanlış: karşılaştırma > olduğu için eşitlikte rekor değişmez.

s[4] = 9 ≠ 5 → sayaç 1. Döngü biter.

return 2. 2 ve 5 ikişer kez geçer; önce görülen (en küçük) 2 kalır. O(n log n) + O(n).

static int mod(int[] dizi) {
  int[] s = dizi.clone();
  Arrays.sort(s);
  int enCok = s[0], enCokSayi = 1;
  int mevcut = 1;
  for (int i = 1; i < s.length; i++) {
    if (s[i] == s[i - 1]) mevcut++;
    else mevcut = 1;
    if (mevcut > enCokSayi) {
      enCokSayi = mevcut; enCok = s[i];
    }
  }
  return enCok;
}

Soru 14: Sıralamasız Mod

Mod metodundan Arrays.sort satırı silinirse aşağıdaki kod ne yazdırır?

int[] s = {1, 4, 2, 4, 3, 4}; // sırasız
int enCok = s[0], enCokSayi = 1, mevcut = 1;
for (int i = 1; i < s.length; i++) {
  if (s[i] == s[i - 1]) mevcut++;
  else mevcut = 1;
  if (mevcut > enCokSayi) {
    enCokSayi = mevcut; enCok = s[i];
  }
}
System.out.println(enCok);

Algoritma yalnızca komşu eşitlikleri sayar. Sırasız dizide hiçbir komşu eşit değildir; mevcut hep 1 kalır, rekor hiç değişmez ve ilk öğe 1 döner. Gerçek mod 4'tür (A), ama 4'ler yan yana olmadığı için bulunamaz; bu yüzden önce sıralama gerekir.

Soru 15: Yerinde Tersine Çevirme

Bir int[] diziyi ek dizi kullanmadan, yerinde tersine çeviren tersineCevir metodunu yazın. 7 öğeli bir dizide kaç takas yapılır?

Cevabı göster 
static void tersineCevir(int[] dizi) {
    int bas = 0, son = dizi.length - 1;
    while (bas < son) {
        int gecici = dizi[bas];
        dizi[bas] = dizi[son];
        dizi[son] = gecici;
        bas++; son--;     // içe doğru
    }
}

7 öğe için ⌊7/2⌋ = 3 takas; ortadaki öğe (indis 3) yerinde kalır. gecici olmadan soldaki değer kaybolurdu.

O(n) zaman, O(1) ek bellek. Yeni diziye sondan başa kopyalamak (yeni[i] = dizi[n-1-i]) da O(n)'dir ama O(n) ek bellek ister.

Soru 16: Sezar Şifresi

sifrele("YAZ", 4) ne döndürür ve şifreli metni çözmek için aynı metot hangi k ile çağrılmalıdır?

static String sifrele(String mesaj, int k) {
    char[] harf = mesaj.toCharArray();
    for (int i = 0; i < harf.length; i++) {
        int sira = harf[i] - 'A';
        harf[i] = (char) ('A' + (sira + k) % 26);
    }
    return new String(harf);
}
Cevabı göster
harfsıra(sıra + 4) % 26sonuç
Y2428 % 26 = 2C
A04E
Z2529 % 26 = 3D

Sonuç: "CED". % 26 sona taşan sırayı başa sarar.

Çözmek için k = 26 − 4 = 22: sifrele("CED", 22) → "YAZ".

String değiştirilemez; bu yüzden harfler toCharArray() ile bir char[]'e kopyalanıp yerinde değiştirilir. char değerleri tamsayıdır. Her harf bir kez işlenir: O(n).

Soru 17: Düzensiz Dizide null Satır

Kod çalıştırıldığında ekrana ne yazılır ve son satırda ne olur?

int[][] m = new int[3][];
m[1] = new int[4];
m[1][2] = 5;
System.out.println(m.length + " "
        + m[1].length + " " + m[0]);
System.out.println(m[0][0]);
Cevabı göster

İlk satır: 3 4 null. Son satırda NullPointerException.

  • Java'da matris, dizilerin dizisidir. new int[3][] yalnızca 3 referanslık dış diziyi oluşturur; satırlar henüz yoktur (null).
  • m.length satır sayısı (3), m[1].length o satırın kendi boyu (4). Satırların boyu farklı olabilir: düzensiz (jagged) dizi.
  • m[0] null olduğundan m[0][0] erişimi istisna fırlatır. Çözüm: önce m[0] = new int[k];

Soru 18: Pascal Üçgeni

Kod n = 5 ile çalıştırıldığında p[4] satırı ne olur ve satırlar için toplam kaç int hücresi ayrılır?

int n = 5;
int[][] p = new int[n][];
for (int i = 0; i < n; i++) {
    p[i] = new int[i + 1];
    p[i][0] = p[i][i] = 1;
    for (int j = 1; j < i; j++)
        p[i][j] = p[i-1][j-1] + p[i-1][j];
}
Cevabı göster 
p[0] = [1]
p[1] = [1, 1]
p[2] = [1, 2, 1]
p[3] = [1, 3, 3, 1]
p[4] = [1, 4, 6, 4, 1]

Örneğin p[4][2] = p[3][1] + p[3][2] = 3 + 3 = 6: her iç hücre üstteki iki komşunun toplamıdır; uçlar 1'dir.

Hücre sayısı: 1 + 2 + 3 + 4 + 5 = 15 (5 × 5 = 25 değil). Her satır i + 1 uzunlukta ayrı bir dizi olduğu için düzensiz dizi yer tasarrufu sağlar.

Soru 19: Sığ ve Derin Kopya

Programın çıktısı nedir? Her değeri sığ/derin kopya kavramıyla açıklayın.

int[][] m = { {1, 2}, {3, 4} };
int[][] s = m.clone();
int[][] d = { m[0].clone(), m[1].clone() };
s[1][0] = 8;
d[0][0] = 6;
s[0] = new int[] {0, 0};
System.out.println(m[0][0] + " " + m[1][0]
        + " " + s[0][0] + " " + d[1][0]);
Cevabı göster

Çıktı: 1 8 0 3

  • m.clone() yalnızca dış diziyi kopyalar: s'nin satır referansları m'ninkilerle aynıdır (sığ kopya). s[1][0] = 8 ortak satırı değiştirir → m[1][0] = 8.
  • s[0] = new int[]… yalnızca s'nin kendi dış dizisindeki referansı değiştirir; m[0] etkilenmez → m[0][0] = 1, s[0][0] = 0.
  • d'nin satırları ayrı ayrı klonlandı (derin kopya); d[1] klonlandığında m[1][0] henüz 3'tü → d[1][0] = 3. d'deki değişiklik m'yi etkilemez.

Soru 20: Matrisi Doldurma

Kod 4×5 matrisi satır satır 1…20 ile doldurmak için 3×3 örneğinden uyarlanmıştır. m[1][4] ve m[2][0] kaç olur, hata nedir ve nasıl düzeltilir?

int[][] m = new int[4][5];
for (int i = 0; i < m.length; i++)
    for (int j = 0; j < m[i].length; j++)
        m[i][j] = i * 3 + j + 1;
Cevabı göster

m[1][4] = 1·3 + 4 + 1 = 8, m[2][0] = 2·3 + 0 + 1 = 7.

Hata: 3 sabiti 3×3 matristen kalmıştır; satır başına 5 sütun vardır. Değerler çakışır (m[1][3] de 7'dir) ve son hücre 20 yerine 14 olur.

Düzeltme: m[i][j] = i * m[i].length + j + 1; (burada i·5 + j + 1). Döngü sınırları gibi formülde de sabit yerine length kullanmak her boyutta doğru çalışan kod verir. Dış döngü satırları, iç döngü sütunları gezer: 4 × 5 = 20 atama.

Soru 21: Üç Boyutlu Dizi

Döngüler bitince u[2][1][0] kaçtır ve en içteki atama kaç kez çalışmıştır?

int[][][] u = new int[3][3][3];
for (int x = 0; x < 3; x++)
  for (int y = 0; y < 3; y++)
    for (int z = 0; z < 3; z++)
      u[x][y][z] = x * 9 + y * 3 + z + 1;

2·9 + 1·3 + 0 + 1 = 22. Her boyut bir iç içe döngü demektir: 3 × 3 × 3 = 27 atama. B "+1"i unutur; C yalnızca iki döngü sayar; D ağırlıkları karıştırır (x·3 + y·9).

Soru 22: Matris Transpozu

m 3 satır, 4 sütunluk ve satır satır 1…12 ile dolu bir matristir. transpoz(m) sonucunun boyutu nedir; t[3][1] ve t[0][2] kaçtır?

static int[][] transpoz(int[][] m) {
    int satir = m.length;
    int sutun = m[0].length;
    int[][] t = new int[sutun][satir];
    for (int i = 0; i < satir; i++)
        for (int j = 0; j < sutun; j++)
            t[j][i] = m[i][j];
    return t;
}
Cevabı göster 
m = 1  2  3  4      t = 1  5  9
    5  6  7  8          2  6 10
    9 10 11 12          3  7 11
                        4  8 12

t 4 × 3'tür (m×n → n×m). t[3][1] = m[1][3] = 8, t[0][2] = m[2][0] = 9.

Her öğe bir kez kopyalanır: 12 atama → O(m·n). Metot static'tir; static main nesne oluşturmadan onu çağırabilir.

Soru 24: Kazanma mı, Beraberlik mi?

Son hamleyi X yaptı ve tahta doldu. oyunDevamEdiyorMu(t, 'X') ne yazdırır, ne döndürür; neden "berabere" yazılmaz?

 O | X | X
 X | X | O
 X | O | O

static boolean oyunDevamEdiyorMu(
        char[][] t, char o) {
  if (kazandi(t, o)) {
    System.out.println("Tebrikler, " + o
        + " oyuncusu kazandı!");
    return false;
  }
  for (char[] satir : t)
    for (char c : satir)
      if (c == ' ') return true;
  System.out.println("Oyun berabere bitti.");
  return false;
}
Cevabı göster

kazandi(t, 'X') 8 çizgiyi (3 satır, 3 sütun, 2 çapraz) denetler. Satır ve sütunların hiçbiri XXX değil; ana çapraz O-X-O. Ters çapraz t[0][2], t[1][1], t[2][0] = X, X, X → true.

Yazdırır: Tebrikler, X oyuncusu kazandı!, döndürür: false (oyun biter).

Kazanma kontrolü beraberlik kontrolünden önce yapıldığı için metot berabere satırına hiç ulaşmaz. Sıra ters olsaydı tahta dolu olduğundan oyun yanlışlıkla berabere ilan edilirdi.

Soru 27: Ortak Öğeleri Hızlandırma

eslestir metodu n = m = 10⁶ öğeli dizilerde çok yavaş kalıyor. Daha hızlı en az iki yaklaşım önerin ve bunları zaman ile ek bellek açısından karşılaştırın.

Örnek cevap ve değerlendirme ölçütleri
  • İç içe döngü 10¹² karşılaştırma yapar. Sırala + ikili arama: dizi2'nin kopyası sıralanır (O(m log m)), her dizi1 öğesi Arrays.binarySearch ile aranır (O(n log m)). Toplam O((n + m) log m) ≈ 4·10⁷ adım; ek bellek kopya için O(m) (orijinal bozulabiliyorsa yerinde sıralanır).
  • Hash kümesi (Bölüm 9): dizi2 bir HashSet'e konur, dizi1 taranır: ortalama O(n + m), ek bellek O(m). En hızlısı, ama bellek ve hash yükü daha fazla.
  • İkisi de sıralıysa iki işaretçi: O(n + m) zaman, O(1) ek bellek.

Not: tekrar eden öğelerde çıktı biçimi (6'nın iki kez yazılması) değişebilir; bu belirtilmelidir.

Değerlendirme: O(n²) maliyetin sayısal yorumu · en az iki doğru yaklaşım ve karmaşıklıkları · zaman–bellek ödünleşiminin tartışılması · sıralılık/tekrar gibi ön koşullara değinme.

Soru 28: Araya Ekleme

a = {3, 8, 2, 6, 0, 0} ve boyut = 4 iken ekle(a, 4, 1, 5) sonrası dizi ve dönüş değeri nedir? Kaydırma neden sağdan başlar?

static int ekle(int[] a, int boyut,
                int indis, int deger) {
  // ön koşul: boyut < a.length
  for (int k = boyut; k > indis; k--)
    a[k] = a[k - 1];   // sağa kaydır
  a[indis] = deger;
  return boyut + 1;
}

Soru 29: Dolu Diziyi Büyütme

Dizi dolduğunda (boyut == a.length) ekleme yapabilmek için ne gerekir? Kapasiteyi her dolduğunda 1 artırmak ile 2 katına çıkarmayı, n ekleme için toplam kopyalama maliyeti ve bellek açısından karşılaştırın.

Örnek cevap ve değerlendirme ölçütleri

Dizinin boyutu sabittir: daha büyük yeni bir dizi oluşturulur, öğeler kopyalanır (a = Arrays.copyOf(a, yeniKapasite), O(n)) ve referans yeni diziye yönlendirilir; eski dizi GC'ye kalır.

  • +1: her eklemede tüm öğeler kopyalanır: 1 + 2 + … + (n − 1) ≈ n²/2 → toplam O(n²), ekleme başına O(n).
  • ×2: kopyalar yalnızca 1, 2, 4, …, n/2 boyutlarında olur: toplam < 2n → O(n), ekleme başına ortalama (amortize) O(1).
  • Bedel: katlamada kapasitenin yarıya yakını boş kalabilir (kullanılmayan kapasite boşa gider). Java'nın ArrayList'i ≈ 1,5 kat büyür (Bölüm 6).

Değerlendirme: yeni dizi + kopyalama gerekçesi · iki stratejinin toplam maliyet hesabı · amortize maliyet fikri · bellek israfı ödünleşimi.

Soru 30: Aradan Silme

a = {3, 5, 8, 2, 6, 0}, boyut = 5 iken sil(a, 5, 0) sonrası dizi ve dönüş değeri nedir?

static int sil(int[] a, int boyut,
               int indis) {
  for (int k = indis; k < boyut - 1; k++)
    a[k] = a[k + 1];   // sola kaydır
  a[boyut - 1] = 0;
  return boyut - 1;
}

k = 0…3 için öğeler bir sola kayar (4 kaydırma), sonra eski son hücre a[4] temizlenir. C, temizleme satırı olmasaydı kalacak kopyayı gösterir (nesne dizilerinde null yazmak GC için önemlidir). Baştan silme n − 1 kaydırma → O(n); sondan silme O(1).

Soru 31: Sıralı Girdide Sıralama

Zaten artan sırada olan n öğeli bir dizi veriliyor. Aşağıdaki algoritmalardan hangisi bu girdide O(n) sürede biter?

Eklemelide her anahtar solundakiyle bir kez karşılaştırılır, kaydırma olmaz: n − 1 karşılaştırma → O(n). Seçimli her durumda n(n−1)/2 karşılaştırma yapar (O(n²)); birleştirme her durumda O(n log n) ve O(n) ek bellek ister. D en çekici yanlış: sıralı girdi + ilk öğe pivot, hızlı sıralamanın en kötü durumudur, O(n²). (Arrays.sort ilkel dizilerde çift pivotlu hızlı sıralama, nesne dizilerinde kararlı TimSort kullanır.)

Soru 34: Eklemeli Sıralamayı İzleme

eklemeliSirala({6, 3, 8, 2}) çalışırken toplam kaç kaydırma (a[j] = a[j - 1]) yapılır?

Önce kendiniz tahmin edin, sonra › ile ilerleyin.

Sıralı kısım {6}. Anahtar 3 bir kenara alınır.

6 > 3 → 6 bir sağa kayar; j = 0.

j == 0: başa gelindi, a[0] = 3. İlk 2 öğe sıralı.

Anahtar 8.

6 > 8 yanlış → while hiç dönmez; 8 yerinde kalır.

Anahtar 2: sıralı kısmın hepsinden küçük.

8 > 2 → sağa kayar.

6 > 2 → sağa kayar.

3 > 2 → sağa kayar; j = 0.

a[0] = 2 → sıralı. 4 kaydırma = ters sıralı çift sayısı: (6,3), (6,2), (3,2), (8,2). En kötü O(n²), sıralı dizide O(n).

static void eklemeliSirala(int[] a) {
  for (int k = 1; k < a.length; k++) {
    int anahtar = a[k];
    int j = k;
    while (j > 0 && a[j - 1] > anahtar) {
      a[j] = a[j - 1];   // sağa kaydır
      j--;
    }
    a[j] = anahtar;      // yerleş
  }
}

Soru 35: Bellek Kullanımı

1920×1080 piksellik bir resim int[1080][1920] dizisinde tutuluyor (piksel başına bir int). Verinin kapladığı bellek kaç bayttır ve gerçek kullanım neden bundan biraz fazladır?

Cevabı göster

Veri: 1080 × 1920 × 4 bayt = 8 294 400 bayt ≈ 7,9 MB. Alan karmaşıklığı O(satır × sütun), yani öğe sayısıyla doğrusal; bayt miktarı öğe tipine bağlıdır (double olsaydı 8 bayt/öğe → iki katı).

Ek yük: 2B dizi dizilerin dizisidir. 1080 satırın her biri ayrı bir dizi nesnesidir ve ~16 baytlık başlık (tür bilgisi + length) taşır; dış dizi de 1080 referans (4/8 bayt) ve kendi başlığını tutar. Toplam ek yük ≈ 1080 × (16 + 8) ≈ 26 KB: veriye göre küçüktür ama sıfır değildir.
