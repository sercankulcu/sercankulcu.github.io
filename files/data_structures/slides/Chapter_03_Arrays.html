Basic Concepts

Arrays

  • Stores many values of the same type, in order, under a single name.
  • Its size is fixed when the array is created and cannot change afterwards.
  • The elements sit side by side in contiguous memory slots.
  • Element values can always be updated; "inserting" or "deleting" means shifting elements.
  • Used to represent matrices, images (pixels), sound (samples), and similar data.

Basic Concepts

Using Arrays: Access by Index

  • An element is reached by its index: arrayName[index].
  • The first element has index 0, the last length − 1.
  • Because the elements are contiguous and equal in size, each address takes one multiplication and one addition to compute.
Click a cell: the top row is the index, the bottom row the value.
int[] arr = {7, 2, 9, 5, 1};
int first = arr[0];      // 7
int last = arr[arr.length - 1];      // 1

Basic Concepts

Arrays: Pros and Cons

Advantages

  • Fast, direct access by index: O(1).
  • Groups data and keeps it in insertion order.
  • Holds primitives (int, char, …) as well as objects.
  • Contiguous memory: no extra references, and cache-friendly.

Disadvantages

  • Fixed size: a full array cannot grow; you must create a bigger one and copy.
  • Inserting or deleting in the middle means shifting elements: O(n).
  • Unused capacity is wasted.
  • Arrays have no methods for sorting, searching, and the like; java.util.Arrays provides them.
Java arrays are covariant, which buys flexibility at the cost of a hole in type safety.

Basic Concepts

Array Covariance and ArrayStoreException

  • Because String is a subtype of Object, String[] counts as a subtype of Object[].
  • So one method that takes an Object[] works with any array of references.
  • The price: a store of the wrong type is caught at run time, not at compile time.
String[] names = {"Ann", "Alice"};
Object[] objects = names; // compiles
objects[0] = 42;   // compiles, but
                    // throws at run time!
FlexibilityYou can write general-purpose methods.static void print(Object[] a)
ContrastGeneric lists are not covariant, so the error is caught at compile time.List<Object> l = new ArrayList<String>(); // error

Copying Arrays: Reference or Copy?

An array is an object, created on the heap (#1). The variable arr on the stack holds only its address.

= copies only the address: both variables point to the same array (#1). No new array is created.

Arrays.copyOf creates a new array (#2) on the heap and copies the elements one by one → O(n). (arr.clone() and System.arraycopy copy elements too.)

ref[0] = 99 changes #1 → arr[0] becomes 99 too. copy[0] lives in a separate object and is still 1.

    Arrays.copyOf(arr, arr.length);

Arrays in Java

Arrays in Memory: Stack and Heap

  • Stack: local variables and method calls. When a method returns, its frame is removed automatically.
  • Heap: every object created with new. In Java every array lives on the heap; only its reference sits on the stack.
  • The heap is managed by the garbage collector (GC), which frees objects that no reference points to.

Array Algorithms

Computing the Median

static double median(double[] arr) {
    double[] s = arr.clone(); // copy
    Arrays.sort(s);             // O(n log n)
    int size = s.length;
    double median;
    if (size % 2 == 0) {       // even
        int m1 = size/2 - 1, m2 = size/2;
        median = (s[m1] + s[m2]) / 2;
    } else {                    // odd
        median = s[size / 2];
    }
    return median;
}
  • The median is the middle value of the sorted array.
  • For an odd size it is the exact middle; for an even size, the mean of the two middle values.
  • Unlike the mean, it isn't thrown off by outliers (e.g. 1000).

Array Algorithms

Mode (the Most Frequent Value)

static int mode(int[] arr) { // not empty
    int[] s = arr.clone();
    Arrays.sort(s);  // equal values side by side
    int best = s[0], bestCount = 1;
    int count = 1;
    for (int i = 1; i < s.length; i++) {
        if (s[i] == s[i - 1]) count++;
        else count = 1;   // new value
        if (count > bestCount) {
            bestCount = count;
            best = s[i];
        }
    }
    return best;
}
  • After sorting, equal values are adjacent, so one pass finds the longest run.
  • On a tie the first (smallest) value wins, because the comparison is >.
  • Cost: sorting O(n log n) + scanning O(n).

Reversing an Array in Place

static void reverse(int[] arr) {
    int start = 0;
    int end = arr.length - 1;
    while (start < end) {
        // swap the two outermost elements
        int temp = arr[start];
        arr[start] = arr[end];
        arr[end] = temp;
        start++;   // move inward
        end--;
    }
}

The left pointer starts at the first element.

The right pointer starts at the last element (length − 1 = 5).

0 < 5 → there is another pair to swap.

temp = arr[0] = 3: save the left value so it isn't lost.

arr[0] = arr[5] → 6. (The old 3 now survives only in temp.)

arr[5] = temp → 3. The pair is swapped.

The pointers move inward: start = 1, end = 4.

1 < 4 → there is another pair to swap.

temp = arr[1] = 8: save the left value so it isn't lost.

arr[1] = arr[4] → 4. (The old 8 now survives only in temp.)

arr[4] = temp → 8. The pair is swapped.

The pointers move inward: start = 2, end = 3.

2 < 3 → there is another pair to swap.

temp = arr[2] = 1: save the left value so it isn't lost.

arr[2] = arr[3] → 9. (The old 1 now survives only in temp.)

arr[3] = temp → 1. The pair is swapped.

The pointers move inward: start = 3, end = 2.

3 < 2 is false → the pointers have crossed in the middle and the loop ends. ⌊n/2⌋ = 3 swaps → O(n) time, O(1) extra space.

Copying back to front into a new array (result[i] = arr[n - 1 - i]) is also O(n) time, but needs O(n) extra space. With an odd number of elements, the middle one stays put.

Application: Caesar Cipher encrypt("ZEKA", 3)

toCharArray() copies the string's letters into a new char[]. A String is immutable; the array can be changed in place.

i = 0: 'Z' − 'A' gives the letter's position in the alphabet: 25 (char values are integers).

chars[0] = 'C': shift the position by 3 and turn it back into a letter. A position past the end wraps around with % 26 (Z → C).

i = 1: 'E' − 'A' gives the letter's position in the alphabet: 4 (char values are integers).

chars[1] = 'H': shift the position by 3 and turn it back into a letter.

i = 2: 'K' − 'A' gives the letter's position in the alphabet: 10 (char values are integers).

chars[2] = 'N': shift the position by 3 and turn it back into a letter.

i = 3: 'A' − 'A' gives the letter's position in the alphabet: 0 (char values are integers).

chars[3] = 'D': shift the position by 3 and turn it back into a letter.

new String(chars) → "CHND". To decrypt, call the same method with k = 26 − 3 = 23. Each letter is handled once: O(n).

static String encrypt(String message, int k) {
    char[] chars = message.toCharArray();
    for (int i = 0; i < chars.length; i++) {
        int pos = chars[i] - 'A';        // 0..25 (A–Z only)
        chars[i] = (char) ('A' + (pos + k) % 26);
    }
    return new String(chars);
}

Multidimensional Arrays · Step through the code

Jagged Array: Pascal's Triangle

new int[n][] creates only the outer array of 4 references; the row arrays don't exist yet (null).

p[0] = new int[1]: row 0 is a separate array of length 1; its cells start at 0.

p[0][0] = 1: in a one-cell row, the first and last cells are the same.

p[1] = new int[2]: row 1 is a separate array of length 2; rows of different lengths make a jagged array.

p[1][0] = p[1][1] = 1: both ends of the row are 1 (a chained assignment runs right to left).

p[2] = new int[3]: a new row of 3 cells.

p[2][0] = p[2][2] = 1: both ends of the row are 1 (a chained assignment runs right to left).

p[2][1] = p[1][0] + p[1][1] = 1 + 1 = 2: the sum of the two neighbors above.

p[3] = new int[4]: a new row of 4 cells.

p[3][0] = p[3][3] = 1: both ends of the row are 1 (a chained assignment runs right to left).

p[3][1] = p[2][0] + p[2][1] = 1 + 2 = 3: the sum of the two neighbors above.

p[3][2] = p[2][1] + p[2][2] = 2 + 1 = 3: the sum of the two neighbors above. Pascal's triangle is complete: 1+2+3+4 = 10 cells in all (not 4×4 = 16).

int n = 4;
int[][] p = new int[n][];          // no rows yet
for (int i = 0; i < n; i++) {
    p[i] = new int[i + 1];         // length i + 1
    p[i][0] = p[i][i] = 1;
    for (int j = 1; j < i; j++)
        p[i][j] = p[i-1][j-1] + p[i-1][j];
}

Shallow and Deep Copies of a 2D Array

A 2×2 matrix: the outer array m points to two row arrays (an array of arrays).

m.clone() copies only the outer array: s is a new outer array, but its references point to the same rows → a shallow copy.

s[0][0] = 9 changes the shared row, so m[0][0] becomes 9 too. A common mistake!

s[1] = new int[] {7, 8}, on the other hand, changes a reference in s's own outer array; m[1] is still {3, 4}.

A deep copy starts with a new outer array d; it has no rows yet.

d[0] = m[0].clone(): the elements of row 0 are copied into a new array.

d[1] = m[1].clone(): the elements of row 1 are copied into a new array.

d[0][1] = 5 changes only the copy; m[0][1] is still 2. A deep copy takes O(rows × columns).

int[][] m = { {1, 2}, {3, 4} };
int[][] s = m.clone();          // shallow copy
s[0][0] = 9;                    // m[0][0] is 9 too!
s[1] = new int[] {7, 8};        // only s changes
int[][] d = new int[2][];       // deep copy:
for (int i = 0; i < 2; i++)
    d[i] = m[i].clone();        // rows too
d[0][1] = 5;                    // m unaffected

Rows become columns and columns become rows: the transpose of an m×n matrix is n×m.

static int[][] transpose(int[][] m) {
    int rows = m.length;

Application: Tic Tac Toe

  • A 3×3 game board: char[][] board.
  • Two players, X and O, take turns.
  • Three of your marks in a row, column, or diagonal wins.
  • If the board fills up first, the game is a draw.

Every move is a single array assignment: board[row][col] = player

Multidimensional Arrays

Tic Tac Toe: The Main Loop

public class TicTacToe {   // import java.util.Scanner;
    static Scanner scanner = new Scanner(System.in); // single Scanner

    public static void main(String[] args) {
        char[][] board = new char[3][3];   // 3x3 game board
        char player = 'X';                   // X moves first
        boolean gameOn = true;
        initBoard(board);                  // every cell ' '
        while (gameOn) {
            showBoard(board);
            makeMove(board, player);
            gameOn = isGameOn(board, player);
            player = (player == 'X') ? 'O' : 'X';   // switch turns
        }
        showBoard(board);
    }

The cells of new char[3][3] start as '\u0000'; to show empty cells as ' ', the board is filled first. All helper methods are static.

Multidimensional Arrays

Tic Tac Toe: Win or Draw

The 8 winning lines (3 rows + 3 columns + 2 diagonals) are checked with one loop (rows and columns) and a single return (diagonals).

static boolean hasWon(char[][] t, char o) {
    for (int i = 0; i < 3; i++)
        if ((t[i][0] == o && t[i][1] == o && t[i][2] == o)     // row i
         || (t[0][i] == o && t[1][i] == o && t[2][i] == o))    // column i
            return true;
    return (t[0][0] == o && t[1][1] == o && t[2][2] == o)      // main diagonal
        || (t[0][2] == o && t[1][1] == o && t[2][0] == o);     // anti-diagonal
}
static boolean isGameOn(char[][] t, char o) {
    if (hasWon(t, o)) {
        System.out.println("Congratulations, player " + o + " wins!");
        return false;
    }
    for (char[] row : t)
        for (char c : row)
            if (c == ' ') return true;          // an empty cell → continue
    System.out.println("The game is a draw.");
    return false;
}

Inserting: Shift Right, O(n)

Capacity 6, with 5 cells in use. To insert 4 at index 1, we first have to make room.

k = 5: a[5] = a[4] = 1 (copied one place right). We start from the right: starting from the left, 2 would overwrite 9.

k = 4: a[4] = a[3] = 5 (copied one place right).

k = 3: a[3] = a[2] = 9 (copied one place right).

k = 2: a[2] = a[1] = 2 (copied one place right).

k = 1, and 1 > 1 is false → the loop ends. That took 4 shifts; a[1] and a[2] are now equal (2).

Write into the gap: a[1] = 4.

return 6. Inserting at the front takes n shifts, in the middle ≈ n/2 → O(n); at the end (if there is room), O(1).

static int insert(int[] a, int size,
             int index, int value) {
  // precondition: size < a.length
  for (int k = size; k > index; k--)
    a[k] = a[k - 1];   // shift right
  a[index] = value;
  return size + 1;   // new size
}

If the array is full (size == a.length), a bigger array must be created and filled first: O(n).

Complexity · Step through the code

Deleting: Shift Left, O(n)

After the previous insertion we delete a[1] = 4. To leave no gap, the elements to its right shift left.

k = 1: a[1] = a[2] = 2. This time we start from the left, overwriting the deleted value.

k = 2: a[2] = a[3] = 9.

k = 3: a[3] = a[4] = 5.

k = 4: a[4] = a[5] = 1.

k = 5 < 5 is false → the loop ends. 4 shifts.

The last cell still held a copy of the old value; write 0 there (null in an object array, which matters for the GC).

return 5. Deleting at the front takes n − 1 shifts → O(n); at the end, O(1).

static int remove(int[] a, int size, int index) {
  for (int k = index; k < size - 1; k++)
    a[k] = a[k + 1];   // shift left
  a[size - 1] = 0;    // clear the old last cell
  return size - 1;    // new size
}

Selection Sort

int[] arr = {64, 25, 12, 22, 11};
int n = arr.length;
for (int i = 0; i < n - 1; i++) {
    int minIndex = i;
    for (int j = i + 1; j < n; j++)
        if (arr[j] < arr[minIndex])
            minIndex = j;
    // swap by index, in place
    int temp = arr[minIndex];
    arr[minIndex] = arr[i];
    arr[i] = temp;
}

An unsorted 5-element array. Each pass will move the smallest element of the unsorted part to the front of that part.

Pass 1: the unsorted part starts at index 0; the smallest so far is arr[0] = 64.

25 < 64 → minIndex = 1.

12 < 25 → minIndex = 2.

22 < 12 is false → no change.

11 < 12 → minIndex = 4.

Swap: arr[0] ↔ arr[4] (64 ↔ 11). Index 0 is now final.

Pass 2: the unsorted part starts at index 1; the smallest so far is arr[1] = 25.

12 < 25 → minIndex = 2.

22 < 12 is false → no change.

64 < 12 is false → no change.

Swap: arr[1] ↔ arr[2] (25 ↔ 12). Index 1 is now final.

Pass 3: the unsorted part starts at index 2; the smallest so far is arr[2] = 25.

22 < 25 → minIndex = 3.

64 < 22 is false → no change.

Swap: arr[2] ↔ arr[3] (25 ↔ 22). Index 2 is now final.

Pass 4: the unsorted part starts at index 3; the smallest so far is arr[3] = 25.

64 < 25 is false → no change.

The smallest is already in place (minIndex = i = 3), so it swaps with itself and nothing changes. The last element is then in place too → sorted: 4 + 3 + 2 + 1 = 10 = n(n−1)/2 comparisons, O(n²).

Java passes arguments by value: swap(arr[minIndex], arr[i]) swaps only copies. Swap by index instead (or with swap(arr, i, minIndex)).

Insertion Sort

At first the sorted part is just a[0] (a single element is always sorted). Each pass puts the next element into its place in the sorted part by shifting.

Pass k = 1: set aside key = a[1] = 2; its cell now counts as a gap.

a[0] = 5 > 2 → 5 shifts one place right; the gap moves to index 0.

j == 0: we have reached the front of the sorted part; a[0] = 2. The first 2 elements are now sorted.

Pass k = 2: set aside key = a[2] = 4; its cell now counts as a gap.

a[1] = 5 > 4 → 5 shifts one place right; the gap moves to index 1.

a[0] = 2 ≤ 4: stop; a[1] = 4. The first 3 elements are now sorted.

Pass k = 3: set aside key = a[3] = 1; its cell now counts as a gap.

a[2] = 5 > 1 → 5 shifts one place right; the gap moves to index 2.

a[1] = 4 > 1 → 4 shifts one place right; the gap moves to index 1.

a[0] = 2 > 1 → 2 shifts one place right; the gap moves to index 0.

j == 0: we have reached the front of the sorted part; a[0] = 1. The first 4 elements are now sorted.

Pass k = 4: set aside key = a[4] = 3; its cell now counts as a gap.

a[3] = 5 > 3 → 5 shifts one place right; the gap moves to index 3.

a[2] = 4 > 3 → 4 shifts one place right; the gap moves to index 2.

a[1] = 2 ≤ 3: stop; a[2] = 3. The array is sorted. 7 shifts = the number of inversions in the array. Worst case O(n²); O(n) on an already sorted array.

static void insertionSort(int[] a) {
    for (int k = 1; k < a.length; k++) {
        int key = a[k];
        int j = k;
        while (j > 0 && a[j - 1] > key) {
            a[j] = a[j - 1];   // shift right
            j--;
        }
        a[j] = key;        // insert
    }
}
