Temel Kavramlar

Diziler (Arrays)

  • Aynı türden birden çok veriyi tek bir isim altında, düzenli olarak saklar.
  • Boyutu dizi oluşturulurken belirlenir ve sonradan değiştirilemez.
  • Öğeler bellekte ardışık (contiguous) yuvalarda, yan yana tutulur.
  • Öğelerin değerleri her zaman güncellenebilir; "ekleme/silme" ise öğeleri kaydırmak demektir.
  • Matris, resim (pikseller) ve ses (örnekler) gibi verileri temsil etmek için kullanılır.

Temel Kavramlar

Dizi Kullanımı: İndisle Erişim

  • Dizi elemanlarına indis (index) numarasıyla erişilir: diziAdi[indis].
  • İlk elemanın indisi 0, son elemanınki length − 1'dir.
  • Öğeler ardışık ve eşit boyutlu olduğundan her öğenin adresi tek bir çarpma ve toplamayla hesaplanır.
Bir hücreye tıkla: üst sıra indis, alt sıra değer.
int[] dizi = {7, 2, 9, 5, 1};
int ilkEleman = dizi[0];   // 7
int sonEleman = dizi[dizi.length - 1];   // 1

Temel Kavramlar

Diziler: Avantajlar ve Dezavantajlar

Avantajları

  • İndisle doğrudan, hızlı erişim: O(1).
  • Verileri gruplar ve eklenme sırasını korur.
  • Hem ilkel tipleri (int, char…) hem nesneleri tutabilir.
  • Ardışık bellek: ek referans yükü yok, önbellek (cache) dostu.

Dezavantajları

  • Sabit boyutludur; dolunca büyütülemez, yenisi oluşturulup kopyalanır.
  • Araya ekleme ve silme öğe kaydırmayı gerektirir: O(n).
  • Kullanılmayan kapasite boşa gider.
  • Dizinin kendi metodu yoktur; sıralama, arama vb. için java.util.Arrays kullanılır.
Java dizileri kovaryanttır (covariant): bu hem esneklik hem de bir tür güvenliği açığı getirir → sonraki slayt.

  • Bedeli: yanlış türde atama derleme zamanında değil, çalışma zamanında yakalanır.

Kod İzleme: Dizide Okuma ve Yazma

İlklendirici listesinde 5 değer var → heap'te 5 elemanlı bir int[] oluşur; sayilar yalnızca onun referansını tutar.

Okuma: sayilar[0] ilk hücre. Adres = başlangıç + 0 × 4 → tek adımda, O(1).

İndis 1 = ikinci eleman (indisler 0'dan başlar).

Yazma: aynı sözdizimi, atamanın solunda. Son hücre (indis 4 = length − 1) 50 → 55.

length bir alandır (parantez yok) → 5. Boyut, dizi oluşturulurken sabitlendi.

Sonradan atamada new int[] gerekir: yeni 3 elemanlı dizi oluşur, sayilar onu gösterir. Eski dizi değişmedi; referansı kalmadığı için GC toplayabilir. diziBoyutu hâlâ 5: o bir kopyaydı.

public class DiziOrnegi {
    public static void main(String[] args) {
        int[] sayilar = new int[5];            // 5 elemanlı dizi
        for (int i = 0; i < sayilar.length; i++)
            sayilar[i] = (i + 1) * 10;              // 10, 20, 30, 40, 50

            System.out.print(x + " ");
    }
}

Dizi Kopyalama: Referans mı, Kopya mı?

Dizi bir nesnedir: heap'te oluşur (#1). Stack'teki dizi değişkeni yalnızca onun adresini tutar.

= yalnızca adresi kopyalar: iki değişken aynı diziyi (#1) gösterir. Yeni dizi oluşmadı.

Arrays.copyOf heap'te yeni bir dizi (#2) oluşturur ve öğeleri tek tek kopyalar → O(n). (dizi.clone() ve System.arraycopy da öğeleri kopyalar.)

referans[0] = 99 #1'i değiştirir → dizi[0] da 99 olur. kopya[0] ayrı nesnede, hâlâ 1.

int[] dizi = {1, 2, 3, 4, 5};
int[] referans = dizi;   // aynı nesne
int[] kopya =
    Arrays.copyOf(dizi, dizi.length);
referans[0] = 99;

Java'da Diziler

Varargs (Değişken Sayıda Argüman)

  • tip... ad yazımı, metodun istediği sayıda argüman almasını sağlar.
  • Metodun içinde parametre sıradan bir dizidir.
  • Yalnızca son parametre varargs olabilir; metot başına bir tane.
  • Hazır bir dizi de doğrudan geçirilebilir.
static double ortalama(double... dizi) {
    if (dizi.length == 0)
        return Double.NaN;  // tanımsız
    var toplam = 0.0;
    for (var eleman : dizi)
        toplam += eleman;
    return toplam / dizi.length;
}

Çağrı ortalama(4, 8, 15): derleyici argümanları bir double[] dizisine koyar (int → double genişletilir).

Java'da Diziler

Bellekte Diziler: Stack ve Heap

  • Stack (yığın belleği): yerel değişkenler ve metot çağrıları. Metot bitince çerçevesi otomatik silinir.
  • Heap: new ile oluşturulan tüm nesneler. Java'da her dizi heap'tedir; stack'te yalnızca referansı durur.
  • Heap'i çöp toplayıcı (garbage collector, GC) yönetir: hiçbir referansın göstermediği nesneleri kendisi serbest bırakır.

static double[] diziOku(Scanner scanner) {

    int boyut = scanner.nextInt();

        System.out.print((i + 1) + ". elemanı girin: "); // 1'den say

Ortanca (Median) Hesaplama

static double ortanca(double[] dizi) {
    double[] s = dizi.clone(); // kopya
    Arrays.sort(s);             // O(n log n)
    int boyut = s.length;
    double ortanca;
    if (boyut % 2 == 0) {       // çift
        int o1 = boyut/2 - 1, o2 = boyut/2;
        ortanca = (s[o1] + s[o2]) / 2;
    } else {                    // tek
        ortanca = s[boyut / 2];
    }
    return ortanca;
}
  • Ortanca, sıralı dizinin ortasındaki değerdir.
  • Tek boyutta tam ortadaki, çift boyutta ortadaki iki değerin ortalaması alınır.
  • Ortalamanın aksine uç değerlerden (ör. 1000) etkilenmez.

Mod (En Sık Tekrar Eden Değer)

static int mod(int[] dizi) { // boş değil
    int[] s = dizi.clone();
    Arrays.sort(s);  // eşitler yan yana
    int enCok = s[0], enCokSayi = 1;
    int mevcutSayi = 1;
    for (int i = 1; i < s.length; i++) {
        if (s[i] == s[i - 1]) mevcutSayi++;
        else mevcutSayi = 1;   // yeni değer
        if (mevcutSayi > enCokSayi) {
            enCokSayi = mevcutSayi;
            enCok = s[i];
        }
    }
    return enCok;
}
  • Sıralamadan sonra eşit değerler ardışık olur; tek geçişte en uzun tekrar dizisi bulunur.
  • Eşitlikte ilk (en küçük) değer kalır, çünkü karşılaştırma >.
  • Maliyet: sıralama O(n log n) + tarama O(n).

    return enCok;
}

Girdi: {4, 1, 4, 2, 1, 4}. Eşit değerler dağınık.

Kopya sıralanınca eşit değerler yan yana gelir; artık tek geçiş yeter.

Başlangıç: ilk değer (1) şimdilik en çok görülen, 1 kez.

s[1] = 1 == s[0] → aynı değer sürüyor, mevcutSayi = 2.

2 > önceki rekor → yeni rekor: enCok = 1, 2 kez.

s[2] = 2 ≠ 1 → yeni değer, sayaç 1'e döner.

1 > 2 yanlış → rekor değişmez.

s[3] = 4 ≠ 2 → yeni değer, sayaç 1'e döner.

1 > 2 yanlış → rekor değişmez.

s[4] = 4 == s[3] → aynı değer sürüyor, mevcutSayi = 2.

2 > 2 yanlış → rekor değişmez. (Eşitlikte ilk değer kalır.)

s[5] = 4 == s[4] → aynı değer sürüyor, mevcutSayi = 3.

3 > önceki rekor → yeni rekor: enCok = 4, 3 kez.

return 4 (3 kez). Sıralama O(n log n) + tarama O(n).

Satırlar sütuna, sütunlar satıra dönüşür: m×n matrisin transpozu n×m'dir.

static int[][] transpoz(int[][] m) {
    int satir = m.length;
    int sutun = m[0].length;
    int[][] t = new int[sutun][satir];
    for (int i = 0; i < satir; i++)
        for (int j = 0; j < sutun; j++)
            t[j][i] = m[i][j];
    return t;
}
static void yazdirMatris(int[][] m) {
    for (int[] s : m) {

    }
}

static void hamleYap(char[][] t,

        || sutun < 0 || sutun > 2

static boolean kazandi(char[][] t, char o) {
    for (int i = 0; i < 3; i++)
        if ((t[i][0] == o && t[i][1] == o && t[i][2] == o)     // satır i
         || (t[0][i] == o && t[1][i] == o && t[2][i] == o))    // sütun i
            return true;
    return (t[0][0] == o && t[1][1] == o && t[2][2] == o)      // ana çapraz
        || (t[0][2] == o && t[1][1] == o && t[2][0] == o);     // ters çapraz
}
static boolean oyunDevamEdiyorMu(char[][] t, char o) {
    if (kazandi(t, o)) {
        System.out.println("Tebrikler, " + o + " oyuncusu kazandı!");
        return false;
    }
    for (char[] satir : t)
        for (char c : satir)
            if (c == ' ') return true;          // boş hücre var → devam
    System.out.println("Oyun berabere bitti.");
    return false;
}

Araya Ekleme: Sağa Kaydırma, O(n)

Kapasite 6, dolu 5 hücre. 4'ü indis 1'e eklemek için önce yer açılmalı.

k = 5: a[5] = a[4] = 1 (bir sağa kopyalandı). Sağdan başlanır: soldan başlasaydık 2, 9'un üzerine yazardı.

k = 4: a[4] = a[3] = 5 (bir sağa kopyalandı).

k = 3: a[3] = a[2] = 9 (bir sağa kopyalandı).

k = 2: a[2] = a[1] = 2 (bir sağa kopyalandı).

k = 1, 1 > 1 yanlış → döngü biter. 4 kaydırma yapıldı; a[1] ve a[2] şu an aynı (2).

Açılan yere yazılır: a[1] = 4.

return 6. Başa eklemek n, ortaya ≈ n/2 kaydırma → O(n); sona eklemek (yer varsa) O(1).

static int ekle(int[] a, int boyut,
             int indis, int deger) {
  // ön koşul: boyut < a.length
  for (int k = boyut; k > indis; k--)
    a[k] = a[k - 1];   // sağa kaydır
  a[indis] = deger;
  return boyut + 1;   // yeni boyut
}

Dizi doluysa (boyut == a.length) önce daha büyük bir dizi oluşturulup kopyalanır: O(n).

Aradan Silme: Sola Kaydırma, O(n)

Önceki eklemeden sonra: a[1] = 4 silinecek. Boşluk kalmaması için sağdakiler sola kayar.

k = 1: a[1] = a[2] = 2. Bu kez soldan başlanır: silinen değerin üzerine yazılır.

k = 2: a[2] = a[3] = 9.

k = 3: a[3] = a[4] = 5.

k = 4: a[4] = a[5] = 1.

k = 5 < 5 yanlış → döngü biter. 4 kaydırma.

Son hücrede eski değerin kopyası kalmıştı; 0 yazılır (nesne dizilerinde null: GC için önemli).

return 5. Baştan silme n − 1 kaydırma → O(n); sondan silme O(1).

static int sil(int[] a, int boyut, int indis) {
  for (int k = indis; k < boyut - 1; k++)
    a[k] = a[k + 1];   // sola kaydır
  a[boyut - 1] = 0;    // eski son hücreyi temizle
  return boyut - 1;    // yeni boyut
}

Seçimli Sıralama (Selection Sort)

int[] dizi = {64, 25, 12, 22, 11};
int n = dizi.length;
for (int i = 0; i < n - 1; i++) {
    int minIndex = i;
    for (int j = i + 1; j < n; j++)
        if (dizi[j] < dizi[minIndex])
            minIndex = j;
    // takas: indislerle, yerinde
    int gecici = dizi[minIndex];
    dizi[minIndex] = dizi[i];
    dizi[i] = gecici;
}

Sırasız 5 elemanlı dizi. Her tur, sıralanmamış kısmın en küçüğünü o kısmın başına getirecek.

1. tur: sıralanmamış kısım indis 0'den başlar; şimdilik en küçük dizi[0] = 64.

25 < 64 → minIndex = 1.

12 < 25 → minIndex = 2.

22 < 12 yanlış → değişmez.

11 < 12 → minIndex = 4.

Takas: dizi[0] ↔ dizi[4] (64 ↔ 11). İndis 0 artık kesin yerinde.

2. tur: sıralanmamış kısım indis 1'den başlar; şimdilik en küçük dizi[1] = 25.

12 < 25 → minIndex = 2.

22 < 12 yanlış → değişmez.

64 < 12 yanlış → değişmez.

Takas: dizi[1] ↔ dizi[2] (25 ↔ 12). İndis 1 artık kesin yerinde.

3. tur: sıralanmamış kısım indis 2'den başlar; şimdilik en küçük dizi[2] = 25.

22 < 25 → minIndex = 3.

64 < 22 yanlış → değişmez.

Takas: dizi[2] ↔ dizi[3] (25 ↔ 22). İndis 2 artık kesin yerinde.

4. tur: sıralanmamış kısım indis 3'den başlar; şimdilik en küçük dizi[3] = 25.

64 < 25 yanlış → değişmez.

En küçük zaten yerinde (minIndex = i = 3); takas kendisiyle yapılır, dizi değişmez. Son eleman da kendiliğinden yerinde → sıralandı: 4 + 3 + 2 + 1 = 10 = n(n−1)/2 karşılaştırma, O(n²).

Java'da parametreler değerle geçer: yerDegistir(dizi[minIndex], dizi[i]) yalnızca kopyaları değiştirir. Takas indislerle yapılmalı (ya da yerDegistir(dizi, i, minIndex)).

Örnek Problemler

  1. int[] a = new int[4]; sonrası a[4] ifadesi ne olur? a.length kaçtır?
  2. int[] b = a; b[0] = 9; sonrası a[0] kaçtır? Neden?
  3. n elemanlı dizide en büyük elemanı bulan metodu yazın. Karmaşıklığı nedir?
  4. {5, 1, 4, 2, 8} dizisine seçimli sıralamanın ilk iki turundan sonra dizi nasıl görünür?
  5. 1000 elemanlı double[] dizinin veri kısmı kaç bayttır?
  6. 3×4 bir matrisin transpozu kaç satır, kaç sütundur? t[2][1] hangi elemandır?
Cevapları göster
  1. ArrayIndexOutOfBoundsException (geçerli indisler 0–3); a.length = 4.
  2. 9: b ve a aynı dizi nesnesini gösterir.
  3. int max = a[0]; for (int x : a) if (x > max) max = x; → O(n) (boş dizi ayrıca kontrol edilmeli).
  4. 1. tur: {1, 5, 4, 2, 8}; 2. tur: {1, 2, 4, 5, 8}.
  5. 1000 × 8 = 8000 bayt (+ dizi başlığı).
  6. 4 satır, 3 sütun; t[2][1] = m[1][2].
