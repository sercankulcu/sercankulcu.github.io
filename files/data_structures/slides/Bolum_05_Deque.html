Deque Simulator

A deque (double-ended queue) allows insertion and removal at both the front and the rear. It can act as a stack (one end) or a queue (both ends).

How to use

  • Add First / Add Last insert the value; Remove First / Remove Last delete an end; Peek First / Peek Last read them.
  • Capacity (1–8) limits the size; adding to a full deque is an overflow.
  • Search and Traverse scan from front to rear; Load / Random fill sample values; Clear empties it; Cancel stops an animation.

Costs

OperationTime
Add / remove / peek at either endO(1)
Search, traverseO(n)

Typical uses: sliding-window maximum, palindrome checks, work-stealing schedulers.
