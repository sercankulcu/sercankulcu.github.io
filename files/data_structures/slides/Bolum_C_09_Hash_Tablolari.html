C ile Gerçekleştirim

Zincirlemeli tablo

typedef struct Kayit {
    char *anahtar;
    int deger;
    struct Kayit *sonraki;
} Kayit;

typedef struct {
    Kayit **kova;
    size_t kapasite, adet;
} HashTablo;
Tür tanımı veri yapısının bellekteki biçimini; yordamlar ise bu yapı üzerindeki davranışı kurar.

Temel İşlemler

Dize anahtar için basit hash

size_t hash_dize(const char *s) {
    size_t h = 5381;
    unsigned char c;
    while ((c = (unsigned char)*s++) != 0)
        h = ((h << 5) + h) ^ c;
    return h;
}

size_t indis = hash_dize(anahtar) % tablo->kapasite;
Kod örnekleri C99/C11 uyumlu olacak biçimde küçük ve tek sorumluluklu tutulmuştur.
