Soru 1: İşaretçi İzleme

Liste başlangıçta bas → 1 → 2 → 3 → 4 → null. Kod çalıştıktan sonra liste nasıl görünür?

Dugum p = bas.sonraki;              // (1)
p.sonraki = p.sonraki.sonraki;      // (2)
Dugum y = new Dugum(9);
y.sonraki = bas;                    // (3)
bas = y;
bas.sonraki = bas.sonraki.sonraki;  // (4)
Cevabı göster
  1. p, 2 değerli düğümü gösterir.
  2. 2'nin sonrakisi 4 olur; 3 listeden çıkar: 1 → 2 → 4
  3. 9 başa eklenir: 9 → 1 → 2 → 4
  4. 9'un sonrakisi 2 olur; 1 listeden çıkar.

Son durum: bas → 9 → 2 → 4 → null. Referansı kalmayan 1 ve 3 düğümleri GC ile temizlenir.

Soru 2: Metot Ne Yapıyor?

Aşağıdaki metodun ne yaptığını açıklayınız. 10 → 20 → 30 → 40 → 50 listesi ve k = 2 için ne döndürür?

int gizem(int k) {
    Dugum a = bas, b = bas;
    for (int i = 0; i < k; i++)
        b = b.sonraki;
    while (b != null) {
        a = a.sonraki;
        b = b.sonraki;
    }
    return a.veri;
}
Cevabı göster

Metot listenin sondan k. öğesini bulur.

b önce k adım öne alınır; sonra ikisi birlikte ilerler. b listenin sonunu (null) geçtiğinde a ile b arasında hâlâ k düğüm fark vardır, yani a sondan k. düğümdedir.

k = 2: b önce 30'a gelir. Birlikte ilerleme: (a, b) = (20, 40), (30, 50), (40, null) → 40.

Tek geçiş, O(n) zaman, O(1) ek bellek. k > boyut ise b.sonraki null üzerinde çağrılır → kontrol eklenmelidir.

Soru 3: Döngü Tespiti

Tek yönlü listede son düğüm yanlışlıkla önceki bir düğümü gösteriyor olabilir. Ek bellek kullanmadan listede döngü olup olmadığını bulan metodu yazınız.

İpucu: Biri birer, diğeri ikişer adım ilerleyen iki işaretçi (Floyd'un "kaplumbağa ve tavşan" yöntemi). Liste ortasını bulan sınav sorusundaki yaklaşımla karşılaştırın.

Cevabı göster 
boolean donguVarMi() {
    Dugum yavas = bas, hizli = bas;
    while (hizli != null && hizli.sonraki != null) {
        yavas = yavas.sonraki;
        hizli = hizli.sonraki.sonraki;
        if (yavas == hizli) return true;
    }
    return false;   // hizli sona ulaştı
}

Döngü yoksa hızlı işaretçi null'a ulaşır. Döngü varsa hızlı işaretçi her adımda aradaki mesafeyi 1 azaltır ve mutlaka yavaşa yetişir.

Zaman O(n), ek bellek O(1). (HashSet ile ziyaret edilenleri tutmak da çalışır ama O(n) bellek ister.)

Soru 4: Çift Yönlü Listede Sondan Silme

Çift yönlü bağlı listede (bas, son, düğümde onceki ve sonraki) son öğeyi silip değerini döndüren metodu yazınız. Tek yönlü listede aynı işlem neden O(n)'dir?

class CiftYonluDugum {
    int veri;
    CiftYonluDugum onceki;
    CiftYonluDugum sonraki;
}
Cevabı göster 
int sondanSil() {
    if (son == null)
        throw new IllegalStateException("Boş");
    int veri = son.veri;
    if (bas == son) {          // tek eleman
        bas = son = null;
    } else {
        son = son.onceki;
        son.sonraki = null;
    }
    return veri;
}

Çift yönlü listede yeni son, son.onceki ile O(1)'de bulunur. Tek yönlü listede son düğümün öncekini bulmak için baştan yürümek gerekir → O(n). Silme işleminde önceki düğümün sonraki bağlantısı güncellenmek zorunda olduğundan önceki düğüm bilgisi gerekir.

Soru 5: Dairesel Bağlı Liste

Yalnızca son işaretçisi tutulan dairesel listede (son.sonraki = ilk düğüm): (a) öğe sayısını bulan boyut(), (b) O(1) zamanda başa ekleyen basaEkle(x) metodlarını yazınız.

Cevabı göster 
int boyut() {
    if (son == null) return 0;
    int n = 0;
    Dugum p = son.sonraki;      // ilk düğüm
    do { n++; p = p.sonraki; }
    while (p != son.sonraki);   // başa döndük
    return n;
}
void basaEkle(int x) {
    Dugum yeni = new Dugum(x);
    if (son == null) {
        son = yeni;
        son.sonraki = son;      // kendini gösterir
    } else {
        yeni.sonraki = son.sonraki;
        son.sonraki = yeni;
    }
}

Dairesel listede null yoktur; başa dönülünce gezinme biter (do-while). Sona ekleme: aynı kod + son = yeni;

Çoktan Seçmeli · Bağlı Liste

Test 1

Yalnızca bas işaretçisi tutulan tek yönlü listede sona ekleme karmaşıklığı nedir?

Son düğümü bulmak için baştan yürümek gerekir → O(n). Ayrıca son işaretçisi tutulursa O(1) olur.

bas = bas.sonraki; satırı ne yapar?

Baş işaretçisi ikinci düğüme kayar; eski ilk düğüme referans kalmazsa çöp toplayıcı temizler. Boş listede NullPointerException verir.

Çoktan Seçmeli · Bağlı Liste

Test 2

Dairesel bağlı listede p = bas ile başlayan gezinme ne zaman biter?

Dairesel listede null yoktur; son düğüm başı gösterir. do-while ile p tekrar bas olana kadar ilerlenir.

Çift yönlü listede ortadaki p düğümünü silmek için doğru atamalar hangisidir?

Komşular birbirine bağlanır, p atlanır. İki atama O(1)'dir; p baş ya da sondaysa bas/son da güncellenmelidir.

Bağlı Listeyi Ters Çevirme

Liste bas → 1 → 2 → 3. Üç işaretçiyle ters çevirme kodunu izleyin.

Önce tahmin edin: döngü bitince bas hangi düğümü gösterir?

onceki null, p ilk düğümde.

p null değil → döngü.

Bağı koparmadan önce sonraki düğüm saklanır.

1 artık geriyi (null) gösterir.

onceki ve p bir adım ilerler.

2. tur: 2 → 1 yapılır, işaretçiler ilerler.

3. tur: 3 → 2 yapılır; p null olur.

p == null → döngü biter.

bas = 3: liste 3 → 2 → 1. Her düğüm bir kez: O(n), ek bellek O(1).

Dugum onceki = null, p = bas;
while (p != null) {
    Dugum sonraki = p.sonraki;
    p.sonraki = onceki;
    onceki = p;
    p = sonraki;
}
bas = onceki;

Ucu Açık Soru · Bağlı Liste

Tarayıcı Geçmişi

  1. Bir web tarayıcısının "geri" ve "ileri" düğmeleri için geçmişi hangi bağlı liste türüyle tutarsınız? Yeni bir sayfa açıldığında ileri geçmişi ne olmalıdır?
  2. Bekçi (sentinel) düğüm kullanmanın ekleme/silme kodunu nasıl sadeleştirdiğini bir örnekle açıklayın. Bedeli nedir?
Örnek cevap ve değerlendirme ölçütleri

1. Çift yönlü bağlı liste ve "şu anki sayfa" işaretçisi: geri = simdiki.onceki, ileri = simdiki.sonraki, ikisi de O(1). Yeni sayfa açılınca şu anki düğümden sonrası (ileri geçmişi) atılır: simdiki.sonraki = yeni. Alternatif: iki yığın (geri yığını, ileri yığını). Bellek sınırı için en eski kayıtlar baştan silinebilir.

2. Bekçi düğümler (baş ve son kukla düğümleri) sayesinde her gerçek düğümün önceki ve sonrakisi her zaman vardır. "Liste boş mu?", "silinen baş mı/son mu?" özel durumları ortadan kalkar; ekleme ve silme tek bir genel kodla yazılır, hata riski azalır. Bedeli: iki ek düğümlük bellek ve gezinmede bekçilerin atlanması.

Değerlendirme: uygun liste türü ve gerekçe · işlemlerin karmaşıklığı · ileri geçmişinin temizlenmesi · bekçi düğümün sağladığı sadeleşme ve maliyeti.
