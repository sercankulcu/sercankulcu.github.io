Soru 1: Bağlı Liste Türleri

Aşağıdaki ifadelerden hangisi dairesel (circular) tek yönlü bağlı liste için doğrudur?

Dairesel listede son düğüm null yerine ilk düğümü gösterir; liste bir halka olur. A doğrusal tek yönlü listeyi, B çift yönlü listeyi tanımlar. D yanlış: hiçbir bağlı liste türünde düğümler ardışık durmaz; sırayı referanslar belirler.

Soru 2: Öz-Referanslı Düğüm

Aşağıdaki Dugum sınıfı hakkında hangisi doğrudur?

class Dugum {
    int veri;
    Dugum sonraki;
    Dugum(int veri) {
        this.veri = veri;
        this.sonraki = null;
    }
}

Java'da nesne türünden alan bir referanstır: sonraki başka düğümün adresini tutar, kopyasını değil (A yanlış). Kurucu sonraki'yi null yapar (D yanlış); düğüm listeye bağlanınca değişir. Jenerik sürüm Dugum<T> aynı yapıyı her tür veri için kurar.

Soru 3: Bağları İzleme

Aşağıdaki kod ne yazdırır? Düğümlerin new ile oluşturulma sırası sonucu etkiler mi?

Dugum a = new Dugum(10), b = new Dugum(20);
Dugum c = new Dugum(30), d = new Dugum(40);
c.sonraki = a;
a.sonraki = d;
d.sonraki = b;
Dugum bas = c;
for (Dugum g = bas; g != null; g = g.sonraki)
    System.out.print(g.veri + " -> ");
System.out.println("null");
Cevabı göster

Çıktı: 30 -> 10 -> 40 -> 20 -> null

Gezinme bas = c (30) ile başlar ve sonraki referanslarını izler: 30 → 10 → 40 → 20; 20'nin sonraki alanı null kaldığı için liste orada biter.

Oluşturulma sırası (ya da bellekteki konum) etkilemez: düğümler bellekte ardışık değildir; sırayı yalnızca sonraki alanları belirler. Listeye erişmek için tek başına bas yeterlidir.

Soru 4: O(1) boyut()

listeUzunlugu() listeyi gezdiği için O(n)'dir; liste sınıfındaki boyut() ise O(1)'dir. Bu nasıl sağlanır ve bedeli nedir?

public class TekYonluBagliListe {
    private Dugum bas = null, son = null;
    private int boyut = 0;    // öğe sayısı
    public int boyut() { return boyut; }
    public boolean bosMu() { return boyut == 0; }
    public Integer ilk() {
        return bosMu() ? null : bas.veri; }
}
Cevabı göster

Sınıfta bir boyut alanı tutulur ve listeyi değiştiren her metotta güncellenir: basaEkle, sonaEkle, konumaEkle → boyut++; ilkOgeyiSil, sonOgeyiSil, ogeyiSil → yalnızca gerçekten silindiğinde boyut--. Böylece boyut() ve bosMu() (boyut == 0) gezinmeden cevap verir.

Bedel: bir metotta güncelleme unutulursa (ör. öğe bulunamadığı hâlde azaltmak) sayaç gerçek uzunluktan sapar. Bellek bedeli yalnızca bir int'tir.

Not: ilk() boş listede istisna yerine null döner.

Soru 5: Diziye Göre Dezavantajlar

Aşağıdakilerden hangisi tek yönlü bağlı listenin diziye göre bir dezavantajı değildir?

D dizinin dezavantajıdır; bağlı liste dinamik boyutludur, her ekleme yalnızca bir new yapar. A, B ve C bağlı listenin bilinen bedelleridir: rastgele erişim yok (i. öğe O(n)), düğüm başına ek referans, yalnızca ileri yön.

Soru 6: Hatalı Yazdırma

Liste 3 → 6 → 9 iken bu metot art arda iki kez çağrılıyor. Çıktı nedir ve hata nasıl düzeltilir?

void listeyiYazdir() {
    System.out.print("Bağlı Liste: ");
    while (bas != null) {
        System.out.print(bas.veri + " -> ");
        bas = bas.sonraki;
    }
    System.out.println("null");
}
Cevabı göster

1. çağrı: Bağlı Liste: 3 -> 6 -> 9 -> null
2. çağrı: Bağlı Liste: null

Döngü bas'ın kendisini ilerletir; döngü bitince bas == null olur. Listeye ulaşan tek referans kaybolduğu için düğümler erişilemez hâle gelir (çöp toplayıcı temizler): liste fiilen silinmiştir.

Düzeltme: yerel bir işaretçiyle gezinin; bas hiç değişmez:

Dugum gecici = bas;
while (gecici != null) {
    ...
    gecici = gecici.sonraki;
}

Soru 8: İşlem Dizisi

Boş bir tek yönlü listeye sırasıyla basaEkle(3), basaEkle(5), sonaEkle(7), basaEkle(9) uygulanıyor. Sonuç liste nedir?

Durumlar: 3 → (5 → 3) → (5 → 3 → 7) → 9 → 5 → 3 → 7. basaEkle yeni düğümü her zaman başa koyduğu için ekleme sırasını tersine çevirir; B bunu gözden kaçıran seçenektir. basaEkle iki atamadır, O(1); son işaretçisi yoksa sonaEkle sona kadar gezer, O(n).

Soru 9: son İşaretçisi Hatası

bas ve son tutan boş listede sonaEkle(5); sonaEkle(7); çağrılıyor. Ne olur? Hatayı düzeltin.

void sonaEkle(int veri) {
    Dugum yeniDugum = new Dugum(veri);
    if (bas == null) {
        bas = yeniDugum;
    } else {
        son.sonraki = yeniDugum;
        son = yeniDugum;
    }
}
Cevabı göster

1. çağrı: liste boş → bas = 5, ama son hâlâ null.

2. çağrı: bas != null → else dalı → son.sonraki null üzerinde erişim → NullPointerException.

Düzeltme: boş liste dalında bas = son = yeniDugum;

son işaretçisi sona eklemeyi gezinmesiz, iki atamalık O(1) işleme çevirir; bedeli, her işlemin (boş listeye ekleme, son düğümü silme) son'u güncel tutmak zorunda olmasıdır.

Soru 10: Konuma Ekleme

Liste 10 → 20 → 30. Sırasıyla konumaEkle(15, 1), konumaEkle(40, 4), konumaEkle(50, 6) çağrılıyor. Son liste nedir, konsola ne yazılır?

void konumaEkle(int veri, int indis) {
    if (indis == 0) { basaEkle(veri); return; }
    Dugum gecici = bas;
    for (int i = 0; i < indis - 1
                    && gecici != null; i++)
        gecici = gecici.sonraki;
    if (gecici == null) {
        System.out.println(
            "Belirtilen konum bulunamadı.");
        return; }
    Dugum yeniDugum = new Dugum(veri);
    yeniDugum.sonraki = gecici.sonraki;   // (1)
    gecici.sonraki = yeniDugum;           // (2)
}
Cevabı göster
ÇağrıgeciciListe
(15, 1)0 adım: 1010 → 15 → 20 → 30
(40, 4)3 adım: 3010 → 15 → 20 → 30 → 40
(50, 6)5. adımda nulldeğişmez

Konsol: Belirtilen konum bulunamadı. (yalnızca 3. çağrıda). Son liste: 10 → 15 → 20 → 30 → 40.

gecici, eklenecek yerin öncesine (indis − 1) yürür; indis = boyut ise sona eklenir. Yürüme O(indis), en kötü O(n); bağlama O(1). indis 0 ayrı ele alınır (basaEkle).

Soru 11: Bağlama Sırası

konumaEkle'nin son iki satırı yandaki gibi yer değiştirmiştir. 10 → 1 → 8 → 11 listesinde konumaEkle(5, 2) sonrası ne olur?

Dugum gecici = bas;
for (int i = 0; i < indis - 1
                && gecici != null; i++)
    gecici = gecici.sonraki;
Dugum yeniDugum = new Dugum(veri);
gecici.sonraki = yeniDugum;           // (2) önce
yeniDugum.sonraki = gecici.sonraki;   // (1) sonra

(2) önce çalışınca gecici.sonraki artık 5'tir; ardından (1) 5.sonraki = 5 yapar. 8'e giden tek referans kaybolmuştur ve gezinme sonsuz döngüye girer. B çekici ama 5'in sonrakisi null değil, kendisidir. Doğru sıra: önce yeni düğümü kalan listeye bağla (1), sonra önceki düğümü yeniye (2).

Soru 12: Baştan Silmede son

bas ve son tutan listede bu metot hangi durumda listeyi tutarsız bırakır? Bir örnekle gösterip düzeltin.

Dugum ilkOgeyiSil() {
    if (bas == null)
        return null;
    Dugum gecici = bas;
    bas = bas.sonraki;
    gecici.sonraki = null;  boyut--;
    return gecici;
}
Cevabı göster

Tek düğümlü listede (bas = son = 7): bas = bas.sonraki → bas null olur, ama son hâlâ 7'yi gösterir. Liste boş (boyut 0) iken son.veri 7 döndürür; son'u kullanan işlemler (ör. son öğeyi okuma, sondan silme) silinmiş düğüm üzerinde çalışır.

Düzeltme: bas = bas.sonraki; satırından sonra if (bas == null) son = null;

Geri kalanı doğrudur: boş liste kontrolü NPE'yi önler; silinen düğüm koparılıp döndürülür; işlem O(1). Kimse tutmazsa düğümü çöp toplayıcı geri alır.

Soru 13: Tek Düğümde Sondan Silme

Tek yönlü sonOgeyiSil'den tek düğüm kontrolü çıkarılmıştır. Liste yalnızca 7'den oluşuyorsa çağrı ne yapar?

void sonOgeyiSil() {
    if (bas == null) return;
    Dugum gecici = bas;
    while (gecici.sonraki.sonraki != null)
        gecici = gecici.sonraki;
    gecici.sonraki = null;
    son = gecici;  boyut--;
}

Tek düğümde gecici.sonraki == null; gecici.sonraki.sonraki null üzerinde alan okur → NPE. Asıl kodda bu yüzden if (bas.sonraki == null) { bas = son = null; } dalı vardır. Birden çok düğümde sondan bir önceki düğüm gezinerek bulunur: son işaretçisi olsa bile geri gidilemediği için O(n).

Soru 14: Belirli Öğeyi Silme

Liste 4 → 8 → 4 → 6 (boyut 4). Sırasıyla ogeyiSil(4), ogeyiSil(6), ogeyiSil(5) çağrılıyor. Sonuçta liste, son ve boyut nedir; konsola ne yazılır?

void ogeyiSil(int silinecek) {
    if (bas == null) return;
    if (bas.veri == silinecek) {
        bas = bas.sonraki;  boyut--;
        if (bas == null) son = null;  return; }
    Dugum onceki = bas, gecici = bas.sonraki;
    while (gecici != null) {
        if (gecici.veri == silinecek) {
            onceki.sonraki = gecici.sonraki;
            if (gecici == son) son = onceki;
            boyut--;  return; }
        onceki = gecici;
        gecici = gecici.sonraki; }
    System.out.println("Bulunamadı.");
}
Cevabı göster
ÇağrıNe olur?Sonuç
ogeyiSil(4)baş siliniyor: bas = 88 → 4 → 6
ogeyiSil(6)onceki = 4, gecici = 6 = son → son = 48 → 4
ogeyiSil(5)gecici null olurBulunamadı.

Sonuç: 8 → 4, son = 4, boyut = 2; konsol: Bulunamadı.

Yalnızca ilk 4 silinir. İki işaretçi birlikte yürür, çünkü silmek için önceki düğümün bağı değişmelidir. Arama O(n) + bağlama O(1) → O(n).

Soru 15: Listeyi Ters Çevirme

Liste bas → 1 → 2 → 3 → null. Kod bitince bas hangi düğümü gösterir ve her düğümün sonraki alanı neyi gösterir?

Önce kendiniz tahmin edin, sonra › ile ilerleyin.

onceki null, suanki ilk düğümde.

suanki null değil → döngü.

Bağı koparmadan önce sonraki düğüm saklanır.

1 artık null'u gösterir (bağ ters döndü).

onceki ve suanki birer düğüm ilerler.

2. tur: 2 → 1 yapılır, işaretçiler ilerler.

3. tur: 3 → 2 yapılır; suanki null olur.

suanki == null → döngü biter.

bas = onceki: liste 3 → 2 → 1 → null. Yeni düğüm yok; O(n) zaman, O(1) ek bellek.

Dugum onceki = null, suanki = bas;
while (suanki != null) {
    Dugum sonraki = suanki.sonraki;
    suanki.sonraki = onceki;
    onceki = suanki;
    suanki = sonraki;
}
bas = onceki;

Soru 16: Orta Öğe

ortaOgeyiBul() 2 → 4 → 6 → 8 → 10 → 12 listesinde ne döndürür?

int ortaOgeyiBul() {
    if (bas == null)
        throw new IllegalStateException(
            "Liste boş");
    Dugum yavas = bas, hizli = bas;
    while (hizli != null &&
           hizli.sonraki != null) {
        yavas = yavas.sonraki;        // 1 adım
        hizli = hizli.sonraki.sonraki; // 2 adım
    }
    return yavas.veri;
}

Turlar (yavas, hizli): (4, 6), (6, 10), (8, null). 2. turdan sonra hizli.sonraki = 12 null olmadığı için 3. tur da yapılır; çift uzunlukta ikinci orta döner. 6 (ilk orta) en çekici yanlıştır. Uzunluk bilinmeden tek geçiş: O(n).

Soru 17: Sığ Kopya

liste = 1 → 2 → 3. Kod ne yazdırır? kopyala() metodu bu sorunu nasıl önler?

Soru 18: Tekrarları Kaldırma

tekrarlayanlariKaldir() 2 → 2 → 5 → 2 → 5 → 9 listesine uygulanıyor. Sonuç liste nedir ve hangi düğümler atlanır?

void tekrarlayanlariKaldir() {
    TekYonluBagliListe gorulen =
        new TekYonluBagliListe();
    Dugum onceki = null, gecici = bas;
    while (gecici != null) {
        int v = gecici.veri;
        if (gorulen.iceriyor(v)) {  // atla
            onceki.sonraki = gecici.sonraki;
            if (gecici == son) son = onceki;
            boyut--;
        } else {
            gorulen.basaEkle(v);
            onceki = gecici; }
        gecici = gecici.sonraki;
    }
}
Cevabı göster
Düğümgorulen'de?İşlem
2hayırkalır, onceki = 2
2evetatlanır
5hayırkalır, onceki = 5
2evetatlanır; onceki 5'te kalır
5evetatlanır: 5.sonraki = 9

Sonuç: 2 → 5 → 9, 3 düğüm atlandı (boyut 3, son = 9). Atlamadan sonra onceki yerinde kalır; ilk düğüm hiç tekrar olmadığı için onceki null iken silme olmaz.

Her düğümde gorulen listesinde arama → O(n²); hash kümesiyle (Bölüm 9) O(n).

Soru 19: Sıralı Listeleri Birleştirme

l1 = 2 → 5 → 9, l2 = 3 → 4; sonuc boş ve sonaEkle O(1). Ana döngüde kaç karşılaştırma yapılır ve sonuc ne olur?

Önce kendiniz tahmin edin, sonra › ile ilerleyin.

İki işaretçi iki sıralı listenin başında.

İkisi de bitmedi; 2 ≤ 3 → doğru.

2 sonuca eklenir, g1 ilerler.

5 ≤ 3 → yanlış: küçük olan l2'de.

3 eklenir, g2 ilerler.

5 ≤ 4 → yanlış.

4 eklenir; g2 null oldu.

g2 == null → ana döngü biter: 3 karşılaştırma.

l1'de kalanlar karşılaştırmasız eklenir: 5.

9 eklenir; g1 null.

g2 zaten null; döngü çalışmaz. Sonuç 2 → 3 → 4 → 5 → 9. Her öğe bir kez eklenir: O(n + m) (sonaEkle O(1) iken).

Dugum g1 = l1.bas, g2 = l2.bas;
while (g1 != null && g2 != null) {
    if (g1.veri <= g2.veri) {
        sonuc.sonaEkle(g1.veri);
        g1 = g1.sonraki;
    } else {
        sonuc.sonaEkle(g2.veri);
        g2 = g2.sonraki;
    }
}
while (g1 != null) {
    sonuc.sonaEkle(g1.veri);
    g1 = g1.sonraki; }
while (g2 != null) {
    sonuc.sonaEkle(g2.veri);
    g2 = g2.sonraki; }

Soru 20: Sıralama Sayımı

sirala() 5 → 2 → 4 → 1 listesinde kaç karşılaştırma ve kaç takas yapar?

void sirala() {
    Dugum suanki = bas;
    while (suanki != null) {
        Dugum diger = suanki.sonraki;
        while (diger != null) {
            if (suanki.veri > diger.veri) {
                int gecici = suanki.veri;
                suanki.veri = diger.veri;
                diger.veri = gecici;
            }
            diger = diger.sonraki;
        }
        suanki = suanki.sonraki;
    }
}
Cevabı göster
suankiKarşılaştırmalarListe
1. (5)5>2 ✓, 2>4 ✗, 2>1 ✓1 5 4 2
2. (5)5>4 ✓, 4>2 ✓1 2 5 4
3. (5)5>4 ✓1 2 4 5
4. (5)diger = null—

6 karşılaştırma (3 + 2 + 1 = n(n−1)/2) ve 5 takas; sonuç 1 → 2 → 4 → 5.

Düğümler ve bağlar yerinde kalır, yalnızca veri alanları takas edilir. Karşılaştırma sayısı girdiden bağımsız: O(n²). Bağlı listede birleştirme sıralaması O(n log n) çalışır, ek dizi gerektirmez.

Soru 21: Çift Yönlü: Kazanç ve Bedel

Aşağıdakilerden hangisi çift yönlü listenin tek yönlü listeye göre üstünlüklerinden biri değildir?

Tersine, her düğüm ikinci bir referans (onceki) taşır ve her ekleme/silmede iki yön de güncellenmelidir: bedel budur. B, C ve D kazançlardır: son.onceki ve d.onceki ile önceki düğüme tek adımda ulaşılır.

Soru 22: Çift Yönlü sondanSil

bas ve son tutan çift yönlü listede (düğümde onceki, sonraki) son öğeyi silip değerini döndüren int sondanSil() metodunu yazın; boş listede IllegalStateException fırlatsın.

Cevabı göster 
int sondanSil() {
    if (son == null)
        throw new IllegalStateException("Liste boş");
    int veri = son.veri;
    if (bas == son) {          // tek düğüm
        bas = son = null;
    } else {
        son = son.onceki;       // tek adımda önceki
        son.sonraki = null;
    }
    return veri;
}

Gezinme yok: O(1). Tek düğümde bas ve son birlikte null yapılmalıdır; yoksa son.onceki null olur ve son.sonraki NPE verir. Tek yönlü listede sondan bir önceki düğümü bulmak için baştan gezmek gerekir: O(n).

Soru 23: Bağ Sırası (3) ↔ (4)

Liste 1 ⇄ 10 ⇄ 15 ⇄ 25, gecici = düğüm(10). Çift yönlü konumaEkle'de (3) ve (4) yer değiştirmiştir. İleri ve geri yazdırma ne verir; hangi bağ bozuktur?

Dugum yeni = new Dugum(12);
yeni.sonraki = gecici.sonraki;  // (1)
yeni.onceki = gecici;           // (2)
gecici.sonraki = yeni;          // (4) önce
gecici.sonraki.onceki = yeni;   // (3) sonra
Cevabı göster

İleri: 1 10 12 15 25  ·  Geri: 25 15 10 1 (12 yok).

(4) önce çalışınca gecici.sonraki artık 12'dir; (3) gecici.sonraki.onceki = yeni ile 12.onceki = 12 olur (kendini gösterir). 15'in onceki alanı hâlâ 10'u gösterdiği için geri gezinme 12'yi atlar.

Doğru sıra (3) sonra (4): 15'e gecici.sonraki üzerinden ulaşılabildiği sürece onun geri bağı düzeltilmelidir. Bağlama O(1); konuma yürümek O(n). (gecici son ise asıl kod sonaEkle çağırarak son'u da günceller.)

Soru 25: Baş ve Son Silme

Liste 1 ⇄ 10 ⇄ 15 ⇄ 25. Önce ogeyiSil(1), sonra ogeyiSil(25) çağrılıyor. Her çağrıda hangi dallar çalışır; sonunda bas ve son nedir?

void ogeyiSil(int veri) {
    Dugum gecici = bas;
    while (gecici != null && gecici.veri != veri)
        gecici = gecici.sonraki;
    if (gecici == null) return;  // bulunamadı
    if (gecici.onceki != null)
        gecici.onceki.sonraki = gecici.sonraki;
    else bas = gecici.sonraki;   // baş siliniyor
    if (gecici.sonraki != null)
        gecici.sonraki.onceki = gecici.onceki;
    else son = gecici.onceki;    // son siliniyor
}
Cevabı göster
Çağrı1. if/else2. if/else
ogeyiSil(1)onceki null → bas = 1010.onceki = null
ogeyiSil(25)15.sonraki = nullsonraki null → son = 15

Sonuç: 10 ⇄ 15, bas = 10, son = 15; geri yazdırma 15 10 verir.

Silinen düğümün komşuları birbirine bağlanır; komşu yoksa (baş/son siliniyorsa) bas ya da son güncellenir. Arama O(n), bağlama O(1).

Soru 27: Matristen Bağlı Yapı

olustur() döngüleri sol üstten başlayacak biçimde değiştirilmiştir. m = {{1,2,3}, {4,5,6}} için goruntule(olustur(m)) (sag ile satır, asagi ile satır atlayarak yazdırır) ne yazdırır?

Dugum olustur(int[][] m) {
    int r = m.length, c = m[0].length;
    Dugum[][] d = new Dugum[r][c];
    for (int i = 0; i < r; i++)           // üstten
        for (int j = 0; j < c; j++) {     // soldan
            Dugum n = new Dugum(m[i][j]);
            if (j + 1 < c) n.sag = d[i][j+1];
            if (i + 1 < r) n.asagi = d[i+1][j];
            d[i][j] = n;
        }
    return d[0][0];
}

Bir düğüm oluşturulurken sağındaki d[i][j+1] ve altındaki d[i+1][j] henüz null'dır; hiçbir bağ kurulmaz, yalnızca 1 yazdırılır. Asıl kod sağ alttan başlar: komşular önceden hazırdır, her hücre tek düğüm, O(satır · sütun). A, yön değişikliğinin etkisini gözden kaçıran seçenektir.

Soru 28: Neden son Tutulur?

Dairesel listede yalnızca bas tutulsaydı basaEkle'nin maliyeti ne olurdu? Bu, yalnızca son tutmayı nasıl gerekçelendirir?

Cevabı göster

O(n): yeni baş eklenince son düğümün sonraki alanı yeni düğümü göstermelidir; son düğümü bulmak için halkada gezmek gerekir.

Yalnızca son tutulursa baş son.sonraki'dir; iki uca da O(1) erişilir:

1 → 8 → 10 → (1) halkasında bu yazdir() ne yapar? Doğru sürümü yazın.

void yazdir() {

    Dugum simdiki = son.sonraki;

Dugum simdiki = son.sonraki;

(Eşdeğer: do { … } while (simdiki != son.sonraki);) Her düğüm bir kez: O(n).

Soru 30: Floyd ile Döngü Tespiti

Liste 1 → 2 → 3 → 4 → 5 ve 5 tekrar 2'yi gösteriyor (döngü baş düğüme dönmüyor). donguVarMi(bas) kaçıncı turda, hangi düğümde true döndürür?

Önce kendiniz tahmin edin, sonra › ile ilerleyin.

İki işaretçi de baştan başlar.

1. tur: hizli (1) ve hizli.sonraki (2) null değil.

yavas 1, hizli 2 adım.

2 ≠ 3 → devam.

2. tur: yavas 3'e, hizli 5'e.

3 ≠ 5 → devam.

3. tur: hizli 5 → 2 → 3; döngüyü dolaşıp yavaşın arkasından geliyor.

4 ≠ 3 → devam.

4. tur: yavas 5'e, hizli 3 → 4 → 5.

yavas == hizli (düğüm 5) → return true. Döngüde hızlı her tur 1 düğüm yaklaşır: O(n) zaman, O(1) bellek.

boolean donguVarMi(Dugum bas) {
    Dugum yavas = bas, hizli = bas;
    while (hizli != null &&
           hizli.sonraki != null) {
        yavas = yavas.sonraki;
        hizli = hizli.sonraki.sonraki;
        if (yavas == hizli) return true;
    }
    return false;
}

Soru 32: Dairesel Sondan Silme

Halka 1 → 8 → 10 → 16 → (1), son = 16. sondanSil() çağrılınca gecici = gecici.sonraki kaç kez çalışır ve sonunda halka nasıl görünür?

void sondanSil() {
    if (son == null) return;
    if (son.sonraki == son) son = null; // tek
    else {
        Dugum gecici = son.sonraki;
        while (gecici.sonraki != son)
            gecici = gecici.sonraki;
        gecici.sonraki = son.sonraki; // başa
        son = gecici;
    }
    boyut--;
}
Cevabı göster

gecici = 1 ile başlar: 1.sonraki = 8 ≠ son → 8; 8.sonraki = 10 ≠ son → 10; 10.sonraki == son → dur. 2 kez ilerler (n düğümde n − 2).

10.sonraki = son.sonraki (1); son = 10. Halka: 1 → 8 → 10 → (1), boyut 3.

Sondan bir önceki düğüm için halkada gezinmek gerekir: O(n). Çift yönlü dairesel listede son.onceki ile O(1) olur.

Soru 35: Tarayıcı Geçmişi

Bir web tarayıcısının “geri” ve “ileri” düğmeleri için geçmişi hangi bağlı liste türüyle tutarsınız; yeni bir sayfa açıldığında yapı nasıl güncellenir?

Örnek cevap ve değerlendirme ölçütleri

Çift yönlü bağlı liste + “şu anki sayfa” işaretçisi (simdiki): geri = simdiki.onceki, ileri = simdiki.sonraki; ikisi de O(1). Tek yönlü listede geri gitmek baştan gezinme (O(n)) isterdi.

Yeni sayfa açılınca ileri geçmişi atılır: yeni.onceki = simdiki; simdiki.sonraki = yeni; simdiki = yeni; Eski ileri düğümlere referans kalmaz, çöp toplayıcı temizler.

Bellek sınırı varsa en eski kayıt baştan O(1)'de silinir (bas tutulur). Alternatif: iki yığın (geri/ileri); bekçi düğümler uç durumları sadeleştirir.

Değerlendirme: uygun liste türü ve gerekçe · geri/ileri işlemlerinin O(1) olduğu · ileri geçmişinin temizlenmesi · tek yönlü alternatifle karşılaştırma.

Soru 36: Müzik Çalma Listesi

Bir müzik çalar için çalma listesi tasarlayın: sonraki/önceki şarkı, listenin sonunda başa dönme (tekrar modu) ve çalan şarkıyı silme desteklensin. Hangi bağlı liste türünü ve hangi işaretçileri kullanırsınız; işlemlerin maliyeti ne olur?

Örnek cevap ve değerlendirme ölçütleri

Çift yönlü dairesel liste + simdiki işaretçisi (ve sona ekleme için son; baş = son.sonraki).

  • Sonraki/önceki: simdiki.sonraki / simdiki.onceki → O(1); sonda başa dönme halka sayesinde kendiliğinden olur (null kontrolü yok).
  • Çalan şarkıyı silme: d.onceki.sonraki = d.sonraki; d.sonraki.onceki = d.onceki; → O(1); silinen son ise son güncellenir, tek şarkıysa liste boşalır.
  • Sona şarkı ekleme O(1); ada göre arama O(n).

Tek yönlü dairesel listede önceki şarkı ve silme O(n) olurdu. Dairesel listede gezinme != null ile değil, başa dönüşle bitirilmelidir.

Değerlendirme: liste türü ve gerekçe · halkanın başa dönmeyi nasıl sağladığı · silmede komşu bağları ve uç durumlar · maliyetlerin doğru verilmesi.
