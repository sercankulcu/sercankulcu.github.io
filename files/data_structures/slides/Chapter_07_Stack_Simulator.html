    Stack Simulator

    A stack is a LIFO (last in, first out) structure: elements are added and removed only at the top (TOP).

    How to use it

    • Push adds the value and Push Random adds a random one; Pop removes the top element and Peek reads it.
    • The capacity is 7. Pushing onto a full stack is an overflow; popping an empty one is an underflow.
    • Fill Randomly fills the stack, Search scans it from the top down, Clear empties it, and Cancel stops the animation.
    • The panel on the right lists the most recent operations.
