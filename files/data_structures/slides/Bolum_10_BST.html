Binary Search Tree Simulator

For every node, all values in the left subtree are smaller and all values in the right subtree are larger. This ordering rule determines search, insertion, deletion, predecessor, successor, minimum, maximum and sorted traversal.

How to use

  • Type an integer and choose Insert, Search, Delete, Predecessor or Successor; the visited nodes are highlighted along the path.
  • The traversal buttons animate the visiting order and write it to the traversal result box.
  • Load Example, Random Tree and Reset replace the tree; Cancel Animation stops the running operation.

BST concepts

  • Search decisions: at each node, equality finishes the search. A smaller target moves left; a larger target moves right.
  • Predecessor and successor: the predecessor is the greatest smaller key and the successor is the smallest larger key. They may be found in a subtree or among the ancestors.
  • Deletion: a leaf is removed, a node with one child is replaced by that child, and a node with two children takes the minimum of its right subtree (the inorder successor).
  • Degeneration: inserting sorted values creates a chain. The BST stays valid, but height and operation time become linear.
