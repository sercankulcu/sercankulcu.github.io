Yığın ADT

Yığın (Stack)

  • Ekleme ve çıkarma yalnızca bir uçtan, yığının üstünden (top) yapılır.
  • Üst üste konmuş tabaklar ya da kutular gibi düşünülebilir.
  • En alttaki öğeye ulaşmak için üstündeki öğeler tek tek çıkarılmalıdır.
  • LIFO (Last-In, First-Out · son giren ilk çıkar) ya da eşdeğeri FILO (ilk giren son çıkar) mantığıyla çalışır.

Yeni tabak en üste konur, alınan tabak da en üstten alınır.

Gerçekleme

Yığın Türleri

Sabit Boyutlu Yığın (Fixed Size Stack)
  • Kapasitesi baştan belirlenir; büyüyemez, küçülemez.
  • Dolu yığına ekleme → taşma (overflow).
  • Boş yığından çıkarma → alt taşma (underflow).
  • Arka planda sabit boyutlu bir dizi kullanır.
Dinamik Boyutlu Yığın (Dynamic Size Stack)
  • Çalışma sırasında büyüyüp küçülebilir.
  • Dolunca kapasitesini otomatik artırır (ör. iki katına çıkarır).
  • Öğe sayısı kapasiteye göre çok azalınca küçülebilir.
  • Dinamik dizi ya da bağlı liste ile gerçekleştirilir.

Boş yığından çıkarma (alt taşma) her iki türde de hatadır; taşma yalnızca sabit boyutlu yığında görülür.

Gerçekleme

Yığın Gerçekleme Yöntemleri

Yığın ADT'si bir dizi (array) ya da bağlı liste (linked list) ile gerçekleştirilebilir.

Dizi Tabanlı push: top indisi artırılır, öğe dizi[top]'a yazılır.
pop: dizi[top] alınır, sonra top azaltılır.
Bağlı Liste Tabanlı push: yeni düğüm listenin başına eklenir.
pop: baştaki düğüm çıkarılır, değeri döndürülür.

Gerçekleme

Dizi Tabanlı Yığın

Bu yaklaşıma sınırlı yığın (bounded stack) da denir: kapasite oluşturulurken belirlenir ve değişmez.

Avantajları

  • Basit ve kolay uygulanır.
  • Düğüm başına referans tutulmaz → bellek tasarrufu.
  • Bellek kullanımı sıkı biçimde kontrol edilir; belleği doldurmaya yönelik saldırılara karşı daha güvenlidir.
  • Öğeler ardışık → önbellek (cache) dostu.

Dikkat edilecekler

  • Eklemeden önce yığının dolu olmadığı kontrol edilmelidir.
  • Kapasite az seçilirse taşma, çok seçilirse boşa bellek.
  • Nesne tutan dizide çıkarılan hücreye null atanmalıdır; yoksa nesne bellekte gereksiz yere kalır.

Gerçekleme

Dizi Tabanlı Yığın: Java

public class DiziYigin<E> implements Stack<E> {
    private E[] veri;
    private int top = -1;                    // -1 → boş yığın
    public DiziYigin(int kapasite) { veri = (E[]) new Object[kapasite]; }
    public boolean isEmpty() { return top == -1; }
    public int size()        { return top + 1; }
    public E top()           { return isEmpty() ? null : veri[top]; }
    public void push(E x) {
        if (top == veri.length - 1) throw new IllegalStateException("Taşma");
        veri[++top] = x;
    }
    public E pop() {
        if (isEmpty()) throw new IllegalStateException("Alt taşma");
        E x = veri[top];
        veri[top--] = null;                  // referansı bırak
        return x;
    }
}

Jenerik (generic) dizi doğrudan oluşturulamadığı için Object[] dönüştürülür (derleyici “unchecked” uyarısı verir). Tüm işlemler O(1).

Kod İzleme: Dolunca İki Katına Büyüyen Yığın

Kapasite 2 ile başlıyoruz: boş yığında top = −1. Beş push yapacağız; dizi yetmeyince büyüyecek.

push(10): top = -1 ≠ 1 → yer var; veri[++top] = x → veri[0] = 10. Maliyet: 1 yazma.

push(20): top = 0 ≠ 1 → yer var; veri[++top] = x → veri[1] = 20. Maliyet: 1 yazma.

push(30): top = 1 = veri.length − 1 → dizi dolu. Hata vermek yerine büyüteceğiz.

buyut(4): kapasitenin iki katı (4) boyutunda yeni dizi ayrılır.

i = 0: yeni[0] = veri[0] = 10 kopyalanır.

i = 1: yeni[1] = veri[1] = 20 kopyalanır.

veri = yeni: yığın artık 4 hücrelik diziyi kullanır; eski 2 hücrelik dizi çöp toplayıcıya kalır.

push'a dönülür: veri[2] = 30. Bu push'un maliyeti 2 kopya + 1 yazma = 3.

push(40): top = 2 ≠ 3 → yer var; veri[++top] = x → veri[3] = 40. Maliyet: 1 yazma.

push(50): top = 3 = veri.length − 1 → dizi dolu. Hata vermek yerine büyüteceğiz.

buyut(8): kapasitenin iki katı (8) boyutunda yeni dizi ayrılır.

i = 0: yeni[0] = veri[0] = 10 kopyalanır.

i = 1: yeni[1] = veri[1] = 20 kopyalanır.

i = 2: yeni[2] = veri[2] = 30 kopyalanır.

i = 3: yeni[3] = veri[3] = 40 kopyalanır.

veri = yeni: yığın artık 8 hücrelik diziyi kullanır; eski 4 hücrelik dizi çöp toplayıcıya kalır.

push'a dönülür: veri[4] = 50. Bu push'un maliyeti 4 kopya + 1 yazma = 5. Toplam: 5 yazma + 6 kopya = 11 < 3n = 15 → push amortize O(1).

public void push(E x) {
  if (top == veri.length - 1)
    buyut(2 * veri.length);
  veri[++top] = x;
}
private void buyut(int yeniKap) {
  E[] yeni = (E[]) new Object[yeniKap];
  for (int i = 0; i <= top; i++)
    yeni[i] = veri[i];
  veri = yeni;
}

Gerçekleme

Neden Amortize O(1)?

Toplam maliyetn push: n yazma + (2 + 4 + 8 + …) kopya < n + 2n = 3n. Push başına ortalama < 3 → amortize O(1).
Sabit artış kötüHer dolumda +c hücre eklenirse kopyalar c + 2c + 3c + … = O(n²) olur; push ortalaması O(n).
Tek işlem vs ortalamaBüyütme yapan tek push O(n) sürer; amortize sınır, uzun bir işlem dizisinin ortalamasıdır.

Küçültme de yapılacaksa dizi dörtte bire düşünce yarıya indirilir; yarıda küçültmek, sınırda push/pop salınımında her işlemi O(n) yapabilir.

Bağlı Liste Tabanlı Yığın

  • Öğeler birbirine bağlı düğümlerden oluşan bir zincirde tutulur → esnek boyut.
  • Boyut, çalışma zamanında ihtiyaca göre değişir; taşma olmaz (bellek bitene kadar).
  • Her düğümde bir referans (sonraki) tutulduğu için ek bellek kullanır.
  • Rastgele erişim yoktur, ama üstteki öğeye (listenin başı) erişim hızlı ve basittir.
  • Ekleme ve çıkarma listenin başında yapıldığı için O(1)'dir.
class Dugum {
    int veri;
    Dugum sonraki;
    Dugum(int veri) { this.veri = veri; }   // sonraki = null
}

Neden başa ekliyoruz? Tek yönlü listede sondan silmek için sondan bir önceki düğümü bulmak gerekir → O(n).

Dugum top;         // yığının üstü

public void push(int veri) {

Çağrı Yığını: fakt(3) Adım Adım

main çalışıyor; fakt(3) çağrılacak. Her çağrı yığına yeni bir çerçeve (frame) iter.

fakt(3) çerçevesi yığına push edildi. n <= 1? 3 <= 1 → false.

3 * fakt(2) hesaplanamaz: önce fakt(2) bitmeli. Bu çerçeve askıda bekler.

fakt(2) çerçevesi yığına push edildi. n <= 1? 2 <= 1 → false.

2 * fakt(1) hesaplanamaz: önce fakt(1) bitmeli. Bu çerçeve askıda bekler.

fakt(1) çerçevesi yığına push edildi. n <= 1? 1 <= 1 → true.

Taban durum: return 1. Artık yığın çözülmeye (unwinding) başlar.

fakt(1) pop edildi, 1 döndü. fakt(2) devam eder: 2 * 1 = 2.

fakt(2) pop edildi, 2 döndü. fakt(3) devam eder: 3 * 2 = 6.

fakt(3) = 6 yazdırılır. Derinlik n → O(n) bellek; çok derin özyineleme StackOverflowError verir.

int fakt(int n) {
  if (n <= 1)
    return 1;
  return n * fakt(n - 1);
}
// main içinde:
System.out.println(fakt(3));

    for (int i = dizi.length-1; i >= 0; i--) {

               yigin.peek() <= dizi[i])

Bilgisayar bilimi ve matematikte klasik bir problem: bir disk yığını, kurallara uyularak kaynak çubuktan hedef çubuğa taşınır.

  • Bir hamlede yalnızca bir disk taşınır (bir çubuğun en üstündeki).

int[] span(int[] fiyatlar) {
    int[] sicrama = new int[fiyatlar.length];
    Deque<Integer> yigin = new ArrayDeque<>();
    yigin.push(0); sicrama[0] = 1;

    yigin.push(0); sicrama[0] = 1;
    for (int i = 1; i < fiyatlar.length; i++) {
        while (!yigin.isEmpty() &&
            fiyatlar[i] >= fiyatlar[yigin.peek()])
            yigin.pop();
        sicrama[i] = yigin.isEmpty() ? i + 1
                              : i - yigin.peek();
        yigin.push(i);
    }
    return sicrama;
}

String infixToPostfix(String ifade) {
  StringBuilder cikti = new StringBuilder();
  Deque<Character> yigin = new ArrayDeque<>();
  for (char c : ifade.toCharArray()) {
    if (Character.isLetterOrDigit(c)) cikti.append(c);
    else if (c == '(') yigin.push(c);
    else if (c == ')') {
      while (yigin.peek() != '(')
        cikti.append(yigin.pop());
      yigin.pop();                  // '(' atılır

          oncelik(yigin.peek()) >= oncelik(c))
        cikti.append(yigin.pop());
      yigin.push(c);
    }
  }
  while (!yigin.isEmpty()) cikti.append(yigin.pop());
  return cikti.toString();
}
int oncelik(char op) {
  switch (op) {
    case '+': case '-': return 1;
    case '*': case '/': return 2;
    default: return 0;   // '('
  }
}

int hesapla(int sol, char op, int sag) {
  switch (op) {
    case '+': return sol + sag;

int postfixDegerlendir(String ifade) {
  Deque<Integer> yigin = new ArrayDeque<>();
  for (char c : ifade.toCharArray()) {
    if (Character.isDigit(c)) {
      yigin.push(c - '0');
    } else {
      int sag = yigin.pop();
      int sol = yigin.pop();
      yigin.push(hesapla(sol, c, sag));
    }
  }
  return yigin.pop();
}
