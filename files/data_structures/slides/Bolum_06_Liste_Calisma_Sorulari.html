Soru 1: ArrayList Çıktısı

Programın çıktısı nedir? remove(1) ile remove(Integer.valueOf(20)) farkını açıklayınız.

List<Integer> l = new ArrayList<>(
        List.of(5, 10, 15, 20, 25));
l.remove(1);
l.remove(Integer.valueOf(20));
l.add(1, 99);
l.set(3, l.get(0) + l.size());
System.out.println(l + " " + l.indexOf(15)
                   + " " + l.contains(25));
Cevabı göster
  • remove(1): int argüman indistir → 10 silinir: [5, 15, 20, 25]
  • remove(Integer.valueOf(20)): nesne argüman değerdir → [5, 15, 25]
  • add(1, 99) → [5, 99, 15, 25]
  • set(3, 5 + 4) → 25'in yerine 9: [5, 99, 15, 9]

Çıktı: [5, 99, 15, 9] 2 false

Soru 2: Gezinirken Silme

Kod çift sayıları silmek için yazılmıştır. Çalıştırınca ne olur? Neden? İki doğru çözüm yazınız.

List<Integer> l = new ArrayList<>(
        List.of(1, 2, 3, 4, 5, 6));
for (Integer x : l)
    if (x % 2 == 0)
        l.remove(x);
System.out.println(l);
Cevabı göster

ConcurrentModificationException. for-each gizli bir Iterator kullanır. 2 silinince listenin değişiklik sayacı (modCount) artar; sonraki next() çağrısı bunu fark eder ve istisna fırlatır.

// Çözüm 1: Iterator.remove
Iterator<Integer> it = l.iterator();
while (it.hasNext())
    if (it.next() % 2 == 0)
        it.remove();

// Çözüm 2: removeIf
l.removeIf(x -> x % 2 == 0);

Sonuç: [1, 3, 5].

Soru 3: ListIterator

Programın çıktısı nedir? Her adımda imlecin (cursor) konumunu belirtiniz.

List<String> l = new LinkedList<>(
        List.of("A", "B", "C"));
ListIterator<String> it = l.listIterator();
it.next();
it.add("X");
it.next();
it.set("Y");
it.previous();
it.remove();
System.out.println(l + " " + it.nextIndex());
Cevabı göster
AdımListe (| = imleç)Not
başlangıç| A B C
next() → AA | B C
add("X")A X | B Cimlecin önüne ekler
next() → BA X B | C
set("Y")A X Y | Cson döneni değiştirir
previous() → YA X | Y C
remove()A X | Cson döneni (Y) siler

Çıktı: [A, X, C] 2

Cevabı göster
İşlemArrayListLinkedList
get(i)O(1)O(n)
