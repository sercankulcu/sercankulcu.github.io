Kuyruk ADT

Kuyruk (Queue)

  • Her iki ucu açık, doğrusal bir veri yapısıdır.
  • İşlemler ilk giren, ilk çıkar (FIFO - First-In, First-Out) sırasıyla yapılır.
  • Ekleme bir uçtan (arka, rear), çıkarma diğer uçtan (ön, front) yapılır.
  • Market kasasındaki, bilet gişesindeki sıra gibi: önce gelen önce hizmet alır.

Kuyruk ADT

Temel Kuyruk İşlemleri

Ekleme (enqueue)Kuyruğun sonuna (arkasına) yeni bir öğe ekler.Zaman karmaşıklığı: O(1)
Çıkarma (dequeue)Kuyruğun başındaki (önündeki) öğeyi çıkarır ve döndürür. İlk giren öğe ilk çıkar (FIFO ilkesi).Zaman karmaşıklığı: O(1)
Kuyrukta ortadaki bir öğeye doğrudan erişilmez; yalnızca ön ve arka uçlar kullanılır.

Tek sıra yürüyen atlar: öndeki önce geçer, yeni gelen sona katılır.

Dizi ile Kuyruk

Dizi ile Kuyruk

  • Öğeler bir dizide tutulur; iki indis kuyruğun uçlarını gösterir:
    • front (ön): ilk öğenin indisi.
    • rear (arka): son öğenin indisi.
  • Eklemede rear, çıkarmada front bir artar. Öğeler yerinden kaydırılmaz.
  • Basit ve hızlıdır, ancak dizinin kapasitesi sabittir.

İndis 0'daki öğe daha önce çıkarıldı; o yuva artık boş ama basit dizi kuyruğu onu yeniden kullanamaz.

Dizi ile Kuyruk

Basit Dizi Kuyruğunun Sorunu

Boş kuyruk, kapasite N = 6. rear = −1: henüz öğe yok.

enqueue(10): rear++ → 0, öğe dizi[0]'e yazılır.

enqueue(20): rear++ → 1, öğe dizi[1]'e yazılır.

enqueue(30): rear++ → 2, öğe dizi[2]'e yazılır.

enqueue(40): rear++ → 3, öğe dizi[3]'e yazılır.

dequeue() → 10: front++ → 1. Boşalan yuva bir daha kullanılmaz.

dequeue() → 20: front++ → 2. Boşalan yuva bir daha kullanılmaz.

dequeue() → 30: front++ → 3. Boşalan yuva bir daha kullanılmaz.

enqueue(50): rear = 4.

enqueue(60): rear = 5 = N − 1, dizinin son indisi.

Yalnızca 3 öğe varken “dolu”: turuncu 3 yuva boşa gidiyor. Kaydırma O(n) sürer; çözüm dairesel kuyruk.

Çözüm 1: KaydırmaHer dequeue'da öğeleri sola kaydır → dequeue O(n).
Çözüm 2: Dairesel diziİndisler sona gelince başa sarar → her işlem O(1).

Dizi ile Kuyruk

Dairesel Kuyruk (Circular Queue)

  • Normal kuyruk gibi FIFO çalışır; ama dizinin son yuvasından sonra ilk yuvaya dönülür.
  • Dizinin başı ve sonu mantıksal olarak birleşip bir halka oluşturur.
  • İndisler mod (%) işlemiyle ilerletilir: (i + 1) % N.
  • Boşalan yuvalar yeniden kullanılır; öğe kaydırmaya gerek kalmaz.
  • Halka tampon (ring buffer) olarak da bilinir.

Burada arka, bir sonraki öğenin yazılacağı boş yuvadır: arka = (front + size) % N = (0 + 5) % 8 = 5.

İndislerin Mod ile Gezinmesi

Sonraki boş yuva (ekleme yeri)(front + size) % N(6 + 4) % 8 = 2
Son öğe(front + size − 1) % N(6 + 3) % 8 = 1

Sıra önden arkaya: A (6), B (7), C (0), D (1). Mod işlemi, dizinin sonundan başına geçişi tek bir ifadeyle çözer.

Dizi ile Kuyruk

Dolu mu, Boş mu?

Yalnızca front ve arka indisleri tutulursa, boş ve dolu kuyrukta ikisi de aynı yuvayı gösterir; durumlar ayırt edilemez. İki yaygın çözüm:

1. Öğe sayacı (size)Boş: size == 0 · Dolu: size == N
Dizinin N yuvasının tamamı kullanılır. Bu derste kullandığımız yöntem.
2. Bir yuvayı boş bırakmakBoş: front == arka · Dolu: (arka + 1) % N == front
Sayaç gerekmez, ama en fazla N − 1 öğe saklanır.

Boş kuyruk: boyut = 0. Halkada kırmızı kenarlı dilim bas, dizide ▲son sonraki yazma yeridir.

ekle(20) → dizi[1]; boyut = 2.

cikar() → 20; bas = (1 + 1) % 5 = 2. Öğeler yerinden oynamaz.

ekle(40) → dizi[3].

ekle(50) → dizi[4].

cikar() → 30; bas = 3.

cikar() → 40; bas = 4.

cikar() → 50; bas = 0. (4 + 1) % 5 = 0 → bas da başa sardı.

cikar() → 60; bas = 1.

cikar() → 70; bas = 2. boyut = 0 → kuyruk yine boş; çıkış sırası 30, 40, 50, 60, 70 = giriş sırası (FIFO).

Dairesel Kuyruk: Sınıf ve Durum Sorguları

public class DaireselKuyruk<E> {
    private E[] dizi;       // öğeleri saklar
    private int bas = 0;    // ilk öğenin indisi (front)
    private int boyut = 0;  // öğe sayısı (size)

    @SuppressWarnings("unchecked")
    public DaireselKuyruk(int kapasite) {
        dizi = (E[]) new Object[kapasite];
    }
    public int boyut()      { return boyut; }
    public boolean bosMu()  { return boyut == 0; }
    public boolean doluMu() { return boyut == dizi.length; }
    public E ilk()          { return bosMu() ? null : dizi[bas]; }
    // ekle(), cikar() → sonraki slayt
}
Arka indisi ayrıca saklanmaz; gerektiğinde (bas + boyut) % dizi.length ile hesaplanır. Böylece iki alanın birbiriyle tutarsız kalma riski ortadan kalkar.

Dairesel Kuyruk: ekle ve cikar

public void ekle(E oge) {           // enqueue
    if (doluMu())
        throw new IllegalStateException("dolu");
    int son = (bas + boyut) % dizi.length;
    dizi[son] = oge;
    boyut++;
}
public E cikar() {                  // dequeue
    if (bosMu())
        throw new IllegalStateException("boş");
    E oge = dizi[bas];
    dizi[bas] = null;               // referansı bırak
    bas = (bas + 1) % dizi.length;
    boyut--;
    return oge;
}
Ekleme yeriN = 5, bas = 3, boyut = 2son = (3 + 2) % 5 = 0
Önü ilerletmeN = 5, bas = 4bas = (4 + 1) % 5 = 0

Kod İzleme: Dairesel ekle()

Başlangıç: dizi.length = 5, bas = 2, boyut = 2 (30 ve 40). Şimdi 50, 60, 70, 80 eklenecek.

ekle(50): doluMu() → boyut 2 == 5? hayır.

son = (2 + 2) % 5 = 4 % 5 = 4.

dizi[4] = 50. Diğer öğeler yerinden oynamaz.

boyut++ → 3. bas değişmedi; ön hâlâ dizi[2].

ekle(60): doluMu() → boyut 3 == 5? hayır.

son = (2 + 3) % 5 = 5 % 5 = 0 → dizinin sonu aşıldı, başa sardı.

dizi[0] = 60. Diğer öğeler yerinden oynamaz.

boyut++ → 4. bas değişmedi; ön hâlâ dizi[2].

ekle(70): doluMu() → boyut 4 == 5? hayır.

son = (2 + 4) % 5 = 6 % 5 = 1 → dizinin sonu aşıldı, başa sardı.

dizi[1] = 70. Diğer öğeler yerinden oynamaz.

boyut++ → 5. bas değişmedi; ön hâlâ dizi[2]. Kuyruk artık dolu.

ekle(80): doluMu() → boyut 5 == 5? evet.

Kuyruk dolu → IllegalStateException("dolu") fırlatılır; dizi değişmez. Kapasite 5 öğede tükendi, hiçbir yuva boşa gitmedi.

Kod İzleme: Dolu Dairesel Kuyruğu Büyütme

Dolu kuyruk (bas = 2): sıra A, B, C, D, dizide ise C, D, A, B. Şimdi ekle(E).

4 == 4 → dolu. Hata yerine iki katı kapasiteyle büyüt.

8 hücrelik yeni dizi ayrılır.

k = 0: yeni[0] = dizi[(2 + 0) % 4] = dizi[2] = A.

k = 1: yeni[1] = dizi[(2 + 1) % 4] = dizi[3] = B.

k = 2: yeni[2] = dizi[(2 + 2) % 4] = dizi[0] = C. Mod ile başa sarıldı.

k = 3: yeni[3] = dizi[(2 + 3) % 4] = dizi[1] = D.

dizi = yeni: öğeler artık sıralı (Arrays.copyOf sırayı bozardı).

bas = 0: ön öğe (A) artık dizi[0]'da.

ekle'ye dönülür: (0 + 4) % 8 = 4 → dizi[4] = E.

boyut → 5. Büyütme O(n), ama 2 katına çıktığı için ekle amortize O(1).

private void buyut(int yeniKap) {
  E[] yeni = (E[]) new Object[yeniKap];
  for (int k = 0; k < boyut; k++)
    yeni[k] = dizi[(bas + k) % dizi.length];
  dizi = yeni;
  bas = 0;
}
public void ekle(E oge) {
  if (boyut == dizi.length) buyut(2 * dizi.length);
  dizi[(bas + boyut) % dizi.length] = oge;
  boyut++;
}

Bağlı Liste ile Kuyruk

Bağlı Liste ile Kuyruk

  • Her kuyruk öğesi bir düğümdür (veri + sonraki referansı).
  • front listenin başını, rear sonunu gösterir: ekleme sona, çıkarma baştan.
  • Boyut dinamiktir; kapasite sınırı (dolu kuyruk) yoktur.
  • Düğüm başına fazladan bir referans ve nesne oluşturma maliyeti vardır.
class Dugum {
    int veri;
    Dugum sonraki;
    Dugum(int veri) {
        this.veri = veri;
    }
}
// alanlar:
Dugum front, rear;
int uzunluk;

Neden ekleme sona, çıkarma başa? Tek yönlü listede baştan silmek O(1), ama sondan silmek için sondan bir önceki düğümü bulmak O(n) gerekir.

Bağlı Liste ile Kuyruk

Enqueue ve Dequeue Algoritması

enqueue(x)
  1. Kuyruk dolu mu? (sabit kapasiteli dizide)
  2. Doluysa taşma (overflow) hatası ver, bitir.
  3. Değilse x'i arka konuma yaz.
  4. Arkayı bir sonraki konuma ilerlet.
  5. Öğe sayısını artır, başarılı dön.
dequeue()
  1. Kuyruk boş mu?
  2. Boşsa alt taşma (underflow) hatası ver, bitir.
  3. Değilse öndeki öğeyi al.
  4. Önü bir sonraki öğeye ilerlet.
  5. Öğe sayısını azalt, alınan öğeyi döndür.

Kod İzleme: Bağlı Liste Kuyruğu enqueue

Boş kuyruk: front = rear = null. Sırayla enqueue(10), enqueue(15), enqueue(20).

new Dugum(10): sonraki = null olan yeni düğüm; henüz listeye bağlı değil.

bosMu() → true (uzunluk 0).

İlk düğüm: front = gecici.

rear = gecici: arka artık yeni düğüm. Tek düğüm hem ön hem arka.

uzunluk++ → 1.

new Dugum(15): sonraki = null olan yeni düğüm; henüz listeye bağlı değil.

bosMu() → false; else dalına gidilir.

rear.sonraki = gecici: eski arka (10) yeni düğüme bağlanır.

rear = gecici: arka artık yeni düğüm.

uzunluk++ → 2.

new Dugum(20): sonraki = null olan yeni düğüm; henüz listeye bağlı değil.

bosMu() → false; else dalına gidilir.

rear.sonraki = gecici: eski arka (15) yeni düğüme bağlanır.

rear = gecici: arka artık yeni düğüm.

public void enqueue(int veri) {
    Dugum gecici = new Dugum(veri);
    if (bosMu()) {
        front = gecici;
    } else {
        rear.sonraki = gecici;
    }
    rear = gecici;
    uzunluk++;
}

Bağlı Liste ile Kuyruk · Kodu adım adım çalıştır

Kod İzleme: Bağlı Liste Kuyruğu dequeue

Önceki slayttan: 10, 15, 20. Üç kez dequeue() çağrılacak.

bosMu() → false (uzunluk 3).

sonuc = front.veri = 10.

front = front.sonraki → düğüm(15). Eski düğüme artık kimse bakmıyor (çöp toplayıcı temizler).

front == null → false; rear aynı kalır.

uzunluk-- → 2; return 10.

bosMu() → false (uzunluk 2).

sonuc = front.veri = 15.

front = front.sonraki → düğüm(20). Eski düğüme artık kimse bakmıyor (çöp toplayıcı temizler).

front == null → false; rear aynı kalır.

uzunluk-- → 1; return 15.

bosMu() → false (uzunluk 1).

sonuc = front.veri = 20.

front = front.sonraki → null. Ama rear hâlâ silinen düğümü gösteriyor!

front == null → true: kuyruk boşaldı.

rear = null: bu satır olmasa kuyruk boşken rear silinen düğümü göstermeye devam ederdi (tutarsız durum).

uzunluk-- → 0; return 20. Çıkış sırası 10, 15, 20 (FIFO), her işlem O(1).

public int dequeue() {
    if (bosMu())
        throw new NoSuchElementException();
    int sonuc = front.veri;
    front = front.sonraki;
    if (front == null)
        rear = null;
    uzunluk--;
    return sonuc;
}

Dairesel Dizi mi, Bağlı Liste mi?

Dairesel dizi

  • Bellekte ardışık; önbellek dostu ve hızlı.
  • Öğe başına ek referans yok.

Öncelikli Kuyruk (Priority Queue)

  • Her öğenin bir önceliği vardır; çıkarma sırasını geliş sırası değil öncelik belirler.
  • Kullanım: işletim sistemi zamanlayıcısı, acil servis triyajı, olay simülasyonu, Dijkstra, Huffman kodlaması.

Bu örnek max-öncelikli bir kuyruktur: büyük sayı daha yüksek öncelik taşır. Bölüm 8'de hem min-öncelikli (removeMin) hem max-heap (silMax) örnekleri vardır; kural seçilen karşılaştırıcıya bağlıdır.

Boş öncelikli kuyruk. Burada büyük değer = yüksek öncelik.

A tek öğe olarak dizi[0]'a yerleşir.

5 > 2 → A bir sağa kayar, B başa yerleşir.

1 en düşük öncelik → C kaydırma olmadan sona eklenir.

D: A ve C kayar; 5 > 5 değil → D, B'nin arkasında kalır (eşitlerde FIFO).

En yüksek öncelikli B, dizi[0]'dan alınır; kalanlar bir sola kayar.

Sonra D çıkar. Çıkış sırası önceliğe göre: B, D, A, C.

class Oge<T> {
    T veri;
    int oncelik;
    Oge(T v, int p) { veri = v; oncelik = p; }
}
// OncelikliKuyruk<E> alanları
private Oge<E>[] dizi =
    (Oge<E>[]) new Oge[10];
private int boyut = 0;
public void ekle(E veri, int p) {
    if (boyut == dizi.length)
        dizi = Arrays.copyOf(dizi, 2 * boyut);
    int i = boyut;
    while (i > 0 && dizi[i-1].oncelik < p) {
        dizi[i] = dizi[i - 1];  // sağa kaydır
        i--;
    }
    dizi[i] = new Oge<>(veri, p);
    boyut++;
}
public E cikar() {
    if (bosMu()) return null;
    E sonuc = dizi[0].veri;
    for (int i = 1; i < boyut; i++)
        dizi[i - 1] = dizi[i];
    dizi[--boyut] = null;
    return sonuc;
}

Dizi, öncelikleri büyükten küçüğe sıralı tutulur: ekle O(n) (kaydırma), cikar O(n). Heap ile ikisi de O(log n) olur (Bölüm 8).

Kuyruk Türleri

Deque İşlemleri Adım Adım

Boş deque. Çift yönlü bağlı liste ile uygulayacağız: her düğümde onceki ve sonraki.

İlk düğüm: bas = son = yeni düğüm.

Sona ekleme: yeni.onceki = son; son.sonraki = yeni; son = yeni.

Başa ekleme: yeni.sonraki = bas; bas.onceki = yeni; bas = yeni.

Her iki uç da referansla tutulduğu için tüm eklemeler O(1).

Sondan çıkarma: son = son.onceki; son.sonraki = null. Önceki referansı sayesinde O(1).

Baştan çıkarma: bas = bas.sonraki; bas.onceki = null.

Tek yönlü listede sondan çıkarma O(n) olurdu (sondan bir önceki düğümü bulmak için). onceki referansı bunu O(1) yapar.

    Dugum<E> d = new Dugum<>(veri);
    if (bosMu()) {
        bas = son = d;
    } else {
        d.sonraki = bas;
        bas.onceki = d;
        bas = d;
    }
    boyut++;
}

    } else {

    E veri;
    Dugum<E> onceki, sonraki;

Deque Uygulaması: Kayan Pencerede En Büyük

k = 3. d indis tutar; değerler önden arkaya azalır, önde en büyük durur.

a[0] = 1: 0 arkaya.

a[1] = 3: arkadan at 0:1. 1 arkaya.

a[2] = -1: 2 arkaya. En büyük = 3.

a[3] = -3: 3 arkaya. En büyük = 3.

a[4] = 5: önden at 1; arkadan at 3:-3; arkadan at 2:-1. 4 arkaya. En büyük = 5.

a[5] = 3: 5 arkaya. En büyük = 5.

a[6] = 6: arkadan at 5:3; arkadan at 4:5. 6 arkaya. En büyük = 6.

Her indis bir kez girer, en çok bir kez çıkar → O(n) (kaba kuvvet O(n·k)).

int[] pencereMax(int[] a, int k) {
  int[] enb = new int[a.length - k + 1];
  Deque<Integer> d = new ArrayDeque<>(); // indis
  for (int i = 0; i < a.length; i++) {
    if (!d.isEmpty() && d.peekFirst() <= i - k)
      d.pollFirst();        // pencere dışı
    while (!d.isEmpty() && a[d.peekLast()] <= a[i])
      d.pollLast();         // aday değil
    d.offerLast(i);
    if (i >= k - 1) enb[i - k + 1] = a[d.peekFirst()];
  }
  return enb;
}

Uygulama: Round Robin Zamanlayıcı

İşletim sistemi CPU'yu süreçler arasında sırayla paylaştırır: kuyruğun önündeki süreç en fazla q birim çalışır, bitmediyse kuyruğun arkasına döner.

Üç süreç hazır kuyruğunda; kalan süreleri 5, 3, 2 birim. Zaman dilimi (quantum) q = 2.

P1 önden alınır (dequeue), 2 birim çalışır, kalan 3 ile arkaya eklenir (enqueue).

P2 2 birim çalışır, kalan 1 ile arkaya döner.

P3'ün 2 birimi bir dilime sığar → t = 6'da biter, kuyruğa dönmez.

P1 yine 2 birim çalışır; kalan 1.

P2'nin kalan 1 birimi biter (t = 9); dilimin tamamı kullanılmaz.

Tümü bitti. Tamamlanma zamanları: P3 = 6, P2 = 9, P1 = 10.

Simülatör: Round Robin Scheduler (quantum ve süreçleri kendiniz belirleyin).

void roundRobin(Queue<Surec> q, int dilim) {
  int t = 0;
  while (!q.isEmpty()) {
    Surec p = q.poll();
    int calis = Math.min(dilim, p.kalan);
    t += calis;
    p.kalan -= calis;
    if (p.kalan > 0) q.offer(p);
    else System.out.println(p.ad + " t=" + t);
  }
}

i = 2: q.offer(q.poll()) → E önden alınıp arkaya eklenir.

i = 1: q.offer(q.poll()) → B önden alınıp arkaya eklenir.

String josephus(Queue<String> q, int k) {
  while (q.size() > 1) {
    for (int i = 1; i < k; i++)
      q.offer(q.poll());      // öndekini arkaya
    String elenen = q.poll();
    System.out.println(elenen + " elendi");
  }
  return q.poll();
}

Uygulama: Öncelikli Zamanlayıcı

Kesin öncelikCPU her zaman en yüksek öncelikli, boş olmayan kuyruğun önündeki süreci seçer.

Örnek: 1'den n'e Kadar İkilik Sayılar

Kuyruk kullanarak 1'den n'e kadar sayıların ikilik (binary) gösterimlerini üretin.

Örnek 1n = 3 → {"1", "10", "11"}
Örnek 2n = 5 → {"1", "10", "11", "100", "101"}
Fikir: x'in iki ardılı x + "0" (2x) ve x + "1" (2x + 1)'dir. Kuyruktan bir sayı alıp sonuca yazar, bu iki sayıyı arkaya eklersek sayılar seviye seviye, yani artan sırada üretilir (genişlik öncelikli gezinme).

String[] ikilikSayiUret(int n) {
    String[] sonuc = new String[n];
    Queue<String> q = new LinkedList<>();
    q.offer("1");
    for (int i = 0; i < n; i++) {
        sonuc[i] = q.poll();
        q.offer(sonuc[i] + "0");
        q.offer(sonuc[i] + "1");
    }
    return sonuc;
}

enqueue(4): gelen.push(4) → O(1).

dequeue: giden boş değil → aktarım yok.

giden.pop() → 2 (FIFO: ilk eklenenlerden).

dequeue: giden boş değil → aktarım yok.

giden.pop() → 3 (FIFO: ilk eklenenlerden).

dequeue: giden boş → gelen'deki her şey giden'e aktarılacak.

4: gelen'den pop, giden'e push. Aktarım sırayı ters çevirir; en eski öğe üste çıkar.

giden.pop() → 4. Çıkış 1, 2, 3, 4 = giriş sırası. Her öğe en çok bir kez aktarılır → dequeue amortize O(1) (tek çağrı en kötü O(n)).

Deque<Integer> gelen = new ArrayDeque<>();
Deque<Integer> giden = new ArrayDeque<>();
void enqueue(int x) {
  gelen.push(x);
}
int dequeue() {
  if (giden.isEmpty())
    while (!gelen.isEmpty())
      giden.push(gelen.pop());
  return giden.pop();
}

Örnek Problemler

  1. Boş kuyrukta: enqueue(4), enqueue(7), dequeue(), enqueue(1), enqueue(9), dequeue(). first() nedir, kuyrukta ne kalır?
  2. N = 6, front = 4, size = 3: öğeler hangi indislerde, sonraki enqueue nereye yazılır?
  3. “Bir yuva boş” yönteminde N = 10 ise en fazla kaç öğe saklanır? Dolu koşulu nedir?
  4. dequeue'dan if (front == null) rear = null; silinirse ne olur?
  5. İki yığınla kuyruk nasıl yapılır? dequeue'nun amortize maliyeti nedir?
  6. Deque ile bir kelimenin palindrom olduğu nasıl kontrol edilir?
Cevapları göster
  1. first() = 1; kuyruk (önden arkaya): 1, 9.
  2. İndis 4, 5, 0. Sonraki yazma: (4 + 3) % 6 = 1.
  3. 9 öğe; dolu: (arka + 1) % 10 == front.
  4. Boş kuyrukta rear eski düğümü gösterir: rear() yanlış değer döndürür, düğüm bellekten atılamaz (tutarsız durum).
  5. Ekle: gelen'e push. Çıkar: giden boşsa gelen'i giden'e aktar, giden'den pop. Her öğe en çok bir kez aktarılır → amortize O(1).
  6. Harfleri deque'ye ekle; iki uçtan birer harf çıkarıp karşılaştır. O(n).

Alıştırmalar

  1. Bir kuyruğu yalnızca kuyruk işlemleri ve bir yığınla ters çevirin.
  2. Tek bir kuyrukla yığın yapın: push'u nasıl yazarsınız, maliyeti nedir?
  3. Josephus: 1..7 numaralı kişiler, k = 3. Eleme sırası ve kazanan?
  4. N = 5, bas = 3, boyut = 5 olan dairesel kuyruk büyütülünce yeni dizide öğeler hangi sırada olur?
  5. Bir kuyruğun ilk k öğesini, kalanların sırasını bozmadan ters çevirin.
  6. Kayan pencere en küçüğü için deque algoritmasında ne değişir?
İpuçları / cevaplar
  1. Hepsini dequeue edip yığına push, sonra pop edip enqueue → O(n).
  2. push(x): enqueue(x), sonra önceki size − 1 öğeyi dequeue+enqueue ile arkaya at → push O(n), pop O(1).
  3. Elenenler 3, 6, 2, 7, 5, 1; kazanan 4.
  4. dizi[3], dizi[4], dizi[0], dizi[1], dizi[2] → yeni[0..4]; bas = 0.
  5. İlk k'yı yığına al, geri enqueue et, sonra kalan n − k öğeyi döndür.
  6. Karşılaştırma tersine döner: a[d.peekLast()] >= a[i] olanlar atılır.
