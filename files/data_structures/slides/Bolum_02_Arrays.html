Array Simulator

Arrays store values in indexed positions. In the classical fixed-size model, elements occupy contiguous memory locations, making indexed access constant time while insertions and deletions may require shifting.

Array concepts

Indexed access

An index maps directly to a position, so reading or replacing array[i] is O(1).

Insertion and deletion

When order matters, elements after the target position may need to shift. Worst-case cost is O(n).

Traversal and search

A full traversal touches every element. Linear search checks positions one by one until a match is found.

Bubble Sort

Adjacent out-of-order values are swapped repeatedly. Its simple mechanics make it useful for visualization, not performance.
