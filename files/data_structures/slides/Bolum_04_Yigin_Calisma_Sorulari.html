Soru 1: push/pop Çıktısı

Aşağıdaki kod parçasının çıktısı nedir?

Deque<Integer> y = new ArrayDeque<>();
y.push(4); y.push(9); y.push(2);
System.out.print(y.pop() + " ");
y.push(7);
System.out.print(y.peek() + " ");
System.out.print(y.pop() + y.pop() + " ");
y.push(5);
System.out.print(y.size() + " " + y.peek());
Cevabı göster

Çıktı: 2 7 16 2 5

  • 4, 9, 2 eklenir; üstte 2 → pop() 2 döndürür (LIFO). Yığın (alt→üst): 4 9.
  • 7 eklenir; peek() 7'yi çıkarmadan döndürür.
  • y.pop() + y.pop() önce tam sayı toplamıdır: 7 + 9 = 16. Yığın: 4.
  • 5 eklenir: yığın 4 5 → size() 2, peek() 5.

Soru 2: Olası Çıkış Sıraları

1, 2, 3, 4 sayıları bu sırayla yığına push ediliyor; aralara istenen anda pop() serpiştirilebiliyor. Pop edilen değerlerin sırası aşağıdakilerden hangisi olamaz?

C: 4 ilk çıkıyorsa 1, 2, 3 hâlâ yığındadır ve üstte 3 vardır; sıradaki pop 3 olmak zorundadır, 2 olamaz. A ise mümkündür: push 1, 2, 3 → pop 3, pop 2 → push 4, pop 4 → pop 1.

Soru 5: Dizi Yığında top ve size

Kapasitesi kap olan dizi tabanlı yığında top üstteki öğenin indisidir ve boş yığında top = −1'dir. "Dolu" koşulu ve size() hangisidir?

B: Son geçerli indis kap − 1'dir; indisler 0'dan başladığı için öğe sayısı top + 1'dir. A en sık yapılan top/size karışıklığıdır: top == kap olduğunda veri[top] zaten dizinin dışındadır.

Soru 6: Yalnızca ADT ile Arama

Yalnızca push, pop ve isEmpty kullanarak, x yığında varsa true döndüren ve yığını işlem sonunda eski hâline getiren icerir(y, x) metodunu yazın. Zaman ve ek bellek karmaşıklığı nedir?

Cevabı göster 
boolean icerir(Deque<Integer> y, int x) {
  Deque<Integer> yard = new ArrayDeque<>();
  boolean bulundu = false;
  while (!y.isEmpty()) {
    int v = y.pop();
    yard.push(v);
    if (v == x) { bulundu = true; break; }
  }
  while (!yard.isEmpty())   // geri taşı
    y.push(yard.pop());
  return bulundu;
}

Yalnızca üste erişilebildiği için öğeler tek tek çıkarılmalıdır: en kötü durumda O(n) zaman ve yardımcı yığın için O(n) ek bellek. Yardımcı yığından geri taşıma sırayı korur (iki kez ters çevirme).

Soru 8: Çıkarılan Hücre

Nesne tutan dizi tabanlı yığının bu pop() metodu doğru değeri döndürür ama bir kusuru vardır. Kusur nedir ve nasıl düzeltilir?

public E pop() {
  if (isEmpty())
    throw new RuntimeException("boş");
  return veri[top--];
}
Cevabı göster

Çıkarılan öğenin referansı veri[top+1] hücresinde kalır. Yığın o nesneyi artık kullanmasa da dizi onu gösterdiği için çöp toplayıcı nesneyi temizleyemez (bellek sızıntısı, loitering).

public E pop() {
  if (isEmpty())
    throw new RuntimeException("boş");
  E x = veri[top];
  veri[top--] = null; // bırak
  return x;
}

İşlem yine O(1)'dir. İlkel tür (int[]) tutan yığında bu sorun yoktur.

Soru 10: İki Katına Büyütme Maliyeti

Kapasitesi 1 olan ve dolunca kapasitesini iki katına çıkaran (eski öğeleri yeni diziye kopyalayan) boş bir yığına 9 kez push yapılıyor. Toplam kaç kopyalama ve kaç yazma yapılır, son kapasite kaçtır ve bu sonuç push'un amortize maliyeti hakkında ne söyler?

Cevabı göster
push no.123456–89
büyütme—1→22→4—4→8—8→16
kopya0120408

Kopya: 1 + 2 + 4 + 8 = 15, yazma: 9, toplam 24; son kapasite 16.

24 < 3n = 27: n push'ta kopyalar 2 + 4 + 8 + … < 2n olduğundan toplam < 3n'dir; push başına ortalama < 3 → amortize O(1). Yine de büyütme yapan tek bir push (9. push) O(n) sürer; amortize sınır uzun bir işlem dizisinin ortalamasıdır.

Soru 11: Sabit Miktarda Büyütme

Dinamik dizi yığını, dolduğunda kapasitesini iki katına çıkarmak yerine 10 hücre artırıyor (10 → 20 → 30 → …). Boş yığına n push yapıldığında toplam maliyet ve push başına ortalama maliyet nedir?

C: Kopyalar 10 + 20 + 30 + … + n ≈ n²/20 → O(n²); n push'a bölünce push başına O(n). A yalnızca kapasite oranla (ör. ×2) büyütülünce doğrudur: o zaman kopyalar geometrik dizi oluşturur ve toplam < 3n kalır.

Soru 12: Küçültme Kuralı

Bir dinamik yığın dolunca iki katına büyüyor, öğe sayısı kapasitenin yarısına inince yarıya küçülüyor. Yığın kapasite 4, öğe sayısı 4 iken sırayla push, pop, push, pop, … yapılırsa her işlemin maliyeti ne olur; doğru küçültme kuralı nedir ve neden?

Cevabı göster
  • push: dizi dolu → kapasite 8, 4 kopya (5 öğe / 8).
  • pop: 4 öğe = 8'in yarısı → kapasite 4, 4 kopya (4 öğe / 4, yine dolu).
  • Sonraki push yine büyütür, pop yine küçültür… Her işlem ~n kopya yapar: her işlem O(n), amortize O(1) bozulur (salınım, thrashing).

Doğru kural: öğe sayısı kapasitenin dörtte birine inince yarıya küçült. Büyütmeden sonra dizi yarı doludur; küçültmeden sonra da yarı doludur. Bir sonraki büyütme ya da küçültmeye kadar en az ~n/4 ucuz işlem yapılması gerekir, böylece kopya maliyeti bu işlemlere yayılır ve push/pop amortize O(1) kalır.

Soru 13: Hatalı Bağlı Liste push

Bağlı liste tabanlı yığının push metodunda iki satırın yeri değişmiş. Boş yığına push(10) ve push(15) yapılıp ardından pop() iki kez çağrılırsa ne olur? Hatayı düzeltin.

public void push(int veri) {
  Dugum gecici = new Dugum(veri);
  top = gecici;
  gecici.sonraki = top;
  uzunluk++;
}
Cevabı göster

top = gecici önce çalıştığı için gecici.sonraki = top düğümü kendisine bağlar. Eski liste (10) hiçbir referansla tutulmaz, kaybolur.

push(15) sonrası: top → [15] → [15] → … (kendine döngü). İlk pop 15 döndürür, top = top.sonraki yine aynı düğümü gösterir; ikinci pop da 15 döndürür. 10'a hiç ulaşılamaz; uzunluk ise 0'a iner ve listeyle tutarsız kalır.

Düzeltme: önce bağla, sonra üstü taşı:

gecici.sonraki = top; // önce bağla
top = gecici;         // yeni üst

Soru 14: Neden Listenin Başı?

Tek yönlü bağlı liste ile gerçekleştirilen yığında push ve pop neden listenin başında yapılır?

B: Baş referansı (top) elimizdedir; başa ekleme ve baştan silme kaydırma ya da tarama gerektirmez. Sona kuyruk referansıyla O(1) eklenebilir ama silmede yeni sonu bulmak için listeyi baştan dolaşmak gerekir. A yanlıştır: bağlı liste düğümleri bellekte ardışık değildir.

Soru 16: Tek Dizide İki Yığın

Kapasitesi N olan tek bir dizide iki yığını, dizi tamamen dolmadıkça hiçbiri taşmayacak biçimde nasıl gerçekleştirirsiniz? İki yığının push/pop işlemlerini, başlangıç değerlerini ve taşma koşulunu açıklayın; diziyi ikiye bölmekle karşılaştırın.

Örnek cevap ve değerlendirme ölçütleri

Birinci yığın dizinin başından sağa, ikinci yığın sonundan sola büyür. Başlangıçta top1 = −1, top2 = N.

  • push1(x): veri[++top1] = x · pop1: veri[top1--]; boş: top1 == −1.
  • push2(x): veri[--top2] = x · pop2: veri[top2++]; boş: top2 == N.
  • Taşma (her iki push için): top1 + 1 == top2, yani boş hücre kalmamıştır.

Tüm işlemler O(1). Diziyi N/2'şerlik iki parçaya bölmek, bir yığın boşken diğerinin N/2'de taşmasına yol açar; ortadan karşılıklı büyüme boş alanı paylaştırır.

Değerlendirme: karşılıklı büyüme fikri · doğru başlangıç değerleri · doğru taşma koşulu (top1 + 1 == top2) · boş koşulları · O(1) ve bölmeye göre avantaj.

Soru 18: Sınırlı Geri Al / Yinele

Bir metin düzenleyicide geri al (undo) ve yinele (redo) özelliğini yalnızca son 100 işlemi saklayacak biçimde tasarlayın. Hangi yapıları kullanırsınız, undo/redo ve yeni düzenleme sırasında ne olur, 101. işlem geldiğinde ne yaparsınız?

Örnek cevap ve değerlendirme ölçütleri

İki yığın: geri ve ileri. Her kayıt, yapılan işlemi ve nasıl tersine çevrileceğini tutar.

  • Düzenleme: kayıt geri'ye push; ileri temizlenir (eski yinele geçmişi artık geçersizdir).
  • Undo: geri.pop(), ters işlem uygulanır, kayıt ileri'ye push. Redo: tersi.
  • Sınır: 100 dolunca en eski kayıt atılmalıdır; saf yığın yalnızca üste eriştiği için iki uçlu yapı (ArrayDeque: üstten push/pop, alttan removeLast) ya da dairesel dizi kullanılır.

Tüm işlemler O(1); bellek O(100).

Değerlendirme: iki yığın modeli · kaydın içeriği (ters işlem) · yeni düzenlemede redo'nun temizlenmesi · sınır için deque/dairesel dizi · karmaşıklık.

Soru 19: Çağrı Yığını

f(472) çağrıldığında çağrı yığını en derin anında hangi çerçeveleri (üstten alta) içerir ve f(472) hangi değeri döndürür?

int f(int n) {
  if (n == 0)
    return 0;
  return n % 10 + f(n / 10);
}
// main içinde:
System.out.println(f(472));
Cevabı göster

En derin an (üstten alta): f(0) · f(4) · f(47) · f(472) · main. Her çağrı yeni bir çerçeve push eder; f(472), f(47) ve f(4) toplama yapabilmek için alt çağrının bitmesini askıda bekler.

Taban durumdan sonra yığın çözülür (unwinding):

  • f(0) = 0 → f(4) = 4 + 0 = 4
  • f(47) = 7 + 4 = 11 → f(472) = 2 + 11 = 13 (basamak toplamı)

Derinlik basamak sayısı kadardır → O(basamak) bellek. Taban durum (n == 0) silinseydi çerçeveler sonsuza dek birikir ve StackOverflowError oluşurdu.

Soru 20: Yığınla Palindrom

Bir dizenin palindrom olup olmadığını (ör. "kayak" evet, "kayık" hayır) bir karakter yığını kullanarak kontrol eden boolean palindrom(String s) metodunu yazın. Zaman ve ek bellek karmaşıklığı nedir?

Cevabı göster 
boolean palindrom(String s) {
  Deque<Character> y = new ArrayDeque<>();
  for (char c : s.toCharArray())
    y.push(c);
  for (int i = 0; i < s.length(); i++)
    if (s.charAt(i) != y.pop())
      return false;
  return true;
}

Fikir, dize ters çevirme ile aynıdır: karakterler sırayla push edilir, pop'lar ters sırayla çıkar. Ters dize baştan sona orijinalle karşılaştırılır.

Zaman O(n), ek bellek O(n) (yığın). İyileştirme: yalnızca ilk yarıyı push edip ikinci yarıyla karşılaştırmak yetişir; karmaşıklık yine O(n) olur.

Soru 25: getMin O(1) Olan Yığın

Sırayla push(4), push(6), push(2), push(2), pop(), getMin(), pop(), getMin() yapılıyor. İki getMin() çağrısı ne döndürür ve en sonda min yığınında ne kalır?

void push(int x) {
  y.push(x);
  if (min.isEmpty() || x <= min.peek())
    min.push(x);
}
int pop() {
  int x = y.pop();
  if (x == min.peek()) min.pop();
  return x;
}
int getMin() { return min.peek(); }
Cevabı göster
  • push'lardan sonra y (alt→üst): 4 6 2 2; min: 4 2 2 (6 > 4 olduğu için eklenmez; ikinci 2, <= sayesinde eklenir).

Soru 26: Hanoi Hamleleri

hanoi(4, 'A', 'B', 'C') çağrısı toplam kaç satır yazdırır ve yazdırılan 8. satır nedir? Gerekçesini özyinelemeli yapıdan çıkarın.

void hanoi(int n, char k, char y, char h) {
  if (n == 1) {
    System.out.println("1: " + k + "→" + h);
    return;
  }
  hanoi(n - 1, k, h, y);
  System.out.println(n + ": " + k + "→" + h);
  hanoi(n - 1, y, k, h);
}
Cevabı göster

T(n) = 2T(n−1) + 1, T(1) = 1 → T(n) = 2ⁿ − 1. T(4) = 15 satır.

Çağrı önce hanoi(3, A, C, B) ile üstteki 3 diski B'ye taşır: T(3) = 7 satır. Ardından en büyük disk taşınır; dolayısıyla 8. satır 4: A→C olur. Son 7 satır hanoi(3, B, A, C)'den gelir.

(n çift olduğu için ilk hamle 1: A→B'dir.) Zaman O(2ⁿ); çağrı yığınının derinliği en çok n (+ main) → bellek O(n).

Soru 28: Stock Span İzleme

span({30, 20, 25, 10, 15, 40}) hangi diziyi döndürür?

Önce kendiniz tahmin edin, sonra › ile ilerleyin.

İlk gün: indis 0 yığına, span 1. Yığında henüz aşılmamış günlerin indisleri tutulur.

20 ≥ fiyatlar[0] = 30? Hayır → span = 1 − 0 = 1; push(1).

25 ≥ fiyatlar[1] = 20 → pop(1). 1. gün artık kimsenin sınırı olamaz.

25 < 30 → durur. span = 2 − 0 = 2; push(2).

10 < 25 → span = 3 − 2 = 1; push(3).

15 ≥ fiyatlar[3] = 10 → pop(3).

15 < 25 → span = 4 − 2 = 2; push(4).

40 ≥ 15 → pop(4); 40 ≥ 25 → pop(2).

40 ≥ 30 → pop(0). Yığın boşaldı: 40 tüm önceki fiyatları aştı.

Yığın boş → span = i + 1 = 6; push(5).

Her indis bir kez push, en çok bir kez pop edilir → O(n).

int[] span(int[] fiyatlar) {
  int[] sicrama = new int[fiyatlar.length];
  Deque<Integer> yigin = new ArrayDeque<>();
  yigin.push(0); sicrama[0] = 1;
  for (int i = 1; i < fiyatlar.length; i++) {
    while (!yigin.isEmpty() &&
        fiyatlar[i] >= fiyatlar[yigin.peek()])
      yigin.pop();
    sicrama[i] = yigin.isEmpty() ? i + 1
               : i - yigin.peek();
    yigin.push(i);
  }
  return sicrama;
}
