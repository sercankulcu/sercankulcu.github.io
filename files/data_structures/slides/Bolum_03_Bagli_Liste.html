Liste türleri

Tek yönlü, çift yönlü ve dairesel listeleri karşılaştırmak.

Maliyet analizi

Bağlı liste işlemlerinin zaman ve alan maliyetlerini değerlendirmek.

Temeller

Bağlı Liste Türleri

Tek yönlü (singly)Her düğüm yalnızca sonrakini gösterir; son düğüm null.
Çift yönlü (doubly)Her düğüm hem öncekini hem sonrakini gösterir; iki yönde gezilir.
Dairesel (circular)Son düğüm null yerine ilk düğümü gösterir; liste bir halka olur.

Üçünde de öğeler, dizideki gibi yan yana hücrelerde değil, birbirini gösteren düğümlerde (node) saklanır.

Temeller

Tek Yönlü Bağlı Liste (Singly Linked List)

  • Elemanlar birbirine tek yönlü bağlantılarla bağlıdır: her eleman kendinden sonrakine bir referans içerir.
  • Liste, ilk elemanı gösteren baş (head, kodda bas) adında özel bir referansa sahiptir.
  • Her düğüm iki parçadan oluşur:
    • Veri: düğümün taşıdığı değer (ilkel tip ya da nesne).
    • İşaretçi (pointer): sonraki düğümün referansı; son düğümde null.

Temeller

Düğümler Bellekte Nasıl Durur?

  • Öğeler bellekte ardışık konumlarda tutulmaz; her düğüm new ile ayrı ayrı oluşturulur.
  • Yine de doğrusal bir veri yapısıdır: her düğümün (sonuncusu hariç) tek bir ardılı vardır.
  • Sırayı bellekteki konum değil, sonraki alanındaki referanslar belirler.

Liste sırası 10 → 1 → 8 → 11 olsa da düğümler bellekte başka sırada; oklar referansları izler.

Temeller

Düğüm (Node) Sınıfı

int veri 
// Düğüm sınıfı
class Dugum {
    int veri;
    Dugum sonraki;
    Dugum(int veri) {
        this.veri = veri;
        this.sonraki = null;
    }
}
Genel (generic) sürüm 
// Düğüm sınıfı
class Dugum<T> {
    T veri;
    Dugum<T> sonraki;
    Dugum(T veri) {
        this.veri = veri;
        this.sonraki = null;
    }
}
  • Sınıf kendi türünden bir alan (Dugum sonraki) içerir: öz-referanslı (self-referential) yapı.
  • Genel sürüm her tür veriyi saklar: Dugum<String> d = new Dugum<>("Ali");
  • Yeni düğümün sonraki alanı başlangıçta null'dır; listeye bağlanınca değişir.

Temeller

Tek Yönlü Bağlı Liste: Avantajlar ve Dezavantajlar

Avantajları

  • Kolay uygulanır.
  • Başa ekleme / baştan silme O(1); araya ekleme kaydırma gerektirmez.
  • Dinamik boyutludur: önceden kapasite ayırmaz, eleman sayısı serbestçe değişir.

Dezavantajları

  • Arama yavaştır: O(n).
  • Rastgele erişim yoktur; i. elemana ulaşmak için baştan gezmek gerekir.
  • Her düğüm fazladan bir referans taşır (ek bellek).
  • Geriye doğru gezilemez.
Araya ekleme/silme O(1) ancak konum (önceki düğüm) biliniyorsa geçerlidir; konumu bulmak için gezinme yine O(n) sürer.

Aynı Desen: Uzunluk ve Arama

O(n) 
int elemaniAra(int aranan) {
    Dugum gecici = bas;
    int konum = 0;
    while (gecici != null) {
        if (gecici.veri == aranan)
            return konum;
        konum++;
        gecici = gecici.sonraki;
    }
    return -1;   // bulunamadı
}
Gezinme deseni: gecici = bas ile başla, gecici != null olduğu sürece işini yap ve gecici = gecici.sonraki ile ilerle. Uzunluk sık gerekiyorsa listede bir boyut alanı tutulup her ekleme/silmede güncellenerek O(1)'e indirilir.

Son (Tail) İşaretçisi ile Sona Ekleme — O(1)

class TekYonluBagliListe {
    Dugum bas, son;   // baş ve son
    void sonaEkle(int veri) {
        Dugum yeniDugum = new Dugum(veri);
        if (bas == null) {
            bas = son = yeniDugum;
        } else {
            son.sonraki = yeniDugum;
            son = yeniDugum;
        }
    }
}
Gezinme yok: O(1)Son düğüm doğrudan bilinir; iki atama yeter.

Belirli Bir Konuma Düğüm Ekleme

void konumaEkle(int veri, int indis) {   // indis 0'dan başlar
    if (indis == 0) { basaEkle(veri); return; }
    Dugum gecici = bas;
    for (int i = 0; i < indis - 1 && gecici != null; i++)
        gecici = gecici.sonraki;
    if (gecici == null) {          // liste indis'ten kısa
        System.out.println("Belirtilen konum bulunamadı.");
        return;
    }
    Dugum yeniDugum = new Dugum(veri);
    yeniDugum.sonraki = gecici.sonraki;   // (1)
    gecici.sonraki = yeniDugum;           // (2)
}
indis 0Başa ekleme ile aynıdır; ayrıca ele alınır.
Sıra önemliÖnce (1), sonra (2); tersi listenin kalanını koparır.
MaliyetKonuma yürümek O(indis), en kötü O(n); bağlama O(1).

    Dugum[][] d = new Dugum[r][c];

void bastanSil() {
    if (son == null) return;
    Dugum bas = son.sonraki;
    if (bas == son)   // tek düğüm
        son = null;
    else
        son.sonraki = bas.sonraki;

}

Dairesel Listede Sondan Silme — O(n)

void sondanSil() {
    if (son == null) return;
    if (son.sonraki == son) son = null;   // tek düğüm
    else {
        Dugum gecici = son.sonraki;
        while (gecici.sonraki != son)     // sondan bir önceki
            gecici = gecici.sonraki;
        gecici.sonraki = son.sonraki;     // başa bağla
        son = gecici;
    }
    uzunluk--;
}

Sondan bir önceki düğümü bulmak için halkada dolaşmak gerekir: O(n). Çift yönlü dairesel listede son.onceki ile O(1) olur.

Örnek Problemler

  1. Tek yönlü listede sona eklemeyi O(1) yapmak için ne gerekir? Hangi işlem yine O(n) kalır?
  2. basaEkle'de iki satırın sırası değişirse (bas = yeniDugum; önce) ne olur?
  3. Bir listenin ortasını, uzunluğunu hesaplamadan tek geçişte nasıl bulursunuz?
  4. Tek yönlü listede bir döngü (son düğümün önceki bir düğüme bağlanması) olup olmadığını nasıl anlarsınız?
  5. Çift yönlü listede son düğümü silmenin maliyeti nedir? Tek yönlüde neden farklıdır?
  6. Dairesel listede neden bas yerine son tutulur?
Cevapları göster
  1. Bir son işaretçisi. Sondan silme O(n) kalır (öncekine geri gidilemez).
  2. Yeni düğüm kendini gösterir (yeniDugum.sonraki = yeniDugum); eski liste kaybolur.
  3. Yavaş (1 adım) ve hızlı (2 adım) işaretçi: hızlı sona varınca yavaş ortadadır.
  4. Aynı iki işaretçi (Floyd): hızlı olan null'a ulaşırsa döngü yok, yavaşa yetişirse döngü var.
  5. O(1): son = son.onceki. Tek yönlüde öncekine ulaşmak için baştan gezmek gerekir: O(n).
  6. Baş = son.sonraki; tek işaretçiyle hem başa hem sona O(1) erişim.
