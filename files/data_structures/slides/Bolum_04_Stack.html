    Stack Simulator

    A stack is a LIFO (last in, first out) structure: elements are added and removed only at the TOP.

    How to use

    • Push adds the value, Push Random adds a random one; Pop removes the top, Peek reads it.
    • The capacity is 7: pushing onto a full stack is an overflow, popping an empty one an underflow.
    • Fill Random fills the stack; Search scans from the top down; Clear empties it; Cancel stops an animation.
    • The right panel lists the most recent operations.

    Costs

    OperationTime

    Typical uses: function calls, undo, bracket matching, expression conversion and evaluation.
