Stack Simulator

A stack is a Last-In, First-Out (LIFO) data structure. Elements are inserted and removed only from the top. The most recently pushed element is therefore the first element to be popped.

    Stack concepts

    LIFO discipline

    The last element inserted is the first one removed. Only the top is directly accessible.

    Constant-time top operations

    Push, pop, and peek only affect the top position, so each takes O(1).

    Searching

    A search may inspect every element from the top downward, giving O(n) worst-case time.

    Common uses

    Stacks are used for function calls, undo/redo, expression evaluation, and depth-first search.
