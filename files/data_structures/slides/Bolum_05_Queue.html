Queue Simulator

A queue is a First-In, First-Out (FIFO) data structure. New elements enter at the rear, while existing elements leave from the front. The element that has waited the longest is therefore removed first.

    Queue concepts

    FIFO discipline

    The first element inserted is the first one removed. Insertion and removal happen at opposite ends.

    Front and rear

    The front identifies the next element to leave, while the rear identifies the most recently inserted element.

    Searching

    A search may inspect every queue element from front to rear, giving O(n) worst-case time.

    Common uses

    Queues are used in scheduling, buffering, breadth-first search, messaging, and request processing.
