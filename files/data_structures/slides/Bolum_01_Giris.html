Dijital Veri

Dijital Veri (Digital Data)

  • Sayı, metin, görüntü ve ses gibi bilgilerin elektronik ortamda 0 ve 1'lerle temsil edilmiş biçimidir.
  • Örnekler: Metin belgeleri, resim dosyaları, veritabanı, ses kayıtları.

Analog ses → ADC → 0 ve 1'ler → bilgisayar → DAC → analog ses

Dijital Veri

Dijital Verinin Özellikleri

Sayısal Olması

Veriler 0 ve 1 (ikili) olarak temsil edilir.

1011 0010
Kolay Saklama

Elektronik ortamda saklanabilir ve kolayca paylaşılabilir.

disk · bulut · ağ
İşlemeye Uygun

Bilgisayarlar üzerinde hızlı bir şekilde işlenebilir.

~10⁹ işlem / saniye
Bilgisayar yalnızca 0 ve 1'leri tanır. Veri yapıları, bu bitleri anlamlı ve verimli bir düzende tutmanın yollarıdır.

Java'da Bellek: Yığın ve Heap

  • İlkel değişken değeri doğrudan tutar.
  • Referans değişken, heap'teki nesnenin adresini tutar; new nesneyi heap'te oluşturur.
  • Her metot çağrısı yığında bir çerçeve açar; yerel değişkenler oradadır, dönüşte silinir.
  • Erişilemeyen nesneleri çöp toplayıcı temizler; p[0] → NullPointerException.
int x = 5;               // ilkel: değer
int[] a = {7, 2, 9};     // referans → dizi
String s = "veri";       // referans → nesne
int[] p = null;          // hiçbir şeyi göstermez

Veri Yapılarına Giriş · Kodu adım adım çalıştır

Kod İzleme: Değer mi, Referans mı?

x = 5: ilkel değişken, değer doğrudan çerçevededir.

y = x: değerin kopyası alınır; x ile y birbirinden bağımsızdır.

y = 7: yalnız y değişti; x hâlâ 5.

Dizi heap'te oluşturulur; a yalnızca ona bir referans (ok) tutar.

b = a: dizi kopyalanmaz, referans kopyalanır. İki ok aynı nesneyi gösterir.

b[0] = 9: nesnenin kendisi değişti → a[0] de 9 görünür (takma ad, aliasing).

b = new int[2]: b artık yeni nesneyi gösterir; a etkilenmez. Yeni dizi 0 ile dolar.

Çıktı 5 9. Kural: = ilkel tipte değeri, referans tipte adresi kopyalar.

int x = 5;
int y = x;
y = 7;
int[] a = {1, 2, 3};
int[] b = a;
b[0] = 9;
b = new int[2];
System.out.println(x + " " + a[0]);

Jenerikler: Her Tür İçin Tek Yapı

public class Kutu<T> {
  private T icerik;
  public void koy(T x) { icerik = x; }
  public T al() { return icerik; }
}

Kutu<String> k = new Kutu<>();
k.koy("veri");
String s = k.al();      // dönüşüm gerekmez
Kutu<Integer> m = new Kutu<>();
m.koy(42);              // int → Integer
// m.koy("x");          // DERLEME HATASI
  • Tür denetimi derleme zamanında; yanlış tür çalışmadan yakalanır.
  • T yalnız referans tipi olabilir: Kutu<int> yok, Integer kullanılır.
  • Java koleksiyonları jeneriktir: ArrayList<E>, Map<K,V>.

ADT'den Java'ya: Arayüz (interface)

public interface Yigin<E> {
  int size();         // öğe sayısı
  boolean isEmpty();  // boş mu?
  void push(E e);     // üste ekle
  E top();            // üsttekini döndür
  E pop();            // üsttekini çıkar
}
  • interface = ADT'nin sözleşmesi: ne yapılır.
  • class = veri yapısı: nasıl yapılır.
  • Aynı ADT'nin birden çok gerçeklemesi olabilir.
Yigin<Integer> y = new DiziYigin<>(10); — gerçeklemeyi değiştirmek için yalnız bu satır değişir; istemci kodu aynı kalır.

Bir Gerçekleme: DiziYigin

public class DiziYigin<E> implements Yigin<E> {
  private E[] veri;         // öğeler
  private int t = -1;       // üst öğenin indisi
  public DiziYigin(int kapasite) {
    veri = (E[]) new Object[kapasite];
  }
  public int size() { return t + 1; }
  public boolean isEmpty() { return t == -1; }
  public E top() {
    if (isEmpty()) return null;
    return veri[t];
  }
  // push ve pop
}
İşlemSüre
size, isEmpty, topO(1)
push, popO(1)
BellekO(N) (kapasite)
  • Java'da jenerik dizi doğrudan oluşturulamaz: (E[]) new Object[..].
  • Kapasite sabit: dolunca push hata fırlatır.

Veri Yapılarına Giriş · Kodu adım adım çalıştır

Kod İzleme: push / pop

y, kapasitesi 4 olan boş bir DiziYigin (t = −1). push(5) çağrılır.

size() = 0 ≠ 4 → dolu değil.

++t → t = 0, sonra veri[0] = 5. Önce artır, sonra yaz.

push(8) çağrılır.

size() = 1 ≠ 4 → dolu değil.

++t → t = 1, sonra veri[1] = 8. Önce artır, sonra yaz.

pop() çağrılır; dönen değer yazdırılacak.

t = 1 → boş değil, devam.

e = veri[1] = 8: en son eklenen öğe (LIFO).

Hücre null yapılır (nesne serbest kalsın), t-- → t = 0.

return 8: çerçeve kapanır.

Ekrana 8 yazılır.

push(3): boşalan 1 numaralı hücre yeniden kullanılacak.

size() = 1 ≠ 4 → dolu değil.

++t → t = 1, sonra veri[1] = 3. Önce artır, sonra yaz.

Son durum: [5, 3], t = 1. Her işlem n'den bağımsız, sabit sayıda adım → O(1).

public void push(E e) {
  if (size() == veri.length)
    throw new IllegalStateException("dolu");
  veri[++t] = e;
}
public E pop() {
  if (isEmpty()) return null;
  E e = veri[t];
  veri[t--] = null;     // GC için boşalt
  return e;
}
y.push(5); y.push(8);
System.out.println(y.pop());
y.push(3);

Örnek Problemler

  1. Metin editöründe "geri al" için hangi veri yapısı uygundur? Neden?
  2. Yazıcıya gelen belgeleri geliş sırasıyla basmak için hangi yapı uygundur?
  3. Öğrenci numarasıyla öğrenci bilgisine hızlı erişim için hangi yapı uygundur?
  4. İki nokta arasındaki en kısa yolu bulmak için şehir haritasını nasıl modellersiniz?
  5. Listedeki tekrar eden öğeleri ayıklamak için hangi yapıyı kullanırsınız?
  6. Yığın ADT'si Java'da arayüz olarak mı, sınıf olarak mı yazılır? DiziYigin hangisidir?
Cevapları göster
  1. Yığın (LIFO): son yapılan işlem ilk geri alınır.
  2. Kuyruk (FIFO).
  3. Eşleme / hash tablosu (anahtar: öğrenci no).
  4. Ağırlıklı çizge: düğümler kavşak, kenarlar yol, ağırlıklar mesafe.
  5. Küme (set).
  6. ADT, arayüzdür (Yigin<E>): ne yapılacağını söyler. DiziYigin onu gerçekleyen sınıftır, yani veri yapısıdır.

Özet

Alıştırmalar

  1. int[] a = {1, 2}; int[] b = a; b[1] = 7; sonrası a[1] kaçtır? Neden?
  2. Kutu<int> k; neden derlenmez? Yerine ne yazılır?
  3. 'B' karakteri ve 13 sayısı 8 bitle nasıl temsil edilir?
  4. String s = "veri"; String t = s; t = t + "!"; sonrası s nedir? Neden?
  5. Kapasitesi 3 olan boş DiziYigin'e push(1), push(2), pop(), push(3), push(4) uygulanıyor. Son durumda t ve dizi nedir?
  6. Müzik çalar: sıralı çalma listesi, "son çalınanlar" ve şarkı adına göre hızlı arama için hangi yapılar uygundur?
Cevaplar / ipuçları
  1. 7: b = a referansı kopyalar; iki değişken aynı diziyi gösterir.
  2. T yalnız referans tipi olabilir: Kutu<Integer> yazılır (otomatik kutulama).
  3. 'B' = 66 = 01000010; 13 = 00001101.
  4. "veri": String değiştirilemez; t + "!" yeni bir nesne oluşturur ve yalnız t onu gösterir.
  5. t = 2, dizi [1, 3, 4]: pop 2'yi döndürür, 3 onun yerine yazılır.
  6. Liste (çalma sırası), yığın (son çalınan en üstte), eşleme (ad → şarkı).
