Soru 1 · Yığın

Soru 1: Stack İşlemleri

Programın çıktısı nedir? (İpucu: Stack, Vector'dan türer.)

Önce kendiniz tahmin edin: çıktıyı kâğıda yazın, sonra › ile adım adım ilerleyin.

Boş yığın (Stack bir Vector'dır: iç dizi, üst = son indis).

push("A"): üste eklenir.

push("B"): üste eklenir.

push("C"): üste eklenir.

pop() → C: üstteki çıkar ve yazdırılır.

peek() → B: üsttekini gösterir, çıkarmaz.

remove("A"): Vector'dan gelen metot; dipteki A silinir → true. (LIFO kuralını deler!)

pop() → B; yığın boş.

add("D"): Vector/List metodu; sona (= üste) ekler → true.

remove("B"): B artık yok → false. Çıktı: C, B, true, B, true, false.

public static void main(String args[]) {
  Stack<String> stack = new Stack<>();
  stack.push("A");
  stack.push("B");
  stack.push("C");
  System.out.println(stack.pop());
  System.out.println(stack.peek());
  System.out.println(stack.remove("A"));
  System.out.println(stack.pop());
  System.out.println(stack.add("D"));
  System.out.println(stack.remove("B"));
}

Soru 5: ListIterator ile Özyineleme

Programın çıktısı nedir? fonksiyon genel olarak neyi hesaplar?

int fonksiyon(ListIterator<String> it) {
  if (it.hasNext()) {
    it.next();
    return 1 + fonksiyon(it);
  }
  return 0;
}
public static void main(String args[]) {
  List<String> list = new LinkedList<>();
  list.add("A"); list.add("B");
  list.add("C");
  ListIterator<String> it =
          list.listIterator();
  System.out.println(
      (new Ornek5()).fonksiyon(it));
}
Cevabı göster 
3
  • Her çağrı bir öğe atlar ve 1 ekler: 1 + (1 + (1 + 0)) = 3.
  • Genel olarak: iterator'ın önünde kalan öğe sayısını sayar. İterator paylaşıldığından, çağrı sonrası imleç sondadır; ikinci çağrı 0 döndürür.
  • fonksiyon statik olmadığından main onu bir Ornek5 nesnesi üzerinden çağırır.
  • Özyineleme derinliği n: çok uzun listede StackOverflowError riski.

Soru 5 · Çözüm

Soru 5: Adım Adım Çözüm

Önce kendiniz tahmin edin: çıktıyı kâğıda yazın, sonra › ile adım adım ilerleyin.

Liste [A, B, C].

Tek bir iterator oluşturulur; imleç başta. Aynı nesne tüm çağrılara geçirilecek.

fonksiyon(it) çağrılır.

#1: hasNext() → true (imleç 0 < 3).

next() → "A" atlanır; imleç 1. Paylaşılan iterator ilerledi.

1 + fonksiyon(it): sonucu beklemek üzere yeni çağrı (#2).

#2: hasNext() → true (imleç 1 < 3).

next() → "B" atlanır; imleç 2. Paylaşılan iterator ilerledi.

1 + fonksiyon(it): sonucu beklemek üzere yeni çağrı (#3).

#3: hasNext() → true (imleç 2 < 3).

next() → "C" atlanır; imleç 3. Paylaşılan iterator ilerledi.

1 + fonksiyon(it): sonucu beklemek üzere yeni çağrı (#4).

#4: hasNext() → false (imleç sonda).

#4 return 0: özyinelemenin taban durumu.

#3: 1 + 0 = 1 döner.

#2: 1 + 1 = 2 döner.

#1: 1 + 2 = 3 döner.

Yazdırılır: 3 = imlecin önünde kalan öğe sayısı. Aynı it ile tekrar çağrılsa 0 dönerdi.

Soru 6 · Yığın

Soru 6: Yığın ve Mod Alma

Programın çıktısı nedir? Kod genel olarak ne yapar?

Önce kendiniz tahmin edin: çıktıyı kâğıda yazın, sonra › ile adım adım ilerleyin.

n = 12, yığın boş.

n = 12 > 0 → döngü sürer.

12 % 2 = 0 → push; n = 12 / 2 = 6.

n = 6 > 0 → döngü sürer.

6 % 2 = 0 → push; n = 6 / 2 = 3.

n = 3 > 0 → döngü sürer.

3 % 2 = 1 → push; n = 3 / 2 = 1.

n = 1 > 0 → döngü sürer.

1 % 2 = 1 → push; n = 1 / 2 = 0.

n = 0 → ilk döngü biter. Kalanlar alttan üste 0, 0, 1, 1 (en anlamsız bit dipte).

pop() → 1 yazdırılır (print: aynı satır).

pop() → 1 yazdırılır (print: aynı satır).

pop() → 0 yazdırılır (print: aynı satır).

pop() → 0 yazdırılır (print: aynı satır).

Yığın boş → biter. Çıktı 1100 = 12'nin ikili gösterimi: yığın, kalanların sırasını tersine çevirdi.

public static void main(String[] args) {
  Stack<Integer> stack =
          new Stack<Integer>();
  int n = 12;
  while (n > 0) {
    stack.push(n % 2);
    n /= 2;
  }
  while (!stack.isEmpty())
    System.out.print(stack.pop());
}

Soru 7 · Dinamik Dizi

Soru 7: Büyüyüp Küçülen Dizi

Bu sınıf, N öğeyi capacity boyutlu items dizisinde tutuyor. Doluluk oranı hangi aralıkta kalır? Kodda hata var mı?

private void shrinkStretch() {
  if (N < capacity / 4) {
    capacity /= 2;
    items = Arrays.copyOf(items, capacity);
  } else if (N > capacity / 2) {
    capacity *= 2;
    items = Arrays.copyOf(items, capacity);
  }
}
public void removeItem() {
  items[N--] = null;  shrinkStretch();
}
public void addItem(E e) {
  items[N++] = e;  shrinkStretch();
}
Cevabı göster
  • Yarıdan fazla dolunca kapasite ikiye katlanır, dörtte birin altına inince yarıya iner → doluluk yaklaşık ¼ ile ½ arasında kalır.
  • Kopyalama O(n) ama seyrek: addItem/removeItem amortize O(1).
  • Hata: items[N--] = null son öğeyi değil, ondan sonraki boş hücreyi siler; son öğe dizide kalır. Doğrusu items[--N] = null;
  • Boş dizide removeItem için kontrol yok (N negatif olur).

Soru 7 · Çözüm

Soru 7: Adım Adım Çözüm

Senaryo: capacity = 2, N = 0. addItem(a), addItem(b), addItem(c), removeItem(), removeItem(). Doluluk nasıl değişir, hata nerede?

items[N++] = a: yuva 0'e yazılır, N = 1.

N < capacity/4 → 1 < 0? hayır.

N > capacity/2 → 1 > 1? hayır.

items[N++] = b: yuva 1'e yazılır, N = 2.

N < capacity/4 → 2 < 0? hayır.

N > capacity/2 → 2 > 1? evet.

Kapasite ikiye katlanır: 2 → 4; dizi kopyalanır (O(n), seyrek).

items[N++] = c: yuva 2'e yazılır, N = 3.

N < capacity/4 → 3 < 1? hayır.

N > capacity/2 → 3 > 2? evet.

Kapasite ikiye katlanır: 4 → 8; dizi kopyalanır (O(n), seyrek).

items[N--] = null: N = 3 olduğundan items[3] (zaten boş) temizlenir; son öğe c (items[2]) dizide kalır! Doğrusu items[--N] = null.

N < capacity/4 → 2 < 2? hayır.

N > capacity/2 → 2 > 4? hayır.

Yine items[2] temizlenir (c ancak şimdi silindi); bu kez b N'nin ötesinde asılı kaldı.

N < capacity/4 → 1 < 2? evet.

Kapasite yarıya: 8 → 4; dizi kopyalanır. Doluluk ¼–½ arasında tutuluyor, ama N-- hatası artık öğeleri bırakmıyor.

private void shrinkStretch() {
  if (N < capacity / 4) {
    capacity /= 2;
    items = Arrays.copyOf(items, capacity);
  } else if (N > capacity / 2) {
    capacity *= 2;
    items = Arrays.copyOf(items, capacity);
  }
}
public void removeItem() {
  items[N--] = null;  shrinkStretch();
}
public void addItem(E e) {
  items[N++] = e;  shrinkStretch();
}

Soru 8 · Kuyruk

Soru 8: Kuyruktan Yığına, Yığından Kuyruğa

Programın çıktısı nedir? İşlemin sonunda kuyruğa ne olmuştur?

Önce kendiniz tahmin edin: çıktıyı kâğıda yazın, sonra › ile adım adım ilerleyin.

Boş yığın ve boş kuyruk.

q = [a, b, c, d]; ön a.

q.poll() → a (önden), s.push(a) (üste).

q.poll() → b (önden), s.push(b) (üste).

q.poll() → c (önden), s.push(c) (üste).

q.poll() → d (önden), s.push(d) (üste).

q boş → ilk döngü biter.

Stack'in toString'i dipten üste yazar: s: [a, b, c, d] --- q: [].

s.pop() → d (üstten), q.offer(d) (arkaya).

s.pop() → c (üstten), q.offer(c) (arkaya).

s.pop() → b (üstten), q.offer(b) (arkaya).

s.pop() → a (üstten), q.offer(a) (arkaya).

s boş → ikinci döngü biter.

s: [] --- q: [d, c, b, a]: yığından geçiş sırayı tersine çevirdi (kuyruğu ters çevirmenin klasik yolu).

Stack<String> s = new Stack<>();
Queue<String> q = new LinkedList<>();
q.offer("a"); q.offer("b");
q.offer("c"); q.offer("d");
while (!q.isEmpty())
    s.push(q.poll());
System.out.println("s: " + s
        + " --- q: " + q);
while (!s.isEmpty())
    q.offer(s.pop());
System.out.println("s: " + s
        + " --- q: " + q);

Soru 9 · Bağlı Liste

Soru 9: Bu Liste Nerede Biter?

Programın çıktısı nedir? fonksiyon neyi test eder?

public static void main(String[] args) {
  Node head = new Node(1);
  head.next = new Node(2);
  head.next.next = new Node(3);
  head.next.next.next = new Node(4);
  head.next.next.next.next = head;
  System.out.println(
      fonksiyon(head, head.next));
}
static int fonksiyon(Node head, Node curr) {
  if (head == null) return 1;
  if (curr == null) return 0;
  if (head == curr) return 1;
  return fonksiyon(head, curr.next);
}
Cevabı göster 
1
  • curr 2 → 3 → 4 → 1 diye ilerler; 1 = head olunca 1 döner.
  • Fonksiyon, listenin dairesel olup olmadığını (sondan head'e dönüp dönmediğini) test eder: null'a ulaşırsa 0.
  • Boş liste (head null) de 1 sayılıyor. Döngü head'e değil ortadaki bir düğüme dönüyorsa özyineleme hiç bitmez.

Soru 9 · Çözüm

Soru 9: Adım Adım Çözüm

Önce kendiniz tahmin edin: çıktıyı kâğıda yazın, sonra › ile adım adım ilerleyin.

Dört düğüm: 1 → 2 → 3 → 4.

4'ün next'i yeniden head'i gösterir: liste dairesel, null'a hiç ulaşılmaz.

head null değil, curr null değil, head ≠ curr (2).

curr.next ile yeniden çağrılır → curr = 3.

head null değil, curr null değil, head ≠ curr (3).

curr.next ile yeniden çağrılır → curr = 4.

head null değil, curr null değil, head ≠ curr (4).

curr.next ile yeniden çağrılır → curr = 1.

curr = düğüm 1 = head → return 1: başa dönüldü.

1 değeri dört çerçeve boyunca aynen geri döner.

Yazdırılır: 1. Fonksiyon listenin head'e dönen dairesel bir liste olup olmadığını test eder (null'a ulaşılsa 0).
