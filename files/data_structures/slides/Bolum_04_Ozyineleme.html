Giriş

Öğrenme Çıktıları

Özyinelemeli tasarım

Bir problemi taban durum ve özyinelemeli adımla tanımlayıp Java'da yazmak.

Çağrı yığını

Özyinelemeli bir metodu çerçeve çerçeve izleyip çıktısını ve dönüş değerini bulmak.

Özyineleme türleri

Doğrusal, ikili ve çoklu özyinelemeyi ve geri izlemeyi örnekleriyle ayırt etmek.

Maliyet

Yineleme bağıntısını yazıp çağrı ağacıyla zaman ve alan maliyetini bulmak; gerektiğinde döngüye çevirmek.

Özyineleme Nedir

Günlük Hayatta Özyineleme

Uzun bir kuyrukta kaçıncı sırada olduğunuzu öğrenmek istiyorsunuz ama yerinizden ayrılıp baştan sayamıyorsunuz.

Aynı soru, küçük kuyrukHerkes önündekine aynı soruyu sorar; soru her seferinde bir kişi kısa bir kuyruk için sorulur.
Taban durumEn öndeki kişi kimseye sormadan cevap verir: “1”. Sorular burada durur.
Geri dönüşCevap geri gelirken her kişi kendi payını ekler: 1, 2, 3, 4, 5.
Özyinelemeli bir metot da böyle çalışır: kendini daha küçük bir girdiyle çağırır, en küçük girdide cevabı doğrudan verir.

Özyineleme Nedir

Özyineleme (Recursion)

n! = 1 (n ≤ 1) · n! = n · (n − 1)! (n > 1)
  • Özyineleme: bir metodun kendini daha küçük bir girdiyle çağırması.
  • Taban durum (base case): özyinelemesiz, doğrudan çözülür. Olmazsa çağrılar bitmez → StackOverflowError.
  • Özyinelemeli adım: problemi küçültür ve taban duruma yaklaştırır; küçük problemin cevabından büyüğünkini kurar.
  • Her çağrı çağrı yığınında yeni bir çerçeve açar (kendi n'si).

Özyineleme Nedir

Özyinelemeli Düşünmek

  1. Taban durum: en küçük girdi hangisi ve cevabı ne? Burada özyineleme durur.
  2. Küçültme: problem, aynı türden daha küçük bir probleme nasıl indirgenir? (n − 1, n / 2, i + 1 …)
  3. Birleştirme: küçük problemin cevabından büyük problemin cevabı nasıl kurulur?

Küçük problemin doğru çözüldüğü kabul edilir ve yalnızca tek bir adım düşünülür. Taban durum doğruysa ve her adım doğruysa tüm zincir doğrudur (tümevarımdaki mantık).

void geriSay(int n) {
  if (n == 0) {     // taban durum
    System.out.println("Bitti");
    return;
  }
  System.out.println(n);
  geriSay(n - 1);   // özyinelemeli adım
}
geriSay(3);         // main içinde

geriSay(n): n'den 1'e kadar yaz, sonra “Bitti”.

Her özyinelemeli çağrı girdiyi taban duruma yaklaştırmalıdır; geriSay'de n her çağrıda 1 azalır ve 0'a ulaşır.

Özyineleme Nedir · Kodu adım adım çalıştır

Kod İzleme: geriSay(3)

main, geriSay(3)'ü çağırır. Yığına yeni bir çerçeve eklenecek.

n = 3 ≠ 0: taban durum değil. 3 yazılır, sonra geriSay(2) çağrılır; bu çerçeve bekler.

n = 2 ≠ 0: taban durum değil. 2 yazılır, sonra geriSay(1) çağrılır; bu çerçeve bekler.

n = 1 ≠ 0: taban durum değil. 1 yazılır, sonra geriSay(0) çağrılır; bu çerçeve bekler.

n = 0: taban durum. “Bitti” yazılır. Yığın en derinde: main + 4 çerçeve.

return: geriSay(0) biter, çerçevesi yığından çıkar.

geriSay(1), satır 7'deki çağrıdan döner. Yapılacak iş kalmadı → o da biter.

geriSay(2), satır 7'deki çağrıdan döner. Yapılacak iş kalmadı → o da biter.

geriSay(3), satır 7'deki çağrıdan döner. Yapılacak iş kalmadı → o da biter.

Tüm çerçeveler döndü. 4 çağrı yapıldı (n = 3, 2, 1, 0); çıktı: 3 2 1 Bitti.

void geriSay(int n) {

  System.out.println(n);

Özyineleme Nedir

İş Çağrıdan Önce mi, Sonra mı?

void geriSay2(int n) {
  if (n == 0) return;
  System.out.print(n + " ");
  geriSay2(n - 1);     // sonra çağrı
}

geriSay2(3) çıktısı: 3 2 1
Yazdırma çağrılar inerken yapılır.

void ileriSay(int n) {
  if (n == 0) return;
  ileriSay(n - 1);     // önce çağrı
  System.out.print(n + " ");
}

ileriSay(3) çıktısı: 1 2 3
Yazdırma çağrılar dönerken yapılır.

  • ileriSay(3), 3'ü yazmadan önce ileriSay(2)'nin bitmesini bekler; o da 2'yi yazmadan önce ileriSay(1)'i bekler.
  • İlk biten çağrı en son başlayandır (n = 0). Bu yüzden çağrıdan sonra yapılan işler ters sırayla yapılır: 1, 2, 3.
Çağrıdan sonra kalan iş, çerçeve yığında beklerken saklanır. Bu iş yığın çözülürken yapılır.

Çağrı Yığını

Çağrı Yığını ve Çerçeveler

  • Her metot çağrısı için bellekte bir çerçeve (frame) açılır: parametreler, yerel değişkenler ve dönüşte devam edilecek yer.
  • Çerçeveler çağrı yığınında tutulur: çağrı yapılınca üste eklenir (push), metot bitince üstten çıkar (pop). Son başlayan ilk biter: LIFO.
  • Yalnızca en üstteki çerçeve çalışır; alttakiler, üstlerindeki çağrının sonucunu bekler.
  • Özyinelemede aynı metodun birden çok çerçevesi aynı anda yığında bulunur; her birinin n'si ayrıdır.
Özyinelemeli bir metodun bellek maliyeti, yığında aynı anda bulunan çerçeve sayısıyla, yani en derin çağrı zinciriyle belirlenir.

Çağrı Yığını · Kodu adım adım çalıştır

Kod İzleme: faktoriyel(4) ve çağrı yığını

main, faktoriyel(4)'ü çağırır.

Yeni çerçeve: n = 4. 4 ≤ 1 mi? Hayır.

4 · faktoriyel(3): çarpım için önce faktoriyel(3) bitmeli; bu çerçeve bekler.

Yeni çerçeve: n = 3. 3 ≤ 1 mi? Hayır.

3 · faktoriyel(2): çarpım için önce faktoriyel(2) bitmeli; bu çerçeve bekler.

Yeni çerçeve: n = 2. 2 ≤ 1 mi? Hayır.

2 · faktoriyel(1): çarpım için önce faktoriyel(1) bitmeli; bu çerçeve bekler.

Yeni çerçeve: n = 1. 1 ≤ 1 mi? Evet.

Taban durum: return 1. Artık çağrı yok; değerler geri dönmeye başlar.

faktoriyel(1) = 1 döndü → 2 · 1 = 2, return 2.

faktoriyel(2) = 2 döndü → 3 · 2 = 6, return 6.

faktoriyel(3) = 6 döndü → 4 · 6 = 24, return 24.

Ekrana 24. 4 çağrı, yığın derinliği en fazla 4 + main → zaman ve bellek O(n).

int faktoriyel(int n) {
  if (n <= 1)
    return 1;               // taban durum
  return n * faktoriyel(n - 1);
}

// main içinde:
System.out.println(faktoriyel(4));

Çağrı Yığını

Yığın Taşması: StackOverflowError

long topla(int n) {        // 1 + 2 + … + n
  if (n == 0) return 0;
  return n + topla(n - 1);
}
// main içinde:
System.out.println(topla(10_000));   // 50005000
System.out.println(topla(1_000_000)); // hata
Exception in thread "main"
  java.lang.StackOverflowError
    at Ornek.topla(Ornek.java:3)
    at Ornek.topla(Ornek.java:3)
    …
  • Çağrı yığını sınırlı bir bellek alanıdır. Boyutu JVM'e ve işletim sistemine bağlıdır; -Xss seçeneğiyle değiştirilebilir.
  • Her çerçeve yer kaplar. Varsayılan ayarlarla derinlik genellikle birkaç bin ile birkaç on bin çağrıyla sınırlıdır.
  • topla(10_000) sığar; topla(1_000_000) taban duruma ulaşmadan yığını doldurur.
  • Aynı toplam bir döngüyle ya da n(n + 1)/2 formülüyle sorunsuz hesaplanır.

Çağrı Yığını

Taban Durumu Unutmak

Taban durum yok
int f(int n) {
  return n * f(n - 1);
}
n = 3, 2, 1, 0, −1, −2 … çağrılar hiç durmaz.
Taban duruma ulaşılamıyor
if (n == 1) return 1;
return n * f(n - 1);
f(0) → −1 → −2 …: n hiçbir zaman 1 olmaz. n <= 1 bu girdiyi de yakalar.
Problem küçülmüyor
if (n <= 1) return 1;
return n * f(n);
Aynı girdiyle tekrar çağrı: taban durum var ama ona hiç yaklaşılmıyor.
Üçünün sonucu da aynıdır: yığın dolar ve StackOverflowError oluşur. Her olası girdi (0 ve negatif değerler dahil) sonlu sayıda adımda bir taban duruma ulaşmalıdır.

Doğrusal Özyineleme

Doğrusal Özyineleme

  • Her çağrı en fazla bir özyinelemeli çağrı yapar; çağrılar dallanmayan bir zincir oluşturur.
  • n boyutlu problem, n − 1 (ya da n / 2) boyutlu tek bir probleme indirgenir.
  • Örnekler: faktoriyel, geriSay, dizinin toplamı, diziyi tersine çevirme, üs alma, bağlı listenin uzunluğu.
  • Dizinin toplamı: ilk n öğenin toplamı = ilk n − 1 öğenin toplamı + a[n − 1]. Taban durum: n = 0 (boş parça) → 0.
int toplam(int[] a, int n) {   // ilk n öğenin toplamı
  if (n == 0)
    return 0;                   // taban durum
  return toplam(a, n - 1) + a[n - 1];
}

Doğrusal Özyineleme · Kodu adım adım çalıştır

Kod İzleme: toplam(a, 4)

main, toplam(a, 4)'ü çağırır: dizinin ilk 4 öğesinin toplamı.

n = 4 ≠ 0 → önce toplam(a, 3) hesaplanmalı; a[3] = 2 toplamaya eklenmeyi bekler.

n = 3 ≠ 0 → önce toplam(a, 2) hesaplanmalı; a[2] = 6 toplamaya eklenmeyi bekler.

n = 2 ≠ 0 → önce toplam(a, 1) hesaplanmalı; a[1] = 3 toplamaya eklenmeyi bekler.

n = 1 ≠ 0 → önce toplam(a, 0) hesaplanmalı; a[0] = 4 toplamaya eklenmeyi bekler.

n = 0: taban durum → 0 döner. Yığın en derinde: main + 5 çerçeve.

toplam(a, 0) 0 döndürdü → 0 + a[0] = 0 + 4 = 4 döner.

toplam(a, 1) 4 döndürdü → 4 + a[1] = 4 + 3 = 7 döner.

toplam(a, 2) 7 döndürdü → 7 + a[2] = 7 + 6 = 13 döner.

toplam(a, 3) 13 döndürdü → 13 + a[3] = 13 + 2 = 15 döner.

Sonuç 15. 5 çağrı (n = 4, 3, 2, 1, 0): zaman O(n), en çok 5 çerçeve (+ main): bellek O(n).

int toplam(int[] a, int n) {   // ilk n öğenin toplamı
  if (n == 0)
    return 0;                   // taban durum
  return toplam(a, n - 1) + a[n - 1];
}
// main içinde:
int[] a = {4, 3, 6, 2};
System.out.println(toplam(a, 4));

Doğrusal Özyineleme

Diziyi Tersine Çevirme

  • Fikir: dizinin iki ucunu değiştir, aradaki parçayı aynı yöntemle tersine çevir.
  • Parça a[i..j] indisleriyle verilir; ilk çağrı ters(a, 0, n − 1).
  • Taban durum: i >= j, yani parçada 0 ya da 1 öğe kaldı; yapılacak iş yok.
  • Her çağrı parçayı 2 öğe kısaltır: n öğe için ⌊n/2⌋ değiştirme, ⌊n/2⌋ + 1 çağrı → O(n).
  • Dizi yerinde değişir; metot bir değer döndürmez (void).

Doğrusal Özyineleme · Kodu adım adım çalıştır

Kod İzleme: ters(a, 0, 5)

main, ters(a, 0, 5)'i çağırır.

i = 0 < j = 5 → a[0] ile a[5] değişir: dizi 6 7 4 9 1 2. Sonra ters(a, 1, 4) çağrılır.

i = 1 < j = 4 → a[1] ile a[4] değişir: dizi 6 1 4 9 7 2. Sonra ters(a, 2, 3) çağrılır.

i = 2 < j = 3 → a[2] ile a[3] değişir: dizi 6 1 9 4 7 2. Sonra ters(a, 3, 2) çağrılır.

i = 3 ≥ j = 2: taban durum, ortada çevrilecek öğe kalmadı. Yığında main + 4 çerçeve.

Çerçeveler sırayla döner; dönüşte yapılacak iş yok. Sonuç: 6 1 9 4 7 2. 3 değiştirme, 4 çağrı.

void ters(int[] a, int i, int j) {
  if (i >= j)
    return;                    // taban: 0 ya da 1 öğe
  int t = a[i]; a[i] = a[j]; a[j] = t;  // uçlar
  ters(a, i + 1, j - 1);       // içteki parça
}
// main içinde:
int[] a = {2, 7, 4, 9, 1, 6};
ters(a, 0, a.length - 1);

Doğrusal Özyineleme

Üs Alma: Yavaş ve Hızlı

Yavaş: xⁿ = x · xⁿ⁻¹, x⁰ = 1

long us(long x, int n) {
  if (n == 0) return 1;
  return x * us(x, n - 1);
}

Hızlı: üssü her adımda yarıya indir

xⁿ = (xn/2)²  (n çift)
xⁿ = x · (x(n−1)/2)²  (n tek)

2¹⁰ = (2⁵)²,  2⁵ = 2 · (2²)²,
2² = (2¹)²,  2¹ = 2 · (2⁰)²

Doğrusal Özyineleme · Kodu adım adım çalıştır

Kod İzleme: hizliUs(2, 10)

main, hizliUs(2, 10)'u çağırır: 2¹⁰.

n = 10 ≠ 0 → önce y = hizliUs(2, 5) hesaplanır (10 / 2 = 5).

n = 5 ≠ 0 → önce y = hizliUs(2, 2) hesaplanır (5 / 2 = 2).

n = 2 ≠ 0 → önce y = hizliUs(2, 1) hesaplanır (2 / 2 = 1).

n = 1 ≠ 0 → önce y = hizliUs(2, 0) hesaplanır (1 / 2 = 0).

n = 0: taban durum → 1 döner (2⁰ = 1).

y = 1 geldi. n = 1 tek → 2 · y · y = 2 · 1 · 1 = 2 döner.

y = 2 geldi. n = 2 çift → y · y = 2 · 2 = 4 döner.

y = 4 geldi. n = 5 tek → 2 · y · y = 2 · 4 · 4 = 32 döner.

y = 32 geldi. n = 10 çift → y · y = 32 · 32 = 1024 döner.

Sonuç 1024. Yalnızca 5 çağrı; yavaş us(2, 10) 11 çağrı yapardı.

long hizliUs(long x, int n) {
  if (n == 0) return 1;           // taban durum
  long y = hizliUs(x, n / 2);     // x^(n/2)
  if (n % 2 == 0) return y * y;   // n çift
  return x * y * y;               // n tek
}
// main içinde:
System.out.println(hizliUs(2, 10));

İkili Özyineleme

Fibonacci Sayıları

int fib(int n) {
  if (n <= 1) return n;    // taban durum
  return fib(n - 1) + fib(n - 2);
}
F(0) = 0, F(1) = 1
F(n) = F(n − 1) + F(n − 2)  (n ≥ 2)
  • İkili özyineleme: bir çağrı iki özyinelemeli çağrı yapar.
  • Çağrılar artık zincir değil, bir çağrı ağacı oluşturur: her düğüm bir çağrı, çocukları onun yaptığı çağrılar.
  • Tanım koda doğrudan dökülür; iki taban durum vardır: n = 0 ve n = 1.
  • Ağaçta aynı değer birden çok kez hesaplanır; maliyeti bu belirler.

İkili Özyineleme · Kodu adım adım çalıştır

Kod İzleme: fib(4) çağrı ağacı

main, fib(4)'ü çağırır.

fib(4): n > 1 → önce fib(3) çağrılır; fib(2) sırada bekler.

fib(3): n > 1 → önce fib(2) çağrılır; fib(1) sırada bekler.

fib(2): n > 1 → önce fib(1) çağrılır; fib(0) sırada bekler.

fib(1): taban durum → 1 döner.

İkinci terim: fib(0): taban durum → 0 döner.

fib(2) = fib(1) + fib(0) = 1 + 0 = 1 döner.

İkinci terim: fib(1): taban durum → 1 döner.

fib(3) = fib(2) + fib(1) = 1 + 1 = 2 döner.

fib(4) ikinci terim için fib(2)'yi çağırır: fib(2) ikinci kez hesaplanacak. Önce fib(1).

fib(1): taban durum → 1 döner.

İkinci terim: fib(0): taban durum → 0 döner.

fib(2) = fib(1) + fib(0) = 1 + 0 = 1 döner.

fib(4) = fib(3) + fib(2) = 2 + 1 = 3 döner.

fib(4) = 3. 9 çağrı: fib(2) iki kez, fib(1) üç kez, fib(0) iki kez hesaplandı.

int fib(int n) {
  if (n <= 1) return n;    // taban durum
  return fib(n - 1) + fib(n - 2);
}
// main içinde:
System.out.println(fib(4));

Özyinelemenin Maliyeti

int fib(int n) {
  if (n <= 1) return n;
  return fib(n - 1) + fib(n - 2);
}
  • faktoriyel: T(n) = T(n − 1) + c → n çağrı → O(n) zaman, O(n) yığın belleği.
  • fib: her çağrı iki çağrı yapar; aynı alt problemler tekrar tekrar çözülür.
  • fib(4) → 9 çağrı; turuncu f(2) iki kez hesaplanıyor. Çağrı sayısı üstel büyür (≈ 1,6ⁿ).
  • Çözüm: sonuçları sakla veya döngüyle hesapla → O(n).

long[] bellek = new long[91];   // 0: hesaplanmadı
long fibBellek(int n) {
  if (n <= 1) return n;
  if (bellek[n] != 0) return bellek[n];
  bellek[n] = fibBellek(n - 1) + fibBellek(n - 2);

long fibDongu(int n) {
  long a = 0, b = 1;              // F(0), F(1)
  for (int i = 0; i < n; i++) {
    long t = a + b;  a = b;  b = t;
  }
  return a;
}
Hesaplanan değerler bir dizide saklanırsa her değer bir kez hesaplanır: fibBellek(40) 79 çağrı yapar. Döngülü sürüm O(n) zaman ve O(1) bellekle çalışır.

İkili Özyineleme

Özyinelemeli İkili Arama

  • Sıralı dizide x aranır: ortadaki öğeye bakılır; x küçükse sol yarıda, büyükse sağ yarıda aynı arama yapılır.
  • İki taban durum: aralık boş (lo > hi) → −1; ortadaki öğe x → indisi.
  • Kodda iki özyinelemeli çağrı yazılıdır ama her çağrı bunlardan yalnızca birini yapar. Fibonacci gibi ağaç oluşmaz; çağrılar bir zincirdir.
  • Aralık her çağrıda yarıya iner: T(n) = T(n/2) + c → O(log n) zaman ve O(log n) yığın belleği.
  • n = 10 için en çok 5, n = 10⁶ için en çok 21 çağrı.

İkili Özyineleme · Kodu adım adım çalıştır

Kod İzleme: ikiliAra(a, 23, 0, 9)

main, 10 öğeli sıralı dizide 23'ü arar: ikiliAra(a, 23, 0, 9).

lo = 0 ≤ hi = 9: aralık boş değil. mid = (0 + 9) / 2 = 4, a[4] = 16.

23 > 16 → sağ yarı: ikiliAra(a, 23, 5, 9). Sol yarıya hiç bakılmaz.

lo = 5 ≤ hi = 9: aralık boş değil. mid = (5 + 9) / 2 = 7, a[7] = 56.

23 < 56 → sol yarı: ikiliAra(a, 23, 5, 6). Sağ yarıya hiç bakılmaz.

lo = 5 ≤ hi = 6: aralık boş değil. mid = (5 + 6) / 2 = 5, a[5] = 23.

a[5] = 23 = x: taban durum (bulundu) → 5 döner.

ikiliAra(a, 23, 5, 9) aldığı 5'i return ile olduğu gibi iletir.

ikiliAra(a, 23, 0, 9) de 5'i iletir. Dönüşte yeni hesap yapılmaz.

Sonuç 5. 3 çağrı; aralık 10 → 5 → 2 öğeye indi.

int ikiliAra(int[] a, int x, int lo, int hi) {
  if (lo > hi) return -1;       // taban: boş aralık
  int mid = (lo + hi) / 2;
  if (a[mid] == x) return mid;  // taban: bulundu
  if (x < a[mid])
    return ikiliAra(a, x, lo, mid - 1); // sol yarı
  return ikiliAra(a, x, mid + 1, hi);   // sağ yarı
}
System.out.println(ikiliAra(a, 23, 0, 9));

Hanoi ve Geri İzleme

Hanoi Kuleleri (Towers of Hanoi)

Bilgisayar bilimi ve matematikte klasik bir problem: bir disk yığını, kurallara uyularak kaynak çubuktan hedef çubuğa taşınır.

  • Bir hamlede yalnızca bir disk taşınır (bir çubuğun en üstündeki).
  • Bir disk yalnızca daha büyük bir diskin üstüne ya da boş çubuğa konabilir.
  • Amaç: yardımcı çubuğu kullanarak tüm diskleri kaynaktan (A) hedefe (C) taşımak.
Özyinelemeli fikir: n−1 diski A'dan B'ye taşı → en büyük diski A'dan C'ye taşı → n−1 diski B'den C'ye taşı. Hamle sayısı T(n) = 2T(n−1) + 1 = 2n − 1.

Hanoi ve Geri İzleme

Hanoi Kuleleri: 3 Diskle 7 Hamle

Başlangıç: 3 disk A çubuğunda (büyük altta). Hedef: hepsini C'ye taşımak.

Hamle 1: disk 1, A → C.

Hamle 2: disk 2, A → B.

Hamle 3: disk 1, C → B.

Hamle 4: disk 3, A → C.

Hamle 5: disk 1, B → A.

Hamle 6: disk 2, B → C.

Hamle 7: disk 1, A → C. Bitti: 2³ − 1 = 7 hamle.

void hanoi(int n, char k, char y, char h) {

}

Hanoi ve Geri İzleme

Geri İzleme (Backtracking)

  • Çözüm adım adım kurulur; her adımda olası seçeneklerden biri denenir.
  • Seçimle bir sonraki adıma geçilir: özyinelemeli çağrı.
  • Çağrı döndüğünde seçim geri alınır ve sıradaki seçenek denenir. Böylece her dal aynı başlangıç durumunu görür.
  • Bir seçim çözüme götüremeyecekse o dal bırakılır, daha derine inilmez.
  • Örnekler: alt kümeleri ya da permütasyonları listeleme, labirentte yol bulma, sudoku, n vezir.
Hanoi'de olduğu gibi her çağrı birden çok özyinelemeli çağrı yapar; çağrı ağacı, denenen tüm seçimlerin ağacıdır (karar ağacı).

void altKumeler(int[] a, int i, List<Integer> s) {

  altKumeler(a, i + 1, s);          // a[i]'siz dene
}

Permütasyonları Listeleme

void perm(char[] h, boolean[] kul, StringBuilder s) {
  if (s.length() == h.length) {  // taban durum
    System.out.print(s + " "); return;
  }
  for (int k = 0; k < h.length; k++) {
    if (kul[k]) continue;        // harf kullanıldı
    kul[k] = true; s.append(h[k]);   // seç
    perm(h, kul, s);
    kul[k] = false;              // geri al
    s.deleteCharAt(s.length() - 1);
  }
}

  • Her seviyede kalan harflerden biri seçilir: 3 · 2 · 1 = 3! = 6 yaprak.
  • Çağrı sayısı 1 + 3 + 6 + 6 = 16.
Bir çağrı, kalan harf sayısı kadar özyinelemeli çağrı yapar: çoklu özyineleme. kul[] ve s tüm çağrılarca paylaşılır; bu yüzden her denemeden sonra seçim geri alınır.

  • Yazmak için üç soru: taban durumun maliyeti nedir (genellikle sabit c)? Kaç özyinelemeli çağrı yapılıyor ve girdileri ne kadar küçük? Çağrılar dışındaki iş ne kadar?

Yineleme Bağıntıları

T(n) = T(n − 1) + c

T(n) = T(n − 1) + c
     = T(n − 2) + 2c
     = T(n − 3) + 3c
     …
     = T(0) + n · c
     = c + n · c   →  O(n)
  • Bağıntı açılarak çözülür: her açılışta bir c daha eklenir, n azalır. n adımda taban duruma inilir.
  • Çağrı ağacı dallanmayan bir zincirdir: n + 1 çağrı. Zincirin tamamı aynı anda yığındadır → bellek de O(n).
  • Örnekler: faktoriyel, toplam, geriSay, yavaş üs alma, bağlı listenin uzunluğu. ters için T(n) = T(n − 2) + c: yarı sayıda çağrı, yine O(n).

Yineleme Bağıntıları

     = T(n/4) + 2c
     = T(n/8) + 3c
     …

n/2ᵏ = 1 olduğunda durulur: k = log₂ n.
T(n) = T(1) + c · log₂ n → O(log n)

Yineleme Bağıntıları

T(n) = 2T(n − 1) + c

  • Her çağrı n − 1 boyutlu iki çağrı yapar: çağrı ağacının her seviyesinde çağrı sayısı ikiye katlanır.
  • Seviye k'de 2ᵏ çağrı; seviyeler 0 … n − 1:
    1 + 2 + 4 + … + 2ⁿ⁻¹ = 2ⁿ − 1 çağrı → O(2ⁿ).
  • Hanoi: tam olarak 2ⁿ − 1 hamle. n = 20 için 1 048 575; n = 64 için yaklaşık 1,8 · 10¹⁹.
  • fib: T(n − 2) ≤ T(n − 1) olduğundan T(n) ≤ 2T(n − 1) + c → üst sınır O(2ⁿ); gerçek büyüme yaklaşık 1,6ⁿ.

Kuyruk Özyinelemesi

Kuyruk Özyinelemesi (Tail Recursion)

  • Özyinelemeli çağrı metodun son işiyse, yani çağrı döndükten sonra yapılacak bir iş kalmıyorsa, metot kuyruk özyinelemelidir.
  • Ara sonuç bir biriktirici parametreyle (acc) aşağı taşınır; çarpma çağrıdan önce yapılır. İlk çağrı: faktKuyruk(n, 1).

Kuyruk özyinelemesi değil

int faktoriyel(int n) {
  if (n <= 1) return 1;
  return n * faktoriyel(n - 1);
  // çarpma, çağrı dönünce yapılır
}

Kuyruk özyinelemeli

int faktKuyruk(int n, int acc) {
  if (n <= 1) return acc;
  return faktKuyruk(n - 1, n * acc);
  // son iş: çağrı (çarpma önce)
}
Kuyruk özyinelemeli: geriSay, ters, ikiliAra, faktKuyruk. Değil: faktoriyel, toplam, fib, ileriSay (çağrıdan sonra iş var).

Kuyruk Özyinelemesini Döngüye Çevirme

int faktDongu(int n) {
  int acc = 1;
  while (n > 1) {   // taban durum değilken
    acc = n * acc;  // çağrının yeni
    n = n - 1;      //   parametreleri
  }
  return acc;       // taban: return acc
}
  • Kuyruk çağrısı, parametreleri yeni değerlerle güncelleyip metodun başına dönmek demektir: parametreler değişken, taban durum döngü koşulu olur.
  • Çevirme mekaniktir; döngülü ikili arama da ikiliAra'nın böyle çevrilmiş hâlidir.
  • Döngü sabit bellekle çalışır: O(1), çerçeve açılmaz.

Dönüş değerini kaybetmekikiliAra'da sol yarı çağrısının önündeki return unutulursa sonuç atılır, akış sağ yarı çağrısına düşer: yanlış cevap, derleyici uyarmaz.
Geri almayı unutmakGeri izlemede s.remove(...) yapılmazsa bir dalın seçimleri sonraki dallara taşar; alt kümeler yanlış çıkar.

Etkileşimli Simülatörler

Hanoi Kuleleri1–6 diskle bulmacayı elle çözme; en kısa çözümü adım adım ileri ve geri oynatma ya da otomatik çözdürme. Yapılan hamle sayısı en az hamle sayısıyla (2ⁿ − 1) karşılaştırılır: n = 6 için 63.
Her kule bir yığın gibi davranır: yalnızca en üstteki disk alınabilir ve yalnızca daha büyük bir diskin üstüne konabilir.

Örnek Problemler

  1. int f(int n) { if (n <= 0) return 0; return n % 10 + f(n / 10); } için f(2026) kaçtır, kaç çağrı yapılır?
  2. ileriSay(4) ne yazar? Yığında (main dahil) en çok kaç çerçeve bulunur?
  3. hizliUs(3, 13) kaç çağrı yapar, sonuç nedir?
  4. fib(6) kaç çağrı yapar?
  5. {1, 2, 3, 4} için altKumeler kaç alt küme yazar, kaç çağrı yapar?
  6. T(n) = T(n/2) + c ve T(1) = c ise n = 64 için zincirde kaç çağrı vardır?
Cevapları göster
  1. Basamaklar toplamı: 6 + 2 + 0 + 2 = 10; çağrılar 2026, 202, 20, 2, 0 → 5.
  2. 1 2 3 4; ileriSay(4 … 0) = 5 çerçeve + main = 6.
  3. n: 13, 6, 3, 1, 0 → 5 çağrı; 3¹³ = 1 594 323.
  4. 2 · F(7) − 1 = 2 · 13 − 1 = 25 çağrı (fib(6) = 8).
  5. 2⁴ = 16 alt küme; 2⁵ − 1 = 31 çağrı.
  6. 64, 32, 16, 8, 4, 2, 1 → 7 = log₂ 64 + 1.

Alıştırmalar

  1. faktoriyel(5) çalışırken çağrı yığınında (main dahil) en fazla kaç çerçeve olur?
  2. 4 diskli Hanoi kaç hamle ister?
  3. Dizinin en büyük öğesini döndüren özyinelemeli enBuyuk(a, n) için taban durum ve özyinelemeli adım nedir?
  4. palindrom(s, i, j) uçları karşılaştırıp içe ilerler: "kayak" için kaç çağrı yapılır?
  5. int g(int n) { if (n <= 1) return 1; return g(n - 1) + g(n - 1); }: g(5) değeri ve çağrı sayısı? Nasıl O(n) yapılır?
  6. faktKuyruk'un döngülü sürümünde her turda n ve acc nasıl değişir?
Cevaplar / ipuçları
  1. faktoriyel(5), (4), (3), (2), (1) + main = 6.
  2. 2⁴ − 1 = 15 hamle.
  3. Taban: n = 1 → a[0]. Adım: max(enBuyuk(a, n − 1), a[n − 1]). O(n).
  4. (0, 4) k = k → (1, 3) a = a → (2, 2) taban: 3 çağrı, true.
  5. g(5) = 2⁴ = 16; 2⁵ − 1 = 31 çağrı. Tek çağrı yeter: return 2 * g(n - 1); → O(n).
  6. acc = n * acc; n = n - 1; döngü n > 1 iken sürer; sonunda acc döner.
