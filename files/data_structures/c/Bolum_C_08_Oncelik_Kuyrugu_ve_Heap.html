C ile Gerçekleştirim

Maksimum heap

typedef struct {
    int *veri;
    size_t adet;
    size_t kapasite;
} MaxHeap;

#define BABA(i) (((i) - 1) / 2)
#define SOL(i)  (2 * (i) + 1)
#define SAG(i)  (2 * (i) + 2)
Tür tanımı veri yapısının bellekteki biçimini; yordamlar ise bu yapı üzerindeki davranışı kurar.

Temel İşlemler

Eklemede yukarı süzme

void yukari_suz(MaxHeap *h, size_t i) {
    while (i > 0) {
        size_t p = BABA(i);
        if (h->veri[p] >= h->veri[i]) break;
        takas(&h->veri[p], &h->veri[i]);
        i = p;
    }
}
Kod örnekleri C99/C11 uyumlu olacak biçimde küçük ve tek sorumluluklu tutulmuştur.

Heap'e 80 ekle

Sona koy

[90, 70, 60, 20, 50, 10, 80]

Babayla karşılaştır

80'in babası indis 2'deki 60'tır.

Takas

80 > 60 olduğu için yer değiştir: [90,70,80,20,50,10,60].

Dur

Yeni baba 90; 90 ≥ 80, heap özelliği sağlandı.
