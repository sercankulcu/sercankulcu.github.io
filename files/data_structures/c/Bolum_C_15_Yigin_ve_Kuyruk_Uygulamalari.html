C ile Gerçekleştirim

Labirent durumu

typedef struct {
    int satir, sutun;
    int sonraki_yon;
} Durum;

typedef struct { Durum *veri; int ust, kapasite; } DurumYigini;
Tür tanımı veri yapısının bellekteki biçimini; yordamlar ise bu yapı üzerindeki davranışı kurar.

Temel İşlemler

Postfix hesaplamanın çekirdeği

if (isdigit((unsigned char)token)) push(&y, token - '0');
else {
    int sag = pop(&y);
    int sol = pop(&y);
    push(&y, uygula(token, sol, sag));
}
Kod örnekleri C99/C11 uyumlu olacak biçimde küçük ve tek sorumluluklu tutulmuştur.
