C ile Gerçekleştirim

Ayrık kümeler yapısı

typedef struct {
    int *ebeveyn;
    unsigned *boyut;
    size_t n;
} DSU;
Tür tanımı veri yapısının bellekteki biçimini; yordamlar ise bu yapı üzerindeki davranışı kurar.

Temel İşlemler

Yol sıkıştırmalı find

int find(DSU *d, int x) {
    if (d->ebeveyn[x] != x)
        d->ebeveyn[x] = find(d, d->ebeveyn[x]);
    return d->ebeveyn[x];
}

bool ayni_kume(DSU *d, int a, int b) {
    return find(d, a) == find(d, b);
}
Kod örnekleri C99/C11 uyumlu olacak biçimde küçük ve tek sorumluluklu tutulmuştur.
