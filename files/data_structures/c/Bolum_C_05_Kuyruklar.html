C ile Gerçekleştirim

Dairesel kuyruk

#define KAPASITE 8
typedef struct {
    int veri[KAPASITE];
    size_t on, arka, adet;
} Kuyruk;
Tür tanımı veri yapısının bellekteki biçimini; yordamlar ise bu yapı üzerindeki davranışı kurar.

Temel İşlemler

enqueue ve dequeue

bool enqueue(Kuyruk *q, int x) {
    if (q->adet == KAPASITE) return false;
    q->veri[q->arka] = x;
    q->arka = (q->arka + 1) % KAPASITE;
    ++q->adet;
    return true;
}

bool dequeue(Kuyruk *q, int *x) {
    if (q->adet == 0) return false;
    *x = q->veri[q->on];
    q->on = (q->on + 1) % KAPASITE;
    --q->adet;
    return true;
}
Kod örnekleri C99/C11 uyumlu olacak biçimde küçük ve tek sorumluluklu tutulmuştur.
