Doğrusal liste

L = (a0, a1, …, an−1), n ≥ 0; ai, ai+1'den önce gelir.

Ön / son koşul

liste_ekle(L, i, x): önce 0 ≤ i ≤ n; sonra x i. konumda, uzunluk n+1, eski ai.. bir kaydı.

Opak tür

struct liste yalnızca .c dosyasında tanımlı; kullanan kod dizi mi bağ mı bilmez, değiştirmek kolaydır.

Liste ADT

Dizi ile gerçekleştirim (sıralı yerleşim)

#define KAPASITE 100
typedef struct {
    int a[KAPASITE];
    int n;                  // öğe sayısı
} DiziListe;

bool dizi_sil(DiziListe *L, int i, int *x) {
    int k;
    if (i < 0 || i >= L->n) return false;
    *x = L->a[i];
    for (k = i; k < L->n - 1; k++)
        L->a[k] = L->a[k + 1];      // sola kaydır
    L->n--;
    return true;
}
Erişim

a[i] adresi hesaplanır: O(1).

Ekleme / silme

i'den sonraki öğeler kaydırılır: en kötü O(n) (başa ekleme, baştan silme).

Kapasite

Sabit dizi dolar; dinamik dizide realloc ile iki katına çıkarmak ortalama O(1) ekleme verir.

Liste ADT · Kodu adım adım çalıştır

Kod İzleme: dizi_ekle(&L, 1, 9)

Liste [4, 7, 2], n = 3; 9 değeri 1. konuma eklenecek (0 tabanlı).

Denetim: dolu değil ve 0 ≤ i ≤ n; ekleme yapılabilir.

k = 3: k > i → doğru, kaydır.

a[3] = a[2]: 2 bir sağa kaydı.

k = 2: k > i → doğru, kaydır.

a[2] = a[1]: 7 bir sağa kaydı.

k = 1: k > i → yanlış, döngü biter.

a[i] = x: boşalan konuma 9 yazıldı.

n++: liste [4, 9, 7, 2]. Kaydırma sayısı n − i: en kötü (i = 0) O(n).

bool dizi_ekle(DiziListe *L, int i, int x) {
    int k;
    if (L->n == KAPASITE || i < 0 || i > L->n)
        return false;          // dolu/geçersiz
    for (k = L->n; k > i; k--)
        L->a[k] = L->a[k - 1];     // sağa kaydır
    L->a[i] = x;
    L->n++;
    return true;
}

Liste ADT

Bağlaçlı gerçekleştirim: göstergeye gösterge

typedef struct dugum *dugum_gost;
struct dugum { int deger; dugum_gost bag; };
typedef struct { dugum_gost bas; int n; } BListe;

bool bl_ekle(BListe *L, int i, int x) {
    dugum_gost *pp = &L->bas, yeni;
    if (i < 0 || i > L->n) return false;
    while (i-- > 0)
        pp = &(*pp)->bag;        // i. bağa yürü
    yeni = malloc(sizeof *yeni);
    if (yeni == NULL) return false;
    yeni->deger = x;
    yeni->bag = *pp;
    *pp = yeni;                  // baş ya da ara: aynı
    L->n++;
    return true;
}
dugum_gost *pp

Değiştirilecek bağın adresi: başta &L->bas, sonra &önceki->bag. Başa ekleme özel durum olmaktan çıkar.

Maliyet

Konuma yürümek O(i), bağlamak O(1). Kaydırma yok; kapasite sınırı yok.

Uzunluk

n alanı tutulursa liste_uzunluk O(1).

Genelleştirilmiş Listeler

Doğrusal listeden genelleştirilmiş listeye

Doğrusal liste

A = (α0, …, αn−1): öğelerin her biri atomik (dizi, tek bağlaçlı liste).

Tanım

αi atomik ya da bir alt liste olabiliyorsa A'ya genelleştirilmiş liste denir. A listenin adı, n uzunluğudur.

Baş ve kuyruk

α0 listenin başı (head), (α1, …, αn−1) kuyruğu (tail). Kuyruk her zaman bir listedir.

LISP bağlantısı

Baş/kuyruk, LISP'teki car/cdr'dir; LISP programları da genelleştirilmiş listedir.

ListeUzunlukAçıklama
D = ()0boş liste
A = (a, (b, c))2ilk öğe atom, ikinci öğe (b, c) alt listesi; baş(A) = a, kuyruk(A) = ((b, c))
B = (A, A, ())3paylaşımlı alt liste: ilk iki öğe aynı A; üçüncüsü boş liste
C = (a, C)2özyineli liste: kendini içerir, C = (a, (a, (a, …)))

Genelleştirilmiş Listeler

Örnek: çok değişkenli polinom

typedef enum { VAR, PTR, NO } uclu_t;
typedef struct poge *poge_gost;
struct poge {
    uclu_t uclu;            // üçlü
    union {
        char deg;           // VAR: değişkenin adı
        poge_gost L_bag;    // PTR: katsayı bir liste
        int kat;            // NO : tamsayı katsayı
    };
    int us;                 // üs bilgisi
    poge_gost bag;
};
Üç tür öğe

VAR: liste başı, değişken adı (us = 0). PTR: katsayı bir alt liste. NO: katsayı tamsayı.

Fikir

P(x,y,z) önce z'ye göre gruplanır; her z-teriminin katsayısı bir y-polinomu, onunkiler de x-polinomu.

Hocadan “Polinomların genelleştirilmiş liste ile gerçekleştirimi için bu, tek bir örnek. Başka şekilde de gerçekleştirebilirsin. Ama bunu yapan dönüşüm yordamlarını da yazabilmelisin.”— Mustafa Ege, VYA2 ders notları

Genelleştirilmiş Listeler

Polinomun bellek görünümü

VAR: liste başı, deg'de değişken adı. PTR: katsayı L_bag'deki liste. NO: katsayı tamsayı.

P(x,y,z) = x¹⁰y³z² + 2x⁸y³z² + 3x⁸y²z² + x⁴y⁴z + 6x³y⁴z + 2yz, z'ye göre gruplanıp iç içe listeye yerleşir.

Çizimi basitleştirmek için notlardaki gibi alt düzeyler kısaltıldı; polinomların ayrıntısı Bölüm 14.

Genelleştirilmiş Listeler

Öğe yapısı ve bellek görünümü

typedef enum { FALSE, TRUE } boolean;
typedef struct oge *oge_gost;
struct oge {
    boolean isaret;       // FALSE: atom
    union {
        char veri;        // atomik değer
        oge_gost L_bag;   // alt listenin başı
    };
    oge_gost bag;         // aynı düzeydeki sonraki
};
Öğe

[isaret | veri/L_bag | bag]: F = atom, T = alt liste.

Bu sunumda

Yordamlarda bu ikinci yapı (isaret) kullanılır.

Adsız union C11 özelliğidir (notlardaki yazım); C99 için union’a ad verilip L->u.veri yazılır.

Temel Yordamlar

SORU: paylaşımsız, özyinelemesiz listeyi kopyala

oge_gost kopyala(oge_gost L) {
    oge_gost q = NULL;
    if (L) {                    // L NULL değil mi
        q = ogeal();            // bir öğe al
        q->isaret = L->isaret;
        if (!L->isaret) q->veri = L->veri; // atom
        else q->L_bag = kopyala(L->L_bag);
        q->bag = kopyala(L->bag);
    }
    return q;
}
Yapı

Her öğe için: yeni öğe al, türü kopyala, atomsa değeri, değilse alt listenin kopyasını bağla; sonra kalanı kopyala.

Düzeltme

Notlardaki 8. satır yorumu “paylaşımlı alt listeyi kopyala” diyor; yordam yalnız paylaşımsız listelerde doğrudur.

ogeal(): malloc(sizeof *p) + NULL denetimi yapan yardımcı (bellek yoksa programı durdurur).

Temel Yordamlar · Kodu adım adım çalıştır

Kod İzleme: kopyala(L), L = (a,(b,c))

ogeal(): a için yeni öğe ayrıldı (alanlar henüz çöp).

Atomik: q->isaret = FALSE, q->veri = 'a'.

Sıradaki öğe için çağrı: kopyala(L->bag).

ogeal(): (b,c) için yeni öğe ayrıldı (alanlar henüz çöp).

Alt liste: önce alt listenin kopyası istenir (özyineli çağrı).

ogeal(): b için yeni öğe ayrıldı (alanlar henüz çöp).

Atomik: q->isaret = FALSE, q->veri = 'b'.

Sıradaki öğe için çağrı: kopyala(L->bag).

ogeal(): c için yeni öğe ayrıldı (alanlar henüz çöp).

Atomik: q->isaret = FALSE, q->veri = 'c'.

Sıradaki öğe için çağrı: kopyala(L->bag).

kopyala(NULL) (bag): L NULL → hiçbir şey ayırmadan q = NULL döner.

Dönüş: q->bag = NULL (son öğe).

Dönüş: q->bag ← &kopya(c).

Dönüş: q->L_bag ← alt listenin kopyası &kopya(b).

Sıradaki öğe için çağrı: kopyala(L->bag).

kopyala(NULL) (bag): L NULL → hiçbir şey ayırmadan q = NULL döner.

Dönüş: q->bag = NULL (son öğe).

Dönüş: q->bag ← &kopya((b,c)).

Kopya tamam: aynı yapı, yeni öğeler. Alırken baştan sona, günlerken sondan başa.

Temel Yordamlar

Kopyalama: test listesi ve sınırlar

Test için: L = ((a,b),((c,d),e))

Paylaşımlı liste

B = (A,A,()) kopyalanırsa A iki kez kopyalanır; kopyada paylaşım kaybolur.

Özyineli liste

C = (a,C) için çağrılar hiç bitmez; yığıt taşar ve program çakılır.

Hocadan “Alırken baştan sona, günlerken sondan başa… “Hocam ben özyineli yazmıycam.” diyen var mı hala? “Ben onu kuyruğa koyarım.” diyen arkadaş varsa artık bir şey diyemeyeceğim…”— Mustafa Ege, VYA2 ders notları

Temel Yordamlar

SORU: paylaşımsız, özyinelemesiz iki liste eşit mi?

boolean esitmi(oge_gost T, oge_gost L) {
    boolean x = TRUE;
    if (!T && !L) return TRUE;
    if (T && L && T->isaret == L->isaret) {
        if (!T->isaret)         // atomik mi?
            x = (T->veri == L->veri) ? TRUE : FALSE;
        else                    // alt listeler
            x = esitmi(T->L_bag, L->L_bag);
        if (x == TRUE) return esitmi(T->bag, L->bag);
    }
    return FALSE;
}
Mantık

İkisi birlikte biterse eşit. Türler aynıysa: atomda değer, alt listede özyineli eşitlik; ardından kalan öğeler.

Sınır

Özyineli listelerde (C = (a,C)) çağrılar sonsuza gider.

Hocadan “Bu kod, ustaca yazılmış bir kod değil. Daha nitelikli kod yazabilirsiniz. Bir de sonsuz çağrılar sebebiyle özyineli listeler karşılaştırılamaz.”— Mustafa Ege, VYA2 ders notları

Temel Yordamlar · Kodu adım adım çalıştır

Kod İzleme: esitmi(T, L)

İkisi de var ve isaret alanları aynı: içeriği karşılaştır.

Atomik: 'a' == 'a' → x = TRUE.

x doğru: kalan öğeler karşılaştırılır (bag alanları).

İkisi de var ve isaret alanları aynı: içeriği karşılaştır.

Alt liste: önce alt listeler karşılaştırılır.

İkisi de var ve isaret alanları aynı: içeriği karşılaştır.

Atomik: 'b' == 'b' → x = TRUE.

x doğru: kalan öğeler karşılaştırılır (bag alanları).

İkisi de var ve isaret alanları aynı: içeriği karşılaştır.

Atomik: 'c' == 'd' → x = FALSE.

x yanlış: return FALSE; kalan öğelere hiç bakılmaz.

Dönüş değeri aynen yukarı iletilir: FALSE.

Alt listelerden dönen: x = FALSE.

x yanlış: return FALSE; kalan öğelere hiç bakılmaz.

Dönüş değeri aynen yukarı iletilir: FALSE.

boolean esitmi(oge_gost T, oge_gost L) {
    boolean x = TRUE;
    if (!T && !L) return TRUE;
    if (T && L && T->isaret == L->isaret) {
        if (!T->isaret)         // atomik mi?
            x = (T->veri == L->veri) ? TRUE : FALSE;
        else                    // alt listeler
            x = esitmi(T->L_bag, L->L_bag);
        if (x == TRUE) return esitmi(T->bag, L->bag);
    }
    return FALSE;
}

Temel Yordamlar

Daha nitelikli sürüm ve paylaşımlı listeler

bool esit(oge_gost T, oge_gost L) {
    if (T == L) return true;        // aynı düğüm/ikisi NULL
    if (!T || !L || T->isaret != L->isaret) return false;
    if (T->isaret ? !esit(T->L_bag, L->L_bag)
                  : T->veri != L->veri)
        return false;
    return esit(T->bag, L->bag);
}
T == L kısayolu

İkisi NULL ise ya da aynı (paylaşılan) alt listeyi gösteriyorsa içine inmeden TRUE.

SORU: paylaşımlı listeler

Özyinelemesiz (döngüsüz) paylaşımlı listelerde de aynı yordam doğru sonuç verir; kısayol, ortak alt listeleri tekrar dolaşmayı önler.

Hocadan “Bakın, programın direnç noktasını tespit ediyorum. Tuşa bastın, çalıştı; yetmez! … Hâlbuki ispat yaparken daha geniş bir bilgi sahasına hâkim olduğunu gösterirsin.”— Mustafa Ege, VYA2 ders notları

void dolas_yaz(oge_gost L) {
    if (L) {
        if (!L->isaret)
            printf("%c", L->veri); // atomikse yaz
        else
            dolas_yaz(L->L_bag);
        dolas_yaz(L->bag);

İki hata: (1) Özyineli çağrılar dolas adını kullanıyor, yordamın adı dolas_yaz (derlenmez). (2) Süslü parantez yok: if(L) yalnızca iç if-else'i kapsar, 7. satır L == NULL iken de çalışır → NULL->bag ile çöker. Doğrusu iki çağrıyı da if (L) { … } içine almaktır.

Temel Yordamlar · Kodu adım adım çalıştır

Kod İzleme: dolas_yaz(L), L = (a,(b),c)

Atomik öğe: 'a' yazıldı.

Aynı düzeyde sıradaki öğeye geç (L->bag).

Alt liste: önce içine dal (L->L_bag).

Atomik öğe: 'b' yazıldı.

Aynı düzeyde sıradaki öğeye geç (L->bag).

L == NULL (düzeyin sonu): hiçbir şey yapmadan dön.

Aynı düzeyde sıradaki öğeye geç (L->bag).

Atomik öğe: 'c' yazıldı.

Aynı düzeyde sıradaki öğeye geç (L->bag).

L == NULL (düzeyin sonu): hiçbir şey yapmadan dön.

Tüm atomlar soldan sağa, derinlikten bağımsız yazıldı: abc. Her öğe bir kez: O(n).

void dolas_yaz(oge_gost L) {
    if (L) {
        if (!L->isaret)
            printf("%c", L->veri); // atomikse yaz
        else
            dolas_yaz(L->L_bag);
        dolas_yaz(L->bag);
    }
}

Temel Yordamlar

Örnek: A(B(E(K,L),F),C(G),D(H(M),I,J))

Her ağaç düğümü bir alt liste: başı düğümün etiketi, kalanı çocukları. Aynı düzeydeki öğeler bir satır boyunca izlenir.

dolas_yaz bu liste için ABEKLFCGDHMIJ yazar: ağacın kök-önde (preorder) dolaşımı.

Derinlik ve Devrik

SORU: listenin derinliği — özyineli

int derinlik(oge_gost L) {
    oge_gost p = L;  int m = 0;    // m: en büyük
    if (!L) return 0;
    while (p) {
        if (p->isaret) {
            int n = derinlik(p->L_bag);
            if (m < n) m = n;
        }
        p = p->bag;
    }
    return m + 1;
}
Tanım

derinlik(()) = 0; aksi hâlde 1 + alt listelerin en büyük derinliği. Atomlar derinlik katmaz.

Örnekler

(a, b) → 1 · (a, (b, c)) → 2 · (a, (b, (c))) → 3 · (()) → 1.

Maliyet

Her öğe bir kez ziyaret: O(n); çağrı yığını en çok derinlik kadar.

Derinlik ve Devrik · Kodu adım adım çalıştır

Kod İzleme: derinlik(L), L = (a,(b,(c)))

1. düzey çağrı: p = L, m = 0.

'a' atomik: derinliği artırmaz.

Alt liste bulundu: derinliği özyineli olarak hesaplanır.

2. düzey çağrı: p = L, m = 0.

'b' atomik: derinliği artırmaz.

Alt liste bulundu: derinliği özyineli olarak hesaplanır.

3. düzey çağrı: p = L, m = 0.

'c' atomik: derinliği artırmaz.

p = p->bag → NULL: bu düzeyin öğeleri bitti.

return m + 1 = 1: en derin alt liste + bu düzey.

Alt listeden n = 1 döndü → m = 1.

p = p->bag → NULL: bu düzeyin öğeleri bitti.

return m + 1 = 2: en derin alt liste + bu düzey.

Alt listeden n = 2 döndü → m = 2.

p = p->bag → NULL: bu düzeyin öğeleri bitti.

return m + 1 = 3: en derin alt liste + bu düzey.

int derinlik(oge_gost L) {
    oge_gost p = L;  int m = 0;    // m: en büyük
    if (!L) return 0;
    while (p) {
        if (p->isaret) {
            int n = derinlik(p->L_bag);
            if (m < n) m = n;
        }
        p = p->bag;
    }
    return m + 1;
}

int derinlik( agac_gost L ){
    agac_gost yigit_al(); void yigit_ekle(agac_gost);
    int max = 0;
    for( int current = 1, p = L ; p ; p->bag ){

            p = p -> L_bag;
            current++;

int derinlik_d(oge_gost L) {
    oge_gost yigit[100];       // yerel yığıt (derinlik<100)
    int ust = 0, d = 1, m = 0;
    oge_gost p = L;
    if (!L) return 0;
    for (;;) {
        if (p == NULL) {             // düzey bitti
            if (ust == 0) return m;
            p = yigit[--ust]->bag;   // T'den sonraki
            d--;
        } else {
            if (d > m) m = d;
            if (p->isaret && p->L_bag) {
                yigit[ust++] = p;    // alt listeye in
                p = p->L_bag;
                d++;
            } else p = p->bag;
        }
    }
}

void devrik_al(oge_gost *L) {
    oge_gost r, p = *L, q = NULL;
    while (p) {
        if (p->isaret)              // atomik değilse
            devrik_al(&p->L_bag);
        r = q;
        q = p;
        p = p->bag;
        q->bag = r;
    }
    *L = q;
}
Bölüm 3'ün yordamı + 2 satır

liste_devrik_al'daki üç gösterge aynen; ek: alt listeyse önce onun devriği. Kullanım: görüntüyü yansıtmak.

Neden &p->L_bag?

Alt listenin başı değişir; T öğesinin L_bag alanı çağrıdan dönmeden, iç çağrının *L = q satırıyla güncellenir.

Derinlik ve Devrik · Kodu adım adım çalıştır

Kod İzleme: devrik_al(&L), (a,(b,c)) → ((c,b),a)

p = *L → &öğe(a), q = NULL.

r = q; q = p; p = p->bag; q->bag = r; → a öğesinin bağı tersine çevrildi.

Öğe bir alt liste: önce onun devriği alınır (&p->L_bag adresiyle).

p = *L → &öğe(b), q = NULL.

r = q; q = p; p = p->bag; q->bag = r; → b öğesinin bağı tersine çevrildi.

p == NULL: bu düzey bitti.

*L = q: bu düzeyin yeni başı c.

p == NULL: bu düzey bitti.

Ağaç ve Paylaşım

Ağaç yapısının genelleştirilmiş listeyle kurulması

A(B(E(K,L),F),C(G),D(H(M),I,J))

Notasyon

C(G): C, G'nin atasıdır. A(B…,C…,D…): A; B, C, D'nin atasıdır.

Esneklik

Bu kadar veri için tek satırlık metin yeter. Virgül yerine nokta, süslü parantez: notasyon size kalmış.

Hocadan “Bundan ona, ondan buna geçebiliyorsan tamamdır; senin içerdeki yapını kimse bilemez.”— Mustafa Ege, VYA2 ders notları

Ağaç ve Paylaşım

Dezavantaj: sağ–sol ayrımı yok

Üç ağacın da doğrusal formu aynı: A(B(C(D(E),G(I)))) — B'nin sol mu sağ çocuk olduğu yazılamıyor.

Sorun

Genel ağaçta çocuk sırası yeterlidir; ama ikili ağaçta sol ve sağ çocuk ayrımı kaybolur.

Çözüm

Her düğümün yanında L/R bilgisi tutulur (ya da boş çocuk yerine özel simge yazılır): A(B(,C(…))).

Ağaç ve Paylaşım

Ödevler

  1. Ödev 1: A(B(E(H,I(J,K)),F),C(G),D) listesinin bellek görünümünü ve ağaç yapısını çiziniz.
  2. Ödev 2: Ağaç yapısı verildiğinde liste yazımını çıktı veren yordamı yazınız.
Çözüm önerileri
void agac_yaz(oge_gost L) {   // L: (kök, alt ağaçlar...)
    printf("%c", L->veri);          // kök etiketi
    if (L->bag) {
        printf("(");
        for (oge_gost p = L->bag; p; p = p->bag) {
            if (p->isaret) agac_yaz(p->L_bag);
            else printf("%c", p->veri);   // yaprak
            if (p->bag) printf(",");
        }
        printf(")");
    }
}

Ağaç ve Paylaşım

Paylaşımlı listeler ve referans sayma

// başlıkta sayac: bu listeyi gösteren sayısı
void liste_birak(oge_gost *L) {
    oge_gost p, q;
    if (*L == NULL) return;
    if (--(*L)->sayac > 0) {    // başkası kullanıyor
        *L = NULL; return;
    }
    p = (*L)->bag;              // ilk gerçek öğe
    free(*L);
    while (p) {
        if (p->isaret) liste_birak(&p->L_bag);
        q = p; p = p->bag; free(q);
    }
    *L = NULL;
}
Başlık düğümü

Her liste bir başlık düğümüyle başlar; sayac onu gösteren gösterge sayısıdır.

Bırakma kuralı

Sayaç 0'a inmedikçe liste bırakılmaz; inerse öğeler ve alt listeler de aynı kuralla bırakılır.

Horowitz–Sahni, Bölüm 4.9 (referans sayaçlı başlık düğümü); notlarda yok, bütünlük için eklendi.

Ağaç ve Paylaşım

Referans sayma adım adım: B = (A, A, ())

Her listenin başında bir başlık düğümü; sayac onu gösteren gösterge sayısı. A'yı A adı ve B'nin iki öğesi gösterir: 3.

liste_birak(&B): B'nin sayacı 1 → 0, B'nin öğeleri tek tek bırakılır.

B'nin iki T öğesi A için liste_birak çağırır: 3 → 2 → 1. A hâlâ kullanımda, bırakılmaz.

Sonra liste_birak(&A): 1 → 0, A bırakılır. Paylaşım güvenle yönetildi.

Kopyalamada da aynı fikir: paylaşımlı alt liste yeniden kopyalanmaz, sayacı artırılır.

Ağaç ve Paylaşım

Referans saymanın sınırı ve çöp toplama

Döngü sorunu

C = (a, C): C kendini gösterdiği için sayacı hiç 0 olmaz; C adı silinse bile liste bellekte kalır (sızıntı).

İşaretle–süpür

(1) Kök göstergelerden (değişkenler) erişilebilen tüm öğeleri işaretle; (2) belleği tara, işaretsizleri süpür (avail'e ekle).

Bedel

Çöp toplayıcı çalışırken program durur; işaret biti için yer gerekir. LISP, Java, Python bu fikrin türevlerini kullanır.

C'de

Otomatik çöp toplama yok: kopyalama, paylaşım ve bırakma sorumluluğu programcıda.
