İkili Arama Ağacı

İkili arama ağacı (binary search tree)

  1. Her öğenin değeri farklıdır; değerler tektir (unique).
  2. Boş olmayan sol alt ağaçtaki değerler, alt ağacın kökündekinden küçüktür.
  3. Boş olmayan sağ alt ağaçtaki değerler kökündekinden büyüktür.
  4. Sol ve sağ alt ağaçlar da ikili arama ağacıdır.
İkili arama ağacı, ikili ağacın bir alt kümesidir. Kök ortada dolaşım değerleri sıralı verir.

Hangisi ikili arama ağacı?

Ekleme

Çarpıklık, dengeli ağaçlar ve sık kullanılan düğümler

  • Veriler sıralı gelirse ağaç sağa ya da sola çarpık olur, derinliği n olur: liste gibi.
  • Derinlik ≈ lg n ise dengeli ikili arama ağacı: ekleme, silme, arama O(lg n).
  • n = 2.000.000 için lg n ≈ 21 karşılaştırma.
  • Dengeli ağaçlar (self-balancing): veri geldikçe ağacı yeniden dengeleyen algoritmalar — kırmızı-siyah, AVL (bu bölümün sonunda).
  • Sık kullanılan düğümler: arama sıklığı yüksek düğümleri köke yaklaştıran algoritmalar (“zig-zag”; literatürdeki adıyla splay tree, Sleator–Tarjan).
Hocadan “O(n) ile O(lgn) arasındaki fark 2.000.000 ile 20 arasındaki fark gibidir.”
Hocadan “Ağacın dengeli olması sizin için çok önemliyse ağacı dengeli kuran algoritmalar kullanmalısınız. Çok zor değil, kitaplarda da var, sadece biraz daha uzun. Ödev olarak sorabilirim.”

Cevap

Aynı sıra her zaman aynı ağacı verir (ekleme deterministiktir). Ama tersi tek değildir: 2,1,3 ve 2,3,1 aynı ağacı kurar. Her atanın torunlarından önce gelmesi yeter; ağacın kök önde sırası daima geçerli bir ekleme sırasıdır.

??? Kök önde, kök ortada, kök sonda dolaşım sırasından ağaç görüntüsü elde edilebilir mi?

Cevap

Genel ikili ağaçta tek dolaşım yetmez; kök ortada + (kök önde ya da kök sonda) tek ağaç verir (Bölüm 7'deki sınav sorusu). İkili arama ağacında kök ortada zaten sıralı hâldir; bu yüzden yalnızca kök önde (ya da kök sonda) sırası yeterlidir.

Hocadan “Şimdiye kadar arka planda bir ağaç olmadığı için kodu çalıştırarak test edemiyordunuz.”

Artık ekleme yordamıyla örnek ağaçlar kurup Bölüm 7'deki yordamları gerçekten çalıştırabiliriz.

Ekleme

Ekleme nasıl yapılır?

  • Her iki çocuğu da olan düğüme eklenemez; en az bir çocuğu olmayan düğüme eklenir.
  • Gelen veri kökten itibaren aranır: daha büyük değerli düğümde sola, daha küçük değerlide sağa ilerlenir.
  • Aynı değer bulunursa tanıma aykırı olacağından ekleme yapılmaz.
  • Arama göstergesinin ilk rastladığı NULL'un yerine yeni öğe eklenir: bunun için bir adım arkadan gelen gösterge (q) gerekir.
typedef enum { FALSE, TRUE } boolean;
typedef struct dugum *agac_gost;
struct dugum {
    agac_gost solcocuk;
    int       veri;
    agac_gost sagcocuk;
};
/* ogeal(): malloc + NULL denetimi,
   çocukları NULL yapar (Bölüm 7) */

Ekleme · Kodu adım adım çalıştır

arama_agacina_ekle(50, &L) adım adım

p kökü gösteriyor (47), q (arkadaki gösterge) NULL.

q = p = 47: arka gösterge bir adım geriden gelir; eklemeyi q'ya yapacağız.

50 > 47 → yeri sağ alt ağaçta: p = 47->sagcocuk = 55.

q = p = 55: arka gösterge bir adım geriden gelir; eklemeyi q'ya yapacağız.

50 < 55 → yeni elemanın yeri sol alt ağaçta: p = 55->solcocuk = 49.

q = p = 49: arka gösterge bir adım geriden gelir; eklemeyi q'ya yapacağız.

50 > 49 → yeri sağ alt ağaçta: p = 49->sagcocuk = 52.

q = p = 52: arka gösterge bir adım geriden gelir; eklemeyi q'ya yapacağız.

50 < 52 → yeni elemanın yeri sol alt ağaçta: p = 52->solcocuk = NULL.

p NULL oldu: döngü biter. Yeni öğe q = 52'nin boş çocuğunun yerine gelecek.

Yeni düğüm ayrılır (çocukları NULL) ve verisi 50 yapılır.

Ağaç boş değil; 50 < 52 → q->solcocuk = r. Bağ kuruldu.

TRUE döner. Yalnızca bir gösterge değişti; ağacın geri kalanına dokunulmadı.

boolean arama_agacina_ekle(int x, agac_gost *L) {
  agac_gost q = NULL, p = *L, r; // q arka, p ön
  while (p) {                    // NULL'a dek in
    q = p;                       // arkayı günle
    if (x < p->veri) p = p->solcocuk;
    else if (x > p->veri) p = p->sagcocuk;
    else { printf("Benzer deger var.\n");
           return FALSE; }
  }
  r = ogeal();                   // çocuklar NULL
  r->veri = x;
  if (*L == NULL) *L = r;        // boş ağaç: kök
  else if (x < q->veri) q->solcocuk = r;
  else q->sagcocuk = r;
  return TRUE;
}

Ekleme

Neden agac_gost *L? Maliyet?

  • Ağaç boşsa (*L == NULL) eklenen öğe kök olur: çağıranın kök göstergesi değişmelidir.
  • Göstergenin kendisini değiştirmek için adresi gönderilir (call by reference): arama_agacina_ekle(x, &kok).
  • Maliyet: derinlik kadar karşılaştırma → Ω(lg n) – O(n).
  • C99 düzeltmesi: q = NULL ilk değeri.
/* Özyineli alternatif: yeni kökü döndürür */
agac_gost ekle(agac_gost L, int x) {
  if (!L) {
    L = ogeal();
    L->veri = x;
  } else if (x < L->veri)
    L->solcocuk = ekle(L->solcocuk, x);
  else if (x > L->veri)
    L->sagcocuk = ekle(L->sagcocuk, x);
  return L;        /* kok = ekle(kok, x); */
}

arama_agacinda_ara(52, L) — döngüsel

52 > 47 → sağa. Sol alt ağaç elenir.

52 < 55 → sola. Sağ alt ağaç (soluk) hiç incelenmez: aramanın gücü buradan gelir.

52 > 49 → sağa. Sol alt ağaç elenir.

52 == 52: bulundu, düğümün adresi döndürülür. Toplam 4 karşılaştırma.

agac_gost arama_agacinda_ara(int x, agac_gost L) {
  while (L) {           // uygun alt ağaçta in
    if (x == L->veri) return L;
    if (x < L->veri) L = L->solcocuk;
    else             L = L->sagcocuk;
  }
  return NULL;          // bulunamadı
}

agac_gost ara(int x, agac_gost L) {
  if (!L) return NULL;          // yok
  if (x == L->veri) return L;   // bulundu
  if (x < L->veri)
    return ara(x, L->solcocuk);
  return ara(x, L->sagcocuk);
}

Örnek çözüm: her ikili ağaçta arama

agac_gost ara_ozyineli(int veri, agac_gost L) {
  if (!L) return NULL;              /* ağaç boş mu   */
  if (L->veri == veri) return L;    /* aranan bulundu */
  agac_gost T = ara_ozyineli(veri, L->solcocuk);
  return T ? T : ara_ozyineli(veri, L->sagcocuk);
}
  • Önce solda arar; bulamazsa (T == NULL) sağda arar.
  • Sıralama bilgisi kullanılmaz → en kötü O(n); BST'de gereksiz yere yavaş.
  • Ağırlık bulma sınav sorusunun çözümünde bu yordam kullanılır.

/* global değişkensiz döngüsel çözüm:
   düzey düzey dolaş, düzeyleri say */
int derinlik_d(agac_gost L) {
  agac_gost k[MAX_SIZE];
  int on = 0, arka = 0, d = 0;
  if (L) k[arka++] = L;
  while (on < arka) {          /* bir düzey */
    int son = arka;
    d++;
    for (; on < son; on++) {
      if (k[on]->solcocuk) k[arka++] = k[on]->solcocuk;
      if (k[on]->sagcocuk) k[arka++] = k[on]->sagcocuk;
    }
  }
  return d;       /* MAX_SIZE >= n olmalı */
}

Derinlik · Kodu adım adım çalıştır

Özyineli derinlik: {sol, sağ} çerçeveleri

L = A: önce sol alt ağacın derinliği: derinlik(B) çağrılır.

L = B: önce sol alt ağacın derinliği: derinlik(D) çağrılır.

L = D: sol = 0, sağ = 0 (NULL → 0) → MAX + 1 = 1 döner; yerel sol/sağ silinir.

L = B: sol = 1, sağ = 0 (NULL → 0) → MAX + 1 = 2 döner; yerel sol/sağ silinir.

sol = 2; şimdi derinlik(C).

L = C: önce sol alt ağacın derinliği: derinlik(E) çağrılır.

L = E: önce sol alt ağacın derinliği: derinlik(F) çağrılır.

L = F: sol = 0, sağ = 0 (NULL → 0) → MAX + 1 = 1 döner; yerel sol/sağ silinir.

L = E: sol = 1, sağ = 0 (NULL → 0) → MAX + 1 = 2 döner; yerel sol/sağ silinir.

L = C: sol = 2, sağ = 0 (NULL → 0) → MAX + 1 = 3 döner; yerel sol/sağ silinir.

L = A: sol = 2, sağ = 3 → MAX + 1 = 4 döner; yerel sol/sağ silinir.

int derinlik(agac_gost L) {
  int sol, sag;
  if (L) {                   // gösterge NULL mı
    sol = derinlik(L->solcocuk);
    sag = derinlik(L->sagcocuk);
    return MAX(sol, sag) + 1;
  }
  else return 0;             // uç yaprağa ulaşıldı
}

Derinlik

Derinlik: problem yeterince küçüldü mü?

  • Ağacın derinliği, sol ve sağ alt ağaçlarının en derin olanının 1 fazlasıdır: MAX(sol, sağ) + 1.
  • Her düğümün kendi 2 yerel değişkeni vardır: sol ve sağ derinlik. NULL ile yapılan çağrıların yerelleri kullanılmadan silinir.
  • Zaman O(n), bellek O(h). #define MAX(a,b) ((a) > (b) ? (a) : (b))
int derinlik(agac_gost L) {    /* tek satır */
  return !L ? 0 : MAX(derinlik(L->solcocuk),
                      derinlik(L->sagcocuk)) + 1;
}

Dikkat: MAX makrosu argümanını iki kez değerlendirir; bu tek satırlıkta özyineli çağrılar iki kez yapılır → üstel süre! Makro yerine max() işlevi kullanın (sınav çözümündeki gibi).

Silme

İkili arama ağacından öğe silme

  • Silerken ağacın ikili arama ağacı özelliği bozulmamalı.
  • Çocuksuz (yaprak): babanın ilgili göstergesi NULL yapılır.
  • Tek çocuklu: babanın göstergesi silinenin tek çocuğunu gösterir.
  • İki çocuklu: farklı yöntemler var; örnek ağaçtan 60'ı silelim.

Örnek ağaç: 40, 20, 60, 10, 30, 50, 70, 42, 55, 65, 73, 52, 57, 66, 56 sırasıyla eklenmiştir (derinlik 6).

Silme

1. yöntem: sol alt ağacın en büyüğü

Sol alt ağaçtaki en büyük değer: sol alt ağaçta sağ işaret alanları üzerinden ilerlenir; sağ çocuğu olmayan öğe (57) en büyüktür.

Bu öğenin bir sol alt ağacı olabilir (57'nin 56'sı). Bu sol çocuk, taşınacak öğenin atasının sağ bağına aktarılmalı (55 → 56).

İkinci yol: 60 free edilmez; veri alanına 57 yazılır, yalnızca 55'in sağ bağı 56'ya günlenir → 1 bağ. Birinci yol (düğümü taşımak) 4 bağ ister: 40→57, 55→56, 57.sol→50, 57.sağ→70.

Silme · Kodu adım adım çalıştır

sil(60, &L): iki çocuklu düğüm

p kökü, bag kök göstergesinin adresini tutar: silinecek düğüme giden bağı değiştirebilmek için.

60 > 40 → bag = &40->sagcocuk, p = 60.

60 bulundu ve iki çocuğu var (50, 70) → sol alt ağacın en büyüğü aranır.

b = &60->solcocuk → *b = 50.

*b'nin sağı var → b = &50->sagcocuk, *b = 55.

*b'nin sağı var → b = &55->sagcocuk, *b = 57.

57'nin sağ çocuğu yok: sol alt ağacın en büyüğü 57.

60'ın veri alanına 57 yazılır (düğüm taşınmaz, 1. yöntemin 2. yolu).

Artık silinecek olan eski 57 düğümü; bag = &55->sagcocuk.

*bag = 57'nin tek çocuğu (56): 55'in sağ bağı artık 56'yı gösterir.

Eski düğüm free edilir. Ağaç yine ikili arama ağacı; derinlik 6 → 5.

void sil(int x, agac_gost *L) {
  agac_gost p = *L, *bag = L;  // bag: p'ye giden
  while (p && p->veri != x) {  // x'i ara
    bag = (x < p->veri) ? &p->solcocuk
                        : &p->sagcocuk;
    p = *bag;
  }
  if (!p) return;              // x yok
  if (p->solcocuk && p->sagcocuk) {  // 2 çocuk
    agac_gost *b = &p->solcocuk;     // sol alt
    while ((*b)->sagcocuk)           // ağacın en
      b = &(*b)->sagcocuk;           // büyüğü
    p->veri = (*b)->veri;      // veriyi taşı
    bag = b;  p = *b;          // onu sileceğiz
  }
  *bag = p->solcocuk ? p->solcocuk : p->sagcocuk;
  free(p);
}

Silme

Dört yöntem ve derinliğe etkisi

1. yöntem: 57 yukarı, 56 55'in sağına. Derinlik 5'e iner.

2. yöntem: sağ alt ağacın en küçüğü 65 taşınır; 65'in sağ çocuğu 66, 70'in soluna bağlanır. Derinlik 6.

3. yöntem: silinenin yerine sağ çocuğu (70) kayar; 50 alt ağacı, 70 alt ağacının en küçüğünün (65) soluna asılır. Derinlik 7.

4. yöntem: yerine sol çocuğu (50) kayar; 70 alt ağacı, 50 alt ağacının en büyüğünün (57) sağına asılır. Derinlik 7 (40-50-55-57-70-65-66 yolu 7 düğümdür).

Hocadan “Sildiğimiz öğenin kökü olduğu ağacın olabildiğince dengeli olmasını sağlayacak şekilde silmeliyiz.”

Dengeli Ağaçlar

AVL ağacı (Adelson-Velski ve Landis, 1962)

  • Her düğümde denge faktörü = yük(sol) − yük(sağ) ∈ {−1, 0, +1}.
  • Yükseklik en çok ≈ 1,44 lg(n+2): arama, ekleme, silme O(lg n).
  • Ekleme sıradan BST eklemesiyle yapılır; sonra eklenen yoldan köke doğru denge faktörleri güncellenir.
  • Faktörü ±2 olan ilk ata bulunur; yeni düğümün o atanın hangi torununda olduğuna göre 4 durum: LL, RR, LR, RL.
  • Eklemede tek (LL/RR) ya da çift (LR/RL) döndürme dengeyi yeniden kurar.
typedef struct avl *avl_gost;
struct avl {
    int      veri;
    int      yuk;        /* alt ağaç yüksekliği */
    avl_gost sol, sag;
};
int yuk(avl_gost t) { return t ? t->yuk : 0; }
int denge(avl_gost t) {
    return yuk(t->sol) - yuk(t->sag);
}

Dengeli Ağaçlar

Tek döndürme: LL ve RR

LL: yeni düğüm z'nin sol çocuğunun (y) sol alt ağacına girdi, z'nin faktörü +2. z sağa döndürülür: y yukarı çıkar, y'nin sağ alt ağacı T3 z'nin soluna geçer. Sıra korunur: T1 x T2 y T3 z T4.

RR ayna durumdur: z sola döndürülür; y'nin sol alt ağacı (T2) z'nin sağına geçer. Her iki durumda alt ağacın yüksekliği eklemeden önceki değerine döner.

Dengeli Ağaçlar

Çift döndürme: LR ve RL

LR: yeni düğüm z'nin sol çocuğunun (y) sağ alt ağacında. Tek sağa döndürme işe yaramaz; önce y sola döndürülür → LL biçimi.

Sonra z sağa döndürülür: torun x iki atasının üstüne çıkar. RL bunun aynasıdır: önce sağ çocuk sağa, sonra z sola.

Dengeli Ağaçlar · Kodu adım adım çalıştır

sag_dondur(): LL durumunda iki gösterge

5 eklendi: 30'un faktörü yük(20)=3 − yük(40)=1 = +2, sol-sol ağır → LL: sag_dondur(30).

k1 = k2->sol = 20: yeni kök olacak düğüm.

k2->sol = k1->sag: 25, 30'un soluna geçer (20 < 25 < 30, sıra korunur). 25'e şimdilik iki gösterge var.

k1->sag = k2: 30, 20'nin sağ çocuğu olur. Bağlar bitti; çizimi düzeltelim →

Yükseklikler aşağıdan yukarı: önce k2 (30): 1 + MAX(1, 1) = 2.

Sonra k1 (20): 1 + MAX(yük(10)=2, 2) = 3. Alt ağacın yüksekliği eklemeden önceki gibi 3.

Yeni kök k1 döner; çağıran, babanın göstergesini buna bağlar. Yalnızca 2 gösterge değişti: O(1).

avl_gost sag_dondur(avl_gost k2) {  // LL
  avl_gost k1 = k2->sol;
  k2->sol = k1->sag;
  k1->sag = k2;
  k2->yuk = 1 + MAX(yuk(k2->sol), yuk(k2->sag));
  k1->yuk = 1 + MAX(yuk(k1->sol), k2->yuk);
  return k1;                       // yeni kök
}

Dengeli Ağaçlar

AVL ekleme: BST eklemesi + dönüşte denge

avl_gost avl_ekle(avl_gost t, int x) {
  if (!t) return yeni_avl(x);              /* malloc, yuk = 1        */
  if (x < t->veri)      t->sol = avl_ekle(t->sol, x);
  else if (x > t->veri) t->sag = avl_ekle(t->sag, x);
  else return t;                           /* tekrar eden değer yok  */
  t->yuk = 1 + MAX(yuk(t->sol), yuk(t->sag));
  int d = denge(t);
  if (d >  1 && x < t->sol->veri) return sag_dondur(t);            /* LL */
  if (d < -1 && x > t->sag->veri) return sol_dondur(t);            /* RR */
  if (d >  1) { t->sol = sol_dondur(t->sol); return sag_dondur(t); } /* LR */
  if (d < -1) { t->sag = sag_dondur(t->sag); return sol_dondur(t); } /* RL */
  return t;
}
  • Özyinelemeden dönerken her ata güncellenir; eklemede en çok bir (tek ya da çift) döndürme yeter.
  • Kullanım: kok = avl_ekle(kok, x); — yeni kök döndüğü için *L gerekmez. Silme de benzer ama O(lg n) döndürme gerekebilir.

Dengeli Ağaçlar

Kısa bakış: kırmızı-siyah ağaç ve B-ağacı

Kırmızı-siyah ağaç (CLRS 13)
  • Her düğüm kırmızı ya da siyah; kök ve NULL yapraklar siyah.
  • Kırmızı düğümün çocukları siyah.
  • Her düğümden NULL'lara giden her yolda aynı sayıda siyah düğüm.
  • Sonuç: yükseklik ≤ 2 lg(n+1); ekleme/silmede en çok 2–3 döndürme + renk değişimi.
  • C++ std::map, Java TreeMap, Linux çekirdeği.
B-ağacı (Bayer–McCreight 1972)
  • m yollu dengeli arama ağacı: düğüm başına ⌈m/2⌉−1 … m−1 anahtar.
  • Tüm yapraklar aynı düzeyde.
  • Dolan düğüm ortadaki anahtarı babaya çıkararak bölünür; ağaç kökten büyür.
  • Bir düğüm = bir disk bloğu → çok az disk erişimi: veritabanı dizinleri, dosya sistemleri (B+ ağacı).

Sınav Soruları

Sınav sorusu: bir öğenin ağırlığı

Değerlerin tekrarlı olmadığı bir ikili ağaçta x değerini içeren öğenin ağırlığı: “uç düğümlere kadar olan yolların en uzunu”. x yoksa ya da L = NULL ise 0. int AgirlikBul(agac_gost L, int x) yordamını yazınız. Global değişken kullanmayın.

Örnek çözüm
int AgirlikBul(agac_gost L, int x) {
  /* agacta_ara: x'i içeren öğe ya da NULL */
  agac_gost agacta_ara(agac_gost L, int x);
  int derinlik(agac_gost L);
  return derinlik(agacta_ara(L, x));
}
agac_gost agacta_ara(agac_gost L, int x) {
  if (!L) return NULL;
  if (L->veri == x) return L;
  agac_gost T = agacta_ara(L->solcocuk, x);
  return T ? T : agacta_ara(L->sagcocuk, x);
}
int derinlik(agac_gost L) {
  int max(int a, int b);  /* a,b'den küçük olmayan */
  return L ? max(derinlik(L->solcocuk),
                 derinlik(L->sagcocuk)) + 1 : 0;
}

Tasarım: iki iyi tanımlı yordamın bileşimi; derinlik(NULL) = 0 sayesinde “bulunamadı” ayrıca ele alınmaz.

int AgirlikBul(oge_gost L, int x) {

      AgirlikBul(L->solcocuk, x))

Ağaç: kök 2, sol 10, sağ 20. i) x = 20 ve x = 30 için kaç çağrı? ii) En kötü durum için özyineli ilişkiyi yazıp çözünüz.

Çözüm

i) x = 20: 14, x = 30: 21. Her yaprak çağrısı 1 + 4 NULL çağrısı = 5 çağrı yapar; x = 30'da kök 1 + 4·5 = 21.

ii) x ağaçta yoksa her çağrı her alt ağacı iki kez çağırır. Çarpık ağaçta T(n) = 2T(n−1) + c → Θ(2n); dengeli ağaçta T(n) = 4T(n/2) + c → Θ(n2). Doğru tasarım (ağırlık bulma sorusunun çözümü) O(n)'dir.

Tanım

Sol alt ağaç küçük, sağ büyük, değerler tek; kök ortada = sıralı.

Ekleme
