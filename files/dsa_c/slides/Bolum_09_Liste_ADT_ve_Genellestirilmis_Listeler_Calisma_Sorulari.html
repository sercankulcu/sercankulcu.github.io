Soru 1: Diziden Silme

DiziListe L = [5, 3, 8, 6] (n = 4) için dizi_sil(&L, 1, &x) çağrılıyor. Sonunda x, liste ve kaydırma döngüsündeki atama sayısı nedir?

C: Silinen a[1] = 3'tür. Döngü k = 1 ve k = 2 için çalışır (k < n − 1 = 3): a[1] = a[2], a[2] = a[3]. n 3'e iner; a[3]'te eski 6 dursa da artık listenin parçası değildir (D bunu sayar). Kaydırma n − 1 − i kadardır; baştan silmede O(n).

Soru 2: Konum n'e Ekleme

Bağlı listede L = 4 → 7 → 2 (n = 3). bl_ekle(&L, 3, 9) ve ardından bl_ekle(&L, 5, 1) çağrılıyor. Sonuç nedir?

B: Geçerli konum 0 ≤ i ≤ n'dir; i = n sona eklemektir: 4 → 7 → 2 → 9 (n = 4). İkinci çağrıda 5 > n = 4 → false. Konum i, yeni öğenin ekleme sonrası indisidir; D bunu “i. öğeden önce”yle karıştırır.

Soru 3: İşaretçiye İşaretçiyle Ekleme

L = 4 → 7 → 2 listesinde bl_ekle(&L, 2, 6) çağrılıyor. pp hangi bağları gösterir, hangi işaretçi değişir?

pp = &L->bas: pp, değiştirilebilecek ilk bağın (baş işaretçisinin) adresini tutar.

Döngü: pp = &(*pp)->bag → 4'ün bag alanı.

pp → 7'nin bag alanı. Koşul (i-- > 0) artık yanlış: döngü biter.

Yeni düğüm ayrılır; NULL denetimi geçilir.

yeni->bag = *pp: yeni düğüm, pp'nin gösterdiği bağın gösterdiğini (2) gösterir.

*pp = yeni: 7'nin bağı artık 6'yı gösterir. Baş ve ara ekleme aynı satırla yapılır; maliyet O(i).

bool bl_ekle(BListe *L, int i, int x) {
  dugum_gost *pp = &L->bas, yeni;
  if (i < 0 || i > L->n) return false;
  while (i-- > 0)
    pp = &(*pp)->bag;
  yeni = malloc(sizeof *yeni);
  if (yeni == NULL) return false;
  yeni->deger = x;
  yeni->bag = *pp;
  *pp = yeni;
  L->n++;
  return true;
}

Soru 4: Dizi mi Bağ mı?

Liste gerçeklemeleri hakkındaki ifadelerden hangisi yanlıştır?

C: İkili arama ortadaki öğeye O(1)'de erişmeyi gerektirir; bağlı listede ortaya yürümek O(n)'dir, sıralı bile olsa arama O(n) kalır. Bu yüzden sık arama yapılan sıralı veri için dizi seçilir.

Soru 5: Baş, Kuyruk ve Derinlik

L = ((a), b, (c, (d))) genelleştirilmiş listesi için uzunluk, baş, kuyruk ve derinlik hangisidir?

A: Üst düzeyde üç öğe vardır: (a), b, (c, (d)). Baş ilk öğedir ve burada bir listedir: (a). Kuyruk her zaman listedir: ilk öğe dışındakiler. En derin yol (d)'ye iner: 1 + 1 + 1 = 3 (programla doğrulandı).

Soru 6: Bellek Görünümü

L = (a, (), (b, (c))) listesinin bellek görünümünü [isaret | veri/L_bag | bag] öğeleriyle çizin. Kaç öğe ayrılır, kaçı T (alt liste) öğesidir, derinlik kaçtır?

Cevabı göster
  • Toplam 6 öğe: üst düzeyde 3 (a, (), (b,(c))), altında 2 (b, (c)), en altta 1 (c).
  • 3 T öğesi; () için T öğesi vardır ama onun L_bag alanı NULL olur. Boş alt liste ile boş liste (NULL) farklı şeylerdir.
  • Derinlik 3: (c)'ye inen yol. Liste programla kurulup sayıldı.

Soru 7: Doğrusal Formda Yazdırma

dogrusal_yaz, L = (a, (), (b)) için çağrılıyor. Çağrı yığını ve çıktı nasıl ilerler?

İlk çağrı: düzeyin başında ( yazılır.

a atom: yazılır; bag var → virgül.

() bir T öğesi: alt liste için çağrı yapılır, L_bag NULL.

NULL ile çağrı: for hiç dönmez, yine ( ve ) yazılır: boş alt liste ().

Dönüş; sıradaki öğe var → virgül.

(b) bir T öğesi: alt listeye inilir.

İç çağrı ( yazar, b atomunu yazar; bag NULL → virgül yok.

İç düzey biter: ) yazılır, dönülür.

(b)'den sonra öğe yok: dış düzey de ) ile kapanır. Metin aynen geri üretildi.

void dogrusal_yaz(oge_gost L) {
  printf("(");
  for (; L; L = L->bag) {
    if (L->isaret) dogrusal_yaz(L->L_bag);
    else printf("%c", L->veri);
    if (L->bag) printf(",");
  }
  printf(")");
}

Soru 8: Eşitlik ve Çağrı Sayısı

esitmi(T, L) T = (a, b) ve L = (a, b, c) için çağrılıyor. Sonuç nedir ve esitmi toplam kaç kez çağrılır (ilk çağrı dahil)?

D: 1. çağrı a = a → bag'lerle 2. çağrı; b = b → 3. çağrı esitmi(NULL, öğe(c)). İkisi birden NULL değil, ikisi birden dolu da değil: FALSE. Uzunlukları farklı listeler, kısa olan bittiğinde ayrışır (sayaçla ölçüldü).

Soru 9: Sığ Kopya

Bir öğrenci kopyala'da alt liste satırını aşağıdaki gibi yazmıştır. L = (a, (b, c)) için kopya nasıl görünür? Sonra hem L hem kopyası bütün öğeleriyle serbest bırakılırsa ne olur?

if (!L->isaret) q->veri = L->veri;
else q->L_bag = L->L_bag;   /* hatalı */
q->bag = kopyala(L->bag);
Cevabı göster

Üst düzey öğeler (a ve T) yeni ayrılır, ama T öğesinin L_bag'i asıl listenin (b, c) alt listesini gösterir: alt liste iki liste arasında paylaşılır (sığ kopya). Programda kopyanın T öğesi asılla aynı adresi gösterdi.

  • Kopyada b'yi değiştirmek asıl listeyi de değiştirir.
  • İki liste ayrı ayrı bırakılırsa b ve c düğümleri iki kez free edilir: tanımsız davranış, çoğu zaman çökme.
  • Doğrusu: q->L_bag = kopyala(L->L_bag); (derin kopya) ya da paylaşım isteniyorsa referans sayma.

Soru 10: Paylaşımlı Listeyi Kopyalamak

A = (x, y) ve B = (A, A, ()) paylaşımlı listesi kuruluyor (B'nin ilk iki öğesi aynı A'yı gösteriyor). kopyala(B) kaç kez ogeal çağırır, kopyada paylaşım korunur mu?

D: B'nin üç öğesi (3) ve A her gösterildiği yerde ayrı kopyalanır: 2 × 2 = 4; toplam 7. Asılda 5 farklı öğe vardır; kopyada A'nın iki ayrı kopyası oluşur (programla doğrulandı). Paylaşımı korumak için eski adres → yeni adres tablosu tutulmalıdır.

Soru 11: Boş Alt Listelerle Derinlik

L = (a, (()), ((b)), c) için özyinelemeli derinlik(L) ne döndürür? derinlik toplam kaç kez çağrılır?

int derinlik(oge_gost L) {
  oge_gost p = L; int m = 0;
  if (!L) return 0;
  while (p) {
    if (p->isaret) {
      int n = derinlik(p->L_bag);
      if (m < n) m = n;
    }
    p = p->bag;
  }
  return m + 1;
}
Cevabı göster
  • (()) öğesi: içindeki liste bir T öğesi taşır, onun L_bag'i NULL → derinlik(NULL) = 0, o listenin derinliği 0 + 1 = 1.
  • ((b)) öğesi: (b)'nin derinliği 1, ((b))'ninki 2.
  • Üst düzey: 1 + max(1, 2) = 3.

Çağrılar: L, (()), NULL, ((b)), (b) → 5. Boş alt liste de bir düzey sayılır: (()) 1 derinliklidir, () ise 0. Sayaçla doğrulandı.

Soru 12: İç İçe Ters Çevirme

devrik_al(&L) L = (a, (b, (c)), d) listesini neye dönüştürür?

B: Her düzey ters çevrilir ve alt listeler de özyinelemeyle ters çevrilir: (b, (c)) → ((c), b); tek öğeli (c) aynı kalır. Üst düzey: (d, ((c), b), a). A yalnız üst düzeyi çevirir; malloc yapılmaz, yalnız bağlar değişir (programla doğrulandı).

Soru 13: Yerel Yığınla Derinlik

Yinelemeli derinlik_d, L = (a, ((b)), c) için çalıştırılıyor. Yığın ve sayaçlar nasıl değişir?

L boş değil: p = L, d = 1.

a atom: m = d = 1, kardeşe geçilir.

((b)) öğesi T1 ve alt listesi dolu: T1 yığına, alt listeye inilir, d = 2.

(b) öğesi T2: m = 2; T2 yığına, d = 3.

b atom: m = 3; bag NULL.

Düzey bitti: T2 yığından alınır, p = T2->bag = NULL, d = 2.

Bu düzey de bitti: T1 alınır, p = T1->bag = c, d = 1.

c atom: m değişmez; p = NULL.

p NULL ve yığın boş: m = 3 döner. Özyinelemeli sürümle aynı sonuç.

int derinlik_d(oge_gost L) {
  oge_gost yigit[100];
  int ust = 0, d = 1, m = 0;
  oge_gost p = L;
  if (!L) return 0;
  for (;;) {
    if (p == NULL) {          /* düzey bitti */
      if (ust == 0) return m;
      p = yigit[--ust]->bag;
      d--;
    } else {
      if (d > m) m = d;
      if (p->isaret && p->L_bag) {
        yigit[ust++] = p; p = p->L_bag; d++;
      } else p = p->bag;
    }
  }
}

Soru 14: Doğrusal Formdan Ağaca

Ağaç A(B(D,E(G)),C(F)) biçiminde yazılmıştır. Ağacı çizin; ağacın derecesini, yapraklarını ve G'nin atalarını yazın. Liste (A,(B,D,(E,G)),(C,F)) olarak tutulursa dolas_yaz ne yazar?

Cevabı göster
  • Derece 2 (A ve B ikişer çocuklu); yapraklar D, G, F; G'nin ataları A, B, E.
  • dolas_yaz atomları soldan sağa yazar: ABDEGCF, ağacın kök önde sırası (programla doğrulandı).
  • Doğrusal form ikili ağaçta sol/sağ ayrımını göstermez: C(F)'de F'nin sol mu sağ mı olduğu yazılamaz.

Soru 15: Referans Sayaçları

Başlık düğümlü listelerde A = (x, y), B = (A, A), C = (B, A) kuruluyor; her sayaç, listeyi gösteren adların ve T öğelerinin sayısıdır. liste_birak(&C) çağrısından sonra A ve B'nin sayaçları kaçtır?

A: Başta A'yı A adı, B'nin iki öğesi ve C'nin ikinci öğesi gösterir: 4; B'yi B adı ve C'nin ilk öğesi: 2; C: 1. C 0'a iner ve bırakılır; öğeleri B'yi 1'e, A'yı 3'e indirir. B adı hâlâ B'yi gösterdiği için B'nin öğelerine inilmez (C ile benzetimle doğrulandı).

Soru 16: Bütün Listeyi Bırakmak

Paylaşımsız ve özyinelemesiz bir genelleştirilmiş listenin bütün öğelerini (alt listeler dahil) serbest bırakan void serbest(oge_gost L) yordamını yazın. Bırakılan öğeye bir daha dokunulmamalıdır.

Cevabı göster 
void serbest(oge_gost L) {
  while (L) {
    oge_gost sonraki = L->bag;
    if (L->isaret)
      serbest(L->L_bag);
    free(L);
    L = sonraki;
  }
}
  • bag, öğe bırakılmadan önce saklanır; free'den sonra L->bag okumak sarkan işaretçi hatasıdır.
  • Alt liste önce bırakılır, sonra T öğesinin kendisi. Aynı düzey döngüyle gezildiği için yığın derinliği yalnız iç içelikle büyür.
  • (a,(b,(),(c,d)),((e))) için sayaçlı testte 10 malloc, 10 free.
