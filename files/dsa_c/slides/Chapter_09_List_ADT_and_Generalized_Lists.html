The List ADT

The List ADT: What It Does, with the How Hidden

typedef struct list List;               // opaque type

List  *list_create(void);
void   list_destroy(List *L);
int    list_length(const List *L);
bool   list_get(const List *L, int i, int *x);
bool   list_insert(List *L, int i, int x); // 0<=i<=n
bool   list_delete(List *L, int i, int *x); // 0<=i<n
int    list_find(const List *L, int x);   // -1 if absent
Linear list

L = (a0, a1, …, an−1), n ≥ 0; ai comes before ai+1.

Pre- / postcondition

list_insert(L, i, x): before, 0 ≤ i ≤ n; after, x is at position i, the length is n+1, and the old ai, …, an−1 have each moved one place right.

Opaque type

struct list is defined only in the .c file; client code can't tell whether it is an array or links, so swapping implementations is easy.

The List ADT

Array Implementation (Sequential Mapping)

#define CAPACITY 100
typedef struct {
    int a[CAPACITY];
    int n;                  // item count
} ArrayList;

bool array_delete(ArrayList *L, int i, int *x) {
    int k;
    if (i < 0 || i >= L->n) return false;
    *x = L->a[i];
    for (k = i; k < L->n - 1; k++)
        L->a[k] = L->a[k + 1];      // shift left
    L->n--;
    return true;
}
Access

The address of a[i] is computed: O(1).

Insert / delete

The items after i must shift: O(n) in the worst case (insert or delete at the front).

Capacity

A fixed array fills up; doubling a dynamic array with realloc gives O(1) insertion on average.

The List ADT · Run the code step by step

Code Trace: array_insert(&L, 1, 9)

List [4, 7, 2], n = 3; 9 is to be inserted at position 1 (0-based).

Check: not full, and 0 ≤ i ≤ n; we can insert.

k = 3: k > i → true, shift.

a[3] = a[2]: 2 moved one place right.

k = 2: k > i → true, shift.

a[2] = a[1]: 7 moved one place right.

k = 1: k > i → false, the loop ends.

a[i] = x: 9 is written into the freed slot.

n++: the list is [4, 9, 7, 2]. The number of shifts is n − i: O(n) in the worst case (i = 0).

bool array_insert(ArrayList *L, int i, int x) {
    int k;
    if (L->n == CAPACITY || i < 0 || i > L->n)
        return false;          // full/invalid
    for (k = L->n; k > i; k--)
        L->a[k] = L->a[k - 1];     // shift right
    L->a[i] = x;
    L->n++;
    return true;
}

The List ADT

Linked Implementation: a Pointer to a Pointer

typedef struct node *node_pointer;
struct node { int data; node_pointer link; };
typedef struct { node_pointer head; int n; } LinkedList;

bool ll_insert(LinkedList *L, int i, int x) {
    node_pointer *pp = &L->head, new_node;
    if (i < 0 || i > L->n) return false;
    while (i-- > 0)
        pp = &(*pp)->link;       // walk to link i
    new_node = malloc(sizeof *new_node);
    if (new_node == NULL) return false;
    new_node->data = x;
    new_node->link = *pp;
    *pp = new_node;              // head or middle: same
    L->n++;
    return true;
}
node_pointer *pp

The address of the link to change: first &L->head, then &prev->link. Inserting at the head stops being a special case.

Cost

Walking to the position is O(i); linking is O(1). No shifting, no capacity limit.

Length

If an n field is kept, list_length is O(1).

Generalized Lists

From Linear Lists to Generalized Lists

Linear list

A = (α0, …, αn−1): every element is an atom (arrays, singly linked lists).

Definition

If each αi may be an atom or a sublist, A is a generalized list. A is the list's name and n its length.

Head and tail

α0 is the head of the list and (α1, …, αn−1) its tail. The tail is always a list.

The LISP connection

Head/tail are LISP's car/cdr; LISP programs are themselves generalized lists.

ListLengthDescription
D = ()0empty list
A = (a, (b, c))2first element an atom, second the sublist (b, c); head(A) = a, tail(A) = ((b, c))
B = (A, A, ())3a shared sublist: the first two elements are the same A; the third is the empty list
C = (a, C)2a recursive list: it contains itself, C = (a, (a, (a, …)))

Generalized Lists

Example: a Multivariate Polynomial

typedef enum { VAR, PTR, NO } tag_t;
typedef struct pnode *poly_pointer;
struct pnode {
    tag_t tag;              // three kinds
    union {
        char var;           // VAR: variable name
        poly_pointer dlink; // PTR: coef is a list
        int coef;           // NO : integer coef
    };
    int exp;                // exponent
    poly_pointer link;
};
Three kinds of node

VAR: list header, the variable's name (exp = 0). PTR: the coefficient is a sublist. NO: the coefficient is an integer.

Grouping

P(x,y,z) is first grouped by z; each z-term's coefficient is a polynomial in y, and theirs are polynomials in x.

Node Structure and Memory Layout

Generalized Lists

Why Generalized Lists?

Compact

Hierarchical data such as a tree fits in the space of a one-line string: a kind of compression.

Natural hierarchy

File-system directories, popup menus, nested XML/JSON, LISP expressions.

Algorithm space

We move the data into a structure we know well; now every list routine is available.

Basic Routines

QUESTION: copy a List with No Sharing and No Recursion

list_pointer copy(list_pointer L) {
    list_pointer q = NULL;
    if (L) {                    // L not NULL?
        q = get_node();         // get a node
        q->tag = L->tag;
        if (!L->tag) q->data = L->data; // atom
        else q->dlink = copy(L->dlink);
        q->link = copy(L->link);
    }
    return q;
}
Structure

For each node, get a new node and copy the tag; for an atom copy the value, otherwise link in a copy of the sublist; then copy the rest.

Limitation

The routine is correct only for unshared lists; a shared sublist is copied separately everywhere it is referenced.

get_node(): a helper doing malloc(sizeof *p) plus a NULL check (it stops the program when memory runs out).

QUESTION: Are Two Lists (No Sharing, No Recursion) equal?

boolean equal(list_pointer T, list_pointer L) {
    boolean x = TRUE;
    if (!T && !L) return TRUE;
    if (T && L && T->tag == L->tag) {
        if (!T->tag)             // atoms?
            x = (T->data == L->data) ? TRUE : FALSE;
        else                    // sublists
            x = equal(T->dlink, L->dlink);
        if (x == TRUE) return equal(T->link, L->link);
    }
    return FALSE;
}
Logic

Equal if both end together. If the tags match: compare values for atoms and recurse for sublists; then compare the rest.

Limitation

On recursive lists (C = (a,C)) the calls go on forever.

Instructor “This isn't masterful code. Better code can be written. And recursive lists can't be compared because of the infinite calls.”

Basic Routines

A Better Version, and Shared Lists

bool same(list_pointer T, list_pointer L) {
    if (T == L) return true;        // same node/both NULL
    if (!T || !L || T->tag != L->tag) return false;
    if (T->tag ? !same(T->dlink, L->dlink)
               : T->data != L->data)
        return false;
    return same(T->link, L->link);
}
The T == L shortcut

If both are NULL or point to the same (shared) sublist, return TRUE without descending into it.

QUESTION: shared lists

The same routine also gives the right answer for non-recursive (acyclic) shared lists; the shortcut avoids walking common sublists again.

Depth and Inversion

QUESTION: The depth of a List, Recursively

int depth(list_pointer L) {
    list_pointer p = L;  int m = 0; // m: the max
    if (!L) return 0;
    while (p) {
        if (p->tag) {
            int n = depth(p->dlink);
            if (m < n) m = n;
        }
        p = p->link;
    }
    return m + 1;
}
Definition

depth(()) = 0; otherwise 1 + the largest depth among the sublists. Atoms add no depth.

Examples

(a, b) → 1 · (a, (b, c)) → 2 · (a, (b, (c))) → 3 · (()) → 1.

Cost

Each node is visited once: O(n); the call stack grows at most as deep as the list.

QUESTION: depth, Iteratively (a Student Solution)

int depth( tree_pointer L ){
    tree_pointer pop(); void push(tree_pointer);
    int max = 0;
    for( int current = 1, p = L ; p ; p->link ){
        if( p->tag ){ // enter the sublist
            push(p);
            p = p -> dlink;
            current++;
        }
        if( !p->link ){   // end of list, go up
            p = pop();
            if( max < current ) max = current;
            current--;
        }
    }
    return max;
}
Compiling / the loop

int current = 1, p = L makes p an int; the update p->link is not an assignment → an infinite loop.

Edge cases

It dereferences NULL on an empty sublist, pops an empty stack, and never moves on to T's sibling.

Instructor “This isn't going to be written as a loop that tracks current and max. That's what a first-year student writes. … And global variables are forbidden!”

Depth and Inversion

Iterative depth with a Local Stack

int iter_depth(list_pointer L) {
    list_pointer stack[100];   // local stack (depth<100)
    int top = 0, d = 1, m = 0;
    list_pointer p = L;
    if (!L) return 0;
    for (;;) {
        if (p == NULL) {             // level done
            if (top == 0) return m;
            p = stack[--top]->link;  // the node after T
            d--;
        } else {
            if (d > m) m = d;
            if (p->tag && p->dlink) {
                stack[top++] = p;    // descend
                p = p->dlink;
                d++;
            } else p = p->link;
        }
    }
}
Method

When descending into a sublist, push its T node; when the level ends, pop it and move on to its sibling.

Rules

No globals: the stack and counters are local. The empty sublist and the empty list are handled separately.

Verification

Checked by simulation to match the recursive version on six sample lists.

Depth and Inversion

QUESTION: invert an Unshared List — L = (a,(b,c)) → ((c,b),a)

void invert(list_pointer *L) {
    list_pointer r, p = *L, q = NULL;
    while (p) {
        if (p->tag)                 // not an atom
            invert(&p->dlink);
        r = q;
        q = p;
        p = p->link;
        q->link = r;
    }
    *L = q;
}
List inversion + 2 lines

The three pointers of the singly linked list_invert routine, unchanged; the addition: if the node is a sublist, invert it first. Use: mirroring an image.

Why &p->dlink?

The sublist's head changes; the T node's dlink field is updated by the inner call's *L = q line before the call returns.

Instructor “If we didn't solve it this way, it would be brute force. That inverts it too, but by bulldozing everything in its path.”

Depth and Inversion · Run the code step by step

Code Trace: invert(&L), (a,(b,c)) → ((c,b),a)

p = *L → &node(a), q = NULL.

r = q; q = p; p = p->link; q->link = r; → a's link is reversed.

The node is a sublist: invert it first (via the address &p->dlink).

p = *L → &node(b), q = NULL.

r = q; q = p; p = p->link; q->link = r; → b's link is reversed.

r = q; q = p; p = p->link; q->link = r; → c's link is reversed.

p == NULL: this level is done.

*L = q: c is this level's new head.

Back from the sublist: the T node's dlink already points to the new head.

r = q; q = p; p = p->link; q->link = r; → (c,b)'s link is reversed.

p == NULL: this level is done.

*L = q: (c,b) is this level's new head.

Trees and Sharing

Drawback: No Left/right Distinction

All three trees have the same linear form, A(B(C(D(E),G(I)))): there is no way to write whether B is a left or a right child.

The problem

For a general tree the order of children is enough, but in a binary tree the distinction between left and right children is lost.

The fix

Store L/R information with each node (or write a special symbol for an empty child): A(B(,C(…))).

Shared Lists and Reference Counting

// header ref: how many pointers point to this list
void list_free(list_pointer *L) {
    list_pointer p, q;
    if (*L == NULL) return;
    if (--(*L)->ref > 0) {      // still in use
        *L = NULL; return;
    }
    p = (*L)->link;             // first real node
    free(*L);
    while (p) {
        if (p->tag) list_free(&p->dlink);
        q = p; p = p->link; free(q);
    }
    *L = NULL;
}
Header node

Every list starts with a header node; ref is the number of pointers pointing to it.

The release rule

A list is not freed until its count reaches 0; when it does, its nodes and sublists are released by the same rule.

Horowitz–Sahni, Section 4.9 (header nodes with reference counts).

Trees and Sharing

Reference Counting Step by Step: B = (A, A, ())

Each list starts with a header node; ref is the number of pointers to it. A is pointed to by the name A and by two of B's elements: 3.

list_free(&B): B's count goes 1 → 0, and B's nodes are released one by one.

B's two T nodes call list_free on A: 3 → 2 → 1. A is still in use, so it is not freed.

Then list_free(&A): 1 → 0, and A is freed. Sharing handled safely.

The same idea works for copying: a shared sublist isn't copied again; its count is incremented.

The Limits of Reference Counting, and Garbage Collection

The cycle problem

C = (a, C): C points to itself, so its count never reaches 0; even if the name C is deleted, the list stays in memory (a leak).

Mark and sweep

(1) Every node reachable from the root pointers (variables) is marked; (2) memory is scanned and unmarked nodes are swept (returned to avail).

The cost

The program pauses while the collector runs, and the mark bit needs space. LISP, Java, and Python use variants of this idea.

In C

No automatic garbage collection: copying, sharing, and freeing are the programmer's responsibility.

Exam Question

Question. A field int count has been added to each node. Write a recursive routine that stores, in the count of every node whose tag is TRUE, the number of nodes below it, and returns the total number of nodes.
Sample solution
int count_nodes(list_pointer L) {
    int total = 0;              // an empty list has 0 nodes
    for (; L; L = L->link) {
        if (L->tag) {           // is there a sublist?
            L->count = count_nodes(L->dlink);
            total += L->count;  // count the sublist's nodes too
        }
        total++;                // the current node
    }
    return total;
}

Example: (a,(b,c)) → the T node's count is 2 and the return value is 4 (the T node counts too). Checked by simulation.

Solution
void print_linear(list_pointer L) {
    printf("(");
    for (; L; L = L->link) {
        if (L->tag) print_linear(L->dlink);
        else printf("%c", L->data);
        if (L->link) printf(",");
    }
    printf(")");
}

Common Mistakes

1Treating a shared list as unshared: copying it, or freeing it twice.
2Calling copy/equality on a recursive list (C = (a,C)): infinite recursion.
3Forgetting the braces on ifs and recursing on NULL too (print_atoms).
4Passing the list by value to a routine that changes its head (inversion needs list_pointer *L).
5Confusing the empty sublist () with the empty list NULL: the T node exists, its dlink is NULL.
6Counting depth in a global variable; the routine breaks once it becomes part of another component.

Chapter Summary

The list ADT

The contract is fixed; the implementation can change: arrays give fast access, links give fast insertion and deletion.

Generalized lists

A node is an atom or a sublist: [tag | data/dlink | link].

The recursive pattern

Process an atom, recurse into a sublist, then continue along link.

Depth and inversion

The recursive versions are short and correct; the iterative ones need a local stack.

Trees

A one-line linear form; for binary trees, left/right information must be added.

Sharing

Copying and freeing have pitfalls; reference counting fails on cycles, so garbage collection is needed.
