C ile Gerçekleştirim

Dizi tabanlı yığın

#define KAPASITE 64
typedef struct {
    int veri[KAPASITE];
    int ust;  /* boşken -1 */
} Yigin;
Tür tanımı veri yapısının bellekteki biçimini; yordamlar ise bu yapı üzerindeki davranışı kurar.

Temel İşlemler

push ve pop

bool push(Yigin *y, int x) {
    if (y->ust == KAPASITE - 1) return false;
    y->veri[++y->ust] = x;
    return true;
}

bool pop(Yigin *y, int *sonuc) {
    if (y->ust < 0) return false;
    *sonuc = y->veri[y->ust--];
    return true;
}
Kod örnekleri C99/C11 uyumlu olacak biçimde küçük ve tek sorumluluklu tutulmuştur.

Cevapları göster
  1. En son eklenen öğe ilk çıkarılır.
  2. Tanıma göre değişebilir; burada boş değer -1 olduğu için önce artırılır.
  3. Yığının üstündeki son açan parantezle.
  4. Her çağrı dönüş adresi ve yerel değişkenlerle çağrı yığınına bir çerçeve ekler.
  5. Başta; böylece O(1) kalır.
