Giriş

Öğrenme Çıktıları

LIFO'yu tanımlamak

Yığıtı S = {a0, …, an−1} listesi olarak tanımlayıp alt ve üst öğeyi göstermek.

Dizi ile gerçekleştirmek

top göstergesiyle push/pop yazmak; taşma (overflow) ve alt taşmayı (underflow) denetlemek.

Bağlaçlı yığıt kurmak

Düğüm ayırıp (malloc) bağlamak, çıkarılan düğümü free ile bırakmak.

Çağrı yığınını okumak

Özyinelemeli bir çağrıda etkinleştirme çerçevelerinin (activation frame) nasıl üst üste bindiğini izlemek.

Tasarım kararı vermek

Sabit dizi, büyüyen dizi ve bağlaçlı liste arasında maliyete göre seçim yapmak.

Çoklu yığıtı yönetmek

Tek bir bellek dizisinde n yığıtı top[i] ve sinir[i] ile paylaştırmak.

Yığıt ADT

Yığıt (Stack): Son Giren İlk Çıkar

Yığıt, ekleme (insertion) ve silmenin (deletion) yalnızca bir uçtan yapıldığı sıralı bir listedir: S = {a0, a1, …, an−1} için a0 alt, an−1 üst (top) öğedir. Son eklenen ilk çıkar: LIFO (last-in-first-out).

Tek arabalık çıkmaz sokağa park eden araçlar: son giren (D) ilk çıkmak zorunda.

Türkçe kaynaklarda yığıt ve yığın ikisi de kullanılır; ders notları “yığıt” der. (“Yığın” sözcüğü heap için de kullanıldığından bu sunumda “yığıt” tercih edildi.)

Yığıt ADT

Yığıtın Büyümesi ve Küçülmesi

A eklendi → üst öğe artık A; top = 0.

B eklendi → üst öğe artık B; top = 1.

C eklendi → üst öğe artık C; top = 2.

D eklendi → üst öğe artık D; top = 3.

E eklendi → üst öğe artık E; top = 4.

Silme yalnız üstten: ilk alınan öğe en son eklenen E olur. Üst öğe yeniden D, top = 3.

  • Ekleme sırası: A, B, C, D, E.
  • Silme sırası (tümü çıkarılsaydı): E, D, C, B, A: tam ters.
  • Ortada bir öğeye (ör. B) erişmek için üstündekilerin hepsi alınmalı.
  • Bu kısıt bir kusur değil, bir sözleşmedir: “en son açılan iş ilk kapanır”.

Yığıt ADT

Yığıtın Kullanıldığı Yerler

Çağrı yığını

Her fonksiyon çağrısı dönüş adresi ve yerel değişkenleriyle bir çerçeve iter (bu bölüm).

İfade değerlendirme

Derleyiciler infix → postfix çevirisi ve postfix hesaplamada yığıt kullanır (Bölüm 15).

Geri izleme

Labirentte çıkmaza girince son yol ayrımına dön (Bölüm 15).

Parantez denetimi

Her kapanan, en son açılanla eşleşmeli (Bölüm 15).

Geri al (undo)

Düzenleyici her işlemi yığıta koyar; Ctrl+Z en sonuncuyu geri alır.

Önce derinliğine arama

DFS, ziyaret edilecek düğümleri yığıtta tutar (Bölüm 11).

Yığıt ADT

Dene: push ve pop Yalnız Üstte

Dört kez push, ardından pop: çıkan sıra girenin tersidir. Boş yığıtta pop alt taşmadır.

Dizi ile Yığıt

Dizi ile Yığıt: top Göstergesi

Boş: top < 0

Boş yığıtta top = −1. Bu hâlde öğe almak alt taşma (underflow) hatasıdır.

Dolu: top ≥ MAX_STACK_SIZE − 1

Bu hâlde öğe eklemek taşma (overflow) hatasıdır.

Öğe sayısı = top + 1

İkisini karıştırmak klasik “bir eksik/bir fazla” hatasıdır.

Ne olur?

C dizi sınırını denetlemez: denetimsiz bir push komşu belleğin üzerine yazar.

Dizi ile Yığıt

Ders Notlarındaki C Tanımları

#include <stdio.h>
#include <stdlib.h>
#define MAX_STACK_SIZE 101

typedef struct {
    int deger;
    /* diğer alanlar */
} element;

element yigit[MAX_STACK_SIZE];

void yigit_dolu(void) {
    printf("Yigit dolu!!!\n"); exit(-1);
}
void yigit_bos(void) {
    printf("Yigit bos!!!\n"); exit(-2);
}
  • element: yığıtta saklanacak kayıt; şimdilik tek alan deger.
  • Yığıt küresel (global) bir dizi; top ise çağırandan adresle gelir.
  • Hata yordamları mesaj basıp programı exit ile sonlandırır.
  • Not: ders notundaki "Yigit bos!!!\\n" dizgesinde çift ters bölü vardı; \n olarak düzeltildi.
Hocadan “Böyle yaparsanız sıfır alırsınız, hatta eksi not alırsınız. Burda bu konuyu kaç kere anlattık değil mi?”

Dizi ile Yığıt

Ekleme ve Silme Yordamları

void yigit_ekle(int *top, element item) {
    if (*top >= MAX_STACK_SIZE - 1)  /* yer var mı? */
        yigit_dolu();         /* uyar ve çık */
    yigit[++*top] = item;     /* önce göstergeyi artır */
}                             /* sonra öğeyi yerleştir */

element yigit_al(int *top) {
    if (*top < 0)
        yigit_bos();          /* boşsa uyar ve çık */
    return yigit[(*top)--];   /* döndür, sonra azalt */
}
yigit[++*top]

Önce *top bir artar, sonra yeni indise yazılır: boş yığıtta −1 → 0.

yigit[(*top)--]

Önce eski indisteki öğe okunur, sonra *top azalır. Parantez şart: *top-- göstergenin kendisini azaltırdı.

Hocadan “Normal şartlarda yordamın formal parametre listesinde “*parametre” olarak gözüken değişken, yordam içinde de “*parametre” olarak kullanılmalıdır.”

Dizi ile Yığıt

C'de Öncelik Tuzağı: * ile ++/--

İfadeC bunu nasıl okurSonuç
++*top++(*top): gösterilen tamsayıyı artırDoğru (push)
(*top)--gösterilen tamsayıyı kullan, sonra azaltDoğru (pop)
*top--*(top--): göstergeyi azalt, eski adresi okuHatalı: top değişmez
*top++*(top++): göstergeyi ilerletHatalı
Kural

Son ek ++/--, tekli *'dan daha önceliklidir; ön ek ++ ile * aynı düzeydedir ve sağdan sola bağlanır.

Neden adresle?

top çağıranın değişkenidir; yordam onu değiştirebilsin diye &top geçirilir (C'de değerle çağrı vardır).

Kod İzleme: Ders Notlarındaki Yığıt

main'de top = −1 (boş). Sırayla ekle A, B, C; al; ekle D, E, F. MAX_STACK_SIZE = 4.

-1 ≥ 3? Hayır, yer var.

++*top → top = 0, sonra yigit[0] = A.

0 ≥ 3? Hayır, yer var.

++*top → top = 1, sonra yigit[1] = B.

1 ≥ 3? Hayır, yer var.

++*top → top = 2, sonra yigit[2] = C.

2 < 0? Hayır, yığıt boş değil.

yigit[2] = C döndürülür, ardından top = 1. Hücrede eski değer durur ama artık yığıtın parçası değildir.

1 ≥ 3? Hayır, yer var.

++*top → top = 2, sonra yigit[2] = D.

2 ≥ 3? Hayır, yer var.

++*top → top = 3, sonra yigit[3] = E.

3 ≥ 3? Evet: yer yok!

yigit_dolu() mesajı basar ve exit(-1) ile tüm programı bitirir. Kütüphane kodunda bu kaba bir tepkidir; birazdan bool döndüren sürümü göreceğiz.

void yigit_ekle(int *top, element item) {
  if (*top >= MAX_STACK_SIZE - 1)
    yigit_dolu();  /* "Yigit dolu!!!", exit */
  yigit[++*top] = item;
}
element yigit_al(int *top) {
  if (*top < 0)
    yigit_bos();   /* "Yigit bos!!!", exit */
  return yigit[(*top)--];
}

Daha İyi Tasarım: Yığıt Bir Nesne Gibi

#include <stdbool.h>
#define KAP 100

typedef struct {
    int veri[KAP];
    int ust;               /* boşken -1 */
} Yigit;

void yigit_baslat(Yigit *y) { y->ust = -1; }
bool yigit_bos(const Yigit *y)  { return y->ust < 0; }
bool yigit_dolu(const Yigit *y) { return y->ust == KAP - 1; }
int  yigit_boyut(const Yigit *y) { return y->ust + 1; }
bool yigit_ust(const Yigit *y, int *x) {
    if (yigit_bos(y)) return false;
    *x = y->veri[y->ust];  return true;
}
  • Yığıt ve ust aynı yapıda: iki yığıt aynı programda karışmadan yaşar.
  • Küresel değişken yok; her yordam yığıtı parametre olarak alır.
  • Hata durumunda exit yerine false döner; kararı çağıran verir.
Hocadan “Global değişken kullanmak yasak! İçinde yığıt kullan, kuyruk kullan, local değişken kullan, ne istersen kullan. Ama global değişken yok!”

Dizi ile Yığıt · Kodu adım adım çalıştır

Kod İzleme: bool Döndüren push / pop

yigit_baslat(&y) sonrası ust = −1. Sırayla push 5, 8, 2, 9; sonra dört kez pop. KAP = 3.

-1 == 2? Hayır, yer var.

++y->ust → 0; veri[0] = 5; true döner.

0 == 2? Hayır, yer var.

++y->ust → 1; veri[1] = 8; true döner.

1 == 2? Hayır, yer var.

++y->ust → 2; veri[2] = 2; true döner.

ust == KAP − 1 (2 == 2) → return false. Program sürer; çağıran taşmayı öğrenir.

Boş değil; *x = veri[2] = 2, sonra ust = 1.

Boş değil; *x = veri[1] = 8, sonra ust = 0.

Boş değil; *x = veri[0] = 5, sonra ust = -1.

ust < 0 → return false: alt taşma, *x'e dokunulmadı.

bool push(Yigit *y, int x) {
  if (y->ust == KAP - 1) return false; /* taşma */
  y->veri[++y->ust] = x;
  return true;
}
bool pop(Yigit *y, int *x) {
  if (y->ust < 0) return false;   /* alt taşma */
  *x = y->veri[y->ust--];
  return true;
}

Dizi ile Yığıt · Kodu adım adım çalıştır

Kod İzleme: Kapasiteyi İkiye Katlayan push

Başlangıç: kapasite 1, içinde 4 var. Sırayla 7, 1, 9, 6 eklenecek.

ust == kap − 1 (0 == 0) → dolu.

realloc 2 hücrelik yer ayırır ve 1 öğeyi taşır (gerekirse kopyalar). Sonucu önce yeni'ye almak, başarısızlıkta eski belleği kaybetmemek içindir.

kap = 2.

veri[1] = 7.

ust == kap − 1 (1 == 1) → dolu.

realloc 4 hücrelik yer ayırır ve 2 öğeyi taşır (gerekirse kopyalar). Sonucu önce yeni'ye almak, başarısızlıkta eski belleği kaybetmemek içindir.

kap = 4.

veri[2] = 1.

2 == 3? Hayır, yer var.

veri[3] = 9.

ust == kap − 1 (3 == 3) → dolu.

realloc 8 hücrelik yer ayırır ve 4 öğeyi taşır (gerekirse kopyalar). Sonucu önce yeni'ye almak, başarısızlıkta eski belleği kaybetmemek içindir.

kap = 8.

veri[4] = 6. 5 öğe için toplam 7 kopya: n öğede kopya sayısı < 2n → push amortize O(1).

typedef struct { int *veri; int ust, kap; } DYigit;
bool push(DYigit *y, int x) {
  if (y->ust == y->kap - 1) {          /* dolu */
    int *yeni = realloc(y->veri,
                        2 * y->kap * sizeof *yeni);
    if (yeni == NULL) return false;
    y->veri = yeni;
    y->kap *= 2;
  }
  y->veri[++y->ust] = x;
  return true;
}

Kullanan kod struct'ın içini göremez; yalnız işlemleri çağırır. Gerçekleştirim diziden bağlaçlı listeye geçse bile kullanan kod değişmez.

/* yigit.c: gerçekleştirim */
struct Yigit { int *veri; int ust, kap; };

Yigit *yigit_olustur(int kap) {
  Yigit *y = malloc(sizeof *y);
  if (y == NULL) return NULL;
  y->veri = malloc(kap * sizeof *y->veri);
  if (y->veri == NULL) {
    free(y);  return NULL;
  }
  y->ust = -1;  y->kap = kap;
  return y;
}
void yigit_yok_et(Yigit *y) {
  if (y) { free(y->veri); free(y); }
}

Kod İzleme: Yığıtla Dizge Ters Çevirme

Girdi "YIGIT"; boş yığıt kuruldu.

s[0] = 'Y' ≠ '\0' → push('Y').

s[1] = 'I' ≠ '\0' → push('I').

s[2] = 'G' ≠ '\0' → push('G').

s[3] = 'I' ≠ '\0' → push('I').

s[4] = 'T' ≠ '\0' → push('T').

pop → 'T', s[0] = 'T'.

pop → 'I', s[1] = 'I'.

pop → 'G', s[2] = 'G'.

pop → 'I', s[3] = 'I'.

pop → 'Y', s[4] = 'Y'.

Yığıt boş: pop false döner, döngü biter. Sonuç "TIGIY": n push + n pop → O(n).

void ters_cevir(char *s) {
  Yigit y;  int c, i;
  yigit_baslat(&y);
  for (i = 0; s[i] != '\0'; i++)
    push(&y, s[i]);     /* KAP yeterli varsayıldı */
  for (i = 0; pop(&y, &c); i++)
    s[i] = (char)c;
}

Bağlaçlı Yığıt

Bağlaçlı Liste Kullanarak Yığıt

A, B, C sırasıyla eklendi: top liste başını gösterir.

  • Her öğe bir düğüm (node): deger + sonraki düğüme bag.
  • Ekleme ve silme liste başında: ikisi de O(1), kaydırma yok.
  • Kapasite sınırı yok: yalnız malloc başarısız olursa taşma olur.
Neden baş, neden son değil? Ders notundaki gibi: silerken son öğeden geri gelmek gerekir; tek bağlaçlı listede bir önceki düğümü bulmak O(n)'dir. Ya iki işaretçiyle sonu tutarsın ya da tek işaretçiyle başı tutarsın; basit olan ikincisi.

Bağlaçlı Yığıt · Kodu adım adım çalıştır

Kod İzleme: Bağlaçlı push

Başlangıç: dugum *top = NULL; (boş yığıt). Sırayla push 10, 20, 30.

malloc yeni bir düğüm ayırır; NULL değilse devam. Alanları henüz belirsiz.

yeni->deger = 10.

yeni->bag = *top: yeni düğüm eski üstü (NULL) gösterir. Sıra önemli: önce bağla, sonra *top'u değiştir.

*top = yeni: çağıranın top'u artık 10'u gösterir. Yığıt: 10.

malloc yeni bir düğüm ayırır; NULL değilse devam. Alanları henüz belirsiz.

yeni->deger = 20.

yeni->bag = *top: yeni düğüm eski üstü (düğüm(10)) gösterir. Sıra önemli: önce bağla, sonra *top'u değiştir.

*top = yeni: çağıranın top'u artık 20'u gösterir. Yığıt: 20 → 10.

malloc yeni bir düğüm ayırır; NULL değilse devam. Alanları henüz belirsiz.

yeni->deger = 30.

yeni->bag = *top: yeni düğüm eski üstü (düğüm(20)) gösterir. Sıra önemli: önce bağla, sonra *top'u değiştir.

*top = yeni: çağıranın top'u artık 30'u gösterir. Yığıt: 30 → 20 → 10.

Üç push sonrası: 30 → 20 → 10 → NULL. Her push sabit sayıda iş: O(1).

bool push(dugum **top, int x) {
  dugum *yeni = malloc(sizeof *yeni);
  if (yeni == NULL) return false;  /* bellek yok */
  yeni->deger = x;
  yeni->bag = *top;      /* eski üstü göster */
  *top = yeni;           /* yeni üst */
  return true;
}

Bağlaçlı Yığıt · Kodu adım adım çalıştır

Kod İzleme: Bağlaçlı pop

Yığıt: 30 → 20 → 10. Dört kez pop çağrılacak; her başarılı sonucu main yazdırır.

eski = *top: yalnızca bir işaretçi kopyası; yeni bellek ayrılmaz.

*x = 30 (değer, düğüm silinmeden önce alınmalı).

*top = eski->bag → düğüm(20).

free(eski): 30 düğümünün belleği sisteme döner. main 30 yazar.

eski = *top: yalnızca bir işaretçi kopyası; yeni bellek ayrılmaz.

*x = 20 (değer, düğüm silinmeden önce alınmalı).

*top = eski->bag → düğüm(10).

free(eski): 20 düğümünün belleği sisteme döner. main 20 yazar.

eski = *top: yalnızca bir işaretçi kopyası; yeni bellek ayrılmaz.

*x = 10 (değer, düğüm silinmeden önce alınmalı).

*top = eski->bag → NULL.

free(eski): 10 düğümünün belleği sisteme döner. main 10 yazar.

eski = NULL → yığıt boş, return false. Döngü burada durur.

bool pop(dugum **top, int *x) {
  dugum *eski = *top;      /* malloc yok! */
  if (eski == NULL) return false;  /* boş */
  *x = eski->deger;
  *top = eski->bag;        /* üstü ilerlet */
  free(eski);              /* belleği bırak */
  return true;
}

Bağlaçlı Yığıt

Bağlaçlı Yığıtta Bellek Sorumluluğu

typedef struct dugum {
    int deger;
    struct dugum *bag;
} dugum;

void yigit_temizle(dugum **top) {
    while (*top != NULL) {
        dugum *eski = *top;
        *top = eski->bag;
        free(eski);
    }
}                  /* sonunda *top == NULL */
  • eski bir işaretçi değişkenidir, yeni düğüm değil: ona malloc gerekmez.
  • Önce bağı kurtar (*top = eski->bag), sonra free: tersi serbest bırakılmış belleği okur.
  • Program bitmeden yigit_temizle: her malloc'un bir free'si olsun.
Hocadan “Her pointer’a mallocla yer ayırmak gerekmiyor, yok öyle bir şey!”
Hocadan “Pointerları bu yaşlarda öğrendin öğrendin, yoksa 4. sınıfta bile pointer’ı öğrenmemiş olursun.”

Çağrı Yığını

Sistem Yığıtı: Etkinleştirme Çerçevesi

Ders notu: Stack Activation Frame bir sistem yığıtıdır; önceki çerçeveye gösterge, programda nereye dönüleceğini gösteren dönüş adresi ve yerel değişkenleri tutar.

  • Çağrı = çerçeve push; return = çerçeve pop.
  • En son çağrılan fonksiyon ilk biter: çağrılar doğal olarak LIFO'dur.
  • Özyinelemede aynı fonksiyonun her çağrısı ayrı çerçeve ve ayrı yerel değişkenler alır.

Çağrı Yığını · Kodu adım adım çalıştır

Kod İzleme: fakt(3) ve Çerçeveler

main çalışıyor; fakt(3) çağrılacak: dönüş adresi (satır 8) saklanır.

Yeni çerçeve: n = 3. 3 ≤ 1? Hayır.

fakt(2) çağrılır; bu çerçeve bekler (çarpma yarım kaldı).

Yeni çerçeve: n = 2. 2 ≤ 1? Hayır.

fakt(1) çağrılır; bu çerçeve bekler (çarpma yarım kaldı).

Yeni çerçeve: n = 1. 1 ≤ 1? Evet.

Taban durum: return 1. Çerçeve pop edilir.

Geri dönüldü: 2 × 1 = 2 döner; çerçeve pop edilir.

Geri dönüldü: 3 × 2 = 6 döner; çerçeve pop edilir.

Tüm fakt çerçeveleri gitti; main 6 yazar. En derin anda yığıtta 4 çerçeve vardı: bellek O(n).

int fakt(int n) {
  if (n <= 1)
    return 1;
  return n * fakt(n - 1);
}

int main(void) {
  int s = fakt(3);
  printf("%d\n", s);
  return 0;
}

Çağrı Yığını

Çağrı Yığını da Taşar

Sonsuz özyineleme

Taban durumu olmayan ya da ona ulaşmayan özyineleme her çağrıda çerçeve iter; sistem yığıtı (tipik olarak birkaç MB) dolunca program stack overflow ile çöker.

Büyük yerel diziler

int a[1000000]; gibi yerel bir dizi çerçevenin içindedir; tek başına yığıtı taşırabilir. Büyük veriler için malloc (heap) kullan.

Yerel adres döndürme

return &yerel; hatalıdır: çerçeve pop edilince o bellek başka çağrılarca yeniden kullanılır (sarkan işaretçi).

Özyinelemeden kurtulmak

Her özyineli algoritma, kendi yığıtını tutan bir döngüye çevrilebilir (Bölüm 15).

Çoklu Yığıt

Çoklu Yığıt: Önce İki Yığıt

  • Yığıt 1 0'dan yukarı, yığıt 2 m−1'den aşağı büyür.
  • Boş: top1 = −1, top2 = m.
  • Dolu: top1 + 1 == top2: ikisi ortada buluşunca.
Avantaj: bir yığıt az, öteki çok öğe tutsa bile hiç hücre boşa gitmez; dizi ancak toplam m öğe olunca dolar. Üç ve daha fazla yığıt için bu hile yetmez.

Çoklu Yığıt · Kodu adım adım çalıştır

Kod İzleme: Tek Bellekte n Yığıt

MEM = 12, n = 3: her yığıta 4 hücre. Başta top[i] = sinir[i] = (m/n)·i − 1, sinir[n] = m − 1.

Yer var; bellek[0] = 5, top[0] = 0.

Yer var; bellek[4] = 7, top[1] = 4.

Yer var; bellek[1] = 9, top[0] = 1.

Yer var; bellek[8] = 4, top[2] = 8.

Yer var; bellek[2] = 2, top[0] = 2.

Yer var; bellek[3] = 8, top[0] = 3.

top[0] == sinir[1] (3 == 3) → yığıt 0 dolu, oysa bellekte 6 boş hücre var! Horowitz'in stack_full'u burada yığıtları kaydırıp yer açar.

top[1] ≠ sinir[1] → boş değil; *x = 7, top[1] = 3.

/* yığıt i: bellek[sinir[i]+1 .. sinir[i+1]] */
bool ekle(int i, int x) {
  if (top[i] == sinir[i + 1]) return false; /* dolu */
  bellek[++top[i]] = x;
  return true;
}
bool al(int i, int *x) {
  if (top[i] == sinir[i]) return false;     /* boş */
  *x = bellek[top[i]--];
  return true;
}

Çoklu Yığıt

n Yığıtın Paylaşımı: Artılar ve Eksiler

Ders notu: tek boyutlu bir dizi (memory[MEMORY_SIZE]) n kesime (segment) bölünerek n yığıt kurulabilir; yığıtların top ve sınır değerleri iki yardımcı dizide tutulur.

Artılar

  • Tek malloc, tek dizi: yönetimi kolay.
  • push/pop yine O(1).
  • Aynı kuyruk fikri de uygulanabilir (n kuyruk).

Eksiler

  • Bir kesim dolunca, bellekte yer olsa bile “dolu” hatası.
  • Yer açmak için yığıtları kaydırmak O(m): kaydırma pahalıdır.
  • Kesim boyutlarını önceden kestirmek zor.
Horowitz–Sahni'nin çözümü: stack_full(i), önce sağdaki, yoksa soldaki boş yeri bulur ve arada kalan yığıtları bir hücre kaydırır. En kötü durumda her ekleme O(m) olabilir.

1, 2, 3, 4 bu sırayla push edilecek; aralara istediğin kadar pop koyabilirsin. Aşağıdaki çıkış sıralarından hangileri elde edilebilir?

Özet

Alıştırmalar

  1. Dizi yığıtında yigit_ekle'yi exit yerine bool döndürecek biçimde yeniden yaz.
  2. Tek dizide iki yığıt için ekle(k, x) ve al(k) yordamlarını yaz (k = 1 ya da 2).
  3. Bağlaçlı yığıtı, top ile birlikte boyut alanı da tutan bir struct içine taşı.
  4. Bir dizgeyi yığıt kullanarak ters çeviren void ters(char *s) yordamını yaz.
  5. Yalnız push/pop kullanarak bir yığıtın en alttaki öğesini döndüren yordamı yaz (yardımcı yığıt serbest).
  6. fakt(5) çağrısında yığıtta en çok kaç çerçeve olur? main dahil çiz.
İpuçları / cevaplar
  1. Taşma varsa return false;, yoksa yigit[++*top] = item; return true;.
  2. Boş: top1 = −1, top2 = m. Dolu: top1 + 1 == top2. k = 2 için ekleme --top2, alma top2++.
  3. typedef struct { dugum *top; int boyut; } BYigit;; push'ta ++boyut, başarılı pop'ta --boyut.
  4. Karakterleri sırayla push et, sonra pop ederek aynı diziye geri yaz: O(n) zaman, O(n) ek bellek.
  5. Tümünü yardımcı yığıta aktar, sonuncuyu sakla, sonra geri aktar: O(n).
  6. fakt(5), fakt(4), …, fakt(1) + main = 6 çerçeve.
