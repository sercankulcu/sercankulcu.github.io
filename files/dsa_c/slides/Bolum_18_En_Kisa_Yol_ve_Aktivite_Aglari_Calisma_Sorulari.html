Çoktan Seçmeli · En Kısa Yol

Soru 1: Kaba Kuvvette Yol Sayısı

K6 tam çizgesinde (düğümler 0..5) 0'dan 5'e giden, düğüm tekrarlamayan kaç farklı yol vardır?

C: Ara düğümler {1, 2, 3, 4} arasından sıralı seçimdir: 1 (doğrudan) + 4 + 4·3 + 4·3·2 + 4! = 1 + 4 + 12 + 24 + 24 = 65 (Python ile sayıldı; K4'te 5, K5'te 16). Son terim (n − 2)! hızla baskın olur; tek bir hedef için bile kaba kuvvet üstel büyür.

Soru 2: Kesinleşme Sırası

Şekildeki yönlü çizgede Dijkstra 0'dan çalıştırılıyor. Düğümler hangi sırayla kesinleşir (S'ye katılır)?

A: Başta 1 → 10, 2 → 3. 2 seçilir ve 1 → 7, 3 → 11, 4 → 5 olur. En küçük 4'tür (5); çıkış kenarı yoktur. Sonra 1 (7) seçilir ve 3 → 9. Son kalan 3'tür (9). Sıra numaraya göre değil, uzaklığa göre belirlenir.

Soru 3: EnKisaYolBul İzleme

Şekildeki çizgede EnKisaYolBul(0, …) çalıştırılıyor. Her turda hangi düğüm seçilir, uzaklik ve onceki nasıl değişir?

A1 sonrası: uzaklik = 0'ın satırı, onceki[] = 0. Kaynak işaretlendi.

minimumBul: işaretsizler arasında en küçük uzaklık 2 (3). Kesinleşti.

2 üzerinden kısalanlar: uzaklik[1] = 7, uzaklik[3] = 11, uzaklik[4] = 5.

minimumBul: işaretsizler arasında en küçük uzaklık 4 (5). Kesinleşti. Çıkış kenarı yok, hiçbir uzaklık kısalmaz.

minimumBul: işaretsizler arasında en küçük uzaklık 1 (7). Kesinleşti.

1 üzerinden kısalanlar: uzaklik[3] = 9.

n − 2 = 3 tur bitti; son kalan 3'ün uzaklığı (9) zaten kesin. Sonuç [0, 7, 3, 9, 5], onceki [0, 2, 0, 1, 2].

gidildi[v] = TRUE;  uzaklik[v] = 0;
for (i = 2; i < n; i++) {            /* n-2 tur */
    u = minimumBul(uzaklik, n, gidildi);
    if (u < 0) break;
    gidildi[u] = TRUE;
    for (w = 0; w < n; w++)
        if (!gidildi[w] &&
            uzaklik[u] + maliyet[u][w] < uzaklik[w]) {
            uzaklik[w] = uzaklik[u] + maliyet[u][w];
            onceki[w] = u;
        }
}

Soru 4: Yığınla Yol

Dijkstra sonunda onceki = {0, 2, 0, 1, 2} bulunmuştur (kaynak 0). Yolu özyinelemesiz yazan yol_yaz2 ile yol_yaz2(onceki, 0, 3), yol_yaz2(onceki, 0, 4) ve yol_yaz2(onceki, 0, 0) ne yazdırır?

void yol_yaz2(int onceki[], int s, int h) {
    int yol[MAX], k = 0;
    while (h != s) {
        yol[k++] = h;
        h = onceki[h];
    }
    printf("%d", s);
    while (k > 0)
        printf(" -> %d", yol[--k]);
    printf("\n");
}

Soru 5: Heap'li Dijkstra

Uzaklıklar ikili min-heap'te, çizge komşuluk listesinde tutulursa Dijkstra'nın zamanı nedir? (n düğüm, e kenar)

D: n kez en küçüğü almak O(n lg n). Her kenar en çok bir kez gevşetilir ve başarılı her gevşetme heap'te bir güncelleme (O(lg n)) ister: O(e lg n). O(n lg n) sanmak sık yapılan bir hatadır; gevşetmelerin maliyeti unutulur. B, ikili heap'le değil Fibonacci heap'le elde edilen sınırdır. Yoğun çizgede (e ≈ n²) matrisli O(n²) sürüm daha iyidir.

Soru 6: gidildi Denetimi Unutulursa

minimumBul'da koşuldan !gidildi[i] çıkarılmıştır. Kenarları 0→1 (10), 0→2 (3), 1→3 (2), 1→4 (6), 2→1 (4), 2→3 (8), 2→4 (2), 3→4 (7) olan çizgede EnKisaYolBul(0, …) hangi uzaklıkları bulur? Neden?

int minimumBul(int uzaklik[], int n,
               short gidildi[])
{
    int i, min = INT_MAX, pos = -1;
    for (i = 0; i < n; i++)
        if (uzaklik[i] < min) {
            min = uzaklik[i];  pos = i;
        }
    return pos;
}
Cevabı göster

Her turda en küçük uzaklık kaynağınkidir (0): minimumBul hep 0 döndürür. 0 üzerinden gevşetme yeniden denenir ama hiçbir değer küçülmez. Üç turun üçü de boşa gider.

Sonuç [0, 10, 3, ∞, ∞]: yalnız doğrudan kenarlar. 1 için 7 yerine 10 kalır, 3 ve 4 erişilemez görünür (simülasyonla doğrulandı).

Düzeltme: if (uzaklik[i] < min && !gidildi[i]). Kesinleşen düğüm bir daha seçilmemelidir.

Soru 7: Bellman-Ford ve Kenar Sırası

Kaynak 0. Kenarlar K dizisinde 2→3, 1→2, 0→1, 0→2 sırasıyla durmaktadır. Hangi turda hangi değer değişir, sonuç nedir?

Kenar dizisi K bu sırada: 2→3 (−2), 1→2 (−3), 0→1 (4), 0→2 (6). d[0] = 0.

Tur 1: 2→3 ve 1→2 atlanır, çünkü d[2] ve d[1] henüz ∞. 0→1: d[1] = 4.

Tur 1, 0→2 (6): d[2] = 6.

Tur 2, 2→3 (-2): d[3] = 4.

Tur 2, 1→2 (-3): d[2] = 1.

Tur 3, 2→3 (−2): d[3] = −1. Kenar sırası kötü olduğu için bilgi her turda bir kenar ilerledi; n − 1 = 3 tur gerekti.

n. turda gevşeyen kenar yok: negatif döngü yok, return 0. Sonuç d = [0, 4, 1, −1].

for (i = 0; i < n; i++) d[i] = SONSUZ;
d[s] = 0;
for (t = 1; t <= n - 1; t++)          /* n-1 tur */
    for (j = 0; j < e; j++) {
        u = K[j].u;  v = K[j].v;
        if (d[u] != SONSUZ && d[u] + K[j].w < d[v])
            d[v] = d[u] + K[j].w;
    }
for (j = 0; j < e; j++)               /* n. tur */
    if (d[K[j].u] != SONSUZ &&
        d[K[j].u] + K[j].w < d[K[j].v]) return -1;
return 0;

Soru 8: Negatif Döngü

Floyd-Warshall, ağırlıkları 0→1: 1, 1→2: −3, 2→0: 1 olan (toplamı −1 olan bir döngü içeren) çizgede çalıştırılıyor. Sonda ne gözlenir?

B: Üç iç içe döngü her durumda biter. Döngü üzerinden dönmek uzaklığı hep azalttığı için en kısa yol tanımsızdır ve bu durum köşegene yansır: son matriste köşegen −1, −1, −2 çıktı (C ile doğrulandı). Bu yüzden köşegen denetimi negatif döngüyü yakalar.

Soru 10: Topolojik Olmayan Sıra

AoV ağının kenarları: A→C, B→C, C→E, B→D, D→E, E→F. Aşağıdakilerden hangisi bir topolojik sıra değildir?

D: B, C'nin öncülüdür (B→C); D'de C, B'den önce gelir. Diğer üç sırada her kenarın başı sonundan önce gelir. Topolojik sıra çoğu zaman tek değildir; sağlamak için her kenar tek tek denetlenir.

Soru 11: Sayaçlı Yığınla Topolojik Sıra

Listeler: 0: 2 · 1: 2, 3 · 2: 4 · 3: 4, 5 · 4: 5. TopolojikSira(baslik, 6) ne yazdırır? Gömülü yığın sayaç alanlarında nasıl tutulur?

Sayaçlar öncül sayısıdır: 2 → 2, 3 → 1, 4 → 2, 5 → 2. 0 ve 1 öncülsüz.

0 ve 1 yığına: sayac[0] = −1 (dip), sayac[1] = 0 (altındaki), ust = 1. Sayaç alanı artık "altımdaki düğüm".

Yığından 1 alınıp yazıldı; sayacı 0'a düşen 3 yığına; 2'nin sayacı 1.

Yığından 3 alınıp yazıldı; 4'ün sayacı 1, 5'in sayacı 1.

Yığından 0 alınıp yazıldı; sayacı 0'a düşen 2 yığına.

Yığından 2 alınıp yazıldı; sayacı 0'a düşen 4 yığına.

Yığından 4 alınıp yazıldı; sayacı 0'a düşen 5 yığına.

Yığından 5 alınıp yazıldı; çıkış kenarı yok. Sıra 1 3 0 2 4 5: yığın kullanıldığı için son giren önce çıktı.

for (i = 0; i < n; i++)          /* sayac 0: yigina */
    if (!baslik[i].sayac) {
        baslik[i].sayac = ust;  ust = i; }
for (i = 0; i < n; i++) {
    if (ust == -1) { printf("dongu"); break; }
    j = ust;  ust = baslik[ust].sayac;
    printf("%d ", j);
    for (p = baslik[j].bag; p; p = p->bag) {
        k = p->dugum;
        if (--baslik[k].sayac == 0) {
            baslik[k].sayac = ust;  ust = k; }
    }
}

Soru 12: Döngülü Ağ

Kenarları 0→1, 1→2, 2→3, 3→4, 4→2 olan ağda TopolojikSira(baslik, 5) ne yazdırır?

A: Yalnız 0 öncülsüzdür. 0 yazılır, 1'in sayacı 0'a düşer; 1 yazılır, 2'nin sayacı 2'den 1'e iner (4→2 kenarı yüzünden). Yığın boşalır ama üç düğüm kalmıştır: üçüncü turda ust == -1 görülür ve "dongu" yazılır. 2, 3, 4 birbirini bekler; proje hiç bitmez.

Soru 13: En Erken, En Geç, Bolluk

Şekildeki AoE ağında (kenar: aktivite:süre) olayların en erken ve en geç zamanlarını, her aktivitenin bolluğunu bulun. Proje kaç günde biter, kritik yol hangisidir?

Cevabı göster
olayv0v1v2v3v4v5
en erken03591114

v3 = max(3 + 6, 5 + 2) = 9, v5 = max(9 + 5, 11 + 3) = 14. Geriye: v2 = min(9 − 2, 11 − 6) = 5, v0 = min(3 − 3, 5 − 5) = 0.

Bolluk (geç − erken): a3 = 9 − 2 − 5 = 2, diğer altı aktivitede 0. Proje 14 gün; iki kritik yol: v0-v1-v3-v5 ve v0-v2-v4-v5 (ikisi de 14).

Soru 14: max Yerine min

Şekildeki AoE ağında en erken zamanlar hesaplanırken öncüller arasından max yerine min alınırsa v5 için kaç bulunur?

B: v3 = min(3 + 6, 5 + 2) = 7 ve v5 = min(7 + 5, 11 + 3) = 12 olur. Oysa v3 ancak a2 ve a3'ün ikisi de bitince gerçekleşir: 9; proje 14 gün sürer. En erken zamanda max, en geç zamanda min alınır; tersi sık yapılan bir hatadır.

Soru 15: Kuyrukla Topolojik Sıra

Komşuluk matrisiyle verilen yönlü çizgede giriş derecelerini sayıp öncülsüz düğümleri kuyruğa alan (Kahn yöntemi) int topo_kahn(int n, int adj[][N], int sira[]) yordamını yazın. Yazılan düğüm sayısını döndürsün; n'den küçükse çizgede döngü vardır.

Cevabı göster 
int topo_kahn(int n, int adj[][N], int sira[]) {
  int gd[N] = {0}, kuyruk[N];
  int bas = 0, son = 0, say = 0;
  for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++)
      gd[j] += adj[i][j];        /* giriş derecesi */
  for (int i = 0; i < n; i++)
    if (gd[i] == 0) kuyruk[son++] = i;
  while (bas < son) {
    int v = kuyruk[bas++];
    sira[say++] = v;
    for (int j = 0; j < n; j++)
      if (adj[v][j] && --gd[j] == 0)
        kuyruk[son++] = j;
  }
  return say;
}

Kenarları 0→2, 1→2, 1→3, 2→4, 3→4, 3→5, 4→5 olan ağda sıra 0 1 2 3 4 5 (sayaçlı yığınla 1 3 0 2 4 5; ikisi de geçerli). Döngülü ağda yalnız 0 ve 1 yazılır, dönüş 2 < 5. Matrisle O(n²), listeyle O(n + e).

Soru 16: Hangi Algoritma?

Döngüsüz yönlü bir çizgede (DAG) bazı kenarlar negatiftir. Tek kaynaktan bütün en kısa yollar en hızlı nasıl bulunur?

C: DAG'de düğümler topolojik sırada işlenir ve her düğümün çıkış kenarları bir kez gevşetilir. Bir düğüme gelindiğinde bütün öncülleri işlenmiştir, uzaklığı kesindir; negatif kenar sorun değildir. B de doğru sonuç verir ama yavaştır; A negatif kenarda yanılabilir; D tüm çiftler içindir.
