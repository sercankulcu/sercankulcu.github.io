Soru 1: Dizide Hızlı, Listede Yavaş

Aşağıdaki işlemlerden hangisi dizide O(1), tek yönlü bağlı listede (yalnız baş işaretçisiyle) O(n) sürer?

D: Dizide a[i]'nin adresi α + i·s ile hesaplanır. Listede i. düğümün adresi hesaplanamaz; baştan i bağ izlenir: O(i). Diğer üçü listede O(1), dizide ise öğeleri kaydırdığı için O(n)'dir.

Soru 2: Değerle Gelen Baş

liste 7 → 2 iken aşağıdaki hatalı sürüm basa_ekle(liste, 5) diye çağrılıyor. Çağrıdan sonra ne olur?

void basa_ekle(oge_gost bas, int x) {
  oge_gost yeni = malloc(sizeof *yeni);
  if (yeni == NULL) return;
  yeni->deger = x;
  yeni->bag = bas;
  bas = yeni;
}

B: bas, main'deki liste'nin kopyasıdır. bas = yeni yalnız kopyayı değiştirir; fonksiyon dönünce yeni düğümün adresi hiçbir yerde kalmaz: liste 7 → 2 olarak kalır ve 5'li düğüm bellek sızıntısı olur. Baş değişen yordam oge_gost *bas almalı ve &liste ile çağrılmalıdır.

Soru 3: İşlem Dizisi

Sunumdaki basa_ekle, sona_ekle, sil, konum ve ara ile bu parça ne yazdırır?

oge_gost L = NULL, p;
basa_ekle(&L, 3);
basa_ekle(&L, 8);
sona_ekle(&L, 5);
sil(&L, 8);
sona_ekle(&L, 8);
yazdir(L);
printf("%d ", konum(L, 1)->deger);
p = ara(L, 9);
printf("%s\n", p ? "var" : "NULL");
Cevabı göster 
3 5 8
5 NULL
  • basa_ekle 3 → 3; basa_ekle 8 → 8 3; sona_ekle 5 → 8 3 5.
  • sil 8: baştaki düğüm silinir (onceki == NULL) → *bas = p->bag: 3 5.
  • sona_ekle 8 → 3 5 8. konum(L, 1) 0 tabanlıdır: 5. 9 listede yok → ara NULL döner.

Soru 4: Koşulların Sırası

ara fonksiyonunun döngüsü while (p->deger != x && p != NULL) diye yazılmış. Hangi durumda tanımsız davranış oluşur?

A: x yoksa p sonunda NULL olur ve koşulun ilk parçası NULL->deger'i okur. x listedeyse p NULL olmadan döngü durur, hata görünmez; bu yüzden hata ancak ‘bulunamadı’ testinde ortaya çıkar. Doğru sıra p != NULL && p->deger != x: kısa devre sağ tarafı korur.

Soru 5: free Sonrası Erişim

Listeyi boşaltan bu fonksiyonun hatası nedir? Doğrusu nasıl yazılır?

void liste_bosalt(oge_gost *list) {
  oge_gost p;
  for (p = *list; p != NULL; p = p->bag)
    free(p);
  *list = NULL;
}
Cevabı göster

Döngünün artış kısmı p = p->bag, free(p)'den sonra çalışır: bırakılmış düğümün bag alanı okunur. Bu, free sonrası erişimdir (tanımsız davranış); bellek yeniden kullanılmışsa döngü rastgele bir adrese atlayabilir.

void liste_bosalt(oge_gost *list) {
  while (*list != NULL) {
    oge_gost p = *list;
    *list = p->bag;   /* once ilerle */
    free(p);          /* sonra birak */
  }
}

Kural: sonraki adres free'den önce saklanır. Sonunda *list NULL'dur; sarkan işaretçi kalmaz.

Soru 6: Sondan k. Düğüm

Listenin sondan k. düğümünü (k = 1 son düğüm) tek geçişte bulan oge_gost sondan_k(oge_gost bas, int k) fonksiyonunu yazınız. Liste k'dan kısaysa NULL dönsün.

Cevabı göster 
oge_gost sondan_k(oge_gost bas, int k) {
  oge_gost hizli = bas, yavas = bas;
  while (k-- > 0) {             /* k adim one */
    if (hizli == NULL) return NULL;
    hizli = hizli->bag;
  }
  while (hizli != NULL) {       /* birlikte */
    hizli = hizli->bag;
    yavas = yavas->bag;
  }
  return yavas;
}

hizli NULL'a vardığında yavas ondan tam k düğüm geridedir. 10 → 20 → … → 60 için k = 1 → 60, k = 2 → 50, k = 6 → 10, k = 7 → NULL. O(n) zaman, O(1) ek bellek.

Soru 7: Sıralı İki Listeyi Birleştirmek

birlestir 1 → 4 → 6 ile 2 → 3 → 7 listelerini düğüm ayırmadan birleştiriyor. Bağlar sırayla nasıl değişir?

Yığındaki kukla başlık görevi görür: son ona bağlanarak başlar, ilk düğüm için özel durum gerekmez.

1 ≤ 2: 1 sonuca bağlanır, a ilerler.

4 > 2: 1'in bağı 2'ye çevrilir, b ilerler.

4 > 3: 3 bağlanır (zaten 2'nin peşindeydi).

4 ≤ 7: 3'ün bağı 4'e çevrilir.

6 ≤ 7: 6 bağlanır, a NULL olur; döngü biter.

Kalan b listesi tek bağla eklenir. Sonuç kukla.bag: 1 → 2 → 3 → 4 → 6 → 7. Hiç malloc yok; O(n + m) zaman, O(1) ek bellek.

oge_gost birlestir(oge_gost a, oge_gost b) {
  struct oge kukla;           /* baslik */
  oge_gost son = &kukla;
  while (a != NULL && b != NULL) {
    if (a->deger <= b->deger) {
      son->bag = a; a = a->bag;
    } else {
      son->bag = b; b = b->bag;
    }
    son = son->bag;
  }
  son->bag = (a != NULL) ? a : b;
  return kukla.bag;
}

Soru 8: Tavşan ile Kaplumbağa

Liste 1 → 2 → 3 → 4 → 5 → 6 ve 6'nın bağı 3'ü gösteriyor. Sunumdaki dongu_var'da yavas ile hizli hangi düğümde buluşur?

C: Turlar (yavas, hizli): (2, 3), (3, 5), (4, 3), (5, 5) → 4. turda düğüm 5'te buluşurlar. Döngünün girişi 3 olsa da buluşma noktası genellikle girişte değildir; girişi bulmak için ayrıca bir adım gerekir.

Soru 9: Döngünün Girişi

Floyd algoritmasını genişleterek döngü varsa döngünün giriş düğümünü, yoksa NULL döndüren dongu_girisi fonksiyonunu yazınız. Önceki sorudaki liste için ne döner?

Cevabı göster 
oge_gost dongu_girisi(oge_gost bas) {
  oge_gost y = bas, h = bas;
  while (h != NULL && h->bag != NULL) {
    y = y->bag; h = h->bag->bag;
    if (y == h) {                /* bulustular */
      y = bas;                   /* biri basa */
      while (y != h) {           /* birer adim */
        y = y->bag; h = h->bag;
      }
      return y;
    }
  }
  return NULL;
}

Örnekte buluşma 5'te olur. y başa alınır, h 5'te kalır; ikisi birer adım ilerler: y 1 → 2 → 3, h 5 → 6 → 3 → düğüm 3. Baştan girişe uzaklık, buluşma noktasından döngü yönünde girişe olan uzaklıkla döngü uzunluğunun katları dışında aynıdır. O(n) zaman, O(1) bellek.

Soru 10: Çift Uzunlukta Orta Düğüm

orta fonksiyonu 1 → 2 → 3 → 4 → 5 → 6 listesinde hangi düğümü döndürür? İlk ortayı (3) döndürmesi için koşul nasıl değişmelidir?

İkisi de baştan başlar. Liste çift uzunlukta: 6 düğüm.

1. tur: yavas 1, hizli 2 adım.

2. tur.

3. tur: 5 → 6 → NULL. hizli NULL olduğu için koşul kısa devreyle yanlış olur.

İkinci orta, 4 döner. Koşul hizli->bag->bag != NULL eklenseydi döngü 2 turda durur, ilk orta 3 dönerdi.

oge_gost orta(oge_gost bas) {
  oge_gost yavas = bas, hizli = bas;
  while (hizli != NULL &&
         hizli->bag != NULL) {
    yavas = yavas->bag;
    hizli = hizli->bag->bag;
  }
  return yavas;
}

Soru 11: do-while Yerine while

3 → 5 → 8 → (3) dairesel listesinde son 8'i gösteriyor. d_uzunluk'taki do-while yerine bu döngü yazılırsa fonksiyon ne döndürür?

int n = 0;
oge_gost p = son;
while (p != son) {
  n++;
  p = p->bag;
}
return n;

C: p = son ile başlanır ve koşul p != son ilk denetimde yanlıştır: gövde hiç çalışmaz, 0 döner. Dairesel listede gezinmenin bitişi başa dönmektir; gövde en az bir kez çalışmalıdır, bu yüzden do-while kullanılır. D, koşul p != NULL olsaydı doğru olurdu.

Soru 12: Dairesel Listeye Ekleme

Sunumdaki d_basa_ekle ile bu parça ne yazdırır? (yeni_oge düğüm ayırır.)

oge_gost son = NULL, y, p;
d_basa_ekle(&son, yeni_oge(4));
y = yeni_oge(7);
d_basa_ekle(&son, y); son = y;
d_basa_ekle(&son, yeni_oge(1));
y = yeni_oge(9);
d_basa_ekle(&son, y); son = y;
p = son->bag;
do {
  printf("%d ", p->deger);
  p = p->bag;
} while (p != son->bag);
printf("son=%d\n", son->deger);
Cevabı göster

Çıktı: 1 4 7 9 son=9.

  • Boş listeye 4: kendini gösterir, son = 4.
  • 7 başa eklenir, sonra son = y: sona ekleme → 4 7, son = 7.
  • 1 başa: son->bag artık 1 → 1 4 7.
  • 9 başa eklenip son yapılır → 1 4 7 9, son = 9.

Başa ve sona ekleme aynı bağ işlemidir; fark yalnızca son'un güncellenmesidir. İkisi de O(1).

Soru 13: Dairesel Listeleri Birleştirmek

n ve m düğümlü iki dairesel liste son1 ve son2 işaretçileriyle tutuluyor. Tek dairesel listede birleştirmenin maliyeti nedir?

D: ilk1 = son1->bag; son1->bag = son2->bag; son2->bag = ilk1; ve yeni son son2: üç bağ, gezinme yok. Düz tek yönlü bağlı listede ilk listenin sonunu bulmak gerektiği için birleştirme O(n)'dir; son işaretçisi bu yürüyüşü kaldırır.

Soru 14: Bağların Sırası

Başlıklı çift yönlü bağlı listede H ⇄ 4 ⇄ 8 ⇄ H; p = 4 ve yeni = 6. cift_ekle'nin son iki satırı yer değiştirmiş. Hangi bağlar yanlış kalır?

yeni->sol = p;
yeni->sag = p->sag;
p->sag = yeni;
p->sag->sol = yeni;

A: p->sag = yeni önce çalışınca p->sag->sol artık 8'in değil 6'nın sol bağıdır: 6->sol = 6 olur, 8->sol 4'te kalır. İleri yön (4 → 6 → 8) doğrudur; geri yönde 8'den 4'e atlanır. Değişmez p == p->sag->sol bozulmuştur.

Başlık (header) düğümlü tek yönlü bağlı liste için hangisi doğrudur?

Soru 16: Kullanılabilir Düğüm Listesi

Boş avail ile yorumdaki işlemler sırayla yapılıyor. Kaç malloc çağrılır, d ve e hangi düğümleri alır, sonunda avail'de ne kalır?

avail boş: üç düğüm de malloc ile gelir (N1, N2, N3).

ret(b), ret(a): free yerine avail'in önüne eklenir. Son iade edilen (N1) başa geçer: avail bir yığındır.

d = get → N1 (a'nın eski düğümü), e = get → N2. malloc çağrılmadı.

avail yine boş: f için 4. malloc.

ret(c), ret(d): avail N1 → N3. Toplam 4 malloc, hiç free yok; avail'deki 2 düğüm program bitene dek heap'e dönmez.

oge_gost get_node(void) {
  oge_gost p;
  if (avail != NULL) {
    p = avail; avail = avail->bag;
  } else {
    p = malloc(sizeof *p);
    if (p == NULL) exit(1);
  }
  return p;
}
void ret_node(oge_gost p) {
  p->bag = avail; avail = p;
}

   ret(b); ret(a);

   ret(c); ret(d);  */
