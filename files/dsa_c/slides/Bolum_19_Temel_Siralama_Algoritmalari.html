Sıralama Kavramları

Sıralama: Tutanak, Anahtar, İç/Dış

  • Alanların (fields) oluşturduğu tutanaklar (records) bellekte tutulunca liste, bellek dışında tutulunca kütük (file) adını alır.
  • Tutanağı biricik (unique) olarak tanıtan alan(lar) anahtardır (key); sıralama anahtara göre yapılır.
  • İç sıralama (internal): verinin tamamı bellekte. Dış sıralama (external): disk/teyp gibi yardımcı bellek kullanılır; disk erişim sayısı belirleyicidir.

Anahtar: öğrenci no

Kararlılık (Stability) ve Yerinde (In-place) Sıralama

Kararlı (stable)

Eşit anahtarlı tutanakların göreli sırası korunur. Önce ada, sonra soyada kararlı sıralarsanız soyadı aynı olanlar ad sırasında kalır (basamak sıralamanın temeli).

Yerinde (in-place)

Girdinin dışında yalnızca O(1) (bazı tanımlarda O(lg n)) ek bellek kullanır. Seçmeli, eklemeli, kabarcık yerindedir; sayarak sıralama değildir (c ve b dizileri).

Sıralama Kavramları · VYA2 s. 56

Ortak Altyapı: kucuk, degistir, karsilas_degis

#define N 15
#define kucuk(A, B) ((A) < (B))
#define degistir(A, B) do { int t_ = (A); (A) = (B); (B) = t_; } while (0)
#define karsilas_degis(A, B) do { if (kucuk(A, B)) degistir(A, B); } while (0)
int main(void) {
    int *a = malloc(N * sizeof *a);
    if (a == NULL) return 1;
    for (int i = 0; i < N; i++)
        a[i] = rand() % 50;
    selection(a, 0, N - 1);   /* sıralama yordamına çağrı */
    for (int i = 0; i < N; i++) printf("%d ", a[i]);
    free(a);
    return 0;
}
Düzeltme

Notlardaki {int t = A; A=B; B=t;} biçimi if (…) degistir(…); else içinde derlenmez; do { … } while (0) bu tuzağı kapatır. karsilas_degis(A,B): A < B ise takas eder.

Seçmeli Sıralama · VYA2 s. 57

Seçmeli Sıralama (Selection Sort)

void selection(int a[], int L, int R) {
    for (int i = L; i < R; i++) {
        int min = i;
        for (int j = i + 1; j <= R; j++)
            if (kucuk(a[j], a[min]))
                min = j;
        degistir(a[i], a[min]);
    }
}
  1. Listedeki en küçük değerli öğeyi bul.
  2. İlk konumdaki öğeyle yerini değiştir.
  3. Aynı adımları 2. öğeden başlayarak kalan alt liste için yinele.
Değişmez

Her dış tur sonunda a[L..i] sıralı ve dizinin en küçük öğelerini içerir.

Neden sona kadar?

En küçüğü seçmek için kalan alt liste kesinlikle sonuna kadar taranmalıdır; veri sıralı olsa bile.

Seçmeli Sıralama · Kodu adım adım çalıştır

Kod İzleme: selection(a, 0, 4)

Tur i = 0: kalan alt liste a[0..4]. Başlangıçta en küçüğün indisi min = 0 (a[0] = 29).

a[1] = 10 < a[0] = 29 → yeni en küçük: min = 1.

a[2] = 14 ≥ a[1] = 10 → min değişmez.

a[3] = 37 ≥ a[1] = 10 → min değişmez.

a[4] = 13 ≥ a[1] = 10 → min değişmez.

degistir(a[0], a[1]): 10 yerine oturdu; a[0..0] artık sıralı.

Tur i = 1: kalan alt liste a[1..4]. Başlangıçta en küçüğün indisi min = 1 (a[1] = 29).

a[2] = 14 < a[1] = 29 → yeni en küçük: min = 2.

a[3] = 37 ≥ a[2] = 14 → min değişmez.

a[4] = 13 < a[2] = 14 → yeni en küçük: min = 4.

degistir(a[1], a[4]): 13 yerine oturdu; a[0..1] artık sıralı.

Tur i = 2: kalan alt liste a[2..4]. Başlangıçta en küçüğün indisi min = 2 (a[2] = 14).

a[3] = 37 ≥ a[2] = 14 → min değişmez.

a[4] = 29 ≥ a[2] = 14 → min değişmez.

min = i olduğundan takas kendisiyle yapılır (değişiklik yok); a[0..2] sıralı.

Tur i = 3: kalan alt liste a[3..4]. Başlangıçta en küçüğün indisi min = 3 (a[3] = 37).

a[4] = 29 < a[3] = 37 → yeni en küçük: min = 4.

degistir(a[3], a[4]): 29 yerine oturdu; a[0..3] artık sıralı.

        for (int j = i + 1; j <= R; j++)
            if (kucuk(a[j], a[min]))
                min = j;
        degistir(a[i], a[min]);

Seçmeli Sıralama · VYA2 s. 57

Seçmeli Sıralamanın Analizi

(n−1) + (n−2) + … + 2 + 1 = n(n−1)/2 ≈ n²/2

  • Karşılaştırma sayısı girdiden bağımsızdır: en iyi = ortalama = en kötü ≈ n²/2.
  • Değiştirme (takas) sayısı n − 1: son öğeye gelindiğinde o zaten doğru yerdedir.
  • Karmaşıklık O(n²); ek bellek O(1) (yerinde).
  • Uzak takaslar yüzünden kararlı değildir (önceki 3a/3c örneği).

Eklemeli Sıralama · VYA2 s. 57

Eklemeli Sıralama (Insertion Sort): İki Sürüm

void insertion(int a[], int L, int R) {
    for (int i = L + 1; i <= R; i++) {
        int v = a[i];      // yerleştirilecek
        int j = i - 1;     // a[L..i-1] sıralı
        while (j >= L && a[j] > v) {
            a[j + 1] = a[j]; // sağa kaydır
            j--;
        }
        a[j + 1] = v;
    }
}
void insertion1(int a[], int L, int R) {
    for (int i = R; i > L; i--) // bekçi
        karsilas_degis(a[i], a[i - 1]);
    for (int i = L + 2; i <= R; i++) {
        int v = a[i], j = i;
        while (kucuk(v, a[j - 1])) {
            a[j] = a[j - 1];
            j--;
        }
        a[j] = v;
    }
}
  • Her turda girdiden bir öğe alınır ve sıralı ön ek içinde uygun konuma eklenir (iskambil kâğıdı dizer gibi).
  • Sağdaki insertion1, soldakinin ilerlemiş hâlidir: önce en küçüğü a[L]'ye taşır; bu bekçi (sentinel) sayesinde iç döngüde j > L sınaması gerekmez.
  • Düzeltme: notlardaki koşul j >= 0 idi; alt dizi L > 0'dan başlarsa sınırı aşar, doğrusu j >= L.

Eklemeli Sıralama · Kodu adım adım çalıştır

Kod İzleme: insertion(a, 0, 4)

i = 1: v = a[1] = 2 bir kenara alındı; a[0..0] sıralı, v için yer aranacak.

a[0] = 7 > v = 2 → 7 bir sağa kaydı (a[1]); j = -1.

j = −1, dizinin başına gelindi → döngü biter; a[0] = 2. Sıralı ön ek artık a[0..1].

i = 2: v = a[2] = 9 bir kenara alındı; a[0..1] sıralı, v için yer aranacak.

a[1] = 7 ≤ v → döngü biter; a[2] = 9. Sıralı ön ek artık a[0..2].

i = 3: v = a[3] = 5 bir kenara alındı; a[0..2] sıralı, v için yer aranacak.

a[2] = 9 > v = 5 → 9 bir sağa kaydı (a[3]); j = 1.

a[1] = 7 > v = 5 → 7 bir sağa kaydı (a[2]); j = 0.

a[0] = 2 ≤ v → döngü biter; a[1] = 5. Sıralı ön ek artık a[0..3].

i = 4: v = a[4] = 1 bir kenara alındı; a[0..3] sıralı, v için yer aranacak.

a[3] = 9 > v = 1 → 9 bir sağa kaydı (a[4]); j = 2.

a[2] = 7 > v = 1 → 7 bir sağa kaydı (a[3]); j = 1.

a[1] = 5 > v = 1 → 5 bir sağa kaydı (a[2]); j = 0.

a[0] = 2 > v = 1 → 2 bir sağa kaydı (a[1]); j = -1.

j = −1, dizinin başına gelindi → döngü biter; a[0] = 1. Sıralı ön ek artık a[0..4].

void insertion(int a[], int L, int R) {
    for (int i = L + 1; i <= R; i++) {
        int v = a[i];      // yerleştirilecek
        int j = i - 1;     // a[L..i-1] sıralı
        while (j >= L && a[j] > v) {
            a[j + 1] = a[j]; // sağa kaydır
            j--;
        }
        a[j + 1] = v;
    }
}

Eklemeli Sıralama · Kodu adım adım çalıştır

Kod İzleme: insertion1(a, 0, 3) (bekçili)

a[3] = 2 ≥ a[2] = 1 → takas yok. En küçük öğe sola doğru ilerliyor.

a[2] = 1 < a[1] = 3 → takas. En küçük öğe sola doğru ilerliyor.

a[1] = 1 < a[0] = 4 → takas. a[0] = 1 artık en küçük: bekçi hazır.

i = 2: v = 3. a[0..1] sıralı.

v = 3 < a[1] = 4 → kaydır; j = 1. Sınır sınaması yok: bekçi a[0] durduracak.

a[0] = 1 ≤ v → dur; a[1] = 3.

i = 3: v = 2. a[0..2] sıralı.

v = 2 < a[2] = 4 → kaydır; j = 2. Sınır sınaması yok: bekçi a[0] durduracak.

v = 2 < a[1] = 3 → kaydır; j = 1. Sınır sınaması yok: bekçi a[0] durduracak.

a[0] = 1 ≤ v → dur; a[1] = 2.

Eklemeli Sıralama · VYA2 s. 57

Eklemeli Sıralama: En İyi ve En Kötü Durum

En iyi: Ω(n)

Girdi sıralıysa seçilen öğe yalnızca sıralı listenin en sağındaki değerle kıyaslanır, daha büyük görülünce hemen yerine konur: toplam n − 1 karşılaştırma.

En kötü: O(n²)

Girdi ters sıralıysa her öğe sıralı listenin tümüyle kıyaslanıp en sola eklenir; sıralı dizi her turda 1 sağa kayar: 1 + 2 + … + (n−1) = n(n−1)/2.

Eklemeli sıralama kararlıdır (a[j] > v katı eşitsizlik: eşit öğe atlanmaz) ve yerindedir. Sıralıya yakın veride neredeyse doğrusaldır.

Eklemeli Sıralama · VYA2 s. 58

Ortalama Durum Analizi: j = 3 İçin Olası Durumlar

Durum 1: 8 > 10 yanlış → 1 karşılaştırma.

Durum 2: 8 > 7 doğru, 6 > 7 yanlış → 2 karşılaştırma.

Durum 3: 8 > 5 doğru, 6 > 5 doğru, 3 > 5 yanlış → 3 karşılaştırma.

Durum 4: 8 > 2 doğru, 6 > 2 doğru, 3 > 2 doğru; j = −1 olunca j >= 0 yanlış, a[j] > v hiç sınanmaz — sondan bir önceki durumla aynı sayıda → 3 karşılaştırma.

j öğesi j + 1 konumdan birine yerleşir: durumların 1'inde 1, 1'inde 2, 2'sinde 3 karşılaştırma. Olasılıklar eşit; yalnız sonuncu “3 karşılaştırma” sonucunu iki kez verir. Ortalama: (1 + 2 + 3 + 3)/4 = 2,25.

Eklemeli Sıralama · VYA2 s. 58

Ortalama Durum: Beklenen Karşılaştırma Sayısı

E(Cj) = (1/(j+1))·[2j + Σk=1j−1 k] = (j+2)/2 − 1/(j+1)

E(Y) = Σj=1N−1 E(Cj) = (N² + 3N)/4 − HN ≈ N²/4

  • Cj: j. öğeyi yerleştirirken yapılan karşılaştırma sayısı, bir rastlantı değişkeni; E(Cj) beklenen değeri.
  • HN = 1 + 1/2 + … + 1/N harmonik sayı: HN = ln N + O(1).
  • Ortalamada ≈ N²/4 karşılaştırma ve ≈ N²/4 yarı değişim (takas değil kaydırma) → O(n²).

Kabarcık Sıralama · VYA2 s. 59

Kabarcık Sıralama (Bubble Sort)

void bubble(int a[], int L, int R) {
    int i, j;
    for (i = L; i < R; i++)
        for (j = R; j > i; j--)
            karsilas_degis(a[j], a[j - 1]);
}
Hocadan “Dizi sıralıysa, hemen çıkacak şekilde daha dikkatli kodlanabilir. Bir döngü boyunca hiç takas yapılmamışsa sonraki döngüye girmeye gerek yoktur.” — Mustafa Ege, VYA2 ders notları, s. 59

Başlangıç: [7, 2, 9, 5, 1]. Her tur sağdan sola komşuları karşılaştırır.

Tur i = 0: en küçük kalan değer 1 kabarcık gibi a[0]'ye yükseldi → [1, 7, 2, 9, 5].

Tur i = 1: en küçük kalan değer 2 kabarcık gibi a[1]'ye yükseldi → [1, 2, 7, 5, 9].

Tur i = 2: en küçük kalan değer 5 kabarcık gibi a[2]'ye yükseldi → [1, 2, 5, 7, 9].

Tur i = 3: en küçük kalan değer 7 kabarcık gibi a[3]'ye yükseldi → [1, 2, 5, 7, 9].

Kabarcık Sıralama · Kodu adım adım çalıştır

Kod İzleme: Erken Durmalı bubble2(a, 0, 4)

Tur i = 0 başlıyor; takas bayrağı sıfırlandı.

a[4] < a[3] → takas: [2, 1, 3, 4, 5]; takas = 1.

a[3] = 4 ≥ a[2] = 3 → takas yok.

a[2] = 3 ≥ a[1] = 1 → takas yok.

a[1] < a[0] → takas: [1, 2, 3, 4, 5]; takas = 1.

takas = 1 → dizi henüz sıralı sayılamaz, sonraki tura geç.

Tur i = 1 başlıyor; takas bayrağı sıfırlandı.

a[4] = 5 ≥ a[3] = 4 → takas yok.

a[3] = 4 ≥ a[2] = 3 → takas yok.

a[2] = 3 ≥ a[1] = 2 → takas yok.

Bu turda hiç takas olmadı → dizi sıralı; erken çıkış. 2 tur boşuna yapılmadı.

void bubble2(int a[], int L, int R) {
    for (int i = L; i < R; i++) {
        int takas = 0;      // bu turda takas oldu mu?
        for (int j = R; j > i; j--)
            if (kucuk(a[j], a[j - 1])) {
                degistir(a[j], a[j - 1]);
                takas = 1;
            }
        if (!takas) return; // sıralı: erken çık
    }
}

Kabarcık Sıralama · VYA2 s. 59

Kabarcık Sıralamanın Analizi

  • Karşılaştırma: her durumda n(n−1)/2 ≈ n²/2 (erken durma yoksa).
  • Değiştirme: en kötü durumda (ters sıralı) n²/2; ortalamada evrik (inversion) sayısı kadar, yani ≈ n²/4.
  • Karmaşıklık O(n²); erken durmalı sürüm sıralı girdide O(n).
  • Yalnız komşular takaslanır ve eşitler takaslanmaz → kararlı, yerinde.

Evrik (Inversion): Eklemeli ve Kabarcığın Ortak Ölçüsü

Evrik: i < j iken a[i] > a[j] olan çift. [7, 2, 9, 5, 1] → (7,2), (7,5), (7,1), (2,1), (9,5), (9,1), (5,1)

  • Komşu takası (kabarcık) ya da bir konum kaydırma (eklemeli) tam olarak bir evriği giderir.
  • Bu yüzden ikisinde de takas/kaydırma sayısı = evrik sayısı: bu dizide 7 (izlerde de 7 kaydırma vardı).
  • Ters sıralı dizide n(n−1)/2 evrik; rastgele dizide ortalama n(n−1)/4 (her çift ½ olasılıkla ters).
  • Komşu öğelerle çalışan her algoritma ortalamada Ω(n²): uzak takas yapan Shell ve hızlı sıralama bu duvarı aşar.

Sayarak Sıralama · VYA2 s. 59

Sayarak Sıralama (Counting Sort)

int counting_sort(const int a[], int b[],
                  int r, int k) {
    int *c = malloc((k + 1) * sizeof *c);
    if (c == NULL) return -1;
    for (int i = 0; i <= k; i++) c[i] = 0;  // L1
    for (int j = 0; j <= r; j++) c[a[j]]++; // L2
    for (int i = 1; i <= k; i++)            // L3
        c[i] += c[i - 1];
    for (int j = r; j >= 0; j--) {          // L4
        b[c[a[j]] - 1] = a[j];
        c[a[j]]--;
    }
    free(c);
    return 0;
}

kdeğerler 0…k aralığında
  • 1954'te Harold H. Seward. Aralığı bilinen tamsayıları sıralar.
  • Değerler birbiriyle karşılaştırılmaz → non-comparison sort (kova sıralama da bu sınıftadır).
  • Düzeltme: notlardaki int c[K] sabit boyut ister; burada malloc + kontrol + free.

void shell_sort(int a[], int n) {
    for (int h = n / 2; h > 0; h /= 2) // aralık
        for (int i = h; i < n; i++) {
            int v = a[i], j = i;
            while (j >= h && a[j - h] > v) {
                a[j] = a[j - h];    // h geri kaydır
                j -= h;
            }
            a[j] = v;
        }
}

Shell ve Kova Sıralama · PDF dışı tamamlayıcı konu

Shell Sıralama (Shell Sort, 1959)

  • Eklemeli sıralamanın zayıflığı: öğe bir seferde yalnız bir konum ilerler; ters sıralıda O(n²).
  • Shell: önce uzak öğeleri (aralık h) sırala, h'yi küçült; son tur h = 1 ile biter, bu yüzden sonuç her zaman doğru.
  • Karmaşıklık aralık dizisine bağlıdır: h = n/2, n/4, … (Shell) için en kötü O(n²); Knuth'un 1, 4, 13, 40, … dizisi için O(n3/2).
  • Yerinde; ama uzak takaslar yüzünden kararlı değildir.
Notlarda

Notlar, veriye ait özellikler biliniyorsa shell sort ve paket (kova) sıralamanın birlikte kullanılabileceğini belirtir (VYA2 s. 74).

Uygulamada

Kısa kod + iyi pratik hız: gömülü sistemlerde ve küçük/orta dizilerde tercih edilir.

Shell ve Kova Sıralama · PDF dışı tamamlayıcı konu

Kova Sıralama (Bucket Sort)

Girdi [0, 1) aralığında 10 sayı; 10 kova, her kova 0,1 genişliğinde.

Dağıt: x değeri ⌊10·x⌋ numaralı kovaya eklenir (ör. .78 → 7, .17 → 1). O(n).

Her kovayı kendi içinde (eklemeli sıralamayla) sırala: kovalar küçük olduğundan ucuz.

Kovaları sırayla birleştir → sıralı çıktı. Düzgün dağılımda ortalama O(n).

Girdi aralıkta düzgün dağılmışsa kova başına beklenen öğe sayısı O(1) → ortalama O(n) (CLRS). Tüm öğeler aynı kovaya düşerse en kötü durum, kova içi sıralamanın maliyetidir (eklemeliyle O(n²)). Ek bellek O(n + kova sayısı).

Shell ve Kova Sıralama · PDF dışı tamamlayıcı konu

Kova Sıralama: C ile Gerçekleştirim

typedef struct kdugum { double x; struct kdugum *bag; } kdugum;

int bucket_sort(double a[], int n) {        /* 0 <= a[i] < 1 */
    kdugum **kova = calloc(n, sizeof *kova);
    kdugum *havuz = malloc(n * sizeof *havuz);
    if (!kova || !havuz) { free(kova); free(havuz); return -1; }
    for (int i = 0; i < n; i++) {           /* dağıt + sıralı ekle */
        kdugum **p = &kova[(int)(a[i] * n)];
        while (*p && (*p)->x <= a[i]) p = &(*p)->bag;
        havuz[i].x = a[i]; havuz[i].bag = *p; *p = &havuz[i];
    }
    int k = 0;                              /* kovaları birleştir */
    for (int b = 0; b < n; b++)
        for (kdugum *q = kova[b]; q; q = q->bag) a[k++] = q->x;
    free(kova); free(havuz);
    return 0;
}
  • n kova; a[i] değeri ⌊a[i]·n⌋ numaralı bağlı listeye sıralı eklenir (kova içi eklemeli sıralama).
  • <= sayesinde eşitler sona eklenir → kararlı. Düğümler tek bir havuz dizisinden alınır: n ayrı malloc yerine iki ayırma, tek free çifti.

Optimal Sıralama Zamanı · VYA2 s. 60

Optimal Sıralama Zamanı: Karar Ağacı

Sınamalar elips, kararlar (sıralamalar) dikdörtgen. n = 3 için yaprak sayısı 3! = 6.

Girdi a = 5, b = 8, c = 2. Kök: a < b? 5 < 8 → evet.

b < c? 8 < 2 → hayır: c, b'den önce gelmeli.

a < c? 5 < 2 → hayır.

Yaprak c < a < b → 2, 5, 8. Bu girdi için 3 karşılaştırma = yolun uzunluğu.

Karşılaştırmalı her sıralama algoritması bir karar ağacıdır: her iç düğüm bir kucuk() çağrısı, her yaprak girdinin bir dizilişi. En kötü durumdaki karşılaştırma sayısı = ağacın yüksekliği.

Optimal Sıralama Zamanı · VYA2 s. 60

Teorem: Karşılaştırmalı Sıralamanın Alt Sınırı

Teorem. n farklı öğeyi sıralayan her karar ağacının derinliği (düzey sayısı) en az ⌈log₂(n!)⌉ + 1dir; yani en kötü durumda en az ⌈lg(n!)⌉ karşılaştırma gerekir.
  • Yaprak sayısı en az n! (her diziliş bir yaprak).
  • Yüksekliği h olan ikili ağacın en çok 2h yaprağı vardır: 2h ≥ n! ⇒ h ≥ lg(n!).
  • Stirling: ⌈lg(n!)⌉ = n lg n − n lg e + Θ(lg n) ≈ n lg n − 1,4427 n.
  • Sonuç: karşılaştırmalı sıralama Ω(n lg n); sayarak/kova/basamak sıralama karşılaştırma yapmadığı için bu sınıra takılmaz.
