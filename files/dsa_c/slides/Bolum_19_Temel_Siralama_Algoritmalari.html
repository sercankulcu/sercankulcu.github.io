Temel İşlemler

Insertion sort

for (size_t i = 1; i < n; ++i) {
    int anahtar = a[i];
    size_t j = i;
    while (j > 0 && a[j - 1] > anahtar) {
        a[j] = a[j - 1]; --j;
    }
    a[j] = anahtar;
}
Kod örnekleri C99/C11 uyumlu olacak biçimde küçük ve tek sorumluluklu tutulmuştur.
