Array ADT · Horowitz 2.1

An Array: a Set of ⟨Index, Value⟩ Pairs

Abstractly, an array is a mapping: each defined index is associated with a value. “Consecutive memory cells” is the most common implementation of this ADT, not its definition.

OperationMeaning
Create(j, list)an empty array of j dimensions with index set list
Retrieve(A, i)return A[i] if i is a valid index, else an error
Store(A, i, x)if i is valid, return a new array where i maps to x
Why is it fast?

Given the base address α and element size s, A[i] is at α + i·s: one multiply and one add, O(1).

The price

The size is fixed up front; inserting or deleting in the middle shifts the elements after it: O(n).

Array ADT · C implementation

Declaring Arrays in C, and Addresses

int list[5], *plist[5];
/* list : 5 ints         */
/* plist: 5 int pointers */

list[i]  /* address: α + i * sizeof(int) */
sizeof list   /* 5 * sizeof(int) bytes */

The compiler keeps the address of list[0] (α); the address of list[i] is computed at run time. Indices are not checked: writing list[5] is undefined behavior.

Addresses assuming sizeof(int) = 4

Indices start at 0: the valid indices of an n-element array are 0 … n−1.

Array ADT · Arrays and pointers

Array Name ≈ Address of the First Element

ExpressionEquivalent
list&list[0]
list + i&list[i] (i·sizeof(int) bytes further)
*(list + i)list[i]
p = list; p[i]the same cell as list[i]

Pointer arithmetic counts elements, not bytes: p + 1 points to the next int.

Difference 1: no assignment

list = p; does not compile; an array name is a constant address, not a variable.

Difference 2: sizeof

For a local array, sizeof list gives the whole array; for a parameter, the pointer size.

Parameters

void f(int a[]) ≡ void f(int *a): the array is not copied, its address is passed; the size goes in a separate parameter.

Array ADT · Run the code step by step

Pointer Arithmetic: *(p + i)

arr is allocated on the stack as 4 consecutive ints; call the address of the first one α.

The call does not copy the array: only the value &arr[0] (α) is passed to p.

0 < 4 → keep looping. p + 0 = α + 0·4 = α+0.

*(p + 0) reads the value at that address: 10 (≡ p[0]).

1 < 4 → keep looping. p + 1 = α + 1·4 = α+4.

*(p + 1) reads the value at that address: 20 (≡ p[1]).

2 < 4 → keep looping. p + 2 = α + 2·4 = α+8.

*(p + 2) reads the value at that address: 30 (≡ p[2]).

3 < 4 → keep looping. p + 3 = α + 3·4 = α+12.

*(p + 3) reads the value at that address: 40 (≡ p[3]).

4 < 4 is false → the loop ends; print_array returns.

The address grows by 4 bytes per line. (Real %p output is a hexadecimal address; shown here as α.)

void print_array(int *p, int n) {
  int i;
  for (i = 0; i < n; i++)
    printf("%p %d\n", (void *)(p + i), *(p + i));
}

int main(void) {
  int arr[] = {10, 20, 30, 40};
  print_array(arr, 4);
  return 0;
}

Dynamic Arrays · malloc / free

An Array Whose Size Is Known Only at Run Time

int n, i, *a;
scanf("%d", &n);
a = malloc(n * sizeof *a);   /* n ints */
if (a == NULL) {
  fprintf(stderr, "Out of memory\n");
  exit(EXIT_FAILURE);
}
for (i = 0; i < n; i++)
  a[i] = i * i;              /* like an array */
free(a);                     /* give it back */
a = NULL;          /* no dangling pointer */
Stack vs. heap memory

A local array disappears when the function returns; a malloc block lives until it is freed.

The sizeof *a idiom

Gives the right size even if the type changes; avoids mixing it up with sizeof(int*).

calloc(n, s)

Allocates a zeroed block; realloc grows or shrinks a block.

Dynamic Arrays · Run the code step by step

A Growing Array: Double the Capacity

An empty dynamic array: {NULL, 0, 0}. We append 7, 3, 9, 4, 6 in order.

0 == 0 → full, must grow.

newcap = 1. realloc returns a 1-cell block; the 0 old elements are copied (realloc from NULL = malloc). The result goes into t first, so the old block survives a failure.

t != NULL: d->data = t, cap = 1.

data[0] = 7, then size++ → 1. (Postfix: use first, then increment.)

1 == 1 → full, must grow.

newcap = 2. realloc returns a 2-cell block; 1 old element is copied (1 copy so far). The result goes into t first, so the old block survives a failure.

t != NULL: d->data = t, cap = 2.

data[1] = 3, then size++ → 2. (Postfix: use first, then increment.)

2 == 2 → full, must grow.

newcap = 4. realloc returns a 4-cell block; 2 old elements are copied (3 copies so far). The result goes into t first, so the old block survives a failure.

t != NULL: d->data = t, cap = 4.

data[2] = 9, then size++ → 3. (Postfix: use first, then increment.)

3 == 4 is false → there is room; store directly.

data[3] = 4, then size++ → 4. (Postfix: use first, then increment.)

4 == 4 → full, must grow.

newcap = 8. realloc returns an 8-cell block; 4 old elements are copied (7 copies so far). The result goes into t first, so the old block survives a failure.

t != NULL: d->data = t, cap = 8.

data[4] = 6, then size++ → 5. Five appends cost only 7 copies in total.

typedef struct { int *data; int size, cap; } DynArray;

int append(DynArray *d, int x) {
  if (d->size == d->cap) {               /* full */
    int newcap = d->cap ? 2 * d->cap : 1;
    int *t = realloc(d->data, newcap * sizeof *t);
    if (t == NULL) return 0;    /* old block intact */
    d->data = t;
    d->cap = newcap;
  }
  d->data[d->size++] = x;
  return 1;
}

With doubling the copies are 1 + 2 + 4 + … + 2k < 2n → O(n) in total (total cost < 3n including the n writes), so O(1) per append (amortized). Growing by 1 (or any constant c) each time costs n(n−1)/2 = O(n²) copies.

A single append can still be O(n)

The append that triggers growth is expensive; amortized analysis guarantees the average over a long sequence.

Memory overhead

Capacity is at most 2·size; the price is at most 50% empty cells.

The realloc trap

If a = realloc(a, …) fails, it returns NULL and the old block is lost (a leak). Assign to a temporary first.

A Dynamic 2D Array: An Array of Pointers + Rows

First allocate an array of pointers with 3 cells (sizeof *x = sizeof(int *)); its contents are still indeterminate.

x != NULL: allocation succeeded, go on.

i = 0 < 3 → allocate row 0.

x[0] points to a new block of 4 ints (sizeof **x = sizeof(int)). Not NULL.

i = 1 < 3 → allocate row 1.

x[1] points to a new block of 4 ints (sizeof **x = sizeof(int)). Not NULL.

i = 2 < 3 → allocate row 2.

x[2] points to a new block of 4 ints (sizeof **x = sizeof(int)). Not NULL.

3 < 3 is false → the loop ends.

Return x; x[i][j] ≡ *(*(x + i) + j). The rows need not be contiguous. To release it, free each x[i] first, then x.

int **make2d(int rows, int cols) {
  int i, **x = malloc(rows * sizeof *x);
  if (x == NULL) return NULL;
  for (i = 0; i < rows; i++) {
    x[i] = malloc(cols * sizeof **x);
    if (x[i] == NULL) {                /* undo */
      while (--i >= 0) free(x[i]);
      free(x); return NULL;
    }
  }
  return x;
}

Multidimensional Arrays

Memory Is One-Dimensional, Arrays Are Not

An n-dimensional array declared as A[upper0][upper1]…[uppern−1] has ∏ upperi elements. E.g. A[10][10][10] → 1000 elements.

Memory, however, is a one-dimensional array of bytes; the compiler must lay the elements out in some order:

  • Row major: all of row 0 first, then row 1… (the default in C, C++, Python/NumPy)
  • Column major: column 0 first… (Fortran, MATLAB)
The question is always the same: how many elements come before A[i][j]? Address = α + (number before it) · element size.
In C

int x[3][4]; is really an array of 3 elements, each an array of 4; x[1] points to the start of row 1.

Multidimensional Arrays

int x[3][4] Can Be Laid Out in Two Ways

Row major: before x[i][j] come i full rows (i·upper1 elements) and j elements → &x[i][j] = α + (i·upper1 + j)·s. C uses this.

Column major: first j full columns (j·upper0 elements), then i elements → &x[i][j] = α + (j·upper0 + i)·s. The same element lands elsewhere: x12 → 6 in row major, 7 in column major.

The formula α + i·upper1 + j counts elements (cells); multiply by s = sizeof(element) for a byte address.

Multidimensional Arrays · Run the code step by step

Computing a Row-Major Address

We want the address of x[1][2]: α = 100, row length upper1 = 4, s = 4 bytes.

Before it: 1 full row (1·4 = 4 elements) and 2 elements in its row → k = 6 (blue cells).

Return 100 + 6·4 = 124.

printf prints 124. In column-major order k = j·3 + i = 7 → 128.

We want the address of x[2][3]: α = 100, row length upper1 = 4, s = 4 bytes.

Before it: 2 full rows (2·4 = 8 elements) and 3 elements in its row → k = 11 (blue cells).

Return 100 + 11·4 = 144.

printf prints 144. The last element: 100 + 11·4 = 144.

/* int x[3][4]: row-major byte address */
long address(long alpha, int i, int j,
             int u1, int s) {
  long k = (long)i * u1 + j;   /* elements before */
  return alpha + k * s;
}

int main(void) {
  printf("%ld\n", address(100, 1, 2, 4, 4));
  printf("%ld\n", address(100, 2, 3, 4, 4));
  return 0;
}

Multidimensional Arrays

G[2][2][3]: Plane · Row · Column

elementaddress (in elements)
[0][0][0]α
[i][0][0]α + i·u1·u2
[i][j][0]α + i·u1·u2 + j·u2
[i][j][k]α + i·u1·u2 + j·u2 + k

The last expression has 3 multiplications + 3 additions. Multiplication costs more than addition, so the compiler factors it:

α + (i·u1 + j)·u2 + k

→ 2 multiplications + 3 additions. Example: [1][0][2] → (1·2 + 0)·3 + 2 = 8.

Multidimensional Arrays

The Address Formula for n Dimensions

For A[u0][u1]…[un−1]:

elementaddress
A[0][0]…[0]α
A[i0][0]…[0]α + i0·u1u2…un−1
A[i0][i1]…[0]… + i1·u2…un−1
A[i0]…[in−1]… + in−1

&A[i0]…[in−1] = α + Σj=0n−1 ij·aj

aj = ∏k=j+1n−1 uk (0 ≤ j < n−1), an−1 = 1

The coefficients aj depend only on the dimensions, so the compiler computes them once. In Horner form n−1 multiplications suffice: t = i0; t = t·uj + ij.

Multidimensional Arrays · Run the code step by step

Relative Position in n Dimensions: Horner’s Method

We look for G[1][0][2]. t = idx[0] = 1: plane number 1.

j = 1 < 3 → one dimension further in.

t = 1·2 + 0 = 2: the “global row” number counted across planes (plane 1, row 0).

j = 2 < 3 → one dimension further in.

t = 2·3 + 2 = 8: 8 elements come before → cell 8.

3 < 3 is false → the loop ends.

Return 8. 2 multiplications in total (n−1). Check: 1·2·3 + 0·3 + 2 = 8. dim[0] was never used!

/* idx: indices, dim: sizes, n: dimensions */
int offset(const int idx[], const int dim[], int n) {
  int j, t = idx[0];
  for (j = 1; j < n; j++)
    t = t * dim[j] + idx[j];            /* Horner */
  return t;               /* address = alpha + t*s */
}

Triangular and Band Matrices

Keeping Half a Matrix in a One-Dimensional Array

The diagonal splits a square matrix in two; sometimes one half is enough (distances between cities, atomic weights in the periodic table…). The data lives in a one-dimensional array LOW; the user gets an interface that behaves like a two-dimensional matrix.

Row i holds i+1 elements → n(n+1)/2 in total. For aij, count the elements of earlier rows plus its place in the row:

k = i(i+1)/2 + j  (j ≤ i)

#define MAX_SIZE 100
void read_lower(int low[], int n) {
  int i, j, k;
  if (n * (n + 1) / 2 > MAX_SIZE) {
    printf("Array too small!\n"); exit(1);
  }
  for (i = 0; i < n; i++) {
    k = (i + 1) * i / 2;      /* before row i */
    for (j = 0; j <= i; j++)  /* j <= i */
      scanf("%d", &low[k + j]);
  }
}

Triangular and Band Matrices

Band Matrices: Store Only the Diagonal band

Elements outside the band are unused or all equal to a constant c. n: side (4), a: number of lower bands including the diagonal (3), b: number of upper bands including the diagonal (2).

elements = n(a+b−1) − a(a−1)/2 − b(b−1)/2 = 12

Instructor “Storing it is not the problem; can we access it quickly?”

Triangular and Band Matrices

Band number j − i and the START Array

  • j − i is constant along a band: for d20 and d31, 0−2 = 1−3 = −2. The main diagonal is 0; negatives are lower bands, positives upper.
  • Valid bands lie in the closed range [1 − a, b − 1]; outside is the constant region.
  • START holds the position in band[] of each band’s first element: a + b − 1 entries. C has no negative indices, so we shift by band number + a − 1.
  • Position within the band: j in a lower band, i in an upper band (each band starts in row 0 or column 0).
Instructor “I design the mechanism by analyzing as if every resource were scarce.”

void build_band(int band[], int start[],
                int n, int a, int b) {
  int i, k, total = 0;       /* earlier bands */
  if (n*(a+b-1) - a*(a-1)/2 - b*(b-1)/2 > MAX_SIZE) {
    printf("Out of memory!\n"); exit(-1);
  }
  for (i = 1 - a; i <= b - 1; i++) {  /* band by band */
    start[i + a - 1] = total;       /* band start */
    for (k = 0; k <= n - abs(i) - 1; k++)
      scanf("%d", &band[start[i + a - 1] + k]);
    total += n - abs(i);
  }
}

int band_index(int i, int j, int n, int a,
               int b, int start[]) {
  if (i < 0 || j < 0 || i >= n || j >= n) {
    printf("Index out of range\n"); return -3;
  } else if (j - i >= 1) {         /* upper triangle */
    if (j - i < b)               /* valid band */
      return start[j - i + a - 1] + i;
    else return -1;              /* upper constant */
  } else if (i - j < a)          /* diagonal/lower */
    return start[j - i + a - 1] + j;
  else
    return -2;                   /* lower constant */
}

A START Array or a Formula? (HOMEWORK 1)

HOMEWORK 1: Compute the band start without the START array. (A sample solution is on the right.)

/* t: band number (1-a..b-1); same as start[t+a-1] */
int band_start(int t, int n, int a) {
  if (t <= 0)                     /* lower bands */
    return (t + a - 1) * n
           - (a * (a - 1) + t * (1 - t)) / 2;
  return (a - 1) * n - a * (a - 1) / 2  /* start of t=0 */
         + t * n - t * (t - 1) / 2;
}

n = 4, a = 3: t = −2, −1, 0, 1 → 0, 2, 5, 9 (same as START). A script tried every a, b for n ≤ 11. Access: band_start(j−i, n, a) + (j > i ? i : j).

Triangular and Band Matrices

Is if (expr1 && expr2) Safe?

A common belief: “We can’t know whether the compiler scans right to left or left to right, so the second of these two equivalent forms is safer.”

/* 1 */ if (i < n && a[i] != 0) ...

/* 2 */ if (i < n)
          if (a[i] != 0) ...
In fact: the C standard guarantees left-to-right evaluation and short-circuiting for && and || (C99 §6.5.13–14): if the left side is false, the right side is never evaluated. Both forms are equally safe; form 1 is a common and correct idiom.
The real trap

& (bitwise AND) does not short-circuit, and the order of evaluation of operands such as in f(x) + g(x) is unspecified.

  enum { FEMALE, MALE } sex;   /* tag */
  union {
    int children;              /* if FEMALE */
    int beard;                 /* if MALE */
  } u;
} sex_type;

sex_type s;
s.sex = MALE;
s.u.beard = 0;   /* read only the field the tag allows */

A union is as large as its largest field (+ alignment). Tracking which field is valid with a tag field is the programmer’s job.

Field order changes the memory layout (compiler-dependent; typical 32/64-bit values)

Walking Through an Array of Structures

An array of structures sits in memory record after record; each record is sizeof(Student) bytes.

0 < 3 → record 0.

Add s[0].gpa = 3.2 → sum = 3.2.

1 < 3 → record 1.

Add s[1].gpa = 2.6 → sum = 5.8.

2 < 3 → record 2.

Add s[2].gpa = 3.5 → sum = 9.3.

3 < 3 is false → the loop ends.

n > 0 → return 9.3 / 3 = 3.10. For n = 0 it returns 0.0 instead of dividing by zero.

typedef struct {
  int id;
  char name[16];
  double gpa;
} Student;

double class_avg(const Student s[], int n) {
  double sum = 0.0;
  int i;
  for (i = 0; i < n; i++)
    sum += s[i].gpa;               /* field via . */
  return n > 0 ? sum / n : 0.0;    /* empty class */
}

const Student s[]: the array is not copied; const documents that the function will not modify the records.

How Does strlen Work?

p points to the same place as s (the first character).

*p = 'd' ≠ '\0' → continue.

p++: one character (1 byte) forward.

*p = 'a' ≠ '\0' → continue.

p++: one character (1 byte) forward.

*p = 't' ≠ '\0' → continue.

p++: one character (1 byte) forward.

*p = 'a' ≠ '\0' → continue.

p++: one character (1 byte) forward.

*p = '\0' → the loop ends.

Return p − s = 4. Finding the length scans the whole string: O(n) — calling strlen in a loop condition makes it O(n²)!

size_t length(const char *s) {
  const char *p = s;
  while (*p != '\0')     /* up to the terminator */
    p++;
  return (size_t)(p - s);  /* pointer difference */
}

Matrix Multiplication: Three Nested Loops

c[0][0] uses row 0 of a and column 0 of b; start at 0.

k = 0: += a[0][0]·b[0][0] = 1·5 → 5.

k = 1: += a[0][1]·b[1][0] = 2·7 → 19.

c[0][1] uses row 0 of a and column 1 of b; start at 0.

k = 0: += a[0][0]·b[0][1] = 1·6 → 6.

k = 1: += a[0][1]·b[1][1] = 2·8 → 22.

c[1][0] uses row 1 of a and column 0 of b; start at 0.

k = 0: += a[1][0]·b[0][0] = 3·5 → 15.

k = 1: += a[1][1]·b[1][0] = 4·7 → 43.

c[1][1] uses row 1 of a and column 1 of b; start at 0.

k = 0: += a[1][0]·b[0][1] = 3·6 → 18.

k = 1: += a[1][1]·b[1][1] = 4·8 → 50.

Done: [[19, 22], [43, 50]]. The innermost statement ran N³ = 8 times → O(n³).

#define N 2
void mult(int a[][N], int b[][N], int c[][N]) {
  int i, j, k;
  for (i = 0; i < N; i++)
    for (j = 0; j < N; j++) {
      c[i][j] = 0;
      for (k = 0; k < N; k++)
        c[i][j] += a[i][k] * b[k][j];
    }
}

Matrix Operations · homework

Homework: Matrix Multiplication and Transpose

  1. Build the step count table for mult (n×n); how many multiplications are performed?
  2. What is the complexity of multiplying an m×n matrix by an n×p matrix? How many cells does the result have?
  3. Write a function that transposes an n×n matrix without an extra array (in place).
Solutions
  1. for i: n+1 · for j: n(n+1) · c=0: n² · for k: n²(n+1) · +=: n³ → 2n³ + 3n² + 2n + 1 = O(n³); n³ multiplications. (Verified by a script for n = 1…9.)
  2. n products per c[i][j]: O(m·n·p); m·p cells.
  3. for (i = 0; i < n; i++) for (j = i + 1; j < n; j++) { t = a[i][j]; a[i][j] = a[j][i]; a[j][i] = t; } — only the upper triangle is visited (starting at j = 0 would swap every pair twice and leave the matrix unchanged). n(n−1)/2 swaps → O(n²).

Common Mistakes

1Writing past the end of an array (a[n]); C does not check.
2a = realloc(a, …): losing the old block on failure.
3Mixing up sizeof(int *) and sizeof(int); using sizeof a on a parameter.
4Freeing only the pointer array of a 2D dynamic array, not its rows.
5Mixing up the row- and column-major formulas; forgetting the element size (s).
6Using == on strings, or leaving no room for '\0'.

Chapter Summary

Array = mapping

ADT: ⟨index, value⟩; the C implementation is contiguous memory with address α + i·s.

Addressing

Row major: α + (i·u1 + j)·s; in n dimensions, n−1 multiplications with Horner.

Saving space

Triangle: n(n+1)/2 elements, k = i(i+1)/2 + j. Band: bands numbered j − i + START.

Dynamic memory

malloc/realloc/free; growth by doubling is amortized O(1); a 2D array = an array of pointers.

Records

A struct groups fields, a union shares them; a string is a char array ending in '\0'.

Matrices

Addition O(mn), multiplication O(n³).
