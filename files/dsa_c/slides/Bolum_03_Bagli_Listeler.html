Öğrenme Çıktıları

Düğüm kurmak

Öz-referanslı struct tanımlar, malloc sonucunu denetler, free ile iade edersin.

Bağ disiplini

Başa, sona, araya ve sıralı eklemeyi bağı kaybetmeden, doğru sırayla yaparsın.

Güvenli silme

Bellek sızıntısı ve sarkan gösterge (dangling pointer) oluşturmadan düğüm silersin.

Klasik yordamlar

Ters çevirme, birleştirme, orta düğüm ve Floyd döngü bulmayı O(1) ek bellekle yazarsın.

Liste türleri

Dairesel, çift bağlaçlı ve başlık düğümlü listeleri amaca göre seçersin.

Bellek yönetimi

Kullanılabilir düğüm listesiyle (available space list) düğümleri yeniden kullanırsın.

Neden Liste?

Dizi yetmediğinde: kaydırma yerine bağ

8'den sonra 10 eklenecek. Dizide yer açmak için arkadaki öğeler kaydırılır; listede yalnızca bağlar değişir.

Dizi: 20 bir sağa kaydı (1. taşıma).

Dizi: 12 bir sağa kaydı (2. taşıma). n öğeli dizide en kötü durumda n taşıma: O(n).

Dizi: boşalan hücreye 10 yazıldı.

Liste: yeni düğüm ayrıldı, yeni->bag 12'yi gösterdi. Hiçbir öğe yer değiştirmedi.

Liste: 8->bag = yeni. Konum biliniyorsa yalnızca iki bağ: O(1).

Hocadan “Pointerları bu yaşlarda öğrendin öğrendin, yoksa 4. sınıfta bile pointer'ı öğrenmemiş olursun.”

Neden Liste?

Düğümler bellekte yan yana olmak zorunda değil

Düğüm = veri + bağ

bag (link) alanı sonraki düğümün adresini tutar; son düğümde NULL.

Rastgele erişim yok

i. düğümün adresi hesaplanamaz; baştan bağlar izlenir: O(i).

Adres nedir?

Notlarda: adres iki parçalı (kesim + kesim içi adresi) — eski x86 bölütlü bellek. Günümüzde düz adres uzayı.

Neden Liste?

İşaretçi (pointer) hatırlatması

int x = 5;
int *p = &x;       // p, x'in adresini tutar
*p = 7;            // p'nin gösterdiğine yaz: x == 7

oge_gost q = NULL; // henüz hiçbir düğüm yok
q = malloc(sizeof *q);
if (q != NULL) {
    q->deger = 3;  // (*q).deger = 3
    q->bag = NULL;
}
free(q);           // iade; q artık sarkan gösterge
q = NULL;
& ve *

&x: x'in adresi · *p: p'nin gösterdiği nesne.

->

q->deger, (*q).deger ile aynıdır; öncelik için parantez şart.

NULL

Hiçbir yeri göstermeyen gösterge; boş listenin gösterimi.

Hocadan “– Ben iki derstir ne anlatıyorum? Dersi bıraktım, C anlattım, pointerları anlattım. – Ben pointerları çok iyi biliyorum, ama hoca bir şey diyor, yine de anlamadım. – Olabilir.”

Neden Liste?

Düğüm ayırmak: malloc, denetim, free

oge_gost yeni_oge(int x) {
    oge_gost p = malloc(sizeof *p);
    if (p == NULL) {
        fprintf(stderr, "Bellek yetmiyor yetmiyoor...\n");
        exit(1);
    }
    p->deger = x;
    p->bag = NULL;
    return p;
}
sizeof *p ve NULL

Türü tekrar yazmadan doğru boyut. Bellek bitince malloc NULL döner; notlardaki ileti: Bellek yetmiyor yetmiyoor...

free kuralı

Her malloc için tam bir free; iki kez free ya da free sonrası erişim tanımsız davranıştır.

Hocadan “Her pointer'a malloc'la yer ayırmak gerekmiyor, yok öyle bir şey!”

Dolaşan göstergeler (p = p->bag) var olan düğümleri gösterir; onlar için malloc yapılmaz.

Tek Bağlaçlı Liste

Düğüm: öz-referanslı yapı (self-referential struct)

typedef struct oge *oge_gost;  // önce gösterge türü

struct oge {
    int deger;       // veri alanı
    oge_gost bag;    // sonraki düğümün adresi
};

oge_gost liste = NULL;  // boş liste
Neden önce typedef?

Yapı kendi türünden bir göstergeyi içerir; eksik (incomplete) türe gösterge tanımlamak serbesttir.

Adlandırma

Ders notlarında list_gosterge ve oge_gost adları geçer; burada oge_gost.

Notlardaki kodda düzeltme: notlardaki typedef struct liste { … }; satırında typedef'e ad verilmemiş; typedef atılmalı ya da sona tür adı yazılmalı.

Tek Bağlaçlı Liste · Adım adım

Listeyi dolaşmak: p = p->bag

yazdir(liste): gösterge değerle geldi; p'yi ilerletmek main'deki liste'yi değiştirmez.

p ilk düğümde: 7 yazılır.

p = p->bag: ikinci düğüm.

2 yazılır.

Üçüncü düğüm.

9 yazılır.

p == NULL: döngü biter.

Satır sonu. n düğüm için n tur: O(n).

void yazdir(oge_gost p) {
    for (; p != NULL; p = p->bag)
        printf("%d ", p->deger);
    printf("\n");
}

Uzunluk aynı kalıpla sayılır: for (; p != NULL; p = p->bag) n++;

Tek Bağlaçlı Liste

Başa ekleme ve adresle aktarım

bool basa_ekle(oge_gost *bas, int x) {
    oge_gost yeni = malloc(sizeof *yeni);
    if (yeni == NULL) return false;
    yeni->deger = x;
    yeni->bag = *bas;
    *bas = yeni;
    return true;
}

oge_gost liste = NULL;
basa_ekle(&liste, 2);   // 2
basa_ekle(&liste, 7);   // 7 -> 2
Neden oge_gost *bas?

Baş değişecek. Değerle gelseydi yalnızca yerel kopya değişir, main'deki liste eski kalırdı.

Sıra önemli

Önce *bas = yeni yazılsaydı düğüm kendine bağlanır, listenin kalanı kaybolurdu. Maliyet O(1).

Hocadan “Normal şartlarda yordamın formal parametre listesinde ‘*parametre’ olarak gözüken değişken, yordam içinde de ‘*parametre’ olarak kullanılmalıdır.”

Tek Bağlaçlı Liste · Kodu adım adım çalıştır

Kod İzleme: basa_ekle(&liste, 5)

Çağrı: basa_ekle(&liste, 5). bas, main'deki liste değişkeninin adresidir; liste 7 → 2.

malloc yığın bellekten (heap) bir düğüm ayırdı. Alanları henüz çöp değer taşıyor.

yeni != NULL: bellek ayrılabildi, devam. (Ayrılamasaydı liste hiç bozulmadan false dönecekti.)

Veri alanı dolduruldu: yeni->deger = 5.

Önce eski baş korunur: yeni->bag = *bas → yeni düğüm 7'yi gösterir. liste hâlâ 7'de.

Sonra baş değişir: *bas = yeni. Adresle aktarım sayesinde main'deki liste güncellendi.

Liste artık 5 → 7 → 2. Liste uzunluğundan bağımsız, sabit sayıda iş: O(1).

bool basa_ekle(oge_gost *bas, int x) {
    oge_gost yeni = malloc(sizeof *yeni);
    if (yeni == NULL) return false;  // bellek yok
    yeni->deger = x;
    yeni->bag = *bas;    // önce eski başı koru
    *bas = yeni;         // sonra başı değiştir
    return true;
}

Tek Bağlaçlı Liste · Adım adım

Sona ekleme: son düğümü bulmak O(n)

Yeni düğüm (5) hazır; bag = NULL çünkü son olacak.

Liste boş değil: p baştan başlar.

p->bag == NULL olana dek ilerler: son düğüm 6. Bu yürüyüş O(n).

p->bag = yeni. Sürekli sona ekleniyorsa bir son göstergesi tutmak işi O(1) yapar (kuyruk, Bölüm 5).

bool sona_ekle(oge_gost *bas, int x) {
    oge_gost p, yeni = malloc(sizeof *yeni);
    if (yeni == NULL) return false;
    yeni->deger = x;
    yeni->bag = NULL;              // yeni son düğüm
    if (*bas == NULL) { *bas = yeni; return true; }
    for (p = *bas; p->bag != NULL; p = p->bag)
        ;                          // son düğümü bul
    p->bag = yeni;
    return true;
}

Tek Bağlaçlı Liste · Adım adım

Araya ekleme: önce sonrakini koru, sonra bağla

12 → 7 → 25; onceki = düğüm(7). 7'nin peşine 9 eklenecek.

yeni_oge(9): düğüm ayrıldı, bag = NULL.

p->bag = onceki->bag: 25'in adresi yeni düğüme kopyalandı; hiçbir şey kaybolmadı.

onceki->bag = p: 12 → 7 → 9 → 25. Düğüm biliniyorsa O(1).

// onceki'nin peşine x değerli yeni düğüm ekler
oge_gost sonrasina_ekle(oge_gost onceki, int x) {
    oge_gost p = yeni_oge(x);  // malloc + denetim
    if (onceki != NULL) {      // araya ya da sona
        p->bag = onceki->bag;
        onceki->bag = p;
    }                          // yoksa tek başına
    return p;
}

Polinom çarpımındaki YeniTerimEkle(Ust, Katsayi, Onceki) yordamının genelleştirilmiş hâli.

Tek Bağlaçlı Liste · Kodu adım adım çalıştır

Kod İzleme: sirali_ekle() — 7 ekle

Sıralı liste 2 → 5 → 9'a 7 eklenecek. Yeni düğüm (malloc ile) hazır; yeni->bag henüz bağlı değil.

p baştan başlar; onceki, p'nin bir gerisinden gelecek (şimdilik NULL).

Koşul: 2 < 7 → doğru. Daha ileri gitmeliyiz.

onceki = p → düğüm(2).

p = p->bag → &düğüm(5).

Koşul: 5 < 7 → doğru. Daha ileri gitmeliyiz.

onceki = p → düğüm(5).

p = p->bag → &düğüm(9).

Koşul: 9 < 7 → yanlış. Ekleme yeri bulundu: onceki ile p arası.

Önce yeni düğüm p'ye bağlanır: yeni->bag = p (9'un adresi kaybolmasın).

onceki != NULL: başa değil, araya ekliyoruz; baş değişmeyecek.

onceki->bag = yeni: 5 artık 7'yi gösteriyor. Liste 2 → 5 → 7 → 9.

void sirali_ekle(oge_gost *bas, oge_gost yeni) {
    oge_gost onceki = NULL, p = *bas;
    while (p != NULL && p->deger < yeni->deger) {
        onceki = p;
        p = p->bag;
    }
    yeni->bag = p;
    if (onceki == NULL) *bas = yeni;  // başa
    else onceki->bag = yeni;          // araya/sona
}

Silme: silinecek düğümün öncesi gerekir

Tek bağlaçlı listede bir düğümü silmek için onun öncesindeki düğüm gerekir: burada 3.

silinecek = onceki->bag: adres saklandı; yoksa free edemezdik.

onceki->bag = silinecek->bag: 3 artık 2'yi gösteriyor, 8 zincirden çıktı.

free(silinecek): bellekteki kalıntı temizlendi. Baş düğüm silinecekse öncesi yoktur → özel durum (ya da başlık düğümü).

// onceki'den sonra gelen düğümü listeden ve
// bellekten siler
void sonrakini_sil(oge_gost onceki) {
    oge_gost silinecek = onceki->bag; // adresi tut
    if (silinecek == NULL) return; // silinecek yok
    onceki->bag = silinecek->bag;  // bağı düzelt
    free(silinecek);               // kalıntıyı sil
}

Ders notlarındaki SonrakiTerimiSil(Onceki); açıklamalar notlardaki yorum satırlarından.

Tek Bağlaçlı Liste · Kodu adım adım çalıştır

Kod İzleme: sil(&liste, 1)

Liste 3 → 8 → 1 → 6, silinecek x = 1. p baştan, onceki = NULL.

Koşul 3 != 1 → doğru. Aramaya devam.

onceki = p → düğüm(3).

p = p->bag → &düğüm(8).

Koşul 8 != 1 → doğru. Aramaya devam.

onceki = p → düğüm(8).

p = p->bag → &düğüm(1).

Koşul 1 != 1 → yanlış. Silinecek düğüm bulundu; onceki bir gerisinde.

p != NULL: x listede var, silmeye geçilir.

onceki != NULL: silinen baş düğüm değil; *bas değişmeyecek.

onceki->bag = p->bag: 8 artık 6'yı gösteriyor; 1 zincirden atlandı.

free(p): düğüm belleğe iade edildi. Bunu unutursak bellek sızıntısı (memory leak) olur.

Liste 3 → 8 → 6. Arama O(n), bağ değişimi O(1): toplam O(n).

bool sil(oge_gost *bas, int x) {
    oge_gost onceki = NULL, p = *bas;
    while (p != NULL && p->deger != x) {
        onceki = p;
        p = p->bag;
    }
    if (p == NULL) return false;        // x yok
    if (onceki == NULL) *bas = p->bag;  // baştaki
    else onceki->bag = p->bag;          // atla
    free(p);
    return true;
}

Tek Bağlaçlı Liste

Arama ve i. düğüme erişim

oge_gost ara(oge_gost p, int x) {
    while (p != NULL && p->deger != x)
        p = p->bag;
    return p;               // bulunamazsa NULL
}

oge_gost konum(oge_gost p, int i) {  // 0 tabanlı
    while (p != NULL && i-- > 0)
        p = p->bag;
    return p;               // i >= uzunluk ise NULL
}
Kısa devre (short-circuit)

p != NULL && p->deger != x: sıra ters olsaydı listenin sonunda NULL'ın içine bakılırdı.

Maliyet

Arama en kötü O(n), konum(p, i) O(i). Dizideki a[i] gibi O(1) değil.

Sıralı listede

p->deger > x görüldüğü an durulabilir; yine de en kötü O(n). İkili arama bağlı listede işe yaramaz.

Tek Bağlaçlı Liste

Sınav sorusu: hangisi doğru?

Final sorusu. Listeyi teker teker serbest bırakan iki yordam (sol: notlardaki, sağ: düzeltilmiş). Soldakinde çağıran yordamdaki list ne olur?
void serbest_birak( list_gost *list ){
    oge_gost p = *list;
    if( *list ){
        p = *list->bag;
        free(*list);
        serbest_birak(&p);
}}
void serbest_birak( list_gost *list ){
    oge_gost p = *list;
    if( p ){
        *list = p->bag;
        free(p);
        serbest_birak(list);
}}
Çözüm

Soldaki özyineli çağrıyı yerel p'nin adresiyle yapar: ana yordamdaki list NULL olmaz, bırakılmış düğümü gösterir (sarkan gösterge). Ayrıca *list->bag = *(list->bag) derlenmez; kastedilen (*list)->bag. Sağdaki *list'i ilerletip aynı adresle devam eder.

Hocadan “Bu ne kodu? Ne çabuk unuttunuz ya! Final sorusu. … Kodu yazdın, çok eminsin. Ama o kadar emin olma!”

Tek Bağlaçlı Liste · Kodu adım adım çalıştır

Kod İzleme: serbest_birak(&liste)

1. çağrı: p = *list → &düğüm(4).

p != NULL: bırakılacak düğüm var.

*list = p->bag: main'deki liste artık &düğüm(9).

free(p): düğüm(4) iade edildi; p artık sarkan (dangling) gösterge, kullanılmaz.

Aynı list adresiyle özyineli çağrı: kalan liste bırakılacak.

2. çağrı: p = *list → &düğüm(9).

p != NULL: bırakılacak düğüm var.

*list = p->bag: main'deki liste artık NULL.

free(p): düğüm(9) iade edildi; p artık sarkan (dangling) gösterge, kullanılmaz.

Aynı list adresiyle özyineli çağrı: kalan liste bırakılacak.

3. çağrı: p = *list → NULL.

p == NULL: liste bitti, çağrı hiçbir şey yapmadan döner. Taban durumu.

2. çağrıya dönüldü; yapılacak iş kalmadı.

1. çağrıya dönüldü; yapılacak iş kalmadı.

Tüm düğümler bırakıldı ve main'deki liste == NULL: sarkan gösterge kalmadı.

void serbest_birak(oge_gost *list) {
    oge_gost p = *list;
    if (p) {
        *list = p->bag;      // önce başı ilerlet
        free(p);             // sonra eski başı bırak
        serbest_birak(list); // aynı adresle devam
    }
}

void liste_bosalt(oge_gost *list) {
    while (*list != NULL) {
        oge_gost p = *list;
        *list = p->bag;     // önce ilerle
        free(p);            // sonra bırak

}
Özyineli sürüm

Her düğüm için bir çağrı çerçevesi: n = 10⁶ düğümde yığıt taşabilir (stack overflow).

Döngüsel sürüm

O(n) zaman, O(1) ek bellek; *list sonunda NULL.

Ortak kural

free'den önce sonraki adresi al; free edilmiş düğümün bag alanı okunmaz.

Klasik Yordamlar

Soru: bağları tersine çevir (liste_devrik_al)

SORU. list göstergesiyle işaret edilen sıralı listenin bağ alanlarını tersine çeviren liste_devrik_al yordamını yazınız.

Ara durum: r ve q arası çevrildi, p'den sonrası henüz eski yönde.

Üç gösterge

r en geride, q ortada, p en ileride; her turda bir bağ çevrilir.

Yerinde (in-place)

Yeni düğüm yok, kopya yok: O(n) zaman, O(1) ek bellek.

Baş değişir

Bu yüzden liste oge_gost *list ile adresle gönderilir.

Hocadan “Oge_ekle, oge_cikar, malloc, ekstra bellek, ekstra işler yok; hiçbir şey yok!”

Klasik Yordamlar · Kodu adım adım çalıştır

Kod İzleme: liste_devrik_al(&liste)

Üç gösterge: p en ileride (baş), q ortada (NULL), r en geride (henüz değer yok).

p != NULL: tur başlar.

1. tur: r = q → NULL.

q = p → &düğüm(10): bu turda bağı çevrilecek düğüm.

p = p->bag → &düğüm(20). Önce ilerliyoruz ki kalan liste kaybolmasın.

q->bag = r: düğüm(10) artık NULL'ı gösteriyor.

p != NULL: tur başlar.

2. tur: r = q → &düğüm(10).

q = p → &düğüm(20): bu turda bağı çevrilecek düğüm.

p = p->bag → &düğüm(30). Önce ilerliyoruz ki kalan liste kaybolmasın.

q->bag = r: düğüm(20) artık düğüm(10)'u gösteriyor.

p != NULL: tur başlar.

3. tur: r = q → &düğüm(20).

q = p → &düğüm(30): bu turda bağı çevrilecek düğüm.

p = p->bag → NULL. Önce ilerliyoruz ki kalan liste kaybolmasın.

q->bag = r: düğüm(30) artık düğüm(20)'u gösteriyor.

p == NULL: döngü biter; q son düğümde.

*list = q: eski son düğüm yeni baş. 30 → 20 → 10; O(n) zaman, O(1) ek bellek, malloc yok.

void liste_devrik_al(oge_gost *list) {
    oge_gost r, p = *list, q = NULL;
    while (p) {
        r = q;         // r, q'yu takip eder
        q = p;         // q, p'yi takip eder
        p = p->bag;    // p'yi ilerlet
        q->bag = r;    // bağı tersine çevir
    }
    *list = q;         // son öğe liste başı
}

Klasik Yordamlar · Adım adım

İki listeyi uç uca birleştirme (concatenate)

L1 = 1 → 4, L2 = 6 → 9. İkisi de boş değil.

p L1'in başından yürür.

p->bag == NULL: L1'in son düğümü bulundu. Maliyet O(|L1|).

p->bag = L2: 1 → 4 → 6 → 9. Kopya yok. Dairesel listede son göstergesiyle bu iş O(1) olur.

// L1'in sonuna L2'yi bağlar, başı döndürür
oge_gost birlestir(oge_gost L1, oge_gost L2) {
    oge_gost p;
    if (L1 == NULL) return L2;
    if (L2 != NULL) {
        for (p = L1; p->bag != NULL; p = p->bag)
            ;                   // L1'in son düğümü
        p->bag = L2;
    }
    return L1;
}

Klasik Yordamlar · Adım adım

Orta düğüm: yavaş ve hızlı gösterge

İkisi de baştan başlar.

yavas 1, hizli 2 adım atar.

hizli son düğümde (hizli->bag == NULL): döngü biter, yavas = 3 ortadadır.

return yavas: tek geçiş, O(n) zaman, O(1) ek bellek.

oge_gost orta(oge_gost bas) {
    oge_gost yavas = bas, hizli = bas;
    while (hizli != NULL && hizli->bag != NULL) {
        yavas = yavas->bag;        // 1 adım
        hizli = hizli->bag->bag;   // 2 adım
    }
    return yavas;
}

Çift uzunlukta (1 → 2 → 3 → 4) ikinci orta (3) döner; ilk orta için koşul hizli->bag->bag != NULL olarak kurulur.

Klasik Yordamlar

Floyd'un döngü bulma algoritması (tavşan ve kaplumbağa)

Sorun

Hatalı bir bağ (son->bag = ortadaki) listeyi döngüye sokar; yazdir hiç bitmez.

Fikir

yavas 1, hizli 2 adım atar. Döngü yoksa hizli NULL'a varır; varsa döngüye girince aradaki uzaklık her tur 1 azalır → mutlaka buluşurlar.

Maliyet

O(n) zaman, O(1) ek bellek. Ziyaret edilenleri bir kümede tutmak da çalışır ama O(n) bellek ister.

Döngünün başı

Buluşmadan sonra bir göstergeyi başa al; ikisini birer adım ilerlet: yeniden buluştukları düğüm döngünün girişidir.

Floyd (1967); Knuth, TAOCP Cilt 2, Alıştırma 3.1-6. Notlarda yok; dersin bütünlüğü için eklendi.

Klasik Yordamlar · Kodu adım adım çalıştır

Kod İzleme: dongu_var() — tavşan ve kaplumbağa

Kaplumbağa (yavas) ve tavşan (hizli) aynı yerden, baştan başlar. Listede 5 → 3 döngüsü var.

hizli ve sonraki NULL değil: koşmaya devam.

1. tur: kaplumbağa 1 adım → düğüm(2).

Tavşan 2 adım → düğüm(3).

Aynı düğümde değiller; devam.

hizli ve sonraki NULL değil: koşmaya devam.

2. tur: kaplumbağa 1 adım → düğüm(3).

Tavşan 2 adım → düğüm(5).

Aynı düğümde değiller; devam.

hizli ve sonraki NULL değil: koşmaya devam.

3. tur: kaplumbağa 1 adım → düğüm(4).

Tavşan 2 adım → düğüm(4).

Buluştular! Tavşan döngüde tur atıp kaplumbağaya yetişti → döngü var, true.

bool dongu_var(oge_gost bas) {
    oge_gost yavas = bas, hizli = bas;
    while (hizli != NULL && hizli->bag != NULL) {
        yavas = yavas->bag;         // 1 adım
        hizli = hizli->bag->bag;    // 2 adım
        if (yavas == hizli) return true;
    }
    return false;
}

Klasik Yordamlar

Bağlaçlı liste ile yığıt (stack)

void yigit_ekle(oge_gost *top, int x) {   // push
    oge_gost p = yeni_oge(x);
    p->bag = *top;
    *top = p;
}
int yigit_al(oge_gost *top) {            // pop
    oge_gost p = *top;
    int x;
    if (p == NULL) { fprintf(stderr, "Yigit bos\n"); exit(2); }
    x = p->deger;
    *top = p->bag;
    free(p);
    return x;
}
Top = liste başı

Ekleme ve alma baştan yapılır: ikisi de O(1), kapasite sınırı yok (bellek bitene dek).

Hocadan “Top, liste başını tuttu. Silerken son elemandan geri gelmek gerektiği için ya iki işaretçi ile sonu tut, ya da tek işaretçi ile başı tut.”

Dairesel ve Çift Bağlaçlı

Dairesel (circular) liste: son düğüm başı gösterir

int d_uzunluk(oge_gost son) {
    int n = 0;
    oge_gost p = son;
    if (son == NULL) return 0;   // boş liste
    do {
        n++;
        p = p->bag;
    } while (p != son);          // tur tamamlandı
    return n;
}
Neden son?

son->bag ilk düğümdür: hem başa hem sona ekleme O(1).

NULL yok

Dolaşımın bitişi p == NULL değil, başa dönmek; bu yüzden do-while.

Dairesel ve Çift Bağlaçlı · Adım adım

Dairesel listede başa ve sona ekleme

3 → 5 → 8 → (3), son = 8. Yeni düğüm 1 eklenecek.

yeni->bag = son->bag: yeni düğüm eski ilk düğümü (3) gösterir.

son->bag = yeni: 8 artık 1'i gösterir. Başa ekleme bitti: 1 → 3 → 5 → 8.

Sona ekleme = başa ekle + *son = yeni: son artık 1; sıra 3 → 5 → 8 → 1. İkisi de O(1).

void d_basa_ekle(oge_gost *son, oge_gost yeni) {
    if (*son == NULL) {           // boş liste
        *son = yeni;
        yeni->bag = yeni;        // kendini gösterir
    } else {
        yeni->bag = (*son)->bag;  // eski ilk düğüm
        (*son)->bag = yeni;
    }
}

Sona ekleme: d_basa_ekle(son, yeni); *son = yeni; — başa ve sona ekleme aynı bağ işlemidir, fark yalnızca son göstergesindedir.

Dairesel ve Çift Bağlaçlı

Başlık (header / sentinel) düğümü

// başlıklı listede sıralı ekleme: özel durum yok
void b_sirali_ekle(oge_gost baslik, oge_gost yeni) {
    oge_gost onceki = baslik;       // asla NULL değil
    while (onceki->bag != NULL &&
           onceki->bag->deger < yeni->deger)
        onceki = onceki->bag;
    yeni->bag = onceki->bag;
    onceki->bag = yeni;
}
Fikir

Listenin başında veri taşımayan, hiç silinmeyen bir düğüm. Boş liste = yalnızca başlık.

Kazanç

Her gerçek düğümün bir öncesi vardır: *bas ve if (onceki == NULL) özel durumu kalkar.

Dairesel ve Çift Bağlaçlı

Çift bağlaçlı (doubly linked) liste

typedef struct doge *doge_gost;
struct doge {
    doge_gost sol;   // önceki (llink)
    int deger;
    doge_gost sag;   // sonraki (rlink)
};
// değişmez: p == p->sol->sag == p->sag->sol

Artı

  • İki yönde dolaşım
  • Bilinen düğümü O(1) silme
  • Öncesine O(1) ekleme

Eksi

  • Düğüm başına 2 gösterge
  • Her işlemde 4 bağ
  • Bağ hatası daha kolay

Dairesel ve Çift Bağlaçlı · Kodu adım adım çalıştır

Kod İzleme: cift_ekle(p, yeni)

Başlık (header) düğümlü dairesel çift bağlaçlı liste: H ⇄ 4 ⇄ 8 ⇄ H. 6, 4'ün sağına eklenecek.

yeni->sol = p: yeni düğümün sol bağı 4'ü gösterir.

yeni->sag = p->sag: sağ bağı 8'i gösterir. Liste henüz değişmedi, yalnız yeni düğüm hazırlandı.

p->sag->sol = yeni: 8'in sol bağı artık 6. (p->sag hâlâ 8 olduğu için bu satır 4. satırdan önce gelemezdi.)

p->sag = yeni: son bağ. Dört bağ güncellendi; özel durum yok: O(1).

Sonuç: H ⇄ 4 ⇄ 6 ⇄ 8 ⇄ H. Başlık düğümü sayesinde boş listede de, sonda da aynı kod çalışır.

// p düğümünün sağına yeni düğümü ekler
void cift_ekle(doge_gost p, doge_gost yeni) {
    yeni->sol = p;
    yeni->sag = p->sag;
    p->sag->sol = yeni;
    p->sag = yeni;
}

Dairesel ve Çift Bağlaçlı · Adım adım

Çift bağlaçlı listede silme: öncesi aranmaz

H ⇄ 4 ⇄ 6 ⇄ 8 ⇄ H; p = düğüm(6). Öncesi p->sol ile zaten elde.

p->sol->sag = p->sag: 4'ün sağı artık 8.

p->sag->sol = p->sol: 8'in solu artık 4.

free(p). Arama yok: O(1). Başlık sayesinde ilk/son düğüm için ayrı kod gerekmez.

void cift_sil(doge_gost baslik, doge_gost p) {
    if (p == baslik) {       // başlık silinmez
        fprintf(stderr, "Baslik silinemez\n");
        return;
    }
    p->sol->sag = p->sag;
    p->sag->sol = p->sol;
    free(p);
}

Bellek Yönetimi

Kullanılabilir düğüm listesi (available space list)

oge_gost avail = NULL;        // kullanılabilir düğümler

oge_gost get_node(void) {
    oge_gost p;
    if (avail != NULL) {         // önce listeden al
        p = avail;
        avail = avail->bag;
    } else {                     // yoksa sistemden iste
        p = malloc(sizeof *p);
        if (p == NULL) exit(1);
    }
    return p;
}

void ret_node(oge_gost p) {      // free yerine
    p->bag = avail;
    avail = p;
}
Fikir (Horowitz)

Silinen düğümler free yerine avail zincirine eklenir; yeni düğüm önce oradan alınır.

Neden?

Sık ekle-sil yapan programlarda malloc/free çağrılarını azaltır; düğüm alma/iade O(1).

Dikkat

avail'deki düğümler program bitene dek sistem yığınına dönmez; düğüm türü tekse işe yarar.

Bellek Yönetimi

get_node ve ret_node adım adım

avail zincirinde iki boş düğüm var; sağda kullanımda olan düğüm(9).

get_node(): avail boş değil → p = avail. malloc çağrılmadı.

avail = avail->bag: zincirin başı ilerledi; p artık çağırana ait.

ret_node(silinen): silinen->bag = avail.

avail = silinen: düğüm yeniden kullanıma hazır. İkisi de bağlaçlı yığıtın ekle/al işlemi gibi O(1).

Aslında avail bir yığıttır: get_node = al (pop), ret_node = ekle (push).

Bellek Yönetimi · Adım adım

Dairesel listeyi tek hamlede iade (Horowitz: cerase)

3 → 5 → 8 → (3), son = 8; avail'de bir düğüm var. ilk = son->bag = 3.

son->bag = avail: halka açıldı, sonu avail zincirine eklendi.

avail = ilk: tüm liste avail'in önüne geçti.

*son = NULL. Uzunluk ne olursa olsun O(1); tek bağlaçlı düz listede sonu bulmak O(n) sürerdi.

// dairesel listeyi O(1)'de avail'e iade et
void d_iade(oge_gost *son) {
    oge_gost ilk;
    if (*son != NULL) {
        ilk = (*son)->bag;     // ilk düğüm
        (*son)->bag = avail;   // halkayı aç
        avail = ilk;
        *son = NULL;
    }
}

Sık yapılan hatalar

1Bağı korumadan üzerine yazmak: p->bag = yeni önce yazılırsa listenin kalanı kaybolur.
2Baş değişen yordama göstergeyi değerle vermek (oge_gost bas); main'deki liste güncellenmez.
3malloc sonucunu denetlememek; free'yi unutmak (sızıntı) ya da iki kez çağırmak.
4free edilmiş düğümün bag alanını okumak; önce sonrakini sakla, sonra bırak.
5Boş liste, tek düğüm, baş/son düğüm durumlarını test etmemek.
6Dairesel listede p != NULL ile dolaşmak: döngü hiç bitmez.

Bölüm özeti

Düğüm + bağ

Liste öğeleri dağınık durur; sıra bag alanlarıyla kurulur. Boş liste = NULL.

Bağ disiplini

Önce koru, sonra bağla, en son bırak (free). Baş değişecekse adresle aktar.

Maliyetler

Konum biliniyorsa ekle/sil O(1); erişim ve arama O(n).

Klasikler

Ters çevirme, birleştirme, orta düğüm, Floyd: tek geçiş, O(1) ek bellek.

Türler

Dairesel (son göstergesi), çift bağlaçlı (iki yön), başlık düğümü (özel durum yok).

Bellek

avail listesi düğümleri yeniden kullanır; dairesel liste O(1)'de iade edilir.
