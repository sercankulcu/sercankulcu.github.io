Klasik Soru · Özyineleme

Soru 1: Ulaşılamayan Taban Durum

Aşağıdaki fonksiyon f(5) için ne döndürür? Hata nedir, nasıl düzeltilir?

int f(int n) {
  if (n == 0)
    return 0;
  return n + f(n - 2);
}
Cevabı göster

Çağrılar n = 5, 3, 1, −1, −3, … diye ilerler; n tek olduğu için hiçbir zaman 0 olmaz. Taban duruma ulaşılamaz, her çağrı yeni bir çerçeve açar ve program yığın taşması (stack overflow) ile çöker; f(5) bir değer döndürmez.

Her çağrı taban duruma yaklaşmalı ve ona varabilmelidir. Düzeltme: if (n <= 0) return 0; → f(5) = 5 + 3 + 1 = 9. f(4) eski sürümde de çalışırdı (4 + 2 + 0 = 6); bu yüzden hata yalnız bazı girdilerde ortaya çıkar ve test verisi çeşitli seçilmelidir.

Soru 2: Kuyruk Çağrısı

Aşağıdaki return satırlarından hangisinde özyinelemeli çağrı bir kuyruk çağrısıdır?

C: Kuyruk çağrısında çağrının sonucu olduğu gibi döndürülür, dönüşten sonra yapılacak iş kalmaz. A, B ve D'de dönen değerle bir çarpma ya da toplama yapılmalıdır; bu yüzden çerçeve saklanır. C'de kısmi sonuç acc parametresinde taşınır; derleyici bu çağrıyı bir atlamaya çevirip O(1) yığınla çalıştırabilir.

Soru 3: Önce ve Sonra Yazdırmak

yaz(3) ne yazdırır? Her printf çalıştığında yığında hangi çerçeveler vardır?

n = 3 ≠ 0: önce 3 yazılır, sonra yaz(2) çağrılır.

Yeni çerçevenin kendi n'si var: 2 yazılır.

1 yazılır, yaz(0) çağrılır.

Taban durum: yaz(0) hiçbir şey yazmadan döner. Yığın en derin hâlinde (4 yaz çerçevesi).

yaz(1) kaldığı yerden devam eder: ikinci printf 1 yazar, çerçeve kapanır.

yaz(2)'nin ikinci printf'i: 2.

Çıktı 3 2 1 1 2 3. Çağrıdan önceki iş iniş sırasıyla, sonraki iş dönüş sırasıyla (ters) yapılır.

void yaz(int n) {
  if (n == 0) return;
  printf("%d ", n);
  yaz(n - 1);
  printf("%d ", n);
}
/* main: yaz(3); */

Soru 4: Orta İndisler

Test dizisi {4, 13, 18, 19, 24, 27, 33, 36, 39, 40}. Yinelemeli binsearch(list, 40, 0, 9) sırasıyla hangi orta (middle) indisleri dener?

A: (0 + 9)/2 = 4 → 24 < 40, left = 5; (5 + 9)/2 = 7 → 36 < 40, left = 8; (8 + 9)/2 = 8 → 39 < 40, left = 9; (9 + 9)/2 = 9 → bulundu. 4 tur, en çok ⌊log₂ 10⌋ + 1 = 4 ile uyumlu. Tam sayı bölmesi aşağı yuvarlar; D ilk ortayı yukarı yuvarlar (4,5 → 5).

Soru 5: Aralık Daralmıyor

binsearch'ün bu sürümünde + 1 ve - 1 unutulmuş. Test dizisinde 4 ve 40 aranınca ne olur?

while (left <= right) {
  int middle = (left + right) / 2;
  switch (COMPARE(list[middle], aranan)) {
    case -1: left = middle; break;
    case 0: return middle;
    case 1: right = middle;
  }
}
return -1;
Cevabı göster
  • 4: orta indisler 4, 2, 1, 0 → list[0] = 4 bulunur, 0 döner. Hata bu girdide görünmez.
  • 40: 4 → left = 4; 6 → left = 6; 7 → left = 7; 8 → left = 8. Sonra left = 8, right = 9 iken middle = 8, list[8] = 39 < 40 → left = middle yine 8 olur. Aralık hiç daralmaz: sonsuz döngü.

middle zaten denetlendiği için aralıktan çıkarılmalıdır: left = middle + 1, right = middle - 1. Ancak bu durumda her tur aralığı en az bir küçültür ve döngü en çok ⌊log₂ n⌋ + 1 turda biter.

Soru 6: Unutulan return

Özyinelemeli binsearch'te iki özyinelemeli çağrının başındaki return unutulmuş. Test dizisinde binsearch(list, 18, 0, 9) ne döndürür?

switch (COMPARE(list[m], x)) {
  case -1: binsearch(list, x, m + 1, r);
           break;
  case 0:  return m;
  case 1:  binsearch(list, x, l, m - 1);
           break;
}
return -1;

B: İlk çağrıda m = 4, list[4] = 24 > 18 → binsearch(list, 18, 0, 3) çalışır ve 2'yi bulur, ama dönen değer atılır; break sonrası son satırdaki return -1 çalışır. Yalnızca ilk ortada bulunan değer (24 → 4) doğru döner. Kod derlenir; uyarı bile vermeyebilir.

Soru 7: En Çok Kaç Tur?

Yinelemeli binsearch sıralı bir dizide en çok kaç tur döner? n = 2000, n = 4095 ve n = 4096 için bulunuz. Aranan dizide yoksa sayı değişir mi?

Cevabı göster

En çok ⌊log₂ n⌋ + 1 tur:

n200040954096
⌊log₂ n⌋101112
en çok tur111213

4095 = 2¹² − 1 öğe tam 12 düzeyli bir karar ağacı oluşturur; bir öğe daha eklenince bir tur artar. Aranan yoksa da aralık her turda yarıya iner ve en çok aynı sayıda tur sonra left > right olur (n = 2000 için bütün olası değerler denenerek 11 bulundu).

Soru 8: Taban Durumu n = 0 Olan Hanoi

Taban durumu n == 0 olan bu sürümde hanoi(2, 'A', 'B', 'C') ne yazdırır? Fonksiyon toplam kaç kez çağrılır?

n = 2: önce üstteki 1 disk A'dan B'ye (C yardımcı).

hanoi(1, A, C, B): önce hanoi(0, A, B, C).

Taban durum: hiçbir şey yapmadan döner. Yığın en derin: 3 hanoi çerçevesi.

Disk 1: A → B. Ardından hanoi(0, C, A, B) çağrılır ve hemen döner.

En büyük disk 2: A → C.

hanoi(1, B, A, C): hanoi(0, B, C, A) döner, disk 1: B → C.

Son hanoi(0, A, B, C) da döner. 3 hamle ama 7 çağrı: hamle 2ⁿ − 1, çağrı 2ⁿ⁺¹ − 1. n = 10 için 1023 hamle, 2047 çağrı.

void hanoi(int n, char k, char a, char h) {
  if (n == 0) return;          /* taban */
  hanoi(n - 1, k, h, a);
  printf("%c -> %c\n", k, h);
  hanoi(n - 1, a, k, h);
}
/* main: hanoi(2, 'A', 'B', 'C'); */

Soru 9: Dört Diskte Hamleler

Sunumdaki hanoi(4, "A", "B", "C") çağrısında 5. hamle nedir? En büyük disk (4) hangi hamlede taşınır? En küçük disk kaç kez yer değiştirir?

Cevabı göster

Hamleler: 1: A→B, 2: A→C, 3: B→C, 4: A→B, 5: C→A (disk 1), 6: C→B, 7: A→B, 8: A→C (disk 4), 9: B→C, …, 15: B→C.

  • En büyük disk, üstündeki 3 disk ara kuleye taşındıktan hemen sonra, 2³ − 1 + 1 = 8. hamlede taşınır.
  • Disk 1 her tek numaralı hamlede oynar: 15 hamlenin 8'i. Genel olarak disk k, 2n−k kez taşınır: 8 + 4 + 2 + 1 = 15 = 2⁴ − 1.

n = 4 çift olduğu için ilk hamle hedefe değil ara kuleye (B) yapılır.

Soru 10: Permütasyonda Çağrı Sayısı

Takaslı perm(list, 0, 4) çağrısı, "abcd" için kendisi dâhil toplam kaç perm çağrısı yapar?

D: i. düzeyde n(n−1)…(n−i+1) çağrı vardır: 1 + 4 + 12 + 24 + 24 = 65. Son terim i = n olan yaprak çağrılarıdır; her biri bir diziliş yazar. A yalnız yaprakları (4! = 24) sayar; C yaprak düzeyini (i = n) atlar. Zaman yaprak başına n karakterle O(n·n!)'dir.

Çıktı Sorusu · Permütasyon

Soru 11: Geri Takas Unutulursa

perm'deki ikinci SWAP silinmiş. perm("abc", 0, 3) ne yazdırır? Çağrıdan sonra dizi nedir?

void perm(char *list, int i, int n) {
  int j, temp;
  if (i == n) {
    for (j = 0; j < n; j++)
      printf("%c", list[j]);
    printf(" ");
  } else
    for (j = i; j < n; j++) {
      SWAP(list[i], list[j], temp);
      perm(list, i + 1, n);
    }
}
Cevabı göster

Çıktı: abc acb cab cba abc acb, dizi sonunda acb.

  • i = 1 düzeyinde j = 1, 2 dalları abc ve acb yazar; dizi acb olarak kalır.
  • i = 0, j = 1: acb'de list[0] ↔ list[1] → cab; alt dallar cab, cba yazar, dizi cba kalır.
  • i = 0, j = 2: list[0] ↔ list[2] → abc; yine abc, acb.

Kardeş dallar aynı başlangıç dizisini görmediği için abc ve acb iki kez çıkar; bac ve bca hiç çıkmaz. Geri takas, seçimi geri almaktır.

Soru 12: Sağlayan Atamalar

(x1 ∨ x2) ∧ ¬x3 ∧ (¬x1 ∨ x3) formülünü sağlayan kaç atama vardır (2³ atama denenir)?

D: ¬x3 için x3 = 0 olmalı. O zaman ¬x1 ∨ x3 yalnız x1 = 0 ile sağlanır; x1 ∨ x2 de x2 = 1 ister. Tek atama x1x2x3 = 010'dur. Önce x3'e değer atayan bir geri izleme, x3 = 1 dalını ¬x3 alt cümlesiyle hemen budayarak 4 atamayı hiç sonuna kadar denemezdi.

Soru 13: Budamalı Alt Küme Toplamı

ara(0, 0) toplamı 7 olan alt kümeleri hangi sırayla yazar? Hangi dallar budanır?

ara(0, 0): 5 alınır → ara(1, 5).

3 de alınınca top = 8 > 7: dal budanır; 2 ve 4 bu dalda hiç denenmez.

3 alınmadan 2 alınır: top = 7 = H → çözüm 5 2 yazılır.

5 + 4 = 9 budanır; 5 tek başına i == N'de sonuçsuz döner.

Kök sağ dala geçer: 5 alınmaz, 3 alınır.

3 + 2 + 4 = 9 budanır; 2 alınmayınca 3 + 4 = 7 → çözüm 3 4.

5'siz ve 3'süz dalda (2, 4) toplam 7'ye ulaşılmaz. 23 çağrı; budama olmasaydı 29. Çözüm yazılırken yalnız j < i kararları geçerlidir.

int a[] = {5, 3, 2, 4}, sec[4];
int N = 4, H = 7;
void ara(int i, int top) {
  int j;
  if (top == H) {                /* cozum */
    for (j = 0; j < i; j++)
      if (sec[j]) printf("%d ", a[j]);
    printf("\n");
    return;
  }
  if (i == N || top > H) return; /* buda */
  sec[i] = 1; ara(i + 1, top + a[i]);
  sec[i] = 0; ara(i + 1, top);
}

Soru 14: Altı Vezir

6-vezir probleminde ilk üç satıra q = [1, 3, 5] yerleştirildi. Sunumdaki uygun(3, c) hangi sütunlar için 1 döndürür?

C: Sütun 1, 3, 5 dolu. c = 0: q[2] = 5 ile |5 − 0| = 5 ≠ 1, q[1] = 3 ile 3 ≠ 2, q[0] = 1 ile 1 ≠ 3 → uygun. c = 2: |5 − 2| = 3 ≠ 1, |3 − 2| = 1 ≠ 2, |1 − 2| = 1 ≠ 3 → uygun. c = 4: |5 − 4| = 1 = 3 − 2 → çapraz tehdit. 0'dan devam edilince [1, 3, 5, 0, 2, 4] çözümü bulunur.

Soru 15: Bütün Çözümleri Saymak

Sunumdaki uygun fonksiyonunu kullanarak n-vezir probleminin bütün çözümlerini sayan int sayac(int r, int n) fonksiyonunu yazınız. yerlestir'den farkı nedir? sayac(0, 6) kaç döndürür?

Cevabı göster 
int sayac(int r, int n) {
  int c, top = 0;
  if (r == n) return 1;       /* bir cozum */
  for (c = 0; c < n; c++)
    if (uygun(r, c)) {
      q[r] = c;
      top += sayac(r + 1, n);  /* durmadan devam */
    }
  return top;
}

yerlestir ilk çözümde return 1 ile bütün çağrıları sonlandırır; sayac ise dönen sayıları toplar ve döngüye devam eder. q[r] geri alınmaz, çünkü sonraki deneme onun üzerine yazar ve uygun yalnız i < r satırlarına bakar.

Sonuçlar: n = 4 → 2, n = 5 → 10, n = 6 → 4, n = 8 → 92.

Soru 16: Warnsdorff Kuralı

At gezisinde Warnsdorff kuralı atın gideceği bir sonraki kareyi nasıl seçer?

B: Az seçenekli kareler (köşeler, kenarlar) önce tüketilir; böylece çıkmaz sonraya kalmaz. Kural her adımda yalnız 8 komşuya bakar ve O(n²) iş yapar, ama çözüm garantisi vermez. D geri izlemedir: her zaman çözer, ancak 8 × 8'de çok yavaştır. A, kolay kareleri sona bırakmak yerine harcar.
