Hızlı sıralama

Analiz

En iyi n lg n, en kötü n², ortalama ≈ 1,39 n lg n sonuçlarını özyineli bağıntılardan elde etmek.

İyileştirmeler

Özyinelemesiz sürüm (O(lg n) yığıt), medyan-3, küçük parçada eklemeli; C'de qsort.

Birleştirmeli

Yığın sıralama

Basamağa göre

Hızlı (Çabuk) Sıralama: Quick Sort

  • 1962'de C. A. R. (Tony) Hoare tarafından geliştirildi.
  • Parçala ve yönet (divide and conquer): problem doğrudan çözülecek kadar küçülene dek özyineli olarak alt problemlere bölünür.
  • Ortalama n lg n ile orantılı zaman; en kötü durumda n². Yalnızca küçük bir yardımcı yığıt kullanır.
  • Kararlı değildir; yine de bilinen en hızlı genel amaçlı algoritmalardan biridir. Standart C kitaplığında qsort vardır.

void quicksort1(int a[], int L, int R) {

bol(): Bölümleme (Partition)

int bol(int a[], int L, int R) {
    int i = L - 1, j = R, v = a[R]; // pivot a[R]
    for (;;) {
        while (kucuk(a[++i], v))
            ;
        while (kucuk(v, a[--j]))
            if (j == L) break;
        if (i >= j) break;
        degistir(a[i], a[j]);
    }
    degistir(a[i], a[R]);
    return i;
}
  • [2] Pivot (partitionary element) v = a[R].
  • [4] i soldan, v'den büyük ya da eşit ilk öğede durur. Sınır sınaması gerekmez: en kötü i = R'de a[R] = v durdurur.
  • [6–7] j sağdan, v'den küçük ya da eşit öğede durur; bu döngüde taşmayı j == L önler.
  • [9] İki öğe yanlış taraftadır → takas. [8] i ile j buluşunca döngü biter; [11] pivot a[i]'ye: solu ≤ v ≤ sağı.

Quick Sort: En Kötü ve En İyi Durum

En kötü: sıralı dizi

Pivot a[R] her seferinde en büyüktür, yerinde kalır; sonraki çağrı bir eksik boyutla yapılır:
n + (n−1) + … + 1 = n(n+1)/2 = O(n²)

Her adımda i ve j toplam n adım ilerler, n/2'lik iki alt problem kalır:
Cn = 2Cn/2 + n = 2kCn/2k + k·n = n lg n

Ortalama Durum Analizi: Özyineli Bağıntı

Cn = (n + 1) + (1/n) Σk=1n (Ck−1 + Cn−k),   C0 = C1 = 0

  • Bölme noktası k, 1 ≤ k ≤ n arasında eşit olasılıklı: n! dizilişin hepsinde bol() çağrılınca frekanslar eşit çıkar.
  • n + 1: bol()'da pivotla yapılan karşılaştırmalar; k'da bölünürse (k−1) ve (n−k) öğeli iki alt dizi kalır.
  • İki toplam aynı terimleri içerir: Σ(Ck−1 + Cn−k) = 2 Σk=0n−1 Ck ⇒ n·Cn = n(n+1) + 2 Σ Ck−1 … (1)

  • (1)'de n yerine n − 1: (n−1)Cn−1 = n(n−1) + 2 Σk=1n−1 Ck−1 … (2)

Özyinelemesiz Quick Sort (quicksort2)

void quicksort2(int a[], int L, int R) {
  yigit_baslat(); yigita_at(L, R);
  while (!yigit_bosmu()) {
    L = yigit_al(); R = yigit_al();
    if (R <= L) continue;
    int i = bol(a, L, R);
    if (i - L > R - i) {       // büyük parça önce
      yigita_at(L, i - 1); yigita_at(i + 1, R);
    } else {
      yigita_at(i + 1, R); yigita_at(L, i - 1);
    }
  }
}
#define YMAX 64     /* > 2·lg n */
static int yigit[YMAX], ust;
void yigit_baslat(void) { ust = 0; }
int yigit_bosmu(void) { return ust == 0; }
void yigit_ekle(int x) { yigit[ust++] = x; }
int yigit_al(void) { return yigit[--ust]; }
#define yigita_at(A, B) \
  do { yigit_ekle(B); yigit_ekle(A); } while (0)
  • Amaç: sistem yığıtı yerine kendi yığıtımızı kullanmak. yigita_at(A,B) önce B'yi sonra A'yı iter; böylece ilk alınan L olur.
  • [7–11] Büyük parça önce itilir, küçük parça sonra: son eklenen önce alındığından hep küçük parça işlenir → yığıt derinliği lg n'i aşmaz.
  • Bellek bağıntısı Tn = Tn/2 + 2 ⇒ Tn = 2 lg n (ikili aramadaki gibi).

#define M 10    /* bu boydan küçük parça kalsın */
void quicksort3(int a[], int L, int R) {
    if (R - L <= M) return;
    degistir(a[(L + R) / 2], a[R - 1]);
    karsilas_degis(a[R - 1], a[L]); // a[L] <= a[R-1]
    karsilas_degis(a[R], a[L]);     // a[L] <= a[R]
    karsilas_degis(a[R], a[R - 1]); // a[R-1] <= a[R]
    int i = bol(a, L + 1, R - 1);
    quicksort3(a, L, i - 1);
    quicksort3(a, i + 1, R);
}
void sirala(int a[], int L, int R) {
    quicksort3(a, L, R);
    insertion(a, L, R);   /* kalan küçük parçalar */
}

Neden Medyan-3 ve Küçük Parça Eşiği?

Medyan-3 (median-of-three)

a[L], ortadaki öğe ve a[R] sıraya konur; ortancası a[R−1]'e alınıp pivot olur. Quick sort en kötü performansını, insertion en iyi performansını sıralı veride gösteriyordu: sıralı girdideki n² durumu bozulur.

Doğal bekçiler

a[L] ≤ pivot ≤ a[R] olduğundan bölümleme L+1..R−1 üzerinde yapılır; uç öğeler taramaları durdurur.

Eşik M

R − L ≤ M olan parçalar sıralanmadan bırakılır; sirala() sonunda tek bir insertion geçişi hepsini neredeyse doğrusal sürede düzeltir. 5 ≤ M ≤ 25 için ≈ %10 kazanç.

Uyarı

Medyan-3 sıralı/ters sıralı girdiyi kurtarır; ama özel olarak kurulmuş kötü girdiler hâlâ n² yapabilir → introsort (sonraki bölüm).

Hocadan “Seni asla n² ile karşı karşıya getirmez. Analizi biraz ağır…”

int artan(const void *p, const void *q) {
    int x = *(const int *)p;

Birleştirmeli Sıralama (Merge Sort)

  1. Liste 0 ya da 1 öğeliyse zaten sıralıdır.
  2. Değilse, listeyi olabildiğince eşit iki parçaya ayır.
  3. Her parçayı merge sort'u özyineli uygulayarak sırala.
  4. Kendi içinde sıralı iki alt listeyi tek sıralı listede birleştir.
  • 1945, John von Neumann; parçala ve yönet.
  • Fikir 1: küçük listeyi sıralamak daha az adım ister.
  • Fikir 2: sıralı iki listeden sıralı liste elde etmek, sırasız ikisinden elde etmekten ucuzdur.
void mergesort(int a[], int b[], int L, int R) {
    if (R <= L) return;
    int m = (R + L) / 2;
    mergesort(a, b, L, m);
    mergesort(a, b, m + 1, R);
    merge(a, b, L, m, R);
}
void merge(int a[], int b[], int L, int m, int R) {
    int i, j, k;
    for (i = m + 1; i > L; i--) b[i - 1] = a[i - 1];
    for (j = m; j < R; j++) b[R + m - j] = a[j + 1];
    for (k = L; k <= R; k++)
        if (kucuk(b[j], b[i]))
            a[k] = b[j--];
        else
            a[k] = b[i++];
}

void heapify(int a[], int kok, int n) {
    int t = a[kok], j;
    for (j = 2 * kok; j <= n; j *= 2) {
        if (j < n && a[j] < a[j + 1]) j++; // büyük
        if (t >= a[j]) break;   // t buraya sığar
        a[j / 2] = a[j];        // çocuğu yukarı al
    }
    a[j / 2] = t;
}
#define SWAP(x, y, t) ((t) = (x), (x) = (y), (y) = (t))
void heapsort(int a[], int n) {     /* a[1..n] */
    int i, p;
    for (i = n / 2; i >= 1; i--)     /* yığın kur */
        heapify(a, i, n);
    for (i = n - 1; i >= 1; i--) {   /* sırala */
        SWAP(a[1], a[i + 1], p);     /* en büyüğü sona */
        heapify(a, 1, i);            /* yığını düzelt */
    }
}

  • heapify(a, kok, n): kok'ün sol ve sağ alt ağaçları zaten max-yığın iken kök değerine uygun yeri arar.
  • Yaprakları atla: ⌊n/2⌋, ⌊n/2⌋−1, …, 1 düğümleri için sondan başa heapify → max-heap.

Notlarda

50.000'den az veri için heapsort makul bir algoritmadır (≈ 2n lg n karşılaştırma). Daha büyük veride karşılaştırma sayısını azaltan bottom-up heapsort ve kuramsal olarak daha da iyi sürümler vardır.

Bottom-up fikri

Kök boşluğunu, t ile karşılaştırmadan büyük çocuklar boyunca yaprağa kadar indir; sonra t'yi yukarı doğru yerleştir. Seviye başına iki karşılaştırma yerine çoğunlukla bir.

Hocadan “Counting sort örneğinde olduğu gibi, sıralanacak verilere ait bazı özellikleri biliyorsak, ona göre bir yaklaşım seçebiliriz. Bu bağlamda shell sort ve package sort'un birlikte kullanımları var. Siz temel birkaç tanesini bilmelisiniz.”

Basamağa Göre Sıralama

Basamağa Göre Sıralama (Radix Sort)

  • Birden çok anahtara göre sıralama: ör. kişileri önce soyadına, soyadı aynı olanları ada göre.
  • Anahtarlar K0, K1, …, Kr−1: K0 en anlamlı (MSD), Kr−1 en az anlamlı (LSD). Örnekte soyadı en anlamlı.
  • LSD radix sort: önce en az anlamlı basamağa göre, sonra sırayla daha anlamlılara göre; en son MSD'ye göre sırala.
  • Her geçiş kararlı olmalı: önceki geçişin düzeni eşit basamaklarda korunur.
  • Sayıları birbiriyle karşılaştırmaz → non-comparison sıralama.
#define MAX_DIGIT 3
#define RADIX 10
typedef struct oge *oge_gost;
struct oge {
    int deger[MAX_DIGIT];  /* 179 → {1, 7, 9} */
    oge_gost bag;
};

K0: yüzler (MSD) · K1: onlar · K2: birler (LSD). [0, 999] aralığı. Düzeltme: notlardaki typedef struct oge {…}; ad içermeyen, anlamsız bir typedef'ti.

Basamağa Göre Sıralama: Analiz

O(MAX_DIGIT · (RADIX + n + RADIX)) = O(MAX_DIGIT · (RADIX + n))

  • Örnekte O(3 · (10 + n)): doğrusal görünür ama sayarak sıralama gibi özel bir durumdur: basamak sayısı ve taban sabit kabul edilmiştir.
  • Veriler (a) pozitif, (b) tamsayı, (c) küçük aralıkta olmalı. Aralık büyürse yine sıralar ama karmaşıklık hızla artar.
  • Ek bellek: 2·RADIX gösterge (liste yerinde yeniden bağlanır).

Bölüm Özeti

Quick sort

Pivotu yerine koyar ve problemi böler: en iyi n lg n, ortalama 1,39 n lg n, en kötü n².

İyileştirmeler

Küçük parça önce (yığıt lg n), medyan-3, küçük parçada eklemeli; qsort ve introsort.

Merge sort

Her durumda n lg n, O(n) ek bellek; bağlaçlı sürüm büyük tutanakları kopyalamaz.

Heap sort

Yığın kurma O(n), sıralama O(n lg n); yerinde ama kararsız.

Radix sort

Kararlı kovalarla LSD'den MSD'ye: O(d(n + r)); pozitif tamsayılar ve küçük aralık.
