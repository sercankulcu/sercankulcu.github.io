Multiple Choice · List ADT

Question 1: Deleting from an Array

array_delete(&L, 1, &x) is called on an ArrayList L = [5, 3, 8, 6] (n = 4). At the end, what are x, the list, and the number of assignments in the shifting loop?

C: The deleted a[1] is 3. The loop runs for k = 1 and k = 2 (k < n − 1 = 3): a[1] = a[2], a[2] = a[3]. n drops to 3; although the old 6 stays in a[3], it is no longer part of the list (D counts it). The shift is n − 1 − i moves; deleting at the front is O(n).

Multiple Choice · List ADT

Question 2: Inserting at Position n

In a linked list L = 4 → 7 → 2 (n = 3), ll_insert(&L, 3, 9) is called, followed by ll_insert(&L, 5, 1). What is the result?

B: The valid positions are 0 ≤ i ≤ n; i = n means appending: 4 → 7 → 2 → 9 (n = 4). In the second call 5 > n = 4 → false. Position i is the index the new item has after insertion; D confuses this with “before item i”.

Step-by-Step Trace · List ADT

Question 3: Insertion with a Pointer to a Pointer

ll_insert(&L, 2, 6) is called on the list L = 4 → 7 → 2. Which links does pp point to, and which pointer changes?

pp = &L->head: pp holds the address of the first link that may be changed (the head pointer).

Loop: pp = &(*pp)->link → the link field of 4.

pp → the link field of 7. The condition (i-- > 0) is now false: the loop ends.

A new node is allocated; the NULL check passes.

new_node->link = *pp: the new node points to the node (2) that the link pp points to currently refers to.

*pp = new_node: the link of 7 now points to 6. Insertion at the head and in the middle use the same line; the cost is O(i).

bool ll_insert(LinkedList *L, int i, int x) {
  node_pointer *pp = &L->head, new_node;
  if (i < 0 || i > L->n) return false;
  while (i-- > 0)
    pp = &(*pp)->link;
  new_node = malloc(sizeof *new_node);
  if (new_node == NULL) return false;
  new_node->data = x;
  new_node->link = *pp;
  *pp = new_node;
  L->n++;
  return true;
}

Multiple Choice · List ADT

Question 4: Array or Links?

Which of the following statements about list implementations is false?

C: Binary search needs O(1) access to the middle item; walking to the middle of a linked list is O(n), so even a sorted linked list stays O(n) for search. That is why an array is chosen for sorted data that is searched often.

Multiple Choice · Generalized Lists

Question 5: Head, Tail and Depth

For the generalized list L = ((a), b, (c, (d))), which gives the length, head, tail and depth?

A: There are three items at the top level: (a), b, (c, (d)). The head is the first item and here it is a list: (a). The tail is always a list: everything except the first item. The deepest path goes down to (d): 1 + 1 + 1 = 3 (verified with a program).

Classic Question · Generalized Lists

Question 6: Memory Layout

Draw the memory layout of the list L = (a, (), (b, (c))) with elements of the form [tag | data/dlink | link]. How many elements are allocated, how many are T (sublist) elements, and what is the depth?

Show answer
  • 6 elements in total: 3 at the top level (a, (), (b,(c))), 2 below (b, (c)), and 1 at the bottom (c).
  • 3 T elements; () has a T element, but its dlink field is NULL. An empty sublist and the empty list (NULL) are different things.
  • Depth is 3: the path down to (c). The list was built and counted with a program.

Question 7: Printing in Linear Form

print_linear is called for L = (a, (), (b)). How do the call stack and the output progress?

First call: ( is printed at the start of the level.

a is an atom: it is printed; link exists → comma.

() is a T element: a call is made for the sublist, dlink is NULL.

Call with NULL: the for loop never runs, ( and ) are still printed: the empty sublist ().

Return; there is a next element → comma.

(b) is a T element: descend into the sublist.

The inner call prints (, prints the atom b; link is NULL → no comma.

The inner level ends: ) is printed, return.

No element after (b): the outer level closes with ) too. The text was reproduced exactly.

void print_linear(list_pointer L) {
  printf("(");
  for (; L; L = L->link) {
    if (L->tag) print_linear(L->dlink);
    else printf("%c", L->data);
    if (L->link) printf(",");
  }
  printf(")");
}

Multiple Choice · Basic Routines

Question 8: Equality and Call Count

equal(T, L) is called with T = (a, b) and L = (a, b, c). What is the result, and how many times is equal called in total (including the first call)?

D: Call 1: a = a → call 2 with the links; b = b → call 3 equal(NULL, element(c)). They are not both NULL and not both non-NULL: FALSE. Lists of different lengths differ when the shorter one ends (measured with a counter).

Classic Question · Basic Routines

Question 9: Shallow Copy

A student wrote the sublist line in copy as below. What does the copy of L = (a, (b, c)) look like? What happens if L and its copy are then both freed with all their elements?

if (!L->tag) q->data = L->data;
else q->dlink = L->dlink;   /* wrong */
q->link = copy(L->link);
Show answer

The top-level elements (a and T) are newly allocated, but the dlink of the T element points to the original sublist (b, c): the sublist is shared between the two lists (shallow copy). In the program the copy's T element pointed to the same address as the original's.

  • Changing b in the copy also changes the original.
  • If the two lists are freed separately, the b and c nodes are freed twice: undefined behavior, often a crash.
  • Correct form: q->dlink = copy(L->dlink); (deep copy), or reference counting if sharing is wanted.

Multiple Choice · Basic Routines

Question 10: Copying a List with Sharing

The shared list A = (x, y) and B = (A, A, ()) is built (the first two elements of B point to the same A). How many times does copy(B) call get_node, and is the sharing preserved in the copy?

D: B's three elements (3) and A, copied separately at each place it is pointed to: 2 × 2 = 4; total 7. The original has 5 distinct elements; the copy ends up with two separate copies of A (verified with a program). To preserve sharing, an old-address → new-address table must be kept.

Classic Question · Depth and Inversion

Question 11: Depth with Empty Sublists

What does the recursive depth(L) return for L = (a, (()), ((b)), c)? How many times is depth called in total?

int depth(list_pointer L) {
  list_pointer p = L; int m = 0;
  if (!L) return 0;
  while (p) {
    if (p->tag) {
      int n = depth(p->dlink);
      if (m < n) m = n;
    }
    p = p->link;
  }
  return m + 1;
}
Show answer
  • The element (()): the list inside it holds a T element whose dlink is NULL → depth(NULL) = 0, so that list's depth is 0 + 1 = 1.
  • The element ((b)): the depth of (b) is 1, that of ((b)) is 2.
  • Top level: 1 + max(1, 2) = 3.

Calls: L, (()), NULL, ((b)), (b) → 5. An empty sublist counts as a level too: (()) has depth 1, while () has depth 0. Verified with a counter.

Multiple Choice · Depth and Inversion

Question 12: Nested Inversion

What does invert(&L) turn the list L = (a, (b, (c)), d) into?

B: Every level is reversed and the sublists are reversed recursively too: (b, (c)) → ((c), b); the one-element (c) stays the same. Top level: (d, ((c), b), a). A reverses only the top level; no malloc is done, only links change (verified with a program).

Step-by-Step Trace · Depth and Inversion

Question 13: Depth with a Local Stack

The iterative iter_depth is run on L = (a, ((b)), c). How do the stack and the counters change?

L is not empty: p = L, d = 1.

a is an atom: m = d = 1, move to the sibling.

The element ((b)) is T1 and its sublist is non-empty: T1 is pushed, descend into the sublist, d = 2.

The element (b) is T2: m = 2; T2 is pushed, d = 3.

b is an atom: m = 3; link is NULL.

The level is finished: T2 is popped, p = T2->link = NULL, d = 2.

This level is finished too: T1 is popped, p = T1->link = c, d = 1.

c is an atom: m is unchanged; p = NULL.

p is NULL and the stack is empty: m = 3 is returned. Same result as the recursive version.

int iter_depth(list_pointer L) {
  list_pointer stack[100];
  int top = 0, d = 1, m = 0;
  list_pointer p = L;
  if (!L) return 0;
  for (;;) {
    if (p == NULL) {          /* level done */
      if (top == 0) return m;
      p = stack[--top]->link;
      d--;
    } else {
      if (d > m) m = d;
      if (p->tag && p->dlink) {
        stack[top++] = p; p = p->dlink; d++;
      } else p = p->link;
    }
  }
}

Classic Question · Trees and Sharing

Question 14: From Linear Form to a Tree

A tree is written as A(B(D,E(G)),C(F)). Draw the tree; give its degree, its leaves and the ancestors of G. If the tree is stored as the list (A,(B,D,(E,G)),(C,F)), what does print_atoms print?

Show answer
  • Degree 2 (A and B have two children each); leaves D, G, F; the ancestors of G are A, B, E.
  • print_atoms prints the atoms from left to right: ABDEGCF, the preorder (root first) of the tree (verified with a program).
  • The linear form does not show the left/right distinction of a binary tree: in C(F) it cannot be written whether F is left or right.

Question 15: Reference Counts

With header nodes, the lists A = (x, y), B = (A, A), C = (B, A) are built; each count is the number of names and T elements pointing to the list. After the call list_free(&C), what are the counts of A and B?

A: At the start, A is pointed to by the name A, the two elements of B and the second element of C: 4; B by the name B and the first element of C: 2; C: 1. C drops to 0 and is freed; its elements bring B down to 1 and A down to 3. Because the name B still points to B, B's elements are not descended into (verified by simulation with C).

Classic Question · Wrap-Up

Question 16: Freeing a Whole List

Write void free_list(list_pointer L), which frees all elements (including sublists) of an unshared, non-recursive generalized list. A freed element must never be touched again.

Show answer 
void free_list(list_pointer L) {
  while (L) {
    list_pointer next = L->link;
    if (L->tag)
      free_list(L->dlink);
    free(L);
    L = next;
  }
}
  • link is saved before the element is freed; reading L->link after free is a dangling pointer bug.
  • The sublist is freed first, then the T element itself. Because the same level is traversed with a loop, the stack depth grows only with nesting.
  • In a counter-instrumented test of (a,(b,(),(c,d)),((e))): 10 malloc, 10 free.
