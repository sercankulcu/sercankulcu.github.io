Giriş

Öğrenme Çıktıları

Özyineli düşünmek

Bir problemi taban durum + küçülen alt problem olarak ifade etmek; özyineleme ile döngüyü karşılaştırmak.

Yığıtı izlemek

Her çağrının yığıt çerçevesini (parametreler, yereller, dönüş adresi) çizmek.

İkili arama

Döngüsel ve özyineli ikili aramayı yazmak; O(log n) sınırını göstermek.

Özyineli bağıntı

Hanoi için h(n) = 2h(n−1) + 1 bağıntısını kurup çözmek; permütasyon için O(n·n!).

Geri izleme

Kaba kuvvet ile geri izlemeyi ayırmak; SAT, n-vezir, alt küme üretimi.

Sezgisel yaklaşım

At gezisinde Warnsdorff kuralının geri izlemeye göre neden hızlı olduğunu açıklamak.

Özyineleme

Özyineli Algoritmalar (Recursive Algorithms)

Bütündeki çözüm mantığı alt problemlerde de geçerliyse özyineli algoritma kullanılabilir.

Doğrudan özyineleme

Fonksiyon kendini çağırır: fakt → fakt.

Dolaylı özyineleme

Çağırdığı bir fonksiyon onu geri çağırır: A → B → A.

Taban durum

Özyinelemesiz çözülen en küçük örnek. Yoksa çağrılar sonsuza gider (yığıt taşar).

Özyineli adım

Problemi daha küçük bir örneğe indirger; her çağrı taban duruma yaklaşmalı.

Hocadan“‘Hocam bu özyinelemeli çözüm çok bellek yemez mi?’ Sakın ha! Önce kodu yazmayı öğrenin; algoritma karmaşıklığını hesaplayabiliyorsanız o zaman böyle diyebilirsiniz. Siz daha özyineli kod yazmayı öğrenmediniz ki!”

Özyineleme

Yığıt Çerçevesi (Stack Activation Frame)

  • Fonksiyon çağrılınca sistem yığıtı kullanılır.
  • Denetim fonksiyona geçmeden önce bir hazırlık yapılır: nereye dönüleceği, parametrelerin saklanması…
  • Bu iletişim–denetim yapısına yığıt çerçevesi denir.
  • Başlangıçta yığıtta iki değer vardır: dönüş adresi ve önceki çerçeveye gösterge.
  • Her özyineli çağrı yeni bir çerçeve demektir → derinlik d ise ek bellek O(d).

Özyineleme · Kodu adım adım çalıştır

Kod İzleme: fakt(3) ve çağrı yığıtı

main, fakt(3)’ü çağırır: yeni çerçeve açılacak.

fakt(3): n = 3 > 1, taban durum değil.

3 * fakt(2): çarpma bekler; önce fakt(2) çağrılır.

fakt(2): n = 2 > 1, taban durum değil.

2 * fakt(1): çarpma bekler; önce fakt(1) çağrılır.

fakt(1): taban durum → return 1. Yığıt en derin hâlde (4 çerçeve).

fakt(2) kaldığı yerden devam: 2 · 1 = 2, çerçeve kapanır.

fakt(3) kaldığı yerden devam: 3 · 2 = 6, çerçeve kapanır.

main 6 yazar. Aynı n değişkeni her çerçevede ayrı bir kopyadır.

long fakt(int n) {
  if (n <= 1)
    return 1;              /* taban durum */
  return n * fakt(n - 1);
}

int main(void) {
  printf("%ld\n", fakt(3));
  return 0;
}

Özyineleme · Zenginleştirme

Kuyruk Özyinelemesi (Tail Recursion)

Özyineli çağrı fonksiyonun son işiyse (dönüşten sonra yapılacak iş kalmıyorsa) buna kuyruk özyinelemesi denir.

long fakt_k(int n, long acc) {
  if (n <= 1) return acc;
  return fakt_k(n - 1, n * acc);  /* son is: cagri */
}
/* ilk cagri: fakt_k(n, 1) */
fakt kuyruk özyineli değil

n * fakt(n-1): dönüşten sonra çarpma bekler, çerçeve saklanmalıdır.

Birikimli parametre

acc kısmi sonucu taşır; dönüşte yapılacak iş kalmaz.

Derleyici

Kuyruk çağrısı bir atlamaya çevrilebilir (O(1) yığıt). C standardı bunu garanti etmez; gcc/clang optimizasyonla çoğu zaman yapar.

Zenginleştirme

İkili Arama

İkili Arama (Binary Search)

Sıralı bir dizide değer arıyoruz: bulunursa indisini, bulunamazsa −1 döndüren yordam. Her adımda ortadaki öğeye bakılır ve aralığın yarısı atılır.

Notlardaki test dizisi (s. 5)

#define COMPARE(x, y) ((x) < (y) ? -1 : (y) < (x) ? 1 : 0)
Hocadan“list[i]’yi değil, i’yi döndür. Neden? Hata değeri olan −1 ile dizi elemanı olabilecek bir −1 karışmasın diye.”

İkili Arama · Kodu adım adım çalıştır

Kod İzleme: döngüsel binsearch(list, 18, 0, 9)

binsearch(list, 18, 0, 9): aralık tüm dizi.

0 ≤ 9: 1. tur. middle = (0 + 9) / 2 = 4, list[4] = 24.

24 > 18 → COMPARE = 1: sağ yarı atılır, right = 3.

0 ≤ 3: 2. tur. middle = (0 + 3) / 2 = 1, list[1] = 13.

13 < 18 → COMPARE = −1: sol yarı atılır, left = 2.

2 ≤ 3: 3. tur. middle = (2 + 3) / 2 = 2, list[2] = 18.

COMPARE = 0 → return 2. 3 turda bulundu.

int binsearch(int list[], int aranan,
              int left, int right) {
  while (left <= right) {
    int middle = (left + right) / 2;
    switch (COMPARE(list[middle], aranan)) {
      case -1: left = middle + 1; break;
      case 0: return middle;
      case 1: right = middle - 1;
    }
  }
  return -1;
}

İkili Arama · Kodu adım adım çalıştır

Kod İzleme: binsearch(list, 25, 0, 9) → −1

binsearch(list, 25, 0, 9): aralık tüm dizi.

0 ≤ 9: 1. tur. middle = (0 + 9) / 2 = 4, list[4] = 24.

24 < 25 → COMPARE = −1: sol yarı atılır, left = 5.

5 ≤ 9: 2. tur. middle = (5 + 9) / 2 = 7, list[7] = 36.

36 > 25 → COMPARE = 1: sağ yarı atılır, right = 6.

5 ≤ 6: 3. tur. middle = (5 + 6) / 2 = 5, list[5] = 27.

27 > 25 → COMPARE = 1: sağ yarı atılır, right = 4.

left > right: döngü biter → return −1 (3 tur).

İkili Arama

Özyineli (Rekürsif) İkili Arama

int binsearch(int list[], int x, int l, int r) {
  int m;
  if (l > r) return -1;          /* aralik bos */
  m = (l + r) / 2;
  switch (COMPARE(list[m], x)) {
    case -1: return binsearch(list, x, m + 1, r);
    case 0:  return m;
    case 1:  return binsearch(list, x, l, m - 1);
  }
  return -1;                     /* ulasilmaz */
}
  • Döngü yerine aralığı küçülterek kendini çağırır.
  • Taban durumlar: bulundu (case 0) ya da aralık boş (l > r). Kısa olsun diye x = aranan, l/r = left/right, m = middle.
  • Her iki özyineli çağrı da kuyruk çağrısıdır: sonucu olduğu gibi döndürür.
Notlardaki özyineli sürümde if yerine while yazılmış (s. 4). Her dal return ile çıktığı için döngü bir kez döner ve sonuç doğrudur, ama yanıltıcıdır: burada if olmalı.

İkili Arama · Kodu adım adım çalıştır

Kod İzleme: özyineli binsearch(list, 18, 0, 9)

Yeni çerçeve: l = 0, r = 9 → m = 4 (list[4] = 24).

24 > 18 → case 1: binsearch(list, 18, 0, 3) çağrılır.

Yeni çerçeve: l = 0, r = 3 → m = 1 (list[1] = 13).

13 < 18 → case −1: binsearch(list, 18, 2, 3) çağrılır.

Yeni çerçeve: l = 2, r = 3 → m = 2 (list[2] = 18).

list[2] = 18: case 0 → return 2.

Dönen 2 olduğu gibi yukarı iletilir (case −1 çerçevesi kapanır).

Dönen 2 olduğu gibi yukarı iletilir (case 1 çerçevesi kapanır).

main’e 2 döner: “2’yi case 1’e döndürür, sonra da main’e döner.” Derinlik 3 → O(log n) yığıt.

int binsearch(int list[], int x, int l, int r) {
  int m;
  if (l > r) return -1;          /* aralik bos */
  m = (l + r) / 2;
  switch (COMPARE(list[m], x)) {
    case -1: return binsearch(list, x, m + 1, r);
    case 0:  return m;
    case 1:  return binsearch(list, x, l, m - 1);
  }
  return -1;                     /* ulasilmaz */
}

Her turda aralık en az yarıya iner: n → n/2 → n/4 → … → 1.

T(n) = T(n/2) + c ⇒ T(n) = O(log n)
  • En fazla ⌊log₂ n⌋ + 1 tur.
  • Döngüsel sürüm ek bellek: O(1).
  • Özyineli sürüm: derinlik kadar çerçeve → O(log n).
  • Ön koşul: dizi sıralı olmalı ve indisle O(1) erişilebilmeli (bağlaçlı listede işe yaramaz).

Hanoi Kuleleri

Hanoi Kuleleri Problemi

Kaynak kulede n disk var; her disk üzerindekinden büyüktür. Amaç: hepsini hedef kuleye taşımak, ara kuleden yardım alarak.

  1. Her seferinde tek disk taşınır.
  2. Bir disk kendinden küçük bir diskin üzerine konamaz.
Özyineli çözüm: En büyük diski hedefe taşıyabilmek için üstündeki n−1 diskin ara kulede olduğu bir an olmalıdır: n−1 disk kaynak→ara, en büyük disk kaynak→hedef, n−1 disk ara→hedef. h(n) = h(n−1) + 1 + h(n−1).
Hocadan“Öyle problemler var ki, ancak rekürsif yolla çözülebilir.”

Kuramsal olarak her özyineleme açık bir yığıtla döngüye çevrilebilir; vurgu, özyinelemenin bu tür problemlerde tek doğal ifade olmasıdır.

Hanoi Kuleleri · Kodu adım adım çalıştır

Kod İzleme: hanoi(3, "A", "B", "C")

n = 3: önce üstteki 2 disk A → B (hedef C yardımcı olur).

n = 2: önce üstteki 1 disk A → C (hedef B yardımcı olur).

n = 1: taban durum. Disk 1: A → C.

Geri dönüldü; en büyük disk 2: A → B. Sonra 1 disk C → B.

n = 1: taban durum. Disk 1: C → B.

Geri dönüldü; en büyük disk 3: A → C. Sonra 2 disk B → C.

n = 2: önce üstteki 1 disk B → A (hedef C yardımcı olur).

n = 1: taban durum. Disk 1: B → A.

Geri dönüldü; en büyük disk 2: B → C. Sonra 1 disk A → C.

n = 1: taban durum. Disk 1: A → C.

Bitti: 7 = 2³ − 1 hamle, 7 çağrı. Yığıt en çok n = 3 çerçeve derinleşti.

void hanoi(int n, char *kaynak, char *ara,
           char *hedef) {
  if (n == 1)
    printf("%s -> %s\n", kaynak, hedef);
  else {
    hanoi(n - 1, kaynak, hedef, ara);
    printf("%s -> %s\n", kaynak, hedef);
    hanoi(n - 1, ara, kaynak, hedef);
  }
}
/* main: hanoi(3, "A", "B", "C"); */

Permütasyon

Permütasyon Problemi [O(n!)]

n ≥ 1 elemanlı bir kümenin tüm dizilişlerini yazdırmak istiyoruz: n! diziliş vardır. {a, b, c} → abc, acb, bac, bca, cab, cba.

Özyineli fikir

{a, b, c, d} kümesinin dizilişleri:
• a’yı izleyen {b, c, d} dizilişleri
• b’yi izleyen {a, c, d} dizilişleri
• c’yi izleyen {a, b, d} dizilişleri
• d’yi izleyen {a, b, c} dizilişleri

Takasla gerçekleştirim

i. konuma sırayla her öğeyi takasla getir, kalan n−i−1 konumu özyineli diz, sonra geri takasla diziyi eski hâline döndür (geri izleme!).

Permütasyon · Kodu adım adım çalıştır

Kod İzleme: perm("abc", 0, 3)

i = 0, j = 0: kendisiyle takas → abc; perm(i = 1) çağrılır.

i = 1, j = 1: kendisiyle takas → abc; perm(i = 2) çağrılır.

i = n: diziliş hazır → abc yazılır.

i = 1, j = 2: list[1] ↔ list[2] → acb; perm(i = 2) çağrılır.

i = n: diziliş hazır → acb yazılır.

Geri takas: list[1] ↔ list[2] → abc (eski hâl).

i = 0, j = 1: list[0] ↔ list[1] → bac; perm(i = 1) çağrılır.

i = 1, j = 1: kendisiyle takas → bac; perm(i = 2) çağrılır.

i = n: diziliş hazır → bac yazılır.

i = 1, j = 2: list[1] ↔ list[2] → bca; perm(i = 2) çağrılır.

i = n: diziliş hazır → bca yazılır.

void perm(char *list, int i, int n) {
  int j, temp;
  if (i == n) {                  /* bir dizilis */
    for (j = 0; j < n; j++) printf("%c", list[j]);
    printf("\n");
  } else
    for (j = i; j < n; j++) {
      SWAP(list[i], list[j], temp);
      perm(list, i + 1, n);
      SWAP(list[i], list[j], temp);
    }
}

Özyineleme Ağacı ve Karmaşıklık

Kök: sabitlenmiş önek yok · her seviye bir konumu sabitler · yapraklar: çıktıdaki sırayla 6 diziliş

Çağrı sayısı

1 + n + n(n−1) + … + n! çağrı; yaprak sayısı n!.

Zaman

Her yaprakta n karakter yazılır → O(n·n!). Notlardaki başlık: O(n!).

Neden geri takas?

Kardeş dallar aynı başlangıç dizisini görmeli; ikinci SWAP diziyi onarır.

Geri İzleme

Kaba Kuvvet ve Geri İzleme (Backtracking)

Kaba kuvvet (brute force)

Olası tüm adayları üret, her birini sına. Bilgisayarın gücüne güvenir; aday sayısı 2ⁿ, n! … olabilir.

Geri izleme

Çözümü adım adım kur; kısmi çözüm bir kuralı bozduğu anda o dalı buda, son seçimi geri al, sıradakini dene.

void geri_izle(kismi_cozum) {
  if (tam_cozum_mu) { yaz; return; }
  for (her aday secim)
    if (kurallara_uygun) { sec; geri_izle(...); secimi_geri_al; }
}
Hocadan“Daha iyi çözüm aramak: Veri yapıları derslerinde problem çözerken veri yapınızdan asla emin olmayın. Sürekli yazın, arkadaşlarınızla tartışın; “Daha iyi bir çözüm yöntemi vardır da biz bulamıyoruz.” deyin.”

Geri İzleme

Satisfiability (SAT) Problemi

(x1 ∧ ¬x2) ∨ (¬x1 ∧ x3) ∨ ¬x3

x1, x2, … true/false alan mantıksal değişkenler; ∧, ∨, ¬ işleçler. Soru: formülü true yapan bir atama var mı?

  • 3 değişken → 2³ = 8 olası atama: {F,F,F}, {F,F,T}, …
  • n değişken → 2ⁿ durum; kaba kuvvet O(2ⁿ). m işlemciye eşit bölünse bile O(2ⁿ/m): hâlâ üstel.
  • SAT, polinom zamanlı algoritması bilinmeyen NP-tam bir problemdir. 2-SAT polinom zamanda çözülür, 3-SAT NP-tamdır.
Hocadan“Computational Theory dersini keşke almış olsaydınız; bu derste problemleri sınıflandırıyoruz.”

Geri İzleme

SAT: Kök-Sonda Dolaşımla Değerlendirme

typedef enum { DEGIL, VE, VEYA, DOGRU, YANLIS } mantik;
typedef struct agac *agac_gost;
struct agac {
  agac_gost solcocuk, sagcocuk;
  mantik veri;
  short deger;
};

void kok_sonda_degerlendir(agac_gost L) {
  if (L) {
    kok_sonda_degerlendir(L->solcocuk);
    kok_sonda_degerlendir(L->sagcocuk);
    switch (L->veri) {
      case DEGIL: L->deger = !L->sagcocuk->deger; break;
      case VE:   L->deger = L->solcocuk->deger
                         && L->sagcocuk->deger; break;
      case VEYA: L->deger = L->solcocuk->deger
                         || L->sagcocuk->deger; break;
      case DOGRU:  L->deger = 1; break;
      case YANLIS: L->deger = 0; break;
    }
  }
}
  • Kök-sonda (postorder): önce iki çocuk, sonra düğümün kendisi.
  • ¬ düğümünün tek işleneni sağ çocuktadır.
  • Yapraklar: her atamada değişkenlerin değeri DOGRU/YANLIS olarak yerleştirilir.
Notlardaki enum { not, and, or, true, false } adları C99’un <stdbool.h> makrolarıyla ve C23 anahtar sözcükleriyle çakışır; typedef struct agac {…}; da ad vermeyen bir typedef’tir. Burada ASCII ve çakışmasız adlar kullandık.

Geri İzleme

SAT Türleri ve Ön Hesaplama (Precomputing)

CIRCUIT-SAT

Verilen bir mantık devresinin çıkışını 1 yapacak bir giriş ataması var mı?

Formula SAT

Yukarıdaki gibi ∧, ∨, ¬ ile kurulmuş bir önerme formülü.

3-CNF-SAT

Her alt cümle (clause) 3 değişken içeren ∧’lerin ∨’si: (x1 ∨ ¬x1 ∨ ¬x2) ∧ (x3 ∨ x2 ∨ x4) ∧ (¬x1 ∨ ¬x3 ∨ ¬x4).

Ön hesaplama

İşlem ağacı bir kez kurulur; her atamada yalnız yapraklar değişir. Defalarca yapılacak iş için bir kez hazırlanan veri yapısı verimi çok artırır.

Hocadan“Google’a yazdın, tak buldu! Bak, hızlı algoritma: Knuth–Morris–Pratt. Lütfen algoritma analizi kitaplarından greedy algoritmalara, branch and bound ve precomputing konularına çalışın!”

Notlardaki özdeyiş (“I haven’t failed, I’ve found 10,000 ways that don’t work.”) Benjamin Franklin’e atfedilmiş; yaygın olarak Thomas Edison’a atfedilir.

Geri İzleme · Zenginleştirme

n-Vezir (n-Queens) Problemi

n×n satranç tahtasına n veziri, hiçbiri diğerini tehdit etmeyecek biçimde yerleştir: aynı satır, sütun ve çaprazda iki vezir olamaz.

  • Her satıra bir vezir → çözüm bir q[0..n−1] dizisi.
  • Kaba kuvvet: nⁿ aday (satır başına bir vezirle; n = 8 için 16,7 milyon).
  • Geri izleme: satır satır ilerle; uygun sütun yoksa bir önceki satıra dön.
  • Çapraz testi: |q[i] − c| == r − i.
int q[8];  /* q[r]: r. satirdaki vezirin sutunu */

int uygun(int r, int c) {
  int i;
  for (i = 0; i < r; i++)
    if (q[i] == c || abs(q[i] - c) == r - i)
      return 0;         /* ayni sutun ya da capraz */
  return 1;
}

Zenginleştirme · Horowitz–Sahni; Sedgewick. n = 4 için 2, n = 8 için 92 çözüm vardır.

Geri İzleme · Kodu adım adım çalıştır

Kod İzleme: yerlestir(0, 4)

(0, 0) uygun → q[0] = 0, sonraki satıra geç.

Sütun 0, 1 çakışıyor (×); (1, 2) uygun → q[1] = 2, sonraki satıra geç.

Sütun 0, 1, 2, 3 çakışıyor; satır 2’e vezir konamaz → return 0: geri dön, bir üst satır sıradaki sütunu denesin.

(1, 3) uygun → q[1] = 3, sonraki satıra geç.

Sütun 0 çakışıyor (×); (2, 1) uygun → q[2] = 1, sonraki satıra geç.

Sütun 0, 1, 2, 3 çakışıyor; satır 3’e vezir konamaz → return 0: geri dön, bir üst satır sıradaki sütunu denesin.

Sütun 2, 3 çakışıyor; satır 2’e vezir konamaz → return 0: geri dön, bir üst satır sıradaki sütunu denesin.

Kalan sütun yok; satır 1’e vezir konamaz → return 0: geri dön, bir üst satır sıradaki sütunu denesin.

(0, 1) uygun → q[0] = 1, sonraki satıra geç.

Sütun 0, 1, 2 çakışıyor (×); (1, 3) uygun → q[1] = 3, sonraki satıra geç.

(2, 0) uygun → q[2] = 0, sonraki satıra geç.

Sütun 0, 1 çakışıyor (×); (3, 2) uygun → q[3] = 2, sonraki satıra geç.

r = n: dört vezir yerleşti → çözüm q = [1, 3, 0, 2]. 8 yerleştirme yaptık; kaba kuvvet 4⁴ = 256 aday.

int yerlestir(int r, int n) {
  int c;
  if (r == n) return 1;             /* cozum */
  for (c = 0; c < n; c++)
    if (uygun(r, c)) {
      q[r] = c;
      if (yerlestir(r + 1, n)) return 1;
    }
  return 0;                  /* geri don */
}

void altkume(char *s, int n, int i,
             int sec[]) {
  int j;
  if (i == n) {                  /* karar bitti */
    printf("{");
    for (j = 0; j < n; j++)
      if (sec[j]) printf("%c", s[j]);
    printf("}\n");
    return;
  }
  sec[i] = 1; altkume(s, n, i + 1, sec);
  sec[i] = 0; altkume(s, n, i + 1, sec);
}

Geri İzleme

Warnsdorff’un Sezgisel Kuralı (1823)

“Atın bir sonraki gideceği yer, ilerleme sayısı sıfır olmayan ama en az olan karedir.” İlerleme sayısı: o kareden doğrudan gidilebilecek boş kare sayısı. Önce köşeler ve kenarlar tüketilir, çıkmaz sonraya kalmaz.

1. kare. Adaylar (yeşil sayı = oradan sonraki hamle sayısı): 5, 5 → en küçük pozitif: 5, (1, 2) seçilir.

2. kare. Adaylar (yeşil sayı = oradan sonraki hamle sayısı): 1, 3, 3, 3, 3 → en küçük pozitif: 1, (0, 4) seçilir.

3. kare. Adaylar (yeşil sayı = oradan sonraki hamle sayısı): 5 → en küçük pozitif: 5, (2, 3) seçilir.

4. kare. Adaylar (yeşil sayı = oradan sonraki hamle sayısı): 1, 3, 2, 3, 3 → en küçük pozitif: 1, (4, 4) seçilir.

5. kare. Adaylar (yeşil sayı = oradan sonraki hamle sayısı): 5 → en küçük pozitif: 5, (3, 2) seçilir.

9. kare. Adaylar (yeşil sayı = oradan sonraki hamle sayısı): 2, 2 → en küçük pozitif: 2, (1, 4) seçilir.

16. kare. Adaylar (yeşil sayı = oradan sonraki hamle sayısı): 1, 4 → en küçük pozitif: 1, (4, 2) seçilir.

24. kare. Adaylar (yeşil sayı = oradan sonraki hamle sayısı): 0 → en küçük pozitif: 0, (2, 2) seçilir.

25 kare, hiç geri dönmeden gezildi. Warnsdorff her adımda yalnız 8 komşuya bakar: toplam iş O(n²).

Notlarda “WANSDORFF” yazılmış; doğrusu H. C. von Warnsdorff. Eşitlikte hamle tablosundaki sıra (0…7) kullanıldı.

Bölüm Özeti

Özyineleme

Taban durum + küçülen adım. Her çağrı bir yığıt çerçevesi; kuyruk özyinelemesi döngüye çevrilebilir.

İkili arama

Sıralı dizide aralığı yarılar: O(log n). İndis döndür, −1 hata.

Hanoi

h(n) = 2h(n−1) + 1 = 2ⁿ − 1. Çağrı ağacı = yığıtın tarihçesi.

Permütasyon

Takas + özyineleme + geri takas: n! çıktı, O(n·n!).

Geri izleme

Kısmi çözümü kur, kural bozulunca buda ve geri al: SAT, n-vezir, alt küme.

Sezgisel

Warnsdorff: en az ilerleme sayılı kare. Daha iyi çözümü aramaktan vazgeçme.
