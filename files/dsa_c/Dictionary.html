Data Structures and Algorithms with C Dictionary

Terms used in the course, each with a short definition and the chapter where it is explained. The chapter column links to that chapter's lecture notes.

TermDefinitionChapter
abstract data type (ADT)A type defined by its values and operations alone, independently of how they are implemented.1 · Introduction and Algorithm Analysis

activity on edge (AOE) networkAn activity network in which the tasks are edges and the events are vertices.18 · Shortest Paths and Activity Networks

address-of operator (&)The unary operator that yields the address of an object.4 · Linked Lists

adjacency matrixAn n×n matrix in which a[i][j] = 1 if there is an edge between i and j.15 · Graphs
adjacency multilistA representation of an undirected graph in which each edge is stored once but appears in the edge lists of both of its endpoints.15 · Graphs
adjacentTwo vertices that are joined by an edge.15 · Graphs

algorithmA method that solves a problem in a finite number of precise and effective steps.1 · Introduction and Algorithm Analysis
alignmentThe compiler's placement of fields at addresses that are multiples of a given size; it affects the size of structures.2 · Arrays and Structures

Big OAn upper bound: f(n) = O(g(n)) if f(n) ≤ c·g(n) for all n ≥ n₀.1 · Introduction and Algorithm Analysis
Big OmegaA lower bound: f(n) = Ω(g(n)) if f(n) ≥ c·g(n) for all n ≥ n₀.1 · Introduction and Algorithm Analysis
Big ThetaA tight bound: f(n) = Θ(g(n)) if f(n) is both O(g(n)) and Ω(g(n)).1 · Introduction and Algorithm Analysis

bottom-upAn approach that first builds small pieces and then combines them into the whole.1 · Introduction and Algorithm Analysis
