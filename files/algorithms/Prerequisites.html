Java basics: types, conditions, loops

int · long · double · if · for · while

The code in the slides is written in Java, so you need to be able to trace on paper how many times a loop runs and how each variable changes. The int type's limit of roughly ±2.1 billion and integer division (7 / 2 = 3) are common sources of bugs.

Why it matters

All the code-trace slides use these constructs; the classic overflow bug in binary search also comes from the int limit.

Where it is usedChapter 3 · Insertion: CodeChapter 2 · Counting StepsChapter 4 · Implementation Details

Check question

int a = 7, b = 2; double d = a / b; What is the value of d?

3.0. The division is performed on integers (3), and only then is the result converted to double. To get 3.5, write (double) a / b.

Example (Java) 
int sum = 0;
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) sum += i;       // even numbers are added
}
System.out.println(sum);            // 30
long big = 50_000L * 50_000;        // would overflow as an int
System.out.println(big);            // 2500000000

Arrays and two-dimensional arrays

indices start at 0 · length · int[][]

Sorting, searching and dynamic programming tables all work on arrays. You should know that indices run from 0 to length − 1, that an array is passed to a method by reference, and that a two-dimensional array is traversed row by row.

Why it matters

Sorting algorithms work in place on an array, DP tables are two-dimensional arrays, and an adjacency matrix is a two-dimensional array too.

Where it is usedChapter 3 · Bubble: CodeChapter 5 · Storing a Graph

Check question

What happens if a[3] is read after the line int[] a = {3, 1, 2};?

An ArrayIndexOutOfBoundsException is thrown; the valid indices are 0, 1 and 2.

Example (Java) 
int[] a = new int[5];              // [0, 0, 0, 0, 0]
a[a.length - 1] = 9;               // last element
int[][] dp = new int[3][4];        // 3 rows, 4 columns
for (int i = 0; i < dp.length; i++)
    for (int j = 0; j < dp[i].length; j++)
        dp[i][j] = i + j;
System.out.println(dp[2][3]);      // 5
Aa

Strings and characters

String · charAt · length() · char codes · compareTo

The Java code of string algorithms works on String objects. s.length() gives the length and s.charAt(i) gives the i-th character; indices start at 0 as in arrays. A String is immutable: s + c builds a new object every time, so StringBuilder is used to accumulate a string inside a loop. The char type is a 16-bit integer; ch - 'a' converts a lowercase letter to an index in the range 0–25, and a character can be used directly as an index into a counting array. The contents of two strings are compared with equals, not ==, and lexicographic order with compareTo.

Why it matters

The brute-force, KMP, Boyer-Moore and Rabin-Karp code compares characters with charAt; trie nodes pick a child with ch - 'a', and hash functions and radix sort use character codes like numbers.

Where it is usedChapter 9 · Brute Force: TraceChapter 11 · Insertion AlgorithmChapter 4 · The Hash FunctionChapter 10 · Example: apple · apricot

Check question

Does "kedi".compareTo("kek") return a negative or a positive value?

Negative. The first two characters are equal; at the third position 'd' (100) is compared with 'k' (107), and 100 − 107 = −7 is returned.

Example (Java) 
String s = "algorithm";
System.out.println(s.length());                // 9
System.out.println(s.charAt(0));               // a
int idx = s.charAt(2) - 'a';                   // 'g' → 6
StringBuilder sb = new StringBuilder();
for (int i = s.length() - 1; i >= 0; i--) sb.append(s.charAt(i));
System.out.println(idx + " " + sb);            // 6 mhtirogla
System.out.println("abc".equals("ab" + "c"));  // true

Methods and parameter passing

return value · pass by value · array reference

Algorithms are usually written as methods: the input is the parameter and the result is the return value. Java passes everything by value; but for arrays and objects the copied value is a reference, so a swap inside the method changes the caller's array.

Why it matters

All sorting algorithms use helper methods that swap or shift elements; the partition method returns the final position of the pivot.

Where it is usedChapter 3 · Bubble: CodeChapter 3 · Partitioning Procedure

Check question

Does writing a = new int[10]; inside a method change the caller's array?

No. Only the method's local reference is bound to the new array; the caller continues to see the old array.

Example (Java) 
static void swap(int[] a, int i, int j) {
    int t = a[i]; a[i] = a[j]; a[j] = t;     // the caller's array changes
}
static void increment(int x) { x++; }        // the caller's variable does not change

int[] d = {5, 7};
swap(d, 0, 1);               // d = [7, 5]
int y = 1;
increment(y);                // y is still 1
System.out.println(d[0] + " " + y);   // 7 1

Recursion and the call stack

base case · recursive call · depth

Merge sort, quicksort, DFS, backtracking and divide-and-conquer algorithms are recursive. You should know that each call is pushed onto the call stack with its own local variables, that forgetting the base case causes a StackOverflowError, and that recursion depth consumes memory.

Why it matters

Fast exponentiation, merge sort, recursive DFS and the backtracking template are written directly with recursion.

Where it is usedChapter 5 · Recursive DFS: Pseudocode

Check question

In the call power(2, 10), how many times does the power method run, counting the first call?

5 times: n = 10, 5, 2, 1, 0.

Example (Java) 
static int power(int a, int n) {          // a to the power n, n >= 0
    if (n == 0) return 1;                    // base case
    int half = power(a, n / 2);              // the problem is halved
    return (n % 2 == 0) ? half * half : half * half * a;
}

System.out.println(power(2, 10));         // 1024; depth is about log2(n)
OOP

Classes, objects and comparators

class · Comparable · Comparator · generics

Concepts such as an edge, a node, a job or an item are represented by small classes. Sorting and priority queues need a compareTo method or a Comparator to compare elements: in Kruskal's algorithm edges are sorted by weight, and in activity selection activities are sorted by finish time.

Why it matters

Most greedy algorithms start with a sort; Dijkstra and Prim put comparable objects into a priority queue.

Where it is usedChapter 7 · Kruskal: Steps and Pseudocode

Check question

Why is writing return w - o.w; inside compareTo risky?

With large positive and negative values the subtraction can exceed the int range and flip the sign; Integer.compare does not overflow.

Example (Java) 
static class Edge implements Comparable<Edge> {
    final int u, v, w;
    Edge(int u, int v, int w) { this.u = u; this.v = v; this.w = w; }
    public int compareTo(Edge o) { return Integer.compare(w, o.w); }
}

List<Edge> edges = new ArrayList<>();
edges.add(new Edge(0, 1, 7));
edges.add(new Edge(1, 2, 3));
Collections.sort(edges);                           // ascending by weight
edges.sort((a, b) -> Integer.compare(b.w, a.w));   // descending: a Comparator
System.out.println(edges.get(0).w);                // 7

Java collections

ArrayList · HashMap · ArrayDeque · PriorityQueue

The Java code in the slides often uses ready-made structures: ArrayList for adjacency lists, ArrayDeque for the BFS queue and the DFS stack, PriorityQueue for Dijkstra and Prim, HashMap for memoization. Knowing the cost of each basic operation is a prerequisite for computing an algorithm's total running time correctly.

Why it matters

BFS is written with a queue, Dijkstra with a priority queue, memoization with a map.

Where it is usedChapter 5 · BFS: PseudocodeChapter 6 · Dijkstra: Java Trace

Check question

How long do add and poll take in a PriorityQueue? How long do contains(x) and remove(x) take?

add and poll take O(log n); contains(x) and remove(x) take O(n) because they scan the internal array from start to end.

Example (Java) 
Deque<Integer> queue = new ArrayDeque<>();
queue.offer(1); queue.offer(2);
int first = queue.poll();                         // 1 (first in, first out)

PriorityQueue<int[]> pq = new PriorityQueue<>((x, y) -> Integer.compare(x[1], y[1]));
pq.add(new int[] {7, 40});
pq.add(new int[] {3, 15});
int[] smallest = pq.poll();                       // [3, 15]

Map<Integer, Long> memo = new HashMap<>();
memo.put(10, 55L);
System.out.println(first + " " + smallest[0] + " " + memo.get(10));   // 1 3 55

Reading and tracing pseudocode

← assignment · indices starting at 1 · trace table

Slides and textbooks often give algorithms in pseudocode: ← is assignment, arrays may start at 1, and “for j ← 2 to n” includes the final value. When translating to Java you need to account for these differences and be able to write the value of every variable at every step into a trace table.

Why it matters

Graph, flow and branch-and-bound algorithms are given first in pseudocode and then in Java.

Where it is usedChapter 3 · Insertion: CodeChapter 6 · Dijkstra: PseudocodeChapter 8 · Pseudocode

Check question

How are the loops written when the pseudocode above is translated to Java with indices starting at 0?

The outer loop becomes for (int j = 1; j < n; j++), and the inner condition takes the form i >= 0 && A[i] > key.

Example 
INSERTION-SORT(A, n)
  for j ← 2 to n
      key ← A[j]
      i ← j − 1
      while i > 0 and A[i] > key
          A[i + 1] ← A[i]
          i ← i − 1
      A[i + 1] ← key

Testing and debugging

edge cases · assertions · small inputs

A correct idea must also be implemented carefully and tested. Testing with empty input, a single element, repeated values, sorted and reverse-sorted arrays, disconnected graphs and large values that may cause overflow should become a habit.

Why it matters

The “common mistakes” slide of every chapter collects such edge cases.

Where it is usedChapter 3 · Common MistakesChapter 4 · Implementation Details

Check question

When does mid = (low + high) / 2 give a wrong result in binary search?

When the sum low + high exceeds the int range, it overflows and becomes negative; low + (high − low) / 2 is safe.

Example (Java) 
int[] empty = {}, one = {4}, equal = {2, 2, 2}, rev = {5, 4, 3, 2, 1};
for (int[] t : new int[][] {empty, one, equal, rev}) {
    int[] k = t.clone();
    Arrays.sort(k);
    for (int i = 1; i < k.length; i++)
        if (k[i - 1] > k[i]) throw new AssertionError("not sorted");
}
System.out.println("all tests passed");

Basic data structures

The structures algorithms work on and the cost of their basic operations. These structures are covered in detail in the prerequisite course Data Structures.

→

Linked lists

node · next · O(1) insertion at the head

Like an array, it stores a sequence, but the elements are not contiguous in memory; each node points to the next one. Insertion at the head takes O(1), and access to the i-th element takes O(n). Adjacency lists, chaining in hash tables and the O(1) implementation of an LRU cache rely on linked lists.

Why it matters

Chained hash tables and the O(1) LRU cache use linked lists.

Where it is usedChapter 4 · Insertion with Chaining

Check question

Why does deleting the last element of a singly linked list take O(n)?

The next field of the second-to-last node must be set to null; reaching that node requires walking from the head.

Example (Java) 
static class Node {
    int value; Node next;
    Node(int value, Node next) { this.value = value; this.next = next; }
}

Node head = null;
for (int x = 1; x <= 3; x++) head = new Node(x, head);    // 3 → 2 → 1
for (Node n = head; n != null; n = n.next) System.out.print(n.value + " ");

Stacks and queues

LIFO · FIFO · push/pop · offer/poll

A stack works by the last-in, first-out (LIFO) principle and a queue by first-in, first-out (FIFO); the basic operations of both take O(1). DFS works with a stack (or with the call stack of recursion) and BFS with a queue; backtracking undoes choices in stack order.

Why it matters

Iterative DFS uses an explicit stack; BFS and Edmonds-Karp use a queue.

Where it is usedChapter 5 · Tracing Stack DFSChapter 5 · BFS: The IdeaChapter 8 · Augmenting Paths with BFS (Java)

Check question

1, 2, 3 are added in this order to both a queue and a stack. Which element comes out first from each?

From the queue, 1 comes out first; from the stack, 3 comes out first.

Example (Java) 
Deque<Character> stack = new ArrayDeque<>();
for (char c : "abc".toCharArray()) stack.push(c);
StringBuilder sb = new StringBuilder();
while (!stack.isEmpty()) sb.append(stack.pop());
System.out.println(sb);                     // cba

Heaps and priority queues

complete binary tree · array layout · O(log n)

In a min-heap every node is smaller than its children, so the smallest element is at the root. Stored as an array, the children of node i are at 2i + 1 and 2i + 2 and its parent is at (i − 1) / 2. Insertion and extracting the minimum take O(log n); heap sort, Dijkstra, Prim, Huffman and the online median rely on this structure.

Why it matters

Heap sort, the complexity of Dijkstra's algorithm, building the Huffman tree and the online median rely on the heap.

Where it is usedChapter 3 · HeapsortChapter 6 · Dijkstra: Complexity

Check question

Building a heap by inserting n elements one at a time takes O(n log n). How long does bottom-up heap construction take?

O(n); because most nodes are near the leaves, the total sift-down work stays linear.

Example 
array:  [2, 5, 3, 9, 6, 4]
index:   0  1  2  3  4  5
children of 2: 5 and 3   (index 1, 2)
children of 5:  9 and 6   (index 3, 4)
child of 3:     4         (index 5)

Hash tables

hash function · collision · average O(1)

A hash table converts a key into an array index with a hash function; insertion and search take O(1) on average. When two keys land in the same cell, the collision is resolved by chaining or linear probing; performance drops as the load factor grows. Memoization, “visited” sets and Rabin-Karp's hash comparison rely on this idea.

Why it matters

Search by hashing, Rabin-Karp and memoization use a hash table.

Where it is usedChapter 4 · Hashing: The IdeaChapter 4 · Load FactorChapter 9 · Rabin-Karp

Check question

What is the worst-case search time in a hash table, and when does it occur?

O(n); when all keys land in the same cell (the same chain).

Example (Java) 
int m = 7;
int[] keys = {10, 17, 24};
for (int k : keys) System.out.print(k % m + " ");   // 3 3 3 → collision
Set<String> visited = new HashSet<>();
visited.add("A");
System.out.println(visited.contains("A"));          // true

Trees and binary search trees

root · parent · child · leaf · height

A tree with n nodes has n − 1 edges and exactly one path between any two nodes. The terms root, parent, child, leaf, depth and height are used unchanged in DFS/BFS trees, MSTs, the union-find structure, tries and state-space trees. A binary search tree keeps smaller keys in the left subtree and larger keys in the right subtree; if the tree is balanced, search takes O(log n).

Why it matters

The BFS tree, spanning trees, tries and state-space trees are described with the same terms.

Where it is usedChapter 5 · BFS Tree and Shortest PathsChapter 7 · Spanning Trees and MSTsChapter 11 · Basic Components

Check question

At most how many nodes can a binary tree of height h contain?

2^(h+1) − 1 (taking the height of a single node as 0).

Example 
        8            height 2; leaves 1, 6, 14
      /   \
     3     10        parent of 3 is 8, children are 1 and 6
    / \      \
   1   6      14     inorder traversal: 1 3 6 8 10 14

Graph representations

G = (V, E) · adjacency list · adjacency matrix

A graph consists of vertices and edges; edges may be directed or undirected, weighted or unweighted. An adjacency matrix uses V² memory and answers an edge query in O(1); an adjacency list uses O(V + E) memory and traverses sparse graphs in O(V + E) time. The terms degree, path, cycle, connectivity and bipartiteness should be familiar.

Why it matters

All graph chapters, and the TSP examples in branch and bound, assume a graph representation.

Where it is usedChapter 5 · Storing a GraphChapter 5 · Kinds of GraphsChapter 6 · Graphs and Shortest Paths

Check question

Which representation suits a road network with 10,000 vertices and 30,000 edges?

An adjacency list: a matrix needs 10⁸ cells, while the list holds about V + 2E = 70,000 entries for an undirected graph.

Example (Java) 
int V = 4;
List<List<Integer>> adj = new ArrayList<>();
for (int i = 0; i < V; i++) adj.add(new ArrayList<>());
int[][] edges = {{0, 1}, {0, 2}, {2, 3}};
for (int[] e : edges) {                    // undirected: both directions are added
    adj.get(e[0]).add(e[1]);
    adj.get(e[1]).add(e[0]);
}
System.out.println(adj.get(0));            // [1, 2]

Discrete mathematics and proof

The language used to define algorithms and prove them correct.

∈

Sets, functions and relations

∪ ∩ \ · |A| · f: A → B · relation

Algorithms are described in the language of sets: G = (V, E), the set of visited vertices, the cut (S, V − S) in an MST, the subset of items chosen in the knapsack. You should know union, intersection, difference, Cartesian product and subsets; the domain and codomain of a function; and the reflexivity, symmetry and transitivity of relations.

Why it matters

The cut property, Floyd-Warshall's transitive closure and the feasible solutions in branch and bound are defined with sets.

Where it is usedChapter 7 · Cut and Cycle PropertiesChapter 6 · The Floyd-Warshall Algorithm

Check question

How many subsets does a set with n elements have, and in which brute-force methods does this cost appear?

2ⁿ; trying every selection one by one in subset sum or 0/1 knapsack.

Example 
A = {1, 2, 3},  B = {2, 3, 4}
A ∪ B = {1, 2, 3, 4}    A ∩ B = {2, 3}    A \ B = {1}
|A × B| = 3 · 3 = 9     number of subsets of A: 2³ = 8
The relation "reachable" is reflexive and transitive; in an undirected graph it is also symmetric.
∀

Logic and quantifiers

∧ ∨ ¬ ⇒ · ∀ ∃ · De Morgan

Loop conditions, pruning conditions and definitions are logical statements. You need to be able to read quantified sentences such as “for every n ≥ n₀, f(n) ≤ c · g(n),” to negate a statement correctly (De Morgan), and to tell “p ⇒ q” from “q ⇒ p.”

Why it matters

Big-O is defined with quantifiers; the inner loop of insertion sort stops on a compound condition.

Where it is usedChapter 2 · Definition of Big OChapter 3 · Insertion: Code

Check question

What is the negation of the statement “every vertex has at least one neighbor”?

“There is at least one vertex with no neighbors.” ∀ and ∃ swap places and the inner statement is negated.

Example 
¬(a ∧ b)  ≡  ¬a ∨ ¬b                         (De Morgan)
while (i > 0 && A[i] > x) loop exit condition:  i <= 0 || A[i] <= x
f(n) = O(g(n))  ⇔  ∃c > 0, ∃n₀, ∀n ≥ n₀ : f(n) ≤ c · g(n)

Induction and loop invariants

base case · inductive step · initialization–maintenance–termination

Induction proves a statement for every n by showing that P(1) is true and that P(k) ⇒ P(k + 1). A loop invariant is its adaptation to algorithms: a statement that is true before the loop (initialization), is preserved in every iteration (maintenance) and gives the result when the loop ends (termination). The correctness of recursive algorithms is also proved by induction.

Why it matters

The correctness of sorting algorithms and the solutions of recurrences are shown by induction.

Where it is usedChapter 3 · Insertion: StepsChapter 2 · f3: Expanding the Recurrence

Check question

How is the equality 1 + 3 + 5 + … + (2n − 1) = n² shown by induction?

For n = 1, 1 = 1². If the equality holds for k, the sum for k + 1 is k² + (2k + 1) = (k + 1)².

Example 
Insertion sort, invariant: "at the start of iteration j, A[0..j−1] is sorted."
  Initialization: j = 1 → A[0..0] is a single element, so it is sorted.
  Maintenance:    A[j] is shifted into place → A[0..j] is sorted.
  Termination:    j = n → A[0..n−1], that is, the whole array is sorted.

Analysis tools

Sums, logarithms and growth rates for computing running times.

Σ

Summation notation and series

arithmetic · geometric · harmonic

The cost of nested loops and recursion trees is written as a sum. Three series are fundamental: the arithmetic series grows quadratically; a geometric series with ratio less than 1 converges to a constant, while one with ratio greater than 1 is of the order of its largest term; the harmonic series grows logarithmically.

Why it matters

Counting loop iterations, adding up the levels of a recursion tree and the expected number of comparisons of randomized quicksort use these series.

Where it is usedChapter 2 · f2: The SumChapter 2 · Loop Patterns

Check question

How many times does the body of the loop for (i = 1; i < n; i *= 2) for (j = 0; j < i; j++) run?

1 + 2 + 4 + … < 2n times, that is, Θ(n) (a geometric series).

Example 
Σ (i = 1..n) i       = n(n + 1) / 2          = Θ(n²)
Σ (i = 0..k) 2^i     = 2^(k+1) − 1             (1 + 2 + 4 + … + 2^k)
Σ (i = 0..∞) (1/2)^i = 2
H(n) = Σ (i = 1..n) 1/i ≈ ln n               = Θ(log n)
log

Logarithm and exponent rules

log₂ n · exponent rules · change of base

Every algorithm that halves its input (binary search, merge sort, heaps) produces logarithmic depth: reducing n to 1 means halving log₂ n times. You should know the rules of exponents and logarithms, that the base of a logarithm is asymptotically irrelevant, and the approximation 2¹⁰ ≈ 10³.

Why it matters

The number of steps of binary search, the n^(log_b a) term in the master theorem and Karatsuba's exponent n^1.585 are computed with logarithms.

Where it is usedChapter 4 · How Many Steps?Chapter 2 · Three Cases

Check question

At most about how many comparisons does binary search make on a sorted array of a billion elements?

About 30, because 2³⁰ ≈ 1.07 · 10⁹.

Example 
log2(1024) = 10        log2(10^6) ≈ 20       log2(10^9) ≈ 30
a^(m+n) = a^m · a^n     (a^m)^n = a^(m·n)     log(x·y) = log x + log y
n^(log_b a) = a^(log_b n)              appears in the master theorem
log_3 n = log_2 n / log_2 3            the base changes only a constant factor

Floor and ceiling

⌊x⌋ · ⌈x⌉ · integer division

When an array is split in two, the halves hold ⌊n/2⌋ and ⌈n/2⌉ elements; in Java n / 2 gives the floor for positive numbers. Floor and ceiling appear in the middle index of binary search, the parent index in a heap, the height of a binary tree and approximation ratios.

Why it matters

The split step of merge sort, the middle index of binary search and the index computations of a heap use floor and ceiling.

Where it is usedChapter 3 · Merge Sort: RecursionChapter 4 · The Binary Search AlgorithmChapter 3 · Heapsort: Example

Check question

What is −7 / 2 in Java? What is ⌊−7/2⌋?

Java gives −3 (it truncates toward zero), whereas ⌊−3.5⌋ = −4. For negative numbers, Math.floorDiv gives the floor.

Example 
⌊7/2⌋ = 3      ⌈7/2⌉ = 4      ⌊n/2⌋ + ⌈n/2⌉ = n
height of a heap with n nodes is ⌊log2 n⌋:  n = 10 → 3
Java: 7 / 2 == 3,  (7 + 2 − 1) / 2 == 4     for positive a, b: ⌈a/b⌉ = (a + b − 1) / b

Asymptotic growth

1 < log n < n < n log n < n² < 2ⁿ < n!

For large n the dominant term decides: 3n² + 100n + 7 = Θ(n²). You should be able to order the growth classes and, assuming roughly 10⁸–10⁹ simple operations per second, estimate which complexity is practical for which n. O is the upper bound, Ω the lower bound and Θ the tight bound.

Why it matters

Every chapter compares algorithms by their complexity; growth classes determine which method suits which input size.

Where it is usedChapter 2 · Growth CurvesChapter 2 · Asymptotic RulesChapter 2 · Common Growth Classes

Check question

Which eventually grows faster: n¹⁰⁰ or 1.01ⁿ?

1.01ⁿ; every exponential function with a base greater than 1 eventually overtakes every polynomial.

Example 
approximate operation counts for n = 10^6
  n log2 n ≈ 2 · 10^7     → under a second
  n²       = 10^12        → hours
  2^n      : even n = 60 is ≈ 10^18 → infeasible
T(n)

Recurrence relations

T(n) = aT(n/b) + f(n) · recursion tree

The running time of a recursive algorithm is written in terms of itself: merge sort solves two halves and merges in linear time, so T(n) = 2T(n/2) + n. Being comfortable with solving a recurrence by unrolling it, or by adding up the work at each level of the recursion tree, makes the master theorem much easier to follow.

Why it matters

Recurrences are solved with the master theorem; every divide-and-conquer algorithm is analyzed with a recurrence.

Where it is usedChapter 2 · Recurrence RelationsChapter 2 · f4: Recursion TreeChapter 2 · Divide-and-Conquer Recurrence

Check question

What is the recurrence of binary search, and what is its solution?

T(n) = T(n/2) + O(1); its solution is Θ(log n).

Example 
T(n) = 2T(n/2) + n
  level 0:  n                    = n
  level 1:  n/2 + n/2            = n
  level 2:  4 · n/4              = n
  … log2 n levels                ⇒ T(n) = Θ(n log n)
T(n) = T(n − 1) + 1  ⇒ Θ(n)        T(n) = 2T(n − 1) + 1  ⇒ Θ(2^n)

Combinatorics: permutations and combinations

multiplication rule · n! · C(n, k) · 2ⁿ

The cost of brute force, backtracking and branch and bound is the size of the search space; counting it takes the multiplication rule, n! permutations, C(n, k) combinations and 2ⁿ subsets. For example, in a TSP with n cities, once the starting city is fixed there are (n − 1)! tours.

Why it matters

Generating permutations, the brute-force solution of TSP and the size of the n-queens search tree are found by counting.

Where it is usedChapter 1 · O(n!): Permutations

Check question

In how many ways can 8 queens be placed on an 8 × 8 board with one queen in each row? In how many ways if the columns must also be distinct?

In 8⁸ = 16,777,216 ways; if the columns must be distinct as well, in 8! = 40,320 ways.

Example 
P(n, k) = n! / (n − k)!          C(n, k) = n! / (k! · (n − k)!)
C(5, 2) = 10       5! = 120        2^10 = 1024
n = 10 cities: 9! = 362,880 tours      n = 20 cities: 19! ≈ 1.2 · 10^17 tours

Matrix operations

row–column product · identity matrix · block form

Directly multiplying two n × n matrices performs n³ multiplications in three nested loops; Strassen reduces this number with block matrices. For adjacency matrices, Floyd-Warshall's distance table and the matrix–vector product in power iteration, you need to know the row–column product, the identity matrix and how to split a matrix into blocks.

Why it matters

Matrix multiplication is the O(n³) example in complexity analysis, the subject of Strassen's algorithm and the basic step of power iteration.

Where it is usedChapter 1 · O(n³): Matrix MultiplicationChapter 6 · Floyd-Warshall: Steps

Check question

What is the product [[1, 2], [3, 4]] · [[0, 1], [1, 0]]?

[[2, 1], [4, 3]]; multiplying by this permutation matrix on the right swaps the columns.

Example (Java) 
static int[][] multiply(int[][] a, int[][] b) {
    int n = a.length;
    int[][] c = new int[n][n];
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            for (int k = 0; k < n; k++)
                c[i][j] += a[i][k] * b[k][j];    // n³ multiplications in total
    return c;
}

int[][] c = multiply(new int[][] {{1, 2}, {3, 4}}, new int[][] {{0, 1}, {1, 0}});
System.out.println(Arrays.deepToString(c));      // [[2, 1], [4, 3]]

Plane geometry and distance measures

Euclidean distance · Manhattan distance · triangle inequality · cross product

The Euclidean distance between two points in the plane is √((x₁ − x₂)² + (y₁ − y₂)²), while the Manhattan distance, measured on a grid with horizontal and vertical steps only, is |x₁ − x₂| + |y₁ − y₂|. If a distance measure satisfies the triangle inequality, then d(a, c) ≤ d(a, b) + d(b, c): visiting a third point never shortens the route. The cross product of the vectors from A to B and from A to P, (B.x − A.x)(P.y − A.y) − (B.y − A.y)(P.x − A.x), is computed with integers; its sign tells whether P is to the left of line AB, to the right, or on it. To merely compare distances there is no need to take square roots; comparing their squares gives the same result.

Why it matters

The heuristics of the A* algorithm are the Euclidean and Manhattan distances; the convex hull relies on the orientation test, the closest pair of points on Euclidean distance, and the 2-approximation of metric TSP on the triangle inequality.

Where it is usedChapter 6 · Heuristic Functions

Check question

What are the Euclidean and Manhattan distances for A = (0, 0) and B = (3, 4)? On which side of line AB is the point P = (1, 5)?

The Euclidean distance is √(9 + 16) = 5 and the Manhattan distance is 3 + 4 = 7. Since the cross product 3 · 5 − 4 · 1 = 11 > 0, P is to the left of the line when looking from A toward B.

Example (Java) 
static double euclid(int x1, int y1, int x2, int y2) {
    return Math.hypot(x1 - x2, y1 - y2);
}
static int manhattan(int x1, int y1, int x2, int y2) {
    return Math.abs(x1 - x2) + Math.abs(y1 - y2);
}
static long cross(int ax, int ay, int bx, int by, int px, int py) {
    return (long) (bx - ax) * (py - ay) - (long) (by - ay) * (px - ax);
}
System.out.println(euclid(0, 0, 3, 4));          // 5.0
System.out.println(manhattan(0, 0, 3, 4));      // 7
System.out.println(cross(0, 0, 3, 4, 1, 5));   // 11 (P is on the left)

Modular arithmetic and GCD

a mod m · (a · b) mod m · GCD · prime numbers

Hash functions, Rabin-Karp's rolling hash, pseudorandom number generators and the Miller–Rabin test work with modular arithmetic. You need to know that taking the remainder at every step of additions and multiplications does not change the result, how the GCD is computed with Euclid's algorithm, and the definition of a prime number.

Why it matters

Euclid's algorithm, rolling hashes, Miller–Rabin and pseudorandom numbers use modular arithmetic.

Where it is usedChapter 1 · Euclid's AlgorithmChapter 9 · Rabin-Karp: How It Works

Check question

How is (17 · 23) mod 5 computed by taking remainders before multiplying?

17 mod 5 = 2 and 23 mod 5 = 3; 2 · 3 = 6 and 6 mod 5 = 1.

Example (Java) 
static int gcd(int a, int b) {
    return b == 0 ? a : gcd(b, a % b);
}

System.out.println(gcd(48, 18));                          // 6
long M = 1_000_000_007L, h = 0;
for (char c : "abc".toCharArray()) h = (h * 31 + c) % M;  // the basis of a rolling hash
System.out.println(h);                                     // 96354

Binary numbers and bit operations

& | ^ ~ << >> · powers of 2 · subset masks

Computers store numbers in binary; powers of 2, shifts and masks shorten many algorithms. The bits of an integer can represent a subset; the expression 1 << k gives 2^k, and x & (x − 1) clears the lowest 1 bit. In the n-queens problem an O(1) safety test, and iterating over all subsets for small n, are done with bit masks.

Why it matters

Radix sort works digit by digit; the n-queens solution uses bit masks.

Where it is usedChapter 3 · Radix Sort

Check question

What is the binary representation of 13? What are 13 >> 1 and 13 & 1?

1101₂; 13 >> 1 = 6 (110₂) and 13 & 1 = 1 (the number is odd).

Example (Java) 
int n = 3;
for (int mask = 0; mask < (1 << n); mask++) {           // 2³ = 8 subsets
    StringBuilder s = new StringBuilder("[");
    for (int i = 0; i < n; i++)
        if ((mask & (1 << i)) != 0) s.append(i);
    System.out.print(s.append("] "));
}
// [] [0] [1] [01] [2] [02] [12] [012]
System.out.println((16 & (16 - 1)) == 0);              // true: 16 is a power of 2
