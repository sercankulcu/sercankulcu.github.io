Soru 3: Ortalama Karşılaştırma

9 öğeli bir dizide doğrusal arama yapılıyor. Hedef her zaman dizidedir ve her konumda olma olasılığı eşittir. Ortalama kaç karşılaştırma (a[i] == hedef) yapılır?

Soru 5: f3'ün Belleği

f3(n) için zaman ve ek bellek (çağrı yığını dahil) karmaşıklığı hangisidir?

public long f3(int n) {
  if (n <= 1) {
    return 1;
  }
  return f3(n - 1) + f3(n - 1);
}

D: 2ⁿ − 1 çağrı yapılır, ama çağrılar sırayla biter: ilk f3(n − 1) tamamen bitip çerçeveleri kalkmadan ikinci başlamaz. Yığında aynı anda en çok n çerçeve bulunur (f3(n), f3(n − 1), …, f3(1)). Zaman ve bellek farklı büyüyebilir.

Soru 6: O İçin c ve n₀

4n + 25 = O(n) olduğunu tanımla gösterin: c ve n₀ sabitlerini bulun. Neden tek bir doğru cevap yoktur?

Cevabı göster

Tanım: her n ≥ n₀ için 4n + 25 ≤ c · n olacak c > 0 ve n₀ bulunmalı.

  • c = 5: 4n + 25 ≤ 5n ⇔ n ≥ 25 → n₀ = 25 (n = 25: 125 ≤ 125 ✓; n = 24: 121 > 120 ✗).
  • c = 29: 4n + 25 ≤ 4n + 25n = 29n her n ≥ 1 için → n₀ = 1.

Tanım yalnızca bir çiftin varlığını ister; c büyüdükçe n₀ küçülebilir. Küçük n'ler (n < n₀) asimptotik analizde önemsizdir.

Soru 7: Hangisi Yanlış?

f(n) = 3n² + 5n + 2 için aşağıdakilerden hangisi yanlıştır?

C: Θ hem alt hem üst sınır ister; f(n) ≥ c · n³ hiçbir c > 0 için büyük n'lerde sağlanmaz (f(n)/n³ → 0). n³ gevşek bir üst sınırdır (A doğru), n gevşek bir alt sınırdır (B doğru); sıkı sınır yalnızca n²'dir.

Soru 10: Yarım Tur Sayısı

Aşağıdaki iki metot n = 7 ve n = 8 için ayrı ayrı çağrılıyor (dizi.length = n). Her biri kaç satır yazdırır? Genel tur sayısı ve karmaşıklık nedir?

void yaz1(int[] dizi) {
  for (int i = 0; i < dizi.length / 2; i++)
    System.out.println(dizi[i]);
}
void yaz2(int n) {
  for (int i = 0; i < n; i += 2)
    System.out.println(i);
}
Cevabı göster
  • yaz1: i < n/2 (tam sayı bölmesi) → n = 7: 3 satır (7/2 = 3), n = 8: 4 satır.
  • yaz2: i = 0, 2, 4, 6 → n = 7: 4 satır (0 2 4 6), n = 8: yine 4 satır; 8 < 8 yanlış.

yaz2 ⌈n/2⌉ kez döner: n çiftse n/2, tekse (n + 1)/2 (n/2 + 1 değil). İkisinde de sabit çarpan ½ atılır: O(n/2) = O(n).

k turdan sonra i = 2ᵏ olur; döngü 2ᵏ ≤ n iken sürer → ⌊log₂ n⌋ + 1 tur → O(log n). Koşul i < n olsaydı n = 8 için 3 tur dönerdi.

Soru 12: f2(4) İzleme

f2(4) çağrısında iç döngü her dış turda kaç kez döner, metot ne döndürür?

x = 0. Dış döngü i = 0'dan 3'e kadar dönecek; iç döngü sınırı her turda i · i'dir.

i = 0: j < 0 hemen yanlış → iç döngü 0 kez döner; x = 0.

i = 1: iç döngü i · i = 1 kez döner → x = 1.

i = 2: iç döngü i · i = 4 kez döner → x = 5.

i = 3: iç döngü i · i = 9 kez döner → x = 14.

i = 4 < 4 yanlış → döngü biter; return 14 = 0 + 1 + 4 + 9 = (n − 1)n(2n − 1)/6 = 3 · 4 · 7 / 6. Toplam ≈ n³/3 → Θ(n³).

public int f2(int n) {
  int x = 0;
  for (int i = 0; i < n; i++) {
    for (int j = 0; j < i * i; j++) {
      x++;
    }
  }
  return x;
}

Soru 13: Geometrik Toplam

fonksiyon(10) ne yazdırır? İç döngünün toplam tur sayısı hangi sınıftadır?

n = 10, sayac = 0. Dış döngü i'yi her turda ikiye katlar: 1, 2, 4, 8, …

i = 1 < 10 → iç döngü 1 kez döner; sayac = 1.

i = 2 < 10 → iç döngü 2 kez döner; sayac = 3.

i = 4 < 10 → iç döngü 4 kez döner; sayac = 7.

i = 8 < 10 → iç döngü 8 kez döner; sayac = 15.

i = 16 < 10 yanlış → döngü biter; 15 yazılır. 1 + 2 + 4 + 8 = 2⁴ − 1 < 2n: dış döngü log n kez dönse de toplam Θ(n).

void fonksiyon(int n) {
  int sayac = 0;
  for (int i = 1; i < n; i *= 2) {
    for (int j = 0; j < i; j++) {
      sayac++;
    }
  }
  System.out.println(sayac);
}

Soru 14: Üçgensel Toplamlar

n = 6 için iki kod parçası ayrı ayrı çalıştırılıyor. Her biri ne yazdırır? İkisinin de karmaşıklığı nedir?

// Parça 1
int sayac = 0;
for (int i = 0; i < n; i++)
  for (int j = 0; j < i; j++)
    sayac++;
System.out.println(sayac);
// Parça 2
int sonuc = 0;
for (int i = 0; i < n; i++)
  for (int j = i; j < n; j++)
    sonuc += 1;
System.out.println(sonuc);
Cevabı göster
  • Parça 1 (j < i): 0 + 1 + 2 + 3 + 4 + 5 = n(n − 1)/2 = 15.
  • Parça 2 (j = i'den n'e): 6 + 5 + 4 + 3 + 2 + 1 = n(n + 1)/2 = 21.

İç döngünün işi her turda değişse de toplam bir aritmetik seridir: ikisi de Θ(n²). Azalan iş yükü daha iyi bir sınıf anlamına gelmez.

Soru 16: Ardışık İki Döngü

Aşağıdaki metodun zaman karmaşıklığı nedir?

public void foo(int m, int n) {

Soru 17: f6'nın Sıkı Sınırı

for (int i = 0; i < n; i = 1 << i) döngüsüyle yazılan f6 için hangisi doğrudur (taşma yok sayılırsa)?

D: i ← 2ⁱ güncellemesi i'yi kuvvet kulesi gibi büyütür: 0, 1, 2, 4, 16, 65536. Tur sayısı yinelenmiş logaritma (log* n) kadardır. A, i = 2 · i döngüsü için doğru olurdu; f6'da i'nin kendisi üs olur.

Çıktı Sorusu · Döngü Analizi

Soru 18: f6 Değerleri

Aşağıdaki f6 için f6(16), f6(17) ve f6(65537) ne döndürür? (Java'da int kaydırma miktarı 32'ye göre mod alınır.)

public static int f6(int n) {
  int x = 0;
  for (int i = 0; i < n; i = 1 << i) {
    x++;
  }
  return x;
}
Cevabı göster
  • f6(16) = 4: i = 0, 1, 2, 4 (< 16); sonra i = 16, 16 < 16 yanlış.
  • f6(17) = 5: i = 16 de 17'den küçük → bir tur daha; sonra i = 65536.
  • f6(65537): hiç bitmez. i = 65536 < 65537 → x = 6, sonra 1 << 65536 = 1 << 0 = 1 (65536 mod 32 = 0). i yeniden 1, 2, 4, 16, 65536 döngüsüne girer.

Analizdeki “taşmayı yok say” varsayımı bu yüzden önemlidir: matematiksel f6 Θ(log* n)'dir, ama Java kodu n > 65536 için sonsuz döngüdür.

Soru 19: İki Çağrı ve Tek Çağrı

f3(5) ne döndürür ve toplam kaç çağrı yapılır (ilk çağrı dahil)? Son satır return 2 * f3(n - 1); olarak değiştirilirse dönüş değeri ve çağrı sayısı ne olur?

public long f3(int n) {
  if (n <= 1) {
    return 1;
  }
  return f3(n - 1) + f3(n - 1);
}
Cevabı göster
  • f3(5) = 16 (= 2ⁿ⁻¹), 31 çağrı (= 2ⁿ − 1): her çağrı iki çağrı doğurur.
  • 2 * f3(n − 1) ile: değer yine 16, ama yalnızca 5 çağrı: f3(5), f3(4), …, f3(1).

Bağıntı 2T(n − 1) + c'den T(n − 1) + c'ye iner: Θ(2ⁿ) → Θ(n). Aynı alt problemin iki kez çözülmesi gereksizdir; sonucu bir kez hesaplayıp kullanmak yeter.

Soru 20: Tek Çağrılı Sürüm

f3'ün tek çağrılı sürümü g(4) ile çağrılıyor. Çağrı yığını nasıl büyüyüp küçülür, kaç çağrı yapılır ve sonuç nedir?

g(4) çağrıldı: 4 ≤ 1 değil → satır 5'te tek bir çağrı: g(3). Sonuç 2 ile çarpılacak.

g(3) → g(2) çağrısı. Her düzeyde yalnızca bir yeni çerçeve açılır.

g(2) → g(1) çağrısı. Her düzeyde yalnızca bir yeni çerçeve açılır.

g(1): n ≤ 1 → taban durum, 1 döner. Yığında 4 çerçeve: derinlik n.

g(2) = 2 · 1 = 2 döner.

g(3) = 2 · 2 = 4 döner.

g(4) = 2 · 4 = 8. Toplam 4 çağrı: T(n) = T(n − 1) + c → Θ(n). Aynı değeri iki çağrıyla hesaplayan f3(4) 15 çağrı yapar.

public long g(int n) {
  if (n <= 1) {
    return 1;
  }
  return 2 * g(n - 1);
}

Soru 21: Bağıntıyı Açma

T(n) = 2T(n − 1) + c, T(1) = c bağıntısı açma yöntemiyle çözülürse kapalı biçim hangisidir?

B: T(n) = 2T(n − 1) + c = 4T(n − 2) + 3c = 8T(n − 3) + 7c = … = 2ᵏ T(n − k) + (2ᵏ − 1)c. k = n − 1'de T(1) = c: 2ⁿ⁻¹c + (2ⁿ⁻¹ − 1)c = (2ⁿ − 1)c → Θ(2ⁿ). Çıkarmalı bağıntı olduğu için ana teorem uygulanamaz.

Soru 22: T(n) = T(n − 1) + n

T(n) = T(n − 1) + n, T(1) = 1 bağıntısını açma yöntemiyle çözün. Neden ana teorem uygulanamaz? Bu bağıntı hangi algoritmanın en kötü durumunda ortaya çıkar?

Cevabı göster

T(n) = n + T(n − 1) = n + (n − 1) + T(n − 2) = … = n + (n − 1) + … + 2 + T(1) = n(n + 1)/2 → Θ(n²).

Ana teorem T(n) = aT(n/b) + f(n) biçimini ister; burada alt problem n/b değil n − 1'dir (çıkarmalı bağıntı).

Pivotun hep en küçük ya da en büyük öğe olduğu hızlı sıralamada her parçalama Θ(n) sürer ve yalnızca pivotu ayırır: T(n) = T(n − 1) + Θ(n). Eklemeli sıralamanın ters sıralı girdisi de aynı toplamı verir.

Soru 27: f4(4) Özyineleme Ağacı

f4(4) çağrısında özyineleme ağacı hangi sırayla oluşur, kaç çağrı yapılır ve sonuç nedir?

f4(4): 4 > 1 → satır 5'te önce soldaki f4(4 / 2) = f4(2) çağrılır.

f4(2): 2 > 1 → f4(1) çağrılır.

f4(1): taban durum, 1 döner.

İkinci f4(1) de 1 döner → f4(2) = 1 + 1 = 2.

f4(4) sağdaki f4(2)'yi çağırır: aynı alt ağaç ikinci kez açılır.

İki f4(1) daha → bu f4(2) de 2 döner.

f4(4) = 2 + 2 = 4. Toplam 7 = 2n − 1 çağrı; seviye işleri c, 2c, 4c: yapraklar baskın → Θ(n). Yığın derinliği yalnızca log₂ n + 1 = 3.

public int f4(int n) {
  if (n <= 1) {
    return 1;
  }
  return f4(n / 2) + f4(n / 2);
}

Soru 28: f4 İçin Sık Hata

f4 (T(n) = 2T(n/2) + O(1)) için hangisi doğrudur?

D: Ana teoremde log₂ 2 = 1 > 0 → Durum 1 → Θ(n). Özyineleme ağacında 1 + 2 + 4 + … + n = 2n − 1 düğüm vardır. log n yalnızca yığın derinliği, yani bellek karmaşıklığıdır. Θ(2ⁿ) girdi n − 1 olsaydı (f3) doğru olurdu.

Soru 29: f5 Değerleri

f5(4) ve f5(32) ne döndürür? (f1(n), n döndürür.) Sonucu n log₂ n + n ile karşılaştırın.

public int f5(int n) {
  if (n <= 1) {
    return 1;
  }
  return f1(n) + f5(n / 2) + f5(n / 2);
}
Cevabı göster
  • f5(1) = 1, f5(2) = 2 + 1 + 1 = 4
  • f5(4) = 4 + 4 + 4 = 12 = 4 · 2 + 4
  • f5(8) = 32, f5(16) = 80 → f5(32) = 32 + 80 + 80 = 192 = 32 · 5 + 32

n = 2ᵏ için f5(n) = n log₂ n + n: log₂ n seviyenin her biri n iş yapar, yapraklar da n. T(n) = 2T(n/2) + Θ(n) → Durum 2 → Θ(n log n).

Soru 30: Dinamik Dizi: 9 Ekleme

Kapasitesi 1 olan ve dolunca iki katına büyüyen boş diziye 9 öğe ekleniyor. Her eklemenin maliyeti (yazma + kopya) ve toplam maliyet nedir?

1. ekleme: kapasite 1, dizi boş → 1 yazma. Maliyet = yazma + kopyalanan öğe sayısı.

2. ekleme: dizi doluydu → kapasite 1 → 2, 1 kopya + 1 yazma = 2.

3. ekleme: dizi doluydu → kapasite 2 → 4, 2 kopya + 1 yazma = 3.

4. ekleme: yer var → yalnızca 1 yazma.

5. ekleme: dizi doluydu → kapasite 4 → 8, 4 kopya + 1 yazma = 5.

6. ekleme: yer var → yalnızca 1 yazma.

7. ekleme: yer var → yalnızca 1 yazma.

8. ekleme: yer var → yalnızca 1 yazma.

9. ekleme: dizi doluydu → kapasite 8 → 16, 8 kopya + 1 yazma = 9. Toplam 24 < 3 · 9 = 27 → ekleme başına amortize Θ(1).

void ekle(int x) {
  if (boyut == veri.length) {
    int[] yeni = new int[2 * veri.length];
    for (int i = 0; i < boyut; i++)
      yeni[i] = veri[i];   // kopya
    veri = yeni;
  }
  veri[boyut++] = x;       // yazma
}

Soru 31: 17 Ekleme

Aynı dinamik diziye (kapasite 1'den başlar, dolunca iki katına çıkar) 17 öğe eklenirse toplam kaç kopya ve kaç yazma yapılır, son kapasite kaçtır? Ekleme başına ortalama maliyet nedir?

Cevabı göster

Büyütmeler 2., 3., 5., 9. ve 17. eklemelerde olur; kopyalar 1 + 2 + 4 + 8 + 16 = 31.

Yazma 17, toplam 48 < 3 · 17 = 51; son kapasite 32. Ortalama 48 / 17 ≈ 2,8 → amortize Θ(1).

17. ekleme tek başına 17 birim (16 kopya + 1 yazma) sürer: tek bir işlemin en kötü durumu Θ(n)'dir. Amortize analiz olasılık kullanmaz; her işlem dizisi için garanti verir.

Soru 32: Amortize ve Ortalama

Amortize analiz ile ortalama durum analizi arasındaki fark hangisidir?

A: Amortize maliyet, en kötü durumdaki bir işlem dizisinin toplamı / işlem sayısıdır; girdi dağılımı varsayımı yoktur. Ortalama durum ise girdilerin bir olasılık dağılımı üzerinden beklenen süredir (D bu yüzden yanlıştır). Dinamik dizide tek ekleme Θ(n) olabilir, amortize maliyet ise Θ(1)'dir.
