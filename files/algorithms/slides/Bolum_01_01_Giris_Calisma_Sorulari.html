Soru 1: Belirsiz Adım

Bir bilgisayar için yazılmış çay hazırlama algoritmasında “Çayın demlenmesini bekle.” adımı algoritmanın hangi özelliğini ihlal eder?

B: Her adımın tek bir anlamı olmalıdır; bilgisayar için adım “10 dakika bekle” biçiminde yazılmalıdır. Beklemek yapılabilir bir işlemdir (etkinlik sorunu yok); sorun sürenin yoruma bırakılmasıdır.

Soru 2: Durmayan Döngü

Aşağıdaki yöntem bir algoritma olarak hangi özelliği her girdi için sağlamaz?

int adim(int n) {
  int sayac = 0;
  while (n != 0) {
    n = n - 2;
    sayac++;
  }
  return sayac;
}

C: n tek sayıysa n hep tek kalır ve hiçbir zaman 0 olmaz; döngü durmaz. Algoritma her girdi için sonlu sayıda adımdan sonra durmalıdır. Adımlar açık ve yapılabilir; durduğu girdilerde bir çıktı da üretir.

Soru 3: Rastgele mi?

Aşağıdaki algoritmalardan hangisi aynı girdide farklı adımlar izleyebilir?

B: Pivot her çalıştırmada rastgele seçilir; aynı dizi farklı parçalamalarla sıralanır, ama çıktı yine aynı sıralı dizidir. Diğerleri deterministiktir: aynı girdide hep aynı adımları izler ve aynı sonucu verir.

Soru 4: Girdi Dört Katına Çıkınca

Bir algoritma n = 1000 öğede 2 ms sürüyor. Aynı makinede n = 4000 öğede yaklaşık ne kadar sürer? Çalışma süresi (a) Θ(n), (b) Θ(n²), (c) Θ(n³), (d) Θ(log n) ise ayrı ayrı hesaplayın.

Cevabı göster
Sınıforan f(4000)/f(1000)tahmini süre
Θ(n)48 ms
Θ(n²)4² = 1632 ms
Θ(n³)4³ = 64128 ms
Θ(log n)log₂ 4000 / log₂ 1000 = 11,97 / 9,972,4 ms

Sabit c makineden gelir ve oranda sadeleşir: T(4000)/T(1000) = f(4000)/f(1000). Logaritmik algoritmada girdinin dört katına çıkması yalnızca 2 adım ekler.

Soru 5: Baskın Terim

T(n) = 5n² + 100n log₂ n + 7 için aşağıdakilerden hangisi doğrudur?

A: n = 100'de 5n² = 50.000, 100n log₂ n = 66.439. Ama asimptotik sınıfı büyük n'deki baskın terim belirler: n = 1000'de 5.000.000'a karşı 996.578. Katsayılar sınıfı değiştirmez; n² terimi bir noktadan sonra (n ≈ 143) hep öndedir.

Soru 6: 1 Saniyede En Büyük n

Saniyede 10⁹ temel işlem yapan bir bilgisayarda, işlem sayısı f(n) olan bir algoritma 1 saniyede en fazla hangi n için biter? (a) f(n) = n log₂ n, (b) f(n) = n³, (c) f(n) = 2ⁿ, (d) f(n) = n!

Cevabı göster
f(n)koşulen büyük n
n log₂ nn log₂ n ≤ 10⁹≈ 3,96 · 10⁷
n³n³ ≤ 10⁹1000
2ⁿ2²⁹ ≈ 5,4 · 10⁸, 2³⁰ ≈ 1,07 · 10⁹29
n!12! ≈ 4,8 · 10⁸, 13! ≈ 6,2 · 10⁹12

Bilgisayar 1000 kat hızlansa n log₂ n için n yaklaşık 1000 kat büyür; 2ⁿ için yalnızca ≈ 10 artar (2¹⁰ ≈ 1000).

Soru 7: Asallık Testi

asalMi(121) ve asalMi(101) çağrılarında for döngüsü içinde kaç bölme (n % i) yapılır, sonuçlar nedir?

boolean asalMi(int n) {
  if (n <= 1)
    return false;
  else if (n == 2)
    return true;
  else if (n % 2 == 0)
    return false;
  int kokN = (int) Math.sqrt(n) + 1;
  for (int i = 3; i < kokN; i += 2)
    if (n % i == 0)
      return false;
  return true;
}
Cevabı göster
  • 121: √121 = 11 → kokN = 12 → i = 3, 5, 7, 9, 11. 121 % 11 = 0 → false, 5 bölme (121 = 11 · 11).
  • 101: (int) √101 = 10 → kokN = 11 → i = 3, 5, 7, 9; hiçbiri bölmez → true, 4 bölme.

Çift sayılar döngüden önce elenir; yalnızca tek i denenir: en fazla ≈ √n / 2 bölme → O(√n). + 1 olmasaydı 121 için i = 11 denenmez ve 121 yanlışlıkla asal bulunurdu.

Soru 8: En Büyük Öğe

enBuyukBul(new int[]{3, 9, 2, 9, 5}) ne döndürür? eleman > enBuyuk karşılaştırması kaç kez yapılır, enBuyuk kaç kez güncellenir? Dizi [2, 3, 5, 9] olsaydı?

Integer enBuyukBul(int[] dizi) {
  if (dizi.length == 0)
    return null;
  int enBuyuk = dizi[0];
  for (int eleman : dizi)
    if (eleman > enBuyuk)
      enBuyuk = eleman;
  return enBuyuk;
}
Cevabı göster
  • [3, 9, 2, 9, 5]: döner 9; 5 karşılaştırma (for-each ilk öğeyi de gezer), 1 güncelleme (3 → 9). İkinci 9, 9 > 9 yanlış olduğu için güncelleme yapmaz.
  • [2, 3, 5, 9]: döner 9; 4 karşılaştırma, 3 güncelleme (artan dizi en çok güncellemeyi yaptırır).

Karşılaştırma sayısı her girdide n'dir: süre Θ(n); güncelleme sayısı ise girdiye göre 0 ile n − 1 arasında değişir. Ek bellek O(1).

Soru 9: Matris Çarpımında Çarpma Sayısı

matrisCarp ile 2 × 3 boyutlu A ve 3 × 4 boyutlu B çarpılıyor. Sonuç matrisinin boyutu nedir, en içteki eleman += A[i][k] * B[k][j] satırı kaç kez çalışır? n × n kare matrislerde n = 100 ve n = 200 için çarpma sayısı nedir?

Cevabı göster
  • n = A.length = 2, m = B[0].length = 4, p = B.length = 3. Sonuç 2 × 4.
  • Üç iç içe döngü: n · m · p = 2 · 4 · 3 = 24 çarpma.
  • Kare matrislerde n³: n = 100 → 10⁶, n = 200 → 8 · 10⁶. n iki katına çıkınca süre 8 katına çıkar: Θ(n³).

Soru 10: Kaç Permütasyon?

permutasyon(new int[]{1, 2, 3, 4, 5}, 0) çağrısı ekrana kaç satır yazdırır?

B: ilk konum için 5, ikinci için 4, … seçenek vardır: 5! = 120 permütasyon, her biri bir satır. 32 = 2⁵ alt küme sayısıdır, 720 = 6!. Her satır n öğe yazdığı için toplam iş Θ(n · n!).

Soru 11: fib(4) Çağrı Ağacı

Saf özyinelemeli fib(4) çağrıldığında çağrılar hangi sırayla açılır, kaç çağrı yapılır ve sonuç ne olur?

fib(4) çağrıldı: 4 ≤ 1 değil. Satır 3'te önce fib(3) çağrılır; fib(4) toplama için yığında bekler.

fib(3) de taban durum değil → önce fib(2).

fib(2) → fib(1) çağrısı. Yığın derinliği 4 (main dahil).

fib(1): n ≤ 1 → taban durum, 1 döner.

fib(2)'nin ikinci çağrısı fib(0) = 0. fib(2) = 1 + 0 = 1 döner.

fib(3) ikinci çağrısını yapar: fib(1) = 1. fib(3) = 1 + 1 = 2 döner.

fib(4), fib(2)'yi çağırır: aynı alt problem ikinci kez baştan çözülür.

fib(1) = 1 ve fib(0) = 0 → bu fib(2) de 1 döner.

fib(4) = fib(3) + fib(2) = 2 + 1 = 3. Toplam 9 çağrı; fib(2) iki kez, fib(1) üç kez hesaplandı.

long fib(int n) {
  if (n <= 1) return n;
  return fib(n - 1) + fib(n - 2);
}

Soru 12: Çağrı Sayıları

fib(6) ve fibBellek(6) ayrı ayrı çağrılırsa (bellek dizisi başta sıfır) her biri toplam kaç kez çağrılır (ilk çağrı dahil) ve ne döndürür?

long fib(int n) {
  if (n <= 1) return n;
  return fib(n - 1) + fib(n - 2);
}
long fibBellek(int n) {
  if (n <= 1) return n;
  if (bellek[n] == 0)
    bellek[n] = fibBellek(n - 1)
              + fibBellek(n - 2);
  return bellek[n];
}
Cevabı göster

İkisi de 8 döndürür.

  • fib(6): 25 çağrı. Ç(n) = 1 + Ç(n − 1) + Ç(n − 2), Ç(0) = Ç(1) = 1: 1, 1, 3, 5, 9, 15, 25. Çağrı sayısı Fibonacci gibi büyür → O(2ⁿ).
  • fibBellek(6): 11 çağrı = 2n − 1. Her F(k) bir kez hesaplanır; ikinci çağrı (n − 2) bellekten hazır döner → O(n).

Soru 13: Büyüme Sırası

Büyüme hızına göre küçükten büyüğe doğru sıralama hangisidir?

D: 1 < log n < √n < n < n log n < n² < n³ < 2ⁿ < n!. n = 10⁶'da log₂ n ≈ 20, √n = 1000. n! en hızlı büyür: n = 10'da bile 3.628.800, 2¹⁰ ise 1024'tür.

Soru 14: ebob(1001, 385)

ebob(1001, 385) çağrısında hangi çağrılar yapılır, kaç bölme (mod) işlemi gerekir ve sonuç nedir?

ebob(1001, 385): b ≠ 0. 1001 = 2 · 385 + 231 → ebob(385, 231) çağrılır.

385 = 1 · 231 + 154 → ebob(231, 154).

231 = 1 · 154 + 77 → ebob(154, 77).

154 = 2 · 77 + 0 → ebob(77, 0).

b == 0 → return 77. 77, son sıfırdan farklı kalandır.

77 hiç değişmeden tüm çerçevelerden geri döner (kuyruk özyineleme). 4 bölme yetti: 1001 = 7 · 11 · 13, 385 = 5 · 7 · 11 → EBOB = 77.

int ebob(int a, int b) {
  if (b == 0)
    return a;
  return ebob(b, a % b);
}

Soru 15: Ardışık Fibonacci Sayıları

ebob(89, 55) çağrısı sonuca ulaşana kadar kaç mod (%) işlemi yapar?

A: 89, 55, 34, 21, 13, 8, 5, 3, 2, 1 kalanları sırayla oluşur; (89, 55)'ten (2, 1)'e kadar 9 çağrının her biri bir mod işlemi yapar, ebob(1, 0) taban durumdur. Ardışık Fibonacci sayılarında her bölüm 1 çıkar ve sayılar en yavaş küçülür: en kötü durum (Lamé). ebob(55, 34) ise 8 mod işlemi yapar.
