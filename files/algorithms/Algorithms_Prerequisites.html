Java temelleri: türler, koşullar, döngüler

int · long · double · if · for · while

Sunumlardaki kodlar Java ile yazılmıştır; bu yüzden bir döngünün kaç kez döndüğünü ve her değişkenin nasıl değiştiğini kâğıt üzerinde izleyebilmek gerekir. int türünün yaklaşık ±2,1 milyarlık sınırı ve tam sayı bölmesi (7 / 2 = 3) sık rastlanan hata kaynaklarıdır.

Neden önemli

Kod izleme slaytlarının hepsi bu yapıları kullanır; ikili aramadaki klasik taşma hatası da int sınırından kaynaklanır.

Kontrol sorusu

int a = 7, b = 2; double d = a / b; d'nin değeri nedir?

3.0. Bölme tam sayılar üzerinde yapılır (3), sonuç ancak ondan sonra double türüne çevrilir. 3.5 elde etmek için (double) a / b yazılır.

Örnek (Java) 
int sum = 0;
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) sum += i;       // çift sayılar toplanır
}
System.out.println(sum);            // 30
long big = 50_000L * 50_000;        // int olsaydı taşardı
System.out.println(big);            // 2500000000

Diziler ve iki boyutlu diziler

0'dan başlayan indis · length · int[][]

Sıralama, arama ve dinamik programlama tablolarının hepsi diziler üzerinde çalışır. İndislerin 0'dan length − 1'e kadar gittiği, bir dizinin metoda referansla geçtiği ve iki boyutlu bir dizinin satır satır dolaşıldığı bilinmelidir.

Neden önemli

Sıralama algoritmaları dizi üzerinde yerinde çalışır, DP tabloları iki boyutlu dizidir, komşuluk matrisi de iki boyutlu bir dizidir.

Kullanıldığı yerlerBölüm 2 · Kabarcık: KodBölüm 8 · Tablo Doldurma İzlemeBölüm 4.1 · Çizgeyi Bellekte Tutmak

Kontrol sorusu

int[] a = {3, 1, 2}; satırından sonra a[3] okunursa ne olur?

ArrayIndexOutOfBoundsException fırlatılır; geçerli indisler 0, 1 ve 2'dir.

Örnek (Java) 
int[] a = new int[5];              // [0, 0, 0, 0, 0]
a[a.length - 1] = 9;               // son öğe
int[][] dp = new int[3][4];        // 3 satır, 4 sütun
for (int i = 0; i < dp.length; i++)
    for (int j = 0; j < dp[i].length; j++)
        dp[i][j] = i + j;
System.out.println(dp[2][3]);      // 5

Metotlar ve parametre aktarımı

dönüş değeri · değerle aktarım · dizi referansı

Algoritmalar genellikle metot olarak yazılır: girdi parametredir, sonuç dönüş değeridir. Java her şeyi değerle aktarır; ancak diziler ve nesneler için kopyalanan değer bir referanstır, bu yüzden metot içindeki bir takas çağıranın dizisini değiştirir.

Neden önemli

Bütün sıralama algoritmaları öğeleri takas eden ya da kaydıran yardımcı metotlar kullanır; parçalama metodu pivotun son konumunu döndürür.

Kullanıldığı yerlerBölüm 2 · Kabarcık: KodBölüm 2 · Parçalama Prosedürü

Kontrol sorusu

Metot içinde a = new int[10]; yazmak çağıranın dizisini değiştirir mi?

Hayır. Yalnız metodun yerel referansı yeni diziye bağlanır; çağıran eski diziyi görmeye devam eder.

Örnek (Java) 
static void swap(int[] a, int i, int j) {
    int t = a[i]; a[i] = a[j]; a[j] = t;     // çağıranın dizisi değişir
}
static void increment(int x) { x++; }        // çağıranın değişkeni değişmez

int[] d = {5, 7};
swap(d, 0, 1);               // d = [7, 5]
int y = 1;
increment(y);                // y hâlâ 1
System.out.println(d[0] + " " + y);   // 7 1

Özyineleme ve çağrı yığını

taban durum · özyinelemeli çağrı · derinlik

Birleştirme sıralaması, hızlı sıralama, DFS, geri izleme ve böl ve fethet algoritmaları özyinelemelidir (recursion). Her çağrının kendi yerel değişkenleriyle çağrı yığınına (call stack) eklendiği, taban durum (base case) unutulursa StackOverflowError oluştuğu ve özyineleme derinliğinin bellek tükettiği bilinmelidir.

Neden önemli

Hızlı üs alma, birleştirme sıralaması, özyinelemeli DFS ve geri izleme şablonu doğrudan özyinelemeyle yazılır.

Kullanıldığı yerlerBölüm 6 · Hızlı Üs Alma: İzlemeBölüm 4.1 · Özyinelemeli DFS: Sözde KodBölüm 9 · Genel Şablon

Kontrol sorusu

power(2, 10) çağrısında, ilk çağrı da sayılırsa power metodu kaç kez çalışır?

5 kez: n = 10, 5, 2, 1, 0.

Örnek (Java) 
static int power(int a, int n) {          // a üzeri n, n >= 0
    if (n == 0) return 1;                    // taban durum
    int half = power(a, n / 2);              // problem yarıya iner
    return (n % 2 == 0) ? half * half : half * half * a;
}

System.out.println(power(2, 10));         // 1024; derinlik yaklaşık log2(n)
NYP

Sınıflar, nesneler ve karşılaştırıcılar

class · Comparable · Comparator · generics

Kenar, düğüm, iş ya da eşya gibi kavramlar küçük sınıflarla gösterilir. Sıralama ve öncelikli kuyruklar öğeleri karşılaştırmak için bir compareTo metoduna ya da bir Comparator'a gerek duyar: Kruskal'da kenarlar ağırlığa göre, etkinlik seçiminde etkinlikler bitiş zamanına göre sıralanır.

Neden önemli

Açgözlü algoritmaların çoğu bir sıralamayla başlar; Dijkstra ve Prim öncelikli kuyruğa karşılaştırılabilir nesneler koyar.

Kullanıldığı yerlerBölüm 4.3 · Kruskal: Adımlar ve Sözde KodBölüm 7 · Etkinlik Seçimi Problemi

Kontrol sorusu

compareTo içinde return w - o.w; yazmak neden risklidir?

Büyük pozitif ve negatif değerlerde çıkarma int sınırını aşıp işareti ters çevirebilir; Integer.compare taşmaz.

Örnek (Java) 
static class Edge implements Comparable<Edge> {
    final int u, v, w;
    Edge(int u, int v, int w) { this.u = u; this.v = v; this.w = w; }
    public int compareTo(Edge o) { return Integer.compare(w, o.w); }
}

List<Edge> edges = new ArrayList<>();
edges.add(new Edge(0, 1, 7));
edges.add(new Edge(1, 2, 3));
Collections.sort(edges);                           // ağırlığa göre artan
edges.sort((a, b) -> Integer.compare(b.w, a.w));   // azalan: Comparator
System.out.println(edges.get(0).w);                // 7

ArrayList · HashMap · ArrayDeque · PriorityQueue

Sunumlardaki Java kodları hazır yapıları sık kullanır: komşuluk listeleri için ArrayList, BFS kuyruğu ve DFS yığını için ArrayDeque, Dijkstra ve Prim için PriorityQueue, bellekleme için HashMap. Her temel işlemin maliyetini bilmek, bir algoritmanın toplam çalışma süresini doğru hesaplamanın ön koşuludur.

Neden önemli

BFS bir kuyrukla, Dijkstra bir öncelikli kuyrukla, bellekleme bir eşlemeyle (map) yazılır.

Kullanıldığı yerlerBölüm 4.1 · BFS: Sözde KodBölüm 4.2 · Dijkstra: Java İzlemeBölüm 8 · Bellekleme İzleme

Kontrol sorusu

PriorityQueue'da add ve poll ne kadar sürer? contains(x) ve remove(x) ne kadar sürer?

add ve poll O(log n) sürer; contains(x) ve remove(x) iç diziyi baştan sona taradığı için O(n) sürer.

Örnek (Java) 
Deque<Integer> queue = new ArrayDeque<>();
queue.offer(1); queue.offer(2);
int first = queue.poll();                         // 1 (ilk giren ilk çıkar)

PriorityQueue<int[]> pq = new PriorityQueue<>((x, y) -> Integer.compare(x[1], y[1]));
pq.add(new int[] {7, 40});
pq.add(new int[] {3, 15});
int[] smallest = pq.poll();                       // [3, 15]

Map<Integer, Long> memo = new HashMap<>();
memo.put(10, 55L);
System.out.println(first + " " + smallest[0] + " " + memo.get(10));   // 1 3 55

Sözde kodu okuma ve izleme

← atama · 1'den başlayan indis · izleme tablosu

Sunumlar ve ders kitapları algoritmaları çoğu zaman sözde kodla (pseudocode) verir: ← atamadır, diziler 1'den başlayabilir ve “for j ← 2 to n” son değeri de kapsar. Java'ya çevirirken bu farkları gözetmek ve her değişkenin her adımdaki değerini bir izleme tablosuna yazabilmek gerekir.

Neden önemli

Çizge, akış ve dal sınır algoritmaları önce sözde kodla, sonra Java ile verilir.

Kullanıldığı yerlerBölüm 2 · Eklemeli: KodBölüm 4.2 · Dijkstra: Sözde KodBölüm 4.4 · Sözde Kod

Kontrol sorusu

Yukarıdaki sözde kod 0'dan başlayan indisli Java'ya çevrilince döngüler nasıl yazılır?

Dış döngü for (int j = 1; j < n; j++) olur, iç koşul da i >= 0 && A[i] > key biçimini alır.

Örnek 
INSERTION-SORT(A, n)
  for j ← 2 to n
      key ← A[j]
      i ← j − 1
      while i > 0 and A[i] > key
          A[i + 1] ← A[i]
          i ← i − 1
      A[i + 1] ← key

Kullanıldığı yerlerBölüm 2 · Sık Yapılan HatalarBölüm 3 · Uygulama Ayrıntıları

Kontrol sorusu

İkili aramada mid = (low + high) / 2 ne zaman yanlış sonuç verir?

low + high toplamı int aralığını aşınca toplam taşar ve negatif olur; low + (high − low) / 2 güvenlidir.

Örnek (Java) 
int[] empty = {}, one = {4}, equal = {2, 2, 2}, rev = {5, 4, 3, 2, 1};
for (int[] t : new int[][] {empty, one, equal, rev}) {
    int[] k = t.clone();
    Arrays.sort(k);
    for (int i = 1; i < k.length; i++)
        if (k[i - 1] > k[i]) throw new AssertionError("sıralı değil");
}
System.out.println("tüm testler geçti");

Bağlı listeler

düğüm · next · başa O(1) ekleme

Dizi gibi bir sırayı saklar, ancak öğeler bellekte bitişik değildir; her düğüm bir sonrakini gösterir. Başa ekleme O(1), i. öğeye erişim O(n) sürer. Komşuluk listeleri, hash tablolarındaki zincirleme ve LRU önbelleğinin O(1) gerçeklemesi bağlı listelere dayanır.

Neden önemli

Kullanıldığı yerlerBölüm 3 · Zincirleme ile EklemeBölüm 13 · LRU: O(1) Uygulama

Kontrol sorusu

Tek yönlü bağlı listede son öğeyi silmek neden O(n) sürer?

Sondan bir önceki düğümün next alanı null yapılmalıdır; o düğüme ulaşmak için baştan yürümek gerekir.

Örnek (Java) 
static class Node {
    int value; Node next;
    Node(int value, Node next) { this.value = value; this.next = next; }
}

Node head = null;
for (int x = 1; x <= 3; x++) head = new Node(x, head);    // 3 → 2 → 1
for (Node n = head; n != null; n = n.next) System.out.print(n.value + " ");

Yığınlar ve kuyruklar

LIFO · FIFO · push/pop · offer/poll

Yığın (stack) son giren ilk çıkar (LIFO), kuyruk (queue) ilk giren ilk çıkar (FIFO) ilkesiyle çalışır; ikisinde de temel işlemler O(1) sürer. DFS bir yığınla (ya da özyinelemenin çağrı yığınıyla), BFS bir kuyrukla çalışır; geri izleme seçimleri yığın sırasıyla geri alır.

Neden önemli

Yinelemeli DFS açık bir yığın kullanır; BFS ve Edmonds-Karp kuyruk kullanır.

Kullanıldığı yerlerBölüm 4.1 · Yığınla DFS İzlemeBölüm 4.1 · BFS: FikirBölüm 4.4 · BFS ile Artış Yolu (Java)

Kontrol sorusu

1, 2, 3 bu sırayla hem bir kuyruğa hem bir yığına ekleniyor. Her birinden ilk hangi öğe çıkar?

Kuyruktan ilk 1, yığından ilk 3 çıkar.

Örnek (Java) 
Deque<Character> stack = new ArrayDeque<>();
for (char c : "abc".toCharArray()) stack.push(c);
StringBuilder sb = new StringBuilder();
while (!stack.isEmpty()) sb.append(stack.pop());
System.out.println(sb);                     // cba

Heap ve öncelikli kuyruklar

tam ikili ağaç · dizi yerleşimi · O(log n)

Bir min-heap'te her düğüm çocuklarından küçüktür, bu yüzden en küçük öğe köktedir. Dizi olarak saklandığında i. düğümün çocukları 2i + 1 ve 2i + 2'de, ebeveyni (i − 1) / 2'dedir. Ekleme ve en küçüğü çıkarma O(log n) sürer; heap sort, Dijkstra, Prim, Huffman ve çevrimiçi ortanca bu yapıya dayanır.

Neden önemli

Heap sort, Dijkstra'nın karmaşıklığı, Huffman ağacının kurulması ve çevrimiçi ortanca heap'e dayanır.

Kullanıldığı yerlerBölüm 2 · Heap SortBölüm 4.2 · Dijkstra: KarmaşıklıkBölüm 7 · Huffman: AdımlarBölüm 13 · Çevrimiçi Ortanca

Kontrol sorusu

n öğeyi tek tek ekleyerek heap kurmak O(n log n) sürer. Aşağıdan yukarı heap kurma ne kadar sürer?

O(n); düğümlerin çoğu yapraklara yakın olduğu için toplam aşağı itme işi doğrusal kalır.

Örnek 
dizi:   [2, 5, 3, 9, 6, 4]

3'ün çocuğu:     4        (indis 5)

Hash tabloları

hash fonksiyonu · çakışma · ortalama O(1)

Hash tablosu bir anahtarı hash fonksiyonuyla (hash function) dizi indisine dönüştürür; ekleme ve arama ortalamada O(1) sürer. İki anahtar aynı hücreye düştüğünde çakışma (collision) zincirlemeyle ya da doğrusal yoklamayla çözülür; yük faktörü (load factor) arttıkça performans düşer. Bellekleme, “ziyaret edildi” kümeleri ve Rabin-Karp'ın hash karşılaştırması bu fikre dayanır.

Neden önemli

Hash ile arama, Rabin-Karp ve bellekleme hash tablosu kullanır.

Kullanıldığı yerlerBölüm 3 · Hash ile Arama: FikirBölüm 3 · Yük FaktörüBölüm 5 · Rabin-Karp

Kontrol sorusu

Hash tablosunda en kötü durumdaki arama süresi nedir ve ne zaman ortaya çıkar?

O(n); bütün anahtarlar aynı hücreye (aynı zincire) düştüğünde.

Örnek (Java) 
int m = 7;
int[] keys = {10, 17, 24};
for (int k : keys) System.out.print(k % m + " ");   // 3 3 3 → çakışma
Set<String> visited = new HashSet<>();
visited.add("A");
System.out.println(visited.contains("A"));          // true

Ağaçlar ve ikili arama ağaçları

kök · ebeveyn · çocuk · yaprak · yükseklik

n düğümlü bir ağacın n − 1 kenarı vardır ve herhangi iki düğüm arasında tam olarak bir yol bulunur. Kök, ebeveyn, çocuk, yaprak, derinlik ve yükseklik terimleri DFS/BFS ağaçlarında, MST'lerde, union-find yapısında, trie'lerde ve durum uzayı ağaçlarında aynen kullanılır. İkili arama ağacı küçük anahtarları sol alt ağaçta, büyük anahtarları sağ alt ağaçta tutar; ağaç dengeliyse arama O(log n) sürer.

Neden önemli

BFS ağacı, kapsayan ağaçlar, trie'ler ve durum uzayı ağaçları aynı terimlerle anlatılır.

Çizge gösterimleri

G = (V, E) · komşuluk listesi · komşuluk matrisi

Çizge düğümlerden ve kenarlardan oluşur; kenarlar yönlü ya da yönsüz, ağırlıklı ya da ağırlıksız olabilir. Komşuluk matrisi (adjacency matrix) V² bellek kullanır ve bir kenar sorgusunu O(1) sürede yanıtlar; komşuluk listesi (adjacency list) O(V + E) bellek kullanır ve seyrek çizgelerde dolaşmayı O(V + E) sürede yapar. Derece, yol, döngü, bağlantılılık ve iki parçalılık terimleri tanıdık olmalıdır.

Neden önemli

Bütün çizge bölümleri ve dal sınırdaki TSP örnekleri bir çizge gösterimini varsayar.

Kullanıldığı yerlerBölüm 4.1 · Çizgeyi Bellekte TutmakBölüm 4.1 · Çizge TürleriBölüm 4.2 · Çizge ve En Kısa Yol

Kontrol sorusu

10.000 düğümlü ve 30.000 kenarlı bir yol ağına hangi gösterim uygundur?

Komşuluk listesi: matris 10⁸ hücre ister, liste ise yönsüz bir çizge için yaklaşık V + 2E = 70.000 kayıt tutar.

Örnek (Java) 
int V = 4;
List<List<Integer>> adj = new ArrayList<>();
for (int i = 0; i < V; i++) adj.add(new ArrayList<>());
int[][] edges = {{0, 1}, {0, 2}, {2, 3}};
for (int[] e : edges) {                    // yönsüz: iki yön de eklenir
    adj.get(e[0]).add(e[1]);
    adj.get(e[1]).add(e[0]);
}
System.out.println(adj.get(0));            // [1, 2]

Kümeler, fonksiyonlar ve bağıntılar

∪ ∩ \ · |A| · f: A → B · bağıntı

Algoritmalar küme diliyle anlatılır: G = (V, E), ziyaret edilmiş düğümler kümesi, MST'deki (S, V − S) kesimi, sırt çantasında seçilen eşyaların alt kümesi. Birleşim, kesişim, fark, Kartezyen çarpım ve alt kümeler; bir fonksiyonun tanım ve değer kümesi; bağıntıların yansıma, simetri ve geçişme özellikleri bilinmelidir.

Neden önemli

Kesim özelliği, Floyd-Warshall'ın geçişli kapanışı ve dal sınırdaki olurlu çözümler kümelerle tanımlanır.

Kullanıldığı yerlerBölüm 4.3 · Kesim ve Döngü ÖzelliğiBölüm 4.2 · Floyd-Warshall AlgoritmasıBölüm 10 · Temel Kavramlar

Kontrol sorusu

n öğeli bir kümenin kaç alt kümesi vardır ve hangi kaba kuvvet yöntemi bu kadar maliyetlidir?

2ⁿ; alt küme toplamında ya da 0/1 sırt çantasında bütün seçimleri tek tek denemek.

Örnek 
A = {1, 2, 3},  B = {2, 3, 4}
A ∪ B = {1, 2, 3, 4}    A ∩ B = {2, 3}    A \ B = {1}
|A × B| = 3 · 3 = 9     A'nın alt küme sayısı: 2³ = 8

Kontrol sorusu

[[1, 2], [3, 4]] · [[0, 1], [1, 0]] çarpımı nedir?

Örnek (Java) 
static int[][] multiply(int[][] a, int[][] b) {
    int n = a.length;
    int[][] c = new int[n][n];
    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            for (int k = 0; k < n; k++)
                c[i][j] += a[i][k] * b[k][j];    // toplam n³ çarpma
    return c;
}

int[][] c = multiply(new int[][] {{1, 2}, {3, 4}}, new int[][] {{0, 1}, {1, 0}});
System.out.println(Arrays.deepToString(c));      // [[2, 1], [4, 3]]

Eş zamanlılığın temelleri

iş parçacığı · paylaşılan değişken · eşzamanlama

Paralel algoritmalar bölümü, işin birkaç iş parçacığına (thread) nasıl bölündüğünü ve sonuçların nasıl birleştirildiğini Java ile gösterir. İş parçacığının ne olduğunu, aynı değişkeni korumasız güncelleyen iki iş parçacığının yarış durumuna (race condition) yol açtığını ve programın sıralı kısmının hızlanmayı sınırladığını sezgisel olarak bilmek yeterlidir.

Neden önemli

Yarış durumu, fork/join ile paralel sıralama ve Amdahl yasası bu fikirlerin üzerine kurulur.

Kontrol sorusu

Bir programın %20'si sıralı kalıyorsa, sınırsız sayıda işlemciyle elde edilebilecek en büyük hızlanma nedir?

1 / 0,2 = 5 kat (Amdahl yasası).

Örnek (Java) 
final AtomicInteger counter = new AtomicInteger();
Runnable job = () -> { for (int i = 0; i < 100_000; i++) counter.incrementAndGet(); };
Thread t1 = new Thread(job), t2 = new Thread(job);
t1.start(); t2.start();
t1.join(); t2.join();
System.out.println(counter.get());   // her zaman 200000; korumasız int++ daha az verebilir
