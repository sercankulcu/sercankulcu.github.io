Warm-up: The Multi-Armed Bandit

The rules

Each arm pays 1 point with a hidden probability; pulling an arm shows only its own outcome, and the goal is to maximize total reward.

Think about it
  • Would you stick with Arm 1, which has the best average so far, or try Arm 3 again?
  • Out of a hundred pulls, how many would you spend on trying arms (exploration)?

Introduction

Why Learning and Adaptation?

Learning: improving a strategy from past experience. Adaptation: updating the strategy as opponents and the environment change.

  • Equilibria can be hard to compute: Nash equilibrium in two-player games is PPAD-complete (so is approximate equilibrium with many players), a class with no known fast algorithm for large games. How do players "find" an equilibrium?
  • They may not know the game: the payoff matrix is unknown; they only play and see the outcome.
  • The question: do simple, local update rules eventually lead to equilibrium, or at least to good performance?
Examples: chess and poker AIs learn through self-play; bidding algorithms in ad auctions adapt daily; navigation apps reroute with traffic.

Best Response and Fictitious Play

Best-Response Dynamics (Step by Step)

Starting profile (B, Z). Players take turns best-responding to the opponent's current action.

Row looks for a best response to Z: u1 = 1, 0, 3 → C. Profile (C, Z).

Column responds to C: u2 = 4, 0, 2 → X. Profile (C, X).

Row responds to X: u1 = 4, 2, 1 → A. Profile (A, X).

Column already picks X against A (3 > 2, 1), and Row does not leave A → the dynamics stop at the Nash equilibrium (A, X).

Starting from (C, Y) would lead to the equilibrium (B, Y): where you end up depends on where you start.

When Does Best-Response Dynamics Converge?

Matching Pennies: (H,H) → (H,T) → (T,T) → (T,H) → (H,H) … an endless cycle

Potential games: convergesEvery improving deviation increases a common potential function, which cannot increase forever in a finite game (Monderer–Shapley 1996; congestion games).
No pure equilibrium: cyclesIn Matching Pennies every step makes one player happy and the other unhappy.
Remedy: remember the pastRespond to the whole history, not just the last action → fictitious play.

Code Trace: Fictitious Play (Matching Pennies, 6 rounds)

Call fictitious(6). Counters are zero; with no history, both play H in round 1.

Next round: the mismatcher mostly played T → matcher T; the matcher mostly played H → mismatcher T.

Round 4: (T, T) is played and the matcher wins. Counters: matcher H/T = 3/1, mismatcher H/T = 1/3.

Next round: the mismatcher mostly played T → matcher T; the matcher mostly played H → mismatcher T.

Round 5: (T, T) is played and the matcher wins. Counters: matcher H/T = 3/2, mismatcher H/T = 1/4.

Next round: the mismatcher mostly played T → matcher T; the matcher mostly played H → mismatcher T.

Round 6: (T, T) is played and the matcher wins. Counters: matcher H/T = 3/3, mismatcher H/T = 1/5.

return nm = [3, 3], nx = [1, 5]. The actions cycle (HH → HT → TT → TH …); as the cycles lengthen, the frequencies approach ½ (0.50 and 0.17 after 6 rounds; 0.472 and 0.492 after 400).

def fictitious(T):
    nm, nx = [0, 0], [0, 0]   # H/T counters
    a, b = 0, 0               # round 1: both H
    for t in range(1, T + 1):
        nm[a] += 1            # matcher's history
        nx[b] += 1            # mismatcher's history
        # matcher: match the mismatcher's majority
        a = 0 if nx[0] >= nx[1] else 1
        # mismatcher: avoid the matcher's majority
        b = 1 if nm[0] > nm[1] else 0
    return nm, nx

Best Response and Fictitious Play

Fictitious Play: Frequencies Converge to Equilibrium

  • Actions change in ever-longer cycles, but the frequencies approach the mixed equilibrium (½, ½): 0.472 and 0.492 after 400 rounds.
  • Guaranteed convergence: two-player zero-sum games (Robinson 1951), 2×2 games, potential games. Shapley (1964): in a 3×3 game the frequencies cycle and never converge.

Regret and Hedge

External Regret: Why Does "Follow the Leader" Fail?

Regret = (the total you would have earned by always playing the best single action in hindsight) − (the total you actually earned). External regret RT = maxi Σt gt(i) − Σt gt(at) (using expected payoff for randomized choices): the gap to the best fixed action in hindsight. If RT/T → 0, the algorithm has no regret.

Regret and Hedge

Multiplicative Weights / Hedge

  1. Give each action a weight: wi = 1.
  2. Each round, play with probabilities pi = wi / Σj wj.
  3. Observe every action's payoff and update:
    wi ← wi · eη·gt(i)An action with payoff 1 has its weight multiplied by eη (exactly doubled if η = ln 2).
Theorem. With payoffs in [0, 1] and n actions, RT ≤ (ln n)/η + ηT (ln n is the natural log of n; ≈ 1.1 for n = 3). Choosing η = √(ln n / T) gives RT ≤ 2√(T ln n), so RT/T → 0.
Randomness is essentialFollow the leader is deterministic, so an adversary exploits it; Hedge plays mixed.
η: the learning rateA large η reacts fast but is sensitive to noise; a small η is slow but stable.
In gamesIf everyone plays a no-regret algorithm, the time average approaches a coarse correlated equilibrium, and minimax in zero-sum games.

import math
def hedge(G, eta):
    w = [1.0] * len(G[0])
    total = 0.0
    for g in G:                       # each round
        W = sum(w)
        p = [x / W for x in w]
        total += sum(pi * gi for pi, gi in zip(p, g))
        w = [x*math.exp(eta*gi) for x, gi in zip(w, g)]
    return total

Regret and Hedge

Hedge vs Itself: Matching Pennies

  • Both players use Hedge (η = 0.1). Initial weights: matcher (H, T) = (0.8, 0.2), so P(H) = 0.8; mismatcher (0.5, 0.5). A win pays 1, a loss 0; each round both players update simultaneously with the expected payoffs of their actions.
  • The probability in each round (the last iterate) never settles at equilibrium; it swings widely around it. The time average approaches the minimax strategy (½, ½) (0.498 after 600 rounds). This is the basis of the learning proof of the minimax theorem.

Regret and Hedge

Which Equilibrium Does No-Regret Learning Reach?

  • A mediator tells everyone what to play (like a traffic light).
  • Correlated equilibrium (CE): following your recommendation is best even after seeing it. With algorithms that minimize a stronger kind of regret (internal regret), the time average approaches the set of CE.
  • Coarse correlated equilibrium (CCE) is weaker: committing to "I'll always play this" before seeing the recommendation does not pay. If everyone plays no-regret, the time average approaches a CCE.
  • CE and CCE are easy to compute; mixed Nash equilibrium is PPAD-complete.
A traffic light at a crossing implements a correlated equilibrium of the game of Chicken: no one gains by ignoring the light. No-regret learning finds such equilibria without a central planner.

Multi-Armed Bandits

The Multi-Armed Bandit

  • A K-armed slot machine: arm i pays a random reward with (unknown) mean μi.
  • Each round one arm is pulled and only its reward is seen (unlike Hedge: partial feedback).
  • Regret: RT = T·μ* − Σt μat, where μ* is the best arm's mean.
The exploration–exploitation dilemma: exploration gathers information about new arms; exploitation uses the arm that looks best so far. Pure exploitation gets stuck on the wrong arm; pure exploration wastes reward.

UCB1, μ = (0.3, 0.5, 0.7), 40 rounds: a rarely tried arm has a wide interval, so it gets tried again.

Applications: ad and news recommendation, A/B testing, clinical trials, price experimentation.

def egreedy(mu, T, eps, rng):
    N, Q = [0] * len(mu), [0.0] * len(mu)
    for t in range(1, T + 1):
        if rng.random() < eps:           # explore
            a = rng.randrange(len(mu))
        else:                            # exploit
            a = Q.index(max(Q))
        r = 1 if rng.random() < mu[a] else 0
        N[a] += 1
        Q[a] += (r - Q[a]) / N[a]
    return N, Q

Multi-Armed Bandits

Code Trace: UCB1 (Upper Confidence Bound)

Call: ucb([0.3, 0.5, 0.7], 8, random.Random(3)). Estimates and counts start at zero. Score Q + √(2 ln t / N): t is the current round, N the arm's pull count. Rarely pulled arms get a large bonus.

t = 1: an untried arm has bonus ∞ → the first untried arm 0 is chosen (each arm once).

import math
def ucb(mu, T, rng):
    K = len(mu)
    N, Q = [0] * K, [0.0] * K
    for t in range(1, T + 1):
        b = [math.inf if n == 0 else
             math.sqrt(2*math.log(t)/n) for n in N]
        a = max(range(K), key=lambda i: Q[i] + b[i])
        r = 1 if rng.random() < mu[a] else 0
        N[a] += 1
        Q[a] += (r - Q[a]) / N[a]
    return N, Q

Reinforcement Learning

From Bandits to Reinforcement Learning

  • A bandit is a one-state problem. In reinforcement learning an action determines not only the reward but also the next state (where the agent is, e.g. the position on a board).
  • Q-learning (Watkins, 1989): updates the state–action value from an observed transition
Q(s, a) ← Q(s, a) + α [ r + γ · maxa′ Q(s′, a′) − Q(s, a) ]

α: the learning rate (how much to trust new information); γ: the discount factor for future reward.

Numerical exampleQ(s, a) = 2, r = 1, γ = 0.9, max Q(s′, ·) = 4, α = 0.5:Q ← 2 + 0.5·(1 + 3.6 − 2) = 3.3
With multiple agentsOther agents are learning too, so from each agent's view the rules of the game keep changing (the environment is non-stationary); single-agent convergence guarantees no longer hold. Self-play (AlphaZero) is one way out.

def q_learn(episodes, alpha, gamma):
    Q = [[0.0, 0.0] for s in range(4)]  # [left, right]
    for ep in episodes:
        for s, a, r, s2 in ep:
            best = 0 if s2 == 3 else max(Q[s2])
            target = r + gamma * best
            Q[s][a] += alpha * (target - Q[s][a])
    return Q

Reinforcement Learning

Beyond Q-Learning: Methods and Milestones

  • Thompson sampling (1933): keeps a distribution over each arm's possible mean (the posterior), draws a sample from it each round and pulls the arm with the largest sample.
  • Win-Stay, Lose-Shift (WSLS; Nowak–Sigmund, 1993): after a 3 or 5 repeat the move, after a 0 or 1 switch; in the Prisoner's Dilemma it recovers cooperation two rounds after a single error.
  • Others: EXP3 (Hedge that sees only the pulled arm's reward; its regret grows slower than T even if an adversary picks the rewards), SARSA and DQN (a neural network instead of a Q table), CFR (a regret-based method for poker).

Evolutionary Dynamics

Replicator Dynamics

  • In a large population, individuals are matched at random; each plays a single strategy and passes it on to its offspring. No rationality, just selection.
  • fi: the average payoff of strategy i (its fitness); f̄: the population's average payoff. Strategies that earn above average spread.
  • The discrete form is enough for this course: new share = old share × fi / f̄ (a baseline of 3 is added to every payoff to keep fitness positive).
  • Evolutionarily stable strategy (ESS): a small group of mutants cannot invade (Maynard Smith–Price, 1973).

Hawk–Dove: resource V = 4, cost of fighting C = 6. Two hawks fight: (V − C)/2 = −1; a hawk against a dove gets V = 4 and the dove 0; two doves share: V/2 = 2.

Repeated Games

The Repeated Prisoner's Dilemma

Points: temptation 5 > mutual cooperation 3 > mutual betrayal 1 > sucker 0. C: stay silent.

  • One-shot, or a known finite number of rounds (backward induction): betray every round.
  • If play continues with probability δ (the shadow of the future), grim trigger can sustain cooperation:

Comply: 3 every round ⇒ 3 + 3δ + … = 3/(1 − δ).

Deviate: 5 now, then 1 forever ⇒ 5 + δ/(1 − δ).

Comply ≥ deviate; times (1 − δ): 3 ≥ 5(1 − δ) + δ ⇔ δ ≥ (5 − 3)/(5 − 1) = 1/2.

δ = 0.9: comply 30, deviate 14 ⇒ cooperate. δ = 0.3: comply ≈ 4.29, deviate ≈ 5.43 ⇒ betray.

The punishment is credible: (D, D) is a stage-game equilibrium. Folk theorem: for large δ, any average payoffs above what betraying guarantees can be sustained.

Repeated Games

Grim Trigger: For Which δ Does Cooperation Last?

Comply: 3/(1 − δ)  ·  deviate: temptation + δ/(1 − δ)  ·  comply ≥ deviate ⇔ δ ≥ δ*  ·  δ* = (temptation − 3)/(temptation − 1)

The more the future is worth (the larger δ), the stronger the deterrent of the grim trigger; as temptation rises, so does the threshold δ* needed for cooperation.

PAY = {"CC": (3, 3), "CD": (0, 5),
       "DC": (5, 0), "DD": (1, 1)}
tft = lambda me, opp: opp[-1] if opp else "C"
stft = lambda me, opp: opp[-1] if opp else "D"
def match(s1, s2, T):
    h1, h2, p1, p2 = [], [], 0, 0
    for t in range(T):
        a, b = s1(h1, h2), s2(h2, h1)
        u, v = PAY[a + b]
        h1.append(a); h2.append(b)
        p1, p2 = p1 + u, p2 + v
    return p1, p2

Discussion: Learning, People and Ethics

Does learning always lead to the optimum?No. Some dynamics cycle (Matching Pennies, Shapley's example); the environment and opponents change; a wrong model leads to bad convergence. The reliable target is usually no regret.
Do people learn like algorithms?Similar: trial and error, learning from the past. Different: people act on risk perception, emotions and social norms; algorithms follow a defined reward.
Ethical risks of adaptive systemsData bias, recommendations that manipulate users (clickbait), privacy, algorithmic price coordination (tacit collusion among learning pricing bots).
