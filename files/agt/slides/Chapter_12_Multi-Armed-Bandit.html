    How to play

    Each arm is an action whose hidden probability of paying reward 1 is unknown. Click an arm to pull it; a pull returns 1 or 0. Learn which arm is best while keeping cumulative regret low. Every new experiment draws new hidden probabilities, so memorising an earlier winner does not help.

    • Reward is the number of successes, Rounds counts all pulls.
    • Each arm card shows its pulls and the observed average (the bar). With “Show true probabilities” the red tick marks the hidden value.
    • Regret = expected reward of always pulling the truly best arm − your reward.
    • “Algorithm: run 50 rounds” lets the selected algorithm continue the same experiment, as a benchmark.

    How this teaches game theory

    Bandit algorithms balance exploration of uncertain options against exploitation of the best-known option. This is the basic learning problem behind repeated games, recommendation systems and online advertising.

    Modes

    • Human vs Computer benchmark: you choose every arm; compare your reward and regret with algorithmic runs. Observe whether you explore enough before committing.
    • Human-assisted recommendation: the arm the selected algorithm would exploit is marked “Recommended”. You may follow or reject the advice — useful for discussing automation bias.
    • Computer learning: the algorithm plays an initial batch of 50 rounds; continue in batches of 50 to watch convergence.

    Levels

    • Level 1 — 3 arms: stationary; the best introduction to exploration versus exploitation.
    • Level 2 — 4 arms: stationary; the extra arm spreads exploration and makes premature commitment costlier.
    • Level 3 — Changing rewards: four arms; after round 40 the hidden probabilities change. Old observations become misleading — watch whether the learner resumes exploring.

    Algorithms

    • ε-greedy: with probability ε = 0.15 pull a random arm, otherwise the arm with the highest observed mean. Simple, keeps exploring forever, so it can notice a change, but wastes pulls on clearly weak arms.
    • UCB1: pull the arm with the highest score = mean + √(2 ln t / pulls). Rarely pulled arms get a large bonus, so exploration is purposeful. Strong in stationary settings, slow after sudden changes because old evidence stays in the averages.

    Recommended sequence

    1. Benchmark + Level 1 + ε-greedy: make at least 20 manual choices.
    2. Repeat with UCB1 and compare how evenly the arms are sampled.
    3. Level 2: see how an extra option raises the cost of exploration.
    4. Recommendation mode: reject some recommendations deliberately and evaluate the result.
    5. Computer learning + Level 3: compare both algorithms after the round-40 change.

    Interpretation note: one run is not enough to call one algorithm superior. Rewards are random, so compare several experiments by average reward, regret and adaptation speed.
