How to play

  1. Players take turns placing one stone on any empty hexagonal cell. Blue moves first.
  2. Blue tries to create one uninterrupted chain connecting the left edge to the right edge (the blue borders).
  3. Violet tries to connect the top edge to the bottom edge (the violet borders).
  4. Placed stones never move and are never captured, so every move permanently changes the geometry of the board.
  5. The first player whose stones form a connected path between the required edges wins immediately; the winning path is marked on the board.
  6. Undo takes back the last move (in computer mode, your move together with the computer's reply). Cells can also be chosen with Tab and Enter.

Computer levels

  • Easy plays randomly.
  • Medium takes or blocks a winning cell, otherwise often plays the cell that shortens its own path the most.
  • Hard always picks the cell that best improves the difference between the opponent's and its own shortest remaining path (the number of empty cells each side still needs).

Reading the board

Connections do not have to form a straight line. Neighboring hexes touch in six directions, so diagonal-looking links can still be part of one continuous path. A useful pattern is the bridge: two stones separated in a way that gives you two possible connection points. Because the opponent can usually block only one point at a time, bridges create resilient future paths.

Strategy tips

  • Build flexible connection networks instead of one fragile line.
  • Block the opponent when one move would create a decisive connection.
  • Central cells often support more possible routes than edge cells.
  • Do not judge a position only by stone count; connectivity and future path options matter more.

Game-theory connection

Hex is a deterministic, perfect-information, two-player zero-sum game. There are no chance events and no hidden cards: both players see the complete state. Because a finished Hex board cannot end in a draw, the strategy-stealing argument proves that the first player has a winning strategy, even though no one knows it for large boards.
