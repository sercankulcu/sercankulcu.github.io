    How to play

    1. Read the grand coalition’s value v(N) and each player’s stand-alone value.
    2. Click the player buttons in the Coalition explorer to see the value v(S) of any coalition S.
    3. Enter an allocation for each player (or start with Split equally) and press Evaluate.
    4. Use Show φ to reveal the exact answer and compare.

    The Shapley value divides a coalition’s total value according to each player’s average marginal contribution over all possible orders of joining. It formalizes contribution-based fairness in cooperative games.

    Model

    A coalition’s value is the sum of its members’ stand-alone values plus a pairwise synergy bonus for every pair of players inside it. A synergy bonus means two players together produce more value than separately. (General cooperative games can give any coalition an arbitrary value; this teaching model keeps it easy to follow.)

    Marginal contribution

    If a coalition is worth 18 before C joins and 27 after, C’s marginal contribution there is 9. The Shapley value is the average of these contributions over all n! orders of joining. In this pairwise model it equals the player’s stand-alone value plus half of every synergy the player takes part in.

    Why is the Shapley value considered fair?

    • Efficiency: all of v(N) is distributed.
    • Symmetry: players who contribute the same get the same share.
    • Dummy player: a player who adds no value gets nothing extra.
    • Additivity: the allocation for the sum of two games is the sum of the allocations.

    Scenarios, modes and levels

    • Scenarios (startup teams, logistics firms pooling their routes, institutions sharing data) give the same mathematics different stories: value often comes from combinations rather than from ownership alone.
    • Guess the allocation: propose a split without seeing the answer.
    • Guess + hint: the table also shows each player’s average pairwise synergy.
    • Computer calculates: the exact Shapley allocation is shown automatically.
    • Levels use 3, 4 or 5 players; the number of coalitions (2n) and orders (n!) grows quickly, which motivates approximation methods.

    Reading the results

    Allocation error is the sum of absolute differences between your allocation and φ. Efficiency compares the total you distributed with v(N); 100% alone does not show the split is fair. Equal-split error shows how far an equal split is from φ.

    Questions to explore

    • Does the player with the largest stand-alone value always get the largest Shapley value?
    • When does an equal split coincide with the Shapley allocation?
    • Why does exact computation get harder as the number of players grows?
