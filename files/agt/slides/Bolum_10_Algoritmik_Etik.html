Algoritmik Kararlar Neden Önemli?

  • Algoritmalar artık yüksek etkili kararlar veriyor ya da önerisiyle yönlendiriyor: kredi onayı, işe alım, sağlık teşhisi, sosyal medya önerileri, ceza adaleti.
  • Adalet ve etik ihlalleri bireylere zarar verir ve kurumlara, teknolojiye duyulan toplumsal güveni aşındırır.
  • Oyun kuramı bağlantısı: karar kuralı bir mekanizmadır; farklı paydaşların (başvuran, kurum, toplum) çıkarları çatışır.

İki karışıklık matrisi hazır. Doğruluk (accuracy) iki grupta da %80 ((40+40)/100 ve (16+64)/100). Model "adil" mi? Ölçütlere göre tek tek bakalım.

Adalet Ölçütleri

Demografik Eşitlik Adım Adım

Demografik eşitlik (demographic parity): P(Ŷ=1 | A) = P(Ŷ=1 | B) olmalı. Onaylananlar: A'da 40 + 10 = 50, B'de 16 + 4 = 20.

Seçim oranları: A = 50/100 = 0,50, B = 20/100 = 0,20. Fark 0,30 ⇒ demografik eşitlik sağlanmıyor.

Oran: 0,20 / 0,50 = 0,40 < 0,8. ABD istihdam hukukundaki "beşte dört kuralı" (disparate impact) da ihlal edilir.

Ama gruplar farklı: gerçekten ödeyenler A'da 50, B'de 32. Demografik eşitliği zorlamak ya B'de ödemeyecek kişileri onaylamak ya da A'da ödeyecekleri reddetmek demektir.

Adalet Ölçütleri

Eşitlenmiş Olasılıklar Adım Adım

Eşitlenmiş olasılıklar (equalized odds; Hardt vd., 2016): gerçek sonuç koşulu altında hata oranları eşit olmalı: TPRA = TPRB ve FPRA = FPRB.

TPR (ödeyecek olanlar arasında onay): A = 40/(40+10) = 0,80, B = 16/(16+16) = 0,50. B'nin kredi değerli başvuranlarının yarısı reddediliyor!

FPR (ödemeyecekler arasında onay): A = 10/(10+40) = 0,20, B = 4/(4+64) = 0,059.

TPR farkı 0,30, FPR farkı 0,141 ⇒ eşitlenmiş olasılıklar sağlanmıyor. Yalnız TPR eşitliği istenirse adı fırsat eşitliğidir (equal opportunity).

Adalet Ölçütleri

Tahmin Eşitliği Adım Adım

Tahmin eşitliği (predictive parity): onay alanların gerçekten ödeme oranı (PPV) gruplar arasında eşit olmalı. Bakış açısı: kararı kullanan kurum.

PPV: A = 40/(40+10) = 0,80, B = 16/(16+4) = 0,80 ⇒ tahmin eşitliği sağlanıyor.

Ret tarafında da (NPV = TN/(TN+FN)): A = 40/50 = 0,80, B = 64/80 = 0,80. "Onay" ve "ret" etiketleri iki grupta aynı anlamı taşıyor.

Adalet Ölçütleri

Kod İzleme: olcutler(TP, FP, FN, TN)

A grubunun matrisiyle fonksiyon çağrılır.

n = 40 + 10 + 10 + 40 = 100 başvuran.

Seçim oranı = (40 + 10) / 100 = 0,5 (demografik eşitlikte karşılaştırılır).

TPR = 40 / (40 + 10) = 0,8.

FPR = 10 / (10 + 40) = 0,2.

PPV = 40 / (40 + 10) = 0,8.

Dört oran bir Python demeti (tuple) olarak döner ve A'ya atanır.

B için aynı hesap: seçim 20/100, TPR 16/32, FPR 4/68 ≈ 0,059, PPV 16/20.

B = (0.2, 0.5, 0.0588…, 0.8).

Demografik eşitlik yok: 0,5 ≠ 0,2.

TPR farklı ⇒ fırsat eşitliği yok.

FPR de farklı ⇒ eşitlenmiş olasılıklar yok.

PPV eşit ⇒ tahmin eşitliği var.

def olcutler(TP, FP, FN, TN):
  n = TP + FP + FN + TN
  secim = (TP + FP) / n   # demografik eşitlik
  tpr = TP / (TP + FN)    # eşitlenmiş olasılıklar
  fpr = FP / (FP + TN)
  ppv = TP / (TP + FP)    # tahmin eşitliği
  return secim, tpr, fpr, ppv

A = olcutler(40, 10, 10, 40)
B = olcutler(16, 4, 16, 64)
ADLAR = ["seçim", "TPR", "FPR", "PPV"]
for i, ad in enumerate(ADLAR):
  print(ad, round(A[i], 3), round(B[i], 3))

Adalet Ölçütleri

Grup Adaletinin Ötesi: Bireysel Adalet

Ece ile Nur arasındaki uzaklık d = 0,05; L·d = 0,1

  • Dwork vd. (2012): "benzer kişilere benzer davranılmalı": |f(x) − f(y)| ≤ L · d(x, y) (Lipschitz koşulu).
  • Kırmızı basamak model eşiğin iki yanındaki Ece ve Nur'a 0,2 ve 0,8 verir: |Δf| = 0,6 > 0,1 ⇒ ihlal. Yeşil model koşulu sağlar.
  • Grup ölçütleri ortalamaları eşitler: B'den rastgele kişileri onaylamak demografik eşitliği sağlar ama bireysel olarak keyfîdir.
Zorluk: uzaklık ölçüsü d'yi kim belirler? "Kimler benzer?" sorusu da bir değer yargısıdır; bireysel adalet sorunu ortadan kaldırmaz, onu d'nin seçimine taşır.

Ölçütlerin Uyumsuzluğu

Ölçütler Neden Birlikte Sağlanamaz?

p = taban oranı, n kişi ⇒ TP = p·n·TPR, FP = (1 − p)·n·FPR
PPV = TP / (TP + FP) = p·TPR / (p·TPR + (1 − p)·FPR)
Düzenle: FPR = p / (1 − p) · (1 − PPV) / PPV · TPR
A: p = 0,5 ⇒ 0,5/0,5 · 0,2/0,8 · 0,8 = 1 · 0,25 · 0,8 = 0,20 ✓
B: p = 0,32 ⇒ 0,32/0,68 · 0,25 · 0,5 = 0,059 ✓
PPV eşit (0,8) ama p farklı ⇒ p/(1 − p) çarpanı farklı ⇒ TPR ve FPR ikisi birden eşit olamaz.

Chouldechova (2017): ölçütler aynı dört sayıdan türetildiği için birbirine bağlıdır. Taban oranı p ile başlayalım.

PPV = TP / (TP + FP) = p·TPR / (p·TPR + (1 − p)·FPR)
Düzenle: FPR = p / (1 − p) · (1 − PPV) / PPV · TPR
A: p = 0,5 ⇒ 0,5/0,5 · 0,2/0,8 · 0,8 = 1 · 0,25 · 0,8 = 0,20 ✓
B: p = 0,32 ⇒ 0,32/0,68 · 0,25 · 0,5 = 0,059 ✓
PPV eşit (0,8) ama p farklı ⇒ p/(1 − p) çarpanı farklı ⇒ TPR ve FPR ikisi birden eşit olamaz.

Ödemeyenlerde de denge yok. Kalibrasyon sağlandığı hâlde denge bozuk.

Kod İzleme: Rastgeleleştirme ile Fırsat Eşitliği

q = 0: yalnız 0,8 puanlılar onaylanır (bugünkü model). TP = 16, FP = 4.

TPR = 16/32 = 0,5; FPR = 4/68 ≈ 0,06; doğruluk (16 + 64)/100 = 0,80.

q = 0,2: 0,2 puanlı 80 kişinin %20'si onaylanır. TP = 16 + 16·q = 19,2, FP = 4 + 64·q = 16,8.

TPR 0,6'ya çıktı ama doğruluk 0,704'e düştü: yeni onaylanan her 5 kişiden 4'ü ödemeyecek olanlardan.

q = 0,4: 0,2 puanlı 80 kişinin %40'ı onaylanır. TP = 16 + 16·q = 22,4, FP = 4 + 64·q = 29,6.

TPR 0,7; FPR 0,44'e fırladı, doğruluk 0,608.

q = 0,6: 0,2 puanlı 80 kişinin %60'ı onaylanır. TP = 16 + 16·q = 25,6, FP = 4 + 64·q = 42,4.

TPR_B = 0,8 = TPR_A: fırsat eşitliği sağlandı. Bedeli: doğruluk 0,512, FPR 0,62.

Fırsat eşitliği için 0,2 puanlıların %60'ı rastgele onaylandı: ödemeyecek 64 kişiden ≈ 38'i kredi alır. FPR, A'dakinin (0,2) üç katı: eşitlenmiş olasılıklar yine yok.

def b_grubu(q):   # 0,2 puanlıyı q ile onayla
  TP = 16 + 16 * q
  FP = 4 + 64 * q
  tpr = TP / 32
  fpr = FP / 68
  dogru = TP + (68 - FP)   # TP + TN
  return tpr, fpr, round(dogru / 100, 3)

for q in [0, 0.2, 0.4, 0.6]:
  tpr, fpr, d = b_grubu(q)
  print(q, round(tpr, 2), round(fpr, 2), d)

Adil Bölüşüm: Pasta Kesme (Cake Cutting)

  • Bölünebilir bir kaynak (pasta = [0, 1] aralığı: zaman, arazi, işlem süresi) n kişi arasında paylaştırılacak.
  • Her kişinin kendi değer fonksiyonu vᵢ var: toplam pasta 1 değerinde, ama kişiler farklı kısımlara farklı değer verir.
  • Algoritma kişilere yalnızca soru sorar (Robertson–Webb modeli): "şu parçaya ne değer verirsin?" ve "değeri α olan parça nerede biter?".
Orantılılık (proportionality)Herkes kendi gözünde en az 1/n alır: vᵢ(Xᵢ) ≥ 1/n.
Kıskançsızlık (envy-freeness)Kimse başkasının parçasını kendininkine tercih etmez: vᵢ(Xᵢ) ≥ vᵢ(Xⱼ).
Oyun kuramı bakışı: kişiler stratejik olabilir. İyi bir protokol, dürüst davranan herkese garanti verir; başkaları ne yaparsa yapsın.

Adil Bölüşüm

Kes-ve-Seç (Cut and Choose) Adım Adım

Ali pastanın her yerine eşit değer verir. Ayşe çikolatayı vanilyadan 3 kat daha çok sever: vAyşe(vanilya) = 1/4, vAyşe(çikolata) = 3/4.

1. Ali keser: kendi gözünde iki eşit parça yapar ⇒ x = 1/2, her parça Ali için 1/2.

2. Ayşe değerlendirir: sol parça 1/4, sağ parça 3/4.

3. Ayşe seçer: değeri büyük olan sağ parçayı (çikolata) alır.

Sonuç: Ali 1/2 ≥ 1/2, Ayşe 3/4 ≥ 1/2 ⇒ orantılı; Ali 1/2 = 1/2, Ayşe 3/4 > 1/4 ⇒ kıskançsız.

Roller değişirse: Ayşe x = 2/3'ten keser (kendi gözünde 1/2 – 1/2). Ali sol parçayı seçer ve 2/3 alır; Ayşe 1/2. Seçen, kesenden avantajlıdır.

Kod İzleme: Kesim Sorgusu İkiye Bölme ile

Robertson–Webb kesim sorgusu: "[0, x] parçası senin için 1/2 olsun, x nerede?" Ayşe'nin değer fonksiyonu artan olduğundan ikiye bölme (bisection) ile bulunur.

1. sorgu: orta = 0,5: vanilyanın tamamı Ayşe için 1/4 = 0,25 < 0,5 ⇒ lo = 0,5. Aralık yarıya iner (genişlik 1/2).

2. sorgu: v(0,75) = 0,625 ≥ 0,5 ⇒ kesim solda ya da burada: hi = orta. Aralık yarıya iner (genişlik 1/4).

3. sorgu: v(0,625) = 0,4375 < 0,5 ⇒ kesim daha sağda: lo = orta. Aralık yarıya iner (genişlik 1/8).

4. sorgu: v(0,6875) = 0,5312 ≥ 0,5 ⇒ kesim solda ya da burada: hi = orta. Aralık yarıya iner (genişlik 1/16).

5. sorgu: v(0,6562) = 0,4844 < 0,5 ⇒ kesim daha sağda: lo = orta. Aralık yarıya iner (genişlik 1/32).

6. sorgu: v(0,6719) = 0,5078 ≥ 0,5 ⇒ kesim solda ya da burada: hi = orta. Aralık yarıya iner (genişlik 1/64).

7. sorgu: v(0,6641) = 0,4961 < 0,5 ⇒ kesim daha sağda: lo = orta. Aralık yarıya iner (genişlik 1/128).

8. sorgu: v(0,668) = 0,502 ≥ 0,5 ⇒ kesim solda ya da burada: hi = orta. Aralık yarıya iner (genişlik 1/256).

8 sorgudan sonra aralık 1/256 genişlikte; orta nokta 0,666. Gerçek kesim 2/3: Ayşe kesen olsaydı buradan keserdi (önceki slaytın son adımı).

def v_ayse(x):          # [0, x] parçasının değeri
  if x <= 0.5: return x / 2
  return 0.25 + 1.5 * (x - 0.5)
def kes_noktasi(v, hedef, adim):
  lo, hi = 0.0, 1.0
  for _ in range(adim):
    orta = (lo + hi) / 2
    if v(orta) < hedef: lo = orta
    else: hi = orta
  return (lo + hi) / 2
print(round(kes_noktasi(v_ayse, 0.5, 8), 3))

Kes-ve-Seç Neden Adil?

  • Kesen hangi parçanın kalacağını bilmez; garantisi iki parçanın küçüğüdür. Bu garanti tam kendi gözündeki yarıda en büyüktür (1/2): dürüst kesmek maksimin stratejisidir.
  • Seçen kendi gözünde büyük parçayı alır: değeri ≥ 1/2 ve ötekinden az değil, kesim nasıl olursa olsun.
  • Kesen, seçenin tercihini bilirse kesimi ona göre kaydırıp 1/2'den fazlasını alabilir; ama garantisi 1/2'dir.
İki kişide orantılılık ⇔ kıskançsızlık: v(X₁) ≥ 1/2 ise v(X₂) = 1 − v(X₁) ≤ 1/2 ≤ v(X₁). Üç ve daha fazla kişide kıskançsızlık daha güçlüdür (sonraki slaytlar).

TeşviklerAlgoritmaya tepki veren insanlar: Goodhart yasası, stratejik sınıflandırma.

Özet

Etkileşimli Oyunlar

Bu bölümle ilişkili etkileşimli sayfalar:

Adil Bölüşüm OyunuKes-ve-seç ve paylaşım protokollerini deneyin: kesen olarak mı, seçen olarak mı daha iyisiniz? Orantılılık ve kıskançsızlığı kontrol edin.
Tavla (Backgammon)Şans ve beceri bir arada: kurallar herkes için aynıdır (usul adaleti), sonuç zara bağlıdır. İkiye katlama küpü beklenen değere dayalı bir teşvik aracıdır.

Özet

Örnek Problemler

  1. Grup C: TP = 30, FP = 20, FN = 10, TN = 40. Seçim oranı, TPR, FPR ve PPV?
  2. 1. sorudaki C grubu ile bu bölümdeki A grubu arasında hangi ölçütler sağlanır?
  3. p = 0,2, PPV = 0,5, TPR = 0,6 ise FPR kaçtır?
  4. Kes-ve-seçte Ali kesiyor ve Ayşe'nin çikolatayı 3 kat sevdiğini biliyor. Ali nereden keser, kendi gözünde ne kazanır?
  5. İki kişilik paylaşımda orantılılığın kıskançsızlığı gerektirdiğini gösterin.
  6. Sırayla seçimde Ayşe başlasaydı (aynı değerlerle) kim neyi alırdı? Paylaşım kıskançsız mı?
Cevapları göster
  1. n = 100; seçim 0,5; TPR 30/40 = 0,75; FPR 20/60 ≈ 0,333; PPV 30/50 = 0,6.
  2. Yalnız demografik eşitlik (0,5 = 0,5). TPR, FPR, PPV farklı.
  3. FPR = 0,2/0,8 · 0,5/0,5 · 0,6 = 0,15.
  4. Ayşe sağ parçayı, sol parçanın onun için değeri ≤ 1/2 olduğu sürece seçer: 1/4 + 1,5(x − 1/2) ≤ 1/2 ⇒ x ≤ 2/3. Ali x = 2/3'ten keser ve 2/3 alır (> 1/2): bilgi kesene avantaj sağlar.
  5. v(X₁) ≥ 1/2 ⇒ v(X₂) = 1 − v(X₁) ≤ 1/2 ≤ v(X₁).
  6. Ayşe m1, Ali m2, Ayşe m3 (1; m4 ile eşit), Ali m4. Ali: 6 vs 10 ⇒ kıskanır, ama m1 çıkarılınca 3 ≤ 6: EF1.

Özet

Alıştırmalar: Yeni Konular

  1. b_grubu izlemesinde A'nın TPR'si 0,7 olsaydı B'de fırsat eşitliği için q kaç olmalıydı? B'nin doğruluğu ne olurdu?
  2. kes_noktasi(v_ayse, 0.5, 3) çalışınca döngü sonunda [lo, hi] nedir? Hatanın 0,001'in altına inmesi için kaç sorgu gerekir?
  3. Son azalan örneğinde Cem'in değerleri Ayşe'ninki gibi (0,1; 0,2; 0,3; 0,4) olsaydı ilk parçayı kim alırdı?
  4. L = 2 ve d(x, y) = 0,1 iken f(x) = 0,8 ise bireysel adalet f(y) için hangi aralığı izin verir?
  5. Geri besleme kodunu kayit = [5, 6] ile çalıştırın. 4 gün sonra bölge 0'ın payı kaçtır?
Cevapları göster
  1. TPR_B = 0,5 + 0,5·q = 0,7 ⇒ q = 0,4; doğruluk (80 − 48·q)/100 = 0,608.
  2. 0,5 → 0,25 < 0,5 (lo = 0,5); 0,75 → 0,625 (hi = 0,75); 0,625 → 0,4375 (lo = 0,625) ⇒ [0,625; 0,75]. Orta nokta hatası ≤ 2−(k+1) ⇒ k = 9.
  3. Cem için [0, 1/3] parçası 1/6 < 1/3: kimse kırpmaz, parçayı son kesen Ali alır.
  4. |f(y) − 0,8| ≤ 0,2 ⇒ f(y) ∈ [0,6; 1] (puan 1'i aşamaz).
  5. Devriye hep bölge 1'e gider: kayit = [5, 18], pay = 5/23 ≈ 0,22. Başlangıçtaki tek kayıtlık fark yine büyür.
