Click a node, then another node, to add or remove the link between them.

    How to play

    Click one node and then another to add or remove the link between them. Watch each player's utility, the social welfare (sum of utilities) and whether the network is pairwise stable. Run best-response formation lets players repeatedly cut unprofitable links and jointly add mutually profitable ones until nothing changes. Path and Empty restart from a path or from no links.

    Network formation games make the network itself strategic: players create or remove links when the private benefit exceeds the private cost.

    Utilities

    Each player gains a benefit from every player it can reach, depending on the distance (1, 2, or 3+ hops), and pays the link cost for every link it is part of (both endpoints pay).

    Link cost is 2 per endpoint at Levels 1–2 and 3.2 at Level 3 (5 nodes). Level 1 uses 4 nodes.

    Pairwise stability

    A network is pairwise stable when no existing link is worth deleting for either endpoint, and no absent link would strictly benefit both endpoints. Best possible is the maximum social welfare over all networks on these nodes (found by checking every graph).

    Modes

    • Human Builds Network: add or remove links freely.
    • Human + Stability Advisor: the panel names a link that some endpoint wants to cut, or a missing link both endpoints want to add.
    • Computer Formation: best-response formation runs automatically after every reset.

    What this shows

    Individually stable networks need not maximise social welfare: a link creates benefits (shorter paths) for third parties that its two owners ignore, and expensive links lead to sparse networks such as stars or even disconnected ones.
