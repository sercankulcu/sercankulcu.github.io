    How to play

    1. Read the grand-coalition value v(N) and each player's stand-alone value.
    2. Click player chips in the coalition explorer to see the value v(S) of any coalition S.
    3. Type an allocation for every player (or start from Fill equal split) and press Evaluate allocation.
    4. Press Show Shapley value to reveal the exact answer and compare.

    The Shapley value distributes a coalition's total value according to each player's average marginal contribution across every possible joining order. It formalises contribution-based fairness in cooperative games.

    The model

    A coalition's value is the sum of its members' stand-alone values plus a pairwise synergy bonus for every pair inside it. A synergy bonus means two players create more together than separately. (General cooperative games can assign an arbitrary value to every coalition; this teaching model keeps it understandable.)

    Marginal contribution

    If a coalition is worth 18 before C joins and 27 after, C's marginal contribution there is 9. The Shapley value averages these contributions over all n! joining orders. In this pairwise model it equals the stand-alone value plus half of every synergy the player takes part in.

    Why the Shapley value is considered fair

    • Efficiency: the whole of v(N) is distributed.
    • Symmetry: players who contribute identically receive the same.
    • Dummy player: a player who never adds value receives nothing extra.
    • Additivity: the allocation of a sum of games is the sum of the allocations.

    Scenarios, modes and levels

    • Scenarios (startup teams, logistics firms pooling routes, organisations sharing data) give the same mathematics different stories: value often comes from combinations rather than from isolated ownership.
    • Human guesses allocation: propose a division before seeing the answer.
    • Human + marginal hints: the table also shows each player's average pair synergy.
    • Computer calculates: the exact Shapley allocation is shown automatically.
    • Levels use 3, 4 or 5 players; the number of coalitions (2n) and orders (n!) grows quickly, which motivates approximation methods.

    Reading the results

    Allocation error is the sum of absolute differences between your allocation and φ. Efficiency compares the total you allocated with v(N); 100% does not by itself mean the division is fair. Equal-split error shows how far an equal division is from φ.

    Questions to explore

    • Does the player with the largest stand-alone value always receive the largest Shapley value?
    • When does equal division happen to match the Shapley allocation?
    • Why does exact computation become difficult as the number of players grows?
