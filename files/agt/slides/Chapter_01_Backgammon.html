How to play

  • Choose AI vs AI to watch two computer players, or Human vs AI to play. In Human vs AI you are White (you move from point 1 towards 24, and your home board is at the top right); the computer is Black.
  • When it is your turn to roll, click the board. Then click a checker to move it by the die shown as Next move in the side panel. Checkers with a legal move are marked with a yellow ring.
  • If both dice can be played from the same point, click the dice to swap their order.
  • Standard rules: hitting an opponent's lone checker (a blot) sends it to the bar; checkers on the bar must re-enter first; once all checkers are in the home board you may bear off. Both dice must be used if possible (all four on doubles); if only one can be used, the larger one must be played.
  • The side panel shows the dice left to play, the pip count (the total distance still to travel) and the checkers borne off.

The small numbers on the board are point numbers: Black moves 24 → 1, White moves 1 → 24. The arrow shows the AI's last move.

A decision in three steps

  1. List the legal moves. For the dice rolled, every playable (checker, die) pair is generated. The rules are checked here too: use both dice if possible, and if only one can be played, play the larger (legalValids).
  2. Score each move. Every candidate is scored without looking ahead, only by the position right after the move (evaluateMoveQuality).
  3. Pick the highest score. The scores are compared and the best move is played (getSmartMove). A small random number breaks near-ties.

The AI plays each die separately: it chooses a move for one die, applies it, then repeats the three steps for the remaining die. This is greedy choice: at each step it takes what looks best right now.

How the score is computed

The score of a move is a weighted sum of the features the move has:

score = Σ (feature present? 1 : 0) × weight  +  small noise

For example, in the Balanced style a move that hits an opponent blot but leaves a single checker behind scores HIT_OPPONENT (+1200) + LEAVE_BLOT (−400) = +800. A move that takes a checker alone to an empty point gets the LEAVE_BLOT / 1.5 (−267) penalty. This is a utility function: as in the decision theory of Chapter 1, the decision maker picks the option with the highest utility.

Tick Show move reasoning and, each time the AI plays a die, the candidate moves and the parts of this sum are shown under the board.

How the three AI styles work

The AI does not use minimax. It computes a heuristic score for every legal move and picks the highest-scoring one. The chosen style only changes these heuristic weights, so you can see how the same legal-move generator produces different behaviour when the evaluation function changes.

Aggressive

Strongly prefers hitting exposed opponent checkers and accepts more blot risk. It uses a larger random tie-breaker, so its play is less predictable.

Balanced

Very close to the original AI. It balances hitting, making points, protecting blots and bearing off without clearly favouring attack or safety.

Defensive

Strongly rewards making safe points and protecting exposed checkers. It heavily penalizes leaving blots and shows little interest in hitting unless the tactical gain is clear.

Important

Changing the selector does not affect a game in progress. Press Restart with style to start a new game with the new parameter set. In AI vs AI mode both sides use the selected profile. Mode menu stops the current game and shows the mode choice again.

Why not minimax?

In chess or tic-tac-toe the AI searches a few moves ahead with minimax. In backgammon the dice are rolled after every move, so chance nodes appear between the players' nodes in the game tree. The method that solves such a tree is expectiminimax: the value of a chance node is the probability-weighted average over the 21 distinct dice outcomes.

  • A roll has about 20 legal moves on average; with 21 dice outcomes, one full round (our move + the opponent's roll and move) branches into roughly 20 × 21 × 20 ≈ 8,400 positions. Two rounds ahead reach the millions.
  • So this game plays at depth 0: it evaluates only the position after the move. Its strength comes from the quality of the evaluation function, not from search.
  • Truly strong backgammon programs (TD-Gammon, 1992) learn this function by playing against themselves instead of using hand-set weights; this is the topic of Chapter 13.

1. Pick the best move: getSmartMove

An argmax: it goes through every candidate move and keeps the highest-scoring one.

function getSmartMove(valids) {
  // valids: the playable dice for each checker position
  let bestMove = null;
  let bestScore = -Infinity;
  const W = weights();                         // weights of the chosen style
  for (const start in valids) {
    for (const die of valids[start]) {
      const score = evaluateMoveQuality(start, die)
                  + Math.random() * W.RANDOMNESS;   // tie-breaker
      if (score > bestScore) {                 // best so far?
        bestScore = score;
        bestMove = { start: start, die: die };
      }
    }
  }
  return bestMove;                             // highest-scoring move
}

2. Score a move: evaluateMoveQuality

Each if is a feature; when the feature is present, its weight is added to the score. The weights come from the style.

function evaluateMoveQuality(start, die) {
  const W = weights();
  const me = Board.onMove === 'black' ? 0 : 1;      // 0 = Black, 1 = White
  const opp = 1 - me;
  const fromBar = start.startsWith('bar');
  const startPt = fromBar ? (me === 0 ? 25 : 0) : Number(start.slice(1));
  const targetPt = me === 0 ? startPt - die : startPt + die;

  // leaving the board: bearing off
  if ((me === 0 && targetPt <= 0) || (me === 1 && targetPt >= 25))
    return W.BEAR_OFF;

  const dest = Board['p' + targetPt];   // [number of checkers, owner]
  const src  = Board[start];
  let score = 0;
  if (dest[1] === opp && dest[0] === 1) score += W.HIT_OPPONENT; // hit a blot
  if (dest[1] === me  && dest[0] === 1) score += W.MAKE_POINT;   // make a point
  if (!fromBar && src[0] === 2)         score += W.LEAVE_BLOT;   // leaves one behind
  if (dest[0] === 0)                    score += W.LEAVE_BLOT / 1.5; // alone on empty
  if (dest[1] === me && dest[0] >= 3)
    score += W.STACKING_PENALTY * (dest[0] - 2);                  // stacking penalty
  if (!fromBar && src[0] === 1)         score += W.COVER_BLOT;   // lift a blot
  if (isHomeBoardTarget(me, targetPt))  score += W.HOME_BOARD;   // enter home board
  return score;
}

4. Rule check: legalValids

To find which dice must be played, every step is tried and undone (the recursive maxDepth). This is a search, but only for the rules; it does not search for how good a move is.

// Rule: use as many dice as possible; if only one can be played, the larger.
function legalValids() {
  const vm = new ValidMoves();            // single steps that obey the rules
  let best = 0;
  const scored = [];
  for (const start in vm)
    for (const die of vm[start]) {
      const saved = snapshot();
      applyStep(start, die);              // try this step
      const d = 1 + maxDepth();           // how many more dice can be played?
      restore(saved);                     // undo
      scored.push({ start, die, d });
      best = Math.max(best, d);
    }
  // only the steps that use the most dice remain
  ...
}

The same idea in Python

The same pattern as the course's Python examples: a utility function and max.

def evaluate(move, W):
    score = 0
    if move.bears_off:     return W['BEAR_OFF']
    if move.hits:          score += W['HIT_OPPONENT']
    if move.makes_point:   score += W['MAKE_POINT']
    if move.leaves_blot:   score += W['LEAVE_BLOT']
    if move.lands_alone:   score += W['LEAVE_BLOT'] / 1.5
    if move.stack > 2:     score += W['STACKING_PENALTY'] * (move.stack - 2)
    if move.lifts_blot:    score += W['COVER_BLOT']
    if move.to_home:       score += W['HOME_BOARD']
    return score

best = max(legal_moves, key=lambda m: evaluate(m, W) + random() * W['RANDOMNESS'])

Using it in class

  1. Predict, then look. In AI – AI mode tick Show move reasoning. At each roll ask the class “which checker would you play?”, then show the move the AI chose and its score in the panel.
  2. Compute a score together. Take a row from the panel (e.g. hit +1200 · leave blot behind −400) and check the total against the table. Which term decided the move?
  3. Compare the styles. Play the same opening with the Aggressive and the Defensive style. In which positions do they choose different moves? Which weight difference in the table explains it?
  4. Discuss the weights. Why is BEAR_OFF the largest weight? How would the AI play if LEAVE_BLOT were very small?

Discussion questions

  • Is this AI a rational decision maker? What is its utility, and where are its beliefs (probabilities)?
  • The evaluation ignores the opponent's next roll. How could the probability that a blot is hit (e.g. 11/36) be added to the score? That is an expected-value calculation.
  • Why is there noise (RANDOMNESS)? What would be the weakness of an AI that always plays the same way?
  • Instead of setting the weights by hand, how could we find them? (Learning by self-play, Chapter 13.)
