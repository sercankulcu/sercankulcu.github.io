    How to play

    1. Players count in turn, starting from 1.
    2. On each turn a player says one, two or three consecutive numbers.
    3. The next player continues from the next number.
    4. The player who is forced to say the losing number (21 by default) loses.
    5. Changing the losing number shows how the winning pattern shifts.

    Control numbers

    Instead of thinking forward from 1, reason backward from the losing number: which number can you leave the opponent so that you can answer every reply? Since at most three numbers can be said per turn, the gap between control positions is four: for 21 the control numbers are 20, 16, 12, 8 and 4.

    Strategy tips

    • Work backward before the game starts to find the numbers on which you want your turns to end.
    • If the opponent says one number, answer with three; if two, answer with two; if three, answer with one.
    • Changing the losing number tests whether you understand the pattern instead of having memorized one sequence.

    Connection to game theory

    This is a small impartial sequential game closely related to subtraction games. It illustrates backward induction, winning and losing positions, strategy invariants, and the fact that a game that looks like a conversation can have an exact mathematical solution.

    No search: one rule

    This computer does not search a game tree. It applies a rule (function ai) that depends on the Computer setting. Let c be the last number said and T the losing number.

    1. Strategic. Say k = (T − 1 − c) mod 4 numbers; if that is 0, say 1 number.
    2. Random. Say 1, 2 or 3 numbers, each with probability 1/3.
    3. In both cases never say more numbers than are left before T (Math.min(k, T − c)).

    Why this rule? Call a number n a control number if T − 1 − n is divisible by 4: for T = 21 these are 20, 16, 12, 8, 4 (and 0, the start). The player who has just said a control number wins. If the opponent then says 1, 2 or 3 numbers, you answer with 3, 2 or 1: together that is 4, so you land on the next control number. At the end you say T − 1 and the opponent is forced to say T. The formula k = (T − 1 − c) mod 4 is exactly “how many numbers bring me to the next control number”.

    Worked example. T = 21 and you say 1, 2, so c = 2. The computer computes k = (21 − 1 − 2) mod 4 = 18 mod 4 = 2 and says 3, 4. Now c = 4, and 20 − 4 = 16 is divisible by 4, so 4 is a control number and you are the one in a lost position. If you say 1, the computer says 3 (5 → 8); if you say 3, it says 1 (7 → 8).

    Is the rule optimal?

    Yes. The Strategic computer wins from every position from which a win is possible. When c is a control number (the panel shows k = 0) the player to move is lost: whichever 1, 2 or 3 numbers are said, the opponent can reach the next control number. There is nothing better to do, so the computer says 1, which keeps the game going in case the opponent errs. Because the start c = 0 is a control number when T − 1 is divisible by 4, with T = 21 the first player (you) is lost against Strategic play; the first player wins exactly when T mod 4 ≠ 1 (for example T = 15 or 31).

    Backward induction in one line

    This is a small subtraction game: only T + 1 positions, so one could label each as winning or losing by backward induction, starting from the position where the player to move must say T (see the code tab and the deck on Minimax). The formula is the compressed result of that labeling. The idea of winning and losing positions is explained in Chapter 2 · Games and Representations.

    What the panel shows

    For every computer move: the numbers c and T, the computation of k, and a row for each possible choice (1, 2 or 3 numbers) with the number it reaches, the remainder (T − 1 − n) mod 4 and whether it is a control number. The chosen row is highlighted. With the Random computer the choice is random, so the panel only shows which rows would have been good.

    1. The computer's move: ai

    function ai() {
  aiTimer = null;
  if (over || turn !== 1) return;
  var t = target();                 // losing number (21 by default)
  var k = (t - 1 - cur) % 4;        // numbers to say to land on a control number
  if (k === 0) k = 1;               // already in a lost position: just say 1
  if (E('dsAI').value === 'Random') k = 1 + Math.floor(Math.random() * 3);
  take(Math.min(k, t - cur), true); // never more numbers than are left
}

    2. The same idea in Python

    TARGET = 21

def computer_move(c, target=TARGET):
    k = (target - 1 - c) % 4         # numbers to say to land on a control number
    return k if k else 1             # k == 0: already lost, just say 1

print(computer_move(2))              # 2: c = 2 -> 4, a control number
print(computer_move(4))              # 1: c = 4 is already a control number

    The backward labeling from dont_say_21.py (Chapter 2 code trace) finds the control numbers without the formula, and a check shows that the two agree:

    wins = {TARGET - 1: False}           # c = 20: lost (must say 21), as in dont_say_21.py
for c in range(TARGET - 2, -1, -1):
    wins[c] = any(not wins[c + k]
        for k in (1, 2, 3) if c + k < TARGET)
control = sorted(c for c in wins if not wins[c])
print(control)                       # [0, 4, 8, 12, 16, 20]

# the formula and the backward labeling agree on every position:
print(all(((TARGET - 1 - c) % 4 == 0) == (not wins[c]) for c in range(TARGET)))   # True

    Try it yourself

    1. Predict first, then look. Tick Show move reasoning and play against Strategic. After you say your numbers, work out (T − 1 − c) mod 4 yourself, before you read the panel. Is the computer's count the same?
    2. List the control numbers. For T = 21 write down the control numbers by counting back from 20 in steps of 4. During a game, check that every number the Strategic computer reaches is in your list (the panel marks it as a control number).
    3. Win as the first player. Change the losing number to 15, then to 31. Use the formula to find your opening (how many numbers must you say first so that c lands on a control number?), and answer every computer move to keep landing on control numbers. What does the panel say each time the computer has to move?
    4. Use the Random computer. With T = 21 you are lost against perfect play, but not against Random. Play so that you land on a control number as soon as the computer lets you, and then keep landing on them. How many turns did it take before the Random computer slipped? Compare with the Strategic computer.

    Discussion questions

    • When c is a control number the computer says 1. Is there a better move?
      Answer

      No. Whether it says 1, 2 or 3 numbers, the opponent can bring the total to the next control number (by saying 3, 2 or 1). Against perfect play every choice loses, so all three are equally good; saying 1 only keeps the game as long as possible so that a fallible opponent has the most chances to make a mistake.

    • The gap between control numbers is 4 because at most 3 numbers can be said. If up to 5 numbers could be said, what would the gap and the computer's rule be?
      Answer

      The gap would be 6: if the opponent says j numbers (1 to 5) you answer 6 − j, so each round adds 6. The rule would be k = (T − 1 − c) mod 6, with k = 0 again meaning that you are lost. In general, with at most m numbers per turn the gap is m + 1.

    • For which losing numbers T does the first player win with perfect play? Check T = 15, 21 and 31.
      Answer

      The first player wins exactly when c = 0 is not a control number, that is, when (T − 1) mod 4 ≠ 0, or T mod 4 ≠ 1. T = 21: 21 mod 4 = 1, so the first player loses. T = 15 and T = 31: 14 mod 4 = 2 and 30 mod 4 = 2, so the first player wins by opening with 2 numbers, landing on c = 2, a control number in both games.

    • Suppose the rules allowed saying 1, 2 or 4 numbers (but not 3). Would the computer's formula still work?
      Answer

      No, the formula depends on the allowed moves being exactly 1, 2, 3. You would have to redo the backward labeling with (1, 2, 4) in place of (1, 2, 3). For T = 21 it gives the lost positions 20, 17, 14, 11, 8, 5, 2: the gap becomes 3 because 4 acts like 1. The backward labeling works for any set of allowed moves; a closed formula exists only for special sets.
