    How to use

    Choose a game, a mode and a level, then press Run experiment. Most agents are random or learn from history, so Run another batch repeats the experiment to show how much results vary. Reset clears the results.

    Why this is game theory

    This final laboratory compares strategy classes rather than only one game. You can observe how success depends on the environment, opponent, feedback, noise and adaptation rule. There is no universally best strategy across all strategic settings.

    Scenarios (row payoff, column payoff)

    • Prisoner's Dilemma — actions Cooperate / Defect; payoffs (3,3), (0,5), (5,0), (1,1). Rewards cooperation but creates a temptation to defect. The last metric is the mutual-cooperation rate.
    • Matching Pennies — Heads / Tails; the row player wins 1 if the coins match, the column player wins 1 if they differ. Zero-sum, no pure-strategy equilibrium; unpredictability matters. The last metric is the match rate.
    • Coordination Game — A / B; both get 3 when they match, 0 otherwise. Highlights convention formation. The last metric is the coordination rate.
    • Rock–Paper–Scissors — cyclic dominance rewards mixed or adaptive behavior rather than a single fixed action. The last metric is the tie rate.

    Modes

    • Agent vs Agent — Agent A (row) and Agent B (column) play 60 rounds (level 1) or 120 rounds (levels 2–3).
    • Human vs Agent — you are the row player and choose every action yourself with the action buttons; Agent B adapts to your history. Run experiment starts a new match.
    • Full Tournament — every available agent plays every other agent once (round robin) and a ranking by total payoff is produced.

    Agents

    • Random — uniform random action.
    • Always first / Always second — fixed action (e.g. always Cooperate / always Defect).
    • Best Response — predicts the opponent's most frequent action so far and plays the best reply to it.
    • Fictitious Play (level 2+) — best reply to the empirical frequency of all the opponent's past actions.
    • Reinforcement (level 2+) — keeps a running average payoff per action and mostly plays the best one, exploring at random 15% of the time.

    Levels

    • Level 1 — Fixed Strategies: Random, always-first, always-second and simple best-response agents.
    • Level 2 — Learning Agents: adds fictitious-play and reinforcement agents that update from observed history.
    • Level 3 — Noisy Environment: learning agents, and each executed action flips with probability 8%, testing robustness and forgiveness under imperfect execution.

    Interpretation

    Tournament success is contextual. A strategy can dominate one opponent and perform poorly against another, so evaluation should include payoff, stability, exploitability and robustness.
