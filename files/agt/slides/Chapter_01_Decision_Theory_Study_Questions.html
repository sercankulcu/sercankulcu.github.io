Multiple Choice · Expected Utility

Question 1

In the Allais paradox (million TL; A: 1 for sure; B: 10% → 5, 89% → 1, 1% → 0; C: 11% → 1, 89% → 0; D: 10% → 5, 90% → 0), most people choose A in the first choice and D in the second. Why does this contradict expected utility theory?

D: E[u(A)] − E[u(B)] = 0.11·u(1) − 0.10·u(5) − 0.01·u(0); C and D are obtained by replacing the common 89% “1 million” part with “0,” so E[u(C)] − E[u(D)] is the same. Hence if A ≻ B then C ≻ D must hold: choosing “A and D” cannot be explained by any u. The violated axiom is independence, not transitivity (B); concavity does not solve the problem (A); the expected values (1; 1.39; 0.11; 0.5) are not equal (C).

Multiple Choice · Expected Value

Question 2

A lottery pays 100 TL with probability 40% and 0 TL with probability 60%. What is the lottery’s expected value in TL?

B: 0.4 · 100 + 0.6 · 0 = 40 TL.

Multiple Choice · Certainty Equivalent

Question 3

For a decision maker with a convex utility function (risk-loving), which statement is true?

C: For a convex u we have E[u(X)] > u(E[X]) (Jensen); CE = u⁻¹(E[u(X)]) and u is increasing, so CE > E[X]. The risk premium E[X] − CE is therefore negative: the person is willing to pay money to bear risk (someone who buys a lottery ticket). Option A describes the concave (risk-averse) case and B the linear (risk-neutral) case. D is the opposite: when the expected values are equal, a risk-loving person prefers the lottery to the sure amount.

Multiple Choice · Risk Attitude

Question 4

A person prefers a sure 50 TL to a lottery that pays 100 TL with probability 50% and 0 TL with probability 50%. Which statement is true for this person?

A: The lottery’s expected value is 50 TL, equal to the sure amount. A risk-neutral person would be indifferent between the two; a person who prefers the sure amount is risk-averse. A risk-loving person would choose the lottery.

Multiple Choice · Bayes’ Rule

Question 5

Which of these is base-rate neglect?

B: Base-rate neglect means substituting the test’s sensitivity, P(+ | sick), for P(sick | +) without accounting for the prior (prevalence, the base rate). When prevalence is low, the healthy are so numerous that most positive results are false positives; ignoring the prior greatly overstates the posterior (for a disease with 1% prevalence, a probability believed to be 90% is actually 9.2%). A and C are other errors; D is not an error at all but correct sequential Bayesian updating. Thinking in natural frequencies (“out of 1,000 people, how many?”) reduces this mistake.

Multiple Choice · Sequential Updating and Decision

Question 6

The function has the signature bayes(p, sens, fp, tests), where p is the prior probability, sens the sensitivity, fp the false-positive rate and tests the list of results. In the call bayes(0.01, 0.9, 0.09, ["+", "+"]), which value is used as the prior in computing the second test?

A: In the loop of bayes(), p = num / den is assigned after each test, so one test’s posterior becomes the next one’s prior. First test: 0.9·0.01 / (0.009 + 0.09·0.99) = 0.009 / 0.0981 ≈ 0.0917. The second test starts from this value: 0.9·0.0917 / (0.0826 + 0.09·0.9083) ≈ 0.5025. B evaluates each test from scratch and loses the cumulative evidence of the two positives; C mistakes the sensitivity for the prior, and D treats an uninformed 0.5 as the prior.

Multiple Choice · Decision Trees

Question 7

What is the rule for backward induction in a decision tree?

D: At a chance node nature makes the choice and the decision maker cannot control it, so the probability-weighted average of the branches is taken. At a decision node the decision maker chooses and picks the branch with the largest value; the sum(p * value(c) …) and max(…) lines of the value() function are exactly this. B swaps the two rules; A is overly optimistic, as if nature also chose in our favor; C ignores low-probability but high-stakes outcomes.

Multiple Choice · Value of Information

Question 8

In the product-launch example from the slides, the best decision without research is “launch,” with expected value 80; if research were free, the best strategy would yield 148 thousand TL. EVSI = 68, EVPI = 120. What should be done if the market research cost 75 thousand TL?

B: The value of imperfect research is EVSI = 148 − 80 = 68 thousand TL; research is worth doing only if its cost is below 68. Since 75 > 68: launch directly, expected 80 (the research route would give 148 − 75 = 73). The EVPI = 120 in A is only an upper bound; an imperfect report is not that valuable. The 128 in C was computed when the cost was 20; D rejects the profitable (80) product.

Classic Question · Expected Utility

Question 9: Certainty Equivalent

Lottery L: 3,600 TL with probability 25%, 400 TL with probability 75%. The decision maker’s utility function is u(x) = √x.

(a) What are E[L] and E[u(L)]? (b) What are the certainty equivalent (CE) and the risk premium? (c) Between a sure 1,000 TL and L, what do this person and a risk-neutral person choose?

Show the answer

(a) E[L] = 0.25·3,600 + 0.75·400 = 900 + 300 = 1,200 TL. E[u] = 0.25·√3,600 + 0.75·√400 = 0.25·60 + 0.75·20 = 15 + 15 = 30.

(b) √CE = 30 ⇒ CE = 900 TL. Risk premium = E[L] − CE = 1,200 − 900 = 300 TL > 0 (concave utility → risk-averse).

(c) u(1,000) = √1,000 ≈ 31.6 > 30 ⇒ the person with √x chooses the sure 1,000 TL (1,000 > CE = 900). A risk-neutral person looks only at the expected value: 1,200 > 1,000 ⇒ chooses L.

Classic Question · Risk Attitudes

Question 10: Insurance Premium

Wealth is 1,600 (thousand TL); with probability 20% there is a loss of 1,200 (leaving 400). Utility is u(x) = √x. What is the highest premium the person is willing to pay for full insurance? What is the least a risk-neutral insurer asks for? Which premiums benefit both sides?

Show the answer

Without insurance: E[u] = 0.8·√1,600 + 0.2·√400 = 0.8·40 + 0.2·20 = 32 + 4 = 36.

Certainty equivalent: 36² = 1,296. The person would accept a sure 1,296 in place of the risky wealth ⇒ highest premium = 1,600 − 1,296 = 304.

Expected loss: 0.2·1,200 = 240; a risk-neutral insurer asks at least this.

Any premium in the range 240 < premium < 304 benefits both: the insured escapes the risk and raises utility, and the insurer earns an expected profit. The 64 in between is the person’s risk premium: expected wealth 1,360 − certainty equivalent 1,296 = 64.

Classic Question · Bayes’ Rule

Question 13: Bayes and a Decision Rule

Prevalence is 5%, test sensitivity 80%, false-positive rate 10%. (a) In a population of 2,000, what is P(sick | +) using natural frequencies? (b) If an independent second test is also positive, what is the posterior? (c) Losses: unnecessary treatment of a healthy person 50, not treating a sick person 100. What is the treatment threshold, and what is the decision after each test?

Show the answer

(a) 100 sick → 80 positive; 1,900 healthy → 190 positive. P(sick | +) = 80/(80 + 190) = 80/270 = 8/27 ≈ 29.6%.

(b) New prior 8/27: num = 0.8·8/27, den = num + 0.1·19/27 ⇒ p = 6.4/(6.4 + 1.9) = 64/83 ≈ 77.1%.

(c) Treat ⇔ (1 − p)·50 < p·100 ⇔ p > 50/150 = 1/3.

Classic Question · Decision Tree

Question 14: Decision Tree and EVPI

A firm must decide whether to launch a new product. If the market is good (probability 0.3) the payoff is +400, if bad (0.7) it is −100 thousand TL; if it does not launch, 0. (a) What is the best decision without information, and its expected value? (b) What is the expected value of perfect information (EVPI)?

Show the answer

(a) Chance node: 0.3·400 + 0.7·(−100) = 120 − 70 = 50. Decision node: max(Launch 50, Don’t launch 0) ⇒ Launch, expected value 50.

(b) If an oracle tells the market in advance: good → launch (400), bad → don’t launch (0). Expected 0.3·400 + 0.7·0 = 120.

EVPI = 120 − 50 = 70. No market research is worth more than 70 thousand TL: perfect information is the upper bound for the value of imperfect information. The gain comes only from avoiding a launch in a bad market: 0.7·100 = 70.

Classic Question · Value of Information

Question 15: The Value of Sample Information

A firm must decide whether to launch a new product: if the market is good (probability 0.3) the payoff is +400, if bad (0.7) it is −100 thousand TL; if it does not launch, 0. Without research the best decision is “launch,” with expected value 50 thousand TL. The firm can commission market research for 10 thousand TL: P(positive | good) = 0.9, P(positive | bad) = 0.2. Find the best strategy by backward induction; what is the EVSI, and what is the most that should be paid for the research?

Show the answer

P(positive) = 0.3·0.9 + 0.7·0.2 = 0.27 + 0.14 = 0.41. P(good | positive) = 0.27/0.41 = 27/41; P(good | negative) = 0.03/0.59 = 3/59.

Launch after a positive report (net, including −10): 27/41·390 + 14/41·(−110) ≈ 219.3 > −10 ⇒ Launch.

Launch after a negative report: 3/59·390 + 56/59·(−110) ≈ −84.6 < −10 ⇒ Don’t launch.

Research node: 0.41·219.3 + 0.59·(−10) = 84 > 50 (no research) ⇒ best strategy: do the research; launch if positive, don’t launch if negative.

EVSI = (84 + 10) − 50 = 44: at most 44 thousand TL should be paid for the research (EVSI ≤ EVPI = 70).

Multiple Choice · Uniqueness of the Utility Scale

Question 16

A decision maker with utility u(x) = √x chooses a sure 400 TL over a lottery paying 900 TL with probability ½ and 0 TL with probability ½. Which of the following functions does not represent the same lottery preferences?

D: vNM utility is unique only up to a positive affine transformation (a·u + b, a > 0): A, B and C have this form and preserve the expected-utility ranking (e.g., with 10√x the lottery is 150 and the sure amount 200). (√x)² = x is also increasing but not affine; it values the lottery at 450 and the sure amount at 400, and it changes the decision. Any increasing transformation preserves the ranking among sure outcomes; only affine transformations preserve it among lotteries.

Multiple Choice · Ambiguity Aversion

Question 17

An Ellsberg urn has 30 red balls and a total of 60 black and yellow balls in unknown proportion. Most people prefer “red” to “black” and “black or yellow” to “red or yellow” (each winning bet pays 100 TL). Which statement is true about these preferences?

A: If the number of black balls is s, the first preference means 30 > s and the second means 60 > 30 + (60 − s), i.e., s > 30; both cannot hold at once. In each bet people choose the option whose winning probability is known: ambiguity aversion (Ellsberg, 1961). B explains only the first preference; C is wrong: the payoff is 100 TL in every option, so the curvature of utility does not change the perception of probability; D forgets that the expected payoff depends on s.

Classic Question · Bayesian Games

Question 18: Updating an Opponent’s Type

In a card game the opponent is a bluffer with probability 30% and honest with probability 70%. In a hand the bluffer raises with probability 80% and the honest player with 25% (hands are independent). Calling a raise earns +40 against a bluffer and −60 against an honest player; folding earns 0. (a) After one raise, what are P(bluffer) and the expected value of calling? (b) After two raises in two separate hands? (c) Above which P(bluffer) threshold is calling profitable?

Show the answer

(a) P = 0.3·0.8 / (0.24 + 0.7·0.25) = 0.24 / 0.415 ≈ 0.578. E[call] = 0.578·40 − 0.422·60 ≈ −2.2 < 0 ⇒ fold.

(b) With 0.578 as the new prior: 0.578·0.8 / (0.578·0.8 + 0.422·0.25) ≈ 0.814 (directly: 0.3·0.64 / (0.192 + 0.7·0.0625) gives the same result). E[call] = 0.814·40 − 0.186·60 ≈ +21.4 ⇒ call.

(c) p·40 − (1 − p)·60 > 0 ⟺ p > 0.6. A single raise brings the belief just below the threshold, the second pushes it above; the decision changes as evidence accumulates.

Question 19: The Hurwicz Criterion

The probabilities are unknown. The Hurwicz criterion evaluates each action as α·(row max) + (1 − α)·(row min); α is the optimism coefficient.

GoodMediumBad
X10030−40
Y604010
Z202020

(a) Which action is chosen for α = 0.3 and α = 0.7? (b) For which ranges of α is each action chosen? (c) Which criteria do α = 0 and α = 1 correspond to?

Show the answer

HX = 100α − 40(1 − α) = 140α − 40; HY = 60α + 10(1 − α) = 50α + 10; HZ = 20.

(a) α = 0.3: X 2, Y 25, Z 20 ⇒ Y. α = 0.7: X 58, Y 45, Z 20 ⇒ X.

(b) Y = Z ⇔ 50α + 10 = 20 ⇔ α = 0.2; X = Y ⇔ 90α = 50 ⇔ α = 5/9 ≈ 0.56. α < 0.2 ⇒ Z; 0.2 < α < 5/9 ⇒ Y; α > 5/9 ⇒ X.

(c) α = 0: maximin (Z, 20). α = 1: maximax (X, 100). Hurwicz lies between the two; the Medium column (30, 40, 20) never affects the result.

Multiple Choice · The St. Petersburg Paradox

Question 20

In the St. Petersburg game a fair coin is flipped until it comes up heads; if heads first appears on flip k, the prize is 2k TL. What is the most that a person with no other wealth and utility u(x) = log₂ x will pay to play?

C: The expected prize is E[X] = Σ (1/2)k·2k = 1 + 1 + 1 + … = ∞; a person who looks only at the expected value (risk-neutral) would pay any price (A). That nobody pays a large sum is the paradox itself. With utility: E[u] = Σ (1/2)k·k = 1/2 + 2/4 + 3/8 + … = 2. The certainty equivalent is CE = u⁻¹(2) = 2² = 4 TL. B mistakes the utility unit for TL and does not apply u⁻¹; D substitutes a single term for the sum.

Multiple Choice · Jensen’s Inequality

Question 21

Lottery L: 0 TL with probability 50%, 400 TL with probability 50%. Utility is u(x) = √x. Which statement is true?

A: E[L] = 200 and u(E[L]) = √200 ≈ 14.1; E[u(L)] = ½·0 + ½·20 = 10. For a concave u the chord lies below the curve: E[u(X)] ≤ u(E[X]) (Jensen). CE = u⁻¹(10) = 10² = 100; risk premium = E[L] − CE = 100 > 0, so the person is risk-averse. B moves the expectation inside the function, which holds only for a linear u (risk-neutral). C computes the premium backwards as CE − E[X]. D again applies u instead of u⁻¹.

Multiple Choice · Code Tracing

Question 22

The criteria(U) function from the slides is called with U = [[2, 7, 7], [5, 4, 6], [1, 8, 0]] (rows are actions 0, 1, 2; columns are states). What does print(criteria(U)) print?

B: The row minima are 2, 4, 0 ⇒ mm = 1; the maxima 7, 6, 8 ⇒ mx = 2; the averages 16/3, 15/3, 9/3 ⇒ lp = 0. The column bests are best = [5, 8, 7]; the largest regrets are reg = [3, 4, 7] ⇒ the smallest is 3, sv = 0. The output is (1, 2, 0, 0). A takes the index of the largest regret (Savage wants the smallest). C computes regret against each row’s own maximum instead of the column’s (5, 2, 8). D assumes the function returns the criterion values; but max(A, key=…) returns an index.

Multiple Choice · The vNM Axioms

Question 23

Which behavior–axiom pairing is correct?

C: Cem’s preferences form a cycle: if tea ≻ coffee and coffee ≻ ayran, then tea ≻ ayran should hold; such a person can be charged a small fee for each swap and brought back to the start. A is transitive (tea ≻ ayran is consistent). Ece in B finds the intermediate 50 TL equivalent to no mixture p·100 + (1 − p)·0 of the two extremes: this is a violation of continuity, not independence. Deniz’s preference in D (a lottery with expected value 450 against a sure 400) is consistent with a risk-neutral or risk-loving person; it does not violate expected utility.
