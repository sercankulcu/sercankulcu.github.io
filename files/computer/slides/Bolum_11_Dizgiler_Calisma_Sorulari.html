Soru 12: E-postadan Ad ve Soyad

E-posta adresinden ad ve soyad ayrılıyor. Her satırdan sonra değişkenler ne olur, çıktı nedir?

Önce kendiniz tahmin edin, sonra › ile ilerleyin.

15 karakterlik dizgi; indeksler 0–14.

indexOf('@') ilk @ karakterinin indeksini verir: 8.

substring(0, 8): 0 dahil, 8 hariç → "ece.kaya" (8 karakter).

Arama artık ad içinde: '.' indeks 3'te.

substring(0, 3) → "ece".

substring(4) → noktadan sonraki kısım: "kaya".

toUpperCase() yeni bir String döndürür; soyad değişkeni yine "kaya"dır.

String s = "ece.kaya@uni.tr";
int at = s.indexOf('@');
String ad = s.substring(0, at);
int nokta = ad.indexOf('.');
String isim = ad.substring(0, nokta);
String soyad = ad.substring(nokta + 1);
System.out.println(soyad.toUpperCase() + ", " + isim);

Soru 23: append, toString, reverse

Aşağıdaki kodun çıktısı nedir? sb'nin içeriğini adım adım izleyin.

Önce kendiniz tahmin edin, sonra › ile ilerleyin.

Değiştirilebilir tampon "ab" ile başlar.

append aynı nesneye ekler ve nesnenin kendisini döndürür; bu yüzden zincirlenebilir.

Yeni String oluşmaz; tampon büyür.

i = 3 de eklendi.

4 <= 3 → false, döngü biter.

toString() o anki içerikten ayrı bir String üretir.

reverse() tamponun kendisini ters çevirir; s etkilenmez (String değişmez).

sb + ile birleştirilirken toString() otomatik çağrılır.

StringBuilder sb = new StringBuilder("ab");
for (int i = 1; i <= 3; i++) {
    sb.append(i).append('-');
}
String s = sb.toString();
sb.reverse();
System.out.println(s + " " + sb);

Soru 26: Sesli Harf Sayma

Her karakterin sesliler dizgisinde olup olmadığına indexOf ile bakılıyor. Çıktı nedir?

Önce kendiniz tahmin edin, sonra › ile ilerleyin.

Önce küçük harfe çevrilir. sesliler dizgisi Türkçe sesli harfleri tutar.

'g': indexOf → -1 → sesli değil.

'i': indexOf → 3 ≥ 0 → sesli, sayac = 1.

'r': indexOf → -1 → sesli değil.

'e': indexOf → 1 ≥ 0 → sesli, sayac = 2.

's': indexOf → -1 → sesli değil.

'u': indexOf → 6 ≥ 0 → sesli, sayac = 3.

'n': indexOf → -1 → sesli değil.

Sesli harf sayısı 3 (i, e, u).

String s = "Giresun".toLowerCase();
String sesliler = "aeıioöuü";
int sayac = 0;
for (int i = 0; i < s.length(); i++) {
    if (sesliler.indexOf(s.charAt(i)) >= 0)
        sayac++;
}
System.out.println(sayac);

Soru 27: Sezar Şifresi (kaydır = 2)

Her harf alfabede 2 ileri kaydırılıyor. Çıktı nedir? ('a' = 0, …, 'k' = 10, 'z' = 25)

Önce kendiniz tahmin edin, sonra › ile ilerleyin.

Sonuç StringBuilder'da biriktirilecek.

'k' − 'a' = 10; (10 + 2) % 26 = 12.

'a' + 12 = 'm'.

'a': (0 + 2) % 26 = 2 → 'c'.

'z': (25 + 2) % 26 = 27 % 26 = 1: % 26 alfabenin başına sarar.

'a' + 1 = 'b'.

Çözmek için aynı döngü kaydir yerine 26 − 2 = 24 ile çalıştırılır.

String metin = "kaz";
int kaydir = 2;
StringBuilder sifreli = new StringBuilder();
for (int i = 0; i < metin.length(); i++) {
    char c = metin.charAt(i);
    int yer = (c - 'a' + kaydir) % 26;
    sifreli.append((char) ('a' + yer));
}
System.out.println(sifreli);

Soru 29: Palindrom: İki Uç

İki işaretçiyle palindrom kontrolü yapılıyor. Çıktı nedir?

Önce kendiniz tahmin edin, sonra › ile ilerleyin.

toLowerCase(): 'K' ≠ 'k' sorununu önler.

Aksi kanıtlanana kadar palindrom kabul edilir.

0 < 4; 'k' != 'k' → false: uçlar eşit.

İçe doğru ilerle.

1 < 3; 'a' != 'a' → false.

sol = sag = 2: ortada tek karakter kaldı.

2 < 2 → false, döngü biter.

toLowerCase() olmasaydı ilk karşılaştırmada 'K' != 'k' → false olurdu.

String s = "Kabak".toLowerCase();
int sol = 0, sag = s.length() - 1;
boolean palindrom = true;
while (sol < sag) {
    if (s.charAt(sol) != s.charAt(sag)) {
        palindrom = false;
        break;
    }
    sol++; sag--;
}
System.out.println(palindrom);

Soru 31: format Belirteçleri

Aşağıdaki kodun çıktısı nedir? (Hücreleri sayın.)

String ad = "Ada";
int adet = 42;
double fiyat = 3.14159;
System.out.println(String.format(Locale.US,
    "%-6s|%4d|%6.2f|", ad, adet, fiyat));
System.out.println(String.format(Locale.US,
    "%05d|%,d", 42, 1234567));
Cevabı göster 
Ada   |  42|  3.14|
00042|1,234,567
  • %-6s: 6 hücre, sola yaslı → "Ada" + 3 boşluk.
  • %4d: 4 hücre, sağa yaslı → 2 boşluk + 42.
  • %6.2f: 2 ondalık ("3.14", 4 karakter) 6 hücreye sağa yaslı.
  • %05d soldan sıfırla doldurur; %,d binlik ayırıcı koyar. Türkçe yerel ayarda ondalık ayırıcı virgül olurdu (3,14).
