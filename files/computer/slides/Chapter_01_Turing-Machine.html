The Turing machine

Goal: Follow, step by step, the abstract model that explains algorithmic computation. Every step of the machine is determined only by the pair (state, symbol read) through the table of transition rules.

Parts

  • Tape: memory divided into cells, extending in both directions; a blank cell is shown as □.
  • Read/write head: reads a cell, writes a new symbol, then moves left or right or stays put.
  • State: the information the machine is “keeping in mind” at that moment (q0, q1, …). When it reaches the HALT state, the machine stops.
  • Transition rule: (state, read) → write, move, new state. The active rule is highlighted in the table.

How to use it

  • Choose a machine, type the tape input and press Load (or pick one of the examples).
  • Step → applies one rule, ← Back undoes it, and Play runs the machine until it halts. The → and ← keys also work.
  • With Try it yourself on, before every step you choose the rule to apply in the table (click it, or move to the row and press Enter); correct guesses are counted.

Ready-made machines

  • Add 1 to a binary number: the 111 + 1 = 1000 example from the slides; also try the input 1011 from the exercise.
  • Subtract 1 from a binary number, Flip the bits, Unary addition (111+11 → 11111) and Parity check (is the number of 1s even or odd?).
