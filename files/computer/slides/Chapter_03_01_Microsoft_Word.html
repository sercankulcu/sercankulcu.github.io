Document Management

AutoSave and OneDrive

AutoSave

Writes changes to the cloud continuously. The file must live in OneDrive or SharePoint; turn it on with the switch in the title bar.

Local file

AutoSave doesn't work on a file in a folder on your computer; save it yourself with Ctrl+S.

Version History

Lists older versions kept in the cloud; you can open an earlier version and restore it.

The Ctrl+S habit

Even with AutoSave on, Ctrl+S does no harm and gives peace of mind.

AutoRecover

A separate feature: offers a recovery copy after an unexpected shutdown; it doesn't replace Save.

Co-authoring

Several people can work on the same cloud file at once.

The button's name, position and presence vary with the Word version and updates; some perpetual-license versions may lack AutoSave. Check the title bar and File → Info to see whether your version has it.

Ctrl+Home takes the cursor to the very start of the document.

Ctrl+→ jumps the cursor to the start of the next word; no need to step through each character.

Ctrl+→ again: the cursor is at the start of “covers”.

Ctrl+Shift+→ makes the same jump but selects the text it passes: “covers ” is selected.

Ctrl+End takes the cursor to the end of the document; moving without Shift clears the selection.

Editing Text

Cut and Paste Step by Step

The recipe is in the wrong order: “Mix the ingredients” should come first. Instead of retyping the line, we'll move it.

First select the range to move (Shift+↓ at the start of the line, or click left of the line).

Ctrl+X (Cut): the selected text leaves the document and goes to the clipboard.

Move the cursor to the destination: the start of the document.

Ctrl+V (Paste): the clipboard text is inserted at the cursor. The clipboard keeps its contents, so you can paste again.

Had we used Copy (Ctrl+C) instead of Cut, the source line would have stayed: the text appears twice (dashed frame).

The clipboard holds the last cut/copied item; the Office Clipboard (Home → Clipboard) can keep the last 24 items.

Editing Text · Step by step

Cleaning Up a Document with Find and Replace

¶ reveals the hidden marks: every Enter is a ¶, every space a dot. Gaps were made with empty paragraphs, and there are double spaces in two places.

Ctrl + H → More >> → Special → Paragraph Mark: Word's code for ¶, ^p, goes into the Find what box.

Two ¶ in a row (an empty paragraph) will be found and replaced with a single ¶. Nothing in the document has changed yet.

Replace All: 3 replacements. The three ¶ after “parts.” dropped to two, leaving one extra: the search moves left to right and never revisits what it replaced.

The same command once more: 1 replacement, no empty paragraphs left. A third try finds 0, which tells you the job is done.

Two spaces were replaced with one (2 places). Space between paragraphs should now come from After spacing, not from empty Enters.

Page Layout

A Different Orientation with Section Breaks

The document has one section, and all pages are portrait. The wide table on page 3 runs off the right edge.

Put the cursor before the table: Layout → Breaks → Next Page. There are now two sections.

A second section break goes after the table, so the table sits alone in its own section (Section 2).

With the cursor in Section 2: Layout → Orientation → Landscape. Only this section turned landscape and the table fits; the other pages stay portrait.

Compare: with a page break instead of a section break, the document would stay one section and the orientation change would apply to every page.

Margins, number of columns, headers and page number format can also be set per section.

Objects · Step by step

Text Wrapping Types Step by Step

In Line with Text: the picture sits in the line like a character and makes the line taller. Its position is tied to the text; it can't be moved freely on the page.

Square: the picture becomes an independent object and text flows around its rectangular frame. It can be moved freely on the page.

Behind Text: the picture is a layer under the text, which is read on top (watermark, background). Unless the picture is faint, readability suffers.

In Front of Text: the picture covers the text, hiding what's underneath. Usually unwanted. Change the type with the Layout Options button when the picture is selected.

Headers, Footers and Page Numbers

  • The first page, or odd and even pages, can be set up differently.
  • With section breaks, “Link to Previous” controls the link to the previous section separately.
  • The page number is inserted as a field, not typed; it updates itself when pages change.

Page Layout · Step by step

Headers: Different First Page and Link to Previous

In a single section the header is the same on every page: you edit it once (here “Report”).

With Different First Page checked, the cover gets its own header area, left empty here. Pages 2 and 3 show “Report”.

A Next Page section break is added at page 3. In the new section Link to Previous is on: the header matches the previous section, so “Report” appears.

Wrong: with the link on, changing the header in Section 2 to “Appendix” changes Section 1 too; page 2 also says “Appendix”.

Right: first turn off Link to Previous in Section 2, then type “Appendix”. Only page 3 shows “Appendix”; page 1 stays empty and page 2 keeps “Report”.

Different First Page in Section 1: the cover shows no number but still counts, so the Abstract is still ii. Section 2 is not affected.

Collaboration

Track Changes Views

The original text. With Review → Track Changes on, every edit is recorded.

“10” is deleted and “17” typed: the deletion shows struck through in red, the insertion underlined in color, and a change bar appears in the margin.

“may only ” is added to the second line. Who made each change, and when, is recorded.

A comment (New Comment) doesn't change the text; it shows as a balloon in the right margin, anchored to its spot.

Simple Markup shows the text as it will end up, but the changes are still pending. Hiding is not accepting.

Review → Accept → Accept All Changes, and the comment is deleted: the text is now clean and final.

Collaboration · Step by step

Accepting and Rejecting Changes One by One

Four changes by Ayşe and Mehmet are pending. Next goes to the first one: “10” was deleted (struck through).

Accept and Move to Next: the deletion is final and “10” is gone from the text. The cursor moves on by itself to the second change, the inserted “17”.

“17” is accepted and becomes ordinary text. The next change is picked by its position in the text: Mehmet's deletion.

The time is needed: Reject and Move to Next. The deletion is undone and “by 17:00” stays in the text as it was.

The last insertion is accepted. No changes are pending; the text is final: “Homework due 17 November by 17:00 as a PDF file.”

Track Changes is turned off: later edits are not recorded but go straight into the text. Leave it on by mistake and every fix becomes another pending change.

Long Documents

How Do Numbers Update?

Two figures with captions (References → Insert Caption). The “Figure 2” in the text wasn't typed: it is a cross-reference field pointing to the chart.

A new figure and caption are inserted in between: Word renumbers them (the chart is now Figure 3). The cross-reference hasn't updated yet.

Select all with Ctrl+A and press F9 (Update Field): the cross-reference shows the right number, “Figure 3”. Text outside the field never changes by itself.

Captions also feed the table of figures: it is built automatically and updates the same way.

Abstract

Chapter Summary

  • Word documents are organized at the text, paragraph, section and page levels.
  • Styles provide document structure and consistent formatting.
  • Breaks set up different page or section layouts.
  • Headings feed the table of contents; captions feed the table of figures.
  • Comments carry feedback; Track Changes keeps the editing history.
  • Direct formatting overrides styles; page number format and start are set per section.
  • Before PDF or printing, check layout, accessibility and hidden content.
