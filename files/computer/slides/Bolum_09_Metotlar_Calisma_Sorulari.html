Çoktan Seçmeli · Metot Temelleri

Soru 1: Çağrıların Sırası

Metot hem ekrana yazıyor hem değer döndürüyor. Çıktı nedir?

static int f(int x) {
    System.out.print("f" + x + " ");
    return x * 2;
}
// main içinde:
System.out.println(f(1) + f(2));

C: println'in argümanı hesaplanırken önce f(1) (soldan sağa) sonra f(2) çağrılır; ikisi de kendi yazısını basar. Sonra 2 + 4 = 6 yazılır. D, "s=" + f(1) + f(2) gibi önce String ile başlayan ifadede olurdu (String birleştirme: "24").

Soru 2: static Olmayan Metot

Program derlenirken ne olur?

public class Ornek {
    void selamla() {
        System.out.println("Merhaba");

    public static void main(String[] args) {

D: main static'tir (nesne olmadan çalışır); static olmayan selamla() bir nesneye aittir ve doğrudan çağrılamaz. Çözüm, metodu static void selamla() yapmaktır.

Soru 3: usHesapla(2, −2)

Negatif üste metot kendini pozitif üsle çağırıyor. usHesapla(2, -2) ne döndürür? Çağrı yığınını izleyin.

main, usHesapla(2, -2)'yi çağırır. int 2, double parametreye 2.0 olarak genişler.

Yeni çerçeve: taban = 2.0, us = −2, sonuc = 1.0.

us < 0 → metot kendini −us = 2 ile çağırır. Üstteki yeni çerçevenin kendi taban, us, sonuc kutuları var.

us = 2 ≥ 0 → for: i = 0, sonuc = 1.0 × 2.0 = 2.0.

i = 1, sonuc = 4.0. Sonra i = 2 < 2 false.

return 4.0: üstteki çerçeve kapanır.

İlk çerçeve kaldığı yerden sürer: sonuc = 1.0 / 4.0 = 0.25. (1.0 yazıldığı için bölme double'dır.)

return 0.25: çerçeve kapanır.

0.25 yazılır: 2⁻² = 1 / 2² = 1/4. (main'den çağırabilmek için metot static yazıldı.)

static double usHesapla(double taban, int us) {
  double sonuc = 1;
  if (us < 0) {
    sonuc = 1.0 / (usHesapla(taban, -us));
  } else {
    for (int i = 0; i < us; i++) {
      sonuc *= taban;
    }
  }
  return sonuc;
}
// main: System.out.println(usHesapla(2, -2));

Soru 5: Negatif Sayının Faktöriyeli

Bu çözüm sayi = -3 ile çağrılıyor. Çıktı nedir? Metotta ne eksik?

public static long faktoriyel(int sayi) {
    if (sayi < 0) {
        System.out.println("Sayi negatif olamaz.");
    }
    long sonuc = 1;
    for (int i = 1; i <= sayi; i++) {
        sonuc *= i;
    }
    return sonuc;
}
// main içinde:
int sayi = -3;
System.out.println(sayi + " sayisinin faktöriyeli: "
    + faktoriyel(sayi));
Cevabı göster 
Sayi negatif olamaz.
-3 sayisinin faktöriyeli: 1
  • println'in argümanı yazılmadan önce hesaplanır: faktoriyel çağrılır ve uyarıyı önce basar.
  • Uyarıdan sonra metot sürer; for hiç dönmez → 1 döner, yanlış bir sonuç ekrana gelir.
  • Eksik: if içinde return -1; (ya da bir istisna) ile erken çıkmak.

Soru 6: kombinasyon(4, 2)

kombinasyon, faktoriyel metodunu üç kez çağırıyor. Çağrı yığınını ve dönen değerleri izleyin.

main, kombinasyon(4, 2)'yi çağırır.

Çerçeve: n = 4, r = 2. İfadeyi hesaplamak için önce faktoriyel(n) gerekir.

Yeni çerçeve: n = 4 (kombinasyon'un n'sinden ayrı kutu). sonuc = 2·3·4 = 24.

24 döner, çerçeve kapanır. Sıradaki çağrı faktoriyel(r) = faktoriyel(2).

n = 2: sonuc = 2 → 2 döner.

faktoriyel(n − r) = faktoriyel(2): aynı metot, yepyeni bir çerçeve → 2.

24 / (2 × 2) = 24 / 4 = 6. return 6.

6 yazılır: 4 öğeden 2'li seçim sayısı. Metot başka metodu çağırarak kod tekrarını önler.

static long faktoriyel(int n) {
  long sonuc = 1;
  for (int i = 2; i <= n; i++)
    sonuc *= i;
  return sonuc;
}
static long kombinasyon(int n, int r) {
  return faktoriyel(n)
    / (faktoriyel(r) * faktoriyel(n - r));
}
// main:
System.out.println(kombinasyon(4, 2));

Soru 7: swap Tuzağı

Aşağıdaki kodun çıktısı nedir?

static void swap(int a, int b) {
    int t = a;
    a = b;
    b = t;
}
// main içinde:
int x = 3, y = 5;
swap(x, y);
System.out.println(x + " " + y);
Cevabı göster

Çıktı: 3 5

  • a ve b, x ve y'nin kopyalarıdır; swap kendi kopyalarını takas eder.
  • Metot bitince a, b, t silinir; main'deki x ve y'ye hiç dokunulmamıştır.

Soru 9: Hangi yaz Çağrılır?

Derleyici her çağrı için argümanların tipine ve sayısına uyan metodu seçer. Çıktıyı bulun.

yaz(5): tek int argüman → tam eşleşme yaz(int).

yaz(5.0): 5.0 bir double sabitidir → yaz(double). double olduğu için 5.0 yazılır.

yaz(3, 4): iki argüman → yaz(int, int). Parantez sayesinde 3 + 4 = 7 toplanır (yoksa "iki 34" olurdu).

yaz('A'): char için tam eşleşme yok; char → int genişlemesi en yakın seçenek. 'A' = 65.

yaz(7L): long, int'e kendiliğinden daralmaz ama double'a genişler → yaz(double).

Seçim program çalışmadan, derlemede yapılır. Uyan hiçbir imza yoksa (ör. yaz("a")) derleme hatası olur.

static void yaz(int x) {
  System.out.println("int " + x);
}
static void yaz(double x) {
  System.out.println("double " + x);
}
static void yaz(int a, int b) {
  System.out.println("iki " + (a + b));
}
// main:
yaz(5);  yaz(5.0);  yaz(3, 4);
yaz('A');  yaz(7L);

Soru 10: enBuyuk(3, 4.5)

Sınıfta static int enBuyuk(int a, int b) ve static double enBuyuk(double a, double b) var. System.out.println(enBuyuk(3, 4.5)); ne yazar?

B: 4.5 double olduğundan enBuyuk(int, int) uymaz; 3 double'a genişletilerek enBuyuk(double, double) çağrılır → 4.5. enBuyuk(3, 4) ise int sürümünü seçer ve 4 yazar.

Soru 11: Blok Dışında Kullanılan Değişken

Hangi satır derleme hatası verir?

static int hesapla(int n) {     // 1
    int sonuc = 0;              // 2
    if (n > 0) {                // 3
        int katki = n * 2;      // 4
        sonuc += katki;         // 5

Soru 12: static Alan ve Yerel Değişken

Sınıf düzeyinde static int x ve metotta aynı adlı yerel x var. Çıktıyı adım adım bulun.

static alan x = 10: sınıfa ait, tüm metotlar görür.

g çağrılır: yerel x = 3 bildirilir. Yerel ad, aynı adlı alanı metot içinde gölgeler (derlenir).

x++ yerel kutuyu artırır → 4 yazılır. Alan hâlâ 10.

g bitti, yerel x silindi. main'de x alanı ifade eder → 10.

Alan güncellenir: x = 11.

g yeniden çağrılır: yerel x her çağrıda yeniden 3 ile doğar → yine 4.

Çıktı: 4, 10, 4, 11. Gölgeleme yalnızca yerel değişken ile alan arasında olur; iki yerel değişken aynı kapsamda aynı adı alamaz.

static int x = 10;
static void g() {
  int x = 3;
  x++;
  System.out.println(x);
}
// main:
g();
System.out.println(x);
x = x + 1;
g();
System.out.println(x);

Soru 14: oncekiAsal(100)

oncekiAsal(100) çağrılıyor. Kaç kez asalMi çağrılır ve ne döner?

Aramaya 100'ün bir altından başlanır: 99.

99 % 2 = 1, 99 % 3 = 0 → return false (erken dönüş).

Asal değil → oncekiSayi-- → 98.

98 % 2 = 0 → false.

oncekiSayi → 97.

i = 2..96 (95 deneme) hiçbiri 97'yi bölmez → true.

if true → return 97. asalMi 3 kez çağrıldı; return döngüyü de metodu da bitirir.

static boolean asalMi(int sayi) {
  if (sayi <= 1) return false;
  for (int i = 2; i < sayi; i++)
    if (sayi % i == 0) return false;
  return true;
}
static int oncekiAsal(int sayi) {
  int oncekiSayi = sayi - 1;
  while (oncekiSayi > 1) {
    if (asalMi(oncekiSayi)) return oncekiSayi;
    oncekiSayi--;
  }
  return -1;
}

Soru 15: oncekiAsal Sınır Değerleri

Aynı oncekiAsal ve asalMi ile çıktı nedir?

System.out.println(oncekiAsal(20));
System.out.println(oncekiAsal(3));
System.out.println(oncekiAsal(2));
Cevabı göster 
19
2
-1
  • 20 → 19 asal (19'u bölen yok).
  • 3 → oncekiSayi = 2; 2 > 1 true, asalMi(2): for hiç dönmez (2 < 2 false) → true → 2.
  • 2 → oncekiSayi = 1; 1 > 1 false → döngüye girilmez, return -1 ("bulunamadı" işareti).

Soru 16: asalMi Kaç Tur Döner?

97 asaldır. Yaygın for (int i = 2; i < sayi; i++) sürümü ile dersteki for (int i = 2; i <= n / i; i++) sürümü 97 için kaçar kez kalan hesaplar?

A: İlki i = 2..96 → 95 tur. İkincisi i × i ≤ 97 iken (i = 2..9; 10 <= 97/10 = 9 false) → 8 tur. √n'den büyük bir bölen varsa küçük eşi de vardır, bu yüzden √n'e kadar bakmak yeter. Sonuç (true) aynıdır.

Soru 17: ebob ve ekok

Aşağıdaki kodun çıktısı nedir?

static int ebob(int a, int b) {
    while (b != 0) {
        int r = a % b;
        a = b;
        b = r;
    }
    return a;
}
static int ekok(int a, int b) {
    return a / ebob(a, b) * b;
}
// main içinde:
System.out.println(ebob(84, 36) + " " + ekok(4, 6));
Cevabı göster

Çıktı: 12 12

  • 84 % 36 = 12 → (36, 12); 36 % 12 = 0 → (12, 0) → ebob = 12.
  • ekok(4, 6): ebob(4, 6) = 2 → 4 / 2 * 6 = 12. Önce bölmek a·b taşmasını önler.

Soru 18: İç İçe Çağrı ve Sayaç

static sayac alanı her çağrıda artıyor. Çıktı nedir?

static int sayac = 0;
static int ikiyle(int n) {
    sayac++;
    return n * 2;
}
// main içinde:
int r = ikiyle(ikiyle(3));
System.out.println(r + " " + sayac);
Cevabı göster

Çıktı: 12 2

  • İç içe çağrıda önce içteki çalışır: ikiyle(3) → 6 (sayac = 1).
  • Sonra ikiyle(6) → 12 (sayac = 2).
  • sayac bir static alan olduğu için çağrılar arasında değeri korunur; yerel değişken olsaydı her çağrıda 0'dan başlardı. Bu bir yan etkidir.

Soru 20: Ortalamada Tam Sayı Bölmesi

static double ortalama(int a, int b, int c) { return (a + b + c) / 3; } için ortalama(7, 8, 8) ne döndürür?

C: (a + b + c) / 3 = 23 / 3 iki int arasında tam sayı bölmesidir → 7; sonra dönüş tipi double olduğu için 7.0 olur. Düzeltme: (a + b + c) / 3.0 → 7.666666666666667. Dönüş tipinin double olması bölmeyi kendiliğinden kayan noktalı bölmeye çevirmez.
