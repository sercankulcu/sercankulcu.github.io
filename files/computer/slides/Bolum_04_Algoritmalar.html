Problem Çözme

Önce Algoritma, Sonra Kod

  • Kod, çözüm fikrinin belirli bir dildeki uygulamasıdır.
  • Algoritma kurulmadan yazılan kod gereksiz denemelere ve gizli hatalara yol açabilir.
  • Doğru sıra: problemi anla, örnek çöz, yöntemi yaz, sonra kodla.

Algoritma

İyi Algoritmanın Özellikleri

  • Adımlar açık, sıralı ve uygulanabilir olmalıdır.
  • Sonlu sayıda adım sonra durmalıdır.
  • Geçerli girdiler için doğru sonucu üretmelidir.
  • Kaynak kullanımı girdi boyutu büyüdüğünde kabul edilebilir olmalıdır.

Algoritma

Algoritma Tasarlama Döngüsü

  • Elle izlemede hata çıkarsa düzeltilir ve döngü yeniden döner; hata kalmayınca kodlamaya geçilir.
  • Birden fazla çözüm varsa doğruluk, okunabilirlik ve verimlilik karşılaştırılır.

Örnek: İki Sayıyı Sırala

oku a, b
eğer a > b ise
    gecici = a
    a = b
    b = gecici
yaz a, b
  • Eşit değerlerde değişim gerekmez.
  • Takas üç atamayla yapılır.
  • Çıktı için a ≤ b koşulu sağlanmalıdır.
Neden gecici değişkeni? Doğrudan a = b; b = a yazılırsa ilk atama a'nın eski değerini siler: a = 7, b = 3 için sonuç 3 3 olur.

İki Sayıyı Sırala Adım Adım (a = 7, b = 3)

Girdiler okunur: a = 7, b = 3. Hedef: küçük olan önce yazılsın.

Koşul: 7 > 3 → doğru → takas bloğuna girilir.

gecici = a = 7: a'nın değeri kaybolmasın diye önce yedeklenir.

a = b = 3. Eski 7 artık yalnızca gecici'de duruyor.

b = gecici = 7. Üç atamayla değerler yer değiştirdi.

Çıktı 3 7: a ≤ b sağlandı. (a = 2, b = 9 girilseydi koşul yanlış olur, 3–5. satırlar atlanırdı.)

Faktöriyel Adım Adım (n = 5)

n = 5 okunur. Beklenen: 5! = 1×2×3×4×5.

Koşul: 5 < 0 → yanlış; hata yok, devam.

Çarpım için başlangıç değeri 1 (0 olsaydı her şey 0 çıkardı).

i = 2: 1 ile çarpmak değeri değiştirmez, 2'den başlanır.

Koşul: 2 ≤ 5 → doğru.

sonuc = 1 × 2 = 2 (= 2!).

i = 3.

Koşul: 3 ≤ 5 → doğru.

sonuc = 2 × 3 = 6 (= 3!).

i = 4.

Koşul: 4 ≤ 5 → doğru.

sonuc = 6 × 4 = 24 (= 4!).

i = 5.

Koşul: 5 ≤ 5 → doğru.

sonuc = 24 × 5 = 120 (= 5!).

i = 6.

Koşul: 6 ≤ 5 → yanlış → döngü biter.

120 yazılır. Döngü n − 1 = 4 kez döndü.

Palindrom Adım Adım ("Kayak")

Metin okunur: "Kayak". İlk harf büyük.

Kural: küçük harfe çevir, boşlukları at → "kayak". Yoksa K ≠ k sanılırdı.

İki uç: sol = 0, sag = 4.

Koşul: 0 < 4 → doğru.

metin[0] = 'k', metin[4] = 'k' → aynı, devam.

İçe doğru bir adım: sol = 1, sag = 3.

Koşul: 1 < 3 → doğru.

metin[1] = 'a', metin[3] = 'a' → aynı, devam.

İçe doğru bir adım: sol = 2, sag = 2.

Koşul: 2 < 2 → yanlış: ortaya gelindi, döngü biter.

Farklı çift bulunmadı → doğru: "Kayak" bir palindromdur. 5 harf için yalnızca 2 karşılaştırma yapıldı.

Örnek: Asal Sayı

oku n
eğer n < 2 ise "asal değil" yaz ve dur
i = 2
i × i ≤ n iken
    eğer n % i == 0 ise "asal değil" yaz ve dur
    i = i + 1
"asal" yaz
  • Bir bölen bulununca arama durur.
  • Karekök sınırı: n = a × b ise a ve b'nin ikisi birden √n'den büyük olamaz; küçük bölen varsa i × i ≤ n aralığında bulunur.
  • % işlemi bölümden kalanı verir.

Örnekler · Adım adım izleme

Asal Sayı Adım Adım (n = 29)

n = 29 okunur.

29 < 2 → yanlış; 0 ve 1 değil, devam.

i = 2: ilk aday bölen.

Koşul: 2×2 = 4 ≤ 29 → doğru.

29 % 2 = 1 → sıfır değil, i bölen değil.

i = 3.

Koşul: 3×3 = 9 ≤ 29 → doğru.

29 % 3 = 2 → sıfır değil, i bölen değil.

i = 4.

Koşul: 4×4 = 16 ≤ 29 → doğru.

29 % 4 = 1 → sıfır değil, i bölen değil.

i = 5.

Koşul: 5×5 = 25 ≤ 29 → doğru.

29 % 5 = 4 → sıfır değil, i bölen değil.

i = 6.

Koşul: 6×6 = 36 ≤ 29 → yanlış: i artık √29'yi geçti, aramaya gerek yok.

Bölen bulunmadı → asal. Yalnızca 4 bölen denendi (2…28 yerine). n = 21 olsaydı i = 3'te 21 % 3 = 0 → asal değil.

Doğrusal Arama

int ara(int[] dizi, int hedef) {
    for (int i = 0; i < dizi.length; i++) {
        if (dizi[i] == hedef) return i;
    }
    return -1;
}
  • Öğeler baştan sona karşılaştırılır; verinin sıralı olması gerekmez.
  • İlk eşleşmede sonlanır, bulunamazsa -1 döndürür.
  • En kötü durumda n öğe incelenir: O(n).

Kod Java ile yazıldı; söz dizimi Bölüm 5–10'da ayrıntılı işlenecek. Şimdilik adımların mantığına odaklanın.

ara(dizi, 5) çağrıldı. Dizi sıralı değil; baştan tek tek bakılacak.

i = 0: 0 < 5 → doğru.

dizi[0] = 7 == 5 → yanlış.

i = 1: 1 < 5 → doğru.

dizi[1] = 3 == 5 → yanlış.

i = 2: 2 < 5 → doğru.

dizi[2] = 9 == 5 → yanlış.

i = 3: 3 < 5 → doğru.

dizi[3] = 5 == 5 → doğru → return 3. 4 karşılaştırma yapıldı; hedef 4 olsaydı 5 karşılaştırmadan sonra -1 dönerdi.

İkili Arama

int ikiliAra(int[] dizi, int hedef) {
    int sol = 0, sag = dizi.length - 1;
    while (sol <= sag) {
        int orta = sol + (sag - sol) / 2;
        if (dizi[orta] == hedef) return orta;
        if (dizi[orta] < hedef) sol = orta + 1;
        else sag = orta - 1;
    }
    return -1;
}
  • Yalnızca sıralı veri üzerinde çalışır; her adımda aralığı yarıya indirir.
  • En kötü durumda ⌊log₂ n⌋ + 1 tur: O(log n).
  • sol + (sag - sol) / 2, (sol + sag) / 2 ile aynı sonucu verir ama çok büyük indislerde taşmaz.
  • Tek arama için önce sıralama yapmak toplam maliyeti artırabilir.

Arama · Kodu adım adım çalıştır

İkili Arama Adım Adım (hedef = 34)

Arama aralığı tüm dizi: sol = 0, sag = 8.

0 ≤ 8 → doğru: aralık boş değil, 1. tur.

orta = 0 + (8 − 0) / 2 = 4, dizi[4] = 21.

21 == 34 → yanlış.

21 < 34 → hedef sağ yarıda: sol = 5. Sol yarı elendi.

5 ≤ 8 → doğru: aralık boş değil, 2. tur.

orta = 5 + (8 − 5) / 2 = 6, dizi[6] = 30.

30 == 34 → yanlış.

30 < 34 → hedef sağ yarıda: sol = 7. Sol yarı elendi.

7 ≤ 8 → doğru: aralık boş değil, 3. tur.

orta = 7 + (8 − 7) / 2 = 7, dizi[7] = 34.

34 == 34 → return 7. 3 turda bulundu; doğrusal arama 8 karşılaştırma yapardı.

int ikiliAra(int[] dizi, int hedef) {
    int sol = 0, sag = dizi.length - 1;
    while (sol <= sag) {
        int orta = sol + (sag - sol) / 2;
        if (dizi[orta] == hedef) return orta;
        if (dizi[orta] < hedef) sol = orta + 1;
        else sag = orta - 1;
    }
    return -1;
}

İkili Arama: Hedef Bulunamadı (hedef = 19)

Arama aralığı tüm dizi: sol = 0, sag = 7. Aranan 19 dizide yok (17 ile 21 arasında olurdu).

0 ≤ 7 → doğru: aralık boş değil, 1. tur.

orta = 0 + (7 − 0) / 2 = 3, dizi[3] = 17.

17 == 19 → yanlış.

17 < 19 → doğru: hedef sağ yarıda olabilir, sol = 4. Sol yarı elendi.

4 ≤ 7 → doğru: aralık boş değil, 2. tur.

orta = 4 + (7 − 4) / 2 = 5, dizi[5] = 25.

25 == 19 → yanlış.

25 < 19 → yanlış, else: hedef sol yarıda olabilir, sag = 4. Sağ yarı elendi.

4 ≤ 4 → doğru: aralık boş değil, 3. tur.

orta = 4 + (4 − 4) / 2 = 4, dizi[4] = 21.

21 == 19 → yanlış.

21 < 19 → yanlış, else: hedef sol yarıda olabilir, sag = 3. Sağ yarı elendi.

4 ≤ 3 → yanlış: sol, sag’ı geçti; aralık boş, döngü biter.

return -1: hedef bulunamadı. 3 turda aralık boşaldı; 8 öğenin hepsine tek tek bakılmadı.

int ikiliAra(int[] dizi, int hedef) {
    int sol = 0, sag = dizi.length - 1;
    while (sol <= sag) {
        int orta = sol + (sag - sol) / 2;
        if (dizi[orta] == hedef) return orta;
        if (dizi[orta] < hedef) sol = orta + 1;
        else sag = orta - 1;
    }
    return -1;
}

Kabarcık Sıralaması

  • Komşu öğeleri karşılaştırır ve yanlış sıradaysa yer değiştirir.
  • Her turda kalanların en büyüğü sona taşınır; sonraki tur bir öğe kısa olur.
  • Bir turda hiç değişim olmazsa dizi sıralıdır, durulur.
  • Genel durumda O(n²); zaten sıralı dizide tek tur: O(n).

Eklemeli Sıralama (Insertion Sort)

  • Elde iskambil kâğıdı dizmeye benzer: soldaki bölüm hep sıralıdır.
  • Sıradaki öğe (anahtar) alınır; ondan büyükler birer sağa kaydırılır, anahtar açılan boşluğa konur.
  • En kötü durumda (ters sıralı) O(n²); zaten sıralı dizide her anahtar için tek karşılaştırma: O(n). Ek bellek O(1).
  • Az sayıda ve neredeyse sıralı veride çok hızlıdır.
i = 1'den n-1'e kadar
    anahtar = dizi[i]
    j = i - 1
    j >= 0 ve dizi[j] > anahtar iken
        dizi[j+1] = dizi[j]
        j = j - 1
    dizi[j+1] = anahtar
