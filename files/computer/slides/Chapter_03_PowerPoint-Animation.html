Animation Pane

    PowerPoint: Animation Timeline

    Goal: See, in the animation pane and on the timeline, which click starts each animation on a slide and how many seconds after the click it begins.

    How to use it

    1. Pick an object and an effect type, then press Add Animation (Entrance: the object appears, Emphasis: draws attention to a visible object, Exit: the object disappears).
    2. Select an effect in the pane and change Start, Duration and Delay; reorder with ▲/▼. The small numbers on the slide show which click starts each effect (0: automatically when the slide opens).
    3. ▶ Restart starts the show, Click is the presenter's click (the → key or the space bar works too). The blue line on the timeline is the current time.
    4. Try it yourself: you get a random animation list; the timeline is hidden, so answer the question (use a decimal point, e.g. 1.25).

    Timing rules

    StartWhen does it begin?
    On ClickWhen the presenter clicks: opens a new click group (time 0).
    With PreviousAt the same time as the previous effect (from the same start point, plus its own delay).
    After PreviousWhen the previous effect(s) finish; then it waits for its own delay.
    • Start = start point + delay; end = start + duration.
    • If the first effect in the list is not On Click, it plays by itself as soon as the slide opens. Clicks needed = number of On Click effects; the click after the last animation moves to the next slide.
    • An object whose first effect is an Entrance is invisible when the slide opens; an object with no animation is visible from the start.
    • Effect names (e.g. Appear, Fly In) vary between versions, so only the types are used here.
