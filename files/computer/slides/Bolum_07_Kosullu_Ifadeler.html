Akış

Sıralı, seçmeli ve tekrarlı akışı ayırt etmek.

Koşul

Karşılaştırma ve mantık operatörleriyle koşul yazmak.

Karar

if, else if ve else yapılarını doğru sırada kurmak.

switch

Ayrık seçeneklerde switch kullanmak.

Temeller

Üç Temel Akış

  • Sıralı yapı deyimleri yazıldığı sırada yürütür; karar yapısı koşula göre farklı yol seçer.
  • Döngü yapısı bir kod bloğunu tekrarlar (Bölüm 8).
  • Bu üç yapı her algoritmanın temel yürütme modelini oluşturur.

Temeller

Sıralı İşlemler

double taban = 8;
double yükseklik = 5;
double alan = taban * yükseklik / 2;
System.out.println(alan);
  • Her deyim bir öncekinin ürettiği değeri kullanabilir.
  • Sıra değiştirilirse tanımsız veya yanlış değer oluşabilir.

Temeller · Kodu adım adım çalıştır

Sıralı İşlemler Adım Adım

taban = 8 → double kutuya 8.0 olarak yazılır (genişletme).

yükseklik = 5.0.

Soldan sağa: önce taban * yükseklik = 40.0.

40.0 / 2 = 20.0 → alan kutusuna yazılır. Bu satır önceki iki kutunun değerini kullanır.

20.0 yazdırılır. Satır 3, satır 1'den önce olsaydı taban henüz tanımsız olurdu → derleme hatası.

double taban = 8;
double yükseklik = 5;
double alan = taban * yükseklik / 2;
System.out.println(alan);

Kararlar

Karar Verme

  • Koşul boolean değer üretir.
  • if doğru yolu, else yanlış yolu tanımlar.
  • Bağımsız if'lerin hepsi denetlenir; else-if zincirinde ilk doğru dal çalışınca gerisi atlanır.
  • Örnek: not = 95. Sağda iki yazımın farklı sonucu.

Kararlar

if-else Yapısı

if (not >= 60) {
    System.out.println("Geçti");
} else {
    System.out.println("Kaldı");
}
  • Sınır değeri koşulun parçasıdır: 60 → Geçti.
  • Her olası değer yalnızca bir dala gider.

Kararlar · Kodu adım adım çalıştır

if-else Adım Adım: not = 75, 60, 45

1. çalıştırma: kullanıcı 75 girer.

Koşul: not >= 60 → 75 >= 60 → true.

true dalı çalışır: Geçti. Diğer dal (else bloğu) atlanır.

2. çalıştırma: kullanıcı 60 girer.

Koşul: not >= 60 → 60 >= 60 → true. Sınır değeri dahil: >=.

true dalı çalışır: Geçti. Diğer dal (else bloğu) atlanır.

3. çalıştırma: kullanıcı 45 girer.

Koşul: not >= 60 → 45 >= 60 → false.

false dalı çalışır: Kaldı. Diğer dal (if bloğu) atlanır.

Scanner klavye = new Scanner(System.in);
int not = klavye.nextInt();
if (not >= 60) {
    System.out.println("Geçti");
} else {
    System.out.println("Kaldı");
}

Kararlar

Çok Yollu Karar: else-if

if (not >= 90) {
    harf = 'A';
} else if (not >= 80) {
    harf = 'B';
} else if (not >= 70) {
    harf = 'C';
} else {
    harf = 'F';
}
  • Koşullar yukarıdan aşağı değerlendirilir; ilk true dal çalışır, gerisi atlanır.
  • Yüksek eşikler önce yazılır: not >= 70 başa yazılsaydı 95 de C alırdı.
  • else hiçbir koşul tutmadığında çalışır.

Kararlar · Kodu adım adım çalıştır

else-if Zinciri: not = 75, 95, 50

1. çalıştırma: not = 75. harf tanımlandı, henüz değeri yok.

1. koşul: not >= 90 → 75 >= 90 → false. Sonraki koşula geçilir.

2. koşul: not >= 80 → 75 >= 80 → false. Sonraki koşula geçilir.

3. koşul: not >= 70 → 75 >= 70 → true. Bu dal seçilir.

harf = 'C'. Zincirin geri kalanı denetlenmeden atlanır.

C yazdırılır.

2. çalıştırma: not = 95. harf tanımlandı, henüz değeri yok.

1. koşul: not >= 90 → 95 >= 90 → true. Bu dal seçilir.

harf = 'A'. Zincirin geri kalanı denetlenmeden atlanır.

A yazdırılır.

3. çalıştırma: not = 50. harf tanımlandı, henüz değeri yok.

1. koşul: not >= 90 → 50 >= 90 → false. Sonraki koşula geçilir.

2. koşul: not >= 80 → 50 >= 80 → false. Sonraki koşula geçilir.

3. koşul: not >= 70 → 50 >= 70 → false. Sonraki koşula geçilir.

Hiçbir koşul tutmadı → else: harf = 'F'.

F yazdırılır.

int not = klavye.nextInt();
char harf;
if (not >= 90)      harf = 'A';
else if (not >= 80) harf = 'B';
else if (not >= 70) harf = 'C';
else                harf = 'F';
System.out.println(harf);

Tek deyimli dallarda süslü parantez yazılmayabilir; zincir önceki slayttakiyle aynıdır.

Kararlar

İç İçe Kararlar

  • Bir karar dalı içinde başka karar bulunabilir: iç koşul yalnızca dış koşul true olduğunda denetlenir.
  • İç içe yapı, ikinci sorunun ancak ilk koşul sağlandığında anlamlı olduğu durumlar içindir.
  • Derin iç içelik okunabilirliği azaltır; koşullar && ile birleştirilebilir.

Kararlar · Kodu adım adım çalıştır

İç İçe Karar: 3 farklı girdi

1. çalıştırma: yaş = 20, ehliyet = true.

Dış koşul: yaş >= 18 → 20 >= 18 → true. İç if'e girilir.

İç koşul: ehliyet → true.

Araç kullanabilir yazdırılır.

2. çalıştırma: yaş = 20, ehliyet = false.

Dış koşul: yaş >= 18 → 20 >= 18 → true. İç if'e girilir.

İç koşul: ehliyet → false.

Önce ehliyet almalı yazdırılır.

3. çalıştırma: yaş = 15, ehliyet = true.

Dış koşul: 15 >= 18 → false. İç if hiç denetlenmez; ehliyet true olsa bile önemsizdir.

Dış else çalışır: Yaş yetersiz.

int yaş = klavye.nextInt();
boolean ehliyet = klavye.nextBoolean();
if (yaş >= 18) {
  if (ehliyet)
    System.out.println("Araç kullanabilir");
  else
    System.out.println("Önce ehliyet almalı");
} else {
  System.out.println("Yaş yetersiz");
}

Kararlar

Mantıksal Operatörlerle Karar

boolean uygun = yaş >= 18 && belgeVar;
if (uygun) {
    System.out.println("Başvuru alınabilir");
}
  • && iki koşulun da doğru olmasını ister.
  • || seçeneklerden en az birinin doğru olmasını ister.

Kararlar · Kodu adım adım çalıştır

&& ile Karar: 3 farklı girdi

1. çalıştırma: yaş = 20, belgeVar = true.

20 >= 18 → true; sağ taraf gerekli: belgeVar → true. true && true → true.

Başvuru alınabilir yazdırılır.

2. çalıştırma: yaş = 20, belgeVar = false.

20 >= 18 → true; sağ taraf gerekli: belgeVar → false. true && false → false.

uygun false → blok atlanır, çıktı yok.

3. çalıştırma: yaş = 16, belgeVar = true.

16 >= 18 → false. Kısa devre: belgeVar okunmaz, sonuç kesin false.

uygun false → blok atlanır, çıktı yok.

int yaş = klavye.nextInt();
boolean belgeVar = klavye.nextBoolean();
boolean uygun = yaş >= 18 && belgeVar;
if (uygun) {
    System.out.println("Başvuru alınabilir");
}

switch

switch Ne Zaman?

  • Tek bir ifadenin ayrık değerlerine göre seçim yaparken okunabilirdir.
  • case etiketleri sabit seçenekleri temsil eder; eşleşen case'e doğrudan gidilir.
  • Aralık ve karmaşık mantıksal koşullarda if-else çoğunlukla daha uygundur.

switch

switch İfadesi

String mevsim = switch (ay) {
    case 12, 1, 2 -> "Kış";
    case 3, 4, 5 -> "İlkbahar";
    case 6, 7, 8 -> "Yaz";
    case 9, 10, 11 -> "Sonbahar";
    default -> "Geçersiz";
};
  • Ok biçimi yanlışlıkla sonraki case'e geçişi önler.
  • default beklenmeyen değerleri ele alır. Bu yazım Java 14 ve sonrası içindir.

switch · Kodu adım adım çalıştır

switch İfadesi: ay = 4, 12, 13

1. çalıştırma: ay = 4.

switch (ay) → 4: 4 bu case'in listesinde. Seçilen dalın değeri: "İlkbahar".

switch ifadesinin ürettiği değer mevsim'e atanır: mevsim = "İlkbahar". Başka case çalışmaz.

İlkbahar yazdırılır.

2. çalıştırma: ay = 12.

switch (ay) → 12: 12 bu case'in listesinde. Seçilen dalın değeri: "Kış".

switch ifadesinin ürettiği değer mevsim'e atanır: mevsim = "Kış". Başka case çalışmaz.

Kış yazdırılır.

3. çalıştırma: ay = 13.

switch (ay) → 13: 13 hiçbir case'te yok → default. Seçilen dalın değeri: "Geçersiz".

switch ifadesinin ürettiği değer mevsim'e atanır: mevsim = "Geçersiz". Başka case çalışmaz.

Geçersiz yazdırılır.

int ay = klavye.nextInt();
String mevsim = switch (ay) {
    case 12, 1, 2 -> "Kış";
    case 3, 4, 5 -> "İlkbahar";
    case 6, 7, 8 -> "Yaz";
    case 9, 10, 11 -> "Sonbahar";
    default -> "Geçersiz";
};
System.out.println(mevsim);

switch · Kodu adım adım çalıştır

Klasik switch: break Unutulursa

gün = 2.

switch (gün) → 2: doğrudan case 2 etiketine atlanır; case 1 hiç denetlenmez.

"Salı" yazdırılır. Bu case'te break yok!

Düşme (fall-through): etiket denetlenmeden sonraki case'in kodu da çalışır → "Çar".

break switch'ten çıkarır; default çalışmaz. Ok (->) biçimi bu hatayı önler.

int gün = 2;
switch (gün) {
  case 1: System.out.println("Pzt"); break;
  case 2: System.out.println("Salı");
  case 3: System.out.println("Çar"); break;
  default: System.out.println("Yok");
}

Örnek

Tek mi Çift mi?

int sayı = 17;
if (sayı % 2 == 0)
    System.out.println("Çift");
else
    System.out.println("Tek");
  • 2 ile bölümden kalan 0 ise sayı çifttir.
  • Negatiflerde de doğru çalışır. Ama Java'da -7 % 2 = -1 olduğundan tek sayıyı sayı % 2 == 1 ile sınamak yanlıştır.

Örnek · Kodu adım adım çalıştır

Tek mi Çift mi? sayı = 17, −4, −7

1. çalıştırma: sayı = 17.

Önce kalan: 17 % 2 = 1.

1 == 0 → false.

Tek yazdırılır.

2. çalıştırma: sayı = -4.

Önce kalan: -4 % 2 = 0.

0 == 0 → true.

Çift yazdırılır.

3. çalıştırma: sayı = -7.

Önce kalan: -7 % 2 = -1 (Java'da kalanın işareti bölünenin işaretidir).

-1 == 0 → false.

Tek yazdırılır. Dikkat: -7 % 2 == 1 → false olurdu!

int sayı = klavye.nextInt();
if (sayı % 2 == 0)
    System.out.println("Çift");
else
    System.out.println("Tek");

Örnek

Mutlak Değer

int sayı = -8;
if (sayı < 0) {
    sayı = -sayı;
}
System.out.println(sayı);
  • Sıfır ve pozitif değer değişmeden kalır.
  • Integer.MIN_VALUE özel bir taşma durumudur.

Örnek · Kodu adım adım çalıştır

Mutlak Değer: sayı = −8, 5, MIN_VALUE

1. çalıştırma: sayı = -8.

Koşul: sayı < 0 → -8 < 0 → true.

sayı = -sayı → -(-8) = 8.

8 yazdırılır.

2. çalıştırma: sayı = 5.

Koşul: sayı < 0 → 5 < 0 → false. Blok atlanır, değer değişmez.

5 yazdırılır.

3. çalıştırma: sayı = -2147483648 (Integer.MIN_VALUE).

Koşul: sayı < 0 → -2147483648 < 0 → true.

-(-2147483648) = 2147483648 int aralığına sığmaz → taşma: sonuç yine -2147483648!

-2147483648 yazdırılır. Mutlak değer negatif çıktı: özel durum.

int sayı = klavye.nextInt();
if (sayı < 0) {
    sayı = -sayı;
}
System.out.println(sayı);

Özet

Bölüm Özeti

  • Sıralı yapı deyimleri yazıldığı sırada yürütür; karar yapısı koşula göre yol seçer.
  • Koşul her zaman boolean bir değer üretmelidir.
  • else-if zincirinde koşullar yukarıdan aşağı denenir; ilk doğru dal çalışır.
  • Aralık ve karmaşık koşullarda if-else, tek değerin ayrık seçeneklerinde switch uygundur.

Özet

Kontrol Soruları

  1. Bağımsız if yapıları ile else-if zinciri nasıl farklıdır?
  2. Not harf dönüşümünde eşikler neden büyükten küçüğe yazılır?
  3. İç içe karar yerine && ne zaman kullanılabilir?
  4. switch için default neden yararlıdır?
  5. Bir sayının çift olduğu hangi koşulla anlaşılır?
