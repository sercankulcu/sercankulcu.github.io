Öğrenme Çıktıları

Yapı

Temel durum ve özyinelemeli adımı belirlemek.

İzleme

Çağrı yığınını adım adım takip etmek.

Karşılaştırma

Özyineleme ile döngüyü değerlendirmek.

İyileştirme

Tekrarlı hesaplamayı memoization ile azaltmak.

Temeller

Özyineleme Nedir?

  • Bir metodun problemi daha küçük bir örneğine indirip kendisini çağırmasıdır.
  • Her çağrı kendi parametre ve yerel değişkenleriyle ayrı bir yığın çerçevesi oluşturur.
  • Problem her çağrıda temel duruma yaklaşmalıdır; yoksa çağrılar sonlanmaz.

Temeller

İki Zorunlu Parça

Temel durum

Sonucun doğrudan bilindiği, yeni çağrı yapılmayan durum (ör. n ≤ 1 → 1).

Özyinelemeli adım

Problemi daha küçük örneğe dönüştüren çağrı (ör. n × f(n − 1)).

Örnekler

Özyinelemeli Faktöriyel

static long faktoriyel(int n) {
    if (n < 0)
        throw new IllegalArgumentException();
    if (n <= 1) return 1;
    return n * faktoriyel(n - 1);
}
Tanım

n! = n × (n − 1)!, 0! = 1! = 1

Temel durum

n ≤ 1 → 1; her çağrıda n bir azalır.

Negatif n

Faktöriyel tanımsız → hata fırlatılır.

Çağrı Yığını · Kodu adım adım çalıştır

Kod İzleme: faktoriyel(4)

main, faktoriyel(4)'ü çağırır; sonucu bekler.

Yeni çerçeve: n = 4. 4 < 0 → false, 4 <= 1 → false.

4 * faktoriyel(3): çarpma için önce alt sonuç gerekli → bu çerçeve bekler, yeni çağrı yapılır.

Yeni çerçeve: n = 3. 3 < 0 → false, 3 <= 1 → false.

3 * faktoriyel(2): çarpma için önce alt sonuç gerekli → bu çerçeve bekler, yeni çağrı yapılır.

Yeni çerçeve: n = 2. 2 < 0 → false, 2 <= 1 → false.

2 * faktoriyel(1): çarpma için önce alt sonuç gerekli → bu çerçeve bekler, yeni çağrı yapılır.

Yeni çerçeve: n = 1. 1 < 0 → false, 1 <= 1 → true: temel durum, return 1.

faktoriyel(1) 1 döndürdü; çerçevesi silindi. Şimdi 2 × 1 = 2.

faktoriyel(2) 2 döndürdü; çerçevesi silindi. Şimdi 3 × 2 = 6.

faktoriyel(3) 6 döndürdü; çerçevesi silindi. Şimdi 4 × 6 = 24.

En üstteki çerçeve de kapandı; main 24 yazdırır. En fazla 5 çerçeve açıktı → ek bellek O(n).

static long faktoriyel(int n) {
    if (n < 0)
        throw new IllegalArgumentException();
    if (n <= 1) return 1;
    return n * faktoriyel(n - 1);
}
System.out.println(faktoriyel(4));

Çağrı Yığını

faktoriyel(4): Açılım ve Dönüş

  • Çağrılar temel duruma ulaşıncaya kadar yığında açılır; hiçbir çarpma henüz yapılmamıştır.
  • f(1) = 1 döndükten sonra bekleyen çarpımlar ters sırada tamamlanır: 2, 6, 24.

Örnekler · Kodu adım adım çalıştır

1'den n'e Toplam: toplam(3)

Tanım: toplam(n) = n + toplam(n − 1), toplam(0) = 0. main, toplam(3)'ü çağırır.

3 <= 0 → false.

3 + toplam(2): toplama bekler, yeni çağrı.

2 <= 0 → false.

2 + toplam(1): toplama bekler, yeni çağrı.

1 <= 0 → false.

1 + toplam(0): toplama bekler, yeni çağrı.

0 <= 0 → true: temel durum, return 0.

toplam(0) = 0 döndü → 1 + 0 = 1.

toplam(1) = 1 döndü → 2 + 1 = 3.

toplam(2) = 3 döndü → 3 + 3 = 6.

6 = 3 + 2 + 1 + 0 yazdırılır.

static int toplam(int n) {
    if (n <= 0) return 0;
    return n + toplam(n - 1);
}
System.out.println(toplam(3));

Örnekler · Kodu adım adım çalıştır

Rakamlar Toplamı: rakamToplami(472)

main, rakamToplami(472)'yi çağırır.

Negatif sayılar için mutlak değer alınır: m = 472 (long'a çevirmek en küçük int'te taşmayı önler).

Asıl işi yapan yardımcı metot çağrılır.

472 < 10 → false: son rakam 2, kalan 47.

472 % 10 = 2 bekletilir; 472 / 10 = 47 ile yeni çağrı.

47 < 10 → false: son rakam 7, kalan 4.

47 % 10 = 7 bekletilir; 47 / 10 = 4 ile yeni çağrı.

4 < 10 → true: tek basamak, return 4.

Alt çağrı 4 döndü → 7 + 4 = 11.

Alt çağrı 11 döndü → 2 + 11 = 13.

Yardımcı metot 13 döndürdü; aynen döndürülür.

4 + 7 + 2 = 13 yazdırılır.

static int rakamToplami(int n) {
    long m = Math.abs((long) n);
    return rakamToplamiPozitif(m);
}
static int rakamToplamiPozitif(long n) {
    if (n < 10) return (int) n;
    return (int) (n % 10)
        + rakamToplamiPozitif(n / 10);
}
System.out.println(rakamToplami(472));

Örnekler · Kodu adım adım çalıştır

Palindrom: palindrom("kayak", 0, 4)

main, palindrom("kayak", 0, 4)'ü çağırır.

0 >= 4 → false.

'k' != 'k' → false: uçlar eşit, içe doğru devam.

İki uç atılır: palindrom(s, 1, 3) çağrılır.

1 >= 3 → false.

'a' != 'a' → false: uçlar eşit, içe doğru devam.

İki uç atılır: palindrom(s, 2, 2) çağrılır.

2 >= 2 → true: ortada tek karakter kaldı → return true.

Alt çağrı true döndürdü; bu çerçeve de aynı değeri döndürür.

Alt çağrı true döndürdü; bu çerçeve de aynı değeri döndürür.

Sonuç main'e ulaştı: true. "kayak" tersten de aynı okunur.

static boolean palindrom(String s,
                         int sol, int sag) {
    if (sol >= sag) return true;
    if (s.charAt(sol) != s.charAt(sag))
        return false;
    return palindrom(s, sol + 1, sag - 1);
}
System.out.println(palindrom("kayak", 0, 4));

Örnekler · Kodu adım adım çalıştır

Öklid ile EBOB: ebob(48, 18)

main, ebob(48, 18)'i çağırır.

18 == 0 → false.

48 % 18 = 12 → ebob(18, 12) çağrılır (sayılar küçülüyor).

12 == 0 → false.

18 % 12 = 6 → ebob(12, 6) çağrılır (sayılar küçülüyor).

6 == 0 → false.

12 % 6 = 0 → ebob(6, 0) çağrılır (sayılar küçülüyor).

0 == 0 → true: temel durum, return 6.

Alt çağrı 6 döndürdü; aynen döndürülür.

Alt çağrı 6 döndürdü; aynen döndürülür.

Alt çağrı 6 döndürdü; aynen döndürülür.

EBOB(48, 18) = 6: kalanlar küçülerek 0'a ulaştı; son sıfır olmayan kalan EBOB'dur.

static int ebob(int a, int b) {
    if (b == 0) return Math.abs(a);
    return ebob(b, a % b);
}
System.out.println(ebob(48, 18));

Örnekler · Kodu adım adım çalıştır

Hanoi Kuleleri: hanoi(3, 'A', 'C', 'B')

3 disk A'dan C'ye taşınacak; B yardımcı. Kural: büyük disk küçüğün üstüne konamaz.

hanoi(3, A, C, B): önce üstteki 2 disk A → B (yardımcıya) taşınmalı.

hanoi(2, A, B, C): önce üstteki 1 disk A → C (yardımcıya) taşınmalı.

Hamle 1: disk 1 A → C. (hanoi(0) çağrıları hemen döner)

Hamle 2: disk 2 A → B.

Hamle 3: disk 1 C → B.

Hamle 4: disk 3 A → C.

hanoi(2, B, C, A): önce üstteki 1 disk B → A (yardımcıya) taşınmalı.

Hamle 5: disk 1 B → A.

Hamle 6: disk 2 B → C.

Hamle 7: disk 1 A → C.

Bitti: 7 = 2³ − 1 hamle. n disk için 2ⁿ − 1 hamle gerekir (üstel).

static void hanoi(int n, char kaynak,
                  char hedef, char ara) {
  if (n == 0) return;
  hanoi(n - 1, kaynak, ara, hedef);
  System.out.print(kaynak + "->" + hedef + " ");
  hanoi(n - 1, ara, hedef, kaynak);
}
hanoi(3, 'A', 'C', 'B');

Örnekler · Kodu adım adım çalıştır

Özyinelemeli Üs: us(2, 4)

2⁴ = 2 × 2³ tanımı: us(taban, n) = taban × us(taban, n − 1), us(taban, 0) = 1.

4 == 0 → false: 2 × us(2, 3) için yeni çağrı.

3 == 0 → false: 2 × us(2, 2) için yeni çağrı.

2 == 0 → false: 2 × us(2, 1) için yeni çağrı.

1 == 0 → false: 2 × us(2, 0) için yeni çağrı.

0 == 0 → true: temel durum, return 1.

us(2, 0) = 1 döndü → 2 × 1 = 2.

us(2, 1) = 2 döndü → 2 × 2 = 4.

us(2, 2) = 4 döndü → 2 × 4 = 8.

us(2, 3) = 8 döndü → 2 × 8 = 16.

16: n + 1 = 5 çağrı → O(n).

static long us(long taban, int n) {
  if (n == 0) return 1;
  return taban * us(taban, n - 1);
}
System.out.println(us(2, 4));

Örnekler · Kodu adım adım çalıştır

Hızlı Üs: hizliUs(2, 10)

Fikir: 2¹⁰ = (2⁵)², 2⁵ = (2²)² × 2. Üs her çağrıda yarıya iner.

us = 10 ≠ 0 → önce hizliUs(2, 5) (10 / 2 = 5).

us = 5 ≠ 0 → önce hizliUs(2, 2) (5 / 2 = 2).

us = 2 ≠ 0 → önce hizliUs(2, 1) (2 / 2 = 1).

us = 1 ≠ 0 → önce hizliUs(2, 0) (1 / 2 = 0).

us == 0: return 1.

yarim = 1; 1 tek → 1 × 1 × 2 = 2.

yarim = 2; 2 çift → 2 × 2 = 4.

yarim = 4; 5 tek → 4 × 4 × 2 = 32.

yarim = 32; 10 çift → 32 × 32 = 1024.

1024, yalnızca 5 çağrıyla (düz yöntem 11 çağrı yapardı) → O(log n).

static long hizliUs(long taban, int us) {
  if (us == 0) return 1;
  long yarim = hizliUs(taban, us / 2);
  if (us % 2 == 0) return yarim * yarim;
  return yarim * yarim * taban;
}
System.out.println(hizliUs(2, 10));

Örnekler · Kodu adım adım çalıştır

Özyinelemeli İkili Arama: ara(a, 38, 0, 7)

Döngü yerine özyineleme: her çağrı aralığın yarısıyla kendini çağırır.

0 <= 7; mid = 3, a[mid] = 12.

12 < 38 → sağ yarı: ara(a, 38, 4, 7).

4 <= 7; mid = 5, a[mid] = 23.

23 < 38 → sağ yarı: ara(a, 38, 6, 7).

6 <= 7; mid = 6, a[mid] = 38.

38 == 38 → return 6 (temel durum).

Sonuç çerçevelerden aynen geri geçer: 6.

static int ara(int[] a, int x,
               int lo, int hi) {
  if (lo > hi) return -1;
  int mid = (lo + hi) / 2;
  if (a[mid] == x) return mid;
  if (a[mid] < x) return ara(a, x, mid + 1, hi);
  return ara(a, x, lo, mid - 1);
}
// a = {2, 5, 8, 12, 16, 23, 38, 56}
System.out.println(ara(a, 38, 0, 7));

Örnekler · Kodu adım adım çalıştır

Dizgiyi Özyinelemeli Ters Çevirme

ters(s) = ters(ilk karakter hariç kalan) + ilk karakter.

ters("bc") çağrılır; 'a' sona eklenmek üzere bekler.

ters("c") çağrılır; 'b' sona eklenmek üzere bekler.

Uzunluk 1 ≤ 1 → temel durum, "c" döner.

"c" + 'b' = "cb".

"cb" + 'a' = "cba".

cba yazdırılır. Her çağrı yeni bir substring üretir.

static String ters(String s) {
  if (s.length() <= 1) return s;
  return ters(s.substring(1)) + s.charAt(0);
}
System.out.println(ters("abc"));

Çağrı Yığını

Çağrı Yığını

  • Yeni çağrı yapıldığında mevcut metodun dönüş noktası ve yerel değişkenleri çerçevesinde saklanır.
  • Temel durumdan sonra çerçeveler ters sırada (son açılan ilk) kapanır.
  • Temel durum yoksa ya da çok derin özyinelemede yığın dolar: StackOverflowError.

Verimlilik

Özyineleme mi Döngü mü?

  • Kendine benzeyen problemlerde (ağaçlar, böl-parçala) özyineleme tanıma yakın ve açıktır.
  • Basit doğrusal tekrarlarda döngü tek çerçevede çalışır, daha az yığın belleği kullanır.
  • Seçim yalnızca kod kısalığına değil; doğruluk, okunabilirlik ve kaynak kullanımına dayanmalıdır.

Verimlilik · Kodu adım adım çalıştır

Karşılaştırma: Döngülü faktoriyel(4)

main, faktoriyelDongu(4)'ü çağırır.

Tek çerçeve açılır; sonuc = 1.

2 <= 4 → true

sonuc *= 2 → 1 × 2 = 2. Yeni çerçeve açılmadı.

i++ → 3 <= 4 → true

sonuc *= 3 → 2 × 3 = 6. Yeni çerçeve açılmadı.

i++ → 4 <= 4 → true

sonuc *= 4 → 6 × 4 = 24. Yeni çerçeve açılmadı.

i++ → 5 <= 4 → false: döngü biter.

return 24.

24 yazdırılır. Yığın hiç 2 çerçeveyi aşmadı → ek yığın O(1).

static long faktoriyelDongu(int n) {
    long sonuc = 1;
    for (int i = 2; i <= n; i++)
        sonuc *= i;
    return sonuc;
}
System.out.println(faktoriyelDongu(4));

Verimlilik

Fibonacci Sorunu: fib(5) Çağrı Ağacı

  • fib(5) için 15 çağrı yapılır: f(3) 2 kez, f(2) 3 kez, f(1) 5 kez hesaplanır (kesikli turuncu = tekrar).
  • fib(n − 1) ve fib(n − 2) alt ağaçları büyük ölçüde örtüşür; çağrı sayısı n ile yaklaşık üstel büyür.

Verimlilik · Kodu adım adım çalıştır

Kod İzleme: fib(4)

main, fib(4)'ü çağırır.

fib(4) çağrıldı: 4 <= 1 → false.

fib(3) çağrıldı: 3 <= 1 → false.

fib(2) çağrıldı: 2 <= 1 → false.

fib(1) çağrıldı: 1 <= 1 → true, return 1.

fib(0) çağrıldı: 0 <= 1 → true, return 0.

İki alt sonuç hazır: 1 + 0 = 1, return.

fib(1) çağrıldı: 1 <= 1 → true, return 1.

İki alt sonuç hazır: 1 + 1 = 2, return.

fib(2) çağrıldı: 2 <= 1 → false. Tekrar: f(2) yeniden hesaplanıyor!

fib(1) çağrıldı: 1 <= 1 → true, return 1.

fib(0) çağrıldı: 0 <= 1 → true, return 0.

İki alt sonuç hazır: 1 + 0 = 1, return.

İki alt sonuç hazır: 2 + 1 = 3, return.

3 yazdırılır. Küçük bir n için bile 9 çağrı yapıldı.

static long fib(int n) {
    if (n <= 1) return n;
    return fib(n - 1) + fib(n - 2);
}
System.out.println(fib(4));

İyileştirme

Memoization (Bellekleme)

  • Hesaplanan alt problem sonuçları bir dizide (önbellek) saklanır.
  • Aynı girdi tekrar gelince çağrı ağacı yeniden açılmaz, kayıtlı değer döner.
  • fib(5) için 15 çağrı yerine 9 çağrı; büyük n'de fark çok büyür.
  • Zaman kazanımı karşılığında O(n) ek bellek kullanılır.

İyileştirme · Kodu adım adım çalıştır

Kod İzleme: Belleklemeli fib(5)

6 hücreli bellek dizisi; 0 = henüz hesaplanmadı.

fib(5): bellek[5] == 0 → henüz yok, hesaplanacak.

fib(4): bellek[4] == 0 → henüz yok, hesaplanacak.

fib(3): bellek[3] == 0 → henüz yok, hesaplanacak.

fib(2): bellek[2] == 0 → henüz yok, hesaplanacak.

fib(1): 1 <= 1 → true, return 1.

fib(0): 0 <= 1 → true, return 0.

bellek[2] = 1 + 0 = 1 kaydedilir ve döndürülür.

fib(1): 1 <= 1 → true, return 1.

bellek[3] = 1 + 1 = 2 kaydedilir ve döndürülür.

fib(2): bellek[2] = 1 != 0 → hesaplamadan return 1.

bellek[4] = 2 + 1 = 3 kaydedilir ve döndürülür.

fib(3): bellek[3] = 2 != 0 → hesaplamadan return 2.

bellek[5] = 3 + 2 = 5 kaydedilir ve döndürülür.

5 yazdırılır. Toplam 9 çağrı (belleksiz 15) → zaman O(n).

static long fib(int n, long[] bellek) {
    if (n <= 1) return n;
    if (bellek[n] != 0) return bellek[n];
    bellek[n] = fib(n - 1, bellek)
              + fib(n - 2, bellek);
    return bellek[n];
}
long[] bellek = new long[6];
System.out.println(fib(5, bellek));

İyileştirme

Kuyruk Özyinelemesi

  • Özyinelemeli çağrı metodun son işlemidir; dönüşte yapılacak iş kalmaz.
  • Ara sonuç bir parametrede (birikim) taşınır.
  • Bazı diller bu çağrıları yığını büyütmeden optimize eder.
  • Java dili/JVM kuyruk çağrısı optimizasyonunu garanti etmez: çerçeveler yine birikir.
static long fakt(int n, long birikim) {
    if (n <= 1) return birikim;
    return fakt(n - 1, n * birikim);
}
// fakt(4, 1) → fakt(3, 4)
//   → fakt(2, 12) → fakt(1, 24) → 24

Özet

Bölüm Özeti

Yapı

Temel durum + probleme küçülten özyinelemeli adım.

Çağrı yığını

Her çağrı bir çerçeve açar; temel durumdan sonra çerçeveler ters sırada kapanır.

Maliyet

Doğrusal özyineleme O(n) yığın kullanır; döngü çoğu zaman O(1) ile aynı işi yapar.

Bellekleme

Tekrarlanan alt problem sonuçlarını saklamak fib'i üstelden O(n)'e indirir.

Özet

Kontrol Soruları

  1. Temel durum olmazsa ne olur?
  2. Çağrı yığını neden ters sırada çözülür?
  3. Özyinelemeli faktöriyel ne kadar ek yığın kullanır?
  4. Doğrudan Fibonacci neden yavaştır?
  5. Java'da kuyruk özyinelemesi neden yığın güvenliği sağlamaz?
Cevaplar
  1. Çağrılar sonlanmaz; yığın dolar ve StackOverflowError oluşur.
  2. Her çağrı, kendisinden sonra açılan çağrının sonucunu bekler; son açılan çerçeve ilk tamamlanır.
  3. n çerçeve → O(n).
  4. Aynı alt problemleri (f(2), f(3)…) tekrar tekrar hesaplar; çağrı sayısı üstel büyür.
  5. JVM kuyruk çağrılarını optimize etmeyi garanti etmez; her çağrı yine yeni çerçeve açar.

Özet

Alıştırmalar

  1. Bir dizinin elemanları toplamını özyinelemeli yazın: toplam(a, i) = a[i] + toplam(a, i + 1).
  2. Bir sayının basamak sayısını özyinelemeli bulun (basamak(472) = 3).
  3. Onluk sayıyı özyinelemeyle ikiliye çeviren ikili(n) metodunu yazın (13 → "1101").
  4. Hanoi'de n = 4 için kaç hamle gerekir? Programla doğrulayın.
  5. kombinasyon(n, k) = kombinasyon(n − 1, k − 1) + kombinasyon(n − 1, k) için temel durumları yazın; belleklemeyle hızlandırın.
  6. Bir dizgideki bir karakterin kaç kez geçtiğini özyinelemeli sayın.
