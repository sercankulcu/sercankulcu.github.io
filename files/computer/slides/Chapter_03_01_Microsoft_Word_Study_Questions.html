Output Question · Interface and Documents

Question 1: Save and Save As

essay.docx is open from disk. The steps below are performed in order. At the end, which files are on disk and which changes does each contain?

  1. Make change 1.
  2. Save As → essay_v2.docx
  3. Make change 2.
  4. Ctrl+S
Show answer
  • Save As creates a new file and the window now works on that file; change 1 was never saved to essay.docx.
  • Ctrl+S (Save) updates the open file, that is, essay_v2.docx.

Multiple Choice · Interface and Documents

Question 2: AutoSave

While working on the local file report.docx on the desktop, the AutoSave switch in the title bar cannot be turned on. Why?

D: AutoSave writes changes to the cloud continuously. AutoRecover is a separate feature: it offers a recovery copy after an unexpected shutdown and does not replace Save.

Multiple Choice · Interface and Documents

Question 3: Document from a Template

After double-clicking the template petition.dotx and filling in a name and a date, Ctrl+S is pressed. What happens?

B: A document opened from a template is a separate copy; the first save asks for a name and location. This way many petitions can be produced from the same template. .dotm is the template format that can contain macros.

Output Question · Text Editing

Question 4: Word Jumping and Selecting

The cursor is at the very start of the line. Ctrl+→, Ctrl+→, Ctrl+Shift+→, Ctrl+Shift+→, Ctrl+B, Ctrl+End are pressed in order. Which words become bold, and where does the cursor end up?

Show answer

Bold: “very long”. The cursor is at the end of the document, with no selection.

  • Two Ctrl+→: the cursor jumps to the start of the word “very”.
  • Ctrl+Shift+→ makes the same jump while selecting: “very ” then “very long ”.
  • Ctrl+B applies to the selection; Ctrl+End (without Shift) clears the selection and goes to the end of the document.

Step-by-Step Trace · Text Editing

Question 5: Cut, Paste, Undo

In the recipe, the last line should come first. How do the document and the clipboard change with the operations below?

The range to be moved was selected together with the paragraph mark (click to the left of the line, or Home, Shift+↓).

Cut: the text left the document and went to the clipboard.

Ctrl+Home: the cursor goes to the very start of the document.

Paste: the text on the clipboard was inserted where the cursor is. (If the numbered list feature is used, the numbers become 1-2-3 automatically.)

The clipboard keeps its content: the second paste inserts the same text once more.

Ctrl+Z undoes only the last operation (the second paste). Result: the correct order.

1. Select line 3
2. Ctrl + X
3. Ctrl + Home
4. Ctrl + V
5. Ctrl + V
6. Ctrl + Z

Multiple Choice · Text Editing

Question 6: Pasting Without Formatting

Red, 20 pt text was copied from a web page. What is used to insert it into the report with the report's own formatting, without the source's color and size?

C: Pasting as text only does not carry the source formatting (in current Microsoft 365: Ctrl+Shift+V). Format Painter copies formatting, and Ctrl+Enter inserts a page break.

Output Question · Text Editing

Question 7: The Replace All Trap

The document contains only this sentence. In Ctrl+H, Find what: note, Replace with: memo is entered and Replace All is pressed. What is the result? What would happen if Find whole words only were checked?

class notes, note pad and notebooks
Show answer

Default (3 replacements):

class memos, memo pad and memobooks

Whole word (1 replacement):

class notes, memo pad and notebooks
  • The search also finds the parts of words that contain “note”: “notes”, “notebooks”.
  • That is why Replace All should not be used without a preview (without checking with Find Next); if a mistake happens, Ctrl+Z.

Multiple Choice · Formatting

Question 8: Character or Paragraph?

Which of the following is paragraph formatting (applied to the whole paragraph when the cursor is in it, without making a selection)?

A: Alignment, indents, line and paragraph spacing, and tabs are at paragraph level. Font, size, emphasis, and superscript/subscript are at character level and apply to the selected text.

Output Question · Formatting

Question 9: When the Cursor Is in a Paragraph

The document has two paragraphs; nothing is selected. The following are done in order. What changes in the end?

  1. The cursor is placed in the middle of paragraph 2.
  2. Home → Center, Line spacing → 1.5.
  3. The cursor is moved to the end of paragraph 1.
  4. Ctrl+B is pressed and “ Extra sentence.” is typed.
Show answer
  • Paragraph formats apply to the whole paragraph where the cursor is, without a selection: all of paragraph 2 is centered and has 1.5 line spacing.
  • With no selection, Ctrl+B makes only the text typed afterwards bold: “Extra sentence.” is bold; the old text of paragraph 1 does not change.

Multiple Choice · Formatting

Question 10: Tab in a List

In a numbered list, Tab is pressed at the start of a new line below the item “2. Method”. What happens?

C: In Word's list feature, Tab and Shift+Tab change the indent level. If list markers are typed by hand, this automatic structure cannot be built.

Step-by-Step Trace · Formatting

Question 11: Changing a Style Definition

In the report, the lines “Introduction”, “Aims”, “Method” are in Normal style. The operations are done in order. How do the headings look?

Heading 1 brings font, size, color, and spacing from a single definition.

Method now has the same look too.

Heading 2 is one level lower (smaller).

Red color is direct formatting: it is added on top of the style.

When the style changes, the headings that use it update together: both got bigger. But Introduction stayed red; direct formatting overrides the style's color. Aims (Heading 2) was not affected.

The navigation pane and table of contents are built from heading styles: Aims is one level inside, under Introduction.

1. Introduction: Heading 1 style
2. Method: Heading 1 style
3. Aims: Heading 2 style
4. Select Introduction, font color red
5. Change the Heading 1 style:
   bigger and orange
6. Open the navigation pane

Multiple Choice · Formatting

Question 12: Style and Theme

What is the difference between choosing another theme from the Design tab and changing the Heading 1 style?

B: A theme is the document-wide color/font/effect system; styles use this system to define element types (heading, normal text...).

Step-by-Step Trace · Page Layout

Question 13: Making Only One Page Landscape

In a 5-page document, the wide table is on page 3; there is a page break at the end of pages 2 and 3. The goal is to make only page 3 landscape. Which pages are landscape at each step?

The document is a single section: the orientation change was applied to all pages. A page break does not create a section.

Undone.

Now there are 2 sections: 1–2 (S1) and 3–5 (S2).

The orientation was applied to the section where the cursor is: 3, 4, and 5 became landscape. Still too many.

Undone; the section break stays.

The table is alone in its own section (S2).

Only page 3 is landscape. Margins, columns, and headers can also be changed per section.

1. Cursor in the table: Landscape
2. Ctrl + Z
3. Instead of the page break at the end of p.2,
   a Next Page section break
4. Cursor in the table: Landscape
5. Ctrl + Z
6. The same change at the end of p.3
7. Cursor in the table: Landscape

Output Question · Page Layout

Question 14: Link to Previous

In a 3-page document, the header on all pages is “Report”. A Next Page section break is inserted at the end of page 2. Then:

  1. In the header of Section 2, “Report” is deleted and “Appendix” is typed (Link to Previous is on).
  2. It is undone; in Section 2, Link to Previous is turned off first and then “Appendix” is typed.

What are the headers of the pages in each case?

Show answer

(a) Link on: the header is shared by both sections; all three pages become “Appendix”.

(b) Link broken: only Section 2 changes.

A new section starts with the header linked to the previous one by default; to have different content, the link must be turned off first.

Multiple Choice · Page Layout

Question 15: No Number on the Cover

In a single-section document, the cover should show no page number, and from page 2 on the number should appear in the footer. Which is the easiest method?

A: Different First Page opens a separate header/footer area for the cover; that area is left empty. The page number is inserted as a field, not typed by hand; it updates itself when pages change.

Multiple Choice · Objects

Question 16: A Picture as a Watermark

A faint logo should sit under the text like a background (watermark); the text must stay readable over it. Which text wrapping type is chosen?

D: Behind Text puts the picture on the layer under the text. In Front of Text covers the text beneath it; with Square the text flows around the picture; an in-line picture sits on the line like a character.

Step-by-Step Trace · Long Documents

Question 17: Updating the Table of Contents

Page 1 is reserved for the table of contents. Introduction and Aims are on p.2, Method on p.3, Results on p.4. How does the table of contents change?

Heading styles build the document structure; the table of contents will be generated from these styles.

The table was generated automatically from the headings and page numbers.

Method is now p.5, Results p.6; but the table is a field and does not update by itself: the old numbers remain.

Update Table → Update page numbers only: the numbers are corrected.

Discussion went onto p.6, Results shifted to p.7. The navigation pane shows the new heading immediately; the table does not.

Only the numbers were updated: Results became 7, but Discussion is not in the table!

Update entire table also adds the new headings. Rule: if a heading was added, update the entire table.

1. Introduction, Method, Results: Heading 1
   Aims: Heading 2
2. References → Table of Contents
3. 2 pages of text before Method
4. Update: page numbers
   only
5. A 1-page “Discussion” (Heading 1)
   is added before Results
6. Update: numbers only
7. Update: entire table

Output Question · Long Documents

Question 18: Figure Numbers and Cross-references

In the document, the captions are “Figure 1: Map” and “Figure 2: Chart”. In the text, “Figure 2” in the phrase “as seen in Figure 2” is a cross-reference field to the chart. A new figure and caption (Insert Caption) are added before the map.

  1. What do the captions show right after?
  2. What does the cross-reference in the text show?
  3. After Ctrl+A, F9, what does the text show?
Show answer
  • (a) The new figure is Figure 1, Map is Figure 2, Chart is Figure 3: Word shifts the caption numbers.
  • (b) The cross-reference has not been updated yet: it still says “Figure 2”; the reader mistakenly looks at the map.
  • (c) The fields update: “as seen in Figure 3”.

A hand-typed “Figure 2” would never update. The table of figures is also built from the captions and updates the same way.

Output Question · Collaboration

Question 19: Track Changes

With Track Changes on, in the sentence “The exam is held on May 10.” the “10” is deleted and “17” typed, and “now ” is inserted before “held”.

  1. In All Markup view, how does the sentence look?
  2. If you switch to Simple Markup, are the changes accepted?
  3. After Review → Reject → Reject All Changes, what is the sentence?
Show answer
  • (a) Deleted text is struck through; inserted text is underlined and colored; a change bar is in the margin.
  • (b) No. The text appears in its final form but the changes are still pending. Hiding is not accepting.
  • (c) It returns to the original sentence: “The exam is held on May 10.”

Step-by-Step Trace · Bulk Documents

Question 20: Mail Merge

Excel list: header row Name | Department | Grade and 4 records: Ali Can | Physics | 78 · Ece Ak | Chemistry | 92 · Can Er | Biology | 65 · Deniz Su | Physics | 88. How does the merge proceed?

The list is linked. The first row holds the field names; it is not a recipient. Each row is a recipient: 4 recipients.

Placeholder fields were put in the blanks; they are not values yet.

Record 1: the values of the 1st data row replaced the fields.

Record 2. The common text of the main document did not change.

Last record (4): Deniz Su.

One letter per record: 4 letters (the header row does not produce a letter). The same steps can also produce e-mails or labels.

1. Mailings → Select Recipients
2. Insert Merge Field:
   «Name», «Department», «Grade»
3. Preview Results
4. Next record ▶
5. Last record ▶|
6. Finish & Merge
