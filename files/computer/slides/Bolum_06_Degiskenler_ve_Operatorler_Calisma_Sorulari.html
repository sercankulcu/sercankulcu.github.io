Soru 1: Geçersiz Tanımlayıcı

Aşağıdakilerden hangisi Java'da geçerli bir değişken adı değildir?

D: Tanımlayıcı harf, _ veya $ ile başlar; rakamla başlayamaz. _deger ve $tutar geçerlidir (yalnızca tek başına _ geçersizdir). Adlar büyük-küçük harfe duyarlıdır.

Soru 2: Büyük Sayı İçin Tür

Dünya nüfusu (yaklaşık 8 milyar) bir değişkende tutulacak. Hangi satır derlenir ve doğrudur?

B: int en fazla ≈ 2,1 milyar tutar; 8 milyar long gerektirir. Ayrıca sabitin kendisi int aralığını aştığı için L son eki şarttır; eksse "integer number too large" derleme hatası alınır.

Soru 3: Hangi Satır Derlenmez?

Aşağıdaki tanımlamalardan hangisi derleme hatası verir?

C: 5L bir long sabitidir; long → int daraltmadır ve açık dönüşüm ister ("possible lossy conversion"). Diğerleri genişletmedir ve otomatik yapılır: 5 → 5L, 'A' → 65.0, 10 → 10.0f.

Soru 4: float oran = 1.5;

float oran = 1.5; satırı neden derlenmez?

A: Ondalıklı sabitler varsayılan olarak double'dır (64 bit). 32 bitlik float'a örtük daraltma yapılmaz; F son eki ya da (float) dönüşümü gerekir. Kodda ondalık ayırıcı her zaman noktadır.

Soru 5: char Aritmetiği

Aşağıdaki kodun çıktısı nedir?

char c = 'C';
c++;
int k = c + 2;
char d = (char) k;
System.out.println(c + " " + k + " " + d);
Cevabı göster

Çıktı: D 70 F

  • 'C' = 67; c++ → 68 = 'D' (tür char kalır).
  • c + 2 int olur: 68 + 2 = 70; k harf değil sayı tutar.
  • (char) 70 = 'F'. Birleştirmede char harf, int sayı olarak yazılır.

Soru 6: byte 127 İki Kez Artırılırsa

Aşağıdaki kod parçasının çıktısı hangi şıkta doğru verilmiştir?

byte x = 127;
x++;
x++;

B: byte 8 bittir ve en büyük değeri 127'dir. İlk x++ taşar ve değer öbür uca sarar: −128. İkinci x++: −128 + 1 = −127. Java taşmada hata vermez (++ gizli bir (byte) dönüşümü içerir).

Soru 9: (byte) Daraltma

Aşağıdaki satır ne yazdırır?

System.out.println((byte) 200 + " " + (byte) 130);

C: Daraltma yalnızca alt 8 biti tutar; 127'den büyük değerden 256 çıkarılmış gibi olur: 200 − 256 = −56, 130 − 256 = −126. Daraltma dönüşümü hata vermez, sınırda "sıkışmaz" (127 olmaz); değer sessizce sarar.

Soru 12: Kesme mi Yuvarlama mı?

Aşağıdaki satır ne yazdırır?

System.out.println((int) -2.7 + " " + Math.round(-2.7));

D: (int) kesir kısmını atar, yani sıfıra doğru keser: −2.7 → −2. Math.round en yakın tam sayıya yuvarlar: −2.7 → −3 (long döner).

Soru 13: Not Ortalaması Hatası

Üç notun ortalaması üç farklı biçimde hesaplanıyor. Her satırdan sonra değişkenler ne olur, program ne yazdırır?

Önce kendiniz tahmin edin, sonra › ile ilerleyin.

Üç int değişken.

70 + 85 + 90 = 245 (int).

245 / 3 iki int → tam sayı bölmesi = 81. Sonra double kutuya genişler: 81.0. Kesir daha önce kayboldu.

3.0 double → 245 de double'a yükselir: 81.666…

Parantez içi önce: int bölme = 81; dönüşüm sonra → 81.0. İşlemden sonra yapılan dönüşüm kesri kurtarmaz.

o1 yazdırılır.

Doğru ortalama yalnızca o2'de.

Düzeltme: toplam / 3.0 ya da (double) toplam / 3.

int n1 = 70, n2 = 85, n3 = 90;
int toplam = n1 + n2 + n3;
double o1 = toplam / 3;
double o2 = toplam / 3.0;
double o3 = (double) (toplam / 3);
System.out.println(o1);
System.out.println(o2);
System.out.println(o3);

Soru 16: byte ile += ve +

byte b = 10; tanımından sonra yazılan iki satır için hangisi doğrudur?

b += 5;     // (1)
b = b + 5;  // (2)

D: b + 5 int'tir (byte işlemde int'e yükselir); int → byte örtük yapılmadığı için (2) derlenmez. Bileşik atama ise gizli dönüşüm içerir: b = (byte)(b + 5).

Soru 18: i++ ve ++i

Önek ve sonek artırmayı izleyin. Her satırdan sonra i, a, b kaç olur?

Önce kendiniz tahmin edin, sonra › ile ilerleyin.

i = 3.

Sonek i++ ifadeye eski değeri (3) verir: a = 3 + 2 = 5…

…ardından i artırılır: i = 4.

Önek ++i: önce artır → i = 5…

…sonra yeni değeri kullan: b = 5 · 2 = 10.

Tek başına i--: i = 4.

Çıktı: 4 5 10.

int i = 3;
int a = i++ + 2;
int b = ++i * 2;
i--;
System.out.println(i + " " + a + " " + b);

Soru 28: Karma İfade: a / b * 1.5 + a % b

İfadenin her alt işlemini, türüyle birlikte izleyin. r kaç olur?

Önce kendiniz tahmin edin, sonra › ile ilerleyin.

a = 9, b = 4 (int).

/, *, % aynı düzey, soldan sağa. İlk: 9 / 4 iki int → 2 (0.25 atılır).

2 * 1.5: 2 double'a yükselir → 3.0.

+'nın sağı: 9 % 4 = 1.

3.0 + 1 → 4.0 (int, double'a yükselir).

Çıktı 4.0. a / 4.0 yazılsaydı 2.25 · 1.5 + 1 = 4.375 olurdu.

int a = 9, b = 4;
double r = a / b * 1.5 + a % b;
System.out.println(r);

Soru 29: Kısa Devre: b = 0 ve b = 4

İki if de aynı koşulu farklı b ile sınıyor. Hangi alt ifadeler hesaplanır, ne yazılır?

Önce kendiniz tahmin edin, sonra › ile ilerleyin.

a = 10, b = 0.

Sol koşul false → kısa devre: a / b hiç hesaplanmaz, sıfıra bölme hatası oluşmaz.

Koşul false; else yok → satır 3 atlanır, çıktı yok.

b = 4.

Sol true → sağ taraf da hesaplanmak zorunda.

10 / 4 tam sayı bölmesi = 2; 2 > 2 → false. true && false → false.

else dalı: Oran küçük. (Gerçek oran 2.5 olsa da tam sayı bölmesi 2 verdi.)

int a = 10, b = 0;
if (b != 0 && a / b > 2)
    System.out.println("Oran büyük");
b = 4;
if (b != 0 && a / b > 2)
    System.out.println("Oran büyük");
else
    System.out.println("Oran küçük");

Soru 34: printf Biçimi

Aşağıdaki kodun çıktısı nedir? (Ondalık ayırıcı nokta kabul edin.)

System.out.printf("%-6s|%7.3f|%04d%n",
        "Can", 2.71828, 7);
Cevabı göster

Çıktı: Can | 2.718|0007

  • %-6s: 6 karakter, sola yaslı (3 harf + 3 boşluk).
  • %7.3f: 3 basamağa yuvarla (2.718), 7 karaktere sağa yasla.
  • %04d: 4 hane, boşluk yerine 0. Türkçe yerel ayarda 2,718 yazılır.

Soru 35: Saniyeyi Saate Çevirme

7384 saniye / ve % ile saat, dakika, saniyeye ayrılıyor. Her değişkeni izleyin.

Önce kendiniz tahmin edin, sonra › ile ilerleyin.

toplam = 7384 saniye.

7384 / 3600 = 2 (tam sayı bölmesi: kaç tam saat).

7384 % 3600 = 7384 − 7200 = 184.

184 / 60 = 3 tam dakika.

184 % 60 = 4.

%02d en az 2 hane, başa 0: 2:03:04. Sağlama: 2·3600 + 3·60 + 4 = 7384.

int toplam = 7384;
int saat = toplam / 3600;
int kalan = toplam % 3600;
int dakika = kalan / 60;
int saniye = kalan % 60;
System.out.printf("%d:%02d:%02d%n",
        saat, dakika, saniye);

Soru 37: Math Metotları

Aşağıdaki satır ne yazdırır?

System.out.println(Math.round(2.5) + " "
    + Math.round(-2.5) + " " + Math.sqrt(16)
    + " " + Math.pow(2, 3));

A: Math.round yarım değeri yukarı (pozitif yöne) yuvarlar: 2.5 → 3, −2.5 → −2; long döner. sqrt ve pow her zaman double döndürür: 4.0 ve 8.0.
