Soru 1: Büyük Sayı İçin Tip

Dünya nüfusu (yaklaşık 8 milyar) bir değişkende tutulacak. Hangi satır derlenir ve doğrudur?

B: int en fazla ≈ 2,1 milyar tutar; 8 milyar long gerektirir. Ayrıca sabitin kendisi int aralığını aştığı için L soneki şarttır; eksikse "integer number too large" derleme hatası alınır.

Soru 2: Hangi Satır Derlenmez?

Aşağıdaki tanımlamalardan hangisi derleme hatası verir?

C: 5L bir long sabitidir; long → int daraltmadır ve açık dönüşüm ister ("possible lossy conversion"). Diğerleri genişletmedir ve otomatik yapılır: 5 → 5L, 'A' → 65.0, 10 → 10.0f.

Soru 3: char Aritmetiği

Aşağıdaki kodun çıktısı nedir?

char c = 'C';
c++;
int k = c + 2;
char d = (char) k;
System.out.println(c + " " + k + " " + d);
Cevabı göster

Çıktı: D 70 F

  • 'C' = 67; c++ → 68 = 'D' (tip char kalır).
  • c + 2 int olur: 68 + 2 = 70; k harf değil sayı tutar.
  • (char) 70 = 'F'. Birleştirmede char harf, int sayı olarak yazılır.

Soru 4: byte 127 İki Kez Artırılırsa

Aşağıdaki kod parçasının çıktısı hangi şıkta doğru verilmiştir?

byte x = 127;
x++;
x++;
System.out.print(x);

B: byte 8 bittir ve en büyük değeri 127'dir. İlk x++ taşar ve değer öbür uca sarar: −128. İkinci x++: −128 + 1 = −127. Java taşmada hata vermez (++ örtük bir (byte) dönüşümü içerir).

Soru 5: int Sınırında Toplama

Aşağıdaki kodun çıktısı nedir?

int m = Integer.MAX_VALUE;
System.out.println(m + 1);
long a = m + 1;
System.out.println(a);
long b = m + 1L;
System.out.println(b);
System.out.println(Math.abs(Integer.MIN_VALUE));
Cevabı göster 
-2147483648
-2147483648
2147483648
-2147483648
  • m + 1: iki int → int toplaması, taşar.
  • long a = m + 1: toplama önce int yapılır (taşar), sonra long'a genişletilir. Hedefin long olması geç kalır.
  • m + 1L: işlenenlerden biri long → toplama long ile yapılır, sığar.
  • |MIN_VALUE| = 2³¹ int'e sığmaz; Math.abs da taşar.

Soru 7: Kesme mi Yuvarlama mı?

Aşağıdaki satır ne yazdırır?

System.out.println((int) -2.7 + " " + Math.round(-2.7));

D: (int) kesir kısmını atar, yani sıfıra doğru keser: −2.7 → −2. Math.round en yakın tam sayıya yuvarlar: −2.7 → −3 (long döner).

Soru 8: Not Ortalaması Hatası

Üç notun ortalaması üç farklı biçimde hesaplanıyor. Her satırdan sonra değişkenler ne olur, program ne yazdırır?

Üç int değişken.

70 + 85 + 90 = 245 (int).

245 / 3 iki int → tam sayı bölmesi = 81. Sonra double kutuya genişler: 81.0. Kesir daha önce kayboldu.

3.0 double → 245 de double'a yükselir: 81.666…

Parantez içi önce: int bölme = 81; dönüşüm sonra → 81.0. İşlemden sonra yapılan dönüşüm kesri kurtarmaz.

o1 yazdırılır.

Doğru ortalama yalnızca o2'de.

Düzeltme: toplam / 3.0 ya da (double) toplam / 3.

int n1 = 70, n2 = 85, n3 = 90;
int toplam = n1 + n2 + n3;
double o1 = toplam / 3;
double o2 = toplam / 3.0;
double o3 = (double) (toplam / 3);
System.out.println(o1);
System.out.println(o2);
System.out.println(o3);

Soru 9: i *= 3 + 7

Aşağıdaki kod parçasının çıktısı hangi şıkta doğru verilmiştir?

int i = 5;
i *= 3 + 7;
System.out.println(i);

B: Bileşik atamada sağ taraf önce tümüyle hesaplanır: i = i * (3 + 7) = 5 · 10 = 50. "i * 3 + 7 = 22" sanmak en sık yapılan hatadır.

Soru 10: Bileşik Atamanın Örtük Dönüşümü

Aşağıdaki kodun çıktısı nedir?

byte b = 120;
b += 10;
int i = 7;
i += 2.9;
System.out.println(b + " " + i);
Cevabı göster

Çıktı: -126 9

  • b += 10 ≡ b = (byte)(120 + 10): 130 byte'a sığmaz → 130 − 256 = −126.
  • i += 2.9 ≡ i = (int)(7 + 2.9) = (int) 9.9 = 9 (kesme, yuvarlama yok).

Soru 11: i++ ve ++i

Önek ve sonek artırmayı izleyin. Her satırdan sonra i, a, b kaç olur?

i = 3.

Sonek i++ ifadeye eski değeri (3) verir: a = 3 + 2 = 5…

…ardından i artırılır: i = 4.

Önek ++i: önce artır → i = 5…

…sonra yeni değeri kullan: b = 5 · 2 = 10.

Tek başına i--: i = 4.

Çıktı: 4 5 10.

int i = 3;
int a = i++ + 2;
int b = ++i * 2;
i--;
System.out.println(i + " " + a + " " + b);

Soru 12: x, y, z Bileşik Atama

Aşağıdaki kod parçası çalıştığında çıktı ne olur? Her satırda kutuların nasıl değiştiğini izleyin.

x = 7, y = 8.

Sağ taraf önce: 7 + 8 = 15 → x'e yazılır.

1. satır.

Sonek: z eski değeri (15) alır, sonra x 16 olur.

2. satır.

y -= 4 → y = 8 − 4 = 4.

3. satır.

x *= y → 16 · 4 = 64.

4. satır.

x /= 4 → 64 / 4 = 16.

5. satır. Toplam 5 satır çıktı.

int x = 7;
int y = 8;
x = x + y;
System.out.println("x: " + x + " y: " + y);
int z = x++;
System.out.println("x: " + x + " z: " + z);
y -= 4;
System.out.println("x: " + x + " y: " + y);
x *= y;
System.out.println("x: " + x + " y: " + y);
x /= 4;
System.out.println("x: " + x + " y: " + y);

Soru 13: Kalan, Sonsuz ve NaN

Aşağıdaki kodun çıktısı nedir?

System.out.println(-7 % 3);
System.out.println(7 % -3);
System.out.println(5.5 % 2);
System.out.println(1.0 / 0);
System.out.println(0.0 / 0 == 0.0 / 0);
Cevabı göster 
-1
1
1.5
Infinity
false
  • Kalanın işareti bölünenin işaretidir: −7 % 3 = −1, 7 % −3 = 1.
  • % ondalıkta da çalışır: 5.5 = 2·2 + 1.5.
  • Ondalıkta sıfıra bölme hata vermez: Infinity. (1 / 0 ise ArithmeticException.)
  • 0.0 / 0 = NaN; NaN kendine bile eşit değildir.

Soru 15: Kısa Devre: b = 0 ve b = 4

İki if de aynı koşulu farklı b ile sınıyor. Hangi alt ifadeler hesaplanır, ne yazılır?

a = 10, b = 0.

Sol koşul false → kısa devre: a / b hiç hesaplanmaz, sıfıra bölme hatası oluşmaz.

Koşul false; else yok → satır 3 atlanır, çıktı yok.

b = 4.

Sol true → sağ taraf da hesaplanmak zorunda.

10 / 4 tam sayı bölmesi = 2; 2 > 2 → false. true && false → false.

else dalı: Oran küçük. (Gerçek oran 2.5 olsa da tam sayı bölmesi 2 verdi.)

int a = 10, b = 0;
if (b != 0 && a / b > 2)
    System.out.println("Oran büyük");
b = 4;
if (b != 0 && a / b > 2)
    System.out.println("Oran büyük");
else
    System.out.println("Oran küçük");

Soru 16: 0.1 + 0.2 == 0.3

double a = 0.1 + 0.2; için System.out.println(a == 0.3); ne yazar ve doğru karşılaştırma nasıl yapılır?

D: 0.1 ve 0.2 ikili tabanda tam gösterilemez; a = 0.30000000000000004 olur ve == false verir. Ondalık değerler küçük bir epsilon ile karşılaştırılır.

Soru 18: nextInt'ten Sonra nextLine

Kullanıcı önce 20 yazıp Enter'a basıyor. Ad sorulmadan program bitiyor. ad değişkeninin değeri nedir?

Scanner klavye = new Scanner(System.in);
System.out.print("Yaş: ");
int yas = klavye.nextInt();
System.out.print("Ad: ");
String ad = klavye.nextLine();

C: nextInt yalnızca 20'yi okur; Enter (⏎) tamponda kalır. nextLine beklemeden bu ⏎'e kadar okur ve boş dizgi döner. Çözüm: nextInt'ten sonra bir klavye.nextLine(); ile ⏎'i tüketmek.

Çıktı Sorusu · Girdi ve Çıktı

Soru 19: printf Biçimi

Aşağıdaki kodun çıktısı nedir? (Ondalık ayırıcı nokta kabul edin.)

System.out.printf("%-6s|%7.3f|%04d%n",
        "Can", 2.71828, 7);
Cevabı göster

Çıktı: Can | 2.718|0007

  • %-6s: 6 karakter, sola yaslı (3 harf + 3 boşluk).
  • %7.3f: 3 basamağa yuvarla (2.718), 7 karaktere sağa yasla.
  • %04d: 4 hane, boşluk yerine 0. Türkçe yerel ayarda 2,718 yazılır.

Soru 20: Math Metotları

Aşağıdaki satır ne yazdırır?

System.out.println(Math.round(2.5) + " "
    + Math.round(-2.5) + " " + Math.sqrt(16)
    + " " + Math.pow(2, 3));

A: Math.round yarım değeri yukarı (pozitif yöne) yuvarlar: 2.5 → 3, −2.5 → −2; long döner. sqrt ve pow her zaman double döndürür: 4.0 ve 8.0.
