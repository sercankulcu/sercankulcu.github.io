    Java Derleme ve Çalıştırma
    
    
    Amaç: Bir Java programının yolculuğunu adım adım görmek: kaynak kod (.java) → javac derleyicisi → bytecode (.class) → java komutuyla JVM → konsol çıktısı. Hata türlerini (derleme, çalışma zamanı, mantık) ayırt etmeyi öğrenmek.
    
    
    Nasıl kullanılır?
    
    
      
      
    1. Soldan hazır bir program seçin. main metodunun gövdesi (kesik çizgili alan) ve dosya adı düzenlenebilir; ↺ Özgün kod değişiklikleri geri alır.
      2. 
      
    2. Adım ▶ hattı başlatır: dosya kaydedilir, javac çalışır. Hata varsa terminalde gerçek javac biçiminde ileti (dosya:satır, açıklama, ^ işareti) görünür ve .class üretilmez. Hata yoksa bytecode listesi gelir; java komutuyla JVM her deyimi çalıştırır, ilgili bytecode komutları vurgulanır, çıktı terminale yazılır.
      3. 
      
    3. ⇥ ↵ göster sekme ve satır sonu karakterlerini görünür yapar (\t, \n, println farkı).
      4. 
      
    4. Kendini dene: derlemeden önce programın sonucunu (derleme hatası / çalışma zamanı hatası / mantık hatası / hatasız) ve her yazdırma deyiminin çıktısını tahmin edin.
      5. 
    
    
    
    Sınırlar
    
    
    Bu gerçek bir derleyici değildir; küçük bir alt kümeyi tanır: satır başına bir deyim; System.out.println(…), System.out.print(…), int/String değişken tanımı ve atama; + - * / %, parantez, \n \t \" \' \\ kaçış dizileri. Hata iletileri ve bytecode, JDK 21 javac/javap/java çıktılarıyla karşılaştırılarak doğrulanmıştır. Alt kümenin dışındaki bir satırda simülatör uyarı verir. Bytecode listesi sadeleştirilmiştir (sabit havuzu numaraları gösterilmez).
