Multiple Choice · Interface and Files

Question 1: Seeing the Flow at a Glance

Which view is best for seeing the flow of a 40-slide presentation on one screen and reordering the slides by dragging?

C: Slide Sorter shows the thumbnails in a grid; it is suited for reordering, sectioning, and hiding. Notes Page is for speaker notes, and Slide Master is for shared layouts.

Multiple Choice · Interface and Files

Question 2: Speaker Notes

Which statement is true about speaker notes typed in the Notes pane?

A: Notes are for narration detail, timing, and reminders that do not fit on the slide. With a second screen connected, Presenter View shows the speaker the notes, the timer, and the next slide.

Step-by-Step Trace · Planning

Question 3: Level in Outline View

In View → Outline View, the operations below are performed. How many slides does the presentation have after each step?

Every top-level line typed in the outline is a new slide title: 6 slides.

Tab demotes the level: Scope became a bullet of the Purpose slide.

Goal is also a bullet of Purpose: 4 slides.

Enter on a title line opens at the same level, i.e. a new slide (still empty).

With Tab, the empty slide turned into a bullet of Method: “Survey”.

Shift+Tab promotes the level: Goal became a slide title again. Result: 5 slides.

1. Type the lines: Introduction, Purpose,
   Scope, Goal, Method, Results
2. Tab on the “Scope” line
3. Tab on the “Goal” line
4. Enter at the end of “Method”
5. Tab on the new line, type “Survey”
6. Shift + Tab on the “Goal” line

Output Question · Interface and Files

Question 4: Opening Three Files

The animated deck.pptx is first saved with Save As as deck.ppsx, then exported as a PDF (deck.pdf). What is seen when each of the three files is double-clicked?

Show answer
  • deck.pptx: PowerPoint opens in Normal view; it is editable.
  • deck.ppsx: The slide show starts directly; animations and transitions play. When the show ends (Esc) it closes.
  • deck.pdf: Fixed pages in a PDF reader; there are no animations or transitions, and the final state of the slide is shown.

Save As creates a new copy; the original .pptx stays unchanged.

Multiple Choice · Slide Management

Question 5: Layout vs. Theme

On a slide, you want the title on top and two content boxes side by side. Which command changes the type and position of the placeholders?

B: Layout determines the type and position of the placeholders on the slide. A theme is the system of colors, fonts, effects, and background. Adding text boxes one by one breaks consistency.

Step-by-Step Trace · Slide Management

Question 6: Insert, Duplicate, Move, Hide

The deck has slides A, B, C, D in order. The following is done in the slide pane. What are the slide order and the show like?

A new slide is inserted after the selected slide.

Duplicate puts a copy of the selected slide right after it.

The order changed by dragging the thumbnail; numbers are reassigned.

A hidden slide stays in the file; its thumbnail looks faded and its slide number is struck through.

F5 starts from the beginning; hidden C is skipped: 5 slides are shown.

Anyone who receives the file can see the content of a hidden slide.

1. Select B, Ctrl + M (new: N)
2. Select A, Ctrl + D
3. Drag D to the very start
4. Right-click C → Hide Slide
5. F5

Multiple Choice · Design

Question 7: A Logo on Every Slide

The institution's logo and footer must appear in the same place on all slides. Which is the safest and most consistent method?

C: Rules on the slide master pass down to the layouts, and from the layouts to the slides. The logo also appears automatically on slides added later; no one-by-one fixing is needed.

Output Question · Design

Question 8: Slide Master and Manual Formatting

In View → Slide Master, the title font is set to Arial and its color to navy. Earlier, only the Times New Roman font had been applied manually to the title of slide 3; slide 5 uses the Blank layout and has no title. After closing the master view, how do the titles look?

Show answer
  • Slides 1, 2, 4: Arial, navy (the rule comes from the slide master).
  • Slide 3: the font stays Times New Roman (manual formatting takes priority), but since the color was not changed manually, it becomes navy.
  • Slide 5: since there is no title placeholder, nothing changes.

For consistency, use the slide master instead of manual formatting on slides; manual formatting can be returned to the layout with Home → Reset.

Multiple Choice · Design

Question 9: Visual Hierarchy

On a slide presenting the finding “Registrations rose 38%”, the viewer's eye should go first to the most important information. Which layout is the most suitable?

A: Size and color show the order of importance; they are not decoration. If everything has the same weight, the viewer has to search for the most important information. The title should state the topic or the main result directly.

Classic Question · Visuals

Question 10: A Chart for Each Message

Which chart type should be chosen for each message, according to the recommendations in the lecture?

  1. Comparing the student numbers of five departments
  2. Change in average temperature over the last 10 years
  3. Splitting a budget into the shares of 3 items
  4. Relationship between weekly study hours and exam grade
Show answer
  • (a) Column / bar: comparing categories.
  • (b) Line: change over time.
  • (c) Pie (few categories) or percentage bar: part-to-whole.
  • (d) Scatter: relationship between two variables.

The chart title should state the main result, axes and units should be visible, and unnecessary 3-D effects should be avoided.

Output Question · Visuals

Question 11: Converting to SmartArt

The slide has this bullet list: Register · Pick courses · Get approval · Start. The text box is selected and Home → Convert to SmartArt → Basic Process is chosen. How does the slide look, and does the text disappear?

Show answer
  • Each bullet becomes a box; the boxes are arranged left to right and connected with arrows. The sequence relationship is clear at first glance.
  • The text does not disappear; the same text is the content of the SmartArt and is editable.
  • A plain bullet list does not show order; SmartArt is suitable for a process, and shapes with connectors for relationships.

Step-by-Step Trace · Design

Question 12: Align, Distribute, Group

On a 400×240-pixel slide there are three 60×40 shapes (the top-left corner coordinates are given). What are the coordinates after each step?

Placed by eye: the top edges and the gaps differ.

The top edges moved to the line of the topmost shape (y = 40); x did not change.

The leftmost and rightmost stay in place. Free space (360 − 20) − 3·60 = 160 → two gaps of 80 each: B x = 20 + 60 + 80 = 160.

The group acts like a single object: width 20…360 = 340, height 40.

Horizontal centering: (400 − 340) / 2 = 30 → the group moved 10 px right; the gaps are preserved.

Vertical centering: (240 − 40) / 2 = 100. The group is exactly at the center of the slide.

Start: A(20,40) B(150,70) C(300,55)
1. Select all three: Align → Align Top
2. Align → Distribute Horizontally
3. Group
4. Align → Align Center (to slide)
5. Align → Align Middle

Multiple Choice · Motion

Question 13: Bullets Appear One by One

The three bullets on the slide should appear one by one as the presenter clicks. What is used?

D: Animation applies to objects inside the slide, a transition applies to the slide as a whole. An entrance animation makes the object appear on the slide; if the start is “On Click”, each click brings one bullet.

Output Question · Motion

Question 14: How Many Clicks?

The show is on slide 1 (no animations). Slide 2 has a Push transition and each of its three bullets has an entrance animation that starts On Click. Slide 3 has no animation. (a) How many clicks are needed to see slide 3? (b) What if the start of bullets 2 and 3 is made After Previous?

Show answer

(a) 5 clicks; (b) 3 clicks.

Click(a)(b)
1Push → Slide 2 (no bullets)Push → Slide 2
2Bullet 1Bullet 1, then 2 and 3 on their own
3Bullet 2Slide 3
4Bullet 3
5Slide 3

A click does not advance to the next slide before the animations finish; it first starts the next effect.

Question 15: Animation Timeline

The Animation pane is as shown below. The presenter clicks at t = 0 and t = 5. When does each effect start and end?

Click 1: Title 0–1 s.

Bullet 1 starts when the title ends: 1–1.5 s. No separate click is needed.

Bullet 2 is triggered together with Bullet 1 (at 1 s), 0.25 delay: 1.25–1.75 s.

The logo waits 0.5 after the previous effect (Bullet 2) ends at 1.75: 2.25–3.25 s.

The automatic chain is over. Since the next effect is On Click, PowerPoint waits for the presenter's click.

Click 2 (t = 5): Bullet 1 emphasis 5–5.5 s. A total of 2 clicks is enough.

2 Bullet 1: After Previous, 0.5 s
3 Bullet 2: With Previous,
  0.5 s, delay 0.25
4 Logo: After Previous, 1 s,
  delay 0.5

  0.5 s

Multiple Choice · Motion

Question 16: Morph

On slide 1 there is a circle; on slide 2 (duplicated) it is larger and shifted right. What happens in the show if slide 2 is given the Morph transition?

A: Morph automatically generates the motion in between when the same object has a different position, size, or color on two slides. Its availability may vary with the PowerPoint version and license.

Step-by-Step Trace · Presenting

Question 17: Show Shortcuts

In a 10-slide presentation without animations, slide 5 is on screen during the show. The keys are pressed in order. What is seen at each step?

B (or .) blacks out the screen; attention is drawn to the speaker.

B again: it returns to the slide where it left off.

Number + Enter jumps directly to that slide.

Space / →: next.

←: previous.

Esc ends the show; you return to editing view, with the last shown slide selected.

Shift+F5 starts the show from the current slide.

F5 always starts from the beginning.

1. B
2. B
3. Type 2, Enter
4. Space
5. ←
6. Esc
7. Shift + F5
8. Esc, then F5

Output Question · Presenting

Question 18: Hidden Slide and Custom Show

In a 6-slide deck, slide 4 is hidden. In addition, a custom slide show named “Short” was created from slides 1, 3, and 5. (a) Which slides are shown with F5? (b) Which slides does the “Short” show display? (c) Can a person who receives the file by e-mail see slide 4?

Show answer
  • (a) 1, 2, 3, 5, 6: the hidden slide is skipped in the normal show.
  • (b) 1, 3, 5: a chosen sequence from the same deck for a different audience.
  • (c) Yes. A hidden slide stays in the file; anyone who opens the file sees it. Sensitive content should be deleted before sharing.

Multiple Choice · Quality

Question 19: Fonts on Another Computer

A special font was used in the deck, and the presentation will be given on another computer in the hall. What should be done so the fonts do not break?

B: Embedded fonts travel with the file (some fonts may not be embeddable). Linked media should also be checked, and a PDF should be prepared as a backup.

Multiple Choice · Quality

Question 20: An Accessible Deck

Which of the following is a wrong practice for a viewer who uses a screen reader?

D is wrong: information should not be given by color alone; a viewer who cannot tell colors apart or who uses a screen reader will miss it. Sufficient contrast and captions for video/audio are also recommended.
