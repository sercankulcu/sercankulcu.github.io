Giriş

Öğrenme Çıktıları

Boyut

Satır ve sütun sayılarını belirlemek.

Döngü

İç ve dış döngünün görevini ayırmak.

Desen

Boşluk ve karakter sayılarını formülleştirmek.

İzleme

Küçük boyutta çıktıyı elle doğrulamak.

Yöntem

Desen Problemini Çözme

  • Önce beklenen çıktıyı küçük bir boyut için yazın.
  • Her satırda kaç boşluk ve kaç karakter olduğunu tabloya dökün.
  • Dış döngüyü satıra, iç döngüleri satır içindeki parçalara bağlayın.

Temeller

Yatay Satır

void çizdir(int n) {
    for (int sütun = 0; sütun < n; sütun++) {
        System.out.print("*");
    }
    System.out.println();
}
  • print karakterleri aynı satırda tutar; println satırı tamamlar.
  • İç döngü n karakter üretir.
  • Satır sonu döngü tamamlandıktan sonra yazılır.

Dikdörtgen

Dolu Kare

for (int satır = 0; satır < n; satır++) {
    for (int sütun = 0; sütun < n; sütun++) {
        System.out.print("*");
    }
    System.out.println();
}
  • Dış döngü satırları, iç döngü sütunları yönetir.
  • Toplam n² karakter yazılır.

Dikdörtgen

Dikdörtgen

for (int satır = 0; satır < yükseklik; satır++) {
    for (int sütun = 0; sütun < genişlik; sütun++) {
        System.out.print("*");
    }
    System.out.println();
}
  • Kareden farkı iki boyutun ayrı değişkenlerle belirlenmesidir.

Üçgen

Artan Üçgen

for (int satır = 1; satır <= n; satır++) {
    for (int sütun = 1; sütun <= satır; sütun++) {
        System.out.print("*");
    }
    System.out.println();
}
  • Satır r ise r yıldız yazılır.
  • İç döngünün üst sınırı dış döngü değişkenidir.

Üçgen

Azalan Üçgen

for (int satır = 0; satır < n; satır++) {
    for (int sütun = 0; sütun < n - satır; sütun++) {
        System.out.print("*");
    }
    System.out.println();
}
  • İlk satır n, son satır 1 karakter içerir.
  • Karakter sayısı her satırda bir azalır.

Boşluk

Sağa Yaslı Üçgen

for (int satır = 1; satır <= n; satır++) {
    for (int boşluk = 0; boşluk < n - satır; boşluk++)
        System.out.print(" ");
    for (int yıldız = 0; yıldız < satır; yıldız++)
        System.out.print("*");
    System.out.println();
}
  • Her satır boşluk bölümü ve karakter bölümünden oluşur.
  • Boşluk azalırken yıldız artar.

Boşluk

Piramit

for (int satır = 1; satır <= n; satır++) {
    boşlukYaz(n - satır);
    yıldızYaz(2 * satır - 1);
    System.out.println();
}
  • Yıldız sayısı tek sayılar dizisidir: 1, 3, 5...
  • Yardımcı metotlar ana deseni okunur kılar.

Desen

Sayı Üçgeni

for (int satır = 1; satır <= n; satır++) {
    for (int değer = 1; değer <= satır; değer++) {
        System.out.print(değer + " ");
    }
    System.out.println();
}
  • Yazdırılan değer sütun değişkeninden gelir.
  • Aynı yapı karakter yerine sayı üretir.

Desen

İçi Boş Kare

for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        boolean kenar = i == 0 || i == n-1 || j == 0 || j == n-1;
        System.out.print(kenar ? "*" : " ");
    }
    System.out.println();
}
  • Yalnızca ilk/son satır veya ilk/son sütun yıldızdır.

Doğrulama

Adım Adım İzleme

  • n = 3 gibi küçük değer seçin.
  • Her dış döngü turunda satır numarasını yazın.
  • İç döngülerin kaç kez çalıştığını ve ne yazdığını kaydedin.
  • Satır sonunda println çağrısının yerini kontrol edin.

Doğrulama

Sık Hatalar

  • println çağrısını iç döngüye koymak her karakteri ayrı satıra yazar.
  • < ve <= farkı bir eksik veya bir fazla karakter üretir.
  • Boşluğu yıldızdan sonra yazmak hizalamayı tersine çevirir.
  • Dış döngü değişkenini iç döngüde yanlış güncellemek akışı bozar.

Özet

Bölüm Özeti

  • Dış döngü satırı, iç döngü satırdaki öğeleri üretir.
  • Her desen satır numarasına bağlı boşluk ve karakter formülüyle tanımlanabilir.
  • Artan ve azalan desenler iç döngü sınırının değişmesiyle oluşur.
  • Küçük bir n değeriyle elle izleme sınır hatalarını görünür kılar.

Özet

Kontrol Soruları

  1. Dolu karede iç ve dış döngü neyi temsil eder?
  2. Artan üçgende yıldız sayısı nasıl bulunur?
  3. Piramit için neden 2 × satır - 1 kullanılır?
  4. println yanlış yerde olursa çıktı nasıl değişir?
  5. İçi boş karede kenar koşulu nasıl belirlenir?
