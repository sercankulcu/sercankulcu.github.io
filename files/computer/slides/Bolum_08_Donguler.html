Döngü

for, while ve do-while yapılarını seçmek.

Kalıplar

Sayaç ve biriktirici ile hesap yapmak.

İç içe

İç içe döngülerle satır-sütun desenleri üretmek.

İzleme

Döngüyü sınır değerlerle adım adım doğrulamak.

Döngüler

Döngünün Bileşenleri

  • Başlangıç, döngüden önce kurulan durumdur.
  • Koşul tekrarın sürüp sürmeyeceğini belirler.
  • Gövde her turda yapılan işlemleri içerir.
  • Güncelleme koşulu sona yaklaştırır.

Döngüler

for Döngüsü

int toplam = 0;
for (int i = 1; i <= 10; i++) {
    toplam += i;
}
System.out.println(toplam);
  • Tekrar sayısı belirgin olduğunda for uygundur.
  • i değişkeni döngü bloğuyla sınırlıdır.

Döngüler

while Döngüsü

int sayı = 5;
int faktöriyel = 1;
while (sayı > 1) {
    faktöriyel *= sayı;
    sayı--;
}
  • Koşul gövdeden önce kontrol edilir.
  • Başlangıçta false ise gövde hiç çalışmaz.

Döngüler

do-while Döngüsü

int seçim;
do {
    seçim = menüyüGöster();
    işle(seçim);
} while (seçim != 0);
  • Koşul gövdeden sonra kontrol edilir.
  • Gövde en az bir kez çalışır.

Dallanma

break ve continue

for (int i = 0; i < değerler.length; i++) {
    if (değerler[i] < 0) continue;
    if (değerler[i] == hedef) break;
    işle(değerler[i]);
}
  • continue o turdaki kalan işlemleri atlar.
  • break en yakın döngüyü sonlandırır.
  • Aşırı kullanım akışı izlemeyi zorlaştırabilir.

Döngüler

Sonsuz Döngü

  • Koşul hiçbir zaman false olmuyorsa döngü bitmez.
  • Sayaç yanlış yönde güncellenmiş veya hiç güncellenmemiş olabilir.
  • Sürekli çalışan olay döngülerinde bile kontrollü çıkış ve kaynak yönetimi gerekir.

Doğrulama

Döngü Değişmezi

  • Her turun başında doğru kalan bir özelliktir.
  • Algoritmanın kısmi sonucunu ve ilerlemesini açıklamaya yardım eder.
  • Örneğin toplam döngüsünde biriktirici, o ana kadar işlenen değerlerin toplamıdır.

Örnek

Basamak Sayısı

long kalan = Math.abs((long) sayı);
int basamak = kalan == 0 ? 1 : 0;
while (kalan > 0) {
    basamak++;
    kalan /= 10;
}
  • Her tam sayı bölmesi son basamağı kaldırır.
  • 0 sayısının bir basamağı olduğu ayrıca ele alınır.
  • long'a dönüştürme, Integer.MIN_VALUE mutlak değer sorununu önler.

Örnek

Rakamlar Toplamı

long kalan = Math.abs((long) sayı);
int toplam = 0;
while (kalan > 0) {
    toplam += (int) (kalan % 10);
    kalan /= 10;
}
  • % 10 son rakamı verir.
  • / 10 işlenen son rakamı sayıdan çıkarır.
  • Hesaplama negatif ve tüm int değerlerinde güvenlidir.

Örnek

Üs Alma

int sonuç = 1;
for (int i = 0; i < üs; i++) {
    sonuç *= taban;
}
  • Üs 0 olduğunda döngü çalışmaz ve sonuç 1 kalır.
  • Bu temel örnek negatif üsleri kapsamaz.

Örnek

Asal Sayı

boolean asal = n >= 2;
for (int i = 2; asal && i <= n / i; i++) {
    if (n % i == 0) asal = false;
}
  • 0 ve 1 asal değildir.
  • n / i karşılaştırması i × i taşma riskini azaltır.

Örnek

Fibonacci Serisi

long a = 0, b = 1;
for (int i = 0; i < adet; i++) {
    System.out.print(a + " ");
    long sonraki = a + b;
    a = b;
    b = sonraki;
}
  • Güncelleme sırası iki önceki değeri korur.
  • Seri büyük indekslerde long sınırını aşar.

Döngüler

İç İçe Döngü

for (int satır = 0; satır < 3; satır++) {
    for (int sütun = 0; sütun < 4; sütun++) {
        System.out.printf("(%d,%d) ", satır, sütun);
    }
    System.out.println();
}
  • İç döngü dış döngünün her turunda tamamlanır.
  • Toplam tekrar sayısı yaklaşık satır × sütundur.

Örnek

Desen Problemini Çözme

  • Önce beklenen çıktıyı küçük bir boyut için yazın.
  • Her satırda kaç boşluk ve kaç karakter olduğunu tabloya dökün.
  • Dış döngüyü satıra, iç döngüleri satır içindeki parçalara bağlayın.

Örnek

Artan Üçgen

for (int satır = 1; satır <= n; satır++) {
    for (int sütun = 1; sütun <= satır; sütun++) {
        System.out.print("*");
    }
    System.out.println();
}
  • Satır r ise r yıldız yazılır.
  • İç döngünün üst sınırı dış döngü değişkenidir.

Örnek

Sağa Yaslı Üçgen

for (int satır = 1; satır <= n; satır++) {
    for (int boşluk = 0; boşluk < n - satır; boşluk++)
        System.out.print(" ");
    for (int yıldız = 0; yıldız < satır; yıldız++)
        System.out.print("*");
    System.out.println();
}
  • Her satır boşluk bölümü ve karakter bölümünden oluşur.
  • Boşluk azalırken yıldız artar.

Örnek

Sayı Üçgeni

for (int satır = 1; satır <= n; satır++) {
    for (int değer = 1; değer <= satır; değer++) {
        System.out.print(değer + " ");
    }
    System.out.println();
}
  • Yazdırılan değer sütun değişkeninden gelir.
  • Aynı yapı karakter yerine sayı üretir.

Örnek

İçi Boş Kare

for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        boolean kenar = i == 0 || i == n-1 || j == 0 || j == n-1;
        System.out.print(kenar ? "*" : " ");
    }
    System.out.println();
}
  • Yalnızca ilk/son satır veya ilk/son sütun yıldızdır.

Örnek

Sık Hatalar

  • println çağrısını iç döngüye koymak her karakteri ayrı satıra yazar.
  • < ve <= farkı bir eksik veya bir fazla karakter üretir.
  • Boşluğu yıldızdan sonra yazmak hizalamayı tersine çevirir.
  • Dış döngü değişkenini iç döngüde yanlış güncellemek akışı bozar.

Örnek

Test Tasarımı

  • Her problem için normal bir değer seçin.
  • 0, 1, negatif ve üst sınıra yakın değerleri ayrı test edin.
  • Beklenen sonucu kodu çalıştırmadan hesaplayın.
  • Değişkenleri tur tur izleyerek ilk sapmayı bulun.

Özet

Bölüm Özeti

  • Her döngü başlangıç, koşul, gövde ve güncelleme parçalarından oluşur.
  • Tekrar sayısı belliyse for, koşul sürdükçe while, en az bir tur gerekiyorsa do-while seçilir.
  • Sayaç ve biriktirici kalıpları basamak, üs ve seri problemlerinde tekrar kullanılır.
  • İç içe döngüde dış döngü satırı, iç döngü satırdaki öğeleri üretir.
  • Döngüler 0, 1 ve sınır değerleriyle elle izlenerek test edilmelidir.
