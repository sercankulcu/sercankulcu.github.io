Döngü

for, while ve do-while yapılarını seçmek.

Kalıplar

Sayaç ve biriktirici ile hesap yapmak.

İç içe

İç içe döngülerle satır-sütun desenleri üretmek.

İzleme

Döngüyü sınır değerlerle adım adım doğrulamak.

Döngüler

Döngünün Bileşenleri

  • Başlangıç: döngüden önce bir kez kurulan durum.
  • Koşul: her turdan önce (do-while’da sonra) sorulur; false ise çıkılır.
  • Gövde: her turda yapılan iş.
  • Güncelleme: koşulu sona yaklaştırır; unutulursa döngü bitmez.
Bu dört renk bölüm boyunca aynı anlamda kullanılır.

Döngüler

for Döngüsü

int n = 4;
int toplam = 0;
for (int i = 1; i <= n; i++) {
    toplam += i;
}
System.out.println(toplam);

başlangıçkoşulgövdegüncelleme

  • Tekrar sayısı belli olduğunda for uygundur; dört parça tek satırda toplanır.
  • Sıra: başlangıç → koşul → gövde → güncelleme → koşul …
  • i yalnızca döngü içinde tanımlıdır.

Döngüler · Kodu adım adım çalıştır

Kod İzleme: for ile 1 + 2 + 3 + 4

n = 4: 1’den 4’e kadar toplayacağız.

Biriktirici toplam = 0 ile başlar (henüz hiçbir sayı eklenmedi).

Başlangıç: int i = 1 yalnızca bir kez çalışır.

Koşul: i <= n → 1 <= 4 → true → gövdeye gir.

Gövde: toplam = 0 + 1 = 1.

Güncelleme: i++ → i = 2. Sonra yine koşula dönülür.

Koşul: i <= n → 2 <= 4 → true → gövdeye gir.

Gövde: toplam = 1 + 2 = 3.

Güncelleme: i++ → i = 3. Sonra yine koşula dönülür.

Koşul: i <= n → 3 <= 4 → true → gövdeye gir.

Gövde: toplam = 3 + 3 = 6.

Güncelleme: i++ → i = 4. Sonra yine koşula dönülür.

Koşul: i <= n → 4 <= 4 → true → gövdeye gir.

Gövde: toplam = 6 + 4 = 10.

Güncelleme: i++ → i = 5. Sonra yine koşula dönülür.

Koşul: i <= n → 5 <= 4 → false → döngü biter.

Döngüden sonra println 10 yazar. i artık yok: kapsamı döngüydü. Gövde 4 kez, koşul 5 kez çalıştı.

int n = 4;
int toplam = 0;
for (int i = 1; i <= n; i++) {
    toplam += i;
}
System.out.println(toplam);

++i ile i++ Farkı

for (int i = 0; i < 3; i++) System.out.print(i + " ");   // 0 1 2
for (int i = 0; i < 3; ++i) System.out.print(i + " ");   // 0 1 2

for’un güncelleme bölümünde ifadenin değeri kullanılmaz; ikisi de yalnızca i’yi 1 artırır, fark yoktur.

Başlangıçİfadesonuçsonra
a = 5b = a++b = 5a = 6
a = 5b = ++ab = 6a = 6
idx = 0d[idx++]10idx = 1
idx = 0d[++idx]20idx = 1
  • i++ önce eski değeri verir, sonra artırır; ++i önce artırır, sonra yeni değeri verir.
  • Tabloda d = {10, 20, 30}; fark yalnızca değer kullanıldığında ortaya çıkar. Okunabilirlik için sayaçta i++ yazın.

while Döngüsü

int sayi = 5;
int faktoriyel = 1;
while (sayi > 1) {
    faktoriyel *= sayi;
    sayi--;
}
System.out.println(faktoriyel);

başlangıçkoşulgövdegüncelleme

  • Koşul gövdeden önce kontrol edilir.
  • Başlangıçta false ise gövde hiç çalışmaz.
  • Başlangıç döngüden önce, güncelleme gövdenin içinde yazılır.

Döngüler · Kodu adım adım çalıştır

Kod İzleme: while ile 5!

Başlangıç: sayi = 5 (5! hesaplanacak).

Çarpım biriktiricisi 1 ile başlar (0 olsaydı sonuç hep 0 olurdu).

Koşul: 5 > 1 → true → gövde çalışır.

faktoriyel = 1 × 5 = 5.

Güncelleme: sayi-- → 4. Koşul sona yaklaşır.

Koşul: 4 > 1 → true → gövde çalışır.

faktoriyel = 5 × 4 = 20.

Güncelleme: sayi-- → 3. Koşul sona yaklaşır.

Koşul: 3 > 1 → true → gövde çalışır.

faktoriyel = 20 × 3 = 60.

Güncelleme: sayi-- → 2. Koşul sona yaklaşır.

Koşul: 2 > 1 → true → gövde çalışır.

faktoriyel = 60 × 2 = 120.

Güncelleme: sayi-- → 1. Koşul sona yaklaşır.

Koşul: 1 > 1 → false → döngüden çıkılır.

120 yazılır: 5 × 4 × 3 × 2 = 120. Gövde 4 kez çalıştı; 1 ile çarpmaya gerek yok.

int sayi = 5;
int faktoriyel = 1;
while (sayi > 1) {
    faktoriyel *= sayi;
    sayi--;
}
System.out.println(faktoriyel);

do-while Döngüsü

Scanner klavye = new Scanner(System.in);
int secim;
do {
  System.out.print("Seçim (1/0): ");
  secim = klavye.nextInt();
  if (secim == 1)
    System.out.println("Merhaba!");
} while (secim != 0);
System.out.println("Güle güle");

başlangıçkoşulgövdegüncelleme

  • Koşul gövdeden sonra kontrol edilir → gövde en az bir kez çalışır.
  • Menü ve girdi doğrulama için doğal seçimdir.
  • while (…); sonundaki noktalı virgül unutulmamalı.

Döngüler · Kodu adım adım çalıştır

Kod İzleme: do-while menüsü (girdi 1, 2, 0)

Klavyeden okumak için Scanner (dosya başında import java.util.Scanner;). Kullanıcı sırayla 1, 2, 0 yazacak.

secim tanımlandı ama değeri yok; koşul ilk kez gövdeden sonra sorulacağı için sorun olmaz.

1. tur: koşula bakmadan gövdeye girilir, menü yazılır.

Kullanıcı 1 yazar → secim = 1.

secim == 1 → true: «Merhaba!» yazılır.

Koşul: 1 != 0 → true → başa dön.

2. tur: koşula bakmadan gövdeye girilir, menü yazılır.

Kullanıcı 2 yazar → secim = 2.

secim == 1 → false: hiçbir şey yapılmaz.

Koşul: 2 != 0 → true → başa dön.

3. tur: koşula bakmadan gövdeye girilir, menü yazılır.

Kullanıcı 0 yazar → secim = 0.

secim == 1 → false: hiçbir şey yapılmaz.

Koşul: 0 != 0 → false → döngü biter.

Gövde 3 kez çalıştı; koşul da 3 kez soruldu (while’da gövde sayısından bir fazla sorulurdu).

Scanner klavye = new Scanner(System.in);
int secim;
do {
  System.out.print("Seçim (1/0): ");
  secim = klavye.nextInt();
  if (secim == 1)
    System.out.println("Merhaba!");
} while (secim != 0);
System.out.println("Güle güle");

Dallanma

break ve continue

for (int i = 1; i <= 10; i++) {
    if (i % 3 == 0) continue;
    if (i == 8) break;
    System.out.print(i + " ");
}
System.out.println("| bitti");
  • continue: turun kalanını atlar, güncellemeye (i++) geçer.
  • break: en yakın döngüyü hemen bitirir.
  • Aşırı kullanım akışı izlemeyi zorlaştırır.

Dallanma · Kodu adım adım çalıştır

Kod İzleme: break ve continue

i = 1: 1 % 3 = 1 → false; 1 == 8 → false. İki kontrol de geçildi.

1 yazılır.

i = 2: 2 % 3 = 2 → false; 2 == 8 → false. İki kontrol de geçildi.

2 yazılır.

i = 3: 3 % 3 == 0 → true → continue: print atlanır, doğrudan i++.

i = 4: 4 % 3 = 1 → false; 4 == 8 → false. İki kontrol de geçildi.

4 yazılır.

i = 5: 5 % 3 = 2 → false; 5 == 8 → false. İki kontrol de geçildi.

5 yazılır.

i = 6: 6 % 3 == 0 → true → continue: print atlanır, doğrudan i++.

i = 7: 7 % 3 = 1 → false; 7 == 8 → false. İki kontrol de geçildi.

7 yazılır.

i = 8: 8 % 3 = 2 → false; 8 == 8 → true → break: döngü burada biter, 9 ve 10’a hiç gelinmez.

Döngü break ile bitti; akış döngüden sonraki satırdan sürer.

for (int i = 1; i <= 10; i++) {
    if (i % 3 == 0) continue;
    if (i == 8) break;
    System.out.print(i + " ");
}
System.out.println("| bitti");

Dallanma · Kodu adım adım çalıştır

Etiketli break dis: iki döngüden birden çık

i = 1, j = 1: 1·1 = 1 ≠ 4, 1 1 yazılır.

j = 2: 1·2 = 2 ≠ 4 → 1 2 yazılır.

j = 3: 1·3 = 3 ≠ 4 → 1 3 yazılır; iç döngü biter.

i = 2; iç döngü yeniden başlar: j = 1, 2·1 = 2 ≠ 4 → 2 1 yazılır.

i = 2, j = 2: 2·2 = 4 → break dis. Yazdırmadan her iki döngüden birden çıkılır; i = 3 hiç denenmez.

Etiketli break dış döngünün ardındaki satıra atlar: bitti yazılır. Çıktı: 4 sayı satırı + bitti.

dis:
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (i * j == 4) break dis;
        System.out.println(i + " " + j);
    }
}
System.out.println("bitti");

Dallanma · Kodu adım adım çalıştır

Karşılaştırma: düz break yalnızca iç döngüyü bitirir

i = 1: j = 1, 2, 3 için 1·j ≠ 4; 1 1, 1 2, 1 3 yazılır.

i = 2, j = 1: 2·1 = 2 ≠ 4 → 2 1 yazılır.

i = 2, j = 2: 2·2 = 4 → düz break yalnızca iç döngüyü bitirir; dış döngü devam eder.

i++ → 3; iç döngü yeniden başlar: j = 1 → 3 1 yazılır.

j = 2 ve j = 3: 3·2 = 6, 3·3 = 9 ≠ 4 → 3 2 ve 3 3 yazılır.

Dış döngü de biter, bitti yazılır. Düz break ile 7 sayı satırı, etiketli break ile 4 sayı satırı çıktı.

for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (i * j == 4) break;
        System.out.println(i + " " + j);
    }
}
System.out.println("bitti");

Döngüler

Sonsuz Döngü

  • Koşul hiçbir zaman false olmuyorsa döngü bitmez: program “donmuş” görünür.
  • Not: i-- ile int sınırı aşılırsa değer sarar ve döngü yaklaşık 4,3 milyar turdan sonra biter; pratikte sonsuz sayılır.
  • Sayaç yanlış yönde güncellenmiş ya da hiç güncellenmemiş olabilir.
  • Kasıtlı while (true) döngülerinde de içeride bir break koşulu olmalıdır. Takılırsa programı Ctrl+C ile durdurun.

Döngüler · Kodu adım adım çalıştır

double Sayaç Tuzağı: x += 0.1

Başlangıç: n = 0. Amaç 0,1’er artıp 10 tur dönmek.

x = 0.0, koşul 0.0 < 1.0 → true.

Gövde: n = 1.

Güncelleme: x = 0.1. 0,1 ikili tabanda tam gösterilemez; küçük hatalar birikir.

10. turun sonu (arada 8 tur atlandı): n = 10, x = 0.8999999999999999.

Güncelleme: x = 0.9999999999999999, tam 1.0 değil. Koşul true: döngü bir tur fazla döner.

11. tur: n = 11.

x = 1.0999999999999999, koşul false → döngü biter.

11 yazılır; beklenen 10 idi.

int n = 0;
for (double x = 0; x < 1.0; x += 0.1) {
    n++;
}
System.out.println(n);

x != 1.0 yazılsaydı x hiçbir zaman tam 1.0 olmayacağından döngü bitmezdi. Gerçek sayılarda sayaç yerine int kullanın.

Doğrulama

Döngü Değişmezi

  • Her turun başında doğru kalan bir özelliktir.
  • Toplam döngüsünde: toplam = 1 + 2 + … + (i − 1).
  • Döngü bitince (i = n + 1) değişmez, sonucun doğru olduğunu söyler.

Başlangıçta hiçbir sayı işlenmedi: toplam = 0 (boş toplam). Değişmez baştan doğru.

i = 2 turunun başında toplam, 1 … 1 sayılarının toplamı: 1.

i = 3 turunun başında toplam, 1 … 2 sayılarının toplamı: 3.

i = 4 turunun başında toplam, 1 … 3 sayılarının toplamı: 6.

i = 5 → koşul false. Değişmez hâlâ doğru: toplam = 1 + 2 + 3 + 4 = 10 → sonuç doğru.

Doğrulama

Sınır Hataları (1’den 5’e say)

  • < ile <=, 0 ile 1 başlangıcı arasındaki fark bir tur eksik/fazla demektir (“off-by-one”).
  • Test: ilk turu, son turu ve tur sayısını elle kontrol edin.

Doğrulama · Kodu adım adım çalıştır

Sınır Hatası Denetimi: i < 5 → 5 tur

Başlangıç: i = 0, sayac = 0. Koşul 0 < 5 → true.

Tur 1: i = 0 yazılır, sayac = 1 olur.

Tur 2: i = 1 yazılır, sayac = 2 olur.

Tur 3: i = 2 yazılır, sayac = 3 olur.

Tur 4: i = 3 yazılır, sayac = 4 olur.

Tur 5: i = 4 yazılır, sayac = 5 olur.

i++ → 5; 5 < 5 → false, döngü biter. Tam 5 tur: i = 0…4.

int sayac = 0;
for (int i = 0; i < 5; i++) {
    System.out.print(i + " ");
    sayac++;
}
System.out.println("| tur: " + sayac);

Doğrulama · Kodu adım adım çalıştır

Sınır Hatası: i <= 5 → 6 tur

Başlangıç: i = 0, sayac = 0. Koşul 0 <= 5 → true.

Tur 1: i = 0 yazılır, sayac = 1 olur.

Tur 2: i = 1 yazılır, sayac = 2 olur.

Tur 3: i = 2 yazılır, sayac = 3 olur.

Tur 4: i = 3 yazılır, sayac = 4 olur.

Tur 5: i = 4 yazılır, sayac = 5 olur.

Tur 6: i = 5 yazılır, sayac = 6 olur.

i++ → 6; 6 <= 5 → false. <= yüzünden fazladan bir tur döndü: sayac = 6, beklenen 5 değil.

int sayac = 0;
for (int i = 0; i <= 5; i++) {
    System.out.print(i + " ");
    sayac++;
}
System.out.println("| tur: " + sayac);

Örnek

Basamak Sayısı

int sayi = -507;
long kalan = sayi;
if (kalan < 0) kalan = -kalan;
int basamak = 0;
do {
    basamak++;
    kalan /= 10;
} while (kalan > 0);
System.out.println(basamak);
  • Her / 10 son basamağı atar; kaç kez bölündüğünü sayarız.
  • do-while sayesinde 0 da 1 basamak sayılır; ayrı bir özel durum gerekmez.
  • long kopya, -2147483648 gibi uç değerde işaret değiştirirken taşmayı önler.

Örnekler · Kodu adım adım çalıştır

Kod İzleme: basamak sayısı (sayi = −507)

Negatif bir sayıyla deneyelim: sayi = −507.

int değer long’a kopyalanır (−2147483648’in tersi int’e sığmaz, long’a sığar).

−507 < 0 → true → kalan = 507. İşaret basamak sayısını değiştirmez.

Sayaç basamak = 0.

Gövde: bir basamak sayıldı → basamak = 1.

kalan = 507 / 10 = 50 (tam sayı bölmesi son basamağı atar).

Koşul: 50 > 0 → true → tekrar.

Gövde: bir basamak sayıldı → basamak = 2.

kalan = 50 / 10 = 5 (tam sayı bölmesi son basamağı atar).

Koşul: 5 > 0 → true → tekrar.

Gövde: bir basamak sayıldı → basamak = 3.

kalan = 5 / 10 = 0 (tam sayı bölmesi son basamağı atar).

Koşul: 0 > 0 → false → bitti.

3 yazılır. sayi = 0 olsaydı do-while gövdeyi yine bir kez çalıştırır → 1 basamak (doğru).

int sayi = -507;
long kalan = sayi;
if (kalan < 0) kalan = -kalan;
int basamak = 0;
do {
    basamak++;
    kalan /= 10;
} while (kalan > 0);
System.out.println(basamak);

Örnek

Rakamlar Toplamı

int sayi = 725;
long kalan = sayi;
if (kalan < 0) kalan = -kalan;
int toplam = 0;
while (kalan > 0) {
    toplam += (int) (kalan % 10);
    kalan /= 10;
}
System.out.println(toplam);
  • % 10 son rakamı verir.
  • / 10 işlenen son rakamı sayıdan çıkarır.
  • Burada while yeterli: 0 için gövde hiç çalışmaz, toplam 0 kalır (doğru).

Örnekler · Kodu adım adım çalıştır

Kod İzleme: rakamlar toplamı (sayi = 725)

Rakamları 7, 2 ve 5 olan sayı: 725.

Üzerinde çalışmak için kopya: kalan = 725.

725 < 0 → false: işaret değişmez.

Biriktirici toplam = 0.

Koşul: 725 > 0 → true.

Son rakam 725 % 10 = 5; toplam = 0 + 5 = 5.

kalan = 725 / 10 = 72: işlenen rakam atıldı.

Koşul: 72 > 0 → true.

Son rakam 72 % 10 = 2; toplam = 5 + 2 = 7.

kalan = 72 / 10 = 7: işlenen rakam atıldı.

Koşul: 7 > 0 → true.

Son rakam 7 % 10 = 7; toplam = 7 + 7 = 14.

kalan = 7 / 10 = 0: işlenen rakam atıldı.

Koşul: 0 > 0 → false.

14 yazılır: 7 + 2 + 5 = 14. sayi değişmedi, yalnızca kopyası (kalan) tüketildi.

int sayi = 725;
long kalan = sayi;
if (kalan < 0) kalan = -kalan;
int toplam = 0;
while (kalan > 0) {
    toplam += (int) (kalan % 10);
    kalan /= 10;
}
System.out.println(toplam);

Örnekler · Kodu adım adım çalıştır

Sayıyı Ters Çevirme ve Palindrom (1221)

Rakamları tersten okununca da aynı kalan sayıya palindrom denir. Deneyelim: 1221.

Kopya üzerinde çalışılır; ters sayı 0’dan kurulacak.

Koşul: 1221 > 0 → true.

rakam = 1221 % 10 = 1; ters = 0 × 10 + 1 = 1 (eski rakamlar bir basamak sola kayar).

kalan = 1221 / 10 = 122.

Koşul: 122 > 0 → true.

rakam = 122 % 10 = 2; ters = 1 × 10 + 2 = 12 (eski rakamlar bir basamak sola kayar).

kalan = 122 / 10 = 12.

Koşul: 12 > 0 → true.

rakam = 12 % 10 = 2; ters = 12 × 10 + 2 = 122 (eski rakamlar bir basamak sola kayar).

kalan = 12 / 10 = 1.

Koşul: 1 > 0 → true.

rakam = 1 % 10 = 1; ters = 122 × 10 + 1 = 1221 (eski rakamlar bir basamak sola kayar).

kalan = 1 / 10 = 0.

Koşul: 0 > 0 → false.

Ters sayı 1221 yazılır.

1221 == 1221 → true: 1221 bir palindromdur. (123 için ters 321 olur → false.)

int sayi = 1221;
int kalan = sayi, ters = 0;
while (kalan > 0) {
    int rakam = kalan % 10;
    ters = ters * 10 + rakam;
    kalan /= 10;
}
System.out.println(ters);
System.out.println(ters == sayi);  // palindrom mu?

Örnekler · Kodu adım adım çalıştır

Armstrong Sayısı: 153 = 1³ + 5³ + 3³

Armstrong sayısı: rakamlarının (basamak sayısı kadar) kuvvetleri toplamı kendisine eşit. 153 üç basamaklı → küpler.

kalan = 153, toplam = 0.

Koşul: 153 > 0 → true.

r = 3; toplam = 0 + 3×3×3 = 27.

kalan /= 10 → 15.

Koşul: 15 > 0 → true.

r = 5; toplam = 27 + 5×5×5 = 152.

kalan /= 10 → 1.

Koşul: 1 > 0 → true.

r = 1; toplam = 152 + 1×1×1 = 153.

kalan /= 10 → 0.

Koşul: 0 > 0 → false.

1 + 125 + 27 = 153 → true. Diğer 3 basamaklı Armstrong sayıları: 370, 371, 407.

int sayi = 153;
int kalan = sayi, toplam = 0;
while (kalan > 0) {
    int r = kalan % 10;
    toplam += r * r * r;   // 3 basamak: küp
    kalan /= 10;
}

  for (int j = 0; j < n; j++) {
    if (i == 0 || i == n - 1 || j == 0 || j == n - 1)
      System.out.print("*");
    else
      System.out.print(" ");
  }
  System.out.println();
}
  • Yalnızca ilk/son satır veya ilk/son sütun yıldızdır.
  • ||: dört koşuldan biri true ise yeter.
  • Diğer hücrelere boşluk yazılır; yoksa kare kayar.

Bölüm Özeti

  • Her döngü başlangıç, koşul, gövde ve güncelleme parçalarından oluşur.

Alıştırmalar
