Soru 1: Koşul Kaç Kez Sorulur?

Aşağıdaki döngüde gövde (toplam += i) ve koşul (i <= n) kaçar kez çalışır?

int n = 4;
int toplam = 0;
for (int i = 1; i <= n; i++) {
    toplam += i;
}
System.out.println(toplam);

B: Koşul i = 1, 2, 3, 4 için true, i = 5 için false olur; o son (false) kontrol de bir değerlendirmedir. Gövde 4 kez çalışır, koşul 5 kez sorulur; ilk değer verme (int i = 1) yalnızca 1 kez. Çıktı 10.

Soru 2: continue Sonrası i Değeri

i döngüden önce bildirilmiş. Döngü bitince i kaçtır?

i döngünün dışında bildirilmiş: döngüden sonra da yaşar ve yazdırılabilir.

İlk değer verme: i = 1 (eski 0 değeri ezilir). 1 < 6 → true; 1 > 3 false.

i++ → 2; 2 > 3 false. Gövdede başka iş yok.

i = 3; 3 > 3 false.

i = 4; 4 > 3 → continue: turun kalanı atlanır, güncellemeye (i++) gidilir.

i = 5; yine continue → i++.

i = 6; 6 < 6 → false: döngü biter. continue döngüyü bitirmez, break bitirirdi.

6 yazılır. Döngü her zaman koşulu false yapan ilk değerde biter.

int i = 0;
for (i = 1; i < 6; i++) {
  if (i > 3)
    continue;
}
System.out.println(i);

Soru 3: i++ mı ++i mi?

İki döngünün çıktıları için hangisi doğrudur?

for (int i = 0; i < 3; i++)
    System.out.print(i + " ");
System.out.println();
for (int i = 0; i < 3; ++i)
    System.out.print(i + " ");

B: for'un güncelleme bölümünde ifadenin değeri kullanılmaz; i++ da ++i da yalnızca i'yi 1 artırır. Fark yalnızca değer bir ifadede kullanıldığında (ör. b = a++) ortaya çıkar.

Soru 4: sonuc *= sayac

Aşağıdaki metot çalıştırıldığında çıktısı ne olur?

void fonksiyon() {
    int sonuc = 1;
    int sayac = 6;
    for (int i = 3; i < sayac; i++) {
        sonuc *= sayac;
        System.out.print(sonuc + " ");
    }
}
Cevabı göster

Çıktı: 6 36 216

  • Tuzak: çarpılan sayac, i değil; sayac hep 6 kalır. i yalnızca tur sayar.
  • i = 3, 4, 5 → 6 − 3 = 3 tur: 6¹, 6², 6³.

Farklı başlangıçlar (sonuc, sayac, i): (1, 7, 4) → 7 49 343; (2, 7, 4) → 14 98 686; (2, 6, 3) → 12 72 432.

Soru 5: do-while En Az Bir Kez

İki döngüde de koşul baştan false. Çıktı nedir?

int n = 5;
do {
    System.out.print(n + " ");
    n++;
} while (n < 3);

int m = 5;
while (m < 3) {
    System.out.print(m + " ");
    m++;
}
System.out.println("| " + n + " " + m);
Cevabı göster

Çıktı: 5 | 6 5

  • do-while koşulu gövdeden sonra sorar: gövde bir kez çalışır (5 yazılır, n = 6), sonra 6 < 3 false.
  • while koşulu önce sorar: 5 < 3 false → gövde hiç çalışmaz, m = 5 kalır.
  • Menü ve girdi doğrulamada "en az bir kez" gerektiği için do-while seçilir.

Soru 7: double Sayaç

Döngünün 10 tur dönmesi bekleniyor. Çıktı nedir?

int n = 0;
for (double x = 0; x < 1.0; x += 0.1) {
    n++;
}
System.out.println(n);
Cevabı göster

Çıktı: 11

  • 0,1 ikili tabanda tam gösterilemez; küçük yuvarlama hataları birikir.
  • 10 toplamadan sonra x = 0.9999999999999999 olur, tam 1.0 değil → koşul true, bir tur fazla döner.
  • x = 1.0999999999999999 olunca döngü biter.

Ders: sayaçta int kullanın (ör. for (int k = 0; k < 10; k++) ve x = k * 0.1). x != 1.0 yazılsaydı döngü hiç bitmezdi.

for (int i = 1; i <= 12; i++) {

Soru 9: Dışta continue, İçte break

i == 3 dış döngüde continue, j == 3 iç döngüde break. Çıktıyı adım adım bulun.

i = 1: i == 3 false → iç döngü. j = 1: j == 3 false → yazdır.

j = 2 → yazdır.

j == 3 → break: yalnızca iç döngü biter; j = 4'e hiç gelinmez.

Dış döngü sürer: i = 2, iç döngü j = 1'den yeniden başlar.

j = 2 → yazdır.

j == 3 → break.

i == 3 → continue: dış turun kalanı (iç döngünün tamamı) atlanır, i++.

i = 4: iç döngü j = 1 → yazdır.

j = 2 → yazdır.

j == 3 → break.

5 <= 4 false: bitti. 6 satır; i = 3 satırı ve j = 3, 4 sütunları hiç yazılmadı.

for (int i = 1; i <= 4; i++) {
  if (i == 3) {
    continue;
  }
  for (int j = 1; j <= 4; j++) {
    if (j == 3) {
      break;
    }
    System.out.println("i: " + i + " j: " + j);
  }
}

Soru 10: j == 4 ise continue

Kod kaç satır yazar ve son satır hangisidir?

for (int i = 2; i < 5; i++) {
    if (i == 4) {
        break;
    }
    for (int j = 2; j < 5; j++) {
        if (j == 4) {
            continue;
        }
        System.out.println("i: " + i + " j: " + j);
    }
}

C: i = 2 ve 3 için j = 2, 3 yazılır, j = 4 atlanır: i: 2 j: 2, i: 2 j: 3, i: 3 j: 2, i: 3 j: 3. i = 4'te dıştaki break döngüyü bitirir, bu yüzden i: 4 … satırı olamaz.

İç döngünün başlangıcı dış değişkene bağlı. sayac kaç olur?

int sayac = 0;
for (int i = 1; i <= 4; i++) {
    for (int j = i; j <= 4; j++) {
        sayac++;
    }

System.out.println(sayac);

A: i = 1 → j = 1..4 (4 tur), i = 2 → 3, i = 3 → 2, i = 4 → 1: 4 + 3 + 2 + 1 = 10. 16 her iki döngünün de 1..4 tam dönmesi (4 × 4) olurdu; burada iç döngü her seferinde daha kısa.

Soru 13: Yıldız ve Tire Deseni

Aşağıdaki metot çalıştırıldığında çıktı ne olur?

public static void cizdir() {
    for (int i = 0; i < 5; i++) {
        for (int j = 0; j <= i; j++) {
            System.out.print("*");
        }
        for (int j = 0; j < 5 - i; j++) {
            System.out.print("-");
        }

}
Cevabı göster
  • Satır i: j <= i → i + 1 yıldız (0'dan başladığı için bir fazla).
  • j < 5 − i → 5 − i tire.
  • Her satır 6 karakter; son satır *****- (bir tire kalır).

Soru 14: Piramit

Satır i'de önce satirSayisi − i boşluk, sonra 2i − 1 yıldız yazılıyor. Çıktıyı satır satır kurun.

Her satır 2 parça: boşluklar (iç döngü j) ve yıldızlar (iç döngü k).

i = 1: 5 − 1 = 4 boşluk, 2·1 − 1 = 1 yıldız.

i = 2: 3 boşluk, 3 yıldız.

i = 3: 2 boşluk, 5 yıldız.

i = 4: 1 boşluk, 7 yıldız.

i = 5: j döngüsü hiç dönmez (1 <= 0 false), 9 yıldız.

6 <= 5 false: bitti. Boşluk azalırken yıldız 2'şer artar; toplam 1 + 3 + 5 + 7 + 9 = 25 yıldız.

int satirSayisi = 5;
for (int i = 1; i <= satirSayisi; i++) {
  for (int j = 1; j <= satirSayisi - i; j++) {
    System.out.print(" ");
  }
  for (int k = 1; k <= 2 * i - 1; k++) {
    System.out.print("*");
  }
  System.out.println();
}

Soru 17: Çift Sayıları Yazdırma

1'den 100'e kadar olan çift sayıları (2, 4, …, 100) yazdıran parça hangisidir?

C: 2'den başlayıp 2'şer artar, 100 de dahil (<=). A tek sayıları yazar. B 0..98 yazar: 0 fazla, 100 eksik. D'de / bölmedir, kalan değil: yalnızca i = 1 için 1 / 2 == 0 → 1 yazar. if (i % 2 == 0) ile yazılan çözüm de doğrudur.

Soru 18: do-while ile Basamak Sayısı

basamakSayisi(-305) çağrılıyor. Kaç döner?

Parametre sayi = −305.

Math.abs ile işaret atılır: basamak sayısı işaretten bağımsız.

Sayaç 0.

do: koşula bakmadan gövde. Sayaç 1, 305 / 10 = 30 (son basamak atıldı).

30 > 0 → true. Sayaç 2, 30 / 10 = 3. Aradaki 0 da bir basamaktır.

3 > 0 → true. Sayaç 3, 3 / 10 = 0.

0 > 0 → false: döngü biter.

3 döner. sayi = 0 ile çağrılsaydı do-while gövdeyi yine bir kez çalıştırır → 1 (doğru).

public static int basamakSayisi(int sayi) {
  sayi = Math.abs(sayi);
  int basamakSayisi = 0;
  do {
    basamakSayisi++;
    sayi /= 10;
  } while (sayi > 0);
  return basamakSayisi;
}

Soru 19: Sıfırın Basamak Sayısı

Üç farklı basamakSayisi çözümü veriliyor. Hangisi basamakSayisi(0) için yanlış sonuç (0) döndürür?

C: 0 > 0 false olduğu için while gövdesi hiç çalışmaz ve 0 döner; oysa 0 tek basamaklıdır. Bu çözüm negatif sayılar için de 0 döndürür (Math.abs yok). A (do-while) ve B (özel durum) doğru: ikisi de 1.
