Soru 1: Koşul Kaç Kez Sorulur?

Aşağıdaki döngüde gövde (toplam += i) ve koşul (i <= n) kaçar kez çalışır?

int n = 4;
int toplam = 0;
for (int i = 1; i <= n; i++) {
    toplam += i;
}
System.out.println(toplam);

B: Koşul i = 1, 2, 3, 4 için true, i = 5 için false olur; o son (false) kontrol de bir değerlendirmedir. Gövde 4 kez çalışır, koşul 5 kez sorulur; başlangıç (int i = 1) yalnızca 1 kez. Çıktı 10.

Soru 5: x += i İzleme

Döngü her turda x'i i kadar artırıyor. Program ne yazdırır?

Biriktirici 0 ile değil, 10 ile başlıyor: sonuç 10 fazla olacak.

1 <= 5 → true. x = 10 + 1 = 11.

i++ → 2; 2 <= 5 → true. x = 11 + 2 = 13.

x = 13 + 3 = 16.

x = 16 + 4 = 20.

x = 20 + 5 = 25.

i++ → 6; 6 <= 5 → false: döngü biter.

25 yazılır: 10 + (1 + 2 + 3 + 4 + 5) = 10 + 15.

int x = 10;
for (int i = 1; i <= 5; i++) {
  x += i;
}
System.out.println(x);

Soru 7: continue Sonrası i Değeri

i döngüden önce tanımlanmış. Döngü bitince i kaçtır?

i döngünün dışında tanımlı: döngüden sonra da yaşar ve yazdırılabilir.

Başlangıç i = 1 (eski 0 değeri ezilir). 1 < 6 → true; 1 > 3 false.

i++ → 2; 2 > 3 false. Gövdede başka iş yok.

i = 3; 3 > 3 false.

i = 4; 4 > 3 → continue: turun kalanı atlanır, güncellemeye (i++) gidilir.

i = 5; yine continue → i++.

i = 6; 6 < 6 → false: döngü biter. continue döngüyü bitirmez, break bitirirdi.

6 yazılır (cevap A). Döngü her zaman koşulu false yapan ilk değerde biter.

int i = 0;
for (i = 1; i < 6; i++) {
  if (i > 3)
    continue;
}
System.out.println(i);

Soru 8: i++ mı ++i mi?

İki döngünün çıktıları için hangisi doğrudur?

for (int i = 0; i < 3; i++)
    System.out.print(i + " ");

Soru 11: while(sayi > 2) Çarpımı

Her turda önce çarpılıyor, sonra sayi azaltılıp ara sonuç yazılıyor. Çıktı nedir?

Çarpım biriktiricisi 1 ile başlar.

6 > 2 → true. sonuc = 1 × 6 = 6, sayi = 5, 6 yazılır.

5 > 2 → sonuc = 6 × 5 = 30, sayi = 4.

4 > 2 → sonuc = 30 × 4 = 120, sayi = 3.

3 > 2 → sonuc = 120 × 3 = 360, sayi = 2.

2 > 2 → false: döngü biter. 4 tur döndü: 6 × 5 × 4 × 3 = 360.

int sonuc = 1;
int sayi = 6;
while (sayi > 2) {
  sonuc *= sayi;
  sayi--;
  System.out.print(sonuc + " ");
}

Soru 12: while(sayi > 3) Çarpımı

Aynı kalıp, farklı sayılar. Çıktı nedir?

int sonuc = 1;
int sayi = 7;
while (sayi > 3) {
    sonuc *= sayi;
    sayi--;

}

D: sayi = 7, 6, 5, 4 için koşul true (4 tur): 7, 7·6 = 42, 42·5 = 210, 210·4 = 840. sayi 3 olunca 3 > 3 false. A, 3 ile de çarpmak (>= sanmak) olurdu.

Soru 15: do-while En Az Bir Kez

İki döngüde de koşul baştan false. Çıktı nedir?

int n = 5;
do {
    System.out.print(n + " ");
    n++;
} while (n < 3);

int m = 5;
while (m < 3) {
    System.out.print(m + " ");
    m++;
}
System.out.println("| " + n + " " + m);
Cevabı göster

Çıktı: 5 | 6 5

  • do-while koşulu gövdeden sonra sorar: gövde bir kez çalışır (5 yazılır, n = 6), sonra 6 < 3 false.
  • while koşulu önce sorar: 5 < 3 false → gövde hiç çalışmaz, m = 5 kalır.
  • Menü ve girdi doğrulamada "en az bir kez" gerektiği için do-while seçilir.

Soru 17: double Sayaç

Döngünün 10 tur dönmesi bekleniyor. Çıktı nedir?

int n = 0;
for (double x = 0; x < 1.0; x += 0.1) {
    n++;

Soru 22: Dışta continue, İçte break

i == 3 dış döngüde continue, j == 3 iç döngüde break. Çıktıyı adım adım bulun.

i = 1: i == 3 false → iç döngü. j = 1: j == 3 false → yazdır.

j = 2 → yazdır.

j == 3 → break: yalnızca iç döngü biter; j = 4'e hiç gelinmez.

Dış döngü sürer: i = 2, iç döngü j = 1'den yeniden başlar.

j = 2 → yazdır.

j == 3 → break.

i == 3 → continue: dış turun kalanı (iç döngünün tamamı) atlanır, i++.

i = 4: iç döngü j = 1 → yazdır.

j = 2 → yazdır.

j == 3 → break.

5 <= 4 false: bitti. 6 satır; i = 3 satırı ve j = 3, 4 sütunları hiç yazılmadı.

for (int i = 1; i <= 4; i++) {
  if (i == 3) {
    continue;
  }
  for (int j = 1; j <= 4; j++) {
    if (j == 3) {
      break;
    }

Soru 29: Piramit

Satır i'de önce satirSayisi − i boşluk, sonra 2i − 1 yıldız yazılıyor. Çıktıyı satır satır kurun.

Her satır 2 parça: boşluklar (iç döngü j) ve yıldızlar (iç döngü k).

i = 1: 5 − 1 = 4 boşluk, 2·1 − 1 = 1 yıldız.

i = 2: 3 boşluk, 3 yıldız.

i = 3: 2 boşluk, 5 yıldız.

i = 4: 1 boşluk, 7 yıldız.

i = 5: j döngüsü hiç dönmez (1 <= 0 false), 9 yıldız.

6 <= 5 false: bitti. Boşluk azalırken yıldız 2'şer artar; toplam 1 + 3 + 5 + 7 + 9 = 25 yıldız.

int satirSayisi = 5;
for (int i = 1; i <= satirSayisi; i++) {
  for (int j = 1; j <= satirSayisi - i; j++) {
    System.out.print(" ");
  }
  for (int k = 1; k <= 2 * i - 1; k++) {
    System.out.print("*");
  }
  System.out.println();
}

Soru 35: while ile Faktöriyel

faktoriyelHesapla(4) çağrılıyor. sonuc ve i tur tur nasıl değişir, ne döner?

n = 4: 4! = 1·2·3·4 hesaplanacak.

Çarpım biriktiricisi 1 (0 olsaydı sonuç hep 0 olurdu); sayaç i = 1.

1 <= 4 → sonuc = 1·1 = 1, i = 2.

2 <= 4 → sonuc = 1·2 = 2, i = 3.

3 <= 4 → sonuc = 2·3 = 6, i = 4.

4 <= 4 → sonuc = 6·4 = 24, i = 5.

5 <= 4 → false: döngü biter.

24 döner. n = 0 için döngü hiç dönmez → 1 (0! = 1, doğru). long, 20!'e kadar sığar.

long faktoriyelHesapla(int n) {
  long sonuc = 1;
  int i = 1;
  while (i <= n) {
    sonuc *= i;
    i++;
  }
  return sonuc;
}

Soru 36: do-while ile Basamak Sayısı

basamakSayisi(-305) çağrılıyor. Kaç döner?

Parametre sayi = −305.

Math.abs ile işaret atılır: basamak sayısı işaretten bağımsız.

Sayaç 0.

do: koşula bakmadan gövde. Sayaç 1, 305 / 10 = 30 (son basamak atıldı).

30 > 0 → true. Sayaç 2, 30 / 10 = 3. Aradaki 0 da bir basamaktır.

3 > 0 → true. Sayaç 3, 3 / 10 = 0.

0 > 0 → false: döngü biter.

3 döner. sayi = 0 ile çağrılsaydı do-while gövdeyi yine bir kez çalıştırır → 1 (doğru).

public static int basamakSayisi(int sayi) {
  sayi = Math.abs(sayi);
  int basamakSayisi = 0;
  do {
    basamakSayisi++;
    sayi /= 10;
  } while (sayi > 0);
  return basamakSayisi;
}
