Soru 7: dizi[i] = dizi[dizi[i]]

Kodun çıktısı nedir? (Seçenekler: A) [0, 2, 3, 1] B) [0, 3, 1, 3] C) [2, 3, 2, 3] D) [0, 1, 2, 3])

Dört öğeli dizi. Dikkat: değerler aynı zamanda geçerli indislerdir (0–3).

i = 0; 0 < 4 → true.

dizi[0] = 0 → dizi[0] = dizi[0] = 0; değişiklik yok.

i = 1; 1 < 4 → true.

dizi[1] = 2 → dizi[1] = dizi[2] = 3.

i = 2; 2 < 4 → true.

dizi[2] = 3 → dizi[2] = dizi[3] = 1.

i = 3; 3 < 4 → true.

dizi[3] = 1 → dizi[3] = dizi[1]. dizi[1] artık 2 değil, i = 1 adımında yazılan 3!

i = 4; 4 < 4 → false, döngü biter.

Doğru şık B. Değişiklikler aynı dizide yapıldığı için sonraki adımlar güncellenmiş değerleri okur.

int[] dizi = {0, 2, 3, 1};
for (int i = 0; i < dizi.length; i++) {
    dizi[i] = dizi[dizi[i]];
}
System.out.println(Arrays.toString(dizi));

Soru 9: copyOf ve copyOfRange

Soru 16: En Küçük Öğeyi Bulma

bulMinimum metodu bu diziyle çağrılıyor. Değişkenleri adım adım izleyin.

main, yeni diziyi metoda gönderir.

İlk öğe aday olur (0 ile başlatmak pozitif dizide yanlış sonuç verirdi).

i = 1'den başlanır (dizi[0] zaten aday). 3 < 7 → true.

minimum = 3.

9 < 3 → false; minimum değişmez.

1 < 3 → true.

minimum = 1.

4 < 1 → false.

i = 5; 5 < 5 → false, döngü biter.

return 1; çerçeve kapanır.

1 yazdırılır. n öğeli dizide n − 1 karşılaştırma yapıldı.

static int bulMinimum(int[] dizi) {
    int minimum = dizi[0];
    for (int i = 1; i < dizi.length; i++) {
        if (dizi[i] < minimum) {
            minimum = dizi[i];
        }
    }
    return minimum;
}
// main içinde:
System.out.println(bulMinimum(new int[]{7, 3, 9, 1, 4}));

Soru 17: En Büyük: Yanlış Başlangıç

static int enBuyukEleman(int[] dizi) {
    int enBuyuk = 0;   // dizi[0] yerine

}

Soru 18: Ortalamada Tip Dönüşümü

static double ortalamaHesapla(int[] dizi) {
    int toplam = 0;
    for (int i = 0; i < dizi.length; i++)
        toplam += dizi[i];
    double ortalama = toplam / dizi.length;
    return ortalama;
}

B: toplam = 19; 19 / 4 iki int'in bölmesidir → 4 (kesir atılır). Sonra double'a atanınca 4.0 olur. Doğrusu (double) toplam / dizi.length → 4.75.

Soru 19: Ortalama ve Boş Dizi

Doğru ortalamaHesapla metodu üç farklı diziyle çağrılıyor. Çıktı nedir?

4.75
5.5
NaN

Soru 22: % 2 ve % 3 ile Değiştirme

Aşağıdaki kod çalıştırıldığında çıktı ne olur? Her öğenin hangi dala girdiğini izleyin.

On öğeli dizi. Her öğe için önce çift mi, değilse 3'e bölünüyor mu bakılacak.

20 % 2 == 0 → çift: 20 × 2 = 40.

15 tek, 15 % 3 == 0 → 15 × 3 = 45.

16 % 2 == 0 → çift: 16 × 2 = 32.

6 % 2 == 0 → çift: 6 × 2 = 12. (3'e de bölünür ama else if'e hiç bakılmaz.)

10 % 2 == 0 → çift: 10 × 2 = 20.

19 ne çift ne 3'e bölünüyor → değişmez.

12 % 2 == 0 → çift: 12 × 2 = 24. (3'e de bölünür ama else if'e hiç bakılmaz.)

5 ne çift ne 3'e bölünüyor → değişmez.

3 tek, 3 % 3 == 0 → 3 × 3 = 9.

13 ne çift ne 3'e bölünüyor → değişmez.

İkinci döngü diziyi yazdırır.

int[] dizi = {20, 15, 16, 6, 10, 19, 12, 5, 3, 13};
for (int i = 0; i < dizi.length; i++) {
    if (dizi[i] % 2 == 0) {
        dizi[i] *= 2;
    }
    else if (dizi[i] % 3 == 0) {
        dizi[i] *= 3;
    }
}
for (int i = 0; i < dizi.length; i++)
    System.out.print(dizi[i] + " ");

Soru 24: Ortanca Öğe

ortancaElemanBul metodunun çıktısı nedir?

static double ortancaElemanBul(int[] dizi) {
    Arrays.sort(dizi);
    if (dizi.length % 2 == 0) {
        int orta1 = dizi[dizi.length / 2 - 1];
        int orta2 = dizi[dizi.length / 2];
        return (orta1 + orta2) / 2.0;
    }
    return dizi[dizi.length / 2];
}
// main içinde:
System.out.println(ortancaElemanBul(new int[]{9, 2, 7, 4}));
System.out.println(ortancaElemanBul(new int[]{8, 1, 6, 3, 5}));
Cevabı göster

Çıktı:

5.5
5.0
  • Çift uzunluk (4): sıralı {2, 4, 7, 9}; ortadaki iki öğe indis 1 ve 2 → (4 + 7) / 2.0 = 5.5.
  • Tek uzunluk (5): sıralı {1, 3, 5, 6, 8}; indis 5 / 2 = 2 → 5; dönüş tipi double → 5.0.

Soru 29: Bir Konum Sağa Döndürme

Dizi, ek dizi kullanmadan bir konum sağa döndürülüyor (son öğe başa). Adım adım izleyin.

Başlangıç dizisi.

Son öğe kaybolmasın diye saklanır.

Sağdan sola gidilir: i = 3; 3 > 0 → true.

a[3] = a[2] = 3.

i = 2: a[2] = a[1] = 2.

i = 1: a[1] = a[0] = 1.

i = 0; 0 > 0 → false, döngü biter.

Saklanan değer başa yazılır.

Soldan sağa kaydırsaydık (i artarak) hep a[0] kopyalanırdı: [1, 1, 1, 1].

int[] a = {1, 2, 3, 4};
int son = a[a.length - 1];
for (int i = a.length - 1; i > 0; i--) {
    a[i] = a[i - 1];
}

Soru 30: Doğrusal Arama: Bulunamayan

Dersteki ara metodu için ara(d, 5) ne döndürür ve dizi[i] == hedef karşılaştırması kaç kez yapılır?

static int ara(int[] dizi, int hedef) {
    for (int i = 0; i < dizi.length; i++)
        if (dizi[i] == hedef) return i;
    return -1;
}
// main içinde:
int[] d = {8, 3, 6, 2};
System.out.println(ara(d, 5));

C: 5 dizide yoktur; dört öğenin hepsine bakılır (n karşılaştırma), döngü bitince return -1 çalışır. En kötü durum O(n).

Soru 31: İkili Arama: hedef = 11

Sıralı dizide 11 aranıyor. lo, hi ve mid değerlerini adım adım izleyin.

Arama aralığı tüm dizi: lo = 0, hi = 6.

0 <= 6 → mid = (0 + 6) / 2 = 3, a[3] = 15.

15 == 11 → false; 15 < 11 → false.

else: hi = mid − 1 = 2. Sağ yarı elendi.

0 <= 2 → mid = (0 + 2) / 2 = 1, a[1] = 8.

8 == 11 → false; 8 < 11 → true: lo = mid + 1 = 2.

2 <= 2 → mid = 2, a[2] = 11.

11 == 11 → sonuc = 2, break.

3 karşılaştırma turunda bulundu (doğrusal arama da 3 öğeye bakardı; büyük dizide fark O(log n) ile O(n) arasındadır).

int[] a = {3, 8, 11, 15, 20, 27, 31};
int hedef = 11, lo = 0, hi = a.length - 1;
int sonuc = -1;
while (lo <= hi) {
    int mid = (lo + hi) / 2;
    if (a[mid] == hedef) { sonuc = mid; break; }
    if (a[mid] < hedef) lo = mid + 1;
    else hi = mid - 1;
}
System.out.println(sonuc);

Soru 33: Kabarcık Sıralaması: İlk Geçiş

Kabarcık sıralamasının yalnızca ilk geçişi yapılıyor. Çıktı nedir?

int[] a = {5, 1, 4, 2, 3};
for (int j = 0; j < a.length - 1; j++) {
    if (a[j] > a[j + 1]) {
        int t = a[j]; a[j] = a[j + 1]; a[j + 1] = t;
    }
}
System.out.println(Arrays.toString(a));

Soru 35: Satır Toplamları

İç içe döngüler her satırın toplamını yazdırıyor. Çıktı nedir?

2 satır, 3 sütun.

i = 0 satırı; toplam her satır başında sıfırlanır.

toplam += m[0][0] → 1.

toplam += m[0][1] → 3.

toplam += m[0][2] → 6. Sonra j = 3 < 3 → false.

Satır toplamı yazılır.

i = 1 satırı; toplam yeniden 0.

toplam += m[1][0] → 4.

toplam += m[1][1] → 9.

toplam += m[1][2] → 15.

İkinci satırın toplamı yazılır.

i = 2; 2 < 2 → false. toplam = 0 satırı dış döngünün içinde olmasaydı ikinci sonuç 21 olurdu.

int[][] m = {{1, 2, 3}, {4, 5, 6}};
for (int i = 0; i < m.length; i++) {
    int toplam = 0;
    for (int j = 0; j < m[i].length; j++) {
        toplam += m[i][j];
    }
    System.out.print(toplam + " ");
}
