Temeller

Program Nedir?

  • Bilgisayarın belirli bir görevi yerine getirmesi için yürüttüğü komutlar bütünüdür.
  • Girdi alabilir, veriyi işler, durum saklar ve çıktı üretebilir.
  • Programın davranışı kullanılan dilin kuralları ve yazılan algoritma tarafından belirlenir.

Temeller

Programlama Dilinin Yönleri

  • Söz dizimi, kodun geçerli biçimini tanımlar.
  • Anlam, geçerli ifadenin çalıştırıldığında ne yaptığını açıklar.
  • Tür sistemi, değerlerle yapılabilecek işlemleri sınırlar.
  • Çalışma modeli belleğin ve komutların nasıl yürütüldüğünü etkiler.

JVM
Çıktı
  • Bytecode, uygun JVM bulunan farklı platformlarda çalıştırılabilir.
  • JDK geliştirme araçlarını, JVM yürütme ortamını sağlar.

Java

İlk Java Programı

public class Merhaba {
    public static void main(String[] args) {
        System.out.println("Merhaba");
    }
}
  • Sınıf adı ile dosya adı eşleşir: Merhaba.java.
  • main, klasik Java uygulamasının başlangıç noktasıdır.

Diller

Programlama Paradigmaları

  • Zorunlu yaklaşım işlemlerin nasıl yapılacağını adım adım belirtir.
  • Nesne yönelimli yaklaşım veri ve davranışı nesnelerde birleştirir.
  • Fonksiyonel yaklaşım dönüşümleri ve değişmez veriyi öne çıkarır.
  • Java birden fazla yaklaşımı birlikte kullanabilir.

Dil Yapısı

İfadeler ve Deyimler

  • İfade bir değer üretir: 2 + 3 veya sayi > 0.
  • Deyim bir işlemi tamamlar: toplam = 5; veya return toplam;.
  • Blok, süslü parantez içindeki deyimleri tek yapı olarak gruplar.

Dil Yapısı

İfade, Deyim ve Blok

int fiyat = 120;          // deyim
int adet = 3;             // deyim
int toplam = fiyat * adet; // ifade + atama
if (toplam > 300) {       // koşul + blok
    System.out.println("İndirim");
}

Veri

Değişkenler

  • Değişken, belirli türdeki değere anlamlı bir ad verir.
  • Tanımlama tür ve adı; ilk değer atama başlangıç değerini belirtir.
  • Değişken kullanılmadan önce kesin olarak atanmış olmalıdır.

Veri

Atama ve Güncelleme

  • Atama işleci sağdaki değeri soldaki değişkene yazar.
  • Yeni değer değişkenin türüyle uyumlu olmalıdır.
  • Bileşik atamalar mevcut değeri kullanarak günceller: toplam += fiyat.

Kontrol

Koşullu İfadeler

  • if, koşul true olduğunda bir bloğu çalıştırır.
  • else alternatif yolu; else if ek koşulları tanımlar.
  • Koşul boolean değer üretmelidir; sayı doğrudan koşul sayılmaz.

Veri

Dizgeler

  • String karakter dizisini temsil eden değiştirilemez bir nesnedir.
  • + işleci dizgeleri birleştirebilir.
  • İçerik karşılaştırmasında == yerine equals kullanılır.

Veri

Türler Farklı Davranır

System.out.println(2 + 3);       // 5
System.out.println("2" + "3");   // 23
System.out.println("Sonuç: " + 2 + 3); // Sonuç: 23
System.out.println("Sonuç: " + (2 + 3)); // Sonuç: 5
  • İşleç davranışı operand türlerine bağlıdır.
  • Parantez değerlendirme sırasını açıklaştırır.

Kodlamadan Önce

  • Örnek girdi ve beklenen çıktıyı yazın.
  • Çözümü doğal dil veya sözde kodla adımlara ayırın.
  • Sınır durumlarını ve hata davranışını belirleyin.
  • Ardından adımları Java yapılarına dönüştürün.

Özet

Bölüm Özeti

  • Java kaynak kodu bytecode'a derlenir ve JVM tarafından yürütülür.
  • İfadeler değer üretir, deyimler işlemi tamamlar, bloklar deyimleri gruplar.
  • Türler değerlerin temsilini ve geçerli işlemleri belirler.
  • Program tasarımı girdi, işlem, çıktı ve hata durumlarını koddan önce tanımlar.
