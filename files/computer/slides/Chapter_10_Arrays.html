Basics

What Is an Array?

  • Stores a fixed number of elements of one type in consecutive cells of a single object.
  • Elements are accessed by a zero-based index: nums[0] … nums[4].
  • The length (length) cannot change after creation.
  • An array variable holds not the elements but a reference (address) to the array object on the heap.

Variable → array object (reference arrow)

Basics

Arrays and Indices

  • The first index is 0, the last is length − 1 (5 elements → 0…4).
  • The address of a[i] is computed directly (start + i × cell size), so access takes constant time (O(1)) without walking the array.

  • Valid indices run from 0 to length − 1; negative indices and length itself are invalid.
  • The compiler doesn't catch this; the program stops at run time with ArrayIndexOutOfBoundsException.

The Enhanced for (for-each)

The enhanced for hands out the elements in order; there is no index.

Pass 1: score gets a copy of scores[0] (70).

score = 75; the array cell stays 70: only the copy changed.

75 is printed.

Pass 2: score gets a copy of scores[1] (88).

score = 93; the array cell stays 88: only the copy changed.

93 is printed.

Pass 3: score gets a copy of scores[2] (90).

score = 95; the array cell stays 90: only the copy changed.

95 is printed.

No elements left → the loop ends; score goes out of scope.

scores[0] is still 70: in an enhanced for, assigning to the loop variable doesn't change the array.

int[] scores = {70, 88, 90};
for (int score : scores) {
    score = score + 5;
    System.out.println(score);
}
System.out.println(scores[0]);

Sum and Average

A four-element array.

The accumulator starts at sum = 0.

value = 4 → sum += value: 0 + 4 = 4.

value = 7 → sum += value: 4 + 7 = 11.

value = 2 → sum += value: 11 + 2 = 13.

value = 6 → sum += value: 13 + 6 = 19.

The loop is done. avg starts at 0 (a safe value for an empty array).

4 > 0 → true: the array isn't empty, so dividing is safe.

(double) 19 / 4 = 4.75. Without the cast, integer division would give 4.

The results are printed.

Reversing an Array (two pointers)

The array to reverse.

Two pointers: left = 0 and right = length − 1 = 4.

0 < 4 → true, so the ends get swapped.

tmp = arr[0] = 1: the left value is saved so it isn't lost.

arr[0] = arr[4] → 5 goes into the left cell.

arr[4] = tmp → 1 goes into the right cell. Swap done.

The pointers move inward: left = 1, right = 3.

1 < 3 → true, so the ends get swapped.

tmp = arr[1] = 2: the left value is saved so it isn't lost.

arr[1] = arr[3] → 4 goes into the left cell.

arr[3] = tmp → 2 goes into the right cell. Swap done.

The pointers move inward: left = 2, right = 2.

2 < 2 → false: the pointers met in the middle → the array is reversed.

int[] arr = {1, 2, 3, 4, 5};
int left = 0, right = arr.length - 1;
while (left < right) {
    int tmp = arr[left];
    arr[left] = arr[right];
    arr[right] = tmp;
    left++;
    right--;
}

n/2 swaps; no extra array needed (in place, O(1) extra space).

The Second-Largest Element of an Array

Both candidates start at the smallest int (Integer.MIN_VALUE); each element is examined once.

7 > MIN → new largest: the old largest (MIN) drops to second, largest = 7.

12 > 7 → new largest: the old largest (7) drops to second, largest = 12.

No change: 5 is not greater than second (7).

No change: 12 == largest (a repeat) doesn't count.

9 is smaller than the largest but greater than second, and 9 != 12 → second = 9.

One pass gives 9 (12 appears twice, but the second largest is 9). If second is still Integer.MIN_VALUE, there is no second distinct value (empty, single-element or all-equal array).

int[] a = {7, 12, 5, 12, 9};
int largest = Integer.MIN_VALUE;
int second = Integer.MIN_VALUE;
for (int x : a) {
  if (x > largest) {
    second = largest;
    largest = x;
  } else if (x > second && x != largest) {
    second = x;
  }
}
System.out.println(second);

Sieve of Eratosthenes (boolean array)

All cells false: initially 2…20 are all prime candidates.

2 × 2 = 4 <= 20 → true.

2 is not crossed out → prime. Its multiples are marked starting from 2·2: k = 4, 6, 8, 10, 12, 14, 16, 18, 20.

3 × 3 = 9 <= 20 → true.

3 is not crossed out → prime. Its multiples are marked starting from 3·3: k = 9, 12, 15, 18.

4 × 4 = 16 <= 20 → true.

composite[4] = true → 4 is already crossed out; no need to visit its multiples.

5 × 5 = 25 <= 20 → false: no need to look for divisors above √20.

The numbers not crossed out are printed: 8 primes.

int n = 20;
boolean[] composite = new boolean[n + 1];
for (int i = 2; i * i <= n; i++)
  if (!composite[i])
    for (int k = i * i; k <= n; k += i)
      composite[k] = true;
for (int i = 2; i <= n; i++)
  if (!composite[i]) System.out.print(i + " ");

Copying Arrays

  • b = a copies the reference, not the elements: two arrows point to the same object.
  • For an independent copy use a.clone(), Arrays.copyOf(a, a.length) or System.arraycopy.
  • For arrays of objects these copy the element references; the objects themselves are not duplicated (shallow copy).

One array on the heap; a refers to it.

b = a: no new array is created; b gets the same reference → two arrows on one object.

b[0] = 99: the object b refers to changed, and it is a's object too!

Search

Sorting and Binary Search

  • Arrays.sort(a) sorts the array in ascending order in place (the original order is lost).
  • Arrays.binarySearch(a, x) works only on a sorted array; it returns the index if found, otherwise a negative value, -(insertion point) - 1.
  • It halves the range at each step, so it makes far fewer comparisons than linear search.
  • Both need import java.util.Arrays;.

Search

The Median

  • Median: the value in the middle of the sorted array; with an even count, the average of the middle two.
  • Unaffected by outliers: for {1, 2, 3, 4, 100} the average is 22.0, the median 3.
  • Arrays.sort changes the array in place, so a copy is sorted.
  • The (double) cast comes before the addition: two large ints can't overflow and the division keeps the fraction.
int[] a = {7, 3, 9, 1, 5};
int[] s = Arrays.copyOf(a, a.length);
Arrays.sort(s);    // a is untouched
int n = s.length;
double m = (n % 2 == 1) ? s[n / 2]
    : (s[n/2 - 1] + (double) s[n/2]) / 2;
System.out.println(m);   // 5.0

Sorting

Bubble Sort

int[] a = {5, 1, 4, 2};
int n = a.length;
for (int pass = 0; pass < n - 1; pass++) {
  for (int j = 0; j < n - 1 - pass; j++) {
    if (a[j] > a[j + 1]) {
      int tmp = a[j];
      a[j] = a[j + 1];
      a[j + 1] = tmp;
    }
  }
}
passarray after passcomp.swap
1[1, 4, 2, 5]33
2[1, 2, 4, 5]21
3[1, 2, 4, 5]10
  • Each pass moves the largest remaining element to the end; the inner loop gets one shorter each pass.
  • 3 + 2 + 1 = 6 comparisons in all → O(n²).
  • No swaps in pass 3: the array was already sorted after pass 2.

Sorting

Insertion Sort

int[] a = {4, 3, 5, 1};
for (int i = 1; i < a.length; i++) {
  int key = a[i];
  int j = i - 1;
  while (j >= 0 && a[j] > key) {
    a[j + 1] = a[j];
    j--;
  }
  a[j + 1] = key;
}
ikeyshifted rightarray after pass
134[3, 4, 5, 1]
25—[3, 4, 5, 1]
315, 4, 3[1, 3, 4, 5]
  • The left part is always sorted; elements larger than the key shift one place right, and the key drops into the gap.
  • Very fast on nearly sorted arrays; O(n²) in the worst case (reverse order).

The Shallow-Copy Trap in 2D Arrays

a is an outer array pointing to two row arrays.

a.clone() copies only the outer array: both outer arrays point to the same row objects (shallow copy).

b[0][0] = 99: b[0] and a[0] are the same row → a[0][0] is 99 too.

b[1] = new int[]{7, 8} only points b's cell at a new row; a[1] is unchanged.

a: shared row 0 changed (99); row 1 is still {3, 4}.

For a real copy, copy each row as well: b[i] = a[i].clone().

int[][] a = {{1, 2}, {3, 4}};
int[][] b = a.clone();
b[0][0] = 99;
b[1] = new int[]{7, 8};
System.out.println(Arrays.deepToString(a));
System.out.println(Arrays.deepToString(b));

Matrix Transpose

The source matrix is 2 × 3.

matrix.length = number of rows = 2.

matrix[0].length = length of the first row = 3.

The target t has the dimensions swapped: 3 × 2, all cells 0.

t[0][0] = matrix[0][0] = 1: rows ↔ columns swap.

t[1][0] = matrix[0][1] = 2: rows ↔ columns swap.

t[2][0] = matrix[0][2] = 3: rows ↔ columns swap.

t[0][1] = matrix[1][0] = 4: rows ↔ columns swap.

t[1][1] = matrix[1][1] = 5: rows ↔ columns swap.

t[2][1] = matrix[1][2] = 6: rows ↔ columns swap.

The loops are done: the rows of matrix became the columns of t.

int[][] matrix = {{1, 2, 3}, {4, 5, 6}};
int rows = matrix.length;
int cols = matrix[0].length;
int[][] t = new int[cols][rows];
for (int i = 0; i < rows; i++)
    for (int j = 0; j < cols; j++)
        t[j][i] = matrix[i][j];

Matrix Multiplication (2×2)

C[i][j] = the sum of products of row i of A and column j of B. C starts as zeros.

C[0][0] += 1 × 5 → 0 + 5 = 5

C[0][0] += 2 × 7 → 5 + 14 = 19 (cell done)

C[0][1] += 1 × 6 → 0 + 6 = 6

C[0][1] += 2 × 8 → 6 + 16 = 22 (cell done)

C[1][0] += 3 × 5 → 0 + 15 = 15

C[1][0] += 4 × 7 → 15 + 28 = 43 (cell done)

C[1][1] += 3 × 6 → 0 + 18 = 18

C[1][1] += 4 × 8 → 18 + 32 = 50 (cell done)

Three nested loops: n³ multiplications for an n×n matrix → O(n³). The column count of A must equal the row count of B.

int[][] A = {{1, 2}, {3, 4}};
int[][] B = {{5, 6}, {7, 8}};
int[][] C = new int[2][2];
for (int i = 0; i < 2; i++)
  for (int j = 0; j < 2; j++)
    for (int k = 0; k < 2; k++)
      C[i][j] += A[i][k] * B[k][j];

Design

Array or List?

  • If the number of elements is known and fixed, an array is simple and fast.
  • If the count will change, collections such as ArrayList are more convenient.
  • int[] stores the numbers directly; ArrayList<Integer> wraps each number in an object.
  • Choose based on usage, readability and measured performance.

Common Mistakes

One pass too many

i <= a.length reaches a[length] on the last pass → ArrayIndexOutOfBoundsException. Use i < a.length.

First element of an empty array

int min = a[0]; fails on an empty array; check a.length == 0 first.

Copying the reference

int[] b = a; is not a new array; b[0] = 9 changes a too. Use a.clone() for a copy.

Jagged matrices

Not every row has length matrix[0].length; use matrix[i].length in the inner loop.

Summary

Chapter Summary

Structure

A fixed number of elements of one type; indices 0 … length − 1; the variable refers to the array.

Access

a[i] reads and writes in constant time; an out-of-bounds index is a run-time error.

Traversal

Classic for (when you need the index) and enhanced for (assigning to the loop variable leaves the array alone); sum, min-max, reversing, searching.

Matrices

int[][] is an array of arrays: matrix.length rows, matrix[i].length columns.

Review Questions

  1. What is the last index of a five-element array?
  2. When is the enhanced for not enough?
  3. What is the difference between assigning an array and copying its elements?
  4. What precondition does binary search require?
  5. What do matrix.length and matrix[0].length give?
Answers
  1. 4 (length − 1).
  2. When you need the index: printing positions, writing a new value to a cell, traversing backward or walking two arrays together.
  3. Assignment (b = a) copies only the reference, so both variables refer to one object; clone/Arrays.copyOf create a new array.
  4. The array must be sorted.
  5. The number of rows and the number of columns of the first row.
