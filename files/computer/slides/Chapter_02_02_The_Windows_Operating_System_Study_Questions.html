Multiple Choice · Desktop

Question 1: Task View

Which item on the taskbar shows open windows and virtual desktops together?

A: Task view lists thumbnails of open windows and the desktops. The system tray shows background apps, quick settings show network/sound/battery, and the notification center shows notifications and the calendar.

Output Question · Desktop

Question 2: Clicks on the Taskbar

What opens on screen with each of the following actions?

  1. (a) Right-clicking the Start button
  2. (b) Clicking the network/sound icons
  3. (c) Clicking the clock
Show answer
  • (a) The context menu with extra system commands (Quick Link menu; also opens with Win+X). A left click opens the Start menu instead.
  • (b) Quick settings: Wi-Fi, Bluetooth, sound, brightness (Win+A).
  • (c) Notification center and calendar (Win+N).

The ^ in the system tray shows the hidden icons of apps running in the background.

Step-by-Step Trace · Window Management

Question 3: Window States

Word and Browser are open; Word is normal size and in front. How does the screen change as the actions are performed in order?

Word went down to the taskbar without closing (there is a line under its icon). The browser came to the front.

Clicking the icon brings Word back at its old size and makes it active.

Win+→: the active window (Word) snaps to the right half of the screen.

The browser snapped to the left half: two windows side by side.

Alt+Tab switches between open windows; the layout does not change, only Word becomes the active window.

Close closes only the Word window (it asks first if there are unsaved changes). The browser stays where it is.

1. Word: Minimize (—)
2. Word icon on the taskbar
3. Word: Win + →
4. Click the browser, Win + ←
5. Alt + Tab (Word is selected)
6. Word: Close (✕)

Multiple Choice · Window Management

Question 4: A New Virtual Desktop

What happens when Win+Ctrl+D is pressed?

C: The new desktop opens empty; apps on the old desktop keep running in the background. Showing the desktop is Win+D, closing a desktop is Win+Ctrl+F4.

Step-by-Step Trace · Window Management

Question 5: Three Virtual Desktops

Word and Browser are open on Desktop 1. The shortcuts are applied in order. Which desktop are we on, and where are the apps?

A new, empty Desktop 2 was created and switched to. The windows on Desktop 1 did not close.

Music is visible only on Desktop 2.

One more desktop: the new one is added at the far right and becomes active.

The game opened on Desktop 3.

Win+Ctrl+← switches to the desktop on the left: Desktop 2. The game keeps running in the background.

The active desktop (2) was closed: Music did not close; it was moved to Desktop 1 on the left. The game stays on its own desktop; the former Desktop 3 now takes the name Desktop 2.

1. Win + Ctrl + D
2. Open the Music app
3. Win + Ctrl + D
4. Open the game
5. Win + Ctrl + ←
6. Win + Ctrl + F4

Multiple Choice · Shortcuts

Question 6: Matching Shortcuts

Which of the following shortcut–function pairs is wrong?

D is wrong: Win+D shows the desktop. Task Manager opens with Ctrl+Shift+Esc.

Output Question · Shortcuts

Question 7: A Sequence of Shortcuts

With Word and the browser open, the following shortcuts are pressed in order. What is seen on screen after each step? Do the open applications close in the last step?

  1. Win+D
  2. Win+E
  3. Win+Shift+S
  4. Win+L
Show answer
  • 1: The desktop is shown; windows are hidden (not closed).
  • 2: A File Explorer window opens.
  • 3: The screen dims and the area to capture is selected; the image goes to the clipboard.
  • 4: The lock screen appears. The session is not closed; Word, the browser and Explorer stay open in the background, and you return with a password/PIN.

Signing out, on the other hand, closes open applications; locking does not.

Output Question · Shortcuts

Question 8: Delete and Shift+Delete

On the desktop (drive C:) there are a.txt, b.txt, c.txt. a.txt is selected and Delete is pressed; b.txt is selected and Shift+Delete is pressed (and confirmed). What is in the Recycle Bin? Which file can be restored?

Show answer

Only a.txt is in the Recycle Bin; Restore returns it to its original location.

  • Shift+Delete deletes permanently: b.txt does not go to the bin and cannot be undone.
  • On USB sticks and network locations, even Delete mostly deletes the file directly.

Multiple Choice · File Management

Question 9: Changing the Extension

With extensions visible, the file photo.jpg is renamed to photo.png with F2. What happens?

B: The extension is only a hint about the format; changing it does not convert the content. Real conversion is done in a program with Save As/Export. When the extension changes, Windows only shows a warning.

Step-by-Step Trace · File Management

Question 10: The Relative Path ..\..\

The current folder is C:\Users\Sercan\Documents\Courses. The path ..\..\Pictures\Holiday\sea.jpg is resolved piece by piece. Where are we after each piece?

A relative path starts from the current folder: Courses.

.. = parent folder: Courses → Documents.

Second ..: Documents → Sercan.

Go down into Pictures inside Sercan.

Go down into the Holiday subfolder.

The last piece is a file. Absolute equivalent: C:\Users\Sercan\Pictures\Holiday\sea.jpg.

Start: ...\Documents\Courses
1. ..
2. ..
3. Pictures
4. Holiday
5. sea.jpg

Output Question · File Management

Question 11: Copy, Cut, Paste

C:\Documents contains a.docx, b.jpg, c.txt; the USB stick (E:\) is empty. The following are done in order. Which files are in the two locations at the end?

  1. Select a.docx, Ctrl+C
  2. Open E:\, Ctrl+V
  3. In C:\Documents select b.jpg, Ctrl+X
  4. Open E:\, Ctrl+V
  5. Open a.docx in C:\Documents, change it, save
Show answer
  • Copy+Paste: a second, independent copy of a.docx is created.
  • Cut+Paste: b.jpg is removed from the source and moved to the target; the number of files does not change.
  • 5: Only a.docx in C:\ changes; the copy in E:\ keeps the old content.

Step-by-Step Trace · File Management

Question 12: Drag-and-Drop Rules

At the start, C:\Documents has photo.jpg, report.docx, note.txt; C:\Archive and E:\ are empty. What is the result of each drag-and-drop?

Initial state. Rule: same drive → move, different drive → copy.

C:\ → C:\ same drive: move. photo.jpg left Documents.

C:\ → E:\ different drive: copy. The original report.docx stayed in place.

Different drive but Shift held: move forced. note.txt left C:\.

E:\ → C:\ different drive, and Ctrl held: copy. In the end there are three separate copies of report.docx.

Summary: 1 and 3 are moves, 2 and 4 are copies. The tip next to the cursor while dragging (“Move” / “Copy”) should always be checked.

1. photo.jpg → C:\Archive
2. report.docx → E:\
3. note.txt → E:\ (Shift held)
4. E:\report.docx → C:\Archive
   (Ctrl held)

Output Question · File Management

Question 13: Copying a Shortcut to USB

The shortcut to report.pdf on the desktop is copied to a USB stick and double-clicked on another computer. What happens? If the desktop shortcut is deleted, what happens to the original file?

Show answer
  • A shortcut is a small .lnk file; it contains not the PDF but only the path of the original file.
  • On the other computer there is no file at this path, so the shortcut cannot be opened (target not found). Copying a shortcut to USB is not a backup.
  • Deleting the shortcut does not delete the original file; report.pdf stays where it is.
  • If the original file is moved to another folder, the shortcut still points to the old path, so it may still fail to open.

Multiple Choice · Settings

Question 14: Adding a Printer

In Windows 11, what path in Settings is followed to add a new printer?

B: Connected devices such as printers, mice and keyboards are under Bluetooth & devices. A printer on the network or USB is usually found automatically; if the printer driver cannot be found, it is downloaded from the manufacturer’s site.

Step-by-Step Trace · Settings

Question 15: Adding the Turkish F Keyboard

The computer has only the Turkish Q keyboard. You want to add and use Turkish F. What steps are followed?

Win+I opens the Settings app.

Language and keyboard settings are in the Time & language category.

Language options next to the language lists the keyboards of that language.

Turkish F was added; the active keyboard has not changed yet.

Win+Space switches between installed layouts; TR F appears on the taskbar.

Pressing it once more returns to Turkish Q. Between layouts of the same language the classic shortcut is Ctrl+Shift; Alt+Shift switches between languages.

1. Win + I
2. Time & language → Language & region
3. Turkish → Language options
4. Add a keyboard → Turkish F
5. Win + Space
6. Win + Space

Multiple Choice · Settings

Question 16: Standard and Administrator

On a lab computer, students should be able to do their daily work but not install programs or change system-wide settings. Which account type is suitable?

C: A standard user’s system changes are limited; installing apps and changing system settings require administrator rights. The principle of safe use: use administrator rights only when needed.

Output Question · Settings

Question 17: Default App and Open With

The default app for .pdf files is Edge. In which app does homework.pdf open in the following actions?

  1. homework.pdf is double-clicked.
  2. Right-click → Open with → Acrobat Reader is chosen (“always use” is not ticked).
  3. homework.pdf is double-clicked again.
  4. From Settings → Apps → Default apps, Acrobat is chosen for .pdf, then it is double-clicked.
Show answer
  • 1: Edge (default).
  • 2: Acrobat Reader, only this time.
  • 3: Edge again: Open with is a one-time choice; it does not change the default.
  • 4: Acrobat Reader: the default was changed for the file type.

The default app is the program Windows automatically chooses when a file type is opened.

Multiple Choice · Security and Maintenance

Question 18: The Dangerous Download Warning

Which component of Windows Security warns about dangerous downloads and malicious sites?

A: SmartScreen checks downloaded files and sites. Firewall shows network connections, Device security shows hardware protections; BitLocker is drive encryption.

Multiple Choice · Security and Maintenance

Question 19: Optimization for SSDs

What operation does the Optimize Drives tool apply to an SSD?

D: On an HDD, fragmented files are consolidated; on an SSD, TRIM is performed. There is no need to run classic defragmentation on an SSD by hand; Windows chooses the operation suitable for the drive type.

Classic Question · Security and Maintenance

Question 20: Which Recovery Tool?

For each situation, choose the most suitable tool from the lecture (from light to heavy: OneDrive folder backup, File History, Restore Point, Reset this PC).

  1. A file deleted yesterday from Documents, which is backed up with OneDrive, is wanted back.
  2. Last week’s version of a file regularly saved to an external disk is wanted.
  3. After a new device driver update the system is unstable; documents are intact.
  4. The system is completely broken; personal files must be preserved, apps can go.
Show answer
  • (a) OneDrive folder backup: the deleted file is restored from the OneDrive recycle bin.
  • (b) File History: older versions on the external drive (the drive must be connected).
  • (c) Restore Point: system files and settings roll back; it does not back up personal documents.
  • (d) Reset this PC → Keep my files: Windows is reinstalled, personal files stay, apps are removed. This is the last resort.
