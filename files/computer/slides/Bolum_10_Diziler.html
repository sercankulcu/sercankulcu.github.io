Diziyi döngülerle gezmek ve dönüştürmek.

Matris

İki boyutlu dizilerle satır-sütun işlemleri yapmak.

Temeller

Dizi Nedir?

  • Aynı tipte, sabit sayıda öğeyi tek nesnede ardışık hücrelerde saklar.
  • Öğelere sıfır tabanlı indisle erişilir: sayilar[0] … sayilar[4].
  • Uzunluk (length) oluşturulduktan sonra değişmez.
  • Dizi değişkeni öğeleri değil, heap'teki dizi nesnesinin referansını (adresini) tutar.

Değişken → dizi nesnesi (referans oku)

Temeller

Dizi ve İndis

  • İlk indis 0, son indis length − 1'dir (5 öğe → 0…4).
  • a[i] adresi doğrudan hesaplanır (başlangıç + i × hücre boyu); bu yüzden erişim diziyi gezmeden, sabit sürede (O(1)) olur.

Kod İzleme: Dizi Oluşturma

Tanımlama: yığında yalnızca sayilar adlı referans değişkeni açılır; henüz bir dizi yok.

new int[4] heap'te 4 hücreli dizi oluşturur, hepsi 0. Değişkene dizinin referansı yazılır (ok).

sayilar[0] = 7: ok izlenir, 0 numaralı hücreye 7 yazılır.

sayilar[3] = 2: son hücre (indis length − 1 = 3) güncellenir.

İlklendirici {…}: 3 değer var → uzunluk 3 olan dizi kurulur ve adlar onu gösterir.

length bir alandır (parantez yok): 4 ve 3 yazılır.

int[] sayilar;
sayilar = new int[4];
sayilar[0] = 7;
sayilar[3] = 2;
String[] adlar = {"Ada", "Can", "Ece"};
System.out.println(sayilar.length + " "
                   + adlar.length);

Erişim · Kodu adım adım çalıştır

Öğe Okuma ve Yazma

Üç öğeli dizi oluşur; indisler 0, 1, 2.

Okuma: puanlar[0] ilk hücredeki değeri verir → ilk = 70.

Yazma: atamanın solundaki puanlar[1] hücrenin kendisidir; 85 silinir, 88 yazılır.

puanlar.length - 1 = 3 − 1 = 2 → son öğe 90. Dizi boyu değişse de kod doğru kalır.

İki değer aralarında boşlukla yazdırılır.

int[] puanlar = {70, 85, 90};
int ilk = puanlar[0];
puanlar[1] = 88;
int son = puanlar[puanlar.length - 1];
System.out.println(ilk + " " + son);

Erişim

Sınır Dışı Hatası

  • Geçerli indisler 0 ile length − 1 arasındadır; negatif indis ve length'in kendisi geçersizdir.
  • Derleyici bunu yakalamaz; program çalışırken ArrayIndexOutOfBoundsException ile durur.
Döngü koşulunda i < dizi.length kullanın; <= bir tur fazla döner.

Erişim · Kodu adım adım çalıştır

Kod İzleme: Bir Tur Fazla (<=)

Uzunluğu 3 olan dizi: geçerli indisler 0, 1, 2.

0 <= 3 → true, gövdeye girilir.

a[0] = 4 yazdırılır.

i++ → 1 <= 3 → true, gövdeye girilir.

a[1] = 8 yazdırılır.

i++ → 2 <= 3 → true, gövdeye girilir.

a[2] = 6 yazdırılır.

i++ → 3 <= 3 → true — dikkat: 3 geçersiz indis ama koşul yine de doğru!

a[3]: böyle bir hücre yok → program hata ile durur. Çözüm: koşulu i < a.length yapmak.

int[] a = {4, 8, 6};
for (int i = 0; i <= a.length; i++) {
    System.out.println(a[i]);
}

Klasik for ile Gezinme

Dizi hazır; i indis olarak 0'dan başlayacak.

int i = 0; 0 < 3 → true

puanlar[0] = 70; %d: %d kalıbı 0: 70 üretir.

i++ → 1 < 3 → true

puanlar[1] = 88; %d: %d kalıbı 1: 88 üretir.

puanlar[2] = 90; %d: %d kalıbı 2: 90 üretir.

i++ → 3 < 3 → false → döngü biter; i = length olduğu için a[i]'ye hiç erişilmez.

int[] puanlar = {70, 88, 90};
for (int i = 0; i < puanlar.length; i++) {
  System.out.printf("%d: %d%n", i, puanlar[i]);
}

İndis gerektiğinde (konum yazdırmak, komşu öğeye bakmak, hücreye yazmak) klasik for kullanılır.

Gelişmiş for (for-each)

Gelişmiş for dizinin öğelerini sırayla verir; indis yoktur.

1. tur: puan'a puanlar[0]'nin kopyası (70) konur.

puan = 75 olur; dizideki hücre 70 olarak kalır — değişen yalnızca kopya.

75 yazdırılır.

2. tur: puan'a puanlar[1]'nin kopyası (88) konur.

puan = 93 olur; dizideki hücre 88 olarak kalır — değişen yalnızca kopya.

93 yazdırılır.

3. tur: puan'a puanlar[2]'nin kopyası (90) konur.

puan = 95 olur; dizideki hücre 90 olarak kalır — değişen yalnızca kopya.

95 yazdırılır.

Öğe kalmadı → döngü biter; puan değişkeni kapsam dışına çıkar.

puanlar[0] hâlâ 70: gelişmiş for'da döngü değişkenine atama diziyi değiştirmez.

int[] puanlar = {70, 88, 90};
for (int puan : puanlar) {
    puan = puan + 5;
    System.out.println(puan);
}
System.out.println(puanlar[0]);

Toplam ve Ortalama

Dört öğeli dizi.

Biriktirici toplam = 0 ile başlar.

deger = 4 → toplam += deger: 0 + 4 = 4.

deger = 7 → toplam += deger: 4 + 7 = 11.

deger = 2 → toplam += deger: 11 + 2 = 13.

deger = 6 → toplam += deger: 13 + 6 = 19.

Döngü bitti. ortalama 0 ile başlatılır (boş dizi için güvenli değer).

4 > 0 → true: dizi boş değil, bölme yapılabilir.

(double) 19 / 4 = 4.75. Dönüşüm olmasa tam sayı bölmesi 4 verirdi.

Sonuçlar yazdırılır.

int[] sayilar = {4, 7, 2, 6};
int toplam = 0;
for (int deger : sayilar) toplam += deger;
double ortalama = 0;
if (sayilar.length > 0)
    ortalama = (double) toplam / sayilar.length;
System.out.println(toplam + " " + ortalama);

En Küçük ve En Büyük

Dizi: 5, 3, 9, 1.

İlk öğe hem min hem max adayıdır (0 ile başlatmak negatif/pozitif dizilerde yanlış sonuç verirdi).

1. tur: deger = 5.

5 < 5 → false; min değişmez.

5 > 5 → false; max değişmez.

2. tur: deger = 3.

3 < 5 → true: min = 3.

3 > 5 → false; max değişmez.

3. tur: deger = 9.

9 < 3 → false; min değişmez.

9 > 5 → true: max = 9.

4. tur: deger = 1.

1 < 3 → true: min = 1.

1 > 9 → false; max değişmez.

Tüm öğelere bakıldı (n = 4 tur) → 1 9.

int[] sayilar = {5, 3, 9, 1};
int min = sayilar[0], max = sayilar[0];
for (int deger : sayilar) {
    if (deger < min) min = deger;
    if (deger > max) max = deger;
}
System.out.println(min + " " + max);

Boş dizide sayilar[0] hata verir; gerçek kodda önce sayilar.length == 0 durumu ele alınmalıdır.

Diziyi Ters Çevirme (iki işaretçi)

Tersine çevrilecek dizi.

İki işaretçi: sol = 0 ve sag = length − 1 = 4.

0 < 4 → true, uçlar yer değiştirecek.

gecici = dizi[0] = 1: soldaki değer kaybolmasın diye saklanır.

dizi[0] = dizi[4] → sol hücreye 5 yazılır.

dizi[4] = gecici → sağ hücreye 1. Takas tamam.

İşaretçiler merkeze yaklaşır: sol = 1, sag = 3.

1 < 3 → true, uçlar yer değiştirecek.

gecici = dizi[1] = 2: soldaki değer kaybolmasın diye saklanır.

dizi[1] = dizi[3] → sol hücreye 4 yazılır.

dizi[3] = gecici → sağ hücreye 2. Takas tamam.

İşaretçiler merkeze yaklaşır: sol = 2, sag = 2.

2 < 2 → false: işaretçiler ortada buluştu → dizi ters çevrildi.

int[] dizi = {1, 2, 3, 4, 5};
int sol = 0, sag = dizi.length - 1;
while (sol < sag) {
    int gecici = dizi[sol];
    dizi[sol] = dizi[sag];
    dizi[sag] = gecici;
    sol++;
    sag--;
}

n/2 takas yapılır; ek dizi gerekmez (yerinde, O(1) ek alan).

Ortalamanın Üstündekileri Sayma

Beş öğrencinin notu. Önce ortalama, sonra ortalamanın üstündekiler: iki geçiş gerekir.

1. geçiş: toplam biriktirilir.

x = 60 → toplam = 60.

x = 75 → toplam = 135.

x = 90 → toplam = 225.

x = 45 → toplam = 270.

x = 80 → toplam = 350.

(double) 350 / 5 = 70.0.

2. geçiş için sayaç: ustte = 0.

60 > 70.0 → false.

75 > 70.0 → true: ustte = 1.

90 > 70.0 → true: ustte = 2.

45 > 70.0 → false.

80 > 70.0 → true: ustte = 3.

Ortalama 70.0, üstünde 3 not var.

int[] notlar = {60, 75, 90, 45, 80};
int toplam = 0;
for (int x : notlar) toplam += x;
double ort = (double) toplam / notlar.length;
int ustte = 0;
for (int x : notlar)
  if (x > ort) ustte++;
System.out.println(ort + " " + ustte);

Dizideki En Büyük İkinci Öğe

İki aday en küçük int değeriyle (Integer.MIN_VALUE) başlar; her öğe bir kez incelenir.

7 > MIN → yeni en büyük: eski en büyük (MIN) ikinciye iner, enBuyuk = 7.

12 > 7 → yeni en büyük: eski en büyük (7) ikinciye iner, enBuyuk = 12.

Değişiklik yok: 5 ikinciden (7) büyük değil.

Değişiklik yok: 12 == enBuyuk (tekrar), sayılmaz.

9 en büyükten küçük ama ikinciden büyük ve 9 != 12 → ikinci = 9.

Tek geçişte sonuç: 9 (12 iki kez geçse de ikinci en büyük 9'dur).

int[] a = {7, 12, 5, 12, 9};
int enBuyuk = Integer.MIN_VALUE;
int ikinci = Integer.MIN_VALUE;
for (int x : a) {
  if (x > enBuyuk) {
    ikinci = enBuyuk;
    enBuyuk = x;
  } else if (x > ikinci && x != enBuyuk) {
    ikinci = x;
  }
}
System.out.println(ikinci);

Frekans Sayma: Zar Histogramı

Atışlar sabit verildi (gerçekte rastgele.nextInt(6) + 1). 7 hücreli sayaç: indis = zar değeri (0 kullanılmaz). Bu, değeri indis olarak kullanma hilesidir.

zar = 3 → sayac[3]++ → 1. if-else zincirine gerek yok!

zar = 6 → sayac[6]++ → 1. if-else zincirine gerek yok!

zar = 3 → sayac[3]++ → 2. if-else zincirine gerek yok!

zar = 1 → sayac[1]++ → 1. if-else zincirine gerek yok!

zar = 6 → sayac[6]++ → 2. if-else zincirine gerek yok!

zar = 3 → sayac[3]++ → 3. if-else zincirine gerek yok!

y = 1: sayac[1] = 1 kadar yıldız.

y = 2: sayac[2] = 0 kadar yıldız (hiç yok).

y = 3: sayac[3] = 3 kadar yıldız.

y = 4: sayac[4] = 0 kadar yıldız (hiç yok).

y = 5: sayac[5] = 0 kadar yıldız (hiç yok).

y = 6: sayac[6] = 2 kadar yıldız.

int[] atislar = {3, 6, 3, 1, 6, 3};
int[] sayac = new int[7];
for (int zar : atislar)
  sayac[zar]++;
for (int y = 1; y <= 6; y++) {
  System.out.print(y + ": ");
  for (int k = 0; k < sayac[y]; k++)
    System.out.print("*");
  System.out.println();
}

Eratosthenes Eleği (boolean dizi)

Tüm hücreler false: başlangıçta 2…20 hepsi asal adayı.

2 × 2 = 4 <= 20 → true.

2 elenmemiş → asal. Katları 2·2'den başlayarak işaretlenir: k = 4, 6, 8, 10, 12, 14, 16, 18, 20.

3 × 3 = 9 <= 20 → true.

3 elenmemiş → asal. Katları 3·3'den başlayarak işaretlenir: k = 9, 12, 15, 18.

4 × 4 = 16 <= 20 → true.

asalDegil[4] = true → 4 zaten elenmiş, katlarına bakmaya gerek yok.

5 × 5 = 25 <= 20 → false: √20'den büyük bölen aramaya gerek yok.

Elenmemiş olanlar yazdırılır: 8 asal.

int n = 20;
boolean[] asalDegil = new boolean[n + 1];
for (int i = 2; i * i <= n; i++)
  if (!asalDegil[i])
    for (int k = i * i; k <= n; k += i)
      asalDegil[k] = true;
for (int i = 2; i <= n; i++)
  if (!asalDegil[i]) System.out.print(i + " ");

Kod İzleme: Referans Kopyası ve Öğe Kopyası

Heap'te bir dizi; a onu gösterir.

b = a: yeni dizi oluşmaz; b'ye aynı referans yazılır → iki ok aynı nesnede.

b[0] = 99: b'nin gösterdiği nesne değişti — bu, a'nın da nesnesi!

a[0] artık 99. Referans kopyası bağımsız bir dizi değildir.

a.clone() heap'te yeni bir dizi açar ve öğeleri tek tek kopyalar.

c[1] = 50 yalnızca kopyayı değiştirir.

a[1] = 2 (değişmedi), c[1] = 50.

int[] a = {1, 2, 3};
int[] b = a;
b[0] = 99;
System.out.println(a[0]);
int[] c = a.clone();
c[1] = 50;
System.out.println(a[1] + " " + c[1]);

Arama · Kodu adım adım çalıştır

Doğrusal Arama: ara(d, 6)

main'de dizi oluşturulur.

ara(d, 6) çağrılır: yeni çerçeve açılır; dizi parametresi aynı diziyi gösterir (referans aktarılır).

0 < 4 → true, i = 0.

dizi[0] == 6 → 8 == 6 → false.

1 < 4 → true, i = 1.

dizi[1] == 6 → 3 == 6 → false.

2 < 4 → true, i = 2.

dizi[2] == 6 → 6 == 6 → true: return 2, döngü erken biter.

Çerçeve kapanır, dönen 2 yazdırılır. Hedef yoksa n karşılaştırmadan sonra −1 dönerdi → O(n).

static int ara(int[] dizi, int hedef) {
    for (int i = 0; i < dizi.length; i++)
        if (dizi[i] == hedef) return i;
    return -1;
}
// main içinde:
int[] d = {8, 3, 6, 2};
System.out.println(ara(d, 6));

Sıralama · Kodu adım adım çalıştır

Kabarcık Sıralaması (Bubble Sort)

Sıralanacak dizi. Kabarcık sıralaması komşu öğeleri karşılaştırır, büyük olanı sağa iter.

n = 4; en fazla n − 1 = 3 geçiş gerekir.

1. geçiş başlar (gecis = 0); j en fazla 2'e kadar gider.

a[0] > a[1] → 5 > 1 → true: yer değiştirir (gecici ile takas).

a[1] > a[2] → 5 > 4 → true: yer değiştirir (gecici ile takas).

a[2] > a[3] → 5 > 2 → true: yer değiştirir (gecici ile takas).

2. geçiş başlar (gecis = 1); j en fazla 1'e kadar gider.

a[0] > a[1] → 1 > 4 → false: sıra doğru, dokunulmaz.

a[1] > a[2] → 4 > 2 → true: yer değiştirir (gecici ile takas).

3. geçiş başlar (gecis = 2); j en fazla 0'a kadar gider.

a[0] > a[1] → 1 > 2 → false: sıra doğru, dokunulmaz.

Geçişler bitti: her geçişte en büyük öğe sona yerleşti (yeşil çizgi). Karşılaştırma sayısı 3 + 2 + 1 = 6 → O(n²).

int[] a = {5, 1, 4, 2};
int n = a.length;
for (int gecis = 0; gecis < n - 1; gecis++) {
  for (int j = 0; j < n - 1 - gecis; j++) {
    if (a[j] > a[j + 1]) {
      int gecici = a[j];
      a[j] = a[j + 1];
      a[j + 1] = gecici;
    }
  }
}

Eklemeli Sıralama (Insertion Sort)

Sol taraf her zaman sıralı tutulur (yeşil); sıradaki öğe bu kısma doğru yerine sokulur.

i = 1: anahtar = a[1] = 3 alınır; j = 0.

a[0] = 4 > 3 → 4 bir sağa kayar (a[1] = 4), j = -1.

j < 0 (başa gelindi) → döngü durur; a[0] = 3. İlk 2 öğe sıralı.

i = 2: anahtar = a[2] = 5 alınır; j = 1.

a[1] = 4 <= 5 → döngü durur; a[2] = 5. İlk 3 öğe sıralı.

i = 3: anahtar = a[3] = 1 alınır; j = 2.

a[2] = 5 > 1 → 5 bir sağa kayar (a[3] = 5), j = 1.

a[1] = 4 > 1 → 4 bir sağa kayar (a[2] = 4), j = 0.

a[0] = 3 > 1 → 3 bir sağa kayar (a[1] = 3), j = -1.

j < 0 (başa gelindi) → döngü durur; a[0] = 1. İlk 4 öğe sıralı. Neredeyse sıralı dizide çok hızlı; en kötü durumda O(n²).

int[] a = {4, 3, 5, 1};
for (int i = 1; i < a.length; i++) {
  int anahtar = a[i];
  int j = i - 1;
  while (j >= 0 && a[j] > anahtar) {
    a[j + 1] = a[j];
    j--;
  }
  a[j + 1] = anahtar;
}

İkili Arama: hedef = 23

Dizi sıralı olmalı. Arama aralığı tüm dizi: lo = 0, hi = 7.

0 <= 7 → 1. tur: mid = (0 + 7) / 2 = 3, a[mid] = 12.

12 < 23 → sol yarı elenir: lo = 4.

4 <= 7 → 2. tur: mid = (4 + 7) / 2 = 5, a[mid] = 23.

23 == 23 → bulundu: sonuc = 5, döngüden çıkılır.

5 yazdırılır. 2 turda bulundu (doğrusal arama 6 karşılaştırma yapardı) → O(log n).

int[] a = {2, 5, 8, 12, 16, 23, 38, 56};
int hedef = 23, lo = 0, hi = a.length - 1;
int sonuc = -1;
while (lo <= hi) {
  int mid = (lo + hi) / 2;
  if (a[mid] == hedef) { sonuc = mid; break; }
  if (a[mid] < hedef) lo = mid + 1;
  else hi = mid - 1;
}
System.out.println(sonuc);

Arama · Kodu adım adım çalıştır

Başarısız Arama: Arrays.binarySearch(a, 5) → -3

ara({2, 4, 6, 8}, 5) çağrısı: dizi sıralı, aranan 5 dizide yok.

Parametreler: a dizisi, x = 5. Arama aralığı tüm dizi: lo = 0, hi = 3.

mid = (0 + 3) / 2 = 1: a[1] = 4, 5’e eşit değil.

4 < 5 → aranan sağ yarıda: lo = mid + 1 = 2. {2, 4} elendi.

mid = (2 + 3) / 2 = 2: a[2] = 6, 5’e eşit değil.

6 < 5 yanlış → sol yarıda: hi = mid - 1 = 1. Artık lo > hi.

2 <= 1 yanlış → döngü biter, 5 yok. return -(lo + 1) = -(2 + 1) = -3. lo = 2, 5’in dizide girmesi gereken indistir.

-3 yazılır. Negatif sonuç “yok” demektir; ekleme noktası = -(-3) - 1 = 2. Arrays.binarySearch da aynı değeri döndürür.

static int ara(int[] a, int x) {
  int lo = 0, hi = a.length - 1;
  while (lo <= hi) {
    int mid = (lo + hi) / 2;
    if (a[mid] == x) return mid;
    if (a[mid] < x) lo = mid + 1; else hi = mid - 1;
  }
  return -(lo + 1);
}
System.out.println(ara(new int[]{2, 4, 6, 8}, 5));

Matris Transpozu

Kaynak matris 2 × 3.

matris.length = satır sayısı = 2.

matris[0].length = ilk satırın uzunluğu = 3.

Hedef t boyutları ters: 3 × 2, hücreler 0.

t[0][0] = matris[0][0] = 1: satır ↔ sütun yer değiştirir.

t[1][0] = matris[0][1] = 2: satır ↔ sütun yer değiştirir.

t[2][0] = matris[0][2] = 3: satır ↔ sütun yer değiştirir.

t[0][1] = matris[1][0] = 4: satır ↔ sütun yer değiştirir.

t[1][1] = matris[1][1] = 5: satır ↔ sütun yer değiştirir.

t[2][1] = matris[1][2] = 6: satır ↔ sütun yer değiştirir.

Döngüler bitti: matrisin satırları t'nin sütunları oldu.

int[][] matris = {{1, 2, 3}, {4, 5, 6}};
int satirSayisi = matris.length;
int sutunSayisi = matris[0].length;
int[][] t = new int[sutunSayisi][satirSayisi];
for (int i = 0; i < satirSayisi; i++)
    for (int j = 0; j < sutunSayisi; j++)
        t[j][i] = matris[i][j];

Matris Çarpımı (2×2)

C[i][j] = A'nın i. satırı ile B'nin j. sütununun çarpımlarının toplamı. C sıfırlarla başlar.

C[0][0] += 1 × 5 → 0 + 5 = 5

C[0][0] += 2 × 7 → 5 + 14 = 19 (hücre tamam)

C[0][1] += 1 × 6 → 0 + 6 = 6

C[0][1] += 2 × 8 → 6 + 16 = 22 (hücre tamam)

C[1][0] += 3 × 5 → 0 + 15 = 15

C[1][0] += 4 × 7 → 15 + 28 = 43 (hücre tamam)

C[1][1] += 3 × 6 → 0 + 18 = 18

C[1][1] += 4 × 8 → 18 + 32 = 50 (hücre tamam)

Üç iç içe döngü: n×n matris için n³ çarpma → O(n³). Sütun sayısı (A) = satır sayısı (B) olmalı.

int[][] A = {{1, 2}, {3, 4}};
int[][] B = {{5, 6}, {7, 8}};
int[][] C = new int[2][2];
for (int i = 0; i < 2; i++)
  for (int j = 0; j < 2; j++)
    for (int k = 0; k < 2; k++)
      C[i][j] += A[i][k] * B[k][j];
