    Word: Styles, Navigation Pane and Table of Contents

    Goal: See the difference between making a heading “big and bold” (direct formatting) and giving it a Heading style: a style comes from a single definition, and when it changes every paragraph that uses it updates together; the Navigation Pane and the table of contents are built only from heading styles.

    How to use it

    1. Click a paragraph on the page (or a heading in the Navigation Pane). Use ↑/↓ to move between paragraphs.
    2. Home · Styles: Normal, Heading 1, Heading 2, Heading 3. Modify… changes the size, color and weight of a style: every paragraph that uses the style is updated; but a property given directly to a paragraph (e.g. Font Color) overrides the style and does not change.
    3. Clear (Clear All Formatting) removes the direct formatting and returns the paragraph to the Normal style. In this simulation, applying a style also removes the direct formatting given to the whole paragraph.
    4. References → Table of Contents inserts the table at the start of the document. The table is a field: it does not refresh by itself when headings or pages change; a dashed orange outline means “out of date”. Update Table (F9) refreshes it.
    5. Page Break (Ctrl+Enter) and a Next Page section break move the selected paragraph to a new page; only the section break starts a new section. Orientation applies to all pages of the section that contains the selected paragraph.
    6. Try it yourself: an operation is described; predict its result, then the operation is applied and shown.

    Notes

    • Heading styles have “Keep with next” turned on: if the paragraph after a heading does not fit, the heading moves to the next page together with it. In this simulation paragraphs are never split across pages.
    • Word's “Update Table of Contents” dialog lets you choose “Update page numbers only” or “Update entire table”; here the entire table is always updated.
