Data

Variables

  • A variable is a named box in memory set aside for a value of a given type.
  • A declaration gives the type and name; initialization gives the starting value.
  • The type determines the box's size and the values it can hold.
  • A local variable must be definitely assigned before it is used.

Data Types

Choosing an Integer Type

  • int is the default for most integer math; long literals take an L suffix.
  • Integer arithmetic past the range overflows: Java raises no error, and the value silently wraps to the other end.
  • Integer.MAX_VALUE + 1 → -2147483648.
  • If large values are expected, choose long from the start.

Data · Run the code step by step

Overflow: Integer.MAX_VALUE + 1

Integer.MAX_VALUE: sign bit 0, the other 31 bits all 1. The largest number an int can hold.

x++ adds 1: the bits carry over and the sign bit becomes 1. The result is no error but −2147483648: the number wraps around like a clock.

A byte has 8 bits: its largest value is 127 (0111 1111).

b++ gives 127 + 1: the bits become 1000 0000 → −128. The same wraparound in a smaller box. Note: byte + byte is an int; 8-bit overflow appears only with a (byte) cast or compound operators such as += and ++.

Output: -2147483648 -128. Both variables wrapped from the largest value to the smallest.

Overflow is neither a compile error nor a runtime error. To catch it, methods such as Math.addExact throw an exception.

int x = Integer.MAX_VALUE;
x++;
byte b = 127;
b++;
System.out.println(x + " " + b);

Data Types

Floating-Point Numbers

  • double is the default for most approximate math; a float literal needs an F suffix.
  • Binary floating point cannot represent some decimal values (such as 0.1) exactly.
  • For exact decimal math such as money, choose a suitable class (BigDecimal) and a rounding rule.

Data Types · Run the code step by step

Comparing Floating-Point Numbers

0.1 and 0.2 have no exact binary form; the sum is not 0.3 but a value very close to it.

Printing reveals the tiny error: 0.30000000000000004.

a == 0.3 → false. The same holds for 0.1 + 0.2 == 0.3. Floating-point numbers are not compared with ==.

The difference is about 5.55E-17, so Math.abs(a - 0.3) < 1e-9 → true. Test the difference against a small threshold (epsilon).

double a = 0.1 + 0.2;
System.out.println(a);
System.out.println(a == 0.3);
System.out.println(Math.abs(a - 0.3) < 1e-9);

Data Types

char and boolean

  • A char is written in single quotes; it stores one UTF-16 code unit (as a number): 'A' = 65.
  • A String, written in double quotes, is an object; the variable holds a reference to it. It is not the same type as char.
  • A boolean takes only true or false; it is not interchangeable with 0/1.

Data · Run the code step by step

char Arithmetic: Letters Are Numbers

c = 'A'. A char is really a number: the Unicode code point of 'A' is 65.

c++ adds 1 to the code point: 65 → 66, so c = 'B'. The type is still char.

The expression c + 1 is an int (66 + 1 = 67). k is an int, so it holds the number 67, not a letter.

To store the result as a letter you need a (char) cast: d = 'C'. Without it, char d = c + 1; does not compile.

Output: B 67 C. A char prints as a letter, an int as a number.

char c = 'A';
c++;
int k = c + 1;
char d = (char)(c + 1);
System.out.println(c + " " + k + " " + d);

Variables

Declaration and Initialization

int age;          // declaration

  • A final variable is assigned only once.

Variables in Memory Step by Step

Declaration: an int box named age is set aside, but it has no value. Reading it now is a compile error.

First assignment: the value 20 on the right goes into the age box.

The right-hand side is computed first: age + 1 → 20 + 1 → 21. The box has not changed yet.

The result goes into the same box: the old 20 is overwritten, age = 21.

A double named avg is declared and assigned 82.5 in the same statement.

avg += 5 means avg = avg + 5: 82.5 + 5 → 87.5.

The box is updated: avg = 87.5.

final constant: 100 is assigned once. Writing MAX = 200; would be a compile error.

The age box is read and 21 is printed. Reading does not change the value.

avg is read: 87.5. Final state: 3 boxes, 2 lines of output.

int age;                  // declaration
age = 20;                 // first assignment
age = age + 1;            // update
double avg = 82.5;        // declare + initialize
avg += 5;                 // compound assignment
final int MAX = 100;      // constant
System.out.println(age);
System.out.println(avg);

Data

Assignment and Update

  • The assignment operator = computes the right-hand side first, then stores the value in the variable on the left.
  • The new value must be compatible with the variable's type.
  • Compound assignment updates using the current value: total += price ≡ total = total + price.

Start: total = 50, price = 20.

First both boxes are read and the right-hand side is computed.

The result goes into the box on the left: total = 70. price does not change.

Conversion

Assignment Compatibility

  • Conversion from a narrower to a wider type (widening) is automatic: double d = 7;
  • Narrowing risks losing information, so it needs an explicit conversion (a cast).
  • A conversion does not change the source variable; it only affects the result.

Conversion

Type Conversion

int count = 7;
double wide = count;      // 7.0
double ratio = 9.8;
int narrow = (int) ratio; // 9
int quot = 5 / 2;          // 2
double exact = 5.0 / 2;    // 2.5
  • Converting a double to int drops the fractional part.
  • Converting after the operation does not bring back a lost fraction.

Conversion · Run the code step by step

Type Conversion Step by Step

count: an int box (32 bits), value 7.

Widening: the int value converts automatically into the double box: 7 → 7.0. No information is lost.

ratio: a double box (64 bits), value 9.8.

Narrowing: (int) must be written explicitly. The fraction is dropped (not rounded): 9.8 → 9. ratio is still 9.8.

5 and 2 are both int → integer division: 5 / 2 = 2, the remainder is dropped.

5.0 is a double, so 2 widens to 2.0 as well: 5.0 / 2.0 = 2.5.

int count = 7;
double wide = count;      // 7.0
double ratio = 9.8;
int narrow = (int) ratio; // 9
int quot = 5 / 2;          // 2
double exact = 5.0 / 2;    // 2.5

The result 2 (int) is printed.

The result 2.5 (double) is printed.

Conversion

Type Promotion Order

  • In a mixed expression, the smaller type is automatically promoted to the larger: int + double → double.
  • byte, short and char become int before any arithmetic, so b + 1 is an int.
  • Going against the arrow (narrowing) needs an explicit (type) cast.

Operators · Run the code step by step

Increment and Decrement: i++ vs ++i

i = 5.

Postfix i++: the expression's value is i's old value → a = 5.

Then i is incremented: i = 6.

Prefix ++i: i is incremented first → i = 7.

The expression's value is the new value → b = 7.

i-- as a statement on its own: prefix vs postfix doesn't matter → i = 6.

Output: 6 5 7. Code is easier to read when ++ and -- stand alone as statements.

int i = 5;
int a = i++;   // use, then increment
int b = ++i;   // increment, then use
i--;
System.out.println(i + " " + a + " " + b);

Operators · Run the code step by step

Compound Assignment Casts Implicitly

b = 10: an 8-bit byte box.

The compiler turns b += 5 into b = (byte)(b + 5): the addition is done in int and the result is narrowed to byte automatically → b = 15.

i = 5 (int).

i += 3.7 also casts implicitly: 8.7 is computed and (int) drops the fraction → i = 8 (no rounding).

Without compound assignment, b = b + 5; does not compile: b + 5 is an int and int → byte is not converted implicitly. That line is left as a comment.

Output: 15 8.

byte b = 10;
b += 5;
int i = 5;
i += 3.7;
// b = b + 5;   // won't compile: int → byte
System.out.println(b + " " + i);

Operators

Operator Precedence

  • Parentheses are evaluated first; unary ! and casts come early too.
  • Multiplication, division and remainder come before addition and subtraction.
  • Comparisons come after arithmetic, and && / || after comparisons.
  • Operators at the same level go left to right (except assignment). Parentheses make your intent visible.

Operators · Step by step

Expression Tree: 2 + 3 * 4 > 10 && 7 % 2 == 1

The compiler turns the expression into a tree by precedence: the lowest operation is computed first, the root (&&) last.

* comes before +: 3 * 4 = 12.

Then the addition: 2 + 12 = 14.

Comparison: 14 > 10 → true (boolean). The left side is true, so && moves to the right side.

On the right, the remainder first: 7 % 2 = 1.

Comparison: 1 == 1 → true (boolean).

Root: true && true → true. Because the left side was true, the right side had to be evaluated too.

Operators · Run the code step by step

Mixed Expression: a / b * 2.0 + a % b

a = 7, b = 2 (int).

/, * and % share a precedence level and go left to right; + comes after them all.

First: a / b has two ints, so it is integer division: 7 / 2 = 3 (the .5 is dropped).

Then 3 * 2.0: 3 is promoted to double → 6.0.

The right side of +: 7 % 2 = 1 (remainder).

Last: 6.0 + 1: the int is promoted to double → 7.0; r = 7.0 (double).

Output: 7.0. Integer division made it 3 × 2.0 = 6.0; with a / 2.0 it would be 3.5 × 2.0 + 1 = 8.0. Order and types decide the result.

int a = 7, b = 2;
double r = a / b * 2.0 + a % b;
System.out.println(r);

Operators

Short-Circuit Evaluation

int a = 10, b = 0;
if (b != 0 && a / b > 2) {
    System.out.println("Large ratio");
}
  • If the first condition is false, && does not evaluate the second: the result is already false.
  • With b = 0, evaluating a / b would throw an ArithmeticException (division by zero); the short circuit prevents it.
  • || skips the second condition if the first is true. That is why the order of conditions matters.

Operators · Run the code step by step

Short Circuit Step by Step: b = 0 and b = 2

a = 10, b = 0.

Left condition: b != 0 → 0 != 0 → false.

Short circuit: false && (anything) → false. The right side never runs; since a / b is not computed, there is no division by zero either.

The condition is false → the block is skipped and nothing is printed.

Set b = 2 and try the same if again.

Left condition: 2 != 0 → true. The result is not known yet, so the right side must be evaluated too.

Right condition: a / b → 10 / 2 = 5; 5 > 2 → true. true && true → true.

We enter the block: Large ratio. Had the conditions been reversed (a / b > 2 && b != 0), the program would crash with b = 0.

int a = 10, b = 0;
if (b != 0 && a / b > 2) {
    System.out.println("Large ratio");
}
b = 2;
if (b != 0 && a / b > 2) {
    System.out.println("Large ratio");
}

Types Behave Differently

System.out.println(2 + 3);       // 5
System.out.println("2" + "3");   // 23
System.out.println("Result: " + 2 + 3); // Result: 23
System.out.println("Result: " + (2 + 3)); // Result: 5
  • An operator's behavior depends on the operand types.
  • Parentheses make the order of evaluation explicit.

Input · Run the code step by step

Scanner Input Flow Step by Step

The Scanner object is attached to the keyboard (System.in). The buffer is empty.

print writes the prompt with no line break; the cursor sits after "Age: ".

The buffer is empty, so nextInt() waits. The user types 20 and presses Enter: "20⏎" enters the buffer.

nextInt reads only the number (20); the ⏎ stays in the buffer.

nextLine() reads up to ⏎: it returns the empty string ("") and consumes the ⏎. The buffer is clear.

The prompt "Name: " is printed.

The buffer is empty, so nextLine waits; the user types Ada Yılmaz and presses Enter.

nextLine reads the whole line (spaces included): name = "Ada Yılmaz". The ⏎ is consumed but not included in the line.

Output

Formatted Output: printf

String name = "Ada";
double avg = 87.456;
System.out.printf("%-10s %6.2f%n", name, avg);

%s string · %d integer · %f floating point · %n newline. Some locales, such as Turkish, use a decimal comma (87,46); this course uses a period (Locale.US). In such a locale nextDouble() expects “37,5”, and “37.5” throws InputMismatchException.

Output · Run the code step by step

Decode a printf Format Step by Step

The format string is scanned left to right: the %... format specifiers are filled with the arguments in order, and other characters are copied as is.

%-8s: a string, 8 characters wide; - left-aligns it → "Ada " (3 letters + 5 spaces).

| is copied as is. %6.2f: 3.14159 is rounded to 2 digits (3.14) and right-aligned in 6 characters (2 spaces). A Turkish locale prints 3,14.

%05d: an integer, 5 characters wide; the 0 flag pads with zeros instead of spaces → 00042.

%n adds a newline. Output: Ada | 3.14|00042. The decimal separator depends on the locale; pass Locale.US for a period.

System.out.printf("%-8s|%6.2f|%05d%n",
                  "Ada", 3.14159, 42);

Swapping Two Variables

a = 5, b = 8. Goal: swap the values (a = 8, b = 5).

a = b → a = 8. a's old value 5 is gone!

b = a → b = 8. The 5 is no longer in any box.

Output 8 8: the swap failed. Keeping one value requires a third box.

The values are reset to 5 and 8.

temp = a → temp = 5: a's value is safe.

a = b → a = 8.

b = temp → b = 5.

Output 8 5: swap done. It took 3 assignments and 1 temporary variable.

int a = 5, b = 8;
a = b;                // wrong attempt
b = a;
System.out.println(a + " " + b);
a = 5; b = 8;         // start over
int temp = a;         // the right way
a = b;
b = temp;
System.out.println(a + " " + b);

Area and Circumference of a Circle: r = 2.5

Radius r = 2.5.

Area = π · r · r = 3.14159… · 2.5 · 2.5 = 19.634954084936208. Math.PI is a ready-made constant.

Circumference = 2 · π · r = 15.707963267948966.

%.2f rounds to two places: 19.63. The value in the variable does not change.

Circumference: 15.71 (15.7079… → 15.71).

Example · Run the code step by step

Seconds → hours:minutes:seconds (3725)

total = 3725 seconds.

hours = total / 3600 → 3725 / 3600 = 1 (integer division: how many whole hours).

rem = total % 3600 → 3725 % 3600 = 125 (remainder: seconds left after the whole hours).

mins = rem / 60 → 125 / 60 = 2 (integer division: how many whole minutes).

secs = rem % 60 → 125 % 60 = 5 (remainder: seconds left after the whole minutes).

%02d: at least 2 digits, padded with 0 instead of a space → 1:02:05. Check: 1·3600 + 2·60 + 5 = 3725.

int total = 3725;
int hours = total / 3600;
int rem = total % 3600;
int mins = rem / 60;
int secs = rem % 60;
System.out.printf("%d:%02d:%02d%n",
                  hours, mins, secs);

Summary

Chapter Summary

  • A variable gives a meaningful name to a value of a given type and must get a value before it is read.
  • The primitive types differ in their value sets and memory needs.
  • Widening is automatic; narrowing needs an explicit cast and can lose information.
  • Operator precedence and operand types directly determine an expression's result.
  • User input must be validated for both type and business rules.
