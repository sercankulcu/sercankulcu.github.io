Çoktan Seçmeli · Java Çalışma Modeli

Soru 1: javac Nerede?

Java derleyicisi javac aşağıdakilerden hangisinin parçasıdır?

C: JDK = JRE + geliştirme araçları (javac, jar, javadoc…). JRE = JVM + sınıf kütüphanesi ve yalnızca çalıştırmak için yeterlidir. Program yazıp derleyecek geliştirici JDK kurar.

Çoktan Seçmeli · Java Çalışma Modeli

Soru 2: Derleme ve Çalıştırma Komutları

Merhaba.java dosyasını derleyip çalıştırmak için doğru komut sırası hangisidir?

B: javac dosya adını uzantısıyla alır ve Merhaba.class üretir. java komutuna ise sınıf adı verilir, .class uzantısı yazılmaz. D'de JVM "Merhaba.class" adlı bir sınıf arar ve bulamaz.

Çoktan Seçmeli · Java Çalışma Modeli

Soru 3: Tek Adımda Çalıştırma

Java 11 ve sonrasında, hiç derlenmemiş bir klasörde java Merhaba.java komutu çalıştırılırsa ne olur?

D: Java 11+ tek dosyalık programlar için "kaynak dosya modu" sunar: derleme ve çalıştırma tek adımda yapılır, derlenen bytecode diske yazılmaz. Arka planda yine derleme vardır; JVM her zaman bytecode yürütür.

Soru 4: Konsol Oturumu

Klasörde yalnızca Merhaba.java var (ekrana Merhaba yazan program). Komutlar sırayla çalıştırılınca konsolda ne görünür?

Henüz Merhaba.class yok: JVM çalıştıracak sınıfı bulamaz.

Derleme başarılı: javac hiçbir şey yazmaz, yalnızca .class dosyası oluşur.

java sınıf adı bekler; "Merhaba.class" adlı sınıf aranır, bulunamaz. Uzantı yazılmaz!

Doğru komut: program çalışır.

Kaynak değişti ama yeniden derlenmedi: JVM eski .class'ı çalıştırır, yine Merhaba yazar.

Yeniden derleme sonrası değişiklik görünür: Selam. (Java 11+ sürümlerinde hata iletilerinin altına bir "Caused by" satırı da eklenir.)

> java Merhaba
> javac Merhaba.java
> java Merhaba.class
> java Merhaba
// Kaynakta "Merhaba" → "Selam" yapıldı
> java Merhaba
> javac Merhaba.java
> java Merhaba

Soru 5: Programın Giriş Noktası

JVM'nin java Uygulama komutuyla programı başlatabilmesi için sınıfta hangi metot bulunmalıdır?

C: public (her yerden erişilebilir), static (nesne oluşturmadan çağrılır), void (değer döndürmez), adı küçük harfle main, parametresi String[] args. A, B ve D derlenir ama JVM giriş noktasını bulamaz ve programı başlatmaz; Java büyük-küçük harfe duyarlıdır (Main ≠ main).

Soru 6: Sınıf Adı ve Dosya Adı

Aşağıdaki kod Merhaba.java adlı dosyaya kaydedilip javac Merhaba.java ile derleniyor. Ne olur?

public class Selam {
  public static void main(String[] args) {
    System.out.println("x");
  }
}

A: public sınıfın adı dosya adıyla birebir (büyük-küçük harf dahil) aynı olmalıdır. Derleyici hatayı satır 1'de bildirir ve .class üretmez. Düzeltme: dosyayı Selam.java diye kaydetmek ya da sınıfı Merhaba diye adlandırmak.

Soru 7: Dosyadaki Tanımlamaların Sırası

Bir Java kaynak dosyasında package, import ve class tanımlamaları hangi sırada yazılmalıdır?

Soru 8: print ve println

Her deyimden sonra konsolda ne görünür ve imleç nerede kalır?

print satır sonu eklemez: imleç boşluğun hemen arkasında kalır.

println aynı satıra "Java" yazar, sonra satır sonu ekler.

"1" yazılır, imleç aynı satırda.

"2" hemen arkasına: 12 (arada boşluk yok).

Argümansız println() yalnızca satırı bitirir.

"Son" yazılır, satır biter. 6 çağrı, 3 satır çıktı.

public class Cizim {
  public static void main(String[] args) {
    System.out.print("Ders: ");
    System.out.println("Java");
    System.out.print("1");
    System.out.print("2");
    System.out.println();
    System.out.println("Son");
  }
}

Soru 11: Çift Ters Eğik Çizgi ve n

System.out.println("A\\nB"); deyiminin çıktısı nedir?

C: Kaynakta \\ bir kaçış dizisidir ve tek bir \ karakteri üretir; ardından gelen n sıradan bir harftir. Ekranda tek satırda A\nB görünür. Yeni satır için "A\nB" yazılmalıydı.

Soru 13: Windows Yolu Yazdırma

Aşağıdaki program derlenip çalıştırılmak isteniyor. Ne olur?

public class Yol {
  public static void main(String[] args) {
    System.out.println("Dosya: C:\yeni");
  }
}
Cevabı göster

Derleme hatası; program hiç çalışmaz:

Yol.java:3: error: illegal escape character
    System.out.println("Dosya: C:\yeni");
                                  ^
  • Dizgi içinde \ bir kaçış dizisi başlatır; \y tanımlı bir kaçış dizisi değildir.
  • Düzeltme: "Dosya: C:\\yeni" → çıktı Dosya: C:\yeni.
  • Dikkat: "C:\new" derlenirdi ama \n yeni satır olurdu!

Soru 14: Kaçış Dizileriyle Tablo

Program satır satır çalışırken konsolda ne oluşur?

\t, "Kredi"yi 8. sütundaki sekme durağına taşır.

"Java" da 4 karakter: 4, "Kredi"nin tam altına hizalanır → basit tablo.

\\ ekranda tek \ olur.

\" metni bitirmeden tırnak yazar.

Tek print iki satır üretir; ikinci \n satırı bitirir. Toplam 6 satır.

public class Tablo {
  public static void main(String[] args) {
    System.out.println("Ders\tKredi");
    System.out.println("Java\t4");
    System.out.println("Yol: C:\\ders");
    System.out.println("O \"tamam\" dedi");
    System.out.print("A\nB\n");
  }
}

Soru 15: Sayı mı, Dizgi mi?

Kodun çıktısı nedir?

System.out.println(5 + 3);
System.out.println("5 + 3");
System.out.println("5" + 3);
System.out.println(5 + 3 + "5");
System.out.println("5" + 5 + 3);
Cevabı göster 
8
5 + 3
53
85
553
  • İki sayı: aritmetik toplama → 8. Tırnak içi her şey dizgidir → 5 + 3 aynen.
  • Bir taraf dizgiyse + birleştirme yapar: "5" + 3 → "53".
  • İşlem soldan sağa: 5 + 3 = 8 önce, sonra 8 + "5" → "85".
  • "5" + 5 → "55", sonra "55" + 3 → "553".

Soru 18: Soldan Sağa Birleştirme

Her println içindeki ifade soldan sağa nasıl değerlendirilir?

İki int: aritmetik toplama.

Bir taraf String: artık birleştirme.

Dizgiye eklenen her sayı dizgi olarak eklenir: "334", "3345".

En soldaki işlenen zaten dizgi.

2 ve 3 toplanmaz, yan yana yazılır.

Parantez önce hesaplanır: 5, sonra metne eklenir.

* önceliklidir: iki çarpma önce yapılır.

Sonra soldan sağa birleştirme: 6=6.

public class Birlestir {
  public static void main(String[] args) {
    System.out.println(1 + 2 + "3" + 4 + 5);
    System.out.println("Toplam: " + 2 + 3);
    System.out.println("Toplam: " + (2 + 3));
    System.out.println(2 * 3 + "=" + 2 * 3);
  }
}

Soru 20: İfade mi, Deyim mi?

Aşağıdakilerden hangisi tek başına bir değer üreten ifadedir (noktalı virgülle biten bir deyim ya da blok değildir)?

C: İfade bir değer üretir (120 * 3 → 360). Deyim bir işlemi tamamlar ve çoğunlukla ; ile biter (A tanımlama, B çağrı deyimi). D süslü parantezle gruplanmış bir bloktur. Bir deyimin içinde bir veya daha çok ifade bulunabilir.

Soru 21: İfade, Deyim ve Blok

Kod satır satır çalışırken değişkenler ve çıktı nasıl değişir?

Tanımlama deyimi: a için int kutusu ayrılır, 40 yazılır.

b = 7.

Önce sağdaki ifade: * önceliklidir, 7 * 5 = 35.

40 − 35 = 5, sonuç c'ye atanır.

Koşul ifadesi true → bloğa girilir.

Blok içindeki deyim çalışır.

Blok bitti; son deyim c'yi yazar. b = 9 olsaydı c = −5 olur, blok atlanırdı.

public class Hesap {
  public static void main(String[] args) {
    int a = 40;
    int b = 7;
    int c = a - b * 5;
    if (c > 0) {
      System.out.println("Pozitif");
    }
    System.out.println(c);
  }
}

Soru 23: Hangi Satırlar Çalışır?

main içindeki bu kodun çıktısı nedir?

// System.out.println("1");

Soru 24: İç İçe Çok Satırlı Açıklama

Program derlenip çalıştırılmak isteniyor. Ne olur?

public class Ic {
  public static void main(String[] args) {
    /* dış /* iç */ kalan */
    System.out.println("Merhaba");
  }
}
Cevabı göster

Derleme hatası; "Merhaba" hiç yazılmaz.

  • /* */ açıklamaları iç içe olamaz: açıklama, ilk */'da biter.
  • Geriye kalan */ kalır ve derleyici bunu kod sanır: javac "illegal start of expression" gibi bir hata bildirir, .class üretmez.
  • İçinde /* */ olan bir bloğu kapatmak için satırları // ile açıklama yapmak daha güvenlidir.

Soru 29: Tam Sayı Bölmesi

Aşağıdaki Java kodunun çıktısı nedir?

public static void main(String[] args) {
  int a = 13;
  int b = 2;
  int sonuc = a / b;
  System.out.println(sonuc);
}

B: İki int bölündüğünde sonuç da int'tir; kesir kısmı atılır (yuvarlanmaz): 13 / 2 = 6. 6.5 elde etmek için en az bir işlenen ondalıklı olmalıdır (ör. 13 / 2.0). Beklenen 6.5 ise bu bir mantık hatasıdır.

Soru 30: Ortalama Neden Yanlış?

İki notun ortalamasını yazdırmak isteyen kodun çıktısı nedir? Hata hangi türdendir?

public class Ort {

    int a = 60, b = 80;
    System.out.println(a + b / 2);
    System.out.println((a + b) / 2);
  }

Cevabı göster 
100
70

  • Mantık hataları derleyici tarafından yakalanmaz; beklenen sonucu önceden hesaplayıp karşılaştırarak (test) bulunur.

Soru 31: Çalışma Zamanı Hatası

Program derleniyor. Çalıştırıldığında hangi satırlar çalışır, konsolda ne görünür?

javac kodu denetler: söz dizimi ve tipler doğru → Hata.class üretilir. 0'a bölme derleme hatası değildir.

JVM main'i çalıştırır: "Başla" yazılır.

x ve y tanımlanır.

Tam sayı sıfıra bölünemez: JVM ArithmeticException fırlatır; iletide satır numarası (5) görünür.

Program durdu: 6. satır hiç çalışmaz, "Bitti" yazılmaz.

public class Hata {
  public static void main(String[] args) {
    System.out.println("Başla");
    int x = 10, y = 0;
    System.out.println(x / y);
    System.out.println("Bitti");
  }
}
