Multiple Choice · Variables and Types

Question 1: A Type for a Large Number

The world population (about 8 billion) will be stored in a variable. Which line compiles and is correct?

B: int holds at most ≈ 2.1 billion; 8 billion needs a long. Also, since the literal itself exceeds the int range, the L suffix is required; without it you get an "integer number too large" compile error. The _ in a number only groups digits; 8_000_000_000L and 8000000000L are the same value.

Multiple Choice · Variables and Types

Question 2: Which Line Does Not Compile?

Which of the declarations below gives a compile error?

C: 5L is a long literal; long → int is a narrowing conversion and needs an explicit cast ("possible lossy conversion"). The others are widening conversions and happen automatically: 5 → 5L, 'A' → 65.0, 10 → 10.0f.

Multiple Choice · Variables and Types

Question 3: char Plus One

What is the output of the code below?

char c = 'A';
System.out.println(c + 1);

C: The code of 'A' is 65. The result of char + int is an int, so 66 is printed. To see a letter you need (char) (c + 1).

Output Question · Variables and Types

Question 4: char Arithmetic

What is the output of the code below?

char c = 'C';
c++;
int k = c + 2;
char d = (char) k;
System.out.println(c + " " + k + " " + d);
Show answer

Output: D 70 F

  • 'C' = 67; c++ → 68 = 'D' (the type stays char).
  • c + 2 becomes an int: 68 + 2 = 70; k holds a number, not a letter.
  • (char) 70 = 'F'. In concatenation, a char is written as a letter and an int as a number.

Multiple Choice · Overflow

Question 5: byte 127 Incremented Twice

In which option is the output of the code fragment below given correctly?

byte x = 127;
x++;
x++;
System.out.print(x);

B: byte is 8 bits and its largest value is 127. The first x++ overflows and the value wraps to the other end: −128. The second x++: −128 + 1 = −127. Java does not report an error on overflow (++ includes an implicit (byte) cast).

What is the output of the code below?

int m = Integer.MAX_VALUE;
System.out.println(m + 1);
long a = m + 1;
System.out.println(a);
long b = m + 1L;
System.out.println(b);
System.out.println(Math.abs(Integer.MIN_VALUE));
Show answer

-2147483648
2147483648
-2147483648
  • m + 1: two ints → int addition, overflows.
  • long a = m + 1: the addition is done first as int (overflows), then widened to long. The target being a long comes too late.
  • m + 1L: one operand is a long → the addition is done as long, and it fits.
  • |MIN_VALUE| = 2³¹ does not fit in an int; Math.abs overflows too.

Multiple Choice · Conversion and Division

Question 8: 7 / 2

What is the output of the code below?

int a = 7, b = 2;
System.out.println(a / b);

A: Since a and b are ints, integer division is performed; the fraction is dropped, with no rounding: 7 / 2 = 3.

Multiple Choice · Conversion and Division

Question 9: 5 / 2.0

What is the output of the code below?

System.out.println(5 / 2.0);

B: Since 2.0 is a double, 5 is also widened to double and a floating-point division is performed: 2.5.

Multiple Choice · Conversion and Division

Question 10: Truncation or Rounding?

What does the following line print?

System.out.println((int) -2.7 + " " + Math.round(-2.7));

D: (int) discards the fractional part, that is, it truncates toward zero: −2.7 → −2. Math.round rounds to the nearest integer: −2.7 → −3 (it returns a long).

Step-by-Step Trace · Conversion and Division

Question 11: The Grade Average Bug

The average of three grades is computed in three different ways. After each line, what do the variables become and what does the program print?

Three int variables.

70 + 85 + 90 = 245 (int).

245 / 3 is two ints → integer division = 81. Then it widens into the double box: 81.0. The fraction was already lost.

3.0 is a double → 245 is promoted to double too: 81.666…

Parentheses first: int division = 81; the cast comes afterwards → 81.0. A cast made after the operation does not save the fraction.

avg1 is printed.

The correct average is only in avg2.

Fix: total / 3.0 or (double) total / 3.

int n1 = 70, n2 = 85, n3 = 90;
int total = n1 + n2 + n3;
double avg1 = total / 3;
double avg2 = total / 3.0;
double avg3 = (double) (total / 3);
System.out.println(avg1);
System.out.println(avg2);
System.out.println(avg3);

Multiple Choice · Compound Assignment and ++

Question 12: x++ and x += 3

What is the output of the code below?

int x = 5;
x++;
x += 3;
System.out.println(x);

D: x++ increases the value by 1: 6. x += 3 means x = x + 3: 9.

Multiple Choice · Compound Assignment and ++

Question 13: i *= 3 + 7

In which option is the output of the code fragment below given correctly?

int i = 5;
i *= 3 + 7;
System.out.println(i);

B: In a compound assignment the right-hand side is evaluated completely first: i = i * (3 + 7) = 5 · 10 = 50. Thinking "i * 3 + 7 = 22" is the most common mistake.

Output Question · Compound Assignment and ++

Question 14: The Implicit Cast of Compound Assignment

What is the output of the code below?

byte b = 120;
b += 10;
int i = 7;
i += 2.9;
System.out.println(b + " " + i);
Show answer

Output: -126 9

  • b += 10 ≡ b = (byte)(120 + 10): 130 does not fit in a byte → 130 − 256 = −126.
  • i += 2.9 ≡ i = (int)(7 + 2.9) = (int) 9.9 = 9 (truncation, no rounding).

Step-by-Step Trace · Compound Assignment and ++

Question 15: i++ and ++i

With prefix and postfix increments, what are i, a and b after each line?

i = 3.

Postfix i++ gives the expression the old value (3): a = 3 + 2 = 5…

…then i is incremented: i = 4.

Prefix ++i: increment first → i = 5…

…then use the new value: b = 5 · 2 = 10.

i-- on its own: i = 4.

Output: 4 5 10.

int i = 3;
int a = i++ + 2;
int b = ++i * 2;
i--;
System.out.println(i + " " + a + " " + b);

Question 17: 17 % 5

What is the output of the code below?

System.out.println(17 % 5);

C: % gives the remainder of the division: 17 = 3 · 5 + 2, remainder 2. The 3 is the integer part of the quotient (17 / 5).

System.out.println(-7 % 3);

  • The sign of the remainder is the sign of the dividend: −7 % 3 = −1, 7 % −3 = 1.
  • % works on floating-point numbers too: 5.5 = 2·2 + 1.5.
  • Floating-point division by zero does not throw an error: Infinity. (1 / 0 throws an ArithmeticException.)
  • 0.0 / 0 = NaN; NaN is not even equal to itself.

Multiple Choice · Operators and Precedence

Question 19: 2 + 3 * 4

What is the output of the code below?

System.out.println(2 + 3 * 4);

D: The * operator has higher precedence than +: first 3 * 4 = 12, then 2 + 12 = 14. If (2 + 3) * 4 were written, the result would be 20.

Question 21: Short-Circuit: b = 0 and b = 4

Both ifs test the same condition with a different b. Which sub-expressions are evaluated, and what is printed?

a = 10, b = 0.

Left condition false → short-circuit: a / b is never evaluated, so no division-by-zero error occurs.

The condition is false; there is no else → line 3 is skipped, no output.

b = 4.

Left is true → the right side must be evaluated too.

10 / 4 is integer division = 2; 2 > 2 → false. true && false → false.

The else branch: Ratio low. (Although the real ratio is 2.5, integer division gave 2.)

int a = 10, b = 0;
if (b != 0 && a / b > 2)
    System.out.println("Ratio high");
b = 4;
if (b != 0 && a / b > 2)
    System.out.println("Ratio high");
else
    System.out.println("Ratio low");

Multiple Choice · Operators and Precedence

Question 22: 0.1 + 0.2 == 0.3

For double a = 0.1 + 0.2;, what does System.out.println(a == 0.3); print, and how should the comparison be done correctly?

D: 0.1 and 0.2 cannot be represented exactly in binary; a = 0.30000000000000004 and == gives false. Floating-point values are compared with a small epsilon.

Multiple Choice · Input and Output

Question 24: nextLine After nextInt

The user first types 20 and presses Enter. The program ends without asking for the name. What is the value of the variable name?

Scanner keyboard = new Scanner(System.in);
System.out.print("Age: ");
int age = keyboard.nextInt();
System.out.print("Name: ");
String name = keyboard.nextLine();

C: nextInt reads only the 20; the Enter (⏎) stays in the buffer. nextLine reads up to this ⏎ without waiting and returns an empty string. The fix: consume the ⏎ with a keyboard.nextLine(); after nextInt.

Output Question · Input and Output

Question 25: The printf Format

What is the output of the code below? (The decimal separator is taken to be a dot.)

System.out.printf("%-6s|%7.3f|%04d%n",
        "Can", 2.71828, 7);
Show answer

Output: Can | 2.718|0007

  • %-6s: 6 characters, left-aligned (3 letters + 3 spaces).
  • %7.3f: round to 3 decimals (2.718), right-align in 7 characters.
  • %04d: 4 digits, padded with 0 instead of spaces. In a Turkish locale it would print 2,718.

Multiple Choice · Examples

Question 26: Math Methods

What does the following line print?

System.out.println(Math.round(2.5) + " "
    + Math.round(-2.5) + " " + Math.sqrt(16)
    + " " + Math.pow(2, 3));

A: Math.round rounds halves up (toward positive infinity): 2.5 → 3, −2.5 → −2; it returns a long. sqrt and pow always return a double: 4.0 and 8.0.
