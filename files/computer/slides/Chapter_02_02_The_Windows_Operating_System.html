Desktop

The Windows Desktop

The desktop is the main workspace, giving access to apps, files and system functions.

Where things appear depends on the Windows version and your personalization settings.

Desktop

Start Menu and Search

  1. Search: finds apps, files, settings and help content (just start typing).
  2. Pinned: frequently used apps; All apps opens the full installed list.
  3. Recommended: recently opened files.
  4. User menu: account options, lock, sign out.
  5. Power: sleep, shut down, restart.

Right-clicking the Start button opens a context menu with extra system commands.

Window Management · Step by step

Window States Step by Step

The window is at normal size: you can drag it and resize it from its edges.

Minimize (—): the window doesn't close, it just drops to the taskbar. The line under the Word icon shows it is still open.

Clicking the icon and choosing Maximize (□) makes the window fill the screen. The same button now becomes Restore.

Win + ←: the window snaps to the left half of the screen.

Win + → snaps the browser to the right: two windows side by side, handy for reading a source while writing a report.

Alt + Tab shows thumbnails of open windows; pick Word with Tab, let go, and Word comes to the front.

Close (✕) closes only this window; if the document is unsaved, Word asks to save it first.

Window Management · Step by step

Virtual Desktops Step by Step

Desktop 1 has the study windows open: Word and a browser.

Win + Ctrl + D creates a new, empty Desktop 2 and switches to it. The windows on Desktop 1 are still open.

Music and a Game are opened on Desktop 2; they appear only on this desktop.

Win + Ctrl + ← goes back to Desktop 1. The apps on the other desktop keep running in the background.

Win + Ctrl + → returns to Desktop 2. Win + Tab (Task view) shows all desktops, as at the top.

Win + Ctrl + F4 closes Desktop 2; its windows don't close, they move to Desktop 1.

File Management

Drives, Volumes and Letters

  • One physical disk can be split into several partitions; each can get its own letter (C:, D:).
  • Windows is usually installed on C:; some small system partitions have no letter.
  • USB drives and network shares also get letters and show up in File Explorer.

File Management

Files and Folders

File

A unit of data with a name, contents and properties.

Folder

File Management

File Names and Extensions

project_report.pdf
File name

The name the user gives to describe the contents.

Extension

Hints at the file format and determines which app opens it.

Visibility

Extensions can be shown from File Explorer's view settings.

Caution

Changing the extension doesn't convert the file's actual format.

File Management

File Naming Rules

Forbidden characters

\ / : * ? " < > | can't be used in file names; most of them have special meaning in paths and searches.

Reserved names

Device names such as CON, PRN, AUX, NUL, COM1 and LPT1 can't be file names, even with an extension.

Upper/lower case

Windows treats Report.docx and report.docx as the same name; they can't share one folder.

Path length

The classic limit is 260 characters for the full path; in very deep folders, copying and opening can fail.

File Management

File Paths

C:\Users\Sercan\Documents\Courses\report.pdf
Absolute path

Starts at the drive root; points to the same file from anywhere.

Relative path

Written relative to the current folder; .. is the parent folder.

On a localized Windows the Documents folder may show a translated name, but its real path is still C:\Users\Sercan\Documents.

File Management · Step by step

An Absolute Path Step by Step: C:\…\report.pdf

A path is read left to right. C:\ is the root folder of the drive; the search starts here.

The root contains the Users folder (Program Files and Windows are skipped).

Inside Users we go down into the user's own Sercan folder.

Documents: the user's documents folder.

Down into the Courses subfolder.

The last part is a file: report.pdf is found. Each “\” means one level down.

File Management · Step by step

A Relative Path Step by Step: ..\Downloads\setup.zip

The current folder is Documents. The relative path ..\Downloads\setup.zip is read starting from here.

.. = the parent folder: from Documents up to Sercan.

Down into the Downloads folder.

setup.zip is found. The absolute equivalent: C:\Users\Sercan\Downloads\setup.zip. Common mistake: forget the leading ..\ and Downloads is looked for inside Documents, so the file isn't found.

File Management · Step by step

Copy and Move Step by Step

Start: two files in C:\Documents, an empty USB drive.

Select report.docx and press Ctrl + C: the clipboard remembers the file. Nothing changes at the source.

Open E:\ and press Ctrl + V: a new copy appears. There are now two separate files; changing one doesn't affect the other.

Select photo.jpg and press Ctrl + X: the icon fades. The file hasn't left yet; it is only marked for moving.

Ctrl + V in E:\: photo.jpg moves to the destination and disappears from the source. The number of files is the same; only the location changed.

Drag and drop defaults to move within the same drive and copy to a different drive. Holding Shift while dropping forces a move, Ctrl forces a copy.

File Management

Renaming and Deleting

  • F2 renames; be careful not to change the extension (.docx).
  • An item in the Recycle Bin can be restored to its original location.
  • Files deleted from USB drives and network locations usually skip the Recycle Bin and are deleted outright.
  • An open or locked file can’t be deleted; deleting in a cloud folder also deletes it on your other devices.

File Management · Step by step

Shortcuts and Original Files Step by Step

A shortcut on the desktop is a small .lnk file that holds only the path of the original. The arrow on the icon marks it.

The shortcut is deleted, but the original report.pdf is still there. Deleting a shortcut doesn't delete the file.

A new shortcut is made and the original is moved to Downloads: the shortcut still points to the old path and may not open.

Make a shortcut with right-click → Create shortcut, or by dragging the file while holding Alt. Copying a shortcut to USB doesn't back up the file!

File Management · Step by step

Creating and Extracting a ZIP Archive

Ctrl + clicking three files one by one selects them all. Shift + click selects every row between two clicks.

Right-click the selection → Compress to → ZIP File. Windows creates the archive without extra software (older versions: Send to → Compressed (zipped) folder).

The archive hw_sercan.zip is created. The text file shrank to a quarter; JPEG and DOCX are already compressed formats, so they barely changed.

Double-clicking a ZIP shows its contents like a folder. A document opened from there is a temporary copy: your changes aren't written back to the ZIP and are easily lost.

Right-click → Extract All… → Extract: the three files come out at their original size into a folder named after the archive. Edit the extracted copies.

System Information and Task Manager

System Information

Shows details of the hardware, operating system, components and resources.

Task Manager

Shows running apps and processes, plus CPU, memory, disk and network use.

Maintenance · Step by step

OneDrive, File History and System Restore

Recovery options run from light to heavy.

OneDrive folder backup: the Desktop, Documents and Pictures folders are backed up to the cloud, reachable from other devices; deleted files can be restored from the OneDrive recycle bin.

File History: regularly saves versions of your files to an external drive; old or deleted versions can be brought back (the drive must be connected).

Restore point: returns system files and settings to an earlier state; it does not back up personal documents. Useful for driver and update problems; it must be turned on.

Reset this PC (Settings → System → Recovery) reinstalls Windows. Keep my files keeps personal files but removes apps; Remove everything erases it all. A last resort, used only after backing up.

Summary

Chapter Summary

  • Start, the taskbar and window controls make up the basic workspace.
  • Virtual desktops and keyboard shortcuts speed up your workflow.
  • A file is defined by its name, extension, path and properties; folders keep things organized.
  • Copying keeps the original; moving changes its location.
  • Settings gathers system, device, network, account, app and accessibility options.
  • Storage Sense, drive optimization, updates and backups are part of routine maintenance.
  • Task Manager ends unresponsive apps and limits startup apps; a ZIP archive bundles files into one smaller package.
