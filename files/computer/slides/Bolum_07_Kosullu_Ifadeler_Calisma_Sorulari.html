Soru 1: if (x > 5) A, değilse B

Aşağıdaki Java kodunun çıktısı nedir?

int x = 3;
if (x > 5)
    System.out.println("A");
else
    System.out.println("B");

A: 3 > 5 → false, bu yüzden else dalı çalışır ve B yazılır. if-else'te her zaman dallardan tam olarak biri çalışır.

Aşağıdaki Java kodunun çıktısı nedir?

Soru 7: Sıralı İşlemler ve Tam Sayı

int t = 7, yk = 3; için aşağıdaki satır ne yazdırır?

System.out.println(t * yk / 2 + " " + t / 2 * yk);

Soru 8: Harf Notu Zinciri

Sınavda istenen harf notu kodu not = 65 ile çalıştırılıyor. Hangi koşullar denenir, hangi dal çalışır?

not = 65.

65 >= 90 → false; sıradaki else if'e geçilir.

65 >= 80 → false.

65 >= 70 → false.

65 >= 60 → true: bu dal seçilir.

D yazılır; else hiç denetlenmez. Eşikler büyükten küçüğe yazıldığı için "not >= 70 && not < 80" gibi üst sınır gerekmez.

int not = 65;
if (not >= 90) {
    System.out.println("A");
} else if (not >= 80) {
    System.out.println("B");
} else if (not >= 70) {
    System.out.println("C");
} else if (not >= 60) {
    System.out.println("D");
} else {
    System.out.println("F");
}

Soru 14: Sarkan else

Girinti yanıltıcı olabilir. else hangi if'e aittir? x kaç yazdırılır?

a = 3, b = −2, x = 0. else'in girintisi dış if'e aitmiş gibi görünüyor.

a > 0 → 3 > 0 → true: dış if'in gövdesine (iç if + else) girilir.

b > 0 → −2 > 0 → false.

else en yakın if'e (b > 0) bağlıdır; iç koşul false olduğu için çalışır: x = 2.

2 yazılır. Belirsizliği önlemek için iç içe if'lerde hep süslü parantez kullanın.

int a = 3, b = -2, x = 0;
if (a > 0)
    if (b > 0)
        x = 1;
else
    x = 2;
System.out.println(x);

Soru 15: Sarkan else: a Negatif

Aynı yapı farklı değerlerle çalıştırılıyor. Çıktı nedir?

int a = -4, b = 6, x = 9;
if (a > 0)
    if (b > 0)
        x = 1;
else
    x = 2;
System.out.println(x);

Soru 17: De Morgan

!(a > 5 && b < 3) koşulunun eşdeğeri hangisidir?

B: ! içeri dağıtılırken && ↔ || yer değiştirir ve her terim tersine döner: !(a > 5) = a <= 5, !(b < 3) = b >= 3. >'ın tersi >= değil <='dir (A'daki hata).

Soru 18: && ile & Farkı

Her ifadeden önce sayac = 0 yapılıyor. Her ifadeden sonra sayac kaçtır? (kontrol her çağrıda sayacı 1 artırır.)

static boolean kontrol(boolean v) {
    sayac++;
    return v;
}
// (1) kontrol(false) && kontrol(true)
// (2) kontrol(false) &  kontrol(true)
// (3) kontrol(true)  || kontrol(false)
// (4) kontrol(true)  |  kontrol(false)
Cevabı göster

sayac: 1, 2, 1, 2

  • (1) false && … → sonuç belli, sağ taraf çağrılmaz.
  • (2) & kısa devre yapmaz: iki taraf da çağrılır.
  • (3) true || … → sağ taraf çağrılmaz.
  • (4) | iki tarafı da çağırır.

Mantık sonuçları aynıdır (false, false, true, true); fark yalnızca yan etkidedir. b != 0 & a / b > 1 b = 0 iken sıfıra bölme hatası verir.

Soru 19: Kısa Devre ve ++k

Koşulların içinde k artırılıyor. Hangi ++k gerçekten çalışır? Ne yazılır?

k = 0.

k > 0 → false; && kısa devre yapar, ++k çalışmaz. A yazılmaz.

k == 0 → true; || kısa devre yapar, ++k yine çalışmaz.

Koşul true → B.

| kısa devre yapmaz: sol true olsa da ++k çalışır → k = 1; 1 > 0 true. true | true → true.

C yazılır.

k = 1: üç ++k'dan yalnızca biri çalıştı.

int k = 0;
if (k > 0 && ++k > 0)
    System.out.println("A");
if (k == 0 || ++k > 0)
    System.out.println("B");
if (k == 0 | ++k > 0)
    System.out.println("C");
System.out.println(k);

Soru 21: Üçgen Türü

Kenarlar 5, 5, 8. Önce üçgen eşitsizliği, sonra tür denetleniyor. Hangi koşullar denenir?

Kenarlar 5, 5, 8.

10 > 8, 13 > 5, 13 > 5 → üçü de true: geçerli üçgen, dış if'e girilir.

a == b true, ama b == c → 5 == 8 false; true && false → false. Eşkenar değil.

a == b → true; || kısa devre yapar, diğer eşitliklere bakılmaz.

İkizkenar yazılır. (2, 3, 6 olsaydı 2 + 3 > 6 false → "Üçgen değil".)

int a = 5, b = 5, c = 8;
if (a + b > c && a + c > b && b + c > a) {
    if (a == b && b == c)
        System.out.println("Eşkenar");
    else if (a == b || b == c || a == c)
        System.out.println("İkizkenar");
    else
        System.out.println("Çeşitkenar");
} else {
    System.out.println("Üçgen değil");
}

Soru 26: switch Düşmesi: gun = 3

Klasik switch'te hangi case kodları çalışır? break nerede durdurur?

gun = 3.

switch (3): doğrudan case 3 etiketine atlanır; case 1 ve case 2 kodları çalışmaz.

Çar yazılır. Bu case'te break yok!

Düşme: case 4 etiketi denetlenmez, kodu çalışır → Per. Sonra break.

break switch'in sonuna atlar; default çalışmaz. Çıktı: Çar, Per. Ok (->) biçiminde düşme olmaz.

int gun = 3;
switch (gun) {
    case 1: System.out.println("Pzt"); break;
    case 2: System.out.println("Salı");
    case 3: System.out.println("Çar");
    case 4: System.out.println("Per"); break;
    default: System.out.println("Yok");
}

Soru 27: Ortadaki default

gun = 7 ise aşağıdaki switch ne yazdırır?

switch (gun) {
    case 1: System.out.println("Pzt"); break;
    default: System.out.println("Yok");
    case 2: System.out.println("Salı");

D: Eşleşen case olmadığı için default'a atlanır; default'ta break olmadığından alttaki case 2 koduna düşülür. default'un sonda olması zorunlu değildir ama düşme kuralı onda da geçerlidir.

Soru 28: switch İfadesi: Mevsim

Program üç kez çalıştırılıyor: ay = 7, 0, 11. Her seferinde ne yazılır?

String mevsim = switch (ay) {

Soru 29: yield ile Şubat

Aşağıdaki kodun çıktısı nedir?

int yil = 2023, ay = 2;
int gun = switch (ay) {
    case 4, 6, 9, 11 -> 30;
    case 2 -> {
        System.out.println("Şubat");
        yield yil % 4 == 0 ? 29 : 28;
    }
    default -> 31;
};
System.out.println(gun);
Cevabı göster 
Şubat
28
  • ay = 2 → blok kolu çalışır; önce "Şubat" yazılır.
  • Blok kolunda değer yield ile verilir: 2023 % 4 = 3 ≠ 0 → 28.
  • gun = 28 yazdırılır. (yield olmasaydı derleme hatası olurdu.)

Soru 34: Üç Sayının En Küçüğü

"Aday + karşılaştır" deseniyle 6, 2, 2 sayılarının en küçüğü bulunuyor. Aday nasıl değişir?

a = 6, b = 2, c = 2.

İlk aday: a = 6.

b < enK → 2 < 6 → true.

Yeni aday: enK = 2.

c < enK → 2 < 2 → false; eşit değer adayı değiştirmez, satır 6 atlanır.

Çıktı: En küçük: 2. Kısa yol: Math.min(a, Math.min(b, c)).

int a = 6, b = 2, c = 2;
int enK = a;
if (b < enK)
    enK = b;
if (c < enK)
    enK = c;
System.out.println("En küçük: " + enK);

double a = 1, b = -5, c = 6;

Çıktı: Normal

vki = 70 / 3.0625 ≈ 22.86. İlk koşul false; ikinci dalda üst sınır yeterli, çünkü bu dala gelen değer zaten 18.5 veya üstüdür.

Soru 37: Mutlak Değer ve MIN_VALUE

Aşağıdaki kodun çıktısı nedir?

int sayi = Integer.MIN_VALUE;
if (sayi < 0) {
    sayi = -sayi;
}
System.out.println(sayi);
System.out.println(sayi < 0);
Cevabı göster 
-2147483648
true
  • Koşul true → -sayi hesaplanır: 2 147 483 648 int'e sığmaz (en büyük 2 147 483 647).
  • Taşma sararak yine −2 147 483 648 verir; "mutlak değer" negatif kalır.
  • Bu özel durum için long kullanılır ya da Math.absExact (Java 15+) istisna fırlatır.
