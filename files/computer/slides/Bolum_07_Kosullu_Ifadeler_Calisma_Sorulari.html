Soru 3: Süslü Parantezsiz if

Aşağıdaki kodun çıktısı nedir?

int x = 2;
if (x > 5)
    System.out.println("A");
    System.out.println("B");
System.out.println("C");
Cevabı göster 
B
C

Süslü parantez yoksa if yalnızca hemen ardından gelen tek deyimi kontrol eder. "B" satırının girintisi yanıltıcıdır; derleyici girintiye bakmaz. 2 > 5 false → yalnızca A atlanır.

if (x > 5) {
    System.out.println("A");
    System.out.println("B");   // niyet buysa
}

Soru 4: Ters Sıralı Eşikler

Bir öğrenci harf notu zincirini küçük eşikten başlayarak yazmış. not = 85 için çıktı nedir?

if (not >= 60) System.out.println("D");
else if (not >= 70) System.out.println("C");
else if (not >= 80) System.out.println("B");
else if (not >= 90) System.out.println("A");
else System.out.println("F");

B: İlk doğru dal çalışır: 85 >= 60 true → D; zincirin geri kalanı atlanır. Bu sıralamayla 60 ve üstü herkes D alır; C, B, A dallarına hiç ulaşılamaz. Eşikler büyükten küçüğe yazılmalıdır.

Soru 6: 10 ile 20 Arası

"10'dan büyük, 20'den küçük" sayılar isteniyor. sayi için doğru koşul hangisidir?

C: İki koşulun birlikte doğru olması gerekir: &&. A her sayı için true olur. B derlenmez: 10 < sayi boolean üretir, boolean < 20 anlamsızdır. D sınırları (10 ve 20) da dahil eder.

Soru 7: Sarkan else

Girinti yanıltıcı olabilir. else hangi if'e aittir? x kaç yazdırılır?

a = 3, b = −2, x = 0. else'in girintisi dış if'e aitmiş gibi görünüyor.

a > 0 → 3 > 0 → true: dış if'in gövdesine (iç if + else) girilir.

b > 0 → −2 > 0 → false.

else en yakın if'e (b > 0) bağlıdır; iç koşul false olduğu için çalışır: x = 2.

2 yazılır. Belirsizliği önlemek için iç içe if'lerde hep süslü parantez kullanın.

int a = 3, b = -2, x = 0;
if (a > 0)
    if (b > 0)
        x = 1;
else
    x = 2;
System.out.println(x);

Çoktan Seçmeli · İç İçe Kararlar

Soru 8: Sarkan else: a Negatif

Aynı yapı farklı değerlerle çalıştırılıyor. Çıktı nedir?

int a = -4, b = 6, x = 9;
if (a > 0)
    if (b > 0)
        x = 1;
else
    x = 2;
System.out.println(x);

A: else iç if'e aittir. Dış koşul −4 > 0 false olduğu için iç if ve onun else'i tümüyle atlanır; x başlangıç değeri 9 olarak kalır. Girintiye bakıp 2 demek tipik hatadır.

Soru 9: De Morgan

!(a > 5 && b < 3) koşulunun eşdeğeri hangisidir?

B: ! içeri dağıtılırken && ↔ || yer değiştirir ve her terim tersine döner: !(a > 5) = a <= 5, !(b < 3) = b >= 3. >'ın tersi >= değil <='dir (A'daki hata).

Soru 10: && ile & Farkı

Her ifadeden önce sayac = 0 yapılıyor. Her ifadeden sonra sayac kaçtır? (kontrol her çağrıda sayacı 1 artırır.)

static boolean kontrol(boolean v) {
    sayac++;
    return v;
}
// (1) kontrol(false) && kontrol(true)
// (2) kontrol(false) &  kontrol(true)
// (3) kontrol(true)  || kontrol(false)
// (4) kontrol(true)  |  kontrol(false)
Cevabı göster

sayac: 1, 2, 1, 2

  • (1) false && … → sonuç belli, sağ taraf çağrılmaz.
  • (2) & kısa devre yapmaz: iki taraf da çağrılır.
  • (3) true || … → sağ taraf çağrılmaz.
  • (4) | iki tarafı da çağırır.

Mantık sonuçları aynıdır (false, false, true, true); fark yalnızca yan etkidedir. b != 0 & a / b > 1 b = 0 iken sıfıra bölme hatası verir.

Soru 11: Kısa Devre ve ++k

Koşulların içinde k artırılıyor. Hangi ++k gerçekten çalışır? Ne yazılır?

k = 0.

k > 0 → false; && kısa devre yapar, ++k çalışmaz. A yazılmaz.

k == 0 → true; || kısa devre yapar, ++k yine çalışmaz.

Koşul true → B.

| kısa devre yapmaz: sol true olsa da ++k çalışır → k = 1; 1 > 0 true. true | true → true.

C yazılır.

k = 1: üç ++k'dan yalnızca biri çalıştı.

int k = 0;
if (k > 0 && ++k > 0)
    System.out.println("A");
if (k == 0 || ++k > 0)
    System.out.println("B");
if (k == 0 | ++k > 0)
    System.out.println("C");
System.out.println(k);

Soru 12: Artık Yıl

(yil % 4 == 0 && yil % 100 != 0) || yil % 400 == 0 koşuluna göre hangisi artık yıldır?

A: 2000: 100'e bölündüğü için parantez false, ama 2000 % 400 == 0 → true. 1900 ve 2100 100'e bölünüp 400'e bölünmez → false. 2023 4'e bölünmez → false.

Soru 13: Koşul Operatörü ?:

Aşağıdaki kodun çıktısı nedir?

int a = 7, b = 12;
int m = a < b ? a : b;
String s = m % 2 == 0 ? "çift" : "tek";
System.out.println(m + " " + s);
int n = -5;
String isaret = n > 0 ? "+" : n < 0 ? "-" : "0";
System.out.println(isaret);
Cevabı göster 
7 tek
-
  • 7 < 12 true → m = a = 7 (küçük olan).
  • 7 % 2 = 1 → "tek".
  • İç içe ?: sağdan gruplanır: n > 0 false → (n < 0 ? "-" : "0") → "-".

String b = "ders";

false

int gun = 1;
switch (gun) {

Cevabı göster 
Pzt
Salı

Adım Adım Çalıştırma · switch

Soru 16: switch Düşmesi: gun = 3

Klasik switch'te hangi case kodları çalışır? break nerede durdurur?

gun = 3.

switch (3): doğrudan case 3 etiketine atlanır; case 1 ve case 2 kodları çalışmaz.

Çar yazılır. Bu case'te break yok!

Düşme: case 4 etiketi denetlenmez, kodu çalışır → Per. Sonra break.

break switch'in sonuna atlar; default çalışmaz. Çıktı: Çar, Per. Ok (->) biçiminde düşme olmaz.

int gun = 3;
switch (gun) {
    case 1: System.out.println("Pzt"); break;
    case 2: System.out.println("Salı");
    case 3: System.out.println("Çar");
    case 4: System.out.println("Per"); break;
    default: System.out.println("Yok");
}

Çoktan Seçmeli · switch

Soru 17: Ortadaki default

gun = 7 ise aşağıdaki switch ne yazdırır?

switch (gun) {
    case 1: System.out.println("Pzt"); break;
    default: System.out.println("Yok");
    case 2: System.out.println("Salı");
}

D: Eşleşen case olmadığı için default'a atlanır; default'ta break olmadığından alttaki case 2 koduna düşülür. default'un sonda olması zorunlu değildir ama düşme kuralı onda da geçerlidir.

Çıktı Sorusu · switch

Soru 18: yield ile Şubat

Aşağıdaki kodun çıktısı nedir?

int yil = 2023, ay = 2;
int gun = switch (ay) {
    case 4, 6, 9, 11 -> 30;
    case 2 -> {
        System.out.println("Şubat");
        yield yil % 4 == 0 ? 29 : 28;
    }
    default -> 31;
};
System.out.println(gun);
Cevabı göster 
Şubat
28
  • ay = 2 → blok dalı çalışır; önce "Şubat" yazılır.
  • Blok dalında değer yield ile verilir: 2023 % 4 = 3 ≠ 0 → 28.
  • gun = 28 yazdırılır. (yield olmasaydı derleme hatası olurdu.)

Soru 19: Tek Sayı Koşulu

1–100 arası tek sayılar i % 2 == 1 ile seçilebilir. Negatifler dahil her int için doğru çalışan tek sayı koşulu hangisidir?

B: Java'da kalanın işareti bölünenin işaretidir: −7 % 2 = −1. Bu yüzden % 2 == 1 yalnızca pozitif tek sayılarda çalışır (1–100 için doğru, −7 için yanlış). != 0 her durumda doğrudur.

Soru 20: Mutlak Değer ve MIN_VALUE

Aşağıdaki kodun çıktısı nedir?

int sayi = Integer.MIN_VALUE;
if (sayi < 0) {
    sayi = -sayi;
}
System.out.println(sayi);
System.out.println(sayi < 0);
Cevabı göster 
-2147483648
true
  • Koşul true → -sayi hesaplanır: 2 147 483 648 int'e sığmaz (en büyük 2 147 483 647).
  • Taşma sararak yine −2 147 483 648 verir; "mutlak değer" negatif kalır.
  • Bu özel durum için long kullanılır ya da Math.absExact (Java 15+) istisna fırlatır.
