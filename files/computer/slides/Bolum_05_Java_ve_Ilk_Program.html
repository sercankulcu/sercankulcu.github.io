Temeller

Program Nedir?

  • Bilgisayarın belirli bir görevi yerine getirmesi için yürüttüğü komutlar bütünüdür.
  • Girdi alabilir, veriyi işler, durum saklar (bellekteki değerler) ve çıktı üretir.
  • Davranışı dilin kuralları ve yazılan algoritma belirler.
  • Örnek: iki notun ortalaması → girdi 70, 90; çıktı 80.

Temeller

Programlama Dilinin Yönleri

  • Söz dizimi geçerli biçimi, anlam çalıştırıldığında ne olacağını tanımlar.
  • Tip sistemi işlemleri sınırlar; çalışma modeli belleğin ve komutların nasıl yürütüldüğünü belirler.
  • Derleyici söz dizimini ve tipleri çalıştırmadan önce denetler.

Diller

Programlama Paradigmaları

  • Buyurgan (imperative) yaklaşım işlemlerin nasıl yapılacağını adım adım belirtir.
  • Nesne yönelimli yaklaşım veri ve davranışı nesnelerde birleştirir.
  • Fonksiyonel yaklaşım dönüşümleri ve değiştirilemez veriyi öne çıkarır.
  • Java birden fazla yaklaşımı birlikte kullanabilir.

Java

JDK, JRE ve JVM

  • JVM (Java Virtual Machine) bytecode'u yürüten sanal makinedir.
  • JRE = JVM + sınıf kütüphanesi: programı çalıştırmak için gerekenler.
  • JDK = JRE + geliştirme araçları (javac, jar, javadoc…). Geliştirici JDK kurar.
  • Oracle, Java 11'den beri ayrı JRE sunmaz; geliştirici JDK kurar (bazı dağıtıcılar JRE'yi ayrıca sunar).

Java · Kodu adım adım çalıştır

Kod İzleme: Merhaba

java Merhaba komutuyla JVM başlar ve Merhaba sınıfını (Merhaba.class) belleğe yükler.

JVM main metodunu çağırır: yığında main çerçevesi açılır. Komut satırında argüman verilmediği için args boştur.

Deyim çalışır: "Merhaba" metni System.out.println metoduna gönderilir.

println metni yazar ve satır sonu ekler: imleç alt satıra geçer. Metot biter, main'e dönülür.

main bloğunun } karakterine gelindi: main biter, çerçevesi yığından kaldırılır.

Çalışacak başka kod yok: JVM kapanır, program sonlanır. Toplam 1 deyim çalıştı, 1 satır çıktı üretildi.

public class Merhaba {
    public static void main(String[] args) {
        System.out.println("Merhaba");
    }
}

Java · Kodu adım adım çalıştır

Kod İzleme: print ve println

JVM main metodunu çağırır; konsol henüz boş, imleç 1. satırın başında.

print "Merhaba " yazar ama satır sonu eklemez: imleç aynı satırda, boşluğun hemen arkasında kalır.

println "Dünya" yazar ve satır sonu ekler: sonraki çıktı alt satırdan başlar.

println "Java" yazar ve satır sonu ekler: sonraki çıktı alt satırdan başlar.

main biter; konsolda 2 satır var: 3 çağrı yapıldı ama yalnızca println satırı bitirdi.

public class Selam {
    public static void main(String[] args) {
        System.out.print("Merhaba ");
        System.out.println("Dünya");
        System.out.println("Java");
    }
}

Java · Kodu adım adım çalıştır

Kod İzleme: Kaçış Dizileri

main başlar; konsol boş.

\t imleci bir sonraki sekme durağına (8. sütun) taşır.

Sekme sayesinde 85, Not başlığının altına hizalanır: basit tablo.

\" metni bitirmeden çift tırnak yazar.

Tek print iki satır üretti: \n satır sonu karakteridir; println de satır sonu ekler (Windows'ta \r\n).

public class Kacis {
    public static void main(String[] args) {
        System.out.println("Ad\tNot");
        System.out.println("Ali\t85");
        System.out.println("\"Java\" dili");
        System.out.print("Satır 1\nSatır 2\n");
    }
}

Kaynak Kod

Java Dosyasının Yapısı

package okul;

import java.util.Scanner;

public class Program {
    public static void main(String[] args) {
        System.out.println("Merhaba");
    }
}
  • package ve import tanımlamaları sınıftan önce gelir; public sınıf adı dosya adıyla eşleşir.
  • package okul; → dosya okul/ klasöründe durur; çalıştırma: java okul.Program.

Çalıştırma

Derleme Hattı Adım Adım

1. Yaz: kaynak kod Merhaba.java adıyla kaydedilir. Dosya adı public sınıf adıyla aynı olmalıdır.

2. Derle: javac (JDK'daki derleyici) tüm dosyayı çalıştırmadan önce denetler.

3. Bytecode: derleme başarılıysa aynı klasörde Merhaba.class oluşur. Bu dosya Windows, Linux ve macOS'ta aynıdır.

4. Çalıştır: java Merhaba JVM'yi başlatır. Sınıf adı yazılır; .class uzantısı yazılmaz.

5. Çıktı: konsolda Merhaba görünür. Değişiklik yaparsanız yeniden derlemeniz gerekir.

Hata olursa: javac satır numarasıyla hata bildirir ve .class üretmez. Önce derleme hataları giderilir.

Çalıştırma

Bytecode ve JVM

  • Derleyici işlemciye özel makine kodu yerine bytecode üretir.
  • Her platformun kendi JVM'si bytecode'u yorumlar; sık çalışan kısımları JIT ile o işlemcinin makine koduna çevirir.
  • Sınıf yükleme, doğrulama ve bellek yönetimi (çöp toplama) çalışma ortamının parçalarıdır.

Dil Yapısı

Temel Programlama Unsurları

  • Derleyici kodu önce belirteçlere (token) ayırır: anahtar kelime, tanımlayıcı, sabit değer, operatör, ayırıcı.
  • Java büyük-küçük harfe duyarlıdır: sayi ve Sayi farklı adlardır.
  • Deyimler çoğunlukla noktalı virgülle biter; bloklar süslü parantezle çevrilir.

Dil Yapısı

İfadeler ve Deyimler

  • İfade bir değer üretir: 2 + 3 → 5, sayi > 0 → true.
  • Deyim bir işlemi tamamlar: toplam = 5; veya System.out.println(toplam);
  • Blok, süslü parantez içindeki deyimleri tek yapı olarak gruplar.
  • Bir deyimin içinde bir veya daha çok ifade bulunabilir.

Dil Yapısı · Kodu adım adım çalıştır

İfade, Deyim ve Blok Adım Adım

fiyat için bellekte int kutusu ayrılır ve 120 yazılır.

adet kutusu oluşur: 3.

Önce sağdaki ifade değerlendirilir: fiyat * adet → 120 * 3 → 360.

Üretilen değer toplam kutusuna atanır: toplam = 360.

Koşul ifadesi: toplam > 300 → 360 > 300 → true. Doğru olduğu için bloğa girilir.

Blok içindeki deyim çalışır: konsola İndirim yazılır.

Blok biter. adet = 2 olsaydı toplam 240 olur, koşul false olur ve blok hiç çalışmazdı.

int fiyat = 120;           // tanımlama deyimi
int adet = 3;              // tanımlama deyimi
int toplam = fiyat * adet; // ifade + atama
if (toplam > 300) {        // koşul + blok
    System.out.println("İndirim");
}

Kaynak Kod

Açıklamalar

  • // satır sonuna kadar açıklamadır.
  • /* ... */ birden fazla satırı kapsar.
  • /** ... */ Javadoc (API belgesi) açıklamasıdır.
  • Derleyici açıklamaları atlar; bytecode'a girmezler.
  • Açıklama kodun ne yaptığını tekrarlamak yerine nedenini açıklamalıdır.
/** Merhaba programı (Javadoc). */
public class Merhaba {
    /* Birden fazla satıra
       yayılan açıklama */
    public static void main(String[] args) {
        // selamı yaz
        System.out.println("Merhaba");
    }
}

public class Hata4 {

115

Hata iletisi yok, ama sonuç yanlış: beklenen 80. / önce yapılır: 70 + 45. Düzeltme: (a + b) / 2.

Özet

Bölüm Özeti

  • Program, bilgisayarın bir görevi yerine getirmek için yürüttüğü komutlar bütünüdür.
  • Java kaynak dosyası javac ile bytecode'a derlenir ve JVM üzerinde çalışır.
  • public sınıf adı dosya adıyla eşleşir; main programın giriş noktasıdır.
  • İfadeler değer üretir, deyimler işlemi tamamlar, bloklar deyimleri gruplar.
  • Kodlamadan önce örnek girdi, beklenen çıktı ve sınır durumları belirlenir.

Özet

Alıştırmalar

  1. Adınızı, bölümünüzü ve öğrenci numaranızı üç ayrı satırda yazdıran Kimlik programını yazın, derleyin, çalıştırın.
  2. Aynı çıktıyı tek bir println ve \n kullanarak üretin.
  3. \t ile üç satırlık bir ders–kredi tablosu yazdırın.
  4. System.out.println("Merhaba") satırındaki ; işaretini silip derleyin; hata iletisinin satır numarasını ve ^ işaretini yorumlayın.
  5. Sınıf adını Merhaba, dosya adını merhaba.java yapıp derleyin. Ne olur, neden?
  6. System.out.println(5 + 3); ile System.out.println("5 + 3"); çıktılarını tahmin edin; çalıştırarak doğrulayın.
