Temeller

Program Nedir?

  • Bilgisayarın belirli bir görevi yerine getirmesi için yürüttüğü komutlar bütünüdür.
  • Girdi alabilir, veriyi işler, durum saklar ve çıktı üretebilir.
  • Programın davranışı kullanılan dilin kuralları ve yazılan algoritma tarafından belirlenir.

Temeller

Programlama Dilinin Yönleri

  • Söz dizimi, kodun geçerli biçimini tanımlar.
  • Anlam, geçerli ifadenin çalıştırıldığında ne yaptığını açıklar.
  • Tür sistemi, değerlerle yapılabilecek işlemleri sınırlar.
  • Çalışma modeli belleğin ve komutların nasıl yürütüldüğünü etkiler.

Diller

Programlama Paradigmaları

  • Zorunlu yaklaşım işlemlerin nasıl yapılacağını adım adım belirtir.
  • Nesne yönelimli yaklaşım veri ve davranışı nesnelerde birleştirir.
  • Fonksiyonel yaklaşım dönüşümleri ve değişmez veriyi öne çıkarır.
  • Java birden fazla yaklaşımı birlikte kullanabilir.

Düz Metin Kaynak Dosyası

  • Sürüm kontrol sistemleri satır değişikliklerini izleyebilir.
  • Kaynak dosyada kodlama, satır sonu ve dosya adı tutarlı olmalıdır.

Çıktı

Java

İlk Java Programı

public class Merhaba {
    public static void main(String[] args) {
        System.out.println("Merhaba");
    }
}
  • Sınıf adı ile dosya adı eşleşir: Merhaba.java.
  • main, klasik Java uygulamasının başlangıç noktasıdır.

Kaynak Kod

Java Dosyasının Yapısı

package okul;

import java.util.Scanner;

public class Program {
    public static void main(String[] args) {
        System.out.println("Merhaba");
    }
}
  • package ve import bildirimleri sınıftan önce gelir.
  • public sınıf adı dosya adıyla eşleşir.

Çalıştırma

Derleme ve Çalıştırma

Program.java
javac Program.java
Program.class
java Program
  • Derleme hataları önce giderilir.
  • Çalıştırma komutunda .class uzantısı yazılmaz.

Çalıştırma

Bytecode ve JVM

  • Derleyici işlemciye özel makine kodu yerine bytecode üretir.
  • JVM bytecode'u bulunduğu platformda yürütür.
  • Sınıf yükleme, doğrulama ve bellek yönetimi çalışma ortamının parçalarıdır.

Dil Yapısı

Temel Programlama Unsurları

  • Belirteçler anahtar kelime, tanımlayıcı, sabit değer, işleç ve ayırıcıları içerir.
  • Java büyük-küçük harfe duyarlıdır: sayi ve Sayi farklı adlardır.
  • Deyimler çoğunlukla noktalı virgülle biter; bloklar süslü parantezle çevrilir.

Dil Yapısı

İfadeler ve Deyimler

  • İfade bir değer üretir: 2 + 3 veya sayi > 0.
  • Deyim bir işlemi tamamlar: toplam = 5; veya return toplam;.
  • Blok, süslü parantez içindeki deyimleri tek yapı olarak gruplar.

Dil Yapısı

İfade, Deyim ve Blok

int fiyat = 120;          // deyim
int adet = 3;             // deyim
int toplam = fiyat * adet; // ifade + atama
if (toplam > 300) {       // koşul + blok
    System.out.println("İndirim");
}

Kaynak Kod

Açıklamalar

  • // satır sonuna kadar açıklamadır.
  • /* ... */ birden fazla satırı kapsar.
  • /** ... */ API belgesi için Javadoc açıklamasıdır.
  • Açıklama kodun ne yaptığını tekrarlamak yerine nedenini açıklamalıdır.
