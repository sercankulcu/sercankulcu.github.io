Output Question · Worksheet

Question 1: Displayed Value, Stored Value

2.6 is typed into A1 and A2 and a 0 decimal places number format is applied to both; the cells display 3. What values do the formulas in C1 and C2 calculate?

Show answer

C1 = 5.2 (with 0 decimal places it shows 5, not 6) · C2 = 26 (not 30).

  • A number format changes only the appearance; 2.6 is still stored in the cell.
  • A formula uses the underlying value shown in the formula bar: 2.6 + 2.6 = 5.2 and 2.6 · 10 = 26.
  • To calculate with the displayed value, we would have to actually round the value (e.g. with the ROUND function).

Multiple Choice · Worksheet

Question 2: Date Difference

A2 contains the date 3/1/2024 and B2 contains 3/15/2024. What does the formula =B2-A2 return (in number format)?

C: Excel stores dates as numeric serial values (e.g. 1/1/2024 = 45292). The difference of two dates is the number of days between them: 15 − 1 = 14. If the dates were stored as text, the subtraction could not be done and the result could be #VALUE!.

Multiple Choice · Operator Precedence

Question 3: Minus Sign and Exponent

In Excel, what is the result of the formula =-3^2?

B: In Excel, negation (the sign) is applied before the exponent: −3 first becomes (−3), then (−3)² = 9. To get the mathematical −3² = −9, write =-(3^2) or =0-3^2.

Step-by-Step Trace · Operator Precedence

Question 4: Evaluate the Formula Step by Step

With B1 = 5 and C1 = 2, in what order is the formula in D1 calculated and what is the result?

First the references are replaced with their values: B1 → 5, C1 → 2.

The highest precedence is the exponent: 2^2 → 4.

Multiplication and division go left to right: first 5/2 → 2.5.

Then 2.5*4 → 10.

Addition and subtraction also go left to right: 10-10 → 0.

The last operation 0+4: D1 = 4. Reading left to right and starting with 10−5 = 5 would be wrong.

// cell values
B1: 5
C1: 2
// cell D1
=10-B1/C1*4+2^C1

Multiple Choice · Cell References

Question 5: Copying a Mixed Reference

The formula =$B3+C$2 in cell E5 is copied and pasted into G8. Which formula is in G8?

D: E5 → G8 is 2 columns right and 3 rows down. $B3: the column is locked (B stays), the row shifts (3 → 6) → $B6. C$2: the row is locked (2 stays), the column shifts (C → E) → E$2. The $ sign locks only the part right after it.

Output Question · Cell References

Question 6: A Multiplication Table with One Formula

=$A2*B$1 was entered in B2 and filled over the range B2:D4. Which formula and which result are in cells D3 and C4?

Show answer

D3: =$A3*D$1 → 3 · 30 = 90
C4: =$A4*C$1 → 4 · 20 = 80

  • $A2: locked to column A, the row changes with the cell → each cell takes the A value of its own row.
  • B$1: locked to row 1, the column changes → each cell takes row 1 of its own column.

Step-by-Step Trace · Cell References

Question 7: Filling the VAT Formula Down

The VAT rate is in E1 (0.2). The formula in C2 is filled down to C4. What results in each cell?

The result in C2 is correct: 20.

One row down: both relative references shifted. E1 → E2 (empty = 0) → result 0!

C4: =B4*E3 → 0. There is no error message but the result is wrong: a sneaky error.

Fix: the rate cell is locked with F4: $E$1.

When filled down, B2 → B3 shifted and $E$1 stayed fixed: 250 · 0.2 = 50.

C4 = 40 · 0.2 = 8. Rule: a constant cell shared by all rows must be an absolute reference.

// data: B2=100  B3=250  B4=40
// E1 = 0.2  (E2, E3 empty)
// attempt 1: cell C2
=B2*E1
// attempt 2: cell C2
=B2*$E$1

Question 8: Functions on Mixed Data

The range B2:B7 contains numbers, a text, and an empty cell. What are the results of the formulas below?

=SUM(B2:B7)
=AVERAGE(B2:B7)
=MAX(B2:B7)    =MIN(B2:B7)
=COUNT(B2:B7)
=COUNTA(B2:B7)

FormulaResultWhy

Multiple Choice · IF and Logical

Question 9: AND, OR, and NOT

With B2 = 72 (grade) and C2 = 65 (attendance %), what is the result of the formula below?

=OR(AND(B2>=60,C2>=70),
     NOT(C2>=70))

A: C2>=70 → 65>=70 FALSE. AND(TRUE, FALSE) = FALSE. NOT(FALSE) = TRUE. OR(FALSE, TRUE) = TRUE: OR needs only one TRUE.

Step-by-Step Trace · IF and Logical

Question 10: AND Inside IF

With B2 = 72, C2 = 65, how is the formula in D2 evaluated step by step, and what appears in D2?

The outer IF wants the test first: the first condition of AND is 72 >= 50 → TRUE.

The second condition is 65 >= 70 → FALSE.

For AND, all conditions must be TRUE → FALSE.

The test is FALSE: "Pass" is skipped, and evaluation moves to the third argument (the inner IF).

Inner IF: 72 >= 50 → TRUE.

The inner IF's second argument is returned: D2 = Absent. (“Fail” would be returned only if the grade were below 50.)

// cell D2
=IF(
  AND(B2>=50,C2>=70),
  "Pass",
  IF(B2>=50,
       "Absent",
       "Fail"))

Output Question · IF and Logical

Question 11: Division by Zero with IFERROR

The cells E2, E3, and F2 in the table contain the formulas below. What does each show?

E2: =IFERROR(B2/D2,"Not calculable")
E3: =IFERROR(B3/D3,"Not calculable")
F2: =B2/D2
Show answer
  • E2: B2/D2 = 72/0 gives an error → IFERROR shows its second argument: Not calculable.
  • E3: 72/4 = 18; since there is no error, IFERROR returns the result as is.
  • F2: since the error is not caught, #DIV/0! appears.

IFERROR hides the error, it does not fix it; the source (the 0 denominator) should still be examined.

Output Question · COUNTIF and SUMIF

Question 12: Conditional Counting and Summing

What are the results of the formulas below for the student list?

=COUNTIF(B2:B7,"Electrical")
=SUMIF(B2:B7,"Computer",C2:C7)
=COUNTIF(C2:C7,">70")
=SUMIF(C2:C7,"<60")
Show answer
  • 3: Electrical appears in 3 rows (Ali, Can, Efe).
  • 168: the scores of the Computer rows: 91 + 77.
  • 4: the scores greater than 70 are 72, 91, 85, 77. The comparison criterion is written in quotes.
  • 58: if sum_range is not given, the criteria range itself is summed; the only score below 60 is 58.

SUMIF order: (range, criteria, sum_range).

Step-by-Step Trace · COUNTIF and SUMIF

Question 13: SUMIF Row by Row

=SUMIF(B2:B7,"Electrical",C2:C7): how does the formula walk through the rows one by one, and what is the result?

B2 = Electrical → matches the criterion; C2 (72) in the same row is added to the sum.

B3 = Computer → does not match, C3 is skipped.

B4 matches: 72 + 85 = 157.

B5 = Mechanical → skipped.

B6 matches: 157 + 58 = 215.

B7 does not match. The range has ended.

The result is 215. With the same criterion COUNTIF gives 3; the ratio of the two is the Electrical average (71.7).

// range: B2:B7
// criteria: "Electrical"
// sum_range: C2:C7
=SUMIF(B2:B7,"Electrical",C2:C7)

Step-by-Step Trace · VLOOKUP

Question 14: Following a VLOOKUP Search

=VLOOKUP("Can",A2:B5,2,0): how does the formula search the table, and what does it return?

The search is done only in the first column, from top to bottom. Ali ≠ Can.

Ece ≠ Can → one row down.

A4 = Can → found. The search stops; the Su row is never looked at.

In the found row, the 2nd column of the table: B4.

The result is 85. If "Mert" were searched, all rows would be tried and #N/A would be returned.

// table A2:B5 (Name, Score)
// lookup_value: "Can"
// col_index_num: 2, 0 = exact match
=VLOOKUP("Can",A2:B5,2,0)

Multiple Choice · VLOOKUP

Question 15: Looking Up to the Left

Column A holds Score and column B holds Name (A2:B5). Which formula returns Ece's score?

C: VLOOKUP always searches in the first column of the table (here Score) and looks only to the right; A and B give #N/A. In XLOOKUP the lookup array and the return array are given separately: the names are searched in B2:B5, and the A value in the same position (91) is returned. D searches for the name in the score column → #N/A.

B is wrong: since Excel does not recognize a function named "SUMM", the result is #NAME?. #REF! appears when the cell/column that the formula refers to is deleted (an invalid reference). Since an empty cell counts as 0, a division-by-zero error occurs in A.

Output Question · Data Analysis

Question 17: Multi-Level Sorting

The list is sorted first by Department (A→Z), and within the same department by Score (largest to smallest). After sorting, what are the names in rows 2–6, in order?

Show answer

Order: Ece, Naz, Can, Ali, Su

  • Level 1: Computer < Electrical < Mechanical.
  • Level 2 only within the same department: Ece 91 > Naz 77, Can 85 > Ali 72.
  • Rows move as a whole; each name stays with its own score.

Multiple Choice · Data Analysis

Question 18: A Two-Condition Filter

In the student list (6 records), only Electrical is selected in the Department column, then a Greater Than 70 number filter is applied to the Score column. How many records are visible, and what happens to the other records?

B: The conditions narrow together (AND): the Electrical ones are Ali 72, Can 85, Efe 58; of these, those greater than 70 are Ali and Can → 2 records. A filter does not delete data, it hides the rows (the row numbers appear blue and with gaps); Clear Filter brings them all back.

Multiple Choice · Data Analysis

Question 19: Icon Set Thresholds

The scores are 40, 55, 80, 92, 100. A three-icon set with default thresholds is applied (▲ 67% and above, ● 33%–67%, ▼ below 33%). Which icon appears in the cell with the score 80?

D: Percent thresholds are calculated from the smallest and largest values: 40 + 0.67 · (100 − 40) = 80.2 and 40 + 0.33 · 60 = 59.8. Since 80 < 80.2, it cannot get ▲; ● (middle) appears. 92 and 100 get ▲, 40 and 55 get ▼.

Multiple Choice · Charts

Question 20: Choosing the Right Chart Type

Which chart is most suitable for showing how monthly sales of a store change over time over 12 months?

A: Change over time (a trend) is shown with a line chart. A pie is for part-to-whole relationships with few categories, a scatter for the relationship of two numeric variables, and a histogram for the shape of one variable's distribution. For comparing categories, a column/bar chart is chosen.
