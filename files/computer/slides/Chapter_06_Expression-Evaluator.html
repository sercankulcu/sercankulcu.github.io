ŞİMDİ

    İfade Değerlendirici

    Amaç: Bir Java ifadesinin değerinin nasıl bulunduğunu adım adım görmek. Java önce işlem önceliğine göre ifade ağacını kurar, sonra işlenenleri soldan sağa değerlendirir.

    Nasıl kullanılır?

    1. Hazır bir örnek seçin ya da kutuya kendi ifadenizi yazıp Değerlendir'e basın.
    2. Adım ▶ her seferinde tek bir alt ifadeyi indirger; vurgulanan kısım bir sonraki adımda hesaplanacak olandır. Oynat adımları otomatik ilerletir, Geri bir adım döner. Klavyede → / ← tuşları da çalışır.
    3. Ağaçta her düğümün altında hesaplanan değer ve tipi (int / double) görünür.
    4. Kendini dene kipinde System.out.println(ifade) çıktısını tahmin edin: double sonuçlar 7.0 gibi yazılır; istisna fırlatacaksa hata yazın.

    Kurallar özeti

    • Öncelik: sonek x++ → önek ++x, birli -, açık dönüşüm (double) → * / % → + -. Aynı öncelikte soldan sağa.
    • İki int arasında / tam sayı bölmesidir: kesirli kısım atılır (17 / 5 → 3). % kalanı verir, işareti bölünenin işaretidir.
    • İşlenenlerden biri double ise diğeri de tip yükseltme ile double olur (7 / 2.0 → 3.5).
    • (double) 7 / 2 önce dönüşüm yapar (3.5); (double) (7 / 2) önce böler (3.0).
    • x++ eski değeri verir sonra artırır; ++x önce artırır, yeni değeri verir.
    • int bölmesinde sıfıra bölme ArithmeticException fırlatır; double bölmesinde Infinity ya da NaN çıkar. int taşması sessizce sarar.
