Computer Fundamentals and Introduction to Programming

Course Map

This page puts every chapter of the course on one map. Each chapter is a node, and an arrow shows which idea from an earlier topic the next one relies on. Read it before the course starts to see where the topics are heading, or during the course to see where you are.

Figure 1 shows the connections between the topics. Each node is a chapter, and an arrow indicates which idea of the earlier topic the later one relies on. Only the closest connections are drawn on the map; every chapter that a given chapter depends on is listed in Table 1.

Table 1: Connections on the map.
Topic (chapter)Builds onConnection
Computer Fundamentals and Computational Thinking (1)—Data represented as bits, hardware and computational thinking: the ground on which all the concepts of the course rest.
Operating Systems (2)Computer Fundamentals and Computational ThinkingThe software that manages the hardware: booting, processes, memory and the file system.
Office Applications (3)Operating SystemsApplications that run on the operating system: Word, Excel and PowerPoint.
Algorithms and Introduction to Programming (4)Computer Fundamentals and Computational ThinkingComputational thinking becomes an algorithm: pseudocode, flowcharts, searching and sorting.
Getting Started with Java (5)Operating Systems, Algorithms and Introduction to ProgrammingThe algorithm becomes Java code: source code, the compiler, bytecode and the JVM.
Variables, Data Types and Operators (6)Computer Fundamentals and Computational Thinking, Getting Started with JavaWhat data looks like in a program: primitive types, overflow, type conversion and operators.
Conditionals (7)Variables, Data Types and Operatorsboolean expressions choose the flow of the program: if, else if, switch.
Loops (8)ConditionalsRepetition while a condition stays true: for, while, do-while; counters and accumulators.
Methods (9)LoopsNaming work that repeats: parameters, return values, the call stack.
Arrays (10)Loops, MethodsIndexed data traversed with loops; the Java code of the searching and sorting from the Algorithms chapter.
Strings (11)Methods, ArraysA sequence of characters: String methods, immutability and StringBuilder.
Recursion (12)Algorithms and Introduction to Programming, MethodsA method that calls itself: the base case, the call stack, Hanoi and binary search.

The backbone of the map can be read as computer → algorithm → program → structure → reuse. The first part introduces the machine and the software that manages it. The Algorithms chapter writes down the steps of problem solving independently of any language; the Java chapters turn these steps into code one after another: first variables and operators, then decisions and loops, and finally methods. Arrays and strings are where loops and methods are used together; recursion makes the method call a tool for shrinking the problem.
