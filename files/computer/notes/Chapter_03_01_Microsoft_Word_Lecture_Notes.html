3.1.1Word and the word processor

The simplest way to write text on a computer is a plain-text editor. Notepad in Windows is an example: it stores letters, but it knows nothing about bold type, page numbers, or tables. A report, however, is more than letters. It has headings, paragraphs, tables, figures, footnotes, and a page layout. A program that keeps and manages all of these elements in a single file is called a word processor.

3.1.1.1What is a word processor?

Definition 3.1.1

A word processor is application software for typing, editing, formatting, laying out, and printing text. A file prepared in a word processor is called a document. Microsoft Word is the word processor of the Microsoft 365 suite; by default it stores its documents in files with the .docx extension.

What sets a word processor apart from a plain-text editor is that, besides the text, it also stores information about how the text looks and what it means. That a line is 14 point and blue is information about appearance. That the same line is a “level-1 heading” is information about structure. Word stores both. This distinction is also the most important idea in these notes: if appearance is derived from structure, the document is easy to manage. If appearance is applied by hand to every line, the document falls apart as it grows.

The page Word shows on screen is very close to the page that will come out on paper when printed. This approach is called WYSIWYG (what you see is what you get). Because the screen looks like paper, users tend to adjust formatting by eye. That is the trap. A heading pushed down with empty lines looks right on screen, but it drifts as soon as two lines are inserted above it. For this reason, most of these notes are about building the layout with Word's tools rather than by eye.

3.1.2The interface

When Word opens, the document area takes up most of the screen. The ribbon holding the commands sits at the top, the status bar at the bottom, and an optional navigation pane on the left. This section introduces the names and roles of these parts. Knowing where the commands are is the foundation for everything else.

3.1.2.1The workspace

Figure 3.1.1 breaks the Word window into its parts. Each part does the following:

  • The title bar shows the name of the open document. If the document is saved to the cloud, the AutoSave switch is here too.
  • The Quick Access Toolbar keeps a few frequently used commands, such as Save and Undo, always visible. The user chooses which buttons stay here.
  • The ribbon is the region that presents all of Word's commands, divided into tabs and groups.
  • The navigation pane lists the headings in the document as a tree; clicking a heading jumps to that place. Search results also appear here.
  • The document area is where the text is typed and the pages are seen. The blinking vertical line, the cursor, shows where the next typed character will be inserted.
  • The status bar shows the page number (“Page 1 of 3”), the word count, the document language, the view buttons, and the zoom slider.
Definition 3.1.2

The ribbon organizes commands on three levels: tab → group → command. A tab is one of the names along the top of the ribbon (Home, Insert, Layout…). Each tab is divided into several groups (on the Home tab: Clipboard, Font, Paragraph, Styles, Editing). Each group in turn holds the related command buttons. A contextual tab is an extra tab that appears only while a particular object is selected.

In these notes the location of a command is written as “tab → group → command”. For example, “Home → Paragraph → Center” means the Center button in the Paragraph group of the Home tab. The group name is omitted when there is no ambiguity, as in “Layout → Breaks”.

Contextual tabs keep the ribbon uncluttered. When a table is selected in the document, a Table Design tab and a separate Layout tab for the table appear on the right of the ribbon. When a picture is selected, the Picture Format tab appears. When the selection is cleared, these tabs disappear again. A user looking for a table's border color will not find the command on any tab unless they click the table first.

Common mistake

Looking on the ribbon for a table-specific or picture-specific command while no object is selected. These commands live on contextual tabs and are visible only while the object is selected. First click inside or on the object, then switch to the tab that appears on the right of the ribbon.

3.1.3Document management

A document's life begins with a blank page or a template. Content is written, saved, reviewed, and finally printed or shared as a PDF. This section covers the file side of that life cycle: the kinds of saving, automatic saving in the cloud, templates, and the internal structure of a document.

3.1.3.1Creating and saving documents

Preparing a document can be summarized as a five-step flow: open a new document or template, create the content, save, review, and finally export to PDF or print. Saving is not a step done only once in this flow; it is repeated many times during the work.

Definition 3.1.3

Save (Ctrl+S) overwrites the same file with the changes in the document open in the window. Save As (F12) writes the document as a separate file with a new name, location, or format; after that, the window works on this new file. When a new document is saved for the first time, Save behaves like Save As and asks for the file name, location, and format.

Figure 3.1.4 shows the difference between the two commands. The little-known consequence of Save As is this: after the command, the window is working not on the old file but on the newly created one. Every later Save updates the new file, and the old one stays as it was. The example below traces this behavior step by step.

Example 3.1.2

The disk holds experiment.docx, which contains only the introduction paragraph. The file is opened and the operations below are performed. After each step, what do the files on disk contain?

The Save in step 5 writes not to experiment.docx but to experiment_v2.docx, the file open in the window. The old file stays as it was in step 2.

Which format a document is saved in depends on what will be done with it. A document that will be edited further is kept as a Word document; a final version to be shared without changes is kept as a PDF. Table 3.1.4 summarizes the main file formats Word uses.

A PDF file can be opened in Word, but Word converts it into an editable document as it opens it, and the layout may break in the conversion. For this reason, the .docx original of every document exported to PDF is kept as well.

Common mistake

Keeping an assignment only as a PDF. A PDF preserves the layout but is unsuited to editing; even a small correction requested by the instructor may mean retyping the document. The right habit is to always keep the .docx original and to produce the PDF from it for submission.

3.1.3.2AutoSave, OneDrive, and AutoRecover

Forgetting to save is one of the oldest accidents in document preparation. Microsoft 365 offers two separate safeguards against it. Their names are similar, but they work differently.

Definition 3.1.4

AutoSave is a feature that writes the changes in the document to the file in the cloud automatically every few seconds. It works only on files stored in OneDrive or SharePoint, and it is switched on and off with the toggle in the title bar. AutoRecover, by contrast, keeps a separate recovery copy at regular intervals. If Word closes unexpectedly, it offers this copy when it reopens.

The AutoSave toggle cannot be turned on for a local file in a folder on the computer, such as one on the desktop. Such a file is saved by hand with Ctrl+S. Pressing Ctrl+S does no harm even when AutoSave is on. This habit keeps the document safe without having to think about whether it is local or in the cloud.

A file kept in the cloud has two further benefits. The first is version history: older versions of the file are listed with their dates and times. An earlier version can be opened, inspected, and restored if necessary. The second is co-authoring: several people can work on the same cloud file at the same time and see each other's changes within moments.

Table 3.1.5: A comparison of the saving-related features.
FeatureWhere does it write?When?Condition

Example 3.1.3

Two students are working on the same assignment. Elif keeps the file in her OneDrive folder; Can keeps his on the desktop. Neither presses Ctrl+S for a whole hour. Then the power goes out.

  1. Elif. Because the file is in the cloud, AutoSave is on. The changes were written to the cloud every few seconds. When the computer starts again, the file comes back in its latest state; at most the last few seconds are lost.
  2. Can. AutoSave does not work on a local file. The original file is as it was an hour ago. When Word reopens, it offers the latest AutoRecover copy. That copy contains the changes up to the last recovery moment; anything after that is lost.
  3. Conclusion. AutoRecover is a safety net, not a substitute for saving. The recovered copy should immediately be saved with Save As as the main file.

The name, position, and even the presence of the AutoSave button can vary with the Word version and its updates. For example, some Office versions sold with a perpetual license may lack this feature. Whether your version has it can be seen in the title bar and in File → Info.

3.1.3.3Templates

Imagine a student who writes a few petitions in the same format every semester. Each time the margins are set, the date is right-aligned, and a space is left for the signature. The tool that removes this repetition is the template.

Definition 3.1.5

A template is a Word file, stored with the .dotx extension, that serves as the starting point for new documents. It contains styles, margins, fixed text, and placeholders that mark the places to fill in. When a template is opened, Word opens not the template itself but an untitled copy derived from it.

Figure 3.1.5 shows this behavior. If you double-click the template, fill in the name and date, and then press Ctrl+S, Word asks for a file name, because the open document is an untitled copy. The template file remains unchanged, and as many petitions as you like can be produced from the same template.

Templates come from two sources. Ready-made templates are listed on the File → New screen: résumé, report, meeting notes, calendar, and so on. To create your own, first edit a sample document, then choose “Word Template (*.dotx)” as the file type in File → Save As.

Word has one more special template: Normal.dotm. The default font, size, margins, and styles used when a blank document is opened come from this file. The m in the extension shows that this template can also store macros. A change in Normal.dotm affects every blank document opened afterward, so it is touched only deliberately.

Example 3.1.4

A template will be prepared for lab reports. The steps and the result of each step are as follows:

  1. In a blank document the margins are set to 2.5 cm, and the Normal and Heading 1 styles are set to the desired font.
  2. Fixed text is typed on the cover: the course name, “Experiment No:”, “Student:”. Placeholders in square brackets mark the places to fill in: [Experiment title], [Full Name], [Date].
  3. The headings “Introduction”, “Method”, “Results”, and “Discussion” are written in the Heading 1 style, with the space beneath them left empty.
  4. File → Save As → file type “Word Template”: LabReport.dotx.
  5. For each new experiment the template is opened, the placeholders are filled in, and the report is saved under a name such as Experiment3_Report.docx. The template waits unchanged for the next experiment.
Common mistake

Opening an old report and deleting its content to write a new one, instead of using a template. Hidden items left over from the old report (comments, pending changes, author information, a forgotten paragraph) are carried into the new document. There is also the risk of accidentally saving over the old file. Preparing a template once for a recurring kind of document is both cleaner and safer.

3.1.3.4The structural levels of a document

A Word document is not a random heap of letters; it is made of nested levels. Knowing these levels lets you predict in advance which part of the document a formatting command will affect.

Definition 3.1.6

The structural levels of a Word document, from the inside out, are: character (a single letter, digit, space, or mark), word, paragraph (the text typed up to the point where Enter is pressed), section (a part of the document with its own page settings), and document. Every formatting command applies at one of these levels.

Figure 3.1.6 and Table 3.1.6 show these levels together with the formatting set at each. For example, bold is at the character level, alignment at the paragraph level, page orientation at the section level, and the theme at the document level.

Table 3.1.6: The structural levels and the formatting set at each level.
LevelFormatting setHow is it applied?
Characterfont, size, bold, italic, color, superscript/subscriptto the selected text; with no selection, to the text typed from then on
Paragraphalignment, indent, line and paragraph spacing, tab stops, borderto the whole paragraph the cursor is in; no selection needed
Sectionmargins, page orientation, number of columns, header/footer, page-number formatto all the pages of the section the cursor is in
Documenttheme, default styles, document propertiesto the whole document
Example 3.1.5

The document has two paragraphs and nothing is selected. With the cursor in the middle of paragraph 2, the Center and Line spacing 1.5 commands are given. Then the cursor is moved to the end of paragraph 1, Ctrl+B is pressed, and “ End.” is typed. What is the result?

  1. Center and line spacing are paragraph formatting. No selection is needed; the whole of paragraph 2, where the cursor is, is centered and set to 1.5 line spacing. Paragraph 1 is unaffected.
  2. Bold is character formatting. With no selection, Ctrl+B makes bold only the characters typed from then on. “ End.” is typed in bold; the existing text of paragraph 1 does not change.

Pressing the same key has a different effect depending on the level the command belongs to.

3.1.4Editing text

Writing a document takes far less time than revising what was written. A student writing a report spends most of the time moving sentences, changing words, and cleaning up unneeded spaces. The tools in this section speed up that work: keyboard movement and selection, the clipboard, undo, and find and replace. Each tool also has a trap, and the traps are shown together with examples.

3.1.4.1The cursor, movement, and selection

Definition 3.1.7

The cursor is the blinking vertical line in the document area; it shows where the next character will be inserted. A selection is a highlighted piece of text. Most commands, such as formatting, deleting, cutting, and copying, apply to the selection.

Moving the cursor by clicking with the mouse is enough in short text. In a long document the keyboard is much faster. The arrow keys move the cursor one character or line at a time. The Ctrl key enlarges the step: it raises it to the scale of a word, a paragraph, or the whole document. The Shift key turns movement into selection: wherever the cursor goes, the text between where it started and where it arrived is selected.

Common mistake

Accidentally pressing a letter key while a selection exists. Word replaces the selected text with the typed character; if the whole paragraph is selected, the paragraph turns into a single letter. There is no need to panic in such a case: Ctrl+Z undoes the last operation and the text comes back.

3.1.4.2Cut, copy, and paste

Definition 3.1.8

The clipboard is the memory area where cut or copied content is held temporarily. Copy (Ctrl+C) puts a copy of the selected content on the clipboard and leaves the source in place. Cut (Ctrl+X) removes the selected content from the document and puts it on the clipboard. Paste (Ctrl+V) inserts the clipboard content where the cursor is.

Figure 3.1.8 shows the one difference between the two operations: does the source stay in place? Copy duplicates; Cut moves. Pasting works the same way for both. The clipboard keeps its content after pasting, so the same content can be pasted again as often as you like. The clipboard holds only the last item cut or copied; a new copy replaces the old one. The Office Clipboard (the small arrow at the bottom-right corner of the Home → Clipboard group), however, can store the last 24 items and lets you paste any one of them.

When text is copied from another source, such as a web page, its color, font, and size come with it. What happens to this formatting on pasting is decided by the paste options:

  • Keep Source Formatting: the text arrives looking as it did at the source. A plain Ctrl+V usually does this.
  • Merge Formatting: the text adapts to the formatting of the place where it is pasted; emphasis such as bold and italic is kept.
  • Keep Text Only: all formatting is discarded; only the letters arrive and take on the formatting of the destination. In current Microsoft 365 versions its shortcut is Ctrl+Shift+V; in older versions the shortcut may differ. In every version it can be chosen from the arrow under the Home → Paste button.

It is also possible to copy formatting separately from the text. The Format Painter is the brush button in the Home → Clipboard group. First select the text whose formatting you want to take, and click the brush. Then select the text the formatting is to be applied to. If you double-click the brush, the tool stays on and can be applied in several places in turn; Esc turns the tool off.

The power of cut and paste is best seen in a small correction. Consider a three-line recipe. The order of the recipe is wrong: the step “Mix the ingredients” is on the second line but should be first. Instead of deleting the line and retyping it, the line is moved.

3.1.4.3Undo, find, and replace

Word keeps the operations performed in a list, in order. Undo (Ctrl+Z) reverses the last operation on this list. If pressed repeatedly, the operations are undone one by one, from last to first. Redo (Ctrl+Y) performs the last undone operation again. When there is nothing to redo, it repeats the last command once more. For example, after one paragraph is made bold, selecting another paragraph and pressing Ctrl+Y makes that one bold too.

Definition 3.1.9

Find (Ctrl+F) searches the document for places where a text occurs and lists the results in the navigation pane. The Find and Replace dialog (Ctrl+H) replaces the places where the text typed in the Find what box occurs with the text in the Replace with box. The Replace button replaces the current match, and Replace All replaces all matches at once.

Replace All is a powerful but dangerous command. By default the search looks for a character string and pays no attention to word boundaries. Figure 3.1.11 shows the result: searching for “and” also matches the middle of the word “candy”. There are two ways to guard against this trap. The first is to open the search options with the More >> button and check the Find whole words only box. The second is, instead of Replace All, to first look at the matches one at a time with Find Next and press Replace only on the right ones.

Example 3.1.8

The document has a single sentence: “Test results and handwritten notes were collected at home and at school.” Find what: and, Replace with: or. What is the result of Replace All under the two settings?

  1. Counting the matches. The string “and” occurs in three places in the sentence, from left to right: the first conjunction “and”, the middle of “handwritten”, and the second conjunction “and”. None of the other words contains it, so there are no other matches.
  2. Default setting. All three matches are replaced (3 replacements): “Test results or horwritten notes were collected at home or at school.” The word “handwritten” has been broken.
  3. Find whole words only. Matches with no letter before or after them are replaced; the match inside “handwritten” is skipped (2 replacements): “Test results or handwritten notes were collected at home or at school.”

If the error is noticed, a single Ctrl+Z undoes all the replacements at once, because Replace All counts as one operation.

Find and Replace can look for not only letters but also special items in the document: paragraph marks, tabs, page breaks, and formats. For that you need to know the hidden marks.

Common mistake

Replacing a short word with Replace All without previewing. Changing “cat” to “dog” turns “catalog” into “dogalog” and “category” into “dogegory”. For short strings that can occur inside other words, either check “Find whole words only” or check the matches one by one with Find Next.

3.1.5Formatting

Formatting is the whole set of settings that determine the appearance of the text. The levels in 3.1.3.4 apply here too: some settings apply to the character, others to the paragraph. In a short document, giving formats one by one causes no trouble. In a long document, repeating the same settings dozens of times takes time and creates inconsistency. This section introduces character and paragraph formats, then the tool that removes this repetition, the style.

3.1.5.1Character formatting

Definition 3.1.12

Character formatting is the set of settings that determine the appearance of individual characters: the font (the visual family of the characters, such as Calibri or Times New Roman), the size (in points), emphasis (bold, italic, underline, color), case conversion, superscript, and subscript. These settings are in the Home → Font group and apply to the selected text.

Text size is measured in points (pt). The point is a unit of length that comes from printing: 1 inch is 72 points, and 1 inch is 2.54 cm. From this the millimeter equivalent of a point can be found.

Example 3.1.10

How big is 12 points?

  1. 1 pt = 1/72 in = 25.4 mm ÷ 72 ≈ 0.353 mm.
  2. 12 pt = 12 × 0.353 mm ≈ 4.23 mm.
  3. For comparison: 72 pt is exactly 1 inch, that is, 2.54 cm.

The point size is not the height of the letter itself but the height of the font's design box. This box extends from the top of the letter that rises highest (b, l) to the bottom of the letter that descends lowest (g, p). That is why a 12-point “a” is shorter than 4.23 mm. Two different fonts at the same point size can also look different in size.

Figure 3.1.16 shows formats that are common in engineering texts. Subscript is used in chemical formulas (H₂O, CO₂), superscript in exponents and units (x², m³, 10⁻⁶). These formats are not merely appearance: “m3” and “m³” mean different things. The Change Case command is the Aa button in the Home → Font group. Without retyping the selected text, it converts it to UPPERCASE, lowercase, or Capitalize Each Word.

The Clear All Formatting command (the A button with an eraser in the Home → Font group) removes all manually applied character formats from the selected text and returns the text to the default look of its style. It is the fastest way to fix text that looks odd after being pasted from another source.

Common mistake

Selecting the headings of a long document one by one and changing the font, size, and color by hand. If one of twenty headings is forgotten, or one is given 16 points instead of 15, the document becomes inconsistent. If the look changes later, all twenty headings have to be fixed again. Styles are used for repeated formats (3.1.5.5).

3.1.5.2Paragraph formatting

Definition 3.1.13

A paragraph in Word is the text between two paragraph marks ( ). Paragraph formatting is the set of settings applied to a paragraph as a whole: alignment, indent, line spacing, paragraph spacing, tab stops, border, and shading. These settings are in the Home → Paragraph group and are stored in the paragraph's mark.

No selection is needed for paragraph formatting; if the cursor is anywhere in the paragraph, the command applies to the whole paragraph. To format several paragraphs, select at least a piece of each.

Figure 3.1.17 compares the alignment types. Body text is usually left-aligned or justified. Headings and the cover page are centered, and the date in a petition is right-aligned. In justified text Word widens the gaps between words to make a line reach the edge. In narrow columns or with long words these gaps can be conspicuous; in that case hyphenation (3.1.6.1) can be turned on.

Tabs are used to set text at particular horizontal positions on the page. For example, if in a petition you want all the values after “Full Name:” to start at the same alignment, you use the Tab key and a tab stop. Borders and shading set a paragraph apart from its surroundings with a frame or a background color; they are suitable for making a warning note stand out.

Common mistake

Aligning text with the space bar. A line such as “Full Name: Ayşe” that looks right on screen shifts when the font or size changes, because the width of space characters depends on the font. Use a tab, an indent, or a table without borders for alignment.

3.1.5.3Indent and spacing measurements

An indent determines how far in from the margin a paragraph starts. Spacing is the vertical space left between lines and between paragraphs. These four measurements have the greatest share in whether a document looks “readable” or “cramped”.

Definition 3.1.14

The left and right indents are how far in from the left and right margins all the lines of a paragraph stand. The first-line indent pushes in only the first line of a paragraph. The hanging indent is its opposite: the first line stays at the left and the following lines are indented. Line spacing is the distance between the lines of a paragraph. Paragraph spacing is the space left before (Before) and after (After) a paragraph; in Word it is given in points (pt).

Figure 3.1.18 shows these measurements on the ruler. The markers on the ruler can be adjusted by dragging, but for an exact value click the arrow at the bottom-right corner of the Home → Paragraph group. In the Paragraph dialog that opens, indents are typed in centimeters and spacing in points. The “pt” unit in Word is the same as the point used for font size: 1 pt ≈ 0.353 mm.

The first-line indent is the traditional way of marking the start of a paragraph in running text; a common value is 1.25 cm. The hanging indent is used especially in a bibliography. The first line of each source starts at the left and the continuation lines stay indented. That way the reader easily tells where each source begins.

Example 3.1.11

In a report set in 12-point text, a spacing of “After: 12 pt” will be used between paragraphs instead of an empty line. How many millimeters is this space? If the line spacing is set to “Exactly 18 pt”, how many millimeters does one line take up?

  1. Spacing after a paragraph. 12 pt × 0.353 mm ≈ 4.23 mm. This is the same height as the font box of an empty 12-point line; the look is close to an empty line, but there is no extra in the document.
  2. Line height. “Exactly 18 pt” gives each line 18 × 25.4 ÷ 72 = 6.35 mm. This value is 1.5 times 12 points.

The “1.5 lines” option in the line-spacing list, on the other hand, is calculated from the font. Word multiplies the single-line height that the font itself suggests by 1.5; for most fonts this height is slightly larger than the point size. That is why “1.5 lines” and “Exactly 18 pt” are close but usually not equal.

Common mistake

Pressing Enter twice to leave space between paragraphs. When empty paragraphs land at the end of a page, they leave a gap at the top of the new page, the layout is disturbed, and cleanup is needed as in 3.1.4.5. Paragraph spacing, on the other hand, shows only between paragraphs and moves with the paragraph.

3.1.5.4Lists

Reports present a lot of information as lists: lab materials, procedure steps, section headings. Word offers three types of list, and all are in the Home → Paragraph group.

  • A bulleted list is for items whose order does not matter, such as lab materials.
  • A numbered list is for items whose order matters: procedure steps, order of priority.
  • A multilevel list builds a hierarchy of main items and sub-items: 1, 1.1, 1.1.1, and so on.

The level-changing rule in Figure 3.1.19 is the most useful feature of lists. If Tab is pressed at the start of a list item, the item drops to a lower level; its number also changes from “3.” to a lower-level number such as “a.” or “2.1”. Shift+Tab raises the item one level. Pressing Enter on an empty item at the end of the list ends the list.

3.1.5.5Styles and themes

The character and paragraph formats described so far can be applied one by one. But in a report the same look is repeated over and over: all the main headings are formatted the same way, and so are all the body paragraphs. The tool that gathers these repeated formats under a name is the style.

Definition 3.1.15

A style is a named package of formatting: it defines settings such as font, size, color, alignment, indent, and spacing together under a single name. Among Word's built-in styles are Normal (body text), Heading 1 (main section heading), and Heading 2 (subsection heading). Styles are applied from the Home → Styles gallery. A theme is the document's overall system of colors, fonts, and effects; it is chosen from the Design tab.

The power of a style comes from a single definition. When Heading 1 is applied to a heading, that heading takes the look in the style's definition. If the style's definition is changed later, all the headings that use this style are updated together. Instead of fixing twenty headings one by one, a single definition is changed.

The second job of heading styles is more important than appearance: they build the structure of the document (Figure 3.1.20). Word recognizes paragraphs in the Heading 1, Heading 2, and Heading 3 styles as “headings”. The navigation pane, the table of contents, the Outline view, and the bookmarks in a PDF are all generated from this information. A line that is merely typed large and bold is, to Word, an ordinary paragraph, however much it looks like a heading.

The relationship between theme and style is layered. The theme determines the document's color palette and its two basic fonts (for headings and for body text). Styles use this palette and these fonts. When another theme is chosen from the Design tab, the styles keep their definitions but take their colors and fonts from the new theme. For example, if Heading 1 is defined with “theme color 1”, all Heading 1s switch to the new theme's first color when the theme changes. A style change, by contrast, affects only the items that use that style.

Common mistake

Leaving a heading in the Normal style and simply typing it bold and large. The look is right, but the navigation pane stays empty and an automatic table of contents does not see this heading. Headings are always written with heading styles; if the look is not liked, the style's definition is changed.

3.1.5.6Style definitions and direct formatting

Text with a style applied can also be given formatting from the ribbon. For example, a heading in the Heading 1 style can be made red with the ribbon's color button. In that case the look of the heading comes from two sources: the style definition and the manually applied format. Knowing which one wins prevents most of the surprises that come up when working with styles.

Definition 3.1.16

Direct formatting is formatting given to text one item at a time, from the ribbon or with a shortcut, rather than through a style. Direct formatting takes precedence over the style: even if the style's definition changes, the manually applied property is kept on that text. Ctrl+Space removes the manually applied character formats from the selected text and ties the text back to the style's definition.

A style definition is changed in two ways. Right-clicking the name of a style in the Styles gallery opens a menu. The Modify… option lets you edit the style's properties in a dialog. Update Heading 1 to Match Selection, on the other hand, takes the definition from the look of the currently selected text. The second way is handy for first trying out a heading by hand and then spreading the look you like to all headings.

The Word Styles, Navigation Pane and Table of Contents simulator lets you try this interaction.

3.1.6Page layout

Character and paragraph formats determine the look of the text. Page layout defines the paper the text sits on: the size of the paper, its orientation, margins, number of columns, header, and footer. All of these settings are at the section level. If a document consists of a single section, all pages have the same layout. When different pages need different layouts, the document is divided into parts with section breaks.

3.1.6.1Page setup

Page settings are collected in the Page Setup group on the Layout tab (Figure 3.1.23):

  • Margins: the blank area between the text and the edge of the paper. For documents that will be bound, an extra gutter can be added on the binding side.
  • Orientation: the page is portrait or landscape.
  • Size: the paper size. A4 (210 × 297 mm) is common in Turkey and Europe, Letter (8.5 × 11 in ≈ 216 × 279 mm) in the USA.
  • Columns: divides the text into columns similar to a newspaper layout. When the text reaches the end of the first column, it continues at the top of the second.
  • Line Numbers: numbers the lines in some legal or refereed documents, so that a correction can be pointed to as “line 12”.
  • Hyphenation: splits long words at the end of a line with a hyphen, reducing large gaps in justified text.
Example 3.1.14

On an A4 page, all four margins are 2.5 cm. How much space is left for text? With line spacing “Exactly 18 pt”, what is the maximum number of lines that fit on a page?

  1. Width. 210 mm − 2 × 25 mm = 160 mm.
  2. Height. 297 mm − 2 × 25 mm = 247 mm.
  3. Line height. 18 pt = 18 × 25.4 ÷ 72 mm = 6.35 mm (3.1.5.3).
  4. Number of lines. 247 ÷ 6.35 ≈ 38.9. Half a line does not fit on the page; round down: 38 lines.

If the same document is printed on Letter size, the page is 6 mm wider but 18 mm shorter. The number of lines decreases and the page breaks shift. For that reason the paper size of a document is set before you start writing, according to where it will be submitted.

3.1.6.4Headers, footers, and page numbers

Definition 3.1.18

The header and footer are areas repeated in the top and bottom margins of every page. Information such as the document title, section name, author, date, and page number is written there. They are edited with the Insert → Header / Footer commands or by double-clicking the top or bottom margin of the page.

The page number is inserted as a field from the Insert → Page Number menu (Figure 3.1.27). A field is a value that Word calculates and shows according to the current situation. A number field inserted once in the footer shows that page's number on every page. As pages are added and deleted, the numbers update by themselves. A “3” typed by hand, on the other hand, stays “3” on every page.

There are two more options for headers and footers. When Different First Page is checked, the first page of the section gets a separate header/footer area; this area is left empty so that the cover shows no number. Different Odd & Even Pages lets you put the number on the right on odd pages and on the left on even pages in documents printed double-sided.

3.1.6.5Different First Page and Link to Previous

Once a document is divided into several sections, a new rule comes into play for headers. A new section starts with its header and footer linked to those of the previous section by default.

Definition 3.1.19

Link to Previous is the button on the Header & Footer contextual tab that appears while a header or footer is being edited. When it is on, the section's header shares the same content as the previous section's: a change made in one appears in the other. When it is turned off, the section has its own independent header.

3.1.6.6Page numbering by section

In theses and long reports, page numbering has two parts. Front matter such as the cover, abstract, and table of contents is numbered with lowercase Roman numerals (i, ii, iii), and the main text is numbered 1, 2, 3 starting from the Introduction page. This arrangement is built with a section break and section-specific page-number settings.

Definition 3.1.20

The Page Number Format dialog is opened with Insert → Page Number → Format Page Numbers and manages two section settings. The number format is how the number is written: 1, 2, 3 or i, ii, iii. Page numbering is where the number starts: “Continue from previous section”, or the value typed in the “Start at” box. Both settings apply to the section the cursor is in.

A reminder about lowercase Roman numerals is useful: i = 1, v = 5, x = 10. If a smaller symbol comes before a larger one it is subtracted, and if it comes after it is added. So ii = 2, iii = 3, iv = 5 − 1 = 4, vi = 5 + 1 = 6.

3.1.7Tables and pictures

In engineering reports, numerical results are given in tables, and setups and graphs as pictures. Word places these objects inside the text and offers separate contextual tabs for each. This section explains the structure of tables and how pictures relate to the text.

3.1.7.1Tables

Definition 3.1.21

A table is an object that arranges information in cells made of rows and columns; it is inserted with Insert → Table. A row is a horizontal sequence of cells and a column a vertical one; the box where the two intersect is called a cell. The first row, which explains what the columns mean, is called the header row.

A few principles help when building a table's layout (Figure 3.1.32):

  • A header row should always be present. If the table runs over several pages, you can choose to repeat the header row on every page (table Layout tab → Repeat Header Rows).
  • Merging cells should be used only for a meaningful group of headings. Too many merged cells make it hard for screen readers to read the table correctly and break sorting.
  • Table styles (Table Design tab) apply borders and colors consistently to the whole table; there is no need to shade cells one by one.
  • Alignment: text is aligned left, and numbers right or on the decimal point, so that the digits line up.
Example 3.1.18

The Average column in Figure 3.1.32 is the arithmetic mean of the midterm and final scores. Let us check the values:

  1. Ali: (70 + 80) ÷ 2 = 150 ÷ 2 = 75.
  2. Ece: (90 + 85) ÷ 2 = 175 ÷ 2 = 87.5.
  3. Can: (60 + 72) ÷ 2 = 132 ÷ 2 = 66.

All three values are correct. Word tables are not spreadsheets: when a score changes, the average does not update by itself. The Formula command on the table Layout tab can do simple calculations, but calculation-heavy tables are prepared in Excel and inserted into Word.

3.1.7.2Pictures

Pictures are inserted with Insert → Pictures from the computer, from online sources, or from stock images. When a picture is selected, the Picture Format contextual tab opens. Three tools on this tab are especially important:

  • Alt text: a short text that explains the purpose of an image to screen-reader users who cannot see it. It should describe the information the image conveys, not be a file name like “image1.png” (3.1.11.1).
  • Crop: leaves unneeded edge areas of the image outside the frame. The cropped part is not deleted but hidden; it can be brought back if necessary. To reduce file size, the cropped areas can also be deleted.
  • Layout Options: the small button that appears at the top-right corner when a picture is selected. It changes the picture's relationship to the text, that is, the text-wrapping type.

3.1.8Review and collaboration

After a document is written it is reviewed at least once: spelling errors are corrected, wording is tidied, and someone else's suggestions are weighed. The Review tab gathers the tools for this work. Some of the tools are for the author's own checking, others for several people working on the same document.

3.1.8.1Language, proofing, and word count

While you type, Word checks the text in the background (Figure 3.1.35). A word not found in the dictionary is marked with a red wavy line, and a suspected grammar or punctuation problem with a blue double line. Right-clicking a marked word lists suggestions. A suggestion can be chosen, the mark can be ignored, or the word can be added to the user's dictionary.

The checking rules are determined by the document language. If the status bar says “English (United States)”, the English dictionary is used. If English text is accidentally marked as Turkish, nearly every word is underlined in red. The language is changed by selecting the text and using Review → Language → Set Proofing Language. This way, English paragraphs and a Turkish abstract can sit side by side in one document, each checked with its own rules.

Treating text with no underlines as error-free. The check catches only words that are not in the dictionary. Automatic suggestions do not know the context either; the author judges each suggestion before accepting it.

3.1.8.2Comments and Track Changes

Imagine a student sending a thesis draft to the advisor. If the advisor edits the text directly, the student cannot see what changed. If the advisor writes notes in the margin by hand, the notes get mixed with the text. Word offers two separate tools for this collaboration.

Definition 3.1.23

A comment is a question, suggestion, or piece of feedback attached to a spot without changing the text; it is added with Review → New Comment and appears as a balloon in the right margin. With Track Changes on, every insertion, deletion, and format change is recorded along with who made it and when. A recorded change stays pending until the author accepts or rejects it.

Figure 3.1.36 shows the difference between the two tools. A comment is a conversation: it can be replied to, marked as “resolved”, or deleted. It never touches the text. Track Changes, by contrast, is a suggestion in the text itself: if accepted, the text becomes final; if rejected, it returns to its old state. Changes can be accepted one by one or all at once with Accept → Accept All Changes.

3.1.9Long documents

In a document of more than ten pages, readers need guides to find what they are looking for: a table of contents, numbered headings, numbered figures, footnotes, and a bibliography. All of these elements can be typed by hand. But as the document changes, every hand-typed number becomes a source of errors. Word generates all of these elements automatically from the structure of the document and keeps them up to date.

3.1.9.1Heading styles and the table of contents

Building an automatic table of contents is a four-step flow: heading styles are applied, the levels are checked in the navigation pane, the table of contents is inserted, and the table is updated as the document changes.

Definition 3.1.24

A table of contents is a list inserted with References → Table of Contents and generated automatically from the heading styles in the document (Heading 1, Heading 2, Heading 3). Each line holds the heading's text and its page number. The table is a field: it does not refresh by itself when the document changes; it is updated with the Update Table command (or with F9 while the table is selected).

In theses and technical reports the headings are numbered: 1 Introduction, 1.1 Purpose, 1.1.1 Objectives. The right way is to link a multilevel list to the heading styles.

The linking is done in the Home → Paragraph → Multilevel List → Define New Multilevel List window. In the window, “More >>” opens additional options and, for each level, a style is chosen in the “Link level to style” field: level 1 to Heading 1, level 2 to Heading 2, level 3 to Heading 3. 3.1.9.3Footnotes, citations, and the bibliography

Definition 3.1.25

A footnote is an additional explanation of an expression, given at the bottom of the page. An endnote gathers the explanations at the end of the document or section. Both are inserted from the References tab and numbered automatically. A citation is a reference in the text to a source. A bibliography is the list of the sources cited in the document.

To insert a footnote, place the cursor at the end of the word the explanation attaches to and choose References → Insert Footnote. Word puts a superscript number in the text and moves the cursor to the footnote area at the bottom of the page (Figure 3.1.44). When a new footnote is inserted in between, the numbers of the following footnotes shift by themselves. If, as the text moves, the word a footnote is attached to goes onto another page, the footnote moves with it to the bottom of that page.

Word can also take over source management. With References → Insert Citation → Add New Source, a source's author, title, year, and publisher are entered in a form. This source is inserted as a citation wherever wanted in the text. The citation style (APA, IEEE, MLA, Chicago, and so on) determines the format of these citations and of the bibliography lines. When the style is changed, all citations and the bibliography switch to the new format. The References → Bibliography command generates an automatic list from the cited sources.

Example 3.1.24

A lab report cites two sources: a textbook and a datasheet. The instructor first asks for APA, then says to switch to IEEE format.

  1. Each source is entered once with the Add New Source form. At the citation points, the relevant source is chosen from the Insert Citation list.
  2. With the citation style set to APA, the citations in the text take the author–year form, for example “(Patterson, 2020)”.
  3. At the end of the report a Bibliography is inserted; the two sources are ordered by APA rules.
  4. IEEE is chosen from the References → Style list. The citations in the text turn into numbers in square brackets, for example “[1]”. When the bibliography is updated, its lines also switch to the numbered IEEE format.

With hand-typed citations this switch means retyping every citation and every bibliography line one by one. Even so, the lines Word generates are only as correct as the information entered in the form. The author of the document checks the accuracy of author names, years, and page numbers.

3.1.9.4Captions and cross-references

Definition 3.1.26

A caption is a label that identifies a figure, table, or equation with a numbered title such as “Figure 1: Circuit diagram”; it is inserted with References → Insert Caption. A cross-reference is a dynamic link from the text to a heading, figure, table, or page elsewhere in the document. A table of figures is a list of figures generated from the captions.

The number in a caption is a field too. When a new figure is added to the document, Word shifts the numbers of the following figures. If the phrase “as seen in Figure 3” in the text was typed by hand, it knows nothing of this shift and starts pointing to the wrong figure. A cross-reference (References → Cross-reference), by contrast, takes the number from the caption and shows the new number when updated.

3.1.10Mail merge

The department office will send each of 120 students a letter announcing their final grades. The text is the same for everyone; only the name, department, and grade change. Writing 120 letters one by one would take hours and risks putting the wrong grade in the wrong student's letter. Mail merge solves this with a main document and a list.

3.1.10.1The main document, the data source, and fields

Definition 3.1.27

Mail merge is a Mailings-tab feature that combines a main document with a data source to produce a personalized output for each recipient. The main document holds the text and layout common to everyone. The data source (for example, an Excel table) holds the recipients' information: each column is a field, and each row is a record, that is, one recipient. A merge field is a placeholder such as «Name» that marks where a value will go in the main document.

The merge proceeds in five stages: the main document is prepared, the recipient list is chosen, merge fields are inserted, the results are previewed, and finally the documents or e-mails are produced. The preview stage should not be skipped. A typo in a column name or an empty cell means an error in hundreds of documents at once.

The first row of the data source holds the field names: Name, Department, Grade. This row is not a recipient and produces no letter. So a list of n rows whose first row is a header yields n − 1 letters. Short, space-free, meaningful field names make it easier to pick the right field in the main document.

3.1.11Quality and sharing

After a document has been written and reviewed, it goes through a final check. Is the document accessible to everyone who will read it? Does it keep its layout when printed or exported to PDF? Does it contain a forgotten comment, hidden change, or personal information? This section deals with these questions and with the security risk that macros carry.

3.1.11.1Accessible documents

Definition 3.1.28

An accessible document is one that people with visual, hearing, or motor impairments can also read and navigate using assistive technologies (for example, screen readers that read text aloud). The accessibility checker (Review → Check Accessibility) lists the possible problems in the document and suggests fixes.

A screen reader reads a document aloud from top to bottom. The user can jump from heading to heading, list the links, and move through a table cell by cell. All of these capabilities rest on the structure of the document. A document that looks right but lacks structure is a meaningless heap of text to a screen reader. The principles of accessibility therefore coincide with the good habits taught since the beginning of these notes:

  • Heading styles tell the screen reader the structure of the document; the user can jump between headings.
  • Alt text explains what meaningful images convey. Images that are purely decorative are marked as “decorative” and are not read out.
  • Link text describes the destination. “Click here” says nothing once it is taken out of context; “Registration Guide (PDF)” names the destination.
  • Table structure is kept simple and the header row is clear. Layouts made with empty cells or merged cells confuse reading across cells.
  • Color and contrast: meaning is not conveyed by color alone. Instead of “Rows in red failed”, a word or symbol saying “failed” is added to the rows as well. Enough contrast is left between text and background.

Figure 3.1.50 shows two small differences. Good alt text conveys to someone who cannot see the image the information the image gives. For a chart, writing “chart” is not enough. The trend the chart shows (“Enrollments rise from 2020 to 2024”) is what gets written. If the detailed numbers are already given in the text or in a table, the alt text can be kept short.

Common mistake

Treating accessibility as an extra job that concerns only readers with disabilities. Heading styles, meaningful link text, and simple tables make every reader's work easier. The bookmarks that appear in a document exported to PDF, search engines indexing the content correctly, and the document being readable on a phone all rest on the same structure.

3.1.11.2Printing and PDF

The File → Print screen shows the print settings on the left and the print preview on the right. The preview is the last check of how the document will come out on paper. An overflowing table, an empty page that has slipped in, or a picture stuck to the margin is noticed here.

The settings in Figure 3.1.51 mean the following. Copies is how many times each page is printed. The Pages box determines which pages are printed: a hyphen marks a range, a comma separates individual pages. For example, “1-3, 5” is pages 1, 2, 3, and 5; that is, 4 pages are printed. The Print All Pages menu also lets you print the selected text or only the current page. Print on Both Sides uses both sides of the paper on printers that support it and cuts paper consumption roughly in half.

Example 3.1.27

In the 6-page document of Figure 3.1.51, “1-3, 5” is typed in the Pages box. How many pages come out, and how many sheets of paper are used, for one-sided and two-sided printing?

  1. Pages to be printed. “1-3” is three pages (1, 2, 3), and “5” is one page. In total 4 pages; pages 4 and 6 are not printed.
  2. One-sided. Each page is printed on a separate sheet: 4 sheets.
  3. Two-sided. Each sheet holds two pages: 4 ÷ 2 = 2 sheets. If the number of pages were odd, it would be rounded up; for example, 5 pages would take 3 sheets.
  4. If Copies were 3. Two-sided printing would use 3 × 2 = 6 sheets.

The standard way to share a document without changes is PDF. Exporting (File → Export → Create PDF/XPS Document, or Save As → file type PDF) produces a copy that keeps the layout. This copy looks the same on a device that does not have Word. In the options window you can ask for PDF bookmarks to be created from the headings. A clickable table of contents then appears in the sidebar of the PDF reader. This is another gain from a document written with heading styles.

Before sharing, the document is also checked for hidden content. Comments, pending changes, and document properties (metadata such as author name, title, and tags) go with the document. The File → Info → Check for Issues → Inspect Document command lists them and, if wanted, removes them all at once. An assignment whose author field shows someone else's name gives away that an old file was used instead of a template.

Common mistake

Printing or exporting to PDF without looking at the print preview. A paragraph added at the last minute can push a table onto the next page. An empty page may be left at the end of the document, or the table of contents may show old numbers. A preview takes a few seconds; reprinting costs paper and time.

3.1.11.3Macros and security

Definition 3.1.29

A macro is a small program that makes a repeated sequence of commands runnable with a single command. It is created by recording the user's actions (View → Macros → Record Macro) or by writing code in VBA (Visual Basic for Applications). Documents that contain macros are stored with the .docm extension, and templates that contain macros with .dotm.

Macros save time in real work. For example, applying the same format to hundreds of tables, or setting all the pictures in a document to the same width, can be done with a single macro. But a macro is a program. A macro that runs when a document is opened can delete files, download other files, or install malware on the computer. That is why attackers hide malicious macros in “invoice” or “shipping information” documents attached to e-mails.

When opening a document with macros, Word by default does not run the macros and shows the warning in Figure 3.1.52. Pressing the Enable Content button means giving the macros in the document permission to run on the computer. For files downloaded from the internet or received by e-mail, current Microsoft 365 versions can block macros entirely. In that case a security-risk warning appears in place of the button. The rule is simple: do not enable content in a document of unknown or unexpected origin. For an unexpected macro-enabled document, even one that seems to come from a known person, ask the sender through a separate channel.

3.1.11.4A document-preparation workflow and common mistakes

A long document is prepared in six stages: the purpose and audience are determined, a draft structure (the headings) is built, the content is written, styles and images are arranged, the document is reviewed, and it is published. The order has an important logic: structure and content come first, and detailed formatting is left for last. Fussing over fonts while the content is still changing is wasted effort. If styles are used, the formatting is in any case set in one place, at the very end, in a few minutes.

The common mistakes spread through these notes are gathered in Table 3.1.15. The fix for all of them rests on the same principle: tell Word the structure, not the appearance.

Even if the document grows to a hundred pages, a change requested at the last minute takes a few minutes.

3.1.12Summary

  • Word is a word processor; it stores a document in a .docx file. Commands sit on the ribbon in a tab → group → command arrangement; contextual tabs appear when a table or picture is selected.
  • Save updates the open file; Save As creates a new file and the window then works on that file. AutoSave works only on a file in the cloud; AutoRecover is no substitute for saving.
  • When a template (.dotx) is opened, an untitled copy derived from it is opened; the template does not change.
  • The structural levels of a document are character, word, paragraph, section, and document. Character formatting applies to the selection, paragraph formatting to the paragraph the cursor is in, and page settings to the section the cursor is in.
  • Cut moves, Copy duplicates; the clipboard keeps its content after pasting. Replace All also changes the insides of words; “Find whole words only” or a Find Next preview is needed.
  • Hidden marks ( , ·, →) are shown with the button; in Find and Replace they are searched with the codes ^p, ^t, ^l, ^s, ^m. ^p^p → ^p is repeated until the result is 0.
  • A style is a named package of formatting; when its definition changes, all the items that use it are updated. Direct formatting takes precedence over the style; Ctrl+Space removes manually applied character formatting.
  • A page break does not create a section; a section break does. To make a single page landscape, put a section break before and after it.
  • The header of a new section starts linked to the previous one by Link to Previous; break the link before typing different content. The page-number format and starting value are set per section.
  • Heading styles are the source of the table of contents, captions are the source of the table of figures, and cross-references depend on both. These are fields; they are refreshed with F9 or Update Table.
  • A comment does not change the text; Track Changes records every edit as a suggestion awaiting acceptance or rejection. Hiding markup is not accepting the changes.
  • In mail merge the main document holds the common text and the data source holds the recipients; the header row does not produce a letter.
  • Before sharing, check hidden content with print preview, the accessibility check, and Inspect Document; do not enable macros in a document of unknown origin.

3.1.14Test Yourself

  1. design.docx is opened on disk. In order: paragraph A is typed, Ctrl+S; paragraph B is typed, Save As → design_final.docx; paragraph C is typed and Word is closed without saving. In the end, which paragraphs are in the two files?

    Answer

    design.docx: only A, because nothing was written to this file after Save As. design_final.docx: A and B. C was lost because it was never saved; after Save As, the file open in the window was design_final.docx.

  2. A one-line document: “This note is read before the exam.” The cursor is at the start of the line. The following are pressed in order: Ctrl+→, Ctrl+Shift+→, Ctrl+Shift+→, Ctrl+I. Which words become italic, and where does the cursor end up?

    Answer

    Ctrl+→ takes the cursor to the start of “note”. Two Ctrl+Shift+→ presses select first “note ”, then “note is ”. Ctrl+I applies to the selection: “note is” becomes italic. The cursor is at the start of the word “read” and the selection remains.

  3. After the “Conclusion” paragraph there are four empty paragraphs in a row, followed by the “Appendices” paragraph. With Find what ^p^p and Replace with ^p, how many times is Replace All run, and how many replacements are made each time?

    Answer

    After “Conclusion.” five follow in a row. Run 1: pairs are matched from the left, 2 replacements; 3 remain (two empty paragraphs). Run 2: 1 replacement; 2 remain (one empty paragraph). Run 3: 1 replacement; a single remains. Run 4 gives 0 results and shows the job is done.

  4. The headings Purpose, Data, and Scope are in the Heading 2 style (12 pt, blue). Data is made orange from the ribbon. Then the definition of Heading 2 is changed with Modify… to 13 pt and purple. How do the three headings look? What happens next if Data is selected and Ctrl+Space is pressed?

    Answer

    Purpose and Scope: 13 pt, purple. Data: 13 pt but orange, because the color was given to it by hand and direct formatting takes precedence over the style; the size comes from the definition because it was not given by hand. Ctrl+Space deletes the manually applied color; Data also becomes 13 pt and purple.

  5. In a 10-page portrait document, a wide table spanning pages 4 and 5 and a diagram on page 9 must be landscape. How many section breaks are needed, and how many sections does the document consist of?

    Answer

    One section break before page 4, after page 5, before page 9, and after page 9: 4 section breaks. k section breaks make k + 1 sections: p.1–3, p.4–5, p.6–8, p.9, and p.10, that is, 5 sections. The sections made landscape are sections 2 and 4.

  6. In a thesis the first four pages are the Cover, Approval, Abstract, and Contents; these are Section 1 and use lowercase Roman numerals, with Different First Page on. Section 2 starts at 1 on the Introduction page. Which number appears on the Abstract page and on the 7th physical page of the document?

    Answer

    In Section 1 the cover is counted but its number is not shown: Cover (i, not shown), Approval ii, Abstract iii, Contents iv. “iii” appears on the Abstract. Section 2 starts at 1 on the 5th physical page; the 7th physical page is number 3.

  7. With Track Changes on, in the sentence “The lab report is due on Friday.”, “Friday” is deleted and “Monday” typed, and “by noon ” is inserted before “on”. The author accepts the deletion and the insertion of “Monday” and rejects the insertion of “by noon ”. What is the final sentence? If the author had sent the document in Simple Markup without accepting anything, what could the recipient have seen?

    Answer

    Final sentence: “The lab report is due on Monday.” The rejected insertion is removed from the text. Had it been sent without accepting anything, three changes would have been pending; the recipient could have switched to All Markup and seen the deleted “Friday” and the inserted phrases. Hiding is not accepting.

  8. The Excel file used in a mail merge has 31 filled rows; the first row is the field names. The Grade cell of two students is empty. How many letters does Finish & Merge produce, and what happens to the empty cells?

    Answer

    The header row produces no letter: 31 − 1 = 30 records, 30 letters. Records with empty cells also produce letters; the place of the «Grade» field is left blank. That is why the records are previewed before the results are produced and the missing data is filled in.

  9. On the Print screen of a 10-page document “2-4, 7, 9-10” is typed in the Pages box, 2 in the Copies box, and Print on Both Sides is chosen. How many sheets of paper are used?

    Answer

    The pages to be printed are 2, 3, 4, 7, 9, and 10: 6 pages. Each sheet holds 2 pages when printed two-sided: one copy takes 6 ÷ 2 = 3 sheets. Two copies take 2 × 3 = 6 sheets.

  10. On an A4 page the left margin (with gutter) is 3.5 cm and the other margins are 2.5 cm. How many millimeters wide is the text area? With line spacing “Exactly 24 pt”, what is the maximum number of lines that fit on a page?

    Answer

    The width is 210 − 35 − 25 = 150 mm, the height 297 − 25 − 25 = 247 mm. 24 pt = 24 × 25.4 ÷ 72 ≈ 8.47 mm. 247 ÷ 8.47 ≈ 29.2; rounded down: 29 lines.
