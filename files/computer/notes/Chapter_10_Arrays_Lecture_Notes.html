Chapter 10: Arrays

Declaring 40 separate variables to store the grades of 40 students in a class is both tedious and error-prone, and when the number of grades changes the program has to be rewritten. An array solves this problem: it holds many values of the same type under a single name, in numbered cells. These notes begin with the structure of an array in memory. They then cover declaring arrays, reaching elements by index, and traversing an array with loops. Basic operations such as the sum, the average, the largest and smallest values, reversing, counting frequencies and the sieve of Eratosthenes are traced step by step. Copying, the Arrays class, passing arrays to methods, and how searching and sorting are written in Java follow. The last sections deal with two-dimensional arrays, matrix operations and common mistakes with arrays. All the programs shown in the notes were compiled and run with JDK 21, and the console output and error messages are taken verbatim from those runs.

10.1The concept of an array

In the programs so far, each value has lived in its own variable: int grade1, int grade2, int grade3. For three grades this works. For forty grades, forty variables are needed, and finding their average means writing a sum with forty terms. If the number of grades rises to forty-one, the program has to be changed. The source of the problem is that the variables are independent of one another. The program cannot say “the third grade” or “the next grade”, because variable names are text, not numbers.

10.1.1What is an array?

Definition 10.1

An array is a data structure that stores a fixed number of values of the same type in a single object, in consecutive cells. The values in the cells are called elements. Each element is reached by its index, the sequence number of its cell. In Java, indices start at 0. The number of cells is the length of the array; the length is fixed when the array is created and cannot change afterward.

Each of the three conditions in the definition has a reason. The same type condition makes every cell the same size: each cell of an int array holds 4 bytes. The fixed number condition allows the array to occupy memory as one contiguous block. Consecutive cells make it possible to find the location of any element with a single calculation.

In Java, an array is an object. Objects are created in the region of memory called the heap. The local variables of methods, in contrast, are kept in a separate region called the stack. An array variable lives on the stack, but it does not contain the elements. The variable stores the reference to the array object on the heap, that is, a value that shows where the object is in memory. In the figures a reference is drawn as an arrow.

Figure 10.1 shows this separation. The box on the left is the variable itself; it contains only an arrow, that is, a reference. The five cells on the right are the array object. At first this separation looks like an unnecessary detail. Yet most of the surprising behavior of arrays comes from it. Two variables can point to the same array; when an array is passed to a method, the method can change the original array; and the == operator compares the references of two arrays, not their contents. Each of these behaviors is worked through with an example in later sections.

10.1.2Index and address calculation

The elements of an array are reached by writing the index in square brackets. a[0] is the first element and a[1] the second. In an array of five elements, the last element is a[4]. The general rule is this: for an array of length n, the first index is 0 and the last is n − 1. In Java the length of an array is read with a.length, so the last element can always be written as a[a.length - 1].

Starting the index at 0 feels strange to beginners. In everyday life, counting starts at 1. In Java, in C and in many other languages, however, the index is really an offset: it says how many cells to move forward from the start of the array. The first element is at the start, so its offset is zero. a[2] is two cells away from the start.

This interpretation also explains why access is fast. Because an array consists of consecutive cells in memory, the address of cell number i is computed with a single formula:

address(a[i]) = start address + i × cell size

Example 10.1

Suppose the start address of an int array on the heap is 1000. Since an int takes 4 bytes, the cell size is 4. What is the address of a[3]?

In the formula i = 3 and the cell size is 4: 1000 + 3 × 4 = 1000 + 12 = 1012. The processor goes directly to this address and reads the value. The cells a[0], a[1] and a[2] are never looked at. The same calculation for a[999] is also a single multiplication and a single addition: 1000 + 999 × 4 = 4996.

The size of the calculation does not depend on the length of the array. An array of five elements and one of a million elements both need one multiplication and one addition. This is why the cost of access by index is constant time, written O(1) in big-O notation. Big-O notation summarizes how the running time of an operation grows as the input grows. O(1) means “the same time however large the input”, while O(n) means “the time grows in proportion to the number of elements”. In a real Java program the start address is not shown to the programmer, and the JVM additionally checks on every access that the index is valid. But the principle of the calculation is the same.

10.1.3Strengths and weaknesses of arrays

The structure of an array gives it some advantages and also sets some limits. Both come from the same source: fixed-size, consecutive cells.

Table 10.1: Advantages and limits of arrays.
AdvantageLimit
Fast access by indexThe size is fixed
Element type is consistentInserting in the middle is costly
Easy to process with loopsGoing out of bounds is a runtime error
Orderly layout in memoryHolds only one element type

In the table, “element type is consistent” and “holds only one element type” are two sides of the same property. The compiler prevents text from being put into an int array by mistake, which is a guarantee. On the other hand, it is impossible to keep a student's name, number and grade in the same array; that takes three separate arrays or another structure.

The right half of Figure 10.3 shows why inserting in the middle is expensive. Suppose 15 is to be placed between 10 and 20 in the array {10, 20, 30, 40}. Because the cells are consecutive, there is no operation “slip a cell in between”. 40 moves one place to the right, then 30, then 20, and 15 is written into the cell that has been freed, number 1. The number of elements shifted equals the number of elements after the insertion point. In the worst case, inserting at the front, all the elements move. This is why inserting and deleting in the middle cost O(n). Moreover, if there is no free cell at the end of the array, the insertion cannot be done at all: the length is fixed. A new, larger array is created and the old elements are copied into it.

10.2Declaring and creating arrays

Using an array takes two separate jobs. First the array variable is declared, which opens a reference box on the stack. Then the array object is created and its reference is written into that box. The two jobs can be done on one line or on separate lines.

10.2.1Declaration and new

In Java, an array type is written by adding a pair of square brackets after the element type: int[] means “array of int”, String[] “array of String” and double[] “array of double”. The array object is created with the new operator, and the length is given in square brackets. The following program shows four separate declarations together:

public class Declaration {
    public static void main(String[] args) {
        int[] nums = new int[5];
        String[] names = {"Ada", "Can", "Ece"};
        double[] readings;
        readings = new double[10];
        System.out.println(nums.length + " " + names.length + " " + readings.length);
    }
}
5 3 10

Let us examine the lines in order.

  1. int[] nums = new int[5]; does the declaration and the creation on one line. new int[5] creates an int array of five cells on the heap. The assignment writes the reference of this array into the variable nums.
  2. String[] names = {"Ada", "Can", "Ece"}; creates the array together with its values. No length is written; the compiler counts the values and makes the length 3.
  3. double[] readings; only declares the variable. At this point there is no array on the heap.
  4. readings = new double[10]; creates the ten-cell array later and writes its reference into the variable.

The length does not have to be a constant; it can also be an int computed while the program runs. new int[n] creates as many cells as the current value of n. The length can be 0; such an array is called an empty array and has no cells. A negative length causes a NegativeArraySizeException when the program runs. Once an array has been created, its length cannot be changed. If new double[20] is later assigned to readings, the old array does not grow; the variable starts pointing to a new, separate array.

Common mistake

Declaring the variable and using it without creating the array. If nums[0] = 7; is written after the line int[] nums;, there are no cells. Java catches this at compile time:

Unassigned.java:4: error: variable nums might not have been initialized
        nums[0] = 7;
        ^
1 error

The message says “the variable nums might not have been assigned a value”. The fix is an assignment such as nums = new int[4]; before use.

10.2.2Default values

The cells of an array created with new are not left empty. Java writes the default value of the element type into every cell. For numeric types this value is zero, and for boolean it is false. For object types, such as String, the default value is null. null is the special value meaning “this reference does not point to any object”.

The program below prints the values in Figure 10.4 to the console. The default value of a char array has been added:

public class Defaults {
    public static void main(String[] args) {
        int[] a = new int[3];
        double[] d = new double[2];
        boolean[] b = new boolean[2];
        String[] s = new String[2];
        char[] c = new char[2];
        System.out.println(a[1] + " " + d[0] + " " + b[1] + " " + s[0]);
        System.out.println((int) c[0]);
        System.out.println(a.length + d.length + s.length);
    }
}

The first line prints one cell from each of four different arrays: 0, 0.0, false and null. The default value of a char array is the character whose code is 0. Because this character is invisible on the screen, it is printed as a number with an (int) cast. The last line contains a trap. The expression a.length + d.length + s.length contains no string, so + performs addition and the result is 3 + 2 + 2 = 7.

The default-value rule applies only to array cells and class fields. Java does not give a value on its own to local variables declared inside a method. int x; System.out.println(x); does not compile. By contrast, a cell of an array created with new int[1] always starts at 0.

10.2.3The initializer

If the values of the elements are known in advance, the array is created by writing the values inside curly braces. This notation is called an array initializer: int[] scores = {70, 85, 90};. No length is written, because the compiler counts the values. Here the length is 3.

The short form of the initializer can be used only on the declaration line. It cannot be used to assign later to a variable that was declared earlier:

10.3Accessing elements

10.3.1Reading and writing

An array element is used like an ordinary variable. If scores[1] appears inside an expression, the value in the cell is read. If it appears on the left of an assignment, the cell itself is meant and a new value is written into it. The index inside the square brackets does not have to be a constant; any expression that gives an int can be an index: a[i], a[i + 1], a[a.length - 1].

public class Reading {
    public static void main(String[] args) {
        int[] scores = {70, 85, 90};
        int first = scores[0];
        scores[1] = 88;
        int last = scores[scores.length - 1];
        System.out.println(first + " " + last);
    }
}

10.3.2The out-of-bounds error

Valid indices are the integers from 0 to length − 1. A negative index, or length itself, is invalid. Access with an invalid index stops the program in Java with an ArrayIndexOutOfBoundsException. This is an exception: an error condition that arises while the program is running and interrupts the normal flow.

Definition 10.2

In an array of length n, access with an index i that does not satisfy 0 ≤ i ≤ n − 1 is an out-of-bounds access. Java checks this condition on every array access; if it is not satisfied, an ArrayIndexOutOfBoundsException is thrown.

The compiler usually cannot catch this error, because the index is often computed while the program runs. The following program compiles without any problem:

public class Negative {
    public static void main(String[] args) {
        int[] a = {4, 8, 6};
        System.out.println(a[-1]);
    }
}
Exception in thread "main" java.lang.ArrayIndexOutOfBoundsException: Index -1 out of bounds for length 3
	at Negative.main(Negative.java:4)

The message gives three pieces of information. The type of the error is ArrayIndexOutOfBoundsException. The detail part says “Index -1 out of bounds for length 3”: index −1 is outside the bounds of an array of length 3. The last line shows where the error occurred: line 4 of the file Negative.java. This check does not exist in languages like C, where an out-of-bounds write can silently corrupt a part of memory that belongs to another variable. Java's check has a cost, but it catches the error at exactly the right place.

10.4Traversing with loops

The real power of an array appears when it is combined with a loop. Because the index can be a variable, a single loop can visit all the elements of the array in turn. Visiting every element of an array once is called traversal. Java has two ways to traverse: the classic for and the enhanced for.

10.4.1The classic for

In the classic for loop, a counter, usually i, starts at 0 and increases by 1 on each iteration. Because the condition is i < array.length, the counter runs over exactly the valid indices:

public class Classic {
    public static void main(String[] args) {
        int[] scores = {70, 88, 90};
        for (int i = 0; i < scores.length; i++) {
          System.out.printf("%d: %d%n", i, scores[i]);
        }
    }
}
0: 70
1: 88
2: 90

printf does formatted printing: the first %d in the pattern is replaced by i, the second %d by scores[i], and %n ends the line. The trace of the loop is given in Table 10.5.

The last row is important: when i is 3, the condition is false and scores[3] is never accessed. The condition is tested at the start of every iteration, before the body. So it is no problem for i to reach an invalid value; the problem is entering the body with an invalid value.

The structure of the classic for is flexible. By changing the start, the condition and the step, the array can be traversed in different ways. for (int i = a.length - 1; i >= 0; i--) traverses the array from the end to the start. A step of i += 2 advances by skipping one element. This flexibility comes from controlling the index directly.

10.4.2The enhanced for

In many traversals the index itself is not needed; only the values of the elements are. Java has a shorter loop for these cases.

Definition 10.3

The enhanced for (also called for-each) is a loop written in the form for (T x : array). The loop goes through the elements of the array in order from start to end; on each iteration it puts a copy of the next element into the variable x. The loop has no index.

The notation reads “for each x in the array”. To the left of the colon is a variable with the element type, and to the right is the array. The word “copy” in the definition explains the behavior of the following program:

public class Enhanced {
    public static void main(String[] args) {
        int[] scores = {70, 88, 90};
        for (int score : scores) {
            score = score + 5;
            System.out.println(score);
        }
        System.out.println(scores[0]);
    }
}

Common mistake

Trying to update the array with the enhanced for. for (int x : a) x = x * 2; compiles and runs, but the array stays the same. The compiler does not even warn, because assigning to the loop variable is allowed by the language rules. The mistake is noticed only when the output is examined.

10.4.3Which loop when?

The two loops cannot always be used in place of each other. The choice is decided by whether the job needs the index.

Table 10.7: The classic and the enhanced for compared.

The enhanced for is as safe as it is short: because there is no index, an out-of-bounds error cannot occur. For this reason it is preferred for traversals that only read. When an index is needed, switch to the classic for.

10.5Basic array operations

The operations in this section are the building blocks of most programs written with arrays. In each of them the same question is asked: how many times must the array be traversed, and what information must be kept while traversing? All the examples except the Sieve of Eratosthenes run in O(n) time, because each element is looked at a constant number of times.

10.5.1Sum and average

To find a sum, an accumulator variable is used. The accumulator starts at 0, the identity of addition, and each element is added to it:

        int[] nums = {4, 7, 2, 6};
        int sum = 0;
        for (int value : nums) sum += value;
        double avg = 0;
        if (nums.length > 0)
            avg = (double) sum / nums.length;
        System.out.println(sum + " " + avg);
        System.out.println(sum / nums.length);
    }
}

10.5.3Reversing an array

The easy way to reverse an array is to create a new array and copy the elements into it from the end to the start. This way needs n cells of extra memory. A more economical way is to reverse the array in place: the elements at the two ends swap places, and then the ends move one step inward. Because two indices are used, the method is called the two-pointer technique.

import java.util.Arrays;

public class Reverse {
    public static void main(String[] args) {
        int[] arr = {1, 2, 3, 4, 5};
        int left = 0, right = arr.length - 1;
        while (left < right) {
            int tmp = arr[left];
            arr[left] = arr[right];
            arr[right] = tmp;
            left++;
            right--;
        }
        System.out.println(Arrays.toString(arr));
    }
}
[5, 4, 3, 2, 1]

The swap is done with three assignments. If arr[left] = arr[right] were written directly, the value on the left would be lost; so it is first saved in the variable tmp. Then the value on the right is written to the left, and the saved value to the right.

Common mistake

Doing the swap along the whole array. If a[i] and a[a.length - 1 - i] are swapped with for (int i = 0; i < a.length; i++), the swaps done in the first half of the array are undone in the second half. 10.5.5The second largest element

To find the second largest element of an array there is no need to sort it. Two candidates are kept in a single pass: largest and second. Repeated values make the question subtler: in the array {7, 12, 5, 12, 9} the largest is 12 and it occurs twice; the second largest element is 9.

public class SecondLargest {

        int[] a = {7, 12, 5, 12, 9};

            second = largest;

10.5.6Counting frequencies: a dice histogram

10.5.7The sieve of Eratosthenes

An old and fast way to find all the prime numbers up to a given number is the sieve of Eratosthenes. The method does not search for primes; it eliminates the non-primes. It starts at 2. Every number that has not been eliminated is prime, and its multiples are eliminated. A boolean array is used to keep track of the eliminated numbers: if composite[k] is true, k has been eliminated.

public class Sieve {
    public static void main(String[] args) {
        int n = 20;
        boolean[] composite = new boolean[n + 1];
        for (int i = 2; i * i <= n; i++)
          if (!composite[i])
            for (int k = i * i; k <= n; k += i)
              composite[k] = true;
        for (int i = 2; i <= n; i++)
          if (!composite[i]) System.out.print(i + " ");
        System.out.println();
    }
}

10.6Copying, the Arrays class and methods

The fact that an array variable holds a reference matters most when copying. For a primitive type, int y = x; copies the value and the two variables become independent. For arrays, the same notation gives a completely different result.

10.6.1Reference copy and element copy

The statement int[] b = a; does not create a new array. The reference in a is copied into b; now two variables point to the same object. This situation is called a reference copy. A change made through one is seen through the other, because there is only one array.

For an independent copy, the elements of the array must be transferred to a new array. Java offers three ready-made ways to do this:

  • a.clone(): creates a new array of the same length and copies all the elements.
  • Arrays.copyOf(a, a.length): does the same job; the second argument can also choose the length of the new array.
  • System.arraycopy(src, srcPos, dest, destPos, length): copies a given number of elements, starting from a given position, into an existing destination array.

The third way is the most flexible, but it requires the destination array to be created beforehand:

import java.util.Arrays;

public class ArrayCopy {
    public static void main(String[] args) {
        int[] a = {1, 2, 3, 4, 5};
        int[] d = new int[7];
        System.arraycopy(a, 1, d, 2, 3);
        System.out.println(Arrays.toString(d));
    }
}
[0, 0, 2, 3, 4, 0, 0]

The call System.arraycopy(a, 1, d, 2, 3) means “write 3 elements, starting at cell 1 of a, starting at cell 2 of d”. The elements copied are 2, 3 and 4; they are written into cells 2, 3 and 4 of d. The remaining cells stay at the default value 0.

Definition 10.4

A shallow copy is a copy in which only the values in the cells of an array are copied. If the cells hold primitive values, a shallow copy is completely independent. If the cells hold references, only the references are copied; the objects they point to are shared between the two arrays.

clone, Arrays.copyOf and System.arraycopy make shallow copies. In int arrays this causes no problem, because the cells hold the numbers themselves. In arrays of objects and in two-dimensional arrays, however, the objects are shared, not copied. This trap is treated separately together with two-dimensional arrays.

10.6.4Arrays and methods

A method can take an array and return an array. In Java every argument passed to a method is passed by copying. For an array argument, what is copied is the reference, not the array itself. So the parameter in the method points to the same object as the array on the caller's side. Two rules follow:

  1. If the method writes into cells through the parameter, the change is seen in the caller's array too.
  2. If the method assigns a new array to the parameter, only the reference in its own local copy changes; the caller's variable is not affected.
import java.util.Arrays;

public class Methods {
    static void doubleAll(int[] arr) {
        for (int i = 0; i < arr.length; i++)
            arr[i] = arr[i] * 2;
    }

    static void assignNew(int[] arr) {
        arr = new int[]{0, 0, 0};
    }

    static int[] squares(int n) {
        int[] result = new int[n];
        for (int i = 0; i < n; i++)
            result[i] = (i + 1) * (i + 1);
        return result;
    }

    public static void main(String[] args) {
        int[] a = {1, 2, 3};
        doubleAll(a);
        System.out.println(Arrays.toString(a));
        assignNew(a);
        System.out.println(Arrays.toString(a));
        System.out.println(Arrays.toString(squares(4)));
    }
}

In the call doubleAll(a), the parameter arr points to the object of a and writes into its cells; a becomes [2, 4, 6]. assignNew(a), on the other hand, binds a new object to arr. This assignment affects only the method's own variable; a keeps pointing to the old object and stays [2, 4, 6]. The method squares(4) creates a new array and returns its reference. When the method ends, the local variable result disappears, but the array on the heap lives on, because its reference has been given to the caller.

This behavior has a side effect. A method that sorts, reverses or fills an array changes the caller's data permanently. If the original order must be kept, the method should first take a copy. 10.7.1Linear search

Linear search traverses the array from start to end and compares each element with the target. At the first match it returns the index; if the target is absent it returns −1. Since −1 cannot be a valid index, it is used to mean “not found”.

public class Linear {

        return -1;

        int[] d = {8, 3, 6, 2};
        System.out.println(search(d, 6));

10.7.3The median

Definition 10.5

The median is the value exactly in the middle of a sorted array. If the number of elements n is odd, the median is s[n / 2]. If n is even, it is the average of the two middle elements, s[n/2 − 1] and s[n/2].

An advantage of the median over the average is that it is not affected by extreme values. The average of the array {1, 2, 3, 4, 100} is 110 / 5 = 22.0; this value is close to none of the elements. The median is 3. In data such as income, house prices or response times there are a few extreme values, so the median gives a more meaningful “typical value”.

import java.util.Arrays;

public class Median {
    public static void main(String[] args) {
        int[] a = {7, 3, 9, 1, 5};
        int[] s = Arrays.copyOf(a, a.length);
        Arrays.sort(s);    // a is untouched
        int n = s.length;
        double m = (n % 2 == 1) ? s[n / 2]
            : (s[n/2 - 1] + (double) s[n/2]) / 2;
        System.out.println(m);   // 5.0
        System.out.println(Arrays.toString(a) + " " + Arrays.toString(s));
    }
}

The second line of the program's output confirms this: a is still [7, 3, 9, 1, 5]. Second, the conditional operator (? :) combines the odd and even cases in a single expression. Third, in the even case s[n/2] is cast with (double) before the addition. This way both the addition and the division are done in double: the sum of two large ints cannot overflow the int limit, and the quotient comes out fractional. Without the cast, the quotient of two ints would be taken, and (3 + 6) / 2 would give 4 instead of 4.5. The program below verifies this difference and the extreme-value example on JDK 21:

import java.util.Arrays;

public class Median2 {
    static double median(int[] a) {
        int[] s = Arrays.copyOf(a, a.length);
        Arrays.sort(s);
        int n = s.length;
        return (n % 2 == 1) ? s[n / 2] : (s[n/2 - 1] + (double) s[n/2]) / 2;
    }

    public static void main(String[] args) {
        int[] u = {1, 2, 3, 4, 100};
        int t = 0;
        for (int x : u) t += x;
        System.out.println((double) t / u.length + " " + median(u));
        System.out.println(median(new int[]{8, 2, 6, 3}));
        System.out.println((3 + 6) / 2);
    }

Common mistake

A method that finds the median but sorts the array without copying it. Because the reference to the array is passed to the method, Arrays.sort(arr) sorts the caller's array too. After getting the median, the caller finds that the order of its own array has changed. The fix is to sort a copy taken inside the method with arr.clone() or Arrays.copyOf.

10.7.4Bubble sort

Bubble sort compares neighboring elements and swaps those that are out of order. On each pass the largest of the remaining elements settles at the end, like a bubble rising to the surface of water. The Java version is two nested for loops:

import java.util.Arrays;

public class Bubble {
    public static void main(String[] args) {
        int[] a = {5, 1, 4, 2};
        int n = a.length;
        for (int pass = 0; pass < n - 1; pass++) {
          for (int j = 0; j < n - 1 - pass; j++) {
            if (a[j] > a[j + 1]) {
              int tmp = a[j];
              a[j] = a[j + 1];
              a[j + 1] = tmp;
            }
          }
        }
        System.out.println(Arrays.toString(a));
    }
}
[1, 2, 4, 5]

The outer loop counts the passes: n − 1 passes are enough for n elements, because once n − 1 elements are in place the last one is automatically in place. The bound of the inner loop is j < n - 1 - pass. This bound has two array-specific details. The first is the “- 1”: since the body accesses a[j + 1], j can be at most n − 2. If the bound were j < n, a[n] would be read on the last iteration and an out-of-bounds error would result. The second is the “- pass”: since each pass puts one element at the end in its place, there is no need to look at that region again.

The total number of comparisons is 3 + 2 + 1 = 6. In general, for n elements (n − 1) + (n − 2) + … + 1 = n(n − 1)/2 comparisons are made; this is O(n²). In the third pass there is no swap at all, because the array was already sorted after the second pass. This observation leads to an improvement: if no swap is made in a pass, the loop can stop early. This improvement is one of the exercises in the slides. The sort is done in place; the extra memory is only the variable tmp: O(1).

10.7.5Insertion sort

Insertion sort grows a sorted part on the left of the array. On each iteration the element immediately to the right of the sorted part is taken as the key. The elements in the sorted part that are larger than the key are shifted one cell to the right, and the key is written into the gap that opens up. It resembles arranging playing cards in your hand.

import java.util.Arrays;

public class Insertion {
    public static void main(String[] args) {
        int[] a = {4, 3, 5, 1};
        for (int i = 1; i < a.length; i++) {
          int key = a[i];
          int j = i - 1;
          while (j >= 0 && a[j] > key) {
            a[j + 1] = a[j];
            j--;
          }
          a[j + 1] = key;
        }
        System.out.println(Arrays.toString(a));
    }
}

The code has three points specific to arrays. First, the key is saved in a separate variable with int key = a[i];. This is necessary because the shifting will overwrite a[i]. The intermediate steps of the third iteration show this clearly. During the shifts the array goes through the states [3, 4, 5, 5], [3, 4, 4, 5] and [3, 3, 4, 5]. During this time the value 1 lives only in key. Second, the check j >= 0 in the while condition comes first. The && operator is evaluated from left to right and does not look at the right side if the left side is false. When j is −1, a[j] is not read and an out-of-bounds error is avoided. If the order of the conditions were reversed (a[j] > key && j >= 0), the program would stop at a[-1] whenever the key is the smallest in the array. Third, when the loop ends, the key is written to a[j + 1], because j stops one place to the left of the last element shifted.

In the worst case, when the array is in reverse order, every key shifts the whole sorted part and the cost is O(n²). If the array is already almost sorted, there is very little shifting and the cost approaches O(n). This is why insertion sort is a good choice for small or nearly sorted arrays.

10.7.6Binary search

Binary search works only on a sorted array. It looks at the element in the middle of the search range. If the target is larger than the middle element, the left half is eliminated; if smaller, the right half is. Because the range is halved at every step, an array of n elements needs at most about log₂ n + 1 iterations. In the Java version the range is kept with two indices: lo (lower bound) and hi (upper bound).

public class Binary {
    public static void main(String[] args) {
        int[] a = {2, 5, 8, 12, 16, 23, 38, 56};
        int target = 23, lo = 0, hi = a.length - 1;
        int result = -1;
        while (lo <= hi) {
          int mid = lo + (hi - lo) / 2;
          if (a[mid] == target) { result = mid; break; }
          if (a[mid] < target) lo = mid + 1;
          else hi = mid - 1;
        }
        System.out.println(result);
    }
}

23 is found in two iterations. Linear search would make six comparisons for the same target. In a small array the difference looks slight. In a sorted array of a million elements, however, binary search needs at most 20 iterations, while linear search on the same array may make up to a million comparisons.

The array-specific points are these. Initially hi = a.length - 1; a.length is not a valid index. The loop condition is lo <= hi: when lo and hi are equal, there is still one element in the range and it must be examined. mid = lo + (hi - lo) / 2 is integer division and rounds down: 0 + (7 − 0) / 2 = 3. This form gives the same result as (lo + hi) / 2, but for very large indices it prevents the sum lo + hi from overflowing (Chapter 4.1). Finally, the ±1 in the updates lo = mid + 1 and hi = mid - 1 is essential. mid has already been examined. If the update is written as lo = mid, the range may fail to shrink in some cases and the loop runs forever.

10.7.7Unsuccessful binary search

If the target is not in the array, the range eventually becomes empty: lo passes hi. At that moment lo shows the position where the target would go in the sorted array, that is, the insertion point. The method below returns this information by the same rule as Arrays.binarySearch:

10.8Two-dimensional arrays

The grades of the students in a class on three exams, the pixel colors of a picture, or the squares of a game board are arranged in rows and columns. For this kind of data, a structure with two indices is more natural: one selects the row and the other the column.

10.8.1Declaring a matrix and accessing it

Definition 10.6

A two-dimensional array is an array whose elements are accessed with two indices. This structure of rows and columns is also called a matrix. In Java, a two-dimensional array is an array of arrays: each cell of the outer array holds the reference to a row array.

The type is written int[][]. In an initializer, each row is given in its own curly braces. An empty matrix is created with new int[2][3]: 2 rows, 3 columns in each row, all cells 0.

public class Matrix {
    public static void main(String[] args) {
        int[][] matrix = {
            {1, 2, 3},
            {4, 5, 6}
        };
        int value = matrix[1][2]; // 6
        System.out.println(value + " " + matrix.length + " " + matrix[0].length);
        int[][] empty = new int[2][3];
        System.out.println(empty[1][2]);
    }
}
6 2 3
0

In an access, the first index selects the row and the second the column. matrix[1][2] is column 2 of row 1, that is, 6. The reading goes from left to right: first matrix[1] finds the row array, then the cell numbered 2 of that array is reached.

Figure 10.18 shows what the “array of arrays” idea looks like in memory. Two important consequences follow from this structure:

  • matrix.length is the length of the outer array, that is, the number of rows (2). matrix[0].length is the length of row 0, that is, the number of columns in that row (3).
  • matrix[1] on its own is a valid expression and is an int[], a whole row. Arrays.toString(matrix[1]) prints that row as [4, 5, 6].

10.8.2Jagged arrays

10.8.5Matrix transpose

The transpose of a matrix is the matrix in which rows become columns and columns become rows. The transpose of an r × c matrix is c × r, and it is filled by the rule t[j][i] = matrix[i][j].

10.8.6Matrix multiplication

The product of two matrices C = A × B is defined as follows: the cell of C in row i and column j is the sum of the products of the corresponding elements of row i of A and column j of B. The number of columns of A must equal the number of rows of B.

C[i][j] = A[i][0] · B[0][j] + A[i][1] · B[1][j] + … + A[i][m−1] · B[m−1][j]

import java.util.Arrays;

public class MatMul {
    public static void main(String[] args) {
        int[][] A = {{1, 2}, {3, 4}};
        int[][] B = {{5, 6}, {7, 8}};
        int[][] C = new int[2][2];
        for (int i = 0; i < 2; i++)
          for (int j = 0; j < 2; j++)
            for (int k = 0; k < 2; k++)
              C[i][j] += A[i][k] * B[k][j];
        System.out.println(Arrays.deepToString(C));
    }
}

Example 10.3

  • C[0][0] = A[0][0] · B[0][0] + A[0][1] · B[1][0] = 1 · 5 + 2 · 7 = 5 + 14 = 19
  • C[0][1] = A[0][0] · B[0][1] + A[0][1] · B[1][1] = 1 · 6 + 2 · 8 = 6 + 16 = 22
  • C[1][0] = A[1][0] · B[0][0] + A[1][1] · B[1][0] = 3 · 5 + 4 · 7 = 15 + 28 = 43
  • C[1][1] = A[1][0] · B[0][1] + A[1][1] · B[1][1] = 3 · 6 + 4 · 8 = 18 + 32 = 50

The code has three nested loops. i and j select the cell to be computed; k runs over the terms of the sum. The statement C[i][j] += A[i][k] * B[k][j] adds each term to the cell. Because C was created with new int[2][2], its cells start at 0; there is no need to zero them separately. For square n × n matrices, n multiplications are made for each cell and n³ multiplications for the n² cells in total: O(n³). For 100 × 100 matrices this is a million multiplications.

10.9Array or list?

The length of an array is fixed. If the number of elements grows and shrinks while the program runs, this limit is annoying: with every insertion a new, larger array has to be created and the old elements copied into it. The ArrayList class in Java's collections library does this job by itself.

import java.util.ArrayList;

public class ListDemo {
    public static void main(String[] args) {
        ArrayList<Integer> list = new ArrayList<>();
        list.add(3);
        list.add(8);
        list.add(5);
        list.add(7);
        System.out.println(list + " " + list.size() + " " + list.get(1));
    }
}
[3, 8, 5, 7] 4 8

Internally, ArrayList still uses an array. When the array fills up, it creates a larger one and moves the elements there (Figure 10.24). The programmer only calls methods such as add, get and size. For access, list.get(1) is written instead of square brackets, and list.size() instead of length for the length.

This convenience has a price. An int[] stores the numbers directly in its cells. An ArrayList<Integer>, however, can hold only objects; each number is put inside an Integer object, and the list holds the references to these objects. This means more memory and somewhat slower access. A rough rule for choosing can be given:

  • If the number of elements is known in advance and fixed, for example the days of the week, the cells of a matrix or a table of counters, an array is sufficient and fast.
  • If the number of elements will change while the program runs, for example records entered by the user, a collection such as ArrayList is more convenient.

The final decision is made according to how it will be used, the readability of the code and, if necessary, measured performance. The traversal, search and sorting methods learned in these notes apply to lists in the same way.

10.10Common mistakes

Most mistakes with arrays fall into four groups. This section gives each with an example that was actually run.

Common mistake

One iteration too many. The condition i <= a.length accesses a[length] on the last iteration, and an ArrayIndexOutOfBoundsException is thrown. The correct form is i < a.length. The same mistake has a silent sibling: writing i < a.length - 1 skips the last element and gives no message.

Common mistake

The first element of an empty array. int min = a[0]; stops with the message “Index 0 out of bounds for length 0” on an empty array. Before computing the minimum, the maximum or the median, the case a.length == 0 is handled separately.

Common mistake

A reference copy. int[] b = a; is not a new array; b[0] = 9 changes a too. For an independent copy, use a.clone() or Arrays.copyOf. For two-dimensional arrays these are not enough either; each row is copied separately.

Common mistake

A fixed number of columns in a jagged matrix. Using matrix[0].length for every row in the inner loop assumes that all the rows are as long as the first. In the following program the second row has only one element:

public class JaggedError {
    public static void main(String[] args) {
        int[][] m = {{1, 2, 3}, {4}};
        int sum = 0;
        for (int i = 0; i < m.length; i++)
            for (int j = 0; j < m[0].length; j++)
                sum += m[i][j];
        System.out.println(sum);
    }
}
Exception in thread "main" java.lang.ArrayIndexOutOfBoundsException: Index 1 out of bounds for length 1
	at JaggedError.main(JaggedError.java:7)

When i = 1, j becomes 1 and cell number 1 is looked up in a row of length 1. When the inner loop bound is changed to m[i].length, the program prints 10.

What these four mistakes have in common is that the compiler catches none of them. All of them show up either as an exception at run time or as a wrong result with no message at all. So when writing array code, three boundary cases are always tried: an empty array, an array with a single element, and an array in which the target is in the first or last position.

10.11Summary

  • An array is an object that holds a fixed number of elements of the same type in consecutive cells. Indices run from 0 to length − 1; length is a field and does not change after creation.
  • An array variable lives on the stack and holds the reference to the array object on the heap. Cells created with new receive the default value: 0 for numbers, false for boolean and null for objects. The initializer {…} takes the length from the number of values.
  • Reading and writing a[i] are done in O(1) time, because the address is computed with the formula start + i × cell size. An invalid index stops the program with an ArrayIndexOutOfBoundsException; the most common cause is a loop condition written with <=.
  • The classic for is used when an index is needed, and the enhanced for when you only read. The loop variable in the enhanced for is a copy of the element; assigning to it does not change the array.
  • The sum and average are found with an accumulator, and the minimum and maximum with candidates initialized to the first element of the array. Reversing is done in place with two pointers. In frequency counting the value is used as the index. The sieve of Eratosthenes eliminates the non-primes with a boolean array.
  • b = a copies only the reference. clone, Arrays.copyOf and System.arraycopy copy the elements, but make shallow copies. == and equals compare references, while Arrays.equals compares contents. An array passed to a method is the same object as the caller's array.
  • Linear search takes O(n) time, and binary search on a sorted array O(log n). Arrays.sort sorts the array in place; Arrays.binarySearch returns -(insertion point) - 1 if it does not find the target. Bubble sort and insertion sort are O(n²).
  • int[][] is an array of arrays. matrix.length is the number of rows, and matrix[i].length is the number of columns of that row. Rows can have different lengths (a jagged array). clone copies only the outer array. Traversal is done with two nested loops, and matrix multiplication with three.

10.13Test Yourself

  1. What is the output of the following program?

    import java.util.Arrays;

public class TY1 {
    public static void main(String[] args) {
        int[] a = new int[4];
        a[a.length - 1] = a.length;
        a[a[3] - 3] = 9;
        System.out.println(Arrays.toString(a));
    }
}
    Answer 
    [0, 9, 0, 4]

    The array starts with four zeros. a[a.length - 1] = a.length writes 4 into the last cell, a[3]. In the next line the inner expression is computed first: a[3] - 3 = 4 − 3 = 1. So 9 is written into a[1].

  2. In the following program, what is a after the method zeroOut has been called?

    import java.util.Arrays;

public class TY2 {
    static void zeroOut(int[] d) {
        d[0] = 0;
        d = new int[]{5, 5, 5};
        d[1] = 0;
    }

    public static void main(String[] args) {
        int[] a = {1, 2, 3};
        zeroOut(a);
        System.out.println(Arrays.toString(a));
    }
}
    Answer 
    [0, 2, 3]

    The reference of a goes to the method. d[0] = 0 writes into the shared array, and a[0] becomes 0. d = new int[]{5, 5, 5}, however, only binds the method's local variable to a new array. The following d[1] = 0 changes this new array; a is not affected.

  3. What is the output of the following program? Why is each of the three values what it is?

    import java.util.Arrays;

public class TY3 {
    public static void main(String[] args) {
        int[] p = {4, 5};
        int[] q = p.clone();
        int[] r = p;
        System.out.println((p == q) + " " + (p == r) + " " + Arrays.equals(p, q));
    }
}
    Answer 
    false true true

    p == q is false, because clone creates a new object. p == r is true, because r = p copies the same reference. Arrays.equals(p, q) is true, because the two arrays have the same length and the same elements.

  4. Arrays.binarySearch looks for 1 first in an unsorted array and then in a sorted one. What is the output, and why is the first result wrong?

    import java.util.Arrays;

public class TY4 {
    public static void main(String[] args) {
        int[] a = {5, 1, 9, 3, 7};
        System.out.println(Arrays.binarySearch(a, 1));
        Arrays.sort(a);
        System.out.println(Arrays.binarySearch(a, 1));
    }
}
    Answer 
    -1
0

    In the first search the range is 0…4 and the middle element is a[2] = 9. Since 1 < 9, the right half is eliminated. Then a[0] = 5 is looked at; since 1 < 5, the search goes left again and the range becomes empty. The method returns −1, although 1 is in the array, at position 1. Because the method assumes the array is sorted, it has eliminated the wrong half. After sorting, the array is [1, 3, 5, 7, 9] and 1 is correctly found at position 0.

  5. The following program creates a triangular jagged array. What are t[3].length and the total number of cells?

    public class TY5 {
    public static void main(String[] args) {
        int[][] t = new int[4][];
        int cells = 0;
        for (int i = 0; i < t.length; i++) {
            t[i] = new int[i + 1];
            cells += t[i].length;
        }
        System.out.println(t[3].length + " " + cells);
    }
}
    Answer 
    4 10

    Row number i has i + 1 cells: 1, 2, 3 and 4. The length of the last row is 4, and the total number of cells is 1 + 2 + 3 + 4 = 10. A regular 4 × 4 matrix would need 16 cells.

  6. The reverse-sorted array {4, 3, 2, 1} is sorted with bubble sort. How many comparisons and how many swaps are made?

    import java.util.Arrays;

public class TY6 {
    public static void main(String[] args) {
        int[] a = {4, 3, 2, 1};
        int comps = 0, swaps = 0;
        for (int pass = 0; pass < a.length - 1; pass++)
            for (int j = 0; j < a.length - 1 - pass; j++) {
                comps++;
                if (a[j] > a[j + 1]) {
                    int tmp = a[j]; a[j] = a[j + 1]; a[j + 1] = tmp;
                    swaps++;
                }
            }
        System.out.println(Arrays.toString(a) + " " + comps + " " + swaps);
    }
}
    Answer 
    [1, 2, 3, 4] 6 6

    The number of comparisons does not depend on the contents of the array: 3 + 2 + 1 = 6. In a reverse-sorted array, every comparison finds an out-of-order pair and ends in a swap; the number of swaps is also 6. This is the worst case for n = 4: n(n − 1)/2 = 6.

  7. The following program looks for the most frequent digit in an array. What is the output? Why does the counts array have 10 cells?

    public class TY7 {
    public static void main(String[] args) {
        int[] a = {2, 7, 7, 3, 7};
        int[] counts = new int[10];
        for (int x : a) counts[x]++;
        int mostCommon = 0;
        for (int d = 1; d < counts.length; d++)
            if (counts[d] > counts[mostCommon]) mostCommon = d;
        System.out.println(mostCommon + " " + counts[mostCommon]);
    }
}
    Answer 
    7 3

    The values are used as indices: counts[x]++. Because digits are between 0 and 9, 10 cells are needed. At the end of counting, counts[2] = 1, counts[3] = 1 and counts[7] = 3. The second loop looks for the index of the largest counter; since 7 occurs three times, the result is 7 3.

  8. The following program fills a 3 × 3 matrix. What are m[2][1] and m[1][2]?

    public class TY8 {
    public static void main(String[] args) {
        int[][] m = new int[3][3];
        for (int i = 0; i < 3; i++)
            for (int j = 0; j < 3; j++)
                m[i][j] = i * 3 + j;
        System.out.println(m[2][1] + " " + m[1][2]);
    }
}
    Answer 
    7 5

    Each cell is given i * 3 + j; the cells end up numbered row by row from 0 to 8. m[2][1] = 2 · 3 + 1 = 7 and m[1][2] = 1 · 3 + 2 = 5. Because the first index is the row and the second the column, the two expressions refer to different cells.

  9. To print an array of length n from the end to the start, a programmer writes the loop for (int i = a.length; i >= 0; i--). What error occurs, and how is the loop corrected?

    Answer

    In the first iteration i = a.length, and an attempt is made to read a[a.length]. Run with a three-element array, the program stops without printing anything:

    Exception in thread "main" java.lang.ArrayIndexOutOfBoundsException: Index 3 out of bounds for length 3
	at TY9.main(TY9.java:5)

    Because the last valid index is a.length - 1, the correct start is int i = a.length - 1. The condition i >= 0 is right, because cell 0 must also be printed.
