2.2.1Windows and the desktop

An operating system is the basic software that manages the hardware and offers common services to applications. It shares memory among applications, organizes files on the disk, and delivers keyboard and mouse events to the right window. Users do not see most of this work; they deal only with the operating system’s interface. In Windows, the center of that interface is the desktop.

2.2.1.1Windows and its versions

Windows is the operating system that Microsoft develops for personal computers, and it is the most widely used operating system on desktop and laptop machines. Windows uses a window-based graphical interface: each application runs in its own rectangular area, a window, and the user manages the windows with the mouse or the keyboard.

Definition 2.2.1

A graphical user interface (GUI) is an interface in which the user interacts with the computer through icons, windows, menus, and buttons. Commands are given not by typing but by clicking items, dragging them, or pressing shortcut keys.

Windows has come in many versions over the years. These notes are written for Windows 11. Support for Windows 10 ended on 14 October 2025. A version that is no longer supported keeps running, but it no longer receives security updates, so a computer connected to the internet should run a supported version.

Windows 11 itself gets one major update a year. Menu names and the positions of some buttons can differ slightly between updates. The names used in these notes are those of the English Windows 11 interface, as in the slides. If a name differs a little on your computer, the option with the same function is usually in the same menu.

Common mistake

Thinking “the computer works, so an old version is not a problem.” Newly discovered security holes are not fixed in a version that is out of support. The computer looks the same every day, but over time it becomes more vulnerable to attacks.

2.2.1.2The desktop

Definition 2.2.2

The desktop is the main work area that appears after sign-in and gives access to applications, files, and system functions. It consists of the wallpaper, the desktop icons, and the taskbar at the bottom of the screen.

Figure 2.2.1 shows the four main parts of the desktop. The work area fills most of the screen; the wallpaper shows here and open windows sit on top of it. The desktop icons at the top left give quick access to frequently used items: “This PC,” “Recycle Bin,” and the files the user has placed on the desktop. The taskbar stretches along the bottom. At the bottom right is the notification area with the clock, network, volume, and battery icons.

The look of the desktop varies from computer to computer. The icons on the taskbar can be centered or left-aligned. The wallpaper, colors, and icon size are changed in the Personalization section of the Settings app. So instead of memorizing where things are, it is more useful to know what each item does.

The desktop is also a folder. A file saved to the desktop sits in the user’s Desktop folder on the disk. Using the desktop as a file store quickly leads to clutter, and a file is hard to find among hundreds of icons. A better habit is to keep on the desktop only the few files and shortcuts being worked on that day and to place everything else in the folder structure described in 2.2.4.2.

2.2.1.3The Start menu and search

The Windows icon on the taskbar is the Start button. Clicking it, or pressing the Windows key (Win) on the keyboard, opens the Start menu.

Definition 2.2.3

The Start menu is the menu from which one reaches installed applications, recently used files, user account options, and power commands in one place.

Figure 2.2.2 shows the five parts of the Start menu by number:

  1. Search. This is the box at the top of the menu. It finds apps, files, settings, and help content. Once the Start menu is open there is no need to click the box; typing starts the search.
  2. Pinned. These are the icons of the apps the user uses often. An app is added here by right-clicking it and choosing “Pin to Start.” The All apps link at the top right opens an alphabetical list of all installed apps.
  3. Recommended. Recently opened files and newly installed apps. It is the shortest way back to an unfinished document.
  4. User menu. It opens when the user name at the bottom left is clicked: account settings, lock, sign out.
  5. Power. The button at the bottom right: sleep, shut down, restart.

Right-clicking the Start button opens another menu. It is called the Quick Link menu and can also be opened with the Win + X shortcut. It contains system tools such as Task Manager, Settings, File Explorer, Device Manager, Disk Management, and Terminal. It is the shortest way to a system tool without searching in the Start menu.

Example 2.2.1

You want to change the screen resolution but do not know which menu the setting is in. Search finds it as follows:

  1. Press the Win key; the Start menu opens.
  2. Type resolution right away. There is no need to click the search box.
  3. The “Change the resolution of the display” setting appears at the top of the results. When you press Enter, the Settings app opens directly on the System → Display page.

The same method works for apps. Pressing the Win key, typing word, and pressing Enter is faster than looking for Word in the menu.

Common mistake

Holding the power button down to shut the computer off. A long press on the case button cuts the power; unsaved documents are lost and the operating system cannot finish half-completed write operations. The computer is shut down with Power → Shut down in the Start menu. Holding the button is a last resort, only when the system responds to no key at all.

2.2.1.4The taskbar

Definition 2.2.4

The taskbar is the bar that is always visible at the bottom of the screen and carries the Start button, the search box, pinned and open apps, the system tray, quick settings, and the clock.

Figure 2.2.3 divides the taskbar into seven parts from left to right. The job of each part is summarized in Table 2.2.1.

The icon of the window that currently receives keyboard input is highlighted more strongly. If an app has several windows open, hovering over its icon shows thumbnails of the windows, and you pick the one you want.

The fifth part, the system tray, is easy to overlook at first. Programs such as cloud sync, antivirus, or a music app run in the background without a window. Their icons appear in the small panel that opens when you click the ^ arrow. To close a background app completely, right-click its icon and choose “Exit” or “Quit.”

2.2.1.5Quick settings and notifications

The two areas at the far right of the taskbar open two small but frequently used panels (Figure 2.2.4).

Definition 2.2.5

Quick settings is the area that gathers frequently changed settings such as Wi-Fi, Bluetooth, airplane mode, volume, brightness, and accessibility in a single panel; it opens by clicking the network, volume, and battery icons or with Win + A. The notification center is the panel that shows app notifications and the calendar; it opens by clicking the clock or with Win + N.

The buttons in the Quick settings panel switch on and off with a click. Airplane mode, for example, cuts all wireless connections at once. Night light reduces the blue light of the screen and eases eye strain in the evening. The arrow next to the Wi-Fi button opens the list of nearby wireless networks. The steps for connecting to a network are given in 2.2.8.2.

A notification is a short message an app gives the user: a new e-mail, an upcoming class, a finished download. Notifications appear in a corner of the screen for a few seconds and then pile up in the notification center. Distracting notifications can be turned off per app. For this, switch off the relevant app’s toggle on the Settings → System → Notifications page. The Do not disturb mode on the same page silences notifications at set times, for example during a class or an exam.

Common mistake

Dismissing all notifications without reading them. Critical system warnings such as “The disk is almost full,” “A restart is needed for the update,” or “Virus & threat protection is off” also arrive as notifications. These warnings should be read before they are dismissed. Only distracting app notifications should be turned off.

2.2.2Window management

Windows takes its name from windows. Each application open at the same time runs in its own window. While writing an assignment, you may have Word on one side, a browser with the sources open on the other, and a music app playing in the background. Arranging windows quickly makes it easier to carry on several tasks together.

2.2.2.1The parts of a window

Definition 2.2.6

A window is the rectangular area an application occupies on the screen, one that can be moved and resized. Almost every window has a title bar, control buttons, a work area, and a border.

Figure 2.2.5 shows the parts of a window on a File Explorer window. Although applications differ, most of these parts are in the same place in every window:

  • The title bar is the strip at the very top. It shows the name of the application and the open document: “Documents - File Explorer.” The window is moved by grabbing this bar and dragging; double-clicking the bar maximizes the window or returns it to its previous size.
  • The control buttons are the three buttons at the right of the title bar: Minimize (—), Maximize (□), and Close (✕).
  • The menu or toolbar carries the application’s commands. In File Explorer, the New, Cut, Copy, Paste, and View commands are here; in Word, this area takes the form of a ribbon.
  • The address and search bar is found in some applications. In File Explorer it shows the path of the folder that is currently open.
  • The work area is the real content of the window: the file list, the document text, the web page.
  • The scroll bar appears when the content does not fit in the window and scrolls the content up and down.
  • The status bar is the thin strip at the bottom. In File Explorer it shows the number of items in the folder and the number of selected items; in Word it shows the page and word counts.
  • The border is the outer line of the window. When the mouse is over the border or a corner, the cursor turns into a double arrow; dragging resizes the window.

2.2.2.2Minimize, maximize, close

A window is in one of three states: normal (it covers part of the screen and can be moved and resized), maximized (it fills the whole screen), or minimized (it is not visible on the screen; only its icon stays on the taskbar). The control buttons move the window between these states:

  • Minimize (—) sends the window to the taskbar. The application does not close; it keeps running. Clicking its icon on the taskbar brings the window back to where it was.
  • Maximize (□) spreads the window over the whole screen. Once the window is maximized, the icon of the same button changes and its name becomes Restore; pressing it returns the window to its previous size.
  • Close (✕) closes the window. If it is the application’s only window, the application closes too. If there are unsaved changes, the application first asks whether to save them.
Common mistake

Confusing minimizing with closing. A minimized window disappears from the screen, but the application keeps running in memory. When dozens of windows are minimized and forgotten, memory fills up and the computer slows down. The lines under the taskbar icons show which applications are still open. A window you are finished with is not minimized; it is closed.

2.2.2.3Snapping and switching between windows

Resizing windows by hand with the mouse is slow. Windows offers a layout feature that quickly places windows along the edges and corners of the screen.

Definition 2.2.7

Snap is the window-layout feature that fits a window into a half, a third, or a quarter of the screen. A window is snapped by dragging it by the title bar to the edge of the screen, with Win + arrow keys, or by choosing one of the snap layouts that open with Win + Z.

Figure 2.2.6 shows four of the snap layouts. Win + ← places the active window in the left half of the screen and Win + → in the right half. Win + ↑ maximizes the window, while Win + ↓ first restores its previous size and, pressed once more, minimizes it. Win + Z, or hovering the mouse over the Maximize button, shows ready-made layouts such as three columns, four quarters, or one large and two small windows.

The fastest way to switch between open windows is the Alt + Tab shortcut. While the Alt key is held down, pressing Tab brings up thumbnails of the open windows in the middle of the screen. As long as Alt stays down, each Tab selects the next thumbnail; when Alt is released, the selected window comes to the front. Pressing Alt + Tab once and releasing it switches back and forth between two windows.

2.2.2.4Virtual desktops

When many windows are open at once, the screen gets crowded. The Word and browser windows opened for class get mixed up with music and game windows. Windows solves this problem by dividing windows into separate workspaces.

Definition 2.2.8

A virtual desktop is a separate workspace that holds a group of open windows. At any moment the screen shows the windows of only one desktop; the applications on the other desktops keep running in the background.

Virtual desktops are managed with four shortcuts (Table 2.2.3). To see all desktops together, Task view is used. Task view opens with the button on the taskbar or with Win + Tab. It shows the open windows of the active desktop at the top and the list of desktops below.

A game on a desktop that is not on screen still uses memory and the processor.

2.2.3Keyboard shortcuts and screenshots

Every move with the mouse means opening a menu, finding an item, and clicking. Doing the same job with a key combination is often several times faster. That is why knowing the shortcuts for frequent tasks saves a great deal of time in daily use.

Definition 2.2.9

A keyboard shortcut is a way of running a command by pressing several keys together instead of choosing it from a menu. The notation “Ctrl + C” means pressing the C key while holding the Ctrl key, then releasing both together.

Each of the modifier keys used in shortcuts has roughly its own area. Ctrl usually runs commands inside an application (copy, paste, save, undo). The Win key reaches Windows’ own functions (Settings, File Explorer, window layout). The Alt key is used for switching between windows and for reaching menus. Shift gives a “stronger” form of a command: Delete sends a file to the Recycle Bin, and Shift + Delete deletes it permanently.

Locking the session with Win + L and signing out are different things. When you lock, the open applications and documents stay exactly as they are. A lock screen appears, and a PIN or password is requested to return. Signing out, on the other hand, closes all applications. When leaving the computer for a short time, locking is enough.

Example 2.2.4

With Word and a browser open, the keys Win + D, Win + E, Win + Shift + S, and Win + L are pressed in turn. After each step the screen shows the following:

  1. Win + D. The desktop becomes visible; the Word and browser windows are hidden. The applications do not close; the line under their icons remains.
  2. Win + E. A File Explorer window opens and appears on top of the desktop.
  3. Win + Shift + S. The screen darkens and a selection bar appears at the top. An area is selected with the mouse; the image of this area is put on the clipboard.
  4. Win + L. The lock screen appears. Word, the browser, and File Explorer stay open in the background. When the PIN or password is entered, the screen returns to the state it was in before locking.

In none of the four steps does an application close. The shortcuts only change what is visible.

2.2.3.3Taking a screenshot

To report an error message, to show where a setting is, or to add a chart to a report, you need to capture an image of the screen. Windows has several ways to do this. They differ in two questions: what is captured and where the image goes (Table 2.2.7).

Definition 2.2.10

A screenshot is the current image of the whole screen or part of it, saved as a picture. In Windows, screenshots are taken with the Snipping Tool and the PrtSc (Print Screen) key.

The other methods put the image on the clipboard. An image on the clipboard is not a file. It is overwritten at the next copy and is lost when the computer restarts. To keep it, paste it into a document or a program such as Paint and save it, or use the Win + V clipboard history. After an image taken with Win + Shift + S, a notification appears in the corner. Clicking it opens the image in the Snipping Tool, where it can be cropped, drawn on, and saved as a file.

Common mistake

Sharing a screenshot without checking it. The image may contain an e-mail address, a password hint, an open chat notification, or the titles of other tabs. Look at the image before sharing it; if necessary, remove personal information by cropping or painting over it.

2.2.4Drives, files, and folders

Every document, photo, and program on a computer sits on the disk as a file. The operating system places these files in folders and the folders on drives. This section describes the building blocks of this organization from the bottom up, that is, from the physical disk to the file name.

2.2.4.1Disks, partitions, and drive letters

In everyday speech the words “disk,” “drive,” and “C:” are used interchangeably. They are in fact three separate concepts.

Definition 2.2.11

A physical disk is the device in which data is stored: an SSD, an HDD, or a USB flash drive. A partition or volume is a logical area set aside on a disk; one disk can be divided into several partitions. A drive letter is the name Windows gives to a volume: C:, D:, E:. In File Explorer each letter appears as a separate drive.

Figure 2.2.9 shows how these three concepts relate. Physical disk 0 is a 512 GB SSD. This disk is divided into three partitions. The first is a small EFI partition; it is used when the computer starts and has no letter. The second is the 400 GB C: volume, where Windows is installed. The third is the 110 GB D: volume, set aside for data. Physical disk 1 is a 64 GB USB flash drive, and its single partition gets the letter E:. The Z: on the far right is not even a disk: a folder shared by another computer on the network is mapped to this letter.

NTFS and exFAT in the figure are names of file systems. A file system is the scheme that keeps the names, sizes, locations, and permissions of the files on a volume. Windows uses NTFS on its own volumes; NTFS supports file permissions, encryption, and large files. USB drives and memory cards usually use exFAT, because Windows, macOS, and many devices can read and write exFAT.

Windows is usually installed on the C: volume, and letters are generally handed out in order. The letters A: and B: were historically reserved for floppy disk drives; that is why the first hard disk volume still gets C: today. When a USB drive is plugged in, it is given the first free letter (E: in this example). For a network share, the user usually picks a letter from the end of the alphabet.

Example 2.2.5

An SSD with “512 GB” on its box is set up as a single partition, C:. Why does Windows show the capacity of this volume as about 476 GB?

  1. Disk manufacturers use decimal units: 1 GB = 109 bytes. The disk holds 512 × 109 = 512,000,000,000 bytes.
  2. Windows, however, calculates with binary units: 1 GiB = 230 = 1,073,741,824 bytes. Even though the screen says “GB,” what is meant is GiB.
  3. 512,000,000,000 ÷ 1,073,741,824 ≈ 476.8. Windows shows this number as “476 GB.”

No byte has been lost from the disk; only the unit is different. The EFI and recovery partitions also take up anywhere from a few hundred MB to a few GB, so the C: volume may look a little smaller still.

Common mistake

Thinking that C: and D: are separate disks. They can also be two partitions of the same physical disk. In that case copying files from C: to D: is not a backup: if the disk fails, both volumes are lost together. A real backup is kept on a separate device or in the cloud.

2.2.4.2Files and folders

Definition 2.2.12

A file is a unit of data with a name, contents, and properties; for example, report.docx. A folder is a logical container that holds files and other folders together; for example, Documents\Courses. A folder inside a folder is called a subfolder.

Because folders can be nested, files are organized in a tree. Figure 2.2.10 gives a small example. Inside the Documents folder there is a Courses subfolder, and inside it three files.

A folder itself holds no document content. A folder is like a list that knows the names of the files inside it and where they are on the disk. It resembles the shelves in a library: a shelf is not a book, but it makes books findable. If the folder organization is set up well, a file you are looking for among hundreds can be found in a few clicks.

2.2.4.3File names and extensions

The full name of a file has two parts: in project_report.pdf, the part up to the last dot is the file name and the part after the last dot is the extension.

Definition 2.2.13

An extension (file name extension) is the part of a file name after the last dot, and it gives a hint about the file’s format: .pdf, .docx, .jpg. When a file is double-clicked, Windows decides which application to open by looking at the extension. This link between an extension and an application is called a file association.

The user gives the file name to describe the content. The extension is usually added by the program that creates the file: Word adds .docx, Excel .xlsx, a camera .jpg. Windows hides extensions by default. In File Explorer, extensions become visible when the View → Show → File name extensions option is checked (2.2.6.2).

Figure 2.2.11 shows the two faces of the extension. At the top, each extension leads to its associated application: .pdf to the PDF reader, .xlsx to Excel, .jpg to the Photos app. At the bottom, the name of a PDF file has been changed to report.docx. Windows now tries to open this file with Word, but because the content is still a PDF, Word cannot recognize the file.

Example 2.2.6

With extensions visible, the file photo.jpg is renamed to photo.png with F2. What happens?

  1. Windows shows a warning that the file may become unusable if the extension changes. If Yes is chosen, the name changes.
  2. The bytes inside the file do not change. The content is still a picture compressed in the JPEG format, and its size stays the same.
  3. Windows now thinks the file is a PNG. Most picture programs look at the first bytes of the content and recognize the format anyway, but some programs and websites may reject the file.

A real conversion is done in a program that opens the file, with the “Save As” or “Export” command. For example, the picture is opened in Paint and saved as a PNG. This operation re-encodes the content and produces a new file.

Common mistake

Renaming a file while extensions are hidden and adding an extension at the end. A file homework.docx with a hidden extension appears on screen as homework. If the user renames it homework.pdf, the file’s real name becomes homework.pdf.docx. The file is still a Word document and is rejected when uploaded to a system that expects a PDF. Malicious files use a similar trick: a program named invoice.pdf.exe looks like invoice.pdf when extensions are hidden. Keeping extensions visible is therefore a safe habit.

2.2.4.4File naming rules

Windows places some limits on file names. Some of these limits are mandatory; Windows does not accept a name that breaks the rule. Others are merely good practice.

Forbidden characters. Nine characters cannot be used in a file name: \ / : * ? " < > |. Most of them have a special meaning in paths and searches. \ separates folders, : follows the drive letter, and * and ? are wildcards in searches. When you try to type one of these characters, Windows shows a warning and does not accept it.

Reserved names. CON, PRN, AUX, NUL, COM1…COM9, and LPT1…LPT9 are old device names. These names cannot be file names even with an extension; con.txt is rejected as well.

Upper and lower case. Windows treats the names Report.docx and report.docx as the same name, so the two cannot be in the same folder. The capital letter is preserved when the name is typed, but the comparison ignores case.

Path length. The classic limit is 260 characters for the full path, from the drive letter to the end of the file name. In very deep folder structures or with very long names, copying and opening operations can fail because of this limit.

2.2.5File paths

Because folders are nested, it is not possible to state a file’s location with a single word. Dozens of files named “report.pdf” can sit in different folders. To specify a file unambiguously, we give the sequence of folders that leads from the drive down to the file. This sequence is called the file’s path.

2.2.5.1The parts of a path

Definition 2.2.14

A path is the sequence of folders passed through to reach a file or folder, separated by backslashes (\). An absolute path starts at the root folder of the drive and points to the same file wherever you are. A relative path is written relative to the folder you are currently in, the current folder.

An example absolute path is:

C:\Users\Sercan\Documents\Courses\report.pdf

Figure 2.2.12 breaks this path into its parts. C:\ is the root folder of the drive. Then come the Users, Sercan, Documents, and Courses folders in turn. The last item, report.pdf, is the file itself. Each \ shows a step down one level.

One detail in this path deserves attention. On a Windows with a non-English interface language, File Explorer may show these folders under translated names (on Turkish Windows, for example, “Belgeler” for Documents), but their real names on disk are English: Documents, Desktop, Downloads, Pictures, Music, and Users. Windows translates the names of these folders into the interface language for display, but real names are used when a path is written. So C:\Users\Sercan\Documents and the translated “Belgeler” in Explorer are the same folder.

The length of a path can be counted, too. The path in this example has 44 characters and contains 5 backslashes. That is far below the classic 260-character limit. But as each folder name grows longer and the number of nested folders increases, the limit gets closer. For example, if a course project’s folder is ten levels deep under C:\Users\Sercan\Documents\… and each level’s name is 25 characters long, the path alone exceeds 250 characters.

Example 2.2.10

Common mistake

Forgetting the ..\ at the start of a relative path. If the current folder is Documents and you write Downloads\setup.zip, the Downloads folder is looked for inside Documents. Because there is no such subfolder, the file cannot be found. Before writing a relative path, you must know exactly which folder is current.

2.2.6File Explorer

The basic tool for moving around the folder tree and for viewing and organizing files is File Explorer. It opens with the folder icon on the taskbar or with Win + E.

2.2.6.1The panes of File Explorer

Definition 2.2.15

File Explorer is the Windows application used to view, open, copy, move, rename, delete, and search for drives, folders, and files.

Figure 2.2.15 divides the File Explorer window into six parts:

  1. Command bar: the New (folder or file), Cut, Copy, Paste, Rename, Sort, and View commands.
  2. Address bar: the path of the current folder. The path is shown as clickable parts: This PC › Documents › Courses. Clicking a part goes back to that folder. When you click an empty spot on the bar, the full path appears as text; typing a path there and pressing Enter goes straight to that folder.
  3. Search box: searches the current folder and all of its subfolders.
  4. Navigation pane: the column on the left. It goes with a single click to frequently used locations such as Home, Desktop, Documents, Downloads, This PC, and Network.
  5. File list: the contents of the current folder. In the Details view, each row shows the name, date modified, type, and size. Clicking a column header sorts the list by that column; clicking once more reverses the order.
  6. Preview / details pane: the optional column on the right. It shows the contents of the selected file without opening it, or lists its properties. It is turned on and off from the View menu.

The three arrows to the left of the address bar make navigation easier. ← (Back) and → (Forward) move back and forth between visited folders, as in a browser. ↑ (Up) goes up to the parent folder of the current folder; that is, it is the Explorer equivalent of .. in a relative path. When This PC is selected in the navigation pane, the file list shows the drives and a usage bar for each.

2.2.7File operations

After files are created, they change places, their names are corrected, unneeded ones are deleted, and those to be shared are gathered in an archive. Each of these operations looks simple, but their consequences differ. Was a copy of the file made, or did the file change place? Can a deleted file be brought back? This section answers these questions step by step.

2.2.7.1Copying and moving

Definition 2.2.16

Copying creates a second, independent instance of an item with the same content at the destination; the original stays at the source. Moving, on the other hand, changes the item’s location; the item leaves the source and goes to the destination. Copying is done with Copy + Paste (Ctrl + C, Ctrl + V), and moving with Cut + Paste (Ctrl + X, Ctrl + V).

Common mistake

Moving an important file without a backup and not checking the destination. If the USB drive is pulled out during the move, or the wrong destination is chosen, the file may end up somewhere unexpected. With important files, it is safe to have a backup before moving and, after the operation, to open the destination folder and confirm that the file is there.

2.2.7.2Drag and drop

Holding a file with the mouse and dropping it on another folder removes the need for the Copy or Cut commands. However, whether drag and drop copies or moves depends on which drives the source and destination are on.

Definition 2.2.17

Drag and drop is the operation of carrying an item to another location while the mouse button is held down and releasing it there. The default rule is this: if the source and destination are on the same drive, the item is moved; if they are on different drives, it is copied. Holding Shift while dropping forces a move, and holding Ctrl forces a copy. Holding Alt creates a shortcut to the item instead of the item itself.

There is a reason for this rule. Moving within the same drive is very fast, because the bytes of the file do not change place on the disk; only the record in the file system passes from one folder to the other. Between different drives, all the bytes must be read and written. In that case Windows treats copying, which leaves the original file untouched, as the safe option.

Example 2.2.13

At the start, C:\Documents holds photo.jpg, report.docx, and note.txt; C:\Archive and E:\ are empty. Four drag-and-drop operations are carried out in turn:

Thinking that drag and drop always copies or always moves. While you drag, a small tooltip appears next to the cursor: “Move to Archive” or “Copy to E:”. Looking at this tooltip before releasing the mouse prevents an unexpected move.

2.2.7.3Renaming and deleting

When a file or folder is selected and F2 is pressed, its name becomes editable. While extensions are visible, Windows selects only the part of the name before the extension, so the new name you type does not break the extension. Even so, take care not to change the extension (2.2.4.3). If several files are selected and F2 is pressed, they are all given the same name and numbered in order: holiday (1).jpg, holiday (2).jpg, …

Definition 2.2.18

The Recycle Bin is the special folder in which files deleted with Delete are held before being permanently deleted. An item in the bin returns to its original location with the Restore command. Permanent deletion deletes an item without sending it to the bin; it is done with Shift + Delete or by emptying the bin.

Figure 2.2.19 shows the two ways of deleting side by side. A file deleted with Delete goes to the Recycle Bin. Two paths lead out of it: Restore returns the file to its original folder, and Empty Recycle Bin deletes it permanently. Shift + Delete skips the bin: Windows asks for confirmation, and when confirmed, the file is permanently deleted directly.

The Recycle Bin does not protect in every case. There are three important exceptions:

  • USB drives and network locations. Files deleted in these locations mostly do not go to the bin; they are deleted directly. In this case Windows asks “Permanently delete?”.
  • Open or locked files. A file that an application keeps open may not be deletable. Windows gives an “the file is open in another program” warning; the application is closed first.
  • Cloud folders. A file deleted in a synced folder such as OneDrive is also deleted from the other devices linked to the same account. The cloud’s own recycle bin offers a chance of recovery for a while.
Example 2.2.14

On the desktop (drive C:) there are a.txt, b.txt, and c.txt. a.txt is selected and Delete is pressed; b.txt is selected, Shift + Delete is pressed, and confirmation is given. Then d.txt on a USB drive is selected and Delete is pressed.

  1. a.txt goes to the Recycle Bin. If the bin is opened and Restore is chosen, it returns to the desktop.
  2. b.txt does not go to the bin; it is deleted permanently and cannot be brought back with Windows’ own tools.
  3. c.txt has not been touched; it stays on the desktop.
  4. Because d.txt is on the USB drive, it does not go to the bin even with Delete. Windows asks for confirmation of permanent deletion.

In the end, only a.txt is in the Recycle Bin.

Common mistake

Treating the Recycle Bin as a backup. When the bin reaches a certain fullness, it automatically deletes the oldest items. Storage Sense can also clean out items older than a set time (2.2.10.1). If the disk fails, the files in the bin are lost too. The bin is only a short-term safeguard against accidental deletion.

A shortcut makes it easier to reach a file that is opened often. The shortcut of a file sitting in a deep folder is placed on the desktop; the file itself never moves. A shortcut is created with right-click → Create shortcut or by dragging the file while holding the Alt key.

2.2.7.5ZIP archives

When you need to send several files of an assignment by e-mail, or upload them to a system as a single file, the files are gathered in an archive.

Definition 2.2.20

An archive is a file that gathers several files and folders into a single file. Compression is the process of reducing a file’s size by writing repetitions in the data in a shorter form. ZIP is a common format that both archives and compresses without loss; Windows creates and opens ZIP files without any extra program. Taking the files out of an archive is called extraction.

Lossless compression guarantees that the bytes of the extracted file are exactly the same as the original. How much compression shrinks a file depends on the content. In plain text, the same words and letter sequences repeat a lot, so text compresses well. JPEG photos and DOCX documents, however, are already compressed formats. A DOCX file is actually a ZIP archive containing XML files. Compressed data has little repetition; compressing it a second time gains almost nothing.

Example 2.2.16

Three files in Documents\Courses are gathered into a ZIP archive: report.docx (480 KB), notes.txt (120 KB), photo.jpg (2,410 KB). The steps are as follows:

  1. Selection. While Ctrl is held down, the three files are clicked one by one. Ctrl + click adds or removes a single item from the selection; Shift + click selects all rows between two clicks. The status bar says “3 items selected.” The total size of the selection is 480 + 120 + 2,410 = 3,010 KB.
  2. Compression. Right-click the selection and choose Compress to → ZIP file. In older versions of Windows 11, this command is named Compress to ZIP file; Microsoft’s help page gives the route “Show more options” → “Send to” → “Compressed (zipped) folder.” The archive is created in the same folder and its name comes up selected; hw_sercan is typed and Enter is pressed. The original files are not deleted.
  3. Result. hw_sercan.zip is 2,905 KB. Table 2.2.17 shows how much each file shrank.
  4. Extraction. Right-click the archive and choose Extract All… → Extract. A folder named hw_sercan, the same as the archive, is created and the three files come out into it at their original sizes.

Common mistake

Double-clicking a document inside a ZIP and editing it. Double-clicking a ZIP shows the inside of the archive like a folder, but a document opened from there is a copy in a temporary folder. Even if the change is saved in Word, it is written to the temporary copy; the file in the ZIP does not change, and the effort is easily lost. Editing is always done first on an extracted copy.

2.2.7.6File and folder properties

When you right-click a file and choose Properties (or press Alt + Enter with the file selected), a window opens that shows the file’s details (Figure 2.2.22).

The General tab contains the following information:

  • Type and app: the file’s format (Microsoft Word Document, .docx) and the application that opens when it is double-clicked. The Change button next to it changes this application.
  • Location: the full path of the folder the file is in.
  • Size and size on disk: the size of the content and the space reserved on the disk. Why these two numbers differ is explained in the example below.
  • Dates: the created, modified, and accessed dates.
  • Attributes: Read-only prevents the file from being changed; Hidden hides the file from the list (2.2.6.2).

The Security tab shows the file’s owner and which users can read or change the file. The Previous Versions tab lists old copies of the file if File History or a restore point is turned on (2.2.10.6).

Definition 2.2.21

A file system divides the disk into fixed-size blocks. In NTFS the size of these blocks is usually 4 KB (4,096 bytes). Every file larger than a few hundred bytes takes at least one block and uses a whole number of blocks. (Very small files can be kept in NTFS’s own record table; their size on disk appears as 0.) The size on disk is therefore calculated as follows:

size on disk = ⌈size ÷ 4,096⌉ × 4,096 bytes

The ⌈ ⌉ sign here means rounding up.

Example 2.2.17

The file in Figure 2.2.22 is 1,500 bytes. Why does Windows show its size as “1.46 KB” and its size on disk as “4.00 KB”?

  1. Windows calculates KB as 1,024 bytes: 1,500 ÷ 1,024 ≈ 1.46. The size appears as 1.46 KB.
  2. How many blocks does the file take? 1,500 ÷ 4,096 ≈ 0.37; rounded up, 1 block.
  3. The size on disk is 1 × 4,096 = 4,096 bytes = 4.00 KB. The remaining 2,596 bytes of the block are empty, but no other file can use them.

The same rule holds for larger files. A 10,000-byte file takes 10,000 ÷ 4,096 ≈ 2.44 → 3 blocks; its size on disk is 3 × 4,096 = 12,288 bytes. With many small files the difference grows: the total size of 100 files of 1,500 bytes each is 150,000 bytes, but on disk they take 100 × 4,096 = 409,600 bytes (400 KB).

Common mistake

Thinking that the Read-only attribute also protects a file from deletion. Read-only prevents the file’s content from being changed and saved under the same name. The file can still be copied, saved under a different name, and deleted. Attributes are a layer of reminders, not a security measure.

Adding a printer. Follow Settings → Bluetooth & devices → Printers & scanners → Add device. A printer on the same network or connected by USB is usually found automatically, and its driver is installed by itself. If the printer’s driver cannot be found, it is downloaded from the manufacturer’s website.

Display resolution and scale. The Settings → System → Display page has two separate settings. Display resolution determines how many pixels the image is made of. This value should stay at the screen’s native resolution, the value Windows marks “(Recommended).” If a lower resolution is chosen, the image becomes blurry. Scale adjusts the size of text and icons. If the text seems small, you do not lower the resolution; you raise the scale.

Definition 2.2.22

Scale is the percentage that determines how many times larger Windows draws text, icons, and windows. At 100% scale an interface element is drawn 1 pixel to 1 pixel; at 150% the same element is drawn 1.5 times larger. The logical area available to applications is the physical resolution divided by the scale.

Example 2.2.18

The screen of a 15.6-inch laptop is 1920 × 1080 pixels. What logical area is left for applications when the scale is 100%, 125%, and 150%?

  1. 100%: 1920 ÷ 1 = 1920, 1080 ÷ 1 = 1080. The logical area is 1920 × 1080; text is at its smallest.
  2. 125%: 1920 ÷ 1.25 = 1536, 1080 ÷ 1.25 = 864. The logical area is 1536 × 864.
  3. 150%: 1920 ÷ 1.5 = 1280, 1080 ÷ 1.5 = 720. The logical area is 1280 × 720; text is large and little content fits on the screen.

In all three cases all 1920 × 1080 physical pixels of the screen are used, and the image stays sharp. Lowering the resolution to 1280 × 720 enlarges the text by the same ratio, but because each logical pixel is spread over 1.5 physical pixels, the image becomes blurry. The right way to enlarge text is scale.

Common mistake

Signing in to important accounts such as banking or school accounts on a public Wi-Fi network (a café, an airport). Others can watch the traffic on these networks, or a fake access point can imitate the name of the real network. Important operations are done on a trusted network or over mobile data.

2.2.8.3User accounts

A computer can be used by several people. Windows opens a separate user account for each person. Each account has its own desktop, Documents folder, settings, and password. Separate accounts keep personal files and settings apart between users. Other standard users cannot access a user’s C:\Users\Ayse folder.

Accounts are classified by two separate questions. The first question is where the credentials are managed:

  • Local account: the user name and password are kept only on that computer. It is not tied to another device.
  • Microsoft account: an online account opened with an e-mail address. It can link supported settings, OneDrive files, and Microsoft Store apps across devices; if the password is forgotten, it can be recovered online.

The second question is the account’s authority:

  • Standard user: does everyday work and changes their own files and settings. Administrator permission is needed for tasks such as installing programs and changing system-wide settings.
  • Administrator: installs and removes apps, manages the other accounts, and can change all system settings.

When a task that needs administrator permission is started, Windows dims the screen and shows a confirmation window. This feature is called User Account Control (UAC). Figure 2.2.23 compares what UAC asks for in the two account types. If a standard user wants to install an app, an administrator’s name and password are requested. If an administrator does the same task, only a Yes / No confirmation is asked.

There is a reason confirmation is requested even on an administrator account. If a malicious program tries to install itself in the background, the UAC window appears. If the user is not installing anything at that moment, this window is a warning sign, and No is chosen. So it is a safe principle to use a standard account for everyday work and to turn on administrator authority only when needed.

Signing out closes the open apps and ends the user’s session. Another user, in turn, signs in on the same computer with their own account. A new account is added on the Settings → Accounts → Other users page; the account type is chosen on the same page with Change account type.

2.2.8.4App management and permissions

From an app’s arrival on the computer to its departure, several decisions are made: where it is installed from, which permissions it is given, whether it runs when you sign in, what to do when it causes trouble, and finally how it is removed.

  • Install source. Apps are obtained from the Microsoft Store or from the vendor’s official site. “Free” versions on unfamiliar sites often carry malware.
  • Uninstalling. On the Settings → Apps → Installed apps page, click the three dots next to the app and choose Uninstall. This is the right way; deleting an app’s shortcut or folder does not uninstall it.
  • Startup apps. Some apps run by themselves when you sign in. This list is limited on the Settings → Apps → Startup page or in Task Manager (2.2.10.4).
  • Permissions. Camera, microphone, location, and file access are controlled per app.
  • Repair and reset. For supported apps, the Repair and Reset buttons are on the Installed apps → Advanced options page. Repair tries to fix the app without touching its data; Reset deletes the app’s data and returns it to the state it was in when first installed.
  • Updates. Apps are kept up to date for security and compatibility. Store apps update automatically; other apps usually show their own update notifications.

Permissions determine how much an app can access personal data and devices. Figure 2.2.24 shows the camera permission page. The Camera app and Teams are allowed to use the camera, and a game is turned off. A game does not need the camera. Giving an app only the permissions it needs to do its job prevents data from being collected needlessly.

Common mistake

Deleting an app’s folder in Program Files to uninstall it. Even if the folder is deleted, the app’s registry entries, shortcuts, and background services remain on the system, and Windows still thinks the app is installed. Apps are uninstalled from the Installed apps page in Settings.

Definition 2.2.23

A default app is the program Windows chooses automatically when a particular file type or link type is opened. For example, the default app for .pdf files may be Microsoft Edge.

2.2.9Security

The security of a computer has several layers. Signing in controls who can use the computer. Antivirus and the firewall stop malware and attacks from the network. The user’s habits also determine whether all these measures will work.

2.2.9.1Windows Hello and sign-in security

Definition 2.2.24

Windows Hello is a way of signing in to Windows with a PIN, face recognition, or a fingerprint instead of a password. In this method the PIN or biometric data (face, fingerprint) never leaves the device. It unlocks a private key stored in a security chip inside the device (the TPM); authentication is done with this key.

Figure 2.2.27 shows the steps of the verification. The user enters the PIN or shows their face to the camera. This gesture unlocks the private key inside the TPM. The account server sends a challenge to the device, and the device signs this challenge with the private key. The server verifies the signature with the public key previously registered with it. Not the PIN but only a digital signature travels over the network.

This design explains why a short PIN can be safer than a long password. A password belongs to the account itself; if it is stolen, the account can be entered from anywhere in the world. A PIN is tied to a single device. A stolen PIN is of no use to an attacker who does not have that device. Moreover, the TPM notices repeated wrong PIN attempts and locks the device for a while.

Example 2.2.21

How many possible values does a 4-digit PIN have? A 6-digit PIN? How do these compare with an 8-character password that may contain uppercase letters, lowercase letters, and digits?

  1. Each digit is one of 10 digits. For 4 digits there are 10 × 10 × 10 × 10 = 104 = 10,000 possibilities.
  2. For 6 digits there are 106 = 1,000,000 possibilities.
  3. In a password, each character is one of 26 lowercase letters, 26 uppercase letters, and 10 digits, that is, 62 characters. For 8 characters there are 628 ≈ 2.18 × 1014 possibilities.

By the number of possibilities, the password looks far stronger. But an attacker can try a PIN only at that device and only a limited number of times; the TPM imposes a waiting period after a few wrong attempts. A password, on the other hand, can be tried online from a leaked list. The strength of a PIN comes not from the number of possibilities but from its being tied to the device.

The other parts of sign-in security are these:

  • Screen lock. When leaving the computer, lock the session with Win + L.
  • Multi-factor authentication. When signing in to an account, a second proof is requested in addition to the password: a code sent to the phone or a confirmation in an authenticator app. Even if the password is stolen, the account cannot be entered without the second proof.
  • Recovery. How to get back into the account if the PIN is forgotten or the device is changed should be arranged in advance: a current phone number, a backup e-mail address, or recovery codes.

These options are on the Settings → Accounts → Sign-in options page.

Common mistake

Turning off real-time protection in order to install a program. If an installer says “turn off your antivirus,” it is most likely malicious. Software from a trusted source can be installed with Defender on. Once the protection is turned off, Windows turns it back on by itself after a while; every download in between goes unchecked.

2.2.9.3Safe everyday use

However good the tools are, most of security depends on the user’s habits. Six habits defeat most ordinary attacks:

  • Lock. When leaving the computer, lock the screen with Win + L.
  • Updates. Keep Windows and apps up to date. Most updates close known security holes.
  • Standard account. Do everyday work with a standard account; use administrator authority only when needed.
  • Downloads. Get software from the Microsoft Store or from the vendor’s official site.
  • Backups. Back up important files regularly and to a separate location (2.2.10.5).
  • Suspicious files. Do not open attachments and executable files from unknown sources.

These habits complement one another. For example, even if a malicious attachment is opened, if the user is on a standard account, UAC asks for an administrator password for the system change, and the attack may stop there. Even if an attack succeeds and encrypts the files, an up-to-date backup in a separate location keeps the loss to a minimum.

2.2.10Maintenance

A computer fills up, slows down, and falls out of date over time. The disk swells with temporary files, the number of programs that run at startup grows, an app freezes, an update causes trouble. Regular maintenance prevents most of these problems in the first place. For those that cannot be prevented, Windows has recovery tools.

2.2.10.1Storage management

When the disk is full, Windows cannot install updates, apps cannot write temporary files, and the computer slows down. What the space on the disk is spent on can be seen on the Settings → System → Storage page. This page divides the space into categories such as apps, system files, documents, and temporary files (Figure 2.2.28).

Example 2.2.22

For the drive in Figure 2.2.28, let us calculate the usage ratio, the share of each category, and what the free space becomes once the temporary files are cleaned.

  1. The sum of the categories: 120 + 60 + 70 + 40 + 22 = 312 GB. Free space: 476 − 312 = 164 GB. The numbers are consistent with the figure.
  2. Usage ratio: 312 ÷ 476 ≈ 0.655, that is, 65.5%. Free space is 34.5%.
  3. The largest part of the used space is apps: 120 ÷ 312 ≈ 38.5%. Temporary files take 40 ÷ 312 ≈ 12.8%.
  4. If the temporary files are deleted, used space falls to 312 − 40 = 272 GB and free space rises to 164 + 40 = 204 GB. The share of free space becomes 204 ÷ 476 ≈ 42.9%.

On this drive, the first category to clean is temporary files, because deleting them loses no data. If more space is needed, the next step is to uninstall unused apps.

The Storage page offers two helper tools:

  • Storage Sense: when turned on, it automatically cleans temporary files and, according to the rules you set, old items in the Recycle Bin. For example, it can be set to delete files that have stayed in the bin for more than 30 days. With this rule, a file deleted on 1 October 2026 is also removed from the bin after 31 October 2026.
  • Cleanup recommendations: lists large or long-unopened files, unused apps, and temporary files. The user decides for themselves what is deleted.
Common mistake

Deleting every large file in the list to free up space. A file in the cleanup recommendations may have been suggested because it has not been opened for a long time; that does not mean it is unnecessary. An old project or the photos of a past term may show up in this list. Before deleting, make sure the file is not needed; if you cannot be sure, move the file to an external drive.

2.2.10.2Optimizing drives

An HDD and an SSD read data in very different ways, so the maintenance applied to each is also different. The Windows Defragment and Optimize Drives tool is opened by searching for “defrag” in the Start menu. The tool recognizes the type of each drive and applies the suitable operation (Table 2.2.21).

Table 2.2.21: Maintenance by drive type.

Definition 2.2.25

If the blocks of a file sit in scattered places on the disk rather than one after another, the file is fragmented. Defragmentation is the process of rearranging the blocks of each file so that they sit side by side on the disk. TRIM is the operating system telling the SSD which blocks of deleted files are no longer in use.

Fragmentation arises by itself as files are deleted and new files are written. If the gap a deleted file leaves is small, part of a new file is written there and the rest in another gap. On an HDD this is a problem, because the read head has to move mechanically to go from one piece to the next. Each jump takes a few milliseconds.

Example 2.2.23

The disk in Figure 2.2.29 has 12 blocks. Before defragmentation the sequence is A A B _ B A _ C A B _ C (_ is an empty block). How many pieces is each file in? If a jump to each piece takes an average of 9.2 ms, how much time is spent on positioning to read the three files?

  1. File A is in blocks 1, 2, 6, and 9. Blocks 1 and 2 are side by side and the others are separate: 3 pieces.
  2. File B is in blocks 3, 5, and 10: 3 pieces. File C is in blocks 8 and 12: 2 pieces.
  3. There are 3 + 3 + 2 = 8 pieces in total. For each piece the head repositions: 8 × 9.2 = 73.6 ms.
  4. After defragmentation each file is a single piece: 3 positionings, 3 × 9.2 = 27.6 ms.

Even in this small example the positioning time falls to a little over a third. On an HDD with thousands of fragmented files, the difference reaches seconds.

An SSD, on the other hand, has no moving head. Every block is read at the same speed wherever it is. So fragmentation does not slow an SSD down, and defragmentation is unnecessary. Moreover, the many writes made during defragmentation needlessly wear an SSD, which has a limited write lifetime. What an SSD really needs is TRIM. When a file is deleted, the SSD does not know it by itself. If no TRIM notification arrives, the SSD still thinks the blocks holding deleted data are full, and on new writes it must first clear those blocks; writing slows down.

Common mistake

Frequently defragmenting an SSD by hand with classic HDD logic. Windows recognizes the drive type and chooses the right operation by itself: it defragments the HDD and applies TRIM to the SSD. The tool is scheduled by default to run weekly. It is enough not to turn this setting off.

2.2.10.3System Information and Task Manager

To solve a problem, you first need to know what is on the computer and what is running at that moment. Windows offers two tools for this.

System Information shows the details of the hardware, the operating system, the components, and the resources: the processor model, the amount of RAM, the Windows version, the BIOS/UEFI version, device drivers. It is opened by searching for “System Information” in the Start menu. A shorter summary is on the Settings → System → About page. You can tell here whether the computer meets a piece of software’s system requirements, and when someone asks for support, the computer’s specifications are read from here.

Definition 2.2.26

Task Manager is the Windows tool that shows running applications and processes and their processor (CPU), memory, disk, and network use, and ends a process when necessary. It opens directly with Ctrl + Shift + Esc, from the Win + X menu, or by right-clicking the taskbar.

A process, mentioned here, is a program that is running. An application can consist of several processes; browsers, for example, open a separate process for each tab. Task Manager shows in columns how many resources each process uses (Figure 2.2.30).

Task Manager consists of several pages. Each page answers a different question (Table 2.2.22).

High resource use is not always a problem. Windows Update, a virus scan, or the building of the search index can use the CPU and disk heavily for a short time. Such loads pass in a few minutes. Constant 100% disk or memory use, however, is a typical cause of slowness. When memory fills up, Windows writes some of the data in RAM to the disk and reads it back when needed; because the disk is thousands of times slower than RAM, the computer slows down noticeably.

Example 2.2.24

On a computer with 8 logical processors, a program has entered an infinite loop and is keeping a single core completely busy. What does Task Manager show in the CPU column for this program? What if the same happened on a computer with 4 logical processors?

  1. The CPU percentage is computed against the whole processor capacity. Each of the 8 logical processors is 100 ÷ 8 = 12.5% of the capacity.
  2. So the program that fully uses one processor appears at about 12.5%.
  3. On 4 logical processors the same program appears at 100 ÷ 4 = 25%.

The remark “the program uses only 12.5%, so it is no problem” can therefore be misleading. The program consumes its own core completely. In the per-core graphs on the Performance page, you can see one core sitting at the top the whole time.

Common mistake

Assuming that every process with an unrecognized name is malicious and ending it or deleting its file. Names such as “Antimalware Service Executable” look suspicious at first glance, but this process is Microsoft Defender itself. An unknown process is not ended or deleted before its name has been looked up in trusted sources. High resource use alone is not evidence of malware either.

2.2.10.4Frozen apps and startup apps

The two situations in which Task Manager is used most often are closing a frozen app and disabling programs that slow down startup. Let us follow both step by step on an example.

Example 2.2.25

Word does not respond to clicks. The computer also takes a long time to start. In Task Manager, opened with Ctrl + Shift + Esc, the steps are as follows:

In the fifth step Spotify is not uninstalled; it simply does not start at sign-in. When needed, it is opened by hand from the Start menu. The same list is also managed on the Settings → Apps → Startup page.

Common mistake

Disabling everything in the startup list. Some programs, such as antivirus, a touchpad driver’s helper, or cloud sync, need to run at startup. The ones to disable are programs that are not really needed at startup and have a high startup impact: a music player, a game client, a chat app.

2.2.10.5Updates, backup, and encryption

Windows Update is the service that brings security and quality updates to Windows. On the Settings → Windows Update page, updates are checked for, installed, and their history is viewed. Security updates are usually released on the second Tuesday of each month. Some updates ask for a restart. The Active hours setting keeps Windows from making this restart during the hours when the user is working. Updates can be paused for a short time but should not be postponed altogether.

Definition 2.2.27

A backup is keeping a copy of important files in a separate location. Restore is returning files or the system to an earlier state.

For a backup to be of use, it must not be lost together with the original files. A copy on the same disk goes with it when the disk fails. That is why there is a common rule: the 3-2-1 rule. Important data should have at least 3 copies, on at least 2 different media, and at least 1 copy should be in another place, for example in the cloud. Figure 2.2.32 shows the Windows counterpart of this scheme: the files on the computer are backed up both to OneDrive and to an external drive.

Definition 2.2.28

BitLocker is the feature that encrypts a whole drive in the supported editions of Windows (Pro, Enterprise, Education). Data on an encrypted drive cannot be read without the right key. The recovery key is the 48-digit number that gives access to the drive when the TPM or the password cannot unlock it. In the Windows Home edition, a similar feature exists under the name “Device encryption.”

Encryption protects the data when the computer is stolen. Even if a thief removes the disk and puts it in another computer, the files cannot be read. But the same protection applies to the owner too. If the motherboard is replaced, the TPM is reset, or the UEFI settings change, Windows asks for the recovery key at startup. If the key is not known, the data can never be accessed again. That is why the recovery key is kept away from the computer: in the Microsoft account, on a printout, or on a USB drive.

Common mistake

Keeping the BitLocker recovery key inside the encrypted drive, for example in a text file in Documents. The key is needed precisely when the drive cannot be opened; at that moment the file inside the drive cannot be reached. The key is always kept outside the computer.

2.2.10.6Recovery options

The tools to turn to when something goes wrong are ordered from light to heavy by their effect. A light tool brings back only a single file; a heavy tool reinstalls all of Windows. The right choice is the lightest tool that solves the problem (Figure 2.2.33, Table 2.2.24).

Example 2.2.26

The most suitable recovery tool is chosen for four different problems.

  1. A file deleted yesterday from Documents, which is backed up with OneDrive, is wanted back. The lightest tool is enough: the file is restored from the OneDrive recycle bin.
  2. Last week’s version of a file that is regularly saved to an external disk is wanted. File History: the external drive is plugged in, and the old version of the file is selected and restored.
  3. After a new device driver update, the system is unstable, but the documents are intact. The problem is in the system, not in the documents. A restore point returns the system to the point before the update; it does not touch the documents.
  4. The system is completely broken; personal files must be kept, and apps can go. Reset this PC → Keep my files. Windows is reinstalled, personal files stay, and apps are removed; the ones needed are installed again by hand.

In every case a heavier tool could also have solved the problem, but it would have caused needless losses. For example, resetting the computer for a single deleted file removes all the apps and does not bring the file back either.

Common mistake

Mistaking a restore point for a document backup. A restore point covers only system files, the registry, and installed programs. A deleted homework file does not come back with a restore point. For documents you need OneDrive, File History, or another file backup.

2.2.11Summary

  • The desktop is the main work area. The Start menu leads to apps, search, the account, and power commands; right-clicking it or pressing Win + X opens the Quick Link menu. The taskbar carries open and pinned apps, the system tray, quick settings (Win + A), and notifications (Win + N).
  • When a window is minimized, the app does not close. Snap (Win + arrow keys, Win + Z) arranges windows, and Alt + Tab changes the active window. Virtual desktops (Win + Ctrl + D, ← / →, F4) group windows; when a desktop is closed, its windows move.
  • Copy (Ctrl + C), Cut (Ctrl + X), and Paste (Ctrl + V) use the clipboard. Win + PrtSc saves a file; Win + Shift + S and Alt + PrtSc put the image on the clipboard.
  • A physical disk can be divided into several partitions; each volume gets a drive letter. A 512 GB disk appears in Windows as ≈ 476.8 GiB.
  • A file is defined by its name, extension, path, and properties. The extension determines the associated app; changing it does not convert the content. Nine characters (\ / : * ? " < > |) and reserved names such as CON and PRN cannot be used; the classic path limit is 260 characters.
  • An absolute path starts at the root; a relative path starts at the current folder, and .. is the parent folder. The real path of the Documents folder is C:\Users\<name>\Documents.
  • Copying keeps the original and increases the number of files; moving changes the location. Drag and drop moves on the same drive and copies across drives; Shift forces a move, Ctrl a copy, and Alt a shortcut.
  • Delete sends to the Recycle Bin, and Shift + Delete deletes permanently; the bin is not used on USB and network locations. A shortcut is a .lnk file that holds only a path; it is not a backup.
  • ZIP gathers files in one package; text compresses well, while JPEG and DOCX hardly compress at all. A document inside a ZIP is not edited without extracting it. Size on disk is rounded up to 4 KB blocks.
  • Settings (Win + I) gathers the system, device, network, account, app, language, and accessibility options. If text is too small, change the scale, not the resolution.
  • A standard user is for everyday work; UAC asks for confirmation or a password for administrator tasks. A default app is a permanent choice, while Open with is a one-time choice.
  • A Windows Hello PIN is tied to the device and does not pass over the network. Windows Security gathers virus protection, the firewall, SmartScreen, and device security.
  • Storage Sense and cleanup recommendations free up space. An HDD is defragmented, and TRIM is applied to an SSD. Task Manager ends a non-responding app and limits startup apps.
  • Keep the backup in a separate medium (3-2-1). Keep the BitLocker recovery key away from the computer. The recovery tools, from light to heavy: OneDrive, File History, Restore point, Reset this PC.

2.2.13Test Yourself

  1. On the taskbar there is a line under the Word icon but the icon is not highlighted; there is no line under the Excel icon. What is the state of these two apps? What happens when the Excel icon is clicked?

    Answer

    Word is open but is not the active window (it may be in the background or minimized). Excel is only pinned and is not open. When the Excel icon is clicked, Excel starts; a line appears under its icon and Excel becomes the active window. Word stays open.

  2. Word is open on Desktop 1 and Music on Desktop 2; the screen shows Desktop 2. Win + Ctrl + D is pressed, then Win + Ctrl + ←. Which desktop are we on, and how many desktops are there? If Win + Ctrl + F4 is then pressed, where does Music go?

    Answer

    Win + Ctrl + D creates a new, empty Desktop 3 and switches to it. Win + Ctrl + ← goes back one to the left, to Desktop 2. There are three desktops, and the screen shows Desktop 2. Win + Ctrl + F4 closes Desktop 2; Music does not close but moves to Desktop 1 on its left.

  3. A disk labeled “1 TB” on its box is set up as a single partition, D:. About how many GB does Windows show as this volume’s capacity?

    Answer

    1 TB = 1012 bytes. Windows counts 230 bytes as 1 GB: 1012 ÷ 1,073,741,824 ≈ 931.3. The volume appears as about 931 GB. The number of bytes is the same; the difference comes from the unit.

  4. The current folder is C:\Users\Ali\Pictures\Holiday. What is the absolute equivalent of the relative path ..\..\Documents\homework.docx? If the leading ..\..\ had not been written, in which folder would it have been looked for?

    Answer

    The first .. goes up from Holiday to Pictures, and the second .. goes up from Pictures to Ali. Then it goes down into Documents: C:\Users\Ali\Documents\homework.docx. Without ..\..\, the Documents folder would have been looked for inside Holiday, that is, as C:\Users\Ali\Pictures\Holiday\Documents, and would not have been found.

  5. Which of these names cannot be file names in Windows: note|1.txt, PRN.docx, printer.docx, 2026-10-23_report.pdf, a<b.txt?

    Answer

    note|1.txt (| is a forbidden character), PRN.docx (PRN is a reserved name; the extension does not change that), and a<b.txt (< is a forbidden character) cannot. printer.docx and 2026-10-23_report.pdf are valid.

  6. C:\Documents holds a.docx and b.jpg, and E:\ (a USB drive) is empty. In order: a.docx is dragged and dropped onto E:\; b.jpg is dragged and dropped onto C:\Archive; the a.docx on E:\ is dragged to C:\Archive while Shift is held. In the end, which files are in which location?

    Answer

    The first operation is a copy because the drives differ: a.docx is in both C:\Documents and E:\. The second is a move because the drive is the same: b.jpg goes to C:\Archive. The third is a move because, although the drives differ, Shift is held: the copy on E:\ goes to C:\Archive. Result: C:\Documents holds a.docx; C:\Archive holds b.jpg and a.docx; E:\ is empty.

  7. What is the size on disk of a 9,000-byte file on an NTFS volume that uses 4,096-byte blocks? About how many KB does Windows show as the file’s size?

    Answer

    9,000 ÷ 4,096 ≈ 2.2; rounded up, 3 blocks. The size on disk is 3 × 4,096 = 12,288 bytes (12.0 KB). The size appears as 9,000 ÷ 1,024 ≈ 8.79 KB.

  8. A 600 KB text file and a 3,000 KB JPEG photo are added to a ZIP archive. The text compresses to 25% and the photo to 99%. What are the approximate size of the archive and the overall saving (ignore the share of archive information)?

    Answer

    The text becomes 600 × 0.25 = 150 KB and the photo 3,000 × 0.99 = 2,970 KB. The archive is ≈ 150 + 2,970 = 3,120 KB. The original total is 3,600 KB; the saving is (3,600 − 3,120) ÷ 3,600 ≈ 13.3%. Almost all of the saving comes from the text file.

  9. On a screen with a resolution of 2560 × 1600, the scale is set to 200%. What logical area is left for applications? Why is lowering the resolution to 1280 × 800 not a good way to enlarge text?

    Answer

    2560 ÷ 2 = 1280, 1600 ÷ 2 = 800: the logical area is 1280 × 800. With scale, all the physical pixels are used and the image stays sharp. Lowering the resolution, on the other hand, spreads each pixel over four (2 × 2); the logical area is the same, but the image becomes blurry.

  10. A student accidentally deleted a homework file with Shift + Delete; the file was in the Documents folder backed up with OneDrive. Also, after a driver update, the sound card does not work. Which recovery tool suits each problem?

    Answer

    Shift + Delete does not send the file to Windows’ Recycle Bin. But while OneDrive reflects the deletion to the cloud, it keeps the file in its own recycle bin for a while; the file is restored from there. The sound card problem is in the system: if restore points are on, the system is returned to the point before the update. Resetting the computer is needlessly heavy for both problems.
