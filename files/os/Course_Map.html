Operating Systems

Course Map

This page puts every chapter of the course on one map. Each chapter is a node, and an arrow shows which idea from an earlier topic the next one relies on. Read it before the course starts to see where the topics are heading, or during the course to see where you are.

Figure 1 shows the connections between the topics. Only the closest connections are drawn on the map; every chapter that a given chapter depends on is listed in Table 1.

Table 1: The connections on the map.
Topic (chapter)Builds onConnection
Introduction (1)—The two roles of an operating system: extended machine and resource manager; kernel mode and user mode.
Operating System Structures (2)IntroductionServices are provided through system calls: the concepts of process, address space, file and pipe.
Processes (3)Operating System StructuresThe running program: fork, exec and wait; process states and the process control block.
Threads (4)ProcessesSeveral flows of execution in the same address space; user-level and kernel-level threads.
CPU Scheduling (5)ProcessesWhich of the processes in the ready queue gets the processor: FCFS, SJF, Round Robin and multilevel feedback queues.
Synchronization (6)ThreadsConcurrent access to shared data creates a race condition: the critical section, mutex and semaphore.
Deadlocks (7)SynchronizationAcquiring locks in the wrong order leads to deadlock: the four conditions, the banker's algorithm.
Memory Management (8)Operating System Structures, ProcessesThe address space of each process: logical and physical addresses, contiguous allocation, paging.
Virtual Memory (9)Memory ManagementThe demand-driven form of paging; page faults and page replacement algorithms.
File Systems (10)Operating System Structures, Virtual MemoryThe on-disk counterpart of the file concept; memory-mapped files and the page cache make use of virtual memory.
Input/Output (11)Processes, File SystemsThe layer beneath the file system: device drivers, interrupts and DMA; a blocked process moves to a wait queue.
Multiprocessor Systems (12)CPU Scheduling, SynchronizationScheduling and synchronization on several processors: cache coherence, the scaling of spinlocks.
Security (13)Operating System Structures, File SystemsProtection from kernel and user mode to file permissions; access control lists and capabilities.
Operating System Design (14)Deadlocks, Multiprocessor Systems, SecurityThe common principles behind the choices in the earlier chapters: separating mechanism from policy, trade-offs.
Linux (15)Input/Output, Multiprocessor Systems, Operating System DesignAll the concepts in a real system: task_struct, the EEVDF scheduler, the virtual address space, the VFS.

The backbone of the map can be read as process → sharing → memory → storage → a real system. The process concept is the center of the course, and three branches grow out of it. The processor branch continues with scheduling, the concurrency branch with threads, synchronization and deadlocks, and the memory branch with paging and virtual memory. Virtual memory leads to the file system, and the file system to the I/O layer. Multiprocessor systems raise scheduling and synchronization together again. The design chapter gathers the common principles behind these choices, and the Linux chapter shows all of them in a working kernel.
