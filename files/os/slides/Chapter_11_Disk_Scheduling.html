Algorithm Comparison

Algorithm Guide

FCFS: serves requests in arrival order.

SSTF: serves the pending request closest to the current head position. Tie rule: if two requests are equally close, the one that appears first in the queue is served.

SCAN: moves like an elevator to one end of the disk, then reverses direction.

C-SCAN: serves in one direction only; after reaching one end, it jumps to the other end.

LOOK: like SCAN, but reverses at the last request rather than the physical disk boundary.

C-LOOK: like C-SCAN, but jumps between the last request on one side and the first request on the other side.

Conventions used here. The direction setting is the head's initial direction of travel for SCAN, C-SCAN, LOOK and C-LOOK (default: toward lower cylinders, as in the course slides). Requests at the head's current cylinder are served first. SCAN and C-SCAN always travel to the disk edge (0 or the max cylinder) in the current direction, and that travel counts as head movement. LOOK and C-LOOK turn or jump at the last request. For C-SCAN (edge to opposite edge) and C-LOOK (last request to the first request on the other side) the return jump serves no requests; the checkbox decides whether its length is added to the total. Textbooks differ on this, so always state which rule you use. Classic example (head 53, queue 98 183 37 122 14 124 65 67, cylinders 0–199): FCFS 640, SSTF 236, SCAN (down) 236, LOOK (down) 208, C-SCAN (up) 382 with the jump / 183 without, C-LOOK (up) 322 / 153.
