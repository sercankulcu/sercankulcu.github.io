Help
Tick
Each core runs its queue head for 1 tick, then re-queues it (RR, q = 1).
Shared
One global queue; idle cores pull from it.
Per-core
Each core keeps its own persistent queue.
Balance
Busiest → idlest queue while lengths differ by more than 1.
Migration
Task runs on a different core than last time (counted once).
Soft
Prefer the last core; may migrate.
Hard
Only the preferred core; never moved.
Config
Changing cores, model, affinity or tasks restarts at tick 0.
