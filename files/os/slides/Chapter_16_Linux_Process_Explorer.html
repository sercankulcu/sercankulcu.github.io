Linux Process Explorer

    
A simulated Linux system shown as a process tree (parent → children), a ps-style table and a /proc inspector. Values are illustrative; the page does not read your computer.

    
How to use

    
    
      
  • Click a node in the tree or a row in the table to select a process; then use fork(), kill -9, wait() or refresh (top-style CPU / MEM update). At most 14 processes.
    • 
      
  • Demo replays a recorded sequence: fork, kill, zombie, wait and orphan adoption by PID 1. The playback buttons move through the history of either scenario.
    • 
      
  • Filter by user or by command / PID; matching processes are highlighted in the tree.
    • 
      
  • The side panel switches between ps (sortable by PID, %CPU, %MEM) and /proc (status, fd and maps of the selected process).
    • 
    

    
Terms

    

      
PID / PPID
Process ID / parent's process ID.

      
fork()
New child: new PID, same UID/GID, program, fd copies and (copy-on-write) memory.

      
kill -9
The process exits; its children are re-parented to PID 1.

      
Zombie
Exited process (Z) kept until its parent calls wait().

      
wait()
The parent collects the exit status; the zombie disappears.

      
PID 1
systemd: adopts orphans and reaps them at once; protected here.

      
STAT
R running · S sleeping · Z zombie.

      
/proc
Kernel view per process. Uid/Gid list real, effective, saved, filesystem IDs.
