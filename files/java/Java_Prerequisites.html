Bilgisayar temelleri

Bir program saklanırken, belleğe yüklenirken ve çalışırken makinenin içinde olup bitenler.

CPU

Donanım: işlemci, bellek ve depolama

CPU · RAM · disk · girdi/çıktı

Program diskte bir dosya olarak durur. Çalışması için ana belleğe (RAM) yüklenir; işlemci de bellekteki verileri okuyup yazarak programın komutlarını tek tek yürütür. RAM hızlıdır ama elektrik kesilince içeriğini kaybeder, disk ise dosyaları saklamayı sürdürür.

Neden önemli

Bir Java programı çalışırken değişkenler, nesneler ve referanslar bellekte bulunur; program bittikten sonra yalnızca bir dosyaya yazılmış olan kalır.

Kontrol sorusu

Bir program int puan = 90; atamasını yapıyor, ardından bilgisayar kapatılıyor. 90 değeri ertesi gün hâlâ yerinde midir?

Hayır. Değişken yalnızca program çalışırken RAM'de bulunur. Değerin saklanması için bir dosyaya ya da veri tabanına yazılması gerekir.

Örnek (Java) 
Runtime rt = Runtime.getRuntime();
System.out.println(rt.availableProcessors());          // örneğin 8 çekirdek
System.out.println(rt.maxMemory() / (1024 * 1024) + " MB"); // JVM'in kullanabileceği bellek

Dosyalar, klasörler ve yollar

mutlak · göreli · uzantı

Yol (path) bir dosyayı adlandırır: mutlak yol kökten başlar (C:\Users\ali\ders\Merhaba.java), göreli yol ise o anki çalışma dizininden başlar (ders\Merhaba.java). Uzantı dosyanın türünü belirtir: .java kaynak kodu, .class derlenmiş bytecode'u gösterir. Windows bilinen uzantıları varsayılan olarak gizler; bu yüzden bir dosyanın adı fark edilmeden Merhaba.java.txt olabilir.

Neden önemli

javac ve java kaynak dosyanın bulunduğu klasörde çalıştırılır; dosya giriş çıkışı da dosyaları göreli ya da mutlak yollarla açar.

Programlar, derleyiciler ve yorumlayıcılar

kaynak kod · makine kodu · bytecode

İşlemci yalnızca makine kodunu yürütür. Derleyici (compiler) programın tamamını önceden çevirir; yorumlayıcı (interpreter) ise programı adım adım okuyup yürütür. Java ikisini birleştirir: javac kaynak kodu platformdan bağımsız bytecode'a derler, Java Sanal Makinesi (JVM) de bu bytecode'u yorumlar ve program çalışırken sık kullanılan kısımları makine koduna derler.

Neden önemli

Derleme zamanı hatası ile çalışma zamanı hatası arasındaki fark ve javac ile java komutlarının görevleri bu iki adımlı süreçten çıkar.

Sayı sistemleri ve veri gösterimi

Sayıların ve karakterlerin bit olarak nasıl saklandığı ve bunun doğurduğu şaşırtıcı sonuçlar.

2

İkilik, onluk ve on altılık sistem

2 tabanı · 10 tabanı · 16 tabanı

2 tabanında her basamak ikinin bir kuvveti değerindedir: 1101₂ = 8 + 4 + 0 + 1 = 13. On altılık sistem dört biti 0–9, A–F arasındaki tek bir basamakta toplar; böylece 1111 1111₂ = FF₁₆ = 255 olur. Bir sayıyı art arda 2'ye bölerek ikilik sisteme çevirmek ve basamak değerlerini toplayarak geri dönmek rahatça yapılabilmelidir.

Neden önemli

Bit örüntüleri, ikiye tümleyen gösterim, renk değerleri ve karakter kodları bu tabanlarda yazılır; Java da ikilik ve on altılık sabit değerleri kabul eder.

Kullanıldığı yerlerBölüm 1 · Basamak DeğeriBölüm 1 · İkiliye Çevirme: İzlemeBölüm 1 · Java'da Tabanlar

Kontrol sorusu

1011₂ ve 2A₁₆ onluk sistemde kaçtır?

1011₂ = 8 + 2 + 1 = 11 ve 2A₁₆ = 2·16 + 10 = 42.

Örnek (Java) 
System.out.println(Integer.toBinaryString(13));   // 1101
System.out.println(Integer.toHexString(255));      // ff
System.out.println(0b1101 + " " + 0x1F);           // 13 31
System.out.println(Integer.parseInt("101", 2));    // 5

Bitler, baytlar ve tam sayı aralıkları

byte · int · long · ikiye tümleyen · taşma

n bit 2ⁿ farklı değer tutabilir. Java işaretli tam sayıları ikiye tümleyen (two's complement) biçimde saklar; bu yüzden bir byte (8 bit) −128 ile 127 arasında, bir int (32 bit) ise yaklaşık −2,1 milyar ile 2,1 milyar arasında değer alır. Sonuç tipe sığmadığında hata oluşmaz, değer sessizce başa sarar.

Neden önemli

int ile long arasında seçim yapmak, faktöriyellerde, toplamlarda ve çarpmalarda taşmayı (overflow) fark etmek bu sınırları bilmeye bağlıdır.

Kullanıldığı yerlerBölüm 1 · İkiye TümleyenBölüm 1 · İkiye Tümleyen ve TaşmaBölüm 2 · Tam Sayı TipleriBölüm 2 · Taşma

Kontrol sorusu

8 bitte kaç farklı değer saklanabilir ve Java'daki byte tipinin aralığı nedir?

2⁸ = 256 değer; byte bunları −128 … 127 için kullanır.

Örnek (Java) 
byte b = (byte) 130;
System.out.println(b);                 // -126
int max = Integer.MAX_VALUE;           // 2147483647
System.out.println(max + 1);           // -2147483648 (taşma)
System.out.println((long) max + 1);    // 2147483648
.1

Kesirli sayılar yaklaşıktır

double · yuvarlama hatası · tam sayı bölmesi

double bir ikilik kesir saklar; bu yüzden 0.1 gibi onluk kesirlerin çoğu ancak yaklaşık olarak tutulur ve toplamlarda küçük hatalar ortaya çıkar. İki double değeri bu nedenle == ile değil, bir tolerans payıyla karşılaştırılır. İki tam sayının bölümü de tam sayıdır: 7 / 2 işleminin sonucu 3, 7 / 2.0 işleminin sonucu ise 3.5'tir.

Neden önemli

Bu iki etki hesaba katılmazsa ortalamalar, birim dönüşümleri ve para hesapları sessizce yanlış sonuç verir.

Kullanıldığı yerlerBölüm 1 · Kesirli SayılarBölüm 2 · Ondalıklı Sayı TipleriBölüm 2 · Ondalık Sayıların HassaslığıBölüm 2 · Tam Sayı Bölmesi ve Dönüşüm

Kontrol sorusu

Para tutarları neden çoğu zaman kuruş ya da sent cinsinden tam sayı olarak saklanır?

Tam sayılar kesindir; 0.10 gibi değerler ise double olarak tam gösterilemez ve bu türden çok sayıda değer toplandıkça yuvarlama hataları birikir.

Örnek (Java) 
System.out.println(0.1 + 0.2);                          // 0.30000000000000004
System.out.println(0.1 + 0.2 == 0.3);                   // false
System.out.println(Math.abs(0.1 + 0.2 - 0.3) < 1e-9);   // true
System.out.println(7 / 2 + " " + 7 / 2.0);              // 3 3.5
A

Karakterler: ASCII ve Unicode

char · karakter kodu · UTF-8

Her karakter bir sayı olarak saklanır: ASCII'de 'A' 65, 'a' 97, '0' ise 48'dir. Unicode bu numaralandırmayı bütün yazı sistemlerine genişletir; Türkçe harflerin de kodu vardır (ş 351'dir). Java'daki char 16 bitlik bir Unicode birimi tutar ve aritmetik işlemlerde kullanılabilir. Dosyalar metni çoğunlukla UTF-8 kodlamasıyla saklar.

Neden önemli

'7' karakterini 7 sayısına çevirmek gibi karakter aritmetiği, dizgilerin karşılaştırılması ve dosyadaki Türkçe metnin doğru okunması karakter kodlarına dayanır.

Kullanıldığı yerlerBölüm 1 · ASCII TablosuBölüm 1 · UnicodeBölüm 2 · char ve intBölüm 1 · UTF-8

Kontrol sorusu

'a' karakterinin kodu 97'dir. System.out.println('a' + 1); ne yazdırır?

98. char + int işlemi int olarak hesaplanır; (char) ('a' + 1) ise b yazdırır.

Örnek (Java) 
char c = 'A';
System.out.println((int) c);          // 65
System.out.println((char) (c + 2));   // C
System.out.println('7' - '0');        // 7
System.out.println((int) 'ş');        // 351

Algoritma: girdi, işlem, çıktı

sonlu · kesin · sonlanan

Algoritma, verilen girdiyi istenen çıktıya dönüştüren ve her zaman duran, sonlu sayıda kesin adımdan oluşan bir dizidir. Kodlamaya geçmeden önce problem açıkça tanımlanır: ne verilmiştir, ne üretilmelidir ve hangi özel durumlar vardır (sıfır, negatif sayılar, boş bir liste).

Neden önemli

Dersteki her alıştırma ve örnek program bir algoritmadan yola çıkar; hataların çoğu Java söz diziminden değil, belirsiz bir problem tanımından kaynaklanır.

“x negatif olana kadar x'e 1 eklemeyi sürdür.” x 5'ten başlıyorsa bu bir algoritma mıdır?

Sözde kod (pseudocode) bir algoritmanın adımlarını söz dizimine takılmadan, sade ve düzenli bir dille anlatır. Ardından her satırın bir Java karşılığı yazılır: Oku Scanner ile okumaya, ← atamaya, Döngü bir döngüye, Yaz da System.out.println çağrısına dönüşür.

Önce adımları yazmak, çözümü düşünmeyi derleyici hatalarıyla uğraşmaktan ayırır.

10, çünkü 1 + 2 + 3 + 4 = 10.

Akış diyagramları ve üç kontrol yapısı

sıra · seçim · tekrar

Akış diyagramı bir algoritmayı standart şekillerle çizer: başlangıç ve bitiş için oval, girdi ve çıktı için paralelkenar, hesaplama için dikdörtgen, karar için eşkenar dörtgen kullanılır. Her algoritma üç yapıyla kurulabilir: sıra, seçim (if) ve tekrar (döngü).

Neden önemli

Bir döngünün ya da iç içe kararların akışı çizildiğinde koşulun nerede sınandığı ve programın döngüden ne zaman çıktığı daha kolay görülür.

Kodu elle izleme

izleme tablosu · adım adım değişken değerleri

İzleme, bir programı kâğıt üzerinde çalıştırmaktır: bir tablo her adımdan sonra her değişkenin değerini kaydeder. Bir döngünün çıktısını önceden kestirmenin, bir eksik ya da bir fazla adım (off-by-one) hatasını bulmanın ve başkasının kodunu anlamanın en güvenilir yoludur.

Neden önemli

Birçok slayt ve sınav sorusu kısa bir kod parçasının çıktısını sorar; izleme tablosu bu soruları bilgisayarsız yanıtlamayı sağlar.

Kullanıldığı yerlerBölüm 1 · ToplamaHesaplama İzlemeBölüm 3 · Sayı Toplama (for)Bölüm 1 · Döngülü İşlemler

Kontrol sorusu

int x = 5; while (x > 1) x = x / 2; Döngü gövdesi kaç kez çalışır ve sonunda x kaçtır?

İki kez: x sırasıyla 5 → 2 → 1 olur, ardından x > 1 koşulu yanlıştır. Sonunda x 1'dir (tam sayı bölmesi).

Örnek (izleme tablosu) 
int s = 0;
for (int i = 1; i <= 4; i++) s += i;

//  i :  1   2   3   4
//  s :  1   3   6  10     -> i 5 olunca döngü biter

Değişkenler, tipler ve atama

int · double · boolean · char · String

Değişken, bellekte adı olan ve hangi değerleri tutabileceğini tipinin belirlediği bir yerdir. Java tipleri derleme zamanında denetler: bir int "5" değerini tutamaz ve bir değişken okunmadan önce ona değer verilmiş olmalıdır. = işareti matematikteki eşitlik değil, atamadır (sağ tarafın değeri değişkene kopyalanır).

Neden önemli

Her program verisini değişkenlerde tutar; ilkel tipler ile referans tipleri ileride atandıklarında ya da metotlara aktarıldıklarında farklı davranır.

int a = 3; int b = a; a = 10; b kaçtır?

3. b = a ataması o andaki değeri kopyaladı; a'nın sonradan değişmesi b'yi etkilemez.

Örnek (Java) 
int age = 20;
double gpa = 3.25;
boolean passed = gpa >= 2.0;

System.out.println(name + " " + age + " " + passed);   // Ayşe 21 true

Mantıksal ifadeler

&& · || · ! · kısa devre · De Morgan

Koşullar && (ve), || (veya) ve ! (değil) ile birleştirilir. Java bunları soldan sağa değerlendirir ve sonuç belli olur olmaz durur (kısa devre değerlendirme, short-circuit); bu yüzden sonraki bir parça önceki bir denetime güvenebilir. De Morgan yasaları olumsuzlamayı içeri dağıtır: !(a && b) ile !a || !b aynıdır.

Neden önemli

Aralık denetimleri, girdi doğrulama ve döngü koşulları boolean ifadelerdir; yanlış yere yazılmış bir && ya da || en sık rastlanan mantık hatalarındandır.

Kullanıldığı yerlerBölüm 2 · Mantıksal OperatörlerBölüm 2 · Kısa DevreBölüm 3 · İç İçe Kararlar (Nesting)

Kontrol sorusu

!(x >= 1 && x <= 10) ifadesi ! kullanılmadan nasıl yazılır?

x < 1 || x > 10 (De Morgan yasası).

Örnek (Java) 
int x = 7;
boolean inRange = x >= 1 && x <= 10;      // true
boolean outside = !(x >= 1 && x <= 10);   // false: x < 1 || x > 10 ile aynı
int d = 0;
if (d != 0 && 10 / d > 1)                 // sağ taraf atlanır: sıfıra bölme olmaz
    System.out.println("büyük");
System.out.println(inRange + " " + outside);   // true false

Kararlar: if, else if, switch

dallanma · iç içe kararlar

if, koşulu doğruysa bir bloğu çalıştırır; else bunun seçeneğini verir. else-if zinciri koşulları sırayla sınar ve yalnızca koşulu sağlanan ilk dalı çalıştırır. switch ise tek bir ifadenin değerine göre bir case seçer.

Neden önemli

Not hesaplama, menüler, girdi denetimleri ve dersteki hemen her algoritma karar verir.

Kullanıldığı yerlerBölüm 3 · if-else YapısıBölüm 3 · else-if ZinciriBölüm 3 · switch-case Yapısı

Yalnızca A. İlk doğru koşul kazanır ve zincirin geri kalanı atlanır; x > 1 de doğru olduğu hâlde B yazdırılmaz.

Örnek (Java) 
int score = 72;

Döngüler: for, while, do-while

sayaç · koşul · iç içe döngüler

Döngü, koşulu doğru olduğu sürece bir bloğu tekrarlar. for tekrar sayısının bilindiği durumlara, while her turdan önce sınanan bir koşula, do-while ise gövdesinin en az bir kez çalışması gereken durumlara uygundur. Her döngüde, koşulun sonunda yanlış olmasını sağlayacak biçimde değişen bir değişken bulunmalıdır.

Neden önemli

Toplamlar, aramalar, desenler, girdi döngüleri ve dizi işlemleri döngüyle yazılır; sonsuz döngüler ve bir eksik ya da bir fazla dönen döngüler sık yapılan hatalardır.

Kontrol sorusu

for (int i = 10; i > 0; i -= 3) döngüsü kaç kez döner?

    digits++;

Fonksiyonlar: parametreler ve dönüş değerleri

metot · parametre · return · void

Fonksiyon (Java'da metot) bir hesaplamayı bir ad altında toplar: değerleri parametreler aracılığıyla alır ve return ile tek bir sonuç döndürebilir; void bir metot değer döndürmez. Java argümanları değer ile aktarır; bu yüzden bir metot, çağıranın int değişkenini değiştiremez.

Neden önemli

Programlar en baştan metotlara bölünür; sınıflar da metotların ve verinin bir araya geldiği yapılardır.

Kullanıldığı yerlerBölüm 3 · Fonksiyon TanımıBölüm 3 · return ve voidBölüm 3 · Değer ile AktarımBölüm 3 · return ve void

Kontrol sorusu

static void inc(int x) { x++; } tanımından sonra int a = 5; inc(a); çalışırsa a kaç olur?

Yine 5. Metot değerin bir kopyasını aldı; yalnızca kendi parametresi x'i değiştirdi.

Diziler ve dizgiler: ilk tanışma

0'dan başlayan indis · length · charAt

Dizi, tek bir tipten sabit sayıda değer tutar; değerler 0'dan length − 1'e kadar indislerle numaralanır. String ise konumları yine 0'dan numaralanan bir karakter dizisidir. Bu sınırların dışı okunmaya çalışılırsa program bir istisnayla durur.

Neden önemli

Not listeleri, matrisler, metin işleme ve koleksiyon sınıflarının hepsi indisle erişime dayanır.

Kontrol sorusu

int[] a = {4, 8, 15}; a[3] okunursa ne olur?

ArrayIndexOutOfBoundsException fırlatılır; geçerli indisler 0, 1 ve 2'dir.

Soyutlama ve problemi parçalama

parçalara ayırma · ayrıntıyı gizleme · yeniden kullanım

Problemi parçalama (decomposition) büyük bir problemi ayrı ayrı çözülebilecek küçük parçalara böler; soyutlama (abstraction) ise bir parçanın yalnızca önemli yönlerini tutar ve içeride nasıl çalıştığını gizler. Math.sqrt metodunu algoritmasını bilmeden kullanmak soyutlamadır; bir programı birkaç küçük metot olarak yazmak ise problemi parçalamadır.

Neden önemli

Metotlar, sınıflar, arayüzler ve sarmalama bu iki fikrin araçlarıdır.

Kullanıldığı yerlerBölüm 3 · Problemi ParçalamaBölüm 3 · SoyutlamaBölüm 4 · SoyutlamaBölüm 1 · Hesaplamanın Yapı Taşları

Kontrol sorusu

Bir program notları okuyor, ortalamalarını hesaplıyor ve bir rapor yazdırıyor. Bu program hangi parçalara ayrılabilir?

Örneğin üç metoda: notları okuyan, ortalamayı hesaplayan ve raporu yazdıran birer metot. Her biri ayrı ayrı yazılıp test edilebilir.

Örnek (Java'ya ön bakış) 
static int[] readGrades() { ... }
static double average(int[] g) { ... }
static void printReport(double avg) { ... }

// main yalnızca parçaları birleştirir:
printReport(average(readGrades()));

Arama ve süzgece uyan konu yok.

Java örneklerindeki çıktılar, programlar javac --release 8 ile derlenip çalıştırılarak denetlendi; “örneğin” ile işaretlenen çıktılar bilgisayara göre değişir.
