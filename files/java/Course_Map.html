Object-Oriented Programming with Java

Course Map

This page puts every chapter of the course on one map. Each chapter is a node, and an arrow shows which idea from an earlier topic the next one relies on. Read it before the course starts to see where the topics are heading, or during the course to see where you are.

Figure 1 shows the connections between the topics. Each node is a chapter, and an arrow indicates which idea of the earlier topic the later one relies on. Only the closest connections are drawn on the map; every chapter that a given chapter depends on is listed in Table 1.

Table 1: The connections on the map.
Topic (chapter)Builds onConnection
Computers, Computation, and Algorithms (1)—Representing information in memory, the stored program, and the algorithm; the ground for programming.
Programming and Java Syntax (2)Computers, Computation, and AlgorithmsThe syntax and meaning of a programming language; compilation, types, and variables in Java.
Control Structures, Methods, Arrays, and Strings (3)Programming and Java SyntaxStructures that direct the flow, methods, arrays, and strings; the last tools before objects.
Objects and Classes, Inheritance, and Polymorphism (4)Control Structures, Methods, Arrays, and StringsData and behavior come together in the class: encapsulation, inheritance, polymorphism, interfaces.
Collections (5)Objects and Classes, Inheritance, and PolymorphismReady-made classes and interfaces: List, Set, Map; generics and comparators.
Exceptions (6)Objects and Classes, Inheritance, and PolymorphismAn error is an object too: the exception hierarchy is built with inheritance; try, catch, and finally.

The backbone of the map can be read as foundations → object → robust program → application. The first three chapters set up the language and structured programming. The chapter on objects and classes is the center of the course: every later chapter uses one of its tools. Collections use interfaces and generics, exceptions use the inheritance hierarchy, and graphical interfaces use inheritance and listener interfaces. Testing and exceptions deal with the robustness of the program, while input/output and databases deal with the persistence of data.
