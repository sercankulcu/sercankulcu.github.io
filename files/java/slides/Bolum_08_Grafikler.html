Grafik Programlama

Grafik Programlama

  • Java, grafik kullanıcı arayüzü (GUI, Graphical User Interface) geliştirmek için güçlü ve kapsamlı bir araç seti sunar: pencereler, düğmeler, metin alanları, çizimler.
  • Böylece etkileşimli ve görsel uygulamalar yazılabilir. Bunun için üç kavramı anlamak gerekir:
Bileşenler (components)

Pencere, düğme, etiket, metin alanı gibi arayüzün yapı taşları. Her biri bir sınıfın nesnesidir.

Olay işleme (event handling)

Fare tıklaması, tuşa basma gibi kullanıcı eylemlerini yakalar ve bunlara yanıt veren metotları çağırır.

Görsel oluşturma (painting)

Şekilleri çizer, ekranı günceller ve bileşenlerin görüntülenmesini sağlar.

Benzetme: bir GUI programı, müşteriyi bekleyen bir dükkân gibidir. Vitrin (bileşenler) hazırlanır, sonra program bekler; müşteri ne zaman neye dokunursa (olay) ilgili görevli (dinleyici metot) çalışır.

Grafik Programlama

AWT ve Swing

AWT (Abstract Window Toolkit), java.awt

Java'nın ilk grafik kütüphanesi. Bugün en çok ortak sınıfları için kullanılır: Graphics, Color, Font, Point, yerleşim yöneticileri ve olay sınıfları (java.awt.event).

Swing, javax.swing

AWT'nin üzerine kurulmuş, bileşenleri Java'nın kendisi çizen kütüphane. Sınıf adları J ile başlar: JFrame, JPanel, JButton, JLabel…

İçi boş üçgen: “türetilmiştir” (kalıtım). JFrame bir AWT penceresidir; diğer Swing bileşenleri JComponent'ten türer (JButton arada AbstractButton üzerinden).

Grafik Programlama

Uygulama Adımları

  1. Java'nın grafik sınıfları kullanılarak arayüze bileşenler eklenir.
  2. Kullanıcının eylemlerine yanıt veren olay işleme metotları tanımlanır.
  3. paint() veya paintComponent() gibi metotlarla görsel oluşturulur.

Ekran bir piksel ızgarasıdır. Koordinatlar tam sayıdır ve bileşenin sol üst köşesinden ölçülür. Matematikteki eksenin tersine, y aşağı doğru büyür: (0, 0) sol üst, (getWidth() − 1, getHeight() − 1) sağ alt pikseldir.

Grafik Programlama

Temel Grafik Kavramları

Tuval (canvas)

Üzerine resim çizilebilen yüzeydir. Swing'de genellikle JPanel (AWT'de Canvas) kullanılır: sınıfı JPanel'den türetir, çizimi onun içine yaparız.

Graphics sınıfı

Çizim işlemlerini yapan “kalem”dir. Metotları: drawLine(), drawRect(), fillOval(), drawString(), drawImage()…

Color ve Font

Kalemin rengini Color, yazı tipini Font belirler: g.setColor(Color.RED), g.setFont(new Font("Serif", Font.BOLD, 24)).

Kalem benzetmesi: Graphics nesnesi elinizdeki kalemdir. setColor kalemi değiştirir; değiştirene kadar bütün çizimler aynı renkle yapılır.

Grafik Programlama

paintComponent ile Çizim

import java.awt.*;
import javax.swing.*;

class CizimPaneli extends JPanel {
    @Override
    public void paintComponent(Graphics g) {
        super.paintComponent(g);     // zemini temizle
        g.setColor(Color.BLUE);
        g.drawRect(20, 30, 50, 70);  // x, y, en, boy
        g.drawString("Merhaba, Java Grafik!", 100, 100);
    }
}
  • paintComponent'i biz çağırmayız: pencere ilk açıldığında, boyutu değiştiğinde veya repaint() istendiğinde Swing çağırır ve hazır bir Graphics g verir.
  • panel.getGraphics() ile de bir grafik nesnesi alınabilir, ama bununla yapılan çizim pencere bir sonraki kez yeniden çizildiğinde silinir. Kalıcı çizim için yol paintComponent'tir.

Pencere ve Panel

JPanel Sınıfı

  • javax.swing paketinde bulunan bir konteynerdir (container): içinde başka GUI öğeleri barındırır.
  • Bir pencerenin içindeki bileşenleri gruplamak ve düzenlemek için kullanılır; birden fazla panel iç içe konarak karmaşık düzenler kurulur.
  • setBackground(), setBorder(), setPreferredSize() ile renk, kenarlık ve boyut özelleştirilir.
  • Kendi çizimimizi, animasyon ve grafikleri yaptığımız tuvaldir: JPanel'den türetip paintComponent'i geçersiz kılarız.
  • Kodu parçalara ayırmaya yarar: her panel ayrı bir sınıf olabilir.

Pencere ve Panel

JPanel Örneği

import java.awt.Color;
import javax.swing.*;

public class PanelOrnegi {
    public static void main(String[] args) {
        JPanel panel = new JPanel();
        panel.setBackground(Color.LIGHT_GRAY);
        panel.add(new JButton("Tıkla"));
        JFrame pencere = new JFrame("JPanel Örneği");
        pencere.add(panel);
        pencere.setSize(300, 150);
        pencere.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        pencere.setVisible(true);
    }
}
JPanel Örneği–  □  ×
Tıkla

Color.LIGHT_GRAY = (192, 192, 192). Düğme panelin üst ortasında durur.

Neden üst ortada? JPanel'in varsayılan yerleşim yöneticisi FlowLayout'tur: bileşenleri tercih ettikleri boyutta, satır satır ve ortalı dizer. JFrame'in içerik bölmesi ise BorderLayout kullanır; bu yüzden panel bütün pencereyi kaplar.

Point Sınıfı: (x, y) Noktası

Point nesnesi oluşur; x ve y alanları public int'tir.

getX() double döndürür: 30.0.

getY(): 40.0.

double değerler ondalıklı yazılır.

Alanlara doğrudan erişim int verir.

Orijine uzaklık: √(30² + 40²) = 50.0.

setLocation noktayı yeni konuma taşır. Değişkenler eski değerleri saklar.

toString() sınıf adını ve alanları yazar.

translate(dx, dy) göreli kaydırır. y azaldı: nokta yukarı çıktı.

Yeni konum yazılır.

static distance(x1, y1, x2, y2): (0, 0) ile (3, 4) arası 5.0.

double yKoordinati = nokta.getY();
System.out.println(xKoordinati + " " + yKoordinati);
System.out.println(nokta.x + " " + nokta.y);

nokta.setLocation(60, 80);
System.out.println(nokta);
nokta.translate(5, -10);   // 5 sağa, 10 yukarı

Yerleşim Yöneticileri

Yerleşim Yöneticisi

Yerleşim yöneticisi (layout manager), bir konteynerin içindeki bileşenlerin boyutunu ve konumunu kurallara göre hesaplayan nesnedir: panel.setLayout(new GridLayout(2, 3));. Koordinatları elle vermek yerine kullanılır, çünkü pencere büyüyünce, yazı tipi veya ekran çözünürlüğü değişince düzen kendiliğinden yeniden hesaplanır.

FlowLayout

Soldan sağa, satır dolunca alta. JPanel varsayılanı.

BorderLayout

Beş bölge. JFrame içerik bölmesi varsayılanı.

GridLayout

Eşit boyutlu hücrelerden ızgara: new GridLayout(2, 3).

BoxLayout

Tek satır veya tek sütun: BoxLayout.Y_AXIS.

Daha esnek ama karmaşık olan GridBagLayout, farklı boyutlarda hücrelerden oluşan bir ızgara kurar. Panelleri iç içe koyup her birine basit bir yönetici vermek çoğu zaman yeterlidir.

Yerleşim Yöneticileri

BorderLayout Sınıfı

  • Bileşenleri beş bölgeye yerleştirir: NORTH, SOUTH, WEST, EAST, CENTER.
  • Önceliği farklı bileşenleri düzenli göstermeye yarar: araç çubuğu üstte, durum satırı altta, asıl içerik ortada.
  • Bölge belirtilmeden eklenen bileşen merkeze yerleşir: add(b) = add(b, BorderLayout.CENTER).
  • Her bölgede tek bileşen olur; aynı bölgeye ikinci ekleme öncekinin yerini alır.
  • Kuzey ve güney tüm genişliği, batı ve doğu kalan yüksekliği alır; merkez geriye kalan her şeyi doldurur.
  • setHgap() ve setVgap() bölgeler arasındaki yatay ve dikey boşluğu (piksel) ayarlar.

Giriş Yasak İşareti

Giriş Yasak İşareti

Hedef: trafikteki “girişi olmayan yol” işaretini çizen bir panel. Şekil üst üste boyanan dört katmandan oluşur:

  1. Yeşil arka plan (setBackground)
  2. Beyaz büyük daire (dış halka)
  3. Kırmızı, biraz küçük daire
  4. Ortada beyaz yatay bar

Bütün ölçüler getWidth() ve getHeight()'tan hesaplanır: pencere büyütülünce işaret de büyür ve hep ortada kalır.

Giriş Yasak İşareti

paintComponent Kodu

public class GirisYasaktirIsareti extends JPanel {
    @Override
    public void paintComponent(Graphics g) {
        super.paintComponent(g);
        var c = new Point(getWidth() / 2, getHeight() / 2); // merkez
        var r = Math.min(getWidth() / 2, getHeight() / 2) - 5; // yarıçap
        var r2 = (int) (r * 0.9);   // iç yarıçap
        var bw = (int) (r2 * 1.4);  // bar genişliği
        var bh = (int) (r2 * 0.35); // bar yüksekliği
        g.setColor(Color.WHITE);
        g.fillOval(c.x - r, c.y - r, 2 * r, 2 * r);
        g.setColor(Color.RED);
        g.fillOval(c.x - r2, c.y - r2, r2 * 2, r2 * 2);
        g.setColor(Color.WHITE);
        g.fillRect(c.x - bw / 2, c.y - bh / 2, bw, bh);
    }
}

var (Java 10+): türü derleyici sağdaki ifadeden çıkarır; burada c bir Point, diğerleri int. Klasik yazım: Point c = new Point(…); int r = …;. (int) dönüşümü ondalık kısmı atar. Gerekli içe aktarmalar: java.awt.* ve javax.swing.*.

İşareti Çizme: paintComponent İzleme

Panel 384 × 261 piksel. super.paintComponent zemini arka plan rengiyle (yeşil) boyar.

Merkez: (384 / 2, 261 / 2) = (192, 130). Tam sayı bölmesi: 130,5 → 130.

Yarıçap: min(192, 130) − 5 = 125. Kısa kenara göre seçilir, 5 piksel pay kalır.

İç yarıçap: (int) 112,5 = 112.

Bar genişliği: (int) (112 × 1,4) = (int) 156,8 = 156.

Bar yüksekliği: (int) 39,2 = 39.

fillOval(67, 5, 250, 250): beyaz daire, sınırlayıcı kare kesikli çizgide.

fillOval(80, 18, 224, 224): kırmızı daire beyazın üstüne boyanır; 13 piksellik beyaz halka kalır.

fillRect(114, 111, 156, 39): beyaz bar en üste. İşaret tamam.

public static void main(String[] args) {
    SwingUtilities.invokeLater(() -> {
        var panel = new GirisYasaktirIsareti();

        var frame = new JFrame("Basit bir grafik programı");

  • SwingUtilities.invokeLater(() -> { … }): arayüzü olay iş parçacığında kurar (birazdan).
  • () -> { … } bir lambda ifadesidir (Java 8+): “sonra çalıştırılacak kod parçası”.
  • Color.GREEN.darker() = (0, 178, 0): saf yeşilden biraz koyu.
  • Panel, pencerenin içerik bölmesinin merkezine eklenir; tek bileşen olduğu için tüm alanı kaplar.

Çizim Programı

Basit Çizim Programı

Basit Çizim Programı–  □  ×
egriler.size() = 0, toplam nokta = 0

Fareyle basılı tutup sürükleyerek çizim yapılan program. Panelin içinde deneyin.

  • Basınca (mousePressed) yeni bir eğri başlar.
  • Sürükledikçe (mouseDragged) eğrinin sonuna nokta eklenir ve repaint istenir.
  • Çizerken (paintComponent) her eğrinin ardışık noktaları çizgilerle birleştirilir.

Program çizimi bir resim olarak değil, noktaların listesi olarak saklar; ekran her seferinde bu veriden yeniden çizilir.

Çizim Programı

Eğrileri Saklamak

public class BasitCizimPaneli extends JPanel {
    private List<List<Point>> egriler = new ArrayList<>();

    public BasitCizimPaneli() {
        addMouseListener(new MouseAdapter() {
            @Override
            public void mousePressed(MouseEvent e) {
                var yeniEgri = new ArrayList<Point>();
                yeniEgri.add(new Point(e.getX(), e.getY()));
                egriler.add(yeniEgri);
            }
        });
        addMouseMotionListener(new MouseMotionAdapter() {
            @Override
            public void mouseDragged(MouseEvent e) {
                egriler.get(egriler.size() - 1)
                       .add(new Point(e.getX(), e.getY()));
                repaint(0, 0, getWidth(), getHeight());
            }
        });
    }
}
  • List<List<Point>>: listelerin listesi. Dış liste eğrileri, her iç liste bir eğrinin noktalarını tutar.
  • Son eğri: egriler.get(egriler.size() - 1). Son eleman indeksi size() - 1'dir; get(size()) IndexOutOfBoundsException fırlatır.

Eğrileri Çizmek: paintComponent

Zemin temizlenir; önceki çizimden iz kalmaz.

İlk eğri; onceki onun ilk noktası.

İç döngü ilk noktadan başlar: kendisiyle birleşir, tek piksel çizilir. Ardından onceki = nokta.

(40,120) → (60,60) çizgisi.

(60,60) → (80,120). Eğri 0 bitti.

Dış döngü ikinci eğriye geçer; onceki yeniden onun ilk noktası olur. Böylece iki eğri birleşmez.

Yine tek piksel.

(50,95) → (70,95). Beş drawLine çağrısıyla çizim tamam.

@Override
public void paintComponent(Graphics g) {
    super.paintComponent(g);
    for (var egri : egriler) {
        var onceki = egri.get(0);
        for (var nokta : egri) {
            g.drawLine(onceki.x, onceki.y, nokta.x, nokta.y);
            onceki = nokta;
        }
    }
}

Para Üstü Uygulaması

Alanlar ve Yapıcı

public class ParaUstuHesaplama extends JFrame {
    private JTextField miktarAlani = new JTextField(12);
    private Document metin = miktarAlani.getDocument();
    private JTextArea rapor = new JTextArea(8, 40);

    public ParaUstuHesaplama() {
        var ustPanel = new JPanel();
        ustPanel.add(new JLabel("Miktar:"));
        ustPanel.add(miktarAlani);
        getContentPane().add(ustPanel, BorderLayout.NORTH);
        getContentPane().add(new JScrollPane(rapor),
                BorderLayout.CENTER);
        setBackground(Color.LIGHT_GRAY);
        rapor.setEditable(false);
        metin.addDocumentListener(new DocumentListener() {
            public void insertUpdate(DocumentEvent e) { raporuGuncelle(); }
            public void removeUpdate(DocumentEvent e) { raporuGuncelle(); }
            public void changedUpdate(DocumentEvent e) { raporuGuncelle(); }
        });
    }
  • Sınıf JFrame'den türer. Swing'de veri ile görünüm ayrıdır (MVC): JTextField görünüm, getDocument() ile alınan Document metni tutan model.
  • DocumentListener: insertUpdate (eklendi), removeUpdate (silindi), changedUpdate (stil değişti; düz metinde çağrılmaz). Arayüz olduğu için üçü de yazılır.

Para Üstü Uygulaması · Kodu adım adım çalıştır

raporuGuncelle: 93 kuruş

Alandaki metin "93" okunur ve tam sayıya çevrilir.

Para değerleri büyükten küçüğe bir dizide.

setText raporu sıfırdan başlatır: eski içerik silinir.

x = 50: 93 / 50 = 1 adet (tam sayı bölmesi), satır sona eklenir.

Kalan: 93 % 50 = 43.

x = 25: 43 / 25 = 1 adet (tam sayı bölmesi), satır sona eklenir.

Kalan: 43 % 25 = 18.

x = 10: 18 / 10 = 1 adet (tam sayı bölmesi), satır sona eklenir.

Kalan: 18 % 10 = 8.

x = 5: 8 / 5 = 1 adet (tam sayı bölmesi), satır sona eklenir.

Kalan: 8 % 5 = 3.

x = 1: 3 / 1 = 3 adet (tam sayı bölmesi), satır sona eklenir.

Kalan: 3 % 1 = 0.

void raporuGuncelle() {
    try {
        var miktar = Integer.parseInt(
                metin.getText(0, metin.getLength()));
        int[] dizi = {50, 25, 10, 5, 1};
        rapor.setText(miktar
                + " kuruş yapmak için kullanılacaklar:\n");
        for (int x : dizi) {
            rapor.append(miktar / x + " " + x + " kuruş\n");
            miktar %= x;
        }
    } catch (NumberFormatException e) {
        rapor.setText("Tam sayı değil veya aralık dışında");
    } catch (Exception e) {
        rapor.setText(e.toString());
    }
}

Sık Yapılan Hatalar

İçe aktarmayı unutmak

JFrame için import javax.swing.*; yoksa: cannot find symbol … class JFrame.

setVisible(true) ya da EXIT_ON_CLOSE yok

Pencere hiç görünmez veya kapatılınca program arka planda çalışmaya devam eder.

Metot adını yanlış yazmak

paintcomponent yeni bir metottur, hiç çağrılmaz. @Override ile: method does not override or implement a method from a supertype.

super.paintComponent(g) unutmak

Zemin temizlenmez; eski çizim artıkları ekranda kalır.

Arayüzün tüm metotlarını yazmamak

Dinleyici is not abstract and does not override abstract method mouseExited(MouseEvent) in MouseListener. Çözüm: MouseAdapter.

Son eleman için get(size())

IndexOutOfBoundsException: Index 1 out of bounds for length 1. Son eleman size() - 1.

Lambda içinde yerel değişken değiştirmek

e -> sayac++: local variables referenced from a lambda expression must be final or effectively final. Alan kullanın.

Sabiti sınıf adı olmadan yazmak

add(bilesen, CENTER): cannot find symbol … variable CENTER. BorderLayout.CENTER yazın.

Örnek Problemler

  1. Giriş yasak işareti paneli 200 × 100 piksel olsaydı r, r2, bw, bh kaç olurdu?
  2. Para üstü programına 68 yazılınca rapor ne olur?
  3. g.drawOval(50, 50, 100, 60) ile çizilen elipsin merkezi neresidir?
  4. BorderLayout kullanan bir panele önce A, sonra B düğmesi aynı NORTH bölgesine eklenirse kuzeyde hangisi görünür?
  5. Kullanıcı panele bir kez tıklayıp bırakırsa MouseListener'ın hangi metotları hangi sırayla çağrılır?
  6. Color.RED.brighter() hangi rengi verir?
Cevapları göster
  1. r = min(100, 50) − 5 = 45, r2 = (int) 40,5 = 40, bw = 56, bh = 14.
  2. “68 kuruş yapmak için kullanılacaklar:” ardından 1 50, 0 25, 1 10, 1 5, 3 1 kuruş.
  3. (50 + 100/2, 50 + 60/2) = (100, 80).
  4. B: her bölgede tek bileşen olur, son eklenen kazanır (A panelde kalır ama yerleşimde yer almaz).
  5. mousePressed → mouseReleased → mouseClicked (işaretçi panele girerken ayrıca mouseEntered).
  6. Yine (255, 0, 0): kırmızı zaten en parlak; 0 olan yeşil ve mavi bileşenler 0 kalır.

Alıştırmalar

  1. Hedef tahtası: panel boyutuna göre ölçeklenen, kırmızı-beyaz 5 iç içe halka çizin.
  2. Sayaç penceresi: “−1”, “+1”, “Sıfırla” düğmeleri ve değeri gösteren bir JLabel.
  3. Çizim programına bir “Temizle” düğmesi ekleyin.
  4. Çizim programında sağ tık son eğriyi silsin.
  5. Para üstü programı negatif miktarlar için “Miktar pozitif olmalı” yazsın.
  6. Sıcaklık dönüştürücü: JTextField'a °C girilip düğmeye basılınca °F gösterilsin.
Cevaplar / ipuçları
  1. Döngü: int ri = r - i * r / 5; g.setColor(i % 2 == 0 ? Color.RED : Color.WHITE); g.fillOval(cx - ri, cy - ri, 2 * ri, 2 * ri); Büyükten küçüğe çizin.
  2. private static int sayac; alanı; arti.addActionListener(e -> etiket.setText("" + (++sayac)));, panel FlowLayout.
  3. Düğme dinleyicisi: egriler.clear(); repaint(); (panel ile düğme BorderLayout'ta CENTER ve SOUTH).
  4. mousePressed başında: if (e.getButton() == MouseEvent.BUTTON3) { if (!egriler.isEmpty()) egriler.remove(egriler.size() - 1); repaint(); return; }; mouseDragged başına if (!SwingUtilities.isLeftMouseButton(e)) return;
  5. parseInt'ten sonra: if (miktar < 0) { rapor.setText("Miktar pozitif olmalı"); return; }
  6. double c = Double.parseDouble(alan.getText()); sonuc.setText(c * 9 / 5 + 32 + " °F"); 100 → 212.0 °F; hatalı girdi için NumberFormatException yakalayın.
