Giriş

Öğrenme Çıktıları

Önce derleyici gibi bakmak

Bir kodun derlenip derlenmediğine karar vermek: tür uyumsuzluğu, yinelenen case etiketi, geçersiz tanımlayıcı.

Sonra JVM gibi çalıştırmak

Programı satır satır izleyip değişken, çağrı çerçevesi ve nesne tablosu tutarak çıktıyı kesin tahmin etmek.

Metot ve nesneler

Değerle aktarımı (pass-by-value), static üyeleri, gölgelemeyi ve this(...) ile yapıcı zincirini açıklamak.

İfade ve kontrol yapıları

a++, işlem önceliği, continue, switch düşmesi (fall-through), if içinde atama ve do-while tuzaklarını tanımak.

Giriş

“Çıktısı Nedir?” Sorusu Nasıl Çözülür?

1. Derlenir mi?

Her bildirimde türü kontrol edin (char d = "d"?), adları kontrol edin, case değerlerini hesaplayın. Tek bir hata varsa program hiç çalışmaz; cevap “derleme hatası” olur.

2. Nereden başlar?

Çalışma her zaman main’in ilk satırından başlar. Bir metot çağrısında yeni bir çağrı çerçevesi (stack frame) açılır, metot bitince kapanır.

3. Tabloyu tutun

Kâğıda değişkenlerin değerini, açık çerçeveleri ve new ile oluşan nesneleri yazın. Her atamada tabloyu güncelleyin; tahmin etmeyin, hesaplayın.

4. Çıktıyı harfiyen yazın

print satır sonu eklemez, println ekler. Boşluklar, iki nokta ve büyük/küçük harf de çıktının parçasıdır: "Renk:" ile "Renk: " farklıdır.

Bu bölümdeki 11 sorunun her biri önce soru olarak gelir (şıklı); bir sonraki slayt ise cevabı adım adım izleme ya da açıklama ile verir. Önce kendiniz çözün!

Soru 1

public class Ornek1 {
  public static void sayiyaEkle(int x, int miktar) {
    x = x + miktar;
  }
  public static void main(String[] args) {
    int a = 15;
    int b = 10;

Program ekrana ne yazar?
  1. 25
  2. 15
  3. 10
  4. Derleme hatası

İpucu: Java’da bir metoda değişkenin kendisi değil, değeri gönderilir.

Cevap

B) 15. sayiyaEkle, a’nın kopyası olan x’i değiştirir; a aynı kalır.

Değerle Aktarım · Adım adım

Soru 1: Değer Kopyalanır

main başlar; çerçevesinde a = 15 oluşur.

b = 10. Henüz hiçbir metot çağrılmadı.

Çağrıda değerler kopyalanır: x = 15, miktar = 10. x ile a ayrı kutulardır.

x = 15 + 10 = 25. Yalnızca kopya değişti; main’deki a hâlâ 15.

Metot biter, çerçevesi silinir; x = 25 de onunla kaybolur. Metot void, bir şey döndürmez.

println(a) → 15. Cevap: B.

Referanslar da kopyalanır. Parametre bir nesne referansıysa referansın kopyası gider: nesnenin alanları değiştirilebilir, ama parametreye yeni nesne atamak çağıranı etkilemez (Örnek Problem 2).
Değerle aktarım (pass-by-value)

Java her zaman değerle aktarır: parametre, argümanın kopyasıdır. Metodun içinde parametreye yapılan atama çağırana yansımaz.

Çözüm

Yeni değeri return ile döndürün ve çağıran tarafta atayın: a = sayiyaEkle(a, b);

Yapıcı Metotlar

Soru 3

public class Ornek3 {
  private String renk;
  public Ornek3() {
    this("beyaz");
  }
  public Ornek3(String renk) {
    this.renk = renk;
  }
  public static void main(String[] args) {
    Ornek3 e = new Ornek3();
    System.out.println("Renk:" + e.renk);
    Ornek3 ee = new Ornek3("kırmızı");
    System.out.println("Renk:" + ee.renk);
  }
}
Program ekrana ne yazar?
  1. Renk:null / Renk:kırmızı
  2. Renk:beyaz / Renk:kırmızı
  3. Derleme hatası: aynı adlı iki yapıcı
  4. Renk:beyaz / Renk:beyaz

İpucu: this(...), aynı sınıfın başka bir yapıcısını çağırır.

Cevap

B) Renk:beyaz, Renk:kırmızı. Parametresiz yapıcı this("beyaz") ile diğer yapıcıyı çağırır.

Yapıcı Metotlar · Adım adım

Soru 3: this(...) ile Yapıcı Zinciri

new öbekte (heap) bir nesne ayırır; renk önce varsayılan null olur. Parametresiz yapıcı çalışmaya başlar.

this("beyaz") aynı nesne için Ornek3(String) yapıcısını çağırır: yeni bir çerçeve açılır.

this.renk nesnenin alanı, sağdaki renk parametredir. Alan "beyaz" olur.

İki yapıcı da biter, çerçeveleri kapanır. e artık nesneyi gösteren referansı tutar.

"Renk:" + e.renk → Renk:beyaz. İki noktadan sonra boşluk yok.

İkinci nesne: bu kez doğrudan Ornek3(String) çağrılır; parametre "kırmızı".

this şimdi ikinci nesneyi gösterir; onun alanı "kırmızı" olur. Birinci nesne etkilenmez.

ee ikinci nesneyi gösterir → Renk:kırmızı. Cevap: B.

public class Ornek3 {
  private String renk;
  public Ornek3() {
    this("beyaz");
  }
  public Ornek3(String renk) {
    this.renk = renk;
  }
  public static void main(String[] args) {
    Ornek3 e = new Ornek3();
    System.out.println("Renk:" + e.renk);
    Ornek3 ee = new Ornek3("kırmızı");
    System.out.println("Renk:" + ee.renk);
  }
}

Yapıcı Metotlar

Yapıcı Zinciri Kuralları

Aşırı yükleme (overloading)

Aynı adlı iki yapıcı, parametre listeleri farklı olduğu için geçerlidir: Ornek3() ve Ornek3(String).

this(...) ilk satırda

Başka bir yapıcıyı çağıran this(...), yapıcının ilk deyimi olmalıdır. Böylece varsayılan değerler tek bir yerde toplanır.

this.renk ↔ renk

Parametre, aynı adlı alanı gölgeler. Alana ulaşmak için this. gerekir; renk = renk; parametreyi kendine atar, alan null kalır.

public class Ornek3Hata {
  private String renk;
  public Ornek3Hata() {
    System.out.println("varsayılan");
    this("beyaz");
  }
  public Ornek3Hata(String renk) {
    this.renk = renk;
  }
}

public class Ornek4 {
  public static void main(String args[]) {
    int a = 0;
    while (a == a++) {
      a++;
      System.out.println(a);
    }
  }
}
Program ekrana ne yazar?
  1. 1
  2. 2
  3. Hiçbir şey yazmaz
  4. 2, 4, 6, … durmadan

İpucu: a++ önce eski değeri verir, sonra a’yı artırır. ==’in sol tarafı önce değerlendirilir.

Cevap

D) 2, 4, 6, … durmadan. a == a++ her zaman true’dur: döngü sonsuzdur.

Artırma İşleci · Adım adım

Soru 4: a == a++ Hep Doğru

a = 0.

Soldan sağa: sol a → 0; a++ → 0 verir, sonra a = 1. 0 == 0 → true.

Gövdedeki a++: a = 2.

println(a) → 2.

Yine iki taraf aynı değeri görür: 2 == 2 → true, ardından a = 3.

a = 4.

println(a) → 4.

Koşul her turda true: program 2, 4, 6, … yazarak sonsuza dek sürer (int taşsa bile).

    }
  }

Kapsam ve Gölgeleme · Adım adım

Soru 5: Hangi i?

Bu satırda henüz yerel i yok; i sınıfın static alanıdır → 1.

Yerel i = 2 tanımlanır. Alanla aynı ad yasaldır; bundan sonra main’de i yereli gösterir (gölgeleme).

Bir nesne oluşturulur. Nesnede alan yok: static alan nesneye değil sınıfa aittir.

Artık i yerel değişkendir → 2.

yazdir static’tir; nesne üzerinden çağrılsa da derleyici bunu Ornek5.yazdir() olarak çalıştırır.

yazdir çerçevesinde yerel i yok; main’in yereli görünmez → statik i → 1. Cevap: B.

  1. 6 satır: her i için j: 2 ve j: 3
  2. 3 satır: j hep 2
  3. 3 satır: j hep 3
  4. Hiçbir şey: continue döngüden çıkar

İpucu: break döngüden çıkar; continue sıradaki tura geçer.

Cevap

B) 3 satır, j hep 2. continue yalnızca iç döngünün o turunu atlar.

İç İçe Döngüler · Adım adım

Soru 8: continue Turu Atlar

Dış döngü i = 1, iç döngü j = 2 ile başlar. 2 == 3 yanlış → i: 1 j: 2 yazılır.

j == 3 → true: continue yazdırmayı atlar, j++ ile iç döngünün koşuluna döner; j = 4, 4 < 4 yanlış → iç döngü biter.

Dış döngü i = 2, iç döngü j = 2 ile başlar. 2 == 3 yanlış → i: 2 j: 2 yazılır.

j == 3 → true: continue yazdırmayı atlar, j++ ile iç döngünün koşuluna döner.

Dış döngü i = 3, iç döngü j = 2 ile başlar. 2 == 3 yanlış → i: 3 j: 2 yazılır.

j == 3 → true: continue yazdırmayı atlar, j++ ile iç döngünün koşuluna döner.

i = 4: 4 < 4 yanlış, program biter. 6 turdan 3’ü yazdı. Cevap: B.

Soru 9

public class Ornek9 {
  public static void main(String args[]) {
    int num = 0;
    switch (num) {
      default:
        System.out.println("default");
      case 0:
        System.out.println("case1");
      case 10 * 2 - 20:
        System.out.println("case2");
        break;
    }
  }
}
Program derlenir mi? Derlenirse ne yazar?
  1. default, case1, case2
  2. case1, case2
  3. case1
  4. Derleme hatası

İpucu: case değeri bir sabit ifadedir; derleyici onu hesaplar.

Cevap

D) Derleme hatası. 10 * 2 - 20 derleme anında 0 olarak hesaplanır; case 0 iki kez yazılmış olur.

Çoklu Seçim

Soru 9: Yinelenen case Etiketi

Sabit ifade (constant expression)

case etiketine yalnızca derleme anında değeri bilinen ifadeler yazılır. Derleyici 10 * 2 - 20’yi 0 olarak hesaplar.

Her değer bir kez

Bir switch’te aynı değer iki etikette olamaz: case 0 ve case 10 * 2 - 20 çakışır. Program hiç çalışmaz.

default nerede olursa olsun

default en başta da yazılabilir; yalnızca hiçbir case eşleşmezse oraya atlanır.

Derleyici
Ornek9.java:9: error: duplicate case label
      case 10 * 2 - 20:
      ^
1 error
Etiketi case 10 * 2 - 10: (yani 10) yapınca program derlenir. Bir sonraki slayt, bu hâli üç farklı num değeriyle izler.

Çoklu Seçim · Adım adım

Düzeltilmiş Hâl: Etiketten Etikete Düşme

num = 0 → case 0 etiketine atlanır; default atlanır.

break yok: case1 yazıldıktan sonra case2’ye düşer; break ile çıkar.

num = 5 hiçbir case ile eşleşmez → default’a atlanır.

break olmadığı için alttaki etiketlere düşer (fall-through): üç satır yazılır, break durdurur. Etiketler yalnızca giriş noktasıdır.

        System.out.println("case1");
      case 10 * 2 - 10:
        System.out.println("case2");
        break;
    }
  }
  public static void main(String args[]) {
    dene(0);
    dene(5);
  }

Atama Koşulu Ne Zaman Derlenir?

Yalnızca boolean ile

if koşulu boolean olmalıdır. boolean bir değişkene atama yapılırsa sonuç da boolean olduğundan kod sessizce derlenir ve hep aynı dala girer.

int ile derlenmez

C’den farklı olarak Java, sayıyı koşul olarak kabul etmez: if (sayi = 5) derleme hatasıdır.

Güvenli yazım

boolean değişkeni == true ile karşılaştırmayın, doğrudan yazın: if (myVal), if (!myVal). Böylece = yazım hatasına yer kalmaz.

public class Ornek10Int {
  public static void main(String args[]) {
    int sayi = 0;
    if (sayi = 5) {
      System.out.println("beş");
    }
  }
}

Soru 11: do-while En Az Bir Kez

i = 10.

do gövdesine koşulsuz girilir. İç while: 10 < 15 doğru.

i = 10 + 20 = 30.

30 < 15 yanlış: iç döngü biter (yalnızca bir tur döndü).

Şimdi do-while koşulu sınanır: 30 < 2 yanlış → dış döngüden çıkılır.

println(i) → 30. Cevap: B.

public class Ornek11 {

    int i = 10;

      while (i < 15) {
        i = i + 20;
      }
    } while (i < 2);
    System.out.println(i);
  }
}

Sık Yapılan Hatalar (1): Derleme Hataları

Çift tırnakla char

char d = "d"; → error: incompatible types: String cannot be converted to char. Tek tırnak: 'd'.

f’siz float

float f = 3.1415; → error: incompatible types: possible lossy conversion from double to float.

Aynı değerde iki case

case 0 ve case 10 * 2 - 20 → error: duplicate case label.

this(...) ikinci satırda

Önce println, sonra this("beyaz") → error: call to this must be first statement in constructor.

Sayıyı koşul yapmak

if (sayi = 5) → error: incompatible types: int cannot be converted to boolean.

static bağlamdan örnek üyesi

main’den static olmayan yaz() çağrısı → error: non-static method yaz() cannot be referenced from a static context.

Özet

Sık Yapılan Hatalar (2): Derlenir ama Yanlış

Metot argümanı değiştirir sanmak

sayiyaEkle(a, b) sonrası a aynı kalır. Sonucu return ile döndürüp atayın.

if içinde =

boolean değişkenle if (myVal = true) derlenir ve her zaman doğru dala girer. if (myVal) yazın.

break unutmak

switch’te break yoksa eşleşen etiketten sonrakiler de çalışır (düşme). Her case’i break ile bitirin.

Alanı yerelle gölgelemek

Alanla aynı adlı yerel değişken, alanı gizler. Okunurluk için farklı ad seçin ya da Ornek5.i / this.renk yazın.

Bir ifadede ++ ile oynamak

a == a++, x++ + ++x gibi ifadeler doğru ama okunmazdır. Artırmayı ayrı satıra yazın.

continue ↔ break

continue sıradaki tura geçer, break döngüyü bitirir. İç içe döngülerde yalnızca en içteki döngüyü etkilerler.

static void tasi(Nokta p) {
  p.x = 5;
  p = new Nokta();

n.x = 1;

  2. 5. p.x = 5, n’nin gösterdiği nesneyi değiştirir. p = new Nokta() yalnızca kopya referansı yeni nesneye çevirir; p.x = 9 o yeni nesneye yazılır.
