Programlama Dilleri

Programlama Dili Nedir?

  • Programlama dili (programming language): bir makinenin yapabileceği hesaplamaları ifade etmek için tasarlanmış yapay bir dildir.
  • Makinenin davranışını kontrol eden programlar yazmak için kullanılır:
    • algoritmaları açık ve kesin biçimde ifade etmek için,
    • programcılar arasında bir iletişim aracı olarak.
  • Bilgisayarlara, telefonlara ve gömülü cihazlara işlevsellik kazandırır.
  • Soyutlama düzeyine göre: makine dili ve assembly düşük seviyeli; Java, Python yüksek seviyeli.
  • Dil seçimi projenin ihtiyaçlarına göre yapılır.
  • Örnekler: C, C++, Java, Python, Prolog, Haskell, Scala…

Programlama Dilleri

Genel Amaçlı ve Hedefe Odaklı

  • Diller, uygulama alanına göre genel amaçlı (general-purpose) ya da hedefe odaklı (targeted, domain-specific) olabilir.

Genel amaçlı

  • Çok çeşitli uygulamaları destekleyen geniş bir temel komut kümesi.
  • Java, C, C++, Python: masaüstü, web, mobil, gömülü sistem…

Hedefe odaklı

  • Belirli bir uygulama türüne odaklanır, o işlemleri kolaylaştırır.
  • MATLAB: sayısal hesaplama; matris ve vektör işlemleri optimize. SQL: veri tabanı sorguları.

Programlama Paradigmaları

Paradigma (paradigm): bir problemi çözerken izlenen temel yaklaşım. Diller, problemi farklı yaklaşımlarla çözebilir.

Buyruksal (imperative)Programcı makineye, durumunu nasıl değiştireceğini adım adım söyler. FORTRAN, BASIC, Pascal, C…
Fonksiyonel (functional)Hesaplamayı matematiksel fonksiyonların değerlendirilmesi olarak ele alır; durum değiştirmekten kaçınır. Lisp, Scheme, Haskell…
Mantıksal (logic)Hesaplamanın mantığını (olgular ve kurallar) açıklar; kontrol akışını ayrıntılandırmaz. Prolog
Nesne yönelimli (object-oriented)İlişkili veri ve metotları bir nesne altında toplar; komutlar, üzerinde çalıştıkları durumla birlikte gruplanır. C++, Java, C#, Python…
Java temelde nesne yönelimli ve buyruksaldır; Java 8'den beri fonksiyonel öğeler (lambda, akışlar) de içerir. Birden çok paradigmayı destekleyen dillere çok paradigmalı denir.

Programlama Dilleri

Aynı Problem: Buyruksal ve Fonksiyonel

Problem: 1'den 5'e kadar sayıların toplamını bul.

import java.util.stream.IntStream;

public class Paradigma {
    public static void main(String[] args) {
        // Buyruksal: adım adım durum değiştir
        int toplam = 0;
        for (int i = 1; i <= 5; i++) {
            toplam = toplam + i;
        }
        System.out.println("Buyruksal: " + toplam);

        // Fonksiyonel (Java 8+): ne istediğini söyle
        int sonuc = IntStream.rangeClosed(1, 5).sum();
        System.out.println("Fonksiyonel: " + sonuc);
    }
}

Çıktı

Buyruksal: 15
Fonksiyonel: 15
  • Buyruksal: toplam değişkeni her adımda değiştirilir; “nasıl” yapılacağı yazılır.
  • Fonksiyonel: “1..5 aralığının toplamı” istenir; değişken güncellenmez.

Programlama Dilleri · Adım adım kod izleme

Buyruksal ve Fonksiyonel: Kod İzleme

Buyruksal yaklaşımda toplam adlı bir durum değişkeni 0 ile başlar.

i = 1: 1 <= 5 doğru → toplam = 0 + 1 = 1. Durum her turda değişir.

i = 2: 2 <= 5 doğru → toplam = 1 + 2 = 3.

i = 3: 3 <= 5 doğru → toplam = 3 + 3 = 6.

i = 4: 4 <= 5 doğru → toplam = 6 + 4 = 10.

i = 5: 5 <= 5 doğru → toplam = 10 + 5 = 15.

i 6 oldu: 6 <= 5 yanlış → döngü biter.

Sonuç yazdırılır: beş turda biriken toplam 15.

Fonksiyonel: rangeClosed(1, 5) 1…5 sayılarını üretir, sum() hepsini toplar. Hiçbir değişken adım adım güncellenmez.

İki yaklaşım aynı sonucu verir; fark, nasıl yapılacağını mı yoksa ne istendiğini mi yazdığımızdadır.

int toplam = 0;
for (int i = 1; i <= 5; i++) {
    toplam = toplam + i;
}
System.out.println("Buyruksal: " + toplam);

int sonuc = IntStream.rangeClosed(1, 5).sum();
System.out.println("Fonksiyonel: " + sonuc);

Yalnızca olgular ve bir kural verilir; sorunun nasıl çözüleceğine (arama sırasına) Prolog kendisi karar verir.

Dikdortgen nesnesi hem veriyi (en, boy) hem de o veri üzerinde çalışan metodu (alan()) taşır.

Nesne yönelimli · Java

public class Dikdortgen {
    double en, boy;          // veri (durum)

    Dikdortgen(double en, double boy) {
        this.en = en;
        this.boy = boy;
    }

    double alan() {          // davranış
        return en * boy;
    }

    public static void main(String[] args) {
        Dikdortgen d = new Dikdortgen(3, 4);
        System.out.println("Alan: " + d.alan());
    }
}

Çıktı

Alan: 12.0

Programlama Dilleri · Adım adım kod izleme

Nesne Yönelimli: Kod İzleme

main çalışmaya başlar. Yığında main çerçevesi var; d henüz bir nesneyi göstermiyor.

new heap'te nesneye yer ayırır; alanlar varsayılan 0.0. Yapıcı çağrılır: 3 ve 4, double'a genişletilir.

this.en nesnenin alanıdır, sağdaki en parametredir: alan 3.0 olur.

boy alanı 4.0 olur. Yapıcı biter, çerçevesi yığından kalkar.

new ifadesinin değeri nesnenin referansıdır; d artık bu nesneyi gösterir.

d.alan(): this ile d aynı nesneyi gösterir. en * boy = 3.0 × 4.0 = 12.0 döndürülür.

Dönen 12.0 dizgiyle birleştirilir: Alan: 12.0. Veri (en, boy) ve davranış (alan) aynı nesnede durur.

public class Dikdortgen {
    double en, boy;
    Dikdortgen(double en, double boy) {
        this.en = en;
        this.boy = boy;
    }
    double alan() {
        return en * boy;
    }
    public static void main(String[] args) {
        Dikdortgen d = new Dikdortgen(3, 4);
        System.out.println("Alan: " + d.alan());
    }
}

Söz Dizimi ve Anlam

Statik Anlam

  • Statik anlam (static semantics): söz dizimi doğru olan bir ifadenin anlamlı olup olmadığını, program çalışmadan önce denetler.
  • İngilizce: “I are big” biçim olarak <isim> <fiil> <isim> kalıbına uyar; ama “I” tekil, “are” çoğuldur → dil açısından geçersiz.
  • Java: <değer> <işleç> <değer> geçerli bir kalıptır; ama bir sayıyı bir dizgiye bölmenin anlamı yoktur → statik anlam hatası.
double sonuc = 2.3 / "abc";
error: bad operand types for binary operator '/'
  first type:  double
  second type: String
int x = "beş";
error: incompatible types:
  String cannot be converted to int
Java statik tipli bir dildir: derleyici her operatörün işlenenlerinin tipini denetler. Bu tür hatalar program hiç çalışmadan yakalanır.

Söz Dizimi ve Anlam

Anlam (Semantics)

  • Anlam (semantics): söz dizimi doğru bir ifadenin ne anlama geldiğini belirler.
  • Doğal dillerde çok anlamlılık olabilir: “They saw the man with the telescope.”
    • adamı teleskopla gördüler, ya da
    • teleskobu olan adamı gördüler.
  • Programlama dilinde her geçerli ifadenin tek bir anlamı vardır.
  • Ancak bu anlam, programcının beklediği şey olmayabilir: yanlış bir işlem beklenmeyen bir sonuç üretir.
int a = 7, b = 8;
int ortalama = (a + b) / 2;
System.out.println(ortalama);       // 7.5 beklenirken
System.out.println(a + b / 2);      // öncelik
System.out.println((a + b) / 2.0);  // doğru

Çıktı

7
11
7.5

7 ile 8'in ortalaması 7.5'tir. İlk satır tam sayı bölmesi yapar, ikinci satırda / işlemi +'dan önce yapılır. Derleyici bu satırlarda hata görmez.

Söz Dizimi ve Anlam · Adım adım kod izleme

Anlam Hatası: Kod İzleme

a = 7, b = 8; ikisi de int. Ağaç, (a + b) / 2 ifadesinin yapısını gösterir.

Parantez önce: a + b = 15 (int).

15 / 2: iki işlenen de int → tam sayı bölmesi, kesir atılır: 7.

7 yazılır. Program hatasız çalıştı ama anlamı beklenenden farklı.

Parantez yok: / önceliği + operatöründen yüksek. Önce b / 2 = 4.

Sonra 7 + 4 = 11 yazılır.

2.0 bir double: 15 de double'a genişletilir, 15 / 2.0 = 7.5.

int a = 7, b = 8;
int ortalama = (a + b) / 2;
System.out.println(ortalama);       // 7.5 değil
System.out.println(a + b / 2);      // öncelik
System.out.println((a + b) / 2.0);  // doğru

İfadeler ve Değişkenler · Adım adım

İfade Değerlendirme Adım Adım

Bilgisayar bir ifadeyi tek seferde değil, öncelik kurallarına göre adım adım sadeleştirir.

(72 - 32) / 9 * 5

Önce parantez içi hesaplanır: 72 − 32 = 40.

40 / 9 * 5

/ ile * aynı önceliktedir → soldan sağa: önce 40 / 9.

4 * 5 (40 / 9 = 4, kalan 4 atıldı)

İki işlenen de int → tam sayı bölmesi: 4.44… değil, 4.

20

Sonuç 20. Matematiksel olarak beklenen 22.22… idi: bir anlam (mantık) hatası.

(72.0 - 32) / 9 * 5

Şimdi 72.0 yazalım: double − int işleminde int önce double'a genişletilir; sonuç 40.0.

40.0 / 9 * 5

40.0 / 9 artık gerçek bölmedir: 4.444444444444445.

4.444444444444445 * 5

Çarpma: double × int → double.

22.22222222222222

Doğru sonuç. Ondalıklı sonuç gerekiyorsa işlenenlerden en az biri double olmalıdır.

İfade ağacı: alttaki işlem önce yapılır; numaralar işlem sırasıdır.

İfadeler ve Değişkenler

Dinamik ve Statik Tipleme

Dinamik tipli diller (Python, JavaScript)

  • Değişkenin tipi önceden belirtilmez; değer atanınca belirlenir.
  • Tip çalışma zamanında değişebilir.
  • Esneklik sağlar, ama hatalar ancak çalışırken ortaya çıkar.

Statik tipli diller (Java, C, C#)

  • Değişkenin tipi açıkça belirtilir ve değişmez.
  • Dizgi ile tam sayı gibi uyumsuz işlemler derleme zamanında hata olarak bulunur.
  • Daha güvenli; derleyici hızlı kod üretebilir.

Python

x = 5          # x şimdi int
x = "beş"      # artık str: sorun yok
print(x + 1)   # çalışırken:
# TypeError: can only concatenate
#   str (not "int") to str

Java

int x = 5;
x = "beş";     // derlenmez:
// error: incompatible types:
//   String cannot be converted to int

Java 10+: var adet = 3; tipi yazmadan tanımlar, ama tip yine derlemede (int olarak) sabitlenir; Java statik tipli kalır.

  • Diller, tiplerin karşılaştırılması için kurallar ve tip dönüşümü (type conversion) yolları tanımlar.

Program ve Algoritma · Adım adım kod izleme

Bir Program Nedir? Sıra Önemlidir

Program bir talimatlar dizisidir; bilgisayar talimatları birer birer ve sırayla işler. Bu yüzden işlem sırasını doğru belirlemek önemlidir.

Amaç: a ile b'nin değerlerini takas etmek (yer değiştirmek).

a = b: a'ya 5 yazılır. a'nın eski değeri 3 kayboldu!

b = a: b'ye a'nın şimdiki değeri (5) yazılır.

Çıktı 5 5: takas başarısız. Deyimlerin sırası sonucu belirler.

Doğru yöntem: üçüncü bir geçici değişken.

c'nin değeri önce gecici'de saklanır.

Artık c'nin üzerine yazılabilir: c = 5.

d'ye saklanan eski c değeri (3) yazılır.

Çıktı 5 3: takas başarılı.

int a = 3, b = 5;
a = b;
b = a;
System.out.println(a + " " + b);

int c = 3, d = 5;
int gecici = c;
c = d;
d = gecici;
System.out.println(c + " " + d);

Program ve Algoritma

İfadeler, Deyimler ve Programlar

İfade (expression) → değerBir değeri hesaplar ve sonucunu döndürür: 3 + 4 ifadesinin değeri 7'dir.
Deyim (statement) → etkiBir etki yaratır: pi = 3.14159; değişkene değer atar, System.out.println(pi); ekrana yazar. Java'da deyimler ; ile biter.

Örnek Problemler

  1. Değerlerini bulun: (a) 10 + 6 / 4 * 2 (b) (10 + 6) / 4 * 2 (c) 10 + 6 / 4.0 * 2
  2. Çıktıları nedir? System.out.println("Toplam: " + 2 + 3); ve System.out.println(2 + 3 + " toplam");
  3. Kod çalıştıktan sonra a ve b kaçtır? int a = 4; int b = a * 3; a = b - a; b = b / a;
  4. Hata türünü söyleyin: (a) int n = 4.5; (b) System.out.println("Merhaba"; (c) dairenin alanı için alan = 2 * pi * r;
  5. double c = (f - 32) * 5 / 9; ile f = 100 için sonuç nedir? f ve c int olsaydı?
Cevapları göster
  1. (a) 6 / 4 = 1, 1 * 2 = 2 → 12 (b) 16 / 4 = 4, 4 * 2 → 8 (c) 6 / 4.0 = 1.5, × 2 = 3.0 → 13.0
  2. Toplam: 23 (soldan sağa birleştirme) ve 5 toplam (önce iki int toplanır).
  3. b = 12, a = 12 − 4 = 8, b = 12 / 8 = 1 (tam sayı bölmesi) → a = 8, b = 1.
  4. (a) statik anlam: possible lossy conversion from double to int (b) söz dizimi: ')' or ',' expected (c) mantık hatası: derlenir ama çevreyi hesaplar; doğrusu pi * r * r.
  5. 68 × 5 / 9 = 37.77777777777778. int ile: 340 / 9 = 37 (kesir atılır).

Özet

Alıştırmalar

  1. Değerlerini ve tiplerini yazın: 7 % 3, -7 / 2, 1 / 3 * 3, 1.0 / 3 * 3, Math.pow(2, 10).
  2. Hangileri geçerli değişken adıdır? toplam2, 2toplam, _sayac, ogrenci sayisi, $fiyat, int, ortalamaNot
  3. Kullanıcıdan Fahrenhayt değeri okuyup Celsius'a çeviren programın önce algoritmasını, sonra Java kodunu yazın.
  4. Şunları ifade ya da deyim olarak sınıflandırın: x * 2, x = 5;, x > 3, System.out.println(x);
  5. 5 / 9 * (f - 32) ifadesi int f = 100 için neden 0 verir? İki farklı biçimde düzeltin.
Cevaplar / ipuçları
  1. 1 (int), -3 (int, sıfıra doğru kesilir), 0 (int: 1 / 3 = 0), 1.0 (double), 1024.0 (double).
  2. Geçerli: toplam2, _sayac, $fiyat, ortalamaNot. Geçersiz: 2toplam (rakamla başlar), ogrenci sayisi (boşluk), int (anahtar kelime).
  3. Oku → c = (f - 32) * 5 / 9 → yazdır; double f = giris.nextDouble();. 100 → 37.77777777777778.
  4. İfadeler: x * 2, x > 3 (değer üretir). Deyimler: x = 5;, System.out.println(x); (etki yaratır).
  5. 5 / 9 tam sayı bölmesiyle 0'dır, 0 × 68 = 0. Çözüm: 5.0 / 9 * (f - 32) ya da (f - 32) * 5 / 9 (önce çarpma: 37).
