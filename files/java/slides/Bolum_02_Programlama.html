Programlama Dilleri

Programlama Dili Nedir?

  • Programlama dili (programming language): bir makinenin gerçekleştirebileceği hesaplamaları ifade etmek için tasarlanmış yapay bir dildir.
  • Makinenin davranışını kontrol eden programlar yazmak için kullanılır:
    • algoritmaları açık ve kesin biçimde ifade etmek için,
    • programcılar arasında bir iletişim aracı olarak.
  • Bilgisayarlara, telefonlara ve gömülü cihazlara işlevsellik kazandırır.
  • Algoritmaların ve mantıksal süreçlerin ifadesidir.
  • Dil seçimi projenin ihtiyaçlarına göre yapılır.
  • Örnekler: C, C++, Java, Python, Prolog, Haskell, Scala…

Programlama Dilleri

Soyutlama Seviyeleri

  • Diller, düşük seviyeden yüksek seviyeye farklı soyutlama (abstraction) düzeylerindedir.
  • Düşük seviye diller (ör. Assembly) neredeyse makine düzeyinde çalışır; komutları çok basittir: “belleği oku”, “topla”, “yaz”.
  • Yüksek seviye diller (ör. C, Java, Python) zengin bir komut kümesi sunar; programcı yazmaçları (register) ve bellek adreslerini düşünmez.
  • Soyutlama arttıkça kod kısalır ve okunur; dönüştürme işini derleyici yapar.

Yüksek seviye · Java

int toplam = a + b;

Düşük seviye · x86 Assembly

add eax, [ebp-4]    ; b'yi ekle
mov [ebp-12], eax   ; sonucu toplam'a yaz

Programlama Dilleri

Java: Önce Derlenir, Sonra JVM'de Çalışır

Programcı kaynak kodu (source code) yazar. Dosyanın adı, içindeki public sınıfın adıyla aynı olmalıdır.

javac derleyicisi kodu denetler: sözdizimi ve tür hataları bu aşamada bulunur. Hata varsa çıktı dosyası üretilmez.

Sonuç makine kodu değil, bytecode'dur: hiçbir işlemciye özgü olmayan, Java Sanal Makinesi (JVM) için ara kod.

java Merhaba komutu JVM'i başlatır. JVM bytecode'u yorumlar; sık çalışan kısımları JIT (Just-In-Time) derleyicisiyle makine koduna çevirir.

Aynı .class dosyası Windows, Linux ya da macOS'taki her JVM'de çalışır: “Bir kez yaz, her yerde çalıştır” (WORA).

Merhaba.java

public class Merhaba {
    public static void main(String[] args) {
        System.out.println("Merhaba, Java!");
    }
}

Komut satırı

> javac Merhaba.java
> java Merhaba
Merhaba, Java!

Programlama Dilleri

Programlama Paradigmaları

Paradigma (paradigm): bir problemi çözerken izlenen temel yaklaşım. Diller, problemi farklı yaklaşımlarla çözebilir.

Buyruksal (imperative)Programcı makineye, durumunu nasıl değiştireceğini adım adım söyler. FORTRAN, BASIC, Pascal, C…
Fonksiyonel (functional)Hesaplamayı matematiksel fonksiyonların değerlendirilmesi olarak ele alır; durum değiştirmekten kaçınır. Lisp, Scheme, Haskell…
Mantıksal (logic)Hesaplamanın mantığını (olgular ve kurallar) açıklar; kontrol akışını ayrıntılandırmaz. Prolog
Nesne yönelimli (object-oriented)İlişkili veri ve metotları bir nesne altında toplar; komutlar, üzerinde çalıştıkları durumla birlikte gruplanır. C++, Java, C#, Python…
Java temelde nesne yönelimli ve buyruksaldır; Java 8'den beri fonksiyonel öğeler (lambda, akışlar) de içerir. Birden çok paradigmayı destekleyen dillere çok paradigmalı denir.

Programlama Dilleri

Aynı Problem: Buyruksal ve Fonksiyonel

Problem: 1'den 5'e kadar sayıların toplamını bul.

import java.util.stream.IntStream;

public class Paradigma {
    public static void main(String[] args) {
        // Buyruksal: adım adım durum değiştir
        int toplam = 0;
        for (int i = 1; i <= 5; i++) {
            toplam = toplam + i;
        }
        System.out.println("Buyruksal: " + toplam);

        // Fonksiyonel (Java 8+): ne istediğini söyle
        int sonuc = IntStream.rangeClosed(1, 5).sum();
        System.out.println("Fonksiyonel: " + sonuc);
    }
}

Çıktı

Buyruksal: 15
Fonksiyonel: 15
  • Buyruksal: toplam değişkeni her adımda değiştirilir; “nasıl” yapılacağı yazılır.
  • Fonksiyonel: “1..5 aralığının toplamı” istenir; değişken güncellenmez.

Dikdortgen nesnesi hem veriyi (en, boy) hem de o veri üzerinde çalışan metodu (alan()) taşır. Sınıf ve nesneler Bölüm 4'te işlenir.

Nesne yönelimli · Java

public class Dikdortgen {
    double en, boy;          // veri (durum)

    Dikdortgen(double en, double boy) {
        this.en = en;
        this.boy = boy;
    }

    double alan() {          // davranış
        return en * boy;
    }

    public static void main(String[] args) {
        Dikdortgen d = new Dikdortgen(3, 4);
        System.out.println("Alan: " + d.alan());
    }
}

Çıktı

Sözdizimi ve Anlam

Statik Anlam

  • Statik anlam (static semantics): sözdizimi doğru olan bir ifadenin anlamlı olup olmadığını, program çalışmadan önce denetler.
  • İngilizce: “I are big” biçim olarak <isim> <fiil> <isim> kalıbına uyar; ama “I” tekil, “are” çoğuldur → dil açısından geçersiz.
  • Java: <değer> <işleç> <değer> geçerli bir kalıptır; ama bir sayıyı bir dizgeye bölmenin anlamı yoktur → statik anlam hatası.
double sonuc = 2.3 / "abc";
error: bad operand types for binary operator '/'
  first type:  double
  second type: String
int x = "beş";
error: incompatible types:
  String cannot be converted to int
Java statik tipli bir dildir: derleyici her işlecin işlenenlerinin türünü denetler. Bu tür hatalar program hiç çalışmadan yakalanır.

Sözdizimi ve Anlam

Anlam (Semantics)

  • Anlam (semantics): sözdizimi doğru bir ifadenin ne anlama geldiğini belirler.
  • Doğal dillerde çok anlamlılık olabilir: “They saw the man with the telescope.”
    • adamı teleskopla gördüler, ya da
    • teleskobu olan adamı gördüler.
  • Programlama dilinde her geçerli ifadenin tek bir anlamı vardır.
  • Ancak bu anlam, programcının beklediği şey olmayabilir: yanlış bir işlem beklenmeyen bir sonuç üretir.
int a = 7, b = 8;
int ortalama = (a + b) / 2;
System.out.println(ortalama);       // 7.5 beklenirken
System.out.println(a + b / 2);      // öncelik
System.out.println((a + b) / 2.0);  // doğru

İfadeler ve Değişkenler

İfadeler ve İşlem Önceliği

  • İfade (expression): bir hesaplamayı tanımlayan, bir değer üreten yapıdır: 3 + 4, x * 2.
  • İfadeler belirli kurallarla değerlendirilir; işleçlerin önceliği (precedence) ve yönü (associativity) tanımlıdır.
  • Çarpma, bölme ve kalan; toplama ve çıkarmadan önce yapılır.
  • Aynı öncelikteki işleçler soldan sağa işlenir: 10 - 4 - 3 = 3.
  • Öncelikleri değiştirmek için parantez kullanılır: (2 + 3) * 4 = 20.

Değişkenler

  • Değişken (variable): programda değerleri saklamak ve yönetmek için kullanılan, adı olan bir bellek alanıdır.
  • Değişkenler program içindeki verilere bir başvuru (ad) sağlar: değeri her yerde adıyla kullanırız.
  • Değer atamak için değişkenAdı = ifade yazılır. Java'da değişken önce türüyle tanımlanır:
double pi = 3.14;      // tanımla ve ata
int sayac = 10;
String ad = "Ayşe";
sayac = sayac + 1;     // içerik değişir: 11
double pi = 3.14; → pi adlı, double türünde bir kutu oluşturulur ve içine 3.14 yazılır. Kutunun türü sonradan değişmez, içeriği değişebilir.

Dinamik ve Statik Tipleme

Dinamik tipli diller (Python, JavaScript)

  • Değişkenin türü önceden belirtilmez; değer atanınca belirlenir.
  • Tür çalışma zamanında değişebilir.
  • Esneklik sağlar, ama hatalar ancak çalışırken ortaya çıkar.

Statik tipli diller (Java, C, C#)

  • Değişkenin türü açıkça belirtilir ve değişmez.
  • Dizge ile tamsayı gibi uyumsuz işlemler derleme zamanında hata olarak bulunur.
  • Daha güvenli; derleyici hızlı kod üretebilir.

Python

x = 5          # x şimdi int
x = "beş"      # artık str: sorun yok
print(x + 1)   # çalışırken:
# TypeError: can only concatenate
#   str (not "int") to str

Java

int x = 5;
x = "beş";     // derlenmez:
// error: incompatible types:
//   String cannot be converted to int

Java 10+: var adet = 3; türü yazmadan tanımlar, ama tür yine derlemede (int olarak) sabitlenir; Java statik tipli kalır.

İfadeler ve Değişkenler

Atama İşlemi

  • Atama (assignment) bir değişkenin değerini değiştirmek için kullanılır.
  • Atama iki adımda gerçekleşir:
    1. Sağ taraftaki ifade hesaplanır.
    2. Değişkenin içeriği hesaplanan yeni değerle güncellenir; eski değer kaybolur.
  • x = 5; → sağdaki 5 değerlendirilir ve x adlı değişkende saklanır.
  • = matematikteki eşitlik değildir: x = x + 1 cebirde çelişkidir, programda ise “x'i bir artır” demektir.
  • Sol tarafta yalnızca bir değişken olabilir: 5 = x; derlenmez (unexpected type).

Önce: x = 7

x = x + 1; çalıştıktan sonra

İfadeler ve Değişkenler · Kodu adım adım çalıştır

Atama: Kodu Adım Adım İzle

x için bellekte yer ayrılır ve içine 5 yazılır.

1. adım: sağ taraf hesaplanır. x'in o anki değeri (5) okunur: 5 + 3 = 8.

2. adım: sonuç x'e yazılır; eski değer 5 kaybolur.

x * 2 = 8 × 2 = 16 hesaplanır ve yeni değişken y'ye yazılır. x değişmez.

Sağ taraf: y - x = 16 − 8 = 8.

Sonuç x'e yazılır. Değer yine 8: atama yapıldı ama içerik değişmedi.

"x = " + x dizge birleştirmedir: x = 8 yazılır.

Program biter. Son değerler: x = 8, y = 16.

Kodlamadan Önce Algoritmayı Tasarla

  • Program yazılmadan önce problemin nasıl çözüleceği düşünülür ve bir algoritma tasarlanır.
  • Algoritmik düşünme: problemi çözme ve işlemleri doğru sıralama yeteneği. İyi bir algoritma programın verimli çalışmasını sağlar.
  • Kodlama, algoritmayı bilgisayarın anlayacağı sözdizimine çevirir ve onu gerçek bir programa dönüştürür.

Algoritma: iki sayının ortalaması

  1. Birinci sayıyı iste ve oku.
  2. İkinci sayıyı iste ve oku.
  3. ortalama ← (sayı1 + sayı2) / 2
  4. Ortalamayı yazdır.
import java.util.Scanner;

public class Ortalama {
    public static void main(String[] args) {
        Scanner giris = new Scanner(System.in);
        System.out.print("Birinci sayı: ");     // 1
        double sayi1 = giris.nextDouble();
        System.out.print("İkinci sayı: ");      // 2
        double sayi2 = giris.nextDouble();
        double ortalama = (sayi1 + sayi2) / 2;  // 3
        System.out.println("Ortalama: " + ortalama); // 4
        giris.close();
    }
}

Her algoritma adımı bir ya da iki Java satırına karşılık gelir. Scanner ile klavyeden okuma Bölüm 7'de ayrıntılı işlenir.

Örnek Problemler

  1. Değerlerini bulun: (a) 10 + 6 / 4 * 2 (b) (10 + 6) / 4 * 2 (c) 10 + 6 / 4.0 * 2
  2. Çıktıları nedir? System.out.println("Toplam: " + 2 + 3); ve System.out.println(2 + 3 + " toplam");
  3. Kod çalıştıktan sonra a ve b kaçtır? int a = 4; int b = a * 3; a = b - a; b = b / a;
  4. Hata türünü söyleyin: (a) int n = 4.5; (b) System.out.println("Merhaba"; (c) dairenin alanı için alan = 2 * pi * r;
  5. double c = (f - 32) * 5 / 9; ile f = 100 için sonuç nedir? f ve c int olsaydı?
Cevapları göster
  1. (a) 6 / 4 = 1, 1 * 2 = 2 → 12 (b) 16 / 4 = 4, 4 * 2 → 8 (c) 6 / 4.0 = 1.5, × 2 = 3.0 → 13.0
  2. Toplam: 23 (soldan sağa birleştirme) ve 5 toplam (önce iki int toplanır).
  3. b = 12, a = 12 − 4 = 8, b = 12 / 8 = 1 (tamsayı bölmesi) → a = 8, b = 1.
  4. (a) statik anlam: possible lossy conversion from double to int (b) sözdizimi: ')' or ',' expected (c) mantık hatası: derlenir ama çevreyi hesaplar; doğrusu pi * r * r.
  5. 68 × 5 / 9 = 37.77777777777778. int ile: 340 / 9 = 37 (kesir atılır).

Alıştırmalar

  1. Değerlerini ve türlerini yazın: 7 % 3, -7 / 2, 1 / 3 * 3, 1.0 / 3 * 3, Math.pow(2, 10).
  2. Hangileri geçerli değişken adıdır? toplam2, 2toplam, _sayac, ogrenci sayisi, $fiyat, int, ortalamaNot
  3. Kullanıcıdan Fahrenhayt değeri okuyup Celsius'a çeviren programın önce algoritmasını, sonra Java kodunu yazın.
  4. Şunları ifade ya da deyim olarak sınıflandırın: x * 2, x = 5;, x > 3, System.out.println(x);
  5. 5 / 9 * (f - 32) ifadesi int f = 100 için neden 0 verir? İki farklı biçimde düzeltin.
Cevaplar / ipuçları
  1. 1 (int), -3 (int, sıfıra doğru kesilir), 0 (int: 1 / 3 = 0), 1.0 (double), 1024.0 (double).
  2. Geçerli: toplam2, _sayac, $fiyat, ortalamaNot. Geçersiz: 2toplam (rakamla başlar), ogrenci sayisi (boşluk), int (anahtar kelime).
  3. Oku → c = (f - 32) * 5 / 9 → yazdır; double f = giris.nextDouble();. 100 → 37.77777777777778.
  4. İfadeler: x * 2, x > 3 (değer üretir). Deyimler: x = 5;, System.out.println(x); (etki yaratır).
  5. 5 / 9 tamsayı bölmesiyle 0'dır, 0 × 68 = 0. Çözüm: 5.0 / 9 * (f - 32) ya da (f - 32) * 5 / 9 (önce çarpma: 37).
