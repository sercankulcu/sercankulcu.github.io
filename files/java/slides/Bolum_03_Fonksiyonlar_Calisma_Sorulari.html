Soru 1: Parametre ve Argüman

Bu çağrı için hangisi doğrudur?

static int kare(int x) {
    return x * x;
}
// main içinde:
int a = 3;
int b = kare(a + 1);

B: Tanımdaki x parametre, çağrıdaki ifade argümandır. Argüman önce hesaplanır (4), değeri yeni çerçevedeki x'e kopyalanır; metot 16 döndürür ve b'ye 16 atanır. a 3 olarak kalır.

Soru 2: Geçerli Metot Başlığı

Aşağıdakilerden hangisi geçerli bir metot başlığıdır?

C: Sıra: düzenleyiciler, dönüş tipi, ad, parametre listesi. Her parametrenin kendi tipi yazılır (int a, b olmaz). Dönüş tipi zorunludur; yoksa yalnızca sınıfla aynı adlı yapıcı olabilir. Dönüş tipi düzenleyiciden önce yazılamaz.

Soru 3: return Kuralları

Aşağıdaki metotlardan hangisi derlenir?

A: void metotta tek başına return; metottan erken çıkar. İkincide iki koşul her durumu kapsasa da derleyici koşulların değerini düşünmez; sonda return olmadığı için missing return statement verir. void metot değer döndüremez; int metot da değersiz return; ile bitemez.

Soru 4: Hangi yaz Çalışır?

Aşırı yüklenmiş üç metot var. Dört çağrı ne yazdırır?

static void yaz(int a) {
    System.out.print("I");
}
static void yaz(long a) {
    System.out.print("L");
}
static void yaz(double a) {
    System.out.print("D");
}
// main içinde:
yaz(5); yaz(5L);
yaz(5.0f); yaz('A');

D: Derleyici argümanın tipine bakar: 5 int → I; 5L long → L. 5.0f float'tır; float sürümü olmadığı için en yakın genişletme double → D. 'A' char'dır; char önce int'e genişler → I. Seçim derleme zamanında yapılır.

Soru 5: Değer ile Aktarım İzleme

Metot da main de sayi adlı bir değişken kullanıyor. Çağrı yığınını izleyin. Program ne yazdırır?

main'in yerel sayi'sı 5.

Yeni çerçeve: parametre sayi, main'deki değerin kopyası. Adları aynı ama iki ayrı değişken.

Yalnızca kopya 15 olur.

Çerçeve kapanır. Dönen 15 hiçbir değişkene atanmadığı için kaybolur.

main'deki sayi hiç değişmedi.

İkinci çağrıda da kopya 15 olur.

Bu kez dönen değer main'deki sayi'ya atanır.

Bir metodun sonucu, yalnızca return ile alınıp atanırsa çağırana ulaşır.

static int arttir(int sayi) {
    sayi += 10;
    return sayi;
}
// main içinde:
int sayi = 5;
arttir(sayi);
System.out.println(sayi);
sayi = arttir(sayi);
System.out.println(sayi);

Soru 6: Öğrenci Numarasını Çözmek

Dokuz haneli numarada ilk iki hane kayıt yılı, sondan dördüncü hane bölüm kodu, son üç hane kayıt sırasıdır. Program ne yazdırır?

static int kayitYili(int no) {
    return no / 10000000 + 2000;
}
static int kayitSirasi(int no) {
    return no % 1000;
}
static String bolum(int no) {
    int kod = (no / 1000) % 10;
    if (kod == 7) return "Elektrik";
    if (kod == 6) return "Bilgisayar";
    return "Bilinmiyor";
}
// main içinde:
int no = 240706045;
System.out.println(kayitYili(no) + " "
        + kayitSirasi(no));
System.out.println(bolum(no) + " / "
        + bolum(no + 1000));
Cevabı göster 
2024 45
Bilgisayar / Elektrik
  • 240706045 / 107 = 24 → 2024. 240706045 % 1000 = 45: sayı baştaki sıfırı (045) tutmaz.
  • 240706045 / 1000 = 240706, % 10 = 6 → Bilgisayar. no + 1000 = 240707045 → kod 7.
  • Her metot tek bir iş yapar ve sonucunu döndürür; yazdırma işi main'de kalır.

Soru 7: Çağrı Yığını İzleme

Metotlar birbirini çağırıyor. Çerçevelerin açılıp kapanışını izleyin. Program ne yazdırır? Yığın en çok kaç çerçeve içerir?

main, fark(2, 3)'ü çağırır; 2 ve 3, a ve b'ye kopyalanır.

Çıkarmanın iki işleneni de gerekli; önce soldaki: kup(2).

n * kare(n) için kare(2) çağrılır.

En derin an: 4 çerçeve. kare(2) 4 döndürür.

kup(2) = 2 · 4 = 8 döner; çerçevesi kapanır.

Şimdi sağ işlenen: kare(3). Yeni çerçevenin kendi n'si 3, 9 döner.

8 − 9 = −1 döner.

Dönen −1 yazdırılır; yığında yalnızca main kaldı.

static int kare(int n) {
    return n * n;
}
static int kup(int n) {
    return n * kare(n);
}
static int fark(int a, int b) {
    return kup(a) - kare(b);
}
// main içinde:
System.out.println(fark(2, 3));

Soru 8: İç İçe Çağrılar

Bir metodun sonucu diğerinin argümanı oluyor. Program ne yazdırır?

static int usAl(int taban, int us) {
    int sonuc = 1;
    for (int i = 0; i < us; i++)
        sonuc *= taban;
    return sonuc;
}
static int faktoriyel(int n) {
    int sonuc = 1;
    for (int i = 2; i <= n; i++)
        sonuc *= i;
    return sonuc;
}
// main içinde:
System.out.println(faktoriyel(usAl(2, 2)));
System.out.println(usAl(faktoriyel(3), 2));
System.out.println(
        usAl(usAl(2, 2), faktoriyel(2)));
Cevabı göster 
24
36
16
  • Önce içteki çağrı çalışır: usAl(2, 2) = 4 → faktoriyel(4) = 24.
  • faktoriyel(3) = 6 → usAl(6, 2) = 36. Argümanların sırası önemlidir: usAl(2, 6) 64 olurdu.
  • Argümanlar soldan sağa hesaplanır: usAl(2, 2) = 4, faktoriyel(2) = 2 → usAl(4, 2) = 16.

Soru 9: Yanlış Kombinasyon

faktoriyel önceki sorudaki int sürümüdür. kombinasyon(5, 2) doğru sonucu (10) veriyor; kombinasyon(13, 2) ise 78 yerine 24 döndürüyor. Neden?

static int kombinasyon(int n, int r) {
    return faktoriyel(n)
         / (faktoriyel(r) * faktoriyel(n - r));
}

A: 13! = 6227020800, int sınırı (2147483647) aşılır ve sessizce 1932053504 olur. 2! · 11! = 79833600 int'e sığar; 1932053504 / 79833600 = 24. Çözüm: long kullanmak ya da C(n, r)'yi çarpıp bölerek adım adım hesaplamak.

Soru 10: Math ve Tam Sayı Bölmesi

System.out.println(Math.sqrt(16) + Math.max(3, 7) / 2); ne yazdırır?

B: Math.max(3, 7) iki int aldığı için int döndürür: 7. 7 / 2 tam sayı bölmesi: 3. Math.sqrt her zaman double döndürür: 4.0. 4.0 + 3 = 7.0.

Soru 11: Mutlak Değer ve Taşma

Kendi yazdığımız metot ile Math.abs karşılaştırılıyor. Program ne yazdırır?

static int mutlakDeger(int sayi) {
    if (sayi < 0) {
        return -sayi;
    } else {
        return sayi;
    }
}
// main içinde
System.out.println(mutlakDeger(-3) + " "
        + mutlakDeger(3));
System.out.println(
        mutlakDeger(Integer.MIN_VALUE));
System.out.println(Math.abs(Integer.MIN_VALUE));
System.out.println(Math.abs(-7.5));
System.out.println(
        Math.abs((long) Integer.MIN_VALUE));
Cevabı göster 
3 3
-2147483648
-2147483648
7.5
2147483648
  • int aralığı −2147483648 … 2147483647: en küçük değerin pozitifi int'e sığmaz. -sayi taşar ve yine −2147483648 olur; Math.abs(int) da aynı sonucu verir.
  • Math.abs aşırı yüklenmiştir: double argümanla double sürümü çağrılır (7.5), long argümanla long sürümü (2147483648 long aralığına sığar).

Soru 12: Hangi Kod Derlenir?

main içinde yazılan parçalardan hangisi derlenir?

D: Bir değişken tanımlandığı blokta yaşar. İki kardeş bloğun t'leri ayrı kapsamlardadır, çakışmaz. İç blok, dıştaki yerel değişkenle aynı adı kullanamaz (already defined). Döngü değişkeni döngüden sonra yoktur (cannot find symbol). Yerel değişken değer almadan okunamaz.

Soru 13: Gölgeleme İzleme

Sınıf alanı, parametre ve yerel değişken aynı adı taşıyor. Hangi x hangisi? Program ne yazdırır?

Sınıf alanı x program boyunca yaşar.

main'in yerel x'i alanı gölgeler: main içinde x bu değişkendir.

f'nin parametresi x, 5'in kopyası. Yerel kopya 15 olur; alana dokunulmaz.

f kendi x'ini yazar.

g'de bu adla yerel değişken yok: x sınıf alanını gösterir, alan 101 olur.

g alanın yeni değerini yazar: 101.

main'in x'i hâlâ 5. Gölgelenen alana Kapsam.x ile ulaşılır.

public class Kapsam {
    static int x = 1;
    static void f(int x) {
        x = x + 10;
        System.out.print(x + " ");
    }
    static void g() {
        x = x + 100;
        System.out.print(x + " ");
    }
    public static void main(String[] args) {
        int x = 5;
        f(x);
        g();
        System.out.println(x + " " + Kapsam.x);
    }
}

Soru 14: İyi Metot Tasarımı

Üç notun ortalaması için yazılan metotlardan hangisi iyi tasarım ilkelerine en uygundur?

C: İyi metot tek bir iş yapar, girdisini parametrelerle alır, sonucunu döndürür ve ne yaptığını anlatan bir ad taşır. Sonuç döndürüldüğü için başka hesaplarda da kullanılabilir. "Hesapla ve yaz", gizli alanlara bağımlılık ve anlamsız islem2 adı bu ilkeleri bozar.

Soru 15: Sonraki Asal Sayı

Problemi iki metoda bölün: boolean asalMi(int sayi) ve onu kullanan, n'den büyük ilk asal sayıyı döndüren int sonrakiAsal(int n). sonrakiAsal(20), sonrakiAsal(23) ve sonrakiAsal(1) kaçtır?

Cevabı göster 
static boolean asalMi(int sayi) {
    if (sayi < 2) return false;
    for (int i = 2; i * i <= sayi; i++)
        if (sayi % i == 0) return false;
    return true;
}
static int sonrakiAsal(int n) {
    int aday = n + 1;
    while (!asalMi(aday)) aday++;
    return aday;
}

Sonuçlar: 23, 29 (n'nin kendisi değil, ondan büyük ilk asal), 2.

sonrakiAsal, asallığın nasıl sınandığını bilmez; yalnızca asalMi'nin ne döndürdüğüne güvenir (fonksiyonel soyutlama). asalMi daha hızlı yazılsa da sonrakiAsal değişmez.

Soru 16: Asal Denetiminde Eksik Koşul

bulSonrakiAsal(20) doğru sonucu (23) veriyor. bulSonrakiAsal(0) ve bulSonrakiAsal(-4) ne döndürür?

static int bulSonrakiAsal(int sayi) {
    int sonraki = sayi + 1;
    while (!asalMi(sonraki)) {
        sonraki++;
    }
    return sonraki;
}
static boolean asalMi(int sayi) {
    for (int i = 2; i < sayi; i++) {
        if (sayi % i == 0) {
            return false;
        }
    }
    return true;
}

D: 2'den küçük sayılarda asalMi'nin döngüsü hiç dönmez ve true döndürür. bulSonrakiAsal(0) ilk aday 1'i "asal" kabul eder; bulSonrakiAsal(-4) ilk aday −3'ü. Doğru sonuç ikisinde de 2 olmalıydı (A). Düzeltme: asalMi'nin başına if (sayi < 2) return false;. bulSonrakiAsal değişmez; hata yalnızca kullandığı metottadır.
