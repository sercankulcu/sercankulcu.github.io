Sınıf ve nesne

Sınıfı bir taslak, nesneyi o taslaktan üretilmiş somut bir örnek olarak açıklamak; nitelik ve metotlarıyla bir sınıf yazmak.

Nesne oluşturmak

new işlecini ve yapıcı metotları (constructor) kullanmak; varsayılan değerleri ve varsayılan yapıcıyı bilmek.

Örnek ve sınıf üyeleri

Örneğe ait ve static nitelik/metotları ayırt etmek; başlatıcı bloklarının çalışma sırasını izlemek.

Referanslar

Değişkenin nesneyi değil referansı tuttuğunu bellek çizimiyle göstermek; this, == ve equals farkını açıklamak.

Erişim ve gizleme

Erişim düzenleyicileri, erişimci (get) ve değiştirici (set) metotlarla veri gizlemeyi uygulamak.

Özel sınıf türleri

Wrapper sınıfları, record, enum ve iç sınıfları tanımak; iyi bir sınıf tasarımının üç unsurunu açıklamak.

Nesne Yönelimli Programlama

Nesneler: Nitelik ve Davranış

  • Bir sınıfın üyeleri (members) vardır: nitelikler (fields), metotlar (methods) ve yapıcılar (constructors).
  • Nesneler veri saklar: bu veri parçalarına nitelik (alan, field) denir.
  • Nesneler işlem yapar: bu işlemlere davranış (metot, method) denir.
  • Veriyi ve o veri üzerinde çalışan kodu bir araya getirmek, programı daha düzenli, yeniden kullanılabilir ve sezgisel yapar.

Üç Temel Özellik

Sarmalama (Encapsulation)

Nesne, nitelik ve davranışlarının ayrıntısını diğer nesnelerden gizleyebilir. Dışarıya karşı kapalı bir kutu gibidir; yalnızca izin verilen metotlarla kullanılır.

Kalıtım (Inheritance)

Bir sınıf, başka bir sınıfın nitelik ve metotlarını miras alabilir. Kodun yeniden kullanımını ve sınıf hiyerarşisini sağlar.

Çok Biçimlilik (Polymorphism)

Bir nesne birden fazla biçim (tür) alabilir; aynı çağrı farklı nesnelerde farklı davranır. Esneklik ve dinamik davranış sağlar.

Bunlara çoğu zaman dördüncü olarak soyutlama (abstraction) eklenir: gereksiz ayrıntıyı gizleyip yalnızca önemli özellikleri göstermek. Bu bölüm temeli (sınıf ve nesne) kurar; sarmalama, kalıtım, çok biçimlilik ve soyut sınıflar sonraki bölümlerde ayrıntılı işlenir.

Sınıf ve Nesne

Sınıf: Nesnenin Taslağı

  • Sınıf (class), bir nesnenin taslağıdır (blueprint); bir sınıftan farklı verileri taşıyan birçok nesne üretilebilir.
  • Sınıf, nesnenin taşıyacağı verileri (nitelikler) ve yapabileceği işlemleri (metotlar) belirtir.
  • Bir nesne, bir sınıfın örneğidir (instance): sınıfın bellekteki somut hâlidir.
  • Sınıflar, gerçek dünyadaki varlıkları modellemeyi sağlar: bir Araba sınıfı her otomobili temsil edebilir; her marka ve model bu sınıftan üretilen bir nesnedir.

Benzetme: sınıf kurabiye kalıbı, nesneler o kalıpla kesilen kurabiyelerdir.

Sınıf ve Nesne

Sınıfın Üyeleri

Nitelikler (fields)

Nesnelerin taşıyabileceği verileri temsil eder. Örnek: bir Ogrenci sınıfında ad ve soyad.

Metotlar (methods)

Nesnelerin gerçekleştirebileceği işlemleri tanımlar. Örnek: bir Kopek sınıfında havla() ve kos().

Erişim düzeyi

Her üye private, protected, varsayılan (yazılmaz) veya public olabilir: kimin kullanabileceğini belirler.

Sahiplik

Her üye nesneye ait (instance, varsayılan) veya static ile sınıfa ait olabilir.

Yapıcı metotlar da sınıfın içinde yazılır; ama yalnızca nesne oluşturulurken çalışırlar ve teknik olarak metot değil, ayrı bir üye türüdür. Sınıfın içinde başka sınıflar (iç sınıflar) da tanımlanabilir.

Yapıcı Metotlar

Yapıcı Metotlar

  • Yapıcı metot (constructor), nesne oluşturmak için kullanılan özel bir metottur; new ile nesne oluşturulduğunda otomatik çağrılır.
  • Görevi, niteliklere ilk değerlerini vermek ve varsa başka hazırlık işlerini yapmaktır.
  • Adı sınıf adıyla aynıdır (büyük-küçük harf dahil).
  • Dönüş türü yoktur, void bile yazılmaz; değer döndüremez.
  • Genellikle public tanımlanır; nesne oluşturmayı kısıtlamak için private da olabilir (bkz. singleton).
  • Bir sınıfın birden çok yapıcısı olabilir (farklı parametrelerle).
public class Ogrenci {
  private String ad;
  private int numara;

  // Yapıcı: sınıfla aynı ad, dönüş türü yok
  public Ogrenci(String ad, int numara) {
    this.ad = ad;
    this.numara = numara;
  }
}

Yapıcı Metotlar

Referanslar

  • Bir nesne doğrudan kullanılamaz; ona yalnızca referans (reference, başvuru) ile erişilir. Değişkenlerde nesnenin kendisi değil, referansı saklanır.
  • Referans, nesnenin bellekte nerede olduğunu gösteren bir adres gibi düşünülebilir.
  • int, double, boolean gibi temel türlü değişkenler değeri kendileri tutar; sınıf türünden değişkenler (Araba, String, Scanner) referans tutar.
  • Hiçbir nesneyi göstermeyen referansın değeri null'dır.
Benzetme: değişken bir televizyon kumandası, nesne televizyondur. Kumandayı kopyalamak ikinci bir televizyon yaratmaz.

Yerel değişkenler yığında (stack), nesneler öbekte (heap) bulunur; ok = referans.

static Sayaç: Adım Adım

Sınıf belleğe yüklenirken static alan bir kez oluşur ve 0 olur. Henüz hiç nesne yok.

İlk nesne: kendi hesapSahibi kopyası "Ali" olur; ortak sayaç 1'e çıkar.

h1 birinci nesneyi gösterir.

İkinci nesnenin ayrı bir hesapSahibi alanı var; sayaç ise aynı alan: 2.

Üç nesne, üç hesapSahibi; ama tek toplamHesapSayisi = 3.

h2.hesapSahibi: örnek alanı nesne üzerinden okunur.

static metot sınıf adıyla çağrılır; this'i yoktur, yalnızca static alanı okur.

Dönen 3, sayi'ya atanır ve yazdırılır.

public class BankaHesabi {
  private String hesapSahibi;
  private static int toplamHesapSayisi = 0;

  public BankaHesabi(String hesapSahibi) {
    this.hesapSahibi = hesapSahibi;
    toplamHesapSayisi++;
  }

  public static int getToplamHesapSayisi() {
    return toplamHesapSayisi;
  }

  public static void main(String[] args) {
    BankaHesabi h1 = new BankaHesabi("Ali");
    BankaHesabi h2 = new BankaHesabi("Ayşe");
    BankaHesabi h3 = new BankaHesabi("Can");
    System.out.println(h2.hesapSahibi);
    int sayi = BankaHesabi.getToplamHesapSayisi();
    System.out.println(sayi);
  }
}

Başlatıcı Blokları

Sınıfa ait başlatıcı (static initializer)

static { ... } bloğu, sınıf belleğe ilk kez yüklenirken, yalnızca bir kez çalışır. Static alanlara karmaşık ilk değer vermek için kullanılır.

Örneğe ait başlatıcı (instance initializer)

{ ... } bloğu, her nesne oluşturulduğunda, yapıcının gövdesinden önce çalışır. Tüm yapıcılarda ortak olan işleri yapar.

Bir nesne oluşturulurken sıra: (1) sınıf ilk kez kullanılıyorsa static alanlar ve static bloklar → (2) new ile bellek ayrılır, alanlar varsayılan değer alır → (3) alan ilk değerleri ve örnek başlatıcı blokları (yazılış sırasıyla) → (4) yapıcının gövdesi.

Sonraki slayttaki Kopek sınıfında her ikisi de var; çıktının sırasını tahmin edip sonra adım adım izleyin. İpucu: havla()'nın döndürdüğü değer yazdırılmıyor; System.out.println(d2.havla()); yazılsaydı son satır "Gece haw haw haw!" olurdu.

Kopek: Başlatıcı Sırası

main çalışmadan önce sınıf yüklenir: static blok bir kez çalışır. (var, Java 10+: türü sağdan çıkarır; String... = String[].)

new Kopek("Kara"): nesne için yer ayrılır, adi = null.

Yapıcının gövdesinden önce örnek başlatıcı bloğu çalışır.

Şimdi yapıcı gövdesi: this.adi = adi.

Yapıcı adı yazdırır: Kara.

İkinci nesne: başlatıcı + yapıcı yeniden; static blok tekrar çalışmaz.

havla() bir metin döndürür ama değer kullanılmıyor: hiçbir şey yazılmaz.

public class Kopek {
  String adi;                 // nitelik
  Kopek(String adi) {         // yapıcı metot
    this.adi = adi;
    System.out.println(adi);
  }
  String havla() {            // örneğe ait metot
    return adi + " haw haw haw!";
  }
  static {                    // sınıfa ait başlatıcı
    System.out.println("Köpekler!");
  }
  {                           // örneğe ait başlatıcı
    System.out.println("Köpek oluşturuluyor.");
  }
  public static void main(String... strings) {
    var d1 = new Kopek("Kara");
    var d2 = new Kopek("Gece");
    d2.havla();
  }
}

Metotlar

Metot Türleri

  • Metotlar, sınıf içinde tanımlanan, belirli bir işi yapan kod bloklarıdır; sınıfın davranışını tanımlar.
  • Örneğe ait metotlar (instance methods) bir nesneyle ilişkilidir: telefon.aramaYap(...). O nesnenin niteliklerini kullanır.
  • Sınıfa ait metotlar (static) sınıfın kendisiyle ilişkilidir, tüm nesnelerde ortaktır: CepTelefonu üzerinden.
  • Static metotlar belirli bir nesneye bağlı olmadığı için nesneye özgü verilere (model gibi) doğrudan erişemez.

      return false;

    Kisi kisi = (Kisi) obj;
    return yas == kisi.yas && ad.equals(kisi.ad);
  }
  @Override
  public int hashCode() {
    return 31 * ad.hashCode() + yas;
  }
}

Sınıfları tasarlarken üç temel unsura dikkat edilmelidir:

1. Tanımlama (Specification)Yapının nasıl kullanılacağını belirler: yapıcı ve metotlar imzalarıyla tanımlanır. Soyutlama, değişikliğin etki alanını azaltır.

public class RasyonelSayi {

  private int pay, payda;
  // Tanımlama: public yapıcı ve metotlar
  public RasyonelSayi(int pay, int payda) {

    this.pay = pay / e;
    this.payda = payda / e;
  }
  public RasyonelSayi topla(RasyonelSayi d) {

  private static int ebob(int a, int b) {
    while (b != 0) { int k = a % b; a = b; b = k; }
    return a;
  }
}
