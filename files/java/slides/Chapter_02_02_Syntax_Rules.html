Every Java program contains at least one class. Its body goes between the { } braces.

Basic Syntax Rules

/* Multi-line comment:
   the compiler ignores it. */
public class Rules {
    // Single-line comment
    public static void main(String[] args) {
        int num = 5;  // ends with ;
        int Num = 7;  // num ≠ Num
        System.out.println(num
                + Num);   // a line can be split
    }

Output
12
  • Syntax: the writing rules of a language. Code that breaks them does not compile.
  • Every statement ends with ;.
  • Blocks open with { and close with }; every opened block must be closed.
  • Java is case-sensitive: num ≠ Num, System ≠ system.
  • Spaces, tabs and line breaks don't matter to the compiler; indentation is for readability.
  • Comments: // runs to the end of the line, /* … */ spans several lines. The compiler ignores both.

Compiling and Running

Levels of Abstraction in Programming

  • High-level language: close to the problem domain; makes software more productive, readable and understandable. Java, C, Python…
  • Assembly language: expresses instructions as text (ADD, MOV) that are translated into the hardware representation. A lower level of abstraction.
  • The higher the abstraction, the shorter and more readable the code; a compiler or assembler translates it to the level below.
  • Hardware representation: only bits. Instructions and data are understood directly by the hardware.

In the example, a, b, sum are assumed to be in registers ebx, ecx, eax, respectively; the machine code is the real x86 encoding (89 D8, 01 C8).

Compiling and Running

Compilation

  • A computer cannot run .java text directly; it must first be compiled. The compile command: javac.
  • The Java compiler translates source code not into the processor's machine language but into bytecode, which the JVM understands, and writes it to a .class file. The JVM turns bytecode into machine code as it runs.

The programmer writes the source as plain text and saves it as HelloWorld.java.

javac HelloWorld.java: the compiler checks syntax and types; if there are no errors, HelloWorld.class is created.

java HelloWorld: the launcher starts the JVM and loads the class; the JVM interprets the bytecode and JIT-compiles hot code to machine code.

The operating system and processor execute the actual instructions; Hello, World! appears on the screen.

Compiling and Running

Why Compile?

  • HelloWorld.java, once compiled, produces HelloWorld.class in the same folder.
  • The compiler catches errors before the program runs: a missing ;, an unclosed parenthesis, a misspelled name, a type mismatch…
  • If there are errors, no .class file is produced; the file:line part of the message shows where the error is.
  • Compilation and the JVM's run-time optimizations (JIT) help programs run faster.

If the ; on line 3 is missing:

Compiling and Running

Bytecode (Intermediate Code)

  • .class files are not machine code.
  • Instead they hold bytecode, which the Java virtual machine understands: bytecode is the JVM's “machine language”.
  • Each instruction's opcode is a single byte (hence the name), optionally followed by operand bytes.
  • Bytecode is not tied to a processor or operating system: the same .class file runs on Windows, Linux and macOS.
Analogy

Bytecode is like sheet music that reads the same everywhere; each computer's JVM is a musician playing it on its own instrument.

To see it

The JDK's javap -c MyClass command lists the bytecode instructions in a .class file in readable form.

Compiling and Running · Step-by-step code trace

Bytecode Example: Step by Step

int x = 5; System.out.println(x); compiled (javap -c, JDK 21). The JVM is a stack machine: instructions push values onto the operand stack and pop them off.

iconst_5: pushes the constant 5 onto the operand stack. (Source: int x = 5;)

istore_1: pops the top of the stack into local variable 1 (x).

getstatic #7: System.out is pushed onto the stack (as a reference). #7 is its constant-pool entry.

iload_1: x's value (5) is copied onto the stack. (Source: System.out.println(x);)

invokevirtual #13: println(int) is called and pops two values; 5 is printed.

return: main ends, and the program terminates.

0: iconst_5
1: istore_1
2: getstatic     #7    // System.out
5: iload_1
6: invokevirtual #13   // println(int)
9: return

Bytecode: The JVM Stack Step by Step

The JVM uses a stack, not registers. iconst_5 pushes the constant 5 onto the operand stack.

istore_1 pops the top of the stack into local 1 (a).

bipush 7: 7 fits in a byte; it is pushed onto the stack.

7 is stored in local 2 (b).

iload_1: a's value (5) is copied onto the stack; a is unchanged.

b's value (7) goes on top. Two values are on the stack.

iadd pops the top two values, adds them and pushes the result (12).

12 is stored in local 3 (sum): int sum = a + b; is done.

The System.out reference is pushed onto the stack.

sum (12) is loaded onto the stack: the argument to println.

println(int) is called; the object and argument are popped, and 12 is printed.

main ends. The same bytecode runs this way on the JVM of every operating system.

istore_1        // a = 5
bipush 7        // push 7
istore_2        // b = 7
iload_1         // load a
iload_2         // load b
iadd            // add
istore_3        // sum = 12
getstatic       // System.out
iload_3         // load sum
invokevirtual   // println(int)
return

Compiling and Running

The Java Virtual Machine (JVM)

  • The JVM (Java Virtual Machine) is the core component that runs Java applications: it interprets bytecode and runs it on the host processor.
  • Frequently executed code is compiled to machine code at run time by the JIT (Just-In-Time) compiler, so programs speed up as they run.
  • The Java launcher is the java command: it starts the JVM, loads the class and calls its main method.

Compiling and Running

Platform Independence

  • One of Java's key features: “Write once, run anywhere”.
  • A program is compiled once; the same bytecode runs on different operating systems.
  • This works because the JVM has been written separately for many operating systems and processors.
  • In languages like C, each platform needs its own build.

Compiling and Running

The Java Platform

Platform: the hardware or software environment a program runs in. The Java platform has two main parts:

  • JVM: runs applications and makes them portable across hardware.
  • API: ready-made class libraries for GUIs, databases, networking, files and much more; they speed up development.

To develop programs, you install the JDK. Since Java 11 the JRE is no longer shipped separately; the JDK includes everything.

Variables and Data Types

Variables: The Building Blocks of Data Storage

  • A variable is a memory location that holds a value and has a name and a type. Think of it as a box with a label on it.
  • Every variable must be declared before use: type first, then name; a declaration ends with ;.
  • Several variables of the same type can be declared on one line, separated by commas.
  • Choose descriptive, meaningful names: not x but checkCount.
int id, checkCount, stockCount;
double amount, interestRate;
char answer;

Syntax: type name; · type name1, name2, name3; · type name = initialValue;

Primitive Data Types

  • Java has eight primitive data types; each has its own memory size and range of values.
  • Integer: byte, short, int, long
  • Floating-point: float, double
  • Character: char
  • Boolean: boolean

In everyday code, int is the default for integers and double for decimals.

Overflow

int max = Integer.MAX_VALUE;
System.out.println(max);
System.out.println(max + 1);   // overflow!
byte n1 = 80;
byte n2 = 50;
byte sum = (byte) (n1 + n2);
System.out.println(sum);        // not 130
long fixed = (long) max + 1;
System.out.println(fixed);
Output
2147483647
-2147483648
-126
2147483648
  • A result beyond a type's limit raises no error: the value “wraps around” to the other end of the range (like a clock going from 12 to 1).
  • 80 + 50 = 130, byte limit is 127 → 130 − 256 = −126.
  • Fix: use a wider type (long) and convert before the operation.

Variables and Data Types · Step-by-step code trace

Overflow: A byte Counter Step by Step

b is a byte: 8 bits. 125 in binary is 01111101; the leftmost bit is the sign bit and has weight −128.

i = 1: 1 <= 4 is true; enter the loop body.

b++ → 126 (01111110); the value is printed.

b++ → 127 (01111111): byte maximum. It is printed.

127 + 1: binary addition gives 10000000. The sign bit is now 1 → the value is −128. No error: the value wrapped around.

−128 is printed: the program carries on with a wrong result, without any warning.

b++ → −127 (10000001): counting now continues upward from −128.

i = 5: 5 <= 4 is false; the loop ends. Output: 126, 127, −128, −127.

byte b = 125;
for (int i = 1; i <= 4; i++) {
    b++;
    System.out.println(b);
}

Variables and Data Types

Primitive Types and Reference Types

  • Primitive types (8 of them): store the value itself; their names are lowercase.
  • Reference types: refer to an object; the variable holds not the object itself but its location (a reference).
  • Examples: String (character strings), arrays, classes, interfaces, enums. Objects are usually created with new.
  • A reference that points to no object has the value null. The empty string "" is an object (length() = 0); null is different: calling a method on it throws NullPointerException.

Identifiers and Keywords

Identifiers

  • Names given to variables, classes and methods are called identifiers. They follow specific rules:
  • May contain only letters, digits (0–9), the underscore _ and the dollar sign $. No spaces, or characters such as -, @, ..
  • The first character must be a letter, _ or $; never a digit.
  • Keywords and true, false, null cannot be identifiers.
  • There is no length limit.
  • Java is case-sensitive: personName and personname are different variables; a misspelled name gives a cannot find symbol error.
Valid examples

userName, totalScore, student_name, data1, _count

Non-English letters

Java accepts any Unicode letter (öğrenci compiles), but stick to English letters in names to avoid problems on other systems.

Assignment, Constants and Conversion

Assignment Statements

  • To give a variable a value, use the = assignment operator: variable = expression;
  • First the right-hand expression is evaluated, and the result is stored in the left-hand variable.
  • The expression can be a literal, another variable or an operation.
  • It is not equality as in math: x = x + 1 means “the new value of x is its old value plus one”.
  • Only a variable may appear on the left: 5 = num; does not compile (unexpected type).
int num, result;
int num1 = 4, num2 = 6;
String name;

num = 10;             // literal
result = num1 + num2; // sum: 10
name = "Ahmet";        // text
num = num * 2;       // 10 → 20

Types must match in an assignment: no number into a String variable, no text into an int variable.

Assignment, Constants and Conversion · Step-by-step code trace

Compound Assignment Operators: Trace

+= -= *= /= %=: x op= y ↔ x = x op y. Shorter to write, same effect.

x starts at 5.

y starts at 10.

Right side: 5 + 10 = 15 → x = 15.

x -= y is short for x = x - y: 15 − 10 = 5.

x = x * 2: 5 × 2 = 10.

x = x / 4: 10 / 4 = 2 (integer division, fraction dropped).

x = x % 3: the remainder of 2 divided by 3 is 2.

The final values are printed.

int x = 5;
int y = 10;
x = x + y;
x -= y;
x *= 2;
x /= 4;
x %= 3;
System.out.println("x = " + x + ", y = " + y);

Initializing Variables

  • A variable can be declared without a value, or initialized in its declaration: int age = 25;
  • Local variables (inside methods) get no default value: reading one before assigning it is a compile error.
  • Class fields get default values automatically: numbers 0, boolean false, char '\u0000'; reference types (e.g. String) null.
  • Still, it is good practice not to rely on defaults and to assign values explicitly.

Floating-Point Precision

  • Floating-point numbers are stored in a limited number of bits, in binary.
  • Values like 1/3 or 0.1 have infinitely many digits in binary (0.1 = 0.000110011…₂, just as 1/3 = 0.333…), so they are stored approximately: 1.0/3.0 is not exactly 1/3.
  • Small rounding errors add up: adding 0.1 ten times does not give exactly 1. Sometimes errors cancel out: the sum of three 1.0/3.0 terms prints 1.0.
  • So floating-point numbers are not compared with ==; instead, check whether the difference is tiny. For money, use BigDecimal.
System.out.println(1.0 / 3.0);
System.out.println(1.0/3 + 1.0/3 + 1.0/3);
System.out.println(0.1 + 0.2);
System.out.println(0.1 + 0.2 == 0.3);
double t = 0.0;
for (int i = 0; i < 10; i++) t += 0.1;
System.out.println(t);
double diff = (0.1 + 0.2) - 0.3;
System.out.println(Math.abs(diff) < 1e-9);

Named Constants

  • final variables get their value once; after that it cannot change. Pattern: public static final Type CONSTANT_NAME = value;
  • Names are written in UPPERCASE, with words separated by _. Use meaningful names instead of “magic numbers”: not 7 but DAYS_PER_WEEK; if the value changes, you update it in one place.
public class Constants {
    public static final double PI = 3.14159;
    public static final int DAYS_PER_WEEK = 7;

    public static void main(String[] args) {
        double r = 2.0;
        double area = PI * r * r;
        System.out.println("Area: " + area);
        int days = 4 * DAYS_PER_WEEK;
        System.out.println(days + " days");
    }
}
Output
Area: 12.56636
28 days

Data Type Conversion (Casting)

Implicit conversion

From a smaller to a larger type, Java converts automatically; the value is preserved (very large integers may be rounded when going to float).

Explicit conversion

From a larger to a smaller type (narrowing), you ask for the conversion by writing the target type in parentheses: (int) d. The programmer accepts any loss:

  • decimal to integer: the fractional part is dropped (not rounded),
  • an integer that doesn't fit overflows ((byte) 130 → −126).
double dbl = 5;     // implicit: 5.0
System.out.println(dbl);
double d = 5.0;
int num = (int) d;   // explicit: 5
System.out.println(num);
System.out.println((int) 3.99);
System.out.println((int) -3.99);
System.out.println(Math.round(3.99));
System.out.println((byte) 130);

char ↔ int: Tracing the Code

c is a char: it stores the Unicode code of 'd', 100.

char → int is an implicit conversion: code = 100. No cast needed.

c - 32 is an int expression: 100 − 32 = 68. Going from int to char requires (char): 68 = 'D'.

Subtracting two char values gives an int: 'z' - 'd' = 122 − 100 = 22.

next starts as 'd'; next++ makes it 101 = 'e'. ++ on a char variable needs no cast.

Because of the " " string, the values are concatenated as text: 100 D 22 e.

c + 1: char is promoted to a number; 100 + 1 = 101 is printed (not a letter).

"" + c first gives the string "d"; then + 1 is appended → d1.

Operators

Short-Circuit Evaluation

  • &&: if the left side is false, the result is already false: the right side is never evaluated.
  • ||: if the left side is true, the right side is skipped: day == 6 || day == 7 — with day = 6, the second comparison is never made. Its negation !(day == 6 || day == 7) means “weekday”.
  • This guards a dangerous operation: first check “is the divisor nonzero?”, and divide only if it is.
  • Order matters: had you written num / divisor > 1 && divisor != 0, the program would stop with a division-by-zero error (ArithmeticException).
int divisor = 0;
int num = 10;
if (divisor != 0 && num / divisor > 1) {
    System.out.println("Ratio above 1");
} else {
    System.out.println("Can't divide or too small");
}
Output
Can't divide or too small

Operators

The Ternary Operator

A short expression that picks one of two values by a condition: if the condition is true, value1, otherwise value2.

result = (condition) ? value1 : value2;

Example: is a number positive or negative?

int num = -5;
String result = (num > 0) ? "Positive" : "Negative";
System.out.println("Result: " + result);
Output
Result: Negative

The same with if-else:

String result;
if (num > 0) {
    result = "Positive";
} else {
    result = "Negative";
}

?: produces a value, so it can go on the right of an assignment or inside println. Both options must have compatible types: double abs = (num < 0) ? -num : num; (−4.5 → 4.5), int max = (a > b) ? a : b; (8, 13 → 13).

Operators

Nested Ternary Operators

Ternary operators can be nested to express more complex conditions briefly. Example: is a number zero, positive or negative?

int num = -5;
String result = (num == 0) ? "Zero" : (num > 0) ? "Positive" : "Negative";
System.out.println("Result: " + result);
numResult
0Zero
7Positive
−5Negative

Read it as: “zero? yes → Zero; no → positive? yes → Positive; no → Negative”. The second ?: is the first one's value2 (they group from the right).

More than two nested ?: hurt readability; use if-else if instead.

Common Mistakes (1)

Missing semicolon

error: ';' expected. The error is usually at the end of the previous line.

File name ≠ class name

class HelloWorld is public, should be declared in a file named HelloWorld.java

Upper/lower case

string, Int do not compile: cannot find symbol; system.out gives package system does not exist. Correct: System, String, int.

Uninitialized local variable

variable count might not have been initialized: local variables get no default value.

Literal without a suffix

float f = 3.14; → possible lossy conversion from double to float (use 3.14f) · long l = 3000000000; → integer number too large (L suffix needed).

Forgetting the cast when narrowing

int → char, double → int assignments give incompatible types: possible lossy conversion; you need (char), (int).

Common Mistakes (2): Compiles but Wrong

Integer division

double avg = (3 + 4) / 2; → 3.0. Correct: (3 + 4) / 2.0 → 3.5.

= vs. ==

if (x = 5) → int cannot be converted to boolean. Comparison uses ==.

switch with no break

Every case after the matching one runs too (fall-through).

if followed by ;

if (x > 0); { … }: the empty statement becomes the body, and the block always runs.

Infinite loop

for (int i = 1; i <= 10; i--), or forgetting to update the condition variable in a while.

Floating-point ==

0.1 + 0.2 == 0.3 → false. Check that the difference is tiny: Math.abs(a - b) < 1e-9.

What does each line print? (int a = 7, b = 2;)

Show answers
  1. 3 1 3.5: 7 / 2 = 3 (integer division), 7 % 2 = 1; (double) is applied first → 7.0 / 2 = 3.5.

Exercises

  1. Convert Celsius to Fahrenheit: F = C × 9 / 5 + 32. What is the result for C = 37? With int arithmetic, what happens if you write 9 / 5 * c + 32?
  2. Split 3725 seconds into hours, minutes and seconds with / and %.
  3. Print whether a number is odd or even using the ternary operator.
  4. Add up the numbers from 1 to 100 that are not multiples of 3, using continue.
