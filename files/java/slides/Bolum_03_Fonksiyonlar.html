Fonksiyon Kavramı

Fonksiyon Nedir?

Fonksiyon (function), bir işi yapan, adı olan ve tekrar tekrar kullanılabilen kod parçasıdır. Java'da fonksiyonlar her zaman bir sınıfın içinde yazılır ve metot (method) adını alır.

  • Aldığı parametreler ve dönüş değeri türü ile tanımlanır.
  • Kodun okunabilirliğini artırır, kod tekrarını azaltır.
  • Modüler ve düzenli kod yazmayı teşvik eder.
  • Programı küçük, yönetilebilir parçalara ayırır.
Benzetme: yemek tarifi

"Çay demle" bir tariftir: bir kez yazılır, istendiği kadar uygulanır. Malzemeler parametre, ortaya çıkan çay dönüş değeridir. Tarifi kullanan, her adımı yeniden düşünmek zorunda kalmaz.

Şimdiye kadar yazdığımız main da bir metottur; System.out.println(...) ise hazır bir metot çağrısıdır.

Fonksiyon Kavramı

Girdi – İşlem – Çıktı

Her fonksiyon üç aşamada düşünülebilir:

Girdi

Fonksiyona veri sağlanır: parametreler. Fonksiyonun ne üzerinde çalışacağını belirler.

İşlem

Fonksiyon, gövdesindeki komutlarla girdiyi işler ve belirli bir görevi yerine getirir.

Çıktı

İşlem sonunda bir sonuç üretilir ve return ile çağırana geri döndürülür.

Matematikteki f(x) = x² gibi: x girdi, kare alma işlem, x² çıktıdır. Bazı fonksiyonların girdisi ya da çıktısı olmayabilir (void).

Tanım ve Çağrı

Fonksiyon Tanımı

publicErişim belirleyici (access modifier): metodu kimlerin çağırabileceğini söyler.
intDönüş değeri türü: metodun geri vereceği değerin türü; değer döndürmüyorsa void.
toplamaMetot adı: fiil ya da fiil öbeği, küçük harfle başlar (camelCase).
(int sayi1, int sayi2)Parametreler: metodun girdileri; her birinin türü ve adı yazılır.
{ ... }Kod bloğu (gövde): metot çağrıldığında çalışacak komutlar.

toplama metodu, sayi1 ve sayi2 adlı iki girdi parametresi alır, bunları toplar ve sonucu geri döndürür.

Tanım ve Çağrı

Fonksiyon Çağırma

public class ToplamaOrnegi {
    public static int toplama(int sayi1, int sayi2) {
        int sonuc = sayi1 + sayi2;
        return sonuc;
    }

    public static void main(String[] args) {
        int sonuc = toplama(5, 3);
        System.out.println("Toplam: " + sonuc);
    }
}
Çıktı
Toplam: 8
  • toplama(5, 3) bir çağrıdır (call): program akışı metoda gider, metot bitince çağrının yapıldığı yere geri döner.
  • Çağrıdaki 5 ve 3 argümandır (argument); tanımdaki sayi1, sayi2 ise parametredir (parameter).
  • Çağrı 8 değerini döndürür; bu değer sonuc değişkenine atanır.
  • Argüman sayısı, sırası ve türleri parametrelerle uyuşmalıdır.
  • static: metot nesne oluşturmadan, doğrudan main'den çağrılabilir (birkaç slayt sonra).

Tanım ve Çağrı · Kodu adım adım çalıştır

Çağrı ve Dönüş: Adım Adım

Program her zaman main metodundan başlar. Yığında yalnızca main çerçevesi vardır.

toplama(5, 3) çağrılır: yeni bir çerçeve (frame) açılır, argümanlar parametrelere kopyalanır.

Gövde çalışır: sonuc = 5 + 3 = 8. Bu sonuc, toplama'nın yerel değişkenidir.

return sonuc; 8 değerini çağırana gönderir ve metodu bitirir; çerçeve yığından silinir.

Akış çağrının yapıldığı satıra döner: dönen 8, main'in sonuc değişkenine atanır. İki sonuc farklı değişkenlerdir.

println de bir metot çağrısıdır: ekrana Toplam: 8 yazılır.

static int toplama(int sayi1, int sayi2) {
  int sonuc = sayi1 + sayi2;
  return sonuc;
}

public static void main(String[] args) {
  int sonuc = toplama(5, 3);
  System.out.println("Toplam: " + sonuc);
}

Değer döndüren metodun sonucu bir ifadede kullanılır; void metot ise tek başına bir komut olarak çağrılır.

Tanım ve Çağrı

return ve void

  • return ifade; değeri çağırana verir ve metodu hemen bitirir; sonraki satırlar çalışmaz.
  • Dönen değerin türü, bildirilen dönüş türüyle uyumlu olmalıdır (int → double genişlemesi serbesttir).
  • Değer döndüren metotta her yol bir return ile bitmelidir; yoksa derleyici missing return statement der.
  • void metot değer döndürmez; erken çıkmak için tek başına return; yazılabilir.
public class Erken {
    static void bolumYazdir(int bolunen, int bolen) {
        if (bolen == 0) {
            System.out.println("Sıfıra bölünemez!");
            return;                      // metottan hemen çık
        }
        System.out.println(bolunen / bolen);
    }
    public static void main(String[] args) {
        bolumYazdir(10, 2);
        bolumYazdir(7, 0);
    }
}

static ve Nesne Üzerinden Çağrı

static metot 
static int toplama(int sayi1, int sayi2) {
    return sayi1 + sayi2;
}
// main içinde, doğrudan:
int sonuc = toplama(5, 3);

static metot sınıfa aittir; nesne gerekmez. Başka sınıftan SinifAdi.metot() biçiminde çağrılır: Math.sqrt(16) gibi.

nesne (örnek) metodu 
public class Hesap {
    int toplama(int sayi1, int sayi2) {
        return sayi1 + sayi2;
    }
    public static void main(String[] args) {
        Hesap hesap = new Hesap();
        int sonuc = hesap.toplama(5, 3);
        System.out.println(sonuc);  // 8
    }
}

static olmayan metot bir nesne üzerinden çağrılır: önce new ile nesne oluşturulur, sonra hesap.toplama(5, 3).

Tanımda static yokken main'den doğrudan toplama(5, 3) yazmak derleme hatasıdır:
non-static method toplama(int,int) cannot be referenced from a static context

Değer ile Aktarım (Pass by Value)

Metot, kendisine verilen değişkeni değiştirebilir mi? Tahmin edin, sonra adım adım izleyin.

main'de sayi = 5.

Çağrıda değerin kopyası (5) gönderilir. arttir'in sayi'si ayrı bir kutudur; adlarının aynı olması önemsizdir.

Yalnızca kopya değişir: arttir'deki sayi 15 olur, main'deki hâlâ 5.

arttir içinde 15 yazılır.

arttir bitti, çerçevesi ve kopyası silindi. main'deki sayi 5 kaldı: Java argümanları değer ile aktarır (pass by value).

static void arttir(int sayi) {
  sayi = sayi + 10;
  System.out.println("arttir: " + sayi);
}

public static void main(String[] args) {
  int sayi = 5;
  arttir(sayi);
  System.out.println("main: " + sayi);
}

public class AsiriYukleme {
    static int topla(int a, int b) {
        return a + b;
    }
    static double topla(double a, double b) {
        return a + b;
    }
    static int topla(int a, int b, int c) {

    }

    public static void main(String[] args) {

Aşırı yükleme (overloading): aynı adlı birden fazla metot, parametre listeleri farklı olduğu sürece aynı sınıfta bulunabilir.

  • Farklılık: parametre sayısı, türü ya da sırası.
  • Derleyici, çağrıdaki argümanlara bakarak hangi metodun çalışacağına derleme zamanında karar verir.
  • Yalnızca dönüş türü farklı olan iki metot aşırı yükleme değildir: method topla(int,int) is already defined hatası verir.
  • println da aşırı yüklenmiştir: println(int), println(String), println(double)…

Fonksiyon İçinde Fonksiyon

Fonksiyon İçinde Fonksiyon

public class IcIce {
    public static int kareAl(int sayi) {
        return sayi * sayi;
    }
    public static int topla(int sayi1, int sayi2) {
        return sayi1 + sayi2;
    }
    public static int ikiKareToplami(int sayi1, int sayi2) {
        return topla(kareAl(sayi1), kareAl(sayi2));
    }
    public static void main(String[] args) {
        int sonuc = ikiKareToplami(3, 4);
        System.out.println(sonuc);
    }
}
Çıktı
25
  • Bir fonksiyon, başka bir fonksiyonu çağırabilir.
  • Karmaşık görev küçük parçalara bölünür: ikiKareToplami, işi kareAl ve topla'ya yaptırır.
  • Kod okunabilir ve yönetilebilir olur; her parça ayrı ayrı test edilebilir.
  • topla(kareAl(sayi1), kareAl(sayi2)) ifadesinde önce argümanlar hesaplanır (soldan sağa), sonra dış çağrı yapılır.
3² + 4² = 9 + 16 = 25. Bir sonraki slaytta çağrı yığını adım adım.

Fonksiyon İçinde Fonksiyon · Kodu adım adım çalıştır

ikiKareToplami(3, 4): Çağrı Yığını

main, ikiKareToplami(3, 4) çağrısını yapar.

topla çağrılmadan önce argümanları hesaplanmalı: önce kareAl(sayi1).

Üçüncü çerçeve açılır: kareAl(3) → 3 × 3 = 9 döner.

kareAl çerçevesi kapandı; ilk argüman (arg1) = 9. Sıradaki: kareAl(sayi2).

kareAl(4) → 4 × 4 = 16 döner.

Argümanlar hazır: topla(9, 16) çağrılır → 25. Buradaki sayi1 = 9; ikiKareToplami'nınki hâlâ 3.

topla'nın sonucu, ikiKareToplami'nın dönüş değeri olur: 25 döner.

main'e dönüldü: sonuc = 25.

Ekrana 25 yazılır. En fazla 3 çerçeve aynı anda yığındaydı.

static int kareAl(int sayi) {
  return sayi * sayi;
}
static int topla(int sayi1, int sayi2) {
  return sayi1 + sayi2;
}
static int ikiKareToplami(int sayi1,
                          int sayi2) {
  return topla(kareAl(sayi1), kareAl(sayi2));
}
public static void main(String[] args) {
  int sonuc = ikiKareToplami(3, 4);
  System.out.println(sonuc);
}

Yapıcı Metotlar

Yapıcı Metot

Yapıcı (constructor), sınıfların özel bir metodudur:

  • Sınıftan bir nesne oluşturulurken (new) otomatik çağrılır.
  • Adı sınıfın adıyla aynıdır (büyük harfle başlar).
  • Dönüş türü yoktur, void bile yazılmaz; değer döndürmez.
  • Nesnenin ilk durum değerlerini atamak için kullanılır.
  • Parametre alarak nesneyi özelleştirebilir.
public class Ogrenci {
    String ad;
    int numara;

    // yapıcı: dönüş türü yok
    public Ogrenci(String ad, int numara) {
        this.ad = ad;
        this.numara = numara;
    }
}
// kullanım:
Ogrenci ogr = new Ogrenci("Ayşe", 101);

this.ad nesnenin alanını, yalnız ad ise parametreyi gösterir.

Yapıcı Metotlar

Yapıcı Türleri

Varsayılan (Default)

Sınıfa hiç yapıcı yazılmazsa derleyici, parametresiz ve hiçbir işlem yapmayan bir yapıcı otomatik ekler.

new Kitap()
Aşırı Yüklenmiş (Overloaded)

Bir sınıfın birden fazla yapıcısı olabilir; farklı parametre listeleriyle ayrılırlar. Her birine aşırı yüklenmiş yapıcı denir.

Kitap(String) Kitap(String, String)
Zincirleme (Chaining)

Bir yapıcı, this(...) ile aynı sınıftaki başka bir yapıcıyı çağırabilir. Bu çağrı yapıcının ilk satırı olmalıdır.

this(ad);
Dikkat: Sınıfa tek bir yapıcı bile yazarsanız varsayılan yapıcı artık eklenmez. Kitap(String ad) varken new Kitap() derlenmez:
constructor Kitap in class Kitap cannot be applied to given types

Yapıcı yazılmamış alanlar varsayılan değerler alır: sayılar 0, boolean false, nesne başvuruları (ör. String) null.

Yapıcı Metotlar

Yapıcı Örneği: Kitap

class Kitap {
    String ad;
    String yazar;
    int sayfaSayisi;
    public Kitap(String ad) {
        this.ad = ad;
    }
    public Kitap(String ad, String yazar) {
        this(ad);  // yapıcı zincirleme
        this.yazar = yazar;
    }
}
public class KitapTest {
    public static void main(String[] args) {
        Kitap k1 = new Kitap("Java");
        Kitap k2 = new Kitap("Nutuk", "Atatürk");
        System.out.println(k1.ad + " / " + k1.yazar
                + " / " + k1.sayfaSayisi);
        System.out.println(k2.ad + " / " + k2.yazar
                + " / " + k2.sayfaSayisi);
    }
}
Çıktı
Java / null / 0
Nutuk / Atatürk / 0
  • new Kitap("Java"): tek parametreli yapıcı; yazar atanmadı → null.
  • new Kitap("Nutuk", "Atatürk"): iki parametreli yapıcı önce this(ad) ile diğerini çağırır, sonra yazarı atar.
  • sayfaSayisi hiç atanmadı: varsayılan 0.

Yapıcı Metotlar · Kodu adım adım çalıştır

new Kitap("Nutuk", "Atatürk"): Adım Adım

new öbekte (heap) yeni bir nesne ayırır; alanlar varsayılan değerleri alır: null, null, 0.

Argümanlar iki String olduğu için iki parametreli yapıcı çalışır. this, yeni nesneyi gösterir.

this(ad): zincirleme. Tek parametreli yapıcı, aynı nesne için çağrılır.

this.ad = ad: parametredeki değer nesnenin ad alanına yazılır.

İç yapıcı bitti. Kalan satır: this.yazar = yazar.

Yapıcılar bitti; new ifadesinin değeri nesnenin başvurusudur (reference). k2 artık nesneyi gösterir.

Nokta operatörüyle alanlar okunur: Nutuk / Atatürk / 0.

class Kitap {
  String ad;
  String yazar;
  int sayfaSayisi;
  public Kitap(String ad) {
    this.ad = ad;
  }
  public Kitap(String ad, String yazar) {
    this(ad);  // yapıcı zincirleme
    this.yazar = yazar;
  }
}
// main içinde:
Kitap k2 = new Kitap("Nutuk", "Atatürk");
System.out.println(k2.ad + " / "
    + k2.yazar + " / " + k2.sayfaSayisi);

Yapıcı Metotlar

Nokta Operatörü

Nokta operatörü (dot operator, .), nesnelerin niteliklerine (alanlarına) ve metotlarına erişmek için kullanılır: nesne.alan, nesne.metot().

class Kitap {
    String baslik;
    String yazar;

    void kitapBilgisiGoster() {
        System.out.println(baslik + " - " + yazar);
    }
}

public class NoktaOperatoru {
    public static void main(String[] args) {
        Kitap kitap = new Kitap();
        //Kitap nesnesinin özelliklerine erişim
        kitap.baslik = "Java Programlama";
        kitap.yazar = "John Doe";
        //Kitap nesnesinin metotlarına erişim
        kitap.kitapBilgisiGoster();
    }
}
Çıktı
Java Programlama - John Doe
  • Yapıcı yazılmadığı için new Kitap() varsayılan yapıcıyı kullanır.
  • kitap, nesnenin kendisi değil, ona bir başvurudur.

Kapsam

Kapsam

Kapsam (scope), bir değişkenin tanımlandığı ve kullanılabildiği kod bölgesidir.

  • Her değişkenin bir kapsamı vardır: Java'da kapsam, değişkenin tanımlandığı süslü parantez bloğudur.
  • Kapsam, değişkenin erişilebilirliğini ve yaşam süresini belirler.
  • Yerel ve genel (global) kapsamlar farklı erişim kurallarına sahiptir.
  • İç içe kapsamda iç kapsam, üst kapsamdaki değişkenlere erişebilir; dış kapsam içtekini göremez.
  • Aynı adın farklı kapsamlarda kullanılması isim çakışmasına yol açabilir; doğru kullanılmayan kapsam hatalara neden olur.

Kapsam

Yerel ve Global Kapsam

public class IcKapsam {
    static int globalDegisken = 10; // global (sınıf alanı)
    static void fonksiyon() {
        int disDegisken = 10;       // yerel kapsam
        {
            int icDegisken = 5;
            // disDegisken ve icDegisken burada erişilebilir
            System.out.println(disDegisken + icDegisken
                    + globalDegisken);
        }
        // icDegisken burada YOK
    }
    public static void main(String[] args) {
        fonksiyon();
    }
}

Soyutlama ve Tasarım

Soyutlama

Soyutlama (abstraction), karmaşıklığı azaltmak için ayrıntıları yok saymaktır.

Neden?

Kodun okunabilirliğini artırır, işlemi basitleştirir; büyük ve karmaşık programları anlaşılır kılar.

Nasıl?

Kodu parçalara ayırır; her parça ayrı ayrı düşünülür. Bir metodu kullanan, onun içini bilmek zorunda değildir.

Günlük benzetme: arabayı sürmek için motorun içini bilmek gerekmez; direksiyon ve pedallar bir "arayüzdür".

Soyutlama ve Tasarım

Fonksiyonel Soyutlama

Hesaplamalar üzerinde soyutlama, işlevsel ya da işlemci soyutlaması (procedural abstraction) olarak da bilinir.

  • Bir fonksiyonun nasıl hesapladığından çok ne hesapladığını bilmek önemlidir.
  • Görevi bilindiği sürece, nasıl yaptığı umursanmaz.
  • Fonksiyonun gerçekleştirimi (gövdesi) hakkında endişelenilmez.
  • Gövde değişse bile (daha hızlı bir algoritma), çağıran kod aynı kalır.
System.out.println("Merhaba");

Fonksiyon, verilen metni konsola yazar; bunu nasıl yaptığını (karakter kodlama, işletim sistemi çağrıları…) bilmek gerekmez.

// Kullanan yalnızca imzayı bilir:
static boolean asalMi(int sayi)
// "sayi asal ise true döner"
if (asalMi(17)) { ... }

Soyutlama ve Tasarım

Genelleme

Bağlam (context):

  • bir sayının, bir denklem içindeki diğer unsurlarla ilişkisi,
  • bir kelimenin anlamının cümledeki yeri ve durumuyla ilişkisi,
  • bir kod bloğu içindeki durum ve etkileşimler.

Bir ifadenin anlamı, çevresindeki diğer kelimelerden etkilenebilir.

Genelleme (generalization):

  • bir bağlama ait bir çözümü başka bağlamlara uygun hâle getirmek,
  • bir ürünü daha genel ve çok amaçlı kullanılabilir yapmak.

Kodda genellemenin aracı parametredir: sabit değerler parametreye dönüşür.

public class Genelleme {
    // Özel: yalnızca 10 tane '-' yazar
    static void cizgiCiz() {
        System.out.println("----------");
    }
    // Genel: uzunluğu ve karakteri parametre
    static void cizgiCiz(int uzunluk, char karakter) {
        for (int i = 0; i < uzunluk; i++) {
            System.out.print(karakter);
        }
        System.out.println();
    }
    public static void main(String[] args) {
        cizgiCiz();
        cizgiCiz(5, '*');
        cizgiCiz(12, '=');
    }
}

Problemi Parçalama

Problemi küçük parçalara ayırmak (decomposition), programlamanın temel adımıdır. Her parça bir fonksiyon olur: kod düzenli, okunur, yeniden kullanılabilir ve sürdürülebilir olur.

// notlariOku ve harfNotu da ayrı metotlardır
static double ortalamaHesapla(int[] notlar) {
    int toplam = 0;
    for (int n : notlar) {
        toplam += n;
    }
    return (double) toplam / notlar.length;
}
public static void main(String[] args) {
    Scanner giris = new Scanner(System.in);
    int[] notlar = notlariOku(giris, 3);
    double ort = ortalamaHesapla(notlar);
    System.out.println("Ortalama: " + ort + " -> " + harfNotu(ort));
}

Ne Zaman Fonksiyon?

Bir kural: DRY (Don't Repeat Yourself, kendini tekrar etme). Kodu kopyalayıp yapıştırma ihtiyacı doğduğunda, fonksiyon yazın!

Tekrarlı kod

double ort1 = (70 + 80 + 90) / 3.0;
System.out.println(ort1);

System.out.println(ort2);
// formül değişirse her yerde
// ayrı ayrı düzeltmek gerekir

Fonksiyonla

static double ortalama(int a, int b, int c) {
    return (a + b + c) / 3.0;
}
System.out.println(ortalama(70, 80, 90));
System.out.println(ortalama(55, 60, 100));

Lambda İfadeleri

Anonim (Lambda) Fonksiyonlar

  • Anonim fonksiyonlar, isimsiz fonksiyonlardır: isim yerine doğrudan kod parçasını temsil ederler.
  • Java'da lambda ifadeleri (lambda expressions) olarak bilinir; Java 8+.
  • Sözdizimi: (ParametreListesi) -> İfade
  • Çok satırlı gövde: (a, b) -> { ...; return ...; }
  • Parametre türleri çoğu zaman yazılmaz, derleyici çıkarır: (x, y) -> x + y. Tek parametrede parantez de gerekmez: s -> s * 2.

Toplama lambda ifadesi: (int x, int y) -> x + y iki tamsayı alır ve toplar. Aynı işi yapan metot:

static int toplama(int x, int y) {
    return x + y;
}

Örnek Problemler (1)

static int f(int x) {
    x = x * 2;
    return x + 1;
}
public static void main(String[] args) {
    int a = 3;
    int b = f(a);
    System.out.println(a + " " + b);
    System.out.println(f(f(1)));
}
static int kare(int n) { return n * n; }
static int kup(int n) { return n * kare(n); }
// main içinde:
System.out.println(kup(2) + kare(3));
  1. Soldaki program ne yazdırır? a neden değişmedi?
  2. Sağdaki satır ne yazdırır? kup(2) çalışırken yığında en çok kaç çerçeve olur (main dahil)?
Cevapları göster
  1. 3 7 ve 7. f, a'nın kopyasını ikiye katlar; a = 3 kalır. f(f(1)) = f(3) = 7.
  2. 8 + 9 = 17. main → kup(2) → kare(2): en çok 3 çerçeve.

Örnek Problemler (2)

static int topla(int a, int b) { return a + b; }
static double topla(double a, double b) { return a + b; }
// main içinde:
System.out.println(topla(2, 3.0));
System.out.println(topla(2, 3));
String s = "Programlama";
System.out.println(s.length() + " " + s.charAt(3) + " "
        + s.substring(3, 7) + " " + s.indexOf("a"));
System.out.println(Math.max(Math.abs(-8), Math.sqrt(49)));
  1. İlk iki println hangi topla metodunu çağırır, ne yazdırır?
  2. Metin satırı ne yazdırır?
  3. Son satır neden 8 değil de 8.0 yazdırır?
Cevapları göster
  1. topla(2, 3.0) → double sürümü (2, double'a genişler): 5.0; topla(2, 3) → int sürümü: 5.
  2. 11 g gram 5 (indisler 0'dan; substring'de 7 hariç; ilk 'a' 5. indiste).
  3. Math.sqrt double döndürür; max(int, double) double sürümünü seçer: 8.0.

Alıştırmalar

  1. boolean ciftMi(int sayi): sayı çiftse true döndürsün.
  2. int enBuyuk(int a, int b, int c): üç sayının en büyüğünü Math.max ile bulsun.
  3. int usAl(int taban, int us): döngüyle üs hesaplasın (Math.pow kullanmadan).
  4. String tersCevir(String metin): metni tersine çevirsin ("Java" → "avaJ").
  5. double daireAlani(double r) yazın; sonucu printf ile 2 basamak yazdırın.
  6. Dikdortgen sınıfı: en, boy alanları, iki yapıcı (parametresiz → 1×1, zincirleme ile) ve alan() metodu.
Cevaplar / ipuçları
  1. return sayi % 2 == 0; → ciftMi(7) = false, ciftMi(10) = true.
  2. return Math.max(a, Math.max(b, c)); → enBuyuk(4, 9, 2) = 9.
  3. int sonuc = 1; for (int i = 0; i < us; i++) sonuc *= taban; return sonuc; → usAl(2, 10) = 1024.
  4. Sondan başa: ters += metin.charAt(i);
  5. return Math.PI * r * r; → printf("%.2f%n", daireAlani(2)) → 12,57.
  6. Dikdortgen() { this(1, 1); }; int alan() { return en * boy; }
