String Basics

What Is a String?

  • A string is an object that holds a sequence of characters; its type is the class java.lang.String.
  • String is a class, not a primitive type; its name is capitalized. import is not needed.
  • Text in double quotes, like "Tarkan", is a string literal; the object is created without new.
  • Characters are stored as Unicode, so Turkish letters such as ç ğ ı İ ö ş ü work fine.
  • A single character is a char in single quotes ('T'); text is a String in double quotes ("T").
String name = "Tarkan";
String fullName = "Mustafa Sandal";
String point = "(" + 3 + ", " + 5 + ")";
System.out.println(name);
System.out.println(fullName);
System.out.println(point);
Output
Tarkan
Mustafa Sandal
(3, 5)

A string is like a row of character boxes.

  • +: if either operand is a String, the other is converted to a string and the two are concatenated.
  • + is evaluated left to right: "Sum: " + 3 first becomes "Sum: 3", then 5 is appended → Sum: 35.
  • Parentheses give the sum: "Sum: " + (3 + 5).
  • 3 + 5 + " apples": the numbers are added first (8), then the string is appended.

  • Every concatenation creates a new String object.

+ Left to Right: Addition or Concatenation?

Two int variables. On each line, + is evaluated left to right; the type is checked at every step.

Left side is a String: 4 is converted and appended → "Total: 4".

Still a String; 2 is appended as text too → "Total: 42", not a sum!

Parentheses first: 4 + 2 adds two ints: the numeric sum is 6.

Then concatenated with the string → "Total: 6".

Both left operands are int: added first → 6.

6 + " pens": now a String → "6 pens".

'x' + 'y': two chars are added as numbers: 120 + 121 = 241.

241 + "z" → "241z".

Empty string first: "" + 'x' becomes a String → "x".

"x" + 'y' → "xy": the char is appended as text.

The first line is printed.

The second line is printed. Rule: once one side is a String, + concatenates; until then, numbers are added.

Immutability

Immutable Objects

  • String objects are immutable: they cannot change once created.
  • toUpperCase, replace, substring, + do not change the original; they return a new object.
  • To keep the result you must assign it: s = s.toUpperCase();
  • Benefits: safe, consistent code (code sharing a string cannot break it), memory savings in the string pool, and safe sharing between threads.
Analogy: a string is a stone tablet. It cannot be scraped and fixed; a new tablet is carved and replaces the old one.
String s = "Giresun Üniversitesi";
s.toUpperCase();      // result is lost
System.out.println(s);
s = s.toUpperCase();  // stored in s
System.out.println(s);
Output
Giresun Üniversitesi
GİRESUN ÜNİVERSİTESİ

On a Turkish-locale (tr-TR) machine the output is GİRESUN ÜNİVERSİTESİ; under an English locale it is GIRESUN ÜNIVERSITESI.

Immutability in Memory, Step by Step

The literal is an object in the pool; s points to it.

toUpperCase() creates a new object. But the result is not assigned to any variable!

s still points to the old object, so the original text is printed. The orphaned object is left to the garbage collector.

Again a new object is created, and this time its reference is assigned to s. The old object did not change; only the arrow moved.

s now points to the uppercase object.

StringBuilder: One Buffer, Changed in Place

One mutable buffer: 4 characters used, capacity 16 + 4 = 20.

append(' '): a space is appended; same object, no new object.

The second call in the chain, append(8): the number is appended as a character. append returns the object itself, so calls can be chained.

insert(0, ">> "): the other characters shift right to make room for 3 cells at the front.

setCharAt(3, 'j'): index 3 changes in place, which a String cannot do.

deleteCharAt(8): the trailing '8' is deleted; length 8.

16 more characters: 24 > 20, no room. The buffer grows: new capacity (20 + 1) × 2 = 42, old contents copied.

toString(): creates a new String from the buffer's current contents.

Length 24 and capacity 42 are printed.

StringBuilder sb = new StringBuilder("Java");
sb.append(' ').append(8);
sb.insert(0, ">> ");
sb.setCharAt(3, 'j');
sb.deleteCharAt(sb.length() - 1);
sb.append("programming book");
String s = sb.toString();
System.out.println(s + " " + sb.length() + " " + sb.capacity());

User Input

User Input: Scanner

  • java.util.Scanner reads input from the keyboard (System.in): import java.util.Scanner;
  • next(): skips whitespace and reads the next word (up to a space).
  • nextLine(): reads everything up to the end of the line; it consumes the newline but drops it from the result.
  • nextInt(), nextDouble(): reads a number but leaves the newline after it in the buffer. If the input is not a number, InputMismatchException is thrown.
  • When done, call keyboard.close().
Scanner keyboard = new Scanner(System.in);
System.out.println("enter some text");

System.out.println(input);    // algorithms
input = keyboard.next();
System.out.println(input);    // in
input = keyboard.nextLine();
System.out.println(input);    //  computational terms

Comparison

Comparing with ==

  • == compares the references (memory addresses) of objects, not their contents.
  • If two variables point to the same object, it returns true; for different objects it returns false, even if the contents match.
  • str1 == str2 being true is no accident but a result of the string pool.
Bottom line: == cannot compare string contents; compare contents with equals().
String str1 = "Giresun";
String str2 = "Giresun";
String str3 = new String("Giresun");
System.out.println(str1 == str2);        // true
System.out.println(str1 == "Giresun");   // true
System.out.println(str1 == str3);        // false
System.out.println(str3 == "Giresun");   // false
Output
true
true
false

Comparison

The String Pool

  • Constants in source code such as "Giresun" are string literals.
  • Literals are stored in a special region of the heap, the string pool: literals with the same content share one object. This saves memory and time (it is safe because strings are immutable).
  • new String(...) bypasses the pool: each new creates a new object.
  • So == gives true for equal literals but false for equal new objects.
  • A string built with + at run time is a new object too; a compile-time constant like "Gire" + "sun" goes to the pool. s.intern() returns the pooled copy.

Two literals share one object; new creates a separate one.

Comparison · Step-by-step code trace

The String Pool: Step by Step

The pool holds an object for the literal "Giresun"; str1 points to it.

The same literal is reused: no new object is created, str2 also points to it.

new always creates a new object outside the pool (same content).

str1 and str2 are the same object (#1) → true.

"Giresun" is also the pooled #1 → true.

#1 and #2 are different objects (same content) → false.

#2 differs from the pooled #1 → false.

String str3 = new String("Giresun");

System.out.println(str1 == "Giresun");

System.out.println(str3 == "Giresun");

  • The Unicode codes of the first differing characters are subtracted: 'e' − 'a' = 101 − 97 = 4.
  • 'E' − 'e' = 69 − 101 = −32: uppercase letters come before lowercase.

Comparison · Step-by-step code trace

compareTo: Up to the First Difference

compareTo compares two strings character by character from the start.

k = 0: 'c' (99) and 'c' (99) are equal; continue.

k = 1: 'a' and 'a' are equal.

k = 2: 's' (115) and 'v' (118) differ: the comparison stops here.

The result is the code difference: 115 − 118 = −3. Negative: "case" comes first.

"car" and "cargo": the first 3 characters match and the shorter one runs out.

One is a prefix of the other: the length difference is returned, 3 − 5 = −2.

The first characters differ: 'Z' (90) − 'a' (97) = −7. Uppercase comes before lowercase: even Z precedes a!

-3 -2 -7 is printed.

String a = "case", b = "cave";
int r1 = a.compareTo(b);
int r2 = "car".compareTo("cargo");
int r3 = "Zeki".compareTo("ali");
System.out.println(r1 + " " + r2 + " " + r3);

Formatted Output

The printf Method

  • Usage: System.out.printf("format string", args);
  • The format string holds format specifiers; the arguments fill them in order.
  • printf adds no newline: append \n or the portable %n.
  • Width: %Wd → W characters, right-aligned; %-Wd → W characters, left-aligned.
  • Precision: %.2f → 2 decimal places (rounded); %8.2f → 8 characters in total.
  • A wider value is not cut; the field grows.

Formatted Output · Step-by-step code trace

Width and Precision, Character by Character

Without a width, each value takes exactly its own length; %f prints 6 decimal places.

%4d and %6s right-align the value, padding the left with spaces. -17,00 is 6 characters: it does not fit width 5, so the field grows.

The minus sign left-aligns: spaces go to the right of the value, so columns line up neatly.

%-6.3f: 3 decimals → -17,000 7 characters; wider than 6, so no padding.

int i = 3;
float f = -17;
String s = "java";
System.out.printf("x: %d y: %f s: %s\n", i, f, s);
System.out.printf("x: %4d y: %5.2f s: %6s\n", i, f, s);

  • %05d pads with leading zeros, %,d adds a thousands separator (tr-TR: period), %e scientific, %x hexadecimal, %% is a percent sign.
  • String.format(...) uses the same rules but, instead of printing, returns the formatted string.
  • The first argument can be a Locale: Locale.US gives a period as the decimal separator.
  • A type mismatch is a runtime error: printf("%d", 3.5) → IllegalFormatConversionException.

Palindrome Check: Step by Step

The text entered by the user: "Kayak".

toLowerCase() converts it to lowercase (the new object is assigned to text).

An empty string is prepared for the result.

i = 4: charAt(4) = 'k' is appended → "k".

i = 3: charAt(3) = 'a' is appended → "ka".

i = 2: charAt(2) = 'y' is appended → "kay".

i = 1: charAt(1) = 'a' is appended → "kaya".

i = 0: charAt(0) = 'k' is appended → "kayak".

i = -1: -1 >= 0 is false; the loop ends.

The reversed text is printed.

Same contents: equals → true, so “kayak” is a palindrome.

String text = "Kayak";
text = text.toLowerCase();
String rev = "";
for (int i = text.length() - 1; i >= 0; i--) {
  rev += text.charAt(i);
}
System.out.println(rev);
System.out.println(text.equals(rev));

A palindrome reads the same backward (kayak, level, noon). For sentences, first remove non-letters: text.replaceAll("[^\\p{L}]", "") (only letters remain). A shortcut for reversing: new StringBuilder(text).reverse().toString(); “A man, a plan, a canal: Panama” is a palindrome once cleaned.

Application: Word Frequency

String text = "One two one six TWO one";
String[] words = text.toLowerCase().split(" ");
boolean[] counted = new boolean[words.length];
for (int i = 0; i < words.length; i++) {
  if (counted[i]) {
    continue; // already counted
  }
  int freq = 1;
  for (int j = i + 1; j < words.length; j++) {
    if (words[i].equals(words[j])) {
      freq++;
      counted[j] = true;
    }
  }
  System.out.println(words[i] + ": " + freq);
}
Output
one: 3
two: 2
six: 1
  • toLowerCase() makes “One/one” and “TWO/two” the same word.
  • split(" ") splits the text into words.
  • Words are compared with equals: split returns separate objects, so == gives wrong results.
  • The counted array stops a word being reported twice.

static int count(String s, char target) {
  int n = 0;
  for (int i = 0; i < s.length(); i++) {

    }
