Öğrenme Çıktıları

Dizgi oluşturmak

String nesnesini deyimle (literal) ve new ile oluşturmak; + birleştirmesinin sırasını açıklamak.

İndeks ve metotlar

charAt, length, indexOf, substring ile parçalara erişmek; dizgiyi döngüyle dolaşmak.

Değiştirilemezlik

Metotların yeni nesne döndürdüğünü bellekte göstermek; döngüde StringBuilder kullanmak.

Kullanıcı girişi

Karşılaştırma

Biçimli çıktı

printf ve String.format ile genişlik, hizalama ve hassasiyeti ayarlamak.

Dizgi Kavramı

Dizgi (String) Nedir?

  • Dizgi (string), karakterlerden oluşan bir metni saklayan bir nesnedir; türü java.lang.String sınıfıdır.
  • String bir sınıftır, ilkel tür değildir; adı büyük harfle başlar. import gerekmez.
  • Çift tırnak içindeki "Tarkan" gibi sabitler dizgi deyimidir (string literal); nesne new kullanılmadan oluşur.
  • Karakterler Unicode ile saklanır: ç ğ ı İ ö ş ü gibi Türkçe harfler sorunsuzdur.
  • Tek karakter char ile tek tırnakta ('T'), metin String ile çift tırnakta ("T") yazılır.
String ad = "Tarkan";
String adSoyad = "Mustafa Sandal";
String nokta = "(" + 3 + ", " + 5 + ")";
System.out.println(ad);
System.out.println(adSoyad);
System.out.println(nokta);

İndeksleme (Indexing)

  • İlk karakterin indeksi 0, sonuncunun length() - 1.
  • charAt(i): i indisli karakter (char).
  • length() bir metottur, parantez gerekir (dizilerdeki length ise alandır).
  • Uzunluğu aşan ya da negatif indeks: çalışma anında StringIndexOutOfBoundsException.
  • char bir sayıdır (Unicode kodu): c + 1 sayı, (char) (c + 1) sonraki harf.
String isim = "Tarkan";
System.out.println(isim.length());
System.out.println(isim.charAt(0));
System.out.println(isim.charAt(isim.length() - 1));
char c = isim.charAt(2);
System.out.println(c + 1);
System.out.println((char) (c + 1));

Değiştirilemezlik

Değiştirilemez (Immutable) Nesne

  • String nesneleri oluşturulduktan sonra değiştirilemez (immutable).
  • toUpperCase, replace, substring, + orijinali değiştirmez; yeni bir nesne döndürür.
  • Sonucu kullanmak için atamak gerekir: s = s.toUpperCase();
  • Faydaları: güvenli ve tutarlı kod (dizgiyi paylaşan kodlar birbirini bozamaz), dizgi havuzu (string pooling) ile bellek tasarrufu, iş parçacıkları arasında güvenli paylaşım.
Benzetme: dizgi bir taş tablettir. Kazıyıp düzeltemezsiniz; yeni bir tablet yazıp eskisinin yerine koyarsınız.
String s = "Giresun Üniversitesi";
s.toUpperCase();      // sonuç kaybolur
System.out.println(s);
s = s.toUpperCase();  // sonuç s'ye atanır
System.out.println(s);

next() ve nextLine(): Adım Adım

İstem yazılır; program kullanıcının satırı girmesini bekler.

Kullanıcı satırı yazıp Enter'a basar (tamponda ⏎ de vardır). next() ilk boşluğa kadar okur: "bilgisayar".

Okunan kelime yazdırılır. İmleç boşluğun önünde bekler.

next() önce boşluğu atlar, sonra "ve" kelimesini okur.

Yazdırılır. İmleç yine bir boşluğun önünde.

nextLine() boşluğu atlamaz: satır sonuna kadar okur, ⏎'yi tüketir: " programlamaya giriş".

Baştaki boşlukla birlikte yazdırılır. Tampon boşaldı.

Karşılaştırma

== ile Karşılaştırma

  • == işleci nesnelerin referanslarını (bellekteki adreslerini) karşılaştırır, içeriklerini değil.
  • İki değişken aynı nesneyi gösteriyorsa true, içerik aynı olsa bile farklı nesneler ise false döner.
  • str1 == str2'nin true çıkması bir şans değil, dizgi havuzunun sonucudur (sonraki slayt).
Kural: dizgilerin içeriğini karşılaştırırken asla == kullanmayın; equals() kullanın.
String str1 = "Giresun";
String str2 = "Giresun";
String str3 = new String("Giresun");
System.out.println(str1 == str2);        // true
System.out.println(str1 == "Giresun");   // true
System.out.println(str1 == str3);        // false
System.out.println(str3 == "Giresun");   // false

Karşılaştırma

Dizgi Havuzu (String Pool)

  • Kaynak koddaki "giresun" gibi sabit ifadeler dizgi deyimleridir (literal).
  • Deyimler öbekteki özel bir bölgede, dizgi havuzunda saklanır: içeriği aynı deyimler aynı nesneyi paylaşır. Bellek kullanımı azalır, performans artar (dizgiler değiştirilemediği için güvenlidir).
  • new String(...) havuza tabi değildir: her new yeni bir nesne demektir.
  • Bu yüzden ==, içeriği aynı deyimlerde true, içeriği aynı new nesnelerinde false döner.
  • Çalışma anında + ile üretilen dizgi de yeni nesnedir; derleme anında hesaplanan "Gire" + "sun" ise havuza gider. s.intern() havuzdaki eşini verir.

İki deyim tek nesneyi paylaşır; new ayrı bir nesne üretir.

Karşılaştırma

Karşılaştırma Metotları: Örnek

String s = "Giresun Üni.";
System.out.println(s.startsWith("Gir"));                // true
System.out.println(s.startsWith("Gır"));                // false
System.out.println(s.endsWith("Üni."));                 // true
System.out.println(s.endsWith("Üni"));                  // false
System.out.println(s.equalsIgnoreCase("Giresun Üni.")); // true
System.out.println(s.equalsIgnoreCase("Gıresun üni.")); // true
System.out.println(s.equalsIgnoreCase("GIresun Uni.")); // false
System.out.println(s.contains("Üni"));                  // true
  • Yorumlardaki sonuçlar programın gerçek çıktısıdır.
  • "Gır": ı ile i farklı karakterlerdir → false.
  • "Üni": dizgi noktayla bitiyor → false.
  • equalsIgnoreCase karakterleri büyük harfe çevirerek karşılaştırır: ı ve i'nin ikisi de I olur → "Gıresun üni." eşit sayılır.
  • "GIresun Uni.": U ile Ü farklı harflerdir → false.

Biçimli Çıktı

printf Metodu

  • Kullanım: System.out.printf("biçim dizgisi", parametreler);
  • Biçim dizgisi, parametrelerin yerleşeceği yer tutucuları (format specifier) içerir; parametreler sırayla yerleşir.
  • printf alt satıra geçmez: sona \n ya da platformdan bağımsız %n eklenir.
  • Genişlik: %Wd → W karakter, sağa hizalı; %-Wd → W karakter, sola hizalı.
  • Hassasiyet: %.2f → virgülden sonra 2 basamak (yuvarlanır); %8.2f → toplam 8 karakter.
  • Değer genişliğe sığmazsa kesilmez, alan genişler.

Palindrom Kontrolü: Adım Adım

Kullanıcının girdiği metin: "Kayak".

toLowerCase() ile küçük harfe çevrilir (yeni nesne metin'e atanır).

Sonuç için boş bir dizgi hazırlanır.

i = 4: charAt(4) = 'k' sona eklenir → "k".

i = 3: charAt(3) = 'a' sona eklenir → "ka".

i = 2: charAt(2) = 'y' sona eklenir → "kay".

i = 1: charAt(1) = 'a' sona eklenir → "kaya".

i = 0: charAt(0) = 'k' sona eklenir → "kayak".

i = -1: -1 >= 0 yanlış, döngü biter.

Ters çevrilmiş metin yazdırılır.

İçerikler aynı: equals → true, “kayak” bir palindromdur.

String metin = "Kayak";
metin = metin.toLowerCase();
String ters = "";
for (int i = metin.length() - 1; i >= 0; i--) {
  ters += metin.charAt(i);
}
System.out.println(ters);
System.out.println(metin.equals(ters));

Palindrom: tersten okunuşu aynı olan metin (kayak, ana, kek). Cümlelerde önce harf olmayanlar silinir: metin.replaceAll("[^\\p{L}]", "") (yalnızca harfler kalır).

static String basHarfBuyuk(String kelime) {

static int say(String s, char aranan) {

  for (int i = 0; i < s.length(); i++) {
    if (s.charAt(i) == aranan) {
      adet++;
    }
  }
  return adet;
}
