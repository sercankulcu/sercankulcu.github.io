Sıralı işlem, karar ve döngü yapılarının programın akışını nasıl yönlendirdiğini açıklamak.

Karar yapıları

if, if-else, else if zinciri, iç içe kararlar ve ?: işleci ile koşula bağlı kod yazmak.

switch-case

Bir değeri sabitlerle karşılaştırmak; break'in görevini ve “aşağı düşme” davranışını açıklamak.

Döngüler

for, while ve do-while döngülerini doğru yerde seçmek; sonsuz döngü ve sınır hatalarından kaçınmak.

İç içe döngüler

Desen, tablo ve basamak örneklerinde iç içe döngülerin kaç kez döndüğünü hesaplamak.

Bir programı adım adım izleyerek değişken değerlerini ve ekran çıktısını önceden bulmak; break ve continue'nun etkisini göstermek.

Giriş

Kontrol Yapıları

  • Kontrol yapıları (control structures) programın akışını, yani deyimlerin hangi sırayla ve kaç kez çalışacağını yönlendirir.
  • Java'da üç temel kontrol yapısı vardır; her program bu üçünün birleşimiyle yazılabilir:
Sıralı işlemler

Deyimler yukarıdan aşağıya, birer kez çalışır.

Karar yapıları

Koşula göre iki (veya daha çok) yoldan biri seçilir: if-else, switch.

Döngüler

Koşul sağlandıkça işlemler tekrarlanır: for, while, do-while.

Önemi: kararlar sayesinde program farklı durumlara ve kullanıcı girdilerine farklı tepki verir; döngüler tekrar eden işleri otomatikleştirir. Programlar böylece esnek ve güçlü olur.

Giriş · Kodu adım adım çalıştır

Sıralı İşlemler

Kod, yukarıdan aşağıya doğru satır satır sırayla çalışır; bir işlem bitmeden diğeri başlamaz. Kontrol yapısı kullanılmayan her program sıralıdır.

İlk satır çalışır: x'e 5 yazılır. Sonraki satır bu satır bitmeden başlamaz.

İkinci satır: y'ye 10 yazılır.

Üçüncü satır, önceki iki satırın sonuçlarını kullanır: 5 + 10 = 15.

Son satır sonucu ekrana yazar. Satırların sırası değişseydi (ör. 3. satır en başta) program derlenmezdi.

int x = 5;
int y = 10;
int sonuc = x + y;
System.out.println(sonuc);

Karar Yapıları: if

Karar Verme İşlemi

  • Karar verme, programın hangi yolu izleyeceğine çalışma anında karar vermesidir.
  • Belirli koşullara bağlı olarak farklı işlemleri yürütme yeteneği sağlar.
  • Java'da if-else ve switch-case ile yapılır.
  • Koşul, sonucu true ya da false olan bir mantıksal ifadedir (boolean expression).
  • Benzetme: yol ayrımındaki tabela. “Hava yağmurluysa şemsiye al, değilse alma.”
  • Önemi: program farklı şartlara ve kullanıcı girdilerine tepki verir, kodun akışı yönlendirilir, esneklik artar.
İşleçAnlamıÖrnek (x = 7)

= atamadır, == karşılaştırmadır. if (x = 7) derlenmez: koşul boolean olmalıdır.

Karar Yapıları: if

if-else Yapısı

if (koşul) {
    // Koşul doğruysa burası çalışır
} else {
    // Koşul yanlışsa burası çalışır
}
  • Önce koşul değerlendirilir.
  • Koşul doğru (true) ise if bloğu çalışır, else bloğu atlanır.
  • Koşul yanlış (false) ise if bloğu atlanır, else bloğu çalışır.
  • else kısmı isteğe bağlıdır (opsiyonel). İki bloktan en fazla biri çalışır.
  • Koşul her zaman parantez içinde yazılır: if (koşul).

else-if Zinciri

import java.util.Scanner;

public class PozitifNegatif {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        System.out.print("Bir sayı girin: ");
        double sayi = scanner.nextDouble();
        if (sayi > 0) {
            System.out.println("Sayı pozitif.");
        } else if (sayi < 0) {
            System.out.println("Sayı negatif.");
        } else {
            System.out.println("Sayı sıfır.");
        }
    }
}

  • Hiçbiri doğru değilse son else çalışır (varsa).

else-if Zinciri: Harf Notu

not = 75.

75 >= 90 → false. Sonraki else if'e geçilir.

75 >= 80 → false. Sonraki koşula geçilir.

75 >= 70 → true: ilk doğru koşul bulundu.

“C” yazılır.

Kalan koşullar (not >= 60 dahil) hiç sınanmaz. Sıra önemlidir: >= 60 en üstte olsaydı 75 için “D” yazılırdı.

int not = 75;
if (not >= 90) {
    System.out.println("A");
} else if (not >= 80) {
    System.out.println("B");
} else if (not >= 70) {
    System.out.println("C");
} else if (not >= 60) {
    System.out.println("D");
} else {
    System.out.println("F");
}

Karar Yapıları: if

İç İçe Kararlar (Nesting)

  • Bir karar yapısının bloğu içinde başka bir karar yapısı kullanılabilir.
  • Daha karmaşık koşullar ve işlemler için kullanışlıdır: dış koşul sağlandıktan sonra ikinci bir soru sorulur.
  • İç if yalnızca dış koşul doğruysa sınanır.
  • Çok derin iç içe yapı kodun okunabilirliğini olumsuz etkiler: düzgün girinti kullanın; mümkünse && veya else if ile düzleştirin.
if (koşul1) {
    if (koşul2) {
        // koşul1 VE koşul2 doğru
    }
} else {
    // koşul1 yanlış
}

not = 85.

Karar Yapıları: if

Kısa Devre Değerlendirme

int a = 10, b = 0;
if (b != 0 && a / b > 2) {
    System.out.println("Bölüm 2'den büyük.");
} else {
    System.out.println("Bölme yapılmadı.");
}
int gun = 7;
if (gun == 6 || gun == 7) {
    System.out.println("Hafta sonu");
}
if (!(gun == 6 || gun == 7)) {
    System.out.println("Hafta içi");
}
Bölme yapılmadı.
Hafta sonu
  • && ve || soldan sağa değerlendirilir ve sonuç belli olunca durur (short-circuit).
  • b != 0 false olduğu için a / b hiç hesaplanmaz; sıfıra bölme hatası (ArithmeticException) oluşmaz.
  • Sıra ters yazılsaydı (a / b > 2 && b != 0) program bölmede çökerdi. Güvenlik denetimini sola yazın.
  • ||: sol taraf true ise sağ taraf sınanmaz (gun == 6 false, gun == 7 true → “Hafta sonu”).
  • !( … ) parantezdeki sonucun tersidir; burada false olduğu için “Hafta içi” yazılmaz.

Karar Yapıları: switch

switch-case Yapısı

  • switch-case, bir değişkenin değerini bir dizi sabit değerle karşılaştırır ve duruma göre farklı işlemleri gerçekleştirir.
  • Birden çok şarta dayalı bir yol seçmeye yarar.
  • Aynı değişken için çok sayıda == karşılaştırması olduğunda else if zincirinden daha düzenlidir.
  • Benzetme: asansör düğmeleri. Basılan kat numarası hangi kata gidileceğini seçer.
switch (değişken) {  // kontrol edilen değer
    case değer1:     // her case bir değer
        // İşlemler 1
        break;
    case değer2:
        // İşlemler 2
        break;
    // ...
    default:         // hiçbiri eşleşmezse
        // Varsayılan işlemler (opsiyonel)
}

Karar Yapıları: switch

switch-case İşleyişi

  • Değişken, case değerleriyle yukarıdan aşağıya karşılaştırılır.
  • Eşleşen case bulunursa o case'in işlemleri çalıştırılır, ardından break ile switch'ten çıkılır.
  • Eşleşen case yoksa default bölümü (varsa) çalışır.
  • default da yoksa hiçbir şey yapılmadan switch'ten çıkılır.
  • break yazılmazsa çalışma bir sonraki case'e düşer (fall-through).

Karar Yapıları: switch · Kodu adım adım çalıştır

Örnek: Mevsim Belirleme

ay = 4.

mevsim tanımlanır, henüz değeri yok.

switch (ay): değer 4 olarak bir kez hesaplanır, sonra case etiketleri aranır.

case 4 eşleşir. Aynı satırdaki üç case aynı koda iner.

mevsim = "İlkbahar".

break: switch'in kapanış parantezinin (satır 18) arkasına atlanır.

default sayesinde mevsim her yolda değer alır; yoksa: variable mevsim might not have been initialized.

int ay = 4;
String mevsim;
switch (ay) {
    case 3: case 4: case 5:
        mevsim = "İlkbahar";
        break;
    case 6: case 7: case 8:
        mevsim = "Yaz";
        break;
    case 9: case 10: case 11:
        mevsim = "Sonbahar";
        break;
    case 12: case 1: case 2:
        mevsim = "Kış";
        break;
    default:
        mevsim = "Bilinmiyor";
}
System.out.println(ay + ". ay: " + mevsim);

break Unutulursa: Aşağı Düşme

gun = 2.

2 değeriyle eşleşen case aranır.

case 1 atlanır, case 2 eşleşir.

“Salı” yazılır. Burada break yok!

case 3: etiketi bir karşılaştırma değildir; çalışma alttaki koda “düşer” (fall-through).

“Çarşamba” da yazılır, oysa gün 3 değil.

break ile switch'ten çıkılır; default çalışmaz.

switch'ten sonra devam edilir. Her case'e break yazın.

int gun = 2;
switch (gun) {
    case 1:
        System.out.println("Pazartesi");
    case 2:
        System.out.println("Salı");
    case 3:
        System.out.println("Çarşamba");
        break;
    default:
        System.out.println("Diğer gün");
}
System.out.println("switch bitti");

int ay = 11;

  • Ok biçiminde aşağı düşme yoktur; break gerekmez.
  • switch ifadesi bir değer üretir ve doğrudan atanabilir; sonuna ; konur.
  • İfade biçimi tüm olasılıkları kapsamalıdır: int için default zorunludur.

Uygulama: Sıcaklık

Sıcaklık Dönüşümü: Tek Değer

public class Program {
    public static void main(String[] args) {
        double celsius = 25.0;
        double fahrenheit = (celsius * 1.8) + 32;
        double kelvin = celsius + 273.15;
        System.out.println(celsius + " °C = " + fahrenheit + " °F = " + kelvin + " K");
    }
}
25.0 °C = 77.0 °F = 298.15 K
  • Sıralı bir programdır: üç satır hesaplama, bir satır yazdırma; karar ya da döngü yoktur.
  • Ondalıklı değerler için double kullanılır. Parantez önceliği netleştirir: önce celsius * 1.8, sonra + 32.
  • + bir dizgeyle (String) kullanılınca birleştirme yapar; double değerler 25.0 biçiminde yazılır.
  • Hesaplanan her değer kullanılmalıdır: kelvin yazdırılmasaydı boşuna hesaplanmış olurdu.

Döngü ve Türleri

Döngü (loop), aynı işlemi birden çok kez tekrarlamak için kullanılır. Benzetme: pistte 10 tur koşmak; her turda aynı hareketler, tur sayacı bir artar.

for

Tekrar sayısı belli olduğunda; belirli bir aralıktaki değerlerle çalışır.

for (int i = 0; i < 5; i++) { … }

while

Belirli bir koşul sağlandığı sürece çalışır; tekrar sayısı önceden bilinmeyebilir.

while (koşul) { … }

do-while

Koşul sona yazılır; gövde en az bir kez çalışır.

do { … } while (koşul);

  • Döngüler bir veri kümesinin sırayla işlenmesi ve işlem tekrarları için kullanışlıdır; özellikle diziler ve listelerle çalışırken önemlidir.
  • Aynı satırı 100 kez yazmak yerine tek bir döngü: kod daha kısa, düzenli ve okunabilir olur.

Döngüler

for Döngüsü

  • Başlık, döngünün başlangıç, koşul ve güncelleme (artırma) adımlarını tek satırda belirler; aralarında ; vardır.
  • Her döngü dönüşünden (tur, iteration) önce koşul kontrol edilir; güncelleme adımı döngü değişkenini değiştirir.
  • Çalışma sırası: 1 → 2 → 4 → 3 → 2 → 4 → 3 → … → 2 yanlış → döngüden çık.
  • i = 0, 1, 2, 3, 4 için gövde 5 kez çalışır; i 5 olunca koşul yanlış olur. i yalnızca döngünün içinde tanımlıdır.

Döngülerin İşleyişi

  • Döngü başlangıç adımıyla başlar.
  • Koşul kontrol edilir.
    • Koşul sağlanıyorsa döngü içindeki işlemler yapılır.
    • Güncelleme (artırma) adımı uygulanır (for döngüsü için).
    • Koşul hâlâ sağlanıyorsa tekrar döngü içine girilir.
  • Koşul sağlanmazsa döngüden çıkılır ve sonraki deyimle devam edilir.
  • Koşul ilk kontrolde yanlışsa gövde hiç çalışmaz.

1. Başlangıç: döngü değişkeni ilk değerini alır (bir kez).

2. Koşul kontrol edilir.

3. Koşul doğruysa gövde çalışır.

4. Güncelleme: döngü değişkeni değişir.

5. Koşula geri dönülür; doğru oldukça 3–4–5 tekrarlanır.

6. Koşul yanlış olunca döngüden çıkılır.

Özet

          
Sık Yapılan Hatalar: Kararlar

          

            
= ile karşılaştırmaif (x = 5) → error: incompatible types: int cannot be converted to boolean. Doğrusu x == 5.

            
if'ten sonra noktalı virgülif (x > 5); { … } derlenir ama ; boş deyimdir: blok her zaman çalışır.

            
Parantezsiz blokif (k) a(); b(); else c(); → error: 'else' without 'if'. Birden çok deyim için { } şarttır.

            
break'i unutmakswitch'te break yoksa alttaki case'ler de çalışır (aşağı düşme). Derleyici uyarmaz.

            
default olmadan atamaDeğişken yalnızca case'lerde atanıyorsa: error: variable mevsim might not have been initialized. default ekleyin.

            
Ondalık girişte noktaTürkçe bölge ayarında nextDouble() için -7.5 → InputMismatchException. -7,5 yazılmalı.

          

        


        

          
Özet

          
Sık Yapılan Hatalar: Döngüler

          

            
Sonsuz döngüwhile'da güncellemeyi (i++) unutmak ya da yanlış yönde güncellemek (i-- ile i <= 10). Derleyici yakalamaz; program durmaz.

            
Döngü başlığında ;for (int i = 0; i < 3; i++); veya while (i < 5); gövdesi boş bir döngüdür; alttaki blok döngüye ait değildir.

            
Sınır hatası (off-by-one)“1'den 10'a kadar” için i < 10 yazmak 10'u atlar; i = 0 ile i <= 10 11 tur döner. İlk ve son turu kontrol edin.

            
Döngü değişkenini dışarıda kullanmakfor (int i …) { } sonrası println(i) → error: cannot find symbol. Gerekirse i'yi döngüden önce tanımlayın.

            
break'ten sonra kodbreak; System.out.println(i); → error: unreachable statement. break'ten sonraki satıra asla ulaşılmaz.

            
Toplam/çarpım başlangıcıToplam 0, çarpım 1 ile başlar. faktoriyel = 0 ile sonuç hep 0 olur. Değişkeni döngünün içinde sıfırlamak da yanlıştır.

}
System.out.println(puan);

Problem 4
1'den 100'e kadar olan sayılardan 3'e veya 5'e tam bölünenlerin toplamını bulan kodu yazın.

            
Problem 5
Bir tam sayının (ör. 2024) kaç basamaklı olduğunu while döngüsüyle bulun. İpucu: sayi /= 10.

          

          

            Cevaplar
            

              
int toplam = 0;
for (int i = 1; i <= 100; i++) {
    if (i % 3 == 0 || i % 5 == 0) {
        toplam += i;
    }
}
System.out.println(toplam);
Çıktı: 2418. Her sayı bir kez denenir; || sayesinde 15 gibi ortak katlar iki kez eklenmez.

              
int sayi = 2024, basamak = 0;
while (sayi > 0) {
    basamak++;
    sayi /= 10;
}
System.out.println(basamak);
Çıktı: 4. Her turda son basamak atılır: 2024 → 202 → 20 → 2 → 0.
