ASCII Tablosu

    
0'dan 255'e kadar karakter kodlarını gezer; onluk değere, onaltılık değere (0x41) ya da görünen karaktere göre arar; standart ASCII aralığını yaygın iki 8 bitlik genişletmeyle karşılaştırır.

    
Kullanım

    
    
      
  • 0–127 / 128–255 tablonun gösterilen yarısını değiştirir. Sütun başlığı alt onaltılık basamak, satır başlığı üst onaltılık basamaktır (4_ satırı, 1 sütunu → 0x41 = 65 = 'A').
    • 
      
  • Bir hücreye tıklanır ya da ok tuşlarıyla ilerlenir (Home / End ilk / son hücreye atlar). Sağdaki panel kodun onluk, onaltılık, sekizlik ve ikilik değerini, Unicode kod noktasını, UTF-8 baytlarını ve Java char sabitini gösterir.
    • 
      
  • Arama kutusuna yazıldıkça eşleşmeyen hücreler soluklaşır; Enter ilk eşleşmeyi seçer.
    • 
    

    
Karakter kodlamaları

    
    
      
  • 0–127 arası kodlar standart ASCII'dir: 0–31 ve 127 kontrol karakterleridir (ör. 9 TAB '\t', 10 LF '\n', 13 CR '\r'), 32 boşluktur.
    • 
      
  • 128–255 arası kodlar ASCII'nin parçası değildir. ISO-8859-1'de n baytı tam olarak U+00nn Unicode kod noktasıdır; bu görünüm aynı zamanda ilk 256 Unicode kod noktasıdır (128–159 C1 kontrol karakterleridir).
    • 
      
  • Windows-1254 Türkçe kod sayfasıdır: Ğ ğ İ ı Ş ş harflerini 208, 240, 221, 253, 222, 254 kodlarına yerleştirir; 128–159 aralığını € ve “ ” gibi yazdırılabilir simgeler için kullanır. ISO-8859-1'den farklı hücreler gölgelidir; beş kod tanımsızdır. Burada Java char değeri bayttan farklıdır: 208 baytı 'Ğ' = U+011E = 286 olarak çözülür.
    • 
      
  • Java char tipi 16 bitlik bir UTF-16 kod birimidir; bu yüzden (int) 'A' 65, (char) 65 ise 'A' olur. UTF-8'de 0–127 arası kodlar bir bayt, tablonun geri kalanı iki ya da üç bayt tutar.
    • 
    

    
Windows-1254 eşlemesi ve UTF-8 baytları Java ile üretildi (new String(bytes, "windows-1254"), getBytes("UTF-8")).
