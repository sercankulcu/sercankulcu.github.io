Kavram

Kalıtımı (inheritance), üst sınıf ve alt sınıf kavramlarını tanımlamak; “is-a” ilişkisini tanımak.

Söz dizimi

extends ile alt sınıf yazmak; neyin kalıtımla alındığını, neyin alınmadığını açıklamak.

Yapıcılar

super(...) ve super.metot() kullanmak; yapıcı zincirinin çalışma sırasını izlemek.

Geçersiz kılma

Metodu geçersiz kılmak (overriding), aşırı yüklemeden (overloading) ayırmak, @Override kullanmak.

Erişim ve sınırlama

protected erişimini ve final ile kalıtımın nasıl sınırlandığını açıklamak.

Object sınıfı

toString, equals ve hashCode metotlarını doğru yazmak; == ile equals farkını bilmek.

Kalıtım Kavramı

Kalıtım Nedir?

  • Kalıtım (Inheritance): mevcut bir sınıfın alan ve metotlarını kalıtımla alıp yeni veya değiştirilmiş yeteneklerle zenginleştirerek yeni bir sınıf oluşturmaktır.
  • Mevcut sınıf: üst sınıf (superclass).
  • Yeni sınıf: alt sınıf (subclass).
  • Alt sınıfa yeni alan ve metotlar eklenebilir; kalıtımla alınan alanlar yeniden tanımlanmaz.
Benzetme: “Her dikdörtgen bir şekildir.” Dikdörtgen, şeklin her şeyine sahiptir; üstüne kendi en, boy ve alan() bilgisini ekler.

Kalıtım Kavramı

extends ile Alt Sınıf

// Temel sınıf (üst sınıf)
public class Sekil {
    // Temel sınıfa ait nitelik ve metotlar
    // ...
}

// Yeni sınıf (alt sınıf), Sekil'den türer
public class Dikdortgen extends Sekil {
    // Yeni sınıfa ait nitelik ve metotlar
    // ...
}
  • Söz dizimi: class AltSinif extends UstSinif. extends: “genişletir”.
  • extends sonrasına yalnızca bir sınıf yazılabilir.
  • Alt sınıf, üst sınıfın public ve protected üyelerini kendi üyesiymiş gibi kullanır.
  • Üst sınıftaki aynı adlı alanı alt sınıfta yeniden tanımlamak onu gizler (hiding); iki ayrı değişken oluşur ve kafa karıştırır. Yapılmamalıdır.
  • extends yazılmazsa sınıf, gizlice Object sınıfından türer.

Kalıtım Kavramı

Alt ve Üst Sınıf

  • Alt sınıf, üst sınıfın davranışlarını sergiler; ek olarak kendine özgü davranışlar da sergiler.
  • Kalıtım bu yüzden özelleştirme (specialization) olarak da adlandırılır: alt sınıf daha özel bir grubu temsil eder.
  • Her kedi bir hayvandır, ama her hayvan kedi değildir.
  • Java sınıf hiyerarşisi, java.lang paketindeki Object sınıfı ile başlar.
  • Her sınıf, doğrudan veya dolaylı olarak Object sınıfından kalıtımla alır.

Kalıtım Kavramı

Kalıtım Türleri

  • Tek düzeyli (single): bir alt sınıf, bir üst sınıf. Kedi extends Hayvan.
  • Çok düzeyli (multilevel): zincir biçiminde. Kedi, Canli'nin üyelerini Hayvan üzerinden alır; her düzey bir öncekinin her şeyini taşır.
  • Hiyerarşik (hierarchical): bir üst sınıftan birçok alt sınıf. Ortak kod bir kez yazılır, her alt sınıf yalnızca farkını ekler.
  • Çoklu (multiple): bir sınıfın birden çok üst sınıfı. Java sınıflarda buna izin vermez; aynı ihtiyaç arayüzlerle karşılanır.
Java'da sınıf hiyerarşisi bir ağaçtır: kökü Object'tir ve Object dışındaki her sınıfın tam olarak bir doğrudan üst sınıfı vardır. Zincirin derinliği sınırsızdır, ama derin zincirler okunmayı ve değiştirmeyi zorlaştırır.

Kalıtım Kavramı

Ortak Kodu Üst Sınıfa Taşımak

Genelleştirme (generalization): birkaç sınıfta tekrar eden alan ve metotları bulup ortak bir üst sınıfa taşımak. Özelleştirmenin ters yönüdür.

Önce: aynı kod iki yerde

class Ogrenci {
    private String ad;
    private int yas;
    private double ortalama;
    String kimlik() { return ad + " (" + yas + ")"; }
}
class Ogretmen {
    private String ad;
    private int yas;
    private String brans;
    String kimlik() { return ad + " (" + yas + ")"; }
}

Yaş biçimi değişirse iki sınıf da düzeltilmeli; biri unutulursa çıktılar tutarsız olur.

Sonra: ortak kısım Kisi'de

class Kisi {
    private String ad;
    private int yas;
    Kisi(String ad, int yas) { this.ad = ad; this.yas = yas; }
    String kimlik() { return ad + " (" + yas + ")"; }
}
class Ogrenci extends Kisi {
    private double ortalama;
    Ogrenci(String ad, int yas, double ortalama) {
        super(ad, yas);
        this.ortalama = ortalama;
    }
    @Override String kimlik() {
        return super.kimlik() + ", ort. " + ortalama;
    }
}   // Ogretmen de aynı biçimde: brans eklenir
Ece (20), ort. 3.4
Murat (41), Fizik

Taşımadan önce sorulacak soru: “Her öğrenci bir kişi midir?” Evet ise genelleştirme doğrudur; yalnızca iki sınıfın birkaç alanı benziyorsa oluşum daha uygundur.

Hayvan Örneği

Hayvan Sınıf Hiyerarşisi

Ortak alan ve metotlar bir kez, Hayvan sınıfında yazılır. Her alt sınıf konus() metodunu kendine göre geçersiz kılar ve kendine özgü bir metot ekler. UML'de kalıtım, ucu üst sınıfa dönük içi boş üçgen okla gösterilir.

Hayvan Örneği

Hayvan ve Kopek Sınıfları

public class Hayvan {
    private String isim;     // ortak nitelikler
    private int yas;
    private double saglik;

    public Hayvan(String isim, int yas) {
        this.isim = isim;
        this.yas = yas;
        this.saglik = 100.0;
    }
    public String getIsim() { return isim; }   // private isim'e erişim yolu
    public void konus() {
        System.out.println("Bu hayvan konuşur.");
    }
    public void uyu() {
        saglik += 5;
        System.out.println(isim + " uyudu. Sağlık: " + saglik);
    }
}

Üst sınıf Hayvan: bütün hayvanlarda ortak olan alanlar ve davranışlar.

public class Kopek extends Hayvan {
    public Kopek(String isim, int yas) {
        super(isim, yas);   // üst sınıf yapıcısı alanları doldurur
    }
    @Override
    public void konus() {   // miras alınan davranışı değiştirir
        System.out.println(getIsim() + " havlar.");
    }
    public void topOyna() { // yalnızca Kopek'te olan davranış
        System.out.println(getIsim() + " top oynuyor!");
    }
}
Kopek kopek = new Kopek("Karabaş", 4);
kopek.konus();     // Kopek'in sürümü
kopek.topOyna();   // Kopek'e özgü
kopek.uyu();       // Hayvan'dan miras
Karabaş havlar.
Karabaş top oynuyor!
Karabaş uyudu. Sağlık: 105.0

Alt sınıf Kopek yalnızca farkı yazar; uyu() hiç yazılmadığı hâlde çalışır.

Kalıtımın Avantajları

Yeniden kullanım

Üst sınıfın metot ve alanları alt sınıfta yeniden yazılmadan kullanılır.

Genişletme

Mevcut sınıf, kodu değiştirilmeden yeni özelliklerle genişletilir.

Değiştirme

Üst sınıfın metotları alt sınıfta geçersiz kılınarak (overriding) değiştirilebilir.

public class GelismisHesapMakinesi
        extends HesapMakinesi {
    // Yeni yetenek: üs alma
    public double us(double taban, int us) {
        double sonuc = 1.0;
        for (int i = 0; i < us; i++) {
            sonuc *= taban;
        }
        return sonuc;
    }
    // faktoriyel(int) benzer biçimde eklenir
}
// main içinde
GelismisHesapMakinesi h = new GelismisHesapMakinesi();
System.out.println(h.topla(5, 3));         // 8.0  (miras)
System.out.println(h.hafizayiGoruntule()); // 8.0  (miras)
System.out.println(h.us(2, 5));            // 32.0 (yeni)

Yapıcılar ve super

super Anahtar Kelimesi

  • super(...): alt sınıfın yapıcısı içinde üst sınıfın yapıcısını çağırır; üst sınıfın alanlarına ilk değerleri o atar.
  • super(...) yapıcının ilk satırı olmalıdır (Java 25'ten önce; Java 25 önüne nesneye dokunmayan deyimlere izin verir).
  • Yazılmazsa derleyici gizlice super(); (parametresiz) ekler.
  • super.metot(): üst sınıfın metoduna nokta (.) ile erişir; geçersiz kılınmış bir metodun içinden üst sınıfın sürümünü çağırmak için kullanılır.
  • İlke: her sınıf yalnızca kendi verilerini yönetmelidir. Kedi, Hayvan'ın isim alanına kendisi atama yapmaz; işi super(isim)'e bırakır.
class Kedi extends Hayvan {
    private boolean evcil;

    Kedi(String isim, boolean evcil) {
        super(isim);         // Hayvan(String)
        this.evcil = evcil;  // kendi verisi
    }

    @Override
    public String toString() {
        return super.toString()   // Hayvan'ınki
               + ", Evcil: " + evcil;
    }
}
// main içinde
System.out.println(new Kedi("Mavi", true));

Çıktı

İsim: Mavi, Sağlık: 100.0, Evcil: true

Hayvan'ın toString() metodu isim ve sağlık bilgisini döndürür; Kedi yalnızca kendi alanını ekler.

super.tanit() Zinciri: Kod İzleme

Nesne bir Kedi; arama en alttan başlar ve Kedi.tanit() bulunur.

super.tanit(): bir üst sınıfın sürümü çağrılır. Kedi.tanit bekler, yığında kalır.

Nesne hâlâ bir Kedi olsa da Hayvan içindeki super sabit olarak Canli'yi gösterir: dinamik bağlama yok.

En üstteki sürüm çalışır ve ilk satırı yazar; sonra döner.

Hayvan.tanit() kaldığı yerden sürer: Hayvanım.

Son olarak Kedi.tanit() kendi satırını yazar.

Çağrılar Kedi → Hayvan → Canli yönünde gitti, çıktılar ters sırada geldi: her sınıf önce üst sınıfın işini yaptırıp sonra kendi farkını ekledi.

class Canli {
    void tanit() { System.out.println("Canlıyım"); }
}
class Hayvan extends Canli {
    void tanit() {
        super.tanit();
        System.out.println("Hayvanım");
    }
}
class Kedi extends Hayvan {
    void tanit() {
        super.tanit();
        System.out.println("Kediyim");
    }
}
new Kedi().tanit();   // main

Kedi yapıcısı çağrılır. Kendi işine başlamadan önce üst sınıf kısmı hazırlanmalıdır.

super(isim): Hayvan yapıcısı çağrılır; Kedi yapıcısı bekler.

Hayvan da önce kendi üst sınıfını çağırır: Object(). Her zincir Object'te biter.

Object() döndü. Hayvan kendi alanını doldurur: isim = "Mavi".

saglik = 100.0.

this(...) ve super(...): Kod İzleme

new önce nesneye yer ayırır; üç alan da varsayılan değerdedir. Ardından Yonetici(String) çağrılır.

İlk satır this(ad, 5000.0): aynı sınıfın iki parametreli yapıcısına geçilir. Yonetici(String) gövdesini henüz çalıştırmadan bekler.

super(ad): üst sınıf Calisan'ın tek parametreli yapıcısı. Yönetici kısmının kurulması, Calisan kısmı bitene kadar bekler.

Calisan da this(...) ile devreder. Bu yapıcının ilk satırı this ya da super olmadığı için derleyici gizli super() ekler: Object() çalışıp döner.

İlk gövde burada çalışır: ad ve maas dolar, ilk satır yazılır. Çağrılar aşağı doğru gitmişti, gövdeler en üstteki sınıftan başlayarak tamamlanır.

İki parametreli yapıcı döndü; Calisan(String) kendi satırını yazar.

super(ad) tamamlandı. Ancak şimdi alt sınıfın kendi alanı dolar: prim = 5000.0.

En son, ilk çağrılan Yonetici(String) biter. Dört yapıcı çalıştı ama tek bir nesne kuruldu.

Nesnenin adresi y'ye atanır. gelir(), kalıtımla gelen getMaas() ile kendi prim alanını toplar: 25000.0.

class Calisan {
    private String ad;  private double maas;
    Calisan(String ad) {
        this(ad, 20000.0);
        System.out.println("Calisan(String)");
    }
    Calisan(String ad, double maas) {
        this.ad = ad;  this.maas = maas;
        System.out.println("Calisan(String, double)");
    }
    double getMaas() { return maas; }
}
class Yonetici extends Calisan {
    private double prim;
    Yonetici(String ad) {
        this(ad, 5000.0);
        System.out.println("Yonetici(String)");
    }
    Yonetici(String ad, double prim) {
        super(ad);
        this.prim = prim;
        System.out.println("Yonetici(String, double)");
    }
    double gelir() { return getMaas() + prim; }
}
Yonetici y = new Yonetici("Ayşe");   // main
System.out.println(y.gelir());

Kalıtımda İlklendirme Sırası: Kod İzleme

İlk new Alt() için JVM Alt sınıfını başlatmalıdır. Önce üst sınıf başlatılır: Ust'un static bloğu çalışır.

Sonra Alt'ın static bloğu. Sınıf başlatma program boyunca bir kez yapılır.

Nesne ayrıldı (a ve b 0). Alt() önce gizli super() der; Ust() gövdesinden önce Ust'un alan ilk değerleri çalışır: a = deger(...).

Ardından Ust() gövdesi. Bu anda b hâlâ 0: Alt kısmı henüz hiç ilk değer almadı.

super() döndükten sonra alt sınıfın alan ilk değerleri çalışır: b = deger("Alt alanı").

En son Alt() gövdesi. Sıra: üst sınıf alanları → üst yapıcı → alt sınıf alanları → alt yapıcı.

İkinci new Alt(): sınıflar zaten başlatıldı, static bloklar tekrar çalışmaz. Nesneye ait dört adım aynı sırayla yinelenir.

class Ust {
    static { System.out.println("Ust static"); }
    int a = deger("Ust alanı");
    Ust() { System.out.print("Ust(), "); }
    static int deger(String s) {
        System.out.print(s + ", ");
        return 1;
    }
}
class Alt extends Ust {
    static { System.out.println("Alt static"); }
    int b = deger("Alt alanı");
    Alt() { System.out.println("Alt()"); }
}
// main içinde:
new Alt();
new Alt();

Geçersiz Kılma

Metodu Geçersiz Kılma

Geçersiz kılma (overriding): alt sınıfın, üst sınıftan kalıtımla aldığı bir metodu aynı imzayla yeniden yazarak kendi davranışını vermesidir.

  • Ad ve parametre listesi aynı olmalı.
  • Dönüş tipi aynı (veya onun alt tipi) olmalı.
  • Erişim daraltılamaz: public metot public kalmalı.
  • final, static ve private metotlar geçersiz kılınamaz.
class Sekil {
    public void ciz() {
        System.out.println("Şekil çiziliyor.");
    }
}
class Dikdortgen extends Sekil {
    @Override
    public void ciz() {
        System.out.println("Dikdörtgen çiziliyor.");
    }
}
// main içinde
new Sekil().ciz();
new Dikdortgen().ciz();

is-a ve has-a İlişkileri

Is-a (kalıtım, inheritance)

  • Bir sınıfın başka bir sınıftan türetilmesidir; türetilen sınıf üst sınıfın bir türüdür.

Kırılgan Üst Sınıf: Kod İzleme

SayanListe, eklenen öğe sayısını tutmak için Liste'den türetildi. İki ekleme metodu da geçersiz kılındı.

Alt sınıfın hepsiniEkle'si sayaca dizinin uzunluğunu ekler: 3. Sonra işi üst sınıfa bırakır.

Liste.hepsiniEkle her öğe için ekle(s), yani this.ekle(s) çağırır. Bu, üst sınıfın bir gerçekleme ayrıntısıdır.

Nesne bir SayanListe olduğu için çağrı alt sınıfın ekle'sine gider. Aynı öğe ikinci kez sayılır: 4.

super.ekle(s) öğeyi diziye yazar: boyut = 1.

"b" ve "c" için de aynı yol izlenir: her biri bir kez daha sayılır. Döngü bitince sayaç 6, boyut 3.

Yanlış sonuç: 6 3. Alt sınıf, üst sınıfın kendi metotlarını nasıl kullandığına bağlı kaldı. Üst sınıfın yeni bir sürümü döngüyü değiştirse sonuç yine değişirdi: kırılgan üst sınıf (fragile base class).

class Liste {
    private String[] ogeler = new String[10];
    private int boyut;
    void ekle(String s) { ogeler[boyut++] = s; }
    void hepsiniEkle(String[] dizi) {
        for (String s : dizi) ekle(s);
    }
    int boyut() { return boyut; }
}
class SayanListe extends Liste {
    int eklemeSayisi = 0;
    @Override void ekle(String s) {
        eklemeSayisi++;
        super.ekle(s);
    }
    @Override void hepsiniEkle(String[] dizi) {
        eklemeSayisi += dizi.length;
        super.hepsiniEkle(dizi);
    }
}
SayanListe l = new SayanListe();   // main
l.hepsiniEkle(new String[] {"a", "b", "c"});
System.out.println(l.eklemeSayisi + " " + l.boyut());

getClass() ile equals

public class Kisi {
    private String ad;
    private int yas;
    // ... yapıcı ...

    @Override
    public boolean equals(Object obj) {
        // aynı referanssa eşittir
        if (this == obj) return true;
        // null ya da farklı sınıf: eşit değil
        if (obj == null
                || getClass() != obj.getClass())
            return false;
        // alanları karşılaştır
        Kisi kisi = (Kisi) obj;
        return yas == kisi.yas
               && ad.equals(kisi.ad);
    }
}
  • this == obj: aynı nesneyse hemen true (hızlı yol).
  • getClass() nesnenin gerçek sınıfını verir; iki tarafın sınıfı birebir aynı olmalıdır.
  • İlkel tipler (int yas) == ile, nesne tipindeki alanlar (String ad) equals ile karşılaştırılır.

Üç ayrı nesne var. k1 ile k2 içerikçe aynı, k3 yalnızca yaşta farklı.

this == obj adresleri karşılaştırır: #1 ≠ #2, hızlı yol işlemez.

obj null değil; getClass() iki tarafta da Kisi. Koşul yanlış, return false atlanır.

Aşağı dönüşüm yeni nesne üretmez: kisi aynı #2'yi, bu kez Kisi tipiyle gösterir; artık kisi.yas yazılabilir.

İlkel yas == ile, String olan ad equals ile karşılaştırılır. İkisi de doğru: true.

k1.equals(k3): yeni çağrı, obj = #3. Farklı nesne, aynı sınıf: alanlara geçilir.

20 == 21 yanlış; && kısa devre yapar, ad.equals hiç çağrılmaz. Sonuç false.

equals ve hashCode

Kural: equals geçersiz kılınıyorsa hashCode da geçersiz kılınmalıdır. Eşit nesnelerin hashCode değerleri aynı olmalıdır.
import java.util.Objects;
public class Nokta {
    private int x, y;
    public Nokta(int x, int y) {
        this.x = x; this.y = y;
    }
    @Override public boolean equals(Object o) {
        return (o instanceof Nokta n)
               && x == n.x && y == n.y;
    }
    @Override public int hashCode() {
        return Objects.hash(x, y);
    }
    @Override public String toString() {
        return "Nokta[x=" + x + ", y=" + y + "]";
    }
}

HashSet İçinde equals ve hashCode: Kod İzleme

Boş bir HashSet: öğeler 16 kovadan birine konur. Kovayı hashCode() seçer.

hashCode() = 31·(31+3)+4 = 1058; 1058 % 16 = 2. Kova boş: nesne eklenir.

Aynı sayılar, farklı sıra: hash 1088, kova 0. Yine boş kova, eklenir.

Kümede iki öğe var: 2.

this(...) ile super(...) birlikte

İkisi de ilk satır olmak ister: call to super must be first statement in constructor. Zincirin sonundaki yapıcı super(...) çağırır.

class A {
    A() { System.out.println("A"); }
    void yaz() { System.out.println("A.yaz"); }
}
class B extends A {
    B() { System.out.println("B"); }
    @Override void yaz() { System.out.println("B.yaz"); }
}
class C extends B {
    C() { super(); System.out.println("C"); }
    @Override void yaz() {
        super.yaz();
        System.out.println("C.yaz");
    }
}
  1. C c = new C(); ne yazdırır?
  2. Ardından c.yaz(); ne yazdırır?
  3. A a = new B(); a.yaz(); ne yazdırır?
  4. c instanceof A nedir?
  5. equals'ı geçersiz kılmayan bir Ogrenci sınıfında, aynı adlı iki nesne için o1.equals(o2) nedir?
