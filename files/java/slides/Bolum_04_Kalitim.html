Öğrenme Çıktıları

Kavram

Kalıtımı (inheritance), üst sınıf ve alt sınıf kavramlarını tanımlamak; “is-a” ilişkisini tanımak.

Sözdizimi

extends ile alt sınıf yazmak; neyin miras alındığını, neyin alınmadığını açıklamak.

Yapıcılar

super(...) ve super.metot() kullanmak; yapıcı zincirinin çalışma sırasını izlemek.

Geçersiz kılma

Metodu geçersiz kılmak (overriding), aşırı yüklemeden (overloading) ayırmak, @Override kullanmak.

Erişim ve sınırlama

protected erişimini ve final ile kalıtımın nasıl sınırlandığını açıklamak.

Object sınıfı

toString, equals ve hashCode metotlarını doğru yazmak; == ile equals farkını bilmek.

Kalıtım Kavramı

Kalıtım Nedir?

  • Kalıtım (Inheritance): mevcut bir sınıfın nitelik ve metotlarını miras alıp yeni veya değiştirilmiş yeteneklerle zenginleştirerek yeni bir sınıf oluşturmaktır.
  • Mevcut sınıf: üst sınıf (superclass, temel sınıf).
  • Yeni sınıf: alt sınıf (subclass, türetilmiş sınıf).
  • Alt sınıfa yeni nitelik ve metotlar eklenebilir; miras alınan nitelikler yeniden tanımlanmaz.
Benzetme: “Her dikdörtgen bir şekildir.” Dikdörtgen, şeklin her şeyine sahiptir; üstüne kendi en, boy ve alan() bilgisini ekler.

Kalıtım Kavramı

extends ile Alt Sınıf

// Temel sınıf (üst sınıf)
public class Sekil {
    // Temel sınıfa ait nitelik ve metotlar
    // ...
}

// Yeni sınıf (alt sınıf), Sekil'den türer
public class Dikdortgen extends Sekil {
    // Yeni sınıfa ait nitelik ve metotlar
    // ...
}
  • Söz dizimi: class AltSinif extends UstSinif. extends: “genişletir”.
  • extends sonrasına yalnızca bir sınıf yazılabilir.
  • Alt sınıf, üst sınıfın public ve protected üyelerini kendi üyesiymiş gibi kullanır.
  • Üst sınıftaki aynı adlı niteliği alt sınıfta yeniden tanımlamak onu gizler (hiding); iki ayrı değişken oluşur ve kafa karıştırır. Yapılmamalıdır.
  • extends yazılmazsa sınıf, gizlice Object sınıfından türer.

Kalıtım Kavramı

Alt ve Üst Sınıf

  • Alt sınıf, üst sınıfın davranışlarını sergiler; ek olarak kendine özgü davranışlar da sergiler.
  • Kalıtım bu yüzden özelleştirme (specialization) olarak da adlandırılır: alt sınıf daha özel bir grubu temsil eder.
  • Her kedi bir hayvandır, ama her hayvan kedi değildir.
  • Java sınıf hiyerarşisi, java.lang paketindeki Object sınıfı ile başlar.
  • Her sınıf, doğrudan veya dolaylı olarak Object sınıfından miras alır.

Hayvan Örneği

Hayvan Sınıf Hiyerarşisi

Ortak nitelik ve metotlar bir kez, Hayvan sınıfında yazılır. Her alt sınıf konus() metodunu kendine göre geçersiz kılar ve kendine özgü bir metot ekler. UML'de kalıtım, ucu üst sınıfa dönük içi boş üçgen okla gösterilir.

Hayvan Örneği

Hayvan ve Kopek Sınıfları

public class Hayvan {
    private String isim;     // ortak nitelikler
    private int yas;
    private double saglik;

    public Hayvan(String isim, int yas) {
        this.isim = isim;
        this.yas = yas;
        this.saglik = 100.0;
    }
    public String getIsim() { return isim; }   // private isim'e erişim yolu
    public void konus() {
        System.out.println("Bu hayvan konuşur.");
    }
    public void uyu() {
        saglik += 5;
        System.out.println(isim + " uyudu. Sağlık: " + saglik);
    }
}

Üst sınıf Hayvan: bütün hayvanlarda ortak olan nitelikler ve davranışlar.

public class Kopek extends Hayvan {
    public Kopek(String isim, int yas) {
        super(isim, yas);   // üst sınıf yapıcısı alanları doldurur
    }
    @Override
    public void konus() {   // miras alınan davranışı değiştirir
        System.out.println(getIsim() + " havlar.");
    }
    public void topOyna() { // yalnızca Kopek'te olan davranış
        System.out.println(getIsim() + " top oynuyor!");
    }
}
Kopek kopek = new Kopek("Karabaş", 4);
kopek.konus();     // Kopek'in sürümü
kopek.topOyna();   // Kopek'e özgü
kopek.uyu();       // Hayvan'dan miras
Karabaş havlar.
Karabaş top oynuyor!
Karabaş uyudu. Sağlık: 105.0

Alt sınıf Kopek yalnızca farkı yazar; uyu() hiç yazılmadığı hâlde çalışır.

Hangi Metot Çalışır?

new Kedi("Mavi"): nesne oluşur. İçinde Hayvan'dan gelen isim ve saglik alanları da vardır.

kedi.konus(): arama nesnenin sınıfı Kedi'de başlar. konus() orada var: geçersiz kılınmış sürüm seçilir.

getIsim() Hayvan'dan miras; private isim'e onun aracılığıyla ulaşılır.

kedi.avlan(): Kedi'ye özgü metot; Kedi'de bulunur.

avlan() gövdesi çalışır ve ikinci satır yazılır.

kedi.yemekYe(5.0): Kedi'de yok → bir üst sınıfa, Hayvan'a bakılır ve orada bulunur.

Miras alınan metot, aynı nesnenin saglik alanını günceller: 100.0 + 5.0.

Sonuç yazılır. Kural: metot önce nesnenin kendi sınıfında, yoksa yukarı doğru üst sınıflarda aranır.

class Hayvan {
    private String isim;
    private double saglik = 100.0;
    Hayvan(String isim) { this.isim = isim; }
    String getIsim() { return isim; }
    void konus() { System.out.println("Ses yok."); }
    void yemekYe(double m) {
        saglik += m;
        System.out.println(isim + ": " + saglik);
    }
}
class Kedi extends Hayvan {
    Kedi(String isim) { super(isim); }
    @Override void konus() {
        System.out.println(getIsim() + " miyavlar.");
    }
    void avlan() {
        System.out.println(getIsim() + " avlandı!");
    }
}
Kedi kedi = new Kedi("Mavi");   // main
kedi.konus();
kedi.avlan();
kedi.yemekYe(5.0);

Kalıtımın Avantajları

Yeniden kullanım

Üst sınıfın metot ve nitelikleri alt sınıfta yeniden yazılmadan kullanılır.

Genişletme

Mevcut sınıf, kodu değiştirilmeden yeni özelliklerle genişletilir.

Değiştirme

Üst sınıfın metotları alt sınıfta geçersiz kılınarak (overriding) değiştirilebilir.

public class GelismisHesapMakinesi
        extends HesapMakinesi {
    // Yeni yetenek: üs alma
    public double us(double taban, int us) {
        double sonuc = 1.0;
        for (int i = 0; i < us; i++) {
            sonuc *= taban;
        }
        return sonuc;
    }
    // faktoriyel(int) benzer biçimde eklenir
}
// main içinde
GelismisHesapMakinesi h = new GelismisHesapMakinesi();
System.out.println(h.topla(5, 3));         // 8.0  (miras)
System.out.println(h.hafizayiGoruntule()); // 8.0  (miras)
System.out.println(h.us(2, 5));            // 32.0 (yeni)

Yapıcılar ve super

super Anahtar Kelimesi

  • super(...): alt sınıfın yapıcısı içinde üst sınıfın yapıcısını çağırır; üst sınıfın niteliklerine ilk değerleri o atar.
  • super(...) yapıcının ilk satırı olmalıdır.
  • Yazılmazsa derleyici gizlice super(); (parametresiz) ekler.
  • super.metot(): üst sınıfın metoduna nokta (.) ile erişir; geçersiz kılınmış bir metodun içinden üst sınıfın sürümünü çağırmak için kullanılır.
  • İlke: her sınıf yalnızca kendi verilerini yönetmelidir. Kedi, Hayvan'ın isim alanına kendisi atama yapmaz; işi super(isim)'e bırakır.
class Kedi extends Hayvan {
    private boolean evcil;

    Kedi(String isim, boolean evcil) {
        super(isim);         // Hayvan(String)
        this.evcil = evcil;  // kendi verisi
    }

    @Override
    public String toString() {
        return super.toString()   // Hayvan'ınki
               + ", Evcil: " + evcil;
    }
}
// main içinde
System.out.println(new Kedi("Mavi", true));

Çıktı

İsim: Mavi, Sağlık: 100.0, Evcil: true

Hayvan'ın toString() metodu isim ve sağlık bilgisini döndürür; Kedi yalnızca kendi alanını ekler.

Yapıcılar ve super · Kodu adım adım çalıştır

Yapıcı Zinciri: new Kedi("Mavi", true)

new: önce bellekte nesneye yer ayrılır; tüm alanlar (Hayvan'ınkiler dahil) varsayılan değerleri alır.

Kedi yapıcısı çağrılır. Kendi işine başlamadan önce üst sınıf kısmı hazırlanmalıdır.

super(isim): Hayvan yapıcısı çağrılır; Kedi yapıcısı bekler.

Hayvan da önce kendi üst sınıfını çağırır: Object(). Her zincir Object'te biter.

Object() döndü. Hayvan kendi alanını doldurur: isim = "Mavi".

saglik = 100.0.

Hayvan yapıcısı mesajını yazar ve döner: önce üst sınıf yazdı.

Kedi yapıcısı kaldığı yerden devam eder: evcil = true.

Kedi yapıcısı mesajını yazar.

Yapıcı bitti; nesnenin adresi kedi değişkenine atanır.

Yapıcılar yukarıdan aşağıya tamamlanır: Object → Hayvan → Kedi.

class Hayvan {
    private String isim;
    private double saglik;
    Hayvan(String isim) {
        super();   // Object() çağrılır
        this.isim = isim;
        saglik = 100.0;
        System.out.println("Hayvan yapıcısı");
    }
}
class Kedi extends Hayvan {
    private boolean evcil;
    Kedi(String isim, boolean evcil) {
        super(isim);
        this.evcil = evcil;
        System.out.println("Kedi yapıcısı");
    }
}
// main içinde
Kedi kedi = new Kedi("Mavi", true);
System.out.println("Nesne hazır");

Geçersiz Kılma

Metodu Geçersiz Kılma

Geçersiz kılma (overriding): alt sınıfın, üst sınıftan miras aldığı bir metodu aynı imzayla yeniden yazarak kendi davranışını vermesidir.

  • Ad ve parametre listesi aynı olmalı.
  • Dönüş türü aynı (veya onun alt türü) olmalı.
  • Erişim daraltılamaz: public metot public kalmalı.
  • final, static ve private metotlar geçersiz kılınamaz.
class Sekil {
    public void ciz() {
        System.out.println("Şekil çiziliyor.");
    }
}
class Dikdortgen extends Sekil {
    @Override
    public void ciz() {
        System.out.println("Dikdörtgen çiziliyor.");
    }
}
// main içinde
new Sekil().ciz();
new Dikdortgen().ciz();
Şekil çiziliyor.
Dikdörtgen çiziliyor.
// alt sınıfta: void ciz()
error: ciz() in Dikdortgen cannot override
  ciz() in Sekil
  attempting to assign weaker access
  privileges; was public
// alt sınıfta: public int ciz()
error: ciz() in Dikdortgen cannot override
  ciz() in Sekil
  return type int is not compatible

Geçersiz Kılma

@Override Etiketi

  • @Override bir etikettir (annotation): metodun, üst sınıftan miras alınan bir metodu geçersiz kıldığını bildirir.
  • Derleyiciye bunu kontrol etmesini söyler: üst sınıfta böyle bir metot yoksa derleme hatası verir.
  • Kodu daha okunabilir yapar; diğer geliştiricilere metodun üst sınıftan geldiğini gösterir.
  • Zorunlu değildir, ama her zaman yazılması önerilir: yazım hatalarını hemen yakalar.
public class Dikdortgen extends Sekil {
    // miras alınan metodu geçersiz kıl
    @Override
    public void ciz() {
        System.out.println("Dikdörtgen çiziliyor.");
    }
}

Yazım hatası: Ciz (büyük C)

    @Override
    public void Ciz() { ... }
error: method does not override or implement
  a method from a supertype

@Override olmasaydı Ciz() sessizce yeni bir metot olurdu ve ciz() çağrıları hâlâ Sekil'in sürümünü çalıştırırdı.

  • public: sınıfın üyelerine her yerden erişilebilir. private: yalnızca o sınıfın içinden.
  • protected: ikisinin arasında bir düzeydir. Sınıfın kendisi, alt sınıfları ve aynı paketteki diğer sınıflar erişebilir.

İyi uygulama: nitelikler yine private kalsın; alt sınıfların ihtiyaç duyduğu işlemler protected metotlar olarak açılsın.

Erişim ve Sınırlama

protected: Kod Örneği

package canli;

public class Hayvan {
    protected String isim;  // alt sınıflar
    private double saglik;  // yalnızca Hayvan

    public Hayvan(String isim) {
        this.isim = isim;
        saglik = 100.0;
    }
    public double getSaglik() { return saglik; }
    protected void saglikEkle(double miktar) {
        saglik += miktar;
    }
}
package evcil;     // başka paket
import canli.Hayvan;

public class Kedi extends Hayvan {
    public Kedi(String isim) { super(isim); }
    public void uyu() {
        // protected alan: izin var
        System.out.println(isim + " uyuyor.");
        // saglik += 5;  // private: hata
        saglikEkle(5);   // protected metot
        System.out.println("Sağlık: "
                           + getSaglik());
    }
}

Erişim ve Sınırlama

final ile Kalıtımı Sınırlamak

  • final anahtar kelimesi kalıtımı sınırlamak için kullanılabilir.
  • Bir metot final tanımlanırsa hiçbir alt sınıfta geçersiz kılınamaz (override).
  • Bir sınıf final tanımlanırsa ondan hiçbir alt sınıf türetilemez. Örnek: String, Math, Integer.
class Hayvan {
    public final void nefesAl() { ... }
}
class Kedi extends Hayvan {
    public void nefesAl() { ... }
}
error: nefesAl() in Kedi cannot override
  nefesAl() in Hayvan
  overridden method is final
final class Sabit { ... }
class Deneme extends Sabit { }
error: cannot inherit from final Sabit
Neden? Güvenlik ve tutarlılık: String değiştirilemez olmalıdır; bir alt sınıf bu sözü bozamasın.

Değişkenlerde final başka bir anlam taşır: değer bir kez atanır (sabit).

Erişim ve Sınırlama

Nesnenin Görünümünü Kısıtlama

  • Bir nesne, üst sınıf türünde bir değişkene atanabilir (yukarı dönüşüm, upcasting): her Lastik bir Parça'dır.
  • Böylece dışarıya yalnızca üst sınıfa ait metotlar açılır.
  • Nesnenin gerçek sınıfına bakılmaksızın, değişkenin türü neyi çağırabileceğimizi belirler.
Parca p = new Lastik("Petlas", "XYZ-123", "225/45R17", true);
System.out.println(p.seriNumarasi());   // izin verilir → XYZ-123
// p.kislikMi()                         // izin verilmez
error: cannot find symbol
  symbol:   method kislikMi()
  location: variable p of type Parca

Lastik'e özgü metoda ulaşmak için önce tür kontrolü, sonra aşağı dönüşüm (downcasting) gerekir: instanceof slaytına bakın.

Sınıflar Arası İlişkiler

is-a ve has-a İlişkileri

Is-a (kalıtım, inheritance)

  • Bir sınıfın başka bir sınıftan türetilmesidir; türetilen sınıf üst sınıfın bir türüdür.
  • Alt sınıf nesnesi, üst sınıfın nesnesi gibi de kullanılabilir.

Has-a (oluşum, composition)

  • Bir sınıfın başka bir sınıf türünde nitelik içermesidir.
  • Nesne, içinde diğer nesnelere referanslar tutar.
// Is-a ilişkisi (kalıtım)
public class Araba extends Arac {
    // Has-a ilişkisi (oluşum)
    private Motor motor;

    public Araba(int beygirGucu) {
        motor = new Motor(beygirGucu);
    }
    public void yolaCik() {
        motor.calistir();   // Motor'a devret
        hizlan(50);         // Arac'tan miras
        System.out.println("Hız: " + hiz
                           + " km/sa");
    }
}
// Motor: beygirGucu alanı ve calistir():
//   "Motor çalıştı: " + beygirGucu + " BG"

new Araba(110).yolaCik();

Motor çalıştı: 110 BG
Hız: 50 km/sa

Sınıflar Arası İlişkiler

Çoklu Kalıtım

  • Java'da doğrudan çoklu kalıtım desteklenmez: bir sınıf yalnızca bir sınıftan türeyebilir.
  • Elmas problemi (diamond problem): B ve C yaz()'ı farklı geçersiz kılarsa D hangisini almalı?
  • Birden fazla sınıfın özellikleri gerekiyorsa: oluşum (composition) ve arayüzler (interface; bir sınıf birçok arayüz uygulayabilir, ayrıntısı “Soyut Sınıflar” bölümünde).
class D extends B, C { }   // geçersiz
error: '{' expected
interface Sarj { void sarjEt(); }

                      implements Sarj {

Object Sınıfı

getClass() ile equals

public class Kisi {
    private String ad;
    private int yas;
    // ... yapıcı ...

    @Override
    public boolean equals(Object obj) {
        // aynı referanssa eşittir
        if (this == obj) return true;
        // null ya da farklı sınıf: eşit değil
        if (obj == null
                || getClass() != obj.getClass())
            return false;
        // alanları karşılaştır
        Kisi kisi = (Kisi) obj;
        return yas == kisi.yas
               && ad.equals(kisi.ad);
    }
}
  • this == obj: aynı nesneyse hemen true (hızlı yol).
  • getClass() nesnenin gerçek sınıfını verir; iki tarafın sınıfı birebir aynı olmalıdır.
  • Temel türler (int yas) == ile, nesne türündeki alanlar (String ad) equals ile karşılaştırılır.

equals ve hashCode

Kural: equals geçersiz kılınıyorsa hashCode da geçersiz kılınmalıdır. Eşit nesnelerin hashCode değerleri aynı olmalıdır.
import java.util.Objects;
public class Nokta {
    private int x, y;
    public Nokta(int x, int y) {
        this.x = x; this.y = y;
    }
    @Override public boolean equals(Object o) {
        return (o instanceof Nokta n)
               && x == n.x && y == n.y;
    }
    @Override public int hashCode() {
        return Objects.hash(x, y);
    }
    @Override public String toString() {
        return "Nokta[x=" + x + ", y=" + y + "]";
    }
}

Neden? HashSet ve HashMap önce hashCode ile “kova” seçer, sonra equals çağırır. hashCode farklıysa eşit nesneler hiç karşılaştırılmaz.

kume.add(new Nokta(3, 4));
System.out.println(kume.size() + " "
    + kume.contains(new Nokta(3, 4)));

Sık Yapılan Hatalar

super(...) çağırmamak

Üst sınıfta parametresiz yapıcı yoksa: constructor Hayvan in class Hayvan cannot be applied to given types.

private alana doğrudan erişmek

saglik += 5; alt sınıfta: saglik has private access in Hayvan. Getter veya protected metot kullanın.

equals(Nokta) yazmak

Parametre Object değilse aşırı yüklemedir; @Override ile: method does not override or implement a method from a supertype.

Nesneleri == ile karşılaştırmak

İçerikleri aynı iki nesne için == → false. String dahil, equals kullanın.

equals var, hashCode yok

Örnek Problemler

class A {
    A() { System.out.println("A"); }
    void yaz() { System.out.println("A.yaz"); }
}
class B extends A {
    B() { System.out.println("B"); }
    @Override void yaz() { System.out.println("B.yaz"); }
}
class C extends B {
    C() { super(); System.out.println("C"); }
    @Override void yaz() {
        super.yaz();
        System.out.println("C.yaz");
    }
}
  1. C c = new C(); ne yazdırır?
  2. Ardından c.yaz(); ne yazdırır?
  3. A a = new B(); a.yaz(); ne yazdırır?
  4. c instanceof A nedir?
  5. equals'ı geçersiz kılmayan bir Ogrenci sınıfında, aynı adlı iki nesne için o1.equals(o2) nedir?
Cevapları göster
  1. A B C: yapıcılar üstten alta tamamlanır (B'nin gizli super()'ı önce A'yı çalıştırır).
  2. B.yaz, sonra C.yaz: super.yaz() B'nin sürümünü çağırır.
  3. A B, sonra B.yaz: değişken A türünde ama nesne B olduğu için B'nin sürümü çalışır.
  4. true: C, B üzerinden A'dan türer.
  5. false: Object'in equals'ı referansları karşılaştırır.
