Bir .java dosyasının javac ile bytecode'a, java ile çalışan programa dönüşmesini anlatmak; soyutlama seviyelerini ve JVM yığınında bytecode'un yürüyüşünü izlemek; JVM'in platform bağımsızlığını nasıl sağladığını açıklamak.

Değişkenler ve tipler

Operatör önceliğine göre ifadeleri hesaplamak, tip dönüşümü yapmak; ?: ile koşula göre değer seçmek; if, switch, for, while, do-while, break, continue deyimlerinin söz dizimini tanımak.

Java ile Yazılım Geliştirme

  • Java kodu düz metin (plain text) dosyalarına yazılır; Word gibi biçimli belgeler kullanılmaz.

Derleme ve Çalıştırma

Programlamanın Soyutlama Seviyeleri

  • Yüksek seviye dil (high-level language): problem alanına yakındır; daha üretken, okunabilir ve anlaşılır yazılım sağlar. Java, C, Python…
  • Assembly dili (assembly language): komutları metin olarak (ADD, MOV) ifade eder; donanım temsiline çevrilir. Daha düşük seviyeli bir soyutlamadır.
  • Soyutlama arttıkça kod kısalır ve okunur; alt seviyeye çevirme işini derleyici ya da assembler yapar.
  • Donanım temsili (hardware representation): yalnızca bitler. Komutlar ve veriler doğrudan donanım tarafından anlaşılır.

Örnekte a, b, toplam sırasıyla ebx, ecx, eax yazmaçlarında varsayılmıştır; makine kodu x86'nın gerçek kodlamasıdır (89 D8, 01 C8).

Derleme ve Çalıştırma

Derleme (Compilation)

  • Bilgisayar .java metnini doğrudan çalıştıramaz; önce derlenmesi gerekir. Derleme komutu: javac.
  • Java derleyicisi kaynak kodu işlemcinin makine diline değil, JVM'in anladığı bytecode'a çevirir ve .class dosyasına yazar. Bytecode'u çalıştırırken makine koduna çeviren JVM'dir.

Programcı kaynak kodu düz metin olarak yazar ve MerhabaDunya.java adıyla kaydeder.

javac MerhabaDunya.java: derleyici söz dizimini ve tipleri denetler; hata yoksa MerhabaDunya.class oluşur.

java MerhabaDunya: başlatıcı (launcher) JVM'i açar, sınıfı yükler; JVM bytecode'u yorumlar, sık çalışan kısmı JIT ile makine koduna çevirir.

İşletim sistemi ve işlemci asıl komutları yürütür; ekranda Merhaba, Dünya! görünür.

Derleme ve Çalıştırma

Bytecode (Ara Kod)

  • .class dosyaları işlemcinin doğrudan anlayabileceği makine kodu içermez.
  • İçlerinde Java sanal makinesinin anladığı bytecode bulunur: bytecode, JVM'in “makine dilidir”.
  • Her komutun işlem kodu (opcode) tek bir bayttır (adı buradan gelir); gerekirse ardından işlenen baytlar gelir.
  • Bytecode bir işlemciye ya da işletim sistemine bağlı değildir: aynı .class dosyası Windows, Linux ve macOS'ta çalışır.
Benzetme

Bytecode, her ülkede aynı okunan bir nota gibidir; her bilgisayardaki JVM ise o notayı kendi çalgısında çalan müzisyendir.

Görmek için

JDK'daki javap -c Sinif komutu bir .class dosyasındaki bytecode komutlarını okunur biçimde listeler.

Bytecode Örneği: Adım Adım

int x = 5; System.out.println(x); satırlarının derlenmiş hâli (javap -c, JDK 21). JVM bir yığın makinesidir: komutlar değerleri işlenen yığınına iter ve oradan alır.

iconst_5: sabit 5 işlenen yığınına itilir. (Kaynak: int x = 5;)

istore_1: yığının üstü alınır, 1 numaralı yerel değişkene (x) yazılır.

getstatic #7: System.out nesnesine başvuru yığına itilir. #7, sabitler tablosundaki kayıt numarasıdır.

iload_1: x'in değeri (5) yığına kopyalanır. (Kaynak: System.out.println(x);)

invokevirtual #13: println(int) çağrılır, iki değer yığından alınır; ekrana 5 yazılır.

return: main biter, program sonlanır.

Bytecode: JVM Yığını Adım Adım

JVM yazmaç değil yığın kullanır. iconst_5 sabit 5'i işlenen yığınına iter.

istore_1 yığının üstünü alır, 1 numaralı yerel değişkene (a) yazar.

bipush 7: 7 bir bayta sığan sabittir; yığına itilir.

7, 2 numaralı yerele (b) yazılır.

iload_1: a'nın değeri (5) yığına kopyalanır; a değişmez.

b'nin değeri (7) yığının üstüne gelir. Yığında iki değer var.

iadd üstteki iki değeri çıkarır, toplar, sonucu (12) geri iter.

12, 3 numaralı yerele (toplam) yazılır: int toplam = a + b; bitti.

System.out nesnesinin referansı yığına itilir.

toplam (12) yığına yüklenir: println'in argümanı.

println(int) çağrılır; nesne ve argüman yığından alınır, 12 yazılır.

main biter. Aynı bytecode her işletim sistemindeki JVM'de böyle çalışır.

Derleme ve Çalıştırma

Java Sanal Makinesi (JVM)

  • JVM (Java Virtual Machine), Java uygulamalarını çalıştıran temel bileşendir: bytecode'u yorumlar ve bulunduğu işlemciye uygun biçimde yürütür.
  • Sık çalışan kod parçalarını JIT (Just-In-Time) derleyicisi çalışma sırasında makine koduna çevirir; program bu yüzden zamanla hızlanır.
  • Java başlatıcı aracı (launcher tool) java komutudur: JVM'i başlatır, sınıfı yükler ve main metodunu çağırır.

Derleme ve Çalıştırma

Platform Bağımsızlık

  • Java'nın temel özelliklerinden biridir: “Bir kez yaz, her yerde çalıştır” (Write Once, Run Anywhere).
  • Program bir kez derlenir; aynı bytecode farklı işletim sistemlerinde çalıştırılır.
  • Bunu mümkün kılan, JVM'in birçok farklı işletim sistemi ve işlemci için ayrı ayrı yazılmış olmasıdır.
  • C gibi dillerde ise her platform için ayrı derleme gerekir.

Derleme ve Çalıştırma

Java Platformu

Platform: bir programın çalıştığı donanım ya da yazılım ortamı. Java platformunun iki ana bileşeni vardır:

  • JVM (Java Virtual Machine): uygulamaları çalıştırır; farklı donanımlara taşınabilirlik sağlar.
  • API (Application Programming Interface): hazır sınıf kütüphaneleri. Grafik arayüz, veri tabanı, ağ iletişimi, dosya işlemleri gibi birçok işlevi hazır sunar; geliştirmeyi hızlandırır.

Program geliştirmek için JDK kurulur. Java 11'den beri JRE ayrı bir paket olarak dağıtılmaz; JDK hepsini içerir.

Temel Programlama Unsurları

Değişkenler, tipler ve ifadeler

Verileri saklamak ve işlemek için değişkenler gerekir. Her değişkenin bir tipi vardır; değerler ifadelerle (expressions) hesaplanır: sayi > 0, toplam + 1.

Kontrol akışı (control flow)

Programın hangi sırayla ve nasıl çalışacağını belirler:

  • Dallanma (branching): koşula göre farklı kısımları çalıştırır, ör. if-else.
  • Döngüler (loops): bir işlemi tekrarlar, ör. for, while.

Örnek kod parçası: değişken + koşul + çıktı

int sayi = 5;
if (sayi > 0) {
    System.out.println("Sayı pozitif.");
} else {
    System.out.println("Sayı negatif veya sıfır.");
}

Taşma: byte Sayacı Adım Adım

b bir byte: 8 bit. 125'in ikili gösterimi 01111101; en soldaki bit işaret bitidir ve ağırlığı −128'dir.

i = 1: 1 <= 4 doğru, döngü gövdesine girilir.

b++ → 126 (01111110); değer yazdırılır.

b++ → 127 (01111111): byte için en büyük değer. Yazdırılır.

127 + 1: ikili toplama 10000000 verir. İşaret biti 1 oldu → değer −128. Hata yok; değer aralığın öbür ucuna sardı.

Ekrana −128 yazılır: program uyarı vermeden yanlış sonuçla devam eder.

b++ → −127 (10000001): sayım artık −128'den yukarı doğru sürer.

i = 5: 5 <= 4 yanlış, döngü biter. Çıktı 126, 127, −128, −127.

  • Değişkene değer vermek için = atama operatörü kullanılır: değişken = ifade;

Kısa Devre (Short-circuit) Değerlendirme

  • &&'de sol taraf false ise sonuç zaten false'tur: sağ taraf hiç hesaplanmaz.
  • ||'de sol taraf true ise sağ taraf hesaplanmaz: gun == 6 || gun == 7 ifadesinde gun = 6 ise ikinci karşılaştırma hiç yapılmaz. Tersi !(gun == 6 || gun == 7) “hafta içi” demektir.

Üçlü Operatör (Ternary Operator)

Koşula göre iki değerden birini seçen kısa bir ifadedir: koşul doğruysa değer1, değilse değer2.

sonuç = (koşul) ? değer1 : değer2;

Örnek: bir sayının pozitif ya da negatif olduğunu belirleme.

int sayi = -5;
String sonuc = (sayi > 0) ? "Pozitif" : "Negatif";
System.out.println("Sayı " + sonuc);
Çıktı
Sayı Negatif

Aynı işi yapan if-else:

String sonuc;
if (sayi > 0) {
    sonuc = "Pozitif";
} else {
    sonuc = "Negatif";
}

?: bir değer üretir, bu yüzden atamanın sağında ya da println içinde kullanılır. İki seçeneğin tipi uyumlu olmalıdır: double mutlak = (sayi < 0) ? -sayi : sayi; (−4.5 → 4.5), int buyuk = (a > b) ? a : b; (8, 13 → 13).
