Derleme ve çalıştırma

Bir .java dosyasının javac ile byte koda, java ile çalışan programa dönüşmesini anlatmak; JVM'in platform bağımsızlığını nasıl sağladığını açıklamak.

Değişkenler ve türler

Sekiz ilkel veri türünü boyut ve aralıklarıyla tanımak; değişken bildirmek, değer atamak, taşma ve ondalık hassasiyet sorunlarını fark etmek.

Kurallar ve adlandırma

Geçerli tanımlayıcıyı geçersizden ayırmak, anahtar kelimeleri tanımak, camelCase / PascalCase / BÜYÜK_HARF kurallarına uymak.

İfadeler ve akış

Operatör önceliğine göre ifadeleri hesaplamak, tür dönüşümü yapmak; if, switch, ?:, for, while, do-while, break, continue ile kısa programlar yazıp çıktısını önceden bulmak.

Derleme ve Çalıştırma

Java ile Yazılım Geliştirme

  • Java kodu düz metin (plain text) dosyalarına yazılır; Word gibi biçimli belgeler kullanılmaz.
  • Kaynak kod (source code) dosyalarının uzantısı .java'dır. Derleyici ve geliştirme ortamları dosyayı bu uzantıdan tanır.
  • Bir dosyada public bir sınıf varsa dosyanın adı sınıfın adıyla aynı olmalıdır: MerhabaDunya → MerhabaDunya.java.
Okunaklı

Düz metin insanlar için okunaklıdır, kod kolayca anlaşılır ve paylaşılır.

Taşınabilir

Aynı .java dosyası her işletim sisteminde ve her geliştirme ortamında açılır.

Kolay düzeltilir

Hataları düzeltmek, kodu güncellemek için herhangi bir metin düzenleyici yeterlidir.

Dosya adında büyük-küçük harf de önemlidir: merhabadunya.java dosyasındaki public class MerhabaDunya derlenmez.

Örnek .java Dosyası: MerhabaDunya.java

Her Java programı en az bir sınıf içerir. Sınıfın gövdesi { } süslü parantezleri arasındadır.

public static void main(String[] args)

Programın giriş noktası: JVM çalışmaya bu metottan başlar. Yazımı birebir böyle olmalıdır.

System.out.println(...)

Parantez içindeki metni konsola yazar ve alt satıra geçer. Metinler çift tırnak içindedir.

Noktalı virgül ;

Her deyim (statement) ; ile biter. Süslü parantezle kapanan bloklardan sonra ; gerekmez.

  • Söz dizimi (syntax): dilin yazım kuralları. Kurala uymayan kod derlenmez.
  • Her deyim ; ile biter.
  • Bloklar { ile açılır, } ile kapanır; her açılan kapanmalıdır.

Derleme ve Çalıştırma

Derleme (Compilation)

  • Bilgisayar .java metnini doğrudan çalıştıramaz; önce derlenmesi gerekir. Derleme komutu: javac.
  • Java derleyicisi kaynak kodu işlemcinin makine diline değil, JVM'in anladığı byte koda çevirir ve .class dosyasına yazar. Byte kodu çalıştırırken makine koduna çeviren JVM'dir.

Programcı kaynak kodu düz metin olarak yazar ve MerhabaDunya.java adıyla kaydeder.

javac MerhabaDunya.java: derleyici söz dizimini ve türleri denetler; hata yoksa MerhabaDunya.class oluşur.

java MerhabaDunya: başlatıcı (launcher) JVM'i açar, sınıfı yükler; JVM byte kodu yorumlar, sık çalışan kısmı JIT ile makine koduna çevirir.

İşletim sistemi ve işlemci asıl komutları yürütür; ekranda Merhaba, Dünya! görünür.

Derleme ve Çalıştırma

Byte Kod (Bytecode)

  • .class dosyaları işlemcinin doğrudan anlayabileceği makine kodu içermez.
  • İçlerinde Java sanal makinesinin anladığı byte kod bulunur: byte kod, JVM'in “makine dilidir”.
  • Her komutun işlem kodu (opcode) tek bir bayttır (adı buradan gelir); gerekirse ardından işlenen baytlar gelir.
  • Byte kod bir işlemciye ya da işletim sistemine bağlı değildir: aynı .class dosyası Windows, Linux ve macOS'ta çalışır.
Benzetme

Byte kod, her ülkede aynı okunan bir nota gibidir; her bilgisayardaki JVM ise o notayı kendi çalgısında çalan müzisyendir.

Görmek için

JDK'daki javap -c Sinif komutu bir .class dosyasındaki byte kod komutlarını okunur biçimde listeler.

Derleme ve Çalıştırma

Java Sanal Makinesi (JVM)

  • JVM (Java Virtual Machine), Java uygulamalarını çalıştıran temel bileşendir: byte kodu yorumlar ve bulunduğu işlemciye uygun biçimde yürütür.
  • Sık çalışan kod parçalarını JIT (Just-In-Time) derleyicisi çalışma sırasında makine koduna çevirir; program bu yüzden zamanla hızlanır.
  • Java başlatıcı aracı (launcher tool) java komutudur: JVM'i başlatır, sınıfı yükler ve main metodunu çağırır.

Derleme ve Çalıştırma

Platform Bağımsızlık

  • Java'nın temel özelliklerinden biridir: “Bir kez yaz, her yerde çalıştır” (Write Once, Run Anywhere).
  • Program bir kez derlenir; aynı byte kod farklı işletim sistemlerinde çalıştırılır.
  • Bunu mümkün kılan, JVM'in birçok farklı işletim sistemi ve işlemci için ayrı ayrı yazılmış olmasıdır.
  • C gibi dillerde ise her platform için ayrı derleme gerekir.

Derleme ve Çalıştırma

Java Platformu

Platform: bir programın çalıştığı donanım ya da yazılım ortamı. Java platformunun iki ana bileşeni vardır:

  • JVM (Java Virtual Machine): uygulamaları çalıştırır; farklı donanımlara taşınabilirlik sağlar.
  • API (Application Programming Interface): hazır sınıf kütüphaneleri. Grafik arayüz, veri tabanı, ağ iletişimi, dosya işlemleri gibi birçok işlevi hazır sunar; geliştirmeyi hızlandırır.

Program geliştirmek için JDK kurulur. Java 11'den beri JRE ayrı bir paket olarak dağıtılmaz; JDK hepsini içerir.

Değişkenler ve Veri Türleri

Temel Programlama Unsurları

Değişkenler, türler ve ifadeler

Verileri saklamak ve işlemek için değişkenler gerekir. Her değişkenin bir türü vardır; değerler ifadelerle (expressions) hesaplanır: sayi > 0, toplam + 1.

Kontrol akışı (control flow)

Programın hangi sırayla ve nasıl çalışacağını belirler:

  • Dallanma (branching): koşula göre farklı kısımları çalıştırır, ör. if-else.
  • Döngüler (loops): bir işlemi tekrarlar, ör. for, while.

Örnek kod parçası: değişken + koşul + çıktı

int sayi = 5;
if (sayi > 0) {
    System.out.println("Sayı pozitif.");
} else {
    System.out.println("Sayı negatif veya sıfır.");
}

  • Aynı türden birden çok değişken virgülle ayrılarak tek satırda bildirilebilir.
  • Adlar açıklayıcı ve anlamlı seçilmelidir: x yerine cekSayisi.

İlkel (Primitive) Veri Türleri

  • Java'da sekiz ilkel veri türü vardır; her birinin kendine özgü bellek boyutu ve değer aralığı vardır.
  • Tam sayı: byte, short, int, long
  • Kesirli (ondalıklı) sayı: float, double
  • Karakter: char
  • Mantıksal: boolean

Günlük kullanımda tam sayılar için int, ondalıklı sayılar için double varsayılan seçimdir.

char ve boolean

char: tek karakter

İlkel Türler ve Referans Türleri

  • İlkel türler (8 tane): değerin kendisini saklar; adları küçük harfle başlar.
  • Referans türleri: bir nesneyi gösterir; değişkende nesnenin kendisi değil, yeri (başvurusu) tutulur.
  • Örnekler: String (karakter dizisi), diziler, sınıflar, arayüzler, enum'lar. Nesneler genellikle new ile oluşturulur.
  • Hiçbir nesneyi göstermeyen referansın değeri null'dır.

Tanımlayıcılar ve Anahtar Kelimeler

  • Değişkenlere, sınıflara, metotlara verilen adlara tanımlayıcı denir. Tanımlayıcılar özel kurallara tabidir:
  • Yalnızca harf, rakam (0–9), alt çizgi _ ve dolar işareti $ içerebilir. Boşluk, -, @, . gibi karakterler olmaz.

  • Anahtar kelimeler ve true, false, null tanımlayıcı olamaz.
  • Uzunluk sınırı yoktur.
  • Java büyük-küçük harfe duyarlıdır: kisiAdi ile kisiadi farklı değişkenlerdir.

Atama İfadeleri

  • Değişkene değer vermek için = atama operatörü kullanılır: değişken = ifade;
  • Önce sağ taraftaki ifade hesaplanır, sonuç sol taraftaki değişkene yazılır.
  • İfade bir sabit değer, başka bir değişken ya da bir işlem olabilir.
  • Matematikteki eşitlik değildir: x = x + 1 “x'in yeni değeri, eski değerinin bir fazlası” demektir.
  • Sol tarafta yalnızca bir değişken olabilir: 5 = sayi; derlenmez.

sayi = sayi * 2;       // 10 → 20

Atamada türler uyumlu olmalıdır: String değişkene sayı, int değişkene metin atanamaz.

Ondalık Sayıların Hassaslığı

  • Ondalık sayılar sınırlı sayıda bitle, ikili (binary) tabanda saklanır.

  • &&'de sol taraf false ise sonuç zaten false'tur: sağ taraf hiç hesaplanmaz.
  • ||'de sol taraf true ise sağ taraf hesaplanmaz.

“if-else” İfadesi

Koşul doğru ise if bloğu, aksi takdirde else bloğu çalışır: iki bloktan tam olarak biri çalışır.

if (koşul) {
    // Koşul doğruysa buradaki kod çalışır.
} else {
    // Koşul yanlışsa buradaki kod çalışır.
}
int sayi = 7;
if (sayi % 2 == 0) {
    System.out.println(sayi + " çift");
} else {
    System.out.println(sayi + " tek");
}

“switch” İfadesi

Bir değerin durumlarına (case) göre farklı kod bloklarını çalıştırır. Değer int, char, String ya da enum olabilir (double, boolean olamaz).

switch (değer) {
    case durum1:
        // Durum 1 için kod
        break;
    case durum2:
        // Durum 2 için kod
        break;
    default:
        // Hiçbir durum uymuyorsa
}
  • break o durumun sonunu belirtir; switch'ten çıkılır.
  • default hiçbir durum uymadığında çalışır (isteğe bağlı).
int gun = 3;
switch (gun) {
    case 1:
        System.out.println("Pazartesi");
        break;
    case 2:
        System.out.println("Salı");
        break;
    case 3:
        System.out.println("Çarşamba");
        break;
    default:
        System.out.println("Diğer gün");
}
Çıktı
Çarşamba

Kontrol Akışı · Kodu adım adım çalıştır

“break” Unutulursa: Düşme (Fall-through)

gun = 2.

switch değeri durumlarla karşılaştırır ve doğrudan case 2'ye atlar.

Salı yazılır. Ama break yok!

break olmadığı için akış bir sonraki duruma düşer (fall-through): koşula bakılmadan Çarşamba yazılır.

Yine düşer: default da çalışır.

switch biter: tek bir gün yerine üç satır yazıldı. Her case'in sonuna break konmalıdır.

int gun = 2;
switch (gun) {
    case 1:
        System.out.println("Pazartesi");
    case 2:
        System.out.println("Salı");
    case 3:
        System.out.println("Çarşamba");
    default:
        System.out.println("Diğer gün");
}

Ok Söz Dizimli switch (Java 14+)

  • Java 14 ile case … -> biçimi geldi: her durum yalnızca kendi kodunu çalıştırır, break gerekmez, düşme olmaz.
  • switch bir değer üreten ifade olarak kullanılabilir; sonuç doğrudan değişkene atanır.
  • Bu derste klasik biçim esas alınır; yeni biçimi gördüğünüzde tanıyın.
int gun = 3;
String ad = switch (gun) {
    case 1 -> "Pazartesi";
    case 2 -> "Salı";
    case 3 -> "Çarşamba";
    default -> "Diğer gün";
};
System.out.println(ad);

Üçlü Operatör (Ternary Operator)

Koşula göre iki değerden birini seçen kısa bir ifadedir: koşul doğruysa değer1, değilse değer2.

sonuç = (koşul) ? değer1 : değer2;

Örnek: bir sayının pozitif ya da negatif olduğunu belirleme.

int sayi = -5;
String sonuc = (sayi > 0) ? "Pozitif" : "Negatif";
System.out.println("Sayı " + sonuc);
Çıktı
Sayı Negatif

Aynı işi yapan if-else:

String sonuc;
if (sayi > 0) {
    sonuc = "Pozitif";
} else {
    sonuc = "Negatif";
}

?: bir değer üretir, bu yüzden atamanın sağında ya da println içinde kullanılır. İki seçeneğin türü uyumlu olmalıdır.

İç İçe Üçlü Operatörler

Üçlü operatörler iç içe kullanılabilir; daha karmaşık koşullar kısa yazılır. Örnek: sayı sıfır mı, pozitif mi, negatif mi?

int sayi = -5;
String sonuc = (sayi == 0) ? "Sıfır" : (sayi > 0) ? "Pozitif" : "Negatif";
System.out.println("Sayı " + sonuc);
sayiSonuç
0Sıfır
7Pozitif
−5Negatif

Okunuşu: “sıfır mı? evet → Sıfır; hayır → pozitif mi? evet → Pozitif; hayır → Negatif”. İkinci ?: birincinin değer2'sidir (sağdan gruplanır).

İkiden fazla iç içe ?: okunurluğu bozar; o durumda if-else if tercih edilir.

“for” Döngüsü

  • Bir işlemi belirli bir aralıkta, kaç kez yapılacağı bilindiğinde tekrarlamak için kullanılır.
  • Başlangıç değeri, koşul ve artırma/azaltma işlemi döngünün çalışmasını kontrol eder.
  • Koşul dikkatle yazılmalıdır: hiç false olmayan bir koşul sonsuz döngü oluşturur (ör. i-- yazıp i <= 4 beklemek).
for (başlangıç; koşul; artırma/azaltma) {
    // Döngü içinde yapılacak işlem
}

Kontrol Akışı · Kodu adım adım çalıştır

for Döngüsü: 1'den 4'e Toplam

toplam 0 ile başlar.

Başlangıç: i = 1. Koşul 1 <= 4 → true, gövdeye girilir.

toplam = 0 + 1 = 1, satır yazdırılır.

i++ → i = 2. Koşul 2 <= 4 → true, gövdeye girilir.

toplam = 1 + 2 = 3, satır yazdırılır.

i++ → i = 3. Koşul 3 <= 4 → true, gövdeye girilir.

toplam = 3 + 3 = 6, satır yazdırılır.

i++ → i = 4. Koşul 4 <= 4 → true, gövdeye girilir.

toplam = 6 + 4 = 10, satır yazdırılır.

i++ → 5. Koşul 5 <= 4 → false: döngü biter. (i yalnızca döngü içinde tanımlıdır.)

Döngüden sonraki satır çalışır: 1 + 2 + 3 + 4 = 10.

int toplam = 0;
for (int i = 1; i <= 4; i++) {
    toplam = toplam + i;
    System.out.println(i + " → " + toplam);
}
System.out.println("Toplam: " + toplam);

“while” Döngüsü

Koşul sağlandığı sürece işlemi tekrarlar; koşul her turdan önce denetlenir. Kaç kez döneceği önceden bilinmediğinde kullanılır. Söz dizimi: while (koşul) { … }

Sayının basamaklarını / 10 ile tek tek atarak sayacağız.

Koşul sayi > 0 doğru → son basamak atılır: sayi = 407, basamak = 1.

Koşul sayi > 0 doğru → son basamak atılır: sayi = 40, basamak = 2.

Koşul sayi > 0 doğru → son basamak atılır: sayi = 4, basamak = 3.

Koşul sayi > 0 doğru → son basamak atılır: sayi = 0, basamak = 4.

Koşul 0 > 0 → false: döngü biter. Kaç tur döneceği önceden bilinmiyordu; koşul belirledi.

Sonuç yazdırılır.

int sayi = 4071;
int basamak = 0;
while (sayi > 0) {
    sayi = sayi / 10;
    basamak++;
}
System.out.println("Basamak sayısı: " + basamak);

“do-while” Döngüsü

  • Gövde en az bir kez çalışır; koşul turun sonunda denetlenir.
  • Kullanıcıdan geçerli bir giriş isteme gibi senaryolar için uygundur.
  • while (koşul); sonundaki ; unutulmamalıdır.
do {
    // Döngü içinde yapılacak işlem
} while (koşul);
// dosyanın başında: import java.util.Scanner;
Scanner giris = new Scanner(System.in);
int sayi;
do {
    System.out.print("1-10 arası bir sayı girin: ");
    sayi = giris.nextInt();
} while (sayi < 1 || sayi > 10);
System.out.println("Girilen: " + sayi);
Örnek çalışma (girişler: 0, 15, 7)
1-10 arası bir sayı girin: 0
1-10 arası bir sayı girin: 15
1-10 arası bir sayı girin: 7
Girilen: 7

“break” ile Döngüden Çıkmak

break içinde bulunduğu döngüden ya da switch bloğundan hemen çıkar. Aranan değer bulunduğunda aramayı bitirmek gibi durumlarda kullanılır.

1 == 5 yanlış → 1 yazdırılır.

2 == 5 yanlış → 2 yazdırılır.

3 == 5 yanlış → 3 yazdırılır.

4 == 5 yanlış → 4 yazdırılır.

i == 5 doğru → break: döngü hemen sonlanır; 5 yazılmaz, 6–10 hiç denenmez.

Akış döngüden sonraki ilk satırdan devam eder.

for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        break; // Döngüyü sonlandır
    }
    System.out.println(i);
}
System.out.println("Döngü bitti");

“continue” ile Tur Atlamak

Koşul sağlandığında turun geri kalanını atlar ve döngüyü bir sonraki değerden sürdürür. Örnek: çift sayıları atlayıp yalnızca tek sayıları yazdırma.

1 % 2 = 1 → koşul yanlış, 1 yazdırılır.

2 % 2 == 0 doğru → continue: println atlanır, i++ ile sonraki tura geçilir.

3 % 2 = 1 → koşul yanlış, 3 yazdırılır.

4 % 2 == 0 doğru → continue: println atlanır, i++ ile sonraki tura geçilir.

5 % 2 = 1 → koşul yanlış, 5 yazdırılır.

6 % 2 == 0 doğru → continue: println atlanır, i++ ile sonraki tura geçilir.

7 % 2 = 1 → koşul yanlış, 7 yazdırılır.

8 % 2 == 0 doğru → continue: println atlanır, i++ ile sonraki tura geçilir.

9 % 2 = 1 → koşul yanlış, 9 yazdırılır.

10 % 2 == 0 doğru → continue: println atlanır, i++ ile sonraki tura geçilir.

11 <= 10 yanlış → döngü biter. continue döngüyü bitirmez, yalnızca o turu atlar.

for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        continue; // Çift sayıları atla
    }
    System.out.println(i);
}

Örnek Problemler

Her satırın çıktısı nedir? (int a = 7, b = 2;)

  1. System.out.println(a / b + " " + a % b + " " + (double) a / b);
  2. System.out.println(1 + 2 + "3" + 4 + 5);
  3. int i = 3; int j = i++ * 2; → i ve j kaçtır?
  4. byte k = (byte) 200; → k kaçtır?
  5. for (int m = 10; m > 0; m -= 3) System.out.print(m + " ");
  6. System.out.println('a' + 1); ve System.out.println((char) ('a' + 1));
Cevapları göster
  1. 3 1 3.5: 7 / 2 = 3 (tam sayı bölmesi), 7 % 2 = 1; (double) önce uygulanır → 7.0 / 2 = 3.5.
  2. 3345: soldan sağa 1 + 2 = 3 (sayı), sonra "3" ile metin olur: "33", "334", "3345".
  3. i = 4, j = 6: sonek i++ eski değeri (3) verir, 3 × 2 = 6.
  4. −56: 200 − 256 = −56 (byte taşması).
  5. 10 7 4 1: m = 10, 7, 4, 1; m = −2 olunca koşul yanlış.
  6. 98 (char + int = int) ve b.

Alıştırmalar

  1. Santigradı Fahrenhayta çevirin: F = C × 9 / 5 + 32. C = 37 için sonuç nedir? int ile 9 / 5 * c + 32 yazılırsa ne olur?
  2. 3725 saniyeyi / ve % ile saat, dakika, saniyeye ayırın.
  3. Bir sayının tek mi çift mi olduğunu üçlü operatörle yazdırın.
  4. 1'den 100'e kadar olan sayılardan 3'ün katı olmayanların toplamını continue ile bulun.
  5. char harf = 'g'; karakterini, kod farkını kullanarak büyük harfe çevirin.
  6. Şu adlardan hangileri geçerli bir tanımlayıcıdır: _toplam, 3boyut, ogrenciNo, final, ad soyad, Final?
Cevaplar / ipuçları
  1. double ile 98.6. int ile c * 9 / 5 + 32 = 98, ama 9 / 5 * c + 32 = 69: 9 / 5 = 1!
  2. saat = s / 3600 → 1, dakika = s % 3600 / 60 → 2, saniye = s % 60 → 5: “1 sa 2 dk 5 sn”.
  3. System.out.println(sayi + (sayi % 2 == 0 ? " çift" : " tek")); → 17 için 17 tek.
  4. if (i % 3 == 0) continue; toplam += i; → 3367 (5050 − 1683).
  5. (char) (harf - 32) → 'G' (yalnızca İngilizce harflerde geçerli).
