Öğrenme Çıktıları

Problemden algoritmaya

Kısa bir problemi girdi → işlem → çıktı adımlarına ayırmak, algoritmayı önce Türkçe adımlarla yazıp sonra Java'ya çevirmek.

Rakamlarla çalışmak

% 10 ile son rakamı almak, / 10 ile silmek; basamak sayısı, rakamlar toplamı ve öğrenci numarası çözme gibi problemleri bu iki işlemle kurmak.

Döngü kalıpları

Sayaç, toplam/çarpım biriktirici, bayrak (boolean) + break ve “kayan pencere” kalıplarını while ve for ile kullanmak; döngüyü adım adım izleyerek çıktıyı önceden bulmak.

Sınırları görmek

Negatif sayı, 0, 1 gibi uç durumları ve int taşmasını fark etmek; Random ile belirli aralıkta rastgele sayı üretmek.

Her Örnekte Aynı Kalıp

  1. Problemi anla: tanımı ve birkaç örneği elle çöz (123 → 3 basamak).

Tek mi Çift mi

Verilen Bir Sayı Tek mi Çift mi?

  • Çift sayı: 2 ile tam bölünür (…, −2, 0, 2, 4, 6 …).
  • Tek sayı: 2 ile bölümünden kalan 0 değildir (1, 3, 5 …, −3).

Algoritma

  1. Kullanıcıdan bir sayı al.
  2. sayi % 2 == 0 ise “çift” yaz.
  3. Değilse “tek” yaz.
Neden == 1 değil de == 0? Java'da -7 % 2 sonucu −1'dir. sayi % 2 == 1 testi negatif tek sayıları “çift” sanar; == 0 (veya != 0) her işarette doğrudur.
Kısa yazım: üçlü operatör

String tur = (sayi % 2 == 0) ? "çift" : "tek";

Tek mi Çift mi

Tek mi Çift mi: Program

import java.util.Scanner;

public class TekMiCiftMi {
    public static void main(String[] args) {
        Scanner okuyucu = new Scanner(System.in);
        System.out.print("Bir sayı girin: ");
        int sayi = okuyucu.nextInt();
        // % : 2'ye bölümden kalan
        if (sayi % 2 == 0) {
            System.out.println(sayi + " çift sayıdır.");
        } else {
            System.out.println(sayi + " tek sayıdır.");
        }
        okuyucu.close();
    }
}

Basamak Sayısı

Basamak Sayısı Bulma

Bir sayının basamak sayısı, içindeki toplam rakam sayısıdır.

  • 123 → 3 basamak (1, 2, 3)
  • 45 → 2 basamak (4, 5)
  • 1000 → 4 basamak

Algoritma

  1. Kullanıcıdan bir sayı al; sayaç = 0.
  2. Sayı 0'dan büyük olduğu sürece (while (sayi > 0)):
    son basamağı sil (sayi = sayi / 10) ve sayacı 1 artır.
  3. Sayaç basamak sayısıdır.
Sezgi: kaç kez 10'a bölebilirim?

1234 → 123 → 12 → 1 → 0. Sayı 0 olana kadar 4 bölme yapılır; her bölme bir basamağı “yer”.

Sayaç kalıbı

Döngüden önce int sayac = 0;, döngüde her turda sayac++. Döngü kaç kez dönerse sayaç o olur.

Uç durum: 0

while koşulu baştan yanlış olduğu için 0 → 0 basamak çıkar. Çözüm sonraki slaytlarda.

Basamak Sayısı

Basamak Sayısı: Program

import java.util.Scanner;

public class BasamakSayisi {
    public static void main(String[] args) {
        Scanner okuyucu = new Scanner(System.in);
        System.out.print("Bir sayı girin: ");
        int sayi = okuyucu.nextInt();
        int basamakSayisi = 0;
        while (sayi > 0) {
            sayi = sayi / 10;   // 1234 → 123
            basamakSayisi++;    // bir basamak daha
        }
        System.out.println("Basamak sayısı: " + basamakSayisi);
        okuyucu.close();
    }
}

sayi = Math.abs(sayi);

    sayi = sayi / 10;

} while (sayi > 0);

Girdi yerine sabit değer: sayi = 1234.

Sayaç 0'dan başlar.

Koşul 1234 > 0 → true, gövdeye girilir.

Koşul 123 > 0 → true, gövdeye girilir.

    sayi = sayi / 10;      // son basamağı sil
    basamakSayisi++;
}

Rakamlar Toplamı

Verilen Bir Sayının Rakamlar Toplamı

Bir sayının rakamları toplandığında elde edilen sonuç:

  • 123 → 1 + 2 + 3 = 6
  • 456 → 4 + 5 + 6 = 15

Algoritma

  1. Kullanıcıdan bir sayı al; toplam = 0.
  2. Sayı 0'dan büyük olduğu sürece:
    • son basamağı al: rakam = sayi % 10
    • toplama ekle: toplam += rakam
    • son basamağı sil: sayi = sayi / 10
  3. Toplamı yazdır.
Basamak sayısıyla farkı

Döngü aynı (while (sayi > 0) + / 10). Fark: sayaç yerine biriktirici (toplam) var ve silmeden önce rakam % 10 ile alınıyor.

Biriktirici kalıbı

Toplam için başlangıç 0, çarpım için başlangıç 1 (etkisiz eleman). Yanlış başlangıç değeri en sık yapılan hatalardandır.

Sıra önemli

Önce % 10, sonra / 10. Ters yazılırsa son rakam kaybolur: 456 için 4 + 5 + 0 = 9 bulunur.

Rakamlar Toplamı

Rakamlar Toplamı: Program

import java.util.Scanner;

public class RakamlarToplami {
    public static void main(String[] args) {
        Scanner okuyucu = new Scanner(System.in);
        System.out.print("Bir sayı girin: ");
        int sayi = okuyucu.nextInt();
        int rakamlarToplami = 0;
        while (sayi > 0) {
            int rakam = sayi % 10;  // son basamak
            rakamlarToplami += rakam;
            sayi = sayi / 10;       // basamağı sil
        }
        System.out.println("Rakamlar toplamı: " + rakamlarToplami);
        okuyucu.close();
    }
}

Bir sayı girin: 456
Rakamlar toplamı: 15
Çalıştırma 2
Bir sayı girin: 123
Rakamlar toplamı: 6

rakam döngü içinde tanımlandığı için yalnızca döngü gövdesinde kullanılabilir; her turda yeniden oluşturulur.

Rakamlar Toplamı · Kodu adım adım çalıştır

Rakamlar Toplamı: Adım Adım

sayi = 456.

Biriktirici 0'dan başlar.

456 > 0 → true.

456 % 10 = 6: son rakam alınır.

Toplama eklenir → 6.

456 / 10 = 45: son rakam silinir.

45 > 0 → true.

45 % 10 = 5: son rakam alınır.

Toplama eklenir → 11.

45 / 10 = 4: son rakam silinir.

4 > 0 → true.

4 % 10 = 4: son rakam alınır.

Toplama eklenir → 15.

4 / 10 = 0: son rakam silinir.

0 > 0 → false: döngü biter (rakam artık yok).

Sonuç yazdırılır. Rakamlar sağdan sola gelir: 6, 5, 4.

int sayi = 456;
int rakamlarToplami = 0;
while (sayi > 0) {
    int rakam = sayi % 10;
    rakamlarToplami += rakam;
    sayi = sayi / 10;
}
System.out.println("Toplam: " + rakamlarToplami);

Üs Alma

Verilen Bir Sayının Üssünü Alma

Üs alma, bir sayının (taban) kendisiyle belirli sayıda (üs) çarpılmasıdır:

  • 23 = 2 × 2 × 2 = 8
  • 52 = 5 × 5 = 25
  • 70 = 1 (hiç çarpma yok)

Algoritma

  1. Kullanıcıdan taban ve üs al.
  2. sonuc = 1 (çarpmanın etkisiz elemanı).
  3. Üs kadar dönen bir döngü kur.
  4. Her turda sonuc = sonuc * taban.
Neden for?

Tekrar sayısı baştan bellidir (üs kadar). Tekrar sayısı belli ise for, “koşul sağlandıkça” ise while daha okunaklıdır.

for (int i = 0; i < us; i++)

i = 0, 1, …, us − 1 → tam us tur. us = 0 ise hiç dönmez ve sonuç 1 kalır.

Hazır metot

Math.pow(2, 10) → 1024.0 (double döner). Döngüyle yazmak algoritmayı öğretir.

Üs Alma · Kodu adım adım çalıştır

Üs Alma: Adım Adım

Taban 2, üs 3.

sonuc = 1: henüz hiç çarpma yapılmadı.

i = 0 ile başla. 0 < 3 → true.

sonuc = 1 × 2 = 2.

i++ → 1. 1 < 3 → true.

sonuc = 2 × 2 = 4.

i++ → 2. 2 < 3 → true.

sonuc = 4 × 2 = 8.

i++ → 3. 3 < 3 → false: döngü biter (3 tur).

Sonuç yazdırılır. (^ burada yalnızca metindir; Java'da üs operatörü yoktur.)

int taban = 2, us = 3;
int sonuc = 1;
for (int i = 0; i < us; i++) {
    sonuc = sonuc * taban;
}
System.out.println(taban + "^" + us + " = " + sonuc);

Üs Alma

Üs Alma: Program ve Sınırlar

import java.util.Scanner;

public class UsAlma {
    public static void main(String[] args) {
        Scanner okuyucu = new Scanner(System.in);
        System.out.print("Taban: ");
        int taban = okuyucu.nextInt();
        System.out.print("Üs: ");

        okuyucu.close();
    }
}

Faktöriyel

Faktöriyel Hesaplama

Pozitif bir tam sayının faktöriyeli, 1'den kendisine kadar olan tam sayıların çarpımıdır. Gösterim: n!

  • 5! = 5 × 4 × 3 × 2 × 1 = 120
  • 3! = 3 × 2 × 1 = 6
  • Tanım gereği 0! = 1

Algoritma

  1. Kullanıcıdan bir sayı al.
  2. faktoriyel = 1.
  3. Sayı 0'dan büyük olduğu sürece: faktoriyel *= sayi, ardından sayi--.
Geriye doğru sayma

Çarpmanın sırası sonucu değiştirmez: 5 × 4 × 3 × 2 × 1 = 1 × 2 × 3 × 4 × 5. Bu yüzden sayıyı azaltarak (sayi--) da yukarı sayarak (for (int i = 1; i <= n; i++)) da hesaplanır.

Çok hızlı büyür

10! = 3 628 800; 13! artık int'e sığmaz. Sonuç değişkeni long seçilmelidir (en çok 20!).

Faktöriyel

Faktöriyel: Program

import java.util.Scanner;

public class Faktoriyel {
    public static void main(String[] args) {
        Scanner okuyucu = new Scanner(System.in);
        System.out.print("Bir sayı girin: ");
        int sayi = okuyucu.nextInt();
        int n = sayi;            // asıl değeri sakla
        long faktoriyel = 1;     // 0! = 1
        while (sayi > 0) {
            faktoriyel *= sayi;  // f = f * sayi
            sayi--;              // bir küçüğe geç
        }
        System.out.println(n + "! = " + faktoriyel);
        okuyucu.close();
    }
}

Asal Sayı

Asal Sayı Bulma

1 ve kendisi dışında pozitif tam böleni olmayan, 1'den büyük sayılara asal sayı (prime number) denir.

  • Örnekler: 2, 3, 5, 7, 11, 13 …
  • 1 asal sayı değildir; 2 tek çift asal sayıdır.
  • 9 = 3 × 3 asal değildir.

Algoritma

  1. Kullanıcıdan bir sayı al; asal = true varsay (2'den küçükse false).
  2. 2'den sayı − 1'e kadar her i için sayi % i == 0 mı bak.
  3. Bir bölen bulunursa asal = false yap ve döngüden çık (break).
  4. Döngüden sonra asal değerine göre yazdır.
Bayrak (flag) kalıbı

“Hiç bölen yok mu?” sorusu ancak bütün adaylar denendikten sonra cevaplanır. Bu yüzden sonuç bir boolean değişkende tutulur ve döngü bittikten sonra yazdırılır.

break neden?

İlk bölen bulunduğunda cevap kesinleşir: “asal değil”. Kalan adayları denemek gereksizdir.

Uç durumlar

0, 1 ve negatif sayılarda döngü hiç dönmez; ayrı kontrol olmazsa “asal” sanılırlar.

Asal Sayı

Asal Sayı: Program

import java.util.Scanner;
public class AsalSayi {
    public static void main(String[] args) {
        Scanner okuyucu = new Scanner(System.in);
        System.out.print("Bir sayı girin: ");
        int sayi = okuyucu.nextInt();
        boolean asal = true;    // asal varsay
        if (sayi < 2) {
            asal = false;       // 0, 1, negatifler
        }
        for (int i = 2; i < sayi; i++) {
            if (sayi % i == 0) {  // bölen bulundu
                asal = false;
                break;            // aramayı bitir
            }
        }
        if (asal) {
            System.out.println(sayi + " asal sayıdır.");
        } else {
            System.out.println(sayi + " asal değildir.");
        }
        okuyucu.close();
    }
}

Asal Sayı: 9 için Adım Adım

sayi = 9.

Önce asal olduğu varsayılır.

i = 2, 2 < 9 → true.

9 % 2 = 1 → bölen değil, if atlanır.

i++ → 3, 3 < 9 → true.

9 % 3 = 0 → bölen bulundu!

Bayrak indirilir: asal = false.

break: 4 … 8 hiç denenmeden döngüden çıkılır.

Döngü sonrası: if (asal) → false, else koluna gidilir.

Yalnızca 2 deneme ile cevap bulundu.

int sayi = 9;
boolean asal = true;
for (int i = 2; i < sayi; i++) {
    if (sayi % i == 0) {
        asal = false;
        break;
    }
}
if (asal) {
    System.out.println(sayi + " asal sayıdır.");
} else {
    System.out.println(sayi + " asal değildir.");
}

Rastgele Sayı

Rastgele Sayı Üretme

Rastgele sayılar belirli bir aralıktan, önceden tahmin edilemeyecek biçimde seçilen sayılardır. Oyunlar (zar, kart karıştırma), simülasyonlar, şifreleme ve istatistikte (örnekleme) kullanılır.

Gerçek rastgele

Fiziksel bir sürece dayanır: radyoaktif bozunma, elektronik gürültü, atmosfer gürültüsü. Tekrar üretilemez.

Sözde rastgele (pseudo-random)

Matematiksel bir formülle üretilir; rastgele görünür ama aynı başlangıçtan hep aynı dizi çıkar. Programlarda genellikle bu kullanılır.

Tohum (seed)

Sözde rastgele üretecin başlangıç değeridir. new Random() tohumu kendisi seçer; new Random(42) hep aynı diziyi verir (test için yararlı).

Java'da iki yol: java.util.Random sınıfı (nextInt, nextDouble, nextBoolean) ve Math.random() (0.0 ≤ x < 1.0 aralığında double). Şifreleme gibi güvenlik gerektiren işlerde java.security.SecureRandom kullanılır.

Rastgele Sayı

Random ile Aralıkta Sayı

import java.util.Random;

Öğrenci Numarası

Öğrenci Numarasını Çözme

Öğrenci numarası her öğrenciyi tanımlayan tekil bir kimliktir; rakamları kayıt bilgilerini taşır. Bu örnekteki 9 haneli düzen: ilk iki hane kayıt yılı, soldan 4. hane bölüm kodu (0–9), son üç hane bölümdeki kayıt sırası.

Numara: 230707123. Her bilgi / ve % ile “kesilip” alınır.

Sağdaki 7 haneyi atmak için 107 = 10000000'a böl: kayıt yılı 2023.

Son üç hane için 103 = 1000'e göre kalan: kayıt sırası 123.

Önce sağdaki 5 haneyi at (/ 100000), kalan 2307'nin son rakamını al (% 10): bölüm 7.

Öğrenci Numarası: Program

import java.util.Scanner;

public class OgrenciNumarasi {
    public static void main(String[] args) {
        Scanner okuyucu = new Scanner(System.in);
        System.out.print("Öğrenci numarası: ");
        int numara = okuyucu.nextInt();
        // ilk iki hane, son üç hane, soldan 4. hane
        int kayitYili = (numara / 10000000) + 2000;
        int kayitSirasi = numara % 1000;
        int bolumu = (numara / 100000) % 10;
        System.out.println("Kayıt yılı: " + kayitYili);
        System.out.println("Kayıt sırası: " + kayitSirasi);
        if (bolumu == 7) {
            System.out.println("Bölüm: Elektrik Elektronik");
        } else if (bolumu == 6) {
            System.out.println("Bölüm: Bilgisayar");
        } else {
            System.out.println("Bilinmeyen bölüm");
        }
        okuyucu.close();
    }
}

Fibonacci

Fibonacci Serisi

Her terimin kendisinden önceki iki terimin toplamı olduğu sayı dizisidir:

1, 1, 2, 3, 5, 8, 13, 21, 34, …

  • Bu bölümde dizi 1 ve 1 ile başlatılır: F(0) = 1, F(1) = 1, F(n) = F(n − 1) + F(n − 2) (n ≥ 2). Birçok kaynak 0'dan başlatır (F(0) = 0, F(1) = 1); aynı dizi bir terim kaymış olur.
  • Doğada sık görülür: yaprakların dizilişi, ayçiçeği ve kozalaktaki sarmallar.
  • Altın oran ile bağlantılıdır: ardışık iki terimin oranı φ = (1 + √5) / 2 ≈ 1.618'e yaklaşır.

Kenarları Fibonacci sayıları olan kareler bir dikdörtgeni doldurur; dikdörtgenin kenar oranı 13 / 8 ≈ 1.625.

Kayan pencere

Yeni terim için yalnızca son iki terimi bilmek yeter: iki değişken (sayi1, sayi2) her turda bir adım kaydırılır.

Fibonacci ve Altın Oran: Program

import java.util.Scanner;

public class Fibonacci {
    public static void main(String[] args) {
        Scanner okuyucu = new Scanner(System.in);
        System.out.print("Kaç terim? ");
        int sayi = okuyucu.nextInt();
        int sayi1 = 1, sayi2 = 1;   // ilk iki terim
        int sonuc = 0;
        System.out.print("1 1 ");
        for (int i = 2; i < sayi; i++) {  // 2'den başla
            sonuc = sayi1 + sayi2;  // son iki terim
            sayi1 = sayi2;          // pencereyi kaydır
            sayi2 = sonuc;
            System.out.print(sonuc + " ");
        }
        System.out.println();
        double oran = (double) sayi2 / sayi1;  // önce dönüştür
        System.out.println("Altın oran ≈ " + oran);
        okuyucu.close();
    }
}

Örnek Problemler

Programı çalıştırmadan cevaplayın.

  1. int x = 100, sayac = 0; while (x > 0) { x = x / 3; sayac++; } → sayac kaçtır?
  2. Rakamlar toplamı programında += yerine *= ve başlangıç 1 yazılırsa 2357 için sonuç nedir?
  3. Öğrenci numarası programı 230612045 için ne yazdırır?
  4. Asal sayı programı 91 için break anında i kaçtır? 91 asal mı?
  5. Üs alma programında üs 0 girilirse döngü kaç kez döner, sonuç nedir?
  6. 1000'den küçük en büyük Fibonacci sayısı (1, 1, 2, … dizisinde) kaçtır?
Cevapları göster
  1. 5: 100 → 33 → 11 → 3 → 1 → 0 (beş bölme). Bu, sayının 3 tabanındaki basamak sayısıdır.
  2. 210 = 2 × 3 × 5 × 7 (rakamlar çarpımı).
  3. Kayıt yılı: 2023, Kayıt sırası: 45, Bölüm: Bilgisayar (2306 % 10 = 6).
  4. i = 7: 91 = 7 × 13, asal değildir.
  5. 0 kez (0 < 0 yanlış); sonuç başlangıç değeri 1 kalır: x0 = 1.
  6. 987 (sonraki terim 1597).

Özet

Alıştırmalar

  1. Bir sayıyı ters çeviren programı yazın (1234 → 4321).
  2. Bir sayının palindrom (tersi kendisine eşit) olup olmadığını bulun; 12321 ile deneyin.
  3. 1 ile 1000 arasındaki mükemmel sayıları (kendisi hariç bölenleri toplamı kendisine eşit) yazdırın.
  4. İki sayının en büyük ortak bölenini (EBOB) while ile bulun; 48 ve 18 için deneyin.
  5. Dijital kök: rakamlar toplamını tek basamak kalana kadar tekrarlayın. 98765 için sonuç?
  6. Collatz: sayı çiftse 2'ye böl, tekse 3 × sayı + 1 yap; 1 olana kadar devam edin. 6 kaç adımda 1 olur?
Cevaplar / ipuçları
  1. ters = ters * 10 + sayi % 10; sayi = sayi / 10; → 4321.
  2. Asıl değeri kopyalayıp tersini bulun, karşılaştırın: 12321 → palindrom.
  3. İç içe döngü: dışta n, içte bölen toplamı → 6 28 496.
  4. Öklid: while (b != 0) { int k = a % b; a = b; b = k; } → 6.
  5. 98765 → 35 → 8 (iç içe while: dışta sayi >= 10).
  6. 6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1: 8 adım.
