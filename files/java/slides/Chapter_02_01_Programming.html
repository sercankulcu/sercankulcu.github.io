Programming Languages

What Is a Programming Language?

  • A programming language is a notation for expressing the computations a machine can perform: an artificial language.
  • It is used to write programs that control a machine's behavior:
    • algorithms stated clearly and precisely;
    • as a means of communication between programmers.
  • It gives computers, phones and embedded devices their functionality.
  • By abstraction level: machine language and assembly are low-level; Java and Python are high-level.
  • The choice of language depends on the project's needs.
  • Examples: C, C++, Java, Python, Prolog, Haskell, Scala…

Programming Languages

General-Purpose and Domain-Specific

  • By application domain, languages are either general-purpose or domain-specific.

General-purpose

  • A broad core instruction set that supports a wide range of applications.
  • Java, C, C++, Python: desktop, web, mobile, embedded…

Domain-specific

  • Focuses on one kind of application and makes those tasks easy.
  • MATLAB: numerical computing; optimized matrix and vector operations. SQL: database queries.

MATLAB · matrix multiplication

C = A * B;   % one line

Java · same job, loops written by hand

for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++)
        for (int k = 0; k < n; k++)
            C[i][j] += A[i][k] * B[k][j];

Programming Languages

Programming Paradigms

A paradigm is the basic approach taken to solve a problem; languages can attack the same problem in different ways.

ImperativeThe programmer tells the machine, step by step, how to change its state. FORTRAN, BASIC, Pascal, C…
FunctionalTreats computation as the evaluation of mathematical functions and avoids changing state. Lisp, Scheme, Haskell…
LogicDescribes the logic of a computation (facts and rules), not its control flow. Prolog
Object-orientedGroups related data and methods into an object; instructions live with the state they work on. C++, Java, C#, Python…
Java is mainly object-oriented and imperative; since Java 8 it also has functional features (lambdas, streams). Languages that support several paradigms are called multi-paradigm.

Programming Languages

Same Problem: Imperative vs. Functional

Problem: find the sum of the numbers 1 to 5.

import java.util.stream.IntStream;

public class Paradigm {
    public static void main(String[] args) {
        // Imperative: change state step by step
        int sum = 0;
        for (int i = 1; i <= 5; i++) {
            sum = sum + i;
        }
        System.out.println("Imperative: " + sum);

        // Functional (Java 8+): say what you want
        int result = IntStream.rangeClosed(1, 5).sum();
        System.out.println("Functional: " + result);
    }
}

Output

Imperative: 15
Functional: 15
  • Imperative: sum is updated at every step; you spell out “how”.
  • Functional: “the sum of the range 1..5” is requested; no variable is updated.

Programming Languages · Step-by-step code trace

Imperative vs. Functional: Code Trace

In the imperative version, the sum state variable starts at 0.

i = 1: 1 <= 5 is true → sum = 0 + 1 = 1. The state changes on every pass.

i = 2: 2 <= 5 is true → sum = 1 + 2 = 3.

i = 3: 3 <= 5 is true → sum = 3 + 3 = 6.

i = 4: 4 <= 5 is true → sum = 6 + 4 = 10.

i = 5: 5 <= 5 is true → sum = 10 + 5 = 15.

i becomes 6: 6 <= 5 is false → the loop ends.

The result is printed: five passes add up to 15.

Functional: rangeClosed(1, 5) generates the numbers 1…5, sum() adds them up. No variable is updated step by step.

Both give the same result; the difference is whether you write how to do it or what you want.

int sum = 0;
for (int i = 1; i <= 5; i++) {
    sum = sum + i;
}
System.out.println("Imperative: " + sum);

int result = IntStream.rangeClosed(1, 5).sum();
System.out.println("Functional: " + result);

Programming Languages

Logic and Object-Oriented

Logic · Prolog

% facts
parent(ali, ayse).
parent(ayse, can).
% rule
grandparent(X, Z) :- parent(X, Y),
                     parent(Y, Z).
% query
?- grandparent(ali, can).
true.

Only facts and a rule are given; Prolog itself decides how to answer the query (the search order).

Rectangle object carries both data (width, height) and the method (area()) that works on that data.

Object-oriented · Java

public class Rectangle {
    double width, height;          // data (state)

    Rectangle(double width, double height) {
        this.width = width;
        this.height = height;
    }

    double area() {          // behavior
        return width * height;
    }

    public static void main(String[] args) {
        Rectangle d = new Rectangle(3, 4);
        System.out.println("Area: " + d.area());
    }
}

Output

Area: 12.0

Programming Languages · Step-by-step code trace

Object-Oriented: Code Trace

main starts. The stack holds a main frame; d does not refer to an object yet.

new allocates the object on the heap; fields start at the default 0.0. The constructor is called: 3 and 4 are widened to double.

this.width is the object's field; the width on the right is the parameter. The field becomes 3.0.

height becomes 4.0. The constructor returns and its frame is popped.

new evaluates to the object's reference; d now refers to this object.

d.area(): this and d refer to the same object. width * height = 3.0 × 4.0 = 12.0 is returned.

The returned 12.0 is concatenated with the string: Area: 12.0. Data (width, height) and behavior (area) live in the same object.

public class Rectangle {
    double width, height;
    Rectangle(double width, double height) {
        this.width = width;
        this.height = height;
    }
    double area() {
        return width * height;
    }
    public static void main(String[] args) {
        Rectangle d = new Rectangle(3, 4);
        System.out.println("Area: " + d.area());
    }
}

Syntax and Semantics

Static Semantics

  • Static semantics: checks whether a syntactically valid expression is meaningful, before the program runs.
  • English: “I are big” matches the pattern <noun> <verb> <noun>, but “I” is singular and “are” plural → invalid.
  • Java: <value> <operator> <value> is a valid pattern, but dividing a number by a string makes no sense → static semantic error.
double result = 2.3 / "abc";
error: bad operand types for binary operator '/'
  first type:  double
  second type: String
int x = "five";
error: incompatible types:
  String cannot be converted to int
Java is statically typed: the compiler checks the operand types of every operator, so these errors are caught before the program ever runs.

Syntax and Semantics

Semantics

  • Semantics: what a syntactically valid expression means.
  • Natural languages can be ambiguous: “They saw the man with the telescope.”
    • They used the telescope, or
    • the man had the telescope.
  • In a programming language every valid expression has exactly one meaning.
  • But that meaning may not be what the programmer intended: a wrong operation gives an unexpected result.
int a = 7, b = 8;
int avg = (a + b) / 2;
System.out.println(avg);       // expected 7.5
System.out.println(a + b / 2);      // precedence
System.out.println((a + b) / 2.0);  // correct

Output

7
11
7.5

The average of 7 and 8 is 7.5. The first line does integer division; in the second line / is applied before +. The compiler sees no error here.

Syntax and Semantics · Step-by-step code trace

Semantic Error: Code Trace

a = 7, b = 8; both are int. The tree shows the structure of (a + b) / 2.

Parentheses first: a + b = 15 (int).

15 / 2: both operands are int → integer division, so the fraction is dropped: 7.

7 is printed. The program ran without errors, but the meaning is not what we wanted.

No parentheses: / has higher precedence than +. First b / 2 = 4.

Then 7 + 4 = 11 is printed.

2.0 is a double: 15 is widened to double too, 15 / 2.0 = 7.5.

int a = 7, b = 8;
int avg = (a + b) / 2;
System.out.println(avg);       // not 7.5
System.out.println(a + b / 2);      // precedence
System.out.println((a + b) / 2.0);  // correct

Syntax and Semantics

What Can Go Wrong?

Error typeDetected when?Java exampleSymptom
Syntaxcompile time (compiler)System.out.println("Hello")';' expected
Static semanticscompile time (type check)int x = "five";incompatible types
Run-timewhile the program runsa / b (when b is zero)crash: ArithmeticException
Logicnot by the compiler; only by testing(a + b) / 2 for an averagewrong result, infinite loop
  • Syntax errors break clearly defined rules, like spelling mistakes; the computer finds them easily.
  • Static semantic errors are checked by language-specific rules before the program runs. In languages with weak checks, the errors that slip through make program behavior unpredictable.
  • Even a program that is flawless in syntax and static semantics may not do what you expect: it can crash, loop forever, or give the wrong result.

Reading Error Messages

Compile error

public class Hello {
    public static void main(String[] args) {
        System.out.println("Hello")
    }
}
Hello.java:3: error: ';' expected
        System.out.println("Hello")
                                   ^
1 error
  • Hello.java:3: file and line number
  • error: ';' expected: what was expected
  • ^ mark: the error's position
  • If there is an error, no .class file is produced; the program never runs.

Run-time error (exception)

public class Divide {
    public static void main(String[] args) {
        int a = 10, b = 0;
        System.out.println(a / b);
    }
}
Exception in thread "main"
java.lang.ArithmeticException: / by zero
	at Divide.main(Divide.java:4)
  • The code compiles, but at run time an exception is thrown.
  • / by zero: an integer cannot be divided by zero.
  • (Divide.java:4): the line where it happened.
  • If the exception is not caught with try-catch, the program stops at this line.

When several errors are listed, start with the first one; the rest are often side effects of it.

Expressions and Variables · Step by step

Evaluating an Expression Step by Step

The computer does not evaluate an expression in one go; it simplifies it step by step by precedence rules.

(72 - 32) / 9 * 5

First the parentheses: 72 − 32 = 40.

40 / 9 * 5

/ and * have the same precedence → left to right: 40 / 9 first.

4 * 5 (40 / 9 = 4, remainder 4 dropped)

Both operands are int → integer division: 4, not 4.44….

20

Result 20. The mathematically expected value was 22.22…: a semantic (logic) error.

(72.0 - 32) / 9 * 5

Now write 72.0: in double − int − int is first widened to double; the result is 40.0.

40.0 / 9 * 5

40.0 / 9 is now real division: 4.444444444444445.

4.444444444444445 * 5

Multiplication: double × int → double.

22.22222222222222

Correct result. If you need a fractional result, at least one operand must be a double.

Expression tree: lower operations run first; numbers give the order.

Expressions and Variables

Dynamic and Static Typing

Dynamically typed languages (Python, JavaScript)

  • A variable's type is not declared in advance; it is set when a value is assigned.
  • The type can change at run time.
  • Flexible, but errors show up only while running.

Statically typed languages (Java, C, C#)

  • A variable's type is declared explicitly and never changes.
  • Incompatible operations, such as string with integer, are reported at compile time.
  • Safer, and the compiler can generate faster code.

Python

x = 5          # x is an int now
x = "five"      # now a str: no problem
print(x + 1)   # at run time:
# TypeError: can only concatenate
#   str (not "int") to str

Java

int x = 5;
x = "five";     // does not compile:
// error: incompatible types:
//   String cannot be converted to int

Java 10+: var count = 3; declares a variable without writing its type, but the type is still fixed at compile time (asint); Java stays statically typed.

Strings and Types

Don't Compare Different Types

  • Comparing different data types directly causes errors: you cannot compare an integer with a string.
  • Languages define rules and type conversions for comparing types.

✗ Direct comparison

int num = 5;
String text = "5";
boolean b = num == text;
error: bad operand types for binary operator '=='
  first type:  int
  second type: String

✓ Convert to one type first

int num = 5;
String text = "5";
System.out.println(Integer.parseInt(text) == num);
System.out.println(text.equals(String.valueOf(num)));
System.out.println(text.equals(num));
true
true
false

text.equals(num) compiles but always returns false: a String is never equal to an Integer. Compare strings with ==, not equals.

Strings and Types

Operations on Different Types

Operations behave differently on different types: on strings, + means concatenation, not addition.

ExpressionJava resultTypeExplanation
3.0 + 4.07.0doubletwo floating-point numbers
3 + 47inttwo integers
3 + 4.07.0doubleint → double widening (automatic)
"3" + "4""34"Stringconcatenation
3 + "4""34"Stringif one side is a string, the other is converted to a string. Not an error (Python raises TypeError)

Mixing types without knowing the language's rules leads to unexpected results or errors. Java's rules are precise, and the compiler enforces them.

Program and Algorithm · Step-by-step code trace

What Is a Program? Order Matters

A program is a sequence of instructions; the computer executes them one at a time and in order, so getting the order right matters.

Goal: take a and b and swap their values.

a = b: 5 is written to a. Its old value 3 is lost!

b = a: b gets a's current value (5).

Output 5 5: the swap failed. The order of statements decides the result.

The right way: a third, temporary variable.

First, c's value goes into temp and is saved.

Now c can be overwritten: c = 5.

d gets the saved old value of c (3).

Output 5 3: the swap worked.

int a = 3, b = 5;
a = b;
b = a;
System.out.println(a + " " + b);

int c = 3, d = 5;
int temp = c;
c = d;
d = temp;
System.out.println(c + " " + d);

Program and Algorithm

Expressions, Statements and Programs

Expression → valueComputes a value and returns it: 3 + 4 evaluates to 7.
Statement → effectHas an effect: pi = 3.14159; assigns a value to a variable, System.out.println(pi); prints to the screen. In Java, statements end with ;.
Expressions can nestAn expression can appear inside other expressions and statements: double area = pi * r * r;
Program = a sequence of statementsA program is many statements executed in order.

A statement cannot appear inside an expression. println prints (an effect) but returns no value (void):

double d = 3 + System.out.println(pi);
error: 'void' type not allowed here
3 + 4;      // value, no effect
error: not a statement

In Java, assignment also produces a value: int y = (x = 4) + 1; → x = 4, y = 5. It compiles, but it is hard to read, so avoid it.

Common Mistakes

Forgetting the semicolonSystem.out.println("Hello") → ';' expected. javac's ^ marks the end of the line missing the ;.
Mixing up = and ==if (x = 100) → int cannot be converted to boolean. Comparison is ==.
Integer division(a + b) / 2 gives 7 as the average of 7 and 8. Real division needs / 2.0.
** or ^ for powers2 ** 3 → illegal start of expression; 2 ^ 3 compiles but is XOR (1). Use Math.pow(2, 3).

Practice Problems

  1. Evaluate: (a) 10 + 6 / 4 * 2 (b) (10 + 6) / 4 * 2 (c) 10 + 6 / 4.0 * 2
  2. What do these print? System.out.println("Total: " + 2 + 3); and System.out.println(2 + 3 + " total");
  3. After this code runs, what are a and b? int a = 4; int b = a * 3; a = b - a; b = b / a;
  4. Name the error type: (a) int n = 4.5; (b) System.out.println("Hello"; (c) for the area of a circle area = 2 * pi * r;
  5. double c = (f - 32) * 5 / 9; — what is the result for f = 100? What if you declare f and c int instead?
Show answers
  1. (a) 6 / 4 = 1, 1 * 2 = 2 → 12 (b) 16 / 4 = 4, 4 * 2 → 8 (c) 6 / 4.0 = 1.5, × 2 = 3.0 → 13.0
  2. Total: 23 (left-to-right concatenation) and 5 total (the two int values are added first).
  3. b = 12, a = 12 − 4 = 8, b = 12 / 8 = 1 (integer division) → a = 8, b = 1.
  4. (a) static semantics: possible lossy conversion from double to int (b) syntax: ')' or ',' expected (c) logic error: it compiles but computes the circumference; the correct formula is pi * r * r.
  5. 68 × 5 / 9 = 37.77777777777778. int version: 340 / 9 = 37 (fraction dropped).

Summary

Exercises

  1. Give the value and type of: 7 % 3, -7 / 2, 1 / 3 * 3, 1.0 / 3 * 3, Math.pow(2, 10).
  2. Which of these are valid variable names? total2, 2total, _counter, student count, $price, int, averageGrade
  3. Write the algorithm, then the Java code, for a program that reads a Fahrenheit value from the user and converts it to Celsius.
  4. Classify each as an expression or a statement: x * 2, x = 5;, x > 3, System.out.println(x);
  5. 5 / 9 * (f - 32) with int f = 100 gives 0 — why? Fix it in two different ways.
Answers / hints
  1. 1 (int), -3 (int, truncated toward zero), 0 (int: 1 / 3 = 0), 1.0 (double), 1024.0 (double).
  2. Valid: total2, _counter, $price, averageGrade. Invalid: 2total (starts with a digit), student count (space), int (keyword).
  3. Read → c = (f - 32) * 5 / 9 → print; double f = in.nextDouble();. 100 → 37.77777777777778.
  4. Expressions: x * 2, x > 3 (produce values). Statements: x = 5;, System.out.println(x); (have effects).
  5. With integer division 5 / 9 is 0, and 0 × 68 = 0. Fix: 5.0 / 9 * (f - 32) or (f - 32) * 5 / 9 (multiply first: 37).
