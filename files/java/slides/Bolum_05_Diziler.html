Giriş

Öğrenme Çıktıları

Kavram

Dizinin (array) aynı türden, sabit sayıda elemanı ardışık hücrelerde tuttuğunu ve elemanlara 0'dan başlayan indis ile erişildiğini açıklamak.

Söz dizimi

Tek ve çok boyutlu dizileri tanımlamak, new ve ilklendirici listesiyle oluşturmak, length ile dolaşmak.

Bellek

Dizi değişkeninin bir referans olduğunu, dizinin öbekte (heap) durduğunu; atama, kopyalama ve metoda geçirmenin sonucunu öngörmek.

Hatalar

ArrayIndexOutOfBoundsException ve sık derleme hatalarını tanımak, sınır kontrolüyle önlemek.

Algoritmalar

Ortalama, ortanca, mod, doğrusal arama, eşleştirme, tersine çevirme ve seçimli sıralamayı yazmak; O(1), O(n), O(n²) maliyetlerini karşılaştırmak.

Uygulama

Matrisleri iç içe döngülerle doldurmak, yazdırmak, transpozunu almak ve char[][] ile Tic Tac Toe oyunu kurmak.

Dizi Kavramı

Dizi Nedir?

  • Dizi (Array): aynı türdeki verileri düzenli bir şekilde, tek bir ad altında saklayan yapıdır.
  • Aynı adla tanımlanan, bir veya daha fazla veri saklayabilen bir değişken gibi düşünülebilir.
  • Elemanlara indis (index) numarasıyla erişilir; indeksleme sayesinde erişim çok hızlıdır.
  • İlk elemanın indisi 0'dır; n elemanlı dizinin son indisi n − 1'dir.
  • Bir elemana erişmek için dizinin adı ve köşeli parantez içinde indis yazılır: dizi[0].
Apartman daireleriTek bir adres (dizinin adı) ve numaralı daireler (indisler). "3 numara" demek, daireyi bulmaya yeter.
Yumurta kolisiHücre sayısı baştan bellidir; koli büyümez. Her hücreye yalnızca aynı tür şey konur.

Örnek: dizi = [10, 20, 30, 40, 50] ise dizi[0] ilk elemandır ve değeri 10'dur; dizi[4] son elemandır (50).

Dizi Kavramı

Avantajlar ve Dezavantajlar

Avantajları
  • Verileri düzenli ve ardışık bir şekilde saklar.
  • İndeksleme ile elemanlara hızlı erişim sağlar: dizi[i] her i için aynı sürede okunur.
  • Verileri gruplandırarak düzenlemeye olanak sağlar; döngülerle kolayca işlenir.
  • Bellek kullanımı yalındır: yalnızca elemanlar ve uzunluk tutulur.
Dezavantajları
  • Sabit boyutludur: oluşturulduktan sonra boyutu değiştirilemez.
  • Yer kalmadığında eleman eklemek için daha büyük yeni bir dizi oluşturup kopyalamak gerekir.
  • Ortaya ekleme veya ortadan silme, elemanları kaydırmayı gerektirir (ek maliyet).
  • Yalnızca tek türden eleman tutar.

Boyutu değişen listeler için Java'da ArrayList vardır; içinde yine bir dizi kullanır ve dolunca büyütür (sonraki bölüm: Koleksiyonlar).

Erişim ve length

  • Dizi elemanlarına indis ile erişilir; indis 0'dan başlar.

Dizi Değişkeni Bir Referanstır

Öbekte bir dizi oluşur; a değişkeninde dizinin kendisi değil, adresi (referansı) vardır.

b = a yalnızca adresi kopyalar. Artık iki değişken aynı diziyi gösterir (takma ad, alias).

b[0] = 99 ortak diziyi değiştirir…

…bu yüzden a[0] da 99 olur.

clone() öbekte yeni bir dizi oluşturup elemanları kopyalar; c bu yeni diziyi gösterir.

c[1] = 77 yalnızca kopyayı değiştirir; asıl dizi etkilenmez.

a[1] hâlâ 2, c[1] ise 77.

== referansları (adresleri) karşılaştırır: a == b doğru (aynı dizi), a == c yanlış (farklı diziler).

int[] a = {1, 2, 3};
int[] b = a;         // kopya değil!
b[0] = 99;
System.out.println(a[0]);
int[] c = a.clone(); // gerçek kopya
c[1] = 77;
System.out.println(a[1] + " " + c[1]);
System.out.println(a == b);
System.out.println(a == c);

Bellek ve Hatalar

Diziler Bellekte Nerede?

String[] plaka = {"", "Adana", "Adıyaman", "Afyon"};
System.out.println(plaka[1]);
int[] dinamikDizi = new int[10]; // heap'te yer ayrılır
System.out.println(dinamikDizi.length);
dinamikDizi = null; // referans koparıldı
System.out.println(dinamikDizi == null);
  • C/C++'ta int a[10]; yığında durur; malloc/new ile öbekte ayrılan dizi elle serbest bırakılır.
  • Çıktı: Adana, 10, true.
  • Java'da tüm diziler öbektedir; boyut çalışma zamanında verilebilir, sonra sabittir. Serbest bırakma otomatiktir.

Her iki dizi de öbekte (heap) oluşur; yığında (stack) yalnızca referans değişkenleri durur. (String[] hücreleri de aslında ayrı String nesnelerine referanstır.)

dinamikDizi = null diziyi silmez, yalnızca bağı koparır. Dizi artık erişilemez olduğundan çöp toplayıcı (garbage collector) uygun bir anda belleği geri alır.

Metot bitince yığın çerçevesi ve içindeki referanslar otomatik kalkar. Başka referans kalmayan diziler de zamanla toplanır. Java'da free/delete yoktur.

Bellek ve Hatalar

İndis Sınır Dışı Hatası

  • Dizinin sınırları (0 … length − 1) dışındaki bir indise erişildiğinde Java çalışma anında ArrayIndexOutOfBoundsException fırlatır (IndexOutOfBoundsException'ın alt sınıfı).
  • Yakalanmazsa program o satırda çöker; C'deki gibi sessizce başka bir belleği bozmaz.
int[] dizi = {10, 20, 30, 40, 50};

    int deger = dizi[index];
    System.out.println("Değer: " + deger);
} else {
    System.out.println("Geçersiz indis: " + index);
}
// Kontrolsüz erişim:
System.out.println(dizi[index]);

Girilen değerler sırasızdır: ortadaki hücre (9.0) ortanca değildir.

Boyut 4 (çift; girdiler 7 3 9 5): orta1 = 4/2 − 1 = 1, orta2 = 4/2 = 2 → (5.0 + 7.0) / 2 = 6.0.

Neden sıralama?Ortanca sıralamaya göre tanımlıdır. Sırasız dizinin ortasındaki eleman rastgele bir değerdir.
Yan etkiArrays.sort diziyi yerinde değiştirir; girilen sıra kaybolur. Sırayı korumak için önce dizi.clone() alınır.

dizi[2] = 2 == dizi[1] = 2 → seri devam ediyor, mevcutTekrarSayisi = 3. 3 > önceki en iyi → en çok tekrar eden 2 (3 kez).

dizi[3] = 4 ≠ dizi[2] = 2 → yeni seri başlıyor: mevcutTekrarEden = 4, sayaç 1.

dizi[4] = 4 == dizi[3] = 4 → seri devam ediyor, mevcutTekrarSayisi = 2.

dizi[5] = 7 ≠ dizi[4] = 4 → yeni seri başlıyor: mevcutTekrarEden = 7, sayaç 1.

dizi[6] = 9 ≠ dizi[5] = 7 → yeni seri başlıyor: mevcutTekrarEden = 9, sayaç 1.

Doğrusal (Lineer) Arama

Bir dizinin içinde belirli bir elemanı aramanın en basit yolu: baştan sona sırayla her elemana bakmak.

main, lineerArama(dizi, 30)'u çağırır. Metoda dizinin referansı ve 30 gider.

eleman = 10: 10 == 30 yanlış → sıradaki elemana geç.

eleman = 20: 20 == 30 yanlış → sıradaki elemana geç.

eleman = 30: 30 == 30 → doğru. Döngü yarıda kesilir, true döner.

Metot çerçevesi yığından çıkar: sonuc = true. 3 karşılaştırma yetti; 40 ve 50'ye hiç bakılmadı. Hedef 35 olsaydı 5 karşılaştırmadan sonra false dönerdi.

static boolean lineerArama(int[] dizi, int hedef) {
    for (int eleman : dizi) {
        if (eleman == hedef) {
            return true;
        }
    }
    return false;
}

// main içinde:
int[] dizi = {10, 20, 30, 40, 50};
boolean sonuc = lineerArama(dizi, 30);

Doğrusal Aramanın Maliyeti

  • En kötü durumda tüm dizi gezilir: n elemanlı dizide n karşılaştırma.

Seçimli Sıralama

static void secimliSirala(int[] dizi) {
    for (int i = 0; i < dizi.length - 1; i++) {
        int minIndeks = i;
        for (int j = i + 1; j < dizi.length; j++) {
            if (dizi[j] < dizi[minIndeks]) {
                minIndeks = j;
            }
        }
        int gecici = dizi[minIndeks];
        dizi[minIndeks] = dizi[i];
        dizi[i] = gecici;
    }
}
  • Seçimli sıralama (Selection Sort): her adımda en küçük eleman bulunup sıralanmamış kısmın başına yerleştirilir.
  • Dış döngü n − 1 tur, iç döngü kalan elemanları tarar → O(n²) karşılaştırma, en fazla n − 1 takas.
  • Takas dizi içinde, geçici değişkenle yapılır.
yerDegistir(dizi[minIndeks], dizi[i]) biçiminde bir metot çalışmaz: metoda elemanların yalnızca kopyaları gider (bir sonraki slayt).

static void tersineCevir(int[] dizi) {
    int baslangic = 0;
    int bitis = dizi.length - 1;
    while (baslangic < bitis) {
        // Başlangıç ve bitiş elemanlarını değiştir

Tic Tac Toe (X-O Oyunu)

  • 3×3'lük bir oyun tahtası kullanılır: char[][] tahta = new char[3][3];
  • İki oyuncu (X ve O) sırayla hamle yapar; her hamle tek bir atamadır: tahta[satir][sutun] = oyuncu.
  • Kendi işaretinden 3 tanesini aynı satıra, sütuna ya da çapraza yerleştiren oyunu kazanır.
  • Boş hücre kalmazsa oyun berabere biter.

Sağdaki tahtada oynayın: her tıklamada çalışan dizi ataması gösterilir.

Uygulama: Tic Tac Toe

TicTacToe: main

import java.util.Scanner;

public class TicTacToe {
    static Scanner scanner = new Scanner(System.in);

    public static void main(String[] args) {
        char[][] tahta = new char[3][3]; // 3x3'lük tahta
        char oyuncu = 'X'; // İlk oyuncu X
        boolean oyunDevamEdiyor = true;
        tahtaDoldur(tahta); // Tüm hücreler boş
        while (oyunDevamEdiyor) {
            tahtayiGoster(tahta);
            hamleYap(tahta, oyuncu);
            oyunDevamEdiyor = oyunDevamEdiyorMu(tahta, oyuncu);
            // Oyuncu değişimi
            oyuncu = (oyuncu == 'X') ? 'O' : 'X';
        }
        tahtayiGoster(tahta);
    }
    // ... metotlar
}
  • İş metotlara bölünmüştür: doldur, göster, hamle al, kontrol et.
  • Tahta metotlara referansla gider: hamleYap'ın yaptığı değişiklik main'de görünür.
  • Metotlar static olmalıdır; değilse:
error: non-static method tahtaDoldur(char[][]) cannot be referenced from a static context

public static void tahtaDoldur(char[][] tahta) {
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) {
            tahta[i][j] = ' ';

}

public static void tahtayiGoster(char[][] tahta) {

        System.out.print("| ");
        for (int j = 0; j < 3; j++) {
            System.out.print(tahta[i][j] + " | ");
        }
        System.out.println("\n-------------");
    }
}

static Scanner scanner = new Scanner(System.in);

public static void hamleYap(char[][] tahta, char oyuncu) {
    int satir, sutun;
    do {
        System.out.print("Sıra " + oyuncu
                + " oyuncusunda. Satır ve sütun seçin (1-3): ");
        satir = scanner.nextInt() - 1;
        sutun = scanner.nextInt() - 1;
    } while (satir < 0 || satir > 2 || sutun < 0 || sutun > 2
            || tahta[satir][sutun] != ' ');
    tahta[satir][sutun] = oyuncu;
}

public static boolean oyunDevamEdiyorMu(char[][] tahta, char oyuncu) {
    // Kazanan durumlarını kontrol et
    if ((tahta[0][0] == oyuncu && tahta[0][1] == oyuncu && tahta[0][2] == oyuncu) ||
        (tahta[1][0] == oyuncu && tahta[1][1] == oyuncu && tahta[1][2] == oyuncu) ||
        (tahta[2][0] == oyuncu && tahta[2][1] == oyuncu && tahta[2][2] == oyuncu) ||
        (tahta[0][0] == oyuncu && tahta[1][0] == oyuncu && tahta[2][0] == oyuncu) ||
        (tahta[0][1] == oyuncu && tahta[1][1] == oyuncu && tahta[2][1] == oyuncu) ||
        (tahta[0][2] == oyuncu && tahta[1][2] == oyuncu && tahta[2][2] == oyuncu) ||
        (tahta[0][0] == oyuncu && tahta[1][1] == oyuncu && tahta[2][2] == oyuncu) ||
        (tahta[0][2] == oyuncu && tahta[1][1] == oyuncu && tahta[2][0] == oyuncu)) {
        System.out.println("Tebrikler, " + oyuncu + " oyuncusu kazandı!");
        return false;
    }
    // ... berabere kontrolü
  • 8 kazanma çizgisi tek tek denetlenir: her biri 3 hücrenin de oyuncu olmasını ister (&&), çizgilerden biri yeterlidir (||).
  • Yalnızca son hamleyi yapan oyuncu denetlenir: yeni bir çizgiyi ancak o tamamlamış olabilir.
  • Kazanan varsa metot false döndürür: "oyun devam etmiyor".

TicTacToe: Berabere mi?

// oyunDevamEdiyorMu metodunun devamı
// Berabere durumunu kontrol et
boolean berabere = true;
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (tahta[i][j] == ' ') {
            berabere = false;
            break;
        }
    }
    if (!berabere) {
        break;
    }
}
if (berabere) {
    System.out.println("Oyun berabere bitti.");
    return false;
}
return true;
  • Önce oyunun berabere olduğu varsayılır (berabere = true); tek bir boş hücre bu varsayımı çürütür.
  • İç break yalnızca iç döngüden çıkar; dıştaki if (!berabere) break; dış döngüyü de bitirir.
  • Kazanan yoksa ve boş hücre varsa true: oyun devam eder.
  • Önce kazanma, sonra beraberlik denetlenir: son hamle tahtayı doldurup aynı anda kazandırabilir.
