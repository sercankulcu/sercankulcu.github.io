Öğrenme Çıktıları

Çıktıyı tahmin etmek

Döngü içeren bir metodun ekrana ne yazdıracağını, çalıştırmadan önce satır satır ve karakter karakter bulmak.

İç içe döngüleri okumak

Dış döngünün satırları, iç döngünün sütunları ürettiğini görmek; iç döngünün kaç kez döndüğünü hesaplamak.

Deseni formüle çevirmek

Kare, üçgen, piramit ve çerçeve desenleri için satır başına boşluk ve yıldız sayısını i cinsinden yazmak.

Biçimlendirmek

print/println farkını, + ile String birleştirmeyi ve printf ile hizalamayı doğru kullanmak.

Giriş

Çıktı Tahmini Nasıl Yapılır?

  1. Parametreyi sabitle: örneğin sayi = 3 gibi küçük bir değerle başla.
  2. Dış döngü = satırlar: her turunda kaç satır üretildiğini bul (çoğunlukla bir println()).
  3. İç döngü = sütunlar: o satırda kaç kez döndüğünü i cinsinden yaz.
  4. Bir tablo tut: i, j ve o an yazılanı satır satır not et.
  5. Genelle: küçük örnekteki kuralı sayi = 9 için uygula.
Benzetme: daktilo

Konsol bir daktilo gibidir. print bir karakter basar ve kafayı sağa kaydırır; println kâğıdı bir satır yukarı iter, kafa satır başına döner. Geri dönüp eski bir satıra yazamazsınız: çıktı her zaman soldan sağa, yukarıdan aşağıya oluşur.

Bu bölümdeki örneklerin hepsi cizdir adlı bir metottur ve aksi belirtilmedikçe cizdir(9) çağrısıyla çalıştırılır. İzleme slaytlarında daha kısa olsun diye 3 veya 4 kullanılır.

Metotları Çalıştırmak: Program İskeleti

public class OrnekCiktilar {

    static void cizdir(int sayi) {
        for (int i = 0; i < sayi; i++) {
            System.out.print("*");
        }
        System.out.println();
    }

    public static void main(String[] args) {
        cizdir(9);   // metodu çağır
        cizdir(3);
    }
}

cizdir(3): Üçgeni İzle

cizdir(3) çağrıldı. İç döngünün sınırı bu kez sayi değil, i.

i = 0: iç döngü j = 0 … 0 için, yani 1 kez dönecek.

j = 0 ≤ i = 0 → doğru: yıldız yazılır.

1 <= 0 yanlış → iç döngü biter; satırda 1 yıldız var, alt satıra geçilir.

i = 1: iç döngü j = 0 … 1 için, yani 2 kez dönecek.

j = 0 ≤ i = 1 → doğru: yıldız yazılır.

j = 1 ≤ i = 1 → doğru: yıldız yazılır.

2 <= 1 yanlış → iç döngü biter; satırda 2 yıldız var, alt satıra geçilir.

i = 2: iç döngü j = 0 … 2 için, yani 3 kez dönecek.

j = 0 ≤ i = 2 → doğru: yıldız yazılır.

j = 1 ≤ i = 2 → doğru: yıldız yazılır.

j = 2 ≤ i = 2 → doğru: yıldız yazılır.

3 <= 2 yanlış → iç döngü biter; satırda 3 yıldız var, alt satıra geçilir.

3 < 3 yanlış: dış döngü biter. Toplam 1 + 2 + 3 = 6 yıldız.

Koşullu Desenler

Örnek 7: Çerçeveli Kare

static void cizdir(int sayi) {
    for (int i = 0; i < sayi; i++) {
        for (int j = 0; j < sayi; j++) {
            if (j == 0 || j == sayi - 1
                    || i == 0 || i == sayi - 1) {
                System.out.print("* ");
            } else {
                System.out.print("  ");   // iki boşluk
            }
        }
        System.out.println();
    }
    System.out.println();
}
  • Yalnızca kenarlara yıldız konur; iç kısım boş kalır.
  • Her hücre için if karar verir: kenardaysa "* ", değilse " ".
  • İki dal da 2 karakter yazar: sütunlar bu sayede hizalı kalır.

Sık Yapılan Hatalar (1): Derleme Hataları




main'den static olmayan metot
void cizdir(int sayi) tanımlanıp main'den cizdir(9) çağrılırsa: error: non-static method cizdir(int) cannot be referenced from a static context. Metodu static yapın.


İç döngüde aynı değişken
İç içe iki for'da da int i: error: variable i is already defined in method cizdir(int). İç döngüye j deyin.


Argümansız print
System.out.print(); → error: no suitable method found for print(no arguments). Satır sonu için println() kullanılır.


Döngü değişkenini dışarıda kullanmak
Döngüden sonra System.out.println(i); → error: cannot find symbol (symbol: variable i). i yalnızca for'un içinde yaşar.


Eksik süslü parantez
İç içe bloklarda bir } unutulursa: error: reached end of file while parsing. Girintileme, hangi {'nin açık kaldığını gösterir.


void metodun sonucunu kullanmak
int sonuc = cizdir(9); → error: incompatible types: void cannot be converted to int. cizdir değer döndürmez, yalnızca yazar.

Sık Yapılan Hatalar (2): Derlenir ama Çıktı Yanlış




for'dan sonra ;
for (int i = 0; i < sayi; i++); boş gövdeyle 9 kez döner; alttaki blok bir kez çalışır. cizdir(9) yalnızca * yazar.


print ↔ println
İç döngüde println("*") her yıldızı ayrı satıra yazar; kare yerine 81 satırlık bir sütun çıkar.


Bir eksik / bir fazla
j <= sayi yazmak her satıra bir fazla yıldız koyar; i = 1 ile başlayıp i < sayi demek bir satır eksik bırakır.


println()'in yeri
İç döngünün içine konursa her hücre ayrı satıra düşer; dış döngünün dışına konursa tüm desen tek satır olur.


char toplama
System.out.print('*' + '*'); → 84. İki char sayı gibi toplanır; "*" + "*" yazın.


Farklı genişlikte hücreler
Kenar "* " (2 karakter), iç " " (1 karakter) ise sağ kenar kayar. Her dal aynı sayıda karakter yazmalıdır.
