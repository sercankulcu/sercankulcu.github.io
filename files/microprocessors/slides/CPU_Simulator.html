CPU Simulator

An 8-bit educational CPU with one accumulator (ACC), a 256-byte data RAM and three flags (Z, N, C). Every instruction runs in five micro-steps, fetch, decode, operand, execute, write back, so each transfer between memory and the CPU registers can be followed on the diagram.

How to use it

  • Pick an example or open Edit source… to write your own program; Assemble & reset loads it. Programs can be exported to and imported from .asm files.
  • Micro-step advances one phase, Instruction one whole instruction, Run plays with the chosen speed and stops at breakpoints (click ○ in the listing). Back undoes micro-steps. Keyboard: → micro-step, Shift + → instruction, ← back.
  • Data memory: select a cell to inspect it; while paused at an instruction boundary a new value can be written to it. Reset restores the .DATA values. The page menu shows other 32-byte pages.
  • IN consumes queued input bytes (0–255) and waits when the queue is empty; OUT prints ACC. The values menu switches between decimal, hex and binary.

Numbers: decimal 42, hex 0x2A or binary 0b101010, all 0–255. A jump target t is a label (loop:) or an instruction number. Flags change only at write back, so STA, OUT and jumps keep the flags of the previous ALU instruction.

On the diagram

PC holds the number of the next instruction, IR the fetched instruction, MAR the data address and MDR the byte read from or written to RAM. The operand latch feeds the ALU; the result reaches ACC and the flags only at write back. The RAM window shows the eight bytes around the current address.

This is a teaching machine, not the 8086: the real 8086 has 16-bit registers, segmented memory and many more flags. Related slides: Bölüm 1 · 8086 Mimarisi.
