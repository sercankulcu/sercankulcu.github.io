Shift and Rotate

Goal: see where every bit goes in the 8086's shift (SHL, SAL, SHR, SAR) and rotate (ROL, ROR, RCL, RCR) instructions, which bit falls into CF, and how the flags are set.

How to use it

  1. Choose the instruction, the size (AL or AX) and the value; the value can be hexadecimal (96h), binary (10010110b) or decimal (-106).
  2. The count is 1 (SHL AL, 1) or CL (SHL AL, CL); on the 8086 no other constant can be written. Here CL can be chosen between 0 and 31.
  3. Step ▶ (or →) performs one single-bit shift at a time: the bit that falls into the CF box and the bit that enters the vacated place are highlighted. The flags are explained in the last step.
  4. Try it yourself: predict the result and CF before the instruction runs.

Rules

  • SHL = SAL: shift left, 0 enters from the right, the bit shifted out goes to CF. With no overflow the unsigned value × 2.
  • SHR: shift right, 0 enters from the left (unsigned ÷ 2). SAR: the sign bit is kept (signed ÷ 2, rounds toward −∞).
  • ROL/ROR: the bit shifted out goes both to the other end and to CF. RCL/RCR: CF is part of the ring too (a 9-bit ring for 8 bits, 17-bit for 16 bits).
  • CF: the last bit shifted out. OF is defined only when the count is 1: for SHL/SAL/ROL/RCL the most significant bit of the result XOR CF; for SHR the old most significant bit of the operand; for SAR 0; for ROR/RCR the XOR of the top two bits of the result. If the count is greater than 1, OF is undefined.
  • Shifts set SF, ZF and PF from the result, AF is undefined. Rotates affect only CF and OF.
  • If the count is 0, no flag changes. The 8086 does not mask the count; later processors use only the low 5 bits of CL.
