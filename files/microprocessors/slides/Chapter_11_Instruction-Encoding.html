Instruction Encoding: Opcode, D/W and ModR/M

Goal: see the machine code of an 8086 instruction field by field. General format: opcode (6 bits) + D (1: REG is the destination, 0: REG is the source) + W (0: byte, 1: word), then the ModR/M byte: MOD (2 bits), REG (3 bits), R/M (3 bits); if needed a displacement (disp) and immediate data. 16-bit values are written little-endian: low byte first.

MODMeaning
00memory, no disp (if R/M = 110, a direct 16-bit address)
01memory + 8-bit disp (signed)
10memory + 16-bit disp
11register: R/M is a register code too

REG / R/M register codes: 000 AL/AX, 001 CL/CX, 010 DL/DX, 011 BL/BX, 100 AH/SP, 101 CH/BP, 110 DH/SI, 111 BH/DI. R/M memory codes: 000 [BX+SI], 001 [BX+DI], 010 [BP+SI], 011 [BP+DI], 100 [SI], 101 [DI], 110 [BP] (a direct address when MOD = 00), 111 [BX].

How to use it

  1. Encode: type an instruction in the box (e.g. MOV CL, [BX+SI+12h]) or pick an example. If an instruction has more than one valid encoding (D = 0 / D = 1, the short accumulator form, the sign extension of 83h), you choose with the buttons above; the first button is the shortest form.
  2. Decode: type the bytes in hexadecimal (e.g. 8A 48 12); each field is read in turn.
  3. Step ▶ / ◀ Back (→ / ←), Play, Reset reveal the fields one by one. With Try it yourself on, you first choose the correct code or instruction.

Supported: MOV, ADD, OR, ADC, SBB, AND, SUB, XOR, CMP, TEST (register, memory, immediate), MOV with a segment register, INC/DEC/PUSH/POP, NOT/NEG/MUL/DIV, IN/OUT, INT, RET and single-byte instructions; the ES:/CS:/SS:/DS: prefixes. In the decode direction jumps are shown with a relative distance ($+n).

The encodings follow the format tables of the Intel 8086 manual; they were checked against the examples in the slides (e.g. MOV AX, BX = 8B C3 / 89 D8), against an independent reference encoder and against the instruction lengths of the shared 8086 tool.
