Giriş

Öğrenme Çıktıları

Komut sınıfları

8086'nın yaklaşık 100 komutunu yedi işlevsel sınıfa ayırmak ve her sınıfın tipik kullanımını açıklamak.

Makine kodu

Opcode, D/W bitleri ve ModR/M baytından bir komutun makine kodunu çıkarmak.

Bayrak etkileri

Hangi komutun hangi bayrağı nasıl değiştirdiğini bilmek; işaretli ve işaretsiz karşılaştırmayı ayırt etmek.

Program izleme

Kaydırma, dizgi, döngü ve çağrı komutları içeren kısa programları yazmaç düzeyinde adım adım izlemek.

Komut Kodlama

Makine Kodu Biçimi

D (direction)1: REG alanı hedef; 0: REG alanı kaynak.
W (word)0: bayt (8 bit) işlem; 1: sözcük (16 bit) işlem.
ModR/MMOD işlenenin yazmaç mı bellek mi olduğunu, R/M adres biçimini, REG diğer yazmacı seçer.
Sık kullanılan komutların daha kısa özel biçimleri vardır: inc ax = 40h (1 bayt), mov ax, imm16 = B8h + 2 bayt, add al, imm8 = 04h + 1 bayt.

Komut Kodlama

Kodlama Adım Adım: MOV CL, [BX+SI+12h]

Komut: bellekteki bir baytı CL'ye taşı. Biçim: MOV reg, r/m (opcode + ModR/M + yer değiştirme).

MOV r/m ↔ reg ailesinin opcode'u 100010.

D = 1: REG alanı hedeftir. W = 0: bayt işlem. 1. bayt = 1000 1010b = 8Ah.

MOD = 01: bellek + 8 bit yer değiştirme. REG = 001 (CL). R/M = 000 ([BX+SI]). 2. bayt = 01 001 000b = 48h.

12h, 8 bitlik yer değiştirme olarak eklenir. Sonuç: 8A 48 12. Yer değiştirme 16 bit olsaydı MOD = 10 ve 4 bayt olurdu.

Ayrıntılar Bölüm 4: Bellek Erişimi'nde. Fiziksel adres = segment × 16 + EA (20 bit).

Adresleme Modları

Fiziksel Adres Hesabı Adım Adım

DS = 2000h, BX = 0100h, SI = 0020h, SS = 3000h, BP = FFF0h

mov al, [bx+si+4]: tabanlı-indisli + d8 → BP yok, varsayılan segment DS.
EA = BX + SI + 4 = 0100h + 0020h + 0004h = 0124h (16 bit).
Fiziksel adres = DS × 10h + EA = 20000h + 0124h = 20124h.
mov ax, [bp+2]: BP kullanıldığı için segment SS. EA = FFF0h + 2 = FFF2h.
Fiziksel adres = 30000h + FFF2h = 3FFF2h; AL ← [3FFF2h], AH ← [3FFF3h] (little-endian).
Dikkat: EA 16 bitte sarar. BX = FFFFh, SI = 0002h ise EA = 1 0001h değil 0001h olur.

Veri Taşıma · Kodu adım adım çalıştır

Kod İzleme: PUSH / POP ile Takas ve XCHG

AX'e anlık değer yüklenir: AX = 1234h. MOV hiçbir bayrağı etkilemez.

BX = 5678h. Yığın henüz boş: COM programında SP = FFFEh.

push ax: önce SP ← SP − 2 = FFFCh, sonra [SS:FFFCh] ← 1234h (düşük bayt 34h küçük adreste).

push bx: SP = FFFAh, yığının üstünde artık 5678h var.

pop ax: üstteki sözcük okunur → AX = 5678h, sonra SP ← SP + 2 = FFFCh. Son giren ilk çıkar (LIFO).

pop bx: BX = 1234h, SP = FFFEh. İki PUSH + ters sırada iki POP = takas.

xchg ah, al: AX'in iki baytı yer değiştirir: 5678h → 7856h. Ek yazmaç gerekmez.

xchg ax, bx: AX ↔ BX. AX = 1234h, BX = 7856h. XCHG AX, r16 tek baytlık bir komuttur (90h+r).

Yığın dengeli (SP = FFFEh) olduğu için ret programı sonlandırır.

org 100h
mov ax, 1234h
mov bx, 5678h
push ax          ; SP -= 2, [SP] = AX
push bx
pop ax           ; AX = son giren
pop bx           ; BX = 1234h
xchg ah, al      ; baytları takas et
xchg ax, bx
ret

Veri Taşıma

G/Ç Komutları: IN ve OUT

  • 8086'nın bellekten ayrı 64 K'lık G/Ç adres alanı vardır (M/IO̅ ucu).
  • Veri yalnızca AL (8 bit) ya da AX (16 bit) üzerinden aktarılır.
  • Sabit port: 00h–FFh, komutun içinde.
  • Değişken port: 0000h–FFFFh, DX ile.
  • Bayrakları etkilemez.
in  al, 60h      ; port 60h'tan bayt oku
out 43h, al      ; port 43h'e yaz

mov dx, 3F8h     ; 255'ten büyük port
in  al, dx       ; DX ile adreslenir
out dx, ax       ; 16 bit yaz

in  bl, 60h      ; HATA: yalnız AL/AX
out 3F8h, al     ; HATA: DX gerekli
emu8086'daki sanal aygıtlar (trafik lambası, step motor, LED ekran) bu komutlarla sürülür; ayrıntılar Bölüm 9: Aygıt Kontrolü'nde.

Veri Taşıma · Kodu adım adım çalıştır

Kod İzleme: XLAT ile Baytı Onaltılı Yazdırma

BX, çeviri tablosunun başlangıç bağıl konumunu (offset) alır: BX = 011Dh.

Yazdırılacak bayt: AL = 3Ch (0011 1100b).

8086'da 1'den büyük kaydırma sayısı CL ile verilir.

shr al, cl: 0011 1100 → 0000 0011. AL = 03h (üst dörtlü).

xlat: AL ← [DS:BX + AL] = tablo[3] = '3' (33h).

Karakter DL'ye kopyalanır (INT 21h/02h parametresi).

AH = 02h: DOS karakter yaz servisi.

DOS ekrana '3' yazar (AL de DL'nin değerini alır).

Aynı bayt yeniden alınır: AL = 3Ch.

and al, 0Fh: üst dörtlü maskelenir → AL = 0Ch.

tablo[12] = 'C' (43h).

DL = 43h. AH hâlâ 02h olduğundan yeniden yüklemeye gerek yok.

Ekrana 'C' yazılır → çıktı 3C.

Program biter. XLAT, en fazla 256 baytlık tablolarla tek komutta çeviri yapar.

org 100h
mov bx, offset tablo
mov al, sayi       ; AL = 3Ch
mov cl, 4
shr al, cl         ; üst dörtlü
xlat               ; AL = [BX+AL]
mov dl, al
mov ah, 2
int 21h            ; DL'yi yaz
mov al, sayi
and al, 0Fh        ; alt dörtlü
xlat
mov dl, al
int 21h
ret
sayi  db 3Ch
tablo db '0123456789ABCDEF'

Veri Taşıma

Adres Yükleme: LEA, LDS, LES

  • lea si, metin ≡ mov si, offset metin; fark: LEA çalışma anında hesaplanan adresleri de verir: lea si, [bx+di+4].
  • LEA belleğe erişmez ve bayrakları etkilemez; bu yüzden toplama için de kullanılabilir: lea ax, [bx+si] → AX = BX + SI.
  • lds si, ptr: SI ← [ptr], DS ← [ptr+2]. les di, ptr aynı işi ES ile yapar.
  • Uzak işaretçi (far pointer) bellekte bağıl konum önce, segment sonra saklanır.
mov bx, 0010h
mov di, 0004h
lea ax, [bx+di+2]  ; AX = 0016h
mov ax, [bx+di+2]  ; AX = [0016h]

; ekran belleği: B800:0000
ekran dw 0000h, 0B800h
les di, ekran      ; DI=0000h ES=B800h
mov al, 'A'
stosb             ; köşeye 'A'
LEA adresi, MOV içeriği verir: lea ax, [bx+di+2] ile mov ax, [bx+di+2] arasındaki fark sınavlarda sık sorulur.

Veri Taşıma

Bayrak Yazmacına Erişim

LAHF / SAHFAH ↔ FLAGS'ın düşük baytı: SF ZF – AF – PF – CF. 8080 uyumluluğu için vardır; OF, DF, IF, TF'ye dokunmaz.
PUSHF / POPF16 bitlik FLAGS'ın tamamı yığına atılır / geri alınır. Bir alt programın bayrakları bozmaması ya da TF'yi değiştirmek için kullanılır.
pushf              ; bayrakları sakla
pop ax             ; AX = FLAGS
or  ax, 0100h       ; TF (bit 8) = 1 → tek adım kipi
push ax
popf               ; TF'yi doğrudan kuran bir komut yoktur

Bayrak Hesaplayıcı (8 bit)

İki onaltılı bayt girin. Deneyin: 7F+01, FF+01, 80+80, 05−07, 38+45 (AF), 0F AND F0.

Aritmetik · Kodu adım adım çalıştır

Kod İzleme: ADD, SUB, NEG, CMP ve Bayraklar

AL = 7Fh = 0111 1111b: işaretli olarak en büyük pozitif bayt (+127).

7Fh + 1 = 80h. İşaretsiz: 128 (doğru, CF = 0). İşaretli: +127 + 1 = −128 → OF = 1 (taşma). SF = 1, bit 3'ten elde → AF = 1.

BL = FFh (işaretsiz 255, işaretli −1).

FFh + 1 = 1 00h → BL = 00h, CF = 1, ZF = 1. İşaretli: −1 + 1 = 0, doğru → OF = 0.

CL = 05h.

5 − 7 = −2 = FEh. Ödünç alındı → CF = 1; SF = 1. İşaretli sonuç doğru → OF = 0.

neg cl: 0 − FEh = 02h. İşlenen sıfır olmadığından CF = 1.

cmp cl, 2: 2 − 2 hesaplanır ama sonuç yazılmaz. ZF = 1 → je dallanır.

CMP yalnızca bayrakları değiştirir; CL hâlâ 02h.

org 100h
mov al, 7Fh
add al, 1        ; +127 + 1
mov bl, 0FFh
add bl, 1        ; 255 + 1
mov cl, 5
sub cl, 7        ; 5 - 7
neg cl
cmp cl, 2
ret

Aritmetik · Kodu adım adım çalıştır

Kod İzleme: ADC ile 32 Bitlik Toplama

Birinci 32 bitlik sayının düşük sözcüğü: AX = F00Fh.

Yüksek sözcük: DX = 1234h. Birlikte DX:AX = 1234F00Fh.

İkinci sayının düşük sözcüğü BX = 2001h.

Yüksek sözcük CX = 0001h → CX:BX = 00012001h.

add ax, bx: F00Fh + 2001h = 1 1010h. 16 bite sığmaz → AX = 1010h, CF = 1 (elde).

adc dx, cx: 1234h + 0001h + CF = 1236h. Sonuç DX:AX = 12361010h.

inc ax: AX = 1011h. INC/DEC CF'yi değiştirmez; döngü sayaçlarında elde bilgisini korur.

Bitti: 1234F00Fh + 00012001h = 12361010h, sonra +1.

org 100h
mov ax, 0F00Fh     ; DX:AX = 1234F00Fh
mov dx, 1234h
mov bx, 2001h      ; CX:BX = 00012001h
mov cx, 0001h
add ax, bx         ; düşük sözcükler
adc dx, cx         ; yüksek + CF
inc ax             ; CF etkilenmez
ret

Aritmetik

Çarpma ve Bölme: Örtük Yazmaçlar

MUL / IMUL kaynakTek işlenen alır (yazmaç ya da bellek, anlık olamaz). Sonuç her zaman çift genişlikte. Üst yarı sıfır değilse (IMUL'da işaret uzantısı değilse) CF = OF = 1.
DIV / IDIV kaynakBölüm hedefe sığmazsa ya da bölen 0 ise işlemci INT 0 (bölme hatası) üretir. IDIV'de kalanın işareti bölünenin işaretidir.
mov al, 80h  mov bl, 4  mul bl    ; AX = 0200h, CF = OF = 1 (AH ≠ 0)
mov al, -2   mov bl, 3  imul bl   ; AX = FFFAh (−6), CF = OF = 0
mov ax, 1000h mov bl, 2 div bl    ; bölüm 800h > FFh → bölme hatası!

Aritmetik · Kodu adım adım çalıştır

Kod İzleme: DIV ile Sayıyı Ondalık Yazdırma

Yazdırılacak sayı: 305 = 0131h.

Bölen BX = 10 (000Ah).

xor cx, cx: CX = 0. Kendisiyle XOR en kısa sıfırlama yoludur.

16 bitlik DIV, bölünen olarak DX:AX'i kullanır; DX mutlaka sıfırlanmalı.

305 ÷ 10 → AX = 30 (001Eh), kalan DX = 5 (birler basamağı).

Kalan yığına atılır: basamaklar ters sırada üretilir, yığın sırayı düzeltir.

Basamak sayacı CX = 0001h.

test ax, ax: AX = 001Eh → ZF = 0.

AX ≠ 0 → bol'e dön.

16 bitlik DIV, bölünen olarak DX:AX'i kullanır; DX mutlaka sıfırlanmalı.

30 ÷ 10 → AX = 3, kalan DX = 0 (onlar basamağı).

  • cwd: AX'in işaret bitini DX'e kopyalar (AX → DX:AX).
  • İşaretli bölmeden (IDIV) önce bölünen bu komutlarla genişletilir; işaretsiz bölmede ise üst yarı sıfırlanır (xor dx, dx / mov ah, 0).

Kod İzleme: DAA ve AAM ile Ondalık Sonuç

Paketli BCD: 38h, ondalık 38 anlamına gelir.

İkili toplama: 38h + 45h = 7Dh. Alt dörtlü Dh > 9 → geçerli BCD değil.

daa: alt dörtlü > 9 → +06h: 7Dh + 6 = 83h. 38 + 45 = 83 ✓.

Yeni örnek: BCD 79.

Kaydırma: SHL/SAL, SHR, SAR

Döndürmede bit kaybolmaz. Yalnızca CF ve (sayı 1 iken) OF değişir; SF, ZF, PF etkilenmez. RCL/RCR çok sözcüklü kaydırmalarda kullanılır: shl ax, 1 + rcl dx, 1 → DX:AX × 2.

Kaydırma ve Döndürme · Kodu adım adım çalıştır

Kod İzleme: Kaydırarak Çarpma (13 × 5)

Çarpılan BL = 13 = 0Dh (0000 1101b).

Çarpan DL = 5 = 0101b: kağıt üzerindeki çarpmada olduğu gibi bitleri tek tek inceleriz.

4 bitlik çarpan için 4 tur.

shr dl, 1: çıkan bit 1 → CF = 1.

CF = 1 → dallanma yok, toplama yapılacak.

sonuc = 0 + 0Dh = 0Dh (13 × 1).

Çarpılan bir sola: BL = 1Ah (26).

loop: CX = 0003h.

Çıkan bit 0 → CF = 0.

CF = 0 → atla'ya dallanır.

BL = 34h (52).

loop: CX = 0002h.

Çıkan bit 1 → CF = 1.

CF = 1 → toplama yapılacak.

sonuc = 0Dh + 34h = 41h = 65 (13 × 4 eklendi).

BL = 68h (104).

loop: CX = 0001h.

Çıkan bit 0 → CF = 0.

CF = 0 → atla.

BL = D0h.

loop: CX = 0000h.

Sonuç: 13 × 5 = 65 = 41h. MUL olmayan işlemcilerde çarpma böyle yapılır.

org 100h
mov bl, carpilan  ; 13
mov dl, carpan    ; 5 = 0101b
mov cx, 4         ; 4 bit
kontrol:
shr dl, 1         ; en sağ bit → CF
jnc atla
add sonuc, bl     ; bit 1 ise ekle
atla:
shl bl, 1         ; çarpılan × 2
loop kontrol
ret
carpilan db 13
carpan   db 5
sonuc    db 0

mov ax, 0         ; toplam
l1:
add ax, [bx]      ; elemanı ekle
add bx, 2         ; sonraki sözcük
loop l1           ; CX--, ≠0 ise dön
mov toplam, ax
ret
dizi   dw 10, 20, 30, 40, 50
toplam dw 0

Kod İzleme: CALL / RET ve Dönüş Adresi

AL = 5.

call kare: sonraki komutun adresi (0105h) yığına atılır, SP = FFFCh, IP = kare (010Fh).

mul al: AX = 5 × 5 = 0019h (25).

ret: yığından 0105h çekilir → IP = 0105h, SP = FFFEh.

BL = 19h (25) saklanır.

AL = 7.

İkinci çağrı: dönüş adresi bu kez 010Ch.

AX = 7 × 7 = 0031h (49).

ret: IP = 010Ch, SP = FFFEh.

BL = 19h + 31h = 4Ah = 74.

Ana program biter.

org 100h
mov al, 5
call kare        ; yığına dönüş adresi
mov bl, al
mov al, 7
call kare
add bl, al       ; 25 + 49
ret
kare:
mul al           ; AX = AL × AL
ret              ; dönüş adresini çek

Denetim Aktarma

Yazılım Kesmesi: INT n

Başlangıç: CS:IP = 0700:0110h → int 21h (CD 21) yürütülmek üzere. SP = FFFEh.

Vektör adresi = 21h × 4 = 0084h. Kesme vektör tablosu 0000:0000–0000:03FFh arasındadır (256 × 4 bayt).

FLAGS yığına atılır; ardından IF = 0, TF = 0 yapılır (kesme sırasında yeni maskelenebilir kesme ve tek adım kapalı).

CS ve dönüş IP'si (0112h, INT'ten sonraki komut) yığına atılır. SP = FFF8h.

IP ← [0000:0084h], CS ← [0000:0086h]. Yürütme kesme hizmet yordamında (ISR) devam eder.

ISR iret ile biter: IP, CS ve FLAGS ters sırada geri alınır; program 0700:0112h'den sürer.

INT 3 tek baytlık (CCh) kesme noktası komutudur; INTO, OF = 1 ise INT 4 üretir. Tablodaki ISR adresi örnektir.

KodlamaKomut 1–6 bayt: opcode (D, W) + ModR/M + yer değiştirme + anlık veri; önekler başa eklenir.

AritmetikCF işaretsiz, OF işaretli taşma. MUL/DIV örtük AL/AX/DX kullanır; BCD için DAA…AAD.

DizgiDS:SI → ES:DI, DF yönü, REP/REPE/REPNE ile CX kadar yineleme.

Alıştırmalar

  1. mov dx, [bp+di+8] komutunu kodlayın (opcode 100010, d = 1, w = 1).
  2. AL = 96h, BL = 70h iken add al, bl sonrası AL, CF, OF, SF, ZF ne olur?
  3. AX = 0FFFh iken shl ax, 1, rcl dx, 1 (DX = 0, CF = 0) sonrası DX:AX?
  4. AL = 'z' iken xor al, 20h ve ardından and al, 0DFh sonrası AL?
  5. CX = 0 iken loop içeren bir döngü kaç kez döner? Nasıl önlenir?
  6. AX = 0007h, BL = 02h için div bl ve AX = FFF9h için idiv bl sonuçları?
  7. Bir dizgideki boşlukları sayan kodu repne scasb ile yazın.
İpuçları / cevaplar
  1. MOD = 01, REG = 010 (DX), R/M = 011 ([BP+DI]) → 8B 53 08; segment SS.
  2. 96h + 70h = 106h → AL = 06h, CF = 1, OF = 0 (negatif + pozitif), SF = 0, ZF = 0.
  3. AX = 1FFEh, CF = 0 → DX = 0000h; DX:AX = 00001FFEh.
  4. 'z' (7Ah) → 5Ah ('Z') → 5Ah ('Z').
  5. 65 536 kez; döngüden önce jcxz.
  6. AL = 03h, AH = 01h; IDIV: −7 ÷ 2 → AL = FDh (−3), AH = FFh (−1).
  7. Her bulunuşta sayacı artırıp CX ≠ 0 ise repne scasb'ı yineleyin (DI kaldığı yerden devam eder).
