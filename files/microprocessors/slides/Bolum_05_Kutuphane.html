Giriş

Öğrenme Çıktıları

INCLUDE

Bir kütüphane dosyasını kaynağa eklemeyi ve derleyicinin dosyayı nerede aradığını açıklamak.

Makrolar

PUTC, GOTOXY, PRINT, PRINTN gibi makroların neye genişlediğini göstermek.

Prosedürler

DEFINE_… ve CALL ile hazır prosedürleri (sayı okuma/yazma, dizgi yazdırma) kullanmak.

CALL / RET

Yığın üzerinden dönüş adresinin nasıl saklandığını izlemek; makro ile prosedürü boyut ve hız açısından karşılaştırmak.

Kütüphane ve INCLUDE

Ortak Fonksiyonlar Kütüphanesi

  • Programlamayı kolaylaştırmak için sık kullanılan bazı işlevler hazır olarak bulunur.
  • Başka dosyalarda tanımlanan işlevler INCLUDE direktifi ile kullanılır.
  • emu8086.inc içindeki herhangi bir işlevi kullanmak için kaynak dosyanın başına include 'emu8086.inc' yazılır.
  • Bu kütüphane, emu8086 platformunda sık kullanılan ekran, klavye ve sayı işlevlerini içerir.

INCLUDE bir direktiftir: işlemci komutu üretmez, derleme sırasında metin ekler.

PUTC ve GOTOXY Neye Genişler?

PUTC 'A'

PUSH AX        ; AX'i koru
MOV  AL, 'A'   ; parametre
MOV  AH, 0Eh   ; teletype
INT  10h
POP  AX        ; AX geri

5 komut, 8 bayt. Yazmaçlar korunur; çağıran kod etkilenmez.

GOTOXY 10, 5

PUSH AX
PUSH BX
PUSH DX
MOV  AH, 02h   ; imleç konumla
MOV  DH, 5     ; satır (row)
MOV  DL, 10    ; sütun (col)
MOV  BH, 0     ; sayfa 0
INT  10h
POP  DX
POP  BX
POP  AX
Parametre sırası sütun, satırdır (x, y); BIOS'ta sütun DL'ye, satır DH'ye gider. Sol üst köşe (0, 0), sağ alt köşe (79, 24).

  • Veri kod kesiminde olduğu için CS:[SI] kesim öneki kullanılır.
  • PRINTN'de dizgi DB sdat, 13, 10, 0 olarak tanımlanır.

Kod İzleme: PRINT 'Hi!' Açılımı

PRINT 'Hi!' derlemede bu koda açılır (emu8086.inc'teki makronun eşdeğeri). Önce AX ve SI yığına: SP = FFFAh.

JMP skip_dcl: kodun içine gömülü dizgi baytları (0104h–0107h) komut sanılmasın diye atlanır.

LEA SI, s_dcl: SI = 0104h, dizginin ilk baytı.

AL = CS:[SI] = 'H' (48h). 48h − 0 ≠ 0 → ZF = 0, JZ atlamaz.

SI = 0105h; AH = 0Eh ile INT 10h AL'deki 'H'yi yazar.

JMP next_char: aynı döngü 'i' (69h) için çalışır; SI = 0106h.

Üçüncü tur: '!' yazılır, SI = 0107h (0 baytı).

AL = 0 → ZF = 1: JZ printed atlar; döngü biter.

POP SI, POP AX ters sırayla: SI ve AX makrodan önceki değerlerine döner, SP = FFFEh.

PUSH AX
PUSH SI
JMP  skip_dcl    ; veriyi atla
s_dcl DB 'Hi!', 0
skip_dcl: LEA SI, s_dcl
next_char: MOV AL, CS:[SI]
CMP  AL, 0
JZ   printed     ; 0 → bitti
INC  SI
MOV  AH, 0Eh
INT  10h
JMP  next_char
printed: POP SI
POP  AX
RET

Kod İzleme: PRINT, GOTOXY, PUTC

include: makro tanımları derleme sırasında eklenir; kod üretilmez.

ORG 100h: COM programı 100h'den başlar.

PRINT: 12 karakter (0–11. sütun) yazılır; imleç 12. sütunda.

GOTOXY 10, 5: imleç 10. sütun, 5. satıra taşınır. Ekrana bir şey yazılmaz.

PUTC 65: 65 = 41h = 'A' yazılır, imleç 11. sütuna geçer.

PUTC 'B': karakter sabiti doğrudan verilebilir.

RET: DOS'a dönüş. END yalnızca derleyiciye “kaynak bitti” der.

include emu8086.inc
ORG    100h
PRINT 'Hello World!'
GOTOXY 10, 5
PUTC 65           ; 65 - is an ASCII code for 'A'
PUTC 'B'
RET               ; return to operating system.
END               ; directive to stop the compiler.

Makrolar

PRINTN ve İmleç Makroları

PRINT ile PRINTN

PRINT 'a' ardından PRINT 'b' → ab aynı satırda.

PRINTN 'a' ardından PRINT 'b' → a ve alt satırda b.

CR (13) imleci satır başına, LF (10) bir alt satıra götürür; yeni satır için ikisi birden gerekir.

CURSOROFF / CURSORON

İmleç şeklini ayarlayan INT 10h, AH = 01h kullanılır: CH = başlangıç, CL = bitiş tarama satırı.

CH'nin 5. biti 1 yapılınca imleç gizlenir; CURSORON normal şekli geri yükler.

Oyun veya menü ekranlarında yanıp sönen imleci saklamak için kullanılır.

PRINTN 'Ad Soyad:'   ; yazıp alt satıra geç
CURSOROFF
GOTOXY 30, 12
PRINT 'Merhaba'
CURSORON

Prosedürler

Prosedür Kullanımı: DEFINE_ ve CALL

include 'emu8086.inc'
ORG 100h
    ...
    CALL print_num   ; kullan
    ...
RET

DEFINE_PRINT_NUM    ; tanımla
DEFINE_PRINT_NUM_UNS
END
  • Her prosedür, END direktifinden önce kendi DEFINE_… makrosuyla bir kez tanımlanmalıdır.
  • DEFINE_… makrosu, prosedürün kodunu bulunduğu yere açar.
  • Tanımlar genellikle RET'ten sonra konur: aksi hâlde işlemci akış içinde prosedür koduna girer.
  • Kodda prosedür adıyla CALL yapılır; adlar küçük harfle yazılır (print_num).
  • PRINT_NUM, işini yaparken PRINT_NUM_UNS'yi çağırır; ikisi birlikte tanımlanmalıdır.

Prosedürler

Dizgi Prosedürleri

PRINT_STRING
  • Null (0) ile sonlanan dizgiyi geçerli imleç konumuna yazar.
  • Dizginin adresi DS:SI'den alınır.
  • Tanım: DEFINE_PRINT_STRING.
LEA  SI, msg
CALL print_string
msg DB 'Merhaba', 0
PTHIS
  • Null ile sonlanan dizgiyi yazar.
  • Dizginin adresini yığından alır: dizgi, CALL'dan hemen sonra tanımlanır.
  • Tanım: DEFINE_PTHIS.
CALL pthis
DB 'Merhaba', 0
; buradan devam eder
PRINT makrosu her kullanımda kodu kopyalar; PRINT_STRING ve PTHIS ise tek kopya kodla istenen sayıda dizgi yazar.

Prosedürler

GET_STRING ve CLEAR_SCREEN

GET_STRING
  • Kullanıcıdan null ile sonlanan bir dizgi alır.
  • Dizgi DS:DI'deki tampona (buffer) yazılır.
  • DX = tampon boyutu; sona 0 eklendiği için en fazla DX − 1 karakter alınır.
  • Enter tuşuna basılınca giriş durur.
  • Tanım: DEFINE_GET_STRING.
CLEAR_SCREEN
  • Ekranı temizler ve imleci en üste (0, 0) taşır.
  • Tanım: DEFINE_CLEAR_SCREEN.
LEA  DI, ad          ; tampon
MOV  DX, 20          ; boyut
CALL get_string
CALL clear_screen
LEA  SI, ad
CALL print_string
RET
ad DB 20 DUP(0)

Kod İzleme: GET_STRING Mantığı (DX = 4)

GET_STRING okuma döngüsünün sadeleştirilmiş eşdeğeri (kütüphanedeki sürüm geri silmeyi de işler). DI = tampon, DX = 4 bayt; kullanıcı “Ece” yazacak.

4 > 1: tamponda karakter ve sondaki 0 için yer var → JBE atlamaz.

INT 21h, AH = 01h: 'E' okunup ekrana yankılanır. Enter (13) değil → JE atlamaz.

'E' tampona yazılır; DI bir ilerler, kalan yer DX = 3.

İkinci tur: 'c' okunur ve ad+1'e yazılır; DX = 2.

Üçüncü tur: 'e' ad+2'ye; DX = 1.

DX = 1: yalnızca sondaki 0 için yer kaldı → JBE bitti. Kullanıcı daha yazsa da okunmaz: en fazla DX − 1 = 3 karakter.

Dizgi 0 ile sonlandırılır: tampon 'E','c','e',0 → PRINT_STRING ile yazdırılabilir.

LEA  DI, ad      ; tampon adresi
MOV  DX, 4       ; tampon boyutu
oku: CMP DX, 1   ; 0 için 1 bayt kalsın
JBE  bitti
MOV  AH, 01h
INT  21h         ; AL = tuş (yankılı)
CMP  AL, 13      ; Enter mi?
JE   bitti
MOV  [DI], AL    ; tampona yaz
INC  DI
DEC  DX
JMP  oku
bitti: MOV BYTE PTR [DI], 0
RET
ad   DB 4 DUP(?)

Kod İzleme: SCAN_NUM Mantığı (girdi 307)

SCAN_NUM'un özü: rakamlar soldan sağa okunur, sonuç = sonuç × 10 + rakam (kütüphanedeki sürüm eksi işaretini ve taşmayı da denetler). CX = 0.

INT 21h, AH = 01h: '3' tuşu, AL = 33h; karakter ekrana yankılanır.

Enter değil. SUB AL, '0': 33h − 30h = 3.

CBW AX = 0003h yapar; XCHG ile AX = eski sonuç (0), CX = rakam (3).

MUL BX: 0 × 10 = 0; ADD CX, AX → CX = 3.

'0' okunur: rakam 0; XCHG sonrası AX = 3, CX = 0.

3 × 10 = 30 (1Eh) → CX = 30 + 0 = 30.

'7' okunur: rakam 7 AX'e (CBW), sonuç 30 hâlâ CX'te.

XCHG: AX = 30, CX = 7. 30 × 10 = 300 (012Ch) → CX = 300 + 7 = 307 = 0133h.

Enter: AL = 0Dh = 13 → ZF = 1, JE bitti atlar.

Sonuç SCAN_NUM'daki gibi CX'te: 0133h = 307.

ORG  100h
XOR  CX, CX      ; sonuç = 0
oku: MOV AH, 01h
INT  21h         ; AL = tuş (yankılı)
CMP  AL, 13      ; Enter mi?
JE   bitti
SUB  AL, '0'     ; ASCII → rakam
CBW              ; AX = rakam
XCHG AX, CX      ; AX=sonuç, CX=rakam
MOV  BX, 10
MUL  BX          ; AX = sonuç × 10
ADD  CX, AX      ; CX = sonuç×10 + rakam
JMP  oku
bitti: RET

Kod İzleme: PRINT_NUM_UNS Mantığı (AX = 1205)

Aynı çıktıyı veren eşdeğer kod (kütüphanedeki sürüm 10000, 1000, … ile böler). AX = 1205 = 04B5h, bölen BX = 10.

DIV BX: DX:AX / 10 → AX = 120, kalan DX = 5. Son basamak yığına, CX = 1.

AX ≠ 0 → döngü sürer: 120 / 10 = 12, kalan 0 yığına; CX = 2.

12 / 10 = 1, kalan 2 yığına; CX = 3.

1 / 10 = 0, kalan 1 yığına; CX = 4 basamak.

OR AX, AX: AX = 0 → ZF = 1, JNZ atlamaz. Yığının üstünde en anlamlı basamak (1) var.

POP AX = 1; + '0' = 31h; INT 10h '1' yazar. LOOP: CX = 3.

Sonraki basamak 2 → '2'. CX = 2.

0 → '0'. CX = 1.

5 → '5'. CX = 0, döngü biter; yığın FFFEh'ye döndü. Ekranda 1205.

ORG  100h
MOV  AX, 1205    ; yazdırılacak sayı
MOV  BX, 10
XOR  CX, CX      ; basamak sayacı
bol: XOR DX, DX
DIV  BX          ; AX=bölüm, DX=kalan
PUSH DX          ; basamak yığına
INC  CX
OR   AX, AX      ; bölüm 0 mı?
JNZ  bol
yaz: POP AX      ; önce en anlamlı
ADD  AL, '0'
MOV  AH, 0Eh
INT  10h
LOOP yaz
RET

Demo: PRINT_NUM ve PRINT_NUM_UNS

AX'e bir değer verin (onluk, negatif ya da h ekli onaltılık): iki prosedürün ekrana ne yazacağını görün.

Örnek Program · Kodu adım adım çalıştır

Kod İzleme: Sayı Oku ve Yazdır

LEA SI, msg1: SI ← msg1 dizgisinin bağıl konumu (offset).

CALL print_string: dönüş adresi yığına itilir (SP = FFFCh); prosedür DS:SI'deki dizgiyi 0'a kadar yazar.

CALL scan_num: kullanıcı -25 yazıp Enter'a basar; karakterler ekrana yankılanır.

Dönüş: CX = FFE7h = −25 (ikiye tümleyen). SP yeniden FFFEh.

MOV AX, CX: PRINT_NUM sayıyı AX'te bekler.

CALL pthis: yığına itilen “dönüş adresi” aslında bir sonraki satırdaki dizginin adresidir.

PTHIS dizgiyi yazar: 13, 10 (yeni satır) ve “You have entered: ”. Sonra dönüş adresini 0'ın ötesine taşır.

Dönüş, dizginin sonrasına yapılır. CALL print_num: AX = FFE7h işaretli yazılır.

RET: DOS'a dönüş. Satır 11–17 veri ve prosedür tanımlarıdır, akışta çalıştırılmaz.

include 'emu8086.inc'
ORG    100h
LEA    SI, msg1       ; ask for the number
CALL   print_string   ;
CALL   scan_num       ; get number in CX.
MOV    AX, CX         ; copy the number to AX.
CALL   pthis          ; print the following string:
DB  13, 10, 'You have entered: ', 0
CALL   print_num      ; print number in AX.
RET                   ; return to operating system.
msg1   DB  'Enter the number: ', 0
DEFINE_SCAN_NUM
DEFINE_PRINT_STRING
DEFINE_PRINT_NUM
DEFINE_PRINT_NUM_UNS  ; required for print_num.
DEFINE_PTHIS
END                   ; directive to stop the compiler.

Örnek Program

PTHIS Nasıl Çalışır?

Bellekte CALL pthis'in hemen ardından dizgi baytları gelir; dizgi 0 ile biter.

CALL, “sonraki komutun” adresini iter. Bu adres, dizginin ilk baytı olan 0Dh'nin adresidir.

PTHIS yığındaki adresi okur ve oradan itibaren baytları 0'a kadar ekrana yazar.

Yığındaki adres, 0 baytının bir ötesiyle değiştirilir: artık CALL print_num'u gösterir.

RET: işlemci dizgiyi atlayıp CALL print_num'dan devam eder. Veri komut sanılıp çalıştırılmaz.

Bu teknik, dönüş adresinin yığında saklandığı bilgisine dayanır. Benzer şekilde PRINT makrosu da veriyi kod içine gömer ama JMP ile atlar.

Sık Yapılan Hatalar

DEFINE_ unutmak

CALL scan_num var ama DEFINE_SCAN_NUM yoksa derleyici etiketi bulamaz: undefined hatası.

DEFINE_'yi akışa koymak

Tanımlar ORG 100h'nin hemen altına konursa işlemci prosedür kodunu ana program sanarak çalıştırır. Yeri: RET ile END arası.

Dizgiyi 0 ile bitirmemek

PRINT_STRING ve PTHIS 0 görene kadar yazar; 0 yoksa bellekteki rastgele baytlar ekrana dökülür.

Yazmaçları varsaymak

Prosedürler sonuçlarını belirli yazmaçlarda döndürür (SCAN_NUM → CX). Başka yazmaçtaki değerin korunduğu belgede yazmıyorsa varsayılmamalıdır.

CALL Komutu

CALL Komutu

  • Derleyici ilk aşamada DEFINE_… tanımlarını işler; bunlar prosedürlere genişleyen normal makrolardır.
  • CALL komutu prosedürleri çağırmak için kullanılır.
  • Derleyici CALL'daki prosedür adını, prosedürün bulunduğu adrese dönüştürür.
  • CALL yürütüldüğünde dönüş adresi yığına itilir ve kontrol prosedüre aktarılır; prosedür RET ile geri döner.
  • Prosedür kodu dosyada bir kez bulunur: aynı prosedür 100 kez çağrılsa da gövdesi çoğalmaz; her çağrı yalnızca 3 baytlık bir CALL ekler.
  • Bu yaklaşım çalıştırılabilir dosyanın boyutunu küçük tutar.

CALL Komutu

CALL ve RET Adım Adım

CALL print_num 0110h adresinde, 3 bayt (E8 + 16 bit bağıl uzaklık). Sonraki komut 0113h'de. (Örnek adresler.)

1) SP ← SP − 2, dönüş adresi 0113h yığına yazılır.

2) IP ← prosedürün adresi (ör. 0200h). Prosedür çalışır.

RET: IP ← [SP] = 0113h, SP ← SP + 2. Ana program kaldığı yerden sürer.

Prosedür içinde PUSH edilen her değer RET'ten önce POP edilmelidir; yoksa RET yanlış adrese döner.

Özet

Özet

INCLUDE

include 'emu8086.inc': önce kaynak klasörü, sonra Inc klasörü aranır.

Makrolar

PUTC, GOTOXY (col, row), PRINT, PRINTN, CURSOROFF, CURSORON: INT 10h üzerine kurulu, kullanıldıkları yere açılır.

Prosedürler

END'den önce DEFINE_…, kullanırken CALL. Girdi/çıktı yazmaçları: SI, DI, DX, CX, AX.

Sayılar

SCAN_NUM → CX (işaretli); PRINT_NUM AX'i işaretli, PRINT_NUM_UNS işaretsiz yazar.

PTHIS

Dizgi CALL'dan hemen sonra; prosedür dönüş adresini dizginin sonrasına taşır.

CALL / RET

CALL dönüş adresini iter ve atlar; RET adresi çekip döner. Prosedür kodu bir kez bulunur.
