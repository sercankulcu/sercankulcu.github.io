Öğrenme Çıktıları

Hizmet çağırma

BIOS ve DOS hizmetlerini AH'deki fonksiyon numarası ve yazmaç parametreleriyle çağırmak.

Ekran çıktısı

INT 10h ve INT 21h ile karakter, renkli karakter ve dizgi yazdırmak; imleci konumlamak.

Klavye girişi

INT 16h ve INT 21h ile tuş okumak, tuş beklemeden yoklamak, satır okumak.

Saat ve sonlandırma

Tarih/saat bilgisini okuyup yazdırmak; programı RET, INT 20h ya da INT 21h/4Ch ile doğru sonlandırmak.

Giriş

BIOS ve DOS Hizmetleri

  • BIOS (Basic Input/Output System): anakarttaki ROM'da bulunan, donanımı doğrudan süren yordamlar. İşletim sistemi olmadan da çalışır; açılışta kesme vektör tablosunu doldurur.
  • DOS: BIOS'un üstünde; dosya, dizgi, saat ve program yönetimi sunar. Kendi işi için çoğu zaman BIOS'u çağırır.
  • Her iki katmana da yazılım kesmesi (INT n) ile ulaşılır; çağıranın hizmet adresini bilmesi gerekmez.
Aynı iş farklı katmanlarda yapılabilir: ekrana karakter INT 21h/02h (DOS), INT 10h/0Eh (BIOS) ya da doğrudan B800h ekran belleğine yazarak. Üst katman daha taşınabilir, alt katman daha hızlı ve esnektir.

Hizmet Çağırma Kalıbı

  1. AH ← hizmet numarası (8 bit: en çok 256 hizmet)
  2. Diğer parametreler: AL, BX, CX, DX, DS:DX, ES:BP …
  3. INT n (10h, 16h, 21h …)
  4. Sonuç yazmaçlarda: AL, AX, CX, DX, ZF/CF …

INT 10h Video

İmleç Konumu: AH = 02h / 03h

  • Satır DH (0–24), sütun DL (0–79); sol üst köşe (0, 0).
  • BH = görüntü sayfası. 80×25 modda 8 sayfa (0–7) vardır; normalde 0 kullanılır.
  • İkisi tek komutla: mov dx, 0C28h → DH = 12, DL = 40 (ekranın ortası).
  • AH = 03h konumu okur: dönüşte DH, DL; ayrıca CH, CL imleç şekli.
  • INT 21h ile yazılan karakterler de bu imleç konumundan başlar.
; imleci ortaya al
mov ah, 02h
mov bh, 0
mov dx, 0C28h   ; 12. satır, 40. sütun
int 10h

; imleci bir sağa kaydır
mov ah, 03h
mov bh, 0
int 10h        ; DH, DL = konum
inc dl
mov ah, 02h
int 10h
Ekran belleği karşılığı: (satır, sütun) hücresinin bağıl konumu = (satır × 80 + sütun) × 2. Örneğin (1, 4) → 84 × 2 = 00A8h; çift adreste karakter, tek adreste öznitelik.

Kod İzleme: Mod, İmleç, 09h ve 0Eh

AH = 00h (mod seç), AL = 03h (80×25, 16 renk metin). İki yazmaç tek komutla yüklenir.

int 10h: mod ayarlanır, ekran temizlenir, imleç (0,0)'a gider.

AH = 02h: imleç konumunu ayarla.

BH = görüntü sayfası (metin modunda 0–7; normalde 0).

DX = 0104h → DH = 1 (satır), DL = 4 (sütun). Sol üst köşe (0,0).

İmleç satır 1, sütun 4'e taşınır. Ekranda henüz bir şey yok.

AH = 09h: imleç konumuna AL'yi BL özniteliğiyle CX kez yaz.

Yazılacak karakter AL = '*' (2Ah).

BL = 4Eh: arka plan 4 (kırmızı), ön plan E (sarı).

Tekrar sayısı CX = 3.

Ekrana *** yazılır, ama 09h imleci ilerletmez: imleç hâlâ (1,4).

AH = 0Eh: teletype (daktilo) çıkışı.

AL = 'A'.

'A', imlecin bulunduğu (1,4)'e yazılır ve ilk yıldızın üzerine gelir; imleç (1,5)'e ilerler.

AL = 'B'. AH hâlâ 0Eh.

'B' (1,5)'e yazılır: ekranda AB*. 0Eh metin modunda öznitelik almaz; hücrelerdeki 4Eh rengi korunur.

09h imleci ilerletmez; yazdıktan sonra imleç AH = 02h ile ayrıca ilerletilir.

org 100h
mov ax, 0003h    ; AH=00h, AL=03h
int 10h          ; ekran silinir
mov ah, 02h      ; imleç konumla
mov bh, 0        ; sayfa 0
mov dx, 0104h    ; DH=1, DL=4
int 10h
mov ah, 09h      ; karakter + öznitelik
mov al, '*'
mov bl, 4Eh      ; kırmızı üstüne sarı
mov cx, 3        ; 3 kez
int 10h          ; imleç ilerlemez!
mov ah, 0Eh      ; teletype
mov al, 'A'
int 10h          ; imleç ilerler
mov al, 'B'
int 10h
ret

BIOS'suz Çıktı: B800h Ekran Belleği

  

    

      
    
        
  • Mod 03h'te ekran, B800:0000h'dan başlayan 4000 baytlık bellekte tutulur (80 × 25 × 2).
    • 
        
  • Her hücre 2 bayt: karakter (çift adres) + öznitelik (tek adres).
    • 
        
  • Belleğe yazılan değer ekran kartı tarafından anında gösterilir: kesme çağrısından çok daha hızlı.
    • 
        
  • Sözcük olarak yazarken little-endian: 4E41h → 41h ('A') düşük adrese, 4Eh özniteliğe.
    • 
      

    

    
; (1,4) hücresine sarı/kırmızı 'A'
mov ax, 0B800h
mov es, ax
mov di, (1*80+4)*2  ; 00A8h
mov ax, 4E41h
mov es:[di], ax

; tüm ekranı '.' ile doldur
xor di, di
mov ax, 072Eh
mov cx, 2000
cld
rep stosw

  


  
Doğrudan yazma imleci hareket ettirmez ve BIOS'un tuttuğu imleç bilgisini güncellemez. emu8086 bu belleği de destekler.

ES = B800h: mod 03h metin ekranının kesimi. Kesim yazmacına sabit doğrudan yazılamadığı için AX üzerinden.


(1, 4) hücresi: (1 × 80 + 4) × 2 = 168 = 00A8h. Çarpım derleme zamanında hesaplanır.


AX = 4E41h: AL = 41h ('A', karakter), AH = 4Eh (öznitelik: kırmızı zemin, sarı yazı).


MOV ES:[DI], AX: little-endian → B80A8h ← 41h, B80A9h ← 4Eh. Karakter anında ekranda; imleç yerinde kalır.


DI = 0: sol üst köşe.


AX = 072Eh ('.' + 07h açık gri), CX = 3.


CLD: DF = 0, DI artarak ilerler.


REP STOSW: ES:[DI] ← AX, DI += 2, CX kez → ilk 3 hücre '.' oldu; DI = 0006h, CX = 0. (Tüm ekran için CX = 2000.)


RET: program biter.

AH = 02h: BIOS gerçek zaman saatini (RTC) oku.


Dönüş paketli BCD: CH = 14h (saat 14), CL = 35h (dakika 35), DH = 07h (saniye). DL = 00h (yaz saati yok).

Saat için prosedür çağrılır (ikinokta atlanır, doğrudan bcdyaz).


DL = BH = 14h = 0001 0100b.


shr dl, cl: 0001 0100b → 0000 0001b. DL = 01h, yani üst basamak.


+30h: DL = 31h = '1'.

Ekrana '1'. DOS, AL'ye DL'yi koyar (AL = 31h).

and dl, 0Fh: üst 4 bit silinir: 0000 0100b = 04h.

Prosedürden dönülür.

AH = 02h.

Dönülür.

Saniye için yine ikinokta.


DL = ':'.


Ekrana ':' → 14:35:.

Ekrana '0' (30h).

Ekrana '7' → 14:35:07.


Dönülür.

Başlangıçta DS = ES = 0700h: DOS onları PSP'ye ayarlar. CS = 0721h (kod), SS = 0710h (yığın). @data veri kesiminin değeridir → AX = 0720h.


MOV DS, AX: artık DS = 0720h, veri kesimini gösteriyor. Bu satır unutulsaydı DS:DX PSP'yi gösterir, ekrana çöp basılırdı.


DX = offset msg = 0000h: msg, veri kesiminin başında.


AH = 09h.


INT 21h: DS:DX = 0720h:0000h'den '$'a kadar → Merhaba.


AX = 4C00h, INT 21h: çıkış kodu 0 ile DOS'a dön. EXE'de RET kullanılamaz (yığının üstünde PSP adresi yok).

org 100h

  • Döngü 8 kez (CX = 8) çalışır: her turda BL'nin en anlamlı biti (MSB) test edilir, '0' ya da '1' yazılır, BL bir sola kaydırılır.
  • En sonda 'b' eki yazılır ve bir tuşa basılması beklenir. Beklenen çıktı: 00001110b.

TEST ve SHL ile Bit Okuma




TEST BL, 10000000b: BL ile maske VE'lenir ama BL değişmez. Sonuç 0 ise bit 7 = 0 → ZF = 1, JZ atlar.


SHL BL, 1: tüm bitler bir sola kayar; çıkan bit 7 CF'ye gider, bit 0'a 0 girer. Bir sonraki bit, test edilecek konuma (bit 7) gelir.


8 tur sonunda BL'nin bitleri MSB'den LSB'ye sırayla yazılmış olur: 00001110, ardından b.


Alternatif: SHL BL,1 ardından JC ile CF'ye bakmak. Ancak bu sıralamada kaydırma, yazdırmadan önce yapılmalıdır.

AL = 5 = 05h = 00000101b. MOV bayrakları etkilemez.

Tur 1: AH = 2 (DOS karakter yaz).
