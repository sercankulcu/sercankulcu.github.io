Port tabanlı G/Ç

IN ve OUT komutlarının biçimlerini ve sınırlarını bilmek.

Bit düzeyinde denetim

Bir porttaki her bitin bir lambaya, mıknatısa ya da duruma karşılık geldiğini çözümlemek.

Yoklama (polling)

Aygıtın hazır bitini bekleyen döngüler yazmak.

Zamanlama

INT 15h / AH = 86h ile mikrosaniye cinsinden bekleme süresi hesaplamak.

emu8086 aygıtları

G/Ç Temelleri

Aygıt Kontrolü

  • x86 ailesi CPU'lar geniş bir aygıt yelpazesini denetleyebilir. Temel G/Ç port numaraları sistemden sisteme farklılık gösterebilir ve uygun bir donanımla (adres çözücü, “tricky” elektronik devre) değiştirilebilir.
  • Gömülü bir sistemde derlenen .bin dosyası Salt Okunur Bellek (ROM) yongasına yazılır.
  • Sistem açılınca programı ROM'dan okur, RAM'e yükler ve yürütür. Bu ilke birçok modern cihazda (çamaşır makinesi, yazıcı, modem…) kullanılır.

G/Ç Temelleri

Port Eşlemeli ve Bellek Eşlemeli G/Ç

Port eşlemeli (isolated) G/Ç
  • 8086'nın ayrı bir 64 K'lık G/Ç adres uzayı vardır.
  • Erişim yalnızca IN/OUT ile; M/IO̅ pini G/Ç döngüsünü belirtir.
  • Bellek adreslerini tüketmez.
  • Bu bölümdeki tüm aygıtlar böyledir.
Bellek eşlemeli (memory-mapped) G/Ç
  • Aygıt yazmaçları bellek adreslerinde durur.
  • Her MOV/ADD/CMP komutu kullanılabilir.
  • Örnek: PC metin ekranı B800:0000'dan başlar; oraya yazılan bayt ekranda görünür.
Yoklama (polling): CPU aygıtın durum bitini döngü içinde okuyarak “hazır” olmasını bekler. Basittir ama beklerken CPU başka iş yapamaz. Alternatifi aygıtın CPU'ya kesme göndermesidir.

G/Ç Temelleri

8255 Programlanabilir Çevre Arayüzü (PPI)

  • Üç 8 bitlik port (A, B, iki 4 bitlik yarıya ayrılabilen C) ve bir kontrol yazmacı; yazmaç A1, A0 ile seçilir, C̅S̅ adres çözücüden gelir.
  • RESET sonrası tüm portlar giriştir; önce kontrol sözcüğü yazılır.
A1 A0YazmaçAdres (taban 310h)
0 0port A310h
0 1port B311h
1 0port C312h
1 1kontrol yazmacı313h
8086'da çift adresler D0–D7'den (alt bank) aktarılır; yazmaçlar çift adrese düşsün diye 8255.A0 ← A1, A1 ← A2 bağlanır (310h, 312h, 314h, 316h). 8088'de A0 ← A0, A1 ← A1 yeterlidir. Port > 255: erişim DX ile.

G/Ç Temelleri

8255 Kontrol Sözcüğü (Mod 0)

D7D6 D5D4D3D2D1D0
1 = mod seçimiA grubu modu
00 = mod 0		port APC7–PC4B grubu modu
0 = mod 0		port BPC3–PC0
yön bitleri:1 = giriş, 0 = çıkış (D4, D3, D1, D0)

1 00 0 0 0 1 0b = 82h

İstenen: A çıkış (LED/röle), B giriş (anahtar), C'nin iki yarısı çıkış, hepsi mod 0.

D7 = 1: mod seçimi · D6 D5 = 00 ve D2 = 0: mod 0

Mod 0 el sıkışmasız basit G/Ç'dir; mod 1 ve 2 el sıkışmalı (strobe) aktarım içindir.

D4 = 0 (A çıkış) · D3 = 0 (C üst çıkış)
D1 = 1 (B giriş) · D0 = 0 (C alt çıkış)

Sonuç 1000 0010b = 82h. Örneğin A giriş, B çıkış, C giriş için 1001 1001b = 99h olur.

D7 = 0 ise bit kur/sil (BSR):
D3–D1 = C'nin bit numarası, D0 = yeni değer

0Fh (0000 1111b) → PC7 = 1, 0Eh → PC7 = 0. Diğer C bitleri değişmez.

mov dx, 313h   ; kontrol yazmacı
mov al, 82h    ; A çık, B gir, C çık
out dx, al
mov dx, 311h   ; port B
in  al, dx     ; anahtarları oku
mov dx, 310h   ; port A
out dx, al     ; LED'lere yaz
mov dx, 313h
mov al, 0Fh    ; BSR: PC7 = 1
out dx, al

8255: Kontrol Sözcüğü, Okuma, Yazma, BSR

org 100h
mov dx, 313h   ; kontrol yazmacı
mov al, 82h    ; A,C çık; B gir
out dx, al
mov dx, 311h   ; port B
in  al, dx     ; anahtarları oku
mov dx, 310h   ; port A
out dx, al     ; LED'lere yaz
mov dx, 313h
mov al, 0Fh    ; BSR: PC7 = 1
out dx, al
ret

RESET sonrası üç port da giriş. Port B'ye bağlı anahtarlar 1001 0110b = 96h konumunda (port sözlüğünde 311h = 96h). DX = 313h, AL = 82h.

OUT 313h ← 82h = 1 00 0 0 0 1 0b: mod 0; A çıkış, C üst çıkış, B giriş, C alt çıkış.

DX = 311h: port B. 311h > 255 olduğundan port numarası DX'te verilir.

IN AL, DX: anahtarlar okunur → AL = 96h.

DX = 310h: port A.

OUT 310h ← 96h: port A çıkış olduğundan LED'ler anahtarları kopyalar (yanan: bit 7, 4, 2, 1).

DX = 313h, AL = 0Fh = 0000 111 1b: D7 = 0 → mod sözcüğü değil, bit kur/sil (BSR).

OUT 313h ← 0Fh: D3–D1 = 111 → PC7, D0 = 1 → PC7 = 1. Port yönleri (82h) değişmez, diğer C bitleri korunur.

Port değerleri yorumlayıcının G/Ç kaydından (anahtar girişi 96h örnek). BSR sözcüğü yalnız seçilen C bitini değiştirir.

  • Kavşakta 4 direk, her direkte 3 lamba: toplam 12 lamba = port 4'e yazılan sözcüğün bit 0–11'i.

    • 

  • Örnek: 0000_0011_0000_1100b → bit 2 ve 8 (yeşil), bit 3 ve 9 (kırmızı).

Trafik Işıkları


INT 15h / AH = 86h ile Bekleme




; 5 saniye bekle (5 milyon µs)
mov cx, 4Ch    ; 004C4B40h = 5 000 000
mov dx, 4B40h
mov ah, 86h
int 15h


    

  • BIOS işlevi INT 15h, AH = 86h: CX:DX mikrosaniye bekler.
    • 

  • CX yüksek sözcük, DX düşük sözcük: 32 bitlik bekleme süresi.
    • 





5 s = 5 × 1 000 000 = 5 000 000 µs
Süre mikrosaniyeye çevrilir.


5 000 000 ÷ 16 = 312 500 kalan 0
312 500 ÷ 16 = 19 531 kalan 4
19 531 ÷ 16 = 1 220 kalan 11 (B)
1 220 ÷ 16 = 76 kalan 4
76 ÷ 16 = 4 kalan 12 (C)
4 ÷ 16 = 0 kalan 4
Ardışık 16'ya bölme: kalanlar sondan başa okunur → 4C4B40h.


0 0 4 C | 4 B 4 0
CX = 004Ch · DX = 4B40h
32 bitlik değer 0000 0000 0100 1100 0100 1011 0100 0000b ikiye bölünür.


1 s → 1 000 000 = 000F4240h → CX = 000Fh, DX = 4240h
Başka bir örnek: 1 saniyelik bekleme.

; ≈ 1 ms gecikme (4,77 MHz 8086)
mov cx, 281    ; 4 çevrim

KomutSaat turu


MOV CX, sabit4


LOOP (CX ≠ 0, atlar)17


LOOP (CX = 0, atlamaz)5




Toplam = 4 + 17(N − 1) + 5 = 17N − 8 saat turu.






4,77 MHz: 1 saat turu ≈ 0,2096 µs
1 ms = 4 770 saat turu
Süre, saat turu sayısının saat frekansına bölümüdür.


17N − 8 = 4 770 → N ≈ 281,06
N = 281 → 4 769 saat turu ≈ 0,9998 ms
CX'e tam sayı yazılabildiği için en yakın değer seçilir.


5 MHz: 1 ms = 5 000 saat turu → N ≈ 294,6
N = 295 → 5 007 saat turu ≈ 1,0014 ms
Aynı N = 281 5 MHz'de yalnızca 0,954 ms sürer: gecikme saat hızına bağlıdır.


En uzun: CX = 0 → 65 536 tur
17 · 65 536 − 8 = 1 114 104 saat turu ≈ 233,6 ms
Daha uzun bekleme için iç içe döngü gerekir. Prosedür olarak çağrılırsa CALL (19) ve RET (8) saat turu da eklenir.






Hesap yaklaşıktır: kesmeler, bellek bekleme durumları ve komut kuyruğu süreyi uzatabilir. emu8086 komut zamanlamasını modellemez; döngü bilgisayarın ve adım gecikmesi ayarının hızında koşar. emu8086'da süreli bekleme için INT 15h/86h kullanın.

1. LOOP: CX = 3 ≠ 0 → atlar (aynı komuta döner): 17 tur. Toplam 21.


2. LOOP: CX = 2, yine 17 tur. Toplam 38.


3. LOOP: CX = 1, 17 tur. Toplam 55.


4. LOOP: CX = 0 → atlamaz: yalnız 5 tur. Toplam 60 = 17 · 4 − 8 tur.


60 tur ÷ 4,77 MHz ≈ 12,6 µs. CX'i N yapınca süre 17N − 8 turdur; 1 ms için N = 281 bulunmuştu.

JB: CF = 1, next'e dön.


… bekleme ve SI artırma … OUT 4, AX: SI = 0126h → port 4 = 069Ah.


… bekleme ve SI artırma … OUT 4, AX: SI = 0128h → port 4 = 0861h.

Step Motor


Step Motor (Port 7)




    

  • Motor hem saat yönünde (CW) hem de tersine (CCW) döndürülebilir.
    • 

  • Port 7'ye yazılan baytın bit 0, 1, 2'si üç elektromıknatısı açar/kapatır.
    • 

  • Yarı adım 11,25°, tam adım 22,5°'dir.
    • 

  • Yarı adım: çift mıknatıs, ardından tek mıknatıs açılarak döndürülür.
    • 

  • Tam adım: çift mıknatıs, çift mıknatıs, tek mıknatıs şeklinde devam eder.
    • 

  • Motor yeni komut almaya hazır olduğunda porttan okunan baytın bit 7'sini 1 yapar.
    •

Step Motor Kontrol Programı




ORG 100h
steps_before_direction_change = 20h
jmp start
datcw     db 110b,100b,011b,010b
datccw    db 011b,001b,110b,010b
datcw_fs  db 001b,011b,110b,000b
datccw_fs db 100b,110b,011b,000b
start:
mov bx, offset datcw
mov si, 0
mov cx, 0   ; tur sayacı


    

  • Yoklama (wait): bit 7 = 0 ise motor meşgul, tekrar oku.
    • 

  • [bx][si] = [BX + SI]: BX tablonun başı, SI sıra (0–3).
    • 

  • 4 bayt gönderilince SI = 0, CX +1; CX = 20h olunca BX 4 artar, son tablodan sonra başa döner.
    • 

  • steps_before_direction_change = 20h bir sabittir (EQU gibi), bellekte yer kaplamaz.
    • 



next_step:
wait: in al, 7
test al, 10000000b
jz wait
mov al, [bx][si]
out 7, al
inc si
cmp si, 4
jb next_step
mov si, 0
inc cx
cmp cx, steps_before_direction_change
jb  next_step
mov cx, 0
add bx, 4   ; sonraki tablo
cmp bx, offset datccw_fs
jbe next_step
mov bx, offset datcw
jmp next_step

TEST AL, 80h → ZF = 1.


JZ: ZF = 1 → tekrar bekle.

TEST AL, 80h → ZF = 0.


JZ: ZF = 0 → devam.

SI = 1.


CMP SI, 4 → CF = 1.


JB: SI < 4 → next_step.

TEST AL, 80h → ZF = 0.


JZ: ZF = 0 → devam.

OUT 7, AL: mıknatıslar 100b → motor yarım adım (11,25°) döner.


SI = 2.


CMP SI, 4 → CF = 1.


JB: SI < 4 → next_step.


IN AL, 7 → AL = 80h (bit 7 = 1, hazır).


TEST AL, 80h → ZF = 0.


JZ: ZF = 0 → devam.

OUT 7, AL: mıknatıslar 011b → motor yarım adım (11,25°) döner.

Ortak desen: durum oku → bit test et → hazırsa veri yaz/oku → döngü. IN/OUT yalnızca AL/AX ile, port > 255 ise DX ile.






Özet


Alıştırmalar


    

  1. Tüm yönlerde yalnızca sarı lambaları yakan port 4 değeri nedir?
    2. 

  2. 2,5 saniyelik bekleme için CX ve DX ne olmalıdır?
    3. 

  3. LED ekranda −1 göstermek için AX'e hangi onaltılık değer yazılır?
    4. 

  4. Termostatı 20–25 °C aralığına göre değiştirin; sıcaklık −10 °C iken JB kullanılsaydı ne olurdu?
    5. 

  5. Step motor programında motoru yalnızca saat yönünde, tam adımla döndürmek için hangi satırlar değişmeli?
    6. 



Cevaplar

    

  1. Bit 1, 4, 7, 10 → 0000_0100_1001_0010b = 0492h.
    2. 

  2. 2 500 000 = 002625A0h → CX = 0026h, DX = 25A0h.
    3. 

  3. FFFFh.
    4. 

  4. cmp al, 20 / jl low / cmp al, 25 / jle ok / .... −10 = F6h; işaretsiz JB için 246 > 20 olur ve ısıtıcı açılmazdı.
    5. 

  5. mov bx, offset datcw_fs ve tablo değiştiren kısım (inc cx … jmp next_step) kaldırılıp jmp next_step yazılır.
    6.

Alıştırmalar (devam)


    

  1. Yazıcıya “Merhaba” yazıp sayfayı çıkaran en kısa programı yazın.
    2. 

  2. 8 MHz'lik bir 8086'da mov cx, N / loop ile yaklaşık 1 ms gecikme için N kaçtır?
    3. 

  3. 8255'te A giriş, B çıkış, C'nin tamamı giriş (mod 0) için kontrol sözcüğü nedir?
    4. 

  4. Ortak anotlu göstergede '5' ve 'H' harfinin kodları nedir (dp g f e d c b a sırası)?
    5. 



Cevaplar

    

  1. Her karakter için MOV DL, 'M' / MOV AH, 5 / INT 21h (veya döngü), sonunda DL = 12 ile form feed.
    2. 

  2. 17N − 8 = 8 000 → N ≈ 471 (7 999 saat turu).
    3. 

  3. 1 00 1 1 0 0 1b = 99h.
    4. 

  4. '5': CC 6Dh → CA 92h; 'H' (b c e f g): CC 76h → CA 89h.
    5.
