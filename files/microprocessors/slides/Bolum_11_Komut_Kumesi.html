Giriş

Öğrenme Çıktıları

Komut sınıfları

8086'nın yaklaşık 100 komutunu altı işlevsel sınıfa ayırmak ve her sınıfın tipik kullanımını açıklamak.

Makine kodu

İşlem kodu, D/W bitleri ve ModR/M baytından bir komutun makine kodunu çıkarmak.

Dizgi komutları

MOVS, CMPS, SCAS, LODS ve STOS komutlarını REP önekleriyle kullanmak; DF, SI, DI ve CX değişimini izlemek.

Başvuru

XLAT, LEA, LDS, LES ve işlemci kontrolü komutlarını tanımak; bayrak etkileri tablosundan bir komutun hangi bayrağı değiştirdiğini okumak.

Komut Kodlama

Makine Kodu Biçimi

D (direction)1: REG alanı hedef; 0: REG alanı kaynak.
W (word)0: bayt (8 bit) işlem; 1: sözcük (16 bit) işlem.
ModR/MMOD işlenenin yazmaç mı bellek mi olduğunu, R/M adres biçimini, REG diğer yazmacı seçer.
Sık kullanılan komutların daha kısa özel biçimleri vardır: inc ax = 40h (1 bayt), mov ax, imm16 = B8h + 2 bayt, add al, imm8 = 04h + 1 bayt.

  • Kesim öneki varsayılanı değiştirir: mov al, es:[bx] → önek 26h.

Komut Kodlama

Kodlama Adım Adım: MOV CL, [BX+SI+12h]

Komut: bellekteki bir baytı CL'ye taşı. Biçim: MOV reg, r/m (işlem kodu + ModR/M + yer değiştirme).

MOV r/m ↔ reg ailesinin işlem kodu 100010.

D = 1: REG alanı hedeftir. W = 0: bayt işlem. 1. bayt = 1000 1010b = 8Ah.

MOD = 01: bellek + 8 bit yer değiştirme. REG = 001 (CL). R/M = 000 ([BX+SI]). 2. bayt = 01 001 000b = 48h.

12h, 8 bitlik yer değiştirme olarak eklenir. Sonuç: 8A 48 12. Yer değiştirme 16 bit olsaydı MOD = 10 ve 4 bayt olurdu.

Komut Kodlama

Aynı Baytlar, Farklı Komutlar: Yanlış Bağıl Konumdan Çözme

Bellekte 11 bayt. Bunlar kod mu, veri mi? İşlemci bunu bilmez: CS:IP nereyi gösteriyorsa oradaki baytı işlem kodu sayar.

Bağıl konum 0: B4h = MOV AH, imm8 (B0h + 4) → 1 anlık bayt alır: mov ah, 02h.

B2h = MOV DL, imm8 → mov dl, 41h (41h = 'A').

CDh = INT imm8 → int 21h: AH = 02h, DOS DL'deki 'A'yı ekrana yazar.

B8h = MOV AX, imm16 → 2 bayt, little-endian: mov ax, 4C00h.

int 21h, AH = 4Ch: program sonlanır. Bağıl konum 0'dan çözüm, programcının yazdığı koddur.

IP bir bayt kaysın (bağıl konum 1). 02h = ADD r8, r/m8; ModR/M B2h = 10 110 010 → MOD = 10 (d16), REG = DH, R/M = [BP+SI]; d16 = CD41h → 4 bayt: 'A' ve INT'in işlem kodu yutuldu.

21h = AND r/m16, r16; ModR/M B8h = 10 111 000 → [BX+SI+d16], REG = DI; d16 = 4C00h. Bu komut belleğe yazar.

Son CD 21 iki çözümde de aynı yere düştü: çözme yeniden eşlendi. Ama AH = 02h hiç yüklenmedi, INT 21h, AH'de o an ne varsa onunla çağrılır. Anlamı baytlar değil, IP'nin başladığı yer belirler.

8086'da kod ile veri arasında donanım ayrımı yoktur: veriye atlayan bir JMP ya da yanlış hesaplanmış bir IP, baytları komut olarak yürütür. Disassembler da başlangıç noktasını bilmek zorundadır.

Veri Taşıma · Kodu adım adım çalıştır

Kod İzleme: XLAT ile Baytı Onaltılık Yazdırma

BX, çeviri tablosunun başlangıç bağıl konumunu (offset) alır: BX = 011Dh.

Yazdırılacak bayt: AL = 3Ch (0011 1100b).

8086'da 1'den büyük kaydırma sayısı CL ile verilir.

shr al, cl: 0011 1100 → 0000 0011. AL = 03h (yüksek nibble).

xlat: AL ← [DS:BX + AL] = tablo[3] = '3' (33h).

Karakter DL'ye kopyalanır (INT 21h/02h parametresi).

AH = 02h: DOS karakter yaz hizmeti.

DOS ekrana '3' yazar (AL de DL'nin değerini alır).

Aynı bayt yeniden alınır: AL = 3Ch.

and al, 0Fh: yüksek nibble maskelenir → AL = 0Ch.

tablo[12] = 'C' (43h).

DL = 43h. AH hâlâ 02h olduğundan yeniden yüklemeye gerek yok.

Ekrana 'C' yazılır → çıktı 3C.

Program biter. XLAT, en fazla 256 baytlık tablolarla tek komutta çeviri yapar.

org 100h
mov bx, offset tablo
mov al, sayi       ; AL = 3Ch
mov cl, 4
shr al, cl         ; üst dörtlü
xlat               ; AL = [BX+AL]
mov dl, al
mov ah, 2
int 21h            ; DL'yi yaz
mov al, sayi
and al, 0Fh        ; alt dörtlü
xlat
mov dl, al
int 21h
ret
sayi  db 3Ch
tablo db '0123456789ABCDEF'

Veri Taşıma

Adres Yükleme: LEA, LDS, LES

  • lea si, metin ≡ mov si, offset metin; fark: LEA çalışma anında hesaplanan adresleri de verir: lea si, [bx+di+4].
  • LEA belleğe erişmez ve bayrakları etkilemez; bu yüzden toplama için de kullanılabilir: lea ax, [bx+si] → AX = BX + SI.
  • lds si, ptr: SI ← [ptr], DS ← [ptr+2]. les di, ptr aynı işi ES ile yapar.
  • Uzak işaretçi (far pointer) bellekte bağıl konum önce, kesim sonra saklanır.
mov bx, 0010h
mov di, 0004h
lea ax, [bx+di+2]  ; AX = 0016h
mov ax, [bx+di+2]  ; AX = [0016h]

; ekran belleği: B800:0000
ekran dw 0000h, 0B800h
les di, ekran      ; DI=0000h ES=B800h
mov al, 'A'
stosb             ; köşeye 'A'
LEA adresi, MOV içeriği verir: lea ax, [bx+di+2] ile mov ax, [bx+di+2] arasındaki fark sınavlarda sık sorulur.

Veri Taşıma · Kodu adım adım çalıştır

Adres mi, İçerik mi? LEA, MOV ve LES

org 100h
lea bx, veri        ; BX ← adres
mov di, 2
lea ax, [bx+di+2]   ; AX ← EA
mov ax, [bx+di+2]   ; AX ← [EA]
les di, ekran       ; uzak işaretçi
mov al, 'A'
stosb               ; ES:[DI] ← AL
ret
veri  dw 1111h, 2222h, 3333h
ekran dw 0000h, 0B800h

LEA, veri değişkeninin adresini verir: BX = 0115h. Bellek okunmaz.

DI = 2.

LEA AX, [BX+DI+2]: yalnız etkin adres hesaplanır → AX = 0115h + 2 + 2 = 0119h. Belleğe dokunulmaz, bayrak değişmez.

MOV AX, [BX+DI+2]: aynı EA'daki içerik okunur → AX = 3333h (veri'nin 3. sözcüğü).

LES DI, ekran: bellekteki uzak işaretçi (bağıl konum önce, kesim sonra) → DI = 0000h, ES = B800h.

AL = 41h ('A').

STOSB: ES:[DI] = B800h × 10h + 0000h = B8000h ← 41h; DF = 0 olduğundan DI = 1. Ekranın sol üst köşesinde 'A'.

RET: program biter.

Kod İzleme: MOVSB ile Kopyalama

DF = 0: ileri yönde kopyalama.

SI = 0110h: kaynak dizgi.

DI = 0114h: hedef alan ('....').

Kopyalanacak bayt sayısı CX = 4.

movsb: bir bayt kopyalanır; SI = 0111h, DI = 0115h. Bayraklar değişmez.

CX = 0003h.

movsb: bir bayt kopyalanır; SI = 0112h, DI = 0116h. Bayraklar değişmez.

CX = 0002h.

movsb: bir bayt kopyalanır; SI = 0113h, DI = 0117h. Bayraklar değişmez.

CX = 0001h.

movsb: bir bayt kopyalanır; SI = 0114h, DI = 0118h. Bayraklar değişmez.

CX = 0000h.

hedef = 'ABCD'. mov cx, 4 + rep movsb aynı işi tek komutla yapar.

org 100h
cld
lea si, kaynak     ; DS:SI kaynak
lea di, hedef      ; ES:DI hedef
mov cx, 4
kopya:
movsb              ; [DI]←[SI], SI++, DI++
loop kopya         ; = rep movsb
ret
kaynak db 'ABCD'
hedef  db 4 dup('.')

Dizgi İşleme · Kodu adım adım çalıştır

Kod İzleme: LODSB + STOSB ile Büyük Harfe Çevirme

cld: DF = 0 → dizgi komutları SI/DI'yi artırır.

SI kaynağı gösterir: SI = 0111h (metin).

Hedef aynı dizgi: DI = 0111h. COM programında ES = DS olduğundan ES:DI aynı yeri gösterir.

5 karakter işlenecek.

lodsb: AL = [DS:SI] = 6Dh, ardından SI = 0112h.

Bit 5 temizlenir: AL = 4Dh.

stosb: [ES:DI] ← AL, ardından DI = 0112h.

CX = 0004h.

lodsb: AL = [DS:SI] = 69h, ardından SI = 0113h.

Bit 5 temizlenir: AL = 49h.

stosb: [ES:DI] ← AL, ardından DI = 0113h.

CX = 0003h.

lodsb: AL = [DS:SI] = 6Bh, ardından SI = 0114h.

Bit 5 temizlenir: AL = 4Bh.

stosb: [ES:DI] ← AL, ardından DI = 0114h.

CX = 0002h.

lodsb: AL = [DS:SI] = 72h, ardından SI = 0115h.

Bit 5 temizlenir: AL = 52h.

stosb: [ES:DI] ← AL, ardından DI = 0115h.

CX = 0001h.

lodsb: AL = [DS:SI] = 6Fh, ardından SI = 0116h.

Bit 5 temizlenir: AL = 4Fh.

stosb: [ES:DI] ← AL, ardından DI = 0116h.

CX = 0000h.

metin = 'MIKRO'. LODS/STOS çifti diziyi yerinde dönüştürmenin tipik kalıbıdır.

org 100h
cld               ; DF = 0: ileri
lea si, metin
mov di, si        ; aynı yere yaz
mov cx, 5
don:
lodsb             ; AL = [SI], SI++
and al, 0DFh      ; büyük harf
stosb             ; [DI] = AL, DI++
loop don
ret
metin db 'mikro'

Dizgi İşleme · Kodu adım adım çalıştır

Kod İzleme: REPNE SCASB ile Karakter Arama

İleri yönde tarama.

DI = 0114h: taranacak dizgi ES:DI'de olmalı.

En fazla 7 karşılaştırma.

Aranan karakter AL = 'h' (68h).

repne scasb: 'm','e','r','h' ile karşılaştırılır; 4. karşılaştırmada ZF = 1 olur ve durur. Her turda DI++ ve CX−−: DI = 0118h, CX = 0003h.

ZF = 1 (bulundu) → atlama yok.

DI eşleşmeden bir sonrayı gösterir; geri al: DI = 0117h.

Başlangıç çıkarılır: DI = 3 → 'h' 3. indiste (0'dan sayarak).

Bulunamasaydı CX = 0 ve ZF = 0 ile çıkılır, jne yok atlardı.

org 100h
cld
lea di, metin
mov cx, 7          ; uzunluk
mov al, 'h'        ; aranan
repne scasb        ; ara
jne yok
dec di             ; bulunan konum
sub di, offset metin
yok:
ret
metin db 'merhaba'

Kısa (short)EB d8−128 … +127 baytjmp short dongu
Yakın (near)E9 d16aynı kesim, ±32 Kjmp basla
Uzak (far)EA IP CSherhangi bir kesimjmp far ptr hedef
Dolaylı yakınFF /4IP ← yazmaç/bellekjmp bx, jmp tablo[bx]
Dolaylı uzakFF /5CS:IP ← bellek (4 bayt)jmp dword ptr [si]
  • Kısa ve yakın atlamalar görelidir: hedef = sonraki komutun adresi + yer değiştirme. Bu sayede kod bellekte taşınabilir.
  • Dolaylı atlama ile atlama tablosu (switch-case) kurulur: shl bx, 1 / jmp tablo[bx].
  • EB FE kendine atlar (sonsuz döngü): FEh = −2 ve komut 2 bayttır.

Özet

Özet

KodlamaKomut 1–6 bayt: işlem kodu (D, W) + ModR/M + yer değiştirme + anlık veri; önekler başa eklenir.
ModR/MMOD = 11 yazmaç, 00/01/10 bellek; MOD = 00, R/M = 110 doğrudan adres olduğu için [BP] d8 = 0 ile kodlanır.
Veri taşımaXLAT: AL ← [DS:BX + AL]. LEA adresi, MOV içeriği verir; LDS/LES uzak işaretçiyi yükler. Bayraklar değişmez.
DizgiDS:SI → ES:DI, DF yönü, REP/REPE/REPNE ile CX kadar yineleme; CX = 0 ise komut hiç çalışmaz.
JMPKısa (EB d8) ve yakın (E9 d16) atlama göreli, uzak ve dolaylı atlama mutlak adres kullanır.
Bayrak etkileriTaşıma, dizgi taşıma ve atlama komutları bayrak değiştirmez; CMP ile Jcc arasına bayrak etkileyen komut girmemeli.

Özet

Alıştırmalar

  1. mov dx, [bp+di+8] komutunu kodlayın (opcode 100010, d = 1, w = 1).
  2. DS = 1000h, BX = 0200h, AL = 05h iken xlat hangi fiziksel adresteki baytı AL'ye yükler?
  3. Bellekteki uzak dd değişkeninin baytları 34 12 00 B8. les di, uzak sonrası ES ve DI nedir?
  4. CX = 0 iken rep movsb kaç bayt kopyalar?
  5. CLD, CX = 5, SI = 0100h, DI = 0200h; repe cmpsb 3. baytta fark buluyor. Sonra CX, SI, DI ve ZF nedir?
  6. 0150h adresindeki jmp short komutu 0130h'ye atlıyor. Makine kodu nedir?
  7. Bir dizgideki boşlukları sayan kodu repne scasb ile yazın.
İpuçları / cevaplar
  1. MOD = 01, REG = 010 (DX), R/M = 011 ([BP+DI]) → 8B 53 08; kesim SS.
  2. EA = BX + AL = 0205h → 10000h + 0205h = 10205h.
  3. Önce bağıl konum, sonra kesim: DI = 1234h, ES = B800h.
  4. 0: REP önce CX'i sınar; CX = 0 ise dizgi komutu hiç yürütülmez.
  5. Üç karşılaştırma: CX = 2, SI = 0103h, DI = 0203h, ZF = 0. Farklı bayt SI − 1 = 0102h'dedir.
  6. Sonraki komut 0152h; 0130h − 0152h = −22h = DEh → EB DE.
  7. Her bulunuşta sayaç artırılır; CX ≠ 0 ise repne scasb yinelenir (DI kaldığı yerden devam eder).

Özet

Alıştırmalar (2)

  1. 8A 1E 34 12 baytları hangi komuttur? Aynı baytlar bir bayt kaydırılarak (bağıl konum 1'den) çözülürse ne olur?
  2. mov es, dx ve mov al, [0020h] komutlarını kodlayın.
İpuçları / cevaplar
  1. mov bl, [1234h] (8Ah: d = 1, w = 0; 1Eh = 00 011 110 → MOD = 00, R/M = 110: d16). Bağıl konum 1'den: 1E = push ds, 34 12 = xor al, 12h.
  2. 8E C2 (11 000 010: sreg = ES, R/M = DX); A0 20 00 (AL kısa biçimi, adres little-endian).
