Giriş

Öğrenme Çıktıları

Servis çağırma

BIOS ve DOS servislerini AH'deki fonksiyon numarası ve yazmaç parametreleriyle çağırmak.

Ekran çıktısı

INT 10h ve INT 21h ile karakter, renkli karakter ve dizgi yazdırmak; imleci konumlamak.

Klavye girişi

INT 16h ve INT 21h ile tuş okumak, tuş beklemeden yoklamak, satır okumak.

Saat ve sonlandırma

Tarih/saat bilgisini okuyup yazdırmak; programı RET, INT 20h ya da INT 21h/4Ch ile doğru sonlandırmak.

Giriş

BIOS ve DOS Servisleri

  • BIOS (Basic Input/Output System): anakarttaki ROM'da bulunan, donanımı doğrudan süren yordamlar. İşletim sistemi olmadan da çalışır.
  • DOS: BIOS'un üstünde; dosya, dizgi, saat ve program yönetimi sunar.
  • Her iki katmana da yazılım kesmesi (INT n) ile ulaşılır; çağıranın servis adresini bilmesi gerekmez.
Aynı iş farklı katmanlarda yapılabilir: ekrana karakter INT 21h/02h (DOS), INT 10h/0Eh (BIOS) ya da doğrudan B800h ekran belleğine yazarak. Üst katman daha taşınabilir, alt katman daha hızlı ve esnektir.

Giriş

Servis Çağırma Kalıbı

  1. AH ← fonksiyon (servis) numarası
  2. Diğer parametreler: AL, BX, CX, DX, DS:DX, ES:BP …
  3. INT n (10h, 16h, 21h …)
  4. Sonuç yazmaçlarda: AL, AX, CX, DX, ZF/CF …
mov ah, 02h    ; servis: karakter yaz
mov dl, 'A'    ; parametre
int 21h        ; DOS'u çağır

Servisler kendi kullandıkları yazmaçları değiştirebilir (ör. INT 21h/02h ve 09h AL'yi). Sonra gerekecek değerleri başka yazmaçta ya da yığında saklayın.

Giriş

Bir Servis Çağrısı Adım Adım: INT 21h

Çağrı öncesi: parametreler yazmaçlarda (AH = 09h, DX = msg). CS:IP = 0700:0105h, komut int 21h.

İşlemci vektör adresini hesaplar: 21h × 4 = 84h → 0000:0084h.

FLAGS, CS ve dönüş IP'si (0107h) yığına atılır; IF = TF = 0.

CS:IP ← [0000:0086h]:[0000:0084h]. DOS'un INT 21h yordamı AH'ye bakarak 09h servisine dallanır.

Servis biter, iret ile IP, CS, FLAGS geri alınır. Sonuçlar yazmaçlarda (09h için AL = 24h).

Vektör tablosundaki adresler sistemden sisteme değişir; bu yüzden programlar servisleri adresle değil kesme numarasıyla çağırır. Ayrıntılar Bölüm 5: Kesmeler'de.

INT 10h Video

İmleç Konumu: AH = 02h / 03h

  • Satır DH (0–24), sütun DL (0–79); sol üst köşe (0, 0).
  • BH = görüntü sayfası. 80×25 modda 8 sayfa (0–7) vardır; normalde 0 kullanılır.
  • İkisi tek komutla: mov dx, 0C28h → DH = 12, DL = 40 (ekranın ortası).
  • AH = 03h konumu okur: dönüşte DH, DL; ayrıca CH, CL imleç şekli.
  • INT 21h ile yazılan karakterler de bu imleç konumundan başlar.
; imleci ortaya al
mov ah, 02h
mov bh, 0
mov dx, 0C28h   ; 12. satır, 40. sütun
int 10h

; imleci bir sağa kaydır
mov ah, 03h
mov bh, 0
int 10h        ; DH, DL = konum
inc dl
mov ah, 02h
int 10h
Ekran belleği karşılığı: (satır, sütun) hücresinin bağıl konumu = (satır × 80 + sütun) × 2. Örneğin (1, 4) → 84 × 2 = 00A8h; çift adreste karakter, tek adreste öznitelik.

INT 10h Video · Kodu adım adım çalıştır

Kod İzleme: Mod, İmleç, 09h ve 0Eh

AH = 00h (mod seç), AL = 03h (80×25, 16 renk metin). İki yazmaç tek komutla yüklenir.

int 10h: mod ayarlanır, ekran temizlenir, imleç (0,0)'a gider.

AH = 02h: imleç konumunu ayarla.

BH = görüntü sayfası (metin modunda 0–7; normalde 0).

DX = 0104h → DH = 1 (satır), DL = 4 (sütun). Sol üst köşe (0,0).

İmleç satır 1, sütun 4'e taşınır. Ekranda henüz bir şey yok.

AH = 09h: imleç konumuna AL'yi BL özniteliğiyle CX kez yaz.

Yazılacak karakter AL = '*' (2Ah).

BL = 4Eh: arka plan 4 (kırmızı), ön plan E (sarı).

Tekrar sayısı CX = 3.

Ekrana *** yazılır, ama 09h imleci ilerletmez: imleç hâlâ (1,4).

AH = 0Eh: teletype (daktilo) çıkışı.

AL = 'A'.

'A', imlecin bulunduğu (1,4)'e yazılır ve ilk yıldızın üzerine gelir; imleç (1,5)'e ilerler.

AL = 'B'. AH hâlâ 0Eh.

'B' (1,5)'e yazılır: ekranda AB*. 0Eh metin modunda öznitelik almaz; hücrelerdeki 4Eh rengi korunur.

Ders: 09h ile yazdıktan sonra imleci AH = 02h ile kendiniz ilerletmelisiniz.

org 100h
mov ax, 0003h    ; AH=00h, AL=03h
int 10h          ; ekran silinir
mov ah, 02h      ; imleç konumla
mov bh, 0        ; sayfa 0
mov dx, 0104h    ; DH=1, DL=4
int 10h
mov ah, 09h      ; karakter + öznitelik
mov al, '*'
mov bl, 4Eh      ; kırmızı üstüne sarı
mov cx, 3        ; 3 kez
int 10h          ; imleç ilerlemez!
mov ah, 0Eh      ; teletype
mov al, 'A'
int 10h          ; imleç ilerler
mov al, 'B'
int 10h
ret

INT 10h Video · Kodu adım adım çalıştır

Kod İzleme: AH = 13h ile Renkli Dizgi

AH = 13h (dizgi yaz). AL = 01h: tüm karakterler BL özniteliğinde, yazdıktan sonra imleç ilerler.

BH = 0 (sayfa), BL = 1Eh: mavi (1) zemin, sarı (E) yazı.

CX = karakter sayısı. '$' gibi bir bitiş işareti yoktur.

DH = 2, DL = 5: yazmanın başlayacağı konum.

Dizginin adresi ES:BP'de olmalıdır (DS:DX değil!). COM programında ES = DS: BP = 0113h.

Satır 2, sütun 5'ten itibaren Merhaba yazılır; imleç (2,12)'ye gider.

AL = 00h olsaydı dizgi yine yazılır ama imleç eski yerinde kalırdı. AL = 02h/03h'te dizgi karakter, öznitelik çiftlerinden oluşur.

org 100h
mov ax, 1301h    ; AH=13h, AL=01h
mov bx, 001Eh    ; BH=0, BL=1Eh
mov cx, 7        ; dizgi uzunluğu
mov dx, 0205h    ; satır 2, sütun 5
lea bp, mesaj    ; ES:BP → dizgi
int 10h
ret
mesaj db 'Merhaba'

INT 10h Video

BIOS'suz Çıktı: B800h Ekran Belleği

  • Mod 03h'te ekran, B800:0000h'dan başlayan 4000 baytlık bellekte tutulur (80 × 25 × 2).
  • Her hücre 2 bayt: karakter (çift adres) + öznitelik (tek adres).
  • Belleğe yazılan değer ekran kartı tarafından anında gösterilir: kesme çağrısından çok daha hızlı.
  • Sözcük olarak yazarken little-endian: 4E41h → 41h ('A') düşük adrese, 4Eh özniteliğe.
; (1,4) hücresine sarı/kırmızı 'A'
mov ax, 0B800h
mov es, ax
mov di, (1*80+4)*2  ; 00A8h
mov ax, 4E41h
mov es:[di], ax

; tüm ekranı '.' ile doldur
xor di, di
mov ax, 072Eh
mov cx, 2000
cld
rep stosw
Doğrudan yazma imleci hareket ettirmez ve BIOS'un tuttuğu imleç bilgisini güncellemez. emu8086 bu belleği de destekler.

INT 10h Video

Mod 13h: 320×200, 256 Renk

  • mov ax, 0013h / int 10h: 320 × 200 grafik modu. Görüntü belleği A000:0000h – A000:F9FFh (64 000 bayt).
  • Her piksel 1 bayt: renk numarası (palet girişi). İlk 16 renk metin renkleriyle aynıdır: 0Eh sarı, 0Fh beyaz.
  • Satır başına 320 = 140h bayt: ofset = y · 320 + x.
  • Örnek: (100, 50) → 50 · 320 + 100 = 16 100 = 3EE4h.
INT 10h / AH = 0Ch: piksel yaz
ALrenk
BHsayfa (mod 13h'te 0)
CX / DXx (sütun 0–319) / y (satır 0–199)

AH = 0Dh aynı CX, DX ile pikselin rengini AL'ye okur.

INT 10h Video

Köşegen Çizgi: BIOS ile ve A000h ile

INT 10h / 0Ch: koordinatla

mov ax, 0013h
int 10h          ; 320×200, 256 renk
xor cx, cx       ; x = 0
xor dx, dx       ; y = 0
mov bh, 0        ; sayfa
nokta: mov ax, 0C0Eh ; AH=0Ch, AL=sarı
int 10h
inc cx           ; bir sağ
inc dx           ; bir alt
cmp dx, 200
jb  nokta         ; 200 piksel
Neden 141h? +140h (320) bir alt satırın aynı sütununa, +1 bir sağ sütuna gider: 141h = 321. Son piksel (199, 199) = 199 · 321 = F987h. Sağ üstten inen ters köşegen için 13Fh (320 − 1) eklenir.

A000h belleği: ofsetle

mov ax, 0013h
int 10h
mov ax, 0A000h
mov es, ax
xor di, di       ; (0,0) → ofset 0
mov al, 0Eh      ; sarı
mov cx, 200
ciz: mov es:[di], al
add di, 141h     ; 320 + 1
loop ciz
mov ah, 0
int 16h          ; tuş bekle
mov ax, 0003h
int 10h          ; metin moduna dön

Belleğe doğrudan yazma, her piksel için kesme çağırmaktan çok daha hızlıdır.

emu8086'nın grafik desteği sınırlıdır: 0Ch yavaş çizer, A000h'a doğrudan yazma her sürümde görünmeyebilir; DOSBox'ta da deneyin.

INT 16h Klavye · Kodu adım adım çalıştır

Kod İzleme: Enter'a Kadar Oku, Büyük Harfle Yaz

AH = 00h: klavye tamponundan bir tuş bekle ve al.

Kullanıcı O (Shift+o) bastı: AL = 4Fh (ASCII), AH = 18h (tarama kodu).

4Fh ≠ 0Dh.

Enter değil, devam.

'O' (4Fh) < 'a' (61h) → CF = 1.

Küçük harf değil → doğrudan yaz.

AH = 0Eh (teletype). AL'de yazılacak karakter var.

Ekrana O.

Sonraki tuşa dön.

AH = 00h: klavye tamponundan bir tuş bekle ve al.

Kullanıcı k bastı: AL = 6Bh, AH = 25h.

6Bh ≠ 0Dh.

Devam.

'k' ≥ 'a' → CF = 0.

Küçük harf olabilir, devam.

6Bh − 7Ah: ödünç → CF = 1, ZF = 0. Yani 'k' < 'z'.

ja CF = 0 ve ZF = 0 ister; CF = 1 → dallanma yok: küçük harf.

Bit 5 temizlenir: 6Bh − 20h = 4Bh = 'K'.

AH = 0Eh (teletype). AL'de yazılacak karakter var.

Ekrana K.

Sonraki tuşa dön.

AH = 00h: klavye tamponundan bir tuş bekle ve al.

Kullanıcı Enter bastı: AL = 0Dh, AH = 1Ch.

AL = 0Dh → ZF = 1.

Enter → bitti.

Enter'da program biter. INT 16h/00h tuşu ekrana yansıtmaz; yansıtmayı biz yaptık.

org 100h
oku:
mov ah, 0        ; tuş bekle
int 16h          ; AH=tarama, AL=ASCII
cmp al, 0Dh      ; Enter?
je bitti
cmp al, 'a'
jb yaz
cmp al, 'z'
ja yaz
sub al, 20h      ; küçük → büyük
yaz:
mov ah, 0Eh
int 10h          ; ekrana yaz
jmp oku
bitti:
ret

INT 16h Klavye · Kodu adım adım çalıştır

Kod İzleme: AH = 01h ile Beklemeden Yoklama

DX = 0: bekleme sırasında yapılan işi sayacağız.

Arka planda iş yapılıyor: DX = 0001h.

AH = 01h: tuş durumunu sorgula (beklemez).

Tamponda tuş yok → ZF = 1.

ZF = 1 → bekle'ye dön; program donmaz.

Arka planda iş yapılıyor: DX = 0002h.

AH = 01h: tuş durumunu sorgula (beklemez).

Hâlâ tuş yok → ZF = 1.

Yoklamaya devam.

Arka planda iş yapılıyor: DX = 0003h.

AH = 01h: tuş durumunu sorgula (beklemez).

Tuş geldi: ZF = 0, AL = 'x' (78h), AH = 2Dh. Tuş tamponda kalır.

ZF = 0 → döngüden çık.

Tuşu tampondan almak için AH = 00h.

Aynı tuş okunur ve tampondan silinir: AL = 'x', AH = 2Dh.

Oyunlarda ve animasyonlarda bu kalıp kullanılır: çalışmayı sürdür, tuşa basılınca tepki ver.

org 100h
xor dx, dx       ; iş sayacı
bekle:
inc dx           ; arka plan işi
mov ah, 01h      ; tuş var mı?
int 16h          ; ZF=1 → yok
jz bekle
mov ah, 00h      ; tuşu tampondan al
int 16h
ret

INT 21h DOS · Kodu adım adım çalıştır

Kod İzleme: Karakter Oku, Yeni Satır, Karakter Yaz

AH = 01h: klavyeden bir karakter bekle ve ekrana yansıt.

Kullanıcı k bastı: AL = 6Bh, ekranda 'k' göründü.

AL sonraki INT 21h çağrılarında değişeceği için BL'de saklanır.

AH = 02h: DL'deki karakteri yaz.

DL = 0Dh (Carriage Return).

İmleç satır başına döner (görünür bir değişiklik yok).

DL = 0Ah (Line Feed).

İmleç bir alt satıra iner. Yeni satır = CR + LF.

BL = 6Bh + 1 = 6Ch = 'l'.

DL = 'l'.

Ekrana l yazılır. 02h sonrası AL de yazılan karakteri içerir.

Program biter.

org 100h
mov ah, 01h      ; oku + yansıt
int 21h          ; AL = karakter
mov bl, al       ; sakla
mov ah, 02h      ; karakter yaz
mov dl, 0Dh      ; CR: satır başı
int 21h
mov dl, 0Ah      ; LF: alt satır
int 21h
inc bl           ; sonraki harf
mov dl, bl
int 21h

INT 21h DOS · Kodu adım adım çalıştır

Kod İzleme: AH = 09h ile Dizgi Yazdırma

DX = 010Dh: dizginin bağıl konumu. Kesim DS'dir.

AH = 09h: '$' ile biten dizgiyi yaz.

'$' görülene kadar yazılır; 0Dh 0Ah satırı bitirir. Dönüşte AL = 24h ('$').

İkinci dizgi: DX = 011Eh.

AH değişmediği için yeniden yüklemek gerekmez (yine de yüklemek iyi alışkanlıktır).

Çıktı iki satır. '$' karakterinin kendisi bu servisle yazdırılamaz.

org 100h
mov dx, offset msg1   ; DS:DX → dizgi
mov ah, 09h
int 21h
mov dx, offset msg2
int 21h               ; AH hâlâ 09h
ret
msg1 db 'Merhaba, 8086!', 0Dh, 0Ah, '$'
msg2 db 'Gule gule$'

INT 21h DOS

AH = 0Ah: Tamponlu Satır Girişi

Program tamponu hazırlar: tampon db 10, ?, 10 dup(?). Bayt 0 = en fazla 10 karakter (Enter dahil).

Kullanıcı A yazar: karakter 2. konuma gelir ve ekrana yansıtılır. Backspace ile düzeltme yapılabilir.

l ve i de eklenir.

Enter: 0Dh sona yazılır; DOS bayt 1'e okunan sayıyı (3, CR hariç) yazar ve döner.

Metin tampon+2'den başlar, uzunluğu [tampon+1]'dedir. '$' ile bitmez; 09h ile yazdırmak için 0Dh yerine '$' konur.

  • DOS satır düzenlemeyi kendisi yapar (Backspace, Esc); Enter'a basılana kadar program beklemez, çalışmaz.
  • Tampon dolunca fazla tuşlar kabul edilmez ve zil çalar. İlk bayt 0 olamaz.

INT 21h DOS · Kodu adım adım çalıştır

Kod İzleme: İsim Oku, Selam Ver

DS:DX tamponu gösterir: DX = 0120h.

AH = 0Ah: Enter'a kadar satır oku.

Kullanıcı Ali⏎ yazdı. DOS: tampon[1] = 3, tampon[2..4] = 'Ali', tampon[5] = 0Dh. Enter yalnızca CR basar: imleç satır başında.

BL = okunan karakter sayısı = 3 (CR sayılmaz).

BX = 0003h; adres hesaplamasında kullanılacak.

tampon[3 + 2] = tampon[5]: 0Dh yerine '$' yazılır → dizgi AH = 09h ile yazılabilir.

DX = selam.

AH = 09h.

CR LF + 'Merhaba ' yazılır (yeni satırda).

DX = tampon + 2: girilen metnin başlangıcı (0122h).

Çıktı: Merhaba Ali.

tampon[0] = 10: en çok 9 karakter + CR. Fazlası kabul edilmez (DOS zil sesi çalar).

org 100h
mov dx, offset tampon
mov ah, 0Ah          ; tamponlu giriş
int 21h
mov bl, [tampon+1]   ; okunan sayı
mov bh, 0
mov byte ptr tampon[bx+2], '$'
mov dx, offset selam
mov ah, 09h
int 21h
lea dx, [tampon+2]
int 21h
ret
tampon db 10, ?, 10 dup(?)
selam  db 0Dh, 0Ah, 'Merhaba $'

Kod İzleme: Saati SS:DD Biçiminde Yazdırma

AH = 2Ch: sistem saatini oku.

Dönüş: CH = 14 (0Eh) saat, CL = 35 (23h) dakika, DH = 7 saniye, DL = 42 salise.

AL = saat = 0Eh.

Alt program çağrılır: dönüş adresi yığında.

aam: 14 → AH = 1, AL = 4.

Her iki hane ASCII'ye: AX = 3134h.

BX'te sakla; INT 21h/02h AL'yi değiştirir.

DL = onlar hanesi.

AH = 02h.

Ekrana '1'.

DL = birler hanesi.

Ekrana '4' → 14.

Alt programdan dönülür.

DL = ':'.

AH = 02h.

Ekrana ':'.

AL = dakika = 23h (35). CL hiçbir çağrıda bozulmadı.

Dakika için aynı alt program.

Her iki hane ASCII'ye: AX = 3335h.

BX'te sakla; INT 21h/02h AL'yi değiştirir.

DL = onlar hanesi.

AH = 02h.

Ekrana '3'.

DL = birler hanesi.

Ekrana '5' → 14:35.

Alt programdan dönülür.

Ekranda 14:35. Tarih için AH = 2Ah: CX = yıl, DH = ay, DL = gün, AL = haftanın günü.

INT 1Ah ve BIOS Verileri

INT 1Ah: Saat Sayacı ve Gerçek Zaman Saati

AHİşlevDönüş
00htık sayacını okuCX:DX = gece yarısından beri tık, AL = gün döndü bayrağı
02hRTC saatini okuCH = saat, CL = dakika, DH = saniye (BCD), DL = yaz saati; CF = 1: hata
04hRTC tarihini okuCH = yüzyıl, CL = yıl, DH = ay, DL = gün (BCD); CF = 1: hata

RTC, pille beslenen CMOS saatidir (AT ve sonrası); bilgisayar kapalıyken de çalışır.

Paketli BCD → ASCII (CL = 35h, yani dakika 35)

35h = 0011 0101b

Her 4 bit bir onluk hanedir: üst yarım bayt 3, alt yarım bayt 5.

shr dl, cl (CL = 4) → 03h

Üst hane sağa kaydırılır. 8086'da 1'den büyük kaydırma sayısı CL ile verilir.

and dl, 0Fh → 05h

Alt hane maskelenir.

+30h → '3' 33h, '5' 35h

Her hane ASCII rakama çevrilir. INT 21h/2Ch ise aynı dakikayı ikili verir: CL = 23h; orada AAM gerekir.

emu8086'nın desteklediği kesmeler arasında INT 1Ah için yalnızca 00h (tık sayacı) bulunur; 02h'yi gerçek DOS ya da DOSBox'ta deneyin. emu8086'da saati INT 21h/2Ch ile okuyun (INT 21h DOS kısmı).

INT 1Ah ve BIOS Verileri · Kodu adım adım çalıştır

Kod İzleme: RTC Saatini SS:DD:ss Yazdırma

AH = 02h: BIOS gerçek zaman saatini (RTC) oku.

Dönüş paketli BCD: CH = 14h (saat 14), CL = 35h (dakika 35), DH = 07h (saniye). DL = 00h (yaz saati yok).

CF = 0: okuma başarılı. CF = 1 olsaydı saat çalışmıyor demekti; program yazdırmadan biterdi.

CL'ye birazdan kaydırma sayısı yazılacak; dakika önce BL'ye kopyalanır.

CL = 4: SHR DL, CL 4 bit kaydıracak (8086'da 1'den büyük sabit kaydırma yok).

BH = saat = 14h. Alt program değeri BH'de bekler; INT 21h/02h BH'yi bozmaz.

Saat için alt program çağrılır (ikinokta atlanır, doğrudan bcdyaz).

DL = BH = 14h = 0001 0100b.

shr dl, cl: 0001 0100b → 0000 0001b. DL = 01h, yani üst hane.

+30h: DL = 31h = '1'.

AH = 02h: DL'deki karakteri yaz.

Ekrana '1'. DOS, AL'ye DL'yi koyar (AL = 31h).

DL = BH = 14h (ikinci hane için yeniden).

and dl, 0Fh: üst 4 bit silinir: 0000 0100b = 04h.

+30h: DL = 34h = '4'.

Ekrana '4' → 14. AH hâlâ 02h olduğundan yeniden yüklemek gerekmez.

Alt programdan dönülür.

BH = dakika = 35h (BL'de saklanmıştı).

Bu kez ikinokta girişi çağrılır: önce ':' yazar, sonra bcdyaz'a düşer.

DL = ':' (3Ah).

AH = 02h.

Ekrana ':' → 14:. Ardından komut bcdyaz etiketine kendiliğinden geçer (fall-through).

35h → 03h (üst hane).

Ekrana '3' (33h).

35h AND 0Fh = 05h.

Ekrana '5' → 14:35.

Dönülür.

BH = saniye = 07h. DH, INT 21h/02h tarafından değiştirilmedi.

Saniye için yine ikinokta.

DL = ':'.

Ekrana ':' → 14:35:.

07h → 00h (üst hane).

Ekrana '0' (30h).

07h AND 0Fh = 07h.

Ekrana '7' → 14:35:07.

Dönülür.

Ekranda 14:35:07. Aynı saat INT 21h/2Ch ile ikili (CH = 0Eh, CL = 23h) gelirdi; BCD'de onaltılı haneler doğrudan onluk hanelerdir.

org 100h
mov ah, 02h
int 1Ah          ; CH=saat CL=dk DH=sn
jc  son          ; CF=1: saat okunamadı
mov bl, cl       ; dakikayı sakla
mov cl, 4        ; SHR kaydırma sayısı
mov bh, ch
call bcdyaz      ; "14"
mov bh, bl
call ikinokta    ; ":35"
mov bh, dh
call ikinokta    ; ":07"
son: ret
ikinokta: mov dl, ':'
mov ah, 02h
int 21h
bcdyaz:          ; BH = paketli BCD
mov dl, bh
shr dl, cl       ; üst hane
add dl, 30h      ; ASCII rakam
mov ah, 02h
int 21h
mov dl, bh
and dl, 0Fh      ; alt hane
add dl, 30h
int 21h
ret

INT 1Ah ve BIOS Verileri

BIOS Veri Alanını Okumak

; yaklaşık 1 saniye bekle
mov ax, 0040h
mov es, ax
mov bx, es:[006Ch]  ; başlangıç tıkı
bekle:
mov ax, es:[006Ch]  ; şimdiki tık
sub ax, bx          ; geçen tık
cmp ax, 18          ; 18 tık ≈ 0,99 s
jb  bekle

; Caps Lock açık mı? Bekleyen tuş var mı?
test byte ptr es:[0017h], 40h
jnz caps_acik       ; bit 6 = 1
mov ax, es:[001Ah]  ; tampon başı
cmp ax, es:[001Ch]  ; tampon sonu
je  tampon_bos

1 193 182 Hz ÷ 65 536 = 18,2065 Hz

8253/8254 zamanlayıcısı bölen 65 536 iken IRQ 0'ı bu sıklıkta üretir; her kesmede 0040:006C bir artar.

1 tık = 65 536 ÷ 1 193 182 s ≈ 54,9 ms
18 tık ≈ 0,989 s · 5 s ≈ 91 tık

Bekleme süresi tık sayısıyla ölçülür; çözünürlük yaklaşık 55 ms'dir.

Günde 1800B0h = 1 573 040 tık

Sayaç bu değere ulaşınca sıfırlanır ve 0040:0070 bayrağı kurulur.

sub ax, bx ile fark

Yalnız düşük word okunur. Fark alındığı için düşük word FFFFh → 0000h dönse de sonuç doğrudur; yalnız gece yarısındaki sıfırlama hesabı bozar.

emu8086 BIOS veri alanının tamamını gerçek PC'deki gibi güncellemez; tık sayacı ve klavye tamponu örneklerini DOSBox'ta da deneyin.

.model small

Alıştırmalar

  1. Ekranın tam ortasına (12, 38) mavi zemin üzerine beyaz "8086" yazan programı INT 10h/13h ile yazın.
  2. Kullanıcıdan iki rakam okuyup (01h) toplamlarını tek haneli olarak yazdırın (toplam ≤ 9).
  3. Esc'ye basılana kadar basılan tuşların tarama kodunu onaltılı yazdıran bir program yazın.
  4. 0Ah ile okunan metni tersten yazdırın.
  5. Tarihi GG.AA.YYYY biçiminde yazdırın. Yıl için hangi yöntemi kullanırsınız?
  6. mov ah, 09h / int 21h ile '$' karakterini nasıl yazdırırsınız?
  7. Mod 13h'te (160, 100) pikselinin A000h kesimindeki ofseti nedir?
  8. INT 1Ah/02h DH = 59h döndürdü. Ekrana ne yazılır? Aynı saniye INT 21h/2Ch ile hangi değerle gelir?
  9. 0040:006C tık sayacıyla yaklaşık 5 saniye beklemek için kaç tık beklenmelidir?
İpuçları / cevaplar
  1. AX = 1301h, BX = 001Fh, CX = 4, DX = 0C26h, ES:BP → '8086'.
  2. AL'den 30h çıkar, BL'de topla, sonra 30h ekleyip DL ile 02h; arada CR LF yazın.
  3. INT 16h/00h; AH'yi XLAT tablosu ile iki onaltılı haneye çevirin (Bölüm 10'daki örnek); cmp al, 1Bh.
  4. SI = tampon+2+sayı−1'den geriye doğru: std + lodsb + 02h, CX = sayı.
  5. Gün/ay için AAM; yıl (CX) için 10'a tekrarlı DIV ve yığın.
  6. Yazdırılamaz; '$' için 02h servisini (DL = 24h) kullanın.
  7. 100 · 320 + 160 = 32 160 = 7DA0h.
  8. '5' ve '9' → 59; 2Ch ise ikili DH = 3Bh verir.
  9. 5 × 18,2065 ≈ 91 tık.
