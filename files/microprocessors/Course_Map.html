Microprocessors

Course Map

This page puts every chapter of the course on one map. Each chapter is a node, and an arrow shows which idea from an earlier topic the next one relies on. Read it before the course starts to see where the topics are heading, or during the course to see where you are.

Figure 1 shows the connections between the topics. Each node is a chapter, and an arrow indicates which idea of the earlier topic the later one relies on. Only the closest connections are drawn on the map; every chapter that a given chapter depends on is listed in Table 1.

Table 1: The connections on the map.

The backbone of the map can be read as number → architecture → assembly → instruction → hardware. The first three chapters set up the processor and the language used to program it. Two branches grow from there: the memory branch starts with addressing and variables and reaches interrupts and device control; the instruction branch starts with arithmetic and flags and reaches flow control and procedures. The stack is where the two branches meet: CALL with RET and INT with IRET both use it. The instruction-encoding chapter shows how the instructions learned along the way look in machine code.
