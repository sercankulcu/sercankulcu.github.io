Introduction

What Question Does It Ask?

How are biological sequences and molecular data analyzed computationally?

Bioinformatics analyses biological data such as DNA, RNA and protein sequences with algorithms and statistics. The course covers problems such as sequence alignment, genome assembly, gene expression analysis and protein structure prediction, using methods that cope with the size and noise of this data.

Introduction

A Short History

1953

Watson and Crick, drawing also on Franklin's data, propose the double-helix structure of DNA.

1970

Needleman and Wunsch publish a global sequence alignment algorithm based on dynamic programming.

1981

Smith and Waterman publish the local sequence alignment algorithm.

1990

BLAST is published: fast, heuristic similarity search in large databases.

2003

The Human Genome Project is completed; sequencing costs begin to fall rapidly.

2020

AlphaFold 2 predicts protein structure at CASP14 with accuracy close to experimental methods.

Core Concepts

Sequence alignment

Global and local alignment; scoring matrices.

Sequence databases

GenBank, UniProt, PDB; similarity search.

Hidden Markov model

Gene finding and protein family profiles.

Genome assembly

Building a genome from short reads; de Bruijn graphs.

Gene expression

Measuring how active each gene is with RNA-seq.

Phylogenetics

Building the family tree of species from sequences.

Protein structure

Predicting 3D shape from the amino acid sequence.

Multiple testing

Controlling the false discovery rate over thousands of genes.

The Course

A Typical Workflow

Example: A bacterium taken from a patient is sequenced, the short reads are assembled into a genome, and its genes are compared with known sequences in a database using BLAST. If antibiotic resistance genes are found, the physician is told which drugs will not work.

Try It

Align Two Gene Fragments

How similar are DNA fragments of the same gene in two species? The Needleman-Wunsch table finds the best alignment. Change the sequences and scores, then click a cell to see how it was computed.

Bioinformatics turns evolution into a scoring model: filling the table takes m×n steps, while trying every alignment is exponential. The same idea underlies tools such as BLAST.

Practice

Common Misconceptions

Common beliefIn fact
One gene means one trait.Most traits come from many genes and the environment together; few are set by a single gene.
Once a genome is sequenced, its function is known.A sequence is only a string of letters; finding what genes do is a separate, hard analysis.
Bioinformatics is only for biologists.The core of the field is algorithms, data structures and statistics; computer engineers are central.
When thousands of genes are tested, the significant ones are real.Multiple testing inflates false positives; corrections such as the false discovery rate are needed.
