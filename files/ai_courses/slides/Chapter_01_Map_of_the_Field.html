Introduction

What Is This Guide About?

Each of 38 courses on AI and data is introduced in one presentation. The aim is not to teach these courses but to map them: what question does each one ask, which tools does it share with others, and where does it part ways?

What you will find

  • Each course's core question and concepts
  • A short history and a typical workflow
  • Prerequisites and neighbouring courses
  • Overlap and difference tables
  • Applications and tools

What you will not find

  • Lecture notes or a textbook
  • Code examples or assignments
  • Derivations of formulas
  • The full syllabus of any course

Introduction

Nested Terms: AI ⊃ ML ⊃ ANN ⊃ DL

Each ring is a subfield of the one around it: every deep learning model is a neural network, but not every AI system learns. A chess program that searches is AI, but it is not machine learning.

Structure

Structure

Four Kinds of Relation Between Courses

subfield

Deep Learning → Neural Networks

Inherits all of its concepts and adds new ones of its own.

builds on

Computer Vision → Image Processing

The other course comes first; this one is built on top of it.

shares methods

Data Mining ↔ Machine Learning

They use the same tools but ask different questions.

application

Medical Image Processing → Computer Vision

Applies the other course's methods to one domain, under that domain's rules.

Structure

Criteria for Comparing Courses

Core question

The course's reason to exist, in one sentence.

Approach

The way of thinking it brings to a problem: search, statistics, logic, transforms…

Input

What kind of data or specification does the course start from?

Output

What comes out at the end: a decision, a model, an image, a report…

Success measure

How do we tell that a solution is good?

Math load

How much mathematics does it rely on, and which kind?

Data needs

How much data does it need; can it work without data?

How to Use

How to Read This Guide

Front to back

The core courses (Chapters 2–5) are the common language of the whole map; read them first.

From an interest

Images, language, data or robotics: start from the part that interests you and follow the prerequisite tables backwards.

By comparison

Open the "Where It Differs" slides of two courses you tend to confuse side by side.

Choosing electives

The roadmaps in the last chapter suggest groups of courses that make sense together.
