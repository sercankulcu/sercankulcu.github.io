Introduction

What Question Does It Ask?

How do several autonomous agents decide together or against each other?

Multi-agent systems study how several autonomous agents, each deciding with its own goals and knowledge, cooperate or compete in a shared environment. One agent's best decision is not enough: what the other agents will do must be taken into account, and joint behavior is steered by communication and rules.

Introduction

A Short History

1950

Nash defines the equilibrium in which each player best-responds to the others.

1980

Smith publishes the Contract Net protocol, which allocates tasks among agents by bidding.

1987

Reynolds introduces boids, a simulation that produces flocking from three simple rules.

1991

Rao and Georgeff formally define the belief-desire-intention (BDI) agent architecture.

1994

Littman proposes Markov games as the framework for multi-agent reinforcement learning.

1997

The first RoboCup robot soccer tournament is held in Nagoya.

The Course

Core Concepts

Autonomous agent

Decides for its own goal without outside control.

BDI architecture

Agent model that reasons with beliefs, desires and intentions.

Communication language

Messages such as propose, request, inform: FIPA ACL.

Coordination

Making agents' actions fit together without conflict.

Negotiation

Agents with different interests reaching agreement: bargaining.

Auctions and task allocation

Dividing work with Contract Net and auctions.

Nash equilibrium

No agent wants to change its strategy unilaterally.

Emergent behavior

Global order arising from simple local rules.

The Course

A Typical Workflow

Example: A hundred robots pick orders in a warehouse. When a new order arrives, each robot bids based on its position and the best bid wins the job; robots announce their paths to each other and pass through aisles without colliding. There is no all-knowing central planner.

Try It

Delivery Robots Bid for Packages

Three delivery robots work on campus with no manager. Each package is auctioned; each robot bids the extra distance it would add to its route, and the cheapest wins. Run auctions step by step or click the map to add packages.

The problem was solved not by one program but by negotiating agents: in the contract net a manager announces a task and agents bid according to their own cost. Adding a robot does not break a central plan.

Practice

Common Misconceptions

Common beliefIn fact
A multi-agent system is a multi-core program.In a parallel program the parts serve one goal; agents are autonomous and their goals may conflict.
If each agent does its best, the whole is best.As in the prisoner's dilemma, individually rational choices can lead to an outcome bad for everyone.
Coordination needs a central manager.Swarms and auction protocols achieve decentralized coordination through local rules and messages.
Agents always cooperate.Agents can also be rivals; the course studies cooperation, competition and mixtures of both.
