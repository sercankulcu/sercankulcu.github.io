Introduction

What Question Does It Ask?

How do we decide from measurements which class an object belongs to?

Pattern recognition studies how to decide which class an object belongs to by looking at a feature vector extracted from measurements. The course treats the chain from sensor to decision as a whole: preprocessing, feature selection, classifier design and error analysis.

Introduction

A Short History

1936

Fisher publishes linear discriminant analysis; the Iris data from that paper is still the first example.

1962

Hu introduces moment features invariant to translation, scale and rotation.

1967

Cover and Hart show that the nearest neighbor rule's error is at most twice the Bayes error.

1973

Duda and Hart publish the field's core textbook, "Pattern Classification and Scene Analysis".

1991

Turk and Pentland build face recognition on PCA with eigenfaces.

1998

LeCun et al. publish LeNet-5 and the MNIST handwritten digit dataset.

The Course

Core Concepts

Feature vector

Measurements that represent an object: length, color, texture.

Feature space

Each example is a point; classes are regions in this space.

Bayesian decision theory

Choose the class with the largest posterior; minimum error.

Decision boundary

The surface that splits feature space into class regions.

Density estimation

Parametric (Gaussian) or nonparametric (Parzen).

Nearest neighbor

Assign a new example to the class of the nearest labeled ones.

Dimensionality reduction

Few but discriminative features with PCA and LDA.

Confusion matrix

Shows which class is confused with which.

The Course

A Typical Workflow

Example: A mail sorting machine scans the postcode on an envelope, binarizes the image and splits it into digits, extracts shape features from each digit, decides which digit it is with nearest neighbor or an SVM, and sends misread envelopes to manual sorting.

Try It

Reject the Defective Part

Every screw on the line is measured; defective ones are longer on average, but the distributions overlap. Change the defect rate and error cost to move the Bayes boundary; click the chart to measure a part.

Pattern recognition decides with probability and cost: the same measurement changes class when the defect rate or the cost of an error changes. The Bayes rule gives the boundary that minimizes expected loss.

Risks and Ethics

Face recognition without consent

Face recognition enables covert tracking; Clearview AI was fined in several European countries for faces scraped from the internet.

Error gaps between groups

In the Gender Shades study, commercial gender classifiers erred far more often on darker-skinned women than on lighter-skinned men.

Treating all errors alike

If a missed cancer weighs the same as a false alarm, total error looks low while outcomes are dangerous; choose the loss matrix with care.

Leakage in feature selection

Selecting features on the full dataset and then cross-validating makes the error look far lower than it really is.

Practice

Common Misconceptions

Common beliefIn fact
Pattern recognition is the old name for machine learning.The two overlap heavily; pattern recognition is an engineering view that also covers sensing and feature design.
Choosing the classifier is the key step.In most problems feature selection decides success; a good classifier cannot rescue bad features.
With the right features the error drops to zero.If classes overlap, even the best decision errs as much as the Bayes error.
The more features, the better.As dimension grows, examples become sparse (the curse of dimensionality); useless features hurt performance.
