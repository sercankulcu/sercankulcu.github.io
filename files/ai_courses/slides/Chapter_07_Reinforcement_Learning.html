Introduction

What Question Does It Ask?

How can good decisions be learned by trial and error from a reward signal alone?

Reinforcement learning studies how an agent, interacting with its environment and guided only by a reward signal, learns by trial and error the behavior that maximizes total reward in the long run. The right action is never given in advance, and the effects of actions often arrive with a delay.

Introduction

A Short History

1957

Bellman's Dynamic Programming introduces the Bellman equation and the idea of a value function.

1988

Sutton publishes temporal-difference (TD) learning: correcting a prediction with the next prediction.

1989

Watkins proposes Q-learning in his PhD thesis.

1992

Tesauro's TD-Gammon nears expert level at backgammon by playing against itself.

2015

DeepMind's deep Q-network (DQN) learns Atari games from raw pixels (Nature).

2016

AlphaGo beats Lee Sedol at Go: tree search, deep networks and reinforcement learning together.

The Course

Core Concepts

Agent and environment

The agent acts; the environment returns a new state and a reward.

Markov decision process

States, actions, transition probabilities and rewards.

Return

The sum of discounted future rewards.

Policy

A rule that says which action to choose in each state.

Value function

The expected return from a state or an action.

Exploration vs. exploitation

Balancing trying new actions against using what is known.

Temporal difference

TD, Q-learning, SARSA: model-free, step-by-step learning.

Policy gradient

Improving the policy directly with the gradient of the return.

The Course

A Typical Workflow

Example: A warehouse robot observes its position on a grid, usually picks the best direction it knows and sometimes a random one, and gets +10 for reaching the shelf and −1 for hitting a wall. Q-learning updates action values at every step; after thousands of trials a short, safe path emerges.

Try It

The Vacuum Finds Its Charger

The robot vacuum has no map; each step is −1, the charging dock +10, falling down the stairs −10. Let it learn by trial over episodes: train it, then send the robot from the top-left corner.

Nobody showed the robot the way: after each step Q-learning updates the value of the action in that cell with reward + best future value. With no exploration no new paths are found; with too much the robot falls often.

Risks and Ethics

Reward hacking

OpenAI's boat-racing agent circled endlessly to hit the same scoring targets instead of finishing the race.

Unsafe exploration

Trial and error is costly in the real world: a robot or a treatment policy can cause harm while it explores.

Results that do not reproduce

The same algorithm gives very different results across random seeds; an advantage reported over a few seeds can mislead.

Shaping the user

A recommendation policy that maximizes clicks can push users toward more extreme content and compulsive use.

In depth: Explainable AI and AI Ethics.

Common Misconceptions

Common beliefIn fact
RL is just another name for supervised learning.The right action is never given; the agent learns only from rewards and the experience it collects.
Writing the reward is easy.An agent exploits a poorly designed reward with unexpected shortcuts (reward hacking).
A robot that learns in simulation works in reality.The gap between simulation and the real world (sim-to-real) must be handled separately.
RL is only for games.Control, resource management and training language models from human feedback also use RL.
