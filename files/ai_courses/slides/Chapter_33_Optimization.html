Introduction

What Question Does It Ask?

How do we find the values that make an objective function best?

Optimization studies how to find the values that minimize or maximize an objective function while respecting constraints. Training an AI model means searching for the weights that minimize a loss function, so an optimization method runs inside every learning algorithm.

Introduction

A Short History

1847

Cauchy proposes steepest descent (gradient descent) for solving systems of equations.

1947

Dantzig develops the simplex method for linear programming.

1951

Kuhn and Tucker publish optimality conditions for constrained problems (KKT).

1957

Bellman's book Dynamic Programming is published.

1984

Karmarkar introduces a polynomial-time interior point method for linear programming.

2014

Kingma and Ba propose Adam, soon widely used to train deep networks.

The Course

Core Concepts

Objective function

The cost or loss to be minimized.

Constraints

Equalities and inequalities a solution must satisfy.

Linear programming

Linear objective and constraints; the simplex method.

Convexity

Every local optimum is also the global optimum.

Gradient descent

Small steps against the slope.

Stochastic gradient

Using a small part of the data at each step.

Lagrange multipliers

Folding constraints into the objective; KKT conditions.

Integer programming

Integer variables; often very hard.

The Course

A Typical Workflow

Example: Training a neural network is an optimization problem: the variables are the weights and the objective is the average loss. The problem is not convex, so stochastic gradient descent on mini-batches or Adam is used, and the loss curve is watched on a validation set.

Try It

Training a Price Model

A model predicts house prices as “price = w·area + b”; gradient descent moves its two weights toward the lowest loss. Click the map to set the start and change the learning rate.

With a small learning rate the model crawls; with a large one it bounces across the narrow valley and diverges. Scaling the features makes the valley round, which is why normalization speeds up neural network training.

Common Misconceptions

Common beliefIn fact
Gradient descent always finds the best solution.On non-convex problems it can get stuck in a local optimum or at a saddle point.
The larger the learning rate, the faster.Too large a step overshoots the minimum and the loss diverges; too small a step drags training out.
Integer problems are solved by rounding.Rounding the linear solution can break constraints or land far from the optimum.
The lowest loss means the best model.Driving training loss to zero can mean overfitting; in AI the goal is generalization.
