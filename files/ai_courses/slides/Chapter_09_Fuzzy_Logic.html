Introduction

What Question Does It Ask?

How do we reason with concepts like "hot" or "fast" that have no sharp boundary?

Fuzzy logic drops the sharp line between belonging and not belonging to a set; it gives each element a degree of membership between 0 and 1. Rules can then be written with linguistic terms such as "hot" or "fairly fast", and these rules produce a numeric decision or control signal.

Introduction

A Short History

1965

Zadeh publishes "Fuzzy Sets", introducing sets with partial membership.

1973

Zadeh introduces linguistic variables and approximate reasoning with fuzzy IF-THEN rules.

1975

Mamdani and Assilian control a steam engine with the first fuzzy controller.

1985

Takagi and Sugeno propose the fuzzy model whose rule outputs are functions (TS model).

1987

The Sendai subway in Japan opens, accelerating and braking under fuzzy control.

1993

Jang publishes ANFIS, which trains fuzzy rules like a neural network.

The Course

Core Concepts

Fuzzy set

Each element has a membership degree between 0 and 1.

Membership function

Triangle, trapezoid, Gaussian: maps a value to a degree.

Linguistic variable

A variable whose values are words: low, medium, high.

Fuzzy operators

Minimum for AND, maximum for OR, 1-µ for NOT.

Rule base

Rules like IF temperature is high THEN fan is fast.

Mamdani inference

Rule outputs are fuzzy sets, later defuzzified.

Sugeno inference

Rule outputs are functions of the inputs; fast to compute.

Defuzzification

Reducing the fuzzy result to one number: the centroid.

The Course

A Typical Workflow

Example: An air conditioner measures 27 °C in a room; this value belongs to "hot" with degree 0.7 and to "warm" with degree 0.3. The rules "if hot, cool strongly" and "if warm, cool moderately" fire with these degrees, their outputs are aggregated, and the centroid gives the compressor a single power value such as 72 percent.

Try It

Fuzzy Rules Run the Air Conditioner

The air conditioner follows verbal rules such as "if it is hot and humid, run the fan fast". Change temperature and humidity; watch how strongly each rule fires and the resulting fan speed.

Expert knowledge was written as verbal rules; fuzzy logic fires each rule partially, aggregates the outputs and turns them into one number with the centroid. No mathematical model is needed.

Risks and Ethics

Arbitrary membership functions

Who placed the corners of a triangle, and why, is rarely documented; other shapes make the same rules decide differently.

Rule explosion

Rule count grows exponentially with inputs and terms; on combinations nobody wrote, the controller gives unforeseen outputs.

Stability without proof

A controller tuned by trial and error is seldom proven stable in closed loop, which is risky in systems such as brakes.

Subjectivity dressed as numbers

A fuzzy score in medicine or credit, presented as an exact measurement, turns an expert's bias into a scientific-looking number.

Common Misconceptions

Common beliefIn fact
Fuzzy logic is imprecise, sloppy logic.Rules use vague concepts, but the computation is exact; the same input always gives the same output.
A membership degree is a probability.0.7 is the degree of being "hot", not the chance of being hot; degrees need not sum to 1.
Fuzzy logic is an old, abandoned field.It is widely used in appliances and industrial control, and its combination with neural networks continues.
A fuzzy system learns from data.A basic fuzzy system takes its rules from an expert; learning is added by hybrid methods such as ANFIS.
