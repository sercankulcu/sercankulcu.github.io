Introduction

What Question Does It Ask?

How does a computer understand what is in an image or a video?

Computer vision studies how to extract meaning from an image or video: which objects are there, where they are, what 3D structure the scene has. The input is an image, but the output is not an image: it is a label, a box, a mask or depth. Transforming the image is the job of image processing.

Introduction

A Short History

1963

Larry Roberts's PhD thesis recovers 3D blocks from line drawings: the field's first work.

1966

MIT's "Summer Vision Project" expects to solve vision in one summer; it does not.

1982

Marr's book Vision appears, describing vision as a layered computational process.

1999

Lowe introduces SIFT features: local point matching invariant to scale and rotation.

2001

Viola and Jones publish a real-time face detector; it ships in digital cameras.

2012

AlexNet wins ImageNet by a wide margin; the deep learning era in vision begins.

The Course

Core Concepts

Local features

Corners and keypoints: Harris, SIFT, ORB.

Classification

One label for the whole image: "cat".

Object detection

A box and label per object: YOLO, Faster R-CNN.

Semantic segmentation

A class for every pixel: road, pedestrian, car.

Camera model

Pinhole model, calibration, intrinsics and extrinsics.

Multi-view geometry

Stereo, epipolar geometry, structure from motion.

Motion and tracking

Optical flow; following an object frame to frame.

Convolutional networks

CNNs and vision transformers (ViT).

The Course

A Typical Workflow

Example: A driver assistance system grabs a frame from the front camera, balances brightness, extracts features with a convolutional network and marks pedestrians with boxes; it also estimates their distance from a stereo camera. The output is not an image but the fact "pedestrian at 8 meters"; the system issues a brake warning accordingly.

Practice

Risks and Ethics

Face recognition and surveillance

Identifying people in a crowd can turn into tracking without consent; many countries restrict its use in public spaces.

Unequal performance

Error rates can be markedly higher for skin tones and age groups that are under-represented in the training data.

Adversarial examples

A small sticker the human eye ignores can make a model read a stop sign as a different sign.

Safety-critical failures

In self-driving, a single missed pedestrian is a cost that average accuracy does not show.

Practice

Common Misconceptions

Common beliefIn fact
Computer vision is another name for image processing.Image processing transforms the image; vision extracts meaning from it. Vision uses image processing as a first step.
Vision is a solved problem.Networks can still fail noticeably when the lighting, weather or camera differs from the training data.
Vision is just deep learning.Calibration, stereo, SLAM and 3D reconstruction rest largely on geometry.
A model "sees" an object the way a human does.Networks can over-rely on texture and context; a small pixel change can flip a decision.
