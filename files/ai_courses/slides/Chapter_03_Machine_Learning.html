Introduction

What Question Does It Ask?

How does a program generalize from examples?

Machine learning studies algorithms that learn from examples without being explicitly programmed and generalize what they learn to new examples. In Mitchell's definition, a program learns if its performance on task T, measured by P, improves with experience E.

Introduction

A Short History

1957

Rosenblatt introduces the perceptron, one of the first models to tune its weights from examples.

1959

Samuel's checkers program improves by playing itself; the term "machine learning" spreads.

1986

Quinlan publishes the ID3 decision tree; the same year backpropagation revives neural networks.

1995

Cortes and Vapnik publish support vector machines (SVM).

2001

Breiman introduces random forests: a vote among many trees.

2012

AlexNet wins the ImageNet challenge by a wide margin; the deep learning era begins.

The Course

Core Concepts

Supervised learning

Classification and regression from labeled examples.

Unsupervised learning

Clustering and dimensionality reduction on unlabeled data.

Model and hypothesis

The form and parameters of the function to be learned.

Loss function

Measures how wrong a prediction is; training minimizes it.

Generalization

Correct predictions on examples not seen in training.

Overfitting

Memorizing the training data; the bias-variance tradeoff.

Validation

Training, validation and test sets; cross-validation.

Features

Turning raw data into numbers a model can use.

The Course

A Typical Workflow

Example: A spam filter collects past messages and their labels, turns word counts into features, trains a logistic regression, measures accuracy on held-out test messages and classifies new incoming mail. No rules are written by hand; they are learned from data.

Try It

Should We Grant the Loan?

The bank knows the income, debt ratio and repayment outcome of past applications. Click the chart to add a new application; the model decides by looking at the k most similar past ones.

Click somewhere on the chart.
● repaid   ● defaulted. With k = 1, see how the regions split around single examples: that is overfitting.
Nobody wrote the rule: the decision comes entirely from examples. With a small k the model memorizes noise, with a large k it misses detail; the right k is chosen on held-out test data.

Practice

Common Misconceptions

Common beliefIn fact
A more complex model is always better.A complex model can memorize the training data (overfitting) and do worse on new data.
Training accuracy shows success.Success is measured on test data never used in training.
More data solves every problem.More biased or noisy data only multiplies the errors.
The model learns cause and effect.ML finds correlations; causation needs experiments or causal inference.
