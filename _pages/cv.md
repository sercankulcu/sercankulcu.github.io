I am an Assistant Professor of Computer Engineering with professional software engineering experience dating back to 2005. My career combines academic teaching and research with extensive hands-on experience in embedded, real-time, and distributed software systems. I hold a Ph.D. in Computer Engineering, with research focused on low-power wireless communication technologies, and I continue to work across areas including operating systems, wireless networks, computer vision, and software development.

## Education

### <img src="/images/logo-ktu.webp" alt="KTU" width="50" height="50"> Ph.D. in Computer Engineering, Karadeniz Technical University, 2022
During my doctoral studies, I developed a simulation framework using the Cooja network simulator. The framework incorporated a steerable smart antenna model, the 6TiSCH protocol, and a configurable traffic generator. I evaluated its performance by analyzing network throughput, energy consumption, reliability, packet delivery ratio, end-to-end delay, and network lifetime. I also conducted research on the application of computer vision techniques to food science, developing Python and OpenCV algorithms for processing and analyzing food images. This work included the design of a system capable of detecting and classifying food items according to visual characteristics such as color, texture, and shape.

### <img src="/images/logo-hacettepe.webp" alt="Hacettepe" width="50" height="50"> M.S. in Information Systems, Hacettepe University, 2010
During my master's studies, I developed a web-based collaborative dictionary platform inspired by Ekşi Sözlük, using PHP and MySQL. I designed the underlying database architecture to support the efficient storage, retrieval, and management of user-generated content. I also developed a social media sentiment analysis tool using Python and natural language processing techniques to examine the sentiment and topics of posts published on platforms such as Twitter and Facebook. In addition, I designed a scalable social network analysis architecture based on semantic web and big data technologies, covering the full process from data ingestion and modeling to querying, analysis, and visualization.

### <img src="/images/logo-hacettepe.webp" alt="Hacettepe" width="50" height="50"> B.S. in Computer Engineering, Hacettepe University, 2006
During my undergraduate studies, I completed several software and systems projects across different programming environments. I developed a Tetris game in assembly language for the x86 PC platform, using interrupts for keyboard interaction and random number generation. I also implemented a file system in C++ based on the B+ tree data structure, supporting efficient file storage, retrieval, allocation, deletion, and search operations. In addition, I built a Java Swing client-server chat application using sockets for communication over a local network. I also developed a computer vision application capable of detecting vehicle license plates and estimating the speed of moving vehicles.
