This course explores advanced Java development beyond core object-oriented programming. Topics include refactoring, design patterns, collections, concurrency, functional programming, modules, reflection, NIO, networking, databases, enterprise applications, JavaFX, testing, security, and cloud deployment.

## Chapter 8: Working with Annotations and the Reflection API

Annotations provide metadata that can be processed at compile time or runtime. Reflection allows programs and frameworks to inspect and manipulate types dynamically, but it should be used carefully because it can weaken encapsulation, reduce compile-time safety, and complicate maintenance.

- [🗒️Lecture Notes (pdf)](../files/java_advanced/Chapter_08_Working_With_Annotations_And_The_Reflection_API.pdf)
