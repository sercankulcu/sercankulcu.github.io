🧠

Memory

Match all eight pairs in as few moves as possible.

Moves: 0 Time: 0s Pairs: 0/8

How to Play

Open two cards at a time and try to find matching symbols. Matched pairs stay visible. The game tracks your moves and elapsed time. Each new game randomly selects one of four emoji themes.
