How to Play

Fill the grid so every row, column, and 3×3 box contains the digits 1–9 exactly once.

  • Select a cell, then choose a number from the keypad.
  • Notes mode stores pencil marks instead of final answers.
  • Undo / Redo works for numbers, notes, erase actions, and hints.
  • Hint fills the selected empty cell, or another empty cell if none is selected.
  • The generator removes values only when the puzzle still has exactly one solution.
  • Rows, columns, 3×3 boxes, and matching numbers are highlighted for easier scanning.
