Connections

Sort 16 words into four connected groups.

Mistakes: 0/4 Found: 0/4

How to Play

  • Select exactly four words.
  • If all four belong to the same category, that group is solved.
  • You may make up to four mistakes.
  • Shuffle changes only the order of the unsolved words.
  • After the fourth mistake, the remaining groups are revealed.
