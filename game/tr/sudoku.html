How to Play

Classic logic puzzle with notes, hints, and unique-solution generation.

Rules

Fill the grid so every row, column, and 3×3 box contains the digits 1–9 exactly once. Three mistakes end the round.

How to play

  • Select a cell, then choose a number from the keypad.
  • Notes stores pencil marks instead of final answers.
  • Undo / Redo works for numbers, notes, erase actions, and hints.
  • Hint fills the selected empty cell, or another empty cell if none is selected.
  • Rows, columns, 3×3 boxes, and matching numbers are highlighted for easier scanning.

Keyboard

  • Arrow keys move the selection; 1–9 enter a number.
  • Backspace, Delete or 0 erases; N toggles notes.
  • Ctrl+Z undoes, Ctrl+Y redoes.

Notes

  • The generator removes values only when the puzzle still has exactly one solution.
  • The clock stops while the tab is hidden or this help is open.
  • TR / EN switches the interface language; the choice is remembered for all games and tools.
