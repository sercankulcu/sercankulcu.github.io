How to play

How to play

  • Type or paste a 4-digit guess, then press Enter or Check.
  • After each guess you get clues:

Bull — correct digit in the correct position.

Cow — correct digit in the wrong position.

Notes

  • Each digit in the hidden code is different, and the code never starts with 0.
  • Four bulls cracks the code; try to do it in as few attempts as possible.
  • Your best score is kept in this browser.
  • TR / EN switches the interface language.
