PDF to A4 Converter

Convert every page of a PDF to standard A4 size while preserving the original page content.

Drop your PDF here

🔒 Your PDF is processed locally in your browser. The document is not uploaded to a server.

How does it work?

This tool creates a new PDF in which every page uses the standard A4 paper size.

  • Standard A4 size: 210 × 297 mm.
  • The original page proportions are preserved.
  • Content is automatically centered on each A4 page.
  • Pages are scaled so that no content is cropped.
  • Automatic mode keeps landscape pages landscape.
  • You can add a safety margin around page content.

Useful for mixed page sizes, scanned pages, presentation slides, or PDFs that need to print cleanly on standard A4 paper.
