How to use

Security tool: create strong random passwords or memorable passphrases.

Steps

  1. Choose Password for random characters or Passphrase for a string of words.
  2. Adjust the length (or the number of words) and the options. A new value is generated on every change.
  3. Press Generate New for another one, and Copy to put it on the clipboard.

Options

  • Allow ambiguous adds characters that are easy to confuse (I, O, l, 0, 1). They are left out by default.
  • Allow spaces adds the space character to the symbols.
  • At least one character set must stay on; if you turn them all off, lowercase comes back.

Strength

The bar and the bit count estimate entropy. Longer passwords and more words make it higher.

Privacy

Everything is generated locally in your browser with a cryptographic random source. Nothing is sent anywhere.
