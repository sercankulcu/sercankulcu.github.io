How to use

Compress image-heavy PDFs by rendering each page as JPEG and rebuilding the document. Useful for upload-size limits.

How to use

  1. Drop a PDF on the drop zone, or click it to choose a file.
  2. Set the JPEG quality and the render scale. Lower values give smaller files.
  3. Press Compress & Download and compare the new size with the original.
  4. Continue with passes the compressed PDF straight to another tool.

Notes

  • Everything is processed in your browser. The PDF is never uploaded.
  • Important: raster compression removes selectable text, links, forms and vector data. Keep the original PDF.

TR / EN switches the interface language; the choice is remembered for all tools.
