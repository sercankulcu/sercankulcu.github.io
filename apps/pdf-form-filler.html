How to use

Add text, today's date or check marks to a PDF. Choose a page, tap the preview to set the position, then export the filled PDF.

How to use

  1. Drop a PDF on the drop zone, or click it to choose a file.
  2. Pick the page and the item type: text, today's date or a check mark.
  3. Type the text and set the font size.
  4. Tap the preview to choose a position, then tap Add Item. Repeat as needed; Undo removes the last item.
  5. Press Download Filled PDF.

Keyboard

  • Tab to the drop zone and press Enter or Space to choose a file.
  • Focus the preview and use the arrow keys to move the position.

Notes

  • Everything is processed in your browser. The PDF is never uploaded.
  • This tool overlays content onto PDF pages. It does not modify interactive AcroForm fields directly.
