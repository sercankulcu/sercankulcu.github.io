How to use

Metadata tool: inspect PDF document information, XMP metadata and page dimensions without uploading the file.

Steps

  1. Drop a PDF on the box or click it to choose one.
  2. The summary cards show the main facts; the table below lists every field found in the file.
  3. Type in Filter metadata… to narrow the table, and press Copy JSON to copy all fields.

Notes

  • The file is processed locally in your browser.
  • Password-protected PDFs may require a password.
  • Some metadata may be absent by design.
