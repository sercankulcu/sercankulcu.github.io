How to use

Compare two PDF files page by page. Added and removed text is highlighted, and pages can also be viewed side by side.

How to use

  1. Choose or drop the original file as PDF A and the revised file as PDF B.
  2. Set the options (ignore case, normalize whitespace, ignore page numbers) and the diff mode.
  3. Press Compare PDFs.
  4. Switch between Text Diff, Page Summary and Visual Compare and step through the pages.

Privacy

Text extraction and comparison run locally in your browser.

TR / EN switches the interface language; the choice is remembered for all tools.
