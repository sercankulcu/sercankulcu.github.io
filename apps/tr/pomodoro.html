How to use

Boost focus with the Pomodoro technique: 25-minute work sessions, short breaks and long breaks, with session tracking and browser notifications.

Steps

  1. Press Start to begin a work session. The ring colour shows the phase: red for work, green for a short break, blue for a long break.
  2. When a phase ends you hear a beep; press Next to start the following phase.
  3. Each dot is a finished work session. After four work sessions comes a long break.
  4. Skip jumps to the next phase; Reset starts the cycle over (you can undo it from the message).

Keyboard shortcuts

Start / pauseSpace Skip phaseS ResetR FullscreenF

Settings and notes

  • ⚙ sets the work, short-break and long-break durations in minutes. They are saved in this browser.
  • 🔕 / 🔔 turns browser notifications on or off; the browser asks for permission the first time.
  • TR / EN switches the interface language; the choice is remembered for all tools.
