How to use

Metadata tool: inspect metadata stored inside DOCX, XLSX and PPTX files, including core, application and custom document properties.

Steps

  1. Drop a DOCX, XLSX or PPTX file on the box or click it to choose one.
  2. The summary cards show the main facts; the table below lists every field found in the file.
  3. Type in Filter metadata… to narrow the table, and press Copy JSON to copy all fields.

Notes

  • The file is read locally in your browser and is not uploaded.
  • Supports .docx, .xlsx and .pptx. Legacy .doc, .xls and .ppt files use a different binary format.
  • TR / EN switches the interface language; the choice is remembered for all tools.
