Memory Test

Press Start.

Level 1 · Best 0

How to use

A brain test that challenges number memory, sequence memory and visual memory. Each correct answer increases the difficulty.

How to use

  1. Choose a mode: Number, Sequence or Visual.
  2. Press Start and memorize what appears.
  3. Answer correctly to move up a level. A wrong answer ends the run and shows the level you reached; Try Again starts over from level 1.

Modes

  • Number: a number is shown briefly, then type it and press Submit or Enter. It gets one digit longer each level.
  • Sequence: watch the pads light up, then tap them in the same order.
  • Visual: some cells are highlighted briefly, then select all of them. The grid grows from 4×4 to 5×5 and 6×6 at higher levels.

Buttons

  • Restart Level repeats the current level with a new pattern.
  • Reset sets the level and best score back to the start.
  • TR / EN switches the interface language; the choice is remembered for all tools.
