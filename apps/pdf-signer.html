How to use

Add text, today's date, check marks and your signature to PDF pages. Place as many items as you need on any number of pages and download them all at once.

How to use

  1. Drop a PDF on the drop zone, or click it to choose a file.
  2. Pick the page and the item type: text, today's date, a check mark or a signature.
  3. For text, type it and set the font size. For a signature, draw it in the signature pad or use Upload signature image for a ready PNG or JPG (for example one made with Signature from photo). Clear Signature starts it over; changing the ink color repaints the drawn signature.
  4. Tap the preview to choose a position, then tap Add Item. A signature is centered on the point you tapped.
  5. Tap a placed item to select it: drag it to move it, or change its font size or signature width. Delete Selected removes it; Undo removes the last item added.
  6. Change the page number to repeat on other pages, then press Download PDF.
  7. Continue with passes the PDF straight to another tool.

Keyboard

  • Tab to the drop zone and press Enter or Space to choose a file.
  • Focus the preview and use the arrow keys to move the position or the selected item (Shift for bigger steps). Delete removes the selected item; Esc clears the selection.

Notes

  • Everything is processed in your browser. The PDF is never uploaded.
  • The signature is added as a picture on the page; it is not a cryptographic digital signature or a legally qualified electronic signature.
  • This tool overlays content onto PDF pages. It does not modify interactive AcroForm fields directly.
  • Letters such as ş, ğ, İ, ı appear correctly in the downloaded PDF.
