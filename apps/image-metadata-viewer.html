How to use

Metadata tool: inspect image dimensions, file properties and available EXIF metadata, including camera, exposure and GPS fields.

Steps

  1. Drop a JPEG, PNG, WebP, HEIC, HEIF or TIFF image on the box or click it to choose one.
  2. The summary cards show the main facts; the table below lists every field found in the file.
  3. Type in Filter metadata… to narrow the table, and press Copy JSON to copy all fields.

Notes

  • Metadata is read locally in your browser.
  • GPS information is shown only when it exists in the file.
