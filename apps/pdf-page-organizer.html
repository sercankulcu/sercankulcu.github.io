How to use

Reorder, remove and rotate PDF pages. Use a simple output list such as 3,1,2,5.

How to use

  1. Drop a PDF on the drop zone, or click it to choose a file.
  2. Type the output page order as comma-separated page numbers. Repeat a number to duplicate a page.
  3. To delete pages, simply omit them from the output page order.
  4. To rotate pages, list their positions in the output order and choose the rotation.
  5. Press Download Organized PDF.

Notes

  • Everything is processed in your browser. The PDF is never uploaded.
