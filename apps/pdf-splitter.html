How to use

Extract a page range or split every page into separate PDFs — all in your browser.

How to use

  1. Drop a PDF on the drop zone, or click it to choose a file.
  2. Extract range: type the pages you want, such as 1-3, 5, 8-12, and press Extract pages. You get one PDF with those pages.
  3. Split all pages: each page is saved as its own PDF file, bundled into a ZIP archive.
  4. Change file starts over with another PDF.
  5. Continue with passes the result (the extracted PDF, or every single-page PDF after a split) straight to another tool.

Keyboard

  • Press Enter in the page range field to extract.
  • Use the left and right arrow keys to switch between the two modes.

Notes

  • Works entirely offline — no file is ever uploaded.
