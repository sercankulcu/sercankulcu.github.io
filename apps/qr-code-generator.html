QR Code Generator

▦
Enter data and generate a QR code.

How to use

Create QR codes for links, text, Wi-Fi credentials and email.

Steps

  1. Pick a type: URL, Text, Wi-Fi or Email.
  2. Fill in the fields. For Wi-Fi, enter the network name, password and security type.
  3. Choose a size and an error-correction level, then press Generate QR.
  4. Press Download PNG to save the image, or Copy Data to copy the encoded text.

Options

  • Size sets the width of the QR code in pixels.
  • Error correction (L, M, Q, H) adds redundancy so the code still scans when part of it is damaged or covered. Higher levels make denser codes.

Privacy

Local · Private: the code is generated in your browser. Nothing you type, including Wi-Fi passwords, is sent to a server.
