I needed Messenger again and started installing it.

The process felt longer than installing the operating system.

This was probably not literally true, but truth was no longer the main issue. I only wanted a chat program. The software appeared to believe I had requested an ecosystem.

There were screens, components, waiting, and the slow sense that a small tool had returned from several years away carrying administrative responsibilities.

I considered two explanations.

Maybe I had become old.

Maybe they had overdone it.

Both were possible.

Successful software has a strange tendency to grow around its original purpose. A simple application becomes an installer, updater, account system, integration layer, optional feature collection, and finally a place where the original function is somewhere inside if the user remains patient.

Every individual addition probably has a reason.

That is how the final result becomes unreasonable.

The user still arrives with one sentence:

I want to talk to someone.

Software answers:

Excellent. First, let us prepare the environment.

Perhaps age had reduced my tolerance for ceremony. Perhaps the program had genuinely become more complicated. Either way, I had reached the point where simplicity felt less like a missing feature and more like a feature nobody remembered to preserve.

I only wanted Messenger.

Messenger wanted a relationship.
