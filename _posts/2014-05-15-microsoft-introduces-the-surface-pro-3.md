Microsoft introduced the Surface Pro 3 in May 2014 with a larger 12-inch display and a redesigned kickstand. Earlier Surface devices had struggled to convince users that one machine could replace both a laptop and a tablet.

The Pro 3 used Intel Core processors and full desktop Windows, so unlike Windows RT devices it could run ordinary x86 applications. Microsoft also changed the screen to a 3:2 aspect ratio, giving more vertical space for documents and making the device more natural for pen input.

The hardware helped define the modern detachable PC category. Instead of copying the iPad directly, Microsoft leaned into Windows' strength: compatibility with desktop software, keyboards, mice, and productivity workflows.
