The Raspberry Pi 2 arrived in February 2015 with a much larger CPU upgrade than earlier revisions. It moved from a single-core ARM11 processor to a 900 MHz quad-core ARM Cortex-A7 while keeping the familiar board layout and low price.

The new processor used the ARMv7 instruction set, which opened compatibility with a broader range of Linux distributions and software than the original ARMv6-based Pi. Memory doubled to 1 GB, making heavier desktop and server workloads more practical.

The board preserved the GPIO header and accessory ecosystem, so existing hardware projects could migrate without starting from zero. The release showed how a stable physical platform can become more valuable as processor generations improve underneath it.
