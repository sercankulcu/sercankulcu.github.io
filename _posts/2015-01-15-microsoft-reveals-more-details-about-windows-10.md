Microsoft used a January 2015 event to show how Windows 10 would move away from the most controversial parts of Windows 8. The Start menu returned as a desktop element, while Live Tiles remained available inside it.

Microsoft also demonstrated Continuum, which changed interface behavior depending on whether a device was being used with touch or a keyboard and mouse. This was a direct response to Windows 8's attempt to force one full-screen interface across every kind of PC.

Windows 10 also introduced Cortana on the desktop and a new browser project that would become Microsoft Edge. The release strategy itself was changing too: Microsoft increasingly described Windows as a continuously updated service rather than a product replaced by a completely new version every few years.
