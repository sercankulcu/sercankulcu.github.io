Mozilla released Firefox 2 on October 24, 2006, approximately two years after Firefox 1.0 (November 9, 2004) and one year after Firefox 1.5 (November 29, 2005). Firefox 2 ran on the Gecko 1.8.1 rendering engine and introduced features that addressed the practical experience of heavy browser users: session restore (automatically recovering all open tabs after a browser crash, the first major browser to offer this as a built-in feature), inline spell checking for text fields and text areas using the same red-underline convention as desktop word processors (checking as users typed in web forms and comment boxes), a redesigned tab bar with a close button on each individual tab (earlier Firefox versions had a single close button at the far right of the tab bar, requiring users to select a tab before closing it), a search plugins list in the search box dropdown allowing one-click installation of new search engines from any website, and enhanced phishing protection using Google's Safe Browsing API to warn users before loading known phishing URLs. The anti-phishing feature was significant: IE 7 (released October 18, 2006, just six days before Firefox 2) also added phishing filtering as a response to the same threat, revealing that both browsers were tracking the same security problem simultaneously.

The browser landscape in October 2006 made Firefox 2's release significant beyond its specific features. Internet Explorer 6, released August 27, 2001 — over five years earlier — had accumulated 85-90 percent browser market share through bundling with Windows XP. Microsoft had effectively halted IE development after winning the first browser war against Netscape in the late 1990s, leading to a period of web development stagnation: IE6's CSS box model implemented incorrectly (applying padding and border inside the declared element width rather than outside, contrary to the W3C specification), its lack of PNG transparency support (requiring JavaScript-based CSS filters as workarounds), and its proprietary JavaScript quirks had created an entire discipline of browser-specific CSS hacks that web developers were expected to master. Firefox 1.0's launch in November 2004 had demonstrated that browser competition was possible: by 2006 Firefox had reached approximately 13-15 percent global browser market share, entirely from user-initiated downloads rather than OS bundling — proving that users cared enough about speed, security, and the extension ecosystem to actively switch browsers. Mozilla's extension architecture (XUL/XPCOM-based in Firefox 2, later redesigned for WebExtensions) allowed third-party developers to build powerful browser modifications: Adblock (content blocking), Greasemonkey (user scripts to modify any web page), Firebug (the first modern browser developer tool, released 2006 — predating Chrome DevTools), and thousands of other extensions built a developer and power-user ecosystem that drove further Firefox adoption.

IE7, which launched six days before Firefox 2, was Microsoft's direct response to Firefox's competitive pressure — the first major IE update in five years, adding tabbed browsing, an RSS reader, a phishing filter, an improved address bar security indicator, and some CSS2 improvements. IE7 did not fully fix the box model or address many legacy IE6 compatibility issues (sites continued to require IE6 hacks), and it did not run on Windows XP SP1 or earlier (requiring SP2 or later). The simultaneous release of Firefox 2 and IE7 in October 2006 represented the browser competition's return after its post-Netscape dormancy, with both browsers now advancing their standards compliance, security features, and user experience in parallel. This renewed competition set the stage for Chrome's launch in September 2008, which accelerated the browser improvement cycle further by introducing a multi-process architecture, the V8 JavaScript engine (dramatically faster than Gecko's SpiderMonkey in 2008), and an auto-update mechanism that delivered improvements to users weekly rather than in annual release cycles. For web developers in 2006, Firefox 2 and Firebug together provided the first practical environment for debugging HTML, CSS, and JavaScript in a live browser — tools that prefigured the comprehensive DevTools later shipped in every major browser.
