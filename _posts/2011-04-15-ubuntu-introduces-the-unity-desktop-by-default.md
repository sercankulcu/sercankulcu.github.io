Ubuntu 11.04 made the Unity desktop interface the default in April 2011. Unity replaced the traditional GNOME 2 desktop layout with a vertical launcher, a global menu, and the Dash interface for finding applications and files.

The interface was originally created for small-screen netbooks, so Canonical tried to reduce wasted screen space and make launching applications more direct. Unity relied on compositing and 3D acceleration through Compiz, which meant graphics-driver quality affected whether users received the full interface or a fallback experience.

The decision was controversial because Canonical was no longer simply packaging an existing desktop environment; it was defining its own user experience. Unity lasted for several Ubuntu generations before Canonical returned to GNOME in 2017, but the project showed how difficult it is to change desktop habits that users have developed over decades.
