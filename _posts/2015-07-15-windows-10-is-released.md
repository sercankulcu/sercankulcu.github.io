Microsoft released Windows 10 on July 29, 2015 and offered it as a free upgrade to many Windows 7 and 8 users. The Start menu returned, combining a familiar application list with optional Live Tiles.

Windows 10 introduced Microsoft Edge, virtual desktops, DirectX 12, Windows Hello biometric authentication, and a stronger model of continuous system updates. DirectX 12 reduced driver overhead and gave game engines lower-level access to GPU resources, following ideas already visible in AMD's Mantle API.

The operating system also marked a business-model transition. Rather than waiting for users to buy a new boxed version, Microsoft wanted one large installed base that would receive regular feature and security updates for years.
