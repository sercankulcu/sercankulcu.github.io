Microsoft released Windows 10 on July 29, 2015 and offered it as a free upgrade to Windows 7 and 8.1 users for one year. The offer addressed Windows 8's poor reception: launched in October 2012, Windows 8 removed the Start menu in favor of a touch-first tiled interface that laptop and desktop users largely rejected. Windows 8.1 in October 2013 partially reversed course. Windows 10 went further by restoring the Start menu and making the modern interface optional.

Windows 10 introduced Microsoft Edge as the replacement for Internet Explorer, virtual desktops, DirectX 12, Windows Hello biometric authentication using fingerprint or facial recognition, and Cortana as a system-integrated assistant. DirectX 12 reduced CPU driver overhead and gave game engines explicit control over memory management and multi-threaded rendering, following the low-overhead approach AMD had demonstrated with its Mantle API in 2013.

The operating system marked a business-model shift. Windows Vista and 7 had been sold as discrete products with major paid upgrades; Windows 10 was Microsoft's move toward treating the OS as a service with a single, continuously updated version. The goal was to consolidate the fragmented Windows install base — still spanning XP, Vista, 7, and 8.x — onto one platform that developers and IT teams could target with a single security and application compatibility baseline.
