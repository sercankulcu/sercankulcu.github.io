Microsoft released Windows XP Service Pack 3 in May 2008, more than six years after XP first reached consumers and more than a year after Windows Vista launched.

SP3 bundled hundreds of security and reliability fixes and added features that had appeared in newer Microsoft products, including Network Access Protection client support and stronger cryptographic components. Unlike a new Windows version, the service pack tried to improve an enormous installed base without changing the user interface or breaking existing software.

Its importance reflected Vista's difficult adoption. Many businesses and home users were still choosing XP, so Microsoft had to maintain an operating system designed for the early 2000s while the security environment around it had changed dramatically. XP's longevity became both a strength and a maintenance burden.
