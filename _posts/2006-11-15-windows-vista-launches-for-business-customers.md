Microsoft released Windows Vista to volume-license business customers on November 30, 2006 (build 6000.16386 RTM), allowing enterprises to begin testing and deployment before the January 30, 2007 retail consumer launch. The release concluded a five-year development cycle that began as "Longhorn" in 2001 and was reset in August 2004 after the WinFS transactional filesystem — intended to make all Windows data addressable through a unified query interface — proved undeliverable. The reset moved Vista's codebase onto Windows Server 2003 SP1, trading the ambitious WinFS vision for a more conservative but shippable release.

Vista's architectural changes were substantial. The Windows Display Driver Model (WDDM) relocated GPU driver code from kernel mode to user mode, allowing the OS to preempt GPU operations (enabling multitasking between graphics workloads) and making GPU driver crashes recoverable without a system restart — a significant reliability improvement over the Windows XP XPDM model. The Desktop Window Manager (DWM) composited all window rendering through a GPU-backed surface, enabling Aero Glass transparency, live taskbar thumbnails, and Flip 3D (Win+Tab). The audio subsystem moved from kernel-mode WDM to user-mode WASAPI, adding per-application volume control but breaking audio software that had bypassed the audio stack entirely. The TCP/IP stack was completely rewritten (tcpip.sys) with native dual-stack IPv6, RFC-compliant auto-tuning for receive window scaling, and improved support for high-bandwidth WAN links. Service isolation changes ran Windows services under dedicated low-privilege accounts (LocalService, NetworkService) rather than the SYSTEM account, reducing the attack surface from compromised services. BitLocker full-disk encryption shipped in Enterprise and Ultimate editions, using a TPM chip to bind decryption to the hardware configuration.

Business deployments were slower than Microsoft projected. Enterprise application compatibility testing revealed that Vista's privilege model changes (UAC requiring standard-user tokens) broke line-of-business applications that had been written assuming administrative privileges, requiring software vendor patches or Windows Vista compatibility mode — a weeks-long qualification process for large software portfolios. Printer, scanner, and specialty hardware drivers were delayed by the WDDM requirement; many vendors had not written WDDM drivers when Vista shipped. Major enterprises including Dell (which sold PCs with Windows XP "downgrade rights" through 2008) and Pfizer deployed Vista on limited new hardware while maintaining XP on the existing fleet. The difficult business deployment experience directly informed Windows 7's development priority: compatibility with Vista's mature driver ecosystem rather than new architectural changes.
