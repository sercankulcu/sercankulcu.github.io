Canonical released Ubuntu 26.04 LTS “Resolute Raccoon” on April 23, 2026, following the two-year LTS cadence from Ubuntu 24.04 LTS “Noble Numbat” (April 2024) and five years after Ubuntu 22.04 LTS “Jammy Jellyfish” (April 2022). As the eleventh long-term-support release, 26.04 carries the standard five-year free security and maintenance update commitment from Canonical for desktop and server, extensible to ten years through the Ubuntu Pro subscription for enterprise users. The kernel version shipped as the 26.04 HWE (Hardware Enablement) base, with a GA kernel selected for stability and broad driver compatibility across the hardware range certified through Canonical's Ubuntu Certified programme — spanning AMD Ryzen and EPYC, Intel Core and Xeon, Ampere Altra, and the ARM server lineup that had grown substantially in cloud deployments since Graviton2. GNOME 49 on the desktop introduced refinements to fractional scaling (HiDPI displays at non-integer ratios, a long-standing pain point), improved color management pipeline integration, and updated Wayland protocol support across graphics hardware. PipeWire had fully replaced PulseAudio for audio and JACK for pro-audio use cases, completing the audio subsystem transition that began with Ubuntu 22.10.

The 26.04 LTS release coordinated closely with the Ubuntu AI stack: Canonical had been expanding the open-source AI tooling layer across LTS releases since 24.04, and 26.04 shipped with updated versions of Ollama (for local LLM serving), ROCm (AMD GPU compute stack for AI acceleration), and CUDA compatibility packages. Confidential computing support advanced with better integration of AMD SEV-SNP (Secure Nested Paging) and Intel TDX (Trust Domain Extensions) for cloud tenants running sensitive workloads in hardware-isolated VMs — both cloud providers and enterprise on-premises deployments were extending their use of TEE (Trusted Execution Environments) for regulated workloads in healthcare, finance, and government. The Snap application packaging format continued alongside APT/deb, with Canonical updating the policy around core system snaps (the browser snap remained controversial among users preferring apt-managed Chrome and Firefox). Ubuntu Core 26 (the all-Snap minimal server/IoT variant) shipped alongside desktop/server, targeting embedded Linux deployments in IoT gateways, industrial controllers, and edge computing appliances.

As an LTS release, Ubuntu 26.04 became the target for cloud image maintenance, CI/CD pipeline base images, and development container images — environments where predictable behavior and five years of security patches matter more than having the latest upstream versions. Docker Hub's official ubuntu:26.04 image, GitHub Actions' ubuntu-26.04 runner, and cloud marketplace AMIs (Amazon EC2, Google Compute Engine, Azure) were updated in coordination with the release. Canonical's commercial support extended to Ubuntu on Raspberry Pi 5 (BCM2712/Cortex-A76) and AWS Graviton4 (Neoverse V2), both of which had matured as production server platforms since 24.04. Ubuntu 26.04 will reach end of standard support in April 2031; ESM (Extended Security Maintenance) through Ubuntu Pro extends that to April 2036, the same ten-year horizon as Ubuntu 22.04's extended support.
