Microsoft launched Windows Phone 7 on October 21, 2010 in the United States and Europe, introducing hardware from HTC (HD7, Surround), Samsung (Focus, Omnia 7), LG (Optimus 7), and Dell (Venue Pro). The launch was a complete architectural break from Windows Mobile 6.5 (released October 2009), which had attempted to put a desktop-like interface onto a touchscreen — using stylus-oriented menus, scroll bars, and desktop Windows conventions that were poorly suited to finger input. Windows Phone 7 instead adopted the Metro design language (later renamed Modern UI by Microsoft): a home screen of resizable Live Tiles that updated dynamically with current information (new emails, weather, news), horizontal panorama-scrolling UI sections within apps, large Helvetica Neue typography without frames or borders, and a consistent navigation model using three hardware buttons (Back, Start, Search) rather than on-screen navigation. The visual identity was derived partly from transit signage design and represented a deliberate departure from both iOS's skeuomorphic icon grids and Android's fragmented manufacturer skins. The user experience was praised by reviewers as distinctive and fluid; Windows Phone 7 was widely considered a genuinely good mobile operating system design at launch.

The application platform for Windows Phone 7 used Silverlight (Microsoft's browser plugin and cross-platform media framework, based on a subset of .NET and WPF) for most applications, with XNA available for games — both managed environments running on the .NET Compact Framework rather than native code. This prevented legacy Windows Mobile applications from running on Windows Phone 7, breaking compatibility completely with the existing Windows Mobile application ecosystem. The hardware requirements were also standardized: Microsoft mandated minimum specifications of a 1 GHz Qualcomm Snapdragon ARMv7 processor, 256 MB RAM, WVGA (800×480) capacitive touchscreen display, 8 GB storage, accelerometer, GPS, compass, and specific camera hardware, with no capability for manufacturers to substitute alternative hardware configurations. This contrasted with Android's approach, which allowed manufacturers to ship a wide range of hardware configurations at different price points. The mandatory specifications ensured consistent performance across all Windows Phone 7 devices — every WP7 device scrolled at 60fps with the same animation behavior — but constrained the hardware variety and the ability to compete on price in emerging markets. Notable missing features at launch: copy and paste (added in the March 2011 update), multitasking for third-party apps (added in Mango, September 2011), microSD expandable storage (added with limitations in Mango).

Windows Phone 7.5, codenamed Mango (released September 27, 2011), was the most significant update, adding multitasking (apps could suspend and resume without losing state), the IE9 browser engine with HTML5, Twitter integration in the People Hub, turn-by-turn navigation, Bing Music and Vision (camera-based object recognition), and copy-paste. Windows Phone 7's market share never exceeded approximately 3-4 percent globally despite the positive reviews, facing iOS's established App Store with 300,000+ apps and Android's growing ecosystem. The Nokia partnership announced February 11, 2011 — when Nokia CEO Stephen Elop published his internal "burning platform" memo describing Symbian as a burning platform on which Nokia stood, and simultaneously announced that Nokia would adopt Windows Phone as its primary smartphone platform — was meant to provide volume and carrier relationships to Windows Phone. Nokia's first Windows Phone 7.5 devices (Lumia 800 and 710) launched November 2011, with the US Lumia 900 following April 2012. However, Microsoft announced Windows Phone 8 (October 2012) with a new NT kernel (replacing the Windows CE kernel used in WP7), which meant no upgrade path for existing Windows Phone 7 devices — Nokia Lumia 800 and 900 buyers from 2012 would receive only minor updates rather than the new platform. This upgrade discontinuity, combined with the ongoing app gap versus iOS and Android, permanently damaged consumer and developer trust in Windows Phone as a long-term platform, setting the trajectory for Windows Phone's eventual discontinuation announced in 2017.
