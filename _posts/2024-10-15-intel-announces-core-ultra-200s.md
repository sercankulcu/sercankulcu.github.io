Intel announced the Core Ultra 200S desktop processor family in October 2024, bringing the Arrow Lake architecture to desktop PCs. The chips used a tiled design with different functional blocks manufactured using different process technologies.

Unlike several previous Intel desktop generations, Arrow Lake removed simultaneous multithreading from its performance cores. Intel focused instead on efficiency, new Lion Cove performance cores, Skymont efficiency cores, integrated graphics, and a neural processing unit.

The launch showed how desktop CPU design was moving toward heterogeneous packages. A modern processor could combine CPU tiles, GPU logic, I/O, and accelerators manufactured separately and connected in one package, allowing each block to use a process suited to its role.
