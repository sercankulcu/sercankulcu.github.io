Microsoft announced the acquisition of GitHub on June 4, 2018 for $7.5 billion in Microsoft stock — the largest acquisition in Microsoft's history at the time, surpassing the $2.5 billion paid for Minecraft's developer Mojang in 2014. The deal closed October 26, 2018. GitHub CEO Chris Wanstrath, who had co-founded the company with Tom Preston-Werner and P.J. Hyett in 2008, stepped down; Nat Friedman (previously CEO of Xamarin, itself acquired by Microsoft in 2016) was appointed GitHub CEO.

By June 2018, GitHub hosted over 85 million repositories from more than 28 million developers, including the Linux kernel, the CPython interpreter, the Go programming language, and virtually every major open-source framework. Its pull-request model, code review interface, issue tracker, and GitHub Actions (CI/CD workflows, announced October 2018, launched November 2019) had become the default collaboration layer for software development. GitHub had been profitable for several years before the acquisition and was reportedly generating around $300 million in annual recurring revenue — primarily from GitHub Enterprise, the self-hosted version used by large corporations.

Developer reaction was initially skeptical: Microsoft's 2000s-era reputation for hostility toward open source and Linux ("the cancer of intellectual property," then-CEO Steve Ballmer had said in 2001) prompted concern that the company would commercialize or restrict GitHub. Satya Nadella, CEO since 2014, had shifted Microsoft toward open-source contribution — Microsoft had become GitHub's largest open-source contributor by 2017 and had acquired the .NET Foundation, TypeScript, and VS Code development under the open-source umbrella. GitHub continued operating independently, and Microsoft expanded it with GitHub Copilot (AI code completion, launched June 2021 using OpenAI Codex) and GitHub Copilot Enterprise, which became one of the fastest-growing products in Microsoft's history by revenue growth rate.
