Windows 8.1 went on sale on October 17, 2013 as a free update from Windows 8, delivered through the Windows Store — the first time a major Windows upgrade was distributed this way. The update came less than a year after Windows 8 launched on October 26, 2012, an unusually fast response driven by poor reception: Windows 8 had been criticized for replacing the Start menu with a full-screen tile interface that made no accommodation for mouse-and-keyboard users on non-touch PCs.

The most visible change was the return of a Start button to the taskbar, though clicking it opened the full-screen Start screen rather than a traditional menu. Users could now boot directly to the desktop, choose between two tile sizes and a new third small size, snap two apps side-by-side at customizable widths, and search the whole system from a unified search box. DPI scaling improved for high-resolution displays arriving on premium laptops, and SkyDrive (later renamed OneDrive) integrated more deeply with the file system. Internet Explorer 11 shipped as part of 8.1, bringing improved JavaScript performance and better compatibility with enterprise web applications still requiring IE.

Windows 8.1 did not fundamentally reverse the Windows 8 strategy, but it acknowledged that touch-optimized interfaces impose real costs when used with a mouse. Satya Nadella replaced Steve Ballmer as CEO in February 2014, and Windows 10, announced in September 2014, would go further by making the Start menu optional from the desktop again and dropping the mandatory full-screen Start screen for desktop users entirely.
