Windows 8.1 became publicly available in October 2013 as a free update for Windows 8 users. The release tried to soften the conflict between Microsoft's touch-first ambitions and the expectations of traditional PC users.

The Start button returned to the desktop, although it still opened the full-screen Start interface. Users gained more control over tile sizes, multitasking, desktop boot behavior, and synchronization. High-resolution display scaling improved as laptops began shipping with denser screens.

Windows 8.1 did not reverse the Windows 8 strategy, but it acknowledged that input method matters. An interface that works well with fingers on a tablet can become inefficient with a mouse on a large monitor. Later Windows versions would move further back toward a unified desktop-oriented shell.
