Microsoft announced Windows 11 on June 24, 2021. The visible changes included a centered Start menu, redesigned windows, new Snap layouts, and a more consistent visual language.

The hardware requirements created a larger debate. Microsoft required supported CPUs, UEFI Secure Boot capability, and TPM 2.0 on most systems. A Trusted Platform Module can store cryptographic keys and support features such as measured boot and device identity, allowing Windows to build stronger security assumptions into the hardware platform.

Windows 11 also promised Android application support through a subsystem and app-store integration, although that feature arrived later. The release showed that Microsoft was willing to leave some older PCs behind in order to make newer security features part of the baseline.
