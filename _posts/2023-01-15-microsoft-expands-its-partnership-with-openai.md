Microsoft announced on January 23, 2023 a new multi-year, multi-billion-dollar investment in OpenAI, reported as approximately $10 billion — the third major investment after $1 billion in 2019 and approximately $2 billion in 2021. The announcement came 54 days after ChatGPT's November 30, 2022 public launch, during which ChatGPT reached 100 million monthly active users in 2 months — faster than any consumer internet product including TikTok (9 months) and Instagram (2.5 years) to the same milestone. The investment was structured partly in Azure cloud computing credits rather than fully in cash, deepening OpenAI's existing exclusive reliance on Microsoft Azure for all training and inference compute. The financial structure included a "capped profit" arrangement: Microsoft and other investors receive returns up to a specific multiple of their investment, after which OpenAI's nonprofit parent entity receives subsequent profits — a structure designed to allow investor returns while preserving OpenAI's nonprofit mission orientation.

The Microsoft-OpenAI relationship had practical product consequences already underway: GitHub Copilot (launched publicly June 2022 using OpenAI's Codex model, a GPT-3 derivative fine-tuned on code) had reached over 1 million paying subscribers by early 2023, making it the most commercially successful AI developer tool at that point. The Azure OpenAI Service (GA January 2023, the same week as the investment announcement) provided enterprise-grade access to GPT-3.5 and (soon after) GPT-4 through Azure's API infrastructure, with data residency controls, content filtering, and the service-level agreements that Azure commercial customers required — differentiating from accessing OpenAI's API directly on openai.com. New Bing with ChatGPT capabilities launched February 7, 2023, integrating a version of GPT-4 (called "Prometheus" internally, with Microsoft's proprietary Bing search index integration for real-time web results) into Bing's search results and sidebar conversation — the first major search engine to integrate a large language model for conversational responses.

The strategic logic from Microsoft's perspective was to position Azure as the default enterprise AI infrastructure in the same way that AWS's 2006 S3 and EC2 launches had positioned Amazon Web Services as the default enterprise cloud infrastructure — arriving early with the technical capacity to serve the category's leading product, capturing the switching costs and integration patterns that follow. Microsoft announced Microsoft 365 Copilot on March 16, 2023 (integrating GPT-4 into Word, Excel, PowerPoint, Outlook, and Teams), and GitHub Copilot Enterprise (organization-level, codebase-aware completions) throughout 2023. Google's competing responses — Bard (February 2023, initially on LaMDA then upgraded to PaLM 2 in May 2023), Gemini integration in Google Workspace, and Gemini Advanced (February 2024) — validated the assessment that AI integration into productivity software was the central enterprise software competition of the mid-2020s. By the time of GPT-4's formal release on March 14, 2023, Microsoft's Azure OpenAI Service already had access to the model for commercial deployment, demonstrating the structural advantage the partnership provided over competitors with access only to the public OpenAI API.
