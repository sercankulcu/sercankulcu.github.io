Microsoft finalized Windows 8.1 in 2013 less than a year after Windows 8, an unusually fast response to criticism of the new interface. The update preserved the touch-oriented Start screen but restored a visible Start button on the desktop and offered more configuration choices.

Windows 8.1 improved high-DPI display support, multitasking between Store apps, integrated search, SkyDrive synchronization, and access to system settings without returning to the old Control Panel as often. It also added the option for some systems to boot directly to the desktop.

The update showed Microsoft moving toward a faster operating-system release cycle. Instead of waiting years for a major correction, the company used a point release to respond to real-world feedback from keyboard-and-mouse users.
