Microsoft released Windows 8.1 to manufacturing (RTM) on August 27, 2013, completing the build that would go to device makers and enterprise customers before the October 17 public release. RTM meant the code was final and ready for hardware certification — OEMs needed this lead time to preinstall 8.1 on new PCs shipped around the holiday season. The August milestone arrived less than ten months after Windows 8 launched on October 26, 2012, signaling how seriously Microsoft was treating user complaints.

Windows 8.1 added a visible Start button on the desktop taskbar, direct-to-desktop boot as an option, three tile sizes, flexible snap multitasking, unified search via Bing, deeper SkyDrive integration exposing cloud files in File Explorer, and Internet Explorer 11 with improved JavaScript engine performance and better rendering compatibility. High-DPI scaling improved to support the 1920×1080 and higher-resolution displays beginning to appear on premium ultrabooks. Settings previously buried in Control Panel moved progressively into the touch-friendly PC Settings app.

The August RTM also confirmed Microsoft's shift to a faster Windows update pace. Windows Vista to Windows 7 was roughly three years; Windows 7 to Windows 8 was another three years. Responding to Windows 8 criticism within twelve months more closely resembled a web-service update cycle, where user feedback could drive visible product changes before the next major version. Windows 8.1 Update — a further set of fixes targeted at keyboard-and-mouse users — followed in April 2014, and Windows 10 was announced in September 2014.
