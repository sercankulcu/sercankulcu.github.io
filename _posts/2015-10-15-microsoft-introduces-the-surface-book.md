Microsoft announced the Surface Book at a press event on October 6, 2015 — Panos Panay introduced it as "the ultimate laptop" — pricing it at $1,499 (Core i5, 8GB RAM, 128GB SSD, integrated GPU only) up to $2,699 (Core i7, 16GB RAM, 512GB SSD, discrete GPU). It was the first Microsoft Surface product with a clamshell laptop form factor (previous Surfaces were tablets with optional keyboard accessories). The Surface Book's 13.5-inch display (3000×2000 resolution, 267 ppi, 3:2 aspect ratio) was mounted on a proprietary Dynamic Fulcrum Hinge — a curved hinge composed of rotating cylinders that kept the display and keyboard close together without touching the display when open, and which left a visible gap between the closed display and keyboard base. The hinge connected the display and keyboard base with four proprietary electrical contacts that carried USB 3.0 and a PCIe-like signal path, allowing the discrete GPU in the keyboard base to be accessed by the CPU and GPU in the display unit when the laptop was in clamshell mode.

The Intel Core m/i5/i7 Skylake processor and all core system components (RAM, SSD, battery partition, USB, SD card reader, 8MP front camera) resided in the display unit — meaning the display alone functioned as a full tablet running Windows 10 on Intel HD graphics. Higher-tier Surface Books included an NVIDIA GeForce GPU (based on the GM108 "custom" variant with 1GB or 2GB GDDR5 VRAM) mounted in the keyboard base as a Performance Base, connected through the hinge to the CPU in the display. When the keyboard was attached, Windows 10 used the discrete GPU for rendering; when the display was detached, the system transitioned to Intel integrated graphics. The detachment required pressing a dedicated "detach" key, which triggered a driver-coordinated handoff: the OS notified the GPU to finish rendering its current frame, flushed pending work, shut down the PCIe connection to the dGPU, and then allowed the electromechanical hinge release mechanism to unlock, separating the display without data corruption or driver crashes. This entire process took approximately 3–5 seconds. Both the display unit and the keyboard base contained separate battery cells; combined runtime was claimed at 12–16 hours, while the display alone provided approximately 3 hours.

The Surface Book established Microsoft as a direct competitor in the premium laptop segment alongside Apple's MacBook Pro, challenging OEM partners (Dell XPS, HP Spectre, Lenovo ThinkPad X1 Carbon) that built Windows machines using Microsoft's operating system. Microsoft had built Surface tablets (Surface RT October 2012, Surface Pro February 2013) as reference designs to demonstrate Windows capabilities; Surface Book represented an escalation into the primary PC form factor. Surface Book 2 (November 2017) upgraded to 7th/8th generation Intel Core processors, an NVIDIA GeForce GTX 1060 dGPU in the 15-inch Performance Base (the first Surface Book with a 15-inch display option), and improved battery life. The Surface Book 3 (May 2020) with GTX 1660 Ti / Quadro RTX 3000 options completed the line before Microsoft replaced it with the Surface Laptop Studio (October 2021).
