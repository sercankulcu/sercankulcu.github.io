Apple introduced the A12 Bionic processor with the iPhone XS generation in September 2018. It was among the first mass-market chips manufactured using a 7 nm process and combined CPU, GPU, image processing, and machine-learning hardware in one SoC.

The A12 included a next-generation Neural Engine capable of far more operations than the earlier A11 design. Apple exposed this hardware through Core ML so applications could accelerate tasks such as image recognition without sending data to the cloud.

The chip illustrated how smartphone processors were becoming heterogeneous computing platforms. Performance no longer came from one general-purpose CPU alone; specialized blocks handled graphics, photography, video, security, and neural-network operations more efficiently.
