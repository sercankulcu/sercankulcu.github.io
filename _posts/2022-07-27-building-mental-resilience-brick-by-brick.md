Resilience is often described as if some people are simply born strong.

I think it is usually more ordinary than that.

We build it from experience.

A difficult conversation we survive.

A project that fails and gets rebuilt.

A period of uncertainty that eventually passes.

Each experience becomes a small piece of evidence that we can handle more than we expected.

This does not mean hardship is automatically good for us.

Too much pressure can damage people.

There is no need to romanticize suffering.

But manageable difficulty can teach useful things.

We learn what calms us.

We learn when we need help.

We learn which problems become smaller with action and which need time.

Mental models matter too. When I understand that a setback is temporary, I react differently than when I treat it as proof that everything is failing.

Learning and experience slowly improve these models.

I like the image of building with bricks because one brick is not impressive.

Resilience is similar.

It rarely appears in one heroic moment.

It grows through many small moments when we continue, adjust, rest, ask for support, and try again.
