Microsoft ended normal support for Windows 7 on January 14, 2020, more than a decade after the operating system's release. Millions of PCs were still using it, so the event created a large migration and security problem.

An unsupported operating system does not suddenly stop working, but newly discovered vulnerabilities may no longer receive fixes for ordinary users. Browsers, drivers, antivirus tools, and enterprise applications also gradually stop supporting the old platform.

Organizations often found migration difficult because they depended on legacy applications, specialized hardware, or management systems certified only for Windows 7. Its long life demonstrated how successful software can become infrastructure: compatibility becomes so valuable that users resist replacing it even when security support ends.
