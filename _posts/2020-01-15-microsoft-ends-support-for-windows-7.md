Microsoft ended extended support for Windows 7 on January 14, 2020 — a milestone that the company had announced and counted down for years. Windows 7 had shipped October 22, 2009, giving it a 10-year-3-month support lifecycle: mainstream support ended January 13, 2015 (after which no new features or non-security fixes were added), and extended support (security patches only) ran for five additional years until January 14, 2020. At end-of-life, Windows 7 still accounted for approximately 26–33% of all active Windows PCs globally depending on the survey methodology — tens of millions of machines ranging from home desktops to industrial controllers to hospital workstations — making it one of the largest simultaneous end-of-support events in consumer software history. The healthcare sector illustrated the most severe risks: WannaCry (May 12, 2017) had spread via the EternalBlue exploit (a leaked NSA tool targeting the SMBv1 protocol), affecting over 300,000 computers running Windows 7 and Windows XP across 150 countries, shutting down approximately one-third of NHS England trusts and forcing cancellation of 19,000 medical appointments. The SMB vulnerability had been patched (MS17-010, March 14, 2017) but hospitals running Windows 7 systems hadn't applied the patch due to lengthy medical device recertification cycles.

Microsoft offered Extended Security Updates (ESU) as a paid continuation program for organizations that couldn't complete Windows 10 migration by January 2020: $50 per device for the first year, doubling to $100 for Year 2 (2021) and $200 for Year 3 (2022, the final year of ESU). US government agencies (including the Department of Defense) and large enterprises negotiated volume ESU agreements. Healthcare organizations in particular used ESU while awaiting FDA re-certification for medical devices running Windows 7 — legacy imaging equipment (MRI/CT scanners, ultrasound workstations) often ran Windows 7 embedded and required vendor re-certification of the complete system (software + hardware + clinical validation) for any OS change, a process taking 1–3 years. ATMs running Windows 7 (a significant portion of global ATM fleets as late as 2020) required similar bank/manufacturer validation cycles. Microsoft Windows 10 had reached approximately 57% of the desktop market by January 2020, with the free upgrade offer (expired July 29, 2016, though the upgrade tool remained functional informally for longer) having driven significant home user migration.

The application ecosystem began enforcing end-of-life in 2020: Google Chrome 86 (October 2020) was the last version to officially support Windows 7; Google announced January 2020 it would maintain Chrome security updates for Windows 7 through mid-2021. Mozilla Firefox ESR (Extended Support Release) continued Windows 7 support through September 2023 under its extended maintenance policy. Enterprise Java (Oracle JDK/OpenJDK builds) dropped Windows 7 support across different release timelines. The pattern repeated the Windows XP end-of-support experience (April 8, 2014, when XP still held approximately 29% of the PC market): a long tail of users who couldn't or wouldn't migrate remained on unsupported software through years after the official end date, accepting increasing security risk as the ecosystem of patches, browsers, and antivirus vendors progressively dropped support for the legacy OS. Windows 7's decade-long lifecycle demonstrated that highly successful operating system versions become infrastructure that organizations embed into processes and systems, making replacement require organizational change management beyond the technical OS migration itself.
