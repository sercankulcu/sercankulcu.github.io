Ubuntu 25.10 “Questing Quokka” was released on October 23, 2025, the interim release immediately preceding Ubuntu 26.04 LTS, scheduled for April 2026 with five years of standard enterprise support. Like all non-LTS Ubuntu releases, 25.10 received only nine months of security maintenance (through July 2026), targeting developers, enthusiasts, and infrastructure teams who want current software versions rather than the stability-optimized LTS freeze. The release shipped GNOME 48, which introduced a tiled window management feature (GNOME's response to years of community requests for built-in tiling without extensions), updated color management, and improved notification grouping. The included Linux kernel was 6.12, which had reached upstream LTS status in December 2024, adding improved scheduler latency for interactive workloads and continued refinement of the SCHED_EXT extensible scheduler framework that allows user-space BPF programs to implement custom scheduling policies.

PipeWire continued as the default audio and video processing server across all Ubuntu 25.10 configurations, replacing the PulseAudio/JACK split that had complicated professional audio on Linux for over a decade. PipeWire handled both consumer audio (USB speakers, headsets, Bluetooth A2DP) and low-latency professional audio (JACK-compatible applications like Ardour and REAPER) through a single unified server with near-zero reconfiguration, integrating directly into GNOME volume controls and screen recording pipelines. Snap packages remained the default delivery for applications including Firefox, Chromium, and desktop software available through the Ubuntu Software Center, while APT .deb packages continued as the primary mechanism for development toolchains, system libraries, and server software. The Raspberry Pi 5 (BCM2712, ARM Cortex-A76 at 2.4 GHz, 4–8 GB LPDDR4X) received kernel improvements for hardware video decoding and better PCIe M.2 HAT+ support. AMD and NVIDIA GPU driver integration improved for recent hardware generations — RDNA 4 GPUs (RX 9000 series) received updated Mesa drivers, and NVIDIA's open-source kernel module (transitioned from proprietary in 2022) matured further for RTX 50-series Blackwell GPUs.

Ubuntu's six-month release cycle serves two audiences: desktop users who prioritize current software — especially developers who need recent compilers, language runtimes, and toolchain versions — and system engineers preparing what will become the 26.04 LTS baseline that enterprises and cloud providers typically adopt for multi-year deployments. Technologies first shipping in 25.10, from GNOME 48 features to kernel 6.12 defaults, reflected what Canonical intended to freeze into Ubuntu 26.04 LTS with five years of enterprise standard support and ten years of expanded security maintenance through Ubuntu Pro.
