Ubuntu 25.10 “Questing Quokka” shipped in October 2025 as the interim release before Ubuntu 26.04 LTS, the next long-term-support branch scheduled for April 2026. Like all non-LTS Ubuntu releases, 25.10 received only nine months of security support, making it primarily a platform for users who want current software and a testbed for Canonical to validate technologies before freezing them into the longer-support cycle.

The release carried GNOME 48, Linux kernel 6.12, and continued the shift to PipeWire as the default audio subsystem across most configurations. Snap packages remained the default delivery mechanism for some applications, though many users supplemented or replaced Snap with APT-installed .deb packages depending on application startup time and offline availability preferences. The Raspberry Pi 5 support continued to mature, and AMD and NVIDIA GPU driver integration improved for recent hardware generations.

Ubuntu's six-month release cycle serves two audiences: desktop users who prioritize current software — especially developers who need recent compilers, language runtimes, and toolchain versions — and system engineers preparing what will become the 26.04 LTS baseline that enterprises and cloud providers typically adopt for multi-year deployments. Technologies that appear first in 25.10, from kernel features to default configuration choices, usually reflect what Canonical expects to ship in April 2026 with five years of standard support.
