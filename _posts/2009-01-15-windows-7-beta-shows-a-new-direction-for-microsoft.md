Microsoft released the Windows 7 public beta on January 9, 2009, after Steve Ballmer announced it on stage at CES on January 7. MSDN and TechNet subscribers had received Build 7000 on January 7. The release came less than two years after Windows Vista's January 30, 2007 launch, making it one of the fastest major Windows release cycles, driven by the need to recover from Vista's poor reception: Vista's UAC (User Account Control) generated constant prompts for routine tasks, it required 2+ GB RAM to run smoothly on hardware where XP used 512 MB, and driver compatibility failures at launch had left many users unable to use printers, scanners, and peripherals.

Windows 7 shared Vista's NT 6.x kernel generation, WDDM (Windows Display Driver Model) graphics driver framework, and kernel security architecture (DEP, ASLR, UAC). The changes were concentrated in the user-facing layers. UAC was restructured so that common administrative tasks — changing display settings, installing Windows Update patches, connecting to a new Wi-Fi network — no longer required elevation prompts, while operations that genuinely modified system state still did; the net effect was dramatically fewer prompts without removing the security boundary. The taskbar was redesigned into what Microsoft called the "Superbar": applications could be pinned to the taskbar without launching, and running and pinned apps used the same large icons with thumbnail previews on hover. Jump Lists (right-click on taskbar icons) provided quick access to recent documents per application. Aero Snap (drag a window to the screen edge or use Win+Left/Right) split the screen to half-width automatically. Minimum requirements dropped to 1 GB RAM for the 32-bit edition.

Boot time on comparable hardware fell from Vista's 40–60 seconds to approximately 22–30 seconds. The beta received immediate praise in technology reviews, and Microsoft finalized the release quickly — Windows 7 RTM reached build 7600 on July 22, 2009, launching at retail on October 22, 2009 at $119.99 (Home Premium upgrade). It sold 90 million licenses by March 2010, the fastest-selling Windows version in Microsoft's history, and reached 46.5% desktop market share globally by 2011 — Vista peaked at roughly 18%.
