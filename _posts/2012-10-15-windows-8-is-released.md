Microsoft released Windows 8 on October 26, 2012 at $119.99 (Windows 8) and $199.99 (Windows 8 Pro) retail, with a $39.99 upgrade promotion for Windows XP/Vista/7 users available through January 31, 2013. The launch was the most radical Windows interface change since Windows 95: the Start menu was removed entirely and replaced by the Start Screen — a full-screen grid of live tiles that updated dynamically with app content (news headlines, weather conditions, email previews, calendar appointments). The Start Screen and all "Metro" (later "Modern UI") apps ran in a full-screen tiled environment designed for touch input, contrasting with the traditional desktop environment that remained present as a separate mode. Switching between them required either a hot corner gesture, keyboard shortcut, or Start button click — on a non-touch laptop or desktop PC, this context switch felt unnatural, as the Start Screen's large tile targets and swiping gestures were sized for finger input but controlled with a mouse cursor.

The architectural additions were significant: WinRT (Windows Runtime) introduced a new sandboxed application model for Store apps (similar in security concept to iOS app sandboxing) where apps declared capabilities in a manifest (camera, microphone, location, contacts) rather than accessing arbitrary system resources. Windows Store apps distributed through the Windows Store were the only way to install apps into this model. Fast startup used a hybrid shutdown technique (saving the kernel session to the hiberfil.sys hibernate file but logging off user sessions, rather than fully shutting down) to dramatically reduce cold-start time — Windows 8 PCs with SSD storage could reach the login screen in 8–10 seconds versus 30–60 seconds for Windows 7. Secure Boot (UEFI firmware requirement for new PCs) prevented unsigned bootloaders from loading before Windows, protecting against rootkits. The completely redesigned Task Manager showed per-app and per-process CPU, memory, disk, and network usage in graphical time-series views. Microsoft accounts (formerly Live IDs) could sync settings, IE favorites, Store app purchases, and desktop wallpaper across multiple PCs when signed in.

Windows 8 adoption was measurably slower than Windows 7: Windows 8 reached approximately 5.1% of the Windows installed base by February 2013 (3 months post-launch), compared to Windows 7's 15.6% at the same point post-launch. Enterprise IT departments largely declined Windows 8 deployment, continuing with Windows 7. The Windows 8.1 update (October 17, 2013) added a Start button (clicking it went to the Start Screen rather than a Start menu), the option to boot directly to the desktop, and Search/Share/Devices/Settings (the "Charms" bar) accessible by hot corners. Windows 10 (July 29, 2015) restored a Start menu combining the traditional program list with a live tile panel, retired the full-screen Start Screen for non-tablet devices, added back the native windowed mode for Modern apps, and offered a free upgrade for Windows 7/8.1 users — effectively acknowledging that the Windows 8 interface strategy had failed to transfer the tablet experience successfully to the keyboard-and-mouse majority.
